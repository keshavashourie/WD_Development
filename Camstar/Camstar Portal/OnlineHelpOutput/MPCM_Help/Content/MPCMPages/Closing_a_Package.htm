Closing a Package

You can close a single package that has a status of Open, Deployed, Voided, or Rejected on the Package Search page if you have package ownership permissions. You typically close a package after the application successfully deploys it.

You cannot update the contents of a package or deploy it after you close it. You cannot close or void a package that is in a Closed status.

You can close a single package on the Activation Search page that has an Open or Voided package status.

Note: Refer to "Closing Multiple Packages" if you want to select multiple packages and close them at one time.

When Closing a Package

The Close Package pop-up appears when you select a package in the Search Results grid on the Package Search or Activation Search page and select Close Package. You can enter any relevant comments in the Comments field using a maximum of 255 characters and then click Close.

The application performs the following when you click Close:

• Closes the package and places it in Closed status
• Closes the Close Package pop-up
• Displays a success message indicating the following:
• Name of the package
• Date and time at which the package was closed
• Name of the employee who closed it
• Reloads the Search Results grid with the current search criteria and returns you to the same page in the grid
• Records the following information in history:
• Name of the employee who closed the package
• Date and time at which the application closed the package
• Any comments you entered in the Close Package pop-up

How to Close a Package

Follow these steps to close a package:

1. Are you closing the package on the source system or the target system?

If . . .

Then . . .

On the source system

Select Package Search from the Change Management menu. The Package Search page appears.

On the target system

Select Activation Search from the Change Management menu.The Activation Search page appears.
2. Enter or select one or more criteria to narrow your search.
3. Click Search. The application displays the packages matching your search criteria in the Search Results grid.
4. Select the package you want to close. The application displays the relevant transactions for the package.
5. Click Close Package. The Close Package pop-up appears.
6. Enter any relevant comments in the Comments field if necessary.
7. Click Close. The application closes the package, closes the Close Package pop-up, displays a success message, reloads the Search Results grid, and records pertinent information in history.
