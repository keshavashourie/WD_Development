Managing Packages

Change management enables you to perform these tasks:

• Start the change management process by creating a package
• Search for existing change management packages using filters and then perform transactions on the packages returned by the search

You must have roles with appropriate permissions assigned to use each of these options.

These topics provide information on managing packages:

• Creating a Package
• Searching for a Package
• Searching for Multiple Packages to Close, Void, or Open
