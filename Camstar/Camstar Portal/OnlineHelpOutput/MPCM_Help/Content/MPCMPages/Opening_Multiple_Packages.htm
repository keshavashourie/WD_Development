Opening Multiple Packages

You can open multiple packages that have a status of Closed or Voided on the Package Search (Multiple) page if you have package ownership permissions.

You can also open packages that have a package status of Closed or Voided on the Activation Search (Multiple) page if you have activation permissions.

When Opening Multiple Packages

The Open Packages pop-up appears when you select one or more packages in the Search Results grid on the Package Search (Multiple) or Activation Search (Multiple) page and select Open Selected. You can enter any relevant comments in the Comments field using a maximum of 255 characters and then click Open.

The application performs the following when you click Open:

• Places each package back into the workflow, step, and status that it was in before it was closed or voided if you open the package on the Package Search (Multiple) page. For example, if a package was closed while it was at the default Pending Approval Camstar step in a workflow, the application places it at the Pending Approval Camstar step in the workflow with a package status of Open when you re-open it.
Note: The application also returns the modeling object instances within the package to a locked state when you re-open it if the step specifies that the content should be locked.
• Places each package back into the activation status that it was in before it was closed or voided if you opened the package on the Activation Search (Multiple) page. For example, if a package was closed while it was in Activation Incomplete status, the application places it in Activation Incomplete status with a package status of Open when you re-open it.
Note: The activation status is the same. Only the package status (Closed, Voided, Open) changes.
• Closes the Open Packages pop-up.
• Displays a success message indicating the following:
• Name of the first selected package listed in the Search Results grid
• Date and time at which the package was opened
• Name of the employee who opened it
Note: The application opens all selected packages, but displays only the name of the first package in the success message.
• Reloads the Search Results grid with the current search criteria and returns you to the same page in the grid.
• Records the following information in history:
• Name of the employee who opened the packages
• Date and time at which the application opened the packages
• Any comments you entered in the Open Packages pop-up

How to Open Multiple Packages

Follow these steps to open multiple packages:

1. Are you opening packages on the source system or the target system?

If . . .

Then . . .

On the source system

Select Package Search (Multiple) from the Change Management menu. The Package Search (Multiple) page appears.

On the target system

Select Activation Search (Multiple) from the Change Management menu. The Activation Search (Multiple) page appears.
2. Enter or select one or more criteria to narrow your search.
3. Click Search. The application displays the packages matching your search criteria in the Search Results grid.
4. Select the check box in the header row in the Search Results grid to select all displayed packages.

Or

Select the check boxes for individual packages.

5. Click Load Actions. The application enables relevant transactions for the selected packages.
6. Click Open Selected. The Open Packages pop-up appears.
7. Enter any relevant comments in the Comments field.
8. Click Open. The application opens the packages, closes the Open Packages pop-up, displays a success message, reloads the Search Results grid, and records pertinent information in history.
