指派和审核包内容

只有包所有者和协同者才能为包指派内容。“指派和审核内容”页将显示一个或两个选项卡，具体取决于是否已为包启用了内容协同：

• 指派和审核内容

通过“指派和审核内容”选项卡，可以将建模对象实例和引用指派给包。还可以显示包的汇总信息。另外，可以在层次视图中显示所有指派的对象及其引用。

• 协同者任务

仅当已为包启用了内容协同时，才会显示“协同者任务”选项卡。该选项卡由“协同者”表格和指示部分组成。“协同者”表格列出了每个协同者的级别、名称、协同工作的状态、协同工作的指派日期、到期日期和完成日期、协同者注释以及协同者指示。此信息使包所有者可以查看协同工作的状态并确定是否需要跟进。指示部分列出了包所有者对所有协同者的指示以及特定于“协同者”表格中所选任务的指示。这些指示仅供显示。仅当您是指派给包的协同者时，才会显示这些指示。有关启用内容协同的信息，请参考“更新包”。

注释: 如果无法执行协同任务，则应用程序不会显示这些指示。如果包所有者或具有所有者角色的用户指派内容且所有任务的“替代选项”设为“无”，则会出现此情况。

只有为其定义了实例的建模对象才在“指派和审核内容”选项卡上可供选择。应用程序不会显示任何尚未定义实例的建模对象。

通过在过滤器字段中输入前几个字符或整个建模对象名称，可以在“对象”列表中搜索特定建模对象。应用程序将在“实例”列表中显示为所选建模对象定义的所有实例。还可以过滤实例列表。有关信息，请参考“过滤实例列表”。

注释: Designer 应用程序中的设置将确定建模对象实例是否可添加到包中。不公开的抽象建模对象不可用。有关信息，请参考《Opcenter Execution Medical Device and Diagnostics Designer 用户指南》或《Opcenter Execution Core Designer 用户指南》

可以选中“实例”标题行的“全选”复选框以自动选择所有显示的实例，也可以选中各个实例对应的复选框。

单击“添加到表格”按钮会将所选实例添加到“对象类型名称”表格中并更新“包内容汇总”信息。表格中的条目依次按建模对象名称和建模对象实例名称的字母顺序显示。添加的实例保留在“实例”列表中，但显示为已选中并禁用。

注释: 在添加引用之前，应先添加所有建模对象和何处使用实例。

在指派包内容时，添加引用为可选项。如果选择不包含引用，则仍按正确的顺序部署对象。必须按正确的顺序指派建模对象实例，或者仅当“更改管理保存”选项设为“打开”时才添加引用。有关“更改管理保存”选项的信息，请参考“在建模中将建模对象实例指派给包”。

示例：

选择将容器级别建模对象的批、支架和托盘实例指派给包。单击“添加到表格”按钮将在“对象类型名称”表格中显示“容器级别”并更新“包内容汇总”表，以指示一个建模对象和 3 个实例。此外，批、支架和托盘保留在“实例”列表中，但已选中并禁用。

过滤实例列表

应用程序提供了两种方法来过滤“实例”列表中显示的实例：

• 输入要查找的实例名称。在“实例”过滤器字段中输入每个字符时，应用程序将更新实例列表。单击“刷新”图标后，应用程序仅显示包含这些字符的实例。
• 单击“过滤器”图标以使用除实例名称之外的准则。单击“过滤器”图标后，应用程序将显示“实例过滤器”弹出窗口。使用此弹出窗口可指定时间戳、最后更新实例的员工等准则。单击“应用”可关闭“实例过滤器”弹出窗口并查看满足这些准则的所有实例。

应用程序将在“过滤器”图标旁边显示一个图标，指示列表已被过滤。

单击“刷新”图标会移除所有过滤准则，应用程序将显示为所选对象定义的所有实例。在“选择对象”字段中选择其他建模对象也会移除所有过滤准则。单击“过滤器”图标旁边的图标还将重置过滤器。

查看实例在何处使用

在以下情况下，单击“何处使用”按钮将显示“何处使用”弹出窗口：

• 已在“对象类型名称”表格中选择了一个或多个实例，并且
• 已为与登录员工关联的工厂指定了更改管理设置。

“何处使用”弹出窗口显示的建模对象实例直接引用在“对象类型名称”表格中选择的实例。例如，应用程序显示引用所选作业实例的所有规范。应用程序不显示引用那些引用所选作业实例的规范的工作流程。

注释: 更改管理设置将确定可在“对象类型名称”表格中选择的实例数。有关配置“更改管理设置”的信息，请参考《Opcenter Execution Medical Device and Diagnostics Modeling 用户指南》或《Opcenter Execution Core Modeling 用户指南》。

可以将“何处使用”建模对象实例添加到更改管理包中。在“何处使用”弹出窗口中选择实例，然后单击“添加”。

注释: 当满足以下任一条件时，如果单击“何处使用”按钮，应用程序将显示一条错误消息：
• 没有与登录用户关联的更改管理设置。
• 未在“对象类型名称”表格中选择任何实例。
• 选择的实例数超过了在更改管理设置中配置的“何处使用”限制。

指派大量实例和引用

如果指派给包的内容超过 1000 个实例（包括引用），应用程序将显示一条警告消息。该消息警告系统性能可能受到影响，但应用程序不会阻止保存并在稍后部署包。

Siemens 建议查看 CamsarAppServer 应用程序池的 Private Memory Usage 应用程序池设置。在使用 1000 个或更多实例时，可能需要增加该值。有关配置应用程序池内存上限的信息，请参考《Opcenter Execution Medical Device and Diagnostics 系统管理指南》或《Opcenter Execution Core 系统管理指南》。

注释: 即使继续超过包的 1000 个实例阈值，应用程序也只显示该警告消息一次。

导出大量实例和参考时，应用程序可能超时或产生意外的结果。可以在以下位置中通过更新值来增加超时设置：

• Management Studio - 在“站点”树中选择“配置节点”，然后选择“数据库连接”选项卡。字段处于空闲状态后，将“关闭连接”中的值增加到 500 秒。
• Management Studio - 在“站点”树中选择“配置节点”，然后选择“安全”选项卡。将“空闲会话超时”字段中的值增加到 30 分钟。
注释: 有关 Management Studio 的信息，请参考《Opcenter Execution Medical Device and Diagnostics 系统管理指南》或《Opcenter Execution Core 系统管理指南》。
• XMLClientConfig.xml - 默认情况下，XMLClientConfig.xml 文件位于 C:\Program Files (x86)\Camstar\InSite Utility 中。将 SendTimeout 和 ReceiveTimeout 的值增加到 500000。
• Web.config - 默认情况下，Web.config 文件位于 C:\Program Files (x86)\Camstar\CamstarPortal 中。在 system.web 节点的 httpRuntime 设置中增加 executionTimeout 值。默认值为 110 秒。

通过应用程序可以添加对角色的引用，但这可能会导致应用程序在对包执行任务时超时。必须从包中移除对角色的引用才能完成这些任务。

完成内容协同

可以在“协同者任务”选项卡上的“协同者”表格中查看协同工作的状态。在加载页面时，应用程序会为当前登录的协同者选择默认任务。“对协同者的指示”部分中的指示包含对当前选定任务的指示。如果在表格中选择了其他任务，应用程序将更新此部分中显示的指示。一次只能在表格中选择一个任务。

可将内容指派给在“指派和审核内容”选项卡中选择的包。如果您是协同者，在执行完协同任务后，在“指派和审核内容”选项卡上单击“完成”。

注释: 协同者还可以在“建模”中为包指派内容或者从包中移除内容。有关信息，请参考“在建模中将建模对象实例指派给包”。

单击“完成”时，将显示“内容协同者 - 完成的指派”弹出窗口。此弹出窗口由“协同者”表格和注释部分组成。该表格列出了每个协同者的级别、名称、协同任务状态以及协同任务的指派日期和到期日期。

“协同者”表格仅列出当前登录的协同者有资格完成的任务。合格任务包括：

• 在当前级别或任何先前级别指派给当前登录协同者的任务。
• 在当前级别或任何先前级别指派给其他协同者的任务（只有在当前登录的协同者具有使用“替代选项”定义的角色时）。

应用程序会为当前登录的协同者选择表格中的默认任务。可以选择任何任务。

单击“完成”时，在此弹出窗口中输入的任何注释都会显示在“协同者任务”选项卡上“协同者”表格的“协同者注释”字段中。应用程序还会更新“协同者任务”选项卡上的“状态”和“完成日期”字段。如果包所有者在“更新包”页的“协同者”选项卡上指定了“给所有者的完成消息”，则应用程序会向包所有者发送电子邮件通知，以指示协同者已完成将内容指派给包。如果在“更新包”页的“协同者”选项卡上选中了“更新时向协同者通知指派情况”复选框，则应用程序还会向下一个协同者（如果指定）发送电子邮件通知。

如果多次单击“完成”，则应用程序会将最新注释保存到“协同者任务”选项卡上的“协同者注释”字段中。

在“更新包”页上添加协同者时，如果包所有者未指定“持续时间”和“期限”，则应用程序会在“协同者任务”选项卡上将“到期日期”和“状态”分别设为“指派日期”和“逾期”。

只要包所处的工步已配置指派和审核内容，在单击“完成”按钮后，协同者就可以通过应用程序继续将内容指派给包。

在指派内容并完成每个任务时，应用程序会列出所有新的合格任务，而无需在完成每个任务后关闭“指派和审核内容”页。
