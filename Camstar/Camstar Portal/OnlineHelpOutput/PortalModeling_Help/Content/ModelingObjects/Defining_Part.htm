Defining Parts

This page enables you to update or edit specifications of a part after it is created.

Note: Part is created in Part Create page. To access the page, navigate to Resource > Parts > Part Services > Part Create.

How to Define a Part

Follow these steps to define a Part:

1. Open the Part modeling page. The Part page appears within the Modeling page.
2. Select Part instance from the displayed modeling instances list.
Note: Part can be created in the Part Create page. To access the page, navigate to Resource > Parts > Part Services > Part Create.
3. Select the Material Part.
4. Select the Part Quantity.
5. Enter optional information according to your business requirements. Refer to "Common Fields on Modeling Pages" for information on the fields common to all modeling objects.
6. Click Save. The application saves the modeling object and displays a success message.
