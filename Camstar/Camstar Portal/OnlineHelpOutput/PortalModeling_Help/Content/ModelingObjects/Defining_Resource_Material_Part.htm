Defining Resource Material Parts

The Resource Material Part page enables you to configurethe maintenance characteristics of resource material parts that are often used to create parts. A resource material part is a required field when a new part is created using the Part Create transaction. Multiple parts can be created using the same Resource Material Part.

The quantity of each part created using the same resource material part will be added to the total quantity of the resource material part. Each part is governed by the maintenance characteristics of its resource material.

Note: This page is referring to the Resource Material Part —not Material Parts used for products.

Part Type

Represents how material parts are to be inventoried and tracked. There are three types:

• Serialized: Requires a new lot to be created for each shipment.
• Bulk: Requires a new lot the first time the material part is shipped. Subsequent shipments from the same mother lot can be inventoried by increasing the quantity of the lot initially created.
• Non-serialized: No lot is created. It generally suffices to record the batch Id for traceability purposes.

How to Define a Resource Material Part

Follow these steps to define a Resource Material Part:

1. Open the Resource Material Part modeling page. The Resource Material Part page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Resource Material Part field.
4. Enter a Part Qty.
5. Enter optional information according to your business requirements.Refer to "Common Fields on Modeling Pages" for information on the fields common to all modeling objects.
6. Click Save. The application saves the modeling object and displays a success message.
