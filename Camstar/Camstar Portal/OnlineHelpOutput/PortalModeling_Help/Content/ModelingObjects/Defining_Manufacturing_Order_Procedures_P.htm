Defining Manufacturing Order Procedures

A manufacturing order procedure (Mfg order procedure) is a revisionable object that enables you to assign a collection of tasks to an order.

When Defining Manufacturing Order Procedures

Make sure you have defined one or more Mfg task lists before defining an Mfg order procedure. The application requires you to assign at least one Mfg task list to an Mfg order procedure.

You cannot use invalid characters in the object name. For example, you cannot use an apostrophe.

Note: Refer to the Opcenter Execution Medical Device and Diagnostics Designer User Guide or the Opcenter Execution Core Designer User Guide for information.

Manufacturing Order Procedure is an optional field in these definitions on an Mfg Order: Pre-Production Procedure and Post-Production Procedure.

How to Define a Manufacturing Order Procedure

Follow these steps to define an Mfg Order Procedure:

1. Open the Manufacturing Order Procedure page. The Manufacturing Order Procedure page is displayed within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Mfg order procedure in the Manufacturing Order Procedure field.
4. Enter the revision of this Mfg order procedure in the Revision field.
5. Select an Execution Mode from the list.
6. Add one or more manufacturing order task lists to the Manufacturing Order Task Lists grid using the "How to Add a Manufacturing Task List to the Manufacturing Order Procedure" procedure.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Save. The application saves the modeling object and displays a success message.

How to Add a Manufacturing Task List to the Manufacturing Order Procedure

Follow these steps to add a task list to a Mfg Order Procedure:

1. Perform the "Defining Manufacturing Order Procedures" procedure.

Or

Select an existing Mfg Order Procedure instance.

2. Click Add new row in the Manufacturing Order Task Lists grid. A new row appears.
3. Click in the field to display a list of Mfg order task lists.
4. Select the task list to associate with this Mfg order procedure.
5. Repeat steps 2-4 to add additional task lists.
6. Click Save. The application saves the modeling object and displays a success message.
