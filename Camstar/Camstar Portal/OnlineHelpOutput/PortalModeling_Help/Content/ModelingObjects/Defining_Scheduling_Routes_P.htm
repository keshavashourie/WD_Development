Defining Scheduling Routes

Scheduling Route enables configuration of specific scheduling routes without leveraging ERP routes. You can define and apply an alternative scheduling route that can be used to identify steps for scheduling integration. Instances of scheduling routes will take precedent over any previously configured ERP routes used within prior scheduling configuration. If no scheduling routes are configured or detected by the application, any previously configured ERP route configured to identify scheduling steps will continue to be used as the default.

Note: You must balance the selection of maximum scheduling steps to optimize the time to generate data and schedules. An increased number of scheduling steps will result in increased scheduling integration run time and may possibly trigger a run-time failure.

How to Define a Scheduling Route

Follow these steps to define a Scheduling Route:

1. Open the Scheduling Route page. The Scheduling Route page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Scheduling route in the Scheduling Route field.
4. Enter the name of this route step in the Route Step Name field.
5. Refer to the "How to Add Route Steps to a Scheduling Route" procedure to add route steps.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.

How to Add Route Steps to a Scheduling Route

Follow these steps to add route steps to a Scheduling Route:

1. Perform the " How to Add Route Steps to a Scheduling Route" procedure.

Or

Select an existing Scheduling Route instance.

2. Click Add new row on the Route Steps grid. A new row appears.
3. Enter the name of this route step in the Route Step Name field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Repeat steps 2-4 to add additional route steps.
6. Click Save. The application displays a success message indicating the modeling object was updated.
