SPC Real Time Monitoring

The SPC Real Time Monitoring page enables you to generate and automatically refresh Inline SPC charts with the most up-to-date (real-time) data.

When Using SPC Real Time Monitoring

You must select a Container, SPC Chart, SPC Chart Group, or Data Collection.

SPC Real Time Monitoring Page Field Definitions

This table defines the fields unique to the SPC Real Time Monitoring page.

Refer to "Common Fields on Modeling Pages" for information on the fields common to all modeling objects.

Definition

Type

Name or ID of the container. Values in the SPC chart and SPC chart group fields are filtered by the container field.

Time slider for refresh rate. Time between refreshes increases the further that you drag the bar to the right. The minimum interval is 10 seconds. The maximum interval is 600 seconds. The default setting is 300 seconds.

How to Use SPC Real Time Monitoring

Follow these steps to use SPC Real Time Monitoring:

1. Select SPC Real Time Monitoring from the SPC menu. The SPC Real Time Monitoring page appears.
2. Select a Container, SPC chart, SPC chart group, or Data Collection. Only one is required.
3. Click Generate Charts. The charts available for the entered filter criteria appear.
4. Slide the Refresh Interval slider to the left or right to increase or decrease the refresh rate for the charts. The charts refresh at the selected interval.
