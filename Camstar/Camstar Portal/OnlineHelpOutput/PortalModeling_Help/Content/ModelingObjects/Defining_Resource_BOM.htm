Defining Resource BOMs

A Resource BOM (a bill of materials for a resource) is a modeling object that enables you to categorized material part based on the same purpose or business requirement. A resource BOM can contain one or more Resource Material Parts.

Where Resource BOMs are Used

Resource BOM is referenced in the following places:

• Maintenance Requirement - A Resource BOM helps to categorize parts required to create Jobs due to a maintenance violation.
• Resource - A Resource BOM helps to categorize parts required for a resource.

How to Define a Resource BOM

Follow these steps to define a Resource BOM:

1. Open the Resource BOM page. The Resource BOM page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the BOM in the Resource BOM field.
4. Click Add new row on the Material List grid. A new row appears.
5. Enter the Material Part including the revision number.
6. Enter the Quantity Required.
7. Repeat steps 4-6 to add additional resource material parts for this resource BOM.
8. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
9. Click Save. The application saves the modeling object and displays a success message.
