Tool Definitions

A tool is a type of equipment resource. Tool Management enables you to define tools, tool families, tool groups, tool plans, and tool matrices. Tool plans are assigned to equipment resources so that the application can validate the resources prior to Move In. You can also define tool plan matrices for the application to dynamically select tool plans based on run-time criteria.
