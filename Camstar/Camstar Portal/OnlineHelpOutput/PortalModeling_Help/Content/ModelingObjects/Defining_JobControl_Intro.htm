Job Control Definitions

The Job Control module provides functionality to define, initiate, schedule, and track manufacturing resource repair and maintenance jobs. Each job consists of a workflow that is configured using the Job Model object.

Refer to Opcenter Execution Core Shop Floor Guide for information.
