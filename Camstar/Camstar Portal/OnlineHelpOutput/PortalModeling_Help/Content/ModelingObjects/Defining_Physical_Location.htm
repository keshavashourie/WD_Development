Defining Physical Locations

Physical Location page enables you to create and configure specific areas within a factory. A location can be as broad as the entire shop floor or as specific as a shelf.

Physical location can be further specified using physical positions. For example, Warehouse A (physical location) can consists of Rack 1, Rack 2, and Rack 3 (physical positions).

How to Define a Physical Location

Follow these steps to define a Physical Location:

1. Open the Physical Location modeling page. The Physical Location page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Physical Location field.
4. Enter optional information according to your business requirements. Refer to "Common Fields on Modeling Pages" for information on the fields common to all modeling objects.
5. Click Save. The application saves the modeling object and displays a success message.
