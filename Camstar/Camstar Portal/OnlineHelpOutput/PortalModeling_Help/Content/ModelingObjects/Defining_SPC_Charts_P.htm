Defining SPC Charts

The SPC Chart modeling object contains information required to display a single SPC chart. It describes the type of chart, SPC Query object, Inline SPC Rules, Out of Control Actions and Procedures (OCAPs), and the variables being plotted for Inline SPC charts.

The SPC Chart modeling object also describes the type of chart, Statit Software macro, Statit Software Rules file, Out of Control Actions and Procedures (OCAPs), and the variable being plotted for Legacy SPC charts.

Siemens provides four default SPC Charts for your use:

• Moving Range
• Range Chart
• Trial I-Chart
• X Chart

When Defining an Inline SPC Chart

You must install and configure Inline SPC on your server before using this page. Otherwise, you will not be able to populate all required fields or save the page.

You must create one SPC chart with the appropriate SPC Chart Type and SPC Query for each chart you want to display.

Use the Out of Control Actions section of the SPC chart to establish the actions triggered upon violation.

SPC Chart is an optional Modeling definition in SPC Chart Group.

SPC Chart contains the following optional Modeling definitions: Document, E-mail Message, Hold Reason, and Resource Status Code.

Refer to the Opcenter Execution Core Inline Statistical Process Control Reference Guide for information on setting up and configuring SPC.

Using Dynamic Parameters

Advanced Inline SPC users can configure chart parameters to use dynamic labels obtained from the field expressions or queries. Select the Is Dynamic check box for a parameter and enter the meta data table name and field or query name and column to display the value for a parameter. For example, the chartTitle parameter can be edited to display the product name from the container table. You must have knowledge of the object model and business logic for this use of the dynamic parameter functionality. Siemens recommends that this functionality is used with the Inline SPC Data Collection functionality.

This image shows an example definition for a dynamic parameter on the SPC Chart modeling page. Container.product.name is entered for the Param Value and the Is Dynamic check box is selected to indicate that the SPC Chart will use the product name from the container table for the chart title.

In this example, the Moving Range Inline chart title is pulled from the container table and the product name field. This image shows an example of a chart with a title for the Spacer Disc 008 product.

You can also use queries to set the dynamic parameter values. The query used cannot have input parameters and should contain only text. Only the first row of the returned data will be applied for the dynamic parameter. User queries and SPC queries can be used. Use the following format for the Param Value parameter field: QueryName.ColumnName.

Dynamic parameters can also be set at the SPC Chart Query level using the Dynamic Value field in the SPC Chart Query Parameters Grid. The dynamic value can also be set for an SPC Query that is used for multiple charts. Refer to "Defining SPC Queries" for more information.

Overriding Browser Language Settings for a Chart

Inline SPC uses your browser settings to determine the language used for Inline SPC pages and charts. You can add the Locale parameter to the SPC Chart Parameters to override the browser language settings for a SPC Chart.

This image shows an example of the optional Locale parameter.

Note: English and German are currently installed and supported with Inline SPC charts. Refer to "SPC/IGC Common Component end user documentation" for information about implementing other languages.

When Defining a Legacy SPC Chart

You must create one SPC chart with the appropriate chart-generating macro for each chart you want to display.

Ensure the path for the chart macros and chart properties are valid. For example, if SPC is installed in a directory other than the default installation directory, you will need to change the paths.

Use the Out of Control Actions section of the SPC chart to establish the actions triggered upon violation.

How to Define a New SPC Chart

Follow these steps to define a new SPC Chart:

1. Open the SPC Chart page. The SPC Chart page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the SPC Chart, Chart Type, Variable to chart, Chart Generating Macro, and SPC Chart Display Options.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.

How to Define a New Inline SPC Chart

Follow these steps to define a new SPC Chart:

1. Log on to Opcenter Execution Medical Device and Diagnostics.

Or

Log on to Opcenter Execution Core.

2. Select Modeling from the Modeling menu. The Modeling page appears.
3. Click SPC Chart. The SPC Chart page appears within the Modeling page.
4. Click New. Blank fields appear for you to define a new instance.
5. Enter the SPC Chart Name.
6. Select the Inline SPC check box to define an Inline SPC chart.
7. Select a Chart Type.
8. Select a Variable to chart.
9. Enter optional information according to your business requirements. Refer to the field definitions table for information about the optional fields.
10. Click Save. The application saves the modeling object and displays a success message.

How to Convert an Existing Legacy Macro into an Inline SPC Query Object

Follow these steps to convert a Legacy macro into an Inline SPC query object:

1. Log on to Opcenter Execution Medical Device and Diagnostics.

Or

Log on to Opcenter Execution Core.

2. Select Modeling from the Modeling menu. The Modeling page appears.
3. Click SPC Chart. The SPC Chart page appears within the Modeling page.
4. Select an existing Legacy chart.
5. Select the Inline SPC check box. A warning message appears confirming the macro conversion.
6. Click Yes. The SPC Macro Conversion pop-up appears. The pop-up fields are automatically populated with information from the selected Legacy Query.
7. Enter the new SPC Query name.
8. Edit the query information according to your business requirements. Refer to the field definitions table for information about the optional fields.
9. Click Submit. The application saves the SPC Query object and displays a success message. You can review the saved query on the SPC Query page.
Note: A warning message appears if the selected Legacy macro includes more than one query and/or incomplete parameters. You must manually edit the query information before using it with Inline SPC. You can edit the converted macro and parameters on the SPC Macro Conversion pop-up and click Submit or click Submit and edit the converted macro and parameters on the SPC Query page.

How to Define a Dynamic Parameter

Follow these steps to define a dynamic parameter for an Inline SPC Chart:

1. Log on to Opcenter Execution Medical Device and Diagnostics.

Or

Log on to Opcenter Execution Core.

2. Select Modeling from the Modeling menu. The Modeling page appears.
3. Click SPC Chart. The SPC Chart page appears within the Modeling page.
4. Select an Inline SPC chart.
5. Complete the following steps for each parameter you want to dynamically display:
• Enter object model or query information in the Param Value field. For example, container.product.name.
• Select Is Dynamic.
6. Click Save. The application saves the modeling object and displays a success message.

How to Override the Browser Language on an Inline SPC Chart

Follow these steps to override the language set in the browser for an Inline SPC Chart:

1. Log on to Opcenter Execution Medical Device and Diagnostics.

Or

Log on to Opcenter Execution Core.

2. Select Modeling from the Modeling menu. The Modeling page appears.
3. Click SPC Chart. The SPC Chart page appears within the Modeling page.
4. Select an Inline SPC Chart.
5. Add a new parameter to the SPC Chart Parameters grid.
6. Enter "Locale" in the Parameter Name field.
7. Enter the appropriate language code in the Param Value field.
• English - en
• German - de
8. Click Save. The application saves the modeling object and displays a success message.

How to Define the Decimal Places on an Inline SPC Chart

Follow these steps to define the number of decimal places shown on an Inline SPC Chart:

1. Log on to Opcenter Execution Medical Device and Diagnostics.

Or

Log on to Opcenter Execution Core.

2. Select Modeling from the Modeling menu. The Modeling page appears.
3. Click SPC Chart. The SPC Chart page appears within the Modeling page.
4. Select an Inline SPC Chart.
5. Update the decimalPlaces Param Value in the the SPC Chart Parameters grid with the number of decimal places you want to appear on the selected chart.
6. Click Save. The application saves the modeling object and displays a success message.
