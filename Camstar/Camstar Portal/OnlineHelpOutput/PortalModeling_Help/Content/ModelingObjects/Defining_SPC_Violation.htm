Defining SPC Violation

The SPC Violation modeling object contains the violation parameters included as criteria in each of the SPC Rules. Use the SPC Violation page to view the parameters for each violation.

Note: Violations are loaded during installation and cannot be edited.

When Using SPC Violations

This table defines the violation parameters available for some of the violations.

Parameter

Definition

Associated Violations

ViewedPoints

Number of points to be considered or viewed as violations.

 

Alternation, MiddleThird, Run_1, Run_2, Trend_1, Trend_2, Zone

Points

Number of points for a trend or a run. This value cannot be higher than the value used for ViewedPoints.

Run_1, Run_2, Trend_1, Trend_2, Zone

Zone

Sigma interval defined zones used with cumulative values to detect points in violation.

Distribution of zones:

• Zone C (+/- 1s) is located in the middle of the control chart, directly at the mean value
• Above or below is zone B (+/- 2s)
• Zone A (+/- 3s) is above or below Zone B and is the farthest away from the mean value

Zone

Areas

Areas considered for violation within designated zones. Values include:

• In
• InOrBeyond
• Beyond

Zone

Direction

Direction for violation testing. Values include:

• U - upper
• L - lower
• empty - If the direction is empty, the test is done in both directions.
