Defining Resource Groups

A Resource Group is a named object group subclass that represents a group of resources. An object group is used to provide a list of objects, such as a list of resources, products, or user codes of a particular type. These lists are typically used for validation and selection. For example, an operation includes a reference to a LossCodeGroup. The entries in this list define the valid loss (reason) codes for work performed while a container is at that operation.

An instance of an object group includes a list of specific objects and a list of object groups. This list of objects for any given object group is restricted to a specific type (or any of its derived types). Likewise, the list of object groups within the object group is restricted to the same type (or any of its derived types).

These are examples of subclasses of named object groups:

• Resource Group
• Shipment Destination Group
• User Code Group

Carrier Group is a subclass of Resource Group.

Refer to "Defining Carrier Groups" for information on this modeling object.

When Defining a Resource Group

Resource Group is an optional field when you are defining Setup, Spec, and Work Center.

You can add multiple entries or groups to their respective grids.

The Resolved Entries button enables you to display a list of all of the values specified in the entries list for this group and all of the nested groups.

When Defining a Resource Group for Use with Opcenter Execution Core Scheduling
Note: The functionality described below is available only when Opcenter Execution Core Scheduling is installed. Refer to "Opcenter Execution Core Scheduling" for information.

Creating a new resource group or updating an existing resource in Opcenter EX MDD or Opcenter EX CR triggers the application to send the resource group information to Preactor.

How to Define a Resource Group

Follow these steps to define a Resource Group:

1. Open the Resource Group page. The Resource Group page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the resource group in the Resource Group field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Add entries to the group as follows:
a. Click Add new row at the bottom of the Entries grid. A new row appears.
b. Click in the new row to display a list of entries, and then select one to add to the group. The selected entry is added to the grid.
c. Repeat steps a–b to add another entry to the grid.
6. Add a subgroup to the group as follows:
a. Click Add new row at the bottom of the Groups grid. A new row appears.
b. Click in the new row to display a list of previously defined groups, and then select one to add (as a subgroup) to the group. The selected group is added to the grid.
c. Repeat steps a–b to add another group to the grid.
7. Click Save. The application saves the modeling object and displays a success message.
