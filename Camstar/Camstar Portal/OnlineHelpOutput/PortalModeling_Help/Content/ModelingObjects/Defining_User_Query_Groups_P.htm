Defining User Query Groups

A User Query Group is a set of user queries. A user query group can be used to narrow the number of user queries available based on your business need. For example, you can define a user query group that contains only those user queries for use when performing a search for containers in the Portal Shop Floor application. A user query group can include individual user queries and other, predefined user query groups.

When Defining a User Query Group

You can add multiple entries or groups to their respective grids.

You must define one or more user queries before defining a user query group.

The Resolved Entries button enables you to display a list of all of the values specified in the entries list for this group and all of the nested groups.

How to Define a User Query Group

Follow these steps to define a User Query Group:

1. Open the User Query Group page. The User Query Group page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for this group in the User Query Group field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.

How to Add Entries to a User Query Group

Follow these steps to add an entry to the User Query Group:

1. Perform the “How to Define a User Query Group” procedure.

Or

Select an existing User Query Group instance.

2. Add entries to the group as follows:
a. Click Add new row at the bottom of the Entries grid. A new row appears.
b. Click in the new row to display a list of entries, and then select one to add to the group. The selected entry is added to the grid.
c. Repeat steps a–b to add another entry to the grid.
3. Add a subgroup to the group as follows:
a. Click Add new row at the bottom of the Groups grid. A new row appears.
b. Click in the new row to display a list of previously defined groups, and then select one to add (as a subgroup) to the group. The application adds the selected group to the grid.
c. Repeat steps a–b to add another group to the grid.
4. Click Save. The application displays a success message indicating the modeling object was uploaded.
