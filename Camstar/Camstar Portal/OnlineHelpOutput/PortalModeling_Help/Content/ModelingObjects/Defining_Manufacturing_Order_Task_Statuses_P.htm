Defining Manufacturing Order Task Statuses

A manufacturing order task status (Mfg order task status) is a named object that enables you to define the status codes used in the instruction task type 'Supervisor Review.'

Manufacturing Order Task Status Page Field Definitions

This table defines the fields on the Manufacturing Order Task Status page.

Field

Definition

Type

Mfg Order Task Status

Custom status code of a Supervisor Review task. Examples include: Blocked, Complete, In Progress, Not Started, and Started.

Required

General

Task Complete

A task with this status will be considered complete and passed.

Important: Only tasks that have been assigned a status with this option checked are considered complete.

Optional

Task Failed

A task with this status will be considered failed. Check this option to indicate that there is a problem that must be fixed before the task can be completed.

Optional
Note: If you do not check either Task Complete or Task Failed, the task is considered to be still in progress.

How to Define a Manufacturing Order Task Status

Follow these steps to define an Mfg Order Task Status:

1. Open the Mfg Order Task Status page. The Mfg Order Task Status page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Name a status code in the Mfg Order Task Status field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
