Defining Tool Groups

A Tool Group is used to group individual Tools together. You must define tools that will be part of the tool group before you can define the tool group.

Tool Group Page Field Definitions

This table defines fields on the Tool Group page.

Refer to "Common Fields on Modeling Pages" for information on the fields common to all modeling objects.

Indicates the type of object contained in this group. For example, Tool for Tool Groups.

Optional

How to Define a Tool Group

Follow these steps to define a Tool Group:

1. Open the Tool Group page. The Tool Group page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Add entries to the group as follows:
a. Click Add new row.
b. Select a Tool from the list that appears in the grid.
c. Repeat steps a-b to add another entry to the grid.
4. Add a subgroup to the group as follows:
a. Click Add new row.
b. Select a Tool Group from the list that appears in the grid.
c. Repeat steps a-b to add another group to the grid.
5. Click Resolved Entries. The application displays a pop-up displaying the list of all of the tools included in the tool group. Tools from the tool groups are listed individually.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
