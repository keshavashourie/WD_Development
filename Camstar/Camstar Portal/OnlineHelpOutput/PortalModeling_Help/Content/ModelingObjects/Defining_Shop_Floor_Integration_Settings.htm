Defining Shop Floor Integration Settings

The Shop Floor Integration Settings page enables you to configure a group of fields related to functionality such as:

• Automatically starting containers
• Collecting defects from automated test equipment
• Communicating with the Material Management Application Programming Interface (API) or the Shop Floor Resource Configuration API

You activate a Shop Floor Integration Settings instance by selecting it on the Factory modeling page.

Shop Floor Integration Settings Field Definitions

This table defines the fields unique to the Shop Floor Integration Settings modeling page.

Field

Definition

Type

Start Reason

Start Reason to set on containers when started.

Optional

Level

Physical section of the container such as panel or PCB.

Optional

Owner

Owner associated with the container. Owner code is used as a grouping to separate containers for inquiry and processing. Some examples are Manufacturing, Engineering, and Prototypes.

Optional

Workflow

Default container processing path or set of manufacturing steps.

Optional

Product Type

Default Product Type to use when automatically creating a product during a Start of a container.

Optional

Material Management API

URL to the Material Management REST API.

Optional

Defect Reason Mapping

Mapping of defect reasons defined in the application to defect labels specific to automated test equipment.

Note: This field appears only when the Industry Solutions workspace is installed.

Optional

Laser Marker Fail

Controls the behavior of how a failed Laser Marker message should be handled. Options include:

• Ignore (Update serial numbers as needed and perform the Move.)
• Prevent Move (and return error)
• Perform Rework (if path available, otherwise return error message)
• Scrap Panel
• XOut (PCB with error)

Note: This field appears only when Opcenter Execution Electronics is installed. Refer to the Opcenter Execution Electronics User Guide for information.

Optional

SRC API

URL to the Shop Floor Resource Configuration API

Optional

How to Define Shop Floor Integration Settings

Follow these steps to define an instance of Shop Floor Integration Settings:

1. Select Shop Floor Integration Settings from the modeling object list. The Shop Floor Integration Settings page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a unique name for the instance of Shop Floor Integration Settings in the Shop Floor Integration Settings field.
4. Enter optional information according to your business requirements.
5. Click Save. The application saves the modeling object and displays a success message.

How to Assign a Shop Floor Integration Settings Instance to a Factory

Follow these steps to assign a Shop Floor Integration Settings instance to a factory:

1. Select Factory from the modeling object list. A list of factory instances appears.
2. Select the factory from the list. The factory is displayed within the modeling page.
3. Select the Shop Floor Integration Settings instance from the Shop Floor Integration Settings field under the General section.
4. Click Save. The application saves the modeling object and displays a success message.
