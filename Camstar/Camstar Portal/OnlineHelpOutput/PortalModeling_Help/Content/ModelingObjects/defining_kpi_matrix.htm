Defining a KPI Matrix

The KPI Matrix page enables you to add individual sets of information called KPI Entries that can be used when conducting analysis of Key Performance Indicators (KPI).

Each KPI Entry enables you to specify a set of KPI analysis criteria including a target value such as Ideal Cycle Time and a lower and upper limit of an acceptable range. Each KPI Entry also enables you to configure look-up values for finding the correct set of analysis criteria. For example, one entry may contain a target value to apply when conducting KPI analysis on product A at a specific operation. Another may contain a different target value to apply for Product B at that same operation.

Note: KPI analysis is used by Opcenter EX EL Intelligence.

How to Define a KPI Matrix

Follow these steps to define a KPI Matrix:

1. Open the KPI Matrix Page.The KPI Matrix page appears within the Modeling page.
2. Enter a name for the KPI Matrix in the KPI Matrix field.
3. Click Add new row on the KPI Entry grid. The application displays the Add pop-up for you to enter the entry values.
4. Enter or select values on the Add pop-up as needed.
5. When finished, click OK to close the pop-up.
6. Repeat steps 3-5 for each additional KPI Entry you want to add.
7. Enter optional information according to your business requirements. Refer to "Common Fields on Modeling Pages" for information on the optional fields.
8. Click Save. The application saves the modeling object and displays a success message.
