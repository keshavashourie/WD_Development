Defining External Permissions

A permission type corresponds to a set of permissions that can be assigned when creating a role. The application has multiple permission types, but the one named External Permission differs from the others in that it allows for permissions to custom functionality not based on the Opcenter Execution Core metadata model. Another difference is that an instance of the External Permission object can be created in Modeling; the other permission types are system defined.

A specific usage of the External Permission type is for the separately licensed SRC module that is integrated into Opcenter Execution Core.

How to Define an External Permission

Follow these steps to define an external permission:

1. Open the External Permission page. The External Permission page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name in the External Permission field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
