Defining Recipe Plans

The Recipe Plan page enables you to define a list of one or more recipes each of which can be associated with a resource, a spec, or both. Before performing a Move In transaction, the application looks for an assigned recipe plan. If one is found, the application checks all recipes in the plan for those with criteria matching the current manufacturing context and then selects the best match if any matches are found. The application compares the name of a found recipe against the name of the recipe selected for resource setup to ensure that the correct recipe is used.

When Defining a Recipe Plan

The recipes to be added to the plan must exist in the database. You can add recipes using the Recipe modeling page. You cannot create more than one entry with the same resource and spec values.

How to Define a Recipe Plan

Follow these steps to define a recipe plan:

1. Open the Recipe Plan page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Recipe Plan in the Recipe Plan field.
4. Click Add new row in the Details grid. The Add pop-up appears.
5. Perform the following steps using the pop-up:
a. Select a Recipe.
b. Select a Resource if you want the recipe to be used only for this resource.
c. Select a Spec if applicable if you want the recipe to be used only for this spec.
d. Do you want to add one or more parameters for the recipe?

If . . .

Then . . .

No
a. Go to step 6.

Yes
a. Click Add new row on the pop-up Parameters grid. A row of blank fields appears for you to add a parameter.
b. Enter a name for the parameter.
c. Enter any other values on the parameter row.
d. Repeat steps a-c for each parameter that you want to add.
e. Click OK when finished adding parameters. The pop-up closes.
6. Click Save. The application saves the modeling object and displays a status message.
