Defining Tool Plans

A Tool Plan is used to specify the required tools that must be attached to an equipment before processing. You can specify tools, tool families, and tool groups under a tool plan. Before defining tool plans, you must create the modeling objects for tools, tool families, and tool groups that will be included.

Tool Plans Validation

Tool plans assigned to equipment resources can be validated when Verify Tool Plan check box is enabled in Spec. The application validates that all tools define in Tool Plan are correctly loaded. This enables users to set up only relevant tools instead of all existing tools.

The application further validates the Tool Plans based on the Board Side configured in Tool Plans Details grid and in Spec based on the following conditions:

• If a Board Side is set to blank (null) for either the Tool Plans Details or Spec or both, all tools that are configured in the tool plan will be validated during the Move transaction. regardless of the Spec or the Tool Plan setting.
• If both Spec and Tool Plan Details' Board Side selection matches each other(and the field is not empty/ null), the tool plan will be validated.
• If both Spec and Tool Plan Details' Board Side selection did not match each other (and the field is not empty/ null), the application skips the tool plan verification process.
Tools Thruput Quantity

When a tool is used either in rework or electronics assembly, the tool thruput quantity is recorded according to it usage in the following conditions:

• If a Board Side is set to blank (null) for either the Tool Plans Details or Spec or both, the tool thruput quantity will be recorded.
• If both Spec and Tool Plan Details' Board Side selection matches each other, the tool thruput quantity will be recorded.
• If both Spec and Tool Plan Details' Board Side selection did not match each other (and the field is not empty/ null), the application skips the tools thruput quantity recording.

How to Define a Tool Plan

Follow these steps to define a Tool Plan:

1. Open the Tool Plan page. The Tool Plan page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Tool Plan in the Tool Plan field.
4. Click Add new row in the Details grid. A row is activated in the grid.
5. Perform the following steps:
a. Enter an item name in the Item Name field.
b. Enter the Qty Required.
c. Select either a Tool, Tool Family, or Tool Group.
d. Select either Top, Bottom or Null (no selection) Board Side.
e. Enter optional information to the Details grid according to your business requirements.
f. Repeat steps a-c for each additional row to be added to the grid.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
