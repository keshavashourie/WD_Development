Defining Recipes

A Recipe is a type of document. The recipe definition consists of the recipe file name, location, and optional parameters.

A recipe usually defines the Resource settings, such as the timing and temperature of a machine, for use in manufacturing. Once defined, the recipe is typically, but not always, performed by the resource itself.

Requirements

Your browser must have the appropriate plug-in to view the type of recipe document selected (such as a .pdf file).

When Defining a Recipe

These rules apply when defining recipes:

• A recipe cannot have the same name as a document. For example, if you create a document named "Test," you cannot create a recipe named "Test."
• The Upload File to Database check box allows you to indicate when to upload the specified file to the database. Typically, you select this check box when defining a recipe initially. Leaving the check box blank when updating existing instances allows you to make changes without having to upload the document.
• The Stored File Name field is a read-only field that displays the file name of a Local file if you upload it and click Save.
• The download/upload time of files varies by file size.
• Any values entered into the Parameters grid may be overridden in a Recipe Plan or Recipe Matrix.

Recipe is:

• An optional field in the definition of Spec (in Recipe File) and WIP Message.
Note: A Recipe definition can have related WIP Messages if it is associated with a field from a container definition. Refer to the Opcenter Execution Medical Device and Diagnostics Shop Floor User Guide or the Opcenter Execution Core Shop Floor User Guide for information.

How to Define a Recipe

Follow these steps to define a Recipe:

1. Open the Recipe page. The Recipe page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for this recipe in the Recipe field.
4. Enter the revision of this recipe in the Revision field.
5. Click the File Upload icon next to the Locate File field. A File Upload dialog appears.
6. Browse for the file and then click Open. The File Upload dialog closes and the file name appears in the File Upload field.
7. Select the Upload File to Database check box if you want to upload this file to the database when you save.
8. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
9. Click Save. The application saves the modeling object, enables the View Document button, and displays a success message.
