Shop Floor Resource Configuration (SRC) Overview

Note: Note: The functionality described below is available only when Shop Floor Resource Configuration (SRC) is installed. Refer to the Opcenter Execution Core System Administration Guide for information.

Shop Floor Resource Configuration (SRC) enables you to configure manufacturing resources with detailed specifications and to identify where these resources fit into the overall manufacturing environment. You define the manufacturing environment by creating a factory hierarchy.

Factory Hierarchy

The Factory Hierarchy represents your physical manufacturing environment in terms of resources and resource locations. You define the hierarchy with instances and relationships of these modeling objects:

• Enterprise—typically represents all manufacturing facilities within an organization
• Factory—one manufacturing facility
• Inventory Location (available if Industry Solutions is installed)—represents location where finished goods are stored
• Resource—can be one of three types:
• Area—defined location devoted to a specific purpose
• Cell—defined location within an area such as a manufacturing line
• Equipment—machines or items typically considered resources
Important: The Resource modeling object contains a field called Factory Level that enables you to configure an area or sub-area of a factory as a resource for purposes of resource grouping.

Accessing the Factory Hierarchy

To access the Factory Hierarchy, select Factory Hierarchy from the main Opcenter Execution Core Modeling menu. The Factory Hierarchy page opens with the Factory Hierarchy tree displayed on the left. The Enterprise is displayed in collapsed mode. If the hierarchy has already been defined, you can expand the tree one level at a time.

Using the Factory Hierarchy

Selecting a hierarchy item on the tree brings up the modeling interface to the right of the tree. You can use the interface page to make updates. If the item can be configured with IPL settings, the page will contain an SRC button. You click this button if you want to configure IPL settings for the item. Refer to “Defining IPL Equipment Settings and Parameters” for details.

Defining IPL Equipment Settings and Parameters

IPL equipment settings and parameters help facilitate IPL messaging. Each equipment resource can have multiple settings. To set the value of a setting, you have three options:

• Enterprise value—a default configured for the Enterprise and inherited by the equipment resource. When an Enterprise setting value is updated, all equipment configured to use the Enterprise value will inherit the updated value. Keep in mind that these defaults can be changed by those with change permissions.
• Suggested value—a value set in the software by equipment engineers and calculated to be the best default value for the specific combination of equipment type, manufacturer, and exact model. The value of a suggested value cannot be changed by end users.
• Manually entered Override value—a manually entered value considered to be the best value for the way the equipment is configured in your factory. Only values within a reasonable range can be saved. Values outside that range cause an error. By clicking on Enterprise or Suggested, the Override value is erased.
Important: You cannot enter non-numeric values to the fields that only support numeric input such as integers.

SRC Settings Page

This SRC page contains the following sections:

1. Selected instance (information carried over from Opcenter Execution Core Modeling).
2. Header area—options for choosing which data to show and how to show it on the Detail area
3. Categories area—list of categories and number of settings within the category that meet selection criteria
4. Details area—actual setting values (content of this area affected by header and category selections)

Categories

There are various category of settings available, depending on the manufacturer and the type of machine available. These categories are fixed and cannot be modified by the user. Categorizing settings makes it much easier to find ones you are interested in, even if you don’t know the exact names. Settings can be required, optional, or other—only needed in certain circumstances or for legacy reasons.

Each category is shown along with the number of parameters included within that category. This number is affected by the selected View option or options. This number may be higher or lower based on whether the Show Optional and Show Others View options are selected. A category will not be shown if does not have any parameters that fall within the selected View option or options.

Details Area

The Details area shows the actual values of the settings. Each setting may have a value such as a name or a number or a toggle switch—Yes/No. Required parameters are shown with an asterisk. When creating or adding a new equipment in SRC page, the application will automatically fill in the 'IPL Machine Type' setting with the default value that is configured in the ResourcesSettingsSchema.json file (schema file containing all equipment settings).

A help button is shown for each parameter. Clicking this button opens the Settings Information dialog.

Important: You cannot enter non-numeric values to the fields that only support numeric input such as integers.

Inheritance

Inheritance, in object-oriented programming, refers to the ability to create a base class the properties of which can be inherited by other classes. In terms of Smart Settings, inheritance refers to the ability to configure settings at the Enterprise level and have all child-level equipment resources within the enterprise inherit those settings as defaults.

Important: Inherited settings are defaults and can be changed by those with change permissions.

Options for Where to Get the Settings Values

For each setting on each equipment resource, there are three options for the source of the setting value:

• •Enterprise value—a default configured for the Enterprise and inherited by the equipment resource. When an Enterprise setting value is changed, all equipment configured to use the Enterprise value will inherit the updated value.
• Suggested value—a value set in the software by equipment engineers and calculated to be the best default value for the specific combination of equipment type, manufacturer, and exact model. The value of a suggested value cannot be changed by end users.
• Manually entered Override value—a manually entered value considered to be the best value for the way the equipment is configured in your factory. Only values within a reasonable range can be saved. Values outside that range cause an error. By clicking on Enterprise or Suggested, the Override value is erased.
Important: You cannot enter non-numeric values to the fields that only support numeric inputs such as integers.

When Changing Smart Settings Values

Often, the most efficient method of updating your resources with the correct settings values is to populate the settings values at the Enterprise level so that resources will inherit those values as defaults. You can change the settings for the Enterprise if they are not correct. All of the changes will cascade down to the resources that are children of the Enterprise, overwriting the previously inherited defaults. If only some resources need different settings, you can change the values for just those resources. Override values are saved in a table for each machine or resource. If either the Enterprise or Suggested button are clicked, the Override value is deleted. Clicking the Save button will trigger a warning pop-up requiring confirmation that changes was made and the values will be inherited down to the other level. Once changes are saved, unused Overide values are deleted.

Important: For the Override values, the name is very specific. All resources using this exact Override parameter name will be using the same value. Changing the value for one setting changes the value for all other settings with the same name. You cannot enter non-numeric values to the fields that only support numeric inputs such as integers.

Role Permissions for Configuring Smart Settings

Users who need to configure the Smart Settings will need to be assigned to a role with the “IPL Configuration” external permission. Users without that permission can still view the settings in read-only mode. More information on the external permissions can be found in "Defining External Permissions."

The following items normally displayed in the page will not be shown when in read-only mode:

• Save button
• Override and inherited values toggle button
• Equipment Type selection

How to Update Setting Values for SRC Equipment

Follow these steps to change setting values for SRC equipment:

1. Select Factory Hierarchy from the main Opcenter Execution Core Modeling menu. The Factory Hierarchy page opens with the Factory Hierarchy tree displayed on the left.
2. Select the equipment resource from the Factory Hierarchy tree. To the right of the tree, the application displays the selected instance in the appropriate modeling page.
3. Click the SRC button. The SRC settings configuration page opens.
4. To change a non-required setting, select Show optional or Show others as needed on the Details header View area. The application displays any additional settings that meet your selection criteria.
5. Click the Expand button next to the setting to be updated. Alternatively, click the Expand All button if there are many settings to be changed. Click Select All if all values must be changed.
6. To customize individual setting values, click on the Override button. The value becomes unlocked for editing
7. Make your changes. Any values that are not within a configured range specific to that make and model of equipment will trigger a warning.
Important: You cannot enter non-numeric values to the fields that only support numeric inputs such as integers.
8. When finished, click Save on the Header area toolbar. If you are making changes at the Enteprise Level, a trigger warning will be displayed requiring confirmation on the changes being made. Click the OK button. A successful save message is displayed.

Copying, Exporting, and Importing Shop Floor Resource Setting

You can only copy settings for individual resources, but settings can be used to make duplicates. This is very important, because for many of the most useful pieces of machinery, there are frequently more than one in the factory. Exporting and importing can be done for any level or group, including the entire enterprise. But the information is saved and reapplied according to the existing names and structures. This is not for making copies.

When Copying Smart Settings for a Resource

Copying can be done for any single element at any level in the Factory Hierarchy tree, but must be done within the Opcenter Execution Core application. Refer to the Opcenter Execution Core Modeling User Guide for detailed instructions.

When Exporting and Importing Smart Settings Values

Values need to be exported before they can be imported. Two facts should be kept in mind:

• The resource structure, the Factory Hierarchy tree, is part of and managed by Opcenter Execution Core.
• The detailed settings for each resource are managed by the SRC plugin, specifically the Smart Settings dialog.

Each type of data can be exported separately from the other. If both are needed, you must perform two separate exports and imports.

Note: For exporting elements of the Factory Hierarchy tree, refer to the Opcenter Execution Core Modeling User Guide.

How to Export SRC Settings

You must export SRC equipment settings before you can import them. Follow these steps to export SRC settings from the Factory Hierarchy tree:

1. Select Factory Hierarchy from the main Opcenter Execution Core Modeling menu. The Factory Hierarchy page opens with the Factory Hierarchy tree displayed on the left.
2. Select the level that you want to export from the Factory Hierarchy tree. For example, for all equipment in a production line, select that line. For all equipment in a factory, select the factory. The application opens the SRC settings page.
3. In the SRC settings page tool bar, click the Export button. A warning message will be triggered if there are any unsaved settings. All of the settings from the selected level of the hierarchy will be exported. Resource details are saved for each element (machine, line, factory), but not the actual layout structure.

How to Import SRC Settings

Before importing the SRC values, an export file needs to have been created that includes all of the elements you now want to import. Refer to “How to Export Settings.”

Follow these steps to import SRC settings:

1. Select Factory Hierarchy from the main Opcenter Execution Core Modeling menu. The Factory Hierarchy page opens with the Factory Hierarchy tree displayed on the left.
2. Select the level that you want to import from the Factory Hierarchy tree. For example, for all equipment in a production line, select that line. For all equipment in a factory, select the factory. To import settings for a single resource, select that resource. The application opens the SRC settings page.
3. In the SRC settings page tool bar, click the Import button. A file dialogue pop- up is displayed showing which resource files can be imported.
4. Select a file and click OK. An Import Setting Information pop-up appeared displaying the name of the current imported file.
5. Click OK. The application displays a message indicating that the import was successful.
