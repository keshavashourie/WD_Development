Assigning an Electronic Signature Requirement to Lock/Unlock

Opcenter EX MDD and Opcenter EX CR enable you to assign an electronic signature requirement to the lock/unlock event using the Modeling ESig page. This ensures that one or more signatures are required before a revisioned object can be locked or unlocked. A revisioned object can also inherit a lock/unlock assignment from a parent (Inherit) or can override a parent's assignment (None).

How to Assign an Electronic Signature Requirement to Lock/Unlock

Follow these steps to lock an existing Electronic Signature Requirement:

1. Open the Modeling ESig page. The Modeling ESig page appears.
2. Select a revisioned object service from the list in the Services section.
3. Select an electronic signature requirement from the Lock/Unlock list in the Signature Requirement Assignment section to assign it to the lock and unlock events.
4. Click Update. The new electronic signature requirement is assigned to the service and a signature is required before the revisioned object can be locked or unlocked.
