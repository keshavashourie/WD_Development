Defining Inventory Locations

The Inventory Location modeling object enables you to create a holding place for containers, lots, or products. Refer to the Opcenter Execution Medical Device and Diagnostics Shop Floor User Guide for information on assigning containers, lots, or products to an inventory location.

When the SRC Settings Button is Available

An SRC Settings button may appear on the Inventory Location page when displaying an existing instance if your application is configured to interact with Shop Floor Resource Configuration (SRC). Clicking the SRC Settings button opens a pop-up for you to view or update additional Inventory Location settings known as SRC settings. The application prompts you with a notification to save any changes before it permits you to close the SRC settings pop-up.

Note: The SRC Settings button is not available when defining a new Inventory Location instance.

How to Define an Inventory Location

Follow these steps to define an Inventory Location:

1. Open the Inventory Location page. The Inventory Location page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the inventory location in the Inventory Location field.
4. Enter optional information according to your business requirements. Refer to "Common Fields on Modeling Pages" for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
