Defining CIO Outbound Connections

The CIO Connection object contains the external connection details where outbound messages are sent using OAuth2 authentication.

Using the Outbound Connection page from Modeling, you can authenticate external applications utilizing supported authentication methods. In this page, you can define an external connection which will appear as an entry in the Outbound Connection drop-down list on the Generic REST API Pop-Up page in the Outbound Definition Grid.

In this page users can either provide credentials or just the token and URL information.

How to Define an Outbound Connection

Follow these steps to define an Outbound Connection:

1. Open the Outbound Connection page. The Outbound Connection page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name in the Outbound Connection field.
4. Authentication Type, OAuth2 is selected by default.
5. Enter the Outbound connection information in the following fields:
• Username
• Password
• Body
• Token URL
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
