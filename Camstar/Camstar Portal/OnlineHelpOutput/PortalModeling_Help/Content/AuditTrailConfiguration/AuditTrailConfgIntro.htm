Manufacturing and Resource Audit Trails

Audit Trail information for transactions and event records is provided in the Opcenter Execution Core and Opcenter Execution Medical Device and Diagnostics applications in the form of manufacturing audit trail information and resource audit trail information.

This audit trail information is displayed as the History Mainline Grid on the Mfg Audit Trail page or the Resource Trail page.

The manufacturing audit trail provides a complete history of all transactions for a container, carrier, or event transactions. It provides a history of manufactured lots, batches and serialized units, spanning production in multiple plants. The manufacturing audit trail captures details such as materials consumed, processes utilized, parametric data collected, dates and times, and electronic signatures.

The resource audit trail provides a complete history of all transactions for a resource. You can configure the information displayed in the audit trail according to your business needs. The resource audit trail captures details such as the machine where material is processed, parametric data collected, and dates and times.

Such audit trail views can be customized and configured using the Audit Trail Configuration modeling object, available with the list of other modeling objects, accessible from the main Modeling page, from the Modeling menu.

Using this modeling object, multiple instances of such audit trail configurations can be defined and configured to be displayed as the History Mainline Grid for the Manufacturing Audit Trail and Resource Audit Trail pages.

Once configured, you can access the Mfg Audit Trail page from the Search menu and the Resource Audit Trail page from the Resource menu. Refer to the Opcenter Execution Medical Device and Diagnostics Shop Floor User Guide or the Opcenter Execution Core Shop Floor User Guide for information on viewing the manufacturing and resource audit trails.
