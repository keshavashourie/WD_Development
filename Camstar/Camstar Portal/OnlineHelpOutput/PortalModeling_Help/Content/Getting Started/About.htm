Modeling User Guide

 

The Modeling User Guide contains information on creating a virtual model of your manufacturing facilities. This guide provides detailed information on modeling objects and how you define them for your requirements using the Portal.

The purpose of this guide is to assist you in creating your modeling definitions and workflows. Modeling is that part of the Portal interface that enables you to add, copy, edit, and delete instances of modeling objects.

This guide is intended for use following the successful installation and configuration of these products:

• Opcenter Execution Medical Device and Diagnostics (OC EX MDD), or
• Opcenter Execution Core (OC EX CR).

Refer to the appropriately branded Installation Guide and the System Administration Guide for information on installing and configuring your product.

Audience

This guide is intended for those responsible for installing your product, for Siemens business partners who assist in implementing this application, and for administrators responsible for defining and maintaining the customer’s virtual model.
