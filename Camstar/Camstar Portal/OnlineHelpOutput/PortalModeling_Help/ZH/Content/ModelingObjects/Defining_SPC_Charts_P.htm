定义 SPC 图表

“SPC 图表”建模对象包含显示单个 SPC 图表所需的信息。描述图表类型、SPC 查询对象、内联 SPC 规则、失控操作和程序 (OCAP) 以及为内联 SPC 图表绘制的变量。

SPC 图表建模对象还描述图表类型、Statit Software 宏、Statit Software 规则文件、失控操作和程序 (OCAP) 以及为原有 SPC 图表绘制的变量。

Siemens 提供了四个默认 SPC 图表供用户使用：

• 移动极差
• 极差图
• 试用 I-图
• X 图

定义 Inline SPC 图表

必须在服务器上安装并配置 Inline SPC 才能使用此页面。否则将无法填充所有必需字段或保存页面。

必须使用相应的 SPC 图表类型和 SPC 查询为要显示的每个图表创建一个具有 SPC 图表。

使用 SPC 图表的“失控操作”部分来确定在违规时触发的操作。

SPC 图表是“SPC 图表组”中的可选建模定义。

SPC 图表包含以下可选建模定义：文档、电子邮件消息、搁置原因和资源状态代码。

有关设置和配置 SPC 的信息，请参考《Opcenter Execution Core Inline Statistical Process Control 参考指南》。

使用动态参数

高级内联 SPC 用户可以配置图表参数，以使用从字段表达式或查询中获取的动态标签。选中对应于参数的“是动态的”复选框，然后输入元数据表名称和字段或者查询名称和列，以显示参数的值。例如，可以编辑 chartTitle 参数，以在容器表中显示产品名称。要以此方式使用动态参数功能，必须了解对象模型和业务逻辑。Siemens 建议将此功能与“内联 SPC 数据收集”功能一起使用。

此图显示了“SPC 图表”建模页面中动态参数的定义示例。为参数值输入 ontainer.product.name，并选中“是动态的”复选框，以指示 SPC 图表将使用容器表中的产品名称作为图表标题。

在此示例中，已从容器表和产品名称字段中拉出“移动极差图内联”图表标题。此图显示了一个带有 Spacer Disc 008 产品标题的图表的示例。

还可以使用查询来设置动态参数值。所使用的查询不能具有输入参数，并且应仅包含文本。仅将返回的第一行数据应用于动态参数。可以使用用户查询和 SPC 查询。对“参数值”参数字段使用以下格式：QueryName.ColumnName。

还可以使用“SPC 图表查询参数”表格中的“动态值”字段在 SPC 图表查询级别设置动态参数。 还可以为用于多个图表的 SPC 查询设置动态值。 有关更多信息，请参考“定义 SPC 查询”。

覆盖图表的浏览器语言设置

内联 SPC 将使用浏览器设置来确定用于内联 SPC 页面和图表的语言。可以将语言环境参数添加到 SPC 图参数，以覆盖 SPC 图表的浏览器语言设置。

定义 Legacy SPC 图表

必须为要显示的每个图表创建一个具有相应图表生成宏的 SPC 图表。

确保图表宏和图表属性的路径有效。例如，如果 SPC 安装在非默认安装目录的目录中，则需要更改路径。

使用 SPC 图表的“失控操作”部分来确定在违规时触发的操作。

SPC 图表是“SPC 图表组”中的可选建模定义。

SPC 图表包含以下可选建模定义：文档、电子邮件消息、搁置原因和资源状态代码。

有关设置和配置 SPC 的信息，请参考《Opcenter Execution Core Statistical Process Control 参考指南》。

如何定义新的 SPC 图表

按照以下步骤定义新的 SPC 图表：

1. 打开 SPC 图表页。随即“建模”页中将显示“SPC 图表”页。
2. 单击新建。 显示用于定义新实例的空白字段。
3. 在 SPC 图表、图表类型、图表变量、生成图表的宏和 SPC 图表显示选项中输入内容。
4. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
5. 单击保存。 应用程序保存建模对象并显示成功消息。

如何定义新的 Inline SPC 图表

按照以下步骤定义新的 SPC 图表：

1. 登录到 Opcenter Execution Medical Device and Diagnostics。

或

登录到 Opcenter Execution Core。

2. 从建模菜单中选择建模。将显示“建模”页。
3. 单击 SPC 图表。随即“建模”页中将显示“SPC 图表”页。
4. 单击新建。显示用于定义新实例的空白字段。
5. 输入 SPC 图表名称。
6. 选中 Inline SPC 复选框以定义 Inline SPC 图表。
7. 选择图表类型。
8. 选择图表变量。
9. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
10. 单击保存。应用程序保存建模对象并显示成功消息。

如何将现有原有宏转换为内联 SPC 查询对象

按照以下步骤将原有宏转换为内联 SPC 查询对象：

1. 登录到 Opcenter Execution Medical Device and Diagnostics。

或

登录到 Opcenter Execution Core。

2. 从建模菜单中选择建模。将显示“建模”页。
3. 单击 SPC 图表。随即“建模”页中将显示“SPC 图表”页。
4. 选择现有原有图表。
5. 选中内联 SPC 复选框。将显示一条警告消息，确认宏转换。
6. 单击是。将显示“SPC 宏转换”弹出窗口。弹出字段将自动填充所选原有查询中的信息。
7. 输入新的 SPC 查询名称。
8. 根据业务需求编辑查询信息。有关可选字段的信息，请参考字段定义表。
9. 单击提交。应用程序保存 SPC 查询对象并显示成功消息。可以在“SPC 查询”页面上查看已保存的查询。
注释: 如果选定的原有宏包含多个查询和/或不完整参数，则会显示一条警告消息。在将查询信息与内联 SPC 一同使用之前，必须手动编辑查询信息。可以在“SPC 宏转换”弹出窗口中编辑转换后的宏和参数，然后单击提交，也可以单击提交，然后在“SPC 查询”页面上编辑已转换的宏和参数。
