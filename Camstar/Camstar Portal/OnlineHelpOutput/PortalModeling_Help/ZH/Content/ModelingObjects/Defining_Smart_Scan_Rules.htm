定义智能扫描规则

智能扫描规则用于基于规则的智能扫描，这是默认智能扫描的替代方法。使用智能扫描规则，可定义用于识别条形码中的数据元素的数据模式。要配置规则，可以使用处理指示，包含自动执行单击按钮等页面操作，否则将由操作员手动执行操作。

了解模式

应用程序使用智能扫描规则中的一个或多个模式来解释条形码数据。这些模式必须与期望处理的条形码一致。

2. 操作员将条形码扫描到应用程序页面中。该页面包含各种字段，包含“容器标识”和“保存”按钮。条形码包含字符串 CON-12348976。同时包含一个字符串，其中的字符 Hold 表示应保存页面数据以稍后完成。
3. 应用程序根据智能扫描规则评估条形码，并执行以下逻辑：
a. 查找第一个模式，该模式解析为三个字母加连字符加八位数字。
b. 抽取数据字符串，并将其放到与模式的智能扫描类型“容器”对应的页面上的字段中。
c. 移除数据字符串，因为已针对模式选择“匹配时移除”。
d. 查找四个字符模式 - Hold。
e. 从条形码中提取 Hold 字符串数据。
f. “操作标识”为“保存”，因此自动提交“保存”按钮的“单击时”操作。
注释: 此示例只是众多示例之一。另一个工厂可以为其“容器标识”配置完全不同的模式。

指定 ASCII 字符

可以通过指定字符的十进制 ASCII 代码（000 到 255）将字符包含在模式中。 反斜线 (\) 用于指示接下来的 1 到 3 位数将解释为 ASCII 代码。例如，大写字母 "A" 的代码是 65。 因此，如果字符串 \65 或 \065 出现在模式中，智能扫描处理器会将其视为 "A"。由于反斜杠对智能扫描处理器具有特殊含义，因此不能将其直接包含在模式中。 必须改用其 ASCII 代码 92。 模式中的任何 ASCII 代码在与条形码匹配之前均解析为其字符值。

模式顺序

条形码可以包含单个或多个信息值。条形码的测试顺序很重要，会产生不同的结果。不同的条形码模式可能会产生相同的结果。

 

示例

希望识别部件号 PAA-123456。条形码的特征是：

• 字母 P 表示部件号。此为可选项，不是必须指定。
• P 后面的两个字符（如果有 P）为字母。
• 连字符 (-) 后面的六个字符为数字。

下表中的所有模式将在匹配 PAA-123456 时产生正确的结果。

模式

匹配的原因

P[*]

P 后跟零个或多个字符。

[?????????]

P 为可选项。10 个问号表示任意十个字母数字字符。

P[??-!!!!!! ]

P 后跟任意两个字母数字字符，后跟一个连字符，再跟六个数字。

如何定义智能扫描规则

按照以下步骤定义智能扫描规则：

1. 打开智能扫描规则页。随即“建模”页中将显示“智能扫描规则”页。
2. 单击新建。 显示用于定义新实例的空白字段。
3. 如果默认“Portal Studio 设置中智能扫描的前导码”不适用于此规则，在前导码字段中输入前导码值。
4. 如果默认“Portal Studio 设置中智能扫描的终止符”不适用于此规则，在终止符字段中输入终止符字符。
5. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
6. 单击保存。 应用程序保存建模对象并显示成功消息。

如何将智能扫描模式添加到智能扫描规则

按照以下步骤将智能扫描模式添加到智能扫描规则中：

1. 执行“如何定义智能扫描规则”过程。

或

选择现有的智能扫描规则实例。

2. 单击智能扫描模式表格中的添加新行。将显示新行。
注释: 当表格上有多个模式时，第一列中会显示上下箭头图标，通过它可以对模式进行重新排序。
3. 在模式字段中输入识别模式的字符。
4. 根据业务需求，在行的剩余字段中选择或输入数据。
5. 重复步骤 2-4 添加其他智能扫描模式。
6. 单击保存。 应用程序显示成功消息，指出建模对象已更新。

如何测试智能扫描规则

按照以下步骤测试智能扫描规则：

1. 打开智能扫描规则页。随即“建模”页中将显示“智能扫描规则”页。
2. 展开测试部分。
3. 在智能扫描值字段中输入要测试的条形码。
4. 单击应用规则。应用程序会按照页面上的显示顺序在条形码中搜索规则内的每个模式。应用程序使用每个智能扫描类型（字段实体）以及将根据智能扫描规则中匹配模式的配置抽取到该实体的值来填充“抽取值”表格。
注释: “智能扫描类型操作”无法使用“智能扫描规则”页进行测试。

如何使用定制 JavaScript 函数

按照以下步骤使用定制 JavaScript 函数：

1. 将 JavaScript 函数添加到位于 \Camstar Portal\Scripts\User 中的 Smartscan.js。 JavaScript 函数的定义方式必须与 SmartScan.js 中定义的 "exampleFunction()" 相同。 JavaScript 函数不能在全局范围内定义。
2. 执行“如何将智能扫描模式添加到智能扫描规则”过程。
注释: 要使用 JavaScript 函数，模式必须是 "Action" 类型。
3. 操作标识符名称必须与步骤 1 中添加的 JavaScript 函数名称匹配。
4. 扫描在步骤 2 中配置的操作模式所包含的条形码。 将调用 JavaScript 函数，并执行其中的任何功能。
