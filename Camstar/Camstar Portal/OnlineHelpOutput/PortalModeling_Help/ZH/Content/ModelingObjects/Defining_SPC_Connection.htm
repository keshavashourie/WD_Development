定义 SPC 连接

SPC 连接对象用于建立 64 位 ODBC 数据库连接。需要建立连接才能为 Inline SPC 检索图表绘图数据。

使用适当的数据库驱动程序。例如，SQL Server 应该有一个名为 SQL Server 的 ODBC 驱动程序，Oracle 应该有一个类似于 Oracle In OraDb11g_home1 的 ODBC 驱动程序。

注释: 必须知道连接值才能配置此对象。有关设置 Oracle 和 SQL ODBC 驱动程序的信息，请参考 《Opcenter Execution Core 安装指南》。

如何定义 SPC 连接

按照以下步骤定义 SPC 连接：

1. 打开“SPC 连接”页。随即“建模”页中将显示“SPC 连接”页。
2. 单击新建。显示用于定义新实例的空白字段。
3. 在 SPC 连接字段中输入名称。
4. 在以下字段中输入 ODBC 连接字符串信息：
• 数据源名称
• 用户名
• 密码
5. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
6. 单击保存。应用程序保存建模对象并显示成功消息。
