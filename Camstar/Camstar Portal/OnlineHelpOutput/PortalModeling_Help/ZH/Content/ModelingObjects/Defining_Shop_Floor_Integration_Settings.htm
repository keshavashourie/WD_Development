定义车间集成设置

通过车间集成设置页，可以配置一组与以下功能相关的字段：

• 自动开始容器
• 从自动化测试装备收集缺陷
• 与物料管理应用程序编程接口 (API) 或车间资源配置 API 通信

可以通过在工厂建模页上选择车间集成设置实例将其激活。

如何定义车间集成设置

按照以下步骤定义车间集成设置的实例：

1. 从建模对象列表中选择车间集成设置。建模页中将显示车间集成设置页。
2. 单击新建。 显示用于定义新实例的空白字段。
3. 在车间集成设置字段中输入车间集成设置实例的唯一名称。
4. 根据您的业务需求输入可选信息。
5. 单击保存。 应用程序保存建模对象并显示成功消息。

如何将车间集成设置实例指派给工厂

按照以下步骤将车间集成设置实例指派给工厂：

1. 从建模对象列表中选择工厂。随即将显示工厂实例列表。
2. 从列表中选择工厂。随即工厂将显示在建模页中。
3. 从常规部分下的车间集成设置字段中选择车间集成设置实例。
4. 单击保存。 应用程序保存建模对象并显示成功消息。
