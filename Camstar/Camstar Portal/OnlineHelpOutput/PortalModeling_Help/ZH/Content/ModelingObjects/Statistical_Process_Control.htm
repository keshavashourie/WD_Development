统计流程控制

质量数据是生产信息的宝贵来源。Opcenter EX MDD 和 Opcenter EX CR 中的规范可以确保未能达到最低准则的在制品 (WIP) 单元不能装运，但这仅仅是开始。制造商还可以在不牺牲生产率的情况下生产高质量的产品。Opcenter Execution Core Inline Statistical Process Control (Inline SPC) 和 Opcenter Execution Core Statistical Process Control (Legacy SPC) 是功能强大且灵活的模块，使制造商能够提前解决问题以避免合格率或生产量降低。

Opcenter Execution Core Inline Statistical Process Control (Inline SPC)

Inline SPC 提供与 Legacy SPC 相同的功能，它使用 Siemens SPC Common Component 功能来计算和可视化数据。

有关信息，请参考《Opcenter Execution Core Inline Statistical Process Control 参考指南》。
