定义外部权限

权限类型对应于创建角色时可以指派的一组权限。应用程序具有多个权限类型，但名为“外部权限”的权限类型不同于其他权限类型，因为它允许不是基于 Opcenter Execution Core 元数据模型的定制功能的权限。另一个区别在于，可以在 Modeling 中创建外部权限对象的实例；而其他权限类型为系统定义。

外部权限类型专门用于集成到 Opcenter Execution Core 中的单独许可 SRC 模块。

外部权限页字段定义

此表定义“外部权限”页的独有字段。

请参考“建模页上的公共字段”获取有关所有建模对象的公共字段的信息。

如何定义外部权限

按照以下步骤定义外部位置权限：

1. 打开外部权限页。Modeling 页面中随即显示“外部权限”页。
2. 单击新建。 显示用于定义新实例的空白字段。
3. 在外部权限字段中输入名称。
4. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
5. 单击保存。 应用程序保存建模对象并显示成功消息。
