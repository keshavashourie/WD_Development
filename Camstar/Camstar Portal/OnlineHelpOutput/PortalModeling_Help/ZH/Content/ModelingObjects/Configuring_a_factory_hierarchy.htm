配置工厂层次结构

工厂层次结构将物理制造环境表示为相关建模对象实例金字塔。不存在“工厂层次结构”建模对象。可通过配置以下对象实例之间的父子关系定义层次结构：

• 企业
• 工厂
• 库存位置（安装行业解决方案时可用）
• 资源
重要提示: 资源建模对象包含名为“工厂等级”的字段。此字段可用于将资源配置为工厂区域或子区域，而不是设备。

工厂层次结构示例

一家名为 ABC Automotive 的虚构企业旗下有一家名为 Factory East 的工厂。该工厂的仪表板制造区域中存在两条生产线，每条生产线具有设备资源和专用库存位置。

此图以图形方式描述示例配置的建模。

示例建模步骤

以下步骤用于配置上图中的示例层次结构：

1. 定义名为 ABC Automotive 的企业。
2. 定义工厂，然后将企业设为 ABC Automotive。
3. 使用区域工厂等级定义名为“仪表板”的资源。将工厂设为 Factory East。
4. 使用单元工厂等级定义名为“SMT 装配”的资源。将父资源设为仪表板。
5. 使用单元工厂等级定义名为“箱装配”的资源。将父资源设为仪表板。
6. 使用设备工厂等级定义 SMT 设备资源。将父资源设为 SMT 装配。
7. 使用设备工厂等级定义箱设备资源。将父资源设为箱装配。
8. 定义名为“SMT 库存”的库存位置。将父资源设为 SMT 装配。
注释: 此步骤假设已安装行业解决方案。
9. 定义名为“箱库存”的库存位置。将父资源设为箱装配。
注释: 此步骤假设已安装行业解决方案。

当在“工厂层次结构”页的“工厂层次结构”树中选择企业时，此配置的结果将显而易见。

展开和折叠树

最初，树在顶层（即”企业”）折叠。单击项前面的向右箭头时，将展开树以显示该项的直系子项。单击项前面的向下箭头时，将折叠该项。可通过带对角箭头的图标，展开树的所有等级，或将树折叠到企业等级。

导入 Legacy Valor MDM XML 文件

通过“导入”按钮，可以将包含工厂生产线、机器和设备等信息的 XML 文件导入至区域的工厂级别，这些信息可用于创建工厂层次结构建模实例以及配置 SRC 设置。 该按钮默认为隐藏，仅当在树中选择区域时才显示。 选择区域后，单击其他建模对象将隐藏“导入”按钮。

单击“导入”按钮时，系统将提示选择要导入的文件。 选择文件后，将显示“导入详细信息”弹出窗口，用于显示导入文件中所含项的预览。 这些项包括生产线和设备，并将作为资源实例导入 Opcenter Execution。

通过勾选项旁边的复选框，可以选择要导入的项。 如果当前工厂层次结构中已存在同名资源实例，复选框将灰显并在项旁边显示一条消息，指明“对象已存在”。

如果 Legacy Valor MDM 文件已成功导入，则会显示一条指明服务已完成的消息并显示成功的导入数。 如果用户尝试导入的相同 Legacy Valor MDM 文件中包含当前工厂层次结构中的已有信息，则将跳过导入过程。 将显示相同的完成消息，但显示跳过的导入数。

如果已安装 Industry Solution，则可以将包含库存位置、资源和车间资源配置 (SRC) 设置等信息的 Legacy Valor MDM 文件导入至区域的工厂级别以创建相应的库存位置建模实例和 SRC 设置。 导入过程与 Opcenter Execution Core 中的导入相同，但会为导入提供额外的库存位置对象和 SRC 设置并将其显示在“导入详细信息”弹出窗口中。

如果资源的现有 SRC 设置是资源或者将要导入库存位置，则应用程序将跳过该对象，只要导入的 SRC 设置与现有设置相同，应用程序就会将其视为成功。 如果资源具有现有的 SRC 设置但机器 ID 不同，或者设置已由 SRC 中的其他资源使用，则将显示错误。

注释: 必须在“车间集成设置”建模页中配置 SRC API 字段才能在导入 Legacy Valor MDM 文件后在工厂中创建 SRC 设置。 有关信息，请参考“定义车间集成设置”。

从 SRC 导入 JSON 导出文件

除了从 Legacy Valor MDM 应用程序导入 XML 文件外，还可以从 SRC 导入 JSON 文件。 Legacy Valor MDM 文件仅限于导入区域及其下的资源，SRC 导入可能包含任何或所有完整工厂结构：企业、工厂、区域、单元和设备。

搜索树

可通过在搜索字段中输入文本，然后按 Enter 键或单击搜索图标来搜索树。

编辑树项

单击树中某个项的名称时，将在树右侧的建模页面区域中打开该项。树中将立即反映在建模区域中所做的更改。例如，如果将子项添加至项，它会在菜单中其父项下显示。

添加新项

该新加项的图标 显示在搜索栏最左侧。该图标可用于执行两项操作：

• 添加与树中的现有项具有相同的工厂等级和父项的建模实例。
• 将子项添加至树中的现有项。

在选择项并单击复制等级图标后，将显示工厂层次结构等级的关联菜单。关联菜单中列出的等级包括所选项本身的等级以及子等级（如果存在）。在关联菜单中选择等级后，应用程序将在建模区域中加载空白实例，并填充相应的工厂等级和父项。

添加现有项

此添加现有对象图标 支持新增的功能：

工厂层次结构树已增强，允许添加没有父企业的现有工厂。 此外，不属于工厂层次结构模型的资源也可以作为区域、单元、设备添加到工厂层次结构中。 选择资源将自动设置工厂/父资源和工厂级别。 最后，如果已安装 Industry Solutions，还可以将现有库存位置添加到树中。 有关如何定义和指派库存位置的详细信息，请参见《Opcenter Execution Core Industry Solutions 用户指南》。
