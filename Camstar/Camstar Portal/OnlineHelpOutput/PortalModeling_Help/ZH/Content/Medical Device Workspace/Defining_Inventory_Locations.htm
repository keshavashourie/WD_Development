定义库存位置

库存位置建模对象可用于创建容器、批次或产品的存放位置。有关将容器、批次或产品指派给库存位置的信息，请参考《Opcenter Execution Medical Device and Diagnostics Shop Floor 用户指南》。

SRC 设置按钮可用

如果应用程序配置为与 Shop Floor Resource Configuration (SRC) 交互，则在显示现有实例时，“库存位置”页上可能会显示“SRC 设置”按钮。 单击“SRC 设置”按钮将打开一个弹出窗口，用于查看或更新其他库存位置设置（称为 SRC 设置）。 应用程序会提示您在允许关闭 SRC 设置弹出窗口之前保存任何更改。

注释: 定义新的库存位置实例时，“SRC 设置”按钮不可用。

如何定义库存位置

按照以下步骤定义库存位置：

1. 打开库存位置页。随即“建模”页中将显示“库存位置”页。
2. 单击新建。显示用于定义新实例的空白字段。
3. 在库存位置字段中输入库存位置的名称。
4. 根据您的业务需求输入可选信息。请参考“建模页上的公共字段”获取有关可选字段的信息。
5. 单击保存。 应用程序保存建模对象并显示成功消息。
