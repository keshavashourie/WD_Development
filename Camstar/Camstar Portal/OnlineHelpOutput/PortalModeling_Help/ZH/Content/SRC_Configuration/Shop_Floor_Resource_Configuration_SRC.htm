Shop Floor Resource Configuration (SRC) 概述

注释: 注：仅当安装了 Shop Floor Resource Configuration (SRC) 时，以下所述功能才可用。 有关信息，请参考《Opcenter Execution Core 系统管理指南》。

通过 Shop Floor Resource Configuration (SRC)，您可以使用详细规范配置制造资源并标识这些资源在整体制造环境中的安装位置。 可以通过创建工厂层次结构来定义制造环境。

工厂层次结构

工厂层次结构从资源和资源位置的角度表示物理制造环境。 可以使用以下建模对象的实例和关系来定义层次结构：

• 企业 - 通常标识企业内的所有制造设施
• 工厂 - 一个制造设施
• 库存位置（安装 Industry Solutions 后可用）- 表示成品存储位置
• 资源 - 可以为三种类型之一：
• 区域 - 专门定义用于特定用途的位置
• 单元 - 定义于生产线等区域内的位置
• 设备 - 机器或通常被视为资源的项
重要提示: “资源”建模对象包含一个名为“工厂等级”的字段，可用于将工厂的区域或子区域配置为资源以对资源分组。

访问工厂层次结构

要访问工厂层次结构，从主 Opcenter Execution Core Modeling 菜单中选择“工厂层次结构”。 将打开“工厂层次结构”页，并在左侧显示工厂层次结构树。 企业以折叠模式显示。 如果层次结构已定义，则可以一次展开一级树。

使用工厂层次结构

在树中选择层次结构项后，树右侧将显示建模界面。 可以使用界面页进行更新。 如果项可以使用 IPL 设置进行配置，则页面将包含 SRC 按钮。 如果要为项配置 IPL 设置，则单击此按钮。 有关详细信息，请参考“定义 IPL 设备设置和参数”。

定义 IPL 设备设置和参数

IPL 设备设置和参数有助于加快 IPL 消息传递。 每个设备资源都可以有多个设置。 要设置一个设置的值，有三个选项：

• 企业值 - 为企业配置的默认值，由设备资源继承。 更新企业设置值后，配置为使用企业值的所有设备都将继承更新后的值。 切记，这些默认设置可被具有更改权限的设置更改。
• 建议值 - 该值由设备工程师在软件中设置，并计算为适合设备类型、制造商和精确模型的特定组合的最佳默认值。 建议值的值不能由最终用户更改。
• 手动输入的替代值 - 该值通过手动输入，视为工厂中设备配置方法的最佳值。 只能保存合理范围内的值。 超出该范围的值会导致错误。 单击“企业”或“建议”将擦除“替代”值。
重要提示: 不能向仅支持整数等数字输入的字段输入非数字值。

SRC 设置页

此 SRC 页包含以下部分：

1. 所选实例（从 Opcenter Execution Core Modeling 沿用的信息）。
2. 标题区域 - 用于选择要在“详细信息”区域显示哪些数据以及如何显示的选项
3. 类别区域 - 类别列表以及类别中符合选择准则的设置数
4. 详细信息区域 - 实际设置值（此区域的内容受标题和类别选择影响）

类别

根据可用的制造商和机器类型，提供各种可用的设置类别。 这些类别是固定的，用户无法修改。 分类设置可以帮助您更轻松地找到需要的设置，即使您不知道具体的名称。 设置可以为“必需”、“可选”或“其他”（仅在特定情况或出于原有原因时才需要该选项）。

每个类别都显示该类别中包含的参数数。 此数字受所选视图选项的影响。 根据是否选择了“显示可选”和“显示其他”视图选项，此数字可能更高或更低。 如果选定视图选项中没有任何参数，则不会显示类别。

详细信息区域

详细信息区域显示设置的实际值。 每个设置都有一个值，如名称、数字或切换开关（是/否）。 必需参数显示一个星号。 在 SRC 页中创建或添加新设备时，应用程序将使用在 ResourcesSettingsSchema.json 文件（包含所有设备设置的 schema 文件）中配置的默认值自动填写“IPL 机器类型”设置。

将为每个参数显示一个帮助按钮。 单击此按钮可打开“设置信息”对话框。

重要提示: 不能向仅支持整数等数字输入的字段输入非数字值。

继承

在对象导向型编程中，继承是指可创建基本类并由其他类继承其属性的功能。 从智能设置角度而言，继承是指在企业级别配置设置并使企业中的所有子级设备资源继承这些设置作为默认设置的功能。

重要提示: 继承的设置是默认设置，可由具有更改权限的设置更改。

用于从何处获取设置值的选项

对于每个设备资源上的每个设置，设置值的源有三个选项：

• 企业值 - 为企业配置的默认值，由设备资源继承。 更改企业设置值后，配置为使用企业值的所有设备都将继承更新后的值。
• 建议值 - 该值由设备工程师在软件中设置，并计算为适合设备类型、制造商和精确模型的特定组合的最佳默认值。 建议值的值不能由最终用户更改。
• 手动输入的替代值 - 该值通过手动输入，视为工厂中设备配置方法的最佳值。 只能保存合理范围内的值。 超出该范围的值会导致错误。 单击“企业”或“建议”将擦除“替代”值。
重要提示: 不能向仅支持整数等数字输入的字段输入非数字值。

更改智能设置值

通常，使用正确的设置值更新资源的最有效方法是在企业级别填充设置值，这样资源将继承这些值作为默认值。 如果企业的设置不正确，则可以更改这些设置。 所有更改都将应用到企业的子级资源，替代先前继承的默认值。 如果只有部分资源需要不同的设置，则可以只更改这些资源的值。 替代值保存在每个机器或资源的表中。 如果单击“企业”或“建议”按钮，则会删除替代值。 单击“保存”按钮将触发一个警告弹出窗口，要求确认进行了更改并且这些值将继承到其他级别。 保存更改后，将删除未使用的替代值。

重要提示: 对于替代值，名称非常具体。 使用此精确替代参数名称的所有资源都将使用相同的值。 更改一个设置的值将更改所有其他同名设置的值。 不能向仅支持整数等数字输入的字段输入非数字值。

用于配置智能设置的角色权限

需要配置智能设置的用户需要获指派具有“IPL 配置”外部权限的角色。没有该权限的用户仍可以在只读模式下查看设置。有关外部权限的更多信息，请参见“定义外部权限”。

在只读模式下，将不显示通常显示在页面中的以下项：

• 保存按钮
• 替代值和继承值切换按钮
• 设备类型选择

如何更新 SRC 设备的设置值

按照以下步骤更改 SRC 设备的设置值：

1. 从主 Opcenter Execution Core Modeling 菜单中选择工厂层次结构。 将打开“工厂层次结构”页，并在左侧显示工厂层次结构树。
2. 从工厂层次结构树中选择设备资源。 在树的右侧，应用程序将在相应的建模页中显示选定的实例。
3. 单击 SRC 按钮。将打开 SRC 设置配置页。
4. 要更改非必需设置，根据需要在“详细信息”标题的“查看”区域中选择显示可选或显示其他。 应用程序将显示符合选择准则的任何其他设置。
5. 单击要更新的设置旁边的展开按钮。 或者，单击全部展开按钮（如果要更改多个设置）。 单击全选（如果必须更改所有的值）。
6. 要定制单独的设置值，单击替代按钮。 该值将解锁以进行编辑
7. 进行更改。 如果值不在特定于此更改或设备模型的配置范围内，则将触发警告。
重要提示: 不能向仅支持整数等数字输入的字段输入非数字值。
8. 完成后，在标题区域工具条中单击保存。 如果要在企业级别进行更改，则会显示触发警告，要求确认将要执行的更改。 单击确定按钮。将显示成功保存消息。

复制、导出和导入车间资源设置

只能复制单个资源的设置，但可以使用设置进行复制。 这一点非常重要，因为许多较为有用的机械经常在工厂中存在多个。 可以为任何级别或组（包括整个企业）执行导出和导入。 但系统会根据现有的名称和结构保存和重新应用信息。 这不适用于制作副本。

复制资源的智能设置

可以对工厂层次结构树中任意级别的任意单个元素执行复制，但复制必须在 Opcenter Execution Core 应用程序中完成。 有关详细说明，请参考《Opcenter Execution Core Modeling 用户指南》。

导出和导入智能设置值

值必须先导出才能导入。 应记住以下两点：

• 资源结构（工厂层次结构树）是 Opcenter Execution Core 的一部分并由其管理。
• 每个资源的详细设置由 SRC 插件（具体为“智能设置”对话框）管理。

这两种类型的数据可以彼此独立导出。 如果这两种数据，必须执行两次单独的导出和导入。

注释: 有关导出工厂层次结构树元素的信息，请参考《Opcenter Execution Core Modeling 用户指南》。

如何导出 SRC 设置

必须先导出 SRC 设备设置，然后才能导入它们。 按照以下步骤从工厂层次结构树导出 SRC 设置：

1. 从主 Opcenter Execution Core Modeling 菜单中选择工厂层次结构。 将打开“工厂层次结构”页，并在左侧显示工厂层次结构树。
2. 从工厂层次结构树中选择要导出的级别。 例如，对于生产线中的所有设备，选择该生产线。 对于工厂中的所有设备，选择工厂。 应用程序将打开 SRC 设置页。
3. 在 SRC 设置页工具条中，单击导出按钮。 如果有任何未保存的设置，则会触发一条警告消息。 将导出选定层次结构级别的所有设置。 将为每个元素（机器、生产线、工厂）保存资源详细信息，但不保存实际布局结构。

如何导入 SRC 设置

在导入 SRC 值之前，需要创建一个导出文件，其中应包含现在要导入的所有元素。 请参考“如何导出设置”。

按照以下步骤导入 SRC 设置：

1. 从主 Opcenter Execution Core Modeling 菜单中选择工厂层次结构。 将打开“工厂层次结构”页，并在左侧显示工厂层次结构树。
2. 从工厂层次结构树中选择要导入的级别。 例如，对于生产线中的所有设备，选择该生产线。 对于工厂中的所有设备，选择工厂。 要导入单个资源的设置，选择该资源。 应用程序将打开 SRC 设置页。
3. 在 SRC 设置页工具条中，单击“导入”按钮。 将显示文件对话框弹出窗口，其中显示可以导入的资源文件。
4. 选择一个文件，然后单击确定。 将显示“导入设置信息”弹出窗口，其中显示当前导入文件的名称。
5. 单击确定。应用程序将显示一条消息，指明导入成功。
