定义 CIO 出站连接

CIO 连接对象包含外部连接详细信息，其中出站消息使用 OAuth2 身份验证发送。

使用“建模”中的“出站连接”页，可以使用支持的身份验证方法对外部应用程序进行身份验证。 在此页面中，可以定义外部连接，该外部连接将在“出站定义表格”的“通用 REST API 弹出”页的“出站连接”下拉列表中作为条目显示。

在此页面中，用户可以提供凭据或仅提供令牌和 URL 信息。

如何定义出站连接

按照以下步骤定义出站连接：

1. 打开“出站连接”页。“建模”页中将显示“出站连接”页。
2. 单击新建。显示用于定义新实例的空白字段。
3. 在出站连接字段中输入名称。
4. 身份验证类型，默认选择 OAuth2。
5. 在以下字段中输入出站连接信息：
• 用户名
• 密码
• Body
• 令牌 URL
6. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
7. 单击保存。应用程序保存建模对象并显示成功消息。
