Konfigurieren der Produktions- und Ressourcenprotokolle

Die Seite "Protokollkonfiguration" enthält den Abschnitt "Historienhauptlinie" und den Abschnitt "Transaktionsdetails". Im Abschnitt "Historienhauptlinie" können Sie die Felder auswählen, die in der Tabelle "Historienhauptlinie" in den Produktions- oder Ressourcenprotokollen angezeigt werden sollen. In den Abschnitten "Transaktionsdetails" können Sie die zusätzlichen Informationen konfigurieren, die angezeigt werden, wenn Sie eine Transaktion in der Tabelle "Historienhauptlinie" in den Produktions- oder Ressourcenprotokollen auswählen.

Tabelle "Historienhauptlinie"

Die Tabelle "Historienhauptlinie" in den Produktions- und Ressourcenprotokollen listet die Transaktionen auf, die für einen Container, Behälter oder Ereignisdatensatz ausgeführt werden, und stellt historische Informationen für diese Transaktionen bereit. Das Portal enthält standardmäßig Informationen zum Transaktionsdatum (Transaktionsdatum). Sie können die im Protokoll angezeigten Informationen den jeweiligen Geschäftsanforderungen entsprechend konfigurieren.

Felddefinitionen der Seite "Protokollkonfiguration"

Diese Tabelle definiert die Felder auf der Seite "Protokollkonfiguration".

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Feld

Definition

Typ

Historienhauptlinie

 

Ermöglicht die Auswahl der Felder, die in der Tabelle "Historienhauptlinie" in den Produktions- oder Ressourcenprotokollen angezeigt werden sollen. Mit Kontrollkästchen können Sie die Felder auswählen, die Sie hinzufügen oder entfernen möchten.

Erforderlich

Transaktionsdetails

 

Baumstruktur, mit der Sie das Historienobjekt / die Transaktion auswählen können, die Sie konfigurieren möchten, und Tabellen, mit denen Sie die Felder auswählen können, die auf der Registerkarte "Zusammenfassung / Details" für die in der Tabelle "Historienhauptlinie" in den Produktions- oder Ressourcenprotokollen ausgewählte Transaktion angezeigt werden sollen. Mit Kontrollkästchen können Sie die Felder auswählen, die Sie hinzufügen oder entfernen möchten.

Optional

Konfigurieren von Transaktionsdetails

Auf der Seite "Produktionsprotokoll" zeigt die Anwendung normalerweise die Registerkarte "Zusammenfassung / Details" unter der Tabelle "Historienhauptlinie" an, wenn Sie eine Transaktion in der Tabelle "Historienhauptlinie" auswählen. Die Tabelle "Zusammenfassung / Details" enthält Historieninformationen für die ausgewählte Transaktion.

Die zu konfigurierenden Historienobjekte oder Transaktionen werden in einer Baumstrukturkonturansicht angezeigt. Die Liste "Objekte" kann erweitert werden und die Historieninformationen für die untergeordneten Objekte können auch so konfiguriert werden, dass sie in der Tabelle "Zusammenfassung / Details" angezeigt werden.

Vorgehensweise zum Definieren einer Protokollkonfigurationsinstanz

Gehen Sie folgendermaßen vor, um eine neue Instanz der Protokollkonfiguration zu erstellen:

1. Öffnen Sie die Seite Protokollkonfiguration. Die Seite "Protokollkonfiguration" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu.Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Protokollkonfigurationsinstanz in das Feld Protokollkonfiguration ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
5. Klicken Sie auf Speichern. Die neue Instanz wird in der Liste der Protokollkonfigurationsinstanzen angezeigt.

Vorgehensweise zum Konfigurieren der Tabelle "Historienhauptlinie"

Gehen Sie folgendermaßen vor, um eine Tabelle "Historienhauptlinie" zu konfigurieren:

1. Führen Sie das Verfahren "Vorgehensweise zum Definieren einer Protokollkonfigurationsinstanz" aus.
Oder
Wählen Sie eine Instanz aus der Liste Protokollkonfigurationen aus. Die Anwendung zeigt alle verfügbaren Felder und alle ausgewählten Felder an, die in der Tabelle "Historienhauptlinie" angezeigt werden sollen. Standardmäßig ist das Feld "Transaktionsdatum" (TxnDate) in der Anwendung ausgewählt.

 

2. Führen Sie eine der folgenden Aktionen durch:
• Aktivieren Sie das Kontrollkästchen Verfügbare Felder, um alle verfügbaren Felder hinzuzufügen. Die Anwendung verschiebt alle Felder aus der Liste "Verfügbare Felder" (Available Fields) in die Liste "Ausgewählte Felder" (Selected Fields).
• Wählen Sie mehrere Felder in der Liste Verfügbare Felder aus und klicken Sie auf die Schaltfläche Hinzufügen. Die Anwendung verschiebt die betreffenden Felder in die Liste "Ausgewählte Felder" (Selected Fields).
• Wählen Sie das gewünschte Feld in der Liste Verfügbare Felder aus und klicken Sie auf die Schaltfläche Hinzufügen. Die Anwendung verschiebt das Feld in die Liste "Ausgewählte Felder" (Selected Fields).
3. Wählen Sie ein beliebiges Feld aus, das Sie verschieben möchten, und verwenden Sie die Pfeiltasten zum Ziehen und Ablegen, um die Reihenfolge der Felder zu ändern.
Hinweis: Die Anwendung zeigt die Spalten in der Tabelle "Historienhauptlinie" in der Reihenfolge der Felder in der Liste "Ausgewählte Felder" (Selected Fields) an.
4. Um ein ausgewähltes Feld zu löschen, verwenden Sie die Schaltfläche Entfernen.
5. Klicken Sie auf Speichern. Die Anwendung aktualisiert die Tabelle "Historienhauptlinie".
6. Weitere Informationen finden Sie unter "Vorgehensweise zum Konfigurieren von Transaktionsinformationen" für diese Historientabelle.

Vorgehensweise zum Konfigurieren von Transaktionsinformationen

Gehen Sie folgendermaßen vor, um Transaktionsinformationen zu konfigurieren:

1. Wählen Sie eine Instanz aus der Instanzliste Protokollkonfiguration aus.
2. Erweitern Sie den Abschnitt Transaktionsdetails. Die Historienobjekte (Transaktionen), für die Zusammenfassung und Details angezeigt werden können, sind in einer Baumstruktur organisiert. Wenn eine Transaktion ausgewählt ist, zeigt die Anwendung alle Felder an, die in der Liste "Verfügbare Felder" verfügbar sind. Für das übergeordnete Objekt "HistoryDetails" wird standardmäßig das Feld "DisplayName"angezeigt.
3. Wählen Sie das Historienobjekt, das Sie konfigurieren möchten, in der Liste Transaktionen aus.
4. Führen Sie eine der folgenden Aktionen durch:
• Aktivieren Sie das Kontrollkästchen Verfügbare Felder, um alle verfügbaren Felder hinzuzufügen. Die Anwendung verschiebt alle Felder aus der Liste "Verfügbare Felder" (Available Fields) in die Liste "Ausgewählte Felder" (Selected Fields).
• Wählen Sie mehrere Felder in der Liste Verfügbare Felder aus und klicken Sie auf die Schaltfläche Hinzufügen. Die Anwendung verschiebt die betreffenden Felder in die Liste "Ausgewählte Felder" (Selected Fields).
• Wählen Sie das gewünschte Feld in der Liste Verfügbare Felder aus und klicken Sie auf die Schaltfläche Hinzufügen. Die Anwendung verschiebt das Feld in die Liste "Ausgewählte Felder" (Selected Fields).
5. Wählen Sie ein beliebiges Feld aus, das Sie verschieben möchten, und verwenden Sie die Pfeiltasten zum Ziehen und Ablegen, um die Reihenfolge der Felder zu ändern.
Hinweis: Die Anwendung zeigt die Spalten in der Tabelle "Zusammenfassung / Details" entsprechend der Reihenfolge der Felder in der Liste "Ausgewählte Felder" an.
6. Um ein ausgewähltes Feld zu löschen, verwenden Sie die Schaltfläche Entfernen.
7. Klicken Sie auf Speichern. Die Anwendung aktualisiert das Historienobjekt (Transaktion).
8. Wiederholen Sie Schritte 3-6 für jede Transaktion, die Sie konfigurieren möchten.
