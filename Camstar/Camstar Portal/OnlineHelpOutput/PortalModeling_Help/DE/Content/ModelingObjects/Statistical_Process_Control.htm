Statistische Prozesskontrolle

Qualitätsdaten sind eine wertvolle Quelle von Produktionsinformationen. Die Spezifikationen in Opcenter EX MDD und Opcenter EX CR gewährleisten, dass Umlaufbestandseinheiten, die nicht den Mindestanforderungen entsprechen, nicht versandt werden können, aber das ist nur der Anfang. Hersteller können hochwertige Produkte ohne Abstriche bei der Produktivität produzieren. Opcenter Execution Core Inline Statistical Process Control (Inline SPC) und Opcenter Execution Core Statistical Process Control (Legacy SPC) sind leistungsstarke und flexible Module, mit denen Hersteller Probleme lösen können, bevor sie zu einer Verringerung des Ertrags oder des Durchsatzes führen.

Opcenter Execution Core Inline Statistical Process Control (Inline SPC)

Unter Verwendung der gemeinsamen Siemens SPC-Komponentenfunktionalität zur Datenberechnung und -visualisierung bietet Inline-SPC die gleiche Funktionalität wie Legacy SPC.

Weitere Informationen finden Sie im Opcenter Execution Core Inline Statistical Process Control-Referenzhandbuch.
