Definieren eines Jobauftrags

Ein Jobauftrag gibt die notwendige Wartung an, die für eine Ressource fällig ist. Auf dieser Seite können Sie die Wartungsfälligkeit der Ressource ermitteln und Techniker zuweisen, um den Wartungs- oder Reparaturjob auszuführen.

Felddefinitionen der Seite "Jobauftrag"

Diese Tabelle definiert die Felder, die nur auf der Seite "Jobauftrag" zu finden sind.

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Feld

Definition

Typ

Details

Jobmodell

Arbeitsplan, der für die Reparatur oder die regelmäßige Wartung einer Fertigungsressource durchgeführt wird.

Erforderlich

Tabelle "Details"

Tabelle, die die Ressource angibt, für die eine Wartung fällig ist.

Optional

Ressource

Ausrüstung, an der die Wartung durchgeführt werden soll.

Optional

Tabelle "Techniker"

Tabelle, die einen oder mehrere Techniker angibt, die den Wartungsjob ausführen können.

Optional

Techniker

Name oder ID des Technikers, der für die Wartung verantwortlich ist.

Optional

Vorgehensweise zum Definieren eines Jobauftrags

Gehen Sie folgendermaßen vor, um einen Jobauftrag zu definieren:

1. Öffnen Sie die Seite Jobauftrag. Die Seite "Jobauftrag" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das Feld Jobauftrag ein.
4. Wählen Sie das Jobmodell aus.
5. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein.Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
