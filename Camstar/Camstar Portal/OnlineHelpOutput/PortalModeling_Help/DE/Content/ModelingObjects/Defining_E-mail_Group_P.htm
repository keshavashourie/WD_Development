Definieren von E-Mail-Gruppen

Das Modellierungsobjekt "E-Mail-Gruppe" wird verwendet, um E-Mail-Empfänger wie Mitarbeiter zu gruppieren. Für jede E-Mail-Gruppe muss ein E-Mail-Transport (SMTP) ausgewählt werden.

Felddefinitionen der Seite "E-Mail-Gruppe"

Diese Tabelle definiert die Felder, die nur auf der Seite "E-Mail-Gruppe" vorhanden sind.

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Feld

Definition

Typ

Details

E-Mail-Transport

Name, der ein SMTP-Protokoll angibt, das zum Senden von E-Mail-Nachrichten verwendet wird.

Erforderlich

Eintragstyp

Typ der Objekte in dieser Objektgruppe.

Hinweis: Die Anwendung bietet einen Standardwert für "Mitarbeiter", der nicht geändert werden kann.

Optional

Tabelle "Einträge"

Eine Tabelle, die es Ihnen ermöglicht, der Gruppe Benutzernamen von Mitarbeitern hinzuzufügen, und die die Benutzernamen von allen Mitarbeitern auflistet, die der Gruppe bereits hinzugefügt wurden.

Hinweis: Vorhandene Einträge können gelöscht werden.

Optional

Tabelle "Gruppen"

Tabelle, die es Ihnen ermöglicht, weitere E-Mail-Gruppen als Untergruppen hinzufügen, und die auch alle bereits hinzugefügten Untergruppen auflistet.

Hinweis: Vorhandene Einträge können gelöscht werden.

Optional

Vorgehensweise zum Definieren einer E-Mail-Gruppe

Gehen Sie folgendermaßen vor, um eine E-Mail-Gruppe zu definieren:

1. Öffnen Sie die Seite E-Mail GruppeKlicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.. Die Seite "E-Mail-Gruppe" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für diese E-Mail-Gruppendefinition in das Feld E-Mail-Gruppe ein.
4. Wählen Sie den E-Mail-Transport aus.
5. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
