Definieren externer Berechtigungen

Ein Berechtigungstyp entspricht einem Satz von Berechtigungen, die beim Erstellen einer Rolle zugewiesen werden können. Die Anwendung verfügt über mehrere Berechtigungstypen, aber die benannte externe Berechtigung unterscheidet sich von den anderen, da sie Berechtigungen für benutzerdefinierte Funktionalität erlaubt, die nicht auf dem Opcenter Execution Core-Metadatenmodell basieren. Ein weiterer Unterschied ist, dass eine Instanz des Objekts "Externe Berechtigung" in der Modellierung erstellt werden kann. Die anderen Berechtigungstypen werden vom System definiert.

Eine bestimmte Verwendung des Typs "Externe Berechtigung" gilt für das separat lizenzierte SRC-Modul, das in Opcenter Execution Core integriert ist.

Felddefinitionen der Seite "Externe Berechtigung"

Diese Tabelle definiert die Felder, die nur auf der Seite "Externe Berechtigung" vorhanden sind.

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Feld

Definition

Typ

Allgemein

Anwendung

Modul

Definieren einer externen Berechtigung

Gehen Sie folgendermaßen vor, um eine externe Berechtigung zu definieren:

1. Öffnen Sie die Seite Externe Berechtigung. Die Seite "Externe Berechtigung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen in das Feld Externe Berechtigung ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
