Definieren von Aufgabenstatus für Produktionsaufträge

Ein Aufgabenstatus für Produktionsaufträge ist ein benanntes Objekt, mit dem Sie die Statuscodes definieren können, die im Anweisungsaufgabentyp "Supervisor-Prüfung" verwendet werden.

Felddefinitionen der Seite "Produktionsauftrag Aufgabenstatus"

Diese Tabelle definiert die Felder auf der Seite "Produktionsauftrag Aufgabenstatus".

Feld

Definition

Typ

Produktionsauftrag Aufgabenstatus

Benutzerdefinierter Statuscode einer Aufgabe "Supervisor-Prüfung". Beispiele sind: Gesperrt, Beendet, In Bearbeitung, Nicht gestartet und Gestartet.

Erforderlich

Allgemein

Aufgabe abgeschlossen

Eine Aufgabe mit diesem Status gilt als abgeschlossen und bestanden.

Wichtig: Nur Aufgaben, denen ein Status zugewiesen wurde, bei dem diese Option aktiviert ist, gelten als abgeschlossen.

Optional

Aufgabe fehlgeschlagen

Eine Aufgabe mit diesem Status gilt als fehlgeschlagen. Aktivieren Sie diese Option, um anzugeben, dass ein Problem vorliegt, das gelöst werden muss, bevor die Aufgabe abgeschlossen werden kann.

Optional
Hinweis: Wenn Sie weder "Aufgabe abgeschlossen" noch "Aufgabe fehlgeschlagen" aktivieren, wird davon ausgegangen, dass die Aufgabe noch ausgeführt wird.

Vorgehensweise zum Definieren des Aufgabenstatus für Produktionsaufträge

Gehen Sie folgendermaßen vor, um einen Aufgabenstatus für Produktionsaufträge zu definieren:

1. Öffnen Sie die Seite Produktionsauftrag Aufgabenstatus. Die Seite "Produktionsauftrag Aufgabenstatus" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Benennen Sie einen Statuscode im Feld Produktionsauftrag Aufgabenstatus.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
