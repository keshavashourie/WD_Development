Definieren von SPC-Verbindungen

Das SPC-Verbindungsobjekt wird verwendet, um eine 64-Bit-ODBC-Datenbankverbindung herzustellen. Dies ist erforderlich, um die Plotdaten eines Charts für Inline-SPC abzurufen.

Verwenden Sie den entsprechenden Datenbanktreiber. SQL Server muss z. B. den ODBC-Treiber "SQL Server" und Oracle einen ODBC-Treiber wie "Oracle In OraDb11g_home1" haben.

Hinweis: Sie müssen die Verbindungswerte kennen, um dieses Objekt zu konfigurieren. Informationen zum Einrichten von Oracle- und SQL-ODBC-Treibern finden Sie in der Opcenter Execution Core-Installationsanleitung.

Vorgehensweise zum Definieren einer SPC-Verbindung

Gehen Sie folgendermaßen vor, um eine SPC-Verbindung zu definieren:

1. Öffnen Sie die Seite "SPC-Verbindung". Die Seite "SPC-Verbindung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen in das Feld SPC-Verbindung ein.
4. Geben Sie die Informationen zum ODBC-Connection String in die folgenden Felder ein:
• Datenquellenname
• Benutzername
• Password
5. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
