Definieren eines Jobmodells

Ein Jobmodell ist ein Ablauf oder eine Reihe von Schritten, die für die Reparatur oder Wartung der Ressource ausgeführt werden müssen. Mit diesem Modellierungsobjekt können Sie die erforderlichen Details vordefinieren, z. B. die Jobtypen, Stufen für die Reparatur, Ausführungsdetails, Anhängen des erforderlichen Dokuments usw.

Ein Jobmodell kann ein einfacher Einschritt-Arbeitsplan oder ein komplizierter Arbeitsablauf mit mehreren Schritten sein. Es wird eine Validierung durchgeführt, um zu gewährleisten, dass die erforderlichen Wartungsschritte in der richtigen Reihenfolge ausgeführt werden.

Die Bewerbung unterstützt drei Jobtypen:

• Normal. Wie der Name schon sagt, handelt es sich um einen normalen Wartungsjobauftrag.
• PM ist für Jobs bei welchen während der Transaktion "Job abschließen" die auto-abgeschlossene Wartung automatisch ausgewählt wird.
• Aufarbeitung. Die Aufarbeitungsanzahl des Teils wird während der Transaktion "Job abschließen" automatisch erhöht.

Wenn ein Jobmodell mit offenen oder aktiven Jobs verknüpft ist, dürfen Sie die folgenden Aktionen nicht ausführen:

• Löschen einer vorhandenen Stufe
• Bearbeiten einer vorhandenen Stufensequenz
• Eine neues Stufe hinzufügen
• löschen des Modellobjekts "Jobmodell"

Sie müssen die offenen Jobs abschließen oder abbrechen, um obige Aktionen durchzuführen.

Nach seiner Konfiguration kann ein Jobmodell einer spezifischen Ausrüstungsressource als Prozedur zugewiesen werden, die befolgt werden muss, wenn die Ausrüstung ausfällt.

Tabelle "Zu Stufen"

Tabelle, die eine Alternative für die nächste Stufe nach dieser aktuellen Stufe angibt. Hier hinzugefügte Stufen werden in der Liste "Zu Stufe" angezeigt, wenn sich der Techniker auf der Seite "Jobfortschritt" für den gerade konfigurierten Schritt befindet. Wenn keine Zielstufen hinzugefügt werden, wechselt die Stufe automatisch zur nächsten konfigurierten Stufe.

Optional

Zu Stufe

Stufe, zu der der Benutzer von der aktuellen Stufe aus wechseln kann. Wenn dieses Feld angegeben ist, wird das Dropdown-Feld "Zu Stufe" auf der Seite "Jobfortschritt" mit diesem Wert ausgefüllt.

Hinweis: Dieses Feld ist erforderlich, wenn der Tabelle eine Zeile hinzugefügt wird.

Optional

Zu Stufe: Auswahl

Dynamischer Ausdruck, mit dem festgelegt wird, welche "Zu Stufe" angemeldet werden soll, wenn während des Jobfortschritts keine Stufe angegeben ist. "Zu Stufe: Auswahl" wird ausgewertet, bis ein Erfolg ("Wahr") erkannt wird und die nächste Stufe auf diesen Wert festgelegt wird. Bei "Falsch"-Ergebnissen für "Zu Stufe: Auswahl" folgt die nächste Stufe der Stufensequenz, die in den Details des Jobmodells angegeben ist. Dieses Feld ist optional. Sie können das Feld "Zu Stufe" ohne "Zu Stufe: Auswahl" auswählen.

Optional

Vorgehensweise zum Definieren eines Jobmodells

Gehen Sie folgendermaßen vor, um ein Jobmodell zu definieren:

1. Öffnen Sie die Seite Jobmodell. Die Seite "Jobmodell" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das Feld Jobmodell ein.
4. Wählen Sie Jobtyp aus.
5. Verwenden Sie die Tabelle Details wie folgt für jede Stufe (jeden Schritt), die (der) dem Jobmodell hinzugefügt werden soll:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung öffnet das Popup "Hinzufügen".
b. Wählen Sie Stufe aus.
c. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf OK. Das Popup "Hinzufügen" wird geschlossen.
7. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
