Definieren der SignalR-Konfiguration

SignalR bietet der Anwendung die Möglichkeit, Echtzeitaktualisierungen hinzuzufügen. Diese Funktionalität ermöglicht es dem Server, Inhalte sofort an die Clients zu senden, ohne dass der Client Daten anfordert. Auf der Seite "SignalR-Konfiguration" können Sie die SignalR-Funktion konfigurieren, die in einer Mendix-UI-basierten Anwendungsseite verwendet werden kann.

Beim Definieren einer SignalR-Konfiguration

Das Feld "SignalR-Konfiguration" auf der Modellierungsseite "Fabrik" ist optional.

Felddefinitionen der Seite "SignalR-Konfiguration"

Feld

Definition

Typ

SignalR HubName

Eine Liste der verfügbaren SignalR-Hubs, die auf einem Server gehostet werden, der für die Verwaltung der Echtzeitkommunikation unerlässlich ist. Die folgenden Hubs sind standardmäßig verfügbar:

• OpcenterHub – Hub, der aus allgemeinen Methoden und Logik besteht, die über verschiedene funktionsspezifische Hubs hinweg gemeinsam verwendet werden. Dieser Hub bietet allgemeine Funktionen, z. B. das Abonnieren von Gruppen und das Versenden von Nachrichten, wodurch die Duplizierung von Code vermieden wird.
• MfgOperationhub – Hub speziell für die MfgOperation ". Dieser Hub erbt von OpcenterHub und verwendet die allgemeinen Methoden und Logik, einschließlich Methoden, die speziell für die MfgOperation-Funktion gelten.

Hinweis: Dieser Hub wird nur angezeigt, wenn Opcenter Execution Electronics installiert ist.

Erforderlich

URL des SignalR-Servers

SignalR-Servername mit optionaler Portnummer.

Erforderlich

Protokoll aktivieren

Kontrollkästchen, mit dem festgelegt wird, ob die Protokollierung im Zusammenhang mit SignalR aktiviert oder deaktiviert werden soll, wenn die Funktion ausgeführt wird.

Optional

Vorgehensweise zum Definieren einer SignalR-Konfiguration

Gehen Sie folgendermaßen vor, um eine SignalR-Konfiguration zu definieren:

1. Öffnen Sie die Seite SignalR-Konfiguration. Die Seite "SignalR-Konfiguration" wird auf der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für diese SignalR-Konfiguration in das Feld SignalR-Konfiguration ein.
4. Wählen Sie einen verfügbaren SignalR-Hub aus der Liste SignalR HubName aus.
5. Geben Sie die Server-URL in das Feld SignalR-Hub-URL ein.
6. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
