Definieren von Werkzeugen

Ein Werkzeug ist eine physische Ressource, die für Ausrüstung verwendet wird und eine Unterklasse des Ressourcenobjekts in der Anwendung darstellt.

Felddefinitionen der Seite "Werkzeug"

Diese Tabelle definiert die Felder auf der Seite "Werkzeug".

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Feld

Definition

Typ

Werkzeug

Name des Werkzeugs.

Erforderlich

Allgemein

Fabrik

Gibt die Fabrik für das Werkzeug an.

Optional

Standort

Gibt den Ort für das Werkzeug an.

Optional

Werkzeugfamilie

Werkzeugfamilie, zu der dieses Werkzeug gehört.

Optional

Trainingsanforderungsgruppe

Trainingsgruppe, die zur Autorisierung eines Benutzers für die Durchführung einer angegebenen Aufgabe erforderlich ist.

Optional

Freigabeebene

Zum Erzwingen der Linienfreigabe festgelegte Ebene. Linienfreigabe schränkt die parallele Bearbeitung ein.

Optional

Druckwarteschlange

Name des Netzwerkdruckers, der ggf. zum Drucken von Containeretiketten im Zusammenhang mit der Ressource verwendet wird.

Optional

Lieferant

Name oder Spezifikation des Lieferanten, von dem das Werkzeug bezogen oder hergestellt wurde.

Optional

Lieferantenmodell

Lieferantenmodell für das Werkzeug.

Optional

Lieferantenseriennummer

Seriennummer des Lieferanten für das Werkzeug.

Optional

Eltern-Ressource

Name der Eltern-Ausrüstungsressource. Beim Speichern der Ausrüstung führt die Anwendung die Kind-Ausrüstung in einer schreibgeschützten Liste in der Tabelle "Kind-Ausrüstungen" der Eltern-Ausrüstung auf.

Optional

Wartungsklasse

Definiert die Beziehung zwischen einer Wartungsanforderung und einer Gruppe von Ressourcen.

Optional

Smart-Scan-Regel

Liste aller in der Anwendung definierten Nummerierungsregeln, die dem Werkzeug zur Implementierung von regelbasiertem Smart Scanning zugewiesen werden können. Verwenden Sie dieses Feld, um einer Fabrik eine Standardnummerierungsregel für automatische Nummerierung beim Starten von Losen und Containern zuzuordnen.

Optional

Ressourcentyp

Bestimmt einen Ausrüstungstyp, z. B. reguläre Wartungsausrüstung, der einem Ressourcenstatusmodell zugeordnet werden kann.

Optional

Ressourcenstatusmodell

Definiert einen Satz gültiger Ressourcenstatusübergänge und zugehöriger Verfügbarkeitsstatus. Ein Ressourcenstatusmodell kann so konfiguriert werden, dass die Anwendung automatisch Wartungsaufträge für Ressourcen erstellt, und zwar basierend auf bestimmten Ursachencodes und konfigurierbaren Bedingungen, die für eine Statusänderung eingegebenen wurden. Ressourcenstatusmodelle werden Ressourcen zugewiesen.

Optional

Kurzname

Beliebiger alternativer Name zum Verweis auf die Ressource.

Anmerkung: Dieses Feld wird von Opcenter EX EL IoT und Opcenter EX EL MM verwendet.

Optional

Fabriklevel

Level, das der Ressource innerhalb der gesamten Fabrikhierarchie zugewiesen ist. Operanden schließen ein:

• Bereich
• Zelle
• Ausrüstung

Anmerkung: Eine Eltern-Ressource, die dieser Ressource zugewiesen ist, muss sich ein Level oberhalb der Hierarchie befinden.

Anmerkung: Dieses Feld wird von Opcenter, IoT und Material Management verwendet.

Optional

Rezeptmuster

Ausdruck, der in den Namen eines Rezepts aufgelöst wird, das für die Ressourceneinrichtung während Fertigungsoperationen erforderlich ist. Die Anwendung verwendet dieses Feld nur, wenn kein Rezept mithilfe eines Rezeptplans oder einer Rezeptmatrix gefunden wurde.

Hinweis: Dieses Feld muss einen einheitlichen Ausdruck enthalten, der in Designer als gültig betrachtet wird.

Optional

Fabrikebenenindex

Ebenenindex, der die Reihenfolge der Elemente definiert, die auf der Seite "Fabrikhierarchie" angezeigt werden. Elemente mit einer höheren Indexebene werden unter Elementen mit einer niedrigeren Indexebene innerhalb derselben Gruppe ihres übergeordneten Elements angezeigt.

Hinweis: Das Feld akzeptiert nur Werte in Form von Ganzzahlen.

Optional

Stückliste

Die für dieses Werkzeug oder diese Ressource verwendete Stück- oder Materialliste.

Optional

Hochvolumige Verfolgbarkeit verwenden

Kontrollkästchen, das die Verfolgbarkeit von hochvolumigen Ressourcen ermöglicht, sodass Fabriken mit einer hohen Materialverbrauchsrate in der Lage sind, alle Materialkomponenten zu verfolgen, die derzeit auf eine Maschine geladen sind. Wenn das Kontrollkästchen beim Definieren einer Ressource aktiviert ist, wird die Ressource auf den Seiten "Hochvolumige Ressourceneinrichtung" und "Hochvolumige Komponentenverbrauch" angezeigt. Diese Seiten werden verwendet, um eine "Maschineneinrichtung" für eine Ressource zu definieren, die mit einem Container verknüpft werden kann, wenn dieser Container durch die Ressource bewegt wird. Anforderungen der Einrichtung eines optionalen Rezepts für eine Produktionsressource.

Optional

Tabelle "Kind-Ressourcen"

Tabelle mit der Kind-Ausrüstung der Ressource.

Optional

Vorgehensweise zum Definieren eines Werkzeugs

Gehen Sie folgendermaßen vor, um ein Werkzeug zu definieren:

1. Öffnen Sie die Seite Werkzeug. Die Seite "Werkzeug" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen des Werkzeugs in das Feld Werkzeug ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
