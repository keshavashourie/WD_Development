Definieren von Teilen

Auf dieser Seite können Sie Spezifikationen eines Teils aktualisieren oder bearbeiten, nachdem es erstellt wurde.

Hinweis: Ein Teil wird auf der Seite Teileerstellung erstellt. Um auf die Seite zuzugreifen, navigieren Sie zu Ressource > Teile > Teile-Services > Teileerstellung.

Vorgehensweise zum Definieren eines Teils

Gehen Sie folgendermaßen vor, um ein Teil zu definieren:

1. Öffnen Sie die Modellierungsseite Teil. Die Seite "Teil" wird innerhalb der Modellierungsseite angezeigt.
2. Wählen Sie in der Liste der angezeigten Modellierungsinstanzen die Instanz Teil aus.
Hinweis: Das Teil kann auf der Seite Teileerstellung erstellt werden. Um auf die Seite zuzugreifen, navigieren Sie zu Ressource > Teile > Teile-Services > Teileerstellung.
3. Wählen Sie das Materialteil aus.
4. Wählen Sie die Teilemenge aus.
5. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
