Definieren von Fehlermodusgruppen

Das Modellierungsobjekt "Fehlermodusgruppe" ermöglicht es Ihnen, eine Gruppe von Fehlermodi zu definieren. Es vereinfacht die Auswahl eines Fehlermodus, indem es Ihnen ermöglicht, Fehlermodi zu gruppieren, die die tatsächliche Fehlerursache darstellen.

Fehlermodusgruppen werden auf der Seite "Organisation" Ereignisklassifikationen und -unterklassifikationen zugeordnet.

Beim Definieren einer Fehlermodusgruppe

Sie können den betreffenden Tabellen mehrere Einträge oder Gruppen hinzufügen.

Die Schaltfläche "Aufgelöste Einträge" ermöglicht es Ihnen, eine Liste aller Werte anzuzeigen, die in der Eintragsliste für diese Gruppe und alle darin enthaltenen Gruppen angegeben sind.

"Fehlermodusgruppe" enthält die optionale Modellierungsdefinition "Fehlermodus".

Vorgehensweise zum Definieren einer Fehlermodusgruppe

Gehen Sie folgendermaßen vor, um eine Fehlermodusgruppe zu definieren:

1. Öffnen Sie die Seite Fehlermodusgruppe. Die Seite "Fehlermodusgruppe" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für diese Fehlermodusgruppe in das Feld Fehlermodusgruppe ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Hinzufügen von Einträgen zu einer Fehlermodusgruppe

Gehen Sie folgendermaßen vor, um einer Fehlermodusgruppe Einträge hinzuzufügen:

1. Führen Sie die Schritte unter "Vorgehensweise zum Definieren einer Fehlermodusgruppe" aus.

Oder

Wählen Sie eine bereits vorhandene Instanz einer Fehleraktionstypgruppe aus.

2. Klicken Sie in der Tabelle "Einträge" auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
3. Klicken Sie auf die leere Zeile und wählen Sie einen Fehlermodus aus der Liste verfügbarer Fehlermodi aus.
4. Wiederholen Sie die Schritte 2 bis 3 für jeden Fehlermodus, der zu dieser Gruppe hinzugefügt werden soll.
5. Klicken Sie auf Speichern. Die Anwendung zeigt eine Erfolgsmeldung an, die angibt, dass das Modellierungsobjekt aktualisiert wurde.

Vorgehensweise zum Hinzufügen von Gruppen zu einer Fehlermodusgruppe

Gehen Sie folgendermaßen vor, um einer Fehlermodusgruppe weitere Fehlermodusgruppen hinzuzufügen:

1. Führen Sie die Schritte unter "Vorgehensweise zum Definieren einer Fehlermodusgruppe" aus.

Oder

Wählen Sie eine bereits vorhandene Instanz einer Fehleraktionstypgruppe aus.

2. Klicken Sie in der Tabelle "Gruppen" auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
3. Klicken Sie auf die leere Zeile und wählen Sie eine Fehlermodusgruppe aus der Liste von verfügbaren Gruppen aus.
4. Wiederholen Sie die Schritte 2 bis 3 für jede Fehlermodusgruppe, die zu dieser Gruppe hinzugefügt werden soll.
5. Klicken Sie auf Speichern. Die Anwendung zeigt eine Erfolgsmeldung an, die angibt, dass das Modellierungsobjekt aktualisiert wurde.
