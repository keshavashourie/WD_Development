Definieren des Unternehmens

Das Unternehmen ist die höchste Stufe in der Modellierungshierarchie. Das Unternehmen kann entweder das Gesamtunternehmen oder aber einen Geschäftsbereich innerhalb des Gesamtunternehmens darstellen. Ein Unternehmen kann eine oder mehrere Fabriken enthalten.

Beim Definieren eines Unternehmens

Ein Portal-Benutzer kann ein Unternehmen als "Erprobungsbereich" festlegen, wenn er ein Ereignis erstellt. Beachten Sie Folgendes:

• Das Unternehmen enthält die optionale Modellierungsdefinition "Trainingsanforderungsgruppe".
• "Unternehmen" ist ein optionales Feld, das Sie bei der Definition einer Fabrik angeben können.
• Sie müssen Standorte definieren, damit das Feld "XML-Connect Proxystandort" ausgefüllt werden kann. Weitere Informationen finden Sie unter "Definieren von Standorten".

Felddefinitionen der Seite "Unternehmen"

In dieser Tabelle sind die Felder definiert, die nur auf der Seite "Unternehmen" zu finden sind.

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Feld

Definition

Typ

Allgemein

Trainingsanforderungsgruppe

Die Trainingsgruppe, die erforderlich ist, damit ein diesem Unternehmen zugeordneter Benutzer eine bestimmte Aufgabe durchführen darf.

Optional

XML-Connect Proxystandort

Damit eine Interoperabilität möglich ist, ist eine Datentransportdefinition (z. B. FTP, SMTP) erforderlich, die eine Verbindung zu einer Remoteanwendung (z. B. Manufacturing Interoperability, SAP xMII, SAP XI) ermöglicht. Daraufhin kann ein Standort in der Modellierung erstellt werden, der als Proxy für die Remoteanwendung fungiert und dann mit dem Unternehmen verbunden wird.

Optional

Fabriken

Der Standardwert sind alle bereits definierten Fabriken, die mit diesem Unternehmen verbunden sind.

Vorgehensweise zum Definieren eines Unternehmens

Gehen Sie folgendermaßen vor, um ein Unternehmen zu definieren:

1. Öffnen Sie die Seite Unternehmen. Die Seite "Unternehmen" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen in das Feld Unternehmen ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
