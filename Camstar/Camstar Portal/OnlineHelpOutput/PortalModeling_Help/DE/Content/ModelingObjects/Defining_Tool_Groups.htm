Definieren von Werkzeuggruppen

Eine Werkzeuggruppe dient zum Gruppieren einzelner Werkzeuge. Sie müssen Werkzeuge definieren, die Bestandteile der Werkzeuggruppe sein sollen, bevor Sie die Werkzeuggruppe definieren können.

Felddefinitionen der Seite "Werkzeuggruppe"

Diese Tabelle definiert Felder auf der Seite "Werkzeuggruppe".

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Feld

Definition

Typ

Allgemein

Eintragstyp

Gibt den Objekttyp an, der in dieser Gruppe enthalten ist, z. B. Werkzeug für Werkzeuggruppen.

Optional

Tabelle "Einträge"

Liste der Werkzeuge, die der Werkzeuggruppe hinzugefügt werden sollen.

Optional

Tabelle "Gruppen"

Liste der Werkzeuggruppen, die der Werkzeuggruppe als Untergruppen hinzugefügt werden sollen.

Optional

Vorgehensweise zum Definieren einer Werkzeuggruppe

Gehen Sie folgendermaßen vor, um eine Werkzeuggruppe zu definieren:

1. Öffnen Sie die Seite Werkzeuggruppe. Die Seite "Werkzeuggruppe" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Fügen Sie der Gruppe wie folgt Einträge hinzu:
a. Klicken Sie auf Neue Zeile hinzufügen.
b. Wählen Sie ein Werkzeug aus der Liste aus, die in der Tabelle angezeigt wird.
c. Wiederholen Sie die Schritte a und b, um der Tabelle einen weiteren Eintrag hinzuzufügen.
4. Fügen Sie der Gruppe wie folgt eine Untergruppe hinzu:
a. Klicken Sie auf Neue Zeile hinzufügen.
b. Wählen Sie eine Werkzeuggruppe aus der Liste aus, die in der Tabelle angezeigt wird.
c. Wiederholen Sie die Schritte a und b, um der Tabelle eine weitere Gruppe hinzuzufügen.
5. Klicken Sie auf Aufgelöste Einträge. Die Anwendung zeigt ein Popup an, in dem die Liste aller Werkzeuge angezeigt wird, die in der Werkzeuggruppe enthalten sind. Werkzeuge aus den Werkzeuggruppen werden einzeln aufgeführt.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
