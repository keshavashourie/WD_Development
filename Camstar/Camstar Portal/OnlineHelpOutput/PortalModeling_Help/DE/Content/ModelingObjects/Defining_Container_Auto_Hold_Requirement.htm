Definieren der Anforderung zum automatischen Anhalten von Containern

Die Anforderung zum automatischen Anhalten von Containern ermöglicht es Ihnen, einen oder mehrere Container in einem Arbeitsplanschritt aus einem bestimmten Grund (z. B. eine geplante Inspektion oder Prüfung) automatisch anzuhalten. Sie können keine Transaktionen für den Container ausführen, wenn der Container angehalten wurde. Der Container kann wieder für den normalen Betrieb freigegeben werden, sobald die Gründe für den Halt erfüllt oder beseitigt wurden.

Beim Definieren einer Anforderung zum automatischen Anhalten von Containern

Anforderungen zum automatischen Anhalten von Containern können für die folgenden Optionen konfiguriert werden:

• Produktionsauftrag: Alle Container, die demselben Produktionsauftrag zugewiesen sind, werden automatisch angehalten.
• Containerliste: Eine Liste der Containernamen, die angehalten werden sollen.
• Containeridentifikatorbereich: Anfangs- und Endtextwerte.
• Losliste: Eine Liste von an den Container ausgegebenen Loscodes, die möglicherweise auch einen Container darstellen.
• Ausdruck: Ermöglicht das Definieren einer zusätzlichen benutzerdefinierten Logik, die Sie möglicherweise implementieren möchten.

Ein Grund für das automatische Anhalten von Containern muss auch auf der Modellierungsseite der "Fabrik" definiert werden, da Sie Gründe für das Anhalten der Container angeben müssen, wenn der Container die Konfigurationsanforderungen für das Anhalten des Containers erfüllt. Informationen zum Definieren von Anhaltegründen finden Sie im Opcenter Execution Medical Device and Diagnostics Modeling-Benutzerhandbuch oder im Opcenter Execution Core Modeling-Benutzerhandbuch.

Vorgehensweise zum Definieren einer Anforderung zum automatischen Anhalten von Containern

Gehen Sie folgendermaßen vor, um eine Anforderung zum automatischen Anhalten von Containern zu definieren:

1. Öffnen Sie die Seite Container automatisches Anhalten Anforderung. Die Seite "Container automatisches Anhalten Anforderung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den eindeutigen Namen dieser Definition in das Feld Container automatisches Anhalten Anforderung ein.
4. Geben Sie die Revision dieses Objekts in das Feld Revision ein.
5. Geben Sie die Containerlisten- und Loslisteninformationen in die Tabelle Containerliste bzw. Losliste ein.
6. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
