Definieren von SPC-Charts

Das Modellierungsobjekt "SPC-Chart " enthält Informationen, die erforderlich sind, um ein einzelnes SPC-Chart anzuzeigen. Es beschreibt den Typ des Charts, des SPC-Abfrageobjekts, der Inline SPC-Regeln, der Außer-Kontrolle-Aktionen und -Prozeduren (OCAPs) und der Variablen, die für Inline SPC-Charts dargestellt werden.

Das Modellierungsobjekt "SPC-Chart" beschreibt auch den Typ des Charts, des Statit-Software-Makros, der Statit-Software-Regeldatei, der Außer-Kontrolle-Aktionen und -Prozeduren (OCAPs) und der Variablen, die für Legacy SPC-Charts dargestellt werden.

Siemens bietet vier Standard-SPC-Charts an, die Sie verwenden können:

• Moving Range
• Range Chart
• Trial I-Chart
• X Chart

Beim Definieren eines Inline SPC-Charts

Sie müssen Inline SPC auf Ihrem Server installieren und konfigurieren, damit Sie diese Seite verwenden können. Andernfalls können Sie nicht alle erforderlichen Felder ausfüllen oder die Seite speichern.

Für jeden Chart, der angezeigt werden soll, müssen Sie mit dem entsprechenden SPC-Charttyp und der SPC-Abfrage einen SPC-Chart erstellen.

Verwenden Sie den Abschnitt "Außer Kontrolle-Aktionen" des SPC-Charts, um die bei einer Regelverletzung ausgelösten Aktionen festzulegen.

SPC-Chart ist eine optionale Modellierungsdefinition in der SPC-Chartgruppe.

Ein SPC-Chart enthält die folgenden optionalen Modellierungsdefinitionen: "Dokument", "E-Mail-Nachricht", "Anhaltegrund" und "Ressourcenstatuscode".

Informationen zum Einrichten und Konfigurieren von Inline SPC finden Sie im Opcenter Execution Core Inline Statistical Process Control-Referenzhandbuch.

Verwenden von dynamischen Parametern

Fortgeschrittene Nutzer von Inline SPC können Chartparameter so konfigurieren, dass dynamische Etiketten verwendet werden, die aus den Feldausdrücken oder Abfragen ermittelt werden. Aktivieren Sie das Kontrollkästchen "Ist dynamisch" für einen Parameter und geben Sie den Namen und das Feld der Metadatentabelle oder den Abfragenamen und die Spalte ein, um den Wert für einen Parameter anzuzeigen. Der chartTitle-Parameter kann z. B. so bearbeitet werden, dass er den Produktnamen aus der Containertabelle anzeigt. Für diese Verwendung der dynamischen Parameterfunktionalität müssen Sie mit dem Objektmodell und der Geschäftslogik vertraut sein. Siemens empfiehlt, diese Funktion mit der Funktion "Datensammlung" von Inline SPC zu verwenden.

Diese Abbildung zeigt eine Beispieldefinition für einen dynamischen Parameter auf der SPC-Chart-Modellierungsseite. Als Parameterwert wird Container.product.name eingegeben und das Kontrollkästchen "Ist dynamisch" wird aktiviert, um anzugeben, dass das SPC-Chart den Produktnamen aus der Containertabelle als Charttitel verwendet.

In diesem Beispiel wird der Inline-Charttitel für "Gleitender Bereich" aus der Containertabelle und dem Feld "Produktname" bezogen. Die folgende Abbildung enthält ein Beispiel für ein Chart mit einem Titel für das Produkt "Abstandsscheibe 008".

Sie können zum Festlegen der dynamischen Parameterwerte auch Abfragen verwenden. Die verwendete Abfrage kann keine Eingabeparameter haben und darf nur Text enthalten. Für den dynamischen Parameter wird nur die erste Zeile der zurückgegebenen Daten angewendet. Es können Nutzerabfragen und SPC-Abfragen verwendet werden. Verwenden Sie das folgende Format für das Parameterfeld "Parameterwert": QueryName.ColumnName.

Dynamische Parameter können auch auf der SPC-Chartabfrageebene über das Feld "Dynamischer Wert" in der Tabelle "SPC-Chartabfrageparameter" festgelegt werden. Der dynamische Wert kann auch für eine SPC-Abfrage festgelegt werden, die für mehrere Charts verwendet wird. Weitere Informationen finden Sie unter Definieren von SPC-Abfragen.

Überschreiben der Browser-Spracheinstellungen für ein Chart

Inline SPC verwendet Ihre Browsereinstellungen, um die Sprache zu bestimmen, die für Inline SPC-Seiten und -Charts verwendet wird. Sie können den Parameter "Gebietsschema" zu den Parametern für SPC-Diagramm hinzufügen, um die Browser-Spracheinstellungen für ein SPC-Chart zu überschreiben.

Beim Definieren eines Legacy SPC-Charts

Für jedes Chart, das angezeigt werden soll, müssen Sie mit dem entsprechenden Makro zur Charterstellung ein SPC-Chart erstellen.

Gewährleisten Sie, dass die Pfade zu den Chartmakros und den Charteigenschaften korrekt sind. Wenn SPC z. B. in einem anderen Verzeichnis als dem Standardverzeichnis installiert wird, müssen Sie die Pfadangaben ändern.

Verwenden Sie den Abschnitt "Außer Kontrolle-Aktionen" des SPC-Charts, um die bei einer Regelverletzung ausgelösten Aktionen festzulegen.

SPC-Chart ist eine optionale Modellierungsdefinition in der SPC-Chartgruppe.

Ein SPC-Chart enthält die folgenden optionalen Modellierungsdefinitionen: "Dokument", "E-Mail-Nachricht", "Anhaltegrund" und "Ressourcenstatuscode".

Informationen zum Einrichten und Konfigurieren von SPC finden Sie im Opcenter Execution Core Statistical Process Control-Referenzhandbuch.

Das SPC-Chart-Anzeigepopup kann erst geschlossen werden, wenn der Datenpunkt mit einer Anmerkung versehen wurde. Wenn der Benutzer versucht, das Popup zu schließen, wird der Benutzer in einer Meldung informiert, dass eine Anmerkung erforderlich ist.

Vorgehensweise zum Definieren eines neues SPC-Charts

Gehen Sie folgendermaßen vor, um ein neues SPC-Chart zu definieren:

1. Öffnen Sie die Seite SPC-Chart. Die Seite "SPC-Chart" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie SPC-Chart, Charttyp, Auszuwertende Variable, Chartgenerierungsmakro und Anzeigeoptionen für SPC-Chart ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Definieren eines neuen Inline SPC-Charts

Gehen Sie folgendermaßen vor, um ein neues SPC-Chart zu definieren:

Vorgehensweise zum Konvertieren eines vorhandenes Legacy-Makros in ein Inline SPC-Abfrageobjekt

Gehen Sie folgendermaßen vor, um ein Legacy-Makro in ein Inline SPC-Abfrageobjekt zu konvertieren:

1. Melden Sie sich bei Opcenter Execution Medical Device and Diagnostics an.

Oder

Melden Sie sich bei Opcenter Execution Core an.

2. Wählen Sie Modellierung im Menü Modellierung aus. Die Seite "Modellierung" wird angezeigt.
3. Klicken Sie auf SPC-Chart. Die Seite "SPC-Chart" wird innerhalb der Seite "Modellierung" angezeigt.
4. Wählen Sie ein vorhandenes Legacy-Chart aus.
5. Aktivieren Sie das Kontrollkästchen Inline SPC. Eine Warnmeldung wird angezeigt, die die Makrokonvertierung bestätigt.
6. Klicken Sie auf Ja. Das Popup "Konvertierung von SPC-Makro" wird angezeigt. Die Popup-Felder werden automatisch mit Informationen aus der ausgewählten Legacy-Abfrage gefüllt.
7. Geben Sie den neuen Namen für die SPC-Abfrage ein.
8. Bearbeiten Sie die Abfrageinformationen entsprechend Ihren Geschäftsanforderungen. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
9. Klicken Sie auf Einreichen. Die Anwendung speichert das SPC-Abfrageobjekt und zeigt eine Erfolgsmeldung an. Sie können die gespeicherte Abfrage auf der Seite "SPC-Abfrage" überprüfen.
Hinweis: Eine Warnmeldung wird angezeigt, wenn das ausgewählte Legacy-Makro mehr als eine Abfrage und/oder unvollständige Parameter enthält. Sie müssen die Abfrageinformationen manuell bearbeiten, bevor Sie sie mit Inline SPC verwenden. Sie können das konvertierte Makro und die konvertierten Parameter im Popup "Konvertierung von SPC-Makro" bearbeiten und auf Abschicken klicken und oder auf Abschicken klicken und das konvertierte Makro und die konvertierten Parameter auf der Seite "SPC-Abfrage" bearbeiten.
