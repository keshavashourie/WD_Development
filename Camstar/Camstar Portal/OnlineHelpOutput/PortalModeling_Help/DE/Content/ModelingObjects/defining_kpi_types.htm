Definieren von KPI-Typen

Auf der Seite "KPI-Typ" können Sie eine Kategorie des KPI-Matrix-Eintrags hinzufügen, der in einer Dropdown-Liste im "Hinzufügen"-Popup von "KPI-Matrix" verfügbar wird. Beispiele für KPI-Typen sind:

• OEE
• DPMO
• Liniennutzung
• In Arbeit (WIP)
• 1. Bestanden-Ertrag in %
Hinweis: KPI-Analysen werden von Opcenter EX EL Intelligence verwendet.

Vorgehensweise zum Definieren eines KPI-Typs

Führen Sie die folgenden Schritt aus, um einen KPI-Typ zu definieren:

1. Öffnen Sie die Seite KPI-Typ. Die Seite "KPI-Typ" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie im Feld KPI-Typ einen Namen für den KPI-Typ ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Unter "Gemeinsame Felder auf Modellierungsseiten" finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
