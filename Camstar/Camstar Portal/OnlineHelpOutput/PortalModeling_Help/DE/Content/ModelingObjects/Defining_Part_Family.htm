Definieren einer Teilefamilie

Eine Teilefamilie ermöglicht das Kategorisieren von Teilegruppen nach ähnlichen Anforderungen oder Merkmalen.

Felddefinitionen der Seite "Teilefamilie"

Diese Tabelle definiert die Felder, die nur auf der Seite "Teilefamilie" vorhanden sind.

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Feld

Definition

Typ

Teilefamilie

Eindeutiger Name des Modellierungsobjekts "Teilefamilie".

Erforderlich

Allgemein

UI-Einstellungen

UI-Einstellungen, die dieser Teilefamilie zugeordnet werden sollen. UI-Einstellungen legen die Informationen fest, die für eine Ressource auf der Registerkarte "Status" auf der Seite "Ressourcenprotokoll" angezeigt werden sollen. UI-Einstellungen werden in der Modellierung definiert.

Optional

Jobbenachrichtigung: E-Mail-Gruppe

Gruppe von Mitarbeitern, die eine E-Mail erhalten sollen, wenn ein Wartungs- oder Reparaturjob für diese Teilefamilie erstellt wird.

Optional

Vorgehensweise zum Definieren einer Teilefamilie

Gehen Sie folgendermaßen vor, um eine Teilefamilie zu definieren:

1. Öffnen Sie die Modellierungsseite Teilefamilie. Die Seite "Teilefamilie" wird innerhalb der Modellierungsseite angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das Feld Teilefamilie ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
