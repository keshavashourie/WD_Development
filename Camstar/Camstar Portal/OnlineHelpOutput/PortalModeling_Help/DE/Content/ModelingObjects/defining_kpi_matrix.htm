Definieren einer KPI-Matrix

Auf der Seite "KPI-Matrix" können Sie einzelne Gruppen von Informationen hinzufügen, die als KPI-Einträge bezeichnet werden und bei der Analyse von Leistungskennzahlen (KPI) verwendet werden können.

Jeder KPI-Eintrag ermöglicht es Ihnen, eine Gruppe von KPI-Analysekriterien anzugeben, einschließlich eines Zielwerts wie z. B. ideale Zykluszeit und eines unteren und oberen Limits eines akzeptablen Bereichs. Mit jedem KPI-Eintrag können Sie auch Nachschlagewerte konfigurieren, um die richtige Gruppe von Analysekriterien zu finden. Ein Eintrag kann z. B. einen Zielwert enthalten, der angewendet werden soll, wenn eine KPI-Analyse für Produkt A an einer bestimmten Operation durchgeführt wird. Ein anderer kann einen anderen Zielwert enthalten, der für Produkt B bei derselben Operation angewendet werden soll.

Hinweis: KPI-Analysen werden von Opcenter EX EL Intelligence verwendet.

Vorgehensweise zum Definieren einer KPI-Matrix

Führen Sie die folgenden Schritte aus, um eine KPI-Matrix zu definieren:

1. Öffnen Sie die Seite "KPI-Matrix".Die Seite "KPI-Matrix" wird innerhalb der Seite "Modellierung" angezeigt.
2. Geben Sie in das Feld KPI-Matrix einen Namen für die KPI-Matrix ein.
3. Klicken Sie in der Tabelle KPI-Eintrag auf Neue Zeile hinzufügen. Die Anwendung zeigt das Popup "Hinzufügen" an, in dem Sie die Eingabewerte eingeben können.
4. Geben Sie im Popup Hinzufügen nach Bedarf Werte ein oder wählen Sie sie aus.
5. Wenn Sie fertig sind, klicken Sie auf OK, um das Popup zu schließen.
6. Wiederholen Sie die Schritte 3–5 für jeden zusätzlichen KPI-Eintrag, den Sie hinzufügen möchten.
7. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Unter "Gemeinsame Felder auf Modellierungsseiten" finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
