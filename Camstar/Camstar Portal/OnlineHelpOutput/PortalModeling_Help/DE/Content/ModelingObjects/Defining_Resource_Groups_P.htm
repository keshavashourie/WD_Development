Definieren von Ressourcengruppen

Eine Ressourcengruppe ist eine Unterklasse einer Named Object Group, die eine Gruppe von Ressourcen darstellt. Eine Objektgruppe wird verwendet, um eine Liste von Objekten wie z. B. eine Liste von Ressourcen, Produkten oder Nutzercodes eines bestimmten Typs zur Verfügung zu stellen. Diese Listen werden in der Regel zur Überprüfung und Auswahl verwendet. Eine Operation enthält z. B. eine Referenz auf eine LossCodeGroup. Die Einträge dieser Liste definieren die zulässigen Verlust- bzw. Verlustgrundcodes für die Arbeiten, die durchgeführt werden, während sich der Container an dieser Operation befindet.

Eine Instanz einer Objektgruppe enthält eine Liste von bestimmten Objekten und eine Liste von Objektgruppen. Diese Liste von Objekten für eine bestimmte Objektgruppe ist auf einen bestimmten Typ (oder von diesem Typ abgeleitete Typen) beschränkt. Ebenso ist die Liste von Objektgruppen innerhalb der Objektgruppe auf einen bestimmten Typ (oder von diesem Typ abgeleitete Typen) beschränkt.

Dies sind Beispiele für Unterklassen von Named Object Groups:

• Ressourcengruppe
• Versandzielgruppe
• Nutzercodegruppe

Die Behältergruppe ist eine Unterklasse der Ressourcengruppe.

Weitere Informationen zu diesem Modellierungsobjekt finden Sie unter "Definieren von Behältergruppen".

Beim Definieren einer Ressourcengruppe

"Ressourcengruppe" ist ein optionales Feld in der Definition von "Einrichtung", "Spez." und "Arbeitsbereich".

Sie können den betreffenden Tabellen mehrere Einträge oder Gruppen hinzufügen.

Die Schaltfläche "Aufgelöste Einträge" ermöglicht es Ihnen, eine Liste aller Werte anzuzeigen, die in der Eintragsliste für diese Gruppe und alle darin enthaltenen Gruppen angegeben sind.

Hinweis: Die nachstehend beschriebene Funktionalität ist nur verfügbar, wenn Opcenter Execution Core Scheduling installiert ist. Weitere Informationen finden Sie unter "Opcenter Execution Core Scheduling".

So wird eine Ressourcengruppe definiert

Gehen Sie folgendermaßen vor, um eine Ressourcengruppe zu definieren:

1. Öffnen Sie die Seite Ressourcengruppe. Die Seite "Ressourcengruppe" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen in das Feld Ressourcengruppe ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
5. Fügen Sie der Gruppe wie folgt Einträge hinzu:
a. Klicken Sie unten in der Tabelle "Einträge" auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
b. Klicken Sie in die neue Zeile, um eine Liste von Einträgen anzuzeigen, und wählen Sie einen Eintrag aus, den Sie der Gruppe hinzufügen möchten. Der ausgewählte Eintrag wird der Tabelle hinzugefügt.
c. Wiederholen Sie die Schritte a und b, um der Tabelle einen weiteren Eintrag hinzuzufügen.
6. Fügen Sie der Gruppe wie folgt eine Untergruppe hinzu:
a. Klicken Sie unten in der Tabelle "Gruppen" auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
b. Klicken Sie in die neue Zeile, um eine Liste zuvor definierter Gruppen anzuzeigen. Wählen Sie dann eine Gruppe aus, die Sie der Gruppe (als Untergruppe) hinzufügen möchten. Die ausgewählte Gruppe wird der Tabelle hinzugefügt.
c. Wiederholen Sie die Schritte a und b, um der Tabelle eine weitere Gruppe hinzuzufügen.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
