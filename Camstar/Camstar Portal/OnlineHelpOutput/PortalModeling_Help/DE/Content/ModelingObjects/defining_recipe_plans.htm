Definieren von Rezeptplänen

Die Seite "Rezeptplan" ermöglicht Ihnen die Definition einer Liste mit einem oder mehreren Rezepten, die jeweils mit einer Ressource und/oder einer Spezifikation verknüpft werden können. Vor dem Ausführen einer Anmeldetransaktion sucht die Anwendung nach einem zugewiesenen Rezeptplan. Wird ein Rezeptplan gefunden, ermittelt die Anwendung unter allen Rezepten im Plan diejenigen mit Kriterien, die dem aktuellen Produktionskontext entsprechen. Werden Entsprechungen gefunden, wählt die Anwendung die beste aus. Die Anwendung vergleicht den Namen eines gefundenen Rezepts mit dem Namen des für die Ressourceneinrichtung ausgewählten Rezepts, um zu gewährleisten, dass das richtige Rezept verwendet wird.

Beim Definieren eines Rezeptplans

Die Rezepte, die dem Plan hinzugefügt werden sollen, müssen in der Datenbank vorhanden sein. Rezepte können Sie mithilfe der Modellierungsseite "Rezept" hinzufügen. Sie können nicht mehr als einen Eintrag mit den gleichen Ressourcen- und Spezifikationswerten erstellen.

Vorgehensweise zum Definieren eines Rezeptplans

Gehen Sie folgendermaßen vor, um einen Rezeptplan zu definieren:

1. Öffnen Sie die Seite Rezeptplan.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für den Rezeptplan in das Feld Rezeptplan ein.
4. Klicken Sie in der Tabelle Details auf Neue Zeile hinzufügen. Das Popup "Hinzufügen" wird angezeigt.
5. Führen Sie im Popup die folgenden Schritte aus:
a. Wählen Sie ein Rezept aus.
b. Wählen Sie eine Ressource aus, wenn das Rezept nur für diese Ressource verwendet werden soll.
c. Wählen Sie ggf. eine Spez. aus, wenn das Rezept nur für diese Spezifikation verwendet werden soll.
d. Möchten Sie einen oder mehrere Parameter für dieses Rezept hinzufügen?

6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Statusnachricht an.
