Definieren von Ressourcenmaterialteilen

Auf der Seite "Ressourcenmaterialteil" können Sie die Wartungseigenschaften von Ressourcenmaterialteilen konfigurieren, die häufig zum Erstellen von Teilen verwendet werden. Ein Ressourcenmaterialteil ist ein erforderliches Feld, wenn ein neues Teil mit der Transaktion "Teileerstellung" erstellt wird. Es können mehrere Teile mit demselben Ressourcenmaterialteil erstellt werden.

Die Menge jedes erstellten Teils, das dasselbe Ressourcenmaterialteil verwendet, wird zur Gesamtmenge des Ressourcenmaterialteils hinzugefügt. Jedes Teil wird durch die Wartungseigenschaften seines Ressourcenmaterials gesteuert.

Hinweis: Diese Seite bezieht sich auf das Ressourcenmaterialteil – nicht auf Materialteile, die für Produkte verwendet werden.

Felddefinitionen der Seite "Ressourcenmaterialteil"

Diese Tabelle definiert die Felder, die nur auf der Seite "Ressourcenmaterialteil" zu finden sind.

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Feld

Definition

Typ

Ressourcenmaterialteil

Eindeutiger Name für das Modellierungsobjekt "Ressourcenmaterialteil".

Erforderlich

Allgemein

Änderungsauftrag

Änderungsauftrag, der dieser Revision zugewiesen wurde. Sie können maximal 30 Zeichen eingeben.

Optional

Teiletyp

Gibt an, wie Materialteile in den Lagerbestand aufgenommen und verfolgt werden sollen. Hierfür gibt es drei Typen:

• Serialisiert: Erfordert, dass für jede Sendung ein neues Los erstellt wird.
• Großmenge: Erfordert ein neues Los, wenn das Materialteil erstmalig versandt wird. Nachfolgende Sendungen aus demselben Hauptlos können in den Lagerbestand aufgenommen werden, indem die Menge des Loses erhöht wird, das anfänglich erstellt wurde.
• Nicht serialisiert: Es wird kein Los erstellt. Grundsätzlich genügt es, für Nachverfolgbarkeitszwecke die Batch-ID zu speichern.

Erforderlich

Details

Mindestmenge

Minimale Menge, die für das Ressourcenmaterialteil erforderlich ist, das in das Lager aufgenommen werden soll.

Optional

Mindestmenge vor Nachbestellung

Minimale Menge zur Nachbestellung von Ressourcenmaterialteilen und zum Auslösen einer Nachbestellungsbenachrichtigung.

Optional

Mindestmenge vor Nachbestellung: E-Mail-Gruppe

E-Mail-Gruppe mit Empfängern, die benachrichtigt werden müssen, wenn ein Ressourcenmaterialteil seine Mindestmenge erreicht hat.

Optional

Max. Menge

Maximale Menge, die für ein Teil im Lagerbestand zulässig ist.

Optional

Nutzungslimit

Maximale Menge des Ressourcenmaterialteils, das verarbeitet werden soll, bevor das Teil zur Wartung oder Aufarbeitung fällig wird. Die Nutzungsanzahl eines Materialteils wird mit diesem Limit verglichen.

Hinweis: Bei Opcenter Execution Semiconductor bezieht sich "Teil" in dieser Definition auf "Die".

Optional

Nutzungslimit 2

Maximale Menge 2 des Ressourcenmaterialteils, das verarbeitet werden soll, bevor das Teil zur Wartung oder Aufarbeitung fällig wird. Die Nutzungsanzahl eines Materialteils wird mit diesem Limit verglichen.

Hinweis: Bei Opcenter Execution Semiconductor bezieht sich "Teil" in dieser Definition auf "Wafer".

Optional

Standzeitlimit

Maximale Menge, die ein Teil, das mit diesem Ressourcenmaterialteil erstellt wurde, verarbeiten darf, bevor es ausgemustert werden muss. "Standzeitanzahl" wird hiermit verglichen.

Hinweis: Bei Opcenter Execution Semiconductor bezieht sich "Teil" in dieser Definition auf "Die".

Optional

Standzeitlimit 2

Maximale Menge 2, die ein Teil, das mit diesem Ressourcenmaterialteil erstellt wurde, verarbeiten darf, bevor es ausgemustert werden muss. "Standzeitanzahl 2" wird hiermit verglichen.

Hinweis: Bei Opcenter Execution Semiconductor bezieht sich "Teil" in dieser Definition auf "Wafer".

Optional

Limits-E-Mail-Gruppe

E-Mail-Gruppe mit Empfängern, die benachrichtigt werden müssen, wenn das Ressourcenmaterialteil sein Limit erreicht hat.

Optional

Warnlimit für Nutzung

Anzahl der Teile, die von diesem Ressourcenmaterialteil verarbeitet werden sollen, um eine Warnbenachrichtigung beim Annähern an Nutzungslimits auszulösen.

Hinweis: Bei Opcenter Execution Semiconductor bezieht sich "Teil" in dieser Definition auf "Die".

Optional

Warnlimit für Nutzung 2

Anzahl der Teile, die von diesem Ressourcenmaterialteil verarbeitet werden sollen, um eine Warnbenachrichtigung beim Annähern an Nutzungslimits auszulösen.

Hinweis: Bei Opcenter Execution Semiconductor bezieht sich "Teil" in dieser Definition auf "Wafer".

Optional

Dauer für Ablaufwarnung (Tage)

Warnungszeitraum (in Tagen) vor dem Ablaufdatum des Teils. Ein Wert <= 0 bedeutet, dass es keine Warnungsdauer gibt.

Optional

Warnlimit für Standzeit

Anzahl der Teile, die vom Materialteil verarbeitet wurden, bevor eine E-Mail-Benachrichtigung zum Warnlimit für die Standzeit ausgelöst wird.

Hinweis: Bei Opcenter Execution Semiconductor bezieht sich "Teil" in dieser Definition auf "Die".

Optional

Warnlimit für Standzeit 2

Anzahl der Teile, die vom Materialteil verarbeitet wurden, bevor eine E-Mail-Benachrichtigung zum Warnlimit für die Standzeit ausgelöst wird.

Hinweis: Bei Opcenter Execution Semiconductor bezieht sich "Teil" in dieser Definition auf "Wafer".

Optional

Aufarbeitungslimit

Maximale Anzahl, wie oft das Materialteil aufgearbeitet werden darf, bevor es ausgemustert werden muss.

Optional

Vorgehensweise zum Definieren eines Ressourcenmaterialteils

Gehen Sie folgendermaßen vor, um ein Ressourcenmaterialteil zu definieren:

1. Öffnen Sie die Modellierungsseite Ressourcenmaterialteil. Die Seite "Ressourcenmaterialteil" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das Feld Ressourcenmaterialteil ein.
4. Geben Sie eine Teilemenge ein.
5. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein.Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
