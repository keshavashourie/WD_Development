Definieren von Werkzeugfamilien

Eine Werkzeugfamilie bietet eine Möglichkeit, Werkzeuge nach deren Attributen und entsprechend Ihren Geschäftsanforderungen zu kategorisieren. Jedes Werkzeug kann eine einzelne Werkzeugfamilie haben.

Felddefinitionen der Seite "Werkzeugfamilien"

Diese Tabelle definiert die Felder auf der Seite "Werkzeugfamilie".

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Feld

Definition

Typ

Allgemein

UI-Einstellungen

Feld zum Auswählen einer Benutzeroberflächeneinstellung.

Optional

Jobbenachrichtigung: E-Mail-Gruppe

Gibt die E-Mail-Gruppe an, die benachrichtigt werden soll, wenn Ereignisse vorliegen, die sich auf den Auftrag oder die Werkzeugverwaltung beziehen.

Optional

Ressourcenstatusmodell

Definiert einen Satz gültiger Ressourcenstatusübergänge und zugehöriger Verfügbarkeitsstatus. Ein Ressourcenstatusmodell kann so konfiguriert werden, dass die Anwendung automatisch Wartungsaufträge für Ressourcen erstellt, und zwar basierend auf bestimmten Ursachencodes und konfigurierbaren Bedingungen, die für eine Statusänderung eingegebenen wurden. Ressourcenstatusmodelle werden Ressourcen zugewiesen.

Optional

Vorgehensweise zum Definieren einer Werkzeugfamilie

Gehen Sie folgendermaßen vor, um eine Werkzeugfamilie zu definieren:

1. Öffnen Sie die Seite Werkzeugfamilie. Die Seite "Werkzeugfamilie" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen eindeutigen Namen der Werkzeugfamilie in das Feld Werkzeugfamilie ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
