Definieren von Wartungsklassen

Sie können eine Wartungsklasse für Ressourcen erstellen, die dieselben Wartungsanforderungen haben. Danach können Sie die Wartungsklasse in der Ressourcendefinition referenzieren. Wartungsklassen werden zur Aktivierung von Ressourcen benutzt. Eine Wartungsanforderung kann einer einzelnen Ressource oder allen Ressourcen in der jeweiligen Wartungsklasse zugewiesen werden.

Beim Definieren von Wartungsklassen

"Wartungsklasse" ist ein optionales Feld in den folgenden Modellierungsdefinitionen: "Ressource" und "Behälter".

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Vorgehensweise zum Definieren einer Wartungsklasse

Gehen Sie folgendermaßen vor, um eine Wartungsklasse zu definieren:

1. Öffnen Sie die Seite Wartungsklasse. Die Seite "Wartungsklasse" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für diese Wartungsklasse in das Feld Wartungsklasse ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Unter "Gemeinsame Felder auf Modellierungsseiten" finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
