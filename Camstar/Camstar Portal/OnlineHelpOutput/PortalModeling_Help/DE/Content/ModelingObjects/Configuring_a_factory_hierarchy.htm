Konfigurieren einer Fabrikhierarchie

Eine Fabrikhierarchie stellt eine physische Fertigungsumgebung als Pyramide zugehöriger Modellierungsobjektinstanzen dar. Es ist kein Modellobjekt "Fabrikhierarchie" vorhanden. Die Hierarchie wird durch Konfigurieren von Über-/Unterordnungsbeziehungen zwischen Instanzen der folgenden Objekte definiert:

• Unternehmen
• Fabrik
• Lagerort (verfügbar, wenn Industrielösungen installiert ist)
• Ressource
Wichtig: Das Modellierungsobjekt "Ressource" enthält ein Feld "Fabriklevel". In diesem Feld können Sie eine Ressource als Fabrikbereich oder Unterbereich und nicht als Ausrüstung konfigurieren.

Beispiel für eine Fabrikhierarchie

Ein fiktives Unternehmen namens ABC Automotive hat eine Fabrik namens Factory East. Diese Fabrik verfügt über einen Armaturenbrett-Produktionsbereich mit zwei Fertigungslinien, von denen jede Ausrüstungsressourcen und einen dedizierten Lagerort hat.

Schritte zum Modellieren des Beispiels

Dies sind die Schritte zum Konfigurieren der oben dargestellten Beispielhierarchie:

1. Definieren Sie ein Unternehmen mit dem Namen ABC Automotive.
2. Definieren Sie eine Fabrik und legen Sie das Unternehmen auf ABC Automotive fest.
3. Definieren Sie eine Ressource mit dem Namen Armaturenbrett mit einem Bereich auf Fabriklevel. Legen Sie die Fabrik auf Factory East fest.
4. Definieren Sie eine Ressource mit dem Namen "SMT Assembly" mit einer Zelle auf Fabriklevel. Legen Sie die Eltern-Ressource auf Armaturenbrett fest.
5. Definieren Sie eine Ressource mit dem Namen "Box Assembly" mit einer Zelle auf Fabriklevel. Legen Sie die Eltern-Ressource auf Armaturenbrett fest.
6. Definieren Sie SMT-Ausrüstungsressourcen mit einem Fabriklevel von Ausrüstung. Legen Sie die Eltern-Ressource auf "SMT Assembly" fest.
7. Definieren Sie Box-Ausrüstungsressourcen mit einem Fabriklevel von Ausrüstung. Legen Sie die Eltern-Ressource auf "Box Assembly" fest.
8. Definieren Sie einen Lagerort mit dem Namen "SMT Inventory". Legen Sie die Eltern-Ressource auf "SMT Assembly" fest.
Hinweis: Bei diesem Schritt wird davon ausgegangen, dass Industrielösungen installiert ist.
9. Definieren Sie einen Lagerort mit dem Namen "Box Inventory". Legen Sie die Eltern-Ressource auf "Box Assembly" fest.
Hinweis: Bei diesem Schritt wird davon ausgegangen, dass Industrielösungen installiert ist.

Die Ergebnisse dieser Konfiguration werden sichtbar, wenn Sie das Unternehmen in der Fabrikhierarchie-Baumstruktur auf der Seite "Fabrikhierarchie" auswählen.

Verwenden der Seite "Fabrikhierarchie"

Das Seitenlayout "Fabrikhierarchie" enthält ein Fenster auf der linken Seite, in dem die Fabrikhierarchie als Baumstruktur angezeigt wird. Die Auswahl in der Baumstruktur bestimmt die Modellierungsseite, die auf der rechten Seite des Fensters angezeigt wird.

Baumstruktur erweitern und reduzieren

Zunächst ist die Baumstruktur auf dem obersten Level (Unternehmen) reduziert. Wenn Sie auf einen nach rechts zeigenden Pfeil vor einem Element klicken, wird die Baumstruktur erweitert, um die unmittelbaren unteren Elemente des Elements zu zeigen. Klicken Sie auf einen nach unten zeigenden Pfeil vor einem Element, um das Element zu reduzieren. Das Symbol mit den gegenüberliegenden diagonalen Pfeilen ermöglicht es Ihnen, alle l-Levels der Baumstruktur zu erweitern oder die Baumstruktur auf Unternehmenslevel zu reduzieren.

Importieren einer älteren Valor-MDM-XML-Datei

Mit der Schaltfläche "Importieren" können Sie eine XML-Datei importieren, die Informationen wie Fabriklinien, Maschinen und Ausrüstung auf der Fabrikebene "Bereich" enthält, der zum Erstellen einer Fabrikhierarchie-Modellierungsinstanz sowie zum Konfigurieren der SRC-Einstellungen verwendet werden kann. Die Schaltfläche ist standardmäßig ausgeblendet und wird nur angezeigt, wenn Sie einen Bereich in der Baumstruktur auswählen. Wenn Sie nach Auswahl eines Bereichs auf andere Modellobjekte klicken, wird die Schaltfläche "Importieren" ausgeblendet.

Wenn Sie auf die Schaltfläche "Importieren" klicken, werden Sie aufgefordert, die zu importierende Datei auszuwählen. Nachdem die Datei ausgewählt wurde, wird das Popup "Importdetails" mit einer Vorschau der Elemente angezeigt, die in der Importdatei enthalten sind. Die Elemente bestehen aus Linien und Ausrüstung und werden als Ressourceninstanzen in Opcenter Execution importiert.

Sie können die Elemente auswählen, die Sie importieren möchten, indem Sie das Kontrollkästchen daneben markieren. Wenn bereits eine Ressourceninstanz mit demselben Namen in der aktuellen Fabrikhierarchie vorhanden ist, wird das Kontrollkästchen abgeblendet, und neben dem Element wird eine Meldung mit dem Hinweis "Objekt bereits vorhanden" angezeigt.

Wenn die ältere Valor-MDM-Datei erfolgreich importiert wurde, wird eine Meldung angezeigt, die angibt, dass der Dienst abgeschlossen ist, und die Anzahl der erfolgreichen Importe wird angezeigt. Wenn Sie versuchen, dieselbe ältere Valor-MDM-Datei mit Informationen zu importieren, die bereits in der aktuellen Fabrikhierarchie vorhanden sind, wird der Importprozess übersprungen. Die gleiche abgeschlossene Meldung wird angezeigt, aber stattdessen mit der übersprungenen Importanzahl.

Wenn Industrielösungen installiert sind, können Sie eine ältere Valor-MDM-Datei, die Informationen wie Lagerort, Ressourcen und Fertigungsressourcenkonfiguration (SRC) enthält, in die Fabrikebene eines Bereichs importieren, um die entsprechenden Modellierungsinstanzen für den Lagerort und SRC-Einstellungen zu erstellen. Der Importprozess ist mit der Vorgehensweise in Opcenter Execution Core identisch, jedoch mit zusätzlichen Lagerortobjekten und SRC-Einstellungen, die für den Import verfügbar sind und im Popup "Importdetails" angezeigt werden.

Wenn eine vorhandene SRC-Einstellung für eine Ressource eine Ressource oder ein Lagerort ist, überspringt die Anwendung dieses Objekt und es wird als erfolgreich betrachtet, solange die importierten SRC-Einstellungen mit den vorhandenen Einstellungen identisch sind. Es wird ein Fehler angezeigt, wenn die Ressourcen über vorhandene SRC-Einstellungen verfügen, aber mit unterschiedlicher Maschinen-ID oder wenn die Einstellungen bereits von anderen Ressourcen in SRC verwendet werden.

Hinweis: Sie müssen das Feld "SRC-API" auf der Modellierungsseite "Fertigungsintegrationseinstellungen" konfigurieren, um die Erstellung der SRC-Einstellungen in der Fabrik nach dem Importieren der älteren Valor-MDM-Datei zu ermöglichen. Weitere Informationen finden Sie unter Definieren von Einstellungen für die Fertigungsintegration.

Importieren einer JSON-Exportdatei aus SRC

Zusätzlich zum Importieren von XML-Dateien aus der älteren Valor-MDM-Anwendung ist es auch möglich, JSON-Dateien aus SRC zu importieren. Während die älteren Valor-MDM-Dateien auf den Import eines Bereichs und der darunter befindlichen Ressourcen beschränkt sind, können die SRC-Importe eine oder die gesamte Fabrikstruktur enthalten: Unternehmen, Fabrik, Bereich, Zellen und Ausrüstung.

Durchsuchen der Baumstruktur

Sie können die Baumstruktur durchsuchen, indem Sie Text in das Suchfeld eingeben und die Eingabetaste drücken oder auf das Suchsymbol klicken.

Bearbeiten von Baumstrukturelementen

Wenn Sie auf den Namen eines Elements in der Baumstruktur klicken, wird das Element im Bereich der Modellierungsseite rechts neben der Baumstruktur geöffnet. Änderungen, die im Modellierungsbereich vorgenommen werden, spiegeln sich sofort in der Baumstruktur wider. Wenn Sie beispielsweise einem Element ein untergeordnetes Element hinzufügen, wird es im Menü unter seinem übergeordneten Element angezeigt.

Hinzufügen eines neuen Elements

Das Symbol für das Hinzufügen eines neuen Elements wird ganz links in der Suchleiste angezeigt. Sie haben die Möglichkeit, zwei Dinge zu tun:

• Fügen Sie eine Modellierungsinstanz mit gleichen Fabriklevel und dem gleichen übergeordneten Element wie ein vorhandenes Element in der Baumstruktur hinzu.
• Fügen Sie ein untergeordnetes Elements zu einem vorhandenen Element in der Baumstruktur hinzu.

Ein Kontextmenü der Fabrikhierarchielevels wird angezeigt, nachdem ein Element ausgewählt und auf das Symbol für das Kopierlevel geklickt wurde. Levels, die im Kontextmenü aufgelistet werden, umfassen das Level des ausgewählten Elements selbst sowie das untergeordnete Level, sofern vorhanden. Wenn ein Level im Kontextmenü ausgewählt wird, lädt die Anwendung eine leere Instanz in den Modellierungsbereich mit dem entsprechenden Fabriklevel und dem übergeordneten Element.

Hinzufügen eines vorhandenen Elements

Das Symbol für das Hinzufügen eines vorhandenen Elements ermöglicht eine erhöhte Funktionalität:

Die Fabrikhierarchie-Baumstruktur wurde erweitert, sodass vorhandene Fabriken ohne übergeordnetes Unternehmen hinzugefügt werden können. Darüber hinaus können Ressourcen, die nicht Teil des Fabrikhierarchiemodells sind, der Fabrikhierarchie als "Bereich", "Zelle" oder "Ausrüstung" hinzugefügt werden. Wenn Sie eine Ressource auswählen, werden automatisch die Fabrik-/Eltern-Ressource und das Fabriklevel festgelegt. Wenn Sie Industry Solutions installiert haben, können Sie der Baumstruktur auch vorhandene Lagerorte hinzufügen. Weitere Informationen zum Definieren und Zuweisen von Lagerorten finden Sie im Opcenter Execution Core Industry Solutions-Benutzerhandbuch.
