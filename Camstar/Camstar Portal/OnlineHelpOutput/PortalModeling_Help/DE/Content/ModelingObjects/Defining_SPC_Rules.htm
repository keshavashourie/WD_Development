Definieren von SPC-Regeln

Das Modellierungsobjekt "SPC-Regeln" enthält Informationen, die bestimmen, wann Chartdaten akzeptabel sind bzw. wann sie Qualitätsstandards verletzen. SPC-Regeln können im Objekt "SPC-Charts" ausgewählt werden.

Beim Definieren von SPC-Expertenregeln

Kopieren Sie eine der bereits geladenen SPC-Regeln, die als Ausgangsbasis für die Erstellung von Expertenregeln verwendet werden soll. Sie können für die kopierte Regel Verletzungsparameter hinzufügen und bearbeiten. Sie können auch eine neue SPC-Expertenregel erstellen.

Weitere Informationen zu den Common Component-Charts und -Regeln, die für Inline SPC verwendet werden, finden Sie im Abschnitt "Industrieregeln" der "SPC/IGC Common Component-Endbenutzerdokumentation" .

Hinweis: Die bereits geladenen SPC-Regeln und -Verletzungen sind gesperrt und können nicht bearbeitet werden. Verletzungsparameter können nur für kopierte Regeln geändert werden.

Vorgehensweise zum Definieren einer SPC-Expertenregel

Gehen Sie folgendermaßen vor, um eine SPC-Expertenregel zu definieren:

1. Öffnen Sie die Seite SPC-Regeln. Die Seite "SPC-Regeln" wird innerhalb der Seite "Modellierung" angezeigt.
2. Wählen Sie das bereits geladene SPC-Regelobjekt aus, das Ihren Anforderungen am besten entspricht. Die SPC-Regelinstanz wird angezeigt.
3. Klicken Sie auf Kopieren. Das Popup "Kopieren" wird angezeigt.
4. Geben Sie einen Namen für die Expertenregel in das Feld Zielinstanzname ein.
5. Klicken Sie auf Kopieren oder drücken Sie Eingabe auf der Tastatur. Eine Erfolgsmeldung wird angezeigt.
6. Überprüfen Sie die Verletzungen in der kopierten Regel.
Hinweis: SPC-Verletzungen sind vordefiniert. Sie können die Werte der Verletzungsparameter für eine kopierte Regel ändern, sie können jedoch keine Verletzungen ändern oder erstellen.
7. Verwenden Sie die Tabellensteuerelemente, um nach Bedarf Verletzungen zur SPC-Regelverletzungstabelle hinzuzufügen oder aus ihr zu löschen. Hinzugefügte Verletzungen werden am Ende der Liste in der Tabellen angezeigt. Gelöschte Verletzungen werden aus der Liste in der Tabelle entfernt.
8. Verwenden Sie die Steuerung zur Tabellenbearbeitung, um die Werte des Felds SPC-Verletzungsparameter in der kopierten Regel nach Bedarf zu bearbeiten. Die bearbeiteten Werte werden in der Spalte SPC-Verletzungsparameter angezeigt.
Hinweis: Weitere Informationen zu den Common Component-Charts und -Regeln für Inline SPC finden Sie im Abschnitt "Industrieregeln" der "SPC/IGC Common Component-Endbenutzerdokumentation" .
9. Klicken Sie auf Speichern. (missing or bad snippet)
