Definieren von Prioritätsstufen

Eine Prioritätsstufe definiert einen Indikator, mit dem einem Ereignis eine Bearbeitungspriorität zugewiesen wird. Sie können eine Prioritätsstufe angeben, wenn Sie ein Ereignis aufzeichnen und wenn Sie Qualitätsdatensätze verwalten.

Beim Definieren von Prioritätsstufen

Verwechseln Sie das Modellierungsobjekt "Prioritätsstufe" nicht mit dem Modellierungsobjekt "Prioritätscode". Prioritätsstufen werden Ereignissen und Qualitätsdatensätzen, Prioritätscodes hingegen Containern zugewiesen. Weitere Informationen zum Definieren von Prioritätsindikatoren für Container finden Sie unter "Definieren von Prioritätscodes".

Prioritätsstufen können als Suchparameter auf der Seite "Qualitätssuche" verwendet werden.

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Vorgehensweise zum Definieren einer Prioritätsstufe

Gehen Sie folgendermaßen vor, um eine Prioritätsstufe zu definieren:

1. Öffnen Sie die Seite Prioritätsstufe. Die Seite "Prioritätsstufe" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für diese Prioritätsstufe in das Feld Prioritätsstufe ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Unter "Gemeinsame Felder auf Modellierungsseiten" finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
