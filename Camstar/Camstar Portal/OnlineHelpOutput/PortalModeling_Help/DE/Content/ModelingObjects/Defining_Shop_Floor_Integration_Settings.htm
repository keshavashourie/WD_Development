Definieren von Einstellungen für die Fertigungsintegration

Auf der Seite "Einstellungen für die Fertigungsintegration" können Sie eine Gruppe von Feldern konfigurieren, die sich zum Beispiel auf diese Funktionalitäten beziehen:

• Automatisches Starten von Containern
• Sammeln von Defekten aus automatisierten Testausrüstungen
• Kommunikation mit der Programmierschnittstelle (API) für die Materialverwaltung oder der API für die Konfiguration der Fertigungsressourcen

Sie aktivieren eine Instanz der Einstellungen für die Fertigungsintegration, indem Sie sie auf der Modellierungsseite "Fabrik" auswählen.

Felddefinitionen der Einstellungen für die Fertigungsintegration

In dieser Tabelle werden die Felder beschrieben, die nur auf der Modellierungsseite der Einstellungen für die Fertigungsintegration zu finden sind.

Feld

Definition

Typ

Startgrund

Startgrund, der für gestartete Container festzulegen ist.

Optional

Level

Physischer Abschnitt des Containers, z. B. ein Panel oder PCB.

Dem Container zugeordneter Eigentümer. Der Eigentümer-Code dient als eine Gruppierung, um Container für Abfrage und Bearbeitung zu trennen. Einige Beispiele sind "Herstellung", "Entwicklung" und "Prototypen".

Optional

Arbeitsplan

Verarbeitungspfad für Standardcontainer oder Satz von Fertigungsschritten.

Optional

Produkttyp

Standardprodukttyp, der beim automatischen Erstellen eines Produkts während eines Containerstarts verwendet werden soll.

Optional

Materialverwaltungs-API

URL zur REST API der Materialverwaltung.

Optional

Defektgrundzuordnung

Zuordnen von in der Anwendung definierten Defektgründen zu Defektbeschriftungen, die für automatisierte Testausrüstung spezifisch sind.

Hinweis: Dieses Feld wird nur angezeigt, wenn der Industry Solutions-Arbeitsbereich installiert ist.

Optional

Lasermarkierungsfehler

Steuert das Verhalten, wie eine Meldung zu einem Lasermarkierungsfehler behandelt werden soll. Mögliche Optionen sind:

• Ignorieren (Seriennummern nach Bedarf aktualisieren und die Bewegung ausführen.)
• Bewegung vermeiden (und Fehler zurückgeben)
• Nacharbeit ausführen (sofern Pfad verfügbar, anderenfalls Fehlermeldung zurückgeben)
• Ausschuss-Panel
• XOut (PCB mit Fehler)

Hinweis: Dieses Feld wird nur angezeigt, wenn Opcenter Execution Electronics installiert ist. Weitere Informationen finden Sie im Opcenter Execution Electronics-Benutzerhandbuch.

Optional

SRC API

URL zur Fertigungsressourcen-Konfigurations-API

Definieren der Einstellungen für die Fertigungsintegration

Gehen Sie folgendermaßen vor, um eine Instanz der Einstellungen für die Fertigungsintegration zu definieren:

1. Wählen Sie in der Modellierungsobjektliste Einstellungen für die Fertigungsintegration aus. Die Seite "Einstellungen für die Fertigungsintegration" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Einstellungen für die Fertigungsintegration einen eindeutigen Namen für die Instanz der Einstellungen für die Fertigungsintegration ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Zuweisen einer Instanz der Einstellungen für die Fertigungsintegration zu einer Fabrik

Gehen Sie folgendermaßen vor, um eine Instanz der Einstellungen für die Fertigungsintegration zu einer Fabrik zuzuweisen:

1. Wählen Sie aus der Modellierungsobjektliste die Option Fabrik aus. Eine Liste der Fabrikinstanzen wird angezeigt.
2. Wählen Sie die Fabrik in der Liste aus. Die Fabrik wird innerhalb der Modellierungsseite angezeigt.
3. Wählen Sie Einstellungen für die Fertigungsintegration im Abschnitt Allgemein im eine Instanz der Einstellungen für die Fertigungsintegration aus.
4. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
