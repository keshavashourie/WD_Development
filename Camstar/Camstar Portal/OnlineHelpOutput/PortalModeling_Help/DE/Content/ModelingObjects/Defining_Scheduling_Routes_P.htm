Definieren von Ablaufplanungsrouten

Die Ablaufplanungsroute ermöglicht die Konfiguration bestimmter Ablaufplanungsrouten, ohne ERP-Routen zu nutzen. Sie können eine alternative Ablaufplanungsroute definieren und anwenden, die zum Identifizieren von Schritten für die Ablaufplanungsintegration verwendet werden kann. Instanzen der Ablaufplanungsrouten haben Vorrang vor allen zuvor konfigurierten ERP-Routen, die in der vorherigen Ablaufplanungskonfiguration verwendet werden. Wenn keine Ablaufplanungsrouten von der Anwendung konfiguriert oder erkannt werden, werden alle zuvor konfigurierten ERP-Routen, die zur Ermittlung der Ablaufplanungsschritte konfiguriert sind, weiterhin als Standard verwendet.

Hinweis: Sie müssen die Auswahl maximaler Ablaufplanungsschritte ausgleichen, um die Zeit zum Generieren von Daten und Zeitplänen zu optimieren. Eine erhöhte Anzahl von Ablaufplanungsschritten führt zu einer erhöhten Laufzeit für die Ablaufplanungsintegration und kann möglicherweise zu einem Laufzeitfehler führen.

Vorgehensweise zum Definieren einer Ablaufplanungsroute

Gehen Sie folgendermaßen vor, um eine Ablaufplanungsroute zu definieren:

1. Öffnen Sie die Seite Ablaufplanungsroute. Die Seite "Ablaufplanungsroute" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Ablaufplanungsroute in das Feld Ablaufplanungsroute ein.
4. Geben Sie den Namen dieses Routenschrittes in das Feld Routenschrittname ein.
5. Weitere Informationen zum Hinzufügen von Routenschritten finden Sie unter "Vorgehensweise zum Hinzufügen von Routenschritten zu einer Ablaufplanungsroute".
6. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Hinzufügen von Routenschritten zu einer Ablaufplanungsroute

Gehen Sie folgendermaßen vor, um einer Ablaufplanungsroute Routenschritte hinzuzufügen:

1. Führen Sie das Verfahren Vorgehensweise zum Hinzufügen von Routenschritten zu einer Ablaufplanungsroute" aus.

Oder

Wählen Sie eine vorhandene Instanz einer Ablaufplanungsroute aus.

2. Klicken Sie in der Tabelle "Routenschritte" auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
3. Geben Sie den Namen dieses Routenschrittes in das Feld Routenschrittname ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
5. Wiederholen Sie die Schritte 2 bis 4, um weitere Routenschritte hinzuzufügen.
6. Klicken Sie auf Speichern. Die Anwendung zeigt eine Erfolgsmeldung an, die angibt, dass das Modellierungsobjekt aktualisiert wurde.
