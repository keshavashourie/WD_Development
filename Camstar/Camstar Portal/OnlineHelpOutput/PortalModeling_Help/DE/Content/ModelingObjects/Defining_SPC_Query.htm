Definieren von SPC-Abfragen

Das SPC-Abfrageobjekt wird verwendet, um eine Abfrage zu modellieren, mit der SPC in Bezug auf Ihren Prozess geplottet wird. Sie können vorhandene Abfragen aus vorhandenen Legacy SPC-Makros kopieren, um eine SPC-Abfrage zu erstellen. Sie können zur Verwendung mit einer Inline SPC-Lösung auch neue SPC-Abfragen erstellen.

Beim Definieren von neuen SPC-Abfragen

Zum Verfassen von SPC-Abfragen müssen Sie mit dem Opcenter Execution Core SPC-Objektmodell und SQL vertraut sein. Neue SPC-Abfragen definieren Sie auf der Seite "SPC-Abfrage".

SPC-Basisabfragen wurden mit zahlreichen dynamischen Parametern entwickelt, damit möglichst wenige SPC-Abfragen neu erstellt werden müssen.

Felddefinitionen der Seite "SPC-Abfrage"

Diese Tabelle definiert die Felder auf der Seite "SPC-Abfrage".

Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.

Standartwert für den Parameter.

Standardmäßiger dynamischer Parameter, der für den Abfrageparameter verwendet wird. Dieser Wert überschreibt den Standardwert. Der Standardwert wird verwendet, wenn dieses Feld leer ist oder der eingegebene Wert falsch ist.

User Fields

Name der Behälterspalte

Rückgabespaltenname für den Behälter. Wird der Name nicht angegeben, erwartet Logik, die ihn benötigt, den Wert CARRIER.

Optional

Name der Ausrüstungsspalte

Rückgabespaltenname für die Ausrüstung. Wird der Name nicht angegeben, erwartet Logik, die ihn benötigt, den Wert EQUIPMENT.

Optional

Rückgabespaltenname für die Los-ID. Wird der Name nicht angegeben, erwartet Logik, die ihn benötigt, den Wert LOT.

Maximale Anzahl erwarteter Datensätze. Mit diesem Wert wird der InSite-Server angewiesen, den entsprechenden Speicher für den Empfang der Abfragedaten zu reservieren.

Vorgehensweise zum Definieren einer SPC-Abfrage

Gehen Sie folgendermaßen vor, um eine SPC-Abfrage zu definieren:

1. Öffnen Sie die Seite "SPC-Abfrage". Die Seite "SPC-Abfrage" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen der SPC-Abfrage in das Feld SPC-Abfrage ein.
4. Geben Sie den Text der SQL-Abfrageanweisung in das Feld Abfragetext ein.
5. Gehen Sie folgendermaßen vor, um Parameter zur Tabelle "Parameter" hinzuzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen.Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
b. Geben Sie den Namen des SPC-Abfrageparameters in das Feld Name für Benutzerabfrageparameter ein.
c. Geben Sie den Datentyp des SPC-Abfrageparameters in das Feld Datentyp ein.
d. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Testen der Abfrage

Gehen Sie folgendermaßen vor, um eine SPC-Abfragedefinition zu testen:

1. Führen Sie die Schritte in "Vorgehensweise zum Definieren einer SPC-Abfrage" aus.

Oder

Wählen Sie eine vorhandene SPC-Abfrageinstanz aus.

2. Klicken Sie auf Abfrage speichern und testen, um die Abfrage zu speichern und zu testen. Die Anwendung öffnet das Popup "Onlineabfrage: Einrichtung: Test".
3. Geben Sie alle Parameter ein, die die Abfrage erfordert.
4. Klicken Sie auf Abfrage testen. Alle Ergebnisse, die der Abfrage und den eingegebenen Parametern entsprechen, werden in der Tabelle "Abfrageergebnisse" angezeigt.
5. Klicken Sie auf Schließen. Das Popup "Onlineabfrage: Einrichtung: Test" wird geschlossen.
