Definieren von physischen Orten

Auf der Seite "Physischer Ort" können Sie bestimmte Bereiche innerhalb einer Fabrik erstellen und konfigurieren. Ein Ort kann so umfassend wie der gesamte Fertigungsbereich oder so speziell wie ein Regal sein.

Der physische Ort kann mithilfe physischer Positionen weiter angegeben werden. Beispielsweise kann Lager A (physischer Ort) aus Regal 1, Regal 2 und Regal 3 (physische Positionen) bestehen.

Vorgehensweise zum Definieren eines physischen Orts

Gehen Sie folgendermaßen vor, um einen physischen Ort zu definieren:

1. Öffnen Sie die Modellierungsseite Physischer Ort. Die Seite "Physischer Ort" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das Feld Physischer Ort ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Siehe auch "Gemeinsame Felder auf Modellierungsseiten". Dieser Abschnitt enthält Informationen zu den Feldern, die alle Modellierungsobjekte aufweisen.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
