Definieren von Werkzeugplänen

Ein Werkzeugplan wird verwendet, um die erforderlichen Werkzeuge anzugeben, die einer Ausrüstung vor der Verarbeitung zugewiesen werden müssen. Sie können Werkzeuge, Werkzeugfamilien und Werkzeuggruppen unter einem Werkzeugplan angeben. Bevor Sie Werkzeugpläne definieren, müssen Sie die Modellierungsobjekte für Werkzeuge, Werkzeugfamilien und Werkzeuggruppen erstellen, die einbezogen werden.

Vorgehensweise zum Definieren eines Werkzeugplans

Gehen Sie folgendermaßen vor, um einen Werkzeugplan zu definieren:

1. Öffnen Sie die Seite Werkzeugplan. Die Seite "Werkzeugplan" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für den Werkzeugplan in das Feld Werkzeugplan ein.
4. Klicken Sie in der Tabelle Details auf Neue Zeile hinzufügen. Eine Zeile wird in der Tabelle aktiviert.
5. Gehen Sie wie folgt vor:
a. Geben Sie einen Elementnamen in das Feld Elementname ein.
b. Geben Sie die Erforderliche Menge ein.
c. Wählen Sie Folgendes aus: Werkzeug, Werkzeugfamilie oder Werkzeuggruppe.
d. Geben Sie in die Tabelle Details abhängig von Ihren Geschäftsanforderungen optionale Informationen ein.
e. Wiederholen Sie die Schritte a bis c für jede zusätzliche Zeile, die der Tabelle hinzugefügt werden soll.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
