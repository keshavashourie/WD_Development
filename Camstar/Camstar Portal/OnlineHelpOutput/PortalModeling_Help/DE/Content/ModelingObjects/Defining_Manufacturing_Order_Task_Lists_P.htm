Definieren von Aufgabenlisten für Produktionsaufträge

Eine Aufgabenliste für Produktionsaufträge ist ein revisionierbares Objekt, mit dem Sie einem Auftrag eine Sammlung von Aufgaben zuweisen können.

Felddefinitionen der Seite "Produktionsauftrag Aufgabenliste"

Diese Tabelle definiert die Felder auf der Seite "Produktionsauftrag Aufgabenliste".

Feld

Definition

Typ

Details

Änderungsauftrag

Änderungsauftrag, der dieser Revision zugewiesen wurde. Sie können maximal 30 Zeichen eingeben.

Optional

Bild

In diesem Feld können Sie der Aufgabenliste für den Produktionsauftrag ein Bild zuordnen.

Optional

Anweisung

Schritte oder zusätzliche Informationen zum Ausführen der Aufgaben in der Aufgabenliste für den Produktionsauftrag. Sie können die Formatierungsfunktionen verwenden, um den Text besonders hervorzuheben, wenn Sie sich im Design-Modus befinden. Die Anwendung zeigt dem Bediener auf der Fertigungsseite "Produktsauftragsablauf" diese Informationen und alle speziellen Formatierungen an. Sie können Bilder auch mithilfe des Bildsymbols im Texteditor formatieren und einbetten.

Optional

Ausführungsmodus

Einstellung, die anzeigt, ob die Anwendung die Aufgaben in einer bestimmten Reihenfolge (Sequenziell) oder in beliebiger Reihenfolge (Nicht sequenziell) ausführt. Derzeit unterstützt die Anwendung nur "Nicht sequenziell".

Tabelle "Aufgaben"

Tabelle, die die Aufgaben auflistet, die der Liste hinzugefügt wurden. Sie müssen der Aufgabenliste mindestens eine Aufgabe hinzufügen.

Nur Anzeige

Aufgabe

Eindeutiger Name der Aufgabe.

Nur Anzeige

Anweisung

Schritte oder zusätzliche Informationen für die Ausführung der Aufgabe. Sie können die Formatierungsfunktionen verwenden, um den Text besonders hervorzuheben, wenn Sie sich im Design-Modus befinden. Diese Informationen mit allen speziellen Formatierungen werden dem Bediener angezeigt.

Nur Anzeige

Aufgabentyp

Folgende Anweisungstypoptionen sind verfügbar:

• Bestätigung – Ein Bediener muss eine Aufgabe als beendet markieren.
• Datensammlung – Ein Bediener muss parametrische Datenwerte für eine Standarddatensammlung oder für eine Datenpunktsammlung eingeben.
• Bestanden/Durchgefallen – Ein Bediener muss das Ergebnis "Bestanden/Durchgefallen" für eine Aufgabe angeben.

Der Typ "Anweisung" ist der einzige verfügbare Aufgabentyp für die Produktionsauftrags-Aufgabenliste.

Nur Anzeige

Max. Iterationen

Gibt an, wie häufig die Aufgabe maximal ausgeführt werden kann.

Nur Anzeige

Aufgabentyp

Art der Aufgabe (Prozess starten, normale Aufgabe oder Prozess beenden). "Normale Aufgabe" ist der einzige verfügbare Aufgabentyp für eine Aufgabe des Typs "Anweisung" in der Aufgabenliste eines Produktionsauftrags.

Nur Anzeige

Trainingsanforderungsgruppe

Erfassung einzelner Trainingsanforderungen und Trainingsanforderungsgruppen, die der Aufgabenliste zugeordnet sind.

Nur Anzeige
Popup "Anweisungsaufgabedetails"

Das Popup "Anweisungsaufgabedetails" wird angezeigt, wenn Sie:

• Wählen Sie eine Anweisungsaufgabe in der Tabelle "Produktionsauftragsaufgaben" aus und klicken Sie auf "Ausgewählte Zeile bearbeiten".
Felddefinitionen des Popups "Anweisungsaufgabedetails"

Diese Tabelle definiert die Felder im Popup-Fenster "Anweisungsaufgabendetails" im Kontext einer Aufgabenliste für einen Produktionsauftrag.

Feld

Definition

Typ

Aufgabe

Eindeutiger Name der Aufgabe. Sie können maximal 30 Zeichen eingeben.

Erforderlich

Anweisung

Schritte oder zusätzliche Informationen für die Ausführung der Aufgabe. Sie können die Formatierungsfunktionen verwenden, um den Text besonders hervorzuheben, wenn Sie sich im Design-Modus befinden. Diese Informationen mit allen speziellen Formatierungen werden dem Bediener angezeigt.

Optional

Aufgabentyp

Aufgabe, die den aktuellen Stand der Verarbeitung an der Arbeitszelle oder am Arbeitsplatz angibt. Die einzige Option für dieses Feld ist "Normale Aufgabe", die zwischen einer Prozess starten-Aufgabe und einer Prozess beenden-Aufgabe auftreten kann.

Erforderlich

Anweisungstyp

Einstellung, die die vom Bediener zu verrichtende Arbeit für die Aufgabe angibt. Dieses Feld wird automatisch auf "Supervisor-Prüfung" festgelegt, was bedeutet, dass ein Bediener den Aufgabenstatus eines Produktionsauftrags für eine Aufgabe auswählen muss.

Nur Anzeige

Min. Iterationen

Gibt an, wie häufig die Aufgabe mindestens ausgeführt werden muss. Dieses Feld wird automatisch auf 1 festgelegt.

Nur Anzeige

Max. Iterationen

Gibt an, wie häufig die Aufgabe maximal ausgeführt werden darf. Sie können in diesem Feld keinen Wert hinzufügen, sodass die Aufgabe beliebig oft ausgeführt werden kann.

Nur Anzeige

Weiter zur nächsten Aufgabe, wenn "Min. Iterationen" erreicht ist

Wenn dieses Kontrollkästchen aktiviert ist, zeigt die Anwendung automatisch die nächste Aufgabe an, wenn die Mindestanzahl von Iterationen für die aktuelle Aufgabe ausgeführt wurde. Dieses Kontrollkästchen ist standardmäßig aktiviert.

Optional

Trainingsanforderungsgruppe

Die mit dieser Aufgabe verknüpfte Trainingsanforderungsgruppe. Eine Trainingsanforderungsgruppe ist eine Sammlung individueller Trainingsanforderungen, die gewährleisten sollen, dass der Bediener zur Ausführung der Aufgabe qualifiziert ist.

Optional

Vorgehensweise zum Definieren einer Aufgabenliste für Produktionsaufträge

Gehen Sie folgendermaßen vor, um eine Aufgabenliste für Produktionsaufträge zu definieren:

1. Öffnen Sie die Seite Produktionsauftrag Aufgabenliste. Die Seite "Produktionsauftrag Aufgabenliste" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für diese Aufgabenliste in das Feld Produktionsauftrag Aufgabenliste ein.
4. Geben Sie die Revision dieser Produktionsauftrags-Aufgabenliste in das Feld Revision ein.
5. Wählen Sie einen Ausführungsmodus in der Liste aus.
6. Fügen Sie mindestens eine Aufgabe zur Tabelle "Aufgaben" hinzu, indem Sie das entsprechende, unten aufgeführte Verfahren befolgen:
• "Definieren von Aufgabenlisten für Produktionsaufträge "
7. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Informationen zu den optionalen Feldern finden Sie in Tabelle mit den Felddefinition.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Weitere Informationen zu Aufgabenlisten finden Sie unter "Definieren einer Aufgabenliste und zugehöriger Aufgaben".
