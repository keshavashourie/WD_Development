Definieren ausgehender CIO-Verbindungen

Das CIO-Verbindungsobjekt enthält die Details zu externen Verbindungen, an die ausgehende Nachrichten mithilfe der OAuth2-Authentifizierung gesendet werden.

Auf der Seite "Ausgehende Verbindung" in "Modellierung" können Sie externe Anwendungen mithilfe unterstützter Authentifizierungsmethoden authentifizieren. Auf dieser Seite können Sie eine externe Verbindung definieren, die als Eintrag in der Dropdown-Liste "Ausgehende Verbindung" auf der Popup-Seite "Allgemeine REST API" in der Tabelle "Ausgangsdefinition" angezeigt wird.

Auf dieser Seite können Benutzer entweder Anmeldeinformationen oder nur die Token- und URL-Informationen angeben.

Diese Tabelle definiert die Felder auf der Seite "Ausgehende Verbindung".

Vorgehensweise zum Definieren einer ausgehenden Verbindung

Gehen Sie folgendermaßen vor, um eine ausgehende Verbindung zu definieren:

1. Öffnen Sie die Seite "Ausgehende Verbindung". Die Seite "Ausgehende Verbindung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen in das Feld Ausgehende Verbindung ein.
4. Authentifizierungstyp OAuth2 ist standardmäßig ausgewählt.
5. Geben Sie die Informationen zur ausgehenden Verbindung in die folgenden Felder ein:
• Benutzername
• Password
• Nachrichtentext
• Token-URL
6. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
