Waagenverwaltung - Übersicht

Hinweis: Die nachstehend beschriebene Funktionalität ist nur verfügbar, wenn Batch Processing installiert ist. Weitere Informationen finden Sie im Opcenter Execution Medical Device and Diagnostics Batch Processing-Benutzerhandbuch und im Opcenter Execution Core Batch Processing-Benutzerhandbuch.

Sie können die Waagenverwaltungsfunktionen verwenden, um Waagen zum Wiegen von Komponentenmaterialien für die Batchverarbeitung zu definieren. Sie können Waagen basierend auf ihren Attributen Waagenfamilien zuordnen. Sie können Waagen auch gruppieren, indem Sie Waagen einer Waagengruppe zuweisen. Sie können die Waagengruppe dann verwenden, um die Waagen einzuschränken, die zum Wiegen von bestimmten Komponentenmaterialien zugelassen sind.
