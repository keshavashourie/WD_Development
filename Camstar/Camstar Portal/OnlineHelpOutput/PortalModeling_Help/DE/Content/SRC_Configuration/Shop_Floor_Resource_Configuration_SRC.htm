Fertigungsressourcenkonfiguration (SRC) - Übersicht

Hinweis: Hinweis: Die unten beschriebene Funktionalität ist nur verfügbar, wenn "Konfiguration von Fertigungsressourcen (SRC)" installiert ist. Weitere Informationen finden Sie in der Opcenter Execution Core-Anleitung zur Systemadministration.

Mit der "Konfiguration von Fertigungsressourcen (SRC)" können Sie Fertigungsressourcen mit detaillierten Spezifikationen konfigurieren und bestimmen, wo diese Ressourcen in die gesamte Fertigungsumgebung passen. Sie definieren die Fertigungsumgebung, indem Sie eine Fabrikhierarchie erstellen.

Fabrikhierarchie

Die Fabrikhierarchie stellt Ihre physische Fertigungsumgebung in Bezug auf Ressourcen und Ressourcenstandorte dar. Sie definieren die Hierarchie mit Instanzen und Beziehungen dieser Modellierungsobjekte:

• Unternehmen – stellt in der Regel alle Fertigungsanlagen innerhalb einer Organisation dar.
• Fabrik – eine Produktionsanlage
• Lagerort (verfügbar, wenn Industrielösungen installiert ist) – stellt den Ort dar, an dem Fertigwaren gelagert werden.
• Ressource – kann eines von drei Arten sein:
• Bereich – definierter Standort, der einem bestimmten Zweck gewidmet ist
• Zelle – definierter Standort innerhalb eines Bereichs, z. B. einer Fertigungslinie
• Ausrüstung – Maschinen oder Gegenstände, die in der Regel als Ressourcen betrachtet werden
Wichtig: Das Modellierungsobjekt "Ressource" enthält ein Feld namens "Fabrikebene", mit dem Sie einen Bereich oder Unterbereich einer Fabrik als Ressource zur Ressourcengruppierung konfigurieren können.

Zugreifen auf die Fabrikhierarchie

Um auf die Fabrikhierarchie zuzugreifen, wählen Sie Fabrikhierarchie im Opcenter Execution Core Modeling Hauptmenü aus. Die Seite "Fabrikhierarchie" wird geöffnet, in der die Fabrikhierarchie-Baumstruktur auf der linken Seite angezeigt wird. Das Unternehmen wird im reduzierten Modus angezeigt. Wenn die Hierarchie bereits definiert wurde, können Sie die Baumstruktur jeweils um eine Ebene erweitern.

Verwenden der Fabrikhierarchie

Wenn Sie ein Hierarchieelement in der Baumstruktur auswählen, wird die Modellierungsschnittstelle rechts neben der Baumstruktur angezeigt. Sie können die Schnittstellenseite verwenden, um Aktualisierungen vorzunehmen. Wenn das Element mit IPL-Einstellungen konfiguriert werden kann, enthält die Seite eine SRC-Schaltfläche. Sie klicken auf diese Schaltfläche, wenn Sie IPL-Einstellungen für das Element konfigurieren möchten. Weitere Informationen finden Sie unter "Definieren von IPL-Ausrüstungseinstellungen und -parametern".

Definieren von IPL-Ausrüstungseinstellungen und -parametern

IPL-Ausrüstungseinstellungen und -parameter helfen dabei, IPL-Nachrichten zu unterstützen. Jede Ausrüstungsressource kann mehrere Einstellungen aufweisen. Um den Wert einer Einstellung festzulegen, haben Sie drei Optionen:

• Unternehmenswert – ein Standard, der für das Unternehmen konfiguriert und von der Ausrüstungsressource geerbt wurde. Wenn ein Wert für die Unternehmenseinstellung aktualisiert wird, erben alle Ausrüstungen, die für den Unternehmenswert konfiguriert sind, den aktualisierten Wert. Denken Sie daran, dass diese Standards durch diejenigen mit Änderungsberechtigungen geändert werden können.
• Vorgeschlagener Wert – ein Wert, der von Ausrüstungsingenieuren in der Software festgelegt und berechnet wurde, um den besten Standardwert für die spezifische Kombination von Ausrüstungstyp, Hersteller und exaktem Modell zu sein. Der Wert eines vorgeschlagenen Werts kann nicht von Endbenutzern geändert werden.
• Wert "Manuell eingegebenen Wert überschreiben" – ein manuell eingegebener Wert, der als der beste Wert für die Konfiguration der Ausrüstung in Ihrer Fabrik betrachtet wird. Es können nur Werte innerhalb eines angemessenen Bereichs gespeichert werden. Werte außerhalb dieses Bereichs führen zu einem Fehler. Wenn Sie auf "Unternehmen" oder "Vorgeschlagen" klicken, wird der Wert "Überschreiben" gelöscht.
Wichtig: Sie können keine nicht numerischen Werte in die Felder eingeben, die nur numerische Eingaben wie Ganzzahlen unterstützen.

Seite "SRC-Einstellungen"

Diese SRC-Seite enthält die folgenden Abschnitte:

1. Ausgewählte Instanz (Informationen, die aus Opcenter Execution Core Modeling übertragen wurden).
2. Kopfzeilenbereich – Optionen zum Auswählen der anzuzeigenden Daten und wie sie im Detailbereich angezeigt werden
3. Kategorienbereich – Liste der Kategorien und Anzahl der Einstellungen innerhalb der Kategorie, die Auswahlkriterien erfüllen
4. Detailbereich – tatsächliche Einstellungswerte (Inhalt dieses Bereichs, der von der Kopf- und Kategorieauswahl betroffen ist)

Kategorien

Je nach Hersteller und Maschinentyp stehen verschiedene Einstellungen zur Verfügung. Diese Kategorien sind fest und können vom Benutzer nicht geändert werden. Durch die Kategorisierung von Einstellungen ist es viel einfacher, diejenigen zu finden, an denen Sie interessiert sind, auch wenn Sie die genauen Namen nicht kennen. Einstellungen können erforderlich, optional oder andere sein, die nur unter bestimmten Umständen oder aus älteren Gründen erforderlich sind.

Jede Kategorie wird zusammen mit der Anzahl der Parameter angezeigt, die in dieser Kategorie enthalten sind. Diese Nummer wird durch die ausgewählte Ansicht-Option(en) beeinflusst. Diese Zahl kann höher oder niedriger sein, je nachdem, ob die Optionen "Optional anzeigen" und "Andere anzeigen" ausgewählt sind. Eine Kategorie wird nicht angezeigt, wenn keine Parameter vorhanden sind, die in die ausgewählte Ansicht-Option(en) fallen.

Detailbereich

Im Bereich Details werden die tatsächlichen Werte der Einstellungen angezeigt. Jede Einstellung kann einen Wert haben, z. B. einen Namen, eine Zahl oder einen Ja-/Nein-Umschalter. Erforderliche Parameter werden mit einem Sternchen angezeigt. Beim Erstellen oder Hinzufügen einer neuen Ausrüstung auf der Seite SRC füllt die Anwendung automatisch die Einstellung "IPL-Maschinentyp" mit dem Standardwert aus, der in der Datei ResourcesSettingsSchema.json (Schemadatei mit allen Ausrüstungseinstellungen) konfiguriert ist.

Für jeden Parameter wird eine Hilfeschaltfläche angezeigt. Durch Klicken auf diese Schaltfläche wird das Dialogfenster "Einstellungeninformationen" geöffnet.

Wichtig: Sie können keine nicht numerischen Werte in die Felder eingeben, die nur numerische Eingaben wie Ganzzahlen unterstützen.

Vererbung

In der objektorientierten Programmierung bezieht sich die Vererbung auf die Fähigkeit, eine Basisklasse zu erstellen, deren Eigenschaften von anderen Klassen geerbt werden können. In Bezug auf intelligente Einstellungen bezieht sich die Vererbung auf die Möglichkeit, Einstellungen auf Unternehmensebene zu konfigurieren sodass alle Ausrüstungsressourcen auf der untergeordneten Ebene innerhalb des Unternehmens diese Einstellungen als Standard erben.

Wichtig: Geerbte Einstellungen sind Standardeinstellungen und können von Personen mit Änderungsberechtigungen geändert werden.

Optionen zum Abrufen der Einstellungswerte

Für jede Einstellung jeder Ausrüstungsressource gibt es drei Optionen für die Quelle des Einstellungswerts:

• •Unternehmenswert – ein Standard, der für das Unternehmen konfiguriert und von der Ausrüstungsressource geerbt wird. Wenn ein Unternehmenseinstellungswert geändert wird, erben alle Ausrüstungen, die für die Verwendung des Unternehmenswerts konfiguriert sind, den aktualisierten Wert.
• Vorgeschlagener Wert – ein Wert, der von Ausrüstungsingenieuren in der Software festgelegt und berechnet wurde, um den besten Standardwert für die spezifische Kombination von Ausrüstungstyp, Hersteller und exaktem Modell zu sein. Der Wert eines vorgeschlagenen Werts kann nicht von Endbenutzern geändert werden.
• Wert "Manuell eingegebenen Wert überschreiben" – ein manuell eingegebener Wert, der als der beste Wert für die Konfiguration der Ausrüstung in Ihrer Fabrik betrachtet wird. Es können nur Werte innerhalb eines angemessenen Bereichs gespeichert werden. Werte außerhalb dieses Bereichs führen zu einem Fehler. Wenn Sie auf "Unternehmen" oder "Vorgeschlagen" klicken, wird der Wert "Überschreiben" gelöscht.
Wichtig: Sie können nur numerische Werte in die Felder eingeben, die nur numerische Eingaben wie Ganzzahlen unterstützen.

Beim Ändern von Werten für intelligente Einstellungen

Häufig besteht die effizienteste Methode zum Aktualisieren Ihrer Ressourcen mit den richtigen Einstellungswerten darin, die Einstellungswerte auf Unternehmensebene zu füllen, sodass Ressourcen diese Werte als Standardwerte erben. Sie können die Einstellungen für das Unternehmen ändern, wenn diese nicht korrekt sind. Alle Änderungen werden bis zu den Ressourcen kaskadiert, die untergeordnete Elemente des Unternehmens sind und die zuvor geerbten Standards überschreiben. Wenn nur einige Ressourcen unterschiedliche Einstellungen benötigen, können Sie die Werte nur für diese Ressourcen ändern. Überschreibungswerte werden in einer Tabelle für jede Maschine oder Ressource gespeichert. Wenn Sie auf die Schaltfläche "Unternehmen" oder "Vorgeschlagen" klicken, wird der Überschreibungswert gelöscht. Wenn Sie auf die Schaltfläche "Speichern" klicken, wird ein Warn-Popup ausgelöst, das eine Bestätigung erfordert, dass Änderungen vorgenommen wurden, und dass die Werte auf die untergeordneten Ebenen vererbt werden. Sobald Änderungen gespeichert wurden, werden nicht verwendete Überschreibungswerte gelöscht.

Wichtig: Für die Überschreibungswerte ist der Name sehr spezifisch. Alle Ressourcen, die genau diesen Überschreibungsparameternamen verwenden, verwenden denselben Wert. Wenn Sie den Wert für eine Einstellung ändern, wird der Wert für alle anderen Einstellungen mit dem gleichen Namen geändert. Sie können nur numerische Werte in die Felder eingeben, die nur numerische Eingaben wie Ganzzahlen unterstützen.

Rollenberechtigungen für die Konfiguration intelligenter Einstellungen

Benutzer, die die intelligenten Einstellungen konfigurieren müssen, müssen einer Rolle mit der externen Berechtigung „IPL-Konfiguration“ zugewiesen werden. Benutzer ohne diese Berechtigung können die Einstellungen weiterhin im schreibgeschützten Modus anzeigen. Weitere Informationen zu den externen Berechtigungen finden Sie unter "Definieren externer Berechtigungen".

Die folgenden Elemente, die normalerweise auf der Seite angezeigt werden, werden nicht im schreibgeschützten Modus angezeigt:

• Schaltfläche "Speichern"
• Umschaltfläche "Überschreiben" und "Geerbte Werte"
• Auswahl des Ausrüstungstyps

Vorgehensweise zum Aktualisieren von Einstellungswerten für die SRC-Ausrüstung

Gehen Sie folgendermaßen vor, um die Einstellungswerte für die SRC-Ausrüstung zu ändern:

1. Wählen Sie Fabrikhierarchie im Hauptmenü von Opcenter Execution Core Modeling aus. Die Seite "Fabrikhierarchie" wird geöffnet, in der die Fabrikhierarchie-Baumstruktur auf der linken Seite angezeigt wird.
2. Wählen Sie die Ausrüstungsressource aus der Fabrikhierarchie-Baumstruktur aus. Die Anwendung zeigt rechts neben der Baumstruktur die ausgewählte Instanz auf der entsprechenden Modellierungsseite an.
3. Klicken Sie auf die SRC-Schaltfläche. Die Seite "SRC-Einstellungenkonfiguration" wird geöffnet.
4. Um eine nicht erforderliche Einstellung zu ändern, wählen Sie Optional anzeigen oder Andere anzeigen nach Bedarf im Kopfbereich der Detailansicht aus. Die Anwendung zeigt alle zusätzlichen Einstellungen an, die Ihren Auswahlkriterien entsprechen.
5. Klicken Sie auf die Schaltfläche Erweitern neben der zu aktualisierenden Einstellung. Klicken Sie alternativ auf die Schaltfläche Alle erweitern wenn viele Einstellungen geändert werden müssen. Klicken Sie auf Alle auswählen wenn alle Werte geändert werden müssen.
6. Um einzelne Einstellungswerte anzupassen, klicken Sie auf die Schaltfläche Überschreiben. Der Wert wird für die Bearbeitung entsperrt
7. Nehmen Sie Ihre Änderungen vor. Alle Werte, die sich nicht innerhalb des konfigurierten Bereichs spezifisch für dieses Herstellungs- und Ausrüstungsmodell befinden, lösen eine Warnung aus.
Wichtig: Sie können nur numerische Werte in die Felder eingeben, die nur numerische Eingaben wie Ganzzahlen unterstützen.
8. Wenn Sie fertig sind, klicken Sie in der Symbolleiste des Kopfzeilenbereichs auf Speichern. Wenn Sie Änderungen auf Unternehmensebene vornehmen, wird eine Warnung ausgelöst, die Bestätigung der vorgenommenen Änderungen erfordert. Klicken Sie auf die Schaltfläche OK. Eine Nachricht zum erfolgreichen Speichern wird angezeigt.

Kopieren, Exportieren und Importieren der Fertigungsressourceneinstellung

Sie können nur Einstellungen für einzelne Ressourcen kopieren, aber Einstellungen können verwendet werden, um Duplikate zu erstellen. Dies ist sehr wichtig, da es viele der nützlichsten Maschinenteile häufig mehr als einmal in der Fabrik gibt. Der Export und Import kann für eine beliebige Ebene oder Gruppe erfolgen, einschließlich des gesamten Unternehmens. Die Informationen werden jedoch entsprechend den vorhandenen Namen und Strukturen gespeichert und erneut angewendet. Dies gilt nicht für das Erstellen von Kopien.

Beim Kopieren intelligenter Einstellungen für eine Ressource

Das Kopieren kann für jedes einzelne Element auf jeder Ebene in der Fabrikhierarchie-Baumstruktur erfolgen, muss jedoch in der Opcenter Execution Core-Anwendung ausgeführt werden. Ausführliche Anweisungen finden Sie im Opcenter Execution Core Modeling-Benutzerhandbuch.

Beim Exportieren und Importieren intelligenter Einstellungen

Werte müssen exportiert werden, bevor sie importiert werden können. Zwei Fakten müssen berücksichtigt werden:

• Die Ressourcenstruktur, d. h. die Fabrikhierarchie-Baumstruktur, ist ein Bestandteil von, und wird verwaltet durch, Opcenter Execution Core.
• Die detaillierten Einstellungen für jede Ressource werden vom SRC-Plug-In verwaltet, insbesondere vom Dialogfenster "Intelligente Einstellungen".

Jeder Datentyp kann separat von der anderen exportiert werden. Wenn beide benötigt werden, müssen Sie zwei separate Exporte und Importe durchführen.

Hinweis: Informationen zum Exportieren von Elementen der Fabrikhierarchie-Baumstruktur finden Sie im Opcenter Execution Core Modeling-Benutzerhandbuch.

Vorgehensweise zum Exportieren von SRC-Einstellungen

Sie müssen SRC-Ausrüstungseinstellungen exportieren, bevor Sie diese importieren können. Gehen Sie folgendermaßen vor, um SRC-Einstellungen aus der Fabrikhierarchie-Baumstruktur zu exportieren:

1. Wählen Sie Fabrikhierarchie im Hauptmenü von Opcenter Execution Core Modeling aus. Die Seite "Fabrikhierarchie" wird geöffnet, in der die Fabrikhierarchie-Baumstruktur auf der linken Seite angezeigt wird.
2. Wählen Sie die Ebene, die Sie exportieren möchten, aus der Fabrikhierarchie-Baumstruktur aus. Beispielsweise für alle Ausrüstungen in einer Produktionslinie, wählen Sie diese Linie aus. Für alle Ausrüstungen in einer Fabrik, wählen Sie die Fabrik aus. Die Anwendung öffnet die Seite "SRC-Einstellungen".
3. Klicken Sie in der Symbolleiste der Seite "SRC-Einstellungen" auf die Schaltfläche Exportieren. Wenn nicht gespeicherte Einstellungen vorhanden sind, wird eine Warnmeldung ausgelöst. Alle Einstellungen aus der ausgewählten Hierarchieebene werden exportiert. Ressourcendetails werden für jedes Element (Maschine, Linie, Fabrik), aber nicht die tatsächliche Layout-Struktur gespeichert.

Vorgehensweise zum Importieren von SRC-Einstellungen

Bevor Sie die SRC-Werte importieren, muss eine Exportdatei erstellt worden sein, die alle Elemente enthält, die Sie importieren möchten. Weitere Informationen finden Sie unter "Vorgehensweise zum Exportieren von Einstellungen".

Gehen Sie folgendermaßen vor, um SRC-Einstellungen zu importieren:

1. Wählen Sie Fabrikhierarchie im Hauptmenü von Opcenter Execution Core Modeling aus. Die Seite "Fabrikhierarchie" wird geöffnet, in der die Fabrikhierarchie-Baumstruktur auf der linken Seite angezeigt wird.
2. Wählen Sie die Ebene aus, aus der Sie aus der Fabrikhierarchie-Baumstruktur importieren möchten. Beispielsweise für alle Ausrüstungen in einer Produktionslinie, wählen Sie diese Linie aus. Für alle Ausrüstungen in einer Fabrik, wählen Sie die Fabrik aus. Um Einstellungen für eine einzelne Ressource zu importieren, wählen Sie diese Ressource aus. Die Anwendung öffnet die Seite "SRC-Einstellungen".
3. Klicken Sie in der Symbolleiste der Seite "SRC-Einstellungen" auf die Schaltfläche "Importieren". Es wird ein Dateidialogfenster angezeigt, in dem angezeigt wird, welche Ressourcendateien importiert werden können.
4. Wählen Sie eine Datei aus und klicken Sie auf OK. Ein Informationen-Popup für Importeinstellung mit dem Name der aktuellen importierten Datei wird angezeigt.
5. Klicken Sie auf OK. Die Anwendung zeigt eine Nachricht mit dem Hinweis an, dass der Import erfolgreich war.
