Fertigungsressourcenkonfiguration

Mit intelligenten Einstellungen können Sie Fertigungs-IoT- und IPL-Ressourcenausrüstung in Ihrer Fabrik konfigurieren und ausrüstungsbasierte Nachrichten verwalten. Auf die Konfiguration intelligenter Einstellungen kann zugegriffen werden, indem Sie auf einer der Opcenter Execution Core Modeling-Seiten auf die Schaltfläche "Einstellungen der Fertigungsressourcenkonfiguration (SRC)" klicken:

• Unternehmen
• Fabrik
• Lagerort (wenn Industrielösungen installiert ist)
• Ressource
• Fabrikebene = Bereich
• Fabrikebene = Zelle
• Fabrikebene = Ausrüstung

Diese Themen enthalten Informationen zur Konfiguration intelligenter Einstellungen:

• Fertigungsressourcenkonfiguration (SRC) - Übersicht
• Definieren von IPL-Ausrüstungseinstellungen und -parametern
• Kopieren, Exportieren und Importieren der Fertigungsressourceneinstellung
