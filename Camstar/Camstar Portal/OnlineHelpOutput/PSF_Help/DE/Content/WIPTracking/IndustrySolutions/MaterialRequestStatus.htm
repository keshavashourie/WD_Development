Anzeigen von Materialanforderungsstatus

Sie können den Status von Materialanforderungen (automatisiert oder manuell) über die Seite "Statustafel für Materialanforderungen" anzeigen. Die Seite "Statustafel für Materialanforderungen" können Sie über das Menü "Ressourcenmaterialwarteschlange" aufrufen.

Die Funktion "Statustafel für Materialanforderungen" ist Bestandteil des eKanban-Prozesses. Weitere Informationen finden Sie im Opcenter Execution Medical Device and Diagnostics Industry Solutions-Benutzerhandbuch und im Opcenter Execution Core Industry Solutions-Benutzerhandbuch.

Konfigurieren der Statustafel für Materialanforderungen

Siemens bietet die Funktion zur automatischen Aktualisierung der Statustafel für Materialanforderungen zur Verfügung, damit Sie aktive Materialanforderungen in Echtzeit anzeigen können.

Sie müssen Opcenter Connect MOM installieren und konfigurieren, um die Funktion zum automatischen Aktualisieren zu aktivieren. Weitere Informationen finden Sie in der Opcenter Connect MOM-Installationsanleitung.

Siemens stellt die folgenden Transaktionsprüfer-Skripte zur Verfügung, um beim Konfigurieren von Opcenter Connect MOM zu unterstützen:

• OPEXCON_MaterialRequest.cfg
• OPEXCR_MaterialRequest.cfg

Die Skripte befinden sich standardmäßig am folgenden Speicherort:

C:\\Programme (x86)\Camstar\Industry Solutions\Industry\Scripts\Config

Hinweis: Die Anwendung verlangt, dass Sie in Opcenter Connect MOM und in der Eigenschaft isMaterialRequestStatusBoard VP tile SignalRURL in Portal Studio denselben Kanalquellennamen und dieselbe Steuerungsadresse verwenden. Wenn Änderungen vorgenommen werden, müssen Sie beide Positionen aktualisieren.

Beim Anzeigen von Materialanforderungsstatus

Auf der Seite "Statustafel für Materialanforderungen" werden alle nicht erfüllten Materialanforderungsstatus angezeigt. Jede Kachel auf der Seite stellt eine Auffüllaufforderung für eine Materialwarteschlange dar. Kacheln werden zur Tafel hinzugefügt, wenn eine Materialanforderung erstellt wurde.

Die Kacheln auf der Tafel werden so angeordnet, dass die nach Datum/Zeit ältesten Status oben links in der Spalte angezeigt werden und dass sie von links nach rechts jünger werden. Die Darstellung der Kacheln wird am Bildschirmrand beendet und eine neue Zeile beginnt, wenn der Platz für eine neue Kachel nicht mehr ausreicht.

Jede Kachel enthält:

• Materialanforderungsstatus
• Name der Materialwarteschlange
• Name des angeforderten Produkts
• Produktbeschreibung
• Angeforderte Menge/Maßeinheit
• Datum der Anforderung
Seite "Statustafel für Materialanforderungen"

Die Seite wird automatisch aktualisiert, sodass aktuelle Anforderungen und Status angezeigt werden, wenn Sie Opcenter Connect MOM installiert haben und die Statustafel für Materialanforderungen konfiguriert haben. Weitere Informationen finden Sie im Opcenter Execution Medical Device and Diagnostics Industry Solutions-Benutzerhandbuch und im Opcenter Execution Core Industry Solutions-Benutzerhandbuch.

Die Anwendung entfernt Kacheln von der Tafel, wenn eine Materialbestätigung für eine erfüllte Materialanforderung eingeht.
