Manuelles Anfordern von Material

Mithilfe der Seite "Materialanforderung" können Sie Material für eine Materialwarteschlange und einen Lagerort manuell anfordern.

Das Feld "Produkt" in der Tabelle "Materialanforderung" zeigt standardmäßig nur die Produkte an, die der ausgewählten Materialwarteschlange oder dem ausgewählten Lagerort zugeordnet sind. Wenn Sie das Kontrollkästchen "Alle Produkte anzeigen" aktivieren, kann die Anwendung alle Produkte anzeigen, die in der Anwendung definiert sind.

Erforderliche Einrichtung für Electronics Suite

Um die Seite "Materialanforderung" verwenden zu können, muss das Kontrollkästchen "Materialverwaltung aktiviert" auf der Modellierungsseite "Fabrik" aktiviert sein. Darüber hinaus muss mindestens ein Lagerort erstellt worden sein.

Hinweis: Benutzer von Execution Electronics können über den Produktions-Client auf ein Materialanforderungs-Popup zugreifen, wenn ein offener Defekt ausgewählt ist.

Beispiel für eine Materialanforderungsnachricht

Die Transaktion "Materialanforderung" bewirkt, dass eine Nachricht generiert wird, die konvertiert und an die REST API der Materialverwaltung gesendet wird, wenn Sie Opcenter Connect MOM installiert und eine ausgehende Nachricht konfiguriert haben. Diese Schnittstelle ist für die Zusammenarbeit mit dem Valor-Materialmanagementsystem vorgesehen. Weitere Informationen finden Sie im Opcenter Execution Medical Device and Diagnostics Industry Solutions-Benutzerhandbuch und im Opcenter Execution Core Industry Solutions-Benutzerhandbuch.

Vorgehensweise zum manuellen Anfordern von Material

Gehen Sie folgendermaßen vor, um Material manuell anzufordern.

1. Öffnen Sie die Seite Materialanforderung. Die Seite "Materialanforderung" wird angezeigt.
2. Wählen Sie in der Liste einen Lagerort oder eine Materialwarteschlange aus. Die Anwendung trägt die entsprechende Ressource in das Feld "Ressource" ein (sofern zutreffend).
3. Aktivieren Sie ggf. das Kontrollkästchen Alle Produkte anzeigen.
4. Wählen Sie in der Tabelle Materialanforderung ein Produkt aus. Die Anwendung füllt das Feld "Beschreibung" aus.
5. Geben Sie im Feld Angeforderte Menge einen Wert ein.
6. Wählen Sie im Feld Maßeinheit einen Wert aus.
7. Wiederholen Sie die Schritte 3-5 für jede zusätzliche Materialanforderung.
8. Klicken Sie auf Einreichen. Die Anwendung speichert Ihre Änderungen und zeigt eine Erfolgsmeldung an.
