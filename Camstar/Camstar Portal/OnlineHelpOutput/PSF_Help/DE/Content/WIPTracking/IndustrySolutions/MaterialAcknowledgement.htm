Durchführen einer Materialbestätigung

Mit Hilfe der Seite "Materialanforderung bestätigen" können Sie, offene Materialauffüllanforderungen bestätigen oder stornieren. Bestätigungen geben an, dass Material empfangen wurde. Stornierungen geben an, dass Materialanforderungen abgebrochen wurden.

Beim Durchführen einer Materialbestätigung

Die Anwendung aktualisiert die Materialmengen in der zugehörigen Materialwarteschlange oder dem zugehörigen Lagerort, wenn Sie den Empfang des Materials bestätigen. Die Zeile wird aus der Tabelle "Materialanforderungsbestätigung" entfernt, wenn die verbleibende Menge Null erreicht.

Wenn das Produkt die folgenden Bedingungen erfüllt, wird das bestätigte Material als neue Zeile in die Materialwarteschlange oder den Lagerort geladen:

• Es weist eine eindeutige Container-/Losidentifikation auf und ist für das geladene Produkt in der Materialwarteschlange oder am Lagerort noch nicht vorhanden.
• Es hat keine Container-/Losnummer, aber die gleichen Produkte in der Materialwarteschlange oder am Lagerort verfügen über Container-/Losnummern.

Beispiele für XML-Nachrichten zur Materialbestätigung

Ausgehende Nachrichten können so konfiguriert werden, dass sie mit der Materialbestätigung erstellt werden. Diese Nachricht ist für die Verwendung in Verbindung mit dem Valor-Materialmanagementsystem vorgesehen. Dieser Abschnitt enthält Snippet-Beispiele für die Nachrichten, die von der Anwendung versendet werden, wenn Sie Materialanforderungen bestätigen oder abbrechen.

XML-Beispiel 1: Mit einem Container empfangenes Material bestätigen

Dieser XML-Code zeigt ein Beispiel für eine Bestätigung mit einem angegebenen Container:

<MaterialRequestAcknowledge>

<Container>REEL-1234</Container>

<Product>PART_1234</Product>

<RequestQty>100</RequestQty>

<ReceivedQty>100</ReceivedQty>

<Resource>My_LOCATION</Resource>

<Employee>My_NAME</Employee>

<CancelRequest>False</CancelRequest>

<AcceptedNoContainer>False</AcceptedNoContainer>

<ExternalOrderID>49e0728000000edb</ExternalOrderID>

<DisplayName>Kanban-3</DisplayName>

<UOM>EACH</UOM>

</MaterialRequestAcknowledge>

XML-Beispiel 2: Ohne Container empfangenes Material bestätigen

Dieser XML-Code zeigt ein Beispiel für eine Bestätigung, ohne dass ein Container angegeben ist:

<MaterialRequestAcknowledge>

<Container>REEL-1234</Container

<Product>PART_1234</Product>

<ReceivedQty>100</ReceivedQty>

<Resource>My_LOCATION</Resource>

<Employee>My_NAME</Employee>

<CancelRequest>False</CancelRequest>

<AcceptedNoContainer>False</AcceptedNoContainer>

<ExternalOrderID>49e0728000000edb</ExternalOrderID>

<DisplayName>Kanban-3</DisplayName>

XML-Beispiel 3: Anforderung abbrechen

Dieser XML-Code zeigt ein Beispiel einer Abbruchanforderung:

<MaterialRequestAcknowledge>

<Container></Container>

<Product>PART_1234</Product>

</MaterialRequestAcknowledge>

Vorgehensweise zum Bestätigen einer Materialanforderung

Führen Sie die folgenden Schritte aus, um eine Materialanforderung zu bestätigen:

1. Öffnen Sie die Seite Materialanforderungsbestätigung.
2. Wählen Sie einen Lagerort oder eine Materialwarteschlange aus. Die Anwendung füllt die Tabelle basierend auf Ihrer Auswahl aus.
3. Wählen Sie die Tabellenzeile aus, in der der zu bestätigende Bestand aufgeführt ist.
4. Geben Sie einen Wert in das Feld Empfangene Menge ein. Die Anwendung füllt das Feld "Verbleibende Menge" mit dem Unterschied zwischen "Angeforderte Menge" und "Empfangene Menge".
5. Führen Sie einen der folgenden Schritte durch:

Wenn das empfangene Material . . .

Dann . . .

einen Containeridentifikator aufweist
a. Scannen Sie den Identifikator in das Feld Container/Los bzw. geben Sie ihn ein.
b. Gehen Sie zu Schritt 6.

keinen Containeridentifikator aufweist
a. Wechseln Sie zu Schritt 6.
6. Wiederholen Sie die Schritte 3-5 für jede zusätzliche Materialanforderung in der Tabelle, die Sie bestätigen müssen.
7. Klicken Sie auf Abschicken. An das Valor-Materialmanagementsystem wird eine Nachricht mit der bzw. den Bestätigungen gesendet. Die empfangene Materialmenge wird in den entsprechenden Lagerort oder die entsprechende Materialwarteschlange geladen. Das Feld "Verbleibende Menge" wird mit der Differenz zwischen der angeforderten Menge und der empfangenen Menge aktualisiert.

Vorgehensweise zum Abbrechen einer Materialanforderung

Gehen Sie folgendermaßen vor, um eine Materialanforderung abzubrechen:

1. Öffnen Sie die Seite Materialanforderungsbestätigung.
2. Wählen Sie einen Lagerort oder eine Materialwarteschlange aus. Die Anwendung füllt die Tabelle basierend auf Ihrer Auswahl aus, wenn Sie die Standardauswahl geändert haben.
3. Wählen Sie die Tabellenzeile aus, in der die abzubrechende Materialanforderung aufgeführt ist.
4. Aktivieren Sie das Kontrollkästchen Abbrechen.
5. Wiederholen Sie die Schritte 3-4 für jede zusätzliche Materialanforderung in der Tabelle, die Sie abbrechen müssen.
6. Klicken Sie auf Abschicken. Die Anwendung bricht die Anforderungen ab und entfernt die Anforderungen von der Statustafel für Materialanforderungen. An das Valor-Materialmanagementsystem wird eine Nachricht mit den Storno-bzw. Abbruchdaten gesendet, sofern dies entsprechend konfiguriert wurde.
