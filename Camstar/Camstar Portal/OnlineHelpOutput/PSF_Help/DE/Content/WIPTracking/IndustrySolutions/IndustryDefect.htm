Industriedefekt

Auf der Seite "Industriedefekt" können Sie aktuelle Defektinformationen für den Container anzeigen.

Hinweis: Dieses Thema enthält grundlegende Informationen zum Arbeiten mit Defekten. Weitere Informationen finden Sie im Opcenter Execution Medical Device and Diagnostics Industry Solutions-Benutzerhandbuch oder im Opcenter Execution Core Industry Solutions-Benutzerhandbuch.

Vor der Verwendung von "Industriedefekt"

Sie müssen Gründe für den Containerdefekt in der Modellierung konfigurieren, bevor Sie Defekte von Containern aufzeichnen können. Die Defektgründe stehen unter diesen Bedingungen zur Auswahl:

• Ein Containerdefektgrund wurde definiert.
• Eine Containerdefektgrund-Gruppe mit dem entsprechenden Grund wurde definiert.
• Die Containerdefektgrund-Gruppe wurde der aktuellen Operation des Containers zugewiesen.

Informationen zum Definieren und Verknüpfen der Objekte, die zum Aufzeichnen von Containerdefekten erforderlich sind, finden Sie im Opcenter Execution Medical Device and Diagnostics Modeling-Benutzerhandbuch und im Opcenter Execution Core Modeling-Benutzerhandbuch.

Bei der Verwendung von "Industriedefekt"

Alle Anzeigefelder sind auf der Seite "Industriedefekt" leer, bis ein Container eingegeben oder ausgewählt wird. Anzeigefelder werden automatisch in der Tabelle "Defektliste" ausgefüllt. Jede Zeile stellt einen offenen Defekt oder einen reparierten Defekt dar. Sie können einen Defekt an einem Container protokollieren, indem Sie das Popup "Defekt protokollieren" über die Schaltfläche "Defekt hinzufügen" in der Befehlsleiste aktivieren. Die Tabelle wird aktualisiert, sobald neue Defekte protokolliert werden.

Hinweis: Sie können Defekte an allen ausgegebenen Materiallistenelementen oder Artikeln protokollieren, deren Verbrauchstyp "Nur Anzeige" lautet.

Seite "Industriedefekt"

Sie können über das Container-Menü auf die Seite "Industriedefekt" zugreifen. Die Seite "Industriedefekt" ermöglicht es Ihnen, eine Liste von Defekten am ausgewählten Container aufzuzeichnen.

Popup "Defekt protokollieren"

Sie können auf das Popup-Fenster "Defekt protokollieren" zugreifen, indem Sie in der Seitenleiste der Seite "Industriedefekt" auf die Schaltfläche "Defekt hinzufügen" klicken.

Die Tabelle "Materialien" wird mit Materiallistenelementen für den Container gefüllt. Sie können ein oder mehrere Elemente in dieser Liste auswählen und auf die Schaltfläche "Hinzufügen" klicken, um sie zur Tabelle "Standort" hinzuzufügen.

Die Tabelle "Standort" stellt die Position am Container dar, an der der Defekt aufgetreten ist. Sie können optional einen Referenzbezeichner sowie die X- und Y-Position manuell eingeben, aber Sie können kein Produkt manuell eingeben. Sie können der Tabelle "Standort" Elemente manuell hinzufügen, ohne die Tabelle "Materialien" verwenden zu müssen.

Symbolleiste der Tabelle "Defekte und Reparaturen"

Die Tabelle "Defektliste" zeigt vorhandene Defekte und Reparaturen für aktuell angezeigten Container an. Die Symbolleiste "Defekttabelle" befindet sich oberhalb der Tabelle "Defektliste". Die Anzeige der Symbole erfolgt dynamisch basierend auf der aktuellen Auswahl in der Tabelle. Diese Symbolleiste enthält Optionen zum Verarbeiten von Tabellenauswahlen. Die Symbolleiste enthält z. B. auf Defekte anwendbare Optionen, wenn nur Defekte ausgewählt wurden.

Vorgehensweise zum Anzeigen von Defektinformationen eines Containers

Gehen Sie folgendermaßen vor, um die Defektinformationen für einen Container anzuzeigen:

1. Öffnen Sie im Menü Container die Seite Industriedefekt. Die Seite "Industriedefekt" wird angezeigt.
2. Wählen Sie einen Container im Container-Feld aus oder geben Sie ihn ein. Die Anwendung aktualisiert den Container-Kopf und die Auswahlfelder, sodass diese Informationen für den angegebenen Container angezeigt werden. Werte werden nur angezeigt, wenn sie für den Container eingegeben wurden.
