Job erstellen

Auf der Seite "Job erstellen" können Sie einen Ressourcenwartungs- oder Reparaturjob erstellen. Die manuelle Joberstellung kann von einem autorisierten Benutzer ausgeführt werden, z. B. von einem Systemadministrator.

Die Anwendung kann so festgelegt werden, dass automatisch Jobs erstellt werden, wenn die Ressource entweder mit Durchsatzanforderung, Wiederholungsterminanforderungen oder Datumsanforderungen konfiguriert ist und den folgenden Wartungszustand erfüllt:

• Die automatische Joberstellung für Durchsatzanforderung wird ausgelöst, wenn der Wartungsstatus "Fällig" oder "Überfällig" ist.
• Automatische Joberstellungen für Datumsanforderungen und Wiederholungsterminanforderungen werden ausgelöst, wenn der Wartungsstatus "Nur fällig" ist. (Verwenden Sie das Feld "Toleranzfrist" auf den Modellierungsseiten "Datum" und "Wiederholungsterminanforderung", um den Status "Fällig" zu aktivieren.)

Informationen zum Definieren von Durchsatzanforderung, Datumsanforderungen und Wiederholungsterminanforderungen finden Sie im Opcenter Execution Medical Device and Diagnostics Modeling-Benutzerhandbuch oder im Opcenter Execution Core Modeling-Benutzerhandbuch.

Hinweis: "Job erstellen" darf nicht für eine Ressource erstellt werden, die einer aktiven Jobauftragskombination zugewiesen ist. Zum Beispiel, Maschine A wird Jobauftrag 01 zugewiesen, der derzeit aktiv oder in Bearbeitung ist. Sie können keinen Job für Maschine A erstellen, bis der Jobauftrag abgeschlossen ist.

Automatisches Erstellen von Aufträgen

Die Anwendung verwendet die Nummerierungsregel, die dem "JobOrder_Name" bei der automatischen Auftragserstellung zugeordnet ist. Bei der manuellen Auftragserstellung kann die Nummerierungsregel verwendet werden, wenn kein Jobauftrag zugewiesen ist. Die Nummerierungsregel wird bei der Installation von Opcenter Execution Core standardmäßig festgelegt. Um die Standardeinstellungen für die Nummerierungsregel zu ändern, wechseln Sie zur Modellierungsseite "Nummerierungsregel" und wählen Sie die Modellierungsinstanz "JobOrder_Name" aus.

Definitionen der Felder auf der Seite "Job erstellen"

Diese Tabelle definiert die Felder auf der Seite "Job erstellen".

Feld

Definition

Typ

Ressource

Name der Fertigungsressource oder -ausrüstung. In diesem Zusammenhang ist dies der eindeutige Name der Ressource, für die der Job erstellt wurde.

Erforderlich

Jobauftrag

Name oder ID des Jobauftrags.

Optional

Jobmodell

Das "Jobmodell"-Objekt, auf dem der Job basiert. Das "Jobmodell"-Objekt ist das Element, in dem die Schritte konfiguriert sind.

Kontrollkästchen, das angibt, ob der einfache Modus für den Job verwendet wird. Im einfachen Modus ist die Transaktion "Jobfortschritt" der erste konfigurierte Schritt. Wenn dieser Schritt abgeschlossen ist, wechselt die Transaktion zum letzten konfigurierten Schritt.

Optional

Stage

Der aktuelle Schritt des Jobs.

Optional

Sequenzielle Reihenfolge der Stufe (Phase).

Vorgehensweise zum Erstellen eines Jobs

Gehen Sie folgendermaßen vor, um einen Job zu erstellen:

1. Öffnen Sie die Seite Job erstellen im Menü Ressource > Jobs > Jobservices. Die Seite "Job erstellen" wird angezeigt.
2. Wählen Sie das Feld Ressource aus.
3. Wählen Sie das Jobmodell aus.
4. Optional können Sie einen Techniker zuweisen, indem Sie auf Neue Zeile hinzufügen über der Tabelle Techniker klicken und einen Techniker aus der aktivierten Feldliste Techniker auswählen.
5. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie in der Befehlsleiste auf Abschicken. Die Anwendung speichert die Daten und zeigt eine Statusmeldung an.
