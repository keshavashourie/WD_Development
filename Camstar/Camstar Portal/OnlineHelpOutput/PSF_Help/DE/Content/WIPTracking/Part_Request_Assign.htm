Teileanforderung zuweisen

Die Seite "Teileanforderung zuweisen" ermöglicht es Ihnen, einem Teileanforderungsauftrag Ressourcenmaterialteile zuzuweisen. Sie können mehrmals Teilmengen zuweisen, bis die vollständige Anforderungsmenge erreicht ist.

Felddefinitionen der Seite "Teileanforderung zuweisen"

Diese Tabelle definiert die Felder auf der Seite "Teilanforderung zuweisen".

Feld

Definition

Typ

Ressource

Ausrüstungsressource, für die Sie mindestens ein Teil zuweisen.

Erforderlich

Jobauftrag

Jobauftragsnummer eines aktiven Wartungsjobs für die Ressource. Dieses Feld wird automatisch ausgefüllt, wenn die Teileanforderung mit einem Jobauftrag verknüpft ist.

Optional

Anforderungsauftrag

Anforderungsauftrag, der für die Teileressource erstellt wird.

Erforderlich

Anforderungstyp

Art der Teileanforderung – entweder Anforderung oder Rücklauf.

Nur Anzeige

Tabelle "Anforderungsauftrag: Materialteile"

Tabelle, in der die Ressourcenmaterialteile aufgelistet werden, die zur Teileanforderung gehören.

Nur Anzeige

Materialteil

Ressourcenmaterialteil, das von einem anderen Ressourcenteil verwendet wird.

Nur Anzeige

Angeforderte Teilemenge

Angeforderte Menge des Materialteils.

Nur Anzeige

Teilemenge zuweisen

Menge des zugewiesenen Materialteils.

Nur Anzeige

Tabelle "Zugewiesene Teile" (zu verbrauchen für Ressource)

Tabelle, in der Materialteilezuweisungen angezeigt werden. Eine vollständige Menge oder Teilmenge von mindestens einem Materialteil muss ausgewählt werden, damit Zuweisen möglich ist.

Erforderlich

Teil

Teil, das das angeforderte Ressourcenmaterialteil enthält.

Nur Anzeige

Materialteil

Feld zum Auswählen des angeforderten Ressourcenmaterialteils.

Nur Anzeige

Teilemenge

Verfügbare Menge des Ressourcenmaterialteils.

Nur Anzeige

Teilemenge zuweisen

Menge des Ressourcenmaterialteils, das der Anforderung zugewiesen werden soll.

Erforderlich

Autom. abschließen

Kontrollkästchen, das angibt, ob die Anwendung die erforderliche Transaktion "Teileanforderung abschließen" automatisch ausführt, nachdem die Transaktion "Teileanforderung abschließen" abgeschlossen wurde.

Optional

Ausblenden/Anzeigen von zusätzlichen Feldern

Kommentare

Zusätzliche Informationen oder Anweisungen für diese Transaktion oder für diesen Container. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Zuweisen von Materialteilen zu einer Teileanforderung

Gehen Sie folgendermaßen vor, um einer Teileanforderung Materialteile zuzuweisen:

1. Öffnen Sie die Seite "Teileanforderung zuweisen", indem Sie das Menü Ressource > Teile-Services > Teileanforderung zuweisen auswählen. Die Seite "Teileanforderung zuweisen" wird angezeigt.
2. Wählen Sie im Feld Ressource eine Ressource aus. Die Anwendung füllt die restlichen Felder auf der Seite aus.
3. Klicken Sie in der Tabelle "Zugewiesene Teile" auf Neue Zeile hinzufügen. Eine Zeile wird in der Tabelle aktiviert.
4. Wählen Sie das Teil aus.
5. Wählen Sie das Materialteil aus.
6. Geben Sie die Menge, die Sie zuweisen möchten, in das Feld Teilemenge zuweisen ein.
7. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an. Bei Bedarf wird eine zusätzliche Warnmeldung zusammen mit der Erfolgsmeldung angezeigt.
