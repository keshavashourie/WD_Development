Schneiden

Die Transaktion "Schneiden" ermöglicht das Erstellen von einem oder mehreren Zielcontainern aus einem vorhandenen Quellcontainer, der Menge1 und Menge2 erbt. Ein Quellcontainer wird in die Anzahl der Container geschnitten, die im Feld "Schnittanzahl" angegeben sind, wobei die Eigenschaften und die Historie des Quellcontainers beibehalten werden. Diese Aktivität wird häufig im Transaktionsprozess "Batterieschneiden" verwendet, bei dem eine einzelne Rolle mit der Menge 1 und möglicherweise einer bestimmten Länge produziert wird (z. B. "Menge2: 100").

Wenn das Feld "Schnittprodukt" konfiguriert ist, übernimmt der Zielcontainer das angegebene Produkt. "Schnittprodukt" und "Schnittanzahl" können auf der Seite "Produktmodellierung" definiert werden. Die automatische Generierung von Zielcontainernamen kann durch Definieren der "Schnitt-Nummerierungsregel" auf der Seite "Fabrikmodellierung" erreicht werden. Nachdem die Schneidtransaktionen ausgeführt wurden, wird der Quellcontainer automatisch geschlossen.

Beim Verwenden der Seite "Schneiden"

Der hinzugefügte Zielcontainer (Zeilen, die in der Tabelle "Zielcontainerdetails" hinzugefügt wurden) muss mit der Menge übereinstimmen, die im Feld "Schnittanzahl" angezeigt wird. Gewährleisten Sie, dass in der Tabelle "Zielcontainerdetails" ein eindeutiger Kind-Containername angegeben wird, der entweder manuell eingegeben oder automatisch von der Anwendung generiert wird. Durch das Schneiden eines Containers oder einer Menge werden weder der Quell- noch der Zielcontainer verschoben. Es impliziert auch keine Verarbeitungsaktivität (Durchsatz) für die Container.

Aktivieren Sie das Kontrollkästchen "Namen automatisch erstellen", um den Containernamen unter Verwendung der definierten Nummerierungsregeln von der Anwendung erstellen zu lassen. Beachten Sie, dass das Feld "Zielcontainer" beim Aktivieren dieses Kontrollkästchens deaktiviert wird. Ein Fehler tritt auf, wenn der Container denselben Namen wie ein vorhandener Container verwendet, selbst bei einem anderen Containerlevel.

Hinzufügen von betroffenen Containern zu Ereignissen

Die Anwendung kann Container automatisch zu Qualitätsereignissen hinzufügen, wenn Sie die Schneidtransaktion für einen Container durchführen, der mit mindestens einem Qualitätsereignis verknüpft ist. Wenn z. B. ein Quellcontainer mit einem Ereignis verknüpft ist, fügt die Anwendung alle neuen Container, die durch das Schneiden des betreffenden Quellcontainers entstehen, automatisch zum Qualitätsereignis hinzu. Ein Systemadministrator konfiguriert die Transaktion "Schneiden" in der Modellierung, um Container zu Ereignissen hinzuzufügen. Informationen zum automatischen Hinzufügen von betroffenen Containern zu Qualitätsereignissen finden Sie im Opcenter Execution Medical Device and Diagnostics Event Management-Benutzerhandbuch und im Opcenter Execution Core Event Management-Benutzerhandbuch sowie im Opcenter Execution Medical Device and Diagnostics Nonconformance Management-Benutzerhandbuch und im Opcenter Execution Core Nonconformance Management-Benutzerhandbuch.

Seite "Schneiden"

Sie können auf die Seite zugreifen, indem Sie im Menü "Container" die Option "Schneiden" auswählen.

Kommentare

Zusätzliche Informationen oder Anweisungen für diese Transaktion oder für diesen Container. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Schneiden eines Containers

Gehen Sie folgendermaßen vor, um einen Container zu schneiden:

1. Öffnen Sie die Seite Schneiden im Menü Container. Die Seite "Schneiden" wird angezeigt.
2. Wählen Sie einen Container im Container-Feld aus oder geben Sie ihn ein. Die Anwendung aktualisiert den Container-Kopf und die Auswahlfelder, sodass diese Informationen für den angegebenen Container angezeigt werden. Werte werden nur angezeigt, wenn sie für den Container eingegeben wurden.
3. Aktivieren Sie das Kontrollkästchen Namen automatisch erstellen. Klicken Sie auf Neue Zeile hinzufügen oder wählen Sie eine Zeile, um einen neuen Container zu starten. Die Anwendung füllt die Zielcontainer in der Tabelle "Zielcontainerdetails" aus.

Oder

Geben Sie einen Namen für den neuen Container in das Feld Zielcontainer ein. Die Anwendung füllt das Feld "Menge" aus. Die Anzahl der eingegebenen Zeilen muss der eingegebenen "Schnittanzahl" entsprechen.

4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. Weitere Informationen zu den optionalen Feldern finden Sie in der Tabelle der Felddefinitionen.
5. Klicken Sie in der Befehlsleiste auf Abschicken.Die Quellcontainer werden in die Zielcontainer geschnitten, die Anwendung löscht die Felder und zeigt dann eine Bestätigungsmeldung an.
