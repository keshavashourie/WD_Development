Jobfortschritt

Auf der Seite "Jobfortschritt" können Techniker einen Schritt in einem zugewiesenen Wartungs- oder Reparaturjob durchführen. "Jobfortschritt" wird verfügbar, nachdem der zugewiesene Techniker den Job bestätigt und aktiviert hat. Dies ist der Hauptdienst, der vom zugewiesenen Techniker verwendet wird für Folgendes:

• Verschieben der Ressource von einer Stufe in eine andere innerhalb des Jobmodells
• Eine Datensammlung ggf. durchführen.
• Die Anweisungen und Prüfungen ausführen, die in der Prüfliste aufgelistet sind.

Auf der Seite "Jobfortschritt" erhält der Techniker die Möglichkeit, die Transaktion "Autom. Abstempelung" automatisch auszulösen. Wenn diese Option ausgewählt ist, stempelt das System den ausführenden Techniker automatisch vom Job ab, wenn er mit der aktuellen Stufe fertig ist.

Hinweis: Die Seite "Jobfortschritt" unterstützt derzeit keine SPC-Datensammlung. Alle Felder, Checklisten und Tabellen, die die SPC-Datensammlung unterstützen, sind nicht verfügbar.

Felddefinitionen der Seite "Jobfortschritt"

Diese Tabelle definiert die Felder auf der Seite "Jobfortschritt".

Feld

Definition

Typ

Ressource

Name der Fertigungsressource oder -ausrüstung. In diesem Zusammenhang ist dies der eindeutige Name der Ressource, für die der Job erstellt wurde.

Nachdem eine Ressource ausgewählt wurde, füllt die Anwendung das Popup "Materialteile" aus, in dem die Liste der verknüpften Ressourcenteile angezeigt wird.

Erforderlich

Jobauftrag

Name oder ID des Jobauftrags. Die in diesem Feld "Jobauftrag" angezeigten Werte hängen vom ausgewählten Ressourcenfeld ab, das im Modellierungsobjekt "Jobauftrag" konfiguriert werden kann.

Optional

Jobmodell

Das "Jobmodell"-Objekt, auf dem der Job basiert. Das "Jobmodell"-Objekt ist das Element, in dem die Schritte konfiguriert sind. Dieses Feld wird basierend auf den vorherigen Feldern automatisch ausgefüllt.

Nur Anzeige

Jobtyp

Gibt den Typ der Arbeit an, die für die Ressource ausgeführt werden muss, z. B. "Normal", "Vorbeugende Wartung" und "Reparatur". Dieses Feld wird basierend auf den vorherigen Feldern automatisch ausgefüllt.

Nur Anzeige

Einfacher Modus

Im einfachen Modus ist die Transaktion "Jobfortschritt" der erste konfigurierte Schritt. Wenn dieser Schritt abgeschlossen ist, wechselt die Transaktion zum letzten konfigurierten Schritt. Das Kontrollkästchen "Einfacher Modus" kann auf den Seiten "Jobmodell" und "Job erstellen" aktualisiert werden.

Optional

Stage

Jobschritt. In diesem Zusammenhang ist dies der aktuelle Schritt des Jobs.

Optional

Entwicklung der Umformstufen

Sequenzielle Reihenfolge der Stufe (Phase).

Optional

Zu Stufe

Listet alle Schritte auf, zu denen der Techniker vom aktuellen Schritt gelangen kann. Diese "Weiter zu"-Schritte müssen im Jobmodell konfiguriert sein, damit sie in diesem Listenfeld angezeigt werden.

Optional

Zu Stufe: Reihenfolge

Sequenzielle Reihenfolge der ausgewählten "Zu Stufe". Wird automatisch gefüllt, wenn der Benutzer "Zu Stufe" auswählt.

Optional

Symptomcode

Feld zum Auswählen eines Codes, der das Symptom kennzeichnet, das ein Hinweis darauf ist, dass die Ressource repariert werden muss.

Nach Auswahl eines Symptomcodes füllt die Anwendung das Symbol "Symptomcode nach Ressource" aus, woraufhin das Popup "Jobcodes nach Ressourcen" angezeigt wird. Das Popup zeigt die Anzahl der Symptomcodes basierend auf der Ressource an.

Erforderlich, sofern konfiguriert oder der Job im einfachen Modus verarbeitet wird.

Ursachencode

Feld zum Auswählen eines Codes, der die Ursache für das Problem kennzeichnet, das es für die Ressource gibt.

Nachdem Symptomcode und Ursachencode ausgewählt wurden, füllt die Anwendung das Symbol "Ursachencode nach Ressource" aus, woraufhin das Popup "Jobcodes nach Ressourcen" angezeigt wird. Das Popup zeigt die Anzahl der Symptomcodes und Ursachencodes basierend auf der Ressource an.

Erforderlich, sofern konfiguriert oder der Job im einfachen Modus verarbeitet wird.

Reparaturcode

Feld zum Auswählen eines Codes, der die Reparatur kennzeichnet, die für die Ressource ausgeführt wird.

Nachdem die Felder "Symptomcode", "Ursachencode" und "Reparaturcode" ausgewählt wurden, füllt die Anwendung das Symbol "Reparaturcode nach Ressource" aus, woraufhin das Popup "Jobcodes nach Ressourcen" angezeigt wird. Das Popup zeigt die Anzahl von Symptomcodes, Ursachencodes und Reparaturcodes basierend auf der Ressource an.

Erforderlich, sofern konfiguriert oder der Job im einfachen Modus verarbeitet wird.

Autom. Abstempelung

Kontrollkästchen, das festlegt, ob die Anwendung Sie automatisch von dem Job abstempeln soll, wenn Sie den aktuellen Schritt abgeschlossen haben.

Optional

Techniker- und Wartungsinformationen & anzeigen/ausblenden

Vorgehensweise zum Abschließen einer Jobstufe

Gehen Sie folgendermaßen vor, um eine Jobphase auf der Seite "Jobfortschritt" abzuschließen:

1. Öffnen Sie die Seite Jobfortschritt im Menü Ressource > Jobs > Jobservices. Die Seite "Jobfortschritt" wird angezeigt.
2. Wählen Sie das Feld Ressource aus.
3. Wählen Sie optional das Feld Jobauftrag aus. Die Anwendung füllt die Werte in den Feldern "Jobmodell" und "Jobtyp" automatisch aus.
4. Führen Sie für jede Checkliste, die in der Tabelle "Checkliste" aufgeführt ist, folgende Schritte aus:
a. Aktivieren Sie das Kontrollkästchen für die Tabelle. Die Zeile wird blau hervorgehoben
b. Scrollen Sie unter die Tabelle "Checkliste", damit alle erforderlichen Datensammlungen zu sehen sind. Die Datensammlungspunkte werden unter der Tabelle angezeigt.
c. Geben Sie jeden erforderlichen Datenpunkt ein.
d. Klicken Sie auf Jobfortschritt. Die Hervorhebungsfarbe der ausgewählten Checklistenzeile wechselt zu grün.
5. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie in der Befehlsleiste auf Abschicken. Die Anwendung speichert die Daten und zeigt eine Statusmeldung an.
