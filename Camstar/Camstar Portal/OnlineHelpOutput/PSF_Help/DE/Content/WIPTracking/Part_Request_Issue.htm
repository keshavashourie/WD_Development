Teileanforderung: Verbrauch

Auf der Seite "Teileanforderung: Verbrauch" kann ein Ressourcen-Jobtechniker angeforderte Teile für die Ausrüstung verbrauchen (oder laden).

Der Anforderungsstatus wird zu "Verbraucht" aktualisiert. Nach der Ausführung der Transaktion "Teileverbrauch" wird die entsprechende Anforderung nicht mehr in den Ansichten (oder im Fenster) "Lageranfragen" und "Technikeranfragen" aufgelistet.

Vor dem Verbrauchen von Teilen

Alle angeforderten Teile müssen zugewiesen sein und "Teileanforderung abschließen" muss ausgeführt werden, bevor Sie ein Teil verbrauchen können.

Felddefinitionen der Seite "Teileanforderung abschließen"

Diese Tabelle definiert die Felder auf der Seite "Teileanforderung abschließen".

Feld

Definition

Typ

Ressource

Ausrüstungsressource oder -maschine, die für die Anforderung angegeben ist.

Erforderlich

Jobauftrag

Jobauftragsnummer eines aktiven Wartungsjobs für die Ressource. Diese Nummer wird angezeigt, wenn die Teileanforderung mit einem Jobauftrag verknüpft ist. Dieses Feld wird automatisch ausgefüllt, wenn die Teileanforderung mit einem Jobauftrag verknüpft ist.

Optional

Anforderungsauftrag

Anforderungsauftrag, der für die Teileressource erstellt wird. Dieses Feld wird automatisch ausgefüllt, wenn Sie das vorherige Ressourcenfeld auswählen.

Erforderlich

Anforderungstyp

Art der Teileanforderung – entweder Anforderung oder Rücklauf. Wird automatisch ausgefüllt. Dieses Feld wird automatisch ausgefüllt, wenn Sie das vorherige Ressourcenfeld auswählen.

Nur Anzeige

Tabelle "Zugewiesene Teile" (zu verbrauchen für Ressource)

Tabelle, in der die Ressourcenmaterialteile aufgelistet werden, die zur Teileanforderung gehören.

Nur Anzeige

Teil

Name oder ID des Ressourcenteils.

Nur Anzeige

Teilemenge

Zu verbrauchende Menge des Materialteils.

Nur Anzeige

Materialteil

Ressourcenmaterialteil, das von einem anderen Ressourcenteil verwendet wird.

Nur Anzeige

Zu ersetzendes Teil

Name des vorhandenen Teils, das in die Ressource geladen ist und durch das zu verbrauchende Teil ersetzt wird. Die Anwendung löst eine "Teileanforderung"-Transaktion mit dem Typ "Rücklauf" aus, wenn in "Zu ersetzendes Teil" ein Name angegeben ist.

Optional

Zu ersetzendes Teil: Menge

Menge, die durch das zu verbrauchende Teil ersetzt wird. Der hier angegebene Wert muss größer gleich 1 und kleiner gleich der "Teilemenge" sein.

Optional

Ausblenden/Anzeigen von zusätzlichen Feldern

Kommentare

Zusätzliche Informationen oder Anweisungen für diese Transaktion oder für diesen Container. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Verbrauchen einer Teileanforderung

Gehen Sie folgendermaßen vor, um eine Teileanforderung zu senden:

1. Öffnen Sie die Seite "Teileanforderung abschließen", indem Sie das Menü Ressource > Teile-Services > Teileanforderung: Verbrauch auswählen. Die Seite "Teileanforderung: Verbrauch" wird angezeigt.
2. Wählen Sie im Feld Ressource eine Ressource aus. Die Anwendung füllt die restlichen Felder auf der Seite aus.
3. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
4. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
