Teil erstellen

Auf der Seite "Teil erstellen" können Sie ein Teil erstellen, das zum Erzeugen oder Verarbeiten von Ressourcenmaterialteilen erforderlich ist. Alle Teile müssen mit einem Ressourcenmaterialteil verknüpft sein, das dazu beiträgt, gemeinsame Merkmale wie Wartungsanforderungen zu definieren. Erzeugte Teile können über die Modellierungsseite "Teil" weiter geändert oder gelöscht werden.

Um über die Menüleiste auf die Seite "Teil erstellen" zuzugreifen, wählen Sie "Ressource" > "Teile-Services" > "Teil erstellen" aus.

Felddefinitionen der Seite "Teil erstellen"

Diese Tabelle definiert die Felder auf der Seite "Teil erstellen".

Feld

Definition

Typ

Teilename

Eindeutiger Name für das neue Teil.

Erforderlich

Teilefamilie

Teilekategorie, zu der dieses Teil gehört. Die Teilefamilie hilft, ähnliche Zeichen oder Wartungsanforderungen auf Teile anzuwenden.

Optional

Ablaufdatum

Datum, zu dem das Teil abläuft.

Erforderlich

Fabrik

Produktionsfabrik.

Optional

Lieferant

Name oder ID des Lieferanten des Teils.

Optional

Lieferantenmodell

Vom Lieferanten zugewiesene Modellnummer für das Teil.

Optional

Lieferantenseriennummer

Vom Lieferanten zugewiesene Seriennummer für das Teil.

Optional

Status

Anfangsstatus, um das neue Teil zuzuweisen.

Optional

Materialteil

Ressourcenmaterialteil, das für das Teil verwendet wird, das Sie erstellen.

Optional

Physischer Ort

Physischer Ort des Teils. Beispiel: Lager A.

Optional

Physische Position

Position des Teils innerhalb des physischen Orts. Beispiel: Baugruppenträger 001.

Optional

Teilemenge

Menge des Ressourcenmaterialteils.

Erforderlich

Zusätzliche Felder anzeigen/ausblenden

Optionale Felder sind standardmäßig ausgeblendet, wenn die Anwendung eine Seite oder ein Popup anzeigt. Durch Klicken auf die Steuerung "Anzeigen" werden die Felder angezeigt. Durch Klicken auf die Steuerung "Verstecken" werden die Felder ausgeblendet.

 

Kommentare

Zusätzliche Informationen oder Anweisungen für diese Transaktion oder für diesen Container. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Erstellen eines Teils

Gehen Sie folgendermaßen vor, um ein Teil zu erstellen:

1. Öffnen Sie die Seite Teil erstellen über das Menü Ressource > Teile-Services > Teil erstellen. Die Seite "Teil erstellen" wird angezeigt.
2. Geben Sie einen Namen in das Feld Teil erstellen ein.
3. Wählen Sie das Materialteil aus, wenn es nicht bereits angezeigt wird.
4. Sie können bei Bedarf die Teilemenge eingeben oder ändern.
5. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie in der Befehlsleiste auf Abschicken. Die Anwendung speichert die Daten und zeigt eine Statusmeldung an.
