SPC-Tester

Siemens stellt einen SPC-Tester bereit, mit dem Sie die in der Anwendung enthaltenen Muster-Charts und -daten testen können. Er erlaubt Ihnen außerdem, Ihre Einstellungen zu prüfen, nachdem Sie Charts und erforderliche Komponenten konfiguriert haben.

Siemens bietet Muster-Charts und Daten, die über das Management Studio geladen werden können.

Beim Verwenden der Seite "SPC-Tester"

Sie müssen einen Container, ein SPC-Chart, eine SPC-Chartgruppe oder eine Datensammlung auswählen. Alle anderen Felder sind Optional.

Wenn Sie einen Container auswählen, werden die Felder "SPC-Chart", "SPC-Chartgruppe" und "Datensammlung" automatisch gefiltert. Wenn ein Container ausgewählt ist, werden in den Feldern nur Werte angezeigt, die mit dem ausgewählten Container verbunden sind.

Sie können zur Laufzeit Parameter übergeben, um neue Parameter hinzuzufügen oder vorhandene Parameter in der Tabelle für Nutzerparameter ändern und entfernen. Benutzeroberflächenparameter, die Sie auf dieser Seite eingeben, überschreiben die im SPC-Chartobjekt festgelegten Parameter. Informationen zum Definieren von Parametern für SPC-Charts finden Sie unter "Definieren von SPC-Charts".

Hinweis: Dynamische Werte können nicht auf der SPC-Testerseite verwendet werden.

Testdaten können über das DB-Update im Management Studio geladen werden. Siemens empfiehlt, dass Sie diese Daten nur in einer Entwicklungsumgebung laden und nicht in der Produktionsumgebung.

Muster-Makros und Muster-Charts verweisen auf die aus dem DB-Update geladenen Daten. Pfade in den Muster-Charts verweisen auf standardmäßige Installationsverzeichnisse. Sie müssen die Pfade aktualisieren, wenn Sie nicht die standardmäßigen Installationsverzeichnisse verwendet haben.

Auch müssen Sie vor der Verwendung der Tester-Seite die Muster-Makros mit Authentifizierungs-Infos für Ihr ODBC aktualisieren.

UI-Parameter, die Sie auf dieser Seite eingeben, überschreiben die im "SPC-Chart"-Objekt festgelegten.

Felddefinitionen der Seite "SPC-Tester"

Diese Tabelle definiert die Felder auf der Seite "SPC-Tester".

Feld

Definition

Typ

Container

Name oder ID des Containers. Werte in den Feldern "SPC-Chart" und "SPC-Chartgruppe" werden nach dem Feld "Container" gefiltert.

Optional

SPC-Chart

Individuelle SPC-Charts, wie in der Modellierung definiert. Die verfügbaren Werte werden gefiltert, wenn das Feld "Container" ausgefüllt wird.

Anmerkung: Dieses Feld ist nicht erforderlich, wenn "SPC-Chartgruppe" oder "Datensammlung" ausgefüllt wird.

Erforderlich

SPC-Chart-Gruppe

Gruppe von SPC-Charts, wie in der Modellierung definiert. Die verfügbaren Werte werden gefiltert, wenn das Feld "Container" ausgefüllt wird.

Anmerkung: Dieses Feld ist nicht erforderlich, wenn "SPC-Chart" oder "Datensammlung" ausgefüllt ist.

Erforderlich

Datensammlung

Benutzerdatensammlung-Definitionen, wie in der Modellierung definiert. Die verfügbaren Werte werden gefiltert, wenn das Feld "Container" ausgefüllt wird.

Anmerkung: Dieses Feld ist nicht erforderlich, wenn "SPC-Chart" oder "SPC-Chartgruppe" ausgefüllt wird.

Erforderlich

Versuche OCAPs an außer-Kontrolle-Charts

Mit diesem Ankreuzfeld kann das Chart die Out-of-Control-Aktionen auslösen, wenn eine Verletzung auftritt. Wenn es nicht mit einem Häkchen versehen ist, werden die Out-des-Control-Aktionen nicht ausgelöst, auch wenn eine Verletzung auftritt.

Optional

Anzuhaltender Container

Liste von Containern, die angehalten werden können, wenn eine Verletzung auftritt.

Optional

Ressource (in Zustandsänderung)

Ressource im Zusammenhang mit einer Verletzung, die aus dem Verkehr gezogen oder auf einen anderen Status geändert wird.

Optional

Löschen der Chart-Dateien nach dem Ansehen

Wenn Sie dieses Ankreuzfeld mit einem Häkchen versehen, werden die Charts automatisch gelöscht, nachdem Sie sie angesehen haben, anstatt dass eine manuelle Löschung zu einem anderen Zeitpunkt erforderlich wäre.

Optional

UI-Parameter

Es können Zeilen hinzugefügt werden, um Parameter an das Makro weiterzugeben, das Chart erzeugt.

Optional

Vorgehensweise zum Verwenden der Seite "SPC-Tester"

Gehen Sie folgendermaßen vor, um die Seite "SPC-Tester" verwenden:

1. Wählen Sie SPC-Tester im Menü SPC. Die Seite "SPC-Tester" wird angezeigt.
2. Wählen Sie einen Container, ein SPC-Chart, eine SPC-Chartgruppe oder eine Datensammlung aus. Nur eines ist erforderlich.
3. Wählen Sie mindestens ein optionales Feld aus, um genauer zu definieren, welche Charts generiert werden sollen.
4. Klicken Sie auf Einreichen. Die ausgewählten Charts wird/werden angezeigt.
