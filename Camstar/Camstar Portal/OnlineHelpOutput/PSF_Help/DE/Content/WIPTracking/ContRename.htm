Container umbenennen

Mit der Transaktion "Container umbenennen" können Sie einen Container umbenennen.

Hinweis: Informationen zum gleichzeitigen Umbenennen mehrerer Container finden Sie unter "Mehrere Container umbenennen".

Beim Umbenennen eines Containers

Alle Anzeigefelder auf der Seite "Container umbenennen" sind leer, bis ein Container ausgewählt wird.

Es kann nur ein Container pro Transaktion umbenannt werden. Sie müssen den neuen Containernamen eingeben. Die Anwendung zeigt eine Fehlermeldung an, wenn Sie auf die Schaltfläche "Abschicken" klicken, ohne den neuen Containernamen eingegeben zu haben.

Die Anwendung überprüft, ob der angegebene Containername verfügbar ist und nicht bereits verwendet wird.

Das Umbenennen eines Containers hat keinen Einfluss auf verbundene Kind- oder Eltern-Container. Sie bleiben mit dem umbenannten Container verbunden.

Seite "Container umbenennen"

Sie können über das Menü "Container" auf die Seite "Container umbenennen" zugreifen. Auf der Seite "Container umbenennen" können Sie einen Container scannen oder eingeben und ihn umbenennen.

Felddefinitionen der Seite "Container umbenennen"

Diese Tabelle definiert die Felder auf der Seite "Container umbenennen".

Feld

Definition

Typ

Containerinformationen

Kopf mit dem Containernamen und Informationen zu diesem Container. Sie müssen auf einer Transaktionsseite einen Container auswählen oder eingeben. Weitere Informationen finden Sie unter "Containerinformationen".

Erforderlich/ Nur Anzeige

Neuer Containername

Neuer Name, der dem ausgewählten Container zugewiesen werden soll. Das Feld akzeptiert maximal 30 Zeichen. Die Anwendung zeigt eine Fehlermeldung an, wenn die Länge des Namens 30 Zeichen überschreitet.

Erforderlich

Primäre Seriennummer

Die einem Container zugeordnete Seriennummer.

Hinweis: Dieses Feld wird nur angezeigt, wenn Opcenter EX EL installiert ist.

Optional

Seriennummer 2

Zusätzliche Seriennummer, die mit einem Container verknüpft werden kann.

Hinweis: Dieses Feld wird nur angezeigt, wenn Opcenter EX EL installiert ist.

Optional

Seriennummer 3

Zusätzliche Seriennummer, die mit einem Container verknüpft werden kann.

Hinweis: Dieses Feld wird nur angezeigt, wenn Opcenter EX EL installiert ist.

Optional

Zusätzliche Felder anzeigen/ausblenden

Optionale Felder sind standardmäßig ausgeblendet, wenn die Anwendung eine Seite anzeigt. Durch Klicken auf das Steuerelement für Anzeigen werden die Felder angezeigt. Durch Klicken auf die Steuerung "Verstecken" werden die Felder ausgeblendet.

  

Kommentare

Zusätzliche Informationen oder Anweisungen für diese Transaktion oder für diesen Container. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Umbenennen eines Containers

Gehen Sie folgendermaßen vor, um einen Container umzubenennen:

1. Öffnen Sie die Seite Container umbenennen im Menü Container. Die Seite "Container umbenennen" wird angezeigt.
2. Wählen Sie einen Container im Container-Feld aus oder geben Sie ihn ein. Die Anwendung aktualisiert den Container-Kopf und die Auswahlfelder, sodass diese Informationen für den angegebenen Container angezeigt werden.Werte werden nur angezeigt, wenn sie für den Container eingegeben wurden.
3. Geben Sie einen neuen Namen für den ausgewählten Container in das Feld Neuer Containername ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. Weitere Informationen zu den optionalen Feldern finden Sie in der Tabelle der Felddefinitionen.
5. Klicken Sie in der Befehlsleiste auf Abschicken, um den Container umzubenennen. Die Anwendung zeigt eine Statusmeldung an, die bestätigt, dass der Container umbenannt wurde.
