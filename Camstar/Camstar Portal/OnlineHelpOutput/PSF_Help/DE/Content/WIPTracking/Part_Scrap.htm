Teileausschuss

Die Seite "Teileausschuss" erlaubt es Ihnen, eine Menge eines Teils als Ausschuss festzulegen. Die Gesamtzahl des Teils wird abgezogen, sobald von dieser Seite aus eine Menge abgeschickt wird. Die Anwendung rangiert das Teil automatisch aus, sobald die gesamte Menge als Ausschuss festgelegt wurde.

Hinweis: Teileausschuss ist auch als Popup auf der Seite "Teilewartung" verfügbar.

Felddefinitionen der Seite "Teileausschuss"

Diese Tabelle definiert die Felder auf der Seite "Teileausschuss".

Zusätzliche Felder anzeigen

Optionale Felder sind standardmäßig ausgeblendet, wenn die Anwendung eine Seite oder ein Popup anzeigt. Durch Klicken auf die Steuerung "Anzeigen" werden die Felder angezeigt. Durch Klicken auf die Steuerung "Verstecken" werden die Felder ausgeblendet.

 

Kommentare

Zusätzliche Informationen oder Anweisungen für diese Transaktion oder für diesen Container. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Festlegen einer Teilemenge als Ausschuss

Gehen Sie folgendermaßen vor, um eine Teilemenge als Ausschuss festzulegen:

1. Öffnen Sie die Seite Teileausschuss über das Menü Ressource > Teile-Services > Teileausschuss. Das Popup "Teileausschuss" wird angezeigt.
2. Wählen Sie im Feld Teil ein Teil aus. Die Anwendung füllt die schreibgeschützten Felder aus.
3. Geben Sie die Menge, die Sie als Ausschuss festlegen möchten, in das Feld Ausschussmenge ein.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie in der Befehlsleiste auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an. Wurde die gesamte Menge des Teils als Ausschuss festgelegt, gibt die Meldung an, dass das Teil ausrangiert wurde.
