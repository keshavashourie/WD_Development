Beschreiben von UDI-Komponenten

Eine UDI besteht aus zwei Teilen: einer Gerätekennung (Device Identifier, DI) und einer Produktionskennung (Production Identifier, PI). Beide Teile sind im UDI-Format enthalten.

Gerätekennung

Die Gerätekennung ist ein statischer Code, mit dem der Hersteller sowie die Marke und das Modell eines Geräts identifiziert werden. Sie wird von einer von der FDA zugelassenen Stelle zugewiesen. Informationen zum Definieren von Gerätekennungen finden Sie im Opcenter Execution Medical Device and Diagnostics Modeling-Benutzerhandbuch und im Opcenter Execution Core Modeling-Benutzerhandbuch.

Produktionskennung

Die Produktionskennung ist ein variabler Code, der vom Gerätehersteller erstellt wird. Er identifiziert folgende Angaben:

• Seriennummer
• Losnummer
• Ablaufdatum
• Herstellung-Datum

Informationen zur Vorgehensweise beim Definieren von Produktionskennungen finden Sie im Opcenter Execution Medical Device and Diagnostics Modeling-Benutzerhandbuch und im Opcenter Execution Core Modeling-Benutzerhandbuch.

UDI-Format

Eine UDI muss sowohl maschinenlesbar als auch für Menschen lesbar sein. In der Regel handelt es sich um einen Strichcode, unter dem alphanumerische Informationen gedruckt sind. Im typischen UDI-Format ist die Gerätekennung zuerst aufgelistet, gefolgt von der Produktionskennung am Ende.
