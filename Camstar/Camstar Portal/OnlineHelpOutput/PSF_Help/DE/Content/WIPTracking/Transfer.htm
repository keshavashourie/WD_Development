Container transferieren

Die Transaktion "Transferieren" erlaubt es Ihnen, einen Container zu einem beliebigen Schritt in einem beliebigen Arbeitsplan abzumelden. Die Transaktion "Transferieren" ähnelt der Transaktion "Abmelden - nicht standardmäßig", außer dass bei einem Transfer sämtliche Anmeldeanforderungen für eine Operation umgangen werden.

Beim Transferieren eines Containers

Alle Anzeigefelder sind auf der Seite "Transferieren" leer, bis ein Container ausgewählt wird. Das Dropdown-Feld "Container" listet alle Container auf, die übertragen werden können. Wenn jedoch die Einstellung der Linienzuordnung konfiguriert ist, werden in der Dropdown-Liste "Container" Listen von Containern angezeigt, die auf dem ausgewählten Arbeitsbereich, der Operation oder dem Spez.-Wert basieren. Sie können den Containerkopf oben auf der Seite auf den aktuellen Linienzuordnungsstatus prüfen. Im Folgenden wird erläutert, wie im Feld "Los" Informationen basierend auf den Einstellungen für die Linienzuordnung angezeigt werden:

• Wenn ein Arbeitsbereich konfiguriert ist, zeigt das Feld verfügbare Container innerhalb des ausgewählten Arbeitsbereichs an.
• Wenn eine Operation konfiguriert ist, zeigt das Feld die verfügbaren Container an, die der ausgewählten Operation zugewiesen sind.
• Wenn ein Spez.-Wert konfiguriert ist, zeigt das Feld die verfügbaren Container an, die dem ausgewählten Spez.-Wert zugewiesen sind.
• Wenn "Operation" und "Spez." konfiguriert sind, zeigt das Feld die verfügbaren Container an, die sowohl "Operation" als auch "Spez." zugewiesen sind.

Weitere Informationen finden Sie unter "Einstellungen der Linienzuordnung".


Anzeigefelder werden im Popup "Transferieren" automatisch gefüllt. Informationen über das Ausführen einer Transaktion über eine Seite oder ein Popup finden Sie unter "Verwenden von Transaktionsseiten und Popups".

Die Anwendung zeigt einen Standardwert im Feld "Ressource" an, wenn eine dieser Bedingungen zutrifft:

• Für den aktuellen Schritt des Containers war ein Anmelden erforderlich, und der Benutzer, der den Container angemeldet hat, hat eine Ressource angegeben.

Oder

• Eine Ressource wurde angegeben, als der Container gestartet wurde, und der Transfer ist die erste Transaktion (mit Angabe einer Ressource), die Sie nach dem Start des Containers durchführen.

Sie können, falls erforderlich, eine andere Ressource auswählen.

Seite "Transferieren"

Sie können über das Menü "Container" auf die Seite "Transferieren" zugreifen. Die Seite "Transferieren" ermöglicht es Ihnen, den Container einzugeben oder auszuwählen, den Sie zu einem Schritt in einem Arbeitsplan transferieren möchten.

Hinweis: Die Seite "Transferieren" ist eventuell auch als Popup verfügbar, wenn die Transaktion "Container transferieren" als verfügbare Aktion auf einer anderen Seite konfiguriert wurde (z. B. "Containersuche").

Felddefinitionen der Seite und des Popups "Transferieren"

Diese Tabelle definiert die Felder auf der Seite und im Popup "Transferieren".

Feld

Definition

Typ

Containerinformationen

Kopf mit dem Containernamen und Informationen zu diesem Container. Sie müssen einen Container auf einer Transaktionsseite auswählen oder eingeben. Alle Informationen in einem Transaktionen-Popup sind schreibgeschützt. Weitere Informationen finden Sie unter "Containerinformationen".

Erforderlich/ Nur Anzeige

Ressource

Ressource, die den Container im aktuellen Schritt bearbeitet hat. Sie können eine andere Ressource auswählen, wenn die Anwendung bereits standardmäßig eine angezeigt. Wenn Sie die Ressource in diesem Schritt angeben, bevor Sie den Container abmelden, sorgt das für Nachverfolgbarkeit.

Welche Ressourcenwerte zur Auswahl stehen, hängt von der Ressourcengruppe ab, die dem Schritt zugewiesen wurde (Spez.). Wenn der Spezifikation keine Ressourcengruppe zugewiesen wurde, stehen alle definierten Ressourcen zur Auswahl.

Optional

Zu Arbeitsplan

Ziel-Arbeitsplan und Schritte. Die Schritte werden angezeigt, wenn Sie den Arbeitsplan erweitern. Die Anwendung verschiebt den Container in den nächsten Schritt im aktuellen Arbeitsplan, es sei denn, Sie geben hier einen anderen Arbeitsplan oder Schritt an.

Optional

Zu Schritt

Schritt im Ziel-Arbeitsplan. Die Anwendung füllt dieses Feld, wenn Sie einen Schritt (Spez.) aus dem erweiterten Arbeitsplan im Feld "Zu Arbeitsplan" auswählen.

Nur Anzeige

Zusätzliche Felder anzeigen/ausblenden

Optionale Felder sind standardmäßig ausgeblendet, wenn die Anwendung eine Seite oder ein Popup anzeigt. Durch Klicken auf die Steuerung "Anzeigen" werden die Felder angezeigt. Durch Klicken auf die Steuerung "Verstecken" werden die Felder ausgeblendet.

  

Zu Standort

Standort, an den der Container im nächsten Schritt zur Bearbeitung bewegt wird. Ein Standort kann eine ganze Fabrik, ein Bereich einer Fabrik oder so spezifisch wie ein Regal-Identifikator sein. Standorte werden innerhalb des Fabrik-Objekts in der Modellierung definiert.

Hinweis: Dieses Feld ist standardmäßig ausgeblendet.

Optional

Kommentare

Zusätzliche Informationen oder Anweisungen für diese Transaktion oder für diesen Container. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Transferieren eines Containers zu einem beliebigen Schritt in einem Arbeitsplan

Gehen Sie folgendermaßen vor, um einen Container zu einem beliebigen Schritt in einem Arbeitsplan zu transferieren:

1. Öffnen Sie die Seite Transferieren im Menü Container. Die Seite "Transferieren" wird angezeigt.
2. Wählen Sie einen Container im Container-Feld aus oder geben Sie ihn ein. Die Anwendung aktualisiert den Container-Kopf und die Auswahlfelder, sodass diese Informationen für den angegebenen Container angezeigt werden. Werte werden nur angezeigt, wenn sie für den Container eingegeben wurden.
Hinweis: Die Anwendung füllt das Feld "Container" und den Container-Kopf automatisch, wenn Sie von einer anderen Fertigungsseite auf das Popup "Transferieren" zugreifen.
3. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. Weitere Informationen zu den optionalen Feldern finden Sie in der Tabelle der Felddefinitionen.
4. Klicken Sie auf Transferieren. Eine Statusmeldung wird angezeigt, die bestätigt, dass der Container transferiert wurde.
