Job bestätigen

Die Seite "Job bestätigen" ermöglicht es einem Techniker, einen zugewiesenen Ressourcenwartungs- oder Reparaturjob zu bestätigen. Dies weist darauf hin, dass der Techniker die Auftragszuweisung kennt.

Definitionen der Felder auf der Seite "Job bestätigen"

Diese Tabelle definiert die Felder auf der Seite "Job bestätigen".

Feld

Definition

Typ

Ressource

Name der Fertigungsressource oder -ausrüstung. In diesem Zusammenhang ist dies der eindeutige Name der Ressource, für die der Job erstellt wurde.

Nachdem eine Ressource ausgewählt wurde, füllt die Anwendung das Popup "Materialteile" aus, in dem die Liste der verknüpften Ressourcenteile angezeigt wird.

Erforderlich

Jobauftrag

Name oder ID des Jobauftrags. Werte, die in diesem Feld "Jobauftrag" angezeigt werden, werden basierend auf dem ausgewählten Feld "Ressource" ausgefüllt, das im Modellierungsobjekt "Jobauftrag" konfiguriert werden kann.

Optional

Jobmodell

Das "Jobmodell"-Objekt, auf dem der Job basiert. Das "Jobmodell"-Objekt ist das Element, in dem die Schritte konfiguriert sind. Dieses Feld wird basierend auf den vorherigen Feldern automatisch ausgefüllt.

Nur Anzeige

Jobtyp

Gibt den Typ der Arbeit an, die für die Ressource ausgeführt werden muss, z. B. "Normal", "Vorbeugende Wartung" und "Reparatur". Dieses Feld wird basierend auf den vorherigen Feldern automatisch ausgefüllt.

Nur Anzeige

Einfacher Modus

Im einfachen Modus ist die Transaktion "Jobfortschritt" der erste konfigurierte Schritt. Wenn dieser Schritt abgeschlossen ist, wechselt die Transaktion zum letzten konfigurierten Schritt. Das Kontrollkästchen "Einfacher Modus" kann auf den Seiten "Jobmodell" und "Job erstellen" aktualisiert werden.

Nur Anzeige

Stage

Jobschritt. In diesem Zusammenhang ist dies der aktuelle Schritt des Jobs.

Nur Anzeige

Entwicklung der Umformstufen

Sequenzielle Reihenfolge der Stufe (Phase).

Nur Anzeige

Erwartetes Startdatum

Feld, das angibt, für wann der Techniker den Start des Jobs plant.

Optional

Geschätzte Dauer (Tage)

Feld, das angibt, wie lange der Job vermutlich dauert, bis die Stufen abgeschlossen sind.

Optional

Autom. Anstempelung

Kontrollkästchen, um zu bestimmen, ob die Anwendung Sie automatisch am Job anstempelt. Der Jobstatus wird bei Auswahl auf "IN BEARBEITUNG" geändert.

Optional

Techniker- und Wartungsinformationen & anzeigen/ausblenden

Schaltfläche, über die die Tabellen "Techniker" und "Wartungsstatus" ausgeblendet oder angezeigt werden. Es ist hilfreich, Tabellen zu reduzieren, um Checklisten oder Datensammlungen für den Jobschritt anzuzeigen.

Tabelle "Techniker"

Tabelle zum Zuweisen von Technikern zum erstellten Job.

Nur Anzeige

Techniker

Einzelne oder Gruppe von Personen, die dem erstellten Job zugewiesen sind.

Nur Anzeige

Anzahl bestätigen

Gibt an, wie oft der Techniker den Job bestätigt hat.

Nur Anzeige

Anstempelungsanzahl

Zahl, die angibt, wie oft der Techniker angestempelt hat.

Nur Anzeige

Tabelle "Wartungsstatus"

Tabelle, die die Wartungsfelder enthält, die für die Ressource konfiguriert sind.

Nur Anzeige

Wartungsanforderung

Name der erforderlichen Wartung für die Ressource.

Nur Anzeige

Wartungsendedatum

Datum, an dem die Wartung abgeschlossen wurde, falls zutreffend.

Nur Anzeige

Nächstes Fälligkeitsdatum

Nächstes Fälligkeitsdatum für die Wartung, falls zutreffend.

Nur Anzeige

Zusätzliche Felder anzeigen/ausblenden

Kommentare

Zusätzliche Informationen oder Anweisungen für diese Transaktion oder für diesen Container. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Bestätigen eines Jobs

Gehen Sie folgendermaßen vor, um einen Job zu bestätigen:

1. Öffnen Sie die Seite Job bestätigen im Menü Ressource > Jobs > Jobservices. Die Seite "Job bestätigen" wird angezeigt.
2. Wählen Sie das Feld Ressource aus. Die Anwendung füllt die Felder auf der Seite aus, wenn sie einen Job für die Ressource findet.
3. Sie können optional das Kontrollkästchen Autom. Anstempelung auswählen, damit die Anwendung den Job automatisch anstempelt und das manuelle Ausführen der Transaktion "Job anstempeln" umgeht.
4. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie in der Befehlsleiste auf Abschicken. Die Anwendung speichert die Daten und zeigt eine Statusmeldung an.
Hinweis: Wenn Sie das Popup verwenden, müssen Sie anstatt auf "Abschicken" auf die Schaltfläche "Job bestätigen" klicken.
Hinweis: Wenn Sie "Autom. Anstempelung" aktiviert haben, hat der Job den Status "IN BEARBEITUNG". Andernfalls hat der Job den Status Anerkannt (ACKNOWLEDGED).
