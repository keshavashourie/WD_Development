Teil einrichten

Auf der Seite "Teil einrichten" können Sie eine Einrichtung angeben, die hilft, Teile mit den Konfigurationen und Prozessen einer physischen Maschine zu verknüpfen, z. B. Dokumentsatz, geschätzte Zeit für die Ressourceneinrichtung und Standardeinrichtungsarbeitszeit. Auf dieser Seite können Sie andere erforderliche Informationen konfigurieren, z. B. Teilemenge, bevor sie in Ausrüstung oder Ressource für die Verfolgungsanforderungen geladen wird.

Hinweis: "Teil einrichten" steht auch als Popup auf der Seite "Teilewartung" zur Verfügung.

Felddefinitionen der Seite "Teil einrichten"

Diese Tabelle definiert die Felder auf der Seite "Teil einrichten".

Feld

Definition

Typ

Teil

Teil, das eingerichtet werden soll.

Erforderlich

Aktive Teilemenge

Menge des Teils, das derzeit in mindestens einer Ressource geladen ist.

Nur Anzeige

Teilemenge in Anforderung

Menge des Teils, das durch eine Teileanforderung angefordert wurde.

Nur Anzeige

Teil ausrangiert

Gibt an, ob das ausgewählte Teil ausrangiert ist. Neben der Feldbezeichnung wird "Wahr" oder "Falsch" angezeigt.

Nur Anzeige

Materialteil

Feld zum Auswählen von Ressourcenmaterialteil und Revisionsnummer. Dieses Feld kann im Modellierungsobjekt "Ressourcenmaterialteil" konfiguriert werden.

Erforderlich

Einrichtung

Einrichtung, die für das Teil verwendet wird. Eine Einrichtung ist eine physische Maschinenkonfiguration für einen bestimmten Prozess. Sie kann einen Dokumentsatz und den voraussichtlichen Zeitaufwand für die Ressourceneinrichtung beinhalten. Eine Einrichtung ist die Konfiguration einer Ressource, die für die Bearbeitung eines bestimmten Materialtyps benötigt wird. (Meist ist dies ein bestimmtes Produkt oder ein Container, der eine bestimmte Spezifikation referenziert.) Weitere Informationen finden Sie im Opcenter Execution Core Modeling-Handbuch.

Optional

Ablaufdatum

Datum, zu dem das Teil abläuft.

Optional

Teilemenge

Menge des Teils, das für die Einrichtung erforderlich ist.

Anmerkung: Sie können ggf. null eingeben.

Erforderlich

Physischer Ort

Physischer Ort, an dem das Teil gelagert wird.

Optional

Physische Position

Physische Position innerhalb des physischen Orts, an dem das Teil gelagert wird.

Optional

Vorgehensweise zum Einrichten eines Teils

Gehen Sie folgendermaßen vor, um ein Teil einzurichten:

1. Öffnen Sie die Seite Teil einrichten über das Menü Ressource > Teile-Services > Teil einrichten. Die Seite "Teil einrichten" wird angezeigt.
2. Wählen Sie einen Wert im Feld Teil aus. Die Anwendung füllt alle Felder aus, für die Daten vorhanden sind.
3. Geben Sie das Ressourcenmaterialteil (und die Revisionsnummer) in das Feld Materialteil ein oder wählen Sie es aus.
4. Geben Sie die Teilemenge, die für die Einrichtung erforderlich ist, in das Feld Teilemenge ein. Sie können eine Null eingeben, falls erforderlich.
5. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie in der Befehlsleiste auf Abschicken. Die Anwendung speichert die Daten und zeigt eine Statusmeldung an.
