Materialteile

Auf der Seite "Materialteile" können Sie die Liste der Materialteile suchen und anzeigen. Sie können aus dem Suchergebnis der ausgewählten Materialteile ein Teil erzeugen.

Die Materialteile auf dieser Seite beziehen sich auf das Materialteil der Ressource – nicht auf Materialteile, die vom Produkt verbraucht werden.

Felddefinitionen der Seite "Materialteile"

Diese Tabelle definiert die Felder auf der Seite "Felddefinitionen".

Feld

Definition

Typ

Filter

Materialteil

Ressourcenmaterialteil, das von einem anderen Ressourcenteil verwendet wird. Das zugehörige Feld enthält die Revision des Materialteils. Falls es aktiviert ist, ist die Revision die aktuelle Standard-Revision.

Erforderlich

Teiletyp

Gibt an, wie Materialteile in den Lagerbestand aufgenommen und verfolgt werden sollen. Hierfür gibt es drei Typen

• Serialisiert: Erfordert, dass für jede Sendung ein neues Los erstellt wird.
• Großmenge: Erfordert ein neues Los, wenn das Materialteil erstmalig versandt wird. Nachfolgende Sendungen aus demselben Hauptlos können in den Lagerbestand aufgenommen werden, indem die Menge des Loses erhöht wird, das anfänglich erstellt wurde.
• Nicht serialisiert: Es wird kein Los erstellt. Grundsätzlich genügt es, für Nachverfolgbarkeitszwecke die Batch-ID zu speichern.

Vorgehensweise zum Erstellen eines Teils über die Seite "Materialteile"

Vorgehensweise zum Erstellen eines Teils über die Seite "Materialteile":

1. Rufen Sie die Seite "Materialteile" über die Menüleiste "Ressource" > "Teile" > "Materialteile" auf. Die Seite "Materialteile" wird angezeigt.
2. Wählen Sie im Suchkriterienbereich ein Materialteil, einen Teiletyp oder beides aus.
3. Klicken Sie auf Übernehmen. Die Anwendung füllt die Tabelle "Suchergebnisse".
4. Wählen Sie in der Tabelle "Suchergebnisse" die Zeile des Materialteils aus.
5. Klicken Sie auf Fertigungsaktionen. Eine Transaktionsliste wird angezeigt.
6. Klicken Sie auf Teil erstellen. Das Popup "Teil erstellen" wird mit dem ausgewählten Materialteil und der ausgewählten Teilemenge angezeigt.
7. Geben Sie einen Namen in das Feld Teilename ein.
8. Sie können das ausgewählte Materialteil ändern, falls erforderlich.
9. Sie können das Feld Teilemenge ändern, falls erforderlich.
10. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
11. Klicken Sie auf Teil erstellen. Das Popup wird geschlossen und die Anwendung zeigt eine Erfolgsmeldung an.
