Hohes Volumen: Komponentenverbrauch

Sie können die Seite "Hohes Volumen: Komponentenverbrauch" verwenden, um Container zu verfolgen, die mit einer Ressource verknüpft sind, die einen hochvolumigen Komponentenverbrauch unterstützt. Eine Ressource ist für hochvolumige Verfolgbarkeit konfiguriert, wenn Folgendes zutrifft:

• Die Ressource hat die Option "Rückverfolgbarkeit für hohes Volumen verwenden" auf der Seite "Ressourcenmodellierung" ausgewählt.
• Die Ressource ist mit hochvolumiger Maschineneinrichtung konfiguriert.

Während der Dienst automatisch während einer Container-Abmeldetransaktion ausgeführt wird, wenn eine verknüpfte Ressource für den hochvolumigen Verbrauch konfiguriert ist, bietet die Seite "Hohes Volumen: Komponentenverbrauch" eine alternative Möglichkeit für Benutzer, denselben Dienst manuell auszuführen.

Die Anwendung bietet Verfolgbarkeit für alle Komponenten, die zur Zeit der Verarbeitung eines Containers in die Ressource geladen wurden. Durch Kombination dieser Informationen mit der Materialliste eines Containers (Komponenten, die vom Container benötigt werden), kann die Anwendung bestimmen, welche Komponenten für den Container verbraucht werden sollen. Eine Komponente wird als verbraucht betrachtet, wenn Folgendes zutrifft:

• Das Produkt des Materiallistenelements stimmt mit dem Produkt einer beliebigen Komponente überein, das in der Ressource geladen ist.
• Spezifikation oder Routenschritt ist für das Materiallistenelement nicht konfiguriert.
• Wenn die Spezifikation oder der Routenschritt konfiguriert ist, entspricht die aktuelle Spezifikation/ der aktuelle Schritt, in der der Container verarbeitet wird, dem konfigurierten Wert.
Hinweis: Das System kann nicht erkennen, welche Komponente im Vergleich zu einer Standardverarbeitung des Komponentenverbrauchs verbraucht wird, da der Container nur mit der Maschineneinrichtung zum Zeitpunkt des hochvolumigen Verbrauchs verknüpft wird. Die obigen Regeln werden dann während einer Anforderung dynamisch angewendet, um zu bestimmen, was verbraucht wurde.
Hinweis: Die anderen Optionen zum automatischen Verbrauchen der Komponenten sind "Materialwarteschlange" im Industrielösungen-Arbeitsbereich und "Autom. Komponentenverbrauch" in Opcenter Execution Electronics. Hochvolumiger Verbrauch hat Vorrang. Wenn alle oben genannten Anwendungen so konfiguriert sind, dass sie im selben Schritt auftreten, hat der hochvolumige Verbrauch Vorrang und wird ausgeführt, während die "Materialwarteschlange" und "Autom. Komponentenverbrauch" nicht ausgeführt werden.

Verbrauchte Komponenten

Dieser Abschnitt der Seite enthält eine Tabelle, in der hochvolumige Verbrauchskomponenten für den aktuell ausgewählten Container angezeigt werden. Die Tabelle füllt nur Komponenten aus, die mit der Transaktion "Hohes Volumen: Komponentenverbrauch" verbraucht wurden. Es werden keine Standardverbrauchskomponenten angezeigt.

Hochvolumiger Verbrauch wird für Container ohne untergeordnete Container ausgeführt. Wenn ein übergeordneter Container an die Transaktion geliefert wird, wird der Verbrauch für alle untergeordneten Container ausgeführt. Wenn der aktuell ausgewählte Container ein übergeordneter Container ist, zeigt die Tabelle den Verbrauch für alle untergeordneten Container an.

Vorgehensweise zum Konfigurieren von hochvolumigen Komponentenverbrauch

Gehen Sie folgendermaßen vor, um die Seite "Hohes Volumen: Komponentenverbrauch" zu verwenden:

1. Öffnen Sie die Seite Hohes Volumen: Komponentenverbrauch im Menü Container. Die Seite "Hochvolumiger Komponentenverbrauch" wird angezeigt.
2. Wählen Sie einen Container im Feld Container aus oder geben Sie einen ein. Die Anwendung aktualisiert den Container-Kopf und die Auswahlfelder, sodass diese Informationen für den angegebenen Container angezeigt werden. Werte werden nur angezeigt, wenn sie für den Container eingegeben wurden.
3. Wählen Sie die Ressource aus, die mit dem ausgewählten Container verknüpft werden soll.
Hinweis: Nur Ressourcen, die für hochvolumige Verfolgbarkeit konfiguriert sind, werden im Dropdown-Menü angezeigt. Komponenten, die derzeit in die Ressource geladen sind, werden in der Tabelle "Aktuelle Einrichtungsdetails" angezeigt.
4. Klicken Sie in der Befehlsleiste auf Abschicken. Die Anwendung führt die Transaktion "Hohes Volumen: Komponentenverbrauch" aus und zeigt eine Statusmeldung mit Ausführungsergebnissen an.
Hinweis: Sie können den Abschnitt "Verbrauchte Komponenten" erweitern, um die aktuell verbrauchten Komponenten mit hochvolumigen Komponentenverbrauch anzuzeigen, die nach Auswahl eines Containers verbraucht wurden.
