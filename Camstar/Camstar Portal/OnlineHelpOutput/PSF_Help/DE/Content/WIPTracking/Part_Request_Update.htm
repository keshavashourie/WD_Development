Teileanforderung aktualisieren

Die Seite "Teileanforderung aktualisieren" erlaubt einem Ressourcenjobtechniker die Aktualisierung einer Teileanforderung.

Hinweis: "Teileanforderung aktualisieren" ist auch als Popup auf der Seite "Teilewartung" verfügbar.

Felddefinitionen der Seite "Teileanforderung aktualisieren"

Diese Tabelle definiert die Felder auf der Seite "Teileanforderung aktualisieren".

Feld

Definition

Typ

Ressource

Ausrüstungsressource, für die Sie Teile anfordern oder aus der Sie Teile zurückführen möchten.

Erforderlich

Jobauftrag

Jobauftragsnummer eines aktiven Wartungsjobs für die Ressource. Diese Nummer wird angezeigt, wenn die Teileanforderung mit einem Jobauftrag verknüpft ist.

Nur Anzeige

Anforderungsauftrag

Anforderungsauftrag, der für die Teileressource erstellt wird.

Erforderlich

Anforderungstyp

Art der Teileanforderung – entweder Anforderung oder Rücklauf.

Nur Anzeige

Tabelle "Angeforderte Teile"

Tabelle, in der die für die ausgewählte Ressource angeforderten Teile aufgelistet werden.

Nur Anzeige

Materialteil

Ressourcenmaterialteil, das von einem anderen Ressourcenteil verwendet wird.

Hinweis: Das Teil muss entweder in der Stückliste, die der Ressource zugewiesen ist, oder in einer Stückliste vorhanden sein, die einer Wartungsanforderung für die Ressource zugewiesen ist.

Nur Anzeige

Angeforderte Teilemenge

Menge des Teils, die angefordert wird.

Nur Anzeige

Teilemenge zuweisen

Menge des zugewiesenen Materialteils.

Nur Anzeige

Tabelle "Zugewiesene Teile" (zu verbrauchen für Ressource)

Tabelle, in der Materialteilezuweisungen angezeigt werden.

Nur Anzeige

Teil

Teil, das das angeforderte Ressourcenmaterialteil enthält.

Nur Anzeige

Materialteil

Angefordertes Ressourcenmaterialteil.

Nur Anzeige

Teilemenge

Menge des Ressourcenmaterialteils, das der Anforderung zugewiesen ist.

Nur Anzeige

Ausblenden/Anzeigen von zusätzlichen Feldern

Kommentare

Zusätzliche Informationen oder Anweisungen für diese Transaktion oder für diesen Container. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Aktualisieren einer Teileanforderung

Gehen Sie folgendermaßen vor, um eine Teileanforderung zu aktualisieren:

1. Öffnen Sie die Seite "Teileanforderung aktualisieren", indem Sie das Menü Ressource > Teile-Services > Teileanforderung aktualisieren auswählen. Die Seite "Teileanforderung aktualisieren" wird angezeigt.
2. Wählen Sie im Feld Ressource eine Ressource aus. Die Anwendung füllt die restlichen Felder auf der Seite aus.
3. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
4. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
