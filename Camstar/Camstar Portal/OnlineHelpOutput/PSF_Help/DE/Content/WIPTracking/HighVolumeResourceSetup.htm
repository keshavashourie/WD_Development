Hohes Volumen: Ressourceneinrichtung

Sie können die Seite "Hohes Volumen: Ressourceneinrichtung" verwenden, um Komponenten zu definieren, die in eine Ressource geladen sind, die hochvolumigen Komponentenverbrauch unterstützt, sodass sie mit einem Container verknüpft werden, wenn sie durch die Ressource bewegt werden. Die Maschineneinrichtung ist eine Liste aller Materialkomponenten, die in eine Fertigungsausrüstung geladen werden und Folgendes enthält:

• Los (Lot)
• Produkt (Product)
• Anbieterlosnummer
• Slot
• SubSlot

Die Anwendung zeichnet die konfigurierten Informationen für Los, Produkt, Anbieterlosnummer, Slot und SubSlot auf, die in der Tabelle für die Ressource angegeben sind. Wenn ein Container dann eine Abmeldetransaktion mit der Ressource durchführt, werden die Komponenteneinrichtungsinformationen mit dem angegebenen Container verknüpft. Diese Informationen stellen dann die verbrauchten Komponenten im Container dar, wenn das Produkt der Einrichtungskomponenten mit Elementen in der Materialliste des Containers übereinstimmt.

Beim Verwenden der hochvolumigen Ressourceneinrichtung

Nur Ressourcen mit aktivierter Option "Rückverfolgbarkeit für hohes Volumen verwenden" werden im Dropdown-Feld "Ressource" angezeigt. Die Option kann konfiguriert werden, wenn Sie eine Ressource mithilfe der Modellierungsseite "Ressource" definieren.

Alle verfügbaren Ressourcen werden in der "Ressourcenliste" angezeigt, es sei denn, Sie wählen eine "Ressourcengruppe", um die Anzahl der angezeigten Ressourcen zu begrenzen. Wenn Sie eine Ressource auswählen, aktualisiert die Anwendung den Kopf, um Informationen in Bezug auf die Ressource, einschließlich der aktuellen Verfügbarkeit der Ressource, anzuzeigen. Sobald eine Ressource ausgewählt ist, wird die Tabelle "Servicedetails" mit Werten der vorhandenen Einrichtung dieser Ressource gefüllt.

Ein Produkt mit einem Revisionswert "1" wird erstellt, falls der Produktname für dieses Produkt nicht vorhanden ist. Sie können Änderungen an den Werten vornehmen, die in der Tabelle "Servicedetails" angezeigt werden, und diese speichern. Beim Speichern überprüft die Anwendung, ob die Kombination von Slot oder SubSlot innerhalb der Einrichtung eindeutig ist. Eine Fehlermeldung wird angezeigt, wenn eine Einrichtung mit mehreren Zeilen dieselben Slot- oder SubSlot-Werte aufweist.

Seite "Hohes Volumen: Ressourceneinrichtung"

Sie können über das Menü "Ressourcen" auf die Seite "Hohes Volumen: Ressourceneinrichtung" zugreifen. Verwenden Sie die Seite "Hochvolumige Ressourceneinrichtung", um die Maschineneinrichtung zu erstellen oder zu ändern.

Felddefinition der Seite "Hohes Volumen: Ressourceneinrichtung"

Diese Tabelle definiert die Felder, die nur auf der Seite "Hohes Volumen: Ressourceneinrichtung" zu finden sind.

Feld

Definition

Typ

Ressourcengruppe

Kopf mit dem Ressource-Namen und Informationen zu dieser Ressource. Sie müssen eine Ressource auswählen oder eingeben, um die Kopf-Felder zu füllen. (Sie können eine Ressourcengruppe auswählen, um die zur Auswahl stehenden Ressourcen zu beschränken.) Weitere Informationen finden Sie unter "Informationen zu Ressourcen".

Optional

Ressource

Maschine, Arbeitszelle, Vorrichtung, Behälter usw. für die Datensammlung. Die Auswahlliste beinhaltet alle Ressource und Behälter, es sei denn sie ist nach "Ressourcengruppen" gefiltert.

Erforderlich

Maschinen-ID

Ein ganzzahliger Wert, der diese Ausrüstung in der Fabrik identifiziert.

Hinweis: Der Wert wird von Opcenter Execution Core nicht verwendet, da keine Gültigkeitsprüfung für den Wert bereitgestellt wird, wenn dieser aufgezeichnet wird.

Optional

Geräte-ID

Ein ganzzahliger Wert, der diese Instanz der Maschineneinrichtung für die Ausrüstung identifiziert.

Optional

Tabelle "Servicedetails"

Los (Lot)

Eine eindeutige Kennung für die Komponente.

Erforderlich

Produkt (Product)

Der OP EX CR-Name des Produkts für die Komponente.

Erforderlich

Anbieterlosnummer

Die eindeutige Kennung, die einer bestimmten Menge oder Gruppe desselben Produkts vom Hersteller zugewiesen ist.

Optional

Slot

Ein ganzzahliger Wert, der den Komponentenort auf der Ausrüstung definiert.

Optional

SubSlot

Ein ganzzahliger Wert, der den Komponentenort innerhalb des Slots definiert.

Optional

Vorgehensweise zum Konfigurieren einer Komponenteneinrichtung einer Ressource

Gehen Sie folgendermaßen vor, um eine Ressource zu ändern:

1. Öffnen Sie die Seite Hohes Volumen: Ressourceneinrichtung im Menü Ressource. Die Seite "Hohes Volumen: Ressourceneinrichtung" wird angezeigt.
2. Wählen Sie die Ressource aus, die Sie anzeigen möchten. Die Anwendung füllt die Felder und die Tabelle mit vorhandenen Maschineneinrichtungsinformationen aus.
3. Klicken Sie ggf. auf die Zeile in der Tabelle, die Sie ändern oder löschen möchten.
4. Klicken Sie auf Einreichen. Die Anwendung zeigt eine Statusmeldung an, die bestätigt, dass die hochvolumige Ressourceneinrichtung abgeschlossen ist.
