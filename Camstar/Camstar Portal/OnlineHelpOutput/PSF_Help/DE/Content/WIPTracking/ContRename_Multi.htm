Mehrere Container umbenennen

Mit der Transaktion "Container umbenennen (mehrere)" können Sie mehrere Container gleichzeitig umbenennen.

Beim Umbenennen mehrerer Container

Sie müssen einen Container auswählen oder eingeben und den neuen Containernamen angeben. Andernfalls deaktiviert die Anwendung die Schaltfläche "Hinzufügen".

Die Anwendung überprüft, ob die angegebenen Containernamen verfügbar sind und noch nicht verwendet werden.

Das Umbenennen von Containern hat keinen Einfluss auf zugeordnete Kind- oder Eltern-Container. Sie bleiben mit dem umbenannten Container verbunden.

Unter "Multi-Container-Transaktionsübersicht" finden Sie Informationen darüber, wie die Anwendung beim Ausführen von Transaktionen an mehreren Containern funktioniert.

Seite "Container umbenennen (mehrere)"

Sie können über das Menü "Container" auf die Seite "Container umbenennen (mehrere)" zugreifen. Auf der Seite "Container umbenennen (mehrere)" können Sie einen oder mehrere Container scannen oder eingeben und sie umbenennen.

Felddefinitionen der Seite "Container umbenennen (mehrere)"

Diese Tabelle definiert die Felder auf der Seite "Container umbenennen (mehrere)".

Definition

Kopf mit dem Containernamen und Informationen zu diesem Container. Sie müssen auf einer Transaktionsseite einen Container auswählen oder eingeben. Weitere Informationen finden Sie unter "Containerinformationen".

Neuer Name für den ausgewählten Container. Das Feld akzeptiert maximal 30 Zeichen. Die Anwendung zeigt eine Fehlermeldung an, wenn die Länge des Namens 30 Zeichen überschreitet.

Optionale Felder sind standardmäßig ausgeblendet, wenn die Anwendung eine Seite anzeigt. Durch Klicken auf das Steuerelement für Anzeigen werden die Felder angezeigt. Durch Klicken auf die Steuerung "Verstecken" werden die Felder ausgeblendet.

Zusätzliche Informationen oder Anweisungen für diese Transaktion oder für diesen Container. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Umbenennen mehrerer Container

Gehen Sie folgendermaßen vor, um mehrere Container umzubenennen:

1. Öffnen Sie die Seite Container umbenennen (mehrere) im Menü Container. Die Seite "Container umbenennen (mehrere)" wird angezeigt.
2. Scannen Sie einen Container im Feld Container oder geben Sie ihn ein.
3. Geben Sie einen neuen Namen für den ausgewählten Container in das Feld Neuer Containername ein.
4. Klicken Sie auf Hinzufügen. Der Container wird zur "Tabelle 'Umzubenennende Container'" hinzugefügt und automatisch ausgewählt.
5. Wiederholen Sie Schritte 2-4, um zusätzliche Container hinzuzufügen.
6. Gewährleisten Sie, dass die ausgewählten Container diejenigen sind, die Sie umbenennen möchten.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. Weitere Informationen zu den optionalen Feldern finden Sie in der Tabelle der Felddefinitionen.
8. Klicken Sie in der Befehlsleiste auf Abschicken. Die Anwendung zeigt eine Statusmeldung an, die bestätigt, dass der Container umbenannt wurde.
