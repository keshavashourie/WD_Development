Job zuweisen

Auf der Seite "Job zuweisen" können Sie Technikern Wartungs- oder Reparaturaufträge zuweisen. Die Seite kann auch zum Ändern oder Entfernen einer vorhandenen Zuweisung verwendet werden.

Definitionen der Felder auf der Seite "Job zuweisen"

Diese Tabelle definiert die Felder auf der Seite "Job zuweisen".

Feld

Definition

Typ

Ressource

Name der Fertigungsressource oder -ausrüstung. In diesem Zusammenhang ist dies der eindeutige Name der Ressource, für die der Job erstellt wurde.

Erforderlich

Jobauftrag

Name oder ID des Jobauftrags.

Optional

Jobmodell

Das "Jobmodell"-Objekt, auf dem der Job basiert. Das "Jobmodell"-Objekt ist das Element, in dem die Schritte konfiguriert sind.

Nur Anzeige

Einfacher Modus

Im einfachen Modus ist die Transaktion "Jobfortschritt" der erste konfigurierte Schritt. Wenn dieser Schritt abgeschlossen ist, wechselt die Transaktion zum letzten konfigurierten Schritt. Das Kontrollkästchen "Einfacher Modus" kann auf der Seite "Job erstellen" aktualisiert werden.

Nur Anzeige

Jobtyp

Gibt einen allgemeinen Grund für den Job an, z. B. "Normal", "Vorbeugende Wartung" oder "Aufarbeitung".

Nur Anzeige

Stage

Der aktuelle Schritt des Jobs.

Nur Anzeige

Entwicklung der Umformstufen

Sequenzielle Reihenfolge der Stufe (Phase).

Nur Anzeige

Techniker- und Wartungsinformationen & anzeigen/ausblenden

Schaltfläche, über die die Tabellen "Techniker" und "Wartungsstatus" ausgeblendet oder angezeigt werden.

Tabelle, in der die zugewiesenen Techniker aufgelistet werden. Sie müssen eine Liste der Techniker im Modellierungsobjekt "Jobauftrag" konfigurieren, bevor sie in diese Tabelle eingetragen werden kann.

 

Techniker

Optional

Vorgehensweise zum Zuweisen eines Jobs

Gehen Sie folgendermaßen vor, um einem Techniker einen Job zuzuweisen:

1. Öffnen Sie die Seite Job zuweisen im Menü Ressource > Jobs > Jobservices. Die Seite "Job zuweisen" wird angezeigt.
2. Wählen Sie das Feld Ressource aus. Die Anwendung füllt die Felder auf der Seite aus, wenn sie einen Job für die Ressource findet.
3. Klicken Sie auf Neue Zeile hinzufügen über der Tabelle Techniker. Die Anwendung aktiviert ein neues Feld "Techniker" in der Tabelle.
4. Wählen Sie aus der Feldliste Techniker einen Techniker aus.
5. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie in der Befehlsleiste auf Abschicken. Die Anwendung speichert die Daten und zeigt eine Statusmeldung an.
