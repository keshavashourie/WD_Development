Part Request Cancel Acknowledge

The Part Request Cancel Acknowledge page enables you to acknowledge the cancellation of a parts request.

Part Request Cancel Acknowledge Page Field Definitions

This table defines the fields on the Part Request Cancel Acknowledge page.

How to Acknowledge a Parts Request Cancellation

Follow these steps to acknowledge a part request cancellation:

1. Open the Part Request Cancel Acknowledge page by selecting Resource > Part Services > Part Request Cancel Acknowledge menu. The Part Request Cancel Acknowledge page appears.
2. Select a resource in the Resource field. The application fills in the remaining page fields.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit. The application displays a success message.
