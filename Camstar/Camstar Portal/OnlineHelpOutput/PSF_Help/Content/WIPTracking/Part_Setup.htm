Part Setup

Part Setup page enables you to specify a setup that helps to link parts to a physical machine's configurations and processes such as document set, estimated resource setup time, and standard setup labor time. This page allows you to configure other necessary information such as Part Qty before it is loaded onto equipment or resource for Track In requirements.

Note: Part Setup is also available as a pop-up from the Part Maintenance page.

How to Set Up a Part

Follow these steps to set up a part:

1. Open the Part Setup page from the Resource > Part Services > Part Setup menu. The Part Setup page appears.
2. Select the a value from the Part field. The application populates any fields for which there is data.
3. Enter or select the resource material part (and revision number) from the Material Part field.
4. Enter the part quantity needed for the setup in the Part Qty field. You may enter a zero if necessary.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit on the command bar. The application saves the data and displays a status message.
