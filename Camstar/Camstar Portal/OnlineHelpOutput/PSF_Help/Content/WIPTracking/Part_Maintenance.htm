Part Maintenance

The Part Maintenance page allows you to search, view and perform maintenance of existing parts or material parts. This page allows configuration of part create, part setup and part scrap via the Shop Floor Txn pop-up.

Part Type

Represents how material parts are to be inventoried and tracked. There are three such types:

• Serialized: Requires a new lot to be created for each shipment
• Bulk: Requires a new lot the first time the material part is shipped. Subsequent shipments from the same mother lot can be inventoried by increasing the quantity of the lot initially created.
• Non-serialized: No lot is created. It generally suffices to record the lot number for traceability purposes

Part Maintenance Page Button Definitions

Shop Floor Txns button is available on the right-command bar of the Part Maintenance page. You must select a row from the search result grid to enable the Shop Floor Txns button.

This table defines the buttons on the Shop Floor Txns.

Button

Definitions

Part Create

Create a part based on the selected material parts. Refer to "Part Create" for the page information and field definitions.

Part Setup

Set up the selected part. Refer to "Part Setup" for the page information and field definitions.

Part Scrap

Scrap quantity from the part. Refer to "Part Scrap" for the page information and field definitions.

Part Set Status

Set the status of the selected part.

Note: Only applicable for Opcenter Execution Semiconductor.

How to Use Part Maintenance Page

Follow these steps to use the Part Maintenance page:

1. Open the Part Maintenance page from the menu bar Resource > Parts > Part Maintenance. The Part Maintenance page appears.
2. Enter search values in the Filter slide-out panel if the value is not populated by default.
3. Click Apply. The application populates the Search Results grid.
4. Select the part row on the Search Results grid. The application enables additional buttons under Shop Floor Txns.
5. Select Part Create, Part Setup or Part Scrap based on your business requirement. Refer to the field definitions in "Part Create
