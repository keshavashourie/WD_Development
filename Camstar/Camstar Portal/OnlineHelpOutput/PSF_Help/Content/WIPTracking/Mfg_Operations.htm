Mfg Operations

The Mfg Operations page provides a comprehensive look at where and how a selected resource is or will be used in manufacturing operations. Operators and operations managers can use this page to view required changeovers from one order to another and may find the page helpful with scheduling and setup activities.

Mfg Operations Page Layout

The Mfg Operations page contains the following areas:

• Resource header area at the top of the page showing details of selected resource
• Mfg Order panel on the left that contains one or more tiles, each of which represents a manufacturing order, workflow step, and product for which the selected resource is being used or may be used based on existing manufacturing orders
• Center panel with Material Requirements grid for selected tile
• Mfg Order Detail panel on the right that displays details for the tile selected on the left panel
• Command bar with buttons available based on selected tile

Mfg Operations Page Data Sources

The Mfg Operations page is sourced by scheduling data for the selected resource if such data exists. Data is also generated based on anticipated use of the resource based on manufacturing orders and workflows with steps that use the resource.

Mfg Operation Material Requirements Grid

The Material Requirements grid attempts to show materials and their quantities required for all containers in the manufacturing order to be processed by the selected resource and step. The grid also shows the setup status of materials.

The grid includes:

• Material items configured for the step
• Material items set up on the resource using the High Volume Resource Setup.
• Material items set up on the resource or operation using the Material Queue (In industry workspace).
Note: If a resource is configured using Material Queue and the High Volume Issue are configured to occur at the same step, the High Volume Issue will take precedence.

A material list is chosen in order of preference as listed below:

• Mfg Order Material
• Mfg Order ERP BOM
• Product BOM
• Product ERP BOM
Note: As an example, if a material list is specified on both the Mfg Order and the Product BOM, the material list on the Mfg Order is chosen.

The application populates the grid with a list of components configured for specific slots pre-defined in High Volume Resource Setup page. Next, the application populates the material list either from the Mfg Order Material List, from the product BOM or from the product ERP BOM if configured.

Note: Refer to Material Requirements grid in the field definitions table for a list of icons used in this grid.

How to Use the Mfg Operations Page

Follow these steps to use the Mfg Operations page:

1. Open the Mfg Operations page.
2. Select a Resource. The application populates the Mfg Order list of tiles and selects the first tile.
3. Select a tile from the list. The application populates the Mfg Order Details panel.
4. Either leave the first tile selected or select a different tile. The application repopulates the rest of the page if you selected a different tile.
5. To view, add, or update comment data for the selected tile, click Comments on the command bar. The application displays the Comment slide-out panel on the right.
Note: Refer to "How to Add or Update a Comment".
6. To view any associated documents, click Documents on the command bar. The application displays the Documents slide-out panel on the right.
Note: Refer toHow to Use the Documents Slide-Out Panel

How to Add or Update a Comment

Follow these steps to add or update a comment:

1. Click Comments on the command bar. The Comments slide-out panel appears.
2. To add a comment, enter a new line at the end of the existing comment data and begin typing your comment.
3. To update existing comment data, type over existing text as necessary.
4. When finished, click Save.
5. Click the X in the upper right corner of the slide-out panel or click Comments on the command bar to close the panel.
Note: This functionality is available only when the Industry Solutions workspace is installed. Refer to the Opcenter Execution Core Industry Solutions User Guide for information.
