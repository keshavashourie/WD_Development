Job Acknowledge

The Job Acknowledge page enables a technician to acknowledge an assigned resource maintenance or repair job. This indicates the technician is aware of the job assignment.

Job Acknowledge Page Field Definitions

This table defines the fields on the Job Acknowledge page.

Field

Definition

Type

Resource

Name of the manufacturing resource or equipment. In this context, it is the unique name of the resource for which the job was created.

After a resource is selected, the application populates Material Parts pop-up that displays list of associated resource parts.

Required

Job Order

Name or ID of Job Order. Values displayed in this Job Order field are populated based on the selected Resource field which can be configured in Job Order modeling object.

Optional

Job Model

Job Model object on which job is based. The Job Model object is where the steps are configured. This field is auto-populated based on the previous fields.

Display Only

Job Type

Indicates type of work being performed on the resource, for example, Normal, PM (Preventative Maintenance), and Repair. This field is auto-populated based on the previous fields.

Display Only

How to Acknowledge a Job

Follow these steps to acknowledge a job:

1. Open the Job Acknowledge page from the Resource > Jobs > Job Services menu. The Job Acknowledge page appears.
2. Select the Resource field. The application populates the page fields if it finds a job for the resource.
3. Optionally, you can select the Auto Clock On check box to have the application automatically clock on the job and bypass the manual Job Clock On transaction.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Submit on the command bar. The application saves the data and displays a status message.
Note: You must click the Job Acknowledge button instead of Submit if you are using the pop-up.
Note: If you selected Auto Clock On, the job status will be IN PROGRESS. If you did not, the status will be ACKNOWLEDGED.
