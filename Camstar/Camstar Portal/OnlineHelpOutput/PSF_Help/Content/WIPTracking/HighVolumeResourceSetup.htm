High Volume Resource Setup

You can use the High Volume Resource Setup page to define components loaded to a resource that supports high volume component issues so that they will be associated to a container when it moves through the resource. The machine setup is a list of all material components that are loaded to a shop floor equipment and includes the following:

• Lot
• Product
• Vendor Lot Number
• Slot
• SubSlot

The application records the configured Lot, Product, Vendor Lot Number, Slot, and SubSlot information specified in the grid against the Resource. When a container then performs a Move transaction using the Resource, the component setup information will be associated to the specified container. This information then represents the components issued to the container if the product of the setup components matches items in the material list of the container.

When Using High Volume Resource Setup

Only resources with "Use High Volume Traceability" option activated will appear in the Resource drop down field. The option can be configured when defining a Resource using the Resource modeling page.

All available resources are displayed in the Resource list unless you select a Resource Group to limit the number of resources displayed. When you select a resource, the application updates the header to display information related to the resource, including the resource's current availability. Once a resource is selected, the service details grid is populated with values of the existing setup of that resource.

A Product with a revision value of "1" is created in the event the product name does not exist for that Product. You can make changes to the values displayed in the Service Details grid and save them. When saving, the application will validate that the combination of Slot or SubSlot is unique within the setup. An error message will pop up if a setup with more than one row has the same Slot or SubSlot values.

High Volume Resource Setup Page

You can access the High Volume Resource Setup page from the Resource menu. Use the High Volume Resources Setup page to create or modify the machine setup .

How to Configure a Component Setup of a Resource

Follow these steps to modify a resource:

1. Open the High Volume Resource Setup page from the Resource menu. The High Volume Resource Setup page appears.
2. Select the Resource that you want to display. The application populates the fields and grid with existing machine setup information.
3. Click on the row in the grid that you want to modify or delete if necessary.
4. Click Submit. The application displays a status message confirming the High Volume Resource Setup is completed.
