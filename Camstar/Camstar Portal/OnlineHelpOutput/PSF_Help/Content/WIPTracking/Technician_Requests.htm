Technician Requests

Technician Requests Page Button Definitions

Shop Floor Txns button is available on the right-command bar of the Technician Requests page. You must select a row from the search result grid to enable the Shop Floor Txns button.

This table defines the buttons on the Shop Floor Txns.

Button

Definitions

Part Request

Request resource material parts from inventory or to return resource material parts back to inventory. Refer to "Part Request" for the page information and field definitions.

Part Request Update

Update a part request. Refer to "Part Request Update" for the page information and field definitions.

Part Request Issue

Issue requested parts to a resource after the parts have been assigned. Refer to "Part Request Issue" for the page information and field definitions.

Part Request Cancel

Cancel a part request. Refer to "Part Request Cancel" for the page information and field definitions.

How to Use Technician Requests Page

Follow these steps to use the Technician Requests page:

1. Open the Technician Requests page from the menu bar Resource > Parts > Technician Requests. The Technician Requests page appears.
2. Enter search values in the Filter slide-out panel if the value is not populated by default.
3. Click Apply. The application populates the Search Results grid.
4. Select the part row on the Search Results grid. The application enables additional buttons under Shop Floor Txns.
5. Select Part Request, Part Request Update, Part Request Issue or Part Request Cancel based on your business requirement.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Submit on the command bar. The application saves and displays a success message.
