SPC Tester

Siemens provides an SPC Tester that allows you to test the sample charts and data included with the application. It also allows you to test your setup after you have configured charts and required components.

Siemens provides sample charts and data that can be loaded through the Management Studio.

When Using the SPC Tester Page

You must select a Container, SPC Chart, SPC Chart Group, or Data Collection. All other fields are optional.

Selecting a container automatically filters the SPC Chart, SPC Chart Group, and Data Collection fields. The fields will only display values associated with the selected container when a container is selected.

You can pass parameters to charts at run-time to add new parameters or modify and remove existing parameters on the User Parameter grid. UI Parameters you enter on this page override those set in the SPC Chart object. Refer to "Defining SPC Charts" for information on defining parameters for SPC charts.

Note: Dynamic values cannot be used on the SPC Tester page.

Test data can be loaded through the DB update in Management Studio. Siemens recommends you only load this data in a development environment, and not in your production environment.

Sample macros and sample charts point to the data loaded from the DB update. Paths in the sample charts point to default install locations. There you will need to update the paths if you did not use the default installation locations.

You must also update sample macros with authentication info for your ODBC before you use tester page.

UI Parameters you enter on this page will override those set in the SPC Chart object.

How to Use the SPC Tester Page

Follow these steps to use the SPC Tester page:

1. Select SPC Tester from the SPC menu. The SPC Tester page appears.
2. Select a Container, SPC Chart, SPC Chart Group, or Data Collection.
Note: Only one field is required.
3. Select one or more optional fields to further define the charts you generate.
4. Click Submit. The selected charts are displayed.
5. Do you want to download the chart or chart group?

If . . .

Then . . .

Yes
a. Click Download Image. The application prompts you to open or save the file, or it automatically downloads the file. (Your Internet browser determines whether the application displays a pop-up, its appearance, and the wording of the Open or Save options.)

Note: The browser displays an error message if you do not have privileges for file downloads on the device.

b. Select the action you want to perform and complete any additional steps for opening the file with a specific application or saving the file to your computer.
c. Click the X in the right corner to close the chart pop-up.

No

Click the X in the right corner to close the chart pop-up.

How to Save SPC Log Files

Follow these steps to to save chart logs for troubleshooting purposes:

Note: Before you can save SPC Log Files, you must define a file path in the SPCLogPath portal setting. Refer to Configuring Portal Settings in the Opcenter Execution Medical Device and Diagnostics Portal 2.0 User Guide or Opcenter Execution Core Portal Studio User Guide for information.
1. Select SPC Tester from the SPC menu. The SPC Tester page appears.
2. Select a Container, SPC Chart, SPC Chart Group, or Data Collection.
Note: Only one field is required.
3. Select the Save SPC logs check box.
4. Select one or more optional fields to further define the charts you generate.
5. Click Submit. The selected charts are displayed. A log file is saved to the file path designated in the SPCLogPath Portal Setting. Navigate to that location to view the saved log.
