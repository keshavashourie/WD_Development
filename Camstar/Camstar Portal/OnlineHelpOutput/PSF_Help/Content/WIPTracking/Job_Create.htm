Job Create

The Job Create page enables you to create a resource maintenance or repair job. Manual job creation can be done by an authorized user, for example, a system administrator.

The application can be set to automatically create jobs if the resource is configured with either Thruput Requirement, Recurring Date Requirements, or Date Requirements and meets the following maintenance state:

• Automatic job creation for Thruput Requirement is triggered when the maintenance state is Due or Past Due.
• Automatic job creations for Date Requirements and Recurring Date Requirements are triggered when the maintenance state is Due only. (Use the Tolerance Period field in the Date and Recurring Date Requirement modeling pages to enable the Due state.)

Refer to the Opcenter Execution Medical Device and Diagnostics Modeling User Guideor the Opcenter Execution Core Modeling User Guide for information on defining Thruput Requirement, Date Requirements, and Recurring Date Requirements.

Note: Job Create is not allowed to be created for a resource that is assigned to an active job order combination. For example, Machine A is assigned to Job Order 01 which is currently active or in progress. You are not able to create a job for Machine A until the job order is completed.

When Generating Job Create Automatically

The application uses the numbering rule associated with the “JobOrder_Name” during automatic job creation. Manual job creation may utilize numbering rule if there is no Job Order assigned. The numbering rule is set by default during the installation of Opcenter Execution Core. To modify the default numbering rule settings, go to Numbering Rule modeling page and select “JobOrder_Name” modeling instance.

How to Create a Job

Follow these steps to create a job:

1. Open the Job Create page from the Resource > Jobs > Job Services menu. The Job Create page appears.
2. Select the Resource field.
3. Select the Job Model.
4. Optionally assign a technician by clicking Add New Row above the Technicians grid and selecting a technician from the enabled Technician field list.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit on the command bar. The application saves the data and displays a status message.
