Rename Multiple Containers

The Container Rename (Multiple) transaction enables you to rename multiple containers simultaneously.

When Renaming Multiple Containers

You must select or enter a container and specify the new container name. Otherwise, the application disables the Add button.

The application validates that the specified container names are available and are not used already.

Renaming containers does not influence associated children or parents containers, they remain linked to the renamed container.

Refer to "Multi-Container Transactions Overview" for information on how the application functions when executing transactions on multiple containers.

Container Rename (Multiple) Page

You can access the Container Rename (Multiple) page from the Container menu. The Container Rename (Multiple) page allows you to scan or enter one or more containers and rename those containers.

How to Rename Multiple Containers

Follow these steps to rename multiple containers:

1. Open the Container Rename (Multiple) page from the Container menu. The Container Rename (Multiple) page appears.
2. Scan or enter a container in the Container field.
3. Enter a new name for the selected container in the New Container Name field.
4. Press Add. The container is added to the Containers to Rename grid and selected automatically.
5. Repeat steps 2-4 to add additional containers.
6. Ensure the selected containers are the ones you want to rename.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Submit on the command bar. The application displays a status message confirming the containers have been renamed.
