Container Rename

The Container Rename transaction enables you to rename a container.

Note: Refer to "Rename Multiple Containers" if you want to rename multiple containers simultaneously.

When Renaming a Container

All display fields are empty on the Container Rename page until a container is selected.

Only one container can be renamed per transaction. You must enter the new container name. The application displays an error message if you click the Submit button without entering the new container name.

The application validates that the specified container name is available and is not used already.

Renaming a container does not influence associated children or parents containers, they remain linked to the renamed container.

Container Rename Page

You can access the Container Rename page from the Container menu. The Container Rename page allows you to scan or enter a container and rename that container.

How to Rename a Container

Follow these steps to rename a container:

1. Open the Container Rename page from the Container menu. The Container Rename page appears.
2. Select or enter a container in the Container field. The application updates the container header and selection fields to display information for the specified container.Values appear only if they were entered for the container.
3. Enter a new name for the selected container in the New Container Name field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Submit on the command bar to rename the container. The application displays a status message confirming the container has been renamed.
