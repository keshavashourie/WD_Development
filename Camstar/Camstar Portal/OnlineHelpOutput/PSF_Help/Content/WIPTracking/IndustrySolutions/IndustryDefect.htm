Industry Defect

The Industry Defect Page enables you to display current defect information against the container.

Note: This topic provides introductory information on working with defects. Refer to the Opcenter Execution Medical Device and Diagnostics Industry Solutions User Guide or the Opcenter Execution Core Industry Solutions User Guide for detailed information on logging and repairing defects.

Before Using Industry Defect

You must configure container defect reasons in Modeling before you can record defects against containers. The defect reasons are available for selection under these conditions:

• A container defect reason has been defined.
• A container defect reason group containing the reason has been defined.
• The container defect reason group has been assigned to the container's current operation.

Refer to the Opcenter Execution Medical Device and Diagnostics Modeling User Guide or the Opcenter Execution Core Modeling User Guide for information on defining and associating the objects necessary to record container defects.

When Using Industry Defect

All display fields are empty on the Industry Defect page until a container is entered or selected. Display fields are populated automatically on the Defect List grid. Each row represents an open defect or a repaired defect. You can log a defect against a container by activating the Log Defect pop-up from the Add Defect button on the command bar. The grid is updated as new defects are logged.

Note: You can log defects against any issued Material List Item or items that have an issue type of "Display Only."

Industry Defect Page

You can access the Industry Defect page from the Container menu. The Industry Defect page enables you to record a list of defects against the selected container.

Log Defect Pop-Up

You can access the Log Defect pop-up by clcking the "Add Defect" button in the sidebar of the Industry Defect page.

The Materials grid is populated with Material List items for the Container. You can select one or more items in this list and click the Add button to add them to the Location grid.

The Location grid represents the location on the Container where the defect occurs. You can optionally enter a Reference Designator and X and Y location manually, but you cannot enter a Product manually. You can choose to add items to the Location grid manually without using the Materials grid.

Defect and Repair Grid Toolbar

The Defect List grid shows existing defects and repair for currently displayed container. The Defect Grid Toolbar is located above the defect list grid. The icons are rendered dynamically based on what is currently selected in the grid. This toolbar contains options for processing grid selections. For example, the toolbar shows options applicable to defects if only defects are selected.

This table describes all possible options that may appear on the Defect and Repair grid toolbar.

Option

Active When

Description

Repair

At least one open defect is selected on the grid.

Opens the Repair Defect pop-up. The status of each selected defect is changed to "Repaired" once the repair is logged.

Reopen

At least one repaired defect is selected in the grid.

Immediately changes the status of each selected defect to "Open."

Change Reason

A defect is selected in the grid.

Enables the operator to change the defect reason for a selected defect.

Notes

A defect is selected in the grid.

Opens a pop-up showing inspect and repair notes for the selected grid row.

Delete

At least one open defect is selected in the grid.

Enables the operator to delete selected defects.
How to View Defect Information for a Container

Follow these steps to view defect information for a container:

1. Open the Industry Defect page from the Container menu. The Industry Defect page appears.
2. Select or enter a container in the Container field. The application updates the container header and selection fields to display information for the specified container. Values appear only if they were entered for the container.
