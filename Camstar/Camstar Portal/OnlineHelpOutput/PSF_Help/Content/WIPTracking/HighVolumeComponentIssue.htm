High Volume Component Issue

You can use the High Volume Component Issue page to track containers associated with a resource that supports high volume component issue. A resource is configured for high volume traceability if the following are true:

• The resource has the "Use High Volume Traceability" option selected in the Resource Modeling page.
• The resource is configured with high volume machine setup.

While the service is automatically performed during a container move transaction if an associated resource is configured for High Volume issue, the High Volume Component Issue page provides an alternative way for users to manually execute the same service.

The application provides traceability on all components loaded to the resource at the time a container was processed. Combining this information with a container's material list (components required by the container), the application can determine what components should have been issued to the container. A component is considered issued if the following are true:

• Product of material list item matches product of any component loaded to the resource.
• Spec or Route Step is not configured on the material list item.
• If the Spec or Route Step is configured, the current Spec/ Step where the container is processed matches the configured value.
Note: The system is unable to recognize what component is issued compared to a standard component issue processing, as it only associates the container to the machine setup at the time the High Volume issue was performed. The rules above are then dynamically applied during any request to determine what was issued.
Note: The other options to issue the components automatically are "Material Queue" in the Industrial Solution workspace and "Auto Component Issue" in Opcenter Execution Electronics. High Volume Issue takes precedence. If all of the applications above are configured to occur at the same step, the High Volume Issue will take precedence and execute, while the "Material Queue" and "Auto Component Issue" will not be performed.

Issued Components

This section of the page contains a grid to show high volume issued components for the currently selected container. The grid will only populate components issued using the High Volume Component Issue transaction. It will not show any standard issue components.

High Volume Issue is performed on containers with no children. If a parent container is supplied to the transaction, the issue will be performed to all of the child containers. If the currently selected container is a parent, the grid will show the issues for all of the child containers.

How to Configure High Volume Component Issue

Follow these steps to use High Volume Component Issue page:

1. Open the High Volume Component Issue page from the Container menu. The High Volume Componenet issue page appears.
2. Select or enter a Container in the Container field. The application updates the container header and selection fields to display information for the specified container. Values appear only if they were entered for the container.
3. Select the Resource to be associated with the selected container.
Note: Only resources configured for High Volume traceability are visible in the drop down. Components currently loaded to the resource are shown in the Current Setup Detail grid.
4. Click Submit on the command bar. The application performs the High Volume Component Issue transaction and displays a status message with results of execution.
Note: You can expand the Issued Components section to see components currently issued using High Volume Component Issue after selecting a container.
