Supervisor Jobs

The Supervisor Jobs page enables the employee designated as Job Control Supervisor to view, create and perform resource's maintenance or jobs. The assigned supervisor can perform the following actions:

• Job Create
• Job Assign
• Job Complete
• Job Cancel

How to Use the Filters Panel

Follow these steps to use the Filters panel:

1. Select one or more filters in the Filters panel.
2. Click Apply. The application filters the grid results by the selected filters.

How to Use the Supervisor Jobs Page

Follow these steps to use the Supervisor Jobs page:

1. Open the Supervisor Jobs page from the Resource > Jobs > Job Services menu. The Supervisor Jobs page appears.
2. Filter the list of jobs if necessary by selecting values from the Filters panel fields and then clicking Apply. The application displays the list of jobs filtered by any criteria entered.
3. Select the job from the Search Results grid.
4. Click Shop Floor Txns on the command bar. The application displays a slide-out menu of one or more available transactions.
5. Select the transaction. The application displays the transaction pop-up.
6. Use the pop-up to complete the transaction. Documentation is available for each transaction pop-up. Refer to these topics as needed:
• Job Create
• Job Assign
• Job Complete
• Job Cancel
