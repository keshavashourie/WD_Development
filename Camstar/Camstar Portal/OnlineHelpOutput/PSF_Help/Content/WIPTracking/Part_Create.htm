Part Create

Part Create page enables you to create a part that is required to produce or process resource material part. All parts must be associated with a resource material part that helps to define common characteristics such as maintenance requirement. Created parts can be further modified or deleted via Part modeling page.

To access Part Create page from the menu bar, select Resource > Part Services > Part Create.

How to Create a Part

Follow these steps to create a part:

1. Open the Part Create page from the Resource > Part Services > Part Create menu. The Part Create page appears.
2. Enter a name in the Part Create field.
3. Select the Material Part if it is not yet displayed.
4. Enter or change the Part Qty as needed.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit on the command bar. The application saves the data and displays a status message.
