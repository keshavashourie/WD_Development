Smart Scanning

The Smart Scanning feature enables configured fields on Portal pages to be automatically populated when the shop floor operator scans a barcode. For example, when an operator scans a container barcode on the Move In page, the application can populate the Container field and the header fields for which information was entered during earlier transactions.

There are two options for implementing Smart Scanning—default and Rule-Based. Rule-Based Smart Scanning can be configured to provide additional functionality including:

• Automated page action initiation, such as a Save button being clicked, eliminating the need for the operator to click the button.
• Extraction of processed data from the barcode.

The Smart Scanning feature must be enabled and configured. Individual Portal pages must also be configured before their fields can be automatically populated during barcode scanning.

Note: Refer to Smart Scanning in the Opcenter Execution Medical Device and Diagnostics System Administration Guide or the Opcenter Execution Core System Administration Guide and “Defining Smart Scan Rules” in the Opcenter Execution Medical Device and Diagnostics Modeling User Guide or the Opcenter Execution Core Modeling User Guide for more detailed information.
