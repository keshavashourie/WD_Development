Transfer Containers

The Transfer transaction allows you to move a container to any step in any workflow. The Transfer transaction is similar to the Move Non-Std transaction, except a Transfer bypasses any Move In requirements for an operation.

When Transferring a Container

All display fields are empty on the Transfer page until a container is selected. The Container drop-down field lists all containers that are available to be transferred. However, if Line Assignment Setting is configured, the Container drop-down is going to display lists of containers based on the selected Work Center, Operation, or Spec value. You may check the Container header located at top of the page for current line assignment status. The following explains some example on how the Lot field displays information based on line assignment settings:

• If a Work Center is configured, the field displays available containers within the selected Work Center.
• If an Operation is configured, the field displays available containers assigned to the selected Operation.
• If a Spec is configured, the field displays available containers assigned to the selected Spec.
• If Operation and Spec is configured, the field displays available containers assigned to both Operation and Spec.

Refer to "Line Assignment Settings" for more information.


Display fields are populated automatically on the Transfer pop-up. Refer to "Using Transaction Pages and Pop-ups" for information on performing a transaction from a page or pop-up.

The application displays a default value in the Resource field when one of these conditions is true:

• A move in was required for the container's current step and the user moving in the container specified a resource.

Or

• A resource was specified when the container was started and the Transfer is the first transaction (specifying a resource) that you are performing after starting the container.

You can select a different resource, if necessary.

Transfer Page

You can access the Transfer page from the Container menu. The Transfer page allows you to enter or select the container you want to transfer to a step in a workflow.

Note: The Transfer page may also be available as a pop-up if the container transfer transaction has been configured as an available action on another page (for example, Container Search).

Transfer Page and Pop-up Field Definitions

This table defines the fields on the Transfer page and Transfer pop-up.

Field

Definition

Type

Container Information

Header containing the container name and information about that container. You must select or enter a container on a transaction page, but all information is display-only on a transaction pop-up. Refer to "Container Information" for information.

Required/ Display Only

Resource

Resource that processed the container at the current step. You can select a different resource if the application displays one by default. Specifying the resource used at this step before moving the container provides traceability.

The resource values available for selection depend on the resource group assigned to the step (spec). If no resource group was assigned to the spec, all defined resources are available for selection.

Optional

To Workflow

Destination workflow and steps. The steps appear when you expand the workflow. The application moves the container to the next step in the current workflow unless you specify a different workflow or step here.

Optional

To Step

Step in the destination workflow. The application populates this field when you select a step (spec) from the expanded workflow in the To Workflow field.

Display Only

Show/Hide additional fields

Optional fields hidden by default when the application displays a page or pop-up. Clicking the Show control displays the fields. Clicking the Hide control hides the fields.

  

To Location

Location to which the container will go for processing at the next step. A location may be an entire factory, an area of a factory, or as specific as a rack identifier. Locations are defined within the Factory object in Modeling.

Note: This field is hidden by default.

Optional

Comments

Additional information or instructions for this transaction or container. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.

Optional

How to Transfer a Container to Any Step in a Workflow

Follow these steps to transfer a container to any step in a workflow:

1. Open the Transfer page from the Container menu. The Transfer page appears.
2. Select or enter a container in the Container field. The application updates the container header and selection fields to display information for the specified container. Values appear only if they were entered for the container.
Note: The application populates the Container field and the container header automatically when you access the Transfer pop-up from another shop floor page.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Transfer. A status message appears confirming that the container has been transferred.
