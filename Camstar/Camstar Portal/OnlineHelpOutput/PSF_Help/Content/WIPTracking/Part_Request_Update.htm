Part Request Update

The Part Request Update page enables a resource job technician to update a part request.

Note: Part Request Update is also available as a pop-up from the Part Maintenance page.

Part Request Update Page Field Definitions

This table defines the fields on the Part Request Update page.

Field

Definition

Type

Resource

Equipment resource for which you want to request parts or from which you want to return parts.

Required

Job Order

Job order number of an active maintenance job for the resource. This applies if the part request is associated with a job order.

Display Only

Request Order

Request Order created for the Part Resource.

Required

Request Type

Type of part request— either Request or Return.

Display Only

Requested Parts grid

Grid that lists parts requested for the selected resource.

Part

Hide/Show additional fields

Comments

Additional information or instructions for this transaction or container. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.

Optional

How to Update a Part Request

Follow these steps to update a part request:

1. Open the Part Request Update page by selecting Resource > Part Services > Part Request Update. The Part Request Update page appears.
2. Select a resource in the Resource field. The application fills in the remaining page fields.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit. The application displays a success message.
