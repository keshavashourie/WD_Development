Job Progress

The Job Progress page enables technicians to perform a step in an assigned maintenance or repair job. Job Progress becomes available after the assigned technician has acknowledged the job and clocked on. This is the main service that is used by the assigned technician to:

• Move the resource from one stage to another within the Job Model
• Perform data collection, if any.
• Carry out the instructions and checks listed in the checklist.

On the Job Progress page, the technician is given the option to auto trigger the Auto Clock Off transaction. If this is selected, the system will automatically clock the transacting technician off from the job when he is finished with the current stage.

Note: The Job Progress page does not currently support SPC Data Collection. Any fields, checklists, and grids that support SPC data collection are not available.

How to Complete a Job Stage

Follow these steps to complete a job stage in Job Progress page:

1. Open the Job Progress page from the Resource > Jobs > Job Services menu. The Job Progress page appears.
2. Select the Resource field.
3. Optionally, select the Job Order field. The application will auto-populate values in Job Model and Job Type fields.
4. For each checklist listed in the Checklist grid:
a. Select the check box for the grid. The row is highlighted in blue
b. Scroll below the Checklist grid to see any data collections required. The data collection points appear below the grid.
c. Enter each required data point.
d. Click Job Progress. The highlighting color of the selected checklist row changes to green.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit on the command bar. The application saves the data and displays a status message.
