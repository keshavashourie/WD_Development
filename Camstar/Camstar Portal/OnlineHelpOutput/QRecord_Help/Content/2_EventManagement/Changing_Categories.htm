Changing Categories

Use the Change Category action to change event record categories. If a system administrator configured a change category e-mail message (stating the category has been changed), the application automatically generates an e-mail for the owner and the role of the event when the category is changed.

When Changing Categories

You can change the category of a record when:

• The status of the record is NOT Pending, In Review, or Closed.
• You have permission to change categories.

The application disables the Change Category button when either of the above conditions are not met.

When you change a record’s category, the application also updates the record type. For example, if you change the record’s category from event to nonconformance, the application changes the event record from a generic event to a production event.

Changing a record’s category is one way to perform manual triage. When you change a record’s category, the application disables the Triage action button.

How to Change Categories

Follow these steps to change the category for a quality record:

1. Access the quality record to be changed. The record's management page appears.
2. Click Change Category in the Quality Actions pane. The Change Category page appears.
3. Select the appropriate category from the Category list.
4. Enter any relevant comments or notes about the change in the Comments field.
5. Click Submit. The application displays a message stating the Quality Object Category has been changed.
