Auswahlwertausdrücke

Felder können so konfiguriert werden, dass sie eine Liste von Werten anbieten. Das Standardverhalten kann über die Steuerelementeigenschaften in der Feldausdruckerstellung überschrieben werden.

Für die Festlegung von Auswahlwertausdrücken sind folgende Optionen verfügbar:

• Liste statischer Werte (Static Value List)
• Festgelegte Daten (Set Data)
• Abfrage

Mit statischen Auswahlwerten können Sie alle Instanzobjekte anzeigen, die den gleichen Feldtyp aufweisen.

Mit einer Abfrage können Sie die Auswahlwerte eines Felds auf der Grundlage der Abfrage definieren.

Beim Verwenden von Auswahlwertausdrücken

Mit der Option "Statisch" (Static) können Sie die Auswahlwertabfrage nicht ändern.

Mit dem Wertausdruck (ValueExpression) können Sie den Produktnamen und die Version zu einer einzigen Spalte kombinieren. Sie müssen jedoch die richtige Syntax verwenden, z. B.:

(Product) : (Rev)
