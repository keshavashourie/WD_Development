Konfigurieren von Beschriftungen für boolesche Dropdown-Steuerelemente

In Portal Studio können Sie benutzerdefinierte Beschriftungen für die Werte "Wahr" und "Falsch" in booleschen Dropdown-Steuerelementen festlegen, indem Sie die Eigenschaften der Steuerelemente ändern.

Beim Konfigurieren von Beschriftungen für boolesche Dropdown-Steuerelemente

True- und False-Beschriftungen müssen im Format X_BenutzerdefinierteBeschriftung eingegeben werden, wobei X eine Designer- oder Benutzerbeschriftung im System und BenutzerdefinierteBeschriftung der Name Ihrer benutzerdefinierten Beschriftung ist. Die standardmäßigen Beschriftungen lauten "True" (Wahr) oder "False" (Falsch), wenn die Beschriftungen nicht konfiguriert werden.

Die Beschriftungen "Wahr" und "Falsch" werden unabhängig voneinander konfiguriert. Die Konfiguration der Beschriftungen "Wahr" und "Falsch" bezieht sich ausschließlich auf das zu ändernde Steuerelement und wirkt sich nicht auf die Beschriftungen anderer Steuerelemente aus.

Das boolesche Dropdown-Steuerelement wird in der Liste der verfügbaren Steuerelemente im Fensterbereich "Toolbox" angezeigt. Weitere Informationen zum Hinzufügen von Steuerelementen zu einem Webpart finden Sie unter "Hinzufügen eines Steuerelements zu einem Webpart".

Vorgehensweise zum Konfigurieren von Beschriftungen für boolesche Dropdown-Steuerelemente

Gehen Sie folgendermaßen vor, um Beschriftungen für boolesche Dropdown-Steuerelemente zu konfigurieren:

1. Greifen Sie auf Portal Studio zu.
2. Doppelklicken Sie auf eine Seite oder ein Webpart, die oder das ein boolesches Dropdown-Steuerelement enthält. Die Seite bzw. das Webpart wird im Arbeitsbereich angezeigt.
3. Wählen Sie ein boolesches Dropdown-Steuerelement aus. Die Eigenschaften für das boolesche Dropdown-Steuerelement werden im Fensterbereich "Eigenschaften" angezeigt.
4. Geben Sie im Bereich "Eigenschaften" im Feld False-Beschriftung (FalseLabel) die neue False-Beschriftung ein.
5. Geben Sie im Bereich "Eigenschaften" im Feld True-Beschriftung (TrueLabel) die neue True-Beschriftung ein.
6. Klicken Sie auf Speichern. Die Anwendung speichert Ihre Änderungen und zeigt eine Erfolgsmeldung an.
