Kopieren von Steuerelementen

Sie können Steuerelemente im Arbeitsbereich von Portal Studio kopieren.

Beim Kopieren von Steuerelementen

Dem kopierten Steuerelement wird ein eindeutiger Name zugewiesen.

Vorgehensweise zum Kopieren von Steuerelementen

Gehen Sie folgendermaßen vor, um Steuerelemente zu kopieren:

1. Greifen Sie auf Portal Studio zu.
2. Doppelklicken Sie auf eine Seite oder ein Webpart. Die Seite bzw. das Webpart wird im Arbeitsbereich angezeigt.
3. Wählen Sie im Arbeitsbereich ein Steuerelement aus.
4. Drücken Sie die STRG-Taste und ziehen Sie das ausgewählte Steuerelement auf eine Zelle in einem Webpart. Die Anwendung fügt der Beschriftung ein "+"-Symbol hinzu, wenn Sie die Strg-Taste drücken.
5. Klicken Sie auf Speichern. Die Anwendung speichert Ihre Änderungen.
