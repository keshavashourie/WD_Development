Konfigurieren von QuickInfos für Steuerelemente

Wenn Sie den Mauszeiger über Steuerelemente auf Seiten bewegen, werden QuickInfos zu den Steuerelementen angezeigt. QuickInfos können Sie unter Verwendung von Text und Beschriftungen in Portal Studio konfigurieren.

Beim Konfigurieren von QuickInfos für Steuerelemente

QuickInfos für Steuerelemente werden im Bereich "Eigenschaften" konfiguriert. Die Eigenschaft "QuickInfoText" (ToolTipText) erstellt eine QuickInfo mit dem Text, den Sie in das Feld "ToolTipText" eingeben. Die Eigenschaft "ToolTipLabel" öffnet das Popup "Beschriftungssuche" zum Suchen und Auswählen einer Beschriftung, die als QuickInfo verwendet werden soll. Weitere Informationen zum Popup "Beschriftungssuche" finden Sie unter "Suchen nach Seitenaktionsbeschriftungen".

Die Eigenschaft "QuickInfoText" (ToolTipText) hat Vorrang vor der Eigenschaft "QuickInfoBeschriftung" (ToolTipLabel), wenn Text in beide eingegeben wurde und eine Beschriftung ausgewählt wurde.

Hinweis: Führen Sie nach dem Speichern der QuickInfo ein "IISReset" aus oder löschen Sie den Bowsercache, falls erforderlich.

Vorgehensweise zum Konfigurieren von QuickInfos für Steuerelemente

Gehen Sie folgendermaßen vor, um QuickInfos für Steuerelemente zu konfigurieren:

1. Greifen Sie auf Portal Studio zu.
2. Doppelklicken Sie auf eine Seite oder ein Webpart mit einem Steuerelement. Die Seite bzw. das Webpart wird im Arbeitsbereich angezeigt.
3. Wählen Sie ein Steuerelement aus. Die Eigenschaften für das Steuerelement werden im Bereich "Eigenschaften" angezeigt.
4. Möchten Sie für die QuickInfo einen Text eingeben oder eine Beschriftung auswählen?

Sie möchten . . .

Dann . . .

Einen Text eingeben
a. Geben Sie den Text für die QuickInfo im Bereich "Eigenschaften" in das Feld QuickInfoText (ToolTipText) ein.
b. Gehen Sie zu Schritt 5.

Eine Beschriftung auswählen
a. Klicken Sie im Fensterbereich "Eigenschaften" auf Mehr für ToolTipLabel. Das Popup "Beschriftungssuche" wird angezeigt.
b. Geben Sie ein oder mehrere Suchkriterien ein, um die Suche einzugrenzen, und klicken Sie anschließend auf Suchen. Die Anwendung zeigt die Beschriftungen, die Ihren Suchkriterien entsprechen, in der Tabelle an.
c. Wählen Sie eine Beschriftung aus. Der Standardtext und der lokale Text für die Beschriftung werden in den Feldern "Standardtext" (Default Text) und "Lokaler Text" (Local Text) angezeigt.
d. Klicken Sie auf OK. Das Popup "Beschriftungssuche" wird geschlossen und die Informationen für die Beschriftung werden im Feld "QuickInfoBeschriftung" (ToolTipLabel) angezeigt.
e. Gehen Sie zu Schritt 5.
5. Klicken Sie auf Speichern. Die Anwendung speichert Ihre Änderungen und zeigt eine Erfolgsmeldung an.
