Creating Page Action Rules

Page action rules determine when an action is active on a Portal page using custom expressions.

When Creating Page Action Rules

Page action rules are created by defining one or more expressions on the Page Action Rule Builder pop-up. Expressions are statements that indicate a page action should be shown or enabled when the statement evaluates to true. Expressions are highly customizable and multiple expressions can be defined within a single page action rule using operators such as "And" and "Or". Supported expression options include Container, Resource, Event, or Change Package.

Note: The "And" operation appears in the first drop-down on the Page Action Rule Builder pop-up by default, but will not be added to the first expression defined for a page action rule. The "And" or "Or" operations will be added to all subsequent expressions added to the page action rule.

You must add custom page action rules to page actions to customize page action behavior. Refer to "Adding Page Action Rules to Page Actions" for information.

How to Create Page Action Rules

Follow these steps to create page action rules:

1. Access Portal Studio.
2. Click New and select Page Action Rule. A blank page action rule appears in the working area.
3. Enter a name in the Name field.
4. Click More for Expression. The Page Action Rule Builder pop-up appears.
5. Select operations and values from the drop-downs or enter custom information manually in the text fields to define your custom expression.
6. Click Add. The expression appears in the text box above the drop-downs and in the list of expressions below the drop-downs.
7. Repeat steps 5-6 to add additional expressions.
8. Click OK. The Page Action Rule Builder pop-up closes.
9. Click Save. The application saves your changes and displays a success message.
