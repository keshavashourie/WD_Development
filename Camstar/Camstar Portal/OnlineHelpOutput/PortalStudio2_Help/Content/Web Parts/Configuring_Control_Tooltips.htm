Configuring Control Tooltips

Control tooltips display when hovering the mouse cursor over controls on pages. Tooltips can be configured in Portal Studio using text or labels.

When Configuring Control Tooltips

Control tooltips are configured in the Properties pane. The ToolTipText property creates a tooltip using text entered in the ToolTipText field. The ToolTipLabel property opens a Label Lookup pop-up to search for and select a label to use as the tooltip. Refer to "Searching for Page Action Labels" for information on the Label Lookup pop-up.

The ToolTipText property takes priority over the ToolTipLabel property when text is entered in both and a label is selected.

Note: Perform an iisreset or clear the browser's cache, if necessary, after saving the tooltip.

How to Configure Control Tooltips

Follow these steps to configure control tooltips:

1. Access Portal Studio.
2. Double-click a page or web part that contains a control. The page or web part appears in the working area.
3. Select a control. The properties for the control appear in the Properties pane.
4. Do you want to enter text or select a label for the tooltip?

If you want to . . .

Then . . .

Enter text
a. Enter text for the tooltip in the ToolTipText field in the Properties pane.
b. Go to step 5.

Select a label
a. Click More for ToolTipLabel in the Properties pane. The Label Lookup pop-up appears.
b. Enter one or more search criteria to narrow your search and then click Search. The application displays labels matching your search criteria in the grid.
c. Select a label. The default text and local text for the label appear in the Default Text and Local Text fields.
d. Click OK. The Label Lookup pop-up closes and the information for the label appears in the ToolTipLabel field.
e. Go to step 5.
5. Click Save. The application saves your changes and displays a success message.
