Adding a File Browse Control

You can add a file browse control to Portal pages to browse for and upload files to Portal pages.

When Adding a File Browse Control

File browse controls contain two fields: Browse Mode and Locate File.

Controls can only be added to a web part. Controls cannot be added directly to a page. Refer to "Adding a Control to a Web Part" for information.

Important: A file browse control is required for Modeling pages that have file upload functionality.

How to Add a File Browse Control

Follow these steps to add a file browse control:

1. Access Portal Studio.
2. Double-click a page or web part. The page or web part appears in the working area.
3. Click and drag a File Browse control from the Toolbox onto a cell on a web part. The File Browse control appears on the web part.
4. Enter a name for the control in the Name field in the Properties pane.
5. Click Save. The application saves your changes and displays a success message.
