Creating a Page Action Category

Page action categories allow you to group actions to appear on a Portal page.

Page Action Category Field Definitions

This table defines the fields used to create a page action category.

Field

Definition

Type

Name

Unique name for the page action category.

Required

Description

Short description of the page action category.

Optional

FilterTags

Specifies a filter tag enabling you to limit the items available for viewing and selection.

Optional

LabelName

Determines the caption that displays on the page action category. Refer to "Searching for Page Action Labels" for information on searching for labels.

Optional

LabelText

Determines the caption that displays on the page action category. This field supercedes text entered in the LabelName field.

Optional

Notes

Relevant comments about the page action category.

Optional

Sequence

Sequence of this page action category.

Optional

How to Create a Page Action Category

Follow these steps to create a page action category:

1. Access Portal Studio.
2. Click New and select Page Action Category. A blank page action category appears in the working area.
3. Enter a name for the page action category in the Name field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves your changes and displays a success message.
