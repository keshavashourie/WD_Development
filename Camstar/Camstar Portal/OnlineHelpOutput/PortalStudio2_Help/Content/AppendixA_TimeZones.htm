Time Zones

Each TimeZoneCode includes the UTC offset at the beginning of the code. For example, the time zone code for Kuala Lumpur, Singapore is +0800SST, which is UTC plus eight hours.

The TimeZoneCode format combines the UTC offset and a unique code. The application automatically adjusts for seasonal time changes for each time zone based on the selected TimeZoneCode. You should not manually update the time zones for seasonal changes. For example, Eastern Time (US and Canada) has a standard UTC offset of -5:00. The system will automatically use an offset of -4:00 during daylight saving time.
