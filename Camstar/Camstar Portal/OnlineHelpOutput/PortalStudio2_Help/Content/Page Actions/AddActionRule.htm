Adding Page Action Rules to Page Actions

Page action rules determine the conditions for when a page action displays on a page. You can add multiple rules to a page action to specify when the page action appears.

When Adding Page Action Rules to Page Actions

Page action rules can also be removed from a page action. A page action is no longer controlled by a page action rule when the rule has been removed.

ActionRules Modal Field Definitions

The ActionRules modal contains only the Name field. The Name field is used to select an existing page action rule and associate it to the page action.

How to Add Page Action Rules to Page Actions

Follow these steps to add page action rules to page actions:

1. Access Portal Studio.
2. Select the Modeling tab on the Components catalog and double-click a page action. The page action appears in the working area.
3. Click More for ActionRules. The ActionRules modal appears.
4. Click Add. A new action rule appears in the list in the left pane.
5. Select a page action rule from the Name field.
6. Repeat steps 4-5 to add additional page action rules as necessary.
7. Click OK. The ActionRules modal closes.
8. Click Save. The application saves your changes and displays a success message.

How to Delete Page Action Rules from Page Actions

Follow these steps to delete page action rules from page actions:

1. Access Portal Studio.
2. Select the Modeling tab on the Components catalog and double-click a page action. The page action appears in the working area.
3. Click More for ActionRules. The ActionRules modal appears.
4. Select a page action rule from the list in the left pane.
5. Click the Delete icon. The page action rule is removed from the list.
6. Repeat steps 4-5 to delete additional page action rules as necessary.
7. Click OK. The ActionRules modal closes.
8. Click Save. The application saves your changes and displays a success message.
