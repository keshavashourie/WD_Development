Creating a Page

Portal Studio allows you to create pages that are used in the Portal.

When Creating a Page

You can create pages by clicking New on the global toolbar and selecting Page or by clicking the New button on the Pages tab of the Components catalog. The Create New Page pop-up appears when creating a page and allows you to select a template for your page. The Create New Page pop-up contains these templates:

• Blank, which provides a blank template for a basic Portal page.
• Container, which provides the basic components used to develop a container page.
• Modeling, which provides the basic components used to develop a modeling page.

You must enter a name for your page in the Page Name field to enable the OK button on the Create New Page pop-up.

Once you create a new page, web parts can then be dragged onto the page. Controls and fields cannot be dragged directly onto a page; they must be placed on a web part. Refer to "Adding a Web Part to a Page" for information on adding web parts to a page.

You can test a page after it is saved using the Run button. Refer to "Testing a Page" for information.

WIP Messaging is set to True in the Portal Settings by default. Since page settings override the global setting, you can disable WIP Messaging for a page using the WIPMessagesRequired field in the Properties pane.

Opening Existing Pages

Existing pages can be opened from the Components Catalog. Refer to “Opening Existing Components” for information on opening existing pages.

How to Create a Page

Follow these steps to create a page:

1. Access Portal Studio.
2. Click the New button and select Page. The Create New Page pop-up appears.
3. Select a page template.
4. Enter a name for the page in the Page Name field.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click OK. The Create New Page pop-up closes and the new page appears in the working area.
7. Click Save. The application saves your changes and displays a success message.
