Adding a Web Part to a Page

Web parts can be added to a page as either a local copy or a reference.

When Adding a Web Part to a Page

Referenced web parts are read-only copies that refer to a master copy of the web part. This allows you to maintain a web part in one place instead of maintaining several individual web parts.

Siemens recommends you add a web part as a:

• Reference when the web part will be the same on all pages and maintained in a single place. Refer to "Viewing Referenced Web Part Locations" for information on viewing a list of components referencing a web part.
• Copy when the web part is a template or when using one web part to make a similar web part.

When testing a page with a reference web part, the Developer content of the reference web part is always displayed.

When a page with a reference web part is published, the Published content of the reference web part is always displayed.

Note: You can only add a web part to a page when you are in Controls view. You cannot drag a web part onto a cell on the page If you are in Design view.

How to Add a Web Part to a Page

Follow these steps to add a web part to a page:

1. Access Portal Studio.
2. Double-click a page. The page appears in the working area.
3. Ensure that Controls is selected in the View list.
4. Expand Web Parts in the Components catalog.
5. Select a web part and drag it onto a cell on the page. The Add Web Part pop-up appears.
6. Do you want to add the web part as a local copy or as a reference?

If you want to add the web part as a . . .

Then . . .

Reference
a. Click Reference. The Add Web Part pop-up closes and the web part appears in the cell.
b. Go to step 7.

Local copy
a. Click Copy. The Add Web Part pop-up closes and the web part appears in the cell.
b. Go to step 7.
7. Click Save. The application saves your changes and displays a success message.
