SetData Property

The SetData property allows control values to be set from a number of different sources such as:

• Another control in any web part on the current page
• Session Data Contract
• User
• Connection Profile
• Organization
• Factory
• WorkCenter
• Operation
• Resource
• Workstation
• HasCMPackage
• IsResponsive
• AllowLineSettingsOverride
• Field Expression
• Static Value

It also allows the use of one or more Initiators to be configured to control when the SetData occurs.
