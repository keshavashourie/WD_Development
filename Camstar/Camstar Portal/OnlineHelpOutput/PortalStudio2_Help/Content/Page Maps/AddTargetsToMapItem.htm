Adding Targets to a Page Map

Targets are the target page, pageflow, or separate page mapping item where you are directed after the logic is applied.

Targets Modal Field Definitions

This table defines the fields on the Targets modal.

Field

Definition

Type

Conditions

Enables you to associate page mapping filter conditions to the target.

Note: Clicking the More button displays the Conditions modal. Refer to "Conditions Modal Field Definitions" for information on the properties that appear on this modal.

Optional

Links

Enables you to define UI component data contract links for the target.

Note: Clicking the More button displays the Links modal. Refer to "Links Modal Field Definitions" for information on the properties that appear on this modal.

Selects a target page, pageflow, or page mapping item and sets it as the target.

How to Add Targets to a Page Map

Follow these steps to add targets to a map item:

1. Access Portal Studio.
2. Select the Modeling tab on the Components catalog and double-click a page map. The page map appears in the working area.
3. Click More for Targets. The Targets modal appears.
4. Click Add. A target is added to the list.
5. Select a target type from the Target Type field.
6. Select a target from the Target field.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Repeat steps 4-7 to add additional targets.
9. Click OK. The Targets modal closes.
10. Click Save. The application saves your changes and displays a success message.
