Creating a Pageflow

Pageflows are used to link pages together to create the desired flow of pages.

When Creating a Pageflow

Dragging a new page onto the pageflow automatically creates a link to the page that is currently highlighted in the pageflow.

You can manage the transition between two pages using the Conditions Editor to create conditional expressions. Click on the arrow between pages to display the RuleCondition property in the Properties pane. Clicking the More button for the RuleCondition property displays the Conditions Editor. Refer to "Conditions Editor" for information on using the Conditions Editor.

You can view or edit the properties of pageflows and the page nodes within pageflows from the Properties pane. Refer to "Pageflow Properties" for information on modifying pageflow properties.

Opening Existing Pageflows

Pageflows you have created can be opened from the UI Components catalog. Refer to “Opening Existing Components” for information on opening existing pageflows.

How to Create a Pageflow

Follow these steps to create a pageflow:

1. Access Portal Studio.
2. Click New and select Pageflow. A blank pageflow appears in the working area.
3. Enter a name for the pageflow in the PageFlowContent Name field of the Properties pane.
4. Click Save. The application saves your changes and displays a success message.
