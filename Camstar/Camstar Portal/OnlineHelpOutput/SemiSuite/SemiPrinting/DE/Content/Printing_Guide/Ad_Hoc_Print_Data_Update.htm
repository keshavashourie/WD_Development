Druckdaten aktualisieren

Über die Seite "Druckdaten aktualisieren" können Sie den Status eines Druckauftrags manuell aktualisieren und die zu druckende Fehlermeldung für einen Druckauftrag festlegen, der fehlgeschlagen ist.

Definition der Felder auf der Seite "Druckdaten aktualisieren"

In der folgenden Tabelle werden die Felder auf der Seite "Druckdaten aktualisieren" erläutert.

Feld

Definition

Typ

Druckstatus

Feld, in dem das Los ausgewählt wird.

Optional

Daten ausgeben

Durch das System generierte ID, die eine Druckanforderung identifiziert.

Erforderlich

Details

Aktion

Status des Druckauftrags.

Erforderlich

Computername

Name des Client-PCs oder name.domain des Computers, an den die Druckanforderung weitergeleitet werden soll.

Optional

Sequenznummer des PrintData-Elementdatensatzes, der die Fehlermeldung im Feld "Meldung für Druckfehler" verursacht hat

Optional

Meldung für Druckfehler

Beschreibung eines Druckanforderungsfehlers.

Optional

Vorgehensweise zum Verwenden der Seite "Druckdaten aktualisieren"

Gehen Sie folgendermaßen vor, um die Seite "Druckdaten aktualisieren" zu verwenden:

1. Öffnen Sie die Seite Druckdaten aktualisieren. Die Seite "Druckdaten aktualisieren" wird angezeigt.
2. Geben Sie die Druckanforderungs-ID in das Feld Daten ausgeben ein.
3. Geben Sie den Status des Druckauftrags in das Feld Aktion ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Abschicken. Die Anwendung führt die Anforderung aus und zeigt eine Statusnachricht an.
