Drucken

Über die Seite "Drucken" können Sie eine Druckeinrichtung manuell ausführen. Bei einer Druckeinrichtung handelt es sich um ein Modellierungsobjekt, das einer Druckanforderung zugeordnet ist, um Verarbeitungsanweisungen bereitzustellen. Das Objekt wird für das automatisierte Drucken verwendet, kann jedoch auch über das Menü ausgeführt werden. Für die Ad-hoc-Verwendung des Objekts ist es erforderlich, dass Sie die Parameterdaten angeben, die normalerweise durch die Transaktion angegeben werden würden.

Definition der Felder auf der Seite "Drucken"

In der folgenden Tabelle werden die Felder auf der Seite "Drucken" erläutert.

Feld

Definition

Typ

Name der Druckeinrichtung

Feld, in dem der Name der auszuführenden Druckeinrichtung ausgewählt wird.

Erforderlich

Mitarbeiter

Mitarbeiter, der diese Transaktion ausführt, wenn er nicht der derzeit angemeldete Benutzer ist.

Optional

Drucktyp

Definiert den Druckzieltyp, z. B. LABEL, REPORT und TEXTFILE.

Nur Anzeige

Beschreibung

Kurze Beschreibung der Druckeinrichtung.

Nur Anzeige

Tabelle "Details"

Tabelle, in der die Parameter aufgeführt sind, mit denen die Eingabedaten für die Druckanforderung bereitgestellt werden.

Optional

Parametername

Name des Parameters.

Nur Anzeige

Parameterwert

Wert, der für den Parameter einzufügen ist.

Optional

Drucker

Drucker, an den Ausgabe weitergeleitet wird.

Erforderlich

Anzahl der Kopien

Erforderlich

Vorgehensweise zum Verwenden der Seite "Drucken"

Gehen Sie folgendermaßen vor, um die Seite "Drucken" zu verwenden:

1. Öffnen Sie die Seite Drucken. Die Seite "Drucken" wird angezeigt.
2. Geben Sie in das Feld Drucken den Namen der Druckeinrichtung ein.Die Anwendung zeigt Informationen zur ausgewählten Druckeinrichtung an.
3. Geben Sie in die Tabelle Details die erforderlichen Parameterwerte ein.
4. Geben Sie in das Feld Drucker einen Drucker ein, wenn die Standardeinstellung nicht korrekt ist.
5. Geben Sie die Anzahl der Kopien ein, wenn der Standardwert nicht korrekt ist.
6. Klicken Sie auf Abschicken.Die Anwendung führt Ihre Druckanforderung aus und leitet sie an den angegebenen Drucker weiter.
