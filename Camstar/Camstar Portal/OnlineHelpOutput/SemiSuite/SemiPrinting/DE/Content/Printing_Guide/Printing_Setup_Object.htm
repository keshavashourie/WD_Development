Definieren von Druckeinrichtungen

Das Druckeinrichtungsobjekt ermöglicht Ihnen das Angeben von Ausgabeformat, Abfragen und anderen wichtigen Faktoren für die Verarbeitung von Druckanforderungen.

Definition der Felder auf der Seite "Druckeinrichtung"

In der folgenden Tabelle werden die Felder auf der Seite "Druckeinrichtung" erläutert.

Feld

Definition

Typ

Druckeinrichtung

Name dieser Instanz des Druckeinrichtungsobjekts.

Erforderlich

Beschreibung

Kurze Beschreibung des Modellierungsobjekts. Sie können maximal 255 Zeichen eingeben.

Optional

Hinweise

Relevante Kommentare zum Modellierungsobjekt. Sie können maximal 2000 Zeichen eingeben.

Optional

Details

Einrichtungszugriff

Legt den Zugriff des einzelnen Mitarbeiters auf das jeweilige Modellierungsobjekt fest.

Optional

Drucktyp

Definiert den Druckzieltyp, z. B. LABEL, REPORT und TEXTFILE. Dieser Wert wirkt sich während einer Drucktransaktion auf die Auswahl der verfügbaren Drucker aus.

Erforderlich

Druckverbindung

Verknüpfung zu einer Druckverbindungsinstanz. Diese Angabe ist nur erforderlich, wenn für den Drucktyp der Wert "REPORT" ausgewählt wurde.

Das Drucksystem übergibt die Werte im Feld "Druckverbindung" an die Berichtsvorlage, um eine Verbindung zu einer Datenbank herzustellen.

Optional

Dateiname (Filename)

Speicherort und Dateiname der zu verwendenden Vorlage. Dabei kann es sich um einen lokalen oder Netzwerkspeicherort handeln.

• LABEL – Speicherort und Dateiname der zu verwendenden Etikettenvorlage. Die Vorlage kann sich in einem lokalen oder Netzwerkspeicherort befinden, z. B. D:\PRINTSYSTEM\TEMPLATES\WAFERLBL.ZPL.
• REPORT – Speicherort und Dateiname der zu verwendenden Berichtsvorlage. Die Vorlage kann sich in einem lokalen oder Netzwerkspeicherort befinden, z. B. \\ShareServer\Rpttemplates\Traveler.rpt.
• TEXTFILE – Speicherort und Dateiname der ausgegebenen Zieltextdatei. Dies kann sich unter einer lokalen oder Netzwerkverbindung befinden, z. B. D:\PrintSystem\Output\TestText.txt. Darüber hinaus können Textdateien so konfiguriert werden, dass sie dynamisch basierend auf einer spezifischen Formatierung benannt werden, z. B. D:PrintSystem\Output\#Container#_File.txt. Die Konfiguration des Speicherorts und Dateinamens der Textdateivorlage wird mit dem reservierten Druckparameternamen (TEXTFILE_TEMPLATE) verwaltet. Weitere Informationen können Sie dem Abschnitt "Druckparameter" entnehmen.

Erforderlich

Anzahl der Kopien

Anzahl der zu druckenden Kopien. Der Standardwert ist 1.

Erforderlich

SQL vor Transaktion

SQL, das auszuführen ist, bevor ein beliebiger Druckeinrichtungsparameter aufgelöst wird. Hiermit kann der Benutzer SQL ausführen, das eine temporäre Ausgabe produziert, z. B. eine temporäre Tabelle, die während der Parameterauflösung verwendet wird.

Optional

SQL nach Transaktion

SQL, das auszuführen ist, nachdem alle Parameter aufgelöst wurden, z. B. eine Anweisung zum Löschen einer temporären Tabelle.

Optional

Offset für Boxanzahl aktivieren

Kontrollkästchen, über das bestimmt wird, ob der Parameter für die Kartonanzahl über mehrere Drucksätze verwendet oder zurückgesetzt wird.

Wenn "Offset für Boxanzahl aktivieren" aktiviert ist, gilt Folgendes:

• Printset 01 Boxnumber Parameter Value 1
• Printset 02 Boxnumber Parameter Value 1
• Printset 03 Boxnumber Parameter Value 1

Wenn "Offset für Boxanzahl aktivieren" deaktiviert ist, gilt Folgendes:

• Printset 01 Boxnumber Parameter Value 1
• Printset 02 Boxnumber Parameter Value 2
• Printset 03 Boxnumber Parameter Value 3

Weitere Informationen können Sie dem Abschnitt "Drucksatzberechnung" entnehmen.

Optional

Tabelle "Parameter"

Liste der Parameter, die zur Druckausführung verwendet werden. Informationen dazu, wie Parameter aufgelöst werden, können Sie dem Abschnitt "Druckparameter" entnehmen.

Optional

Parametername

Parametername, der in der Druckausgabe verwendet oder gesendet wird. Eine Liste der verfügbaren Systemparameter können Sie dem Abschnitt "Druckparameter" entnehmen.

Hinweis: Das Ausfüllen dieses Felds ist beim Hinzufügen eines Parameters obligatorisch.

Optional

Parametertyp

Gültige Werte für den Parametertyp:

• REQUIRED – Ein Wert ist erforderlich.
• OPTIONAL – Ein Wert ist nicht erforderlich.
• INTERNAL – Der Wert wird durch das System bestimmt. Dieser Parameter wird dem Benutzer nicht angezeigt.

Bei Verwendung des Ad-hoc-Druckformulars:

• Wenn "Parametertyp" = REQUIRED, wird der Parameter in Fettschrift (weist auf Pflichtfeld hin) angezeigt.
• Wenn "Parametertyp" = OPTIONAL, wird der Parameter angezeigt.
• Wenn "Parametertyp" = INTERNAL, wird der Parameter nicht angezeigt.

Hinweis: Das Ausfüllen dieses Felds ist beim Hinzufügen eines Parameters obligatorisch.

Optional

Parameterwert

Standardmäßiger Parameterwert.

Optional

Parameterwert ist dynamisch

Kontrollkästchen, über das bestimmt wird, ob der Parameterwert intern durch den XML-Server aufgelöst wird. Der Parameterwert muss einer gültigen Designer-Notation entsprechen, damit die Einstellung des Kontrollkästchens gültig ist.

Optional

An Drucker senden

Dieses Feld wird von der Anwendung nicht verwendet.

 

Text anzeigen

Zeigt den Text für einen Parameternamen an. Wenn kein Text verfügbar ist, wird der Parametername in der Anzeige verwendet.

Optional

Formelcode

Funktion zur Formatierung von Zeichenketten, die auf Parameterwerte angewendet werden kann. Die verfügbaren Funktionen lauten:

• RPAD – Füllt den Parameterwert rechts. Der Längenwert ist in der Formel Param01 definiert, z. B. 10.
• LPAD – Das Füllzeichen ist in der Formel Param02 definiert, z. B. X.
• TRIM – Verringert die Länge des Parameterwerts. Der Längenwert ist in der Formel Param01 definiert.
• Teilzeichenfolge – Extrahiert eine Teilzeichenfolge des Parameterwerts. Der Längenwert ist in der Formel Param01 definiert. Der Startindex der Zeichenfolge ist in der Formel Param02 definiert.

Optional

Formelparam. 01

Wird in Verbindung mit den Formelcodes verwendet.

Optional

Formelparam. 02

Wird in Verbindung mit den Formelcodes verwendet.

Optional

Formelparam. 03

Wird in Verbindung mit den Formelcodes verwendet.

Optional

Abfragentabelle

Liste der Abfragen, die während der Parameterauflösung verwendet werden.

Optional

Abfragetext

Abfragetext – SQL-Abfrage, die zum Produzieren von Parameterwerten ausgeführt wird.

Hinweis: Das Ausfüllen dieses Felds ist beim Hinzufügen einer Abfrage erforderlich.

Optional

Drucken überspringen, wenn keine Datensätze

Flag, das angibt, ob ein Druckauftrag übersprungen oder abgebrochen werden soll, wenn durch die Abfrage keine Datensätze produziert werden.

Optional

Teilmengentabelle

Liste der Druckeinrichtungen für Teilmengen, die auf Drucksatzebene ausgelöst werden.

Optional

Druckeinrichtung für Teilmenge

Enthält zusätzliche Druckanforderungen für jeden Drucksatz. So kann z. B. ein Karton nur ein Etikett erfordern, während für jedes Element in dem Karton ebenfalls ein Etikett erforderlich ist. Die Elemente im Karton würden durch die Druckeinrichtung für Teilmenge abgedeckt. Wird in der Regel für Etiketten verwendet.

Hinweis: Das Ausfüllen dieses Felds ist beim Hinzufügen einer Teilmenge obligatorisch.

Optional

Vorgehensweise zum Definieren einer Druckeinrichtung

Gehen Sie folgendermaßen vor, um eine Druckeinrichtung zu definieren:

1. Öffnen Sie die Seite Druckeinrichtung. Die Seite "Druckeinrichtung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Druckeinrichtung einen Namen für die neue Instanz ein.
4. Geben Sie einen Drucktyp ein.
5. Geben Sie den Dateinamen ein.
6. Geben Sie in das Feld Anzahl der Kopien einen Wert ein.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
