Definieren von Druckern

Das Druckerobjekt definiert die physischen Drucker, die für das System verfügbar sind. Die Druckerinstanznamen müssen exakt mit dem Namen des physischen Druckers übereinstimmen. Wenn die Namen nicht übereinstimmen, kann das Drucksystem keine Verbindung zu dem physischen Drucker herstellen.

Hinweis: Wenn sich der physische Drucker auf einem Netzwerkdruckserver befindet, muss der Instanzname nicht den Druckservernamen enthalten. Der Druckservername ist im Feld "Name des Druckservers" definiert.

Definition der Felder auf der Seite "Drucker"

In der folgenden Tabelle werden die Felder auf der Seite "Drucker" erläutert.

Feld

Definition

Typ

Drucker

Name des Druckers. Muss dem Namen des physischen Druckers entsprechen.

Erforderlich

Beschreibung

Kurze Beschreibung des Modellierungsobjekts. Sie können maximal 255 Zeichen eingeben.

Optional

Hinweise

Relevante Kommentare zum Modellierungsobjekt. Sie können maximal 2000 Zeichen eingeben.

Optional

Details

Einrichtungszugriff

Legt den Zugriff des einzelnen Mitarbeiters auf das jeweilige Modellierungsobjekt fest.

Optional

Nutzerfelder

Wird verwendet: Timeout (Minuten)

Für den Abschluss einer Druckanforderung vorgesehene Zeit, bevor der Drucker für die Verarbeitung der nächsten Druckanforderung freigegeben wird. Ein Wert von 0 oder weniger gibt an, dass kein Timeout vorgesehen ist. Der Wert ist standardmäßig auf 5 Minuten eingestellt.

Optional

Letztes Drucken: Zeitstempel

Zeigt den Zeitstempel des letzten Druckvorgangs an.

Nur Anzeige

Druckertyp

Definiert den Druckzieltyp, z. B. LABEL, REPORT und TEXTFILE.

Erforderlich

Druckintervall

Intervall, das gewährleistet, dass der Drucker innerhalb der angegebenen Zeitspanne nach dem letzten Druck nicht verwendet wird. Ein Wert von 0 oder weniger gibt an, dass keine Wartezeit erforderlich ist. Für die Druckautomatisierung wird dieser Wert ignoriert.

Optional

Name des Druckservers

Name eines Druckservers, wenn der physische Drucker mit einem verbunden ist.

Optional

Vorgehensweise zum Definieren eines Druckers

Gehen Sie folgendermaßen vor, um einen Drucker zu definieren:

1. Öffnen Sie die Seite Drucker. Die Seite "Drucker" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Drucker einen Namen für die neue Druckerinstanz ein.
4. Wählen Sie einen Druckertyp aus.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
