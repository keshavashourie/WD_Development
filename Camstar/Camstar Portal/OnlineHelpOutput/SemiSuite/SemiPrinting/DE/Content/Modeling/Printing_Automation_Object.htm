Definieren von Matrixobjekten zur Druckautomatisierung

Das Matrixobjekt zur Druckautomatisierung wird verwendet, um eine Transaktion, die eine automatisierte Druckanforderung auslöst, und die Druckeinrichtungen zu definieren, die für diese Anforderung ausgeführt werden.

Definition der Felder auf der Seite "Druckautomatisierung"

In der folgenden Tabelle werden die Felder auf der Seite "Druckautomatisierung" erläutert.

Feld

Definition

Typ

Kriterien

Dienstname

Service (Transaktion) zum Auslösen eines Ausdrucks.

Erforderlich

Spez.

Spezifikation zur Spezifizierung der Druckautomatisierung.

Optional

Prozessspez.: Objekttyp

Objekttyp der Prozessspezifikation zur Spezifizierung der Druckautomatisierung.

Optional

Kundencode

Kundencode zur Spezifizierung der Druckautomatisierung.

Optional

Details

Druckautomatisierung: Name

Eindeutiger Name für die Matrixinstanz. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld automatisch aus, wenn Sie die Instanz speichern.

Optional

Beschreibung

Kurze Beschreibung des Modellierungsobjekts. Sie können maximal 255 Zeichen eingeben.

Optional

Tabelle "Details"

Tabelle, die mindestens eine Druckeinrichtung enthält, die automatisch für die angegebene Transaktion ausgelöst wird.

Einrichtung, die für automatisierte Druckanforderungen verwendet wird. Siehe "Definieren von Druckeinrichtungen".

Vorgehensweise zum Definieren einer Matrixinstanz zur Druckautomatisierung

Gehen Sie folgendermaßen vor, um eine Matrixinstanz zur Druckautomatisierung zu definieren:

1. Öffnen Sie die Seite Druckautomatisierung. Die Seite "Druckautomatisierung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie.
3. Geben Sie im Feld Servicename den Service (Transaktion) ein, der einen Ausdruck auslöst.
4. Geben Sie in das Feld Druckautomatisierung: Name einen Namen für die Matrixinstanz der Druckautomatisierung ein.
5. Führen Sie Folgendes in der Tabelle Details für jede Druckeinrichtung aus:
a. Klicken Sie auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
b. Geben Sie in das Feld Druckeinrichtung die Druckeinrichtung ein.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
