Definieren von Druckertypen

Das Druckertypobjekt definiert Druckertypen. Instanzen dieses Objekts sind mit Instanzen des Druckertypobjekts verknüpft.

Beim Definieren von Druckertypen

Der Name des Druckertyps muss exakt dem Namen des physischen Druckers entsprechen.

Definition der Felder auf der Seite "Druckertyp"

In der folgenden Tabelle werden die Felder auf der Seite "Druckertyp" erläutert.

Feld

Definition

Typ

Druckertyp

Name für diese Instanz des Druckertypobjekts.

Erforderlich

Beschreibung

Kurze Beschreibung des Modellierungsobjekts. Sie können maximal 255 Zeichen eingeben.

Optional

Hinweise

Relevante Kommentare zum Modellierungsobjekt. Sie können maximal 2000 Zeichen eingeben.

Optional

Einrichtungszugriff

Legt den Zugriff des einzelnen Mitarbeiters auf das jeweilige Modellierungsobjekt fest.

Optional

Drucktyp

Feld, in dem der Typ der Ausgabe ausgewählt wird, die der Drucker produziert. Mögliche Optionen sind LABEL, REPORT und TEXTFILE.

Erforderlich

Vorgehensweise zum Definieren eines Druckertyps

Gehen Sie folgendermaßen vor, um einen Druckertyp zu definieren:

1. Öffnen Sie die Seite Druckertyp. Die Seite "Druckertyp" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Druckertyp einen Namen für die neue Druckertypinstanz ein. Dieser Name muss exakt mit dem Namen des physischen Druckers übereinstimmen.
4. Wählen Sie einen Drucktyp aus.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
