Definieren von Druckverbindungen

Das Objekt "Druckverbindung" definiert eine Druckverbindung.

Definition der Felder auf der Seite "Druckverbindung"

In der folgenden Tabelle werden die Felder auf der Seite "Druckverbindung" erläutert.

Feld

Definition

Typ

Druckverbindung

Name dieser Instanz des Druckverbindungsobjekts.

Erforderlich

Beschreibung

Kurze Beschreibung des Modellierungsobjekts. Sie können maximal 255 Zeichen eingeben.

Optional

Hinweise

Relevante Kommentare zum Modellierungsobjekt. Sie können maximal 2000 Zeichen eingeben.

Optional

Details

Einrichtungszugriff

Legt den Zugriff des einzelnen Mitarbeiters auf das jeweilige Modellierungsobjekt fest.

Optional

Nutzerfelder

Datenbankname

Name der SQL-Datenbank oder des Oracle-Schemas.

Optional

Kennwort

Kennwort zum Herstellen der Verbindung zu einer Datenbank.

Optional

Servername

DSN-Name, der in der ODBC-Einrichtung für das Drucksystem erstellt wurde.  Dieser Name darf nicht mit dem DSN identisch sein, der für Opcenter Execution Core oder Opcenter Execution Semiconductor.

Hinweis: Ein Crystal Report wird über einen DSN mit einer Datenquelle verbunden.

Erforderlich

Benutzername

Gültiges Benutzerkonto, das eine Verbindung zur definierten SQL-Datenbank oder zum definierten Oracle-Schema herstellen kann.

Erforderlich

Vorgehensweise zum Definieren einer Druckverbindung

Gehen Sie folgendermaßen vor, um eine Druckverbindung zu definieren:

1. Öffnen Sie die Seite Druckverbindung. Die Seite "Druckverbindung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Druckverbindung einen Namen für die neue Instanz ein.
4. Geben Sie in das Feld Servername den DSN-Namen ein.
5. Geben Sie in das Feld Benutzername den Benutzerkontonamen ein.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
