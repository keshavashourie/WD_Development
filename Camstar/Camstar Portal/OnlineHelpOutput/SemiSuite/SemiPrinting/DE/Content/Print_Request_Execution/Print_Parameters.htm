Druckparameterauflösung

Die Parameter rufen die Daten während der Ausführung der Druckanforderung ab. Einige Parameter werden durch Abfragen von Opcenter Execution Semiconductor-Transaktionsdaten gefüllt. Einige Parameter werden mit Standardwerten konfiguriert. Bei einem Standardwert kann es sich um einen tatsächlichen Wert oder um einen Wert handeln, der andere Parameter enthalten kann, die zur Bestimmung des Werts aufgelöst werden müssen.

Ersatzzeichen

Das Doppelkreuz (#) ist der standardmäßige Ersatzzeichenwert, der im Produkt verfügbar ist. Das System erkennt einen Parameter durch dessen Platzierung innerhalb eines Paares von Ersatzzeichen, wie in folgendem Beispiel dargestellt: #Param01#. Alle Namen von Drucksystemparametern müssen innerhalb von Ersatzzeichen angegeben werden.

Parameter in SQL-Abfragen

Drucksystemparameter können im Drucksystem für SQL-Abfragen verwendet werden. Beispiel:

SELECT ProductName FROM Product WHERE Characteristic = '#Param02#'

Drucksystemabfragen, bei denen es sich immer um SELECT-Anweisungen handelt, werden direkt über das Opcenter Execution Semiconductor-Schema ausgeführt, um Daten abzurufen.

Die erste SQL-Abfrage in einer Liste von Abfragen bestimmt die Anzahl der Drucksätze für den jeweiligen Druckauftrag. Dies bedeutet, dass das Drucksystem alle zurückgegebenen Datenzeilen berücksichtigt. Für nachfolgende Abfragen in der Liste der Abfragen wird nur die erste Datenzeile verwendet. Andere Datenzeilen werden ignoriert.

Die durch die Abfragen zurückgegebenen Daten können zu Druckparametern zugewiesen werden, wenn die ausgewählten Spalten genau dieselben Namen wie die Druckparameter aufweisen. Beachten Sie, dass beim Abgleich von Parameternamen die Groß-/Kleinschreibung berücksichtigt wird. Alternativ besteht auch die Möglichkeit, einen Alias in der Abfrage zu verwenden.

Beispiele

Es ist ein Druckparameter mit der Bezeichnung "ProductName" verfügbar. Mit der folgenden SQL-Abfrage werden Daten an den Parameter zurückgegeben:

SELECT ProductName FROM ProductTable WHERE Criteria = 'XXX'

Die folgende SQL-Abfrage wird verwendet, wenn "ProductName" nicht als Spalte in der Tabelle vorhanden ist:

SELECT Name AS ProductName FROM ProductTable WHERE Criteria = 'XXX'
