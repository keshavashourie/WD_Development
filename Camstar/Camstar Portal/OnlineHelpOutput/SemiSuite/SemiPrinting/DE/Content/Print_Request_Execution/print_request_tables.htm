Druckanforderungstabellen

Im Drucksystem werden während der Ausführung von Druckanforderungen drei Druckanforderungstabellen verwendet:

• A_PrintData – Enthält eine Zeile pro Druckanforderung.
• A_PrintDataItem – Enthält eine Zeile pro Druckauftrag (Drucksatz). Ein Druckauftrag wird in eine Druckausgabe übertragen.
• A_PrintDataItemParams – Enthält eine Zeile pro Parameter für jeden Druckauftrag.
Beispieldaten für Druckanforderungstabelle

Benutzer A führt eine Transaktion in Opcenter Execution Semiconductor. Für die durchgeführte Transaktion wurde konfiguriert, dass ein Etikett und ein Bericht gedruckt werden. Der Benutzer gibt Container und Spezifikationen als Eingaben für die Drucktransaktion an. Nach Ausführung der Transaktion enthalten die Tabellen "A_PrintData", "A_PrintDataItem" und "A_PrintDataItemParams" die folgenden Daten.
