Verarbeitungsablauf

Dies ist der logische Ablauf zur Ausführung von Druckaufträgen:

1. Rufen Sie die Druckeinrichtungsdetails basierend auf dem Druckeinrichtungsnamen ab, der mit dem Druckauftrag verknüpft ist.
2. Wenden Sie die eingegebenen Parameterwerte auf die Druckeinrichtungsparameter an.
3. Lösen Sie die Parameter auf. (Siehe "Druckparameter".)
4. Führen Sie die erste SQL-Anweisung aus, um die Drucksätze zu bestimmen. (Siehe "Drucksatzberechnung".)
5. Duplizieren Sie die Druckeinrichtungsparameter und SQL-Abfragen der Druckeinrichtung gemäß der Anzahl an Drucksätzen.
6. Führen Sie Folgendes für jeden Drucksatz aus:
a. Für jede SQL-Abfrage der Druckeinrichtung eines Drucksatzes:
• Führen Sie die SQL-Abfrage aus.
• Wenden Sie die Werte, die durch die Abfrage zurückgegeben werden, auf die Druckeinrichtungsparameter des Drucksatzes an.
• Führen Sie die Parameterauflösung aus.
b. Ermitteln Sie die Menge pro Karton und berechnen Sie die Anzahl der Kartons. (Siehe "Berechnung der Menge pro Packung".)
c. Duplizieren Sie die Druckeinrichtungsparameter gemäß der Anzahl an Kartons.
d. Rufen Sie die Etiketten- oder Berichtsvorlage ab.
e. Wenden Sie die Werte der Druckeinrichtungsparameter auf die Vorlage an.
f. Senden Sie die Vorlage mit den Daten an den Zieldrucker.
