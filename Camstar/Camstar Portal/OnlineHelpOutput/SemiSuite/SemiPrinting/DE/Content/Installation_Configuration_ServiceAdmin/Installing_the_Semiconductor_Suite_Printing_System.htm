Installation

Sie benötigen Zugriff auf die Installationsdatei, die mit dem Opcenter Execution Semiconductor Printing System bereitgestellt wird.

Vorgehensweise zum Installieren von Opcenter Execution Semiconductor Printing

Gehen Sie folgendermaßen vor, um Opcenter Execution Semiconductor Printing zu installieren:

1. Führen Sie die Installationsdatei "OpcenterEXSM_x_PrintSystem.msi" aus (wobei x die zu installierende Version ist, z. B. v10.2). Das Fenster für die Erstinstallation wird angezeigt.
2. Klicken Sie auf Weiter. Das Fenster "Installationsordner auswählen" (Select Installation Folder) wird angezeigt. Das Standard-Installationsverzeichnis lautet C:\Programme (x86)\Camstar\Opcenter EX SM Printing System. Sie können die Installation aber an jedem beliebigen Speicherort, der im Feld "Ordner" (Folder) verfügbar ist, durchführen.
3. Klicken Sie auf Weiter. Sie werden im Popup "Installation bestätigen" aufgefordert, auf "Weiter" zu klicken, um die Installation zu starten.
4. Klicken Sie auf Weiter. Dem daraufhin angezeigten Dialogfeld können Sie den Fortschritt der Installation entnehmen. Sobald die Installation abgeschlossen ist, wird das Popup "Installation abgeschlossen" (Installation Complete) angezeigt.
5. Klicken Sie auf Schließen.

Vorgehensweise zum Überprüfen der Installation

Gehen Sie folgendermaßen vor, um die Installation zu überprüfen:

1. Öffnen Sie die Services-App. Das Fenster "Dienste" wird angezeigt.
2. Blättern Sie durch die Liste der installierten Dienste und gewährleisten Sie, dass OC EX SM Printing System in der Liste enthalten ist.

Vorgehensweise zum Installieren von Crystal Report Runtime

Ab Release 2410 ist die Crystal Reports-Runtime nicht mehr im OC EX CR-Installationsprogramm enthalten und muss manuell heruntergeladen und installiert werden.

Um das Drucken von Crystal Reports zu ermöglichen, muss die Crystal Report Runtime auf demselben Server installiert werden, auf dem auch OC EX SM Printing installiert ist. Diese Installation der Crystal Report Runtime kann jederzeit nach Einrichtung des OC EX SM Printing System durchgeführt werden.

Die empfohlene Laufzeitversion ist 13.0.36, die unter folgendem Link heruntergeladen werden kann: SAP Crystal Reports Runtime-Engine für .NET Framework

Hinweis: Diese Installation ist nicht erforderlich, wenn Crystal Reports nicht gedruckt werden muss.
