Konfiguration

Die Parameter der Drucksystemanwendung werden in der Registrierung des Servers gespeichert, auf dem das Drucksystem installiert ist, und werden mit dem Dienstprogramm "Printing System Registry Control" festgelegt.

Definition der Felder im Fenster "Printing System Registry Control"

In der folgenden Tabelle werden die Felder im Fenster "Printing System Registry Control" erläutert.

Feld

Definition

Typ

Camstar Server-Host

Hostname/IP

Servername oder IP-Adresse des Servers, auf dem das Drucksystem XML-Druckanforderungen verarbeitet.

Erforderlich

Port

Portnummer des Servers, der für Druckanforderungen abgefragt wird. Der Standardwert ist 443 .

Erforderlich

Nutzer

Opcenter Execution Semiconductor-Serverkonto, das zum Ausführen der XML-Transaktion verwendet wird.

Erforderlich

Kennwort

Kennwort für das Opcenter Execution Semiconductor-Serverkonto, das zum Ausführen der XML-Transaktion verwendet wird.

Erforderlich

Datenbankkonfiguration (Database Configuration)

Datenbanktyp (Database Type)

Typ der Datenbank (z. B. MS_SQL oder Oracle), zu der das Drucksystem eine Verbindung herstellt.

Erforderlich

SQL Server-Name/Oracle TNS (SQL ServerName/Oracle TNS)

Servername, IP-Adresse oder TNS-Name der Datenbank.

• MS SQL – Tatsächlicher Servername oder IP-Adresse.
• Oracle – TNS-Name

Erforderlich

SQL-DB-Name/Oracle-Schema (SQL DB Name/Oracle Schema)

Name der SQL-Datenbank oder des Oracle-Schemas

Erforderlich

Nutzer

Benutzerkonto, das eine Verbindung zur definierten SQL-Datenbank oder zum definierten Oracle-Schema herstellen kann.

Erforderlich

Kennwort

Kennwort für das Benutzerkonto, das eine Verbindung zur definierten SQL-Datenbank oder zum definierten Oracle-Schema herstellen kann.

Erforderlich

Drucksystemeinstellungen (Printing System Settings)

 

Abfrageintervall (Sekunden) (Poll Interval (seconds))

Intervall zwischen den einzelnen Prüfungen der Datenbank. Dieser Wert wird in Sekunden angegeben.

Optional

Ersatzzeichen (Replacement Character)

Zeichen, in das Parameternamen eingeschlossen werden, damit das System sie während der Verarbeitung der Druckanforderung als Parameter erkennt. Der Standardwert ist #.

Optional

Trace-Level aktivieren

Kontrollkästchen für die Trace-Dateierstellung. Wenn dieses Kontrollkästchen aktiviert wird, erstellt das System Trace-Dateien für jede Druckanforderung und fügt die Dateien in den Pfad der Protokolldatei ein. Die Grad der Informationsausgabe hängt vom ausgewählten Wert ab.

Optional

Trace-Dateipfad (Trace File Path)

Dateiverzeichnis, in dem Trace-Dateien erstellt werden.

Optional

Paralleler Verarbeitungsmodus (Parallel Process Mode)

Kontrollkästchen zum Umschalten zwischen den Modi zur Druckanforderungsverarbeitung.

Optional

Unicode-Etikett aktivieren

Kontrollkästchen, um das Lesen von Etikettenvorlagen im Unicode-Format zu aktivieren.

Optional

Vorgehensweise zum Konfigurieren des Dienstprogramms Printing System Registry Control

Gehen Sie folgendermaßen vor, um das Dienstprogramm Printing System Registry Control zu konfigurieren:

1. Navigieren Sie zu folgendem Ordner:

C:\Programme (x86)\Camstar\Opcenter EX SM Printing System\Assembly

2. Klicken Sie auf die Anwendungsdatei mit dem Namen PrintingSystemRegControl (nicht mit der Datei mit demselben Namen, aber der Erweiterung .exe verwechseln). Das Fenster des Dienstprogramms Printing System Registry Control wird angezeigt.
3. Geben Sie die erforderlichen Feldwerte ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. In einem Bestätigungs-Popup wird die erfolgreiche Ausführung des Speichervorgangs bestätigt.
6. Klicken Sie auf OK.
