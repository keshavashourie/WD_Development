Systemübersicht

Das Opcenter Execution Semiconductor Printing System wird über Opcenter Execution Semiconductor als Microsoft Windows-Dienst installiert. Das Drucksystem basiert auf der Konfiguration, die im Dienstprogramm "Printing System Registry Control" und in Semiconductor Portal.

Druckanforderungsdatenbank Tabellen

Es werden drei Druckanforderungstabellen in der Opcenter Execution Semiconductor-Datenbank erstellt, um Druckanforderungen zu verwalten:

• A_PrintData
• A_PrintDataItem
• A_PrintDataItemParams

Alle SQL-Abfragen des Drucksystems, die Opcenter Execution Semiconductor-Daten abrufen, sind schreibgeschützt. Die Druckanforderungstabellen werden mit XML-Transaktionen aktualisiert.

XML-Transaktionen

XML-Client-APIs, die mit dem Opcenter Execution Semiconductor-Server bereitgestellt werden, führen die XML-Transaktionen aus. Der PrintDataUpdate-Service wird an den folgenden Ausführungspunkten aufgerufen:

• Vor der Verarbeitung einer Druckanforderung legt der Service den Druckanforderungsstatus auf INPROCESS fest.
• Nach dem Ausdrucken legt der Service den Druckanforderungsstatus auf COMPLETED fest, um die erfolgreiche Ausführung anzugeben.
• Bei einem kritischen Fehler legt der Service die Druckanforderung auf ERROR fest und aktualisiert den Datensatz mit einer Fehlermeldung.
Druckanforderung Abfragen

Das Drucksystem fragt die Opcenter Execution Semiconductor-Datenbank regelmäßig ab, um festzustellen, ob Druckanforderungen zu verarbeiten sind. Das Intervall zwischen den einzelnen Abfragen wird durch den Parameter für das Abfrageintervall in der Konfiguration des Drucksystems festgelegt.

Bei jeder Abfrage handelt es sich um eine SQL SELECT-Anweisung, die eine Tabelle in der Datenbank abfragt. Die Verbindungsinformationen für die Datenbank basieren auf den Parametern der Datenbankkonfiguration. Siehe "Konfiguration" für Informationen in Bezug auf die Parameter für das Abfrageintervall und die Datenbankkonfiguration.

Die SELECT-Anweisung fragt die A_PrintData-Tabelle für Druckanforderungsdatensätze mit dem Status ACTIVE in der Spalte "Druckstatus" ab. Das System unterbricht die Abfrage und beginnt mit der Verarbeitung der Druckanforderungen, wenn mindestens eine Druckanforderung gefunden wird. Die Abfrage wird fortgesetzt, nachdem alle Anforderungen bearbeitet wurden.

Alle neuen Anforderungen, die zur A_PrintData-Tabelle hinzugefügt wurden, während die Abfrage unterbrochen war, werden während des nächsten Abfragezyklus verarbeitet.
