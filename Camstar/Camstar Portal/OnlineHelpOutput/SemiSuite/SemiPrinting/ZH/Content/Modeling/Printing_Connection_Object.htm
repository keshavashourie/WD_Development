定义打印连接

“打印连接”对象定义打印连接。

打印连接页字段定义

此表定义“打印连接”页中的字段。

字段

定义

类型

打印连接

此“打印连接”对象实例的名称。

必需

描述

建模对象的简短描述。最多可以输入 255 个字符。

可选

注释

建模对象的相关备注。最多可以输入 2000 个字符。

可选

详细信息

设置访问权限

设置员工对此建模对象的访问权限。

可选

用户字段

数据库名称

可选

密码

可选

服务器名称

在打印系统 ODBC 设置中创建的 DSN 名称。  它不能与用于 Opcenter Execution Core 或 Opcenter Execution Semiconductor 的 DSN 相同。

必需

用户名

必需

如何定义打印连接

按照以下步骤定义打印连接：

1. 打开打印连接页。随即“建模”页中将显示“打印连接”页。
2. 单击新建。 显示用于定义新实例的空白字段。
3. 在打印连接字段中输入新实例的名称。
4. 在服务器名称字段中输入 DSN 名称。
5. 在用户名字段中输入用户帐户名称。
6. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
7. 单击保存。应用程序保存建模对象并显示成功消息。
