处理流程

以下是每个打印工作的执行逻辑流：

1. 根据链接至打印工作的打印设置名称检索打印设置详细信息。
2. 将输入参数值应用于打印设置参数。
3. 解析参数。（请参考“打印参数”。）
4. 执行第一个 SQL 语句以确定打印集。（请参考“打印集计算”）。
5. 根据打印集数量复制打印设置参数和打印设置 SQL 查询。
6. 对每个打印集执行以下操作：
a. 对于每个打印集的打印设置 SQL 查询：
• 执行 SQL 查询。
• 将查询返回的值应用于打印集的打印设置参数。
• 执行参数解析。
b. 确定每箱数量并计算箱数。（请参考“每包装数量计算”）。
c. 根据箱数复制打印设置参数。
d. 检索标签或报告模板。
e. 将打印设置参数值应用于模板。
f. 将模板和数据处理至目标打印机。
