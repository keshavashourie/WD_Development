打印参数解析

打印请求执行期间，参数将获取其数据。有些参数是通过对 Opcenter Execution Semiconductor 事务数据的查询来填充的。 一些参数配置了默认值。默认值可能是实际值，也可能包含必须通过解析确定值的其他参数。

替换字符

数字符号 (#) 是随产品提供的默认替换字符值。系统通过参数在替换字符对（例如 #Param01#）中的位置识别参数。所有打印系统参数名称均必须在替换字符内指定。

SQL 查询中的参数

打印系统参数可用于打印系统 SQL 查询，例如：

SELECT ProductName FROM Product WHERE Characteristic = '#Param02#'

打印系统查询（始终为 SELECT 语句）直接针对 Opcenter Execution Semiconductor 架构运行，以获取数据。

查询列表中的第一项 SQL 查询决定打印工作的打印集数。这意味着打印系统将充分考虑返回的所有数据行。对于查询列表中的后续查询，则仅使用第一个数据行。其他数据行将被忽略。

如果所选列使用与打印参数完全相同的名称，则可将查询返回的数据指派给打印参数。注意，参数名称匹配区分大小写。别名可以作为备选名称在查询中使用。

示例

有一个名为 ProductName 的打印参数。此 SQL 查询用于返回参数数据：

SELECT ProductName FROM ProductTable WHERE Criteria = 'XXX'

如果 ProductName 不以表列形式存在，则使用此 SQL 查询：

SELECT Name AS ProductName FROM ProductTable WHERE Criteria = 'XXX'
