系统概述

Opcenter Execution Semiconductor 打印系统安装在 Opcenter Execution Semiconductor 的顶层，作为一项 Microsoft Windows 服务。打印系统依赖“打印系统注册表控制”中的配置，以及依赖 Semiconductor Portal 中的配置。

打印请求数据库 表

在 Opcenter Execution Semiconductor 数据库中创建三个打印请求表以管理打印请求：

• A_PrintData
• A_PrintDataItem
• A_PrintDataItemParams

检索 Opcenter Execution Semiconductor 数据的所有打印系统 SQL 查询都是只读的。 XML 事务用于更新打印请求表。

XML 事务

随 Opcenter Execution Semiconductor 服务器提供的 XML 客户端 API 执行 XML 事务。 在以下执行点调用 PrintDataUpdate 服务：

• 处理打印请求前，此服务将打印请求状态设为 INPROCESS。
• 打印后，服务将打印请求状态设为 COMPLETED 表示成功执行。
• 发生严重错误时，服务将打印请求设为 ERROR，并使用错误消息更新记录。
打印请求 轮询

打印系统定期轮询 Opcenter Execution Semiconductor 数据库，以确定是否有要处理的打印请求。 每次轮询之间的间隔在名为“轮询间隔”的打印系统配置参数中设置。

每个轮询均为 SQL SELECT 语句，用于查询数据库中的表。数据库连接信息取决于数据库配置参数。有关轮询间隔和数据库配置参数的信息，请参考“配置”。

SELECT 语句查询 A_PrintData 表中的打印请求 — PrintStatus 列中显示 ACTIVE 状态的记录。如果发现一个或多个打印请求，系统将暂停轮询并开始处理打印请求。处理完所有请求后，恢复轮询。

暂停轮询期间，插入 A_PrintData 表中的所有新请求都将在下一轮询周期进行处理。
