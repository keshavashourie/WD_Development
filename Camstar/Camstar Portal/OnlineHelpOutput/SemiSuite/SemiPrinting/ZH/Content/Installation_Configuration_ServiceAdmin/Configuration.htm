打印系统注册表控制窗口字段定义

此表定义“打印系统注册表控制”窗口中的字段。

字段

定义

类型

Camstar 服务器主机

主机名/IP

打印系统处理 XML 打印请求的服务器的服务器名称或 IP 地址。

必需

端口

执行打印请求轮询的服务器的端口号。默认值为 443。

必需

用户

Opcenter Execution Semiconductor服务器帐户的密码，用于执行 XML 事务。

必需

密码

用于执行 XML 事务的 Opcenter Execution Semiconductor 服务器帐户的密码。

必需

数据库配置

数据库类型

打印系统将连接的数据库类型（例如 MS_SQL 或 Oracle）。

必需

SQL ServerName/Oracle TNS

数据库的服务器名称、IP 地址或 TNS 名称。

• MS SQL – 实际服务器名称或 IP 地址。
• Oracle – TNS 名称

必需

SQL DB 名称/Oracle 架构

SQL DB 名称或 Oracle 架构名称

必需

用户

能够连接到定义的 SQL 数据库或 Oracle 架构的用户帐户。

必需

密码

能够连接到定义的 SQL 数据库或 Oracle 架构的用户帐户的密码。

必需

打印系统设置

 

轮询间隔（秒）

每次连续数据库检查之间的间隔。此值以秒为单位进行测量。

可选

替换字符

用于括住参数名称的字符，使系统能够在打印请求处理期间将它们识别为参数。默认值为 #。

可选

启用跟踪级别

此复选框用于生成跟踪文件。选中此复选框时，系统将为每个打印请求创建跟踪文件，并将文件置于日志文件路径。信息输出级别取决于所选的值。

可选

跟踪文件路径

将生成跟踪文件的文件目录位置。

可选

并行流程模式

此复选框用于切换打印请求处理模式。

可选

启用 Unicode 标签

此复选框用于启用以 Unicode 格式读取标签模板。

可选

如何配置打印系统注册表控制

按照以下步骤配置“打印系统注册表控制”：

1. 导航至以下文件夹：

C:\Program Files (x86)\Camstar\Opcenter EX SM Printing System\Assembly

2. 单击名为 PrintingSystemRegControl 的应用程序文件 — 切勿与扩展名为 .exe 的同名文件混淆。此实用程序显示“打印系统注册表控制”窗口。
3. 输入必填字段值。
4. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
5. 单击保存。确认弹出窗口确认保存。
6. 单击确定。
