Print Parameter Resolution

Parameters get their data during print request execution. Some parameters are populated by queries against Opcenter Execution Semiconductor transactional data. Some parameters are configured with default values. A default value may be an actual value or it may contain other parameters that must be resolved to determine the value.

Replacement Characters

The number sign (#) is the default replacement character value provided with the product. The system recognizes a parameter by its placement within a pair of replacement characters, for example, #Param01#. All printing system parameter names must be specified within replacement characters.

Parameters in SQL Queries

Printing system parameters can be used in printing system SQL queries, for example: 

SELECT ProductName FROM Product WHERE Characteristic = '#Param02#'

Printing system queries, which are always SELECT statements, are run directly against the Opcenter Execution Semiconductor schema to pull data.

The first SQL query in a list of queries determines the number of print sets for the print job. This means that the printing system takes into account all returned data rows. For subsequent queries in the list of queries, only the first data row will be used. Other data rows will be ignored.

The return data from the queries can be assigned to print parameters if the selected columns use the exact same names as the print parameters. Note that parameter name matching is case sensitive. An alias can be used in the query as an alternative.

Examples

There is a print parameter called ProductName. This SQL query is used to return data to the parameter:

SELECT ProductName FROM ProductTable WHERE Criteria = 'XXX'

This SQL query is used if ProductName does not exist as a column in the table:

SELECT Name AS ProductName FROM ProductTable WHERE Criteria = 'XXX'
