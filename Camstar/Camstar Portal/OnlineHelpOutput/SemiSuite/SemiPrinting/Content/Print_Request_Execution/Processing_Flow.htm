Processing Flow

This is the execution logic flow for each print job:

1. Retrieve printing setup details based on the printing setup name linked to the print job.
2. Apply input parameter values to printing setup parameters.
3. Resolve parameters. (Refer to "Print Parameters.")
4. Execute the first SQL statement to determine the PrintSets. (Refer to "Print Set Calculation.")
5. Duplicate the Printing Setup Parameters and Printing Setup SQL Queries according to the number of PrintSets.
6. Perform the following for each PrintSet:
a. For each of the PrintSet's Printing Setup SQL Queries:
• Execute the SQL query.
• Apply the values returned from the query to the PrintSet's Printing Setup Parameters.
• Perform parameter resolution.
b. Determine the quantity per box and calculate the number of boxes. (Refer to "Quantity Per Pack Calculation.")
c. Duplicate the printing setup parameter according to the number of boxes.
d. Retrieve the label or report template.
e. Apply the printing setup parameter values to the template.
f. Transact the template and data to the target printer.
