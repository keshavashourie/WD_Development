Print Request Tables

The printing system uses three print request tables during print request execution:

• A_PrintData – Contains one row per print request,
• A_PrintDataItem – Contains one row per print job (print set). A print job translates to a printout.
• A_PrintDataItemParams – Contains one row per parameter for each print job.
Example Print Request Table Data

User A performs a transaction in Opcenter Execution Semiconductor. The performed transaction has been configured to print one label and one report.
