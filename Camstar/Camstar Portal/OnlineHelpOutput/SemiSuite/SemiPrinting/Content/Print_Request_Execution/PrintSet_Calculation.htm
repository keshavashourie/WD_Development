Print Set Calculation

The printing system must determine the number of print sets (individual items) to be printed for each print request. For each print set, it must also determine the number of boxes required if the print set outputs labels. The system uses queries and parameters that are configured in the printing setup associated with the print request.

Quantity Per Pack Calculation

The quantity per pack value is retrieved based on two parameters—Product and Packing Type. If these parameters are not set or the quantity per pack cannot be determined, quantity per pack will be made equal to the value of the Qty parameter. The quantity per pack value is stored in the QtyPerBox parameter. The system calculates the number of labels by dividing the Qty parameter value by the QtyPerBox parameter value. The Print Set is then duplicated according to the number of labels.

Example

The first query in the Print Setup (Query 1) is executed to determine the number of print sets. The query returns two rows—two containers with a quantity greater than 500. Therefore there are two print sets. The second query in the Print Setup (Query 2) executes once for each print set. The parameter #MYCONTAINER# gets populated with the container name of the print set currently being processed.

Each print set has a container quantity of 500, but QtyPerBox is determined to be 400. Two boxes and two sets of labels will be needed for each print set, so Query 2 for is duplicated for each print set.
