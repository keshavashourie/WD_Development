How to Define a Printing Connection

Follow these steps to define a Printing Connection:

1. Open the Printing Connection page. The Printing Connection page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the new instance in the Printing Connection field.
4. Enter the DSN name in the Server Name field.
5. Enter the user account name in the Username field.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
