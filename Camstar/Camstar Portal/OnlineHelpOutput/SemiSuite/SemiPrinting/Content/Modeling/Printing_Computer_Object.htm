Defining Printing Computer Matrix Objects

The Printing Computer matrix object associates one or more printers to a printing setup.

Refer to the Opcenter Execution Semiconductor Modeling Guide for general information on matrix objects.

Printing Computer Page Field Definitions

This table defines the fields on the Printing Computer page.

Field

Definition

Type

Criteria

Computer Name

Client PC name or Client PC name.domain of the computer to which the instance applies.

Optional

Printing Setup

Printing Setup object to which the instance applies. Refer to "Defining Printing Setups."

Printing Computer Name

Unique name for the matrix instance. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.

Optional

Description

Short description of the modeling object. You can enter a maximum of 255 characters.

Optional

Setup Access

Sets the employee's access to this modeling object.

Optional

Details grid

Grid displaying the valid printers. The system will match the printing type assigned to the printing setup and the printer’s printer type to filter the list of valid Printers.

The sequence of the printers in the grid is important, as the first applicable printer is considered the default for automated printing.

Example: Ten printers with three different printing types have been entered into the grid. The first printer found for each printing type will be used as the default printer for jobs requiring that printing type.

Required

Printer

Printer available on the server.

How to Define a Printing Computer Matrix Instance

Follow these steps to define a Printing Computer matrix instance:

1. Open the Printing Computer page. The Printing Computer page appears within the Modeling page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit an existing instance.
3. Enter a name for the Printing Computer matrix instance in the Printing Computer Name field.
4. Perform the following for every printing setup in the Details grid:
a. Click Add new row. A new row appears.
b. Enter the printer in the Printer field.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
