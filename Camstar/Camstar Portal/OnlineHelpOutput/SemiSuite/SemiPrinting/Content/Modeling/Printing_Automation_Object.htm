Defining Printing Automation Matrix Objects

The Printing Automation matrix object is used to define a transaction that will trigger an automated print request and the printing setups that will be executed for that request.

How to Define a Printing Automation Matrix Instance

Follow these steps to define a Printing Automation matrix instance:

1. Open the Printing Automation page. The Printing Automation page appears within the Modeling page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit an existing instance.
3. Enter the service (transaction) that will trigger a printout in the Service Name field.
4. Enter a name for the Printing Automation matrix instance in the Printing Automation Name field.
5. Perform the following for every printing setup in the Details grid:
a. Click Add new row. A new row appears.
b. Enter the printing setup in the Printing Setup field.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
