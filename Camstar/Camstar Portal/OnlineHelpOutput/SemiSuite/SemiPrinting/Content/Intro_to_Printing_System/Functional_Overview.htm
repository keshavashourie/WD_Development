Functional Overview

The Opcenter Execution Semiconductor Printing System enables transaction-based and ad hoc printing within the Semiconductor Portal. It supports dynamic parameter population during print request execution.

Output Formats

The printing system supports three output formats—text files, labels, and reports.

Text Files

The text file output format enables you to output all of the parameters for a print job to a flat file, without the need for a physical printer. The flat file location is specified in the print system configuration. Formatting of the output text file is based on the parameter TEXTFILE_TEMPLATE which is defined in the Parameters list in a Printing Setup instance. The printing engine takes the file specified in the TEXTFILE_TEMPLATE parameter, looks for all parameter placeholders encased within the replacement character identifier, and then replaces the placeholders in the template with the actual values. It then outputs the formatted text to the Filename location specified in the Printing Setup.

Labels

The printing system supports label printers that have compliant ASCII label printing language. The two supported label printer brands are:

• Zebra– Using ZPL2 (Zebra Printing Language 2) or EPL2 (Eltron Printing Language)
• Intermec – Using IPL (Intermec Printing Language)

The print engine uses the template specified in the Filename field of the Printing Setup object and attempts to resolve parameter placeholders in the template by replacing them with matching parameter values. The data is then sent to the specified label printer.

Reports

The printing system supports the printing of Crystal Reports. Reports can be exported to a PDF or RTF (Rich Text Format) using the following system parameters:

• REPORT_EXPORT
• REPORT_EXPORTONLY
• REPORT_EXPORTFILENAME
• REPORT_EXPORTTYPE
Note: These parameters are defined in the Printing Setup instance parameters list.

The printing logic retrieves the report template and passes in the logon credentials that have been specified in the Printing Connection setup. Print Parameters are matched to report template fields that have the exact same names. For each match, the report field is set to the value of the corresponding parameter.
