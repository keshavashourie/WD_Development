System Overview

The Opcenter Execution Semiconductor Printing System is installed on top of Opcenter Execution Semiconductor as a Microsoft Windows service. The printing system relies upon configuration in the Printing System Registry Control as well as within Semiconductor Portal.

Print Request Database Tables

Three print request tables are created on the Opcenter Execution Semiconductor database to manage print requests:

• A_PrintData
• A_PrintDataItem
• A_PrintDataItemParams

All printing system SQL queries that retrieve Opcenter Execution Semiconductor data are read-only. XML transactions are used to update the print request tables.

XML Transactions

XML Client APIs provided with the Opcenter Execution Semiconductor server execute the XML transactions. The PrintDataUpdate service is called at the following execution points:

• Prior to processing the print request, the service sets the print request status to INPROCESS.
• Post print out, the service sets the print request status to COMPLETED to indicate successful execution.
• On critical error, the service sets the print request to ERROR and updates the record with an error message.
Print Request Polling

The printing system periodically polls the Opcenter Execution Semiconductor database to determine if there are any print requests to process. The interval between each poll is set in the printing system configuration parameter named Poll Interval.

Each poll is a SQL SELECT statement that queries a table in the database. Connection information to the database is based on the Database Configuration parameters. Refer to "Configuration" for information regarding the Poll Interval and Database Configuration parameters.

The SELECT statement queries the A_PrintData table for print requests—records with an ACTIVE status in the PrintStatus column. The system suspends polling and begins print request processing if one or more print requests are found. Polling resumes after all requests have been processed.

Any new requests that are inserted into the A_PrintData table while polling is suspended will be processed during the next poll cycle.
