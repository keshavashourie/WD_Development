Configuration

The printing system application parameters are stored in the registry of the server on which the printing system is installed and are set using the Printing System Registry Control utility.

For instructions on using the Semi Printing solution in a containerized environment, refer to the Opcenter Execution Semiconductor Installation Guide (version 2504 and later) for information about installation, configuration, and tracing.

Printing System Settings

 

Poll Interval (seconds)

Interval between each successive check against the database. This value is measured in seconds.

Replacement Character

Character used to encase parameter names thus enabling the system to recognize them as parameters during print request processing. Default value is #.

Optional

Optional

How to Configure the Printing System Registry Control

Follow these steps to configure the Printing System Registry Control:

1. Navigate to the following folder:

C:\Program Files (x86)\Camstar\Opcenter EX SM Printing System\Assembly

2. Click the Application file named PrintingSystemRegControl—not to be confused with the file of the same name that has an extension of .exe. The utility displays the Printing System Registry Control window.
3. Enter required field values.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. An acknowledgment pop-up confirms the save.
6. Click OK.
