Installation

Starting with Release 2510, the printing system installation file is included in the Opcenter Execution Semiconductor installation folder.

How to Install Opcenter Execution Semiconductor Printing

Follow these steps to install Opcenter Execution Semiconductor Printing:

1. Access the Support Center using your WebKey credentials. Use the same username and password used for Opcenter Execution Core (Opcenter EX CR) installation.
2. Navigate to the semiconductor installer folder and look for the file named "OpcenterEXSM_x_PrintingSystem", where "x" represents the version number (e.g., 2510 or 2510.0001). Note that the Printing System installer is located in the same directory as the main semiconductor installer.
3. Run the installation file. The initial installation window appears.
4. Click Next. The Select Installation Folder window appears. The default install location is C:\Program Files(x86)\Camstar\Opcenter EX SM Printing System folder, but you can install to any location available from the Folder field.
5. Click Next. The Confirm Installation pop-up prompts you to click Next to start the installation.
6. Click Next. A dialog briefly appears indicating the progress of the installation. The Installation Complete pop-up displays when the installation completes.
7. Click Close.

How to Verify the Installation

Follow these steps to verify the installation:

1. Open the Services app. The Services window appears.
2. Scroll through the list of installed services and verify that you see Opcenter EX SM Printing System in the list.

How to Install Crystal Report Runtime

Crystal Reports runtime is no longer included with the OC EX CR installer and must be downloaded and installed manually.

To enable Crystal Reports printing, the Crystal Reports runtime needs to be installed on the same server where the OC EX SM Printing is installed. This installation of the Crystal Reports runtime can be performed at any time after the OC EX SM Printing System has been set up. The recommended runtime version is 13.0.36.

Users must provide the installer (MSI file) to install it at the following location:

<metadatapath>/printing-service/startup/crystal-report-runtime.

After placing the installer at the specified location, redeploy or restart the printing-service pod. The Crystal Report Runtime should be installed once the pod is running. Users can find the log file of the installation at the same location as the installer:

(<metadatapath>/printing-service/startup/crystal-report-runtime/<installer_name.msi>.log).

Note: This installation is not required if there is no need for printing of Crystal Reports.
