Printing

The Printing page enables you to manually execute a Printing Setup. A Printing Setup is a modeling object associated with a print request to provide processing instructions. The object is used in automated printing but can also be executed from the menu. The ad hoc use of the object requires you to supply the parameter data that would normally be supplied by the transaction.

How to Use the Printing Page

Follow these steps to use the Printing page:

1. Open the Printing page. The Printing page appears.
2. Enter the name of the printing setup in the Printing Name field. The application displays information for the selected printing setup.
3. Enter the required parameter values in the Details grid.
4. Enter the printer in the Printer field if the default is not correct.
5. Enter the Number of Copies if the default is not correct.
6. Click Submit.The application executes your print request and directs it to the specified printer.
