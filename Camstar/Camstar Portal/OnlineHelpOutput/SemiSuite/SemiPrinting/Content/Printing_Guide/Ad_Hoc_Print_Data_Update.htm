Print Data Update

The Print Data Update page enables you to manually update the status of a print job and to set a printing error message for a print job that failed.

How to Use the Print Data Update Page

Follow these steps to use the Print Data Update page:

1. Open the Print Data Update page. The Print Data Update page appears.
2. Enter the print request Id in the Print Data field.
3. Enter the print job status in the Action field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Submit. The application executes your request and displays a status message.
