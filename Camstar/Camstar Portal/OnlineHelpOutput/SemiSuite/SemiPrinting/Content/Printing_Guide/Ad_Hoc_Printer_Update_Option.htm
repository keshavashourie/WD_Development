Printer Update

The Printer Update page enables you to make the following printer updates:

• LOCK – Locks the printer for the calling server to do the printing.
• UNLOCK – Release the printer for other servers to do printing. The ComputerName must be the same as when LOCK was requested.
• RESET – Force a reset of the printer. This is the same as the UNLOCK command except that it does not validate the Computer Name.

How to Use the Printer Update Page

Follow these steps to use the Printer Update page:

1. Open the Printer Update page. The Printer Update page appears.
2. Enter the printer name in the Printer field.
3. Enter an action using the Action field.
4. Enter the computer name in the Computer Name (In Use By) field. The application uses the Computer Name to set the InUseBy field of the printer.
5. Click Submit. The application executes your request and displays a status message.
