Printing by Lot

The Printing by Lot page uses transaction based printing automation to figure out what needs to be printed without actually executing the shop floor transaction. This feature is useful when a transaction print request fails and you need to manually generate the output.

How to Use the Printing by Lot Page

Follow these steps to use the Printing by Lot page:

1. Open the Printing by Lot page. The Printing by Lot page appears.
2. Enter the lot in the Selection Id field. The application displays details for the selected lot.
3. Enter the transaction in the Service Name field.
4. Enter the spec name in the Spec field, or leave blank to have the system use the spec at which the lot is currently located.
5. Click Submit. The application executes the printing setup associated with the selected lot.
Note: The application displays an error message if there is no printing setup available for the lot.
