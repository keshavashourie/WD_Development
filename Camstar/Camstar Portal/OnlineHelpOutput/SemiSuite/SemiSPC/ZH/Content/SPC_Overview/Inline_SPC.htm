Inline SPC

内联 SPC 是 Siemens Opcenter Execution Semiconductor 应用程序的单独许可模块，用于提供管理和改进制造流程的关键要素。它允许制造商在问题导致产量或吞吐量下降前解决问题。缺少它，流程问题将无法得到及时处理，且会花费宝贵的时间和资源来修复本可以预防的问题。

生产期间发生，测量或测试属性（例如，产品厚度）期间出现的情况的示例。产品规范可能规定厚度必须介于 0.95 到 1.05 英寸之间，才能被视为适用于子装配的零件。测量显示连续五个批次的平均产品厚度为 0.96、0.98、1.00、1.02 和 1.04 英寸。但是，在单独查看批次时，应用程序不会采取措施，因为其都在产品规范范围内。

将 Statistical Process Control 应用于这些值将揭示这种趋势，可能是在记录第三批的平均厚度之后。可以通知工程，制造的产品厚度正在增加。此时，将努力确定装置厚度增加的原因 — 同时继续生产。因此，解决可能存在的问题，以防设备关闭、单元搁置、材料报废、生产时间浪费等现象的产生。

SPC 使制造和工程能够配置和包含 SPC 控制图表。控制图表可以在收集质量数据时进行更新，并可对操作人员显示及时反馈。工程还可以审核历史图表，并将其作为研究特定事件的一部分。

Inline Statistical Process Control 模块使用 SPC 公共组件分析和显示 SPC 图表。有关 Inline SPC 安装、配置和建模要求的信息，参考《Opcenter Execution Core Inline Statistical Process Control 参考指南》。

Inline SPC 安装

要使用 Inline SPC，应熟悉 Statistical Process Control 实施过程所基于的组件、必要条件和假设。

按照以下步骤确保正确安装和配置 Inline SPC：

1. 通过 Opcenter Execution Core 安装向导安装 Inline SPC。有关信息，请参考《Opcenter Execution Core 安装指南》。
2. 安装中包含以下脚本：

SPCConfiguration.cfg for SQL

SPCConfiguration.ORA.cfg for Oracle

3. 完成安装后，必须运行相应的脚本。有关信息，参考《Opcenter™ Execution Core Transaction Tester 用户指南》。存在几个以最少的配置运行的样本图表。有关详细信息，可参考“配置样本图表”。
注释: （可选）可以通过 Management Studio 加载 Inline SPC 测试数据。有关信息，请参考《Opcenter Execution Core 系统管理指南》。
