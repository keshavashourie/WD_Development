定义 SPC 图表

SPC 图表包含显示单个 SPC 图表所需的信息。SPC 图表描述：

• 图表类型
• OCAP
• 绘制的变量

Siemens 提供四种默认 SPC 图表供用户使用：

• 移动极差
• 极差图
• 试用 I-图表
• X 图表
• Inline 移动极差
• Inline 极差图
• Inline 试用 I 图表
• Inline X 图表
重要提示: 具有关联 SPC 图表的 SPC 图表组配置应仅链接到用户数据收集定义，该定义配置为在 Opcenter Execution Semiconductor 的电子流程中执行。SPC 图表的所有功能 (OCAPS) 尚不完全受支持。建议将 Semiconductor SPC 设置或 SPC 基础设置指派给用户数据收集定义。或者，应通过 WIP 数据来收集所有需要 SPC 分析的关键参数。
定义 SPC 图表

对于 Inline SPC，必须在服务器上安装并配置 Inline SPC，才能使用此页面。否则将无法填充所有必需字段或保存页面。使用 SPC 图表的“失控操作”部分来确定违规时触发的操作。SPC 图表是 SPC 图表组建模对象中的可选定义。SPC 图表包含以下可选建模定义：文档电子邮件消息、搁置原因和原因状态代码。它还在“参数”部分中使用数据收集定义和用户收集定义。

“需要注释”复选框要求在图表生成期间发生违规时输入注释。在生成最后的违规数据点图表时，如果选中“试图对失控图表执行 OCAP”复选框，则会显示“SPC 图表”弹出窗口，并且在为最后的数据点添加批注之前无法关闭。仅当图表上最后的数据点违规时，才会显示“SPC 注释”弹出窗口。如果尝试关闭“SPC 图表”弹出窗口，则将显示警告消息以通知您需要注释并引用需要注释的图表。有关信息，请参考《Opcenter™ Execution Core Statistical Process Control 参考指南》中的“查看和输入注释”。

为 Inline SPC 使用动态参数

高级 Inline SPC 用户可以配置图表参数，以使用从字段表达式或查询中获取的动态标签。在“参数”部分中，为参数选中“是动态的”复选框，然后输入元数据表名称和字段或查询名称和列，以显示参数的值。例如，可以编辑 chartTitle 参数，以显示容器表中的产品名称。要使用动态参数功能，必须了解对象模型和业务逻辑。Siemens 建议将此功能与“Inline SPC 数据收集”功能一起使用。

还可以使用查询来设置动态参数值。所使用的查询不能具有输入参数，并且应仅包含文本。仅将返回的第一行数据应用于动态参数。可以使用用户查询和 SPC 查询。对“参数值”参数字段使用以下格式：QueryName.ColumnName。

如何定义 Inline SPC 图表

按照以下步骤定义 Inline SPC 图表：

1. Opcenter Execution Semiconductor。
2. 从建模菜单中选择建模。将显示“建模”页。
3. 单击 SPC 图表。随即“建模”页中将显示“SPC 图表”页。
4. 要创建新对象，单击新建。显示用于定义新实例的空白字段。还可以通过搜索实例使用默认的预定义 Inline SPC 图表。
5. 输入 SPC 图表名称。
6. 输入图表类型。
7. 输入图表变量。
8. 选中 Inline SPC 复选框以定义 Inline SPC 图表。
9. 填写必填字段：SPC 查询、SPC 连接和 SPC 图表显示选项。
10. 根据业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
11. 单击保存。应用程序保存建模对象并显示成功消息。

如何将现有原有宏转换为内联 SPC 查询对象

按照以下步骤将原有宏转换为内联 SPC 查询对象：

1. Opcenter Execution Semiconductor。
2. 从建模菜单中选择建模。将显示“建模”页。
3. 单击 SPC 图表。随即“建模”页中将显示“SPC 图表”页。
4. 选择现有原有图表。
5. 选择内联 SPC 复选框。将显示一条警告消息，确认宏转换。
6. 单击是。将显示“SPC 宏转换”弹出窗口。弹出字段将自动填充所选原有查询中的信息。
7. 输入新的 SPC 查询名称。
8. 根据业务需求编辑查询信息。有关可选字段的信息，请参考字段定义表。
9. 单击提交。应用程序保存 SPC 查询对象并显示成功消息。可以在“SPC 查询”页面上查看已保存的查询。
注释: 如果选定的原有宏包含多个查询和/或不完整参数，则会显示一条警告消息。在将查询信息与内联 SPC 一同使用之前，必须手动编辑查询信息。可以在“SPC 宏转换”弹出窗口中编辑转换后的宏和参数，然后单击提交，也可以单击提交，然后在“SPC 查询”页面上编辑已转换的宏和参数。
