定义 SPC 设置

完全配置后，“SPC 设置”将提供调用内联 SPC 组件以进行 SPC 处理所需的所有信息。此对象包含用于图表显示和失败处理的字段。

SPC 设置可用于更改图表配置为请求时的默认参数值。当此设置发起请求时，这些更改后的值将用于图表。

SPC 随附的 SPC 设置

SPC 对象建模电子表格包含用于配置几个 SPC 设置对象实例的数据。每个 SPC 设置都与预定义的但可进行自定义的 SPC 查询结合使用，如下所示：

• ADHOCWIPDATA - 由基于 SPCAdhocWIPData SPC 查询的基本 X 条形图 (GXChart) 和极差图 (GRChart) 组成的示例 SPC 设置。
• ADHOCWIPDATAINLINE - 由基于 SPCAdhocWIPData SPC 查询的基本 X 条形图和极差图组成的示例 SPC 设置。
• CHANGECOUNT - 由基于 SPChangeCount SPC 查询的基本 X 条形图 (GXChart) 和极差图 (GRChart) 组成的示例 SPC 设置。
• CHANGECOUNTINLINE - 由基于 SPChangeCount SPC 查询的基本 X 条形图和极差图组成的示例 SPC 设置。
• DATAVALUES - 由基于 SPCDataValues SPC 查询的基本 X 条形图 (GXChart) 和极差图 (GRChart) 组成的示例 SPC 设置。
• DATAVALUESINLINE - 由基于 SPCDataValues SPC 查询的基本 X 条形图和极差图组成的示例 SPC 设置。
• REJECTS - 由基于 SPCRejects SPC 查询的基本 X 条形图 (GXChart) 和极差图 (GRChart) 组成的示例 SPC 设置。
• REJECTSINLINE - 由基于 SPCRejects SPC 查询的基本 X 条形图和极差图组成的示例 SPC 设置。
• USERDATACOLLECTION - 由基于 SPCUserDataCollection SPC 查询的基本 X 条形图 (GXChart) 和极差图 (GRChart) 组成的示例 SPC 设置。
• USERDATACOLLECTIONINLINE - 由基于 SPCUserDataCollection SPC 查询的基本 X 条形图和极差图组成的示例 SPC 设置。

指派 SPC 设置

对于要执行的 SPC 设置，必须将其指派给车间对象。在车间事务期间使用对象时，将触发已指派的 SPC 设置。

可以将 SPC 设置指派给以下对象：

• SPC 矩阵 - 使用配置准则以确定给定车间事务关联中匹配度最高（最适用）的 SPC 设置。
• 设备 - 当车间事务中使用的设备配置了“SPC 设置”或“使用 SPC 矩阵”时，将触发 SPC 设置。
• WIP 数据设置 - 将数据输入到“WIP 数据设置”字段时，将触发 SPC 设置。
• 数据收集定义 - 将数据输入到数据收集定义（工作进度事务的一部分）时，将触发 SPC 设置。

如何定义 Inline SPC 设置

按照以下步骤定义 SPC 设置 (Inline)：

1. 打开“SPC 设置”页。随即“建模”页中将显示“SPC 设置”页。
2. 单击新建。显示用于定义新实例的空白字段。
3. 输入 SPC 设置名称。
4. 选中 Inline SPC 复选框。
5. 输入图表高度。（建议值为 450。）
6. 输入图表宽度。（建议值为 900。）
7. 单击“详细信息”表格中的添加新行。应用程序将显示“添加”弹出窗口。
8. 使用“添加”弹出窗口：
a. 输入项名称以标识图表。
b. 选择 SPC 图表类型 (Inline)。应用程序使用针对图表配置的参数和默认值填充“Inline 图表参数”表格。
c. 使用 Inline 图表参数表格：
• 要更改参数值，单击参数值。（如果为空，则单击空白区域。）该字段将变为启用状态。输入值。
• 要在应用 SPC 矩阵时替代参数值，选中允许矩阵替代复选框。
• 要添加可用于图表的参数，在输入参数名称中输入参数的确切名称，然后根据业务要求在参数值和矩阵替代字段中输入值。
d. 完成后，单击确定。弹出窗口关闭。
9. 在“查询”表格中输入 SPC 查询名称。
10. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
11. 单击保存。应用程序保存建模对象并显示成功消息。

如何将 SPC 设置从“原有”转换为“Inline”

1. 从建模菜单中打开 SPC Setup 页。随即“建模”页中将显示“SPC 设置”页。
2. 选择要转换的现有的原有 SPC 设置。
3. 选择内联 SPC 复选框。
4. 要更改“详细信息”表格中的现有项的详细信息，选择“项名称”行，并单击“编辑”按钮：
a. 选择 SPC 图表类型 (Inline)。应用程序使用针对图表配置的参数和默认值填充“Inline 图表参数”表格。
b. 使用 Inline 图表参数表格：
• 要更改参数值，单击参数值。（如果为空，则单击空白区域。）该字段将变为启用状态。输入值。
• 要在应用 SPC 矩阵时替代参数值，选中允许矩阵替代复选框。
• 要添加可用于图表的参数，在输入参数名称中输入参数的确切名称，然后根据业务要求在参数值和矩阵替代字段中输入值。
c. 转换过程将启用五 (5) 个可选字段：是 Y 变量、X 轴趋势值、ANNVAR 主值、ANNVAR 次值和 ANNVAR 第三值。可以根据业务需求输入可选信息。
d. 完成后，单击确定。弹出窗口关闭。
5. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
6. 单击保存。应用程序保存建模对象并显示成功消息。

如何指派 SPC 设置

按照以下步骤指派 SPC 设置：

1. 打开要为其指派 SPC 设置的对象实例的建模页。
2. 在 SPC 设置字段中输入 SPC 设置的名称。
3. 单击保存。应用程序保存建模对象并显示成功消息。
