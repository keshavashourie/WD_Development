图表参数描述

Opcenter Execution Semiconductor 为其提供的图表提供默认参数和值。此表提供对图表参数及其定义的参考。

参数

描述

有效值

ALARM_COLOR

用于在违反任何失控规则测试时更改图表背景颜色。第二个参数用于确定是查看图表上的所有点 (0)，还是仅查看最终点 (1)。

示例：RED 0
• [颜色] 0
• [颜色] 1

 

ALARM_NO_CHART

用于禁止图表显示，除非存在失控违规。

选项：

• 0：任何点的违规都将触发图表显示。
• 1：仅最终点的违规会触发图表显示。
• 0
• 1

ALARM_TEXT

用于在违反任何失控规则测试时显示消息。这些参数是要显示的文本，以及确定是查看图表上的所有点 (0)，还是仅查看最终点 (1)。

示例：VIOLATION OCCURS [0]
• 字符串 [ 0 ]
• 字符串 [ 1 ]

 

ANNVAR

批注变量：用于将文本放置在绘制点附近的图表上。还必须使用 /Axis 选项。变量依次为 X 轴 ID、消息及缩写变量（可选）。必需的命名约定为 [QUERYNAME}.COMMENTS，后跟空格和 [QUERYNAME}.INSTANCEID。

[QUERYNAME].INSTANCEID[QUERYNAME].COMMENTS

[QUERYNAME].COMMENTABREV

AXIS

用于指定包含图表 X 轴标签的变量。此变量必须具有与数据变量相同的事例，可以是字符或数字。

示例：MEASUREMENTVALUES.INSTANCEID

{QUERYNAME].INSTANCEID

 

BARCOLOR

设置直方图条形的颜色。默认颜色为蓝灰色。

 

BRIEF

简要结果：用于显示简要结果

 

CL

中心线：定义图表中心线的值。

选项：

• 关闭
• 单个值 — 用于所有显示值或子组
• 值列表 — 空格分隔列表，其中必须为每个显示值或子组指派一个值，例如，150 125 100
• 关闭
• 单个值
• 值列表

CLASSES

要跨整个 X 轴长度使用的间隔数。默认值为 10。

 

COUNT

用于对包含原始数据的变量执行频率计数。

 

CS

中心规范：在图表上定义中心规范或工程线。选项：

• 单个值 — 用于所有显示值或子组
• 值列表 — 空格分隔列表，其中必须为每个显示值或子组指派一个值，例如，150 125 100
• 单个值
• 值列表

CURVE

生成曲线图。此选项连接所有 X 和 Y 轴变量的数据点。

 

DATA_STYLE

线条类型：用于指定线条类型的参数。

选项：

• 直线：点用细线相连；为默认值。
• 曲线：点用平滑（样条）曲线相连。
• 回归线：曲线显示数据的总体趋势，其中极值对曲线影响很小。
• 直线
• 曲线
• 回归线

DATA_WIDTH

线宽：用于指定数据线的宽度。

 

DELTA

与 /Vmask 结合使用，以指定流程中要防范的最小移位。该值必须为流程标准偏差的倍数。

任何实数。

DISPLAY

用于饼图以确定如何标记扇区。“百分比”标记每个扇区所占总数的百分比。这是默认情况。“数量”标记每个扇区的实际频率。
• 百分比
• 数量

DISPLAY3D

用于以三维外观形式显示图表。

 

DISPLAYVALUES

用于显示每个条形图上方的频率计数（条形高度）

 

GAP

用于显示条形之间有小间隙的图表

 

LABEL

用于指定数据点标签是否显示及其位置。

• NO — 不显示标签。
• INSIDE — 在每个数据点下方显示标签。
• OUTSIDE — 在每个数据点上方显示标签。
• NO
• INSIDE
• OUTSIDE

LABELSIZE

用于指定标签的字体大小。默认值是 25。

数值

LCL

控制下限

选项：

• 关闭
• 单个值 — 用于所有显示值或子组
• 值列表 — 空格分隔列表，其中必须为每个显示值或子组指派一个值，例如，150 125 100
• 关闭
• 单个值
• 值列表

LEGEND

用于饼图，以指定要显示的扇区标签。

 

LHEADSTART

起点值下限：用于累积和图表中，以指定累积和行起点值下限。默认值为 0。

 

LOCATION

图表位置：用于定位图表。指定的 X、Y 值表示图表左下角的位置。这些值必须在 [0,1000] 范围内。默认位置 0,0 表示图形区域的左下角。

 

LREFERENCE

参考下限：用于指定累积和行参考值下限。默认值是 0。

 

LSIZE

用于指定标签大小

 

LSL

规范下限：定义图表的规范下限或工程线。

选项：

• 单个值 — 用于所有显示值或子组
• 值列表 — 空格分隔列表，其中必须为每个显示值或子组指派一个值，例如，150 125 100
• 单个值
• 值列表

MANTISSA

用于指定计算值小数位后要显示的位数。默认值为 3。

 

MSTANDARD

总体均值：用于设置均值的标准值。此选项与 /RSTANDARD 结合使用，以提供控制限制的方法。

 

NODRAW

图表显示：选择此切换选项时，将定义图表但不显示。当使用自定义图形命令修改图表，或在同一图形上显示多个图表时使用此选项。

 

NORMAL

使用此选项会导致正态分布曲线下的预期频率叠加在直方图上。

当与 /CUMULATIVE 选项一起使用时将忽略。

 

NSIGMA

Sigma 数值：用于更改用于计算控制限制的 sigma 系数，默认值为 3.00。如果指定为 0，则不绘制控制上限和控制下限。

 

ORIENTATION

条形图方向：Vertical（默认）以垂直方式显示条形图，其标签位于数据空间下方。Horizontal 以水平方式显示条形图，其标签位于条形图左侧。
• Vertical
• Horizontal

REPORT

生成图表的文本报告。

 

RLEGEND

右侧图例：使用右侧图例标识每个控制行、警告行及规范行。
• 缩写
• 值
• 两者

RULE_LETTERS

显示规则字母：每个失控规则都有一个关联的字母。此选项控制是否显示违反特定规则的点旁边的字母。

• ON
• OFF

RSTANDARD

总体极差：指定数值用作总体极差的已知或假设值。

 

SAVE

保存数据：保存计算数据。

 

SAVEDATASET

结果数据集：指定已保存变量的数据集名称。

 

选择

在命令启动之前选择数据子集的表达式。

示例：( width > 1.3 )

( 表达式 )

SIZE

图表大小：默认情况下，使用整个显示区域生成图表。要限制图表的大小，在范围 [1,1000] 内指定 X（水平）和 Y（垂直）尺寸。

X 和 Y 必须都在 [1,1000] 范围内

 

SMOOTH

此选项用于绘制数据点的平滑曲线。

 

STDDEV

标准偏差：子组标准偏差用于计算控制和警告限制，而不是范围默认值。使用此选项时，子组可以包含的最大值数没有限制。如果未使用 STDDEV，则子组中的最大值数为 30。

 

SUBGROUPSIZE

表示要作为系数的分组数据点数。有两种分组方法：

• 数值常量：使用此方法可以指定一个数值。例如，数字五 (5) 表示前五个变量属于第一个组，接下来五个变量属于下一个组，以此类推。
• 组 Id：此方法要求为每个变量指定一个组标识。标识可以是数字或字符。可以根据变量的组 Id 得知其所属的组。（基本 SPC 产品随附的 SPC 查询中尚未使用此方法。）

 

SUMMARY

汇总信息：在图表底部显示汇总信息，如限值、点数及所违反的规则。当将“警报”子对话框显示规则字母切换设为 Auto 或 On 时，还会在违反特定规则的点旁边显示失控规则字母。
• 关闭
• On

TABLE_OTHER

用于在表中显示工作区变量信息。指定变量可以是字符或数字，且对于图表上的每个点必须有一个事例，或者有与数据变量相同的事例数，在此情况下，特定子组的所有信息都放在同一个单元中。必需的命名约定为 [QUERYNAME}.CONTAINERNAME。

[QUERYNAME}.CONTAINERNAME

表示要在曲线的尾部检查的数据分数。该值必须在 (0,1) 范围内。默认值为 0.1。

 

TIP_STATS

TITLE

用于指定要在图形顶部中心显示的字符串。

 

UCL

控制上限：定义图表的控制上限。

选项：

• 关闭
• 单个值 — 用于所有显示值或子组
• 值列表 — 空格分隔列表，其中必须为每个显示值或子组指派一个值，例如，150 125 100
• 关闭
• 单个值
• 值列表

USL

规范上限：定义图表的规范上限或工程线。

选项：

• 关闭
• 单个值 — 用于所有显示值或子组
• 值列表 — 空格分隔列表，其中必须为每个显示值或子组指派一个值，例如，150 125 100
• 关闭
• 单个值
• 值列表

WARN

警告限制：图表上将显示警告限制（UWL、LWL）。默认情况下，警告限制设为 ± 2-Sigma。可以通过指派大于 0 的参数值来调整警告限制。

 

WOFF

与 WARN 参数结合使用。取决于提供的参数值，将不显示警告上限或警告下限。

• 下限
• 上限

XLSIZE

X 轴标签字体大小：指定 X 轴标签的字体大小。指定的整数必须在 [1,100] 范围内。

 

YLSIZE

Y 轴标签字体大小：指定 Y 轴标签的字体大小。指定的整数必须在 [1,100] 范围内。

 

YMIN

定义 Y 轴的最小值。

 

YNAME

Y 轴旁边显示的字符串。

 

YSTEP

用于定义 Y 轴的刻度标签步长。

 

YFORMAT

用于指定 Y 轴刻度线标签的整数格式。
