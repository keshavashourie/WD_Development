设置输出参数

宏执行完成后，Statit 会填充输出参数。输出参数将返回到 SPC 函数 (_SPCExecuteSPC)。

重要提示: 假设输出参数（不要与输出参数值相混淆）不变。这样做将需要对 Opcenter Execution Semiconductor SPC 函数本身进行更改。

本区段中的代码

##---------------------

## Set Output Parameters

##---------------------

%SPCFailureAction = ""

%SPCResult = ""

%SPCTxnItemNames = ""

%SPCTxnResults = ""

%SPCTxnRuleViolationCounts = ""

%SPCStatitReturns = ""

%SPCTxnDataPointReturns = ""

$SPCQueryResultCount = 0
