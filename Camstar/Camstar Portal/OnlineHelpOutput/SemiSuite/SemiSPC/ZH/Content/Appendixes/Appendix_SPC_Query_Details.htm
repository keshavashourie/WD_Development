SPC 查询详细信息

SPC 查询对于评估 Opcenter Execution Semiconductor 内的制造流程非常关键。SPC 查询检索的数据的内容和结构必须符合已配置的 SPC 引擎。

SPCDataValues 查询

SPCDataValues 查询旨在评估 TrackOutLot 期间针对当前车间处理中的批次收集的 WIP 数据。该查询支持名为 DATAVALUES 的标准 SPC 设置。由于 SPC 的一个关键目的是审核制造绩效，因此查询需要同时从当前批次和历史数据中检索数据。因此，此查询是两个子查询的组合。

子查询

查询必须从两个单独的表集中提取数据：一个是当前批次数据集，另一个是历史数据集。

用于存储当前批次数据的表取决于 WIP 数据设置配置、是否存在设置流程类型以及哪种事务（服务）包含数据集合。如果将 WIP 数据设置配置为在 LotMoveOut 上发生，且 ProcessType 为空，则数据将临时存储在表 A_WIPLotData 中。所有其他 WIP 数据设置配置将存储在 A_WIPLotDetailsData 中。

如果在 TrackIn 或 TrackOut 期间收集 WIP 数据，则会在 TrackOut 流程中将结果转移到名为 A_WIPEquipmentDataHistory 的设备数据历史表中。

当该批次省略当前步骤时，系统会将所有 WIP 数据分别转移到正式历史表 A_WIPLotDataHistory 和 A_WIPLotDetailsDataHistory 中。

与 SPC 矩阵结合使用

如果为已选设备配置默认 SPC 设置，且选中“使用 SPC 矩阵”，则会在 Track In 过程中对 SPC 矩阵进行评估。要在 SPC 查询内使用 SPC 矩阵，必须更改与 SPC 矩阵相关联的 SPC 设置所使用的查询。具体而言，必须更改历史数据 JOIN 的 WHERE 子句，以包含矩阵 id。

如何修改 SPC 矩阵的 SPCDataValues 查询

按照以下步骤修改 SPCDataValues 查询：

1. 访问 SPC 查询对象的 SPCDataValues 实例。
2. 通过添加突出显示的行，修改第二个子查询中的 WHERE 子句，使其看起来与以下子句相似：

WHERE

WDN.WIPDataNameName LIKE ?WIPDATANAME

AND WEDH.WIPDataValue IS NOT NULL

AND WEDH.ServiceName = 'TrackOutLot'

AND WE.SPCMATRIXID = ?SPCMatrixId

AND WDN.FieldType = 'NUMBER'

AND WE.EquipmentName = ?EQUIPMENT

AND (CASE WHEN STDP.ExcludeData IS NULL THEN 0 ELSE STDP.ExcludeData END) = 0

) Query1

3. 单击“参数”表格上的添加新行。系统将启用表格上的一行字段。
4. 添加以下查询参数定义：
• 参数名称：SPCMatrixId
• 数据类型：字符串
• 显示文本：SPCMatrixId
• 参数值：
• 动态值：StringFromObject(SPCMatrix.InstanceID)
• 是必需的：True
• 用于块行：False
5. 单击保存。应用程序保存更改，随即显示状态消息。
