获取 DatabaseType

“获取 DatabaseType”区段检索 DatabaseType 变量，以确定数据库是 SQL Server 还是 Oracle。

本区段中的代码

##---------------------

##Get DatabaseType

##---------------------

SET DEFAULTDATASET ddsDatabaseType

BEGINSQL

SELECT

DB.DatabaseType AS "DatabaseType"

FROM

DBDataSourceNames DB

WHERE

DBDataSourceUsageId=1

ENDSQL

 

%DataBaseType = ddsDatabaseType.DataBaseType(1)

%ConcatSymbol = ""

IF %DataBaseType = "Oracle" THEN

%ConcatSymbol = " || "

ELSE IF %DataBaseType = "SQLServer"

%ConcatSymbol = " + "

END IF

%ParamNamesList = %ParamNamesList & "ConcatSymbol$"

%ParamValuesList = %ParamValuesList & %ConcatSymbol & "$"
