如何创建自定义规则文件

在开始之前

此部分仅适用于原有 SPC。开发人员必须能够访问 Statit Custom QC 应用程序才能成功生成自定义规则文件。

此流程的推荐方法是复制现有规则文件以用作基线并修改副本。为此，Siemens 建议复制 QC_ATT 规则文件 (qc_att.fcn)。

有关信息，请参考“SPC 随附的规则”。

QC 规则函数

所有规则均基于随 Opcenter Execution Semiconductor SPC 一同提供的三个标准规则函数之一。这些函数为 qc_rule1、qc_rule3 和 qc_rule4。

qc_rule1

在对一行的 M 个点中的 N 个点（超出或在某些限制范围内）进行测试时使用此函数；N 可以等于 M。

示例：

call qc_rule1( ("A", "A) 1 point above Zone

A",1,1,1,num(qc_ucl), 0,0,0, $found, $error)

decreasing", 6, 1, $found, $error))

如何创建自定义规则文件

按照以下步骤创建自定义规则文件：

1. 使用 Windows 资源管理器，在 C:\Program Files (x86)\Statit CustomQC\fsrc 文件夹中找到 qc_att.fcn。
2. 将 qc_att.fcn 复制到同一文件夹，将副本命名为 MyQCRules.fcn。
3. 使用记事本或其他可用的文本编辑器打开新文件 (MyQCRules.fcn)。
4. 在文件的第一行，将 "function qc_att" 更改为 "function MyQCRules"，如下例所示：

注释: 与该文件关联的每个规则的声明和定义直接显示在显示名称下方。注意下图中的规范上限违反示例：

6. 根据提供的函数信息，继续添加、删除或修改文件 MyQCRules.fcn 中的规则。
7. 保存文件并关闭文本编辑器。
8. 通过桌面图标或从“开始”菜单打开 CustomQC。
9. 在 CustomQC 中，选择文件 > 进程编译器并浏览进程源文件字段以选择 MyQCRules.fcn。将输出定向至 C:\Program Files (x86)\Statit CustomQC\fcns\ MyQCRules.stf。必须指定 .STF 扩展，否则会默认选择 .STP。
10. 单击确定。
11. 使用 Windows 资源管理器，将 .stf 文件复制到 C:\Program Files (x86)\Statit e-Server\fcns。如果要从 Portal 和 e-Server 而不仅仅是在 CustomQC 中使用，则可以执行此操作。
