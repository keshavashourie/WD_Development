提取 SPCSetupCDOType

“提取 SPCSetupCDOType”区段检索 CDOName 以确定 SPC 设置是标准还是基础。

本区段中的代码

##---------------------

## Fetch SPCSetupCDOType

##---------------------

SET DEFAULTDATASET ddsSPCSetupCDOType

BEGINSQL

SELECT

CD.CDONAME CDOName

FROM

A_SPCSETUP SS

JOIN CDODEFINITION CD ON SS.CDOTYPEID = CD.CDODEFID

WHERE

SS.SPCSETUPNAME = '@v[%SPCSetUpName]'

ENDSQL
