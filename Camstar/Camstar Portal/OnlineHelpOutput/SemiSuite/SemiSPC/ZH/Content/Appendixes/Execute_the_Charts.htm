执行图表

宏的“执行图表”区段为主要区段，针对每个已配置 SPC 图表执行最终编译和 SPC 执行过程。最后一个区段由经过重新处理（针对在 SPC 设置中建模的每个 SPC 图表）的子区段组成。

将某些变量设为项

由于这是宏的最终 SPC 评估过程，因此需要变量来处理每个 SPC 图表。以下列表概述所需变量：

• SPCChartName：当前正在处理的 StatIt SPC 图表名称。
• SPCSetupDetailsId：与 SPC 图表详细信息相关联的数据库实例 ID。
• ItemName：与当前正在处理的 SPC 图表相关联的通用名称。
• SPCRulesName：在当前 SPC 分析期间应用的 SPC 规则。
• FailureAction：根据 SPC 分析的结果应用于 Semi Suite 批次的操作。
• DisplayHistoricalLimits：确定是否将显示历史限制的标志。
• RuleViolationMethod：要实施以下哪种违规方法：
• 数据点违规
• 最后一个数据点违规
• 最后一个组违规
• SubGroupPlotMethod：用于确定是以默认方式、按晶元还是按批次对数据进行分组的标志。
• SPCQueryOverrideName：为当前正在处理的 SPC 图表配置的 SPC 查询替代的名称。
• DataValueNameOverride：用于确定当前正在处理的 SPC 图表是否具有数据值名称替代的标志。
• ResultsetSizeLimitOverride：当前正在处理的 SPC 图表的结果集大小限制替代值。

所有这些值都是根据“提取 SPCSetupDetails”流程返回的数据所得到的结果。

提取 SPCSetupDetailsParams

“提取 SPCSetupDetailsParams”仅执行 SQL 语句，以返回已在 SPC 设置详细信息上配置的所有图表参数名称和参数值。此查询还可以评估已由当前指派的 SPC 矩阵替代的图表参数。

本区段中的代码

##---------------------

## Fetch SPCSetupDetailsParams

##---------------------

SET DEFAULTDATASET ddsSPCSetupDetailsParams

BEGINSQL

SELECT

P.ParamName,

CASE WHEN WDMP.ParamName IS NULL THEN

CASE WHEN MP.ParamName IS NULL THEN P.ParamValue ELSE MP.ParamValue END

ELSE WDMP.ParamValue END ParamValue

FROM

A_SPCSetupDetails D

INNER JOIN A_SPCSetupDetailsParams P ON D.SPCSetupDetailsId = P.SPCSetupDetailsId

LEFT OUTER JOIN A_SPCMatrixParams MP ON D.SPCSetupDetailsName = MP.SPCSetupDetailsName

AND MP.SPCMatrixId = '@v[%SPCMatrixId]'

AND MP.ParamName = P.ParamName

LEFT OUTER JOIN A_SPCWIPDataMatrixParams WDMP ON D.SPCSetupDetailsName = WDMP.[Name]

AND WDMP.WIPDataSetupDetailsId = '@v[%WIPDataSetupDetailsId]'

AND WDMP.ParamName = P.ParamName

WHERE

D.SPCSetupDetailsId = '@v[%SPCSetupDetailsId]'

AND P.ParamType = 'CHART'

ENDSQL

ELSE
