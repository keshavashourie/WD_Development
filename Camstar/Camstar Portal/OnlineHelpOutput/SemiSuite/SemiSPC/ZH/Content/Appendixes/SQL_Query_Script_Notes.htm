SQL 查询脚本注释

此列表提供有关 SQL 查询的重要信息：

1. 对于此查询或此查询的任何变体，不得更改 Order by 子句，例外情况除外 - 即当对于每个晶元收集多个数据点且想要单独分析每个晶元时，可以将“Waferscribenumber DESC”添加到 ORDER BY 子句中。按以下步骤格式化修订子句：

Order By DataSource DESC, TxnTimestamp ASC, Waferscribenumber ASC ,DisplaySequence ASC

注释: 两个子查询还需要包含 Waferscribenumber。

在查看 SPC 图表时，从右到左评估 Statit 中的所有 SPC 趋势分析。注意以下子句参数的重要性：

• "DataSource DESC" 确保来自当前批次的数据始终显示为 SPC 图表上最右侧的数据点。
• "TxnTimeStamp ASC" 确保所有数据点按从新到旧的历史顺序放置。
• "DisplaySequence DESC" 确保在 WIP 数据流程期间所有数据点按收集顺序放置。
2. 图表上绘制的数据点数等于返回的行数除以 SubGroupSize。SubGroupSize 参数在 SPC 设置对象中进行配置。
