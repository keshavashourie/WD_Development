提取 SPCSetupQuery

“提取 SPCSetupQuery”区段的目的是通过定义的查询检索三个关键变量。该查询使用 SPCSetUpName 输入参数。在 Opcenter Execution Semiconductor 中，可以使用一个或多个 SPC 查询来配置 SPC 设置实例。这意味着“获取 SPCSetupQuery”可能会在结果中返回多条记录。下面是已配置查询的查询结果集中返回的三个变量：

• QueryName：与 SPC 设置相关的查询的名称。
• QueryText：与查询关联的查询文本。稍后将在宏中执行此查询文本
• SPCSetupId：与 SPC 设置关联的 Semi Suite 数据库实例 ID。

本区段中的代码

##---------------------

## Fetch SPCSetupQuery

##---------------------

SET DEFAULTDATASET ddsSPCSetupQuery

BEGINSQL

SELECT

C.UserQueryName QueryName

, C.QueryText QueryText

, A.SPCSetupId SPCSetupId

FROM

A_SPCSetup A

INNER JOIN A_SPCSetupQuery B ON A.SPCSetupId = B.SPCSetupId

INNER JOIN UserQuery C ON B.SPCQueryId = C.UserQueryId

WHERE

A.SPCSetupName = '@v[%SPCSetUpName]'

ENDSQL
