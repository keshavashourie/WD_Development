SPC Real Time Monitoring

The SPC Real-Time Monitoring page enables you to execute a previously executed SPC Setup and refresh the chart with the most up-to-date (real time) data.

The SPC Real Time Monitoring page also enables you to generate and automatically refresh configured Inline SPC charts. You can edit data points and add annotations for displayed Inline SPC charts.

When Using the SPC Real Time Monitoring Page

The SPC Real-Time Monitoring page requires you to have previously executed the chart for which you want real-time data. The Chart Section is initially blank. The application searches for an SPC record after you enter an SPC Setup and click Search . The application displays the chart or charts in the Chart Section after you click Search.

The size of the displayed chart can be configured in SPC Basic Setup modeling page by setting up the Chart Height and Chart Width fields. For chart's control, you may refer to Chart Display and Control for information on annotations and override.

How to Use the SPC Real Time Monitoring Page

Follow these steps to use the SPC Real Time Monitoring page:

1. Open the SPC Real Time Monitoring page.
2. Select an SPC Setup. The application enables the Search button.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Search. The application looks for the SPC Record. The application results displays any parameters and enables the Execute SPC button if the search is successful.
5. Click Execute SPC. The application displays the On button, the Refresh Interval control, and the chart or charts in the Chart Section.
6. Drag the Refresh Interval slider control to the right if you want to increase the refresh interval.
