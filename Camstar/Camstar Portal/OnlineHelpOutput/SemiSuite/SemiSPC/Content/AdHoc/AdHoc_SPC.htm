Ad-Hoc SPC

Ad-Hoc SPC page offers functionality to manually execute SPC Basic Setup or SPC Setup for both Legacy and Inline. This is typically used during run-time execution at Track Out Lot or WIP Data level.

The page allows you to plot and display SPC Chart for any collected shop floor data stored in the database as needed for any lot, regardless of state of the equipment in which it is transacting.

You are able to change data in the SPC Chart displayed on the Ad-Hoc SPC page. You also able to correct data that previously entered incorrectly or to exclude any bad data for future data traceability. When you change data in this way, SPC re-examines and updates the SPC Chart.

When Using Ad-Hoc SPC

You must create SPC data before you can use Ad-Hoc SPC to plot and display charts.

How to Display Information for an SPC Record

Follow these steps to display information for an SPC Record:

1. Open the Ad-Hoc SPC page.
2. Enter the SPC Setup for which you want to view SPC failure information in the SPC Setup field.
3. Enter parameters in the Param Value column for the relevant Param Name in the Parameters grid.
4. Click Execute SPC. The application displays the SPC Chart pop-up and SPC results in the Results area.

How to Override SPC Data Point Values

1. Perform the procedure in "How to Display Information for an SPC Record."
2. Click the data point that you wish to override in the SPC Chart. The application displays the Annotation pop-up.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit on the Annotation pop-up. The application displays a success message and returns you to the SPC Chart pop-up.
5. Click Close on the SPC Chart pop-up.
