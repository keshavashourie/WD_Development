SPC Triggers

These are the events that can trigger the Execute SPC transaction:

• Ad hoc WIP Data – This transaction is used to collect data for configured NDO, RDO or Container objects using the WIP Data Setup and Ad hoc WIP Data Setup configurations. When the user enters a value into the WIP Data field, the SPC Setups assigned to the WIP Data Setup are triggered.
• Ad hoc SPC – This transaction is used to manually trigger SPC execution. This transaction requires the field to be set since it is meant to execute SPC.
• Job Progress – This transaction is used to move the Resource from the current Stage to the next Stage within the Job Model. The technician must first be logged on and in the "clocked on" status. Note that multiple technicians can work at the same time.
• Track Out Lot – The SPC Setup that was determined during the Track In Lot service will be triggered if at least one unit is being tracked out. The Track In Lot transaction determines the SPC Setup by using either the Equipment’s SPC Setup or Use SPC Matrix field as described earlier. Note that for this transaction only one SPC Setup will be triggered.
• WIP Data – This transaction is used to collect data during Track In, Track Out, Complete Insertion or Move Out for a lot in a WIP step. The SPC Setups that were assigned to the WIP Data Setup will be triggered when a data value is updated.
Note: Grouped Data Collection is available in WIP Data Setup page. If primary lot fails the SPC conditions, then all other lots will be subjected to the same SPC Disposition Failure. Failure actions include HOLD, FUTUREHOLD or attached to NCR.
