Defining SPC Connections

The SPC Connection object is used to establish an ODBC database connection. SPC Connection is a required step for Inline SPC.

For Inline, it is required to create a 64Bit ODBC database connection to retrieve chart plotting data. Use the appropriate database driver. The application has created a default SPC Connection modeling object for Inline SPC which has pre-filled criteria for Inline SPC. You need to fill-up the remaining required connection fields to use this object.

Note: You must know the connection values to configure this object.

SPC Connection Provided with SPC

The SPC object modeling spreadsheet contains data to configure a default instance of the SPC Connection object. To view the instance created by the spreadsheet or to create a new instance, use the SPC Connection page.

How to Define an SPC Connection

Follow these steps to define an SPC Connection:

1. Open the SPC Connection page. The SPC Connection page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. For Inline SPC, you may use the predefined connection which has pre-filled criteria by selecting Inline SPC in the search instances. The application will populate page with pre-filled values.
4. To create custom connection for Legacy, enter a name in the SPC Connection field.
5. Enter the ODBC connection string information in the following fields:
• Data Source Name
• Username
• Password
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
