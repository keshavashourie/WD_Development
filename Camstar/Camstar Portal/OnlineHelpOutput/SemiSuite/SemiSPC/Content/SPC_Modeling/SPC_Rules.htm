Defining SPC Rules

When Defining SPC Rules for Inline

SPC Rules modeling object contains information that determines when charted data is acceptable or in violation of quality standards. SPC Rules are available for selection on the SPC Setup and SPC Basic Setup Details. You may copy one of the pre-loaded SPC Rules to use as the baseline for expert rule creation. You can then add and edit violation parameters to the copied rule. You can also create a new expert SPC Rule.

Refer to the Industry Rules section of the "SPC/IGC Common Component end user documentation" for information about the Common Component charts and rules used for Inline SPC.

Note: The pre-loaded SPC rules and violations are locked and cannot be edited. You can modify violation parameters for copied rules only.
Note: Warning limits are only calculated and utilized when employing the evaluation type "DGQ_WL"; other evaluation types do not accommodate warning limits.

How to Define New SPC Rules for Inline

1. Open the SPC Rules page. The SPC Rules page appears within the Modeling page.
2. Select the pre-loaded SPC Rule object that most closely resembles your requirements. The SPC Rule instance appears.
3. Click Copy. The Copy pop-up appears.
4. Enter a name for the expert rule in the Target Instance Name field.
5. Click Copy or press Enter on the keyboard. A success message displays.
6. Review the violations in the copied rule.
Note: Note: SPC violations are predefined. You can modify the violation parameters values for a copied rule, but you cannot modify or create violations.
7. Use the grid controls to add or delete violations from the SPC Rule Violations grid as needed. Added violations display at the bottom of the list in the grid. Deleted violations are removed from the list in the grid.
8. Use the edit grid control to edit the SPC Violation Parameters field values in the copied rule as needed. The edited values display in the SPC Violations Parameters column.
Note: Note: Refer to the Refer to the Industry Rules section of the "SPC/IGC Common Component end user documentation" for more information about the Common Component charts and rules used for Inline SPC.
9. Click Save. The application saves the modeling object and displays a success message.
