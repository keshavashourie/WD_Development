Defining SPC Chart Type

For Inline, the SPC Chart Type objects enable you to model supported chart types with parameters available to generate a chart in Inline SPC. The SPC Chart Type modeling object serves as a template to configure chart commands. There must be an instance of the SPC Chart Type modeling object for each chart that you want to call from Opcenter Execution Semiconductor.

SPC Chart Type Provided with SPC

The SPC object modeling spreadsheet contains data to configure instances of the SPC Chart Type object. Refer to "Appendix F: Inline SPC Chart Descriptions" for Inline SPC.

When Using the SPC Chart Type Page

The following rules apply when defining SPC Chart Type:

• Use this page to view instances of the SPC Chart Type object configured from the SPC object modeling spreadsheet.
• Although the automated spreadsheet process is recommended, you may use this page to manually create new instances or to manually update existing instances of the SPC Chart Type object.
• Do not use this page to modify default parameter values for specific use cases. Use SPC Setup instead. Also, note that SPC Setup values override default values when the setup executes the chart command.

How to Define an SPC Chart Type

Follow these steps to define an SPC Chart Type:

1. Open the SPC Chart Type page. The SPC Chart Type page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the SPC Chart Type name.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields. Refer to "Chart Parameter Descriptions" for parameter information.
5. Click Save. The application saves the modeling object and displays a success message.
