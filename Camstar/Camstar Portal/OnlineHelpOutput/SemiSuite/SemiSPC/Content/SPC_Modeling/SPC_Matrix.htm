Defining an SPC Matrix

The SPC matrix object is used during shop floor processing to determine the SPC Setup most suitable for the lot being processed. The SPC Matrix is only evaluated during the Track In transaction. The identified matrix is then triggered during the Track Out transaction and evaluates any data based on the configuration of the SPC Setup.

When Defining an SPC Matrix

Before defining an SPC matrix, there must be at least one SPC Setup configured.

Keep the following points in mind if the matrix object uses WIP Step Workflow to define a step in the workflow as one of the criteria:

• Deleting a step from the workflow referenced in the matrix object will render that particular matrix entry invalid.
• Editing a step in the workflow referenced in the matrix object does not render that particular matrix entry as invalid unless the step is removed and then re-entered.

How to Define an SPC Matrix

Follow these steps to define an SPC matrix:

1. Open the SPC Matrix page. The SPC Matrix page appears.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance
1. Click the Add button on the right-command bar.
2. Enter a name in the SPC Matrix Name field. If you do not enter a name, the system will generate one for you and display it in the post Save status message.
3. Select the SPC Setup.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.

An instance from an existing instance
1. In the Filter area, enter or select field values to search for the SPC Matrix you want to copy.
2. Click Apply button under the Filter grid. The application populates the grid with SPC Matrix instances that meet the entered criteria.
3. Scroll horizontally on the SPC Matrix grid to see additional instance detail.
4. Click the row with the instance you want to copy and click the Edit button. The application populates the Edit pop-up with the selected instance details.
5. Change the SPC Matrix Name.
6. Change criteria as needed.
7. Click Save As New. The application saves the modeling object and displays a status message.

Important: You must change both the name and at least one item in the Criteria area. Failure to do so will result in an error and the application will not save the new instance.
