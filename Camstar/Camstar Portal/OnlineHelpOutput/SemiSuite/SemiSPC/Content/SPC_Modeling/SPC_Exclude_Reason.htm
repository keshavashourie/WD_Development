Defining SPC Exclude Reasons

SPC Exclude Reasons are used when marking SPC Transaction Data Points for exclusion from SPC calculation.

SPC Exclude Reasons Provided with SPC

The SPC object modeling spreadsheet contains data to configure three exclude reasons:

• Engineering
• Production
• Customer

How to Define an SPC Exclude Reason

Follow these steps to define an SPC Exclude Reason:

1. Open the SPC Exclude Reason page. The SPC Exclude Reason page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name in the SPC Exclude Reason field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
