Defining SPC Charts

SPC Charts contain information required to display a single SPC chart. SPC charts describe the:

• Type of chart
• OCAPs
• Variable being plotted

Siemens provides four default SPC Charts for your use:

• Moving Range
• Range Chart
• Trial I-Chart
• X Chart
• Moving Range Inline
• Range Chart Inline
• Trial I-Chart Inline
• X Chart Inline
Important: The configuration of a SPC Chart Group with an associated SPC Chart should only be linked to a User Data Collection Definition that is configured to be executed within an Electronic Procedure in Opcenter Execution Semiconductor. All functionality (OCAPS) of the SPC Chart are not fully supported yet. It is recommended that a Semiconductor SPC Setup or SPC Basic Setup is assigned to the User Data Collection Definition. Alternately, all critical parameters requiring SPC Analysis should be collected via WIP Data.
When Defining SPC Charts

For Inline SPC, you must install and configure Inline SPC on your server before using this page. Otherwise, you will not be able to populate all required fields or save the page. Use the Out of Control Actions section of the SPC Chart to establish the actions triggered upon violation. SPC Chart is an optional definition in the SPC Chart Group modeling object. SPC Chart contains these optional Modeling definitions: Document E-mail Message, Hold Reason, and Reason Status Codes. It also uses Data Collection Def and User Collection Def in the Parameters section.

The Require Annotation check box requires annotations be entered when violations occur during chart generation. The SPC Charts pop-up appears when the Attempt OCAPs on Out-of-Control Charts check box is selected when generating a chart where the last data point is in violation, and cannot be closed until the last data point has been annotated. The SPC Annotation pop-up appears when only the last data point on the chart is in violation. If you attempt to close the SPC Charts pop-up, a warning message appears to inform you an annotation is required and references which charts require annotations. Refer to "Viewing and Entering Annotations" in the Opcenter™ Execution Core Statistical Process Control Reference Guide for information.

Using Dynamic Parameters for Inline SPC

Advanced Inline SPC users can configure chart parameters to use dynamic labels obtained from the field expressions or queries. In Parameters section, select the Is Dynamic check box for a parameter and enter the meta data table name and field or query name and column to display the value for a parameter. For example, the chartTitle parameter can be edited to display the product name from the container table. You must have knowledge of the object model and business logic for this use of the dynamic parameter functionality. Siemens recommends that this functionality is used with the Inline SPC Data Collection functionality.

You can also use queries to set the dynamic parameter values. The query used cannot have input parameters and should contain only text. Only the first row of the returned data will be applied for the dynamic parameter. User queries and SPC queries can be used. Use the following format for the Param Value parameter field: QueryName.ColumnName.

How to Define SPC Charts for Inline

Follow these steps to define Inline SPC Charts:

1. Opcenter Execution Semiconductor.
2. Select Modeling from the Modeling menu. The Modeling page appears.
3. Click SPC Chart. The SPC Chart page appears within the Modeling page.
4. To create new object, click New. Blank fields appear for you to define a new instance. You may also use the default pre-defined Inline SPC Chart from the search Instances.
5. Enter the SPC Chart Name.
6. Enter the Chart Type.
7. Enter the Variable to chart.
8. Select the Inline SPC check box to define an Inline SPC chart.
9. Complete the required fields: SPC Query, SPC Connection and SPC Chart Display Options.
10. Enter optional information according to your business requirements. Refer to the field definitions table for information about the optional fields.
11. Click Save. The application saves the modeling object and displays a success message.

How to Convert an Existing Legacy Macro into an Inline SPC Query Object

Follow these steps to convert a legacy macro into an Inline SPC Query object:

1. Opcenter Execution Semiconductor.
2. Select Modeling from the Modeling menu. The Modeling page appears.
3. Click SPC Chart. The SPC Chart page appears within the Modeling page.
4. Select an existing Legacy chart.
5. Select the Inline SPC check box. A warning message appears confirming the macro conversion.
6. Click Yes. The SPC Macro Conversion pop-up appears. The pop-up fields are automatically populated with information from the selected Legacy Query.
7. Enter the new SPC Query name.
8. Edit the query information according to your business requirements. Refer to the field definitions table for information about the optional fields.
9. Click Submit. The application saves the SPC Query object and displays a success message. You can review the saved query on the SPC Query page.
Note: A warning message appears if the selected Legacy macro includes more than one query and/or incomplete parameters. You must manually edit the query information before using it with Inline SPC. You can edit the converted macro and parameters on the SPC Macro Conversion pop-up and click Submit or click Submit and edit the converted macro and parameters on the SPC Query page.
