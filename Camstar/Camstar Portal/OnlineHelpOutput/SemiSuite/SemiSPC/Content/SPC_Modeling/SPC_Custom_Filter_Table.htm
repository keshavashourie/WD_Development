Defining SPC Custom Filter Tables

SPC Custom Filter Tables define aliases for table names used in SPC queries. Because SPC Custom Filters only affect the SPC Basic Setups configured with the SPC Matrix, the application only uses SPC custom filter tables for SPC analysis performed at Track Out .

Note: You must add any new SPC Custom Filters to the appropriate SPC Query. Custom filter tables are integrated to basic SPC queries.

How to Define an SPC Custom Filter Table

Follow these steps to define an SPC Custom Filter Table:

1. Open the SPC Custom Filter Table page. The SPC Custom Filter Table page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the SPC Custom Filter Table name.
4. Enter an alias for the table in the Alias field.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
