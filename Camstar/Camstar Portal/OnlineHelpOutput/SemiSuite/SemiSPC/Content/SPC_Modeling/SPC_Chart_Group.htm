Defining SPC Chart Groups

SPC Chart Groups are used to define a collection of SPC Charts, SPC Chart Groups, or both, depending on whether a single chart or a group of charts should be displayed. They are processed concurrently.

Defining SPC Chart Groups

Chart Groups can be associated with data collection definitions and user data collection definitions. Data collection definitions and user data collection definitions are usually linked to the Task object for task-based data collection.

SPC Chart Group contains the optional Modeling definition SPC Chart. SPC Chart Groups are attached to the Spec to define what chart is used on the data collection. Refer to the Opcenter Execution Medical Device and Diagnostics Modeling User Guide or the Opcenter Execution Core Modeling User Guide for information. Only groups that were previously defined can be added to the Groups grid.

The Resolved Entries button enables you to to display all charts and chart groups that currently belong to the SPC Chart Group.

Important: The configuration of a SPC Chart Group with an associated SPC Chart should only be linked to a User Data Collection Definition that is configured to be executed within an Electronic Procedure in Opcenter Execution Semiconductor. All functionality (OCAPS) of the SPC Chart are not fully supported yet. It is recommended that a Semiconductor SPC Setup or SPC Basic Setup is assigned to the User Data Collection Definition. Alternately, all critical parameters requiring SPC Analysis should be collected via WIP Data.

How to Define a New SPC Chart Group

Follow these steps to define a new SPC Chart Group:

1. Log on to Opcenter Execution Semiconductor.
2. Select Modeling from the Modeling menu. The Modeling page appears.
3. Click SPC Chart Group. The SPC Chart Group page appears within the Modeling page.
4. Click New. Blank fields appear for you to define a new instance.
5. Enter a name for the new SPC Chart Group.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information about the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.

How to Add SPC Charts or SPC Chart Groups

1. Complete the "How to Define a New SPC Chart Group" procedure.
2. Click Add new row in the Entries grid to add an SPC Chart. An entry field is displayed.
Or
Click Add new row in the Groups grid to add an SPC Chart Group. An entry field is displayed.
3. Select the desired SPC Chart or SPC Chart Group.
4. Repeat steps 2-3 to add additional charts or chart groups.
5. Click Save. The application saves the modeling object and displays a success message.
