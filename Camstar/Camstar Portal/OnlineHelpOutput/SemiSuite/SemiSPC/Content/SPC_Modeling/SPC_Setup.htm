Defining SPC Setups

When fully configured, an SPC Setup provides all of the information required to call the Inline SPC components for SPC processing. This object contains fields for chart display and failure processing.

SPC Setup can be used to change default parameter values for the chart it is configured to request. These changed values will be used for the chart when it is requested by this setup.

SPC Setups Provided with SPC

The SPC object modeling spreadsheet contains data to configure several SPC Setup object instances. Each SPC Setup works with a predefined, but customizable, SPC Query as follows:

• ADHOCWIPDATA – Sample SPC Setup consisting of a basic X-Bar (GXChart) and Range (GRChart) based on the SPCAdhocWIPData SPC Query.
• ADHOCWIPDATAINLINE – Sample SPC Setup consisting of a basic X-Bar and Range based on the SPCAdhocWIPData SPC Query.
• CHANGECOUNT – Sample SPC Setup consisting of a basic X-Bar (GXChart) and Range (GRChart) based on the SPChangeCount SPC Query.
• CHANGECOUNTINLINE – Sample SPC Setup consisting of a basic X-Bar and Range based on the SPChangeCount SPC Query.
• DATAVALUES – Sample SPC Setup consisting of a basic X-Bar (GXChart) and Range (GRChart) based on the SPCDataValues SPC Query.
• DATAVALUESINLINE – Sample SPC Setup consisting of a basic X-Bar and Range based on the SPCDataValues SPC Query.
• REJECTS – Sample SPC Setup consisting of a basic X-Bar (GXChart) and Range (GRChart) based on the SPCRejects SPC Query.
• REJECTSINLINE – Sample SPC Setup consisting of a basic X-Bar and Range based on the SPCRejects SPC Query.
• USERDATACOLLECTION – Sample SPC Setup consisting of a basic X-Bar (GXChart) and Range (GRChart) based on the SPCUserDataCollection SPC Query.
• USERDATACOLLECTIONINLINE – Sample SPC Setup consisting of a basic X-Bar and Range based on the SPCUserDataCollection SPC Query.

Assigning an SPC Setup

For an SPC Setup to be executed, it must be assigned to a shop floor object. When the object is used during a shop floor transaction, the assigned SPC Setup is triggered.

An SPC Setup can be assigned to the following objects:

• SPC Matrix – Uses configured criteria to determine the highest matching (most applicable) SPC Setup within the context of a given shop floor transaction.
• Equipment – The SPC Setup is triggered when equipment, used in a shop floor transaction, has been configured with SPC Setup or Use SPC Matrix.
• WIP Data Setup – The SPC Setup is triggered when data is entered into the WIP Data Setup field.
• Data Collection Def – The SPC Setup is triggered when data is entered into a Data Collection Definition that is part of a Job Progress transaction.

How to Define an SPC Setup for Inline

Follow these steps to define an SPC Setup (Inline):

1. Open the SPC Setup page. The SPC Setup page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the SPC Setup name.
4. Select the Inline SPC checkbox.
5. Enter the Chart Height. (A value of 450 is recommended.)
6. Enter the Chart Width. (A value of 900 is recommended.)
7. Click Add new row in the Details grid. The application displays the Add pop-up.
8. Using the Add pop-up:
a. Enter an Item Name to identify the chart.
b. Select the SPC Chart Type (Inline). The application fills in the Inline Chart Parameter grid with parameters and default values configured for the chart.
c. Using the Inline Chart Parameters grid:
• To change a parameter value, click the Param Value. (If blank, click the blank area.) The field becomes enabled. Enter the value.
• To allow a parameter value to be overridden when an SPC Matrix is applied, select the Allow Matrix Override check box.
• To add a parameter that is available for the chart, enter the exact name of the parameter in Param Name and enter values in the Param Value and Allow Matrix Override fields per your business requirements.
d. When finished, click OK. The pop-up closes.
9. Enter the SPC Query name in the Queries grid.
10. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
11. Click Save. The application saves the modeling object and displays a success message.

How to Convert SPC Setup from Legacy to Inline

1. Open the SPC Setup page from the Modeling menu. The SPC Setup page appears within the Modeling page.
2. Select an existing Legacy SPC Setup to convert.
3. Select the Inline SPC check box.
4. To change the existing Item's detail in Details grid, select the Item Name row and click the Edit button:
a. Select the SPC Chart Type (Inline). The application fills in the Inline Chart Parameter grid with parameters and default values configured for the chart.
b. Using the Inline Chart Parameters grid:
• To change a parameter value, click the Param Value. (If blank, click the blank area.) The field becomes enabled. Enter the value.
• To allow a parameter value to be overridden when an SPC Matrix is applied, select the Allow Matrix Override check box.
• To add a parameter that is available for the chart, enter the exact name of the parameter in Param Name and enter values in the Param Value and Allow Matrix Override fields per your business requirements.
c. Conversion process will enable five (5) optional fields; Is Y Variable, X Axis Trend Value, ANNVAR Primary Value, ANNVAR Secondary Value and ANNVAR Third Value. You may enter the optional information according to your business requirement.
d. When finished, click OK. The pop-up closes.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.

How to Assign SPC Setup

Follow these steps to assign an SPC Setup:

1. Open the modeling page for the object instance to which you want to assign the SPC Setup.
2. Enter the name of the SPC Setup in the SPC Setup field.
3. Click Save. The application saves the modeling object and displays a success message.
