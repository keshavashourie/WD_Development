Defining SPC Basic Setup

The SPC Basic Setup enables you to call Inline SPC for SPC processing. The SPC Basic Setup is different from the SPC Setup in that SPC Basic Setup minimizes the need to write custom SPC queries. Instead, it uses predefined basic SPC queries which are customized through the SPC Basic Setup page.

The SPC Basic Setup page contains fields for chart display and failure processing and can be used to change default parameter values for the chart it is configured to request. These changed values will be used for the chart when it is requested by the transaction that triggers the SPC analysis.

Assigning an SPC Basic Setup

For an SPC basic setup to be executed, it must be assigned to a shop floor object. When the object is used during a shop floor transaction, the assigned SPC basic setup is triggered.

An SPC basic setup can be assigned to the following objects:

• SPC Matrix – Uses configured criteria to determine the highest matching (most applicable) SPC basic setup within the context of a given shop floor transaction. The SPC Matrix is initiated only during Track Out and has no impact on SPC analysis triggered by other means.
• Equipment – The SPC basic setup is triggered when equipment, used in a shop floor transaction, has been configured with SPC basic setup or SPC Matrix.
• WIP Data Setup – The SPC basic setup is triggered when data is entered into the WIP Data Setup field.
• Data Collection Def – The SPC basic setup is triggered when data is entered into a Data Collection Definition that is part of a Job Progress transaction.

SPC Rule Data Point Analysis Method

Indicates which data points the SPC Macro will analyze to determine whether the SPC Result is recorded as PASS or FAIL. Options are:

• DEFAULT – The Macro assigns a FAIL SPC Result if there are any SPC Rule violations based on the selected SPC Rule.
• LAST DATA POINT – The Macro assigns a FAIL SPC Result if the last data point only is identified as an SPC Rule violation based on the selected SPC Rule. All SPC Rule violations prior to the last point will be ignored.
• LAST GROUP – Currently configured for the I-Chart (GICHART) within the Macro only. See "Prepare the Chart Parameters" for information on extending this feature to other charts. The macro assigns a FAIL SPC result if any data point within the last GROUP SEQUENCE (as defined in the SPC query) is identified as an SPC Rule violation.

Note: The background coloring of the SPC Chart during the chart display process is based on the ALARM_COLOR chart parameter. If the configured SPC Rule identifies a failure, the background color changes based on the configuration. This might not agree with the selected SPC Rule Data Point Analysis. The ALARM_COLOR default function is based on the evaluation of any failed data point. By extending the ALARM_COLOR value to RED 1, the background will evaluate only the last data point.

How to Define SPC Basic Setup for Inline

Follow these steps to define an SPC Basic Setup:

1. Open the SPC Basic Setup page. The SPC Basic Setup page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Select the Inline SPC checkbox.
4. Enter values for the following:

SPC Basic Setup

Chart Height

Chart Width

SPC Basic Query

Resultset Size Limit

5. Click Add new row in the Details grid. The application displays the Add pop-up.
6. Perform the following for every SPC item:
a. Enter required values for the following:

Item Name

SPC Chart Type (Inline)

Data Values

b. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
c. Click OK. The application closes the pop-up.
7. Click Save. The application saves the modeling object and displays a success message.
