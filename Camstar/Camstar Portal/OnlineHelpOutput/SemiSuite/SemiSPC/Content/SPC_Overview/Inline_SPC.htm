Inline SPC

Inline SPC is a separately licensed module of the Siemens Opcenter Execution Semiconductor applications that provides key elements in managing and improving the manufacturing process. It allows manufacturers to solve problems before they cause a reduction in yield or throughput. Without it, process problems are discovered too late, and valuable time and resources are consumed trying to fix a problem that could have been prevented.

An example of what happens during production occurs during measurement or testing of an attribute such as product thickness. The product's specification may state that the thickness must fall between 0.95 and 1.05 inches to be deemed an adequate part for use in a sub-assembly. Measurements show the average product thickness of five consecutive lots are 0.96, 0.98, 1.00, 1.02 and 1.04 inches. However, the application does not take action when looking at the lots individually because they are all within the product's specification.

Applying Statistical Process Control to these values would reveal this trend, probably after the third lot's average thickness is recorded. Engineering could be notified that the manufactured product’s thickness is increasing. At this point, effort would go into determining why the thickness of the units is increasing — while production continues. Therefore, the potential problem can be solved before equipment is shut down, before units are placed on hold, before material is scrapped, and before production time is lost.

SPC enables manufacturing and engineering to configure and include SPC control charts. Control charts can be updated as quality data is collected, and can be displayed to the operator for immediate feedback. Engineering can also review historical charts as a part of research into specific events.

The Inline Statistical Process Control module is using the SPC Common Component to analyze and display SPC charts. Refer to the Opcenter Execution Core Inline Statistical Process Control Reference Guide for more information on the Inline SPC installation, configuration and modeling requirements.

Inline SPC Installation

To use Inline SPC, you should be familiar with the components, prerequisites, and assumptions on which the implementation of Statistical Process Control is based.

Follow these steps to ensure Inline SPC is installed and configured correctly:

1. Install Inline SPC through the Opcenter Execution Core installation wizard. Refer to the Opcenter Execution Core Installation Guide for information.
2. The following scripts are included with the installation:

SPCConfiguration.cfg for SQL

SPCConfiguration.ORA.cfg for Oracle

3. You must run the appropriate script after you complete the installation. Refer to the Opcenter™ Exe-cution Core Transaction Tester User Guide for information. There are several sample charts available that will run with minimal configuration. Refer to "Configuring Sample Charts" for more information.
Note: Optionally, you can load Inline SPC test data through Management Studio. Refer to the Opcenter Execution Core System Administration Guide for information.
