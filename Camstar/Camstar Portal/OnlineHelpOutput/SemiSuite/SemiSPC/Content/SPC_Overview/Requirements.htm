Requirements

For Legacy SPC, the solution requires both SPC module and Statit e-Server to be installed at manufacturing site. The SPC modeling objects must be configured. This is generally done using the installation spreadsheet that comes with SPC and then making a few manual updates using SPC modeling object pages. Additionally, the Factory object XML client connection fields must be populated for SPC.

For Inline SPC, you may refer to Inline SPC and Required Modeling Objects for Inline SPC in this guide for more information.
