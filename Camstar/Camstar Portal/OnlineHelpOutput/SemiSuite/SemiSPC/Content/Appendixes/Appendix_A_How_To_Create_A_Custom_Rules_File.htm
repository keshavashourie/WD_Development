How to Create a Custom Rules File

Before You Begin

This section is only applicable for Legacy. The developer must have access to the Statit Custom QC application to successfully generate a custom Rules file.

The recommended approach to this process is to copy an existing rules file to use as a baseline and to modify the copy. For this purpose, Siemens recommends that you copy the QC_ATT rules file (qc_att.fcn).

Refer to "Rules Included with SPC" for information.

QC Rule Functions

All rules are based on one of the three standard rule functions supplied with Opcenter Execution Semiconductor SPC. These functions are qc_rule1, qc_rule3, and qc_rule4.

qc_rule1

This function is used when testing N out of M points in a row which are beyond or within some limits; N can equal M.

Example:

call qc_rule1( ("A", "A) 1 point above Zone

A",1,1,1,num(qc_ucl), 0,0,0, $found, $error)

qc_rule3

This function is used when testing for a number of points in a row of length N which are increasing and/or decreasing.

Example:

call qc_rule3( ("D", "D) 6 points in a row increasing or

decreasing", 6, 1, $found, $error))

qc_rule4

How to Create a Custom Rules File

Follow these steps to create a custom rules file:

1. Using Windows Explorer, locate qc_att.fcn in the C:\Program Files (x86)\Statit CustomQC\fsrc folder.
2. Copy qc_att.fcn to the same folder, naming the copy MyQCRules.fcn.
3. Open the new file (MyQCRules.fcn) with Notepad or another viable text editor.
4. At the very top line of the file change “function qc_att” to “function MyQCRules” as shown in this example:

5. Scroll down the rules file to find the display name. Change from “AT&T” to “MyQCRules” as shown in this example:

Note: The declaration and definition of each rule associated with the file appear directly below the display name. Note the Upper Spec Violation example in the image below:

6. Based on the function information provided, proceed to add, delete, or modify rules in the file MyQCRules.fcn.
7. Save the file and close the text editor.
8. Open CustomQC via the desktop icon or from the Start menu.
9. In CustomQC, select File > Proc Compiler and browse on the Proc Source File field to select MyQCRules.fcn. Direct the output to C:\Program Files (x86)\Statit CustomQC\fcns\ MyQCRules.stf. You must specify the .STF extension, or by default it will choose .STP.
10. Click OK.
11. Using Windows Explorer, copy the .stf file to C:\Program Files (x86)\Statit e-Server\fcns. This is done in case you want to use it from the Portal and e-Server and not just in CustomQC.
