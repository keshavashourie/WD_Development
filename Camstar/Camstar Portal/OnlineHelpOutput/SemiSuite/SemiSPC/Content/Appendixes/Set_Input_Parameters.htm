Set Input Parameters

SPC Macro requires five input parameters. These Parameters correlate to the parameters processed by the function (_SPCExecuteSPC).

Important: It is assumed that the input parameters (not to be confused with the input parameter values) would not be changed. Doing so would necessitate a change to the Opcenter Execution Semiconductor SPC function itself.
