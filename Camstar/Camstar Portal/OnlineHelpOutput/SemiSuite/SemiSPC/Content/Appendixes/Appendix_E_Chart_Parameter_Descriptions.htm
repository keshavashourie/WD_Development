Chart Parameter Descriptions

Opcenter Execution Semiconductor provides default parameters and values for the charts it provides. This table provides a reference to chart parameters and their definitions.

Parameter

Description

Valid Values

ALARM_COLOR

Used to change the chart background color when any of the out-of-control rule tests are violated. The second parameter is used to determine whether to look at all points (0) on the chart or just the final point (1).

Example: RED 0
• [color] 0
• [color] 1

 

ALARM_NO_CHART

Used to suppress chart display unless there is an Out-of-Control violation.

Options:

• 0: violation for any point will trigger chart display.
• 1: Only a violation at the final point triggers chart display.
• 0
• 1

ALARM_TEXT

Used to display a message when any of the out-of-control rule tests are violated. The parameters are the text to display and whether to look at all points (0) on the chart or just the final point (1).

Example: VIOLATION OCCURS [0]
• string [ 0 ]
• string [ 1 ]

 

ANNVAR

Annotation Variables: Used to place text on the chart near a plotted point. The /Axis option must also be used. The variables, in order, are the X-axis ID, Message, and optionally an Abbreviation variable. Required naming convention is [QUERYNAME}.COMMENTS followed by a space and [QUERYNAME}.INSTANCEID.

[QUERYNAME].INSTANCEID[QUERYNAME].COMMENTS

[QUERYNAME].COMMENTABREV

AXIS

Used to specify a variable containing labels for the X-axis of the chart. This variable, which must have the same number of cases as the data variable, is either character or numeric.

Example: MEASUREMENTVALUES.INSTANCEID

{QUERYNAME].INSTANCEID

 

BARCOLOR

Sets the color of the histogram bars. The default color is BlueGrey.

 

BRIEF

Brief Results: Used to display brief results

 

CL

Center Line: Defines the value of the chart's center line.

Options:

• Off
• One Value—used against all displayed values or subgroup
• List of Values—space delimited list where one value must be assigned for each displayed value or subgroup, for example, 150 125 100
• Off
• One Value
• List of Values

CLASSES

Number of intervals, to be used across the entire X-axis length. The default is 10.

 

COUNT

Used to perform a frequency count on a variable that contains raw data.

 

CS

Center Specification: Defines the center specification or engineering line on the chart. Options:

• One Value—used against all displayed values or subgroup
• List of Values—space delimited list where one value must be assigned for each displayed value or subgroup, for example, 150 125 100
• One Value
• List of Values

CURVE

Produce a curve plot. This option connects the data points for all X and Y axis variables.

 

DATA_STYLE

Line Type: Parameter used to specify type of line.

Options:

• Line: Points are connected with a sharp line; this is the default.
• Curve: Points are connected with a smoothed (spline) curve.
• Lowess: Curve shows the overall trend of the data where extreme values have little influence on the curve.
• Line
• Curve
• Lowess

DATA_WIDTH

Line Width: Used to specify the width of the data line.

 

DELTA

Used in conjunction with /Vmask to specify the smallest shift in the process mean to be guarded against. This value must be a multiple of the process standard deviation.

Any real number.

DISPLAY

Used for pie chart to determine how to label slices. "Percent" labels each slice as its percent of the total. This is the default. "Quantity" labels each slice with its actual frequency.
• Percent
• Quantity

DISPLAY3D

Used to display the chart with a 3-dimensional appearance.

 

DISPLAYVALUES

Used to show the frequency count (bar height) above each bar

 

GAP

Used to display the chart with a small gap between bars

 

LABEL

Used to specify presence of and position of data point labels.

• NO—Do not display labels.
• INSIDE—Display lables below each data point.
• OUTSIDE—Display labels above each data point.
• NO
• INSIDE
• OUTSIDE

LABELSIZE

Used to specify font size of labels. Default is 25.

Number

LCL

Lower Control Limit

Options:

• Off
• One Value—used against all displayed values or subgroup
• List of Values—space delimited list where one value must be assigned for each displayed value or subgroup, for example, 150 125 100
• Off
• One Value
• List of Values

LEGEND

Used in pie charts to specify slice label to display.

 

LHEADSTART

Lower Head Start: Used in cumulative sum charts to specify the lower cumulative sum line headstart value. The default is 0.

 

LOCATION

Chart Location: Used to position the chart. The specified X, Y values indicate the position of the chart bottom left corner. These values must be in the range [0,1000]. The default position of 0,0 indicates the bottom left corner of the graph area.

 

LREFERENCE

Lower Reference: Used to specify the lower cumulative sum line reference value. Default is 0.

 

LSIZE

Used to specify label size

 

LSL

Lower Spec Limit: Defines the lower specification or engineering line on the chart.

Options:

• One Value—used against all displayed values or subgroup
• List of Values—space delimited list where one value must be assigned for each displayed value or subgroup, for example, 150 125 100
• One Value
• List of Values

MANTISSA

Used to specify number of digits after the decimal place to display for calculated values. The default is 3.

 

MSTANDARD

Population Mean: Used to set the standard value of the mean. This option is used in conjunction with /RSTANDARD to provide one method of controlling the limits.

 

NODRAW

Chart Display: When this toggle is selected, the chart is defined but not displayed. This is used when the chart is to be modified using custom graphics commands or multiple charts are to be displayed on the same graph.

 

NORMAL

Use of this option results in the expected frequencies under the normal distribution curve to be superimposed on the histogram.

Ignored when used in conjunction with the /CUMULATIVE option.

 

NSIGMA

Number of Sigmas: used to change the coefficient of sigma used in computing the control limits from the default of 3.00. If 0 is specified, the upper and lower control limits are not drawn.

 

ORIENTATION

Bar Orientation: Vertical (the default) displays the bars vertically with their labels below the data space. Horizontal displays the bars horizontally with their labels to the left of the bar.
• Vertical
• Horizontal

REPORT

Generates a text report for the chart.

 

RLEGEND

Right Legend: Used to identify each control line, warning line and spec line with a right-side legend.
• abbreviation
• value
• both

RULE_LETTERS

Display Rule Letters: Each out-of-control rule has a letter associated with it. This option controls whether or not to display the letter next to points which violate the particular rule.

• ON
• OFF

RSTANDARD

Population Range: Number specified is used as the known or assumed value of the universe range.

 

SAVE

Save Data: Saves the calculated data.

 

SAVEDATASET

Results Dataset: Specifies the dataset name for the saved variables.

 

SELECT

An expression that selects a subset of data prior to the start of the command.

Example: ( width > 1.3 )

( expression )

SIZE

Chart Size: By default, the chart is generated using the entire display area. To restrict the size of the chart, specify the X (horizontal) and Y (vertical) dimensions in the range [1,1000].

X and Y must both be within range [1,1000]

 

SMOOTH

This option plots a smooth curve through the data points.

 

STDDEV

Standard Deviation: Results in the subgroup standard deviations being used to compute the control and warning limits rather than the default of the ranges. There is no limit on the maximum number of values that a subgroup can contain when this option is used. If STDDEV is not utilized, the maximum number of values in a subgroup is 30.

 

SUBGROUPSIZE

Represents the number of data points to be grouped as factors. There are two grouping methods:

• Numeric constant: With this method, you specify a numeric value. For example, the number five (5) indicates that the first five variables belong to the first group, the next five values belong to the next group, and so on.
• Group Id: This method requires that each variable be given a group identifier. The identifier can be numeric or character. The group to which a variable belongs is known by its group Id. (This method is not demonstrated in the SPC Queries provided with the base SPC product.)

 

SUMMARY

Summary Information: Displays summary information at the bottom of the chart such as the limit values, number of points and rules violated. Also displays the out-of-control rule letter next to points which violate a particular rule when the Alarm subdialog Display rule letters toggle is set to Auto or On.
• Off
• On

TABLE_OTHER

Used to display workspace variable information in the table. The specified variables are either character or numeric and must have either one case for each point on the chart or the same number of cases as the Data Variable, in which case all information for a particular subgroup is placed in the same cell. Required naming convention is [QUERYNAME}.CONTAINERNAME.

[QUERYNAME}.CONTAINERNAME

TABLE_STATS

Used to display statistics related to each sub-group. Space delimited.

• Data
• Mean
• Range_STDDEV
• N
• X
• Shortrun
• UCL
• CL
• LCL
• CS
• LSL
• UWL
• LWL

TAIL

Indicates fraction of data to be examined in the tail or tails of the curve. This value must be in range of (0,1). The default value is 0.1.

 

TIP_STATS

Used to display Data Tips based on options provided. Options (listed on right) are separated by a space.
• Data
• N
• X
• Shortrun
• UCL
• CL
• LCL
• CS
• LSL
• UWL
• LWL

TITLE

Used to specify string or strings to be displayed at the top center of the graph.

 

UCL

Upper Control Limit: Defines the upper control limit for the chart.

Options:

• Off
• One Value—used against all displayed values or subgroup
• List of Values – space delimited list where one value must be assigned for each displayed value or subgroup, for example, 150 125 100
• Off
• One Value
• List of Values

USL

Upper Spec Limit: Defines the upper specification or engineering line on the chart.

Options:

• Off
• One Value—used against all displayed values or subgroup
• List of Values – space delimited list where one value must be assigned for each displayed value or subgroup, for example, 150 125 100
• Off
• One Value
• List of Values

WARN

Warning Limits: Results in Warning Limits (UWL, LWL) limits being displayed on the chart. By default, Warning Limits are placed at ± 2-Sigma. The Warning Limits may be adjusted by assigning a parameter value greater than 0.

 

WOFF

Works with the WARN parameter. Dependent on the provided parameter value, either the lower or upper warning limit will not be displayed.

• lower
• upper

XLSIZE

X Axis Label Font Size: Specifies font size for the X-axis labels. Specified integer must be in the range [1,100].

 

YLSIZE

Y Axis Label Font Size: Specifies font size for the Y-axis labels. Specified integer must be in the range [1,100].

 

YMIN

Defines the minimum value for the Y-axis.

 

YNAME

Character string displayed beside the Y-axis.

 

YSTEP

Used to define the tick label step size for the Y-axis.

 

YFORMAT

Used to specify the integer format for the Y-axis tick mark labels.

 
Note: Review the help files provided with Statit Custom QC for a complete list of all parameters available for each chart type.
