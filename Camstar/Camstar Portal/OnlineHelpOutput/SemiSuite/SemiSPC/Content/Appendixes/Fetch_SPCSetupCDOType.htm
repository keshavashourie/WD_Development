Fetch SPCSetupCDOType

The Fetch SPCSetupCDOType section retrieves the CDOName to determine whether the SPC Setup is standard or basic.

Code in this Section

##---------------------

## Fetch SPCSetupCDOType

##---------------------

SET DEFAULTDATASET ddsSPCSetupCDOType

BEGINSQL

SELECT

CD.CDONAME CDOName

FROM

A_SPCSETUP SS

JOIN CDODEFINITION CD ON SS.CDOTYPEID = CD.CDODEFID

WHERE

SS.SPCSETUPNAME = '@v[%SPCSetUpName]'

ENDSQL
