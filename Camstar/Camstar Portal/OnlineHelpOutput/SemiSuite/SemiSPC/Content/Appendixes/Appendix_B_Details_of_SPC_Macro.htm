SPC Macro

The section is only applicable for Legacy. The Opcenter Execution Semiconductor SPC Macro file is named SPCInterface.stc. It is designed to dynamically support all supplied Opcenter Execution Semiconductor SPC chart with no need for modification. Users who determine that a modified macro is necessary should find this section helpful. Additional information can be viewed in the Statit Custom QC Help files.

The SPC Macro file has several main areas of logic, each identified by a comment area at its beginning. This appendix is organized into those same areas with each subheading matching its counterpart comment in the macro file.
