Execute SPCSetupQuery Queries

The primary objective of this section of the macro is to execute the Query text that was previously retrieved in “Fetch SPCSetupQuery.” Prior to executing the query, it is necessary to replace the query parameters with the appropriate parameter values. Both the list of parameter names and parameter values were submitted to the macro as input parameters by the Opcenter Execution Semiconductor function (_SPCExecuteSPC). After the parameters are replaced, the queries are executed and the results are stored in variables for future reference.

Note: You should use unique parameter names within the SPC query configuration unless you want to use the same resolved query parameter value in each query when configuring multiple SPC setup queries.

Code in this Section

##---------------------

## Execute SPCSetupQuery Queries

##---------------------

FOR $QueryIndex = 1 to CASE(ddsSPCSetupQuery.QueryText)

%SQLQueryText = ddsSPCSetupQuery.QueryText($QueryIndex)

%SQLQueryName = ddsSPCSetupQuery.QueryName($QueryIndex)

##---------------------

## Replace Query Parameters in the QueryText with the ParamNames and ParamValues passed in

##---------------------

$ParamNameStartPos = 1

$ParamNameStopPos = 1

$ParamValueStartPos = 1

$ParamValueStopPos = 1

%CustomFilterParamExist = "false"

WHILE ($ParamNameStopPos > 0)

$ParamNameStopPos = INSTR($ParamNameStartPos, %ParamNamesList, %ParamDelimiter)

IF ($ParamNameStopPos > 0) THEN

%ParamName = "?" & MID(%ParamNamesList, $ParamNameStartPos, $ParamNameStopPos - $ParamNameStartPos)

$ParamNameStartPos = $ParamNameStopPos + 1

$ParamValueStopPos = INSTR($ParamValueStartPos, %ParamValuesList, %ParamDelimiter)

IF ($ParamValueStopPos > 0) THEN

IF (%ParamName = "?CustomFilters") THEN

%ParamValue = MID(%ParamValuesList, $ParamValueStartPos, $ParamValueStopPos - $ParamValueStartPos)

%CustomFilterParamExist = "true"

ELSE IF (%ParamName = "?ConcatSymbol") THEN

/*

*/

%ParamValue = MID(%ParamValuesList, $ParamValueStartPos, $ParamValueStopPos - $ParamValueStartPos)

ELSE

%ParamValue = "'" & MID(%ParamValuesList, $ParamValueStartPos, $ParamValueStopPos - $ParamValueStartPos) & "'"

ENDIF

$ParamValueStartPos = $ParamValueStopPos + 1

ELSE

%ParamValue = "''"

END IF

%SQLQueryText = CHANGE(%SQLQueryText, %ParamName, %ParamValue, 10)

END IF

WEND

##---------------------

## Replace Query CustomFilters Parameter in the QueryText with with empty value

##---------------------

IF (%CustomFilterParamExist = "false") THEN

%ParamName = "?CustomFilters"

%ParamValue = ""

%SQLQueryText = CHANGE(%SQLQueryText, %ParamName, %ParamValue, 10)

END IF

NEXT
