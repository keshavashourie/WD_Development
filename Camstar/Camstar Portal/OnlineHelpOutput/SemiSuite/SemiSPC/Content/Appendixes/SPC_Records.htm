SPC Records

SPC Records is used to search previously executed SPC Setups. Once SPC Setup is selected, you are able to see SPC Chart pop-up. The pop-up displays SPC Charts and allow user to add annotation and exclusion of data points. You are also able to re-plot the chart by using the SPC Txn Data maintenance service.

The SPC Records is now integrated with Inline SPC where you can use display and re-plot button to display Inline SPC Chart as well as adding annotation and data points to the chart.

How to Search SPC Records

Follow these steps to query the SPC records:

1. Open the SPC Records page.
2. Enter the search criteria in the Enter Search Criteria area.
3. Click Search. The application displays the records that match the search criteria in the Search Results grid.
4. Click the record which you want to see or edit in the Search Results grid. The application displays the details in the Details area.
5. Perform one of the following:

Click...

To display...

Display

Historic data. The application displays a pop-up showing the SPC Chart for the historic SPC records.

Re-Plot

Current data. The application displays a pop-up showing the SPC Chart for the most current SPC records.

How to Override SPC Data Point Values

1. Perform the procedure in "SPC Records."
2. Click the data point that you wish to override in the SPC Chart. The application displays the Annotation pop-up.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit on the Annotation pop-up. The application displays a success message and returns you to the SPC Chart pop-up.
5. Click Close on the SPC Chart pop-up.
