SPC Chart Type Descriptions

This table provides information about the charts provided with SPC and supported by Statit. For each chart, It lists the command used to generate the chart, the chart name, and the chart description.

Chart Command

Chart Name

Chart Description

DISPERSION

Dispersion

Provides inference about either the standard deviation or the interquartile range (IQR) of a population, based on a single sample.

FREQ

Frequency Distribution

Computes a frequency distribution for measurement variables.

GBAR

Bar

Useful for viewing a wide variety of data. In its most simple form, it can be used to examine one categorical variable, in which case a bar is drawn for each unique value and the length of the bar represents the number of occurrences of the value.

GBOX

Box

Plots each variable in the variable list. The command requires a real variable and can handle a grouping variable that is numeric or string.

GCCHART

C

Based on the total number of defects per "area of opportunity" (unit). It is very important that the "area of opportunity" for a defect be constant from subgroup to subgroup since it shows the total number of nonconformities.

GCUSUM

Cumulative Sum

Displays a running summation of process deviation from a pre-selected reference or target value. It resolves the shotgun or scattered appearance of the regular control chart into a visual tracking of process changes.

GDOT

Dot

Displays measurement data displaying a label for each point on the chart. This chart is often used in place of a pie or bar chart because it does not require making difficult angle judgments or having a meaningful baseline.

GGROUPM

Group Measures

Allows examination of various statistics for different samples or population groups of data variables (requires at least two (2) variables).

GHIST

Histogram

Plots a histogram for measurement variables.

GICHART

Item, I, X

Often used when the process under observation is too slow to form special clusters over time. Consequently, a "subgroup size" value of at least 2 is required.

GMEDCHART

Median

Plots the Median to prevent extremely high or low values in a subgroup from effecting the chart.

GMVAVG

Moving Average

Both uniformly weighted and exponentially weighted moving average charts are available.

A uniformly weighted chart displays the moving average of successive observations. For example, if the chart is based on 2 observations, then the first point on the chart is the average of the first and second observations, the second point is the average of observations 2 and 3, then the average of 3 and 4, etc.

Each point on the exponentially weighted chart is composed of a fraction of the subgroup average, or individual observation, and a fraction of the previous point.

GMVRNG

Moving Range

This type of chart displays the moving range of successive observations.

For example, if the chart is based on 2 observations, then the first point on the chart is the range of the first and second observations, the second point is the range of observations 2 and 3, then the range of 3 and 4, etc. This results in a smoothing effect which is often useful in continuous process chemical manufacturing.

GNPCHART

NP

Control chart for the number of nonconforming items found in either constant or varying sized subgroups.

GPAIRS

Scatterplot Matrix

Scatter plot matrices, where all variables in the list are plotted against each other (requires at least 2 variables).

GPARETO

Pareto

Indicates which problem to tackle first by showing the proportion of the total problem that the smaller problems comprise.

GPC

Process Capability

Generates a chart that deals with the problem of adjusting the process to the point where virtually all of the product output meets specifications.

GPCHART

P

Control chart for the fraction or percent of nonconforming items found in either constant or varying sized subgroups.

GPERCENT

Q-Q PLOT

Used to examine the distribution of one variable or compare the distributions of two variables. The percentile plot helps identify median, quartiles, interquartile range, and other individual percentiles.

GPIE

Pie

Slices represent the frequency of each unique data value for a single variable.

GPLOT

XY, Contour Plot

Used to generate a variety of general purpose plots including XY, XYZ, bubble, sunflower, and contour. Requires at least two variables.

GPROB

Probability Plot

Used to display a normal probability plot for a single variable. The purpose of this plot is to show whether the data approximates a normal distribution, which can be an important assumption in many statistical analyses.

GRCHART

R

Displays the ranges of the subgroups.

GROUP

Multi-way univariate statistics

Provides a technique for examining various statistics for dependent or analysis variables among various groupings in a sample or population.

GSCHART

S

Displays the standard deviation of the subgroups.

GUCHART

U

Designed for situations where the number of nonconformities per unit is measured and the number of units changes from subgroup to subgroup. The symbol u is the total number of defects observed divided by the total number of items inspected.

GUCUSUM

U-Type Cumulative Sum

Points plotted are a function of the cumulative deviations of the number of nonconformities per unit from a known target value.

GXCHART

X-Bar

Displays the means of the subgroups.

LOCATION

Location

Provides inference about either the mean or median of a population, based on a single sample.

PROCCAB

Process Capability Analysis

Intended for large amounts of data and seeks to identify future data expected to fall outside of configured limits. If the data is grouped, data is adjusted by removing the group variation ( data_adj = deviation from group mean + grand mean ).

STATS

Univariate Statistics

Computes various univariate statistics, such as mean, median, variance, maximum, minimum.

SWNORM

Shapiro-Wilk W

Carries out a test of normality which is based on the Shapiro-Wilk W test.

TTEST

T-Test

Used for general testing and applicable to all of the one-sample, two-sample, or paired-data problems.
