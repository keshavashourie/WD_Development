SQL Query Script Notes

This list provides important information about the SQL query:

1. Order by clause must not be changed for this query or any variations of this query with one exception – when multiple data points are collected per wafer and you want to analyze each wafer individually, you can add "Waferscribenumber DESC” to the ORDER BY clause. Format the revised clause as follows:

Order By DataSource DESC, TxnTimestamp ASC, Waferscribenumber ASC ,DisplaySequence ASC

Note: Both sub-queries would also need to include the Waferscribenumber.

All SPC trend analysis within Statit is evaluated from right to left when viewing the SPC Chart. Note the significance of the following clause parameters:

• “DataSource DESC” ensures that the data from the current lot is always presented as the farthest right data point on the SPC Chart.
• “TxnTimeStamp ASC” ensures that all data points are placed in historical order from newest to oldest.
• “DisplaySequence DESC” ensures that all data points are placed in the order of collection during the WIP Data process.
2. The number of data points plotted on the chart equals the number of rows returned divided by SubGroupSize. The SubGroupSize parameter is configured in the SPC Setup object.
