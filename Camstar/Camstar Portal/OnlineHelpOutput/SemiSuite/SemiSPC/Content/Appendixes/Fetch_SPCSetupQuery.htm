Fetch SPCSetupQuery

The objective of the Fetch SPCSetupQuery section is to retrieve three key variables via the defined query. The query utilizes the SPCSetUpName Input Parameter. Within Opcenter Execution Semiconductor, the SPC Setup instance can be configured with one or more SPC queries. This means that the Fetch SPCSetupQuery may return more than one record in the result. Below are the three variables returned in the query resultset for a configured query:

• QueryName: The Name of the query associated to the SPC Setup.
• QueryText: The Query Text associated to the query. This query text will be executed later in the macro
• SPCSetupId: The Semi Suite database InstanceId associated to the SPC Setup.

Code in this Section

##---------------------

## Fetch SPCSetupQuery

##---------------------

SET DEFAULTDATASET ddsSPCSetupQuery

BEGINSQL

SELECT

C.UserQueryName QueryName

, C.QueryText QueryText

, A.SPCSetupId SPCSetupId

FROM

A_SPCSetup A

INNER JOIN A_SPCSetupQuery B ON A.SPCSetupId = B.SPCSetupId

INNER JOIN UserQuery C ON B.SPCQueryId = C.UserQueryId

WHERE

A.SPCSetupName = '@v[%SPCSetUpName]'

ENDSQL
