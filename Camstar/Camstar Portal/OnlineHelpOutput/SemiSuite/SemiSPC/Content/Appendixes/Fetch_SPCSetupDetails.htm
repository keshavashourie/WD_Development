Fetch SPCSetupDetails

The primary objective of Fetch SPCSetupDetails is to retrieve all customized configuration related to a specific SPC Setup. Since multiple types of SPC Chart are generally modeled within each SPC Setup, this query may return numerous records. This is a list of the key parameters related to each SPC Chart:

• SPCSetupName: Repeat of the SPCSetupName query parameter. No impact to overall processing.
• SPCSetupDetailsId: Unique database InstanceID associated to the configured SPC Chart within the SPC Setup.
• ItemName: Generic name associated to the SPC Chart, for example, X-Bar or Range.
• FailureAction: Action that will occur to the shop floor Lot in the event of an SPC Rules failure.
• SPCChartName: Statit name of the SPC Chart associated to the SPCSetupDetailsId, for example, GXCHART, GRCHART, or STATS.
• SPCRulesName: SPC Rules instance to apply to the data during the SPC evaluation process. Equivalent to the a StatIt SPC rule, for example, QC_ATT, or NONE.

##---------------------

## Fetch SPCSetupDetails

##---------------------

SET DEFAULTDATASET ddsSPCSetupDetails

BEGINSQL

SELECT

A.SPCSetupName

, B.SPCSetupDetailsId SPCSetupDetailsId

, B.SPCSetupDetailsName ItemName

, B.DisplaySequence DisplaySequence

, B.FailureAction FailureAction

, C.SPCChartName SPCChartName

, D.SPCRulesName SPCRulesName

, B.ss_DisplayHistoricalLimits DisplayHistoricalLimits

, CASE WHEN B.SS_SPCRULEDATAPOINTANALYSISMET IS NULL THEN '1' ELSE B.SS_SPCRULEDATAPOINTANALYSISMET END RuleViolationMethod

, CASE WHEN B.SS_SUBGROUPPLOTMETHOD IS NULL THEN '-1' ELSE B.SS_SUBGROUPPLOTMETHOD END SubGroupPlotMethod

, CASE WHEN E.UserQueryName IS NULL THEN '-1' ELSE E.UserQueryName END QueryName

, CASE WHEN B.scsDVNOverride IS NULL THEN '-1' ELSE B.scsDVNOverride END DataValueName

, CASE WHEN B.scsRSLOverride IS NULL THEN 0 ELSE B.scsRSLOverride END ResultsetSizeLimit

FROM

A_SPCSetup A

INNER JOIN A_SPCSetupDetails B ON A.SPCSetupId = B.SPCSetupId

/*

*/

INNER JOIN A_SPCChart C ON B.SPCChartId = C.SPCChartId

LEFT OUTER JOIN A_SPCRules D ON B.SPCRulesId = D.SPCRulesId

LEFT OUTER JOIN UserQuery E ON B.scsSPCQueryOverrideId = E.UserQueryId

WHERE

A.SPCSetupName = '@v[%SPCSetupName]'

ORDER BY

B.DisplaySequence

ENDSQL

 

%BeforeReplace = %SQLQueryText

 

$SpecificDataValueNameStartPos = 1

 

$SpecificChartTitleStartPos = 1
