SPC Query Details

The SPC queries are critical to the evaluation of the manufacturing process within Opcenter Execution Semiconductor. The content and structure of the data retrieved by the SPC query must comply with the configured SPC engine.

SPCDataValues Query

The SPCDataValues query is designed to evaluate the WIP Data collected for a lot currently in shop floor processing during TrackOutLot. The query supports the standard SPC Setup named DATAVALUES. Since a key purpose of SPC is to review the performance of manufacturing over time, the query needs to retrieve the data from the current lot and the historical data at the same time. Thus, this query is a composite of two sub-queries.

Sub-queries

The query must pull data from two separate sets of tables: One set for current lot data and another set for historical data.

The tables used to store current lot data vary depending upon WIP Data Setup configuration, whether there is a set Process Type, and which transaction (service) contains the data collection. If the WIP Data Setup is configured to occur on LotMoveOut and the ProcessType is empty, the data will be temporarily stored in the table A_WIPLotData. All other WIP Data Setup configurations will be stored in A_WIPLotDetailsData.

If WIP Data is collected during TrackIn or TrackOut, the results are transferred during the TrackOut process to an equipment data history table named A_WIPEquipmentDataHistory.

When the Lot is moved out of the current step, all WIP Data is transferred to the formal history tables – A_WIPLotDataHistory and A_WIPLotDetailsDataHistory respectively.

Details

When Working with the SPC Matrix

The SPC Matrix is evaluated during Track In if the selected equipment is configured with a default SPC Setup and the Use SPC Matrix is checked. To use the SPC Matrix within the SPC Query, you must change the query used by the SPC Setup associated with the SPC Matrix. Specifically, the WHERE clause for the JOIN of historical data must be changed to include the Matrix id.

How to Modify an SPCDataValues Query for SPC Matrix

Follow these steps to modify the SPCDataValues query:

1. Access the SPCDataValues instance of the SPC Query object.
2. Modify the WHERE clause in the second sub-query to look like the clause below by adding the highlighted line:

WHERE

WDN.WIPDataNameName LIKE ?WIPDATANAME

AND WEDH.WIPDataValue IS NOT NULL

AND WEDH.ServiceName = 'TrackOutLot'

AND WE.SPCMATRIXID = ?SPCMatrixId

AND WDN.FieldType = 'NUMBER'

AND WE.EquipmentName = ?EQUIPMENT

AND (CASE WHEN STDP.ExcludeData IS NULL THEN 0 ELSE STDP.ExcludeData END) = 0

) Query1

3. Click Add new row on the Parameters grid. A row of fields becomes enabled on the grid.
4. Add the following query parameter definition:
• Parameter Name: SPCMatrixId
• Data Type: String
• Display Text: SPCMatrixId
• Param Value: 
• Dynamic Value: StringFromObject(SPCMatrix.InstanceID)
• Is Required: True
• Use for Block Rows: False
5. Click Save. The application saves the changes and a status message appears.
