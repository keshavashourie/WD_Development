Inline SPC

Inline SPC ist ein separat lizenziertes Modul der Siemens Opcenter Execution Semiconductor-Anwendungen, das Schlüsselelemente zum Verwalten und Verbessern des Fertigungsprozesses bereitstellt. Es ermöglicht Herstellern, Probleme zu lösen, bevor sie zu einer Verringerung des Ertrags oder Durchsatzes führen. Ohne dieses Modul werden Prozessprobleme zu spät erkannt, sodass wertvolle Zeit und Ressourcen für die Behebung eines Problems benötigt werden, das hätte verhindert werden können.

Nachstehend finden Sie ein Beispiel für die Vorgänge in der Produktion bei der Messung oder Überprüfung eines Attributs, z. B. Dicke des Produkts. In der Spezifikation des Produkts kann festgelegt sein, dass die Dicke zwischen 0,95 und 1,05 Zoll liegen muss, damit das Teil in einer Unterbaugrupp verwendet werden kann. Messungen haben ergeben, dass die durchschnittliche Produktdicke von fünf aufeinanderfolgenden Losen 0,96, 0,98, 1,00, 1,02 und 1,04 beträgt. Die Anwendung ergreift jedoch keine Maßnahme, wenn die Lose einzeln betrachtet werden, da sie alle innerhalb der Produktspezifikation liegen.

Durch Anwendung von Statistical Process Control auf diese Werte ist der Trend erkennbar, wahrscheinlich nachdem die durchschnittliche Dicke des dritten Loses aufgezeichnet wurde. Die Technik kann dann benachrichtigt werden, dass die Dicke des gefertigten Produkts stetig zunimmt. An dieser Stelle muss ermittelt werden, warum die Dicke zunimmt, während die Produktion fortgesetzt wird. Das mögliche Problem kann daher gelöst werden, bevor die Anlage abgeschaltet wird, bevor Einheiten angehalten werden, bevor Material ausrangiert wird und bevor Produktionszeit verloren geht.

Mit SPC können Fertigung und Engineering SPC-Kontrollcharts konfigurieren und einbeziehen. Die Kontrollcharts können bei der Erfassung von Qualitätsdaten aktualisiert und angezeigt werden, damit der Operator sofort Feedback erhält. Die Technik kann bei der Untersuchung bestimmter Vorfälle auch historische Charts überprüfen.

Das Modul "Inline Statistical Process Control" verwendet die gemeinsame SPC-Komponente, um SPC-Charts zu analysieren und anzuzeigen. Weitere Informationen zu den Installations-, Konfigurations- und Modellierungsanforderungen von Inline SPC finden Sie im Opcenter Execution Core Inline Statistical Process Control-Referenzhandbuch.

Inline SPC-Installation

Darüber hinaus sollten Sie mit den Komponenten, Voraussetzungen und Annahmen vertraut sein, die Grundlage einer Statistical Process Control-Implementierung sind.

Gehen Sie folgendermaßen vor, um sicherzustellen, dass Inline SPC richtig installiert und konfiguriert ist:

1. Installieren Sie Inline SPC über den Installationsassistenten von Opcenter Execution Core. Weitere Informationen finden Sie in der Opcenter Execution Core-Installationsanleitung.
2. Die folgenden Skripte sind in der Installation enthalten:

SPCConfiguration.cfg für SQL

SPCConfiguration.ORA.cfg für Oracle

3. Sie müssen das entsprechende Skript ausführen, nachdem Sie die Installation abgeschlossen haben. Weitere Informationen finden Sie im Opcenter™ Execution Core Transaction Tester-Benutzerhandbuch. Es sind mehrere Beispielcharts verfügbar, die mit minimaler Konfiguration ausgeführt werden. Weitere Informationen finden Sie unter "Konfigurieren von Beispielcharts".
Hinweis: Optional können Sie Inline SPC-Testdaten über Management Studio laden. Weitere Informationen finden Sie in der Opcenter Execution Core-Anleitung zur Systemadministration.
