Definieren von SPC-Abfragen

Das SPC-Abfrageobjekt ist eine Unterklasse des Online-Abfrageobjekts. Es wird verwendet, um Abfragen zu konfigurieren, mit denen die SPC-Makrodatei Daten abruft. Das Tabellenblatt für die SPC-Objektmodellierung enthält Daten für die Konfiguration von fünf Instanzen des SPC-Abfrageobjekts.

Die Anwendung bietet zwei Arten von Abfragen:

• Standard-Abfragen werden für die Verwendung mit SPC-Einrichtungsobjekten bereitgestellt. Diese Abfragen sind anpassbar: Sie können damit die Abfrage ändern, um Daten abzurufen, die nur in Ihrer Konfiguration vorkommen. Weitere Informationen zu SPC-Einrichtungen finden Sie unter "Definieren von SPC-Einrichtungen".
• Basis-Abfragen werden für die Verwendung mit SPC-Basiseinrichtungsobjekten bereitgestellt. Diese Abfragen enthalten voll funktionsfähige Abfragen, die Sie mithilfe des SPC-Basiseinrichtungsobjekts anpassen. Weitere Informationen zu SPC-Basiseinrichtungen finden Sie unter "Definieren von SPC-Basiseinrichtungen".

Ruft die historischen Daten im Zusammenhang mit Benutzerdatensammlungen ab, die mit "Automatischer Ablauf" oder "Prüfblatt" verarbeitet wurden.

Hinweis: Diese Abfrage ist nur für die Verwendung durch SPC-Basiseinrichtungen vorgesehen.
Hinweis: Wenn Sie neue Abfragen für eine SPC-Basiseinrichtung entwickeln, muss der Abfragename das Wort Basis innerhalb des Abfragenamens enthalten.

Jede SPC-Abfrage (sofern nicht anderweitig geändert) muss drei Schlüsselfelder zurückgeben:

• DATAVALUE
• INSTANCEID
• COMMENTS

Die meisten SPC-Basiseinrichtungsabfragen enthalten die folgenden zusätzlichen Felder, um die einfache Konfiguration neuer Funktionen innerhalb des Prozesses für die Konfiguration von SPC-Basiseinrichtungen zu erlauben:

• Container
• Wafermarkierungsnummer
• TxnTimeStamp
• COMMENTABREV
• GROUPSEQ
• RN
• BYLOTID
• BYWAFERID

Weitere Informationen zur Abfrage "SPCDataValues" finden Sie unter "SPC-Abfragedetails".

Hinweis: Siemens empfiehlt Ihnen, Sicherungskopien der Abfragen zu erstellen, bevor Sie diese ändern.

Beim Definieren von neuen SPC-Abfragen

Zum Verfassen von SPC-Abfragen müssen Sie mit dem Opcenter Execution Semiconductor SPC-Objektmodell und SQL vertraut sein. Neue SPC-Abfragen definieren Sie auf der Seite "SPC-Abfrage".

SPC-Basisabfragen wurden mit zahlreichen dynamischen Parametern entwickelt, damit möglichst wenige SPC-Abfragen neu erstellt werden müssen.

Vorgehensweise zum Definieren einer SPC-Abfrage

Gehen Sie folgendermaßen vor, um eine SPC-Abfrage zu definieren:

1. Öffnen Sie die Seite "SPC-Abfrage". Die Seite "SPC-Abfrage" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen der SPC-Abfrage in das Feld SPC-Abfrage ein.
4. Geben Sie den Text der SQL-Abfrageanweisung in das Feld Abfragetext ein.
5. Führen Sie die folgenden Schritte aus, um Parameter zur Tabelle "Parameter" hinzuzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
b. Geben Sie den Namen des SPC-Abfrageparameters in das Feld Name für Benutzerabfrageparameter ein.
c. Geben Sie den Datentyp des SPC-Abfrageparameters in das Feld Datentyp ein.
d. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Testen der Abfrage

Gehen Sie folgendermaßen vor, um eine SPC-Abfragedefinition zu testen:

1. Führen Sie die Schritte in "Vorgehensweise zum Definieren einer SPC-Abfrage" aus oder

Wählen Sie eine vorhandene SPC-Abfrageinstanz aus.

2. Klicken Sie auf Abfrage speichern und testen, um die Abfrage zu speichern und zu testen. Die Anwendung öffnet das Popup "Onlineabfrage: Einrichtung: Test".
3. Geben Sie alle Parameter ein, die die Abfrage erfordert.
4. Klicken Sie auf Abfrage testen. Alle Ergebnisse, die der Abfrage und den eingegebenen Parametern entsprechen, werden in der Tabelle "Abfrageergebnisse" angezeigt.
5. Klicken Sie auf Schließen. Das Popup "Onlineabfrage: Einrichtung: Test" wird geschlossen.
