Definieren von SPC-Chartgruppen

SPC-Chartgruppen werden verwendet, um eine Sammlung von SPC-Charts und/oder SPC-Chartgruppen zu definieren, je nachdem, ob ein einzelnes Chart oder eine Chartgruppe angezeigt werden soll. Sie werden gleichzeitig verarbeitet.

Definieren von SPC-Chartgruppen

Chartgruppen können Datensammlungsdefinitionen und Benutzerdatensammlungsdefinitionen zugeordnet werden. Datensammlungsdefinitionen und Benutzerdatensammlungsdefinitionen sind normalerweise mit dem Aufgabenobjekt für eine aufgabenbasierte Datensammlung verknüpft.

Eine SPC-Chartgruppe enthält die optionale Modellierungsdefinition "SPC-Chart". SPC-Chartgruppen sind mit der Spezifikation verbunden, um festzulegen, welches Chart in der Datensammlung verwendet wird. Weitere Informationen finden Sie im Opcenter Execution Medical Device- und Diagnostics Modeling-Benutzerhandbuch oder im Opcenter Execution Core Modeling-Benutzerhandbuch. Zur Tabelle "Gruppen" können nur Gruppen hinzugefügt werden, die vorher definiert wurden.

Über die Schaltfläche "Aufgelöste Einträge" können Sie alle Charts und Chartgruppen anzeigen, die derzeit zur SPC-Chartgruppe gehören.

Wichtig: Die Konfiguration einer SPC-Chartgruppe mit einem verknüpften SPC-Chart sollte nur mit einer Benutzerdatensammlungsdefinition verknüpft sein, die so konfiguriert ist, dass sie in einem automatischen Ablauf in Opcenter Execution Semiconductor ausgeführt wird. Es werden noch nicht alle Funktionen (OCAPS) des SPC-Chart vollständig unterstützt. Es wird empfohlen, dass der Nutzerdatensammlungsdefinition eine Semiconductor-SPC-Einrichtung oder eine SPC-Basiseinrichtung zugewiesen wird. Alternativ sollten alle kritischen Parameter, die eine SPC-Analyse erfordern, über Umlaufbestandsdaten erfasst werden.

Vorgehensweise zum Definieren einer neuen SPC-Chartgruppe

Gehen Sie folgendermaßen vor, um eine neue SPC-Chartgruppe zu definieren:

1. Melden Sie sich bei Opcenter Execution Semiconductor an.
2. Wählen Sie Modellierung im Menü Modellierung aus. Die Seite "Modellierung" wird angezeigt.
3. Klicken Sie auf SPC-Chartgruppe. Die Seite "SPC-Chartgruppe" wird innerhalb der Seite "Modellierung" angezeigt.
4. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
5. Geben Sie einen Namen für die neue SPC-Chartgruppe ein.
6. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Hinzufügen von SPC-Charts oder SPC-Chartgruppen

1. Führen Sie die Schritte unter "Vorgehensweise zum Definieren einer neuen SPC-Chartgruppe" aus.
2. Klicken Sie in der Tabelle "Einträge" auf Neue Zeile hinzufügen, um ein SPC-Chart hinzuzufügen. Ein Eingabefeld wird angezeigt.
Oder
Klicken Sie in der Tabelle "Gruppen" auf Neue Zeile hinzufügen, um eine SPC-Chartgruppe hinzuzufügen. Ein Eingabefeld wird angezeigt.
3. Wählen Sie das gewünschte SPC-Chart oder die gewünschte SPC-Chartgruppe aus.
4. Wiederholen Sie die Schritte 2 bis 3, um weitere Charts oder Chartgruppen hinzuzufügen.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
