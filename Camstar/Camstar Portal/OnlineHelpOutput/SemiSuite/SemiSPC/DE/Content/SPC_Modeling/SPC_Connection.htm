Definieren von SPC-Verbindungen

Das SPC-Verbindungsobjekt wird verwendet, um eine ODBC-Datenbankverbindung herzustellen. "SPC-Verbindung" ist ein erforderlicher Schritt für Inline SPC.

Für Inline ist es erforderlich, eine ODBC-Datenbankverbindung mit 64 Bit zu erstellen, um Chart-Plot-Daten abzurufen. Verwenden Sie den entsprechenden Datenbanktreiber. Die Anwendung hat ein Standardmodellierungsobjekt "SPC-Verbindung" für Inline SPC erstellt, das bereits ausgefüllte Kriterien für Inline SPC enthält. Sie müssen die verbleibenden erforderlichen Verbindungsfelder ausfüllen, um dieses Objekt zu verwenden.

Hinweis: Sie müssen die Verbindungswerte kennen, um dieses Objekt zu konfigurieren.

Mit SPC bereitgestellte SPC-Verbindung

Das Tabellenblatt für die SPC-Objektmodellierung enthält Daten für die Konfiguration einer Standardinstanz des SPC-Verbindungsobjekts. Wenn Sie eine Instanz anzeigen möchten, die mit dem Tabellenblatt erstellt wurde, oder eine neue Instanz erstellen möchten, verwenden Sie die Seite "SPC-Verbindung".

Vorgehensweise zum Definieren einer SPC-Verbindung

Gehen Sie folgendermaßen vor, um eine SPC-Verbindung zu definieren:

1. Öffnen Sie die Seite "SPC-Verbindung". Die Seite "SPC-Verbindung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Für Inline SPC können Sie die vordefinierte Verbindung mit vorausgefüllten Kriterien verwenden, indem Sie Inline SPC in den Suchinstanzen auswählen. Die Anwendung füllt die Seite mit vorausgefüllten Werten aus.
4. Um eine benutzerdefinierte Verbindung für Legacy zu erstellen, geben Sie einen Namen in das Feld SPC-Verbindung ein.
5. Geben Sie die Informationen zum ODBC-Connection String in die folgenden Felder ein:
• Datenquellenname
• Benutzername
• Password
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
