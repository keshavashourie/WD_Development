Definieren von SPC-Ausschlussgründen

Mithilfe von SPC-Ausschlussgründen werden SPC-Transaktionsdatenpunkte markiert, die von der SPC-Berechnung ausgeschlossen werden sollen.

Mit SPC bereitgestellte SPC-Ausschlussgründe

Das Tabellenblatt für die SPC-Objektmodellierung enthält Daten für die Konfiguration von drei Ausschlussgründen:

• Engineering
• Produktion (Production)
• Kunde

Vorgehensweise zum Definieren eines SPC-Ausschlussgrunds

Gehen Sie folgendermaßen vor, um einen SPC-Ausschlussgrund zu definieren:

1. Öffnen Sie die Seite "SPC-Ausschlussgrund". Die Seite "SPC-Ausschlussgrund" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen in das Feld SPC-Ausschlussgrund ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
