Erforderliche Modellierungsobjekte für Inline SPC

Die nachstehend aufgeführten Modellierungsobjekte sind die erforderlichen Modellierungsobjekte, um die Definition von Inline SPC-Charts und die Aufzeichnung von Benutzeranmerkungen und -verletzungen zu unterstützen:

• Definieren von SPC-Verbindungen
• Definieren von SPC-Charttypen
• Anzeigen einer SPC-Verletzung
• Definieren von SPC-Regeln
• Definieren von SPC-Abfragen
• Definieren von SPC-Charts
• Definieren von SPC-Chartgruppen
Hinweis: Die SPC-Verletzung wird während der Installation geladen und kann nicht bearbeitet werden. Verwenden Sie die Seite "SPC-Verletzung", um die Parameter für jede Verletzung anzuzeigen.
