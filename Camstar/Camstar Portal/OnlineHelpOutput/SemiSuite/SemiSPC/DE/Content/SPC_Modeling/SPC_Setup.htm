Definieren von SPC-Einrichtungen

Eine vollständig konfigurierte SPC-Einrichtung stellt alle erforderlichen Informationen bereit, um die Komponenten von Inline SPC für die SPC-Verarbeitung aufzurufen. Dieses Objekt enthält Felder für die Chartanzeige und Fehlerverarbeitung.

Mit der SPC-Einrichtung können Sie Standardparameterwerte für die Chart ändern, für deren Anforderung sie konfiguriert ist. Diese geänderten Werte werden für die Chart verwendet, wenn sie von dieser Einrichtung angefordert wird.

Mit SPC bereitgestellte SPC-Einrichtungen

Das Tabellenblatt für die SPC-Objektmodellierung enthält Daten für die Konfiguration mehrerer SPC-Einrichtungsobjektinstanzen. Jede SPC-Einrichtung arbeitet folgendermaßen mit einer vordefinierten, aber anpassbaren SPC-Abfrage:

• ADHOCWIPDATA – SPC-Beispieleinrichtung aus einer X-Bar-Basischart (GXChart) und einer Range-Chart (GRChart) auf Grundlage der SPC-Abfrage "SPCAdhocWIPData".
• ADHOCWIPDATAINLINE – SPC-Beispieleinrichtung aus einer X-Leiste-Basischart und einer Range-Chart auf Grundlage der SPC-Abfrage "SPCAdhocWIPData".
• CHANGECOUNT – SPC-Beispieleinrichtung aus einer X-Bar-Basischart (GXChart) und einer Range-Chart (GRChart) auf Grundlage der SPC-Abfrage "SPChangeCount".
• CHANGECOUNTLINE – SPC-Beispieleinrichtung aus einer X-Leiste-Basischart und einer Range-Chart auf Grundlage der SPC-Abfrage "SPChangeCount".
• DATAVALUES – SPC-Beispieleinrichtung aus einer X-Bar-Basischart (GXChart) und einer Range-Chart (GRChart) auf Grundlage der SPC-Abfrage "SPCDataValues".
• DATAVALUESINLINE – SPC-Beispieleinrichtung aus einer X-Leiste-Basischart und einer Range-Chart auf Grundlage der SPC-Abfrage "SPCDataValues".
• REJECTS – SPC-Beispieleinrichtung aus einer X-Bar-Basischart (GXChart) und einer Range-Chart (GRChart) auf Grundlage der SPC-Abfrage "SPCRejects".
• REJECTSINLINE – SPC-Beispieleinrichtung aus einer X-Leiste-Basischart und einer Range-Chart auf Grundlage der SPC-Abfrage "SPCRejects".
• USERDATACOLLECTION – SPC-Beispieleinrichtung aus einer X-Bar-Basischart (GXChart) und einer Range-Chart (GRChart) auf Grundlage der SPC-Abfrage "SPCUserDataCollecction".
• USERDATACOLLECTIONINLINE – SPC-Beispieleinrichtung aus einer X-Leiste-Basischart und einer Range-Chart auf Grundlage der SPC-Abfrage "SPCUserDataCollection".

Zuweisen einer SPC-Einrichtung

Damit eine SPC-Einrichtung ausgeführt werden kann, muss sie einem Fertigungsobjekt zugewiesen werden. Bei Verwendung des Objekts in einer Fertigungstransaktion wird die zugewiesene SPC-Einrichtung ausgelöst.

Eine SPC-Einrichtung kann den folgenden Objekten zugewiesen werden:

• SPC-Matrix – Verwendet konfigurierte Kriterien, um die SPC-Einrichtung mit der höchsten Übereinstimmung (geeignetste) im Kontext einer gegebenen Fertigungstransaktion zu bestimmen.
• Ausrüstung – Die SPC-Einrichtung wird ausgelöst, wenn die in einer Fertigungstransaktion verwendete Ausrüstung mit einer SPC-Einrichtung oder SPC-Matrix konfiguriert wurde.
• Umlaufbestandsdateneinrichtung – Die SPC-Einrichtung wird ausgelöst, wenn die Daten in das Feld "Umlaufbestandsdateneinrichtung" eingegeben werden.
• Datensammlungsdefinition – Die SPC-Einrichtung wird ausgelöst, wenn die Daten in eine Datensammlungsdefinition eingegeben werden, die Teil einer Jobfortschrittstransaktion ist.

Beim Verwenden der Titeltabelle "SPC-Einrichtung"

Die Titeltabelle im Popup "SPC-Einrichtung" wird verwendet, um den dynamischen Wert im SPC-Chart-Titel zu konfigurieren. Diese Abbildung enthält ein Beispiel mit mehreren Zeilen für jede Titelzeile.

Die Anwendung erzeugt während der Verarbeitung die folgenden drei Zeichenketten:

1. Chart: X-Leiste
2. Maschine: MNT001
3. Messung: Stärke

Das Endergebnis ist der folgende Befehl: Titel="Chart: X-Leiste" "Maschine: MNT001" "Messung: Stärke".

Hinweis: Die Anwendung ignoriert alle Titelwerte in der Tabelle "Chartparameter", wenn die Tabelle "Titel" verwendet wird.

Vorgehensweise zum Definieren einer SPC-Einrichtung für Inline

Gehen Sie folgendermaßen vor, um eine SPC-Einrichtung (Inline) zu definieren:

1. Öffnen Sie die Seite "SPC-Einrichtung". Die Seite "SPC-Einrichtung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen der SPC-Einrichtung ein.
4. Aktivieren Sie das Kontrollkästchen Inline SPC.
5. Geben Sie die Charthöhe ein. (Empfohlen wird ein Wert von 450.)
6. Geben Sie die Chartbreite ein. (Empfohlen wird ein Wert von 900.)
7. Klicken Sie in der Tabelle "Details" auf Neue Zeile hinzufügen. Die Anwendung zeigt das Popup "Hinzufügen" an.
8. Führen Sie mithilfe des Popups "Hinzufügen" die folgenden Schritte aus:
a. Geben Sie einen Elementnamen ein, um die Chart zu identifizieren.
b. Wählen Sie den SPC-Charttyp (Inline) aus. Die Anwendung füllt die Tabelle für Parameter des Inline-Chart mit Parametern und Standardwerten, die für das Chart konfiguriert wurden.
c. Verwenden der Tabelle "Inline-Chartparameter":
• Um einen Parameterwert zu ändern, klicken Sie auf Parameterwert. (Wenn das Feld leer ist, klicken Sie auf den leeren Bereich.) Das Feld wird aktiviert. Wert eingeben.
• Um das Überschreiben eines Parameterwerts zu erlauben, wenn eine SPC-Matrix angewendet wird, aktivieren Sie das Kontrollkästchen Matrixüberschreibung erlauben.
• Um einen Parameter hinzuzufügen, der für die Chart verfügbar ist, geben Sie den genauen Namen des Parameters in Parametername und Werte in die Felder Parameterwert und Matrixüberschreibung erlauben ein, die Ihren geschäftlichen Anforderungen entsprechen.
d. Klicken Sie abschließend auf OK. Das Dialogfeld wird geschlossen.
9. Geben Sie den Namen der SPC-Abfrage in die Tabelle "Abfragen" ein.
10. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
11. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

So konvertieren Sie die SPC-Einrichtung von Legacy in Inline

1. Öffnen Sie die Seite SPC-Einrichtung im Menü Modellierung. Die Seite "SPC-Einrichtung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Wählen Sie eine vorhandene Legacy SPC-Einrichtung aus, die konvertiert werden soll.
3. Aktivieren Sie das Kontrollkästchen Inline SPC.
4. Um das Detail des vorhandenen Elements in der Tabelle "Details" zu ändern, wählen Sie die Zeile "Elementname" aus und klicken Sie auf die Schaltfläche "Bearbeiten":
a. Wählen Sie den SPC-Charttyp (Inline) aus. Die Anwendung füllt die Tabelle für Parameter des Inline-Chart mit Parametern und Standardwerten, die für das Chart konfiguriert wurden.
b. Verwenden der Tabelle "Inline-Chartparameter":
• Um einen Parameterwert zu ändern, klicken Sie auf Parameterwert. (Wenn das Feld leer ist, klicken Sie auf den leeren Bereich.) Das Feld wird aktiviert. Wert eingeben.
• Um das Überschreiben eines Parameterwerts zu erlauben, wenn eine SPC-Matrix angewendet wird, aktivieren Sie das Kontrollkästchen Matrixüberschreibung erlauben.
• Um einen Parameter hinzuzufügen, der für die Chart verfügbar ist, geben Sie den genauen Namen des Parameters in Parametername und Werte in die Felder Parameterwert und Matrixüberschreibung erlauben ein, die Ihren geschäftlichen Anforderungen entsprechen.
c. Der Konvertierungsprozess aktiviert fünf (5) optionale Felder: "Ist Y-Variable", "X-Achsen-Trendwert", "ANNVAR Primärer Wert", "ANNVAR Sekundärer Wert" und "ANNVAR Tertiärer Wert". Sie können die optionalen Informationen entsprechend Ihrer Geschäftsanforderung eingeben.
d. Klicken Sie abschließend auf OK. Das Dialogfeld wird geschlossen.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Zuweisen einer SPC-Einrichtung

Gehen Sie folgendermaßen vor, um eine SPC-Einrichtung zuzuweisen:

1. Öffnen Sie die Modellierungsseite für die Objektinstanz, der Sie die SPC-Einrichtung zuweisen möchten.
2. Geben Sie den Namen der SPC-Einrichtung in das Feld SPC-Einrichtung ein.
3. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
