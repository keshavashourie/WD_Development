Definieren von SPC-Basiseinrichtungen

Mit der SPC-Basiseinrichtung können Sie Inline SPC für die SPC-Verarbeitung aufrufen. Die SPC-Basiseinrichtung unterscheidet sich von der SPC-Einrichtung darin, dass die SPC-Basiseinrichtung die Erfordernis minimiert, benutzerdefinierte SPC-Abfragen zu schreiben. Stattdessen verwendet sie vordefinierte SPC-Basisabfragen, die über die Seite "SPC-Basiseinrichtung" angepasst werden.

Die Seite "SPC-Basiseinrichtung" enthält Felder für die Chartanzeige und Fehlerverarbeitung und kann verwendet werden, um Standardparameterwerte für die Chart zu ändern, für deren Anforderung sie konfiguriert ist. Diese geänderten Werte werden für die Chart verwendet, wenn sie von der Transaktion angefordert wird, die die SPC-Analyse auslöst.

Zuweisen einer SPC-Basiseinrichtung

Damit eine SPC-Basiseinrichtung ausgeführt werden kann, muss sie einem Fertigungsobjekt zugewiesen werden. Die Verwendung des Objekts während einer Fertigungstransaktion bewirkt das Auslösen der zugewiesenen SPC-Basiseinrichtung.

Eine SPC-Basiseinrichtung kann den folgenden Objekten zugewiesen werden:

• SPC-Matrix – Verwendet konfigurierte Kriterien, um die SPC-Basiseinrichtung mit der höchsten Übereinstimmung (geeignetste) im Kontext einer gegebenen Fertigungstransaktion zu bestimmen. Die SPC-Matrix wird erst beim Ausbringen initiiert und hat keine Auswirkungen auf die SPC-Analyse, die auf andere Weise ausgelöst wird.
• Ausrüstung – Die SPC-Basiseinrichtung wird ausgelöst, wenn die Ausrüstung in einer Fertigungstransaktion mit einer SPC-Basiseinrichtung oder SPC-Matrix konfiguriert wurde.
• Umlaufbestandsdateneinrichtung – Die SPC-Basiseinrichtung wird ausgelöst, wenn die Daten in das Feld "Umlaufbestandsdateneinrichtung" eingegeben werden.
• Datensammlungsdefinition – Die SPC-Basiseinrichtung wird ausgelöst, wenn die Daten in eine Datensammlungsdefinition eingegeben werden, die Teil einer Jobfortschrittstransaktion ist.
Beim Verwenden der Tabelle "Titel" in "SPC-Basiseinrichtung"

Die Tabelle "Titel" im Popup "SPC-Basiseinrichtung" wird verwendet, um den dynamischen Wert im SPC-Charttitel zu konfigurieren. Diese Abbildung enthält ein Beispiel mit mehreren Zeilen für jede Titelzeile.

Die Anwendung erzeugt während der Verarbeitung die folgenden drei Zeichenketten:

1. Chart: X-Leiste
2. Maschine: MNT001
3. Messung: Stärke

Das Endergebnis ist der folgende Befehl: Titel="Chart: X-Leiste" "Maschine: MNT001" "Messung: Stärke".

Hinweis: Die Anwendung ignoriert alle Titelwerte in der Tabelle "Chartparameter", wenn die Tabelle "Titel" verwendet wird.

Fehleraktion

An einem Los auszuführende Fehleraktion, wenn ein Fehler in der SPC-Chart erkannt wurde. Dieses Feld wird übersprungen, wenn während der SPC-Ausführung kein Los erkannt wird. Zu den Fehleraktionen gehören:

• HOLD – Das Los wird angehalten, wenn Fehler erkannt werden. Die Anwendung verarbeitet keine Transaktionen für das Los. Sie müssen einen Wert für das Feld "Fehler: Anhaltegrund" angeben, wenn Sie HOLD auswählen.
• HOLDALL – Das Los und alle anderen Lose im zugehörigen Zeitplan werden angehalten, wenn Fehler erkannt werden. Die Anwendung verarbeitet keine Transaktionen für keine Lose.
• FUTUREHOLD – Das Los wird in einem späteren Schritt angehalten. Die Anwendung setzt die Verarbeitung von Transaktionen fort, bis das Los den späteren Schritt erreicht. Sie müssen einen Wert für das Feld "Einrichtung für zukünftiges Anhalten bei Fehlern" angeben, wenn Sie FUTUREHOLD auswählen.
• WAIVE – Das Los wird nicht angehalten, selbst wenn Fehler erkannt werden. Die Anwendung setzt die Verarbeitung von Transaktionen für das Los fort.

SPC-Regel: Methode für Datenpunktanalyse

Gibt an, welche Datenpunkte das SPC-Makro analysiert, um zu bestimmen, ob das SPC-Ergebnis mit PASS oder FAIL aufgezeichnet wird. Folgende Optionen sind möglich:

• DEFAULT – Das Makro weist ein SPC-Ergebnis des Typs FAIL zu, wenn es SPC-Regelverletzungen auf der Basis der ausgewählten SPC-Regel gibt.
• LAST DATA POINT – Das Makro weist ein SPC-Ergebnis des Typs FAIL zu, wenn nur der letzte Datenpunkt als SPC-Regelverletzung auf der Basis der ausgewählten SPC-Regel identifiziert wird. Alle SPC-Regelverletzungen vor dem letzten Punkt werden ignoriert.
• LAST GROUP – Ist momentan nur für die I-Chart (GICHART) im Makro konfiguriert. Informationen zum Erweitern dieser Funktion auf andere Charts finden Sie unter "Prepare the Chart Parameters". Das Makro weist ein SPC-Ergebnis des Typs FAIL zu, wenn bei einem Datenpunkt innerhalb der letzten Gruppensequenz (wie in GROUP SEQUENCE in der SPC-Abfrage definiert) eine SPC-Regelverletzung festgestellt wird.

Hinweis: Die Hintergrundfarbe der SPC-Chart während des Chartanzeige-Prozesses basiert auf dem Chartparameter ALARM_COLOR. Wenn die konfigurierte SPC-Regel einen Fehler feststellt, ändert sich die Hintergrundfarbe entsprechend der Konfiguration. Dies stimmt unter Umständen nicht mit der ausgewählten Datenpunktanalyse der SPC-Regel überein. Die Standardfunktion ALARM_COLOR basiert auf der Auswertung eines beliebigen fehlerhaften Datenpunkts. Bei Erweiterung des ALARM_COLOR-Werts auf RED 1 wertet der Hintergrund nur den letzten Datenpunkt aus.

Plotmethode für Untergruppe

Legt fest, wie die Anwendung Daten bei Verwendung des Parameters SUBGROUPSIZE plottet. Mögliche Optionen sind:

• BY LOT – Die Anwendung ordnet die Daten in der Reihenfolge ihrer Ausführung, wobei alle Daten nach Los gruppiert werden. Wenn diese Option ausgewählt ist, ignoriert die Anwendung den SubGroupSize-Parameterwert.
• BY WAFER – Die Anwendung ordnet die Daten in der Reihenfolge der Ausführung, wobei alle Daten nach Los und Wafer-ID gruppiert werden. Wenn diese Option ausgewählt ist, ignoriert die Anwendung den SubGroupSize-Parameterwert.
• Kein Wert – Die Anwendung verwendet den SubGroupSize-Parameterwert und gruppiert Daten mithilfe der Statit-Methode DEFAULT.

Hinweis: Die Optionen BY LOT und BY WAFER erlauben Ihnen, die Datensammlung zu konfigurieren. Dies erfordert u. U., dass die SUBGROUPSIZE dynamisch ist.

Vorgehensweise zum Definieren einer SPC-Basiseinrichtung für Inline

Gehen Sie folgendermaßen vor, um eine SPC-Basiseinrichtung zu definieren:

1. Öffnen Sie die Seite "SPC-Basiseinrichtung". Die Seite "SPC-Basiseinrichtung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Aktivieren Sie das Kontrollkästchen Inline SPC.
4. Geben Sie Werte für die folgenden Elemente ein:

SPC-Basiseinrichtung

Charthöhe

Chartbreite

SPC-Basisabfrage

Größenlimit für Ergebnismenge

5. Klicken Sie in der Tabelle "Details" auf Neue Zeile hinzufügen. Die Anwendung zeigt das Popup "Hinzufügen" an.
6. Führen Sie die folgenden Schritte für jedes SPC-Element aus:
a. Geben Sie die erforderlichen Werte für die folgenden Elemente ein:

Elementname

SPC-Charttyp (Inline)

Datenwerte

b. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
c. Klicken Sie auf OK. Die Anwendung schließt das Popup.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
