Definieren von SPC-Charttypen

Die SPC-Charttyp-Objekte ermöglichen für Inline das Modellieren unterstützter Charttypen mit Parametern, die zum Erstellen eines Charts in Inline SPC verfügbar sind. Das SPC-Charttypmodellierungsobjekt dient als Vorlage für die Konfiguration von Chartbefehlen. Für jedes Chart, das Sie in Opcenter Execution Semiconductor aufrufen möchten, muss eine Instanz des Modellierungsobjekts "SPC-Charttyp" vorhanden sein.

Mit SPC bereitgestellter SPC-Charttyp

Das Tabellenblatt für die SPC-Objektmodellierung enthält Daten für die Konfiguration von Instanzen des Objekts "SPC-Charttyp". Weitere Informationen finden Sie unter "Anhang F: Inline SPC-Chartbeschreibungen" für Inline SPC.

Beim Verwenden der Seite "SPC-Charttyp"

Die folgenden Regeln gelten, wenn Sie den SPC-Charttyp definieren:

• Verwenden Sie diese Seite, um Instanzen des im Tabellenblatt für die SPC-Objektmodellierung konfigurierten SPC-Charttypobjekts anzuzeigen.
• Der automatisierte Tabellenblattprozess wird zwar empfohlen, Sie können aber auch diese Seite verwenden, um neue Instanzen manuell zu erstellen oder um vorhandene Instanzen des SPC-Charttypobjekts manuell zu aktualisieren.
• Verwenden Sie diese Seite nicht zum Ändern der Standardparameterwerte für bestimmte Verwendungsfälle. Verwenden Sie stattdessen die Seite "SPC-Einrichtung". Beachten Sie außerdem, dass die SPC-Einrichtungswerte beim Ausführen des Chartbefehls Standardwerte überschreiben.

Vorgehensweise zum Definieren eines SPC-Charttyps

Gehen Sie folgendermaßen vor, um einen SPC-Charttyp zu definieren:

1. Öffnen Sie die Seite SPC-Charttyp. Die Seite "SPC-Diagrammtyp" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen des SPC-Charttyps ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.Weitere Informationen zu Parametern finden Sie unter "Chartparameter-Beschreibungen".
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
