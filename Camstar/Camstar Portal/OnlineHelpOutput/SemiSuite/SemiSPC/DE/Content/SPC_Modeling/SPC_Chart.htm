Definieren von SPC-Charts

SPC-Charts enthalten die erforderlichen Informationen, um ein einzelnes SPC-Chart anzuzeigen. SPC-Charts beschreiben:

• Charttyp
• OCAPs
• Dargestellte Variable

Siemens bietet vier Standard-SPC-Charts an, die Sie verwenden können:

• Moving Range
• Range Chart
• Trial I-Chart
• X Chart
• Moving Range Inline
• Range Chart Inline
• Trial I-Chart Inline
• X Chart Inline
Wichtig: Die Konfiguration einer SPC-Chartgruppe mit einem verknüpften SPC-Chart sollte nur mit einer Benutzerdatensammlungsdefinition verknüpft sein, die so konfiguriert ist, dass sie in einem automatischen Ablauf in Opcenter Execution Semiconductor ausgeführt wird. Es werden noch nicht alle Funktionen (OCAPS) des SPC-Chart vollständig unterstützt. Es wird empfohlen, dass der Nutzerdatensammlungsdefinition eine Semiconductor-SPC-Einrichtung oder eine SPC-Basiseinrichtung zugewiesen wird. Alternativ sollten alle kritischen Parameter, die eine SPC-Analyse erfordern, über Umlaufbestandsdaten erfasst werden.
Beim Definieren von SPC-Charts

Für Inline SPC müssen Sie Inline SPC auf Ihrem Server installieren und konfigurieren, damit Sie diese Seite verwenden können. Andernfalls können Sie nicht alle erforderlichen Felder ausfüllen oder die Seite speichern. Verwenden Sie den Abschnitt "Außer-Kontrolle-Aktionen" des SPC-Charts, um die bei einer Regelverletzung ausgelösten Aktionen festzulegen. SPC-Chart ist eine optionale Definition im Modellierungsobjekt "SPC-Chartgruppe". Ein SPC-Chart enthält die folgenden optionalen Modellierungsdefinitionen: "Dokument", "E-Mail-Nachricht", "Anhaltegrund" sowie Ursachenstatuscodes. Darüber hinaus werden Datensammlungsdefinitionen und Benutzerdatensammlungsdefinitionen im Abschnitt "Parameter" verwendet.

Das Kontrollkästchen "Anmerkung erforderlich" schreibt vor, dass Anmerkungen eingegeben werden müssen, wenn bei der Chartgenerierung Verletzungen auftreten. Das Popup "SPC-Charts" wird angezeigt, wenn das Kontrollkästchen "OCAPs für Außer-Kontrolle-Charts versuchen" beim Generieren eines Charts aktiviert ist und der letzte Datenpunkt eine Verletzung verursacht, und kann erst geschlossen werden, nachdem der letzte Datenpunkt mit einer Anmerkung versehen wurde. Das Popup für SPC-Anmerkungen wird angezeigt, wenn nur der letzte Datenpunkt im Chart eine Verletzung verursacht. Wenn Sie versuchen, das Popup "SPC-Charts" zu schließen, wird eine Warnmeldung mit dem Hinweis, dass eine Anmerkung erforderlich ist, und einem Verweis auf die Charts angezeigt, für die Anmerkungen erforderlich sind. Weitere Informationen finden Sie unter "Anzeigen und Eingeben von Anmerkungen" im Opcenter™ Execution Core Statistical Process Control-Referenzhandbuch.

Verwenden dynamischer Parameter für Inline SPC

Fortgeschrittene Inline SPC-Benutzer können Chartparameter so konfigurieren, dass dynamische Bezeichnungen verwendet werden, die aus den Feldausdrücken oder Abfragen stammen. Aktivieren Sie im Abschnitt "Parameter" das Kontrollkästchen "Ist dynamisch" für einen Parameter und geben Sie den Namen der Metadatentabelle sowie das Feld oder den Abfragenamen und die Spalte ein, um den Wert für einen Parameter anzuzeigen. Der chartTitle-Parameter kann z. B. bearbeitet werden, um den Produktnamen aus der Containertabelle anzuzeigen. Für diese Verwendung der dynamischen Parameterfunktionalität müssen Sie mit dem Objektmodell und der Geschäftslogik vertraut sein. Siemens empfiehlt, dass diese Funktionalität mit der Inline SPC-Funktionalität "Datensammlung" verwendet wird.

Sie können Abfragen auch zum Festlegen der dynamischen Parameterwerte verwenden. Die verwendete Abfrage kann keine Eingabeparameter haben und darf nur Text enthalten. Für den dynamischen Parameter wird nur die erste Zeile der zurückgegebenen Daten angewendet. Es können Nutzerabfragen und SPC-Abfragen verwendet werden. Verwenden Sie das folgende Format für das Parameterfeld "Parameterwert": QueryName.ColumnName.

Vorgehensweise zum Definieren von SPC-Charts für Inline

Gehen Sie folgendermaßen vor, um Inline SPC-Charts zu definieren:

1. Opcenter Execution Semiconductor.
2. Wählen Sie Modellierung im Menü Modellierung aus. Die Seite "Modellierung" wird angezeigt.
3. Klicken Sie auf SPC-Chart. Die Seite "SPC-Chart" wird innerhalb der Seite "Modellierung" angezeigt.
4. Um ein neues Objekt zu erstellen, klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt. Sie können auch das standardmäßige vordefinierte Inline SPC-Chart aus den Instanzen der Suche verwenden.
5. Geben Sie den SPC-Chartnamen ein.
6. Geben Sie den Charttyp ein.
7. Geben Sie die Auszuwertende Variable ein.
8. Aktivieren Sie das Kontrollkästchen Inline SPC, um ein Inline SPC-Chart zu definieren.
9. Füllen Sie die erforderlichen Felder aus: SPC-Abfrage, SPC-Verbindung und Anzeigeoptionen für SPC-Chart.
10. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
11. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Konvertieren eines vorhandenes Legacy-Makros in ein Inline SPC-Abfrageobjekt

Gehen Sie folgendermaßen vor, um ein Legacy-Makro in ein Inline SPC-Abfrageobjekt zu konvertieren:

1. Opcenter Execution Semiconductor.
2. Wählen Sie Modellierung im Menü Modellierung aus. Die Seite "Modellierung" wird angezeigt.
3. Klicken Sie auf SPC-Chart. Die Seite "SPC-Chart" wird innerhalb der Seite "Modellierung" angezeigt.
4. Wählen Sie ein vorhandenes Legacy-Chart aus.
5. Aktivieren Sie das Kontrollkästchen Inline SPC. Eine Warnmeldung wird angezeigt, die die Makrokonvertierung bestätigt.
6. Klicken Sie auf Ja. Das Popup "Konvertierung von SPC-Makro" wird angezeigt. Die Popup-Felder werden automatisch mit Informationen aus der ausgewählten Legacy-Abfrage gefüllt.
7. Geben Sie den neuen Namen für die SPC-Abfrage ein.
8. Bearbeiten Sie die Abfrageinformationen entsprechend Ihren Geschäftsanforderungen. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
9. Klicken Sie auf Einreichen. Die Anwendung speichert das SPC-Abfrageobjekt und zeigt eine Erfolgsmeldung an. Sie können die gespeicherte Abfrage auf der Seite "SPC-Abfrage" überprüfen.
Hinweis: Eine Warnmeldung wird angezeigt, wenn das ausgewählte Legacy-Makro mehr als eine Abfrage und/oder unvollständige Parameter enthält. Sie müssen die Abfrageinformationen manuell bearbeiten, bevor Sie sie mit Inline SPC verwenden. Sie können das konvertierte Makro und die konvertierten Parameter im Popup "Konvertierung von SPC-Makro" bearbeiten und auf Abschicken klicken und oder auf Abschicken klicken und das konvertierte Makro und die konvertierten Parameter auf der Seite "SPC-Abfrage" bearbeiten.
