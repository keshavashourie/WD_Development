Definieren von SPC-Tabellen für benutzerdefiniertes Filtern

SPC-Tabellen für benutzerdefiniertes Filtern definieren Aliasnamen für Tabellennamen in SPC-Abfragen. Da benutzerdefinierte SPC-Filter nur die SPC-Basiseinrichtungen betreffen, die mit der SPC-Matrix konfiguriert wurden, verwendet die Anwendung SPC-Tabellen für benutzerdefiniertes Filtern nur für die SPC-Analyse beim Ausbringen.

Hinweis: Sie müssen alle neuen benutzerdefinierten SPC-Filter zur entsprechenden SPC-Abfrage hinzufügen. Tabellen für benutzerdefiniertes Filtern werden in SPC-Basisabfragen integriert.

Felddefinitionen der Seite "SPC-Tabelle für benutzerdefiniertes Filtern"

Diese Tabelle definiert die Felder auf der Seite "SPC-Tabelle für benutzerdefiniertes Filtern".

Vorgehensweise zum Definieren einer SPC-Tabelle für benutzerdefiniertes Filtern

Gehen Sie folgendermaßen vor, um eine SPC-Tabelle für benutzerdefiniertes Filtern zu definieren:

1. Öffnen Sie die Seite "SPC-Tabelle für benutzerdefiniertes Filtern". Die Seite "SPC-Tabelle für benutzerdefiniertes Filtern" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen der SPC-Tabelle für benutzerdefiniertes Filtern ein.
4. Geben Sie einen Alias für die Tabelle in das Feld Alias ein.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
