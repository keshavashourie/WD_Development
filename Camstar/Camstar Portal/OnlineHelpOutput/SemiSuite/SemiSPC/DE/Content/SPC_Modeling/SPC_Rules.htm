Definieren von SPC-Regeln

Beim Definieren von SPC-Regeln für Inline

Das Modellierungsobjekt "SPC-Regeln" enthält Informationen, die bestimmen, wann Chartdaten akzeptabel sind bzw. wann sie Qualitätsstandards verletzen. SPC-Regeln können in den Details der SPC-Einrichtung und der SPC-Basiseinrichtung ausgewählt werden. Sie können eine der bereits geladenen SPC-Regeln kopieren, die als Ausgangsbasis für die Erstellung von Expertenregeln verwendet werden soll. Sie können dann Verletzungsparameter zur kopierten Regel hinzufügen und bearbeiten. Sie können auch eine neue SPC-Expertenregel erstellen.

Weitere Informationen zu den für Inline SPC verwendeten Charts und Regeln für die gemeinsame Komponente finden Sie im Abschnitt Industrieregeln der "SPC/IGC Common Component End User Documentation".

Hinweis: Die bereits geladenen SPC-Regeln sind gesperrt und können nicht bearbeitet werden. Sie können Verletzungsparameter nur für kopierte Regeln ändern.
Hinweis: Warngrenzen werden nur bei Verwendung des Auswertungstyps "DGQ_WL" berechnet und verwendet. Andere Auswertungstypen unterstützen keine Warngrenzen.

Definieren von neuen Regeln

Im Normalfall reichen die mit SPC zur Verfügung gestellten Regeln aus, um die Anforderungen zu erfüllen. Sie müssen eine entsprechende Instanz des SPC-Regelobjekts mithilfe der Seite "SPC-Regeln" definieren.

Vorgehensweise zum Definieren neuer SPC-Regeln für Inline

1. Öffnen Sie die Seite SPC-Regeln. Die Seite "SPC-Regeln" wird innerhalb der Seite "Modellierung" angezeigt.
2. Wählen Sie das bereits geladene SPC-Regelobjekt aus, das Ihre Anforderungen am ehesten erfüllt. Die SPC-Regelinstanz wird angezeigt.
3. Klicken Sie auf Kopieren. Das Popup "Kopieren" wird angezeigt.
4. Geben Sie einen Namen für die Expertenregel in das Feld Zielinstanzname ein.
5. Klicken Sie auf Kopieren oder drücken Sie Eingabe auf der Tastatur. Eine Erfolgsmeldung wird angezeigt.
6. Überprüfen Sie die Verletzungen in der kopierten Regel.
Hinweis: Hinweis: SPC-Verletzungen sind vordefiniert. Sie können die Werte der Verletzungsparameter für eine kopierte Regel ändern, sie können jedoch keine Verletzungen ändern oder erstellen.
7. Verwenden Sie die Tabellensteuerelemente, um nach Bedarf Verletzungen zur SPC-Regelverletzungstabelle hinzuzufügen oder aus ihr zu löschen. Hinzugefügte Verletzungen werden am Ende der Liste in der Tabellen angezeigt. Gelöschte Verletzungen werden aus der Liste in der Tabelle entfernt.
8. Verwenden Sie das Steuerelement zum Bearbeiten der Tabelle, um die Werte des Felds SPC-Verletzungsparameter in der kopierten Regel nach Bedarf zu bearbeiten. Die bearbeiteten Werte werden in der Spalte SPC-Verletzungsparameter angezeigt.
Hinweis: Hinweis: Weitere Informationen zu den für Inline SPC verwendeten Charts und Regeln für die gemeinsame Komponente finden Sie im Abschnitt Industrieregeln der "SPC/IGC Common Component End User Documentation".
9. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
