SPC-Makro

Der Abschnitt gilt nur für Legacy. Die SPC-Makrodatei von Opcenter Execution Semiconductor trägt den Namen SPCInterface.stc. Aufgrund ihrer Konzeption bietet sie dynamische Unterstützung für alle bereitgestellten Opcenter Execution Semiconductor SPC-Charts, ohne dass Änderungen erforderlich sind. Nutzer, die dennoch ein Makro ändern müssen, werden die Informationen in diesem Abschnitt hilfreich finden. Weitere Informationen finden Sie in den Dateien der Statit Custom QC-Hilfe.

Die SPC-Makrodatei umfasst mehrere wichtige Logikbereiche, die jeweils durch einen Kommentarbereich am Anfang identifiziert werden. Dieser Anhang folgt der Struktur der Makrodatei. Jede Unterüberschrift stimmt mit dem entsprechenden Kommentar in der Makrodatei überein.

Die folgenden Themen enthalten Informationen zum SPC-Makro:

• Set Input Parameters
• Set Output Parameters
• Fetch SPCSetupQuery
• Get DatabaseType
• Fetch SPCSetupCDOType
• Execute SPCSetupQuery Queries
• Fetch SPCSetupDetails
• Execute the Charts
