Set Input Parameters

Das SPC-Makro erfordert fünf Eingabeparameter. Diese Parameter korrelieren mit den von der Funktion (_SPCExecuteSPC) verarbeiteten Parametern.

Wichtig: Es wird angenommen, dass die Eingabeparameter (nicht zu verwechseln mit den Eingabeparameterwerten) nicht geändert werden. Dies würde eine Änderung der SPC-Funktion von Opcenter Execution Semiconductor selbst erfordern.

Code in diesem Abschnitt

##---------------------

## Set Input Parameters

##---------------------

%SPCSetupName = {%SPCSetupName%}

%SPCMatrixId = {%SPCMatrixId%}

%ParamDelimiter = {%ParamDelimiter%}

%ParamNamesList = {%ParamNames%}

%ParamValuesList = {%ParamValues%}
