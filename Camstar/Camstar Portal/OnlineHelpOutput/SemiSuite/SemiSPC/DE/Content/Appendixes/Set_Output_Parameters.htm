Set Output Parameters

Statit füllt die Ausgabeparameter nach Abschluss der Makroausführung. Die Ausgabeparameter werden an die SPC-Funktion (_SPCExecuteSPC) zurückgegeben.

Wichtig: Es wird angenommen, dass die Ausgabeparameter (nicht zu verwechseln mit den Ausgabeparameterwerten) nicht geändert werden. Dies würde eine Änderung der SPC-Funktion von Opcenter Execution Semiconductor selbst erfordern.

Code in diesem Abschnitt

##---------------------

## Set Output Parameters

##---------------------

%SPCFailureAction = ""

%SPCResult = ""

%SPCTxnItemNames = ""

%SPCTxnResults = ""

%SPCTxnRuleViolationCounts = ""

%SPCStatitReturns = ""

%SPCTxnDataPointReturns = ""

$SPCQueryResultCount = 0
