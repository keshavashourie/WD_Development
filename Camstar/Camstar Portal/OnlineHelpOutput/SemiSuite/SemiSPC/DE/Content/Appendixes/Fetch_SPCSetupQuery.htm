Fetch SPCSetupQuery

Der Abschnitt "Fetch SPCSetupQuery" soll drei wichtige Variablen über die definierte Abfrage abrufen. Die Abfrage nutzt den Eingabeparameter SPCSetUpName. In Opcenter Execution Semiconductor kann die SPC-Einrichtungsinstanz mit einer oder mehreren SPC-Abfragen konfiguriert werden. Dies bedeutet, dass "Fetch SPCSetupQuery" mehr als einen Datensatz im Ergebnis zurückgeben kann. Die folgenden drei Variablen werden in der Abfrage-Ergebnismenge für eine konfigurierte Abfrage zurückgegeben:

• QueryName: Name der Abfrage, die der SPC-Einrichtung zugeordnet ist.
• QueryText: Abfragetext, der der Abfrage zugeordnet ist. Dieser Abfragetext wird später im Makro ausgeführt.
• SPCSetupId: Semi Suite-Datenbank-InstanceId, die der SPC-Einrichtung zugeordnet ist.

Code in diesem Abschnitt

##---------------------

## Fetch SPCSetupQuery

##---------------------

SET DEFAULTDATASET ddsSPCSetupQuery

BEGINSQL

SELECT

C.UserQueryName QueryName

, C.QueryText QueryText

, A.SPCSetupId SPCSetupId

FROM

A_SPCSetup A

INNER JOIN A_SPCSetupQuery B ON A.SPCSetupId = B.SPCSetupId

INNER JOIN UserQuery C ON B.SPCQueryId = C.UserQueryId

WHERE

A.SPCSetupName = '@v[%SPCSetUpName]'

ENDSQL
