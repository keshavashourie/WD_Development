Chartparameter-Beschreibungen

Opcenter Execution Semiconductor stellt Standardparameter und -werte für die enthaltenen Charts bereit. Diese Tabelle enthält eine Referenz zu den Chartparametern und ihren Definitionen.

Parameter

Beschreibung

Gültige Werte

ALARM_COLOR

Wird verwendet, um die Hintergrundfarbe der Chart zu ändern, wenn einer der Außer-Kontrolle-Regeltests verletzt wird. Mit dem zweiten Parameter wird bestimmt, ob alle Punkte (0) in der Chart oder nur der letzte Punkt (1) betrachtet werden.

Beispiel: RED 0
• [Farbe] 0
• [Farbe] 1

 

ALARM_NO_CHART

Wird verwendet, um die Chartanzeige zu unterdrücken, es sei denn, es liegt eine Außer-Kontrolle-Verletzung vor.

Optionen:

• 0: Verletzung bei einem beliebigen Punkt löst Chartanzeige aus.
• 1: Nur eine Verletzung beim letzten Punkt löst Chartanzeige aus.
• 0
• 1

ALARM_TEXT

Wird verwendet, um eine Nachricht anzuzeigen, wenn einer der Außer-Kontrolle-Regeltests verletzt wird. Die Parameter sind der anzuzeigende Text und die Angabe, ob alle Punkte (0) in der Chart oder nur der letzte Punkt (1) betrachtet werden sollen.

Beispiel: VIOLATION OCCURS [0]
• Zeichenkette [ 0 ]
• Zeichenkette [ 1 ]

 

ANNVAR

Anmerkungsvariablen: Wird verwendet, um Text in der Chart in der Nähe eines geplotteten Punkts zu platzieren. Die Option /Axis muss ebenfalls verwendet werden. Die Variablen sind die X-Achsen-ID, die Nachricht und optional eine Abkürzungsvariable, in dieser Reihenfolge. Die erforderliche Benennungskonvention lautet [ABFRAGENAME}.COMMENTS gefolgt von einem Leerzeichen und [ABFRAGENAME}.INSTANCEID.

[ABFRAGENAME].INSTANCEID[ABFRAGENAME].COMMENTS

[ABFRAGENAME].COMMENTABREV

AXIS

Wird verwendet, um eine Variable anzugeben, die Beschriftungen für die X-Achse der Chart enthält. Diese Variable muss dieselbe Anzahl von Fällen wie die Datenvariable haben und aus Buchstaben oder Zahlen bestehen.

Beispiel: MEASUREMENTVALUES. INSTANCEID

{ABFRAGENAME].INSTANCEID

 

BARCOLOR

Legt die Farbe der Balken im Histogramm fest. Die Standardfarbe ist BlueGrey.

 

BRIEF

Kurzergebnisse: Wird verwendet, um kurze Ergebnisse anzuzeigen.

 

CL

Mittellinie: Definiert den Wert der Mittellinie in der Chart.

Optionen:

• Aus
• One Value – Ein Wert wird für alle angezeigten Werte oder Untergruppe verwendet
• List of Values – Durch Leerzeichen getrennte Liste, in der ein Wert für jeden angezeigten Wert oder die Untergruppe zugewiesen werden muss, z. B. 150 125 100.
• Aus
• One Value
• List of Values

CLASSES

Anzahl der Intervalle, die über die gesamte Länge der X-Achse verwendet werden sollen. Die Standardeinstellung lautet 10.

 

COUNT

Wird verwendet, um eine Häufigkeitszählung für eine Variable durchzuführen, die Rohdaten enthält.

 

CS

Mittlere Spezifikation: Definiert die mittlere Spezifikations- oder technische Linie in der Chart. Optionen:

• One Value – Ein Wert wird für alle angezeigten Werte oder Untergruppe verwendet
• List of Values – Durch Leerzeichen getrennte Liste, in der ein Wert für jeden angezeigten Wert oder die Untergruppe zugewiesen werden muss, z. B. 150 125 100.
• One Value
• List of Values

CURVE

Erzeugt einen Kurvenplot. Diese Option verbindet die Datenpunkte für alle X- und Y-Achsenvariablen.

 

DATA_STYLE

Linientyp: Parameter, mit dem der Linientyp angegeben wird.

Optionen:

• Line: Punkte werden durch eine dünne Linie verbunden. Dies ist die Standardeinstellung.
• Curve: Punkte werden durch eine geglättete (Spline-)Kurve verbunden.
• Lowess: Kurve zeigt den allgemeinen Trend der Daten an, wobei Extremwerte geringen Einfluss auf die Kurve haben.
• Line
• Curve
• Lowess

DATA_WIDTH

Linienbreite: Wird verwendet, um die Breite der Datenlinie anzugeben.

 

DELTA

Wird in Verbindung mit /Vmask verwendet, um die kleinste Änderung des Prozessmittelwerts anzugeben, vor der geschützt werden soll. Dieser Wert muss ein Mehrfaches der Prozess-Standardabweichung sein.

Beliebige reelle Zahl.

DISPLAY

Wird für Kreischarts verwendet, um zu bestimmen, wie Sektoren beschriftet werden sollen. Bei "Percent" wird jeder Sektor mit seinem Prozentsatz vom Ganzen beschriftet. Dies ist die Standardeinstellung. Bei "Quantity" wird jeder Sektor mit seiner tatsächlichen Häufigkeit beschriftet.
• Percent
• Anzahl

DISPLAY3D

Wird verwendet, um die Chart dreidimensional anzuzeigen.

 

DISPLAYVALUES

Wird verwendet, um die Häufigkeit (Balkenhöhe) über jedem Balken anzuzeigen

 

GAP

Wird verwendet, um die Chart mit einem kleinen Abstand zwischen Balken anzuzeigen

 

LABEL

Wird verwendet, um das Vorhandensein und die Position der Datenpunkt-Beschriftungen anzugeben.

• NO – Keine Beschriftungen anzeigen.
• INSIDE – Beschriftungen unter jedem Datenpunkt anzeigen.
• OUTSIDE – Beschriftungen über jedem Datenpunkt anzeigen.
• NO
• INSIDE
• OUTSIDE

LABELSIZE

Wird verwendet, um den Schrittgrad der Beschriftungen anzugeben. Der Standardwert ist 25.

Nummer

LCL

Untere Regelgrenze

Optionen:

• Aus
• One Value – Ein Wert wird für alle angezeigten Werte oder Untergruppe verwendet
• List of Values – Durch Leerzeichen getrennte Liste, in der ein Wert für jeden angezeigten Wert oder die Untergruppe zugewiesen werden muss, z. B. 150 125 100.
• Aus
• One Value
• List of Values

LEGEND

Wird in Kreischarts verwendet, um die anzuzeigende Sektorbeschriftung anzugeben.

 

LHEADSTART

Unterer Anfang: Wird in kumulativen Summencharts verwendet, um den unteren Anfangswert für die Linie der kumulativen Summe anzugeben. Die Standardeinstellung lautet 0.

 

LOCATION

Chartposition: Wird verwendet, um die Chart zu positionieren. Die angegebenen X, Y-Werte geben die Position der linken unteren Chartecke an. Diese Werte müssen im Bereich [0,1000] liegen. Die Standardposition 0,0 gibt die untere linke Ecke des Graphenbereichs an.

 

LREFERENCE

Untere Referenz: Wird verwendet, um den unteren Referenzwert für die Linie der kumulativen Summe anzugeben. Der Standardwert ist 0.

 

LSIZE

Wird verwendet, um die Größe der Beschriftung anzugeben

 

LSL

Untere Spezifikationsgrenze: Definiert die untere Spezifikations- oder technische Linie in der Chart.

Optionen:

• One Value – Ein Wert wird für alle angezeigten Werte oder Untergruppe verwendet
• List of Values – Durch Leerzeichen getrennte Liste, in der ein Wert für jeden angezeigten Wert oder die Untergruppe zugewiesen werden muss, z. B. 150 125 100.
• One Value
• List of Values

MANTISSA

Wird verwendet, um die Anzahl der Nachkommastellen anzugeben, die für berechnete Werte angezeigt werden sollen. Die Standardeinstellung lautet 3.

 

MSTANDARD

Mittelwert der Grundgesamtheit: Wird verwendet, um den Standardwert für den Mittelwert festzulegen. Diese Option wird zusammen mit /RSTANDARD verwendet, um eine Methode für die Kontrolle der Limits zur Verfügung zu stellen.

 

NODRAW

Chartanzeige: Wenn dieser Schalter ausgewählt ist, wird die Chart definiert, jedoch nicht angezeigt. Wird verwendet, wenn die Chart über benutzerdefinierte Grafikbefehle geändert oder mehrere Charts im selben Graphen angezeigt werden sollen.

 

NORMAL

Diese Option bewirkt, dass die erwarteten Häufigkeiten unter der normalen Verteilungskurve über das Histogramm gelegt werden.

Sie wird ignoriert, wenn sie in Verbindung mit der Option /CUMULATIVE verwendet wird.

 

NSIGMA

Anzahl der Sigmas: Wird verwendet, um die Standardeinstellung 3,00 des Sigmakoeffizienten für die Berechnung der Regelgrenzen zu ändern. Wenn 0 angegeben ist, werden die oberen und unteren Regelgrenzen nicht gezogen.

 

ORIENTATION

Balkenausrichtung: "Vertical" zeigt die Balken vertikal mit ihren Beschriftungen unter dem Datenbereich an. "Horizontal" zeigt die Balken horizontal mit ihren Beschriftungen auf der linken Seite des Balkens an.
• Vertikal (Vertical)
• Horizontal

REPORT

Geniert einen Textbericht für die Chart.

 

RLEGEND

Rechte Legende: Wird verwendet, um jede Regellinie, Warnungslinie und Spezifikationslinie mit einer Legende auf der rechten Seite zu identifizieren.
• abbreviation
• value
• both

RULE_LETTERS

Regelbuchstaben anzeigen: Jeder Außer-Kontrolle-Regel ist ein Buchstabe zugeordnet. Diese Option steuert, ob der Buchstabe neben Punkten angezeigt wird, die die spezielle Regel verletzen.

• ON
• OFF

RSTANDARD

Grundgesamtheitsbereich: Die angegebene Zahl wird als bekannter oder angenommener Wert des Gesamtheitsbereichs verwendet.

 

SAVE

Daten speichern: Speichert die berechneten Daten.

 

SAVEDATASET

Ergebnisdataset: Gibt den Namen des Datasets für die gespeicherten Variablen an.

 

SELECT

Ausdruck, der eine Teilmenge der Daten vor dem Start des Befehls auswählt.

Beispiel: ( width > 1.3 )

( Ausdruck )

SIZE

Chartgröße: Standardmäßig wird die Chart unter Ausnutzung des gesamten Anzeigebereichs generiert. Um die Größe der Chart zu beschränken, geben Sie die X-Dimension (horizontal) und Y-Dimension (vertikal) im Bereich [1,1000] an.

X und Y müssen jeweils im Bereich [1,1000] liegen.

 

SMOOTH

Diese Option plottet eine glatte Kurve durch die Datenpunkte.

 

STDDEV

Standardabweichung: Bewirkt, dass die Standardabweichungen der Untergruppe verwendet werden, um die Regel- und Warngrenzen zu berechnen und nicht den Standardwert der Bereiche. Es gibt kein Limit hinsichtlich der maximalen Anzahl von Werten in einer Untergruppe, wenn diese Option verwendet wird. Wenn STDDEV nicht verwendet wird, liegt die maximale Anzahl der Werte in einer Untergruppe bei 30.

 

SUBGROUPSIZE

Stellt die Anzahl der Datenpunkte dar, die als Faktoren gruppiert werden sollen. Es gibt zwei Gruppierungsmethoden:

• Numerische Konstante: Bei dieser Methode geben Sie einen numerischen Wert an. Die Zahl 5 gibt z. B. an, dass die ersten fünf Variablen zur ersten Gruppe gehören, die nächsten fünf Werte zur nächsten Gruppe usw.
• Gruppen-ID: Diese Methode erfordert, dass jeder Variablen eine Gruppen-ID zugeordnet wird. Die ID kann aus Zahlen oder Buchstaben bestehen. Die Gruppe, zu der eine Variable gehört, wird anhand der Gruppen-ID identifiziert. (Diese Methode wird nicht in den SPC-Abfragen demonstriert, die mit dem SPC-Basisprodukt bereitgestellt werden.)

 

SUMMARY

Zusammenfassungsinformationen: Zeigt zusammenfassende Informationen unter der Chart an, z. B. Limitwerte, Anzahl der Datenpunkte und verletzte Regeln. Darüber hinaus wird der Buchstabe für die Außer-Kontrolle-Regel neben Punkten angezeigt, die eine bestimmte Regel verletzen, wenn im Unterdialog "Alarm" der Schalter "Regelbuchstaben anzeigen" auf "Autom" oder "Ein" gestellt ist.
• Aus
• Ein

TABLE_OTHER

Wird verwendet, um Informationen zu den Arbeitsbereichsvariablen in der Tabelle anzuzeigen. Die angegebenen Variablen können Buchstaben oder Zahlen sein und müssen einen Fall für jeden Punkt in der Chart oder dieselbe Anzahl von Fällen wie die Datenvariable haben, in welchem Fall alle Informationen für eine bestimmte Untergruppe in derselben Zelle platziert werden. Erforderliche Namenskonvention ist [ABFRAGENAME}.CONTAINERNAME.

[ABFRAGENAME}.CONTAINERNAME

TAIL

Gibt den Bruchteil der Daten an, die in den Schwänzen der Kurve geprüft werden sollen. Dieser Wert muss im Bereich (0,1) liegen. Der Standardwert ist 0.1.

Wird verwendet, um Datentipps auf der Basis bereitgestellter Optionen anzuzeigen. Optionen (rechts aufgeführt) werden durch ein Leerzeichen voneinander getrennt.

TITLE

Wird verwendet, um eine oder mehrere Zeichenketten anzugeben, die oben in der Mitte des Graphen angezeigt werden sollen.

 

UCL

Obere Regelgrenze: Definiert die obere Regelgrenze für die Chart.

Optionen:

• Aus
• One Value – Ein Wert wird für alle angezeigten Werte oder Untergruppe verwendet
• List of Values – Durch Leerzeichen getrennte Liste, in der ein Wert für jeden angezeigten Wert oder die Untergruppe zugewiesen werden muss, z. B. 150 125 100.
• Aus
• One Value
• List of Values

USL

Obere Spezifikationsgrenze: Definiert die untere Spezifikations- oder technische Linie in der Chart.

Optionen:

• Aus
• One Value – Ein Wert wird für alle angezeigten Werte oder Untergruppe verwendet
• List of Values – Durch Leerzeichen getrennte Liste, in der ein Wert für jeden angezeigten Wert oder die Untergruppe zugewiesen werden muss, z. B. 150 125 100.
• Aus
• One Value

WARN

Warngrenzen: Bewirkt, dass Warngrenzen (UWL, LWL) in der Chart angezeigt werden. Standardmäßig wird die Warngrenze bei ± 2-Sigma gesetzt. Die Warngrenzen können angepasst werden, indem ihnen ein Parameterwert größer als 0 zugewiesen wird.

 

WOFF

Arbeitet mit dem Parameter WARN. Je nach bereitgestelltem Parameterwert wird entweder die untere oder obere Warngrenze nicht angezeigt.

• lower
• upper

XLSIZE

Schrittgrad der X-Achsenbeschriftung: Gibt den Schrittgrad für die Beschriftungen der X-Achse an. Angegebene Ganzzahl muss im Bereich [1,100] liegen.

 

YLSIZE

Schrittgrad der Y-Achsenbeschriftung: Gibt den Schrittgrad für die Beschriftungen der Y-Achse an. Angegebene Ganzzahl muss im Bereich [1,100] liegen.

 

YMIN

Definiert den Mindestwert für die Y-Achse.

 

YNAME

Neben der Y-Achse angezeigte Zeichenkette.

 

YSTEP

Wird verwendet, um die Skalenbeschriftungsschrittgröße für die Y-Achse zu definieren.

 

YFORMAT

Wird verwendet, um das Ganzzahlformat für die Skalenstrich-Beschriftungen der Y-Achse anzugeben.
