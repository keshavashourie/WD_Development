SQL-Abfrageskript – Hinweise

Diese Liste enthält wichtige Informationen über die SQL-Abfrage:

1. Die Order by-Klausel darf für diese Abfrage oder Variationen dieser Abfrage nicht geändert werden, mit einer Ausnahme: Wenn mehrere Datenpunkte pro Wafer gesammelt werden und Sie jeden Wafer einzeln analysieren möchten, können Sie "Waferscribenumber DESC" zur ORDER BY-Klausel hinzufügen. Formatieren Sie die überarbeitete Klausel wie folgt:

Order By DataSource DESC, TxnTimestamp ASC, Waferscribenumber ASC ,DisplaySequence ASC

Hinweis: Beide Unterabfragen müssen auch die Waferscribenumber enthalten.

Alle SPC-Trendanalysen innerhalb von Statit werden von rechts nach links ausgewertet, wenn die SPC-Chart angezeigt wird. Beachten Sie die Bedeutung der folgenden Klauselparameter:

• "DataSource DESC" gewährleistet, dass die Daten aus dem aktuellen Los immer als äußerster rechter Datenpunkt in der SPC-Chart dargestellt werden.
• "TxnTimeStamp ASC" gewährleistet, dass alle Datenpunkte in historischer Reihenfolge von neu nach alt platziert werden.
• "DisplaySequence DESC" gewährleistet, dass alle Datenpunkte in der Reihenfolge der Datensammlung während des Umlaufbestandsdaten-Prozesses platziert werden.
2. Die Anzahl der Datenpunkte, die in der Chart geplottet werden, entspricht der Anzahl der zurückgegebenen Zeilen dividiert durch SubGroupSize. Der Parameter SubGroupSize wird im SPC-Einrichtungsobjekt konfiguriert.
