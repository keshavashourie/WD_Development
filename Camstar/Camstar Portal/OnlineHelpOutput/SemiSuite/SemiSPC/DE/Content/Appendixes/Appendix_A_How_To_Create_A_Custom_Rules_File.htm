Vorgehensweise zum Erstellen einer benutzerdefinierten Regeldatei

Bevor Sie anfangen

Dieser Abschnitt gilt nur für Legacy. Der Entwickler muss Zugriff auf die Anwendung Statit Custom QC haben, um eine benutzerdefinierte Regeldatei erstellen zu können.

Die empfohlene Vorgehensweise für diesen Prozess besteht darin, eine vorhandene Regeldatei zu kopieren, die als Grundlage dienen soll, und diese Kopie anschließend zu ändern. Zu diesem Zweck empfiehlt Siemens, die QC_ATT-Regeldatei (qc_att.fcn) zu kopieren.

Informationen finden Sie unter "In SPC enthaltene Regeln".

QC-Regelfunktionen

Alle Regeln basieren auf einer der drei Standard-Regelfunktionen, die mit Opcenter Execution Semiconductor SPC bereitgestellt werden. Dies sind die Funktionen qc_rule1, qc_rule3 und qc_rule4.

qc_rule1

Diese Funktion wird verwendet, wenn N von M aufeinanderfolgenden Punkten getestet werden, die außerhalb oder innerhalb bestimmter Limits liegen. N kann gleich M sein.

Beispiel:

call qc_rule1( ("A", "A) 1 point above Zone

A",1,1,1,num(qc_ucl), 0,0,0, $found, $error)

qc_rule3

Beispiel:

decreasing", 6, 1, $found, $error))

Vorgehensweise zum Erstellen einer benutzerdefinierten Regeldatei

Gehen Sie folgendermaßen vor, um eine benutzerdefinierte Regeldatei zu erstellen:

1. Suchen Sie in Windows Explorer im Ordner "C:\Programme (x86)\Statit CustomQC\fsrc" die Datei qc_att.fcn.
2. Kopieren Sie qc_att.fcn im selben Ordner und benennen Sie die Kopie in Meine_QC_Regeln.fcn um.
3. Öffnen Sie die neue Datei (Meine_QC_Regeln.fcn) mit Notepad oder einem anderen geeigneten Texteditor.
4. Ändern Sie "function qc_att" in der obersten Zeile der Datei in "function Meine_QC_Regeln", wie in diesem Beispiel abgebildet:

5. Scrollen Sie in der Regeldatei nach unten bis zum Anzeigenamen. Ändern Sie "AT&T" in "Meine_QC_Regeln", wie in diesem Beispiel abgebildet:

Hinweis: Die Deklaration und Definition jeder mit der Datei verknüpften Regel werden direkt unter dem Anzeigenamen angezeigt. Beachten Sie das Beispiel für die Verletzung der oberen Spezifikation (Upper Spec) in der folgenden Abbildung:

6. Fahren Sie je nach den bereitgestellten Funktionsinformationen mit dem Hinzufügen, Löschen oder Ändern von Regeln in der Datei Meine_QC_Regeln.fcn fort.
7. Speichern Sie die Datei und schließen Sie den Texteditor.
8. Öffnen Sie CustomQC über das Desktopsymbol oder über das Menü "Start".
9. Wählen Sie File (Datei) > Proc Compiler (Prozesskompilierer) aus. Durchsuchen Sie anschließend das Feld Proc Source File (Prozessquelldatei), um die Datei Meine_QC_Regeln.fcn auszuwählen. Speichern Sie die Ausgabe in C:\Programme (x86) \Statit CustomQC\fcns\ MyQCRules.stf. Sie müssen die Erweiterung .STF angeben, da ansonsten standardmäßig .STP ausgewählt wird.
10. Klicken Sie auf OK.
11. Kopieren Sie die STF-Datei mit Windows Explorer nach C:\Programme (x86)\Statit e-Server\fcns. Dieser Schritt wird ausgeführt, wenn Sie die Datei im Portal und in e-Server und nicht nur in CustomQC verwenden möchten.
