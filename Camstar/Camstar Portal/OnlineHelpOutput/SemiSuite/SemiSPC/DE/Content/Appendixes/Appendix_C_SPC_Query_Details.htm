SPC-Abfragedetails

Die SPC-Abfragen sind wichtig für die Auswertung des Produktionsprozesses im Rahmen von Opcenter Execution Semiconductor. Inhalt und Struktur der durch die SPC-Abfrage abgerufenen Daten müssen mit der konfigurierten SPC-Engine übereinstimmen.

Abfrage SPCDataValues

Die Abfrage SPCDataValues wertet die gesammelten Umlaufbestandsdaten für ein Los aus, das sich gerade in der Fertigungsverarbeitung während TrackOutLot befindet. Die Abfrage unterstützt die SPC-Standardeinrichtung DATAVALUES. Da eine der Hauptaufgaben von SPC darin besteht, die Produktionsleistung im zeitlichen Verlauf zu überprüfen, muss die Abfrage gleichzeitig die Daten aus dem aktuellen Los und die historischen Daten abrufen. Deshalb setzt sich diese Abfrage aus zwei Unterabfragen zusammen.

Unterabfragen

Die Abfrage muss Daten aus zwei separaten Gruppen von Tabellen abrufen: eine Gruppe für aktuelle Losdaten und eine weitere Gruppe für historische Daten.

Die Tabellen, in denen aktuelle Losdaten gespeichert werden, variieren je nach Konfiguration der Umlaufbestandsdateneinrichtung, in der es einen festgelegten Prozesstyp gibt, und je nachdem, welche Transaktion die Datensammlung enthält. Wenn die Umlaufbestandsdateneinrichtung so konfiguriert ist, dass sie bei LotMoveOut stattfindet, und ProcessType leer ist, werden die Daten temporär in der Tabelle A_WIPLotData gespeichert. Alle anderen Konfigurationen für Umlaufbestandsdateneinrichtungen werden in A_WIPLotDetailsData gespeichert.

Wenn die Erfassung der Umlaufbestandsdaten beim TrackIn oder TrackOut stattfindet, werden die Ergebnisse im Zuge des TrackOut-Prozesses an die Tabelle A_WIPEquipmentDataHistory mit den historischen Ausrüstungsdaten übertragen.

Wenn das Los aus dem aktuellen Schritt verschoben wird, werden alle Umlaufbestandsdaten an die formellen Historientabellen (A_WIPLotDataHistory bzw. A_WIPLotDetailsDataHistory) übertragen.

Abfrageparameter

Diese Tabelle nennt drei in der Abfrage SPCDataValues verwendete Parameter.

Parametername

Details

CONTAINER

• Beschreibung: Wird für die erste Unterabfrage verwendet, um die Umlaufbestandsdaten aus dem aktuellen Los abzurufen
• Datentyp: Zeichenkette
• Text anzeigen: Container
• Parameterwert:
• Dynamischer Wert: Container.Name
• Ist erforderlich: Wahr
• Für Blockzeilen verwenden: Falsch

EQUIPMENT

• Beschreibung: Wird für beide Unterabfragen verwendet, um die Umlaufbestandsdaten zu begrenzen, die aus der momentan vom Los verwendeten Ausrüstung abgerufen werden.
• Anzeigetyp: Zeichenkette
• Text anzeigen: Ausrüstung
• Parameterwert:
• Dynamischer Wert: Equipment.Name
• Ist erforderlich: Wahr
• Für Blockzeilen verwenden: Falsch

WIPDATANAME

• Beschreibung: Wird für beide Unterabfragen verwendet, um Datensätze mit den spezifischen Umlaufbestandsdaten abzurufen. Versucht, den eindeutigen Namen der Umlaufbestandsdaten aus der aktuellen SPC-Transaktion abzurufen. Gelingt dies nicht, werden alle Namen von Umlaufbestandsdaten abgerufen, die mit dem Wert "DATA" beginnen.
• Datentyp: Zeichenkette
• Text anzeigen: WIPDATANAME
• Parameterwert: Data%
• Dynamischer Wert: SPCObject?SPCObject.WIPDataName.Name:"DATA%"
• Ist erforderlich: Wahr
• Für Blockzeilen verwenden: Falsch
Hinweis: Wenn Abfrageparameter mithilfe dynamischer Werte festgelegt werden, sollten keine Parameterwerte bereitgestellt werden.

Beim Arbeiten mit der SPC-Matrix

Die SPC-Matrix wird beim Einbringen ausgewertet, wenn die ausgewählte Ausrüstung mit einer SPC-Standardeinrichtung konfiguriert ist und "SPC-Matrix verwenden" aktiviert ist. Um die SPC-Matrix innerhalb der SPC-Abfrage zu verwenden, müssen Sie die Abfrage ändern, die von der mit der SPC-Matrix verknüpften SPC-Einrichtung verwendet wird. Genauer gesagt muss die WHERE-Klausel für die Verknüpfung (JOIN) historischer Daten geändert werden, indem die Matrix-ID aufgenommen wird.

Vorgehensweise zum Ändern einer SPCDataValues-Abfrage für die SPC-Matrix

Gehen Sie folgendermaßen vor, um die Abfrage SPCDataValues zu ändern:

1. Rufen Sie die Instanz SPCDataValues des SPC-Abfrageobjekts auf.
2. Ändern Sie die WHERE-Klausel in der zweiten Unterabfrage so, dass sie wie die Klausel unten aussieht. Fügen Sie dazu die hervorgehobene Zeile hinzu:

WHERE

WDN.WIPDataNameName LIKE ?WIPDATANAME

AND WEDH.WIPDataValue IS NOT NULL

AND WEDH.ServiceName = 'TrackOutLot'

AND WE.SPCMATRIXID = ?SPCMatrixId

AND WDN.FieldType = 'NUMBER'

AND WE.EquipmentName = ?EQUIPMENT

AND (CASE WHEN STDP.ExcludeData IS NULL THEN 0 ELSE STDP.ExcludeData END) = 0

) Query1

3. Klicken Sie in der Tabelle "Parameter" auf Neue Zeile hinzufügen. Eine Zeile von Feldern wird in der Tabelle aktiviert.
4. Fügen Sie die folgende Abfrageparameter-Definition hinzu:
• Parametername: SPCMatrixId
• Datentyp: Zeichenkette
• Text anzeigen: SPCMatrixId
• Parameterwert: 
• Dynamischer Wert: StringFromObject(SPCMatrix.InstanceID)
• Ist erforderlich: Wahr
• Für Blockzeilen verwenden: Falsch
5. Klicken Sie auf Speichern. Die Anwendung speichert die Änderungen und eine Statusnachricht wird angezeigt.
