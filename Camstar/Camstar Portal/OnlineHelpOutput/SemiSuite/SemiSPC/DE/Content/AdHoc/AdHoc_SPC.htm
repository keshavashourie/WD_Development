Ad-hoc-SPC

Die Seite "Ad-hoc-SPC" bietet Funktionen zum manuellen Ausführen der SPC-Basiseinrichtung oder der SPC-Einrichtung für sowohl Legacy als auch Inline SPC. Dies wird in der Regel während der Laufzeitausführung auf der Ebene "Los ausbringen" oder "Umlaufbestandsdaten" verwendet.

Auf der Seite können Sie die SPC-Chart für gesammelte, in der Datenbank gespeicherte Fertigungsdaten nach Bedarf für jedes Los plotten und anzeigen, unabhängig vom Status der Ausrüstung, in der die Transaktion durchgeführt wird.

Sie können die Daten in der SPC-Chart ändern, die auf der Seite "Ad-hoc-SPC" angezeigt werden. Sie können auch Daten korrigieren, die zuvor falsch eingegeben wurden, oder fehlerhafte Daten ausschließen, um zukünftige Datenverfolgbarkeit zu gewährleisten. Wenn Sie Daten auf diese Weise ändern, prüft SPC die SPC-Chart erneut und aktualisiert sie.

Beim Verwenden von Ad-hoc-SPC

Sie müssen SPC-Daten erstellen, bevor Sie Charts mithilfe von Ad-hoc-SPC plotten und anzeigen können.

Felddefinitionen des Popups "Anmerkung"

Diese Tabelle definiert die Felder im Popup "Anmerkung".

Feld

Definition

Typ

Eintragstypen

Gibt an, wie die Datenpunkte in der Untergruppe mit Anmerkungen versehen werden. Mögliche Werte:

• Nach Untergruppe – Ermöglicht Ihnen, die Daten für die gesamte Untergruppe mit Anmerkungen zu versehen. Die Anzahl der Datenwerte in der Untergruppe wird in der SPC-Einrichtung oder SPC-Basiseinrichtung definiert.

Tabelle, in der Datenpunktwerte angezeigt werden, die für die SPC-Chart eingegeben wurden.

Vorgehensweise zum Anzeigen von Informationen für einen SPC-Datensatz

Gehen Sie folgendermaßen vor, um Informationen für einen SPC-Datensatz anzuzeigen:

1. Öffnen Sie die Seite "Ad-hoc-SPC".
2. Geben Sie die SPC-Einrichtung ein, für die Sie SPC-Fehlerinformationen im Feld SPC-Einrichtung anzeigen möchten.
3. Geben Sie Parameter in die Spalte Parameterwert für den relevanten Parameternamen in der Tabelle "Parameter" ein.
4. Klicken Sie auf SPC ausführen. Die Anwendung zeigt das Popup "SPC-Chart" und SPC-Ergebnisse im Bereich "Ergebnisse" an.

Vorgehensweise zum Überschreiben von SPC-Datenpunktwerten

1. Führen Sie die Schritte in "Vorgehensweise zum Anzeigen von Informationen für einen SPC-Datensatz" aus.
2. Klicken Sie im SPC-Chart auf den Datenpunkt, den Sie überschreiben möchten. Die Anwendung zeigt das Popup "Anmerkung" an.
3. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
4. Klicken Sie im Popup "Anmerkung" auf Abschicken. Die Anwendung zeigt eine Nachricht über den Erfolg an und kehrt dann wieder zum Popup "SPC-Chart" zurück.
5. Klicken Sie im Popup "SPC-Chart" auf Schließen.
