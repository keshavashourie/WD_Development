SPC-Echtzeitüberwachung

Auf der Seite "SPC-Echtzeitüberwachung" können Sie eine zuvor ausgeführte SPC-Einrichtung ausführen und die Chart mit den aktuellen Daten (Echtzeitdaten) aktualisieren.

Auf der Seite "SPC-Echtzeitüberwachung" können Sie auch konfigurierte Inline SPC-Charts erstellen und automatisch aktualisieren. Sie können Datenpunkte bearbeiten und Anmerkungen für angezeigte Inline SPC-Charts hinzufügen.

Beim Verwenden der Seite "SPC-Echtzeitüberwachung"

Die Seite "SPC-Echtzeitüberwachung" setzt voraus, dass Sie zuvor die Chart ausgeführt haben, für die Sie Daten in Echtzeit anzeigen möchten. Der Chartbereich ist zunächst leer. Die Anwendung sucht nach einem SPC-Datensatz, nachdem Sie eine SPC-Einrichtung eingegeben und auf "Suchen" geklickt haben. Die Anwendung zeigt die Chart oder Charts im Chartbereich an, nachdem Sie auf "Suchen" geklickt haben.

Die Größe des angezeigten Charts kann auf der Modellierungsseite "SPC-Basiseinrichtung" konfiguriert werden, indem die Felder "Charthöhe" und "Chartbreite" eingerichtet werden. Informationen zu Anmerkungen und Überschreibungen finden Sie unter Chartanzeige und -steuerung.

Vorgehensweise zum Verwenden der Seite "SPC-Echtzeitüberwachung"

Gehen Sie folgendermaßen vor, um die Seite "SPC-Echtzeitüberwachung" zu verwenden:

1. Öffnen Sie die Seite "SPC-Echtzeitüberwachung".
2. Wählen Sie eine SPC-Einrichtung aus. Die Anwendung aktiviert die Schaltfläche "Suchen".
3. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
4. Klicken Sie auf Suchen. Die Anwendung sucht den SPC-Datensatz. Die Anwendung zeigt alle Parameter an und aktiviert die Schaltfläche "SPC ausführen", wenn die Suche erfolgreich ist.
5. Klicken Sie auf SPC ausführen. Die Anwendung zeigt die Schaltfläche "Ein", das Steuerelement "Aktualisierungsintervall" und die Chart oder Charts im Chartbereich an.
6. Ziehen Sie den Schieberegler Aktualisierungsintervall nach rechts, wenn Sie das Aktualisierungsintervall erhöhen möchten.
