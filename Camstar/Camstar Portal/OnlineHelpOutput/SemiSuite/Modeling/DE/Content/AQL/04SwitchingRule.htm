Definieren von Umschaltregeln

Auf der Seite "Umschaltregel" können Sie die Regeln definieren, mit denen ein Stichprobenplan von einer Prüfebene auf eine andere verschoben wird. Umschaltregeln ermöglichen die Änderung eines Stichprobenplans in einen reduzierten oder strafferen Inspektionsplan, je nach Anzahl der bestandenen oder durchgefallenen Lose in einer Lossequenz. Ein Stichprobenplan ermöglicht das Definieren von Umschaltregeln, die auf der Basis der Anzahl der bestandenen Lose für eine definierte Anzahl von Losen oder auf der Basis eines Ausdrucks ausgewertet werden. Wenn die Kriterien der Umschaltregel erfüllt sind, kann die Anwendung den Umschaltregel-Inspektionsplan automatisch ändern und/oder eine E-Mail-Benachrichtigung an einen Entscheidungsträger senden, damit dieser manuell eingreift.

Analog zu den Stichprobenraten können auch Umschaltregeln eine Maximaldauer haben. Als Teil der Stichprobenrate kann für die Umschaltregel eine maximale Dauer definiert werden. Daher werden nur Lose bei der Auswertung von Umschaltregeln berücksichtigt, die innerhalb des (im Feld "Umschaltregel max. Dauer" im Stichprobenplan festgelegten) maximalen Zeitfensters verarbeitet werden. Die Anwendung initiiert den Auswertungsprozess der Umschaltregel nur, wenn eine der folgenden Bedingungen erfüllt ist:

• Das Feld "Umschaltregel max. Dauer" im Stichprobenplan ist auf 0 festgelegt.
• Die Anzahl von Tagen seit der Aktualisierung des aktuellen Stichprobenstatus-Datensatzes ist kleiner als der Wert, der im Feld "Umschaltregel max. Dauer" im Stichprobenplan festgelegt wurde.

Weitere Informationen zum Feld "Umschaltregel max. Dauer" finden Sie unter "Definieren von Stichprobenplänen".

Felddefinitionen des Popups "Hinzufügen" für Umschaltregeln

Diese Tabelle definiert die Felder im Popup "Hinzufügen".

Feld

Definition

Typ

Von Prüfebene

Ausgangsprüfebene für diese Umschaltregel, die angewendet werden kann, wenn die aktuelle Prüfebene diesem Wert entspricht.

Erforderlich

Zu Prüfebene

Resultierende Prüfebene, die als neue Prüfebene verwendet wird, wenn Kriterien der Umschaltregel erfüllt werden.

Erforderlich

Anzahl bestandener (oder durchgefallener) Container

Anzahl der Lose, die die Prüfung bestanden haben oder durchgefallen sind. Ob die Zahl Lose darstellt, die bestanden haben oder durchgefallen sind, hängt vom Wert des Felds "Bestanden/Durchgefallen" ab. Dieses Feld ist immer eine Integer-Zahl.

Die Anwendung bestimmt, ob der Inspektionsplan geändert werden soll, wenn der folgende Ausdruck wahr ist:

X von Y

Dabei gilt:

• X ist die Anzahl der Container, die bestanden haben (oder durchgefallen sind) (dieses Feld).
• Y ist die Anzahl der Lose im letzten Satz (Feld "Anzahl in letztem Containersatz").

"Bestanden/Durchgefallen" wird z. B. auf "Bestanden", der Wert für "Anzahl bestandener (oder durchgefallener) Container" auf "3" und der Wert für "Anzahl in letztem Containersatz" auf "4" festgelegt. Wenn drei der letzten vier Lose (3 von 4) die Inspektion bestehen, ändert die Anwendung den Inspektionsplan.

Hinweis: Das Feld "Automatisches Umschalten erlauben" muss festgelegt werden, damit die Anwendung den Inspektionsplan ändert.

Optional

Anzahl in letztem Containersatz

Anzahl der Lose im letzten Satz, für die die Bestanden- oder -Durchgefallen-Ergebnisse ermittelt werden. Ob die Zahl Lose darstellt, die bestanden haben oder durchgefallen sind, hängt vom Wert des Felds "Bestanden/Durchgefallen" ab. Dieses Feld ist immer eine Integer-Zahl.

Die Anwendung bestimmt, ob der Inspektionsplan geändert werden soll, wenn der folgende Ausdruck wahr ist:

X von Y

Dabei gilt:

• X ist die Anzahl der Container, die bestanden haben (oder durchgefallen sind).
• Y ist die Anzahl im letzten Containersatz (dieses Feld).

"Bestanden/Durchgefallen" wird z. B. auf "Bestanden", der Wert für "Anzahl bestandener (oder durchgefallener) Container" auf "3" und der Wert für "Anzahl in letztem Containersatz" auf "4" festgelegt. Wenn drei der letzten vier Lose (3 von 4) die Inspektion bestehen, ändert die Anwendung den Inspektionsplan.

Hinweis: Das Feld "Automatisches Umschalten erlauben" muss festgelegt werden, damit die Anwendung den Inspektionsplan ändert.

Optional

Bestanden/Durchgefallen

Gibt an, ob das Feld "Anzahl bestandener (oder durchgefallener) Container" die Anzahl für bestandene oder durchgefallene Stichprobentests angibt.

Optional

Ausdruck

Dieser einheitliche Ausdruck kann anstelle der Felder Anzahl bestandener (oder durchgefallener) Container und Anzahl in letztem Containersatz verwendet werden, um zu bestimmen, ob die Umschaltregel ausgelöst wird. Der Ausdruck muss in einem booleschen Wert (wahr/falsch) resultieren. Informationen zu vereinheitlichten Ausdrücken finden Sie im Opcenter Execution Core Designer-Benutzerhandbuch.

Hinweis: Es werden entweder die Felder "Anzahl bestandener (oder durchgefallener) Container", "Anzahl in letztem Containersatz" und "Bestanden/Durchgefallen" oder nur das Feld "Ausdruck" ausgefüllt.

Optional

Automatisches Umschalten erlauben

Zeigt an, ob die Prüfebene automatisch an den Wert von "Zu Prüfebene" angepasst wird, wenn die Kriterien der Umschaltregel erfüllt sind.

Optional

Benachrichtigung notwendig

Wenn die Kriterien der Umschaltregel erfüllt sind, wird eine E-Mail-Benachrichtigung gesendet.

Optional

E-Mail-Verteiler

E-Mail-Verteilerliste für diese Umschaltregel, falls sie sich von der Standardliste im Abschnitt "In Verarbeitung" unterscheidet.

Vorgehensweise zum Definieren einer Umschaltregel

Gehen Sie folgendermaßen vor, um eine Umschaltregel zu definieren:

1. Öffnen Sie die Seite Umschaltregel. Die Seite "Umschaltregel" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Umschaltregelinstanz in das Feld Umschaltregel ein.
4. Geben Sie die Revision oder Version der Instanz in das Feld Revision ein. Die Anwendung verwendet den Namen und die Revision, um die Definition zu identifizieren.
5. Geben Sie die Umschaltregelparameter wie folgt in die Tabelle "Umschaltregeldetails" ein:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
b. Geben Sie die Ausgangsprüfebene für die Umschaltregel in das Feld Von Prüfebene ein. Der Wert für "Von Prüfebene" kann angewendet werden, wenn die aktuelle Prüfebene diesem Wert entspricht.
c. Geben Sie die resultierende Prüfebene für die Umschaltregel in das Feld Zu Prüfebene ein. Dieser Wert wird für die neue Prüfebene verwendet, wenn die Kriterien der Umschaltregel erfüllt sind.
d. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. Weitere Informationen zu den optionalen Feldern finden Sie unter "Felddefinitionen des Popups "Hinzufügen" für Umschaltregeln".
e. Wiederholen Sie die Schritte a bis d für jeden Umschaltregelparameter, den Sie hinzufügen möchten.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
