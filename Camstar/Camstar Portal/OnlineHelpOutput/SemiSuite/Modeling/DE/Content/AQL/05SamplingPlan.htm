Definieren von Stichprobenplänen

Die Seite "Stichprobenplan" wird verwendet, um die Stichprobenaktivität für ein Los zu organisieren. Aktualisierungen an Stichprobenplänen wirken sich nicht auf Lose aus, die sich gerade im Umlaufbestand befinden. Die Revisionen werden aber auf das nächste Los angewendet.

Stichprobenrate

Eine Stichprobenrate muss entweder für den gesamten Stichprobenplan oder für jeden Stichprobentest definiert werden. Die Stichprobenrate ist eine Zahl, die die Stichprobenhäufigkeit angibt. Wenn die Stichprobenhäufigkeit z. B. durch die Variable N dargestellt wird, bedeutet N = 1 jedes Los, N = 2 jedes zweite Los, N = 3 jedes dritte Los usw. Ein Stichprobenplan kann überschrieben werden, um eine Prüfrate von 100 % zu erzwingen (Stichprobenrate = 1), d. h., die Stichprobenprüfung muss für jedes Los durchgeführt werden.

Maximale Dauer

Die Verwendung des Felds "Stichprobenrate max. Dauer" zum Definieren einer maximalen Dauer gewährleistet, dass nur Lose einbezogen werden, die innerhalb eines maximalen Zeitfensters erzeugt werden, wenn bestimmt werden soll, ob die Stichprobenprüfung auf der Grundlage der Stichprobenrate durchgeführt werden muss. Der Stichprobenzähler wird zurückgesetzt, um zu verhindern, dass lange Zeitspannen die Stichprobenhäufigkeit beeinflussen, wenn die maximale Dauer von allen relevanten Losen überschritten wird.

Ein Beispiel: Es wird jedes zehnte Los geprüft, aber die Produktion stoppt beim fünften Los. Einen Monat später beginnt die Produktion wieder. Da die maximale Dauer auf 15 Tage festgelegt wurde, ist der Loszähler nun veraltet. Er wird daher von der Anwendung auf 1 zurückgesetzt und erneut gestartet. Nun wird wieder das zehnte Los geprüft und nicht das fünfte Los, das eigentlich an der Reihe gewesen wäre, wenn der Zähler nicht zurückgesetzt worden wäre. Dieser Prozess gewährleistet, dass Lose, die chronologisch weit auseinanderliegen, nicht miteinander verglichen werden.

Beim Definieren von Stichprobenplänen

Die folgenden Regeln gelten bei der Modellierung des Stichprobenplans:

• Ein Wert in der Tabelle "Details" setzt den im Abschnitt "In Verarbeitung" definierten Standardwert außer Kraft.
• Die standardmäßigen Stichprobentestwerte gelten global für jeden Stichprobentest, es sei denn, sie werden durch die speziellen Werte eines bestimmten Stichprobentests in der Tabelle "Details" vorbelegt.
• Das Standardfeld im Abschnitt "In Verarbeitung" oder das gleichnamige Feld in der Tabelle "Details" muss für diese erforderlichen Felder ausgefüllt werden:
• Spez.
• AQL-Level
• Prüfebene
• Stichprobenrate
• Das Standardfeld im Abschnitt "In Verarbeitung" oder das gleichnamige Feld in der Tabelle "Details" kann für die Umschaltregel ausgefüllt werden.

Vorgehensweise zum Definieren ein Stichprobenplan

Gehen Sie folgendermaßen vor, um einen Stichprobenplan zu definieren:

1. Öffnen Sie die Seite Stichprobenplan. Die Seite "Stichprobenplan" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das Stichprobenplanobjekt in das Feld Stichprobenplan ein.
4. Geben Sie die Revision oder Version der Instanz in das Feld Revision ein. Die Anwendung verwendet den Namen und die Revision, um die Definition zu identifizieren.
5. Geben Sie die Stichprobenplan-Testdaten wie folgt in die Tabelle "Stichprobenplandetails" ein:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung öffnet das Popup "Hinzufügen".
b. Geben Sie den Stichprobentest, der dem Stichprobenplan hinzugefügt werden soll, in das Feld Umlaufbestandsdateneinrichtung ein. Der Stichprobentest wird über die Seite "Umlaufbestandsdateneinrichtung" erstellt. Weitere Informationen finden Sie unter "Definieren von Stichprobeninformationen für Umlaufbestandsdateneinrichtungsobjekte".
c. Geben Sie die Spezifikation, in der die Stichprobenprüfung stattfinden soll, in das Feld Spez. ein.
d. Geben Sie die AQL-Levels, auf denen die Stichprobenprüfung stattfinden soll, in das Feld AQL-Level ein.
e. Geben Sie die Prüfebene, auf der die Stichprobenprüfung stattfinden soll, in das Feld Prüfebene ein.
f. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. Weitere Informationen zu den optionalen Feldern finden Sie unter "Definitionen der optionalen Felder des Popups "Hinzufügen" für Stichprobenpläne".
g. Klicken Sie auf OK.
h. Wiederholen Sie die Schritte a bis g für jeden Stichprobenplan, den Sie hinzufügen möchten.
Hinweis: Die Werte der Felder im Popup "Hinzufügen" überschreiben die Werte für die entsprechenden Felder auf der Seite "Stichprobenplan". Das Feld Spez. im Popup "Hinzufügen" überschreibt z. B. den Wert für das Feld Spez. auf der Seite "Stichprobenplan".
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
