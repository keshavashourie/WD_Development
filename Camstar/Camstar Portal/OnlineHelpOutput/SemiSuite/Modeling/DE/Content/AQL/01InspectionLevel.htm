Definieren von Prüfebenen

Prüfebenen-Modellierungsobjekte legen Stichprobengrößencodes auf Grundlage einer minimalen und maximalen Container- oder Losgröße fest.

Standardmäßig verwendet die Anwendung die aktuelle Menge bei der Bestimmung der Stichprobengröße und erlaubten Ablehnungen. Wenn das Feld "Stichprobengröße basierend auf Startmenge" ausgewählt ist, verwendet die Anwendung für die Menge des Loses die Werte, die beim ursprünglichen Start des Loses für "Menge" und "Menge2" angegeben wurden. Die Anwendung verwendet den angegebenen Stichprobengrößencode, der durch die Prüfebene definiert wird, wenn die Menge eines Loses zwischen dem Minimum und Maximum ("Min. Menge" bzw. "Max. Menge) liegt, die für den Code angegeben wurden.

Das Modellierungsobjekt für AQL-Levels verwendet die Ablehnungsnummer und den Stichprobengrößencode, die im Prüfebenenobjekt definiert wurden, um die akzeptablen Qualitätslevels für ein Los zu definieren. Weitere Informationen zum Modellierungsobjekt für AQL-Levels und zur Ablehnungsnummer finden Sie unter "Definieren von AQL-Levels".

Vorgehensweise zum Definieren einer Prüfebene

Gehen Sie folgendermaßen vor, um eine Prüfebene zu definieren:

1. Öffnen Sie die Seite Prüfebene. Die Seite "Prüfebene" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Prüfebeneninstanz in das Feld Prüfebene ein, z. B. Ebene I oder Ebene II.
4. Geben Sie die Prüfebenendetails wie folgt in die Tabelle "Losgrößendetails" für jede Stichprobengröße ein, die Sie zum Prüfebenenobjekt hinzufügen möchten:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
b. Geben Sie die minimale Losmenge für den Stichprobengrößencode in die Spalte Min. Menge ein.
c. Geben Sie die maximale Losmenge für den Stichprobengrößencode in die Spalte Max. Menge ein.
d. Geben Sie einen Stichprobengrößencode ein, um die Stichprobengröße zu identifizieren, die der minimalen und maximalen Losmenge in der Spalte Stichprobengrößencode entspricht.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
