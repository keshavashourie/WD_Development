Zuweisen von Stichprobenplänen zu Produkten

Mit dem PN-Objekt können Sie einem Produkt einen Stichprobenplan zuweisen. Die beiden spezifischen Felder für AQL-Stichproben, "Stichprobenplan" und "100 %-Prüfung", weisen einen Stichprobenplan zu und zeigen an, ob alle Lose stichprobenartig getestet werden müssen.

Hinweis: Die Anwendung ignoriert die AQL-Stichprobenwerte des Objekts "PN", wenn eine Stichprobenplaneinrichtungsmatrix definiert ist.

Beim Definieren des PN-Objekts für AQL-Stichproben

Wenn das optionale Feld "100 %-Prüfung" aktiviert ist, muss das Feld "Stichprobenplan" ausgefüllt werden.

Stichproben-Felddefinitionen der Seite "PN"

Diese Tabelle definiert die relevanten Felder für AQL-Stichproben auf der Seite "PN". Informationen zu weiteren verfügbaren Feldern im PN-Modellierungsobjekt finden Sie unter "Definieren von PN- und Materialteilprodukten".

Feld

Definition

Typ

Stichprobenplan

Liste aller definierten Stichprobenpläne. Die Stichprobenpläne definieren die Prüfkriterien des Produkts, wie z. B. den benötigten Stichprobentest, die Anzahl der Stichproben, die Stichprobenrate, den Ort der Stichprobennahme und die zulässigen Ablehnungen für einen Container dieses Produkts. Wählen Sie den Stichprobenplan aus, den Sie dem Produkt zuweisen möchten. Weitere Informationen zu Stichprobenplänen finden Sie unter "Definieren von Stichprobenplänen".

Der Revisionsindikator wird im Bereich unter diesem Feld angezeigt, falls zutreffend. Das Kontrollkästchen gibt an, ob diese Revision die Standardrevision ist.

Hinweis: Dieses Feld ist erforderlich, wenn das Kontrollkästchen "Alle Container überprüfen" aktiviert ist.

Optional

100 %-Prüfung

Wenn dieses Feld ausgewählt ist, wird die Stichprobenrate auf 1 gesetzt, wodurch jedes Los dieses Produkts überprüft wird.

Diese Option wird in der Regel verwendet, wenn eine Produktion Qualitätsprobleme hat, um Verluste zu minimieren, oder um zu überprüfen, ob alles in Ordnung ist, wenn ein neues Produkt in Produktion geht.

Hinweis: Wenn dieses Kontrollkästchen aktiviert ist, wird ein Stichprobenplan benötigt.

Optional

Vorgehensweise zum Definieren eines PN-Modellierungsobjekts für AQL Sampling

Gehen Sie folgendermaßen vor, um ein PN-Modellierungsobjekt für AQL Sampling zu definieren:

1. Öffnen Sie die Seite PN. Die Seite "PN" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Stichprobenplan, der auf das Produkt angewendet werden soll, in das Feld Stichprobenplan ein.
4. Wählen Sie die Option 100 %-Prüfung aus, wenn Sie jedes Los prüfen möchten.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern. Informationen zu den verfügbaren Feldern finden Sie unter "Definieren von PN- und Materialteilprodukten".
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
