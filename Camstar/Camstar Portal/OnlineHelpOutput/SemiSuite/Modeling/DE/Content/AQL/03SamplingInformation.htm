Definieren von Stichprobeninformationen für Umlaufbestandsdateneinrichtungsobjekte

Im Abschnitt "Stichprobeninformationen" der Seite "Umlaufbestandsdateneinrichtung" können Sie Stichprobentests erstellen, die anschließend gruppiert werden, um Stichprobenpläne zu erstellen. Der Abschnitt "Stichprobeninformationen" der Seite "Umlaufbestandsdateneinrichtung" darf nur für AQL-Stichproben verwendet werden. Weitere Details zu anderen Abschnitten der Seite "Umlaufbestandsdateneinrichtung" finden Sie unter "Definieren von Umlaufbestandsdateneinrichtungsobjekten".

Stichprobentest-Typen

Es gibt zwei Typen von Stichprobentests: gezählte und gemessene Tests. Mit einem gezählten Stichprobentest können Sie die Anzahl von getesteten Stichproben und abgelehnten Stichproben aufzeichnen. Opcenter Execution Semiconductor verwendet die Summe aller aufgezeichneten Mengen dann als Gesamtzahl der Ablehnungen.

Mit einem gemessenen Stichprobentest können Sie einen oder mehrere Datenpunktwerte eingeben, die hinsichtlich bestimmter Limits ausgewertet werden. Wenn ein Stichprobendatenpunkt außerhalb der angegebenen Limits liegt, wird die Stichprobe abgelehnt. Je nach minimaler Stichprobenanforderung müssen Sie einen oder mehrere Stichprobendatenpunkte für gemessene Testtypen konfigurieren.

Stichprobenwerte für gezählte und gemessene Stichproben sammeln Sie über die Registerkarte "Stichproben" im Fenster "Hauptumlaufbestand". Informationen zum Sammeln von AQL-Stichprobenwerten finden Sie im Opcenter Execution Semiconductor Shop Floor-Benutzerhandbuch.

Verwalten von Stichproben und aufgezeichneten Ablehnungen

Semiconductor Shop Floor bietet zwei weitere Optionen für die Verwaltung von Stichproben und aufgezeichneten Ablehnungen: "Grund f. zerstörte Stichprobe" und "Standardgrund für Ausschussablehnungen". "Grund f. zerstörte Stichprobe" bewirkt, dass die Anwendung die Losgröße oder Wafermenge um die Stichprobenmenge reduziert. "Standardgrund für Ausschussablehnungen" bewirkt, dass die Anwendung die Losgröße oder Wafermenge nur um die Menge reduziert, die als defekt aufgezeichnet wurde. Die Anzahl der abgelehnten Stichproben wird nur anhand des in der Umlaufbestandsdateneinrichtung ausgewählten Standardgrunds für Ausschussablehnungen zu Ausschluss deklariert, wenn kein Wert für "Grund f. zerstörte Stichprobe" bereitgestellt wird.

Hinweis: Geben Sie keinen Wert für "Grund f. zerstörte Stichprobe" an, wenn Sie eine losbasierte Stichprobenprüfung in einem Elementschritt durchführen.

Sie können die Los- und Wafermengen um die Stichprobengröße verringern (wenn "Grund f. zerstörte Stichprobe" festgelegt ist), das Los um die Ablehnungsanzahl verringern (wenn "Standardgrund für Ausschussablehnungen" festgelegt ist) und bei einem Fehler automatisch ein Produktionsereignis für gezählte und gemessene Testtypen erstellen.

Wenn Ablehnungen in Ausschuss umgewandelt sollen, müssen Sie einen Verlustgrund aus dem Feld "Standardgrund für Ausschussablehnungen" auswählen. Die Stichprobe wird abgelehnt, falls einer der Werte außerhalb der definierten Limits für gemessene Stichproben liegt. Wenn Sie auf zerstörte Stichproben prüfen möchten, wählen Sie einen Grund im Feld "Grund f. zerstörte Stichprobe" aus.

Beim Definieren von Stichprobeninformationen

Beim Definieren von Stichprobeninformationen für Umlaufbestandsdateneinrichtungsobjekte gelten die folgenden Regeln:

• Sie können losbasierte Stichprobenprüfungen für Lose in Element-Verarbeitungsschritten und Nicht-Element-Verarbeitungsschritten durchführen.
• Waferbasierte Stichprobenprüfungen können Sie nur für Lose in Element-Verarbeitungsschritten durchführen.
• Sie müssen Stichprobenprüfungen in einem Nicht-Element-Verarbeitungsschritt durchführen, wenn Sie Ihre Losgrößen um die Stichprobenmenge oder die aufgezeichnete Anzahl von Ablehnungen verringern möchten.
• Sie müssen Stichprobenprüfungen in einem Element-Verarbeitungsschritt durchführen, wenn Sie die Menge jedes Wafers um die Stichprobenmenge oder die aufgezeichnete Anzahl von Ablehnungen verringern möchten.
• Sie können keine Stichprobenprüfung an Losen und Wafern im selben Schritt durchführen.

Diese Regeln werden nicht angewendet, wenn ein Stichprobentest aktualisiert wird, nachdem die Stichprobenanforderungen festgelegt und in das Los geschrieben wurden. Lose in Bearbeitung nehmen keine Revisionsaktualisierungen an, die Revisionen werden aber auf das nächste Los angewendet. Bei der Bestimmung der Stichprobengröße und der erlaubten Ablehnungen für einen Stichprobentest wird standardmäßig die aktuelle Menge des Loses verwendet. Sie können aber auch angeben, dass stattdessen die ursprüngliche Losmenge verwendet werden soll.

Felddefinitionen der Stichprobeninformationen

Diese Tabelle definiert die Felder im Abschnitt "Stichprobeninformationen" der Seite "Umlaufbestandsdateneinrichtung".

Feld

Definition

Typ

Stichprobentyp

Stichprobentest-Typ, der mit dem Stichprobenplan verknüpft werden soll.

Erforderlich

Abmelden bei Fehler erlauben

Wenn dieses Feld ausgewählt ist, kann das Los aus dem aktuellen Schritt verschoben werden, falls ein Stichprobentest abgelehnt wird.

Optional

Standardgrund für Ausschussablehnungen

Bei Eingabe eines Verlustgrundcodes in dieses Feld wird die Wafer- oder Losmenge um die Anzahl der Ablehnungen verringert, die diesen Verlustgrundcode verwenden.

Hinweis: Diese Einstellung wird überschrieben, wenn das Feld "Grund f. zerstörte Stichprobe" ausgefüllt ist.

Optional

Grund f. zerstörte Stichprobe

Bei Eingabe eines Verlustgrundcodes in dieses Feld wird die Wafer- oder Losmenge um die Gesamtmenge der Stichproben verringert, die diesen Verlustgrundcode verwenden.

Hinweis: Geben Sie keinen Wert für "Grund f. zerstörte Stichprobe" an, wenn Sie eine losbasierte Stichprobenprüfung in einem Elementschritt durchführen.

Hinweis: Diese Einstellung überschreibt den im Feld "Standardgrund für Ausschussablehnungen" festgelegten Wert.

Optional

Standardbeschreibung für Produktionsereignis

Beschreibt das Produktionsereignis, das vorliegt, wenn eine Stichprobe abgelehnt wird.

Hinweis: Alle Felder im Abschnitt "Produktionsereignis" sind erforderlich, wenn beim Nichtbestehen eines Tests ein Produktionsereignis erstellt werden soll.

Optional

Nutzerfelder

 

Standardfehlermodus

Liste aller Standardfehlermodi. Wenn Sie einen Standardfehlermodus auswählen, wird dieser verwendet, um ein Produktionsereignis zu erstellen, wenn eine Stichprobe abgelehnt wird.

Hinweis: Alle Felder im Abschnitt "Produktionsereignis" sind erforderlich, wenn beim Nichtbestehen eines Tests ein Produktionsereignis erstellt werden soll.

Optional

Klassifikation

Liste aller Klassifikationen. Wenn Sie eine Klassifikation auswählen, wird diese verwendet, um ein Produktionsereignis zu erstellen, wenn eine Stichprobe abgelehnt wird.

Hinweis: Alle Felder im Abschnitt "Produktionsereignis" sind erforderlich, wenn beim Nichtbestehen eines Tests ein Produktionsereignis erstellt werden soll.

Optional

Unterklassifikation

Liste aller Unterklassifikationen. Wenn Sie eine Standardunterklassifikation auswählen, wird diese verwendet, um ein Produktionsereignis zu erstellen, falls eine Stichprobe abgelehnt wird.

Hinweis: Alle Felder im Abschnitt "Produktionsereignis" sind erforderlich, wenn beim Nichtbestehen eines Tests ein Produktionsereignis erstellt werden soll.

Vorgehensweise zum Definieren von Stichprobeninformationen für Umlaufbestandsdateneinrichtungsobjekte

Gehen Sie folgendermaßen vor, um Stichprobeninformationen für Umlaufbestandsdateneinrichtungsobjekte zu definieren:

1. Öffnen Sie die Seite Umlaufbestandsdateneinrichtung. Die Seite "Umlaufbestandsdateneinrichtung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie die Informationen für das Umlaufbestandsdateneinrichtungsobjekt ein, wie in "Definieren von Umlaufbestandsdateneinrichtungsobjekten" beschrieben.
4. Geben Sie im Bereich Stichprobeninformationen den Stichprobentyp, der mit dem Stichprobenplan verknüpft werden soll, wie folgt in das Feld Stichprobentyp ein:

Wählen Sie eines der folgenden Konten aus . . .

Um folgende Daten zu sammeln . . .

Gezählt

Anzahl der abgelehnten Stichproben.

Gemessen

Numerischer Wert für jeden Datenpunkt.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
