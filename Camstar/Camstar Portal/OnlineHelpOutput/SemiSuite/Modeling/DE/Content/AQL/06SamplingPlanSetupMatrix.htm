Definieren einer Stichprobenplaneinrichtungsmatrix

Die Matrixseite "Stichprobenplaneinrichtung" wird verwendet, um das einem bestimmten Produkt zugewiesene Stichprobenplanobjekt zu überschreiben. Unter "Informationen zu Matrixmodellierungsobjekten" oder "Matrixmodellierungsseiten" finden Sie allgemeine Informationen zu Matrixobjekten. Unter "Verwalten von Instanzen" finden Sie weitere Informationen zum Verwalten von Matrixobjektinstanzen.

Stichprobenplaneinrichtung: Name

Eindeutiger Name für die Matrixinstanz. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld automatisch aus, wenn Sie die Instanz speichern.

Erforderlich

Stichprobenplan

Stichprobenplanobjekt, das auf das Los angewendet werden soll. Bei Auswahl dieser Option sind die Stichprobenplandaten im Umlaufbestand für Lose erforderlich, die den definierten Kriterien entsprechen.

Der Revisionsindikator wird im Bereich unter diesem Feld angezeigt, falls zutreffend. Das Kontrollkästchen gibt an, ob diese Revision die Standardrevision ist.

Hinweis: Sie müssen eine Spezifikation für jeden Stichprobentest im Abschnitt "Stichprobenplandetails" auswählen, wenn keine Standardspezifikation ausgewählt ist.

Erforderlich

Vorgehensweise zum Definieren einer Stichprobenplaneinrichtungsmatrix-Instanz

Gehen Sie folgendermaßen vor, um eine Stichprobenplaneinrichtungsmatrix-Instanz zu definieren:

1. Öffnen Sie die Seite Stichprobenplaneinrichtung. Die Anwendung zeigt die Seite "Stichprobenplaneinrichtung" an.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz" finden Sie weitere Informationen.
3. Geben Sie einen Namen für die Stichprobenplaneinrichtungsmatrix-Instanz in das Feld Stichprobenplaneinrichtung: Name ein. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld beim Speichern der Instanz automatisch aus.
4. Geben Sie das Stichprobenplanobjekt, das auf das Los angewendet werden soll, in das Feld Stichprobenplan ein. Bei Auswahl dieser Option sind die Stichprobenplandaten im Umlaufbestand für Lose erforderlich, die den definierten Kriterien entsprechen. Geben Sie die Revision in den Bereich unter diesem Feld ein, falls zutreffend. Klicken Sie auf das Kontrollkästchen, wenn das Objekt die Standardrevision verwenden soll.
Hinweis: Sie müssen eine Spezifikation für jeden Stichprobentest im Abschnitt "Stichprobenplandetails" auswählen, wenn keine Standardspezifikation ausgewählt ist.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
