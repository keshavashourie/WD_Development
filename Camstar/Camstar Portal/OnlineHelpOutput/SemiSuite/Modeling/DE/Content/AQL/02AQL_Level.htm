Definieren von AQL-Levels

Mit der Seite "AQL-Level" können Sie erlaubte Qualitätslevels definieren, indem Sie einem Stichprobengrößencode eine Stichprobengröße und eine Ablehnungsmenge zuweisen. Die Stichprobengrößencodes der AQL-Levels müssen mit den Codes übereinstimmen, die von den Prüfebenenobjekten definiert werden. Weitere Informationen zum Festlegen von Stichprobengrößencodes in Prüfebenenobjekten finden Sie unter "Definieren von Prüfebenen".

Hinweis: Die Mengen gelten für Wafer (Menge2 des Containers), wenn sich ein Los in einem Waferverarbeitungsschritt befindet ("Ist Elementverarbeitung" ist in der Spezifikation ausgewählt).
Hinweis: Die Anwendung ignoriert die Ablehnungsmenge (Feld "Ablehnungsnummer") beim Erstellen eines AQL-Levels für die Waferauswahl, da der Hauptzweck darin besteht, die Anzahl der Wafer für die Stichprobennahme innerhalb des Loses zu identifizieren.

Beim Definieren von AQL-Levels

Beim Modellieren von Modellierungsobjekten für AQL-Levels gelten folgende Regeln:

• Die Seite "AQL-Level" muss mindestens ein Element in der Tabelle "Details" enthalten, wenn das AQL-Level modelliert wird.
• Die Stichprobengrößencodes für das AQL-Level müssen mit den Stichprobengrößencodes übereinstimmen, die durch die Prüfebeneninstanzen definiert werden. Weitere Informationen finden Sie unter "Definieren von Prüfebenen".

Vorgehensweise zum Definieren eines AQL-Levels

Gehen Sie folgendermaßen vor, um ein AQL-Level zu definieren:

1. Öffnen Sie die Seite AQL-Level. Die Seite "AQL-Level" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das AQL-Levelobjekt in das Feld AQL-Level ein, z. B. AQL0.25 oder AQL1.5.
4. Geben Sie die AQL-Leveldetails wie folgt in die Tabelle "Stichprobengrößendetails" ein:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
b. Geben Sie den Stichprobengrößencode dieses AQL-Levels in die Spalte Stichprobengrößencode ein.
c. Geben Sie die erforderliche Stichprobengröße für den Stichprobengrößencode in die Spalte Stichprobengröße ein. Die Stichprobengröße muss mit der Anzahl der Datensammlungspunkte übereinstimmen, die in der Tabelle "Details" des Umlaufbestandsdaten-Einrichtungsobjekts definiert sind. Weitere Informationen zur Tabelle "Details" finden Sie unter "Definieren von Umlaufbestandsdateneinrichtungsobjekten".
d. Geben Sie die maximal erlaubte Ablehnungsmenge für die definierte Stichprobengröße in die Spalte Ablehnungsnummer ein. Die Anwendung lehnt Lose ab, deren Defektzahl über diesem Wert liegt.
Hinweis: Die Anwendung ignoriert diesen Wert, wenn das AQL-Level im Waferauswahlprozess verwendet wird.
e. Wiederholen Sie die Schritte a bis d für jedes AQL-Level, das Sie hinzufügen möchten.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
