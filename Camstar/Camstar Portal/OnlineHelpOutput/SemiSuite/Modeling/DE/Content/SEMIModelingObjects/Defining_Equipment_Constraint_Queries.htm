Definieren von Ausrüstungszwangsabfragen

Die Seite "Ausrüstungszwangsabfrage" ermöglicht Ihnen die Definition einer Abfrage, die die Einschränkungen einer Ausrüstungszwangsmatrix erweitert. Sie möchten z. B. einen Zwangswert hinzufügen, der nur von einer Abfrage ermittelt werden kann. Sie erstellen die Abfrage mithilfe der Seite "Ausrüstungszwangsabfrage" und fügen anschließend die Abfrage zur Matrix hinzu.

Felddefinitionen der Seite "Ausrüstungszwangsabfrage"

Diese Tabelle definiert die Felder auf der Seite "Ausrüstungszwangsabfrage".

Feld

Definition

Typ

Ergebnisspaltenname

Abfragespalte, aus der ein Wert in die Einschränkungslogik zurückgegeben wird.

Erforderlich

Abfragetext

SQL-Abfrage-Anweisung. Die Standardbegrenzung für dieses Feld beträgt 4.000 Zeichen. Diese Begrenzung kann in Designer angepasst werden. Weitere Informationen finden Sie im Opcenter Execution Core Designer-Benutzerhandbuch.

Erforderlich

Tabelle "Parameter"

Enthält die für die Abfrage konfigurierten Parameter.

Optional

Name für Benutzerabfrageparameter

Eindeutiger Name für diesen Parameter in diesem Satz von Abfrageparametern.

Hinweis: Dies ist ein erforderliches Feld, wenn ein Parameter hinzugefügt wird.

Optional

Datentyp

Feldliste zum Auswählen des Typs der Daten für diesen Parameter, z. B. "Dezimal", "Zeichenkette" und "Gleitkomma".

Hinweis: Dies ist ein erforderliches Feld, wenn ein Parameter hinzugefügt wird.

Optional

Text anzeigen

Wird dem Benutzer in der Eingabeaufforderung angezeigt, damit er Parameterwerte eingibt.

Optional

Parameterwert

Zeichenkettenwert, der den Wert des Parameters darstellt, der vor der Ausführung an die Abfrage weitergeleitet wird.

Optional

Dynamischer Wert

Wenn kein Parameterwert angegeben ist, wird der dynamische Wert aufgelöst und als Parameterwert verwendet.

Optional

Ist erforderlich

Gibt an, ob dieser Parameter beim Ausführen der Abfrage angegeben werden muss.

Optional

Für Blockzeilen verwenden

Es kann nur ein Parameter für "Für Blockzeilen verwenden" festgelegt werden. Mit diesem Flag beschränkt die Anwendung den Abfrageinhalt. Nicht erforderlich für die Einrichtung der PM-Anforderungsabfrage.

Optional

Nutzerfelder

Größenlimit für Ergebnismenge

Maximale Anzahl der Zeilen, die von der Abfrage zurückgegeben werden.

Erforderlich

Vorgehensweise zum Definieren einer Ausrüstungszwangsabfrage

Gehen Sie folgendermaßen vor, um eine Ausrüstungszwangsabfrage zu definieren:

1. Öffnen Sie die Seite Ausrüstungszwangsabfrage. Die Seite "Ausrüstungszwangsabfrage" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Ausrüstungszwangsabfrage den Namen der Ausrüstungszwangsabfrage ein.
4. Geben Sie in das Feld Abfragetext den Text der SQL-Abfrageanweisung ein.
5. Gehen Sie folgendermaßen vor, um die einzelnen Parameter der Tabelle "Parameter" hinzuzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
b. Geben Sie den Namen für Benutzerabfrageparameter ein.
c. Geben Sie den Datentyp ein.
d. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Ändern Sie den Standardwert im Feld Größenlimit für Ergebnismenge oder lassen Sie den vorhandenen Standardwert unverändert.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Testen der Abfrage

Gehen Sie folgendermaßen vor, um die Definition einer Ausrüstungszwangsabfrage zu testen:

1. Führen Sie die Schritte im Abschnitt "Vorgehensweise zum Definieren einer Ausrüstungszwangsabfrage" aus.

Oder

Wählen Sie eine vorhandene Instanz der Ausrüstungszwangsabfrage aus.

2. Klicken Sie auf Abfrage speichern und testen, um die Abfrage zu speichern und zu testen. Die Anwendung öffnet ein Popup für den Test.
3. Geben Sie alle Parameter ein, die die Abfrage erfordert.
4. Klicken Sie auf Abfrage testen. Alle Ergebnisse, die mit der Abfrage und den eingegebenen Parametern übereinstimmen, werden in der Tabelle "Abfrageergebnisse" angezeigt.
5. Klicken Sie auf Schließen. Das Popup wird geschlossen.
