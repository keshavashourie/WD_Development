Definieren von Serviceeinrichtungen

Serviceeinrichtung ermöglicht es Ihnen, zusätzliche Logik für eine vorhandene Transaktion zu konfigurieren. Der Name der Einrichtung muss mit dem Namen der vorhandenen Transaktion übereinstimmen. Zum Beispiel muss die LotStart-Serviceeinrichtung den Namen "LotStart" haben.

Felddefinitionen der Seite "Serviceeinrichtung"

Diese Tabelle definiert die Felder, die nur auf der Seite "Serviceeinrichtung" zu finden sind.

Feld

Definition

Typ

Los-ID-Regel (Nummerierungsregel)

Regel, die bestimmt, wie eine neue Los-ID benannt wird, wenn der Benutzer keinen Namen eingibt.

Optional

Anmeldungs-Mitarbeitergruppe verifizieren

Gibt an, ob die Anmeldungs-Mitarbeitergruppe verifiziert werden soll, die dem Anmeldebenutzerkonto zugewiesen ist.

Optional

Mitarbeiter/Benutzer-Logik

Legt fest, ob und wie der Mitarbeiter in Bezug auf den Benutzer überprüft wird, der einen Service nutzt.

Optional

Abfragentabelle

Abfragen, die der Service verwendet, um Listenfelder auszufüllen.

Optional

Onlineabfrage: Einrichtung

Name der "Onlineabfrage: Einrichtung"-Instanz, die die auszuführende Abfrage enthält.

Erforderlich

Abfragetyp

Typ der Ausgabe, die von der Abfrage erstellt wird, z. B. Los, Behälter oder Ausrüstung.

Erforderlich

Tabelle "Geschäftsregeln"

Geschäftsregeln, die der Service auf einer ereignisgesteuerten Basis verwendet.

Optional

Ereignisname

Name des Ereignisses, das die Ausführung der Geschäftsregel auslöst.

Erforderlich

Geschäftsregel

Name der "Geschäftsregel"-Instanz, die ausgeführt werden soll, wenn das auslösende Ereignis auftritt.

Erforderlich

Serviceregeln

Name der "Serviceregeln"-Instanz, die für den Service ausgeführt werden soll.

Optional

Vorgehensweise zum Definieren einer Serviceeinrichtung

Gehen Sie folgendermaßen vor, um eine Serviceeinrichtung zu definieren:

1. Öffnen Sie die Seite Serviceeinrichtung. Die Seite "Serviceeinrichtung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen des Service in das Feld Serviceeinrichtung ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
