Definieren von SM-Feederbanken

Eine Feederbank kann mehrere Feeder mit Verbrauchsmaterial enthalten. Eine Feederbank enthält einen physischen Slot für jeden Feeder, für den sie Platz bietet. Mithilfe von Feederbanken kann mindestens ein Feeder geladen werden, bevor die Maschine, für die das Verbrauchsmaterial vorgesehen ist, verfügbar wird.

Vorgehensweise zum Definieren einer SM-Feederbank

Gehen Sie folgendermaßen vor, um eine SM-Feederbank zu definieren:

1. Öffnen Sie die Seite SM-Feederbank. Die Seite "SM-Feederbank" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Feeder einen Namen für die Feederbank ein.
4. Wählen Sie die Feederfamilie über das Feld Ressourcenfamilie aus, wenn die Feederbank zu einer Feederfamilie gehört.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
