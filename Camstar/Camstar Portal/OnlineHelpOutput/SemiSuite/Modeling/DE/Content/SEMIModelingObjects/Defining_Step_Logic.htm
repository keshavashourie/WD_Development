Definieren von Schrittlogik

Schrittlogik ist eine optionale Umlaufbestandsverarbeitung, auf die Geschäftsregeln angewendet werden können. Schrittlogik wird auf Spezifikationsebene zugewiesen. Opcenter Execution Semiconductor umfasst die folgenden Standard-Schrittlogikinstanzen:

• INPROCESSSPLIT: Wird verwendet, um einen Teil eines Loses während der Umlaufbestandsverarbeitung in ein vordefiniertes "Zu Los" aufzuteilen.
• LOTSIZESAMPLING: Wird verwendet, um Stichproben auszuwerten, die nicht AQL-bezogen sind.
• PACKING: Wird verwendet, um Schachtelmengen für ein Los festzulegen.
• SORTING: Wird verwendet, um den Gütegrad von Wafern oder Elementen eines Loses in der Umlaufbestandsverarbeitung zu bestimmen. Nur für elementbasierte Schritte.
• SORTIQC: Wird verwendet, um eingehende Wafer oder Elemente eines Loses in der Umlaufbestandsverarbeitung zu prüfen.
• SORTSQA: Wird verwendet, um ausgehende Wafer oder Elemente eines Loses in der Umlaufbestandsverarbeitung zu prüfen.
Hinweis: Zwei Standardinstanzen erfordern, dass eine Matrix konfiguriert wird. Weitere Informationen finden Sie unter "Definieren einer Losgrößenstichprobenmatrix" und "Definieren einer Verpackungsmengenmatrix".

Über die Modellierungsseite "Schrittlogik" können Sie Standardinstanzen einer Schrittlogik ändern und neue Instanzen erstellen.

Definieren von Schrittlogik

Die Seite "Schrittlogik" enthält die folgenden Kontrollkästchen, von denen jedes einen Verarbeitungspunkt eines Hauptumlaufbestands darstellt.

• Verteilung ausführen
• Einsetzungsdetails festlegen (Dieses Kontrollkästchen muss aktiviert sein, damit Losgrößenstichproben funktionieren.)
• Umlaufbestandsdaten verifizieren
• "Einsetzung abschließen" verifizieren
• Einbringen verifizieren
• Ausbringen verifizieren
• Abmelden verifizieren

Direkt unter jedem der oben aufgeführten Kontrollkästchen befindet sich ein entsprechendes Feld, um eine Geschäftsregel auszuwählen. Die erforderlichen Geschäftsregeln müssen bereits erstellt worden sein.

Wichtig: Es gibt ein zusätzliches Kontrollkästchen mit der Bezeichnung "Geschäftsregel verwenden". Dieses Kontrollkästchen muss aktiviert sein, damit die Anwendung eine ausgewählte Geschäftsregel verarbeiten kann.

Vorgehensweise zum Definieren von neuer Schrittlogik

Gehen Sie folgendermaßen vor, um eine Schrittlogik zu definieren:

1. Öffnen Sie die Seite Schrittlogik. Die Seite "Schrittlogik" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie im Feld Schrittlogik einen Namen für die Schrittlogik ein.
4. Entsprechend den Anforderungen Ihres Unternehmens:
a. Aktivieren Sie jedes Kontrollkästchen, das einen Punkt darstellt, an dem Sie eine Geschäftsregel ausführen möchten.
b. Wählen Sie für jedes aktivierte Kontrollkästchen eine Geschäftsregel aus, wenn Sie möchten, dass für diesen Punkt eine Regel ausgeführt wird.
5. Aktivieren Sie das Kontrollkästchen Geschäftsregel verwenden, wenn Sie möchten, dass die von Ihnen ausgewählten Geschäftsregeln während der Verarbeitung angewendet werden.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
Wichtig: Eine Schrittlogik muss einer Spezifikation zugewiesen sein, damit sie wirksam wird.

Vorgehensweise zum Aktualisieren einer Standardinstanz für Schrittlogik

Gehen Sie folgendermaßen vor, um eine Standardinstanz für Schrittlogik zu aktualisieren:

1. Wählen Sie Schrittlogik in der Liste der Modellierungsobjekte aus. Eine Liste der Schrittlogikinstanzen und eine leere "Schrittlogik"-Seite werden auf der Seite "Modellierung" angezeigt.
2. Wählen Sie die Instanz aus, die aktualisiert werden soll. Die ausgewählte Instanz wird auf der Seite "Modellierung" angezeigt.
3. Entsprechend den Anforderungen Ihres Unternehmens:
a. Aktivieren Sie jedes Kontrollkästchen, das einen Punkt darstellt, an dem Sie eine Geschäftsregel ausführen möchten.
b. Wählen Sie für jedes aktivierte Kontrollkästchen eine Geschäftsregel aus, wenn Sie möchten, dass für diesen Punkt eine Regel ausgeführt wird.
4. Aktivieren Sie das Kontrollkästchen Geschäftsregel verwenden, wenn Sie möchten, dass die von Ihnen ausgewählten Geschäftsregeln während der Verarbeitung angewendet werden.
5. Gewährleisten Sie, dass das Kontrollkästchen Einsetzungsdetails festlegen aktiviert ist, wenn Sie die standardmäßige LOTSIZESAMPLING-Instanz aktualisieren.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
