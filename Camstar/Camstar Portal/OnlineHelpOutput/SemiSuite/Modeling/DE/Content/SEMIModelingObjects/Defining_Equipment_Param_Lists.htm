Definieren von Ausrüstungsparameterlisten

Ausrüstungsparameter bieten Details dazu, wie Ausrüstung eingerichtet wird. Beispiel: Eine Ressource kann ein bestimmtes Rezept erfordern oder muss möglicherweise auf eine bestimmte Temperatur festgelegt werden, bevor es für die Losverarbeitung verwendet wird. Auf der Seite "Ausrüstungsparameterliste" können Sie eine Reihe von Parametern definieren. Sie können eine Liste mit definierten Parametern einer oder mehreren Ressourcen zuweisen. Die Anwendung zeigt den Parameter bei der Ressourceneinrichtung an.

Vor dem Definieren von Ausrüstungsparameterlisten

Alle Parameter, die für eine Ausrüstungsparameterliste ausgewählt werden, müssen zunächst definiert werden. Weitere Informationen finden Sie unter "Definieren von Parameternamen".

Vorgehensweise zum Definieren einer Ausrüstungsparameterliste

Gehen Sie folgendermaßen vor, um eine Ausrüstungsparameterliste zu definieren:

1. Öffnen Sie die Seite Ausrüstungsparameterliste. Die Seite "Ausrüstungsparameterliste" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie im Feld Ausrüstungsparameterliste einen Namen für die Ausrüstungsparameterliste ein.
4. Fügen Sie wie folgt der Tabelle "Details" Parameter zu:
a. Klicken Sie in der Tabelle auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
b. Wählen Sie ein Parameterobjekt aus.
c. Wählen Sie einen Parameternamen aus.
d. Wiederholen Sie die Schritte 2 bis 4, um weitere Parameter hinzuzufügen.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Zuweisen einer Ausrüstungsparameterliste zu einer Ressource

Gehen Sie folgendermaßen vor, um einer Ressource eine Ausrüstungsparameterliste zuzuweisen:

1. Öffnen Sie für die Ressource die Seite "Modellierung".
2. Erweitern Sie den Bereich Prozessdaten. Die Felder "Prozessdaten" werden angezeigt.
3. Wählen Sie im Feld Parameterliste die Ausrüstungsparameterliste aus.
4. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
