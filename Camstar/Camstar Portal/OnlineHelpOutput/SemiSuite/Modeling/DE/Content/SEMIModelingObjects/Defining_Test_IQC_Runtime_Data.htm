Definieren von Laufzeitdaten für Test IQC

Die Transaktion "Los empfangen" verwendet Laufzeitdaten für Test IQC, um Lose für Test IQC auszuwählen.

Felddefinitionen der Seite "Test IQC: Laufzeitdaten"

Diese Tabelle definiert die Felder auf der Seite "Test IQC: Laufzeitdaten".

Testmengentyp

Bestimmt die zu testende Menge. Gültige Werte sind:

• % – Der Prozentsatz von "Testmengenwert" wird verwendet, um die erforderliche Menge zum Testen anzugeben.
• Einheiten – Der Wert von "Testmengenwert" wird verwendet, um die erforderliche Menge zum Testen anzugeben.

Optional

Testmengenwert

Wert, der zusammen mit dem Testmengentyp verwendet wird, um die erforderliche Menge zum Testen anzugeben. Der Wert "0" bedeutet 100 %.

Hinweis: Der Wert gibt dem Benutzer nur die zu testende Menge an. Er löst keine automatische Logik aus.

Optional

Testtyp

Gibt den Typ und die Häufigkeit des Tests an. Gültige Werte sind:

1 – Jedes Los. Jedes empfangene Los muss getestet werden.

2 – Nach Pakettyp und Versandnummer. Der Pakettyp und die Versandnummer jedes empfangenen Loses werden zum Prüfen für Tests bis zu dem jeweils angegebenen maximalen Wert verwendet.

3 – Nach Monat und Pakettyp. Der Pakettyp und der Kalendermonat, in dem ein Los empfangen wird, werden zum Prüfen für Tests bis zu dem jeweils angegebenen maximalen Wert verwendet.

Optional

Vorgehensweise zum Definieren von Laufzeitdaten von Test IQC

Gehen Sie folgendermaßen vor, um Laufzeitdaten von Test IQC zu definieren:

1. Öffnen Sie die Seite Test IQC: Laufzeitdaten. Die Seite "Test IQC: Laufzeitdaten" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie im Feld Test IQC: Laufzeitdaten einen Namen für die Instanz der Laufzeitdaten von Test IQC ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
