Definieren von Materialtypen

Ein Materialtyp dient zum Unterscheiden der Typen von Materialteilen oder -produkten, die als Materialien für ein Los verwendet werden, und zum Festlegen, wie diese Materialien verbraucht werden. Jeder Materialtyp kann mindestens eine Spezifikation angeben, wo das Material verbraucht werden soll.

Felddefinitionen der Seite "Materialtyp"

Diese Tabelle definiert die Felder auf der Seite "Materialtyp".

Feld

Definition

Typ

Details

Verbrauchstyp (Elementverarbeitung)

Gibt an, wie die Materialien verbraucht werden. Gültige Werte sind:

• Menge – Materialien werden anhand des Werts "Menge" verbraucht. Dies ist die Standardeinstellung.
• Menge2 – Materialien werden anhand des Werts "Menge2" verbraucht.

Optional

Verbrauchsmenge

Gibt an, ob die Menge des Materialloses beim Verbrauchen des Materials reduziert werden soll.

Optional

Serie

Gibt an, ob ein Materiallos in der Anwendung gestartet werden muss, damit es von einem Produktionslos verbraucht werden kann.

Optional

Verweis auf Attributnummer

ID für den Materialtyp.

Optional

Attribut zum Anpassen an Batch

Feld mit Losattributen, anhand dessen das Material während des Einbringens verglichen wird. Sofern angegeben, wird das entsprechende Feld "Losattribute" für den Vergleich mit dem Materiallosnamen verwendet. Wenn im Feld "Losattribute" null angegeben ist, überspringt die Anwendung die Verifizierung.

Optional

Tabelle "Verbrauchsspez."

Tabelle mit einer Liste der Spezifikationen (Schritte), wo sich das Hauptproduktionslos befinden muss, um das Material zu verwenden.

Optional

Spez.

Umlaufbestandsspezifikation, die angibt, wo die Verarbeitung stattfindet.

Optional

Tabelle "Anbieter"

Tabelle mit einer Liste der Anbieter für den Materialtyp.

Optional

Anbieter

Anbieter des Materials. Sofern angegeben, verifiziert die Anwendung die Angabe anhand des in der Ausrüstung geladenen Materialanbieters.

Optional

Vorgehensweise zum Definieren eines Materialtyps

Gehen Sie folgendermaßen vor, um einen Materialtyp zu definieren:

1. Öffnen Sie die Seite Materialtyp. Die Seite "Materialtyp" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen des Materialtyps in das Feld Materialtyp ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
