Definieren von SM-Feederbankgruppen

Eine Feederbankgruppe dient zum Gruppieren einzelner Feederbanken.

Definieren von SM-Feederbankgruppen

Sie müssen vor dem Definieren der Gruppe zunächst die Feederbanken definieren, die Teil der Feederbankgruppe sein werden.

Felddefinitionen der Seite "SM-Feederbankgruppe"

Diese Tabelle definiert die Felder auf der Seite "SM-Feederbankgruppe".

Feld

Definition

Typ

Eintragstyp

Von der Anwendung generierter Wert.

Nur Anzeige

Tabelle "Einträge"

Liste der Feederbanken, die dieser Gruppe hinzugefügt werden sollen.

Optional

Tabelle "Gruppen"

Liste anderer Feederbankgruppen, die als Untergruppen hinzugefügt werden sollen.

Optional

In Bearbeitung-Statusänderung erlauben

Kontrollkästchen, das Sie aktivieren müssen, wenn Sie "In Bearbeitung"-Statusänderungen für Feederbanken innerhalb der Gruppe erlauben möchten. Die "In Bearbeitung"-Statusänderung bezieht sich auf den Status einer Ressource, die derzeit ein Los verarbeitet.

Hinweis: Informationen zum Festlegen von "In Bearbeitung"-Statusänderungen auf Ausrüstungsebene finden Sie unter Definieren von Ausrüstung. Informationen zum Einrichten der "In Bearbeitung"-Statusänderung auf Gruppenebene finden Sie unter "Definieren von Ausrüstungsgruppen".

Optional

Vorgehensweise zum Definieren einer SM-Feederbankgruppe

Gehen Sie folgendermaßen vor, um eine SM-Feederbankgruppe zu definieren:

1. Öffnen Sie die Seite SM-Feederbankgruppe. Die Seite "SM-Feederbankgruppe" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Feederbankgruppe einen eindeutigen Namen für die Feederbankgruppe ein.
4. Gehen Sie folgendermaßen vor, um Feederbanken zur Tabelle "Einträge" hinzuzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen. In der Tabelle "Einträge" wird ein Auswahlfeld aktiviert.
b. Wählen Sie in der Tabelle "Einträge" aus der Liste der Felder eine Feederbank aus.
c. Wiederholen Sie die Schritte a bis b für jede Feederbank, die Sie der Gruppe hinzufügen möchten.
5. Gehen Sie folgendermaßen vor, um der Tabelle "Gruppen" Feederbankuntergruppen hinzuzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen. In der Tabelle "Gruppen" wird ein Auswahlfeld aktiviert.
b. Wählen Sie in der Tabelle "Gruppen" aus der Liste der Felder eine Feederbankgruppe aus.
c. Wiederholen Sie die Schritte a bis b für jede Feederbankgruppe, die Sie als Untergruppe hinzufügen möchten.
6. Klicken Sie auf Aufgelöste Einträge. Die Anwendung zeigt ein Popup mit einer Liste aller Feederbanken in der Gruppe an.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
