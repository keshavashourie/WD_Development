Definieren von ergänzenden Spezifikationen

Das Objekt "Ergänz. Spez." ist eine Unterklasse des Objekts "Prozessspez.". Es gibt einen Arbeitsplan und optionale schrittspezifische Details an und hat einen Zeitplantyp. Eine ergänzende Spezifikation, die einem Los zugewiesen ist, stellt weitere Verarbeitungsoptionen zusätzlich zu denen der Prozessspezifikation bereit.

Losplaner weisen einem Los eine ergänzende Spezifikation zu, indem sie diese einer der beiden Tabellen für ergänzende Spezifikationen auf der Seite "Loszeitplan" oder auf der Seite "Loszeitplan ändern" hinzufügen. Der Zeitplantyp der ergänzenden Spezifikation muss mit dem Zeitplantyp der Prozessspezifikation für das Los identisch sein.

Vor dem Definieren einer ergänzenden Spezifikation

"Arbeitsplan" ist ein erforderliches Feld für die Erstellung einer ergänzenden Spezifikation. Daher müssen Sie, wenn der erforderliche Arbeitsplan nicht vorhanden ist, diesen erstellen, bevor Sie die ergänzende Spezifikation erstellen.

Vorgehensweise zum Definieren einer ergänzenden Spezifikation

Gehen Sie folgendermaßen vor, um eine ergänzende Spezifikation zu definieren:

1. Wählen Sie Haupt im Menü Modellierung aus. In der Anwendung wird die Registerkarte "Haupt" angezeigt.
2. Suchen Sie die "Typ: Geplante Spez." in der Liste der Objekte und wählen Sie diese Spezifikation aus. Dabei steht Typ für den Bereich, auf den sich die Spezifikation bezieht. Klicken Sie z. B. für den Zusammenbaubereich auf Zusammenbau: Ergänz. Spez..
3. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
4. Geben Sie einen Namen für die neue Prozessspezifikation in das erste Dateneingabefeld ein.
5. Wählen Sie einen Status aus.
6. Wählen Sie einen Arbeitsplan aus.
7. Klicken Sie auf Alles erweitern, um weitere Felder anzuzeigen. Die reduzierten Bereiche werden zur vollständigen Ansicht erweitert.
8. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
9. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
