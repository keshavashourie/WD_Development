Definieren von Losüberwachungsanforderungen

Losüberwachungsanforderungen erzwingen die Datensammlung für Ressourcen, Ressourcengruppen, Operationen und Arbeitsbereiche basierend auf den Losverarbeitungszahlen. Diese Anforderungen können mit Optionen zum Festlegen von Toleranz- und Warnungsvorgaben (in Tagen) und von E-Mail-Verteilerlisten für ausstehende, fällige und überfällige Benachrichtigungen konfiguriert werden.

Vor dem Definieren von Losüberwachungsanforderungen

"Überwachungsgrund" ist ein erforderliches Feld auf der Seite "Losüberwachung". Gewährleisten Sie vor dem Definieren einer Losüberwachungsanforderung, dass der erforderliche Überwachungsgrund der Anwendung hinzugefügt wurde.

Felddefinitionen der Seite "Losüberwachung"

Diese Tabelle definiert die Felder auf der Seite "Losüberwachung".

Feld

Definition

Typ

Ablaufplanungsdetails

Überwachungsgrund

Der mit der Überwachungsanforderung verknüpfte Grund.

Erforderlich

Datensammlungsdefinition

Name der Datensammlung, die ausgeführt werden muss, wenn die Anforderung fällig wird.

Erforderlich

Count

Maximale Anzahl der Lose, die verarbeitet werden können, bevor die Losüberwachungsanforderung fällig und eine Fälligkeits-E-Mail gesendet wird. Eine Anzahl von 100 bedeutet z. B., dass 100 Lose verarbeitet werden können, bevor eine Fälligkeits-E-Mail gesendet wird.

Erforderlich

Warnungsanzahl

Betrag, der von der Anzahl subtrahiert wird, um das Warnlimit für das Senden einer E-Mail vom Typ "Ausstehend" zu bestimmen. Eine Anzahl von 100 und eine Warnungsanzahl von 5 bedeuten, dass eine E-Mail vom Typ "Ausstehend" nach 95 verarbeiteten Losen gesendet wird.

Optional

Toleranzanzahl

Betrag, der zur Anzahl addiert wird, um zu bestimmen, wann die E-Mail vom Typ "Überfällig" gesendet wird. Eine Anzahl von 100 und eine Toleranzanzahl von 10 bedeuten, dass eine E-Mail vom Typ "Überfällig" nach 110 verarbeiteten Losen gesendet wird.

Optional

Benachrichtigungen

Tabelle "Ausstehend - E-Mail-Empfänger"

In dieser Tabelle werden die Empfänger einer E-Mail angegeben, die bei einer ausstehenden Anforderung gesendet wird.

Optional

Ausstehend - E-Mail-Text

Der Text der E-Mail, die bei einer ausstehenden Anforderung gesendet wird. Sie müssen einen Text eingeben, wenn Sie im Feld "Ausstehend - E-Mail-Empfänger" eine Angabe machen. Es können Textvariablen verwendet werden.

Optional

Tabelle "Fällig - E-Mail-Empfänger"

In dieser Tabelle werden die Empfänger einer E-Mail angegeben, die gesendet wird, wenn die Anforderung fällig ist. Siehe das Feld Erster Termin in dieser Tabelle.

Optional

Fällig - E-Mail-Text

Der Text der E-Mail, die gesendet wird, wenn die Anforderung fällig ist (aber noch in der Toleranzfrist liegt). Sie müssen einen Text eingeben, wenn Sie im Feld "Fällig - E-Mail-Empfänger" eine Angabe machen. Es können Textvariablen verwendet werden.

Optional

Tabelle "Überfällig - E-Mail-Empfänger"

In dieser Tabelle werden die Empfänger einer E-Mail angegeben, die gesendet wird, wenn die Anforderung überfällig ist. Siehe das Feld "Toleranzfrist" in dieser Tabelle. Sie müssen einen Text eingeben, wenn Sie im Feld "Fällig - E-Mail-Empfänger" eine Angabe machen.

Optional

Überfällig - E-Mail-Text

Der Text der E-Mail, die gesendet wird, wenn die Anforderung überfällig ist. Sie müssen Text eingeben, wenn Sie im Feld "Überfällig - E-Mail-Empfänger" eine Angabe machen. Es können Textvariablen verwendet werden.

Optional

Vorgehensweise zum Definieren einer Losüberwachungsanforderung

Gehen Sie folgendermaßen vor, um eine Losüberwachungsanforderung zu definieren:

1. Öffnen Sie die Seite Losüberwachung. Die Seite "Losüberwachung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Anforderung in das Feld Losüberwachung ein.
4. Klicken Sie auf einen Überwachungsgrund.
5. Geben Sie in das Feld Datensammlungsdefinition den Namen der erforderlichen Datensammlung ein.
6. Geben Sie eine Anzahl ein.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
Hinweis: Überwachungsanforderungen werden für Ressourcen, Ressourcengruppen, Operationen und Arbeitsbereiche aktiviert, die die Fertigungsseite "Überwachungsaktivierung" verwenden.

Vorgehensweise zum Hinzufügen einer Benachrichtigung zu einer Losüberwachungsanforderung

Gehen Sie folgendermaßen vor, um eine Benachrichtigung zu einer Losüberwachungsanforderung hinzuzufügen:

1. Führen Sie die Schritte in "Vorgehensweise zum Definieren einer Losüberwachungsanforderung" durch.

Oder

Wählen Sie eine vorhandene Losüberwachungsinstanz aus.

2. Erweitern Sie den Abschnitt "Benachrichtigungen".
3. Klicken Sie in der Tabelle "Ausstehend - E-Mail-Empfänger", "Fällig - E-Mail-Empfänger" oder "Überfällig - E-Mail-Empfänger" auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
4. Geben Sie eine E-Mail-Benachrichtigung in die neu hinzugefügte Zeile ein. Die Benachrichtigung wird der Tabelle hinzugefügt.
5. Geben Sie den Text der E-Mail in das entsprechende Feld ein: Ausstehend - E-Mail-Text, Fällig - E-Mail-Text oder Überfällig - E-Mail-Text. Sie haben auch die Möglichkeit, Textvariablen zu verwenden.
6. Wiederholen Sie die Schritte 3 bis 5, um die Benachrichtigungen für weitere Empfänger einzurichten.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
