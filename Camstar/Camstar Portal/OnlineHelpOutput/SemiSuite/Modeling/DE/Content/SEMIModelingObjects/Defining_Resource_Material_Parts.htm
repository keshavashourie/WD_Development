Definieren von Ressourcenmaterialteilen

Ein Ressourcenmaterialteil ist ein Satz von Eigenschaften, einschließlich Nutzungslimit, Aufarbeitungslimit, Standzeitlimit und Ablaufinformationen, die für mindestens ein Teil verwendet werden.

So werden Ressourcenmaterialteile verwendet

Ein Ressourcenmaterialteil ist ein erforderliches Feld, wenn ein neues Teil mit der Transaktion "Teileerstellung" erstellt wird. Es können mehrere Teile mit demselben Ressourcenmaterialteil erstellt werden. Die Menge jedes erstellten Teils, für das dasselbe Ressourcenmaterialteil verwendet wird, wird zur Gesamtmenge des Ressourcenmaterialteils hinzugefügt. Jedes Teil wird durch die Wartungseigenschaften seines Ressourcenmaterialteils gesteuert.

Wichtig: Ein Ressourcenmaterialteil darf nicht mit einem Materialteil verwechselt werden, das ein Komponentenmaterial ist, z. B. Substrate, die für das Produkt bei der Fertigung verbraucht werden.

Anzahl der Wafer, die vom Materialteil verarbeitet wurden, nach denen eine E-Mail-Benachrichtigung ausgelöst wird, um die Empfänger vor dem Erreichen des Nutzungslimits für die Wafermenge zu warnen.

Warnlimit für Standzeit 2

Anzahl der Wafer, die vom Materialteil verarbeitet wurden, bevor eine E-Mail-Benachrichtigung zum Warnlimit für die Standzeit ausgelöst wird.

Vorgehensweise zum Definieren eines Ressourcenmaterialteils

Gehen Sie folgendermaßen vor, um ein Ressourcenmaterialteil zu definieren:

1. Öffnen Sie die Seite Ressourcenmaterialteil. Die Seite "Ressourcenmaterialteil" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen des Materialteils in das Feld Ressourcenmaterialteil ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
