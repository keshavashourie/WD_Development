Definieren von Waferbehältern

Sie definieren Waferbehälter-Modellierungsobjekte, um die Behälter (z. B. Kassetten, Tabletts usw.) anzugeben, in denen die Wafer während der Fertigungstransaktionen gelagert, transportiert und verarbeitet werden. Waferbehälterobjekte können mehrere Lose unterstützen.

Um die Anzahl der Slots für einen Waferbehälter anzugeben, müssen Sie zunächst ein "Waferbehälter: Familie"-Objekt definieren. Sie können dann beim Definieren des Waferbehälters die Waferbehälterfamilie angeben.

Sie müssen außerdem ein Waferbehälterobjekt angeben, um die Funktion für Zuweisen einer Slotzuordnung verwenden zu können. Die Funktion für Zuweisen einer Slotzuordnung ermöglicht Ihnen, bestimmte Wafer einer bestimmten Position (oder Slot) im Waferbehälter zuzuweisen. Informationen über "Waferbehälter: Familie"-Objekte finden Sie unter "Definieren von Waferbehälterfamilien". Informationen zur Funktion zum Zuweisen einer Slotzuordnung finden Sie im Opcenter Execution Semiconductor Shop Floor-Benutzerhandbuch.

Standort

Physischer Ort innerhalb einer Fabrik, z. B. ein Gang, Regalplatz oder Arbeitsbereich in der Fertigung, an dem sich der Waferbehälter befindet.

Waferbehälterfamilie, die die Anzahl der Slots definiert, die in Multislotbehältern verfügbar sind. Hersteller der Waferbehälterausrüstung.

Lieferantenseriennummer

Seriennummer des Lieferanten für die Ausrüstung.

Eltern-Behälter

Gruppe der Waferbehälter, zu der der Waferbehälter gehört. Wenn Sie eine Transaktion für einen Eltern-Behälter ausführen, wirkt sich die Transaktion alle seine Kind-Waferbehälter aus. Wenn Sie einen Eltern-Waferbehälter auswählen und das Waferbehälterobjekt speichern, zeigt die Anwendung Folgendes für den ausgewählten Eltern-Waferbehälter an:

• Den aktuellen Waferbehälter in der Tabelle "Kind-Behälter"
• Informationen über jeden Slot des Kind-Behälters in der Tabelle "Slotzuordnung"

Wartungsklasse

Wartungsklasseninstanz, in der die Wartungsanforderungen gruppiert sind. Wenn die Waferbehälterausrüstung z. B. einen bestimmten Typ von monatlicher Wartung erfordert, würden Sie die Wartungsklasse angeben, die zu dieser Anforderung gruppiert ist. So können Sie die Wartung für alle Waferbehälter, die der Wartungsklasse zugewiesen sind, gleichzeitig aktivieren.

Optional

Ressourcentyp

Kategorisiert den Waferbehälter nach Ausrüstungstyp.

Optional

Ressourcenstatusmodell

Steuert den Zustand, in den die Ressource aus ihrem aktuellen Zustand versetzt werden kann. Im E10-Zustandsmodell kann eine Ressource z. B. in den Zustand "Standby", "Produktiv", "Engineering" usw. versetzt werden.

Optional

Tabelle "Kind-Behälter"

Listet die Namen der Behälter- und Waferbehälterobjekte auf, für die dieser Waferbehälter als Eltern-Behälter angegeben ist. Die Anwendung füllt diese Tabelle, wenn Sie den Waferbehälter speichern.

Optional

Kind-Behälter

Die Namen der Behälter- und Waferbehälterobjekte, für die dieser Waferbehälter als Eltern-Behälter angegeben ist.

Optional

Tabelle "Slotzuordnung"

Ist dieser Waferbehälter ein Eltern-Behälter, füllt die Anwendung, wenn der Waferbehälter gespeichert wird, die Tabelle "Slotzuordnung" mit einer Zeile entsprechend der Anzahl der Slots, wie sie durch die Waferbehälterfamilie angegeben ist, die Sie für das Feld "Waferbehälter: Familie" ausgewählt haben.

Optional

Slotnummer

Durch das System generierte Slotnummer. Die Nummer (Anzahl) der Slots ist durch das "Waferbehälter: Familie"-Objekt definiert. Informationen über das Angeben der Anzahl der Slots für ein "Waferbehälter: Familie"-Objekt finden Sie unter "Definieren von Waferbehälterfamilien".

Anfangsstatus (festzulegender Null-Status)

Wartungsfehlerstatus

Vorgehensweise zum Definieren eines Waferbehälters

Gehen Sie folgendermaßen vor, um einen Waferbehälter zu definieren:

1. Öffnen Sie die Seite Waferbehälter. Die Seite "Waferbehälter" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen eindeutigen Namen für das Waferbehälterobjekt in das Feld Waferbehälter ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
