Definieren von Ressourcenstatuscodes

Ein Ressourcenstatuscode stellt eine Beschreibung der momentanen Verfügbarkeit einer Ressource bereit. Die Seite "Ressourcenstatuscode" ermöglicht es Ihnen, diese Codes hinzuzufügen und zu konfigurieren.

Felddefinitionen der Seite "Ressourcenstatuscode"

In dieser Tabelle sind die Felder definiert, die nur auf der Seite "Ressourcenstatuscode" zu finden sind.

Feld

Definition

Typ

Verfügbarkeit

Verfügbarkeit der Ressource, die dem Statuscode zugeordnet ist:

• Verfügbar
• Nicht verfügbar

Hinweis: Dieses Feld wird nur in der Konfiguration des Arbeitsbereichs "SM-EL Synergy" angezeigt.

Erforderlich

Statuscodeverhalten

Wird von Opcenter EX EL IoT und Opcenter EX EL MM verwendet, um einen Bericht über den Status einer Ressource zu erstellen. Dieses Feld hat die folgenden Optionen:

• Nicht festgelegt
• Vordefiniert
• Normal (Dies ist die Standardeinstellung.)
• Festkomma
• Künftig

Sie können den Wert nur dann auf "Vordefiniert" festlegen, wenn das Feld derzeit leer ist oder den Wert "Nicht gesetzt" enthält. Wenn das Statuscodeverhalten auf "Vordefiniert" festgelegt ist, können Sie die Informationen für den Ressourcenstatuscode nicht ändern. Sie können den Ressourcenstatuscode nur löschen, wenn das Statuscodeverhalten leer ist.

Hinweis: Dieses Feld wird nur in der Konfiguration des Arbeitsbereichs "SM-EL Synergy" angezeigt.

Optional

Ressourcenstatus

Status der Ressource, die dem Statuscode zugeordnet ist:

• Entwicklungszeit
• Ungeplante Zeit
• Produktive Zeit
• Geplante Ausfallzeit
• Bereitschaftszeit
• Ungeplante Ausfallzeit

Hinweis: Dieses Feld wird nur in der Konfiguration des Arbeitsbereichs "SM-EL Synergy" angezeigt.

Optional

Ressourcenstatusursachengruppe

Statusursachengruppe, die die gültigen Statusursachen für diesen Statuscode enthält.

Hinweis: Dieses Feld wird nur in der Konfiguration des Arbeitsbereichs "SM-EL Synergy" angezeigt.

Optional

Ist verfügbar

Kontrollkästchen, das aktiviert werden kann, um zu kennzeichnen, dass eine Ressource mit dem Statuscode für eine Losverarbeitung verfügbar ist.

Optional

Tabelle "Statusursachen"

Zeigt eine Liste der Ursachen an, die für den Statuscode konfiguriert sind. Sie können auf "Neue Zeile hinzufügen" in der Tabellensymbolleiste klicken, um eine Ursache hinzuzufügen.

Optional

Statusursachen

Zeigt die Ursachen an, die für diesen Ressourcenstatuscode konfiguriert sind. Diese Ursachen können ausgewählt werden, wenn ein Operator den Statuscode einer Ressource zuweist.

Optional

Vorgehensweise zum Definieren eines Ressourcenstatuscodes

Gehen Sie folgendermaßen vor, um einen Ressourcenstatuscode zu definieren:

1. Öffnen Sie die Seite Ressourcenstatuscode. Die Seite "Ressourcenstatuscode" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für den Code in das Feld Ressourcenstatuscode ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
