Definieren von Ausrüstungsgruppen

Eine Ausrüstungsgruppe dient zum Gruppieren einzelner Ausrüstungsressourcen. Es gibt fünf Typen von Ausrüstungsgruppen, die jeweils einer Fertigungsoperation entsprechen. Es gibt fünf Typen von Ausrüstungsgruppen:

• Zusammenbauausrüstung
• Backgrind-Ausrüstung
• Testausrüstung
• Waferausrüstung
• Wafersortierung: Ausrüstung

Definieren von Ausrüstungsgruppen

Sie müssen vor dem Definieren der Gruppe zunächst die Ausrüstung definieren, die Teil der Ausrüstungsgruppe sein wird.

"In Bearbeitung"-Statusänderung für Ausrüstungsgruppen

Eine "In Bearbeitung"-Statusänderung bezieht sich auf die Möglichkeit, den Ausrüstungsstatus unabhängig davon zu ändern, ob die Ausrüstung ein Los aktiv bearbeitet. Die "In Bearbeitung"-Statusänderung kann auf Ausrüstungsgruppenebene ausgewählt werden, indem Sie das Kontrollkästchen "In Bearbeitung-Statusänderung erlauben" auf der Seite "Ausrüstungsgruppe" aktivieren. Die folgenden Bedingungen müssen erfüllt sein, bevor eine Einstellung für die "In Bearbeitung"-Statusänderung auf Gruppenebene auf einzelne Ausrüstung angewendet wird:

• Alle Ausrüstungsgruppen, zu denen die Ausrüstung gehört, müssen die gleiche Einstellung für die "In Bearbeitung"-Statusänderung aufweisen.
• Alle Untergruppen innerhalb dieser Gruppen müssen die gleiche Einstellung wie die Elterngruppen aufweisen.
Hinweis: Informationen zum Festlegen von "In Bearbeitung"-Statusänderungen auf Ausrüstungsebene finden Sie unter "Definieren von Ausrüstung".

Felddefinitionen der Seite "Ausrüstungsablehnungen"

Diese Tabelle definiert die Felder auf der Seite "Ausrüstungsgruppe".

Feld

Definition

Typ

[Typ] Ausrüstungsgruppe

Eindeutiger Name für die Ausrüstungsgruppe.

Hinweis: Die Feldbeschriftung entspricht dem Typ der Ausrüstungsgruppe, die Sie im Menü ausgewählt haben, z. B. "Zusammenbauausrüstung: Gruppe".

Erforderlich

Eintragstyp

Wert, der von der Anwendung basierend auf dem Typ der im Menü ausgewählten Ausgangsgruppe generiert wurde, z. B. "Zusammenbauausrüstung".

Nur Anzeige

Tabelle "Einträge"

Liste der Ausrüstungsressourcen, die dieser Ausrüstungsgruppe hinzugefügt werden sollen.

Optional

Tabelle "Gruppen"

Liste anderer Ausrüstungsgruppen, die als Untergruppen hinzugefügt werden sollen.

Optional

In Bearbeitung-Statusänderung erlauben

Kontrollkästchen, das Sie aktivieren müssen, wenn Sie "In Bearbeitung"-Statusänderungen für Ausrüstung innerhalb der Gruppe erlauben möchten. Die "In Bearbeitung"-Statusänderung bezieht sich auf den Status der Ausrüstung, die derzeit ein Los verarbeitet.

Optional

Mehrstufiges Einbringen erlauben

Kontrollkästchen, das Sie aktivieren müssen, wenn Sie erlauben möchten, dass mehrere Schritte gleichzeitig eingebracht werden, wenn deren Anforderungen identisch sind. Das mehrstufige Einbringen ist zulässig, wenn die folgenden Anforderungen erfüllt sind:

• Gleiches Rezept
• Gleiche Maske
• Gleicher Werkzeugplan
• Gleiche Materialien erforderlich
• Gleiche Ausrüstungsparameter

Vorgehensweise zum Definieren einer Ausrüstungsgruppe

Gehen Sie folgendermaßen vor, um eine Ausrüstungsgruppe zu definieren:

1. Öffnen Sie die Seite Ausrüstungsgruppe für den Ausrüstungstyp, den Sie hinzufügen möchten. Die Seite "Ausrüstungsgruppe" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Ressourcengruppe einen Namen für die Ausrüstungsgruppe ein.
4. Gehen Sie folgendermaßen vor, um Ausrüstung zur Tabelle "Einträge" hinzuzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen.
b. Wählen Sie eine Ausrüstungsressource aus der Liste aus, die in der Tabelle angezeigt wird.
c. Wiederholen Sie die Schritte a bis b für jede Ausrüstungsressource, die Sie der Gruppe hinzufügen möchten.
5. Gehen Sie folgendermaßen vor, um Ausrüstungsuntergruppen zur Tabelle "Gruppen" hinzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen.
b. Wählen Sie eine Ausrüstungsgruppe aus der Liste aus, die in der Tabelle angezeigt wird.
c. Wiederholen Sie die Schritte a bis b für jede Ausrüstungsgruppe, die Sie als Untergruppe hinzufügen möchten.
6. Klicken Sie auf Aufgelöste Einträge. Die Anwendung zeigt ein Popup mit einer Liste der gesamten Ausrüstung in der Gruppe an.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
