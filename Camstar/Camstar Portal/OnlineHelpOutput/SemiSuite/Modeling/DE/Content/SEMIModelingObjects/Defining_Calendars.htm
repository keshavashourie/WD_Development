Definieren von Kalendern

Auf der Seite "Kalender" können Sie das Produktionsjahr und die Mitarbeiterschichten Ihrer Einrichtung definieren.

Beim Definieren von Kalendern

Eine Schicht muss definiert sein, bevor sie in der Tabelle "Schichten" auf dieser Seite ausgewählt werden kann. Sie definieren eine Schicht über die Modellierungsseite "Schicht". Sie müssen außerdem einen Kalenderschichtenzyklus definieren, bevor Sie ihn im Feld "Schichtenzyklus" auf dieser Seite auswählen können. Sie definieren einen Kalenderschichtenzyklus über die Modellierungsseite "Kalenderschichtenzyklus".

Felddefinitionen der Seite "Kalender"

Schichtenzyklus

Schichten sind erforderlich, um einen kompletten Schichtenzyklus zu bilden. Die Tagschicht A beginnt z. B. an einem Sonntag und dauert vier Tage, gefolgt von Schicht B, die ebenfalls vier Tage dauert usw. Daher ist ein vollständiger Zyklus erreicht, wenn die Tagschicht A erneut an einem Sonntag für vier Tage beginnt.

Hinweis: Für die Kalendereinrichtung ist ein Kalenderschichtenzyklus erforderlich, damit die Schichten für das ganze Jahr automatisch generiert werden können.

Erforderlich

Berichterstellung: Offset Monatsende

Wird verwendet, um sowohl das Enddatum als auch das Startdatum eines Monats anzugeben. Beispiel: Null Stunden bedeutet 12.00 Uhr am letzten Tag des Monats. Dieses Feld wird auch für die Startzeit des ersten Tages eines Monats verwendet.

Vorgehensweise zum Definieren eines Kalenders

Gehen Sie folgendermaßen vor, um einen Kalender zu definieren:

1. Öffnen Sie die Seite Kalender. Die Seite "Kalender" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie im Feld Kalender einen Namen für den Kalender ein.
4. Wählen Sie einen Schichtenzyklus aus.
5. Geben Sie das Startdatum ein.
6. Geben Sie das Enddatum ein.
7. Ändern Sie alle Werte für Monat/Woche, falls erforderlich.
8. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
9. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
