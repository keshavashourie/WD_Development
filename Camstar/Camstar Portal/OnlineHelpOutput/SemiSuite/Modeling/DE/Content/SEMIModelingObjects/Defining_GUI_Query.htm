Definieren von GUI-Abfragen

GUI-Abfragen dienen zum Abrufen von Informationen z. B. von Losen und Ausrüstung, um diese während einer Transaktion anzuzeigen. Die GUI-Abfrage ist eine vordefinierte Abfrage, die in Form von Instanzdaten gespeichert ist. Beachten Sie, dass die Abfragedefinition als Instanzdaten definiert ist, während die Abfrage selbst verwendet werden kann, um Informationen aus Instanzdatentabellen oder Metadatentabellen abzurufen.

Die Tabelle "Parameter" ist als persistente Liste implementiert, sodass die Parameterreihenfolge automatisch mit Informationen aus der entsprechenden persistenten Listentabelle aktualisiert wird.

Anforderungen für GUI-Abfragen

Für das Schreiben von GUI-Abfragen müssen Sie mit dem Objektmodell vertraut sein, die SQL-Syntax kennen und Erfahrungen mit SQL-Abfragen haben. Sie müssen auch die Anforderungen der Endbenutzer kennen, damit mit Ihren Abfragen die richtigen Informationen ermittelt und auf der Benutzeroberfläche angezeigt werden.

Nachdem die Abfragen erstellt und getestet wurden, müssen diese von der benutzerdefinierten Anwendung aufgerufen werden. Dies erreichen Sie mit API-Aufrufen in Opcenter Execution Semiconductor Services (WSQuery) oder über eine benutzerdefinierte Ausführung.

Felddefinitionen der Seite "GUI-Abfrage"

Diese Tabelle definiert die Felder auf der Seite "GUI-Abfrage".

Feld

Definition

Typ

Abfragedefinition

Abfragetext

SQL-Abfrage-Anweisung. Die Standardbegrenzung für dieses Feld beträgt 4.000 Zeichen. Diese Begrenzung kann in Designer angepasst werden. Weitere Informationen finden Sie im Opcenter Execution Core Designer-Benutzerhandbuch.

Tabelle "Parameter"

Tabelle, die die Parameter der Abfrage definiert. Wird als benanntes Unterobjekt definiert und der Parametername ist jeweils eindeutig.

Name für Benutzerabfrageparameter

Eindeutiger Name für den Abfrageparameter.

Erforderlich

Datentyp

Datentyp des Abfrageparameters. Folgende Auswahlmöglichkeiten sind verfügbar:

• Boolesch
• Dezimal
• Festkomma
• Gleitkomma
• Integer
• Objekt
• Zeichenkette
• Zeitstempel

Erforderlich

Text anzeigen

Text, der für den Parameter angezeigt wird, wenn die Abfrage ausgeführt wird.

Optional

Parameterwert

Standartwert für den Parameter.

Optional

Dynamischer Wert

Wert, der in den tatsächlichen Wert aufgelöst wird, der für die Abfrage verwendet werden soll. Dieses Feld wird von der internen Logik verwendet, wenn die Einrichtung einer Online-Abfrage intern durch einen Service ausgelöst wird. Ein Beispiel wäre die Überprüfung eines Erledigungsplans, um festzustellen, ob ein Los das nächste Los der Transaktion ist. Wenn für dieses Feld kein Wert festgelegt ist, wird der Standardwert verwendet.

Optional

Ist erforderlich

Flag, das angibt, ob der Parameter für das Drucken erforderlich ist.

Optional

Für Blockzeilen verwenden

Markierung, die angibt, ob der Parameter zum Abrufen von Blockzeilen verwendet werden soll. Dieser Wert wird in der Onlineabfrage-Benutzeroberfläche verwendet, um die Schaltflächen "Weiter" und "Zurück" zum Abrufen der Zeilen zu automatisieren.

Hinweis: Sie können dieses Flag nur für einen Parameter festlegen.

Optional

Details

Name der Behälterspalte

Rückgabespaltenname für den Behälter. Wird der Name nicht angegeben, erwartet Logik, die ihn benötigt, den Wert CARRIER.

Optional

Name der Ausrüstungsspalte

Rückgabespaltenname für die Ausrüstung. Wird der Name nicht angegeben, erwartet Logik, die ihn benötigt, den Wert EQUIPMENT.

Optional

Name der Losspalte

Rückgabespaltenname für die Los-ID. Wird der Name nicht angegeben, erwartet Logik, die ihn benötigt, den Wert LOT.

Optional

Größenlimit für Ergebnismenge

Maximale Anzahl erwarteter Datensätze. Mit diesem Wert wird die Anzahl der zurückgegebenen Datensätze begrenzt, um die Speicherauslastung zu minimieren.

Optional

Vorgehensweise zum Definieren einer GUI-Abfrage

Gehen Sie folgendermaßen vor, um eine GUI-Abfrage zu definieren:

1. Öffnen Sie die Seite GUI-Abfrage. Die Seite "GUI-Abfrage" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld GUI-Abfrage den Namen der GUI-Abfrage ein.
4. Geben Sie in das Feld Abfragetext den Text der SQL-Abfrageanweisung ein.
5. Gehen Sie folgendermaßen vor, um Parameter zur Tabelle "Parameter" hinzuzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
b. Geben Sie in das Feld Name für Benutzerabfrageparameter den Namen des Parameters für die GUI-Abfrage ein.
c. Geben Sie in das Feld Datentyp den Datentyp des Parameters für die GUI-Abfrage ein.
d. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
