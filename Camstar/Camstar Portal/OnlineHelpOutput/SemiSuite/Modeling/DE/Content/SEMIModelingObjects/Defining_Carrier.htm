Definieren von Behältern

Ein Behälter ermöglicht es Ihnen, mehrere Materialien während des Produktionsprozesses zu tragen oder aufzunehmen. Er kann verwendet werden, um Materialsätze in der Fertigung zu bewegen.

Beispiel: Ein Bediener stellt ein Medikament her und teilt 100 kg des ersten Wirkstoffs auf fünf Tabletts mit jeweils 20 kg auf. Die Tabletts in diesem Beispiel sind die Behälter.

Sie können einen Container einem Behälter zuweisen. Die Transaktion muss jedoch für den Container und nicht für den Behälter ausgeführt werden.

Felddefinitionen der Seite "Behälter"

Diese Tabelle definiert die Felder auf der Seite "Behälter".

Feld

Definition

Typ

Allgemein

Fabrik

Die Fabrik, in der sich der Behälter befindet.

Optional

Standort

Standort des Behälters. Der Standort muss sich innerhalb der im Feld "Fabrik" angegebenen Fabrik befinden. Gültige Standorte werden im Modellierungsobjekt "Fabrik" erstellt und verwaltet.

Optional

Behälterfamilie

Die diesem Behälter zugeordnete Familie.

Wenn Sie einen Wert in diesem Feld auswählen, werden auf dieser Seite automatisch zugehörige Informationen in die Tabelle "Behälter-Positionszuordnung" geladen. Die ausgewählte Behälterfamilie muss zuerst auf der Seite zur Modellierung von Behälterfamilien definiert werden – zur Aktivierung der Behälterposition und Zuweisung der Werte der Positionen x, y und z. Weitere Informationen finden Sie unter Definieren von Behälterfamilien.

Optional

Lieferant

Lieferant dieses Behälters.

Optional

Lieferantenmodell

Das vom Lieferanten verwendete Modell.

Optional

Lieferantenseriennummer

Die Seriennummer des Lieferanten.

Optional

Eltern-Behälter

Ein anderer Behälter, der der Eltern-Behälter dieses Behälters ist. Wenn Sie einen Eltern-Behälter festlegen, stellen Sie eine Beziehung zwischen den Behältern her, sodass dieser Behälter Attribute (etwa die Fabrik und Anmerkungen) vom Eltern-Behälter "erbt".

Optional

Wartungsklasse

Wartungsklasse, zu der dieser Behälter gehört, falls zutreffend.

Optional

Position: Los zuweisen – Verifizierung

Zusätzliche Verifizierung der Losposition.
Mögliche Optionen sind:

• Kein
• Eltern-Container
• Arbeitsauftrag

Optional

Ressourcentyp

Art der Ausrüstung (etwa übliche Wartungsausrüstung), die mit einem Ressourcenstatusmodell verknüpft werden kann.

Optional

Ressourcenstatusmodell

Anfängliche Ressourcenstatuscodegruppe, die einer bestimmten Ressource bei der Transaktion für Ressourceneinrichtung zugewiesen werden soll, oder die gültige Ressourcenstatuscodegruppe, die die zulässigen Status definiert, in die eine Ressource mit einem anderen Status überführt werden kann.

Optional

Kind-Behälter

Liste der Behälter, die diesen Behälter als ihren Eltern-Behälter referenzieren.

Optional

Details

Dokumentsatz

Name des Dokumentsatzes, der dem Behälter zugeordnet ist. Zu den Einrichtungsdokumenten zählen in der Regel Ausrüstungszeichnungen, Teilelisten, Einrichtungsanweisungen und Rezepte.

Optional

Anfangsstatus (festzulegender Null-Status)

Gibt den anfänglichen Status für die Ausrüstung an.

Optional

Wartungsfehlerstatus

Wartungsfehlerstatus für die Ausrüstung.

Optional

Behälter-Positionszuordnung

Tabelle "Behälter-Positionszuordnung"

Tabelle, in der die Positionsinformationen für das Los im Behälter angegeben sind. Weitere Informationen finden Sie unter Vorgehensweise zum Definieren einer Behälter-Positionszuordnung auf der Seite "Behältermodellierung"

Nur Anzeige

Los

Name des Loses.

Nur Anzeige

Positionsnummer

Positionsnummer des Loses. Der in diesem Feld angezeigte Wert basiert auf der Positionsmethode, die auf der Seite "Behälterfamilien" ausgewählt wurde. Es gibt zwei Typen: "Numerisch" oder "Vektor".

Bei der Methode "Numerisch" basiert der Wert der Positionsnummer auf X-Position mal Y-Position mal Z-Position. Wenn das Los z. B. X:2, Y:2, Z:1 ist (Los in Spalte 2, Zeile 2, an vertikaler Position 1), sind die Positionsnummern 1 bis 4.

Bei der Methode "Vektor" basiert der Wert der Positionsnummer auf dem X.Y.Z-Format. Z. B. 2.2.1.

Nur Anzeige

Positionsebene

Positionsebene des Loses in einem Behälter. Der Wert dieses Felds basiert auf der Z-Position, die auf der Seite "Behälterfamilie" festgelegt wurde.

Nur Anzeige

Status

Status des Loses: entweder "Verfügbar" oder "Nicht verfügbar". Sie können den Status in der Tabelle über die Dropdown-Liste des Felds ändern.

Optional

Vorgehensweise zum Definieren eines Behälters

Gehen Sie folgendermaßen vor, um einen Behälter zu definieren:

1. Öffnen Sie die Seite Behälter. Die Seite "Behälter" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für den Behälter in das Feld Behälter ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Definieren einer Behälter-Positionszuordnung auf der Seite "Behältermodellierung"

Gehen Sie folgendermaßen vor, um die Behälter-Positionszuordnung zu verwenden:

1. Öffnen Sie die Seite Behälter. Die Seite "Behälter" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für den Behälter in das Feld Behälter ein.
4. Wählen Sie eine Behälterfamilie im Feld Behälterfamilie aus. Wenn Sie ein Feld auswählen, werden die Werte in der Tabelle "Behälter-Positionszuordnung" ausgefüllt. Informationen zur Behälterposition finden Sie unter Definieren von Behälterfamilien.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
6. Die Tabelle "Behälter-Positionszuordnung" wird mit Informationen geladen. Informationen zur Felddefinition finden Sie in der Tabelle "Behälter-Positionszuordnung".
