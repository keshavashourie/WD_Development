Definieren von Ressourcensymbolen

Ein Ressourcensymbol ist ein Bild, das Sie auf der Seite "Ressourcenlayout" als ein Symbol verwenden können, um eine Ressource grafisch darzustellen.

Vor dem Definieren von Ressourcensymbolen

Symboldateien können in einem beliebigen Unterordner gespeichert werden, solange dieser sich im Camstar-/Camstar Portal-Verzeichnis befindet.

Felddefinitionen der Seite "Ressourcensymbol"

In dieser Tabelle sind die Felder definiert, die nur auf der Seite "Ressourcensymbol" zu finden sind.

Feld

Definition

Typ

Details

 

 

Symbol-Dateiname

Bilddateiname.

Hinweis: Dieses Feld muss eingegeben werden, obwohl es als optional kategorisiert ist. Ein Fehler beim Eingeben des Dateinamens führt zu einem Systemfehler.

Optional

Symbolhöhe

Höhe des Bilds in Pixeln. Sollte auf etwa "30" festgelegt werden. Die Größe kann entsprechend der Anzahl von Ressourcen auf jedem Layout angepasst werden.

Optional

Symbolbreite

Breite des Bilds in Pixeln. Sollte auf etwa "30" festgelegt werden. Die Größe kann entsprechend der Anzahl von Ressourcen auf jedem Layout angepasst werden.

Optional

Vorgehensweise zum Definieren eines Ressourcensymbols

Gehen Sie folgendermaßen vor, um ein Ressourcensymbol zu definieren:

1. Öffnen Sie die Seite Ressourcensymbol. Die Seite "Ressourcensymbol" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen des Ressourcensymbols in das Feld Ressourcensymbol ein.
4. Wählen Sie die Symbolbilddatei im Feld Symbol-Dateiname aus. Es kann eine Verzögerung geben, weil die Anwendung die Feldliste lädt, damit Sie eine Auswahl treffen können.
5. Geben Sie die Symbolhöhe ein.
6. Geben Sie die Symbolbreite ein.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
