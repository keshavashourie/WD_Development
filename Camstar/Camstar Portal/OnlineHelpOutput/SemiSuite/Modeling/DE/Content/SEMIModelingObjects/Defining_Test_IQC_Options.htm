Definieren von Optionen für Test IQC

Auf der Seite "Test IQC: Option" können Sie Optionen für interne Qualitätskontrolltests konfigurieren.

Felddefinitionen der Seite "Test IQC: Option"

Diese Tabelle definiert die Felder auf der Seite "Test IQC: Option".

Feld

Definition

Typ

Details

Lose autom. auswählen

Kontrollkästchen, das angibt, ob die Anwendung automatisch Lose zur Test IQC auswählen soll, während Lose empfangen werden.

Optional

Lose autom. auswählen: Alarm

Kontrollkästchen, das angibt, ob der Benutzer benachrichtigt wird, wenn ein Los für Test IQC ausgewählt wird.

Optional

Variable Daten erforderlich

Kontrollkästchen, das angibt, ob ein Test variabler Daten erforderlich ist.

Optional

Eingehende Lötbarkeit erforderlich

Kontrollkästchen, das angibt, ob ein Test eingehender Lötbarkeit erforderlich ist.

Optional

Typ des Tests der eingehenden Lötbarkeit

Gibt den Typ des erforderlichen Tests der eingehenden Lötbarkeit an: Gültige Werte sind:

1 – Jedes Los. Jedes empfangene Los muss getestet werden.

2 – Optionale kontinuierliche wöchentliche Überwachung. Wird für die manuelle Verfolgung von Tests verwendet. Die Anwendung wählt Lose nicht automatisch aus.

Optional

Variable Daten: Testtyp

Gibt den Typ und die Häufigkeit von Tests variabler Daten an. Gültige Werte sind:

1 – Jedes Los. Jedes empfangene Los muss getestet werden.

2 – Nach Pakettyp und Versandnummer. Der Pakettyp und die Versandnummer jedes empfangenen Loses werden zum Prüfen für Tests bis zu den erforderlichen Losen variabler Daten verwendet.

3 – Nach Monat und Pakettyp. Der Pakettyp und der Kalendermonat, in dem ein Los empfangen wird, werden zum Prüfen für Tests bis zu den erforderlichen Losen variabler Daten verwendet.

Optional

Variable Daten: Lose erforderlich

Anzahl der Lose, die für variable Daten erforderlich sind.

Optional

Variable Daten: Mengentyp

Bestimmt die zu testende Menge. Gültige Werte sind:

• % – Der Prozentsatz von "Variable Daten: Mengenwert" wird verwendet, um die erforderliche Menge zum Testen anzugeben.
• Einheiten – Der Wert von "Variable Daten: Mengenwert" wird verwendet, um die erforderliche Menge zum Testen anzugeben.

Optional

Variable Daten: Mengenwert

Wert, der zusammen mit "Variable Daten: Mengentyp" verwendet wird, um die erforderliche Menge zum Testen anzugeben. Der Wert "0" bedeutet 100 %.

Hinweis: Der Wert gibt dem Benutzer nur die zu testende Menge an. Er löst keine automatische Logik aus.

Optional

VM erforderlich

Optional

VM-Lose erforderlich

Anzahl der Lose, die für VM erforderlich sind.

VM-Mengenwert

Hinweis: Der Wert gibt dem Benutzer nur die zu testende Menge an. Er löst keine automatische Logik aus.

Optional

Vorgehensweise zum Definieren einer Option für Test IQC

Gehen Sie folgendermaßen vor, um eine Option für Test IQC zu definieren:

1. Öffnen Sie die Seite Test IQC: Option. Die Seite "Test IQC: Option" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie im Feld Test IQC: Option einen Namen für die Option für Test IQC ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
