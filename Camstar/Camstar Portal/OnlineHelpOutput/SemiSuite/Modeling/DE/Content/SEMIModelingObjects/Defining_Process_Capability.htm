Definieren von Prozessfähigkeiten

Eine Prozessfähigkeit ist eine Bedingung, die bestimmt, ob ein Teil einer Ausrüstung mit mehreren Kammern (Multikammerausrüstung) durch den Fertigungsprozess verwendet werden kann. Die Bedingung, die als Bedingung für mehrere Kammern bezeichnet wird, ist eine Formel, die die Kind-Ausrüstung definiert, die zur Verwendung verfügbar sein muss. Sie können z. B. angeben, dass die Ausrüstung, die durch mindestens ein Eltern- und ein Kind-Ausrüstung-Modellierungsobjekt definiert ist, verfügbar sein muss, damit die Ausrüstung mit mehreren Kammern verwendet werden kann.

Nachdem Sie das "Prozessfähigkeit"-Modellierungsobjekt erstellt haben, können Sie es verwenden, um das Multikammerwerkzeug anzugeben, das in einem bestimmten Prozess oder in einer bestimmten ergänzenden Spezifikation verwendet werden soll.

Beim Definieren einer Prozessfähigkeit

Die folgenden Regeln gelten, wenn Sie Prozessfähigkeiten definieren:

• Sie müssen Ausrüstung und Kind-Ausrüstung definieren, die von der Prozessfähigkeit zu verwenden sind. Ausrüstungsobjekte sind je nach Ihren geschäftlichen Anforderungen auf den Seiten "Zusammenbauausrüstung", "Backgrind-Ausrüstung", "Testausrüstung", "Waferausrüstung" und "Wafersortierung: Ausrüstung" definiert. Weitere Informationen über das Definieren von Kind-Ausrüstung finden Sie unter Definieren von Ausrüstung.
• Die Ausrüstung muss verfügbar sein.

Erstellen einer Bedingung für mehrere Kammern

Die Bedingung für mehrere Kammern ist eine boolesche Formel, die die Ausrüstung mit mehreren Kammern definiert, die zur Verwendung verfügbar ist. Jedes Ausrüstungsteil ist durch einen Operanden definiert, der aus zwei Variablen besteht, die wie folgt durch ein Trennzeichen getrennt sind:

equipmentType$equipmentLogicalID

Dabei gilt:

• equipmentType ist der Typ der Ausrüstung. Dieser Typ muss entweder auf "CH" (für Chamber/Kammer) oder "LP" (Load Port/Beladungsport) festgelegt werden.
• equipmentLogicalID ist die logische ID der Ausrüstung. Sie weisen die logische ID zu, wenn Sie das Ausrüstungsmodellierungsobjekt erstellen.
• Das Dollarzeichen ($) ist das Trennzeichen.

Sie können jeden booleschen Operator, z. B. AND und OR, verwenden, um die Formel genauer zu definieren. Außerdem müssen Sie jeden Operanden in Klammern (()) setzen sowie Klammern verwenden, um Operanden zu gruppieren.

Die folgende Formel gibt z. B. an, dass das Kammerausrüstungsobjekt A und entweder das Kammerausrüstungsobjekt B oder C verfügbar sein müssen:

(CH$A) AND ((CH$B) OR (CH$C))

Bedingung für mehrere Kammern

Die Formel, die angibt, welche Ausrüstung verwendet werden kann. Sie müssen jeden einzelnen Operanden und jede Gruppe von Operanden in Klammern setzen. Die folgende Formel gibt z. B. das Kammerausrüstungsobjekt A und entweder das Kammerausrüstungsobjekt B oder C an:

(CH$A) AND ((CH$B) OR (CH$C))

Dabei gilt:

• CH entspricht einem Kammerausrüstungsobjekt.
• Das Dollarzeichen ($) ist ein Trennzeichen.
• A, B und C entsprechen den logischen IDs für jedes Kammerausrüstungsobjekt.

Optional

Vorgehensweise zum Definieren einer Prozessfähigkeit

Gehen Sie folgendermaßen vor, um eine Prozessfähigkeit zu definieren:

1. Öffnen Sie die Seite Prozessfähigkeit. Die Seite "Prozessfähigkeit" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Prozessfähigkeit in das Feld Prozessfähigkeit ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
