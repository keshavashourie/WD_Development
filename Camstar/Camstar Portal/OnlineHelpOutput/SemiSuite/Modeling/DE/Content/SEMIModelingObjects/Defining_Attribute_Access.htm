Definieren von Attributzugriff

Der Attributzugriff dient zum Verifizieren der Servicefelder während der Transaktionsausführung. Attributzugriff wird in der Tabelle "Zugriffe" für die entsprechende Rolle in Bezug auf den Mitarbeiter konfiguriert.

Felddefinitionen der Seite "Attributzugriff"

Diese Tabelle definiert die Felder auf der Seite "Attributzugriff".

Feld

Definition

Typ

Details

Feldtyp

Feldtyp des Attributs. Gültige Werte sind:

• Boolesch
• Nummer
• Zeitstempel
• Zeichenkette
• RDO
• NDO

Erforderlich

Attributliste

Objekt, das das Attributfeld enthält.

Optional

Attributfeld

Name des Attributs.

Erforderlich

Attributanzeigename

Name, der zum Anzeigen des Attributs verwendet wird, wenn ein Zugriffsfehler während einer Transaktion erkannt wird. Wenn dieser Wert fehlt, wird stattdessen der Wert für "Attributfeld" verwendet.

Optional

Dienstname

Name des zu verifizierenden Services. Wenn dieses Feld leer bleibt, wird die Anwendung für jeden ausgeführten Service (jede Transaktion) ausgeführt.

Optional

Tabelle "Gültige Werte"

Tabelle, in der die gültigen Werte für die Attribute aufgelistet sind.

Optional

Attributwert

Gültiger Wert für das Attribut. Die Anwendung löst diesen Wert auf. Wenn der aufgelöste Wert nicht in der Liste "Gültige Werte" enthalten ist, schlägt die Ausführung fehl.

Optional

Attributrevision

Revision des Attributs. Wird ausschließlich für einen Vergleich mit revisionierten Objekten verwendet. Sie können eine bestimmte Revision des Attributs angeben, wenn es sich um ein revisioniertes Objekt handelt. Die Anwendung verwendet die Standardrevision, wenn Sie keine Attributrevision angeben.

Optional

Vorgehensweise zum Definieren eines Attributzugriffs

Gehen Sie folgendermaßen vor, um einen Attributzugriff zu definieren:

1. Öffnen Sie die Seite Attributzugriff. Die Seite "Attributzugriff" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Attributzugriff den Namen des Objekttyps ein.
4. Geben Sie in das Feld Feldtyp den Feldtyp des Attributs ein.
5. Geben Sie in das Feld Attributfeld den Namen des Attributs ein.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
