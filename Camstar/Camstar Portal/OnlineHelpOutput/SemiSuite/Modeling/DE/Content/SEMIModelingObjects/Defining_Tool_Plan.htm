Definieren von Werkzeugplänen

Ein Werkzeugplan wird verwendet, um die erforderlichen Werkzeuge anzugeben, die der Ausrüstung vor der Verarbeitung zugewiesen werden müssen. Sie können Werkzeuge, Werkzeugfamilien oder beides als Bestandteile von Werkzeugplänen angeben.

Beim Definieren von Werkzeugplänen

Bevor Sie Werkzeugpläne definieren können, müssen Sie Werkzeug- und Werkzeugfamilien-Modellierungsobjekte definieren, die Bestandteile des Werkzeugplans sein sollen.

Vorgehensweise zum Definieren eines Werkzeugplans

Gehen Sie folgendermaßen vor, um einen Werkzeugplan zu definieren:

1. Öffnen Sie die Seite Werkzeugplan. Die Seite "Werkzeugplan" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für den Werkzeugplan in das Feld Werkzeugplan ein.
4. Klicken Sie auf Neue Zeile hinzufügen in der Tabelle "Elemente". Das Dialogfeld "Hinzufügen" wird geöffnet.
5. Führen Sie die folgenden Schritte im Dialogfeld "Hinzufügen" aus:
a. Geben Sie einen Parameternamen in das Feld Elementname ein.
b. Klicken Sie für jede Werkzeugfamilie und jedes Werkzeug, das Sie dem Werkzeugplan hinzufügen möchten, in der Tabelle "Details" auf Neue Zeile hinzufügen und fügen Sie entweder in der Spalte Werkzeugfamilie oder Werkzeug einen gültigen Eintrag hinzu.
Hinweis: Es ist nicht möglich, in einer einzelnen Zeile sowohl eine Werkzeugfamilie als auch ein Werkzeug hinzuzufügen. Fügen Sie für jeden Eintrag eine neue Zeile hinzu.
c. Geben Sie optionale Informationen entsprechend Ihren Geschäftsanforderungen in das Dialogfeld "Hinzufügen" ein. Weitere Informationen zu den optionalen Feldern finden Sie unter "Felddefinitionen des Popups "Hinzufügen" für Werkzeugpläne".
d. Klicken Sie auf OK. Die Anwendung schließt das Dialogfeld "Hinzufügen" und fügt das von Ihnen hinzugefügte Element zur Tabelle "Einträge" hinzu.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
