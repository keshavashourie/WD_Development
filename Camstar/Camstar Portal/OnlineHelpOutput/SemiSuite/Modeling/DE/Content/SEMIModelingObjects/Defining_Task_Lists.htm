Definieren von Aufgabenlisten

Eine Aufgabenliste ermöglicht es Ihnen, einen Satz von Prozeduren zu definieren, die während einer Umlaufbestandsverarbeitung ausgeführt werden. Sie implementieren die Liste, indem Sie sie einem automatischen Ablauf und dann den automatischen Ablauf einer Spezifikation zuweisen.

Eine Aufgabenliste kann mit Datensammlungen und mit Anweisungen sowohl auf Listenebene als auch auf der Ebene einzelner Aufgaben konfiguriert werden. Die Anweisungen können "Umlaufbestandsdatenname"-Variablen enthalten, die zur Laufzeit dynamisch aufgelöst werden. Sie definieren eine Aufgabenliste über die Seite "Aufgabenliste".

Eine vollständige Beschreibung der Aufgaben und Aufgabenlisten finden Sie im Opcenter Execution Core Modeling-Benutzerhandbuch.

Felddefinitionen der Seite "Aufgabenliste"

Diese Tabelle definiert die Felder auf der Seite "Aufgabenliste".

Feld

Definition

Typ

Details

Änderungsauftrag

Änderungsauftrag, der dieser Revision zugewiesen wurde. Sie können maximal 30 Zeichen eingeben.

Optional

Anweisung

Anweisungen, die die Anwendung über der Liste der Aufgaben auf der Seite "Automatischer Ablauf" anzeigt. Sie können eine "Umlaufbestandsdatenname"-Anweisungsvariable einfügen, indem Sie diese in ein $-Präfix und ein $-Suffix setzen, z. B. $DATEN01$.

Optional

Ausführungsmodus

Einstellung, die anzeigt, ob die Anwendung die Aufgaben in einer bestimmten Reihenfolge (Sequenziell) oder in beliebiger Reihenfolge (Nicht sequenziell) ausführt. Der Standardwert ist "Sequenziell".

Erforderlich

Vorausgesetzte Aufgabenliste

Liste von zuvor definierten Aufgabenlisten. Sie können eine Aufgabenliste auswählen, die vor der aktuell ausgewählten Aufgabenliste ausgeführt werden muss.

Optional

Arbeitsplatz

Liste von zuvor definierten Ressourcen, die Sie dieser Aufgabenliste zuordnen können. Benutzer in der Fertigung verwenden den Arbeitsplatz, den Sie auswählen, um Aufgaben auszuführen.

Optional

Arbeitsplatzgruppe

Liste von zuvor definierten Ressourcengruppen, die Sie dieser Aufgabenliste zuordnen können. Benutzer in der Fertigung verwenden Arbeitsplätze in der Gruppe, die Sie auswählen, um Aufgaben auszuführen.

Optional

Batch Processing

Dieser Abschnitt wird nur angezeigt, wenn Batch Processing installiert ist.

 

Menge des mittleren Batches

Ausdruck, der zum Berechnen der Menge des mittleren Batches, der Komponente oder der Unterbaugruppe verwendet wird.

Optional

Maßeinheit des mittleren Batches

Maßeinheit des mittleren Batches, der Komponente oder der Unterbaugruppe.

Optional

Aufgabendetails

Tabelle "Aufgaben"

Tabelle, die die Aufgaben auflistet, die der Liste hinzugefügt wurden. Sie müssen der Aufgabenliste mindestens eine Aufgabe hinzufügen.

Nur Anzeige

Aufgabe

Eindeutiger Name der Aufgabe.

Nur Anzeige

Anweisungstyp

Die folgenden Optionen sind verfügbar:

• Bestätigung – Ein Bediener muss eine Aufgabe als beendet markieren.
• Datensammlung – Ein Bediener muss parametrische Datenwerte für eine Standarddatensammlung oder für eine Datenpunktsammlung eingeben.
• Bestanden/Durchgefallen – Ein Bediener muss das Ergebnis "Bestanden/Durchgefallen" für eine Aufgabe angeben.

Der Anweisungstyp ist nur verfügbar, wenn Sie für "Aufgabenelementtyp" die Option "Anweisung" auswählen.

Nur Anzeige

Min. Iterationen

Gibt an, wie häufig die Aufgabe mindestens ausgeführt werden muss.

Nur Anzeige

Max. Iterationen

Gibt an, wie häufig die Aufgabe maximal ausgeführt werden kann.

Nur Anzeige

Aufgabentyp

Art der Aufgabe (Prozess starten, normale Aufgabe oder Prozess beenden). Die Prozess starten-Aufgabe ist für eine Transaktionsaufgabe nicht verfügbar.

Nur Anzeige

Anforderung zur elektronischen Unterschrift

Die Anforderung zur elektronischen Unterschrift, die mit dieser Aufgabenliste verknüpft ist. Wenn Sie einer Aufgabe eine Anforderung zur elektronischen Unterschrift zuweisen, muss ein Bediener eine elektronische Unterschrift eingeben, bevor die Aufgabenliste beendet werden kann.

Nur Anzeige

Trainingsanforderungsgruppe

Die mit dieser Aufgabenliste verknüpfte Trainingsanforderungsgruppe. Eine Trainingsanforderungsgruppe ist eine Sammlung individueller Trainingsanforderungen, die gewährleisten sollen, dass der Bediener zur Ausführung der Aufgabenliste qualifiziert ist.

Nur Anzeige

Popups für Aufgabendetails

Wenn Sie eine Aufgabe zur Aufgabenliste hinzufügen, zeigt die Anwendung je nach Aufgabentyp, den Sie auswählen, eines von drei Popups an:

• Anweisung
• Berechnung
• Transaktion

Feld

Definition

Typ

Aufgabe

Eindeutiger Name der jeweiligen Aufgabe.

Erforderlich

Anweisung

Aufgabentyp

Aufgabe, die den aktuellen Stand der Verarbeitung an der Arbeitszelle oder am Arbeitsplatz angibt. Mögliche Optionen sind:

• Prozess beenden-Aufgabe – Wird benötigt, um das Ende eines Prozesses in einer Arbeitszelle oder an einem Arbeitsplatz zu kennzeichnen.
• Normale Aufgabe – Kann zwischen einer Prozess-starten-Aufgabe und einer Prozess-beenden-Aufgabe vorkommen.
• Prozess starten-Aufgabe – Wird benötigt, um den Start eines Prozesses in einer Arbeitszelle oder an einem Arbeitsplatz zu kennzeichnen.

Hinweis: Die Option "Prozess starten-Aufgabe" ist für Transaktionsaufgaben nicht verfügbar.

Erforderlich

Anweisungstyp

Die folgenden Optionen sind verfügbar:

• Bestätigung – Ein Bediener muss eine Aufgabe als beendet markieren.
• Datensammlung – Ein Bediener muss parametrische Datenwerte für eine Standarddatensammlung oder für eine Datenpunktsammlung eingeben.
• Bestanden/Durchgefallen – Ein Bediener muss das Ergebnis "Bestanden/Durchgefallen" für eine Aufgabe angeben.

Der Anweisungstyp ist nur verfügbar, wenn Sie für "Aufgabenelementtyp" die Option "Anweisung" auswählen.

Erforderlich

Min. Iterationen

Gibt an, wie häufig die Aufgabe mindestens ausgeführt werden muss.

Erforderlich

Max. Iterationen

Gibt an, wie häufig die Aufgabe maximal ausgeführt werden kann.

Optional

Dokumentsatz

Liste mit einem oder mehreren Dokumenten, die erweiterte Informationen enthalten, z. B. Zeichnungen, gescannte Bilder und Verfahren.

Optional

Weiter zur nächsten Aufgabe, wenn "Min. Iterationen" erreicht ist

Wenn dieses Kontrollkästchen aktiviert ist, zeigt die Anwendung automatisch die nächste Aufgabe an, wenn die Mindestanzahl von Iterationen für die aktuelle Aufgabe ausgeführt wurde. Dieses Kontrollkästchen ist standardmäßig aktiviert.

Optional

Anforderung zur elektronischen Unterschrift

Die Anforderung zur elektronischen Unterschrift, die mit dieser Aufgabe verknüpft ist. Wenn Sie einer Aufgabe eine Anforderung zur elektronischen Unterschrift zuweisen, muss ein Bediener eine elektronische Unterschrift eingeben, bevor die Aufgabe beendet werden kann.

Hinweis: Dieses Feld ist für Transaktionsaufgaben nicht verfügbar.

Optional

Trainingsanforderungsgruppe

Die mit dieser Aufgabenliste verknüpfte Trainingsanforderungsgruppe. Eine Trainingsanforderungsgruppe ist eine Sammlung individueller Trainingsanforderungen, die gewährleisten sollen, dass der Bediener zur Ausführung der Aufgabenliste qualifiziert ist.

Optional

Datensammlungsdefinition

Die Datensammlungsdefinition, die mit der Aufgabe verknüpft ist. Eine in der Modellierung definierte Datensammlungsdefinition referenziert eine parametrische Datendefinition, die einen Satz von Datensammlungsparametern enthält. Diese Parameter werden Benutzern während der Transaktionsverarbeitung angezeigt.

Hinweis: Die Datensammlungsfelder werden nur dann auf der Fertigungsseite "Automatischer Ablauf" angezeigt, wenn Sie hier eine Datensammlungsdefinition und im Feld "Anweisungstyp" den Typ "Datensammlung" auswählen.

Optional

Tabelle "Vorausgesetzte Aufgaben"

Liste der Aufgaben in der Aufgabenelementliste, die abgeschlossen sein müssen, bevor diese Aufgabe ausgeführt werden kann.

Optional

Vorgehensweise zum Definieren einer Aufgabenliste

Gehen Sie folgendermaßen vor, um eine Aufgabenliste zu definieren:

1. Öffnen Sie die Seite Aufgabenliste. Die Seite "Aufgabenliste" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für diese Aufgabenliste in das Feld Aufgabenliste ein.
4. Geben Sie die Revision dieser Aufgabenliste in das Feld Revision ein.
5. Wählen Sie einen Ausführungsmodus für diese Aufgabenliste aus.
6. Fügen Sie mindestens eine Aufgabe zur Tabelle "Aufgaben" hinzu, indem Sie die entsprechenden, unten aufgeführten Prozeduren befolgen:
a. "Vorgehensweise zum Hinzufügen einer Anweisungsaufgabe zu einer Aufgabenliste"
b. "Vorgehensweise zum Hinzufügen einer Berechnungsaufgabe zu einer Aufgabenliste
c. "Vorgehensweise zum Hinzufügen einer Transaktionsaufgabe zu einer Aufgabenliste"
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Hinzufügen einer Anweisungsaufgabe zu einer Aufgabenliste

Gehen Sie folgendermaßen vor, um einer Aufgabenliste eine Transaktionsaufgabe hinzuzufügen:

1. Führen Sie die Schritte unter "Vorgehensweise zum Definieren einer Aufgabenliste" aus.

Oder

Wählen Sie eine vorhandene Instanz einer Aufgabenliste aus.

2. Klicken Sie in der Tabelle "Aufgaben" auf Neue Zeile hinzufügen. Das Menü "Wählen Sie einen Aufgabenelementtyp" wird angezeigt.
3. Klicken Sie auf Anweisung. Das Popup "Anweisungsaufgabedetails" wird angezeigt.
4. Geben Sie einen Namen für die Aufgabe in das Feld Aufgabe ein.
5. Wählen Sie einen Wert für das Feld Aufgabentyp aus.
6. Wählen Sie einen Wert für das Feld Anweisungstyp aus.
7. Geben Sie eine Zahl in das Feld Min. Iterationen ein, um anzugeben, wie oft die Aufgabe mindestens durchgeführt werden muss.
8. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
9. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Hinzufügen einer Berechnungsaufgabe zu einer Aufgabenliste

Gehen Sie folgendermaßen vor, um einer Aufgabenliste eine Berechnungsaufgabe hinzuzufügen:

1. Führen Sie die Schritte unter "Vorgehensweise zum Definieren einer Aufgabenliste" aus.

Oder

Wählen Sie eine vorhandene Instanz einer Aufgabenliste aus.

2. Klicken Sie in der Tabelle "Aufgaben" auf Neue Zeile hinzufügen. Das Menü "Wählen Sie einen Aufgabenelementtyp" wird angezeigt.
3. Wählen Sie Transaktion aus. Das Popup "Transaktionsaufgabedetails" wird angezeigt.
4. Geben Sie einen Namen für die Aufgabe in das Feld Aufgabe ein.
5. Wählen Sie einen Wert für das Feld Aufgabentyp aus.
6. Geben Sie eine Zahl in das Feld Min. Iterationen ein, um anzugeben, wie oft die Aufgabe mindestens durchgeführt werden muss.
7. Wählen Sie eine Benutzerdatensammlungsdefinition aus.
8. Wählen Sie eine Berechnung aus dem Feld Berechnung aus. Die Eingabevariablen, die für die ausgewählte Berechnung definiert sind, werden angezeigt.
9. Ordnen Sie jede Variable dem entsprechenden Datenpunkt zu, indem Sie den Datenpunkt aus den Datenpunkt-Listen in der Tabelle auswählen. Sie müssen die Benutzerdatensammlung erweitern, um die Datenpunkte zu sehen.
10. Wählen Sie eine Revision einer Berechnungsparameterspez. aus.
11. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
12. Klicken Sie auf OK. Das Popup wird geschlossen und die Aufgabe wird in der Tabelle "Aufgaben" angezeigt.
13. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Hinzufügen einer Transaktionsaufgabe zu einer Aufgabenliste

Gehen Sie folgendermaßen vor, um einer Aufgabenliste eine Transaktionsaufgabe hinzuzufügen:

1. Führen Sie die Schritte unter "Vorgehensweise zum Definieren einer Aufgabenliste" aus.

Oder

Wählen Sie eine vorhandene Instanz einer Aufgabenliste aus.

2. Klicken Sie in der Tabelle "Aufgaben" auf Neue Zeile hinzufügen. Das Menü "Wählen Sie einen Aufgabenelementtyp" wird angezeigt.
3. Wählen Sie Transaktion aus. Das Popup "Transaktionsaufgabedetails" wird angezeigt.
4. Geben Sie einen Namen für die Aufgabe in das Feld Aufgabe ein.
5. Wählen Sie einen Wert für das Feld Aufgabentyp aus.
6. Geben Sie eine Zahl in das Feld Min. Iterationen ein, um anzugeben, wie oft die Aufgabe mindestens durchgeführt werden muss.
7. Wählen Sie eine Transaktionsseite in der Liste Transaktionsseiten aus.
8. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
9. Klicken Sie auf OK. Das Popup wird geschlossen und die Aufgabe wird in der Tabelle "Aufgaben" angezeigt.
10. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Hinzufügen und Formatieren von Anweisungen

Für die Popups "Aufgabenliste" und "Aufgabendetails" wird die gleiche Vorgehensweise zur Eingabe von Anweisungen verwendet. Gehen Sie folgendermaßen vor, um Anweisungen einer Aufgabenliste oder einer einzelnen Aufgabe hinzuzufügen und die Anweisungen zu formatieren:

1. Führen Sie die Schritte unter "Vorgehensweise zum Definieren einer Aufgabenliste" aus.

Oder

Wählen Sie eine vorhandene Instanz einer Aufgabenliste aus.

2. Führen Sie abhängig davon, ob Sie eine Anweisung für die gesamte Aufgabenliste oder für eine einzelne Aufgabe hinzufügen möchten, eine dieser beiden Schrittfolgen aus:

Sie möchten . . .

Dann . . .

Die Anweisung aktualisieren, die für die gesamte Aufgabenliste gilt

Greifen Sie auf das Textbereichsfeld Anweisung im Abschnitt "Details" zu.

Eine Anweisung aktualisieren, die für eine einzelne Aufgabe gilt
a. Wählen Sie die Aufgabe in der Tabelle "Aufgaben" aus.
b. Klicken Sie auf Ausgewählte Zeile bearbeiten..
c. Greifen Sie im Popup auf das Textbereichsfeld Anweisung zu.
3. Geben Sie den Anweisungstext in den Textbereich ein.
4. So formatieren Sie eine Zeile oder einen Absatz:
a. Setzen Sie den Cursor unmittelbar vor den ersten Buchstaben des Textes, den Sie formatieren möchten, und klicken Sie.
b. Wählen Sie in der Symbolleiste des Textbereichs "Anweisung" die gewünschten Formatierungsoptionen aus.Die Anwendung zeigt den Text im ausgewählten Format an.
5. Um einen Abschnitt eines Texts in einer Zeile zu formatieren, markieren Sie den zu formatierenden Textabschnitt und wählen im Textbereich in der Symbolleiste "Anweisung" eine Formatierungsoption aus. Die Anwendung zeigt den Text im ausgewählten Format an.
6. Um eine Anweisungsvariable einzufügen, platzieren Sie den Cursor an genau der Stelle in der Anweisung, an der Sie die Variable hinzufügen möchten. Geben Sie den Variablennamen ein, wobei Sie diesen in ein $-Präfix und ein $-Suffix setzen, z. B. $DATEN01$. Weitere Informationen zu Anweisungsvariablen finden Sie unter "Definieren von Prozessspezifikationen" oder "Definieren von PN- und Materialteilprodukten".

Hinweis: Das Standardpräfix und -suffix ($) kann mit Designer geändert werden.

7. So fügen Sie ein Bild ein:
a. Platzieren Sie den Cursor an der Stelle, an der das Bild im Feld "Anweisung" angezeigt werden soll.
b. Klicken Sie auf die Schaltfläche Bild einfügen/bearbeiten. Das Popup "Bild einfügen/bearbeiten" wird angezeigt.
c. Geben Sie in das Feld Quelle eine relative oder eine absolute URL für ein Bild ein.
d. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
e. Klicken Sie auf OK. Das Popup "Bild einfügen/bearbeiten" wird geschlossen und das Bild wird im Feld "Anweisung" angezeigt.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
