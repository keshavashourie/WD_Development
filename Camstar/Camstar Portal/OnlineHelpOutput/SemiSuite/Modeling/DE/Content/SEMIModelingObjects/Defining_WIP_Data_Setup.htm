Definieren von Umlaufbestandsdateneinrichtungsobjekten

Das Fabrikmodell von Opcenter Execution Semiconductor kann so konfiguriert werden, dass Daten an bestimmten Punkten während des Fertigungsprozesses gesammelt werden. Diese Konfiguration erfolgt über das Modellierungsobjekt "Umlaufbestandsdateneinrichtung". Nach der Konfiguration kann beim Modellieren einer Spezifikation oder einer Prozessspezifikation im Feld "Umlaufbestandsdateneinrichtung" auf die Einrichtung verwiesen werden.

Dynamisch berechnete Datensammlung

Eine berechnete Datensammlung wird mit einer Formel konfiguriert, die von der Anwendung während der Verarbeitung von Umlaufbestand verwendet wird, um den Wert zu berechnen. Formeln können Systemparametervariablen enthalten. Zum Beispiel weist WD$DATEN01 + WD$DATEN02 die Anwendung an, DATEN01 und DATEN01 zu addieren.

Wichtig: Setzen Sie Namen nicht in Klammern, wenn Sie diese Formeln erstellen. Verwenden Sie z. B. WD$DATEN01 anstelle von WD$(DATEN01).

Die folgende Tabelle enthält die Anwendungsparametervariablen, die für berechnete Datensammlungspunkte verfügbar sind.

SPC-Einrichtung

SPC-Einrichtung, die zugewiesen ist, um die Ergebnisse der Umlaufbestandsdatensammlung zu analysieren.

Die Umlaufbestandsdateneinrichtung löst den SPC-Analyseprozess während der Datensammlung aus, wenn mindestens eine Umlaufbestandsdateneingabe eine zugehörige SPC-Einrichtung hat, die ausgelöst werden soll. Wenn Sie die Daten aktualisieren, die sich auf die Umlaufbestandsdatensammlung beziehen, wird der SPC-Analyseprozess nur ausgelöst, wenn der Umlaufbestandsdatenname, der der SPC-Einrichtung zugeordnet ist, der aktualisierte Datenpunkt war. Wenn Sie die SPC-Analyse auslösen möchten, sobald irgendein Datenpunkt aktualisiert wurde, müssen Sie die SPC-Einrichtung jedem Umlaufbestandsdatennamen zuweisen, der durch die SPC-Analyse ausgewertet werden soll.

Hinweis: Ein Fehler tritt auf, wenn mehrere SPC-Einrichtungen in einer Umlaufbestandsdateneinrichtung unterschiedlich konfiguriert sind. Stellen Sie sicher, dass sie richtig konfiguriert wurden: entweder mit Legacy (Inline SPC = falsch) oder Inline (Inline SPC = wahr). Informationen zu Inline und Legacy SPC finden Sie im Opcenter Execution Semiconductor Statistical Process Control-Referenzhandbuch.

Hinweis: Die Umlaufbestandsdatengruppierung ist nur bei Verarbeitung von losspezifischen Umlaufbestandsdaten konfigurierbar ("Sind Elementdaten" nicht aktiviert). Wenn während der Umlaufbestandsdatensammlung für den Hauptumlaufbestand die Gruppierung "Ausrüstung" konfiguriert ist, wird durch die Transaktion der Datenwert des ersten eingegebenen Loses in alle Lose mit demselben Umlaufbestandsdatennamen kopiert, die auf derselben Ausrüstung vorhanden sind (Einbringen, Ausbringen). Vorgehensweise zum Definieren einer Umlaufbestandsdateneinrichtung

Gehen Sie folgendermaßen vor, um eine Umlaufbestandsdateneinrichtung zu definieren:

1. Öffnen Sie die Seite Umlaufbestandsdateneinrichtung. Die Seite "Umlaufbestandsdateneinrichtung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Einrichtung in das Feld Umlaufbestandsdateneinrichtung ein.
4. Führen Sie Folgendes für jeden Datensammlungspunkt in der Tabelle "Details" aus: Es wird ein Dateneingabefenster angezeigt, in dem Sie einen Datensammlungspunkt erstellen können.
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung öffnet das Popup "Hinzufügen".
b. Wählen Sie die Transaktion im Feld Servicename aus.
c. Wählen Sie den Namen des Datenpunkts im Feld Umlaufbestandsdatenname aus.
d. Klicken Sie auf Ist erforderlich, wenn die Daten eingegeben werden müssen.
e. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
f. Klicken Sie auf OK. Die Anwendung schließt das Popup "Hinzufügen" und zeigt die neu erstellten Sammlungspunktinformationen in der Tabelle "Details" an. Scrollen Sie horizontal in der Tabelle, um alle Tabelleninformationen zu sehen.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
