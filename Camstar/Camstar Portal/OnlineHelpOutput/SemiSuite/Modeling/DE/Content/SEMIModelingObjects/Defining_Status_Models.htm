Definieren von SCS-Statusmodellen

Opcenter Execution Semiconductor verwendet SCS-Statusmodelle, um Ressourcenstatusänderungen zu überprüfen. Das Objekt "SCS-Statusmodell" ermöglicht es Ihnen, einen Satz von gültigen Ressourcenstatusübergängen zu definieren. Jeder Übergang enthält einen "Status" ("Aktuell" oder "Von Status") und einen "Zu Status", z. B. "UAZ zu SBY" (Ungeplante Ausfallzeit zu Standby). Ein Statusmodell kann auch so konfiguriert werden, dass es die Erstellung eines Wartungsjobauftrags anhand von bestimmten Ursachencodes auslöst.

Hinweis: Ab Release 2310+ wurde die Seite "Statusmodell" in Semiconductor in Seite "SCS-Statusmodell" umbenannt. Die Objekte "SCS-Statusmodell" wurden ebenfalls mit dem Präfix 'scs' umbenannt (also scsStatusModel, scsStatusModelDetail und scsStatusModelDetailToReason).

Zuweisen eines Statusmodells zu einer Ressource

Sie weisen einer Ressource ein Statusmodell zu, indem Sie das Statusmodell auswählen, wenn Sie die Ressource definieren.

Vorgehensweise zum Definieren eines SCS-Statusmodells

Gehen Sie folgendermaßen vor, um ein SCS-Statusmodell zu definieren:

1. Öffnen Sie die Seite SCS-Statusmodell. Die Seite "SCS-Statusmodell" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das Modell in das Feld SCS-Statusmodell ein.
4. Klicken Sie in der Tabelle "Details" auf Neue Zeile hinzufügen. Das Popup "Hinzufügen" wird angezeigt.
5. Wählen Sie einen Status aus.
6. Wählen Sie in Zu Status einen Zielstatus aus.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf OK. Das Dialogfeld wird geschlossen.
9. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
