Definieren von SM-Feedern

Ein Feeder ist eine Ausrüstungsressource, die in einem Slot an einer Maschine platziert wird. Meistens wird ein Feeder zum Halten einer Rolle mit Material verwendet, das von der Maschine verbraucht wird.

Felddefinitionen der Seite "SM-Feeder"

Diese Tabelle definiert die Felder auf der Seite "SM-Feeder", die sich auf die Definition eines Feeders beziehen.

Wichtig: Alle anderen ausrüstungsbezogenen Felddefinitionen finden Sie unter "Felddefinitionen der Seite "Ausrüstung"".

Feld

Definition

Typ

Details

Feederfamilie

Feederfamilie, zu der der Feeder gehört.

Optional

Vorgehensweise zum Definieren eines SM-Feeders

Gehen Sie folgendermaßen vor, um einen SM-Feeder zu definieren:

1. Öffnen Sie die Seite SM-Feeder. Die Seite "SM-Feeder" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Feeder einen Namen für den Feeder ein.
4. Wählen Sie die Feederfamilie über das Feld Ressourcenfamilie aus, wenn der Feeder zu einer Feederfamilie gehört.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
