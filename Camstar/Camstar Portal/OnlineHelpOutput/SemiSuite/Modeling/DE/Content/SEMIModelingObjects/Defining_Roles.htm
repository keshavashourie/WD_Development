Definieren von Rollen

Eine Rolle bezieht sich auf eine Jobfunktion oder einen Funktionsbereich, z. B. Systemadministrator, Paketersteller, Standardmodellierung und SPC. Eine Rolle umfasst die Berechtigungen, die für die Jobfunktion oder den Funktionsbereich erforderlich sind, die oder den sie darstellt. Mitarbeiter können einer oder mehreren Rollen zugewiesen werden.

Felddefinitionen der Seite "Rolle"

In dieser Tabelle sind die Felder der Seite "Rolle" definiert.

Feld

Definition

Typ

Berechtigungstypfilter

Feld, um einen Filter auszuwählen, der die Liste der verfügbaren Berechtigungen einschränkt.

Optional

Tabelle "Zugewiesene Berechtigungen"

Tabelle, die jeden Berechtigungsnamen anzeigt, der in der Tabelle "Verfügbare Berechtigungen" ausgewählt wird.

Optional

Rollenberechtigungsname

Name der verfügbaren Berechtigung, die zur Aufnahme in die Rolle ausgewählt ist.

Erforderlich

Tabelle "Verfügbare Berechtigungen"

Tabelle, die die Berechtigungen anzeigt, die in die Rolle einbezogen werden können.

Optional

Berechtigungsname

Name der verfügbaren Berechtigung.

Erforderlich

Mitgliedschaft

 

 

Tabelle "Mitarbeiter-Rollenmitgliedschaften"

Eine Tabelle, die die Mitarbeiter anzeigt, die der Rolle zugewiesen wurden. Die Tabelle zeigt die Organisation an, für die die Rolle gilt. Sie zeigt auch an, ob die Rolle auch für jeden Benutzer auf die Unterorganisationen der Organisation übertragen wird.

Optional

[Kontrollkästchen]

Ermöglicht es Ihnen, einen Mitarbeiter auszuwählen. Aktivieren Sie das Kontrollkästchen in der Kopfzeile, wenn Sie automatisch alle angezeigten Mitarbeiter auswählen möchten.

Optional

Mitarbeiter

Name des Mitarbeiters, dem die Rolle zugewiesen wurde.

Optional

Organisation

Name der Organisation, für die die Rollenzuweisung zum betreffenden Mitarbeiter gilt. Dieses Feld kann leer bleiben, um anzuzeigen, dass diese Rolle ein Objekt ohne Organisationskontext ist, wie etwa eine Produktionstransaktion.

Optional

Weitergeben

Das Aktivieren dieses Kontrollkästchens gibt an, dass die Rolle für alle Unterorganisationen der Organisation gültig ist.

Optional

Nutzerfelder

 

 

Tabelle "Zugriffe"

Ermöglicht zusätzliche Zugriffsvalidierung in Modellierungs- und Fertigungsaktivitäten.

Optional

Einrichtungszugriff

Der für die Rolle des Benutzers konfigurierte Einrichtungszugriff bestimmt, welche Modellierungsinstanzen der Benutzer bearbeiten kann. Bearbeiten ist auf die Modellierungsinstanzen beschränkt, die denselben Einrichtungszugriff haben wie die Rolle.

Optional

Onlineabfrage: Einrichtung

Onlineabfrageeinrichtungen, die für die Rolle eines Benutzers konfiguriert sind, um zu bestimmen, auf welche Onlineabfrageeinrichtungen der Benutzer aus der Fertigung zugreifen kann.

Optional

Druckeinrichtung

Druckeinrichtungen, die für die Rolle eines Benutzers konfiguriert sind, um zu bestimmen, welche Druckeinrichtungen der Benutzer aus der Fertigung drucken kann.

Optional

Attributzugriff

Attributzugriff, der für die Rolle eines Benutzers konfiguriert ist. Bestimmt, welche Attribute für den Benutzer auf Fertigungstransaktionsseiten verfügbar sind.

Optional

Vorgehensweise zum Definieren einer Rolle

Gehen Sie folgendermaßen vor, um eine Rolle zu definieren.

1. Öffnen Sie die Seite Rolle. Die Seite "Rolle" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Rolle in das Feld Rolle ein.Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
4. Wählen Sie einen Berechtigungstyp aus dem Feld Berechtigungstypfilter aus. Die Tabelle "Verfügbare Berechtigungen" wird aktualisiert und enthält nun die Berechtigungen des angegebenen Berechtigungstyps.
5. Wählen Sie mit einer der folgenden Methoden die Berechtigungen aus, die Sie zuweisen möchten:
• Aktivieren Sie das Kontrollkästchen Berechtigungsname in der Kopfzeile der Tabelle "Verfügbare Berechtigungen", um alle Berechtigungen auszuwählen.
• Aktivieren Sie die Kontrollkästchen der einzelnen Berechtigungen.
6. Klicken Sie auf < Hinzufügen, um die ausgewählten Berechtigungen zuzuweisen. Die Berechtigungen werden der Tabelle "Zugewiesene Berechtigungen" hinzugefügt und alle Zugriffsmodi werden standardmäßig ausgewählt.
7. Wiederholen Sie die Schritte 5 bis 6, um zusätzliche Berechtigungen für diese Rolle hinzuzufügen.
8. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
9. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
