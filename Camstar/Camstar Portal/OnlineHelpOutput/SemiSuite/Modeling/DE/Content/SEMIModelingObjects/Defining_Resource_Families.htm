Definieren von Ausrüstungsfamilien

Sie definieren Ausrüstungsfamilien, um eine Gruppierung der Ausrüstung nach Attributen zu ermöglichen.

Felddefinitionen der Seite "Ausrüstungsfamilie"

Diese Tabelle definiert die Felder auf der Seite "Ausrüstungsfamilie".

Feld

Definition

Typ

Typ der Ausrüstungsfamilie

Eindeutiger Name für die Ausrüstungsfamilie, wobei Typ für den Lagerbestandsbereich steht, für den die Spezifikation gilt. Für den Zusammenbaubereich lautet das Feld z. B. "Zusammenbauausrüstung: Familie".

Erforderlich

Allgemein

Jobbenachrichtigung: E-Mail-Gruppe

Gibt die E-Mail-Gruppe an, die benachrichtigt werden soll, wenn ein Fehler erkannt wird.

Optional

Statusmodell

Name des Statusmodellobjekts, das den erlaubten Statussatz (Behälterstatuscodes) für diese Ausrüstungsfamilie angibt, in den ein Ressourcenstatus basierend auf seinem aktuellen Status übergeben werden kann.

Optional

Maßeinheit

Maßeinheit zum Messen von Wafern, die von Ausrüstung dieser Familie verarbeitet werden.

Optional

Prozess: Nutzungsanforderungen (Ad-hoc)

Kontrollkästchen, das angibt, ob die Ad-hoc-Verarbeitung von Ausrüstung in dieser Familie zum Erhöhen der Nutzungsanforderungszähler führen soll (sofern konfiguriert).

Optional

Wafer-Handler

Kontrollkästchen, das angibt, welche Ausrüstungsfamilie eine Wafer-Handler-Familie ist, um die angezeigte Ausrüstungsliste zu begrenzen.

Optional

Vorgehensweise zum Definieren einer Ausrüstungsfamilie

Gehen Sie folgendermaßen vor, um eine Ausrüstungsfamilie zu definieren:

1. Wählen Sie Haupt im Menü Modellierung aus. In der Anwendung wird die Registerkarte "Haupt" angezeigt.
1. Geben Sie in das Filterfeld "Objekte" die Zeichenfolge Ausrüstungsfamilie ein. Die Liste der Objekttypen für die Ausrüstungsfamilie wird anzeigt.
2. Wählen Sie das Ausrüstungsfamilienobjekt basierend auf dem Zeitplantyp (Wafer, Zusammenbau usw.) aus. Die Liste der Instanzen und das Menü für den ausgewählten Objekttyp werden angezeigt.
3. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
4. Geben Sie in das Feld <Typ>-Ausrüstung: Familie einen eindeutigen Namen für die Ausrüstungsfamilie ein. Dabei steht Typ für den Bereich, auf den die Ausrüstungsfamilie angewendet wird.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
