Definieren von Nummerierungsregeln

Eine Nummerierungsregel ist ein konfigurierbares Nummerierungsschema, das Matrixobjekten, Qualitätsdatensätzen und Losen automatisch eindeutige Nachverfolgungsnummern zuweist. In der Regel definiert eine Organisation ein Nummerierungsschema und weist das Schema diesen Objekten zu. Die Anwendung wendet das entsprechende Nummerierungsschema an und weist dem entsprechenden Matrixobjekt, Qualitätsdatensatz oder Container die nächste verfügbare ID oder Nummer zu. Weitere Informationen zu Nummerierungsregeln finden Sie im Opcenter Execution Core Modeling-Benutzerhandbuch.

Definieren von Nummerierungsregeln für Container und Lose

Die Anwendung verwendet die in den folgenden Modellierungsobjekten angegebenen Nummerierungsregeln, um automatisch Container- und Losnamen zu generieren:

• Produkt
• Produktfamilie
• Serviceeinrichtung

"Nummerierungsregel" ist ein optionales Feld in diesen Modellierungsdefinitionen.

Benutzer in der Fertigung haben die Möglichkeit, beim Starten von Eltern- und Kindcontainern, Aufteilen von Containern und Losen sowie beim Aufteilen von Mengen automatisch Containernamen zu generieren. Informationen zum automatischen Erzeugen von Containernamen finden Sie im Opcenter Execution Core Shop Floor-Benutzerhandbuch.

Die Anwendung verwendet diese Rangordnung, um die zu verwendende Nummerierungsregel zu bestimmen, wenn für mehrere Modellierungsobjekte Nummerierungsregeln festgelegt wurden:

1. Produkt
2. Produktfamilie
3. Serviceeinrichtung

Formatanforderungen für Eingaben in die Felder

Nummern dürfen maximal 30 Zeichen lang sein, einschließlich des jeweiligen Präfixes (Vorsilbe) und Suffixes (Nachsilbe) sowie der Sequenznummer. Die generierte Nummer wird folgendermaßen berechnet:

Nummer = Präfix (falls vorhanden) + Sequenznummer (erforderlich) + Suffix (falls vorhanden)

Z. B.: EREIGNIS-ABT15-00000001-2014

Die Felder "Vorsilbe" und "Nachsilbe" können entweder für literale Einträge oder für Einträge mit Syntax für einheitliche Ausdrücke verwendet werden.

Beide erfordern sehr spezielle Formate, z. B.:

• Ein literales Präfix kann z. B. als "ABCUnt_" oder "_Schmidt" definiert sein. Der jeweilige Eintrag muss in doppelten Anführungszeichen stehen.
• Die Syntax für einheitliche Ausdrücke kann genutzt werden, um ein dynamisches Präfix oder Suffix zu erzeugen, etwa:
• Präfix = "(<Organisation.Name>"
• Suffix ="_"+StrSubstring(String(TruncateTime(GMTToLocal(SetSystemDateGMT()))),(StrLength(String(TruncateTime(GMTToLocal(SetSystemDateGMT()))))-4),4)

Informationen zur Syntax für einheitliche Ausdrücke finden Sie im Opcenter Execution Core Designer-Benutzerhandbuch.

Typ der Nummerierungsregel

Liste mit den Nummerierungsregeltypen, die zur Auswahl stehen. Mögliche Werte sind:

• Hohes Volumen / Überspringen
• Geringes Volumen / Nicht überspringen

Erforderlich

Präfix (dynamischer Ausdruck)

Sie können ein Präfix (Vorsilbe) definieren, das vor die Sequenznummer gesetzt werden soll. Das Präfix kann sowohl statische Zeichenketten als auch Syntax für einheitliche Ausdrücke enthalten, um dynamischen Text zu generieren. Ein Beispiel für ein Präfix mit statischem Text ist "PE-ORG15". Sie müssen den Eintrag, wie im Beispiel gezeigt, in doppelte Anführungszeichen setzen.

Optional

Suffix (dynamischer Ausdruck)

Sie können ein Suffix (Nachsilbe) definieren, das an die Sequenznummer angehängt werden soll. Das Suffix kann sowohl statische Zeichenketten als auch Syntax für einheitliche Ausdrücke enthalten, um dynamischen Text zu generieren. Ein Beispiel für ein Suffix mit statischem Text ist die vierstellige Jahreszahl "2014" oder der Produktname "DGMON". Sie müssen den Eintrag, wie in den Beispielen gezeigt, in doppelte Anführungszeichen setzen.

Optional

Präfix basierend auf der letzten zugeordneten Sequenz verwenden

Gibt an, ob die regelbasierte Sequenzierung durch präfixbasierte Sequenzierung überschrieben werden soll.

Hinweis: Die präfixbasierte Sequenzierung ist für Nummerierungsregeln sinnvoll, die mit einheitlichen Ausdrücken zur dynamischen Erzeugung von Präfixen konfiguriert wurden. Die Anwendung weist immer dann einen Anfangssequenzwert zu, wenn eine Nummerierungsregel zum ersten Mal ein eindeutiges Präfix erzeugt. Wenn eine Nummerierungsregel später dasselbe Präfix erzeugt, erhöht die Anwendung beim Erzeugen des Containernamens die zuletzt zugewiesene Sequenz für dieses Präfix.

Weitere Informationen finden Sie im Opcenter Execution Core Modeling-Benutzerhandbuch.

Optional

Hexadezimalwert verwenden

Gibt an, ob ein Hexadezimalwert anstelle des Integer-Werts verwendet werden soll.

Optional

Alphanumerischen Wert verwenden

Kontrollkästchen, das angibt, ob eine alphanumerische Nummerierung für die Sequenz verwendet werden soll.

Hinweis: Diese Option kann sowohl für die regelbasierte als auch für die präfixbasierte Sequenzierung verwendet werden.

Optional

Nummerierungsregeloptionen

Einstellung, die das Verhalten der Nummerierungsregel steuert, wenn der maximale Sequenzwert erreicht wird. Die Nummerierungsregeloptionen umfassen Folgendes:

• Rollover – Die Sequenz wird neu gestartet, nachdem ein vordefinierter Grenzwert erreicht wurde. Wenn der maximale Sequenzwert erreicht ist, beginnt die Nummerierungsregel, aufsteigende Werte ab dem Wert zu generieren, der im Feld "Zuletzt zugewiesener Wert" angegeben ist.

Hinweis: Ein Fehler triff auf, wenn bei Auswahl von "Rollover" ein doppelter Containername erkannt wird.

• Stopp – Die Sequenz hält an einem vordefinierten Grenzwert an. Die Nummerierungsregel kann nach Erreichen des Maximalwerts keine Werte mehr generieren.
• Fortsetzen – Die Sequenz wird ohne Begrenzung inkrementiert. Die Nummerierungsregel erzeugt weiterhin Werte, nachdem der Maximalwert erreicht wurde.

Hinweis: Dieses Feld wird aktiviert, wenn das Kontrollkästchen "Alphanumerischen Wert verwenden" ausgewählt wird.

Optional

Max. Wert

Sie können einen zu generierenden Maximalwert definieren. Dieser Wert muss Integer-Werte akzeptieren, wenn die Nummerierungsregel keine Hexadezimalwerte verwendet, und ansonsten Hexadezimalwerte unterstützen. Wenn die Nummerierungsregel einen Wert generiert, der den festgelegten Maximalwert überschreitet, wird eine Fehlermeldung angezeigt.

Optional

Werte verwenden

Gibt an, ob die Werteliste zum Abrufen der nächsten Sequenz anstelle der Sequenzlänge verwendet wird.

Optional

Werte bei Präfixänderung zurücksetzen

Gibt an, ob der in Werten verwendete Index auf den ersten Wert zurückgesetzt wird, wenn sich der dynamische Wert des Präfixes während der Generierung ändert.

Hinweis: Sie müssen das Feld "Werte verwenden" aktivieren, um dieses Feld verwenden zu können.

Optional

Werte bei Suffixänderung zurücksetzen

Gibt an, ob der in Werten verwendete Index auf den ersten Wert zurückgesetzt wird, wenn sich der dynamische Wert des Suffixes während der Generierung ändert.

Hinweis: Sie müssen das Feld "Werte verwenden" aktivieren, um dieses Feld verwenden zu können.

Optional

Letzte zugeordnete Sequenz

Die letzte Sequenznummer, die einem Qualitätsdatensatz zugeordnet wurde. Die Anwendung berechnet die nächste zuzuordnende Sequenznummer, indem sie diese Nummer um 1 erhöht. Der Standardwert ist 0.

Erforderlich

Sequenzlänge

Gewünschte Länge der Sequenznummer. Die maximale Länge einer berechneten Sequenznummer beträgt 30 Zeichen, vorausgesetzt, es werden weder ein Präfix (Vorsilbe) noch ein Suffix (Nachsilbe) verwendet.

Erforderlich

Transaktionsdatenschlüssel (dynamischer Ausdruck)

Das Feld wird verwendet, wenn die nächste Sequenz mithilfe der Werteliste verwendet wird. Der aufgelöste Wert des Transaktionsschlüssels wird in der Liste "Transaktionsdaten" gespeichert, um mehrere Sequenzen pro Einrichtung zu erlauben. Die Einrichtung einer Nummerierungsregel kann z. B. von mehreren Ausrüstungsteilen zum Generieren einer Durchlaufnummer verwendet werden. Damit also gewährleistet ist, dass jede Ausrüstung ihre eigene Sequenz aufweist, muss der Transaktionsschlüssel als Ausrüstungsname konfiguriert werden.

Optional

Tabelle "Reihenfolgewerte"

Liste, die eine bestimmte Reihenfolge der Werte angibt, die anstelle einer Reihenfolgenummer zum Generieren der Reihenfolge verwendet wird. Die Reihenfolge, in der der Wert eingerichtet wird, ist wichtig, da die Logik immer dann den nächsten Index auswählt, wenn eine Reihenfolge erforderlich ist.

Optional

Wert

Wert für die Reihenfolge.

Optional

Tabelle "Transaktionsdaten"

Wird verwendet, wenn die Werteliste zum Generieren der nächsten Reihenfolge verwendet wird. Der aufgelöste Wert jedes Transaktionsdatenschlüssels dient zum Verfolgen verschiedener Sequenzen mit einer Nummerierungsregeleinrichtung.

Optional

Schlüsselwert

Schlüssel, der zum Generieren der Reihenfolge mithilfe der Werteliste verwendet wird.

Erforderlich

Letzte Wertzeichenkette

Letzte Wertzeichenkette, die in der übergeordneten Werteliste zum Generieren der Reihenfolge verwendet wird.

Optional

Letzter Präfixwert

Letzter aufgelöster Wert des Präfixes. Dieser wird für den Vergleich mit dem generierten Präfix verwendet, um zu bestimmen, ob die Werte bei einer Änderung zurückgesetzt werden müssen.

Optional

Letzter Suffixwert

Letzter aufgelöster Wert des Suffixes. Die Anwendung vergleicht diesen Wert mit dem generierten Suffix, um zu bestimmen, ob die Werte bei einer Änderung zurückgesetzt werden.

Optional

Vorgehensweise zum Definieren eine Nummerierungsregel

Gehen Sie folgendermaßen vor, um eine Nummerierungsregel zu definieren:

1. Öffnen Sie die Seite Nummerierungsregel. Die Seite "Nummerierungsregel" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Nummerierungsregel in das Feld Nummerierungsregel ein.
4. Wählen Sie einen Typ der Nummerierungsregel aus.
5. Geben Sie einen Wert in das Feld Letzte zugeordnete Sequenz ein.
6. Geben Sie einen Wert in das Feld Sequenzlänge ein.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
