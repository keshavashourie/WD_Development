Definieren von Masken

Masken dienen zum Angeben der erforderlichen Maskentools, die vor der Verarbeitung mit der Ausrüstung verknüpft werden müssen.

Felddefinitionen der Seite "Maske"

Diese Tabelle definiert die Felder auf der Seite "Maske".

Kontrollkästchen, das Sie aktivieren müssen, wenn Sie erlauben möchten, dass mehrere Schritte gleichzeitig eingebracht werden, wenn deren Anforderungen identisch sind. Das mehrstufige Einbringen ist zulässig, wenn die folgenden Anforderungen erfüllt sind:

• Gleiche Maske
• Gleicher Werkzeugplan
• Gleiche Materialien erforderlich

Automatisierung aktiviert

Kontrollkästchen zur Angabe, ob die betreffende Ausrüstung mit einer Automatisierungsebene verknüpft ist. Wenn dieses Feld aktiviert ist, wird davon ausgegangen, dass die Rezeptauswahl und -überprüfung auf der Automatisierungsebene durchgeführt wird. Die Rezeptverifizierung durch Semiconductor Suite wird deaktiviert.

Optional

Rezept erforderlich

Kontrollkästchen zur Angabe, ob ein Rezept innerhalb einer Ebene der Modellierungshierarchie (Prozessspez., Rezeptmatrix, Pauschalversuch, Losversuch usw.) konfiguriert werden muss. Wenn "Rezept erforderlich" aktiviert ist, schlägt die Einbringung fehl, wenn ein Rezept nicht erkannt wird. Dieses Feld wird ignoriert, wenn "Automatisierung aktiviert" auf wahr festgelegt ist.

Optional

Vorgehensweise zum Definieren einer Maske

Gehen Sie folgendermaßen vor, um eine Maske zu definieren:

1. Öffnen Sie die Seite Maske. Die Seite "Maske" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Maske den Namen der Maske ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
