Definieren von Einrichtungen für zukünftiges Anhalten bei Fehlern

Einrichtungen für zukünftiges Anhalten bei Fehlern werden zum Definieren von Einrichtungsdetails verwendet, die erforderlich sind, wenn für Lose im Falle eines Fehlers ein zukünftiges Anhalten festgelegt wird.

Vorgehensweise zum Definieren einer Einrichtung für zukünftiges Anhalten bei Fehlern

Gehen Sie folgendermaßen vor, um eine Einrichtung für zukünftiges Anhalten bei Fehlern zu definieren:

1. Öffnen Sie die Seite Einrichtung für zukünftiges Anhalten bei Fehlern. Die Seite "Einrichtung für zukünftiges Anhalten bei Fehlern" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Einrichtung für zukünftiges Anhalten bei Fehlern den Namen der Einrichtung für zukünftiges Anhalten bei Fehlern ein.
4. Führen Sie Folgendes für jedes zukünftige Anhalten in der Tabelle "Einrichtung für zukünftiges Anhalten: Details" aus:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
b. Geben Sie in das Feld Spez. die Spezifikation ein, die die Verarbeitung des zukünftigen Anhaltens beschreibt.
c. Geben Sie in das Feld Anhaltegrund den Grund für das zukünftige Anhalten ein.
d. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
e. Wiederholen Sie die Schritte a bis d für jedes hinzuzufügende zukünftige Anhalten.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
