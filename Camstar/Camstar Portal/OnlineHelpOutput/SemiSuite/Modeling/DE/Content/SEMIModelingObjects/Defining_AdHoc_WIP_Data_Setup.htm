Definieren von Ad-hoc-Umlaufbestandsdateneinrichtungen

Ad-hoc-Umlaufbestandsdateneinrichtungen dienen zum Konfigurieren einer Liste mit Umlaufbestandsdateneinrichtungsobjekten, die zum Sammeln von Daten für ein Objekt (z. B. ein Los oder eine Ausrüstung) verwendet werden können. Die meisten Umlaufbestandsdaten werden in einem vordefinierten Schritt und zu einer festgelegten Uhrzeit (z. B. beim Ausbringen) gesammelt, aber Sie können Ad-hoc-Umlaufbestandsdateneinrichtungen zum Sammeln von Daten für einen beliebigen Objekttyp und an einem beliebigen Sammlungspunkt verwenden.

Beim Definieren von Ad-hoc-Umlaufbestandsdateneinrichtungen

Sie müssen den Objekttypnamen als Instanznamen für die Ad-hoc-Umlaufbestandsdateneinrichtung verwenden. Verwenden Sie z. B. den Namen "Los", um eine Einrichtung für Lose zu erstellen. Verwenden Sie den Namen "Ausrüstung", um eine Einrichtung für Ausrüstung zu erstellen.

Vorgehensweise zum Definieren einer Ad-hoc-Umlaufbestandsdateneinrichtung

Gehen Sie folgendermaßen vor, um eine Ad-hoc-Umlaufbestandsdateneinrichtung zu definieren:

1. Öffnen Sie die Seite Ad-hoc-Umlaufbestandsdateneinrichtung. Die Seite "Ad-hoc-Umlaufbestandsdateneinrichtung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Ad-hoc-Umlaufbestandsdateneinrichtung den Namen des Objekttyps ein.
4. Gehen Sie folgendermaßen vor, um Umlaufbestandsdateneinrichtungen zur Tabelle "Details" hinzuzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
b. Geben Sie in das Feld Umlaufbestandsdateneinrichtung den Namen für die Umlaufbestandsdateneinrichtung ein.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
