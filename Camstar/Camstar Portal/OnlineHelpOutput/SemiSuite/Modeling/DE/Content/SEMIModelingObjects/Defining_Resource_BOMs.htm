Definieren von Ressourcenstücklisten

Eine Ressourcenstückliste ist eine Stückliste für eine Ressource. Eine Ressourcenstückliste enthält mindestens ein Ressourcenmaterialteil.

Wo Ressourcenstücklisten verwendet werden

Eine Ressourcenstückliste wird an den Stellen referenziert:

• Wartungsanforderung: Gibt die Teile an, die wegen einer Wartungsverletzung für einen Job erforderlich sind.
• Ressource: Gibt die Teile an, die für eine Ressource erforderlich sind.

Vorgehensweise zum Definieren einer Ressourcenstückliste

Gehen Sie folgendermaßen vor, um eine Ressourcenstückliste zu definieren:

1. Öffnen Sie die Seite Ressourcenstückliste. Die Seite "Ressourcenstückliste" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Stückliste in das Feld Ressourcenstückliste ein.
4. Klicken Sie auf Neue Zeile hinzufügen in der Tabelle "Materialliste". Eine neue Zeile wird angezeigt.
5. Wählen Sie das Produkt einschließlich der Revisionsnummer aus.
6. Geben Sie die Erforderliche Menge ein.
7. Wiederholen Sie die Schritte 4 bis 6, um weitere Ressourcenmaterialteile für diese Ressourcenstückliste hinzuzufügen.
8. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
9. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
