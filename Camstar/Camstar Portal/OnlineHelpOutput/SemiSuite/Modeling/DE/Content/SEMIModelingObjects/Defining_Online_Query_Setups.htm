Definieren von Onlineabfrageeinrichtungen

Onlineabfrageeinrichtungen werden verwendet, um Laufzeitdaten mit dem Onlineabfrage-Dienst anzuzeigen.

Beim Definieren von Onlineabfrageeinrichtungen

Das Feld "Größenlimit für Ergebnismenge" muss verwendet werden, um die Auswirkungen auf die Speichernutzung zu minimieren.

Felddefinitionen der Seite "Onlineabfrage: Einrichtung"

Diese Tabelle definiert die Felder auf der Seite "Onlineabfrage: Einrichtung".

Feld

Definition

Typ

Abfragedefinition

Abfragetext

SQL-Abfrage-Anweisung. Die Standardbegrenzung für dieses Feld beträgt 4.000 Zeichen. Diese Begrenzung kann in Designer angepasst werden. Weitere Informationen finden Sie im Opcenter Execution Core Designer-Benutzerhandbuch.

Erforderlich

Tabelle "Parameter"

Tabelle, die die Parameter der Abfrage definiert. Wird als benanntes Unterobjekt definiert und der Parametername ist jeweils eindeutig.

Erforderlich

Name für Benutzerabfrageparameter

Eindeutiger Name für den Abfrageparameter.

Erforderlich

Datentyp

Datentyp des Abfrageparameters. Folgende Auswahlmöglichkeiten sind verfügbar:

• Boolesch
• Dezimal
• Festkomma
• Gleitkomma
• Integer
• Objekt
• Zeichenkette
• Zeitstempel

Erforderlich

Text anzeigen

Text, der für den Parameter angezeigt wird, wenn die Abfrage ausgeführt wird.

Optional

Parameterwert

Standartwert für den Parameter.

Optional

Dynamischer Wert

Wert, der in den tatsächlichen Wert aufgelöst wird, der für die Abfrage verwendet werden soll. Dieses Feld wird von der internen Logik verwendet, wenn die Einrichtung einer Online-Abfrage intern durch einen Service ausgelöst wird. Ein Beispiel wäre die Überprüfung eines Erledigungsplans, um festzustellen, ob ein Los das nächste Los der Transaktion ist. Wenn dieses Feld nicht festgelegt ist, wird der Standardwert verwendet.

Optional

Ist erforderlich

Option, die angibt, ob der Parameter erforderlich ist.

Optional

Für Blockzeilen verwenden

Gibt an, ob der Parameter verwendet werden soll, um Blockzeilen abzurufen. Dieser Wert wird in der Onlineabfrage-Benutzeroberfläche verwendet, um die Schaltflächen "Weiter" und "Zurück" zum Abrufen der Zeilen zu automatisieren.

Hinweis: Sie können dieses Flag nur für einen Parameter festlegen.

Optional

Nutzerfelder

Name der Behälterspalte

Rückgabespaltenname für den Behälter. Wird der Name nicht angegeben, erwartet Logik, die ihn benötigt, den Wert CARRIER.

Optional

Name der Ausrüstungsspalte

Rückgabespaltenname für die Ausrüstung. Wird der Name nicht angegeben, erwartet Logik, die ihn benötigt, den Wert EQUIPMENT.

Optional

Name der Losspalte

Rückgabespaltenname für die Los-ID. Wird der Name nicht angegeben, erwartet Logik, die ihn benötigt, den Wert LOT.

Optional

Größenlimit für Ergebnismenge

Maximale Anzahl erwarteter Datensätze. Mit diesem Wert wird die Anzahl der zurückgegebenen Datensätze begrenzt, um die Speicherauslastung zu minimieren.

Optional

Felddefinitionen des Popups "Onlineabfrage: Einrichtung: Test"

Diese Tabelle definiert die Felder im Popup "Onlineabfrage: Einrichtung: Test".

Feld

Definition

Typ

Abfrageparameter

Eingabedaten für die Parameter, die in der SQL-Abfrage-Anweisung genannt werden. Es werden keine Felder angezeigt, wenn keine Eingabe erforderlich ist.

Hinweis: Die im Popup angezeigten Felder variieren entsprechend Ihrer SQL-Anweisung.

Erforderlich

Abfrageergebnisse

Die Ergebnisse der Testabfrage. Die Ergebnisse werden automatisch angezeigt, wenn keine Parameter erforderlich sind. Wenn Parameter erforderlich sind, werden die Ergebnisse erst angezeigt, wenn Sie die Parameter eingeben und auf "Abfrage testen" klicken.

Optional

Vorgehensweise zum Definieren einer Onlineabfrageeinrichtung

Gehen Sie folgendermaßen vor, um eine Onlineabfrageeinrichtung zu definieren:

1. Öffnen Sie die Seite Onlineabfrage: Einrichtung. Die Seite "Onlineabfrage: Einrichtung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen der Onlineabfrageeinrichtung in das Feld Onlineabfrage: Einrichtung ein.
4. Geben Sie in das Feld Abfragetext den Text der SQL-Abfrageanweisung ein.
5. Gehen Sie folgendermaßen vor, um Parameter zur Tabelle "Parameter" hinzuzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
b. Geben Sie in das Feld Name für Benutzerabfrageparameter den Namen des Parameters für die GUI-Abfrage ein.
c. Geben Sie in das Feld Datentyp den Datentyp des Parameters für die GUI-Abfrage ein.
d. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Testen der Abfrage

Gehen Sie folgendermaßen vor, um die Definition einer Onlineabfrage zu testen:

1. Führen Sie die Schritte in "Vorgehensweise zum Definieren einer Onlineabfrageeinrichtung" aus.

Oder

Wählen Sie eine vorhandene Instanz der Onlineabfrageeinrichtung aus.

2. Klicken Sie auf Abfrage speichern und testen, um die Abfrage zu speichern und zu testen. Die Anwendung öffnet das Popup "Onlineabfrage: Einrichtung: Test".
3. Geben Sie alle Parameter ein, die die Abfrage erfordert.
4. Klicken Sie auf Abfrage testen. Alle Ergebnisse, die der Abfrage und den eingegebenen Parametern entsprechen, werden in der Tabelle "Abfrageergebnisse" angezeigt.
5. Klicken Sie auf Schließen. Das Popup "Onlineabfrage: Einrichtung: Test" wird geschlossen.
