Definieren von Ferien der Zykluszeit

Die Zykluszeit bezieht sich auf die geschätzte Anzahl von Tagen, bis der Arbeitsplan für die Umlaufbestandsverarbeitung abgeschlossen ist. Ferien der Zykluszeit werden verwendet, um das geschätzte Enddatum zu verschieben, wenn das Enddatum der Zykluszeit für den Loszeitplan berechnet wird.

Felddefinitionen der Seite "Zykluszeit: Ferien"

Diese Tabelle definiert die Felder, die nur auf der Seite "Zykluszeit: Ferien" zu finden sind.

Feld

Definition

Typ

Details

Tagesfaktor

Anzahl der Tage, die als Offset verwendet werden, wenn das Datum und die Uhrzeit des Zyklus berechnet werden. Muss null oder eins sein.

Erforderlich

Feriendatum

Datum, an dem die Ferien beginnen.

Erforderlich

Arbeitsplanobjekttyp

Typ der Arbeitsplanverarbeitung, für die diese Ferien der Zykluszeit verwendet werden, um ein Enddatum der Verarbeitung zu berechnen.

Erforderlich

Vorgehensweise zum Definieren von Ferien der Zykluszeit

Gehen Sie folgendermaßen vor, um Ferien der Zykluszeit zu definieren:

1. Öffnen Sie die Seite Zykluszeit: Ferien. Die Seite "Zykluszeit: Ferien" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie im Feld Zykluszeit: Ferien einen Namen für die Ferien der Zykluszeit ein.
4. Geben Sie einen Tagesfaktor ein.
5. Geben Sie das Feriendatum ein.
6. Geben Sie den Arbeitsplanobjekttyp ein.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
