Definieren von Attributeinrichtungen

Auf der Seite "Attributeinrichtung" können Sie zulässige Änderungen an vorhandenen Los- und Containerattributen zu konfigurieren. Auf ihr können Sie auch Benutzerattribute erstellen, die in "Ext. Losattribute" ohne Designer-Änderungen gespeichert werden.

Vorgehensweise zum Definieren einer Attributeinrichtung

Gehen Sie folgendermaßen vor, um eine Attributeinrichtung zu definieren:

1. Öffnen Sie die Seite Attributeinrichtung. Die Seite "Attributeinrichtung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Attributeinrichtung in das Feld Attributeinrichtung ein.
4. Klicken Sie in der Tabelle "Details" auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
5. Geben Sie in das Feld Attributwert einen Wert ein.
6. Geben Sie einen Wert ein, in den das Attribut basierend auf dem Attributwert im Feld Attributrevision geändert werden kann.
7. Wiederholen Sie die Schritte 4 bis 6, um weitere Elemente hinzuzufügen.
8. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
9. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
