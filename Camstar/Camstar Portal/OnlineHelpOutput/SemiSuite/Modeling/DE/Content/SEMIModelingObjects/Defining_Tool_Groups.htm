Definieren von Werkzeuggruppen

Eine Werkzeuggruppe dient zum Gruppieren einzelner Werkzeuge.

Beim Definieren von Werkzeuggruppen

Sie müssen Werkzeuge definieren, die Bestandteile der Werkzeuggruppe sein sollen, bevor Sie eine Werkzeuggruppe definieren können.

Felddefinitionen der Seite "Werkzeuggruppe"

Diese Tabelle definiert die Felder auf der Seite "Werkzeuggruppe".

Feld

Definition

Typ

Allgemein

Eintragstyp

Gibt den Objekttyp an, der in dieser Gruppe enthalten ist, z. B. Werkzeug für Werkzeuggruppen.

Optional

Tabelle "Einträge"

Liste der Werkzeuge, die der Werkzeuggruppe hinzugefügt werden sollen.

Optional

Tabelle "Gruppen"

Liste der Werkzeuggruppen, die der Werkzeuggruppe als Untergruppen hinzugefügt werden sollen.

Optional

Vorgehensweise zum Definieren einer Werkzeuggruppe

Gehen Sie folgendermaßen vor, um eine Werkzeuggruppe zu definieren:

1. Öffnen Sie die Seite Werkzeuggruppe. Die Seite "Werkzeuggruppe" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Werkzeuggruppe in das Feld Werkzeuggruppe ein.
4. Gehen Sie folgendermaßen vor, um Werkzeuge zur Tabelle "Einträge" hinzuzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen. Wählen Sie ein Werkzeug aus der Liste aus, die in der Tabelle angezeigt wird.
b. Wiederholen Sie die Schritte für jedes Werkzeug, das Sie der Werkzeuggruppe hinzufügen möchten.
5. Gehen Sie folgendermaßen vor, um Werkzeuguntergruppen zur Tabelle "Gruppen" hinzuzufügen:
a. Klicken Sie auf Neue Zeile hinzufügen. Wählen Sie eine Werkzeuggruppe aus der Liste aus, die in der Tabelle angezeigt wird.
b. Wiederholen Sie die Schritte für jede Werkzeuggruppe, die Sie als Untergruppe hinzufügen möchten.
6. Klicken Sie auf Aufgelöste Einträge. Die Anwendung zeigt ein Popup an, in dem die Liste aller Werkzeuge angezeigt wird, die in der Werkzeuggruppe enthalten sind. Werkzeuge aus den Werkzeuggruppen werden einzeln aufgeführt.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
