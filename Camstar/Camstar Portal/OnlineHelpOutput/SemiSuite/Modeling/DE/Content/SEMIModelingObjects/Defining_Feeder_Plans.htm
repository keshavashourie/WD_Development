Definieren von SM-Feederplänen

Ein Feederplan definiert die einzelnen Feederslots einer Ausrüstungsressource und den Typ der zulässigen Komponentenmaterialien für den Slot.

Felddefinitionen der Seite "SM-Feederplan"

Diese Tabelle definiert die Felder auf der Seite "SM-Feederplan".

Feld

Definition

Typ

Details

Tabelle "Details"

Tabelle mit einer Liste der Slotinformationen für Feeder, Feederfamilien und Feedergruppen.

Optional

Slot

Gibt einen physischen Slot für eine Ressource an. Zweck des Slots ist das Halten eines Komponentenmaterialfeeders.

Optional

Produkt

Komponentenmaterial, das von einem Feeder gehalten wird.

Optional

Feeder

Typ der Ausrüstungsressource, die in einem Slot an einer Maschine platziert wird. Meistens wird ein Feeder zum Halten einer Rolle mit Material verwendet, das von der Maschine verbraucht wird.

Optional

Feederfamilie

Kategorie der Feeder, die gemeinsame Attribute verwenden.

Optional

Feedergruppe

Sammlung von Feedern mit ähnlichen Eigenschaften.

Optional

Vorgehensweise zum Definieren eines SM-Feederplans

Gehen Sie folgendermaßen vor, um einen SM-Feederplan zu definieren:

1. Öffnen Sie die Seite SM-Feederplan. Die Seite "SM-Feederplan" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Feederplan einen Namen für den Feederplan ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
