Definieren von physischen Positionen

Das Objekt "Physische Position" ermöglicht es Ihnen, einen Bereich in einem physischen Ort zu konfigurieren. Zum Beispiel kann "Lagerhalle" ein definierter physischer Ort und "Regal A-1" eine definierte physische Position sein. Definierte physische Positionen können Sie in der Tabelle "Positionen" auswählen, wenn Sie einen physischen Ort definieren.

Vorgehensweise zum Definieren einer physischen Position

Gehen Sie folgendermaßen vor, um eine physische Position zu definieren:

1. Öffnen Sie die Seite Physische Position. Die Seite "Physischer Ort" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Position in das Feld Physische Position ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
