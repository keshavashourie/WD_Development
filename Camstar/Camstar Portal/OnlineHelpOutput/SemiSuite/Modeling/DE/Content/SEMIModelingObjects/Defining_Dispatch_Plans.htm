Definieren von Erledigungsplänen

Mit einem Erledigungsplan können Sie die Reihenfolge der Lose steuern, die in den Portaltabellen zur Losauswahl angezeigt werden. Außerdem können Sie über den Erledigungsplan eine Transaktion angeben und festlegen, ob Lose von dieser Transaktion in der Reihenfolge ihrer Auflistung verarbeitet werden müssen. Diese Funktionalität wird von drei Feldern des Objekts "Erledigungsplan" unterstützt:

• Dienstname
• Abfrage
• Reihenfolge durchsetzen

Vor dem Definieren eines Erledigungsplans

Sie müssen zum Definieren eines Erledigungsplans eine Abfrage angeben. Dies bedeutet, dass die Abfrage vor dem Plan definiert werden sollte. Opcenter Execution Semiconductor umfasst eine standardmäßige Erledigungsplanabfrage namens DispatchListForTrackIn. Sie können diese Abfrage ändern oder Ihre eigene Abfrage erstellen. Der Abfragetyp muss "GUI" sein.

Zuweisen von Erledigungsplänen

Ein Erledigungsplan kann folgenden Objekten zugewiesen werden, die nach Priorität aufgelistet sind: 

• Prozesstyp "Prozessspez.: Details"
• Schritt "Prozessspez.: Details"
• Spez.

Wenn mehrere Erledigungspläne angewendet werden, wählt die Anwendung den mit dem Objekt verknüpften Plan mit der höchsten Priorität aus.

Vorgehensweise zum Definieren eines Erledigungsplans

Gehen Sie folgendermaßen vor, um einen Erledigungsplan zu definieren:

1. Öffnen Sie die Seite Erledigungsplan. Die Seite "Erledigungsplan" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Erledigungsplan einen eindeutigen Namen für den Erledigungsplan ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Zuweisen eines Erledigungsplans zu einem Prozesstyp des Schritts "Prozessspez.: Details"

Gehen Sie folgendermaßen vor, um einen Erledigungsplan einem Prozesstyp innerhalb einer Prozessspezifikation zuzuweisen:

1. Wählen Sie die Prozessspezifikationsinstanz aus.
2. Wählen Sie die Zeile der Tabelle "Details" aus, in der der Schritt oder die Spezifikation aufgeführt ist, und klicken Sie auf Zeile bearbeiten. In der Anwendung wird das Popup "Bearbeiten" angezeigt.
3. Möchten Sie einen Erledigungsplan einem vorhandenen Prozesstyp zuweisen oder müssen Sie zunächst einen Prozesstyp hinzufügen?

Verwenden eines vorhandenen Prozesstyps
a. Wählen Sie die Zeile mit dem Prozesstyp aus der Tabelle "Prozesstypen" aus. Die Anwendung aktiviert die Felder, damit sie bearbeitet werden können.
b. Geben Sie in das Feld Erledigungsplan den Erledigungsplan ein.

Hinzufügen eines Prozesstyps
a. Klicken Sie auf die erste leere Zeile in der Tabelle "Prozesstypen". Die Anwendung aktiviert eine Zeile mit leeren Feldern.
b. Geben Sie in das Feld Prozesstyp den Prozesstyp ein.
c. Geben Sie in das Feld Erledigungsplan den Erledigungsplan ein.
d. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein.

5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Zuweisen eines Erledigungsplans zu einem Schritt oder einer Spezifikation von Prozessspezifikationsdetails

Gehen Sie folgendermaßen vor, um einen Erledigungsplan einem Schritt oder einer Spezifikation innerhalb einer Prozessspezifikation zuzuweisen:

1. Wählen Sie die Prozessspezifikationsinstanz aus.
2. Wählen Sie die Zeile der Tabelle "Details" aus, in der der Schritt oder die Spezifikation aufgeführt ist, und klicken Sie auf Zeile bearbeiten. In der Anwendung wird das Popup "Bearbeiten" angezeigt.
3. Geben Sie in das Feld Erledigungsplan den Erledigungsplan ein. (Verwechseln Sie dies nicht mit dem Feld Erledigungsplan in der Tabelle "Prozesstypen".)
4. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Zuweisen eines Erledigungsplans zu einer Spezifikation

Gehen Sie folgendermaßen vor, um einen Erledigungsplan einer Spezifikation zuzuweisen:

1. Wählen Sie die Spezifikationsinstanz aus.
2. Geben Sie in das Feld Erledigungsplan den Erledigungsplan ein.
3. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
