Definieren von Empfängerfabriken

Das Objekt "Empfängerfabrik" ermöglicht es Ihnen, eine Fabrik hinzuzufügen, an die Ihre Fabrik fertige Produkte liefert.

Felddefinitionen der Seite "Empfängerfabrik"

Diese Tabelle definiert die Felder, die nur auf der Seite "Empfängerfabrik" zu finden sind.

Feld

Definition

Typ

Adresse

Adresse der Empfängerfabrik.

Optional

E-Mail-Gruppe

E-Mail-Empfängergruppe.

Optional

Tabelle "Details"

Tabelle, in der die Details der Empfängerfabrik aufgelistet werden.

Optional

Absenderspez.

Punkt im Arbeitsplan, an dem das Material geliefert werden soll.

Erforderlich

Empfängerprozess

Prozessbereich in der Zielfabrik, an den das Material gesendet werden soll.

Optional

Losinformationen senden

Ist dieses Kontrollkästchen aktiviert, werden die Losinformationen gesendet. Der Versand erfolgt automatisch.

Optional

Los ist abgeschlossen

Ist dieses Kontrollkästchen aktiviert, sind sowohl die Dokumentnummer als auch der Lieferschein erforderlich.

Optional

Vorgehensweise zum Definieren einer Empfängerfabrik

Gehen Sie folgendermaßen vor, um eine Empfängerfabrik zu definieren:

1. Öffnen Sie die Seite Empfängerfabrik. Die Seite "Empfängerfabrik" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Fabrik in das Feld Empfängerfabrik ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
