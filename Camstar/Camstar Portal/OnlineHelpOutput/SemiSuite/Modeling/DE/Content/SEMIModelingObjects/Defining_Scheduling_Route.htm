Definieren von Ablaufplanungsrouten

"Ablaufplanungsroute" ist ein Modellierungsobjekt, das die Konfiguration bestimmter Ablaufplanungsrouten ermöglicht, ohne ERP-Routen zu nutzen. Sie können eine alternative Ablaufplanungsroute definieren und anwenden, die zum Identifizieren von Schritten für die Integration der Ablaufplanung verwendet werden kann. Instanzen der Ablaufplanungsrouten haben Vorrang vor allen zuvor konfigurierten ERP-Routen, die in der vorherigen Ablaufplanungskonfiguration verwendet werden. Wenn keine Ablaufplanungsrouten von der Anwendung konfiguriert oder erkannt werden, werden alle zuvor konfigurierten ERP-Routen, die zur Identifizierung der Ablaufplanungsschritte konfiguriert wurden, weiterhin als Standard verwendet. Informationen zum Definieren einer ERP-Route finden Sie im Opcenter Execution Core Modeling-Benutzerhandbuch.

Die Ablaufplanungsroute bietet die Möglichkeit, einen grenzenlosen Ablaufplanungsschritt auszuführen und einen vollständigen Fabrikzeitplan auszuführen. Die Konfiguration des maximalen Ablaufplanungsschritts kann auf der Modellierungsseite "Fabrik" konfiguriert werden.

Hinweis: Sie müssen die Auswahl maximaler Ablaufplanungsschritte ausgleichen, um die Zeit zum Generieren von Daten und Zeitplänen zu optimieren. Eine erhöhte Anzahl von Ablaufplanungsschritten führt zu einer erhöhten Laufzeit für die Integration der Ablaufplanung und kann möglicherweise zu einem Laufzeitfehler führen.

Vorgehensweise zum Definieren einer Ablaufplanungsroute

Gehen Sie folgendermaßen vor, um eine Ablaufplanungsroute zu definieren:

1. Öffnen Sie die Seite "Ablaufplanungsroute". Die Seite "Ablaufplanungsroute" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen eindeutigen Namen in das Feld Ablaufplanungsroute ein.
4. Klicken Sie in der Tabelle "Routenschritte" auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
5. Geben Sie den Namen dieses Routenschrittes in das Feld Routenschrittname ein.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Hinzufügen von Routenschritten zu einer Ablaufplanungsroute

Gehen Sie folgendermaßen vor, um Routenschritte zu einer Ablaufplanungsroute hinzuzufügen:

1. Befolgen Sie die Schritte unter "Vorgehensweise zum Definieren einer Ablaufplanungsroute".

Oder

Wählen Sie eine vorhandene Instanz einer Ablaufplanungsroute aus.

2. Klicken Sie in der Tabelle "Routenschritte" auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt. Wenn "Industrielösung" installiert ist, wird das Popup "Hinzufügen" angezeigt.
3. Geben Sie den Namen dieses Routenschrittes in das Feld Routenschrittname ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Wenn "Industrielösung" installiert ist, klicken Sie im Popup "Hinzufügen" auf OK.
6. Wiederholen Sie die Schritte 2 bis 5, um weitere Routenschritte hinzuzufügen.
7. Klicken Sie auf Speichern. Die Anwendung zeigt eine Erfolgsmeldung an, die angibt, dass das Modellierungsobjekt aktualisiert wurde.
