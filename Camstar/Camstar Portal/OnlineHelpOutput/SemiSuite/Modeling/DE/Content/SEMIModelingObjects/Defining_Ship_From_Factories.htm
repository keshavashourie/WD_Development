Definieren von Absenderfabriken

Das Objekt "Absenderfabrik" ermöglicht es Ihnen, eine Fabrik hinzuzufügen, die Ihre Fabrik mit Losen und Materialien beliefert.

Felddefinitionen der Seite "Absenderfabrik"

Diese Tabelle definiert die Felder, die nur auf der Seite "Absenderfabrik" zu finden sind.

Feld

Definition

Typ

Tabelle "Details"

Tabelle, in der die Lagerbestands- und Ausgangsverarbeitungsinformationen für die Absenderfabrik aufgelistet werden.

Optional

Empfängerprozess

Der Prozess, der für Lose verwendet werden soll, die an die Fabrik geliefert wurden.

Hinweis: Die Eingabe dieser Informationen wird nicht erzwungen, obwohl das Feld als erforderlich markiert ist.

Erforderlich

Unterwegs-Position

Position zum Aufnehmen von Informationen für ein Los, das erwartet wird, aber noch nicht physisch angekommen ist.

Optional

Empfangsposition

Position im Lagerbestand, in der das Los eingelagert werden soll, wenn es angekommen ist.

Optional

Vorgehensweise zum Definieren einer Absenderfabrik

Gehen Sie folgendermaßen vor, um eine Absenderfabrik zu definieren:

1. Öffnen Sie die Seite Absenderfabrik. Die Seite "Absenderfabrik" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Fabrik in das Feld Absenderfabrik ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
