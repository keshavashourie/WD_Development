Definieren von Abbruchgründen

Auf der Seite "Abbruchgrund" können Sie einen Grund für den Abbruch eines Loses hinzufügen.

Felddefinitionen der Seite "Abbruchgrund"

Diese Tabelle definiert die Felder auf der Seite "Abbruchgrund".

Feld

Definition

Typ

In Umlaufbestand erlauben

Kontrollkästchen, das angibt, ob dieser Grund während der Umlaufbestandsverarbeitung ausgewählt werden darf.

Hinweis: Wenn dieses Kontrollkästchen nicht aktiviert wird, bedeutet dies, dass der Abbruchgrund während der Umlaufbestandsverarbeitung nicht verwendet werden darf.

Optional

Vorgehensweise zum Definieren eines Abbruchgrunds

Gehen Sie folgendermaßen vor, um einen Abbruchgrund zu definieren:

1. Öffnen Sie die Seite Abbruchgrund. Die Seite "Abbruchgrund" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie im Feld Abbruchgrund einen Namen für den Abbruchgrund ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
