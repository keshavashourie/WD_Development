Vorgehensweise zum Definieren eines Maskensatzes

Gehen Sie folgendermaßen vor, um einen Maskensatz zu definieren:

1. Öffnen Sie die Seite Maskensatz. Die Seite "Maskensatz" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen des Maskensatzes in das Feld Maskensatz ein.
4. Gehen Sie für jede Maskenebene, die Sie dem Maskensatz in der Tabelle "Details" hinzufügen möchten, folgendermaßen vor:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung öffnet das Popup "Hinzufügen".
b. Klicken Sie in der Liste Maskenebene auf eine Maskenebene.
c. Klicken Sie in der Tabelle "Masken" auf Neue Zeile hinzufügen, um Masken zum Maskensatz hinzuzufügen.
d. Klicken Sie in der Spalte Maske auf eine Maske.
e. Klicken Sie in der Tabelle "Tools" auf Neue Zeile hinzufügen, um Tools zum Maskensatz hinzuzufügen.
f. Klicken Sie in der Spalte Tool auf ein Tool.
g. Klicken Sie auf OK. Die Anwendung schließt das Popup "Hinzufügen" und zeigt die Maskenebene in der Tabelle "Details" an.
h. Wiederholen Sie die Schritte a bis g für jede Maskenebene, die Sie dem Maskensatz hinzufügen möchten.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
