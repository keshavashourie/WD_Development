Definieren von Rezepten

Ein Rezept ist ein Dokument, in dem die Ressourceneinstellungen definiert sind, die in der Fertigung verwendet werden, z. B. das Timing und die Temperatur eines Servers. Eine Rezeptdefinition besteht aus dem Namen und dem Speicherort der Rezeptdatei. Sobald ein Rezept definiert wurde, wird es normalerweise, aber nicht immer, von der Ressource selbst ausgeführt.

Wenn Sie die Rezeptdatei hochladen, speichert die Anwendung die Datei in der Datenbank als CLOB (Character Large Object). Die Anwendung verweist dann nach Bedarf auf die Datei, um Server entsprechend den Rezeptdefinitionen zu konfigurieren.

Anforderungen

Ihr Browser muss über das entsprechende Plugin zum Anzeigen des ausgewählten Rezeptdokuments verfügen (z. B. eine PDF-Datei).

Beim Definieren eines Rezepts

Die folgenden Regeln gelten, wenn Sie Rezepte definieren:

• Ein Rezept darf nicht denselben Namen wie ein Dokument haben. Wenn Sie z. B. ein Dokument namens "Test" erstellen, können Sie kein Rezept mit demselben Namen erstellen.
• Die Zeit, die für das Herunterladen/Hochladen von Dateien benötigt wird, ist entsprechend der Dateigröße unterschiedlich.

Vorgehensweise zum Definieren eines Rezepts

Gehen Sie folgendermaßen vor, um ein Rezept zu definieren:

1. Öffnen Sie die Seite Rezept. Die Seite "Rezept" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das Rezept in das Feld Rezept ein.
4. Geben Sie die Revision dieses Rezepts in das Feld Revision ein.
5. Klicken Sie auf Durchsuchen neben dem Feld Speicherort der Datei. Die Anwendung öffnet das Dialogfeld zum Hochladen von Dateien.
6. Suchen Sie die Datei und klicken Sie dann auf Öffnen. Das Dialogfeld zum Hochladen von Dateien wird geschlossen und der Dateiname wird im Feld "Speicherort der Datei" angezeigt.
7. Aktivieren Sie das Kontrollkästchen Datei in die Datenbank hochladen, wenn diese Datei beim Speichern in die Datenbank hochgeladen werden soll.
8. Klicken Sie auf Neue Zeile hinzufügen in der Tabelle "Rezeptparameter" und geben Sie Folgendes ein:
a. Geben Sie einen Parameternamen in das Feld Parametername ein.
b. Geben Sie einen Wert für den Parameter in das Feld Parameterwert ein.
9. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
10. Klicken Sie auf Speichern. Die Anwendung lädt die Rezeptdatei in die Datenbank hoch (wenn Sie "Datei in die Datenbank hochladen" aktiviert haben), speichert das Modellierungsobjekt, aktiviert die Schaltfläche "Dateiaktionen" und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Öffnen oder Speichern der Rezeptdatei

Gehen Sie folgendermaßen vor, um die Rezeptdatei zu öffnen oder zu speichern:

1. Öffnen Sie die Seite Rezept. Die Seite "Rezept" wird innerhalb der Seite "Modellierung" angezeigt.
2. Suchen Sie die Rezeptinstanz in der Liste der Instanzen und wählen Sie sie aus.
3. Klicken Sie auf Dateiaktionen. Die Anwendung zeigt das Dialogfeld "Öffnen Dokumentname" an, wobei "Dokumentname" der Name des Dokuments ist.
4. Führen Sie einen der folgenden Schritte durch:

Sie möchten . . .

Dann . . .

Das Dokument öffnen

Klicken Sie auf Öffnen mit und wählen Sie das Programm aus, mit dem die Datei geöffnet werden soll.

Das Dokument speichern

Klicken Sie auf Datei speichern.
5. Klicken Sie auf OK. Die Anwendung führt die angegebene Aktion aus.
