Definieren von Ressourcenlayouts

Ein Ressourcenlayout ermöglicht es Ihnen, die Orte von einer oder mehreren Ressourcen visuell darzustellen. Sie können Layouts auf der Seite "Ressourcenlayout" auswählen, um ressourcenbezogene Transaktionen auszuführen. Informationen zur Seite "Ressourcenlayout" finden Sie im Opcenter Execution Semiconductor Shop Floor-Benutzerhandbuch.

Felddefinitionen der Seite "Ressourcenlayout"

Diese Tabelle definiert die Felder auf der Seite "Ressourcenlayout".

Feld

Definition

Typ

Ressource

Ressource, die dem Ressourcenlayout hinzugefügt werden soll. Wählen Sie eine Ressource aus, ziehen Sie das Ressourcensymbol () in den Zeichenbereich und legen Sie es dort ab.

Optional

Datei für Hintergrund

Hintergrundbild, das für die Anzeigeanwendung verwendet werden soll. Das Bild muss im Format .jpg, .jpeg, .png, .gif oder .bmp vorliegen und muss sich im Camstar Portal-Ordner oder einem seiner Unterordner befinden. Es gibt keine Größeneinschränkungen.

Optional

Layouthöhe

Höhe des Layouts (in Pixel).

Optional

Layoutbreite

Breite des Layouts (in Pixel).

Optional

Vorgehensweise zum Definieren eines Ressourcenlayouts

Gehen Sie folgendermaßen vor, um ein Ressourcenlayout zu definieren:

1. Öffnen Sie die Seite Ressourcenlayout. Die Seite "Ressourcenlayout" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen eindeutigen Namen des Ressourcenlayouts in das Feld Ressourcenlayout ein.
4. Geben Sie eine Ressource in das Feld "Ressource" ein, ziehen Sie das Ressourcensymbol () in den Zeichenbereich und legen Sie es dort ab. Die Anwendung zeigt die Ressource im Zeichenbereich an.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Löschen von Ressourcen aus dem Ressourcenlayout

Gehen Sie folgendermaßen vor, um Ressourcen aus einem Ressourcenlayout zu löschen:

1. Öffnen Sie die Seite Ressourcenlayout. Die Seite "Ressourcenlayout" wird innerhalb der Seite "Modellierung" angezeigt.
2. Wählen Sie die Instanz des Ressourcenlayouts aus.
3. Klicken Sie im Zeichenbereich auf die Ressource und klicken Sie auf . Die Anwendung entfernt die Ressource aus dem Ressourcenlayout.
4. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
