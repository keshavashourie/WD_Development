Definieren von Nutzercodegruppen

Sie können Nutzercodes innerhalb des Typs kategorisieren, indem Sie Gruppen erstellen. Sie könnten z. B. alle Nacharbeitsgründe identifizieren, die speziell für Revisionen von Arbeitsaufträgen gelten, im Gegensatz zu Defekten. Wenn ein Nutzercode einer Gruppe zugewiesen wird, wird der Code nicht aus der Elterngruppe auf der Basis des Typs entfernt.

Beim Definieren von Nutzercodegruppen

Die zu verwendende Modellierungsseite hängt vom Typ der zu gruppierenden Nutzercodes ab. Beispiel: Sie definieren eine Gruppe von Nacharbeitsgründen mithilfe der Seite "Nacharbeitsgrundgruppe".

Hinweis: Gruppenmodellierungsseiten enthalten in der Regel ein Feld vom Typ "Eintragstypen", das standardmäßig auf den Typ der Nutzercodegruppe festgelegt ist, den Sie im Menü ausgewählt haben.

Felddefinition der Seite "Nutzercodegruppe"

Diese Tabelle definiert die Felder auf der Seite "Nutzercodegruppe".

Feld

Definition

Typ

Eintragstypen

Typ der Nutzercodes, die in der Gruppe enthalten sind.

Erforderlich

Tabelle "Einträge"

Enthält eine Liste der vorhandenen Nutzercodes in der Gruppe und ermöglicht Ihnen das Hinzufügen oder Löschen von Codes.

Optional

Tabelle "Gruppen"

Enthält eine Liste der vorhandenen Untergruppen, die in der Gruppe enthalten sind, und ermöglicht Ihnen das Hinzufügen oder Löschen von Untergruppen.

Optional

Vorgehensweise zum Definieren einer Nutzercodegruppe

Gehen Sie folgendermaßen vor, um eine Nutzercodegruppe zu definieren:

1. Wählen Sie die Gruppenmodellierungsseite für den Typ des Nutzercodes aus, die Sie gruppieren möchten. Die Gruppenseite wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für die Nutzercodegruppe ein.
4. Fügen Sie der Tabelle "Einträge" wie folgt Einträge hinzu:
a. Klicken Sie in der Tabelle auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
b. Wählen Sie in der Tabelle Einträge in der Liste der aktivierten Felder den Eintrag aus.
c. Wiederholen Sie die Schritte a und b, um weitere Einträge hinzuzufügen.
5. Fügen Sie Untergruppen (falls nötig) hinzu, indem Sie die folgenden Schritte ausführen:
a. Klicken Sie in der Tabelle auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
b. Wählen Sie in der Tabelle Gruppen in der Liste der aktivierten Felder die Untergruppe aus.
c. Wiederholen Sie die Schritte a und b, um weitere Untergruppen hinzuzufügen.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
