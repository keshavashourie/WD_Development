Definieren von Beschriftungseinrichtungen

Beschriftungseinrichtungen definieren die grundlegenden Parameter für die Generierung von Beschriftungen.

Vor dem Definieren von Beschriftungseinrichtungen

Bevor Sie Beschriftungseinrichtungen definieren, müssen Sie mindestens einen Beschriftungstyp und mindestens eine Nummerierungsregel definieren. Weitere Informationen zu Beschriftungstypen finden Sie unter "Definieren von Beschriftungstypen". Weitere Informationen zu Nummerierungsregeln finden Sie unter "Definieren von Nummerierungsregeln".

Felddefinitionen der Seite "Beschriftungseinrichtung"

Diese Tabelle definiert die Felder auf der Seite "Beschriftungseinrichtung".

Feld

Definition

Typ

Beschriftungstyp

Beschriftungstyp der Beschriftung. Z. B. Rollen oder Verpackung.

Erforderlich

Nummerierungsregel

Nummerierungsregel, die die automatisch generierten Namen für die Beschriftung definiert.

Erforderlich

Standardmenge pro Beschriftung

Menge pro Beschriftung, die zum Berechnen der Anzahl der zu generierenden Beschriftungen verwendet wird.

Erforderlich

Druckeinrichtung

Druckeinrichtung, die eine Druckanforderung definiert.

Optional

Elektr. Unterschrift erforderlich für Neudruck

Gibt an, ob eine elektronische Unterschrift erforderlich ist, um die Beschriftung neu zu drucken.

Optional

Vorgehensweise zum Definieren einer Beschriftungseinrichtung

Gehen Sie folgendermaßen vor, um eine Beschriftungseinrichtung zu definieren:

1. Öffnen Sie die Seite Beschriftungseinrichtung. Die Seite "Beschriftungseinrichtung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie in das Feld Beschriftungseinrichtung den Namen der Beschriftungseinrichtung ein.
4. Geben Sie in das Feld Beschriftungstyp den Beschriftungstyp ein.
5. Geben Sie in das Feld Nummerierungsregel die Nummerierungsregel ein.
6. Geben Sie in das Feld Standardmenge pro Beschriftung die Anzahl der zu generierenden Beschriftungen ein.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
