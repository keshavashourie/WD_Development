Definieren von Nutzungsanforderungen

Mit einer Nutzungsanforderung, z. B. einer Durchsatzanforderung, können Sie konfigurieren, wann eine Wartung für verknüpfte Ressourcen fällig wird. Sie können mit einer Nutzungsanforderung aber auch einen Zähler und die Vorgehensweise definieren, wie dieser Zähler erhöht wird. Sie können den Zähler so konfigurieren, dass er um eine Integer-Zahl oder durch einen Ausdruck erhöht wird, der zu einer Integer-Zahl ausgewertet wird, oder Sie können eine benutzerdefinierte Abfrage erstellen, die eine Integer-Zahl für die Erhöhung des Zählers zurückgibt. Sie konfigurieren den Zähler mit einem Maximalwert und können auch Toleranzfenster festlegen.

Hinweis: Verwenden Sie die Seite "Ressourcenaktivierung", um die Anforderung mit einer oder mehreren Ressourcen zu verknüpfen.

Änderungsauftrag, der dieser Revision zugewiesen wurde. Sie können maximal 30 Zeichen eingeben.

Verzögerungsdetails löschen

Kontrollkästchen, das alle Verzögerungen für Wartungen löscht, die im Ergebnis der Anforderung derzeit fällig sind.

Ablaufplanungsdetails

Wartungsgrund

Dieser Anforderung zugeordneter Grund.

Dokumentsatz

Dieser Anforderung zugeordneter Dokumentsatz. Dokumentsätze werden in der Modellierung definiert.

Datensammlungsdefinition

Die Datensammlungsdefinition, die mit dieser Anforderung verknüpft ist. Datensammlungsdefinitionen werden in der Modellierung definiert.

Maximale Nutzungsanzahl

Gibt an, wie oft die Ressource maximal genutzt werden kann, bevor eine Wartung für die Ressource erforderlich ist.

Erforderlich

Anzahl für Nutzungswarnung

Gibt an, wie oft die Ressource maximal genutzt werden kann, bevor ein Warnungsstatus erreicht wird.

Optional

Toleranznutzungsanzahl

Gibt die Toleranz an, die besagt, wie oft die Ressource genutzt (oder der Zähler weiterlaufen) kann, nachdem die Ressource die maximale Nutzungsanzahl erreicht hat.

Optional

Verzicht möglich

Gibt an, ob diese Wartungsanforderung für eine Ressource aufgehoben werden kann.

Optional

Elektronische Unterschrift erforderlich für Verwaltung von Verzicht/Verzögerung

Vordefinierte Anforderung hinsichtlich einer elektronischen Unterschrift. Falls diese hier festgelegt wird, muss die elektronische Unterschrift bereitgestellt werden, wenn diese Wartungsanforderung für eine Ressource aufgehoben oder verschoben werden soll.

Optional

Anforderung zur elektronischen Unterschrift

Vordefinierte Anforderungen zur elektronischen Unterschrift. Falls diese hier festgelegt wird, können Sie die Transaktion erst durchführen, wenn alle Unterschriften vorliegen.

Optional

Verzögerung möglich

Gibt an, ob diese Wartungsanforderung für eine Ressource verschoben werden kann.

Optional

Max. Nutzungsanzahl bei Verzögerung

Maximale Anzahl, die für eine Verzögerung eingegeben werden kann. Die Zahl besagt, wie oft der Nutzungsanforderungszähler erhöht werden kann, bevor eine Wartung fällig wird.

Optional

Tabelle "Nutzungsanforderung: Einrichtungsdetails"

Tabelle, die die Nutzungsanzahlkonfigurationen für die Nutzungsanforderung auflistet.

Optional

Nutzungsanf.-Transaktion

Diese Transaktionen erhöhen den Nutzungszähler oder verhindern die Verarbeitung, bis die Anforderung als abgeschlossen markiert und der Zähler zurückgesetzt wird.

• Ad-hoc-Umlaufbestandsdaten (falls der Objekttyp "Ausrüstung" ist und das Kontrollkästchen "Prozess: Nutzungsanforderungen (Ad-hoc)" für die Ausrüstungs- oder Ausrüstungsfamilienobjektinstanz aktiviert ist)
• Status der Ausrüstung festlegen
• Ausrüstungseinrichtung (siehe Hinweis)
• Ausbringen

Hinweis: "Ausrüstungseinrichtung" erhöht den Zähler nur, wenn die Ausrüstung losfrei ist. So können Sie mehrere Ausrüstungseinrichtungen für verschiedene Parameter durchführen, aber der Zähler wird nur einmal erhöht. Die Ausrüstungseinrichtung kann nicht durchgeführt werden, wenn Lose bereits eingebracht wurden. Nachdem alle Lose aus der Ausrüstung ausgebracht wurden, erhöht die nächste Ausrüstungseinrichtung den Zähler wieder.

Optional

Nutzungsanf.-Anzahltyp

Feld für die Auswahl der Methode, mit der der Zähler erhöht werden soll.  Mögliche Optionen sind "Ausdruck" oder "Abfrage".

Optional

Nutzungsanzahlausdruck

Zahl oder Ausdruck, die bzw. der zu einer Zahl aufgelöst wird. Die Zahl wird zur Erhöhung des Nutzungszählers verwendet. Ein Beispielausdruck ist Container.Qty.

Optional

Nutzungsanzahlabfrage

Name der Abfrage, die für die Nutzungsanforderung ausgeführt wird. (Wird verwendet, wenn "Nutzungsanf.-Anzahltyp" auf "Abfrage" festgelegt ist.) Die Abfrage muss zuerst erstellt werden, damit Sie sie hier auswählen können.

Hinweis: Abfragen, die im Feld "Abfragename" verfügbar sind, werden mithilfe der Seite "PM-Anforderungsabfrage" erstellt. Die Abfrage sollte nur eine Spalte mit einem numerischen Wert zurückgeben. Wenn die Abfrage mehr als eine Zeile zurückgibt, wird nur die erste Zeile als die Erhöhungszahl verwendet. Weitere Informationen finden Sie unter "Definieren einer PM-Anforderungsabfrage".

Optional

Tabelle "Checkliste"

Optional

Checklisten-ID

Eindeutiger Checklistenname zur Identifizierung der Checkliste.

Erforderlich

Anweisung

Unformatierter Text, der während einer Checklistenkonfiguration hinzugefügt wird und den Benutzer bei der Verwendung der Checkliste unterstützen soll.

Erforderlich

Mitarbeitergruppe

Gruppe von Mitarbeitern, die die Checkliste ausführen dürfen.

Optional

Nur einzeln

Kontrollkästchen, das steuert, ob diese Checkliste zusammen mit anderen Checklisten ausgewählt werden kann.

Optional

Datensammlungsdefinition

Definiert Daten, die bei der Verwendung der Checkliste gesammelt werden.

Optional

Beschreibung

Unformatierter Text, um aussagekräftige Informationen über die Checkliste hinzuzufügen.

Optional

Hinweise

Relevante Kommentare. Sie können maximal 2000 Zeichen eingeben.

Optional

Checklistenreihenfolge erzwingen

Gibt an, ob die Anwendung die Reihenfolge der Checklistenelemente durchsetzen soll.

Optional

Tabelle "PM-Überschreibungen"

Tabelle mit verknüpften Anforderungen, die als abgeschlossen markiert werden, sobald diese Basisanforderung als abgeschlossen markiert ist.

Optional

Wiederholungsterminanforderung

Name der verknüpften Nutzungsanforderung.

Optional

Benachrichtigungen

Tabelle "Ausstehend - E-Mail-Empfänger"

In dieser Tabelle werden die Empfänger angegeben, die eine E-Mail-Benachrichtigung über eine ausstehende Wartung erhalten. Siehe Feld Warnungsfrist in dieser Tabelle.

Optional

Ausstehend - E-Mail-Text

Der Text der E-Mail, die versandt wird, wenn die Wartung ausstehend ist. Sie müssen einen Text eingeben, wenn Sie im Feld "Ausstehend - E-Mail-Empfänger" eine Angabe machen. Es können Textvariablen verwendet werden.

Optional

Tabelle "Fällig - E-Mail-Empfänger"

In dieser Tabelle werden die Empfänger angegeben, die eine E-Mail-Benachrichtigung erhalten, wenn die Wartung fällig ist. Siehe das Feld Erster Termin in dieser Tabelle.

Optional

Fällig - E-Mail-Text

Der Text der E-Mail, die versandt wird, wenn die Wartung fällig ist (aber noch in der Toleranzfrist liegt). Sie müssen einen Text eingeben, wenn Sie im Feld "Fällig - E-Mail-Empfänger" eine Angabe machen. Es können Textvariablen verwendet werden.

Optional

Tabelle "Überfällig - E-Mail-Empfänger"

In dieser Tabelle werden die Empfänger angegeben, die eine E-Mail-Benachrichtigung erhalten, wenn die Wartung überfällig ist. Siehe das Feld "Toleranzfrist" in dieser Tabelle. Sie müssen einen Text eingeben, wenn Sie im Feld "Fällig - E-Mail-Empfänger" eine Angabe machen.

Optional

Überfällig - E-Mail-Text

Der Text der E-Mail, die versandt wird, wenn die Wartung überfällig ist. Sie müssen Text eingeben, wenn Sie im Feld "Überfällig - E-Mail-Empfänger" eine Angabe machen. Es können Textvariablen verwendet werden.

Optional

Vorgehensweise zum Definieren einer Nutzungsanforderung

Gehen Sie folgendermaßen vor, um eine Nutzungsanforderung zu definieren:

1. Öffnen Sie die Seite Nutzungsanforderung. Die Seite "Nutzungsanforderung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für diese Anforderung in das Feld Nutzungsanforderung ein.
4. Wählen Sie einen Wartungsgrund aus.
5. Geben Sie eine maximale Nutzungsanzahl ein.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie in der Tabelle "Einrichtungsdetails" auf Neue Zeile hinzufügen. Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
8. Wählen Sie die Transaktion im Feld Transaktion aus. Hiermit geben Sie eine Transaktion an, die diese Nutzungsanforderung ausführt.
9. Wählen Sie den Nutzungsanf.-Anzahltyp aus.

Wenn Sie Folgendes ausgewählt haben . . .

Dann . . .

Ausdruck

Geben Sie den Ausdruck in das Feld Nutzungsanzahlausdruck ein. Der Ausdruck muss in einen numerischen Wert aufgelöst werden. Dieser Wert wird verwendet, um die Nutzungsanzahl zu erhöhen.

Abfrage

Wählen Sie den Abfragenamen im Feld Nutzungsanzahlabfrage aus.
10. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Hinzufügen von Nutzungsanforderungsbenachrichtigungen

Gehen Sie folgendermaßen vor, um Nutzungsanforderungsbenachrichtigungen hinzuzufügen:

1. Führen Sie die Schritte unter "Vorgehensweise zum Definieren einer Nutzungsanforderung" aus.

Oder

Wählen Sie eine vorhandene Nutzungsanforderungsinstanz aus.

2. Erweitern Sie den Abschnitt "Benachrichtigungen".
3. Klicken Sie in der Tabelle "Ausstehend - E-Mail-Empfänger", "Fällig - E-Mail-Empfänger" oder "Überfällig - E-Mail-Empfänger" auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
4. Geben Sie eine E-Mail-Benachrichtigung in die neu hinzugefügte Zeile ein. Die Benachrichtigung wird der Tabelle hinzugefügt.
5. Geben Sie den Text der E-Mail in das entsprechende Feld ein: Ausstehend - E-Mail-Text, Fällig - E-Mail-Text oder Überfällig - E-Mail-Text. Sie haben auch die Möglichkeit, Textvariablen zu verwenden.
6. Wiederholen Sie die Schritte 3 bis 5, um die Benachrichtigungen für weitere Empfänger einzurichten.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Hinzufügen von PM-Überschreibungen zu einer Nutzungsanforderung

Gehen Sie folgendermaßen vor, um PM-Überschreibungen hinzuzufügen:

1. Führen Sie die Schritte unter "Vorgehensweise zum Definieren einer Nutzungsanforderung" aus.

Oder

Wählen Sie eine vorhandene Nutzungsanforderungsinstanz aus.

2. Erweitern Sie alle Abschnitte.
3. Klicken Sie in der Tabelle "PM-Überschreibungen" auf Neue Zeile hinzufügen. Die Anwendung fügt der Tabelle eine leere Zeile hinzu.
4. Wählen Sie eine Nutzungsanforderung aus, die in den Überschreibungsprozess aufgenommen werden soll.
5. Wiederholen Sie die Schritte 3 und 4 für jede weitere hinzuzufügende PM-Überschreibung.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
