Referenzieren einer Wartungsklasse in der Ressource

Ressourcen, die die gleichen Wartungsanforderung haben, gehören zu einer Wartungsklasse. Die Seite zum Hinzufügen oder Bearbeiten einer Ressource enthält ein Feld, mit dem Sie eine Wartungsklasse für die Ressource auswählen können.

Vorgehensweise zum Ändern einer Ressource, sodass sie eine Wartungsklasse referenziert

Gehen Sie folgendermaßen vor, um die Wartungsklasse anzugeben, zu der die Ressource gehört:

1. Öffnen Sie die Seite Ressource. Die Seite "Ressource" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf die Ressource, die Sie ändern möchten. Die Seite "Ressource" wird für die ausgewählte Ressource angezeigt.
3. Erweitern Sie die Feldgruppe Wartungsdaten. Die Wartungsfelder werden angezeigt.
4. Wählen Sie die entsprechende Wartungsklasse für diese Ressource im Feld Wartungsklasse aus.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
