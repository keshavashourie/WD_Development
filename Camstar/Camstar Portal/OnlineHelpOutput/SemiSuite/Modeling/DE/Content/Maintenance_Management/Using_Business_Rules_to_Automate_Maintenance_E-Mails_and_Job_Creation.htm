Mithilfe von Geschäftsregeln können Sie der Opcenter Execution Semiconductor-Anwendung benutzerdefinierte Verarbeitungslogik hinzufügen. Diese Tabelle enthält jedes Geschäftsregel-Modellierungsobjekt und die Musterinstanz, die zur Unterstützung bei der Wartung bereitgestellt wird.

Benutzerdefinierte Logik definieren Sie in einem Geschäftsregelhandler und verknüpfen den Geschäftsregelhandler dann mit einer Geschäftsregel für Wartungszwecke. Anschließend planen Sie die Geschäftsregel für die automatische Ausführung mithilfe der geplanten Geschäftsregel.

Hinweis: Die Zustellung von E-Mails wird vom Notification Server und vom konfigurierten SMTP-Server in Modeling gesteuert. Weitere Informationen finden Sie in der Opcenter Execution Core-Installationsanleitung.
Vor dem Definieren von Geschäftsregelhandlern

Kunden können Hunderte und Tausende Ausrüstungselemente haben, die an Produktionsprozessen ausgerichteten Gruppen zugewiesen sind. Siemens empfiehlt Ihnen, Eltern-Ausrüstungsgruppen zu erstellen, die die kleineren Gruppen einschließen, sodass Sie keinen Geschäftsregelsatz für einzelne Ausrüstungsgruppen erstellen müssen.

Das folgende Diagramm veranschaulicht den Prozess der Definition einer Eltern-Gruppe und Konfiguration der Objekte, die für die automatisierte E-Mail-Benachrichtigung und Wartungsjoberstellung erforderlich sind. Der Prozess wird für jede Eltern-Gruppe wiederholt.

Vorgehensweise zum Definieren der Geschäftsregelhandler für automatisierte Benachrichtigungen

Hinweis: Die folgenden Anweisungen basieren auf der Annahme, dass Sie Datums- und/oder Wiederholungsterminwartungsanforderungen für Ausrüstungsgruppen oder Wartungsklassen zugeordnet haben.

Gehen Sie folgendermaßen vor, um den Geschäftsregelhandler für automatisierte Benachrichtigungen zu definieren:

1. Öffnen Sie die Seite Geschäftsregelhandler. Die Seite "Geschäftsregelhandler" wird innerhalb der Seite "Modellierung" angezeigt.
2. Wählen Sie die bereitgestellte Instanz aus: StateChangeMaintainHandler.
3. Klicken Sie auf Kopieren. Das Popup "Kopieren" wird angezeigt.
4. Geben Sie einen neuen Zielinstanznamen ein, der sich auf die spezifische Ausrüstungsgruppe bezieht, z. B. ELTERN_AUSRÜSTUNGSGRUPPE01_BRH.
5. Klicken Sie auf Kopieren. Das Dialogfeld wird geschlossen.
6. Suchen Sie im Bereich Skript die folgende Zeile: GetNamedObject("SMTPTransportName","SMTPTransport",Transaction::EmailTransport);
Ersetzen Sie "SMTPTransportName" durch den Namen des SMTP-Transports, der in der Modellierung konfiguriert wurde.
7. Suchen Sie im Bereich Skript die folgende Zeile: InitQueryParametersEx("ResourceGroupName","%",CLF::Param). Ersetzen Sie das Symbol % durch den tatsächlichen Ausrüstungsgruppennamen, z. B. "ELTERN_AUSRÜSTUNGSGRUPPE_01" in Anführungszeichen.

Mit diesem Beispiel würde die Zeile folgendermaßen aussehen:
InitQueryParametersEx("ResourceGroupName","ELTERN_AUSRÜSTUNGSGRUPPE_01",CLF::Param);

8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Definieren der Geschäftsregel für automatisierte Benachrichtigungen

Gehen Sie folgendermaßen vor, um die Geschäftsregel für automatische Benachrichtigungen zu definieren:

1. Öffnen Sie die Seite Geschäftsregel. Die Seite "Geschäftsregel" wird innerhalb der Seite "Modellierung" angezeigt.
2. Wählen Sie die bereitgestellte Instanz aus: StateChangeMaintainRules.
3. Klicken Sie auf Kopieren. Das Popup "Kopieren" wird angezeigt.
4. Geben Sie einen neuen Zielinstanznamen ein, der sich auf die spezifische Ausrüstungsgruppe bezieht, z. B. ELTERN_AUSRÜSTUNGSGRUPPE01_BR.
5. Klicken Sie auf Kopieren. Das Dialogfeld wird geschlossen.
6. Löschen Sie den gesamten Inhalt in der Tabelle "Handler". Gehen Sie für jede Zeile mit Inhalt folgendermaßen vor:
a. Wählen Sie die Zeile aus.
b. Klicken Sie in der Symbolleiste der Tabelle "Handler" auf Ausgewählte Zeile löschen. Die Anwendung löscht die ausgewählte Zeile aus der Tabelle.
7. Klicken Sie in der Symbolleiste der Tabelle "Handler" auf Neue Zeile hinzufügen. Eine neue Zeile wird angezeigt.
8. Geben Sie den Namen des Geschäftsregelhandlers in die Spalte Handler ein.
9. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Definieren der geplanten Geschäftsregel für automatisierte Benachrichtigungen

Gehen Sie folgendermaßen vor, um die geplante Geschäftsregel für automatische Benachrichtigungen zu definieren:

1. Öffnen Sie die Seite Geplante Geschäftsregel. Die Seite "Geplante Geschäftsregel" wird innerhalb der Seite "Modellierung" angezeigt.
2. Wählen Sie die bereitgestellte Instanz aus: StateChangeMaintain.
3. Klicken Sie auf Kopieren. Das Popup "Kopieren" wird angezeigt.
4. Geben Sie einen neuen Zielinstanznamen ein, der sich auf die spezifische Ausrüstungsgruppe bezieht, z. B. ELTERN_AUSRÜSTUNGSGRUPPE01_SBR.
5. Klicken Sie auf Kopieren. Das Dialogfeld wird geschlossen.
6. Wählen Sie die geeignete Geschäftsregel im Feld Geschäftsregel aus. (Nach dem Beispiel wäre dies die zuvor erstellte Regel ELTERN_AUSRÜSTUNGSGRUPPE01_BR.)
7. Geben Sie Ablaufplanungsinformationen gemäß den Einstellungen "Ausstehend", "Fällig" und "Überfällig" der Wartungsanforderungen Ihrer Installation ein.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
Hinweis: Denken Sie beim Erstellen von geplanten Geschäftsregeln daran, die Ablaufplanung so anzuordnen, dass die Auswirkungen auf die Serverleistung so gering wie möglich gehalten werden.
