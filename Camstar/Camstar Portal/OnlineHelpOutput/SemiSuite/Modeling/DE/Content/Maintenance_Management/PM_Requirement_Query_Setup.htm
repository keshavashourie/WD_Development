Definieren einer PM-Anforderungsabfrage

Mit der PM-Anforderungsabfrage können Sie eine Abfrage erstellen, die eine Integer-Zahl zurückgibt, mit der wiederum ein Nutzungsanforderungszähler erhöht wird. Die Seite ähnelt der Seite "Onlineabfrage: Einrichtung".

Felddefinitionen der Seite "PM-Anforderungsabfrage"

Diese Tabelle definiert die Felder auf der Seite "PM-Anforderungsabfrage".

Feld

Definition

Typ

PM-Anforderungsabfrage

Eindeutiger Name für diese Instanz des Objekts.

Erforderlich

Abfragedefinition

Ergebnisspaltenname

Spalte des Abfrageergebnisses, mit dem die Nutzungsanzahl für die Nutzungsanforderung abgefragt wird.

Erforderlich

Abfragetext

Unformatierter Textbereich, in dem Sie den SQL-Abfragecode eingeben können.

Erforderlich

Tabelle "Parameter"

Enthält die für die Abfrage konfigurierten Parameter.

Optional

Name für Benutzerabfrageparameter

Eindeutiger Name (in dieser Gruppe von Abfrageparametern) für diesen Parameter.

Erforderlich für neue Parameter

Datentyp

Feldliste zum Auswählen des Typs der Daten für diesen Parameter, z. B. "Dezimal", "Zeichenkette" und "Gleitkomma".

Erforderlich, wenn Sie einen Parameter hinzufügen

Text anzeigen

Wird dem Benutzer in der Eingabeaufforderung angezeigt, damit er Parameterwerte eingibt.

Optional

Parameterwert

Zeichenkettenwert, der den Wert des Parameters darstellt, der vor der Ausführung an die Abfrage weitergeleitet wird.

Optional

Dynamischer Wert

Wenn kein Parameterwert angegeben ist, wird der dynamische Wert aufgelöst und als Parameterwert verwendet.

Optional

Ist erforderlich

Gibt an, ob dieser Parameter beim Ausführen der Abfrage angegeben werden muss.

Optional

Für Blockzeilen verwenden

Es kann nur ein Parameter für "Für Blockzeilen verwenden" festgelegt werden. Mit diesem Flag beschränkt die Anwendung den Abfrageinhalt. Nicht erforderlich für die Einrichtung der PM-Anforderungsabfrage.

Optional

Nutzerfelder

Größenlimit für Ergebnismenge

Maximale Anzahl der Zeilen, die von der Abfrage zurückgegeben werden.

Erforderlich

Vorgehensweise zum Definieren einer PM-Anforderungsabfrage

Gehen Sie folgendermaßen vor, um eine PM-Anforderungsabfrage zu definieren:

1. Öffnen Sie die Seite PM-Anforderungsabfrage. Die Seite "PM-Anforderungsabfrage" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für diese Anforderung in das Feld PM-Anforderungsabfrage ein.
4. Geben Sie die Spalte des Abfrageergebnisses ein, mit dem die Nutzungsanzahl im Feld Ergebnisspaltenname abgerufen wird.
5. Geben Sie den Abfragecode in den Bereich Abfragetext ein.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. So testen Sie die Abfrage:
a. Klicken Sie auf Abfrage speichern und testen. Die Anwendung zeigt die Ergebnisse in einem Popup an.
b. Klicken Sie auf Schließen. Die Anwendung schließt das Popup.
8. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
