Angeben der Voraussenden-Validierungsspezifikation

Eine Voraussenden-Validierungsspezifikation ist eine Spezifikation, die mit einer Umlaufbestandsdateneinrichtung konfiguriert ist, die die Daten sammelt, anhand derer der Voraussenden-Validierungsstatus (Bestanden/Fehlgeschlagen) ermittelt wird.

Vor dem Angeben der Validierungsspezifikation

Die Umlaufbestandsdateneinrichtung muss definiert sein, bevor ihr die Validierungsspezifikation zugeordnet werden kann. Weitere Informationen finden Sie unter "Definieren von Umlaufbestandsdateneinrichtungsobjekten".

Beim Angeben der Validierungsspezifikation

Die Validierungsspezifikation muss in der Voraussendematrix ausgewählt werden. Die Umlaufbestandsdateneinrichtung, die zur Validierung verwendet wird, muss entweder in der Spezifikation selbst oder innerhalb der Prozessspezifikationsdetails ausgewählt werden.

Wichtig: Die Validierungsspezifikation muss sich im Arbeitsplan mindestens einen Arbeitsplanschritt hinter der Blockspezifikation befinden.

Vorgehensweise zum Angeben einer Voraussenden-Validierungsspezifikation

Gehen Sie folgendermaßen vor, um die zur Validierung verwendete Umlaufbestandsdateneinrichtung für die Spezifikation anzugeben:

1. Rufen Sie die Modellierungsseite für eine vorhandene Spezifikation auf.

Oder

Erstellen Sie eine neue Spezifikation entsprechend den Anforderungen Ihres Unternehmens.

2. Wählen Sie die Umlaufbestandsdateneinrichtung aus.
3. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Angeben der zur Validierung verwendeten Umlaufbestandsdateneinrichtung

Gehen Sie folgendermaßen vor, um die zur Validierung verwendete Umlaufbestandsdateneinrichtung in den Prozessspezifikationsdetails anzugeben:

1. Rufen Sie eine vorhandene Prozessspezifikationsinstanz auf.

Oder

Erstellen Sie eine neue Instanz entsprechend den Anforderungen Ihres Unternehmens.

2. Klicken Sie in der Tabelle "Details" auf Neue Zeile hinzufügen. Das Popup "Hinzufügen" wird angezeigt.
3. Wählen Sie die Validierungsspezifikation im Feld Spez. aus.
4. Wählen Sie die Umlaufbestandsdateneinrichtung im Feld Umlaufbestandsdateneinrichtung aus.
5. Klicken Sie auf OK. Das Popup wird geschlossen und der Eintrag wird auf der Seite "Prozessspez." in der Tabelle "Details" angezeigt.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
Hinweis: Die Spezifikation und die Umlaufbestandsdateneinrichtung müssen in der Voraussendematrix ausgewählt werden. Weitere Informationen finden Sie unter "Definieren einer Voraussendematrix".
