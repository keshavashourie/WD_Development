Revisionierte Objekte

Ein revisioniertes Objekt (RO) ist ein Objekt, das einen Namen und eine Revision erfordert. Mithilfe von Revisionen können Sie mehrere Versionen derselben Modellierungseinheit verwalten. Wenn Änderungen an einem revisionierten Modellierungsobjekt vorgenommen werden, können Sie neue Versionen definieren, ohne einen neuen Objektnamen zuzuweisen. ROs sind wie NDOs persistent, sodass Sie mehrere Versionen derselben Modellierungsobjekte verwalten und jede vorhandene Revision des RO nach Bedarf referenzieren können.

Mit revisionierten Objekten können Sie:

• Revisionen für Modellierungsobjekte wie Produkte (PNs), Arbeitspläne und Prozessspezifikationen bereitstellen. Dies ist hilfreich, wenn Sie verschiedene Versionen von den ROs für verschiedene Zwecke erstellen möchten. Sie könnten z. B. eine vorhandene Revision klonen, um eine neue Revision zu erstellen, während das Modell beibehalten wird. Da Semiconductor Shop Floor es Ihnen ermöglicht, mehrere ROs in Ihren Modellierungsdaten zu verwalten, können Sie anschließend ein vorhandenes RO ändern, ohne die Fabrikabhängigkeiten in diesem RO zu verletzen.
• eine bestimmte Revision oder die Standardrevision (aktuelle Version) referenzieren. Wenn Sie z. B. eine Spezifikation referenzieren, müssen Sie entweder eine bestimmte Revision oder die Standardrevision auswählen. Wenn Sie eine bestimmte Revision referenzieren, verwendet der Arbeitsplan immer diese Revision, auch wenn neue Revisionen erstellt werden. Wenn Sie jedoch die Standardrevision referenzieren, verwendet der Arbeitsplan immer die Standardrevision, unabhängig von der tatsächlichen Revisionsnummer.
• vorhandene Revisionen klonen, um eine neue Revision zu erstellen, während das Modell beibehalten wird. Da Semiconductor Shop Floor es Ihnen ermöglicht, mehrere ROs in Ihren Modellierungsdaten zu verwalten, können Sie ein vorhandenes RO ändern, ohne die Fabrikabhängigkeiten für dieses RO zu verletzen.
