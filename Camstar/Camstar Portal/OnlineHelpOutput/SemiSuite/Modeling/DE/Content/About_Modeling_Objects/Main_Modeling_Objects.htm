Hauptmodellierungsobjekte

Hauptmodellierungsobjekte definieren die physischen Modelle und die Prozessmodelle für Ihre Fabrik. Hauptmodellierungsobjekte fallen in eine von zwei Kategorien:

• Modellierungsobjekte im physischen Modell beschreiben die physischen Elemente Ihrer Fabrik. Diese Elemente definieren die Ausrüstung und andere Ressourcen, die im Produktionsprozess verwendet werden, sowie Abteilungen, Standorte und Bereiche der Fabrik. Das Standortmodellierungsobjekt definiert z. B. einen physischen Ort innerhalb einer Fabrik wie einen Gang oder Regalplatz in einem Lagerhaus.
• Modellierungsobjekte im Prozessmodell beschreiben die Steuerungskomponente des Fabrikmodells einschließlich der Abläufe und Spezifikationen des Produktionsarbeitsplans. Arbeitsplanmodellierungsobjekte definieren z. B. die Schritte, mit denen ein Produkt hergestellt wird.

Diese Modellierungsobjekte sind statisch, d. h., Sie können die Modellierungsobjekte einmal definieren und sie dann zum Steuern der Produktverarbeitungsprozesse in Opcenter Execution Semiconductor verwenden.

Hinweis: Die wichtigsten Modellierungsobjekte wurden in Semiconductor Suite Version 6 SU1 und früher als "Setup A"-Objekte (Einrichtung A) bezeichnet.

Named Data Objects

Ein benanntes Datenobjekt (NDO) ist eine Klasse von Hauptmodellierungsobjekten, die durch einen eindeutigen Namen identifiziert werden. NDO-Instanzen sind persistent, d. h., dass die zugehörigen Informationen in die Datenbank geschrieben werden. Da NDOs nur durch einen Namen gekennzeichnet sind, müssen benannte Modellierungsobjekte desselben Typs eindeutige Namen aufweisen. Wenn Sie z. B. das Operationsmodellierungsobjekt "Montage" haben, können Sie keine andere Operation erstellen, die auch "Montage" heißt.

Revisionierte Objekte

Ein revisioniertes Objekt (RO) ist ein Objekt, das einen Namen und eine Revision erfordert. Mithilfe von Revisionen können Sie mehrere Versionen derselben Modellierungseinheit verwalten. Wenn Änderungen an einem revisionierten Modellierungsobjekt vorgenommen werden, können Sie neue Versionen definieren, ohne einen neuen Objektnamen zuzuweisen. ROs sind wie NDOs persistent, sodass Sie mehrere Versionen derselben Modellierungsobjekte verwalten und jede vorhandene Revision des RO nach Bedarf referenzieren können.

Mit revisionierten Objekten können Sie:

• Revisionen für Modellierungsobjekte wie Produkte (PNs), Arbeitspläne und Prozessspezifikationen bereitstellen. Dies ist hilfreich, wenn Sie verschiedene Versionen von den ROs für verschiedene Zwecke erstellen möchten. Sie könnten z. B. eine vorhandene Revision klonen, um eine neue Revision zu erstellen, während das Modell beibehalten wird. Da Opcenter EX SM Portal es Ihnen ermöglicht, mehrere ROs in Ihren Modellierungsdaten zu verwalten, können Sie anschließend ein vorhandenes RO ändern, ohne die Fabrikabhängigkeiten in diesem RO zu verletzen.
• eine bestimmte Revision oder die Standardrevision (aktuelle Version) referenzieren. Wenn Sie z. B. eine Spezifikation referenzieren, müssen Sie entweder eine bestimmte Revision oder die Standardrevision auswählen. Wenn Sie eine bestimmte Revision referenzieren, verwendet der Arbeitsplan immer diese Revision, auch wenn neue Revisionen erstellt werden. Wenn Sie jedoch die Standardrevision referenzieren, verwendet der Arbeitsplan immer die Standardrevision, unabhängig von der tatsächlichen Revisionsnummer.
• vorhandene Revisionen klonen, um eine neue Revision zu erstellen, während das Modell beibehalten wird. Da Opcenter EX SM Portal es Ihnen ermöglicht, mehrere ROs in Ihren Modellierungsdaten zu verwalten, können Sie ein vorhandenes RO ändern, ohne die Fabrikabhängigkeiten für dieses RO zu verletzen.

Filtern der Instanzliste

Das Feld "Filtern" kann verwendet werden, um eine große Anzahl von Modellierungsinstanzen einzugrenzen, die in der Liste "Instanzen" angezeigt werden. Sie können die Filterungsliste für revisionierte oder benannte Datenobjekte verwenden.

Geben Sie einen Teil einer Zeichenkette ein und klicken Sie auf "Aktualisieren", um eine Liste aller Instanzen anzuzeigen, deren Namen mit dieser Teilzeichenkette beginnen. Wenn Sie bei leerem Filterfeld auf "Aktualisieren" klicken, sehen Sie wieder alle Instanzen.

Unterhalb des Filters wird ein Listen-Steuerelement angezeigt, wenn die Anzahl der definierten Instanzen größer als 100 ist.

Standardrevision

Die Standardrevision ist die Revision, die derzeit als Standard für die Verwendung im Fabrikmodell und in der Fertigung festgelegt ist, auch wenn andere Revisionen aktiv und zur Verwendung verfügbar sind. Die Funktion "Standardrevision" reduziert den Wartungsaufwand am Modell und gewährleistet die Verwendung korrekter Revisionen in der Fertigung.

Die Standardrevision ist nicht unbedingt die neueste Revision des Objekts. Sie können nur eine Revision als Standardrevision festlegen, diese Zuweisung aber jederzeit ändern und eine andere Revision als Standardrevision festlegen.

Der Vorteil der Standardrevision liegt darin, dass Sie sie referenzieren können und so nicht jedes Mal die Arbeitspläne, die dieses Objekt verwenden, überarbeiten müssen, wenn eine neue Revision des Objekts für die Verwendung genehmigt wird. Wenn Sie z. B. einen Arbeitsplan erstellen, erstellen Sie Schritte, indem Sie Spezifikationsobjekte oder andere Arbeitsplanobjekte referenzieren. Wenn Sie eine Spezifikation referenzieren, müssen Sie entweder eine bestimmte Revision oder die Standardrevision auswählen. Wenn Sie eine bestimmte Revision referenzieren, verwendet der Arbeitsplan immer diese Revision, auch wenn neue Revisionen erstellt werden. Wenn Sie jedoch die Standardrevision referenzieren, verwendet der Arbeitsplan immer die Standardrevision, unabhängig von der tatsächlichen Revisionsnummer.

Revisionierte Objekte in der Liste "Instanzauswahl"

Die Liste "Instanzauswahl" wird in der erweiterten Ansicht angezeigt. So können Sie die Instanzen und die mit ihnen verbundenen Revisionen sehen. Die Anwendung zeigt die Standardrevision an, indem sie die Standardrevision nach dem Namen der Instanz zusammen mit einem Kontrollkästchen nach dem Namen der spezifischen Revision auflistet.

Durch Klicken auf einen Instanznamen wird die Wartungsseite für die Standardrevision dieser Instanz angezeigt. Durch Klicken auf den Namen einer bestimmten Revision wird die Wartungsseite für diese Revision angezeigt.

Die erste Instanz eines revisionierten Objekts, die Sie erstellen, ist standardmäßig die Standardrevision.

Sie können eine Revision einer vorhandenen revisionierten Objektinstanz definieren, indem Sie eine der folgenden Methoden verwenden:

• Klicken Sie auf "Neue Revision", um eine Kopie der Revision zu erstellen, in der alle Felder bis auf den Namen leer sind. Diese Möglichkeit bietet sich an, wenn die meisten Attribute für die neue Revision eindeutig sind.
• Klicken Sie auf "Kopieren", um eine Kopie der Revision mit allen Informationen der Originalrevision zu erstellen. Diese Möglichkeit bietet sich an, wenn Sie eine vorhandene Revision als Grundlage für eine neue Revision verwenden möchten.
• Klicken Sie auf "Revision kopieren", um ein Duplikat des revisionierten Objekts mit allen Informationen der Originalrevision außer der Revisionsnummer zu erstellen.

Vorgehensweise zum Definieren einer neuen Revision

Gehen Sie folgendermaßen vor, um eine neue Revision zu definieren:

1. Wählen Sie Haupt im Menü Modellierung aus. Die Anwendung zeigt den Objektauswahlbereich an.
2. Klicken Sie auf den Objekttyp in der Liste Objekte, der dem Objekttyp der zu definierenden Revision entspricht. Die Anwendung zeigt die Instanzauswahlliste an.
3. Klicken Sie auf die Revision der Instanz, für die Sie eine neue Revision definieren möchten. Die Anwendung zeigt die ausgewählte Instanz an.
Hinweis: Wenn Sie auf den Instanznamen statt auf eine bestimmte Revision klicken, wählt die Anwendung standardmäßig die Standardrevision aus.

Eine Kopie der ausgewählten Instanz zu erstellen

a. Klicken Sie auf Kopieren. Die Anwendung öffnet das Dialogfeld "Kopieren".

Vorgehensweise zum Löschen einer Instanz oder Revision

Gehen Sie folgendermaßen vor, um eine Instanz oder eine Revision zu löschen:

1. Wählen Sie Haupt im Menü Modellierung aus. Die Anwendung zeigt den Objektauswahlbereich an.
2. Klicken Sie auf den Objekttyp in der Liste Objekte, der dem Objekttyp der Instanz oder Revision entspricht, die Sie kopieren möchten. Die Instanzauswahlliste wird angezeigt.
3. Klicken Sie auf die Instanz oder Revision, die Sie löschen möchten. Wenn Sie auf den Instanznamen statt auf eine bestimmte Revision klicken, wählt die Anwendung standardmäßig die Standardrevision aus.
4. Führen Sie einen der folgenden Schritte durch:

Alle Revisionen
a. Wählen Sie die Standardrevision des Modellierungsobjekts aus. Die Schaltfläche "Alles löschen" wird angezeigt.
