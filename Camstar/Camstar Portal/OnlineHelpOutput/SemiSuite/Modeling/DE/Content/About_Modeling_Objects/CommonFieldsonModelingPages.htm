Gemeinsame Felder auf Modellierungsseiten

Jede Modellierungsobjektseite enthält Felder, die alle Modellierungsobjekte aufweisen. Diese Felder werden im Kopf der Seite und ganz unten auf der Seite angezeigt.

In dieser Tabelle sind die Felder definiert, die auf den Modellierungsseiten angezeigt werden.

Feld

Definition

Typ

<Modellierungsobjekt>

Eindeutiger Name des Modellierungsobjekts.

Erforderlich

Symbol für Revisionssperrung

Zeigt den Sperrstatus dieser Revision an. Bei Aktivierung dieses Symbols wird das Modellierungsobjekt gesperrt.

Hinweis: Dieses Feld ist nur für revisionierte Objekte verfügbar.

Optional

Revision

Revision oder Version der Objektinstanz. Sowohl der Name als auch die Revision sind erforderlich, um die Definition zu identifizieren.

Hinweis: Dieses Feld ist nur für revisionierte Objekte verfügbar.

Erforderlich

Ist Standardrevision

Gibt an, ob diese Revision die Standardrevision ist. In der Anwendung muss eine Revision als Standardrevision definiert werden. Es ist nur eine Standardrevision ist zulässig.

Hinweis: Dieses Feld ist nur für revisionierte Objekte verfügbar.

Optional

Filter-Tags

Tags, die der Modellierungsobjektinstanz zugewiesen werden, um die Datenfilterung zu erleichtern. Weitere Informationen finden Sie im Opcenter Execution Core Modeling-Benutzerhandbuch.

Optional

Beschreibung

Kurze Beschreibung des Modellierungsobjekts. Sie können maximal 255 Zeichen eingeben.

Optional

Hinweise

Relevante Kommentare. Sie können maximal 2000 Zeichen eingeben.

Optional

Status

Aktueller Status des Ortes (Aktiv oder Inaktiv).

Hinweis: Dieses Feld ist nur für revisionierte Objekte verfügbar.

Optional

Einrichtungszugriff

Legt die Zugriffskontrolle für diese Instanz fest. Nutzer müssen die gleiche Zugriffsebene besitzen, um diese Instanz zu ändern.

Optional
