Named Data Objects

Ein benanntes Datenobjekt (NDO) ist eine Klasse von Hauptmodellierungsobjekten, die durch einen eindeutigen Namen identifiziert werden. NDO-Instanzen sind persistent, d. h., dass die zugehörigen Informationen in die Datenbank geschrieben werden. Da NDOs nur durch einen Namen gekennzeichnet sind, müssen benannte Modellierungsobjekte desselben Typs eindeutige Namen aufweisen. Wenn Sie z. B. das Operationsmodellierungsobjekt "Montage" haben, können Sie keine andere Operation erstellen, die auch "Montage" heißt.

Sperrung von Revisionen

Die Funktion zur Sperrung von Revisionen bietet Ihnen die Möglichkeit, eine Instanz eines revisionierten Objekts dynamisch zu sperren oder zu entsperren.

Beim Sperren und Entsperren einer Instanz eines revisionierten Objekts ist Folgendes zu beachten:

• Sie müssen eine Instanz nicht speichern, um sie zu sperren oder zu entsperren.
• Auch auf die Felder einer gesperrten Instanz können Sie nach wie vor zugreifen. Allerdings kann eine gesperrte Instanz nicht gespeichert werden.
• Eine gesperrte Instanz kann nicht gelöscht werden.

Die Sicherheitsverwaltung für Semiconductor Shop Floor basiert auf einem rollenbasierten Zugriffssteuerungsmodell. Diese Sicherheitsverwaltung richtet Benutzerberechtigungen ein, die wiederum beeinflussen, wer die Revisionssperrfunktion verwenden kann.

Vorgehensweise zum Sperren oder Entsperren einer Instanz

Gehen Sie folgendermaßen vor, um eine Instanz zu sperren oder entsperren:

1. Wählen Sie Haupt im Menü Modellierung aus. Die Anwendung zeigt den Objektauswahlbereich an.
2. Klicken Sie auf den Objekttyp in der Liste Objekte, der dem Objekttyp der Instanz oder Revision entspricht, die Sie sperren oder entsperren möchten. Die Anwendung zeigt die Auswahlliste "Instanzen" an.
3. Klicken Sie auf den Namen der Instanz, die Sie sperren oder entsperren möchten. Die Anwendung zeigt die Objektseite für die ausgewählte Instanz an.
4. Führen Sie einen der folgenden Schritte durch:

Kopieren von gesperrten Instanzen und Revisionen

Die Anwendung ermöglicht es Ihnen, gesperrte Instanzen und Revisionen zu kopieren. Dazu können Sie folgendermaßen vorgehen:

• Klicken Sie auf "Kopieren", um eine Kopie der gesperrten Instanz mit allen ihren ursprünglichen Informationen mit Ausnahme des Namens zu erstellen.
• Klicken Sie auf "Revision kopieren", um eine Kopie der gesperrten Revision mit allen ihren ursprünglichen Informationen mit Ausnahme der Revision zu erstellen.

Vorgehensweise zum Kopieren von gesperrten Instanzen und Revisionen

Gehen Sie folgendermaßen vor, um eine gesperrte Instanz oder Revision zu kopieren:

1. Wählen Sie Haupt im Menü Modellierung aus. Die Anwendung zeigt den Objektauswahlbereich an.
2. Klicken Sie auf den Objekttyp in der Liste Objekte, der dem Objekttyp der Instanz oder Revision entspricht, die Sie kopieren möchten. Die Anwendung zeigt die Auswahlliste "Instanzen" an.
3. Klicken Sie auf die Seite, die das revisionierte Objekt mit der Instanz, die Sie kopieren möchten, enthält. Die Anwendung zeigt die Auswahlliste "Instanzen" an.
4. Klicken Sie auf den Instanznamen. Eine Seite mit der ausgewählte Instanz und einem Symbol mit geschlossenem Schloss wird angezeigt.
5. Führen Sie einen der folgenden Schritte durch:
