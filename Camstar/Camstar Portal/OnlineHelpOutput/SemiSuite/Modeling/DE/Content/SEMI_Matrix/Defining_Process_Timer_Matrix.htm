Definieren einer Prozesstimermatrix

Mit der Prozesstimermatrix können Sie Prozesstimer und deren zugehörige Start- und Endtransaktionen angeben, die verwendet werden, wenn ein Los die in der Matrix angegebenen Kriterien erfüllt.

Definieren einer Prozesstimermatrix

Ein Prozesstimer wird zu einer Spezifikation hinzugefügt. Sie können innerhalb der Spezifikation eine Haupttransaktion für Umlaufbestand, die den Timer auslöst (Starttransaktion), und eine Haupttransaktion für Umlaufbestand, die den Timer stoppt (Endtransaktion), angeben. Die Seite "Prozesstimermatrix" enthält zwei Tabellen – eine zum Hinzufügen von Timern, die starten, wenn bestimmte Transaktionen auftreten, und eine zum Hinzufügen von Timern, die enden, wenn bestimmte Transaktionen auftreten.

Vorgehensweise zum Definieren einer Prozesstimermatrix

Gehen Sie folgendermaßen vor, um eine Prozesstimermatrix zu definieren:

1. Öffnen Sie die Seite Prozesstimermatrix.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz" finden Sie weitere Informationen.
3. Geben Sie in das Feld Prozesstimermatrixname einen Namen für die Instanz der Prozesstimermatrix ein.
4. Geben Sie mindestens einen Eintrag in die Tabelle Starttimer-Transaktionszuordnung und einen Eintrag in die Tabelle Endtimer-Transaktionszuordnung ein.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
