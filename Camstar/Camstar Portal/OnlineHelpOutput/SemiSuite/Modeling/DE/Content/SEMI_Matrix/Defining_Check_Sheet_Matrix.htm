Definieren einer Prüfblattmatrix

Das Objekt "Prüfblattmatrix" dient zum Auflösen des Prüfblatts (auch automatische Abläufe genannt) für eine Transaktion. Prüfblätter ermöglichen Ihnen die Zuweisung einer Sammlung von Aufgaben zu einer Spezifikation. Ein Prüfblatt könnte z. B. erfordern, dass der Bediener die Workstation reinigt, einen Wafer misst, einen Wafer in ein Reinigungsbad setzt und schließlich den Wafer herausnimmt und erneut misst.

Dank der Prüfblattmatrix können mehrere Prüfblätter in einer einzelnen Spezifikation unterstützt werden. Sie können bis zu drei verschiedene Prüfblätter pro Spezifikation konfigurieren: eines für die Transaktion "Einbringen", eines für die Transaktion "Ausbringen" und eines für die Transaktion "Abmelden".

Hinweis: Da die Anwendung keine automatischen Abläufe vor der Transaktion "Einbringen" für den Container unterstützt, können Sie keine Prüfblätter für die Verwendung durch Anmeldetransaktionen konfigurieren.

Vorgehensweise beim Definieren von Objekten der Prüfblattmatrix

Denken Sie an folgende Punkte, wenn das Matrixobjekt die Funktion "Arbeitsplan für Umlaufbestandsschritt" verwendet, um einen Schritt im Arbeitsplan als eines der Kriterien zu definieren:

• Wenn Sie einen Schritt im Arbeitsplan löschen, der im Matrixobjekt referenziert wird, ist dieser spezielle Matrixeintrag ungültig.
• Wenn Sie einen Schritt im Arbeitsplan bearbeiten, der im Matrixobjekt referenziert wird, ist dieser spezielle Matrixeintrag nicht ungültig, es sei denn, der Schritt wird entfernt und erneut eingegeben.

Erforderlich

Fehleraktion

Die Fehleraktion für das Prüfblatt. Folgende Auswahlmöglichkeiten sind verfügbar:

• Fortsetzen. Gibt an, dass die Transaktion im Falle eines Prüfblattfehlers fortgesetzt werden soll.
• Blockiert. Gibt an, dass die Transaktion im Falle eines Prüfblattfehlers blockiert werden soll. Wenn die Transaktion blockiert wird, gibt die Anwendung das Los nicht an die nächste Transaktion weiter und es wird eine Fehlermeldung angezeigt, die darüber informiert, dass die Transaktion blockiert wurde.

Vorgehensweise zum Definieren einer Prüfblattmatrix

Gehen Sie folgendermaßen vor, um eine Prüfblattmatrix zu definieren:

1. Öffnen Sie die Seite Prüfblattmatrix. In der Anwendung wird die Seite "Prüfblattmatrix" angezeigt.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz" finden Sie weitere Informationen.
3. Geben Sie in das Feld Prüfblattmatrix: Name einen Namen für die Instanz der Prüfblattmatrix ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
