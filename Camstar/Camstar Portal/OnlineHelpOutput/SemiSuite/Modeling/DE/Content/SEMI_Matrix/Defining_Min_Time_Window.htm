Definieren einer Matrix für das minimale Zeitfenster

Die Matrix des minimalen Zeitfensters wird verwendet, um anzugeben, dass die minimal erforderliche Zeitdauer zwischen dem Einbringen und dem Ausbringen des Loses durchgesetzt wird. Das Zeitfenster wird beim Einbringen des Loses gestartet und während des Ausbringens verifiziert.

Definieren von Objekten der Matrix für das minimale Zeitfenster

Denken Sie an folgende Punkte, wenn das Matrixobjekt die Funktion "Arbeitsplan für Umlaufbestandsschritt" verwendet, um einen Schritt im Arbeitsplan als eines der Kriterien zu definieren:

• Wenn Sie einen Schritt im Arbeitsplan löschen, der im Matrixobjekt referenziert wird, ist dieser spezielle Matrixeintrag ungültig.
• Wenn Sie einen Schritt im Arbeitsplan bearbeiten, der im Matrixobjekt referenziert wird, ist dieser spezielle Matrixeintrag nicht ungültig, es sei denn, der Schritt wird entfernt und erneut eingegeben.

Sie können ein Nummerierungsregelobjekt definieren, um das Matrixobjekt automatisch zu benennen. Die Anwendung füllt das Feld "Name" dann automatisch, wenn Sie die Instanz speichern. Unter "Verwenden von Nummerierungsregeln zur automatischen Benennung von Instanzen" finden Sie weitere Informationen zur Verwendung von Nummerierungsregeln für die Benennung von Matrixobjektinstanzen.

E-Mail-Gruppe

Gibt die E-Mail-Gruppe an, an die eine E-Mail gesendet werden soll, falls im Hauptumlaufbestand ein Fehler erkannt wird.

Optional

Aktion für Vorzeitig

Auszuführende Aktion, falls das Los vor der Mindestzeit ausgebracht wird. Gültige Werte sind:

• Nicht erlaubt (NOTALLOWED; Standardwert) – Das Los darf nicht vor der Mindestzeit ausgebracht werden.
• Anhalten (HOLD) – Das Los wird angehalten, wenn es vor der Mindestzeit ausgebracht wird.
• Warnung (WARNING) – Es wird eine Warnmeldung zurückgegeben, wenn das Los vor der Mindestzeit ausgebracht wird.

Optional

Status für Vorzeitig

Status, der für die Ausrüstung festgelegt wird, wenn das Los vor der Mindestzeit ausgebracht wird.

Optional

Aktion für Verspätet

Aktion, die ausgeführt wird, wenn das Los nach der Mindestzeit plus dem Verspätungszeitrahmen ausgebracht wird. Gültige Werte sind:

• HOLD – Das Los wird angehalten, wenn Fehler erkannt werden. Die Anwendung verarbeitet keine Transaktionen für das Los.
• WARNING – Die Anwendung gibt eine Warnung aus, wenn Fehler erkannt werden, setzt die Verarbeitung von Transaktionen für das Los jedoch fort.

Erforderlich

Verspätungszeitrahmen (Minuten)

Zeitrahmen nach der Mindestzeit, während dem das Los ausgebracht werden kann. Wenn das Los nach der Mindestzeit plus dem Verspätungszeitrahmen ausgebracht wird, gilt das Los als verspätet und fehlgeschlagen.

Optional

Vorgehensweise zum Definieren einer Matrix für das minimale Zeitfenster

Gehen Sie folgendermaßen vor, um eine Matrix für das minimale Zeitfenster zu definieren:

1. Öffnen Sie die Seite Minimales Zeitfenster. Die Anwendung zeigt die Seite "Minimales Zeitfenster" an.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz" finden Sie weitere Informationen.
3. Geben Sie in das Feld Minimales Zeitfenster: Einrichtung: Name einen Namen für die Instanz der Matrix für das minimale Zeitfenster ein. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld beim Speichern der Instanz automatisch aus.
4. Geben Sie im Feld Mindestzeit (Stunden) an, nach wie vielen Stunden ein Los nach dem Einbringen wieder ausgebracht werden darf.
5. Geben Sie in das Feld Aktion für Verspätet die Aktion ein, die für das Los ausgeführt werden soll, wenn das Zeitfenster überschritten wird.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
