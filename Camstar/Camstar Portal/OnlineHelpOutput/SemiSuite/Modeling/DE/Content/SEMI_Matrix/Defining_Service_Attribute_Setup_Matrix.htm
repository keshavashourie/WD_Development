Definieren einer Serviceattributeinrichtungsmatrix

Die Serviceattributeinrichtung ist ein Matrixobjekt, das Ihnen die Definition von Attributen für einen Service (auch Transaktion genannt) ermöglicht, der die Matrixkriterien erfüllt. Sie verwenden die Seite "Serviceattribute: Einrichtung", um eine Instanz dieses Objekts zu konfigurieren.

Definieren einer Serviceattributeinrichtungsmatrix

Sie können ein Nummerierungsregelobjekt definieren, um das Matrixobjekt automatisch zu benennen. Die Anwendung füllt das Feld "Name" dann automatisch, wenn Sie die Instanz speichern. Unter "Verwenden von Nummerierungsregeln zur automatischen Benennung von Instanzen" finden Sie weitere Informationen zur Verwendung von Nummerierungsregeln für die Benennung von Matrixobjektinstanzen.

Vorgehensweise zum Definieren einer Serviceattributeinrichtungsmatrix

Gehen Sie folgendermaßen vor, um eine Serviceattributeinrichtungsmatrix zu definieren:

1. Öffnen Sie die Seite der Matrix Serviceattribute: Einrichtung. Die Anwendung zeigt die Seite "Serviceattributeinrichtungsmatrix" an.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz" finden Sie weitere Informationen.
3. Wählen Sie im Abschnitt "Kriterien" aus dem Feld Servicename einen Service (Transaktion) aus.
4. Geben Sie in das Feld Serviceattribute: Einrichtung: Name einen Namen für die Instanz ein. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld beim Speichern der Instanz automatisch aus.
5. Klicken Sie in der Tabelle "Details" auf Neue Zeile hinzufügen. Das Popup "Hinzufügen" wird angezeigt.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf OK. Das Popup wird geschlossen und das ausgewählte Attribut wird in der Tabelle "Details" angezeigt.
8. Wiederholen Sie die Schritte 5 bis 7, um weitere Attribute auszuwählen und zu konfigurieren.
9. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
10. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
