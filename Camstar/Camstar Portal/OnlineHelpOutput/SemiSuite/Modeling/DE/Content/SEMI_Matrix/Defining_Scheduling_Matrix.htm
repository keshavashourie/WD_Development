Definieren einer Ablaufplanungsmatrix

Eine Ablaufplanungsmatrix bestimmt das Planungsverhalten für Lose, die die in der Matrix angegebenen Kriterien erfüllen. Auf der Seite "Ablaufplanungsmatrix" können Sie Ablaufplanungsmatrizen anzeigen, erstellen und aktualisieren. Die Ablaufplanungsmatrix ist verfügbar, wenn "Ablaufplanung" auf Ihrem Opcenter Execution Semiconductor-Server installiert ist.

Hinweis: Allgemeine Informationen zu Matrixobjekten finden Sie unter "Informationen zu Matrixmodellierungsobjekten" und "Matrixmodellierungsseiten". Weitere Informationen zum Verwalten von Matrixobjektinstanzen finden Sie unter "Verwalten von Instanzen".

Nicht geplante Zeit

Option zum Konfigurieren zusätzlicher Prozesszeit, die nicht in den Einträgen "Einheiten pro Stunde", "Stunden pro Einheit" oder "Zeit pro Batch" enthalten oder gezählt ist. Dieses Feld ermöglicht es, die Dauer übersprungener Schritte oder zusätzlicher Schritte in die Gesamtprozesszeit einzurechnen. Z. B.:

• Das Backen eines Loses erfordert eine 10-minütige Abkühlzeit der Ausrüstung, die nicht in "Einheit pro Stunde" enthalten ist. "Nicht geplante Zeit" hilft, diese Zeiten in die Prozesszeit einzubeziehen.

Geben Sie die Batchverarbeitungszeit im zugehörigen Feld ein (in Tagen [optional], Stunden, Minuten und Sekunden).

Zeit pro Batch

Hinweis: Geben Sie die Batchverarbeitungszeit im zugehörigen Feld ein (in Tagen [optional], Stunden, Minuten und Sekunden). Wenn diese Option angegeben ist, sind "Stunden pro Einheit" und "Einheiten pro Stunde" deaktiviert.

Vorgehensweise zum Definieren einer Ablaufplanungsmatrix

Gehen Sie folgendermaßen vor, um eine Ablaufplanungsmatrix zu definieren:

1. Öffnen Sie die Seite Ablaufplanungsmatrix. Die Anwendung zeigt die Seite "Ablaufplanungsmatrix" an.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz" finden Sie weitere Informationen.
3. Geben Sie in das Feld Ablaufplanungsmatrix einen Namen für die Matrixinstanz ein. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld beim Speichern der Instanz automatisch aus.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
