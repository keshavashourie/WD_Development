Definieren einer Ausrüstungszwangsmatrix

Eine Ausrüstungszwangsmatrix ermöglicht Ihnen das Konfigurieren der Kriterien für die Ausrüstung, um zu kontrollieren, welche Lose der Ausrüstung eingebracht werden können. Die Anwendung prüft die für die Einbringung ausgewählte Ausrüstung und führt eine Zwangsmatrix aus, sofern eine für die Ausrüstung konfiguriert ist.

Definieren von Zwangsausdrücken

Sie können der Tabelle "Ausrüstungszwangsdetails" mehrere Zwangsausdrücke hinzufügen.

Hinweis: Sie können ein Nummerierungsregelobjekt definieren, um das Matrixobjekt automatisch zu benennen. Die Anwendung füllt das Feld "Name" dann automatisch, wenn Sie die Instanz speichern. Unter "Verwenden von Nummerierungsregeln zur automatischen Benennung von Instanzen" finden Sie weitere Informationen zur Verwendung von Nummerierungsregeln für die Benennung von Matrixobjektinstanzen.

Vorgehensweise zum Definieren einer Ausrüstungszwangsmatrix

Gehen Sie folgendermaßen vor, um eine Ausrüstungszwangsmatrix zu definieren:

1. Öffnen Sie die Seite Ausrüstungseinschränkung. In der Anwendung wird die Seite "Ausrüstungseinschränkung" angezeigt.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz" finden Sie weitere Informationen.
3. Geben Sie in das Feld Ausrüstungszwangsmatrix: Name einen Namen für die Instanz der Ausrüstungszwangsmatrix ein. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld beim Speichern der Instanz automatisch aus.
4. Klicken Sie in der Tabelle "Ausrüstungszwangsdetails" auf Neue Zeile hinzufügen und gehen Sie folgendermaßen vor:
a. Geben Sie in das Feld Aktion eine Aktion ein, die die Anwendung beim Einbringen ausführen soll.
b. Geben Sie in das Feld Ausdruck einen Ausdruck ein, der die Einschränkung definiert.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
