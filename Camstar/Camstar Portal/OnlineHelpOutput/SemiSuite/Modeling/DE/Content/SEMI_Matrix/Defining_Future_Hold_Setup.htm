Definieren der Matrix einer Einrichtung für zukünftiges Anhalten

Mit der Matrix einer Einrichtung für zukünftiges Anhalten werden die Einstellungen für zukünftiges Anhalten für Lose angegeben, die in der Zukunft ausgelöst werden. Die Matrix einer Einrichtung für zukünftiges Anhalten wird nur ausgewertet, wenn die Anwendung folgende Transaktionen ausführt:

• Los empfangen: Jedes Los, das in einen Lagerbereich eingeht, sucht während des Losempfangs nach einer Einrichtung für zukünftiges Anhalten. Die Anwendung hält das Los sofort an, wenn eine Einrichtung für zukünftiges Anhalten gefunden wird.
• Loszeitplan freigeben: Die Anwendung durchsucht während der Loszeitplanfreigabe alle Umlaufbestandsarbeitsplanschritte nach einer Einrichtung für zukünftiges Anhalten. Wenn die Anwendung eine Einrichtung für zukünftiges Anhalten findet, wird sie zum Los hinzugefügt. Nachdem sie zum Los hinzugefügt wurde, können Sie "Los: Einrichtung für zukünftiges Anhalten" verwenden, um sie anzuzeigen und zu ändern.
Hinweis: Die Matrix zur Einrichtung für zukünftiges Anhalten unterstützt keine Lose, die mit der Transaktion "Loszeitplan freigeben" (HPE) freigegeben wurden.

Definieren der Matrix einer Einrichtung für zukünftiges Anhalten

Sie können ein Nummerierungsregelobjekt definieren, um das Matrixobjekt automatisch zu benennen. Die Anwendung füllt das Feld "Name" dann automatisch, wenn Sie die Instanz speichern. Unter "Verwenden von Nummerierungsregeln zur automatischen Benennung von Instanzen" finden Sie weitere Informationen zur Verwendung von Nummerierungsregeln für die Benennung von Matrixobjektinstanzen.

Vorgehensweise zum Definieren der Matrix einer Einrichtung für zukünftiges Anhalten

Gehen Sie folgendermaßen vor, um die Matrix einer Einrichtung für zukünftiges Anhalten zu definieren:

1. Öffnen Sie die Seite Einrichtung für zukünftiges Anhalten. Die Anwendung zeigt die Seite "Einrichtung für zukünftiges Anhalten" an.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Klicken Sie auf die Schaltfläche Hinzufügen. Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Suchen Sie im Fenster "Filter" nach einer vorhandenen Instanz. Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Anweisungen hierzu finden Sie unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz".
3. Geben Sie in das Feld Einrichtung für zukünftiges Anhalten: Name einen Namen für die Instanz der Matrix einer Einrichtung für zukünftiges Anhalten ein. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld beim Speichern der Instanz automatisch aus.
4. Geben Sie in das Feld Spez. die Spezifikation für das zukünftige Anhalten ein.
5. Geben Sie in das Feld Anhaltegrund den Anhaltegrund ein.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
