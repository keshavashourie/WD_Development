Definieren einer Ausrüstungs-Erledigungsabfragematrix

Die Objekte der Ausrüstungs-Erledigungsabfragematrix werden zum Verwalten der Instanzen der verschiedenen Erledigungsabfragen und zum Auflösen der Erledigungsabfragen verwendet, die auf der Seite "Nachverfolgung des Ausrüstungsumlaufbestands" angezeigt werden. Weitere Informationen finden Sie im Opcenter Execution Semiconductor Shop Floor-Benutzerhandbuch.

Beispielerledigungsabfrage

Opcenter Execution Semiconductor stellt eine Beispielerledigungsabfrage entweder in der GUI-Abfrage "SEMI 0205 GUI Control" (für Oracle Portal) oder in der GUI-Abfrage "SEMI 0205 GUI Control" (für SQL Portal) zur Verfügung. Die Beispielabfrage gibt alle Lose für alle Spezifikationen zurück. Sie müssen die bereitgestellte Abfrage replizieren und ändern, um die Abfrageergebnisse basierend auf der Ausrüstungsverwendung innerhalb der Fabrik einzuschränken.

Definieren einer Ausrüstungs-Erledigungsabfragematrix

Sie können ein Nummerierungsregelobjekt definieren, um das Matrixobjekt automatisch zu benennen. Die Anwendung füllt das Feld "Name" dann automatisch, wenn Sie die Instanz speichern. Unter "Verwenden von Nummerierungsregeln zur automatischen Benennung von Instanzen" finden Sie weitere Informationen zur Verwendung von Nummerierungsregeln für die Benennung von Matrixobjektinstanzen.

Vorgehensweise zum Definieren einer Ausrüstungs-Erledigungsabfragematrix

Gehen Sie folgendermaßen vor, um eine Ausrüstungs-Erledigungsabfragematrix zu definieren:

1. Öffnen Sie die Seite Ausrüstung: Erledigungsabfrage. In der Anwendung wird die Seite "Ausrüstung: Erledigungsabfrage" angezeigt.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz" finden Sie weitere Informationen.
3. Geben Sie in das Feld Ausrüst.-Erledigungsabfragematrix: Name einen Namen für die Instanz der Ausrüstungs-Erledigungsabfragematrix ein. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld beim Speichern der Instanz automatisch aus.
4. Geben Sie in das Feld Erledigungsabfrage eine Erledigungsabfrage ein.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
