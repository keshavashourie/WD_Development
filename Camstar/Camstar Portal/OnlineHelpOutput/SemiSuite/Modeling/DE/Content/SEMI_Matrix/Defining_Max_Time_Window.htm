Definieren einer Matrix für das maximale Zeitfenster

Die Matrix für das maximale Zeitfenster wird verwendet, um anzugeben, dass ein Los die maximale Zeitdauer zwischen zwei Schritten nicht überschreitet. Das Zeitfenster wird gestartet, wenn das Los von der erforderlichen Startspezifikation ausgebracht und durch den Hauptumlaufbestand verifiziert wird, wenn das Los in der erforderlichen Stoppspezifikation ausgewählt wird.

Definieren von Objekten der Matrix für das maximale Zeitfenster

Wenn das Matrixobjekt das Kriterium "Arbeitsplan mit Startschritt" oder "Arbeitsplan mit Stoppschritt" zum Definieren eines Schritts im Arbeitsplan verwendet und der Schritt gelöscht oder bearbeitet wird, werden alle vorhandenen Matrixobjekte, die mit dem Schritt verknüpft sind, ungültig.

Sie können ein Nummerierungsregelobjekt definieren, um das Matrixobjekt automatisch zu benennen. Die Anwendung füllt das Feld "Name" dann automatisch, wenn Sie die Instanz speichern. Unter "Verwenden von Nummerierungsregeln zur automatischen Benennung von Instanzen" finden Sie weitere Informationen zur Verwendung von Nummerierungsregeln für die Benennung von Matrixobjektinstanzen.

Vorgehensweise zum Definieren einer Matrix für das maximale Zeitfenster

Gehen Sie folgendermaßen vor, um eine Matrix für das maximale Zeitfenster zu definieren:

1. Öffnen Sie die Seite Maximales Zeitfenster. Die Anwendung zeigt die Seite "Maximales Zeitfenster" an.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz" finden Sie weitere Informationen.
3. Geben Sie in das Feld Maximales Zeitfenster: Einrichtung: Name einen Namen für die Instanz der Matrix für das maximale Zeitfenster ein. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld beim Speichern der Instanz automatisch aus.
4. Geben Sie in das Feld Startspez. die Spezifikation ein, die den Anfang der Zeitdauer markiert.
5. Geben Sie in das Feld Stoppspez. die Spezifikation ein, die das Ende der Zeitdauer markiert.
6. Geben Sie in das Feld Max. Zeit (Stunden) die maximale Zeitdauer für das Zeitfenster ein.
7. Geben Sie in das Feld Aktion für Verspätet die Aktion ein, die für das Los ausgeführt werden soll, wenn das Zeitfenster überschritten wird.
8. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
9. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
