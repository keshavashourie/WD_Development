Definieren einer Losgrößenstichprobenmatrix

Die Losgrößenstichprobenmatrix dient zum Angeben der Parameter für Stichprobentests einer Spezifikation.

Definieren einer Losgrößenstichprobenmatrix

Sie können ein Nummerierungsregelobjekt definieren, um das Matrixobjekt automatisch zu benennen. Die Anwendung füllt das Feld "Name" dann automatisch, wenn Sie die Instanz speichern. Unter "Verwenden von Nummerierungsregeln zur automatischen Benennung von Instanzen" finden Sie weitere Informationen zur Verwendung von Nummerierungsregeln für die Benennung von Matrixobjektinstanzen.

Felddefinitionen der Seite "Losgrößenstichprobe"

Diese Tabelle definiert die Felder auf der Seite "Losgrößenstichprobe".

Feld

Definition

Typ

Kriterien

Spez.

Spezifikation, für die die Instanz gilt.

Erforderlich

Details

Einrichtungsname der Losgrößenstichprobe

Eindeutiger Name für die Matrixinstanz. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld automatisch aus, wenn Sie die Instanz speichern.

Optional

Schwellenwert für Losgröße

Schwellenwert, der zum Vergleich mit der Losmenge verwendet wird, um die zu verwendenden Kontrolllimits zu bestimmen. Es wird der kleinste Schwellenwert verwendet, der größer oder gleich der Losmenge ist.

Erforderlich

Zu verarbeitende Menge

Losmenge, die zum Verarbeiten der Stichprobe erforderlich ist.

Erforderlich, wenn "Zu verarbeitende Menge: Prozentsatz" nicht angegeben ist.

Zu verarbeitende Menge: Prozentsatz

Prozentsatz der Losmenge, die zum Verarbeiten der Stichprobe erforderlich ist.

Erforderlich, wenn "Zu verarbeitende Menge" nicht angegeben ist.

Vorgehensweise zum Definieren einer Losgrößenstichprobenmatrix

Gehen Sie folgendermaßen vor, um eine Losgrößenstichprobenmatrix zu definieren:

1. Öffnen Sie die Seite Losgrößenstichprobe. Die Anwendung zeigt die Seite "Losgrößenstichprobe" an.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz" finden Sie weitere Informationen.
3. Geben Sie in das Feld Losgrößenstichprobe: Einrichtung: Name einen Namen für die Instanz der Losgrößenstichprobenmatrix ein. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld beim Speichern der Instanz automatisch aus.
4. Geben Sie in das Feld Spez. die Umlaufbestandsspezifikation für die Losstichprobe ein.
5. Führen Sie Folgendes für jede Losstichprobe in der Tabelle "Details" aus:
a. Klicken Sie auf Neue Zeile hinzufügen.
b. Geben Sie in das Feld Schwellenwert für Losgröße den Schwellenwert für den Vergleich mit der Losmenge ein.
c. Geben Sie einen oder beide der folgenden Werte ein:
• Die Losmenge, die zum Verarbeiten der Stichprobe erforderlich ist (Feld Zu verarbeitende Menge).
• Den Prozentsatz der Losmenge, die zum Verarbeiten der Stichprobe erforderlich ist (Feld Zu verarbeitende Menge: Prozentsatz).
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
