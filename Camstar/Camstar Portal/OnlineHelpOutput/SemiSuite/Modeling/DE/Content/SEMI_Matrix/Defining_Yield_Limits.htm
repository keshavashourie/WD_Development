Definieren einer Ertragslimitmatrix

Objekte der Ertragslimitmatrix werden verwendet, um Limits anzugeben, die für die Berechnungen des Ertragshandlers verwendet werden.

Definieren von Objekten der Ertragslimitmatrix

Denken Sie an folgende Punkte, wenn das Matrixobjekt die Funktion "Arbeitsplan für Umlaufbestandsschritt" verwendet, um einen Schritt im Arbeitsplan als eines der Kriterien zu definieren:

• Wenn Sie einen Schritt im Arbeitsplan löschen, der im Matrixobjekt referenziert wird, ist dieser spezielle Matrixeintrag ungültig.
• Wenn Sie einen Schritt im Arbeitsplan bearbeiten, der im Matrixobjekt referenziert wird, ist dieser spezielle Matrixeintrag nicht ungültig, es sei denn, der Schritt wird entfernt und erneut eingegeben.

Sie können ein Nummerierungsregelobjekt definieren, um das Matrixobjekt automatisch zu benennen. Die Anwendung füllt das Feld "Name" dann automatisch, wenn Sie die Instanz speichern. Unter "Verwenden von Nummerierungsregeln zur automatischen Benennung von Instanzen" finden Sie weitere Informationen zur Verwendung von Nummerierungsregeln für die Benennung von Matrixobjektinstanzen.

Oberer Ertrag: Fehleraktion

Gibt die Aktion an, die im Falle eines Fehlers des oberen Ertrags ausgeführt wird. Folgende Optionen sind möglich:

• HOLD – Das Los wird angehalten, wenn Fehler erkannt werden. Die Anwendung verarbeitet keine Transaktionen für das Los. Sie müssen einen Wert für das Feld "Oberer Ertrag: Fehler: Anhaltegrund" angeben, wenn Sie "HOLD" auswählen.
• HOLDALL – Das Los und alle anderen Lose im zugehörigen Zeitplan werden angehalten, wenn Fehler erkannt werden. Die Anwendung verarbeitet keine Transaktionen für keine Lose. Sie müssen einen Wert für das Feld "Oberer Ertrag: Fehler: Anhaltegrund" angeben, wenn Sie "HOLDALL" auswählen.
• WAIVE – Das Los wird nicht angehalten, selbst wenn Fehler erkannt werden. Die Anwendung setzt die Verarbeitung von Transaktionen für das Los fort.
• FUTUREHOLD – Das Los wird in einem späteren Schritt angehalten. Die Anwendung setzt die Verarbeitung von Transaktionen fort, bis das Los den späteren Schritt erreicht. Sie müssen einen Wert für das Feld "Oberer Ertrag: Einrichtung für zukünftiges Anhalten bei Fehlern" angeben, wenn Sie "FUTUREHOLD" auswählen.

Vorgehensweise zum Definieren einer Ertragslimitmatrix

Gehen Sie folgendermaßen vor, um eine Ertragslimitmatrix zu definieren:

1. Öffnen Sie die Seite Ertragslimits. Die Anwendung zeigt die Seite "Ertragslimits" an.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Geben Sie Einstellungen im Abschnitt Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Instanz aus und bearbeiten Sie sie. Anweisungen hierzu finden Sie unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz".
3. Geben Sie in das Feld Ertragslimits: Name einen Namen für die Matrixinstanz ein. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld beim Speichern der Instanz automatisch aus.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
