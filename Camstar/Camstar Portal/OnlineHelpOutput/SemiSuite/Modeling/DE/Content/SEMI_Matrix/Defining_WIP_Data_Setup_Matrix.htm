Definieren einer Matrix für Umlaufbestandsdateneinrichtung

Die Matrix für Umlaufbestandsdateneinrichtung dient zum Auflösen der Umlaufbestandsdateneinrichtung, mit der während der folgenden Transaktionen Daten für Lose gesammelt werden:

• Einbringen
• Ausbringen
• Abmelden
• Einsetzung abschließen

Wenn die Matrix für Umlaufbestandsdateneinrichtung definiert ist und das Kontrollkästchen "Matrix für Umlaufbestandsdateneinrichtung verwenden" in der Umlaufbestandsspezifikation aktiviert wurde, bestimmt die Anwendung die zu verwendende Umlaufbestandsdateneinrichtung anhand des höchsten übereinstimmenden Algorithmus, basierend auf den Suchkriterien, die in der Matrix definiert sind. Die resultierende Umlaufbestandsdateneinrichtung überschreibt alle Umlaufbestandsdateneinrichtungen, die auf der Spezifikations- oder Prozessspezifikationsebene konfiguriert sind. Umlaufbestandsdateneinrichtungen, die innerhalb der Versuchspläne zugewiesen sind, werden nicht überschrieben. Weitere Informationen zu Umlaufbestandsspezifikationen finden Sie unter "Definieren von Umlaufbestandsspezifikationen".

Definieren von Objekten der Matrix für Umlaufbestandsdateneinrichtung

Denken Sie an folgende Punkte, wenn das Matrixobjekt die Funktion "Arbeitsplan für Umlaufbestandsschritt" verwendet, um einen Schritt im Arbeitsplan als eines der Kriterien zu definieren:

• Wenn Sie einen Schritt im Arbeitsplan löschen, der im Matrixobjekt referenziert wird, ist dieser spezielle Matrixeintrag ungültig.
• Wenn Sie einen Schritt im Arbeitsplan bearbeiten, der im Matrixobjekt referenziert wird, ist dieser spezielle Matrixeintrag nicht ungültig, es sei denn, der Schritt wird entfernt und erneut eingegeben.

Sie können ein Nummerierungsregelobjekt definieren, um das Matrixobjekt automatisch zu benennen. Die Anwendung füllt das Feld "Name" dann automatisch, wenn Sie die Instanz speichern. Unter "Verwenden von Nummerierungsregeln zur automatischen Benennung von Instanzen" finden Sie weitere Informationen zur Verwendung von Nummerierungsregeln für die Benennung von Matrixobjektinstanzen.

Hinweis: Sie müssen auf der Seite "Matrix für Umlaufbestandsdateneinrichtung" auf "Speichern" klicken, damit die Anwendung auf anderen Seiten vorgenommene neue Änderungen laden kann. Wenn Sie z. B. Änderungen an Umlaufbestandsdatenname, Umlaufbestandsdateneinrichtung oder Modellierungsinstanzen vorgenommen haben, die mit den Einträgen oder der Tabelle der Matrix für die Umlaufbestandsdateneinrichtung verbunden sind, müssen Sie die Matrixseite speichern, um die neuen Informationen zu laden.

Vorgehensweise zum Definieren einer Instanz der Matrix für Umlaufbestandsdateneinrichtung

Gehen Sie folgendermaßen vor, um eine Matrix für Umlaufbestandsdateneinrichtung zu definieren:

1. Öffnen Sie die Seite Matrix für Umlaufbestandsdateneinrichtung. Die Anwendung zeigt die Seite "Matrix für Umlaufbestandsdateneinrichtung: Name" an.
2. Führen Sie eines der Verfahren wie in der folgenden Tabelle angegeben aus:

Zu definierendes Element . . .

Gehen Sie wie folgt vor . . .

Neue Instanz

Klicken Sie in der rechten Befehlsleiste auf die Schaltfläche Hinzufügen. Geben Sie Einstellungen im Bereich Kriterien an. Der Tabelle mit den Felddefinitionen können Sie Informationen zu den verfügbaren Feldern entnehmen.

Instanz unter Verwendung einer vorhandenen Instanz

Wählen Sie eine vorhandene Zeileninstanz aus dem Gitter der Seite aus. Klicken Sie in der rechten Befehlsleiste auf die Schaltfläche Bearbeiten, um die Seite "Popup bearbeiten" anzuzeigen. Anweisungen hierzu finden Sie unter "Vorgehensweise zum Speichern einer bearbeiteten Instanz als neue Instanz".
3. Geben Sie in das Feld Matrix für Umlaufbestandsdateneinrichtung: Name einen Namen für die Instanz ein. Wenn Sie keinen Namen angeben und für dieses Matrixobjekt ein Nummerierungsregelobjekt modelliert wurde, füllt die Anwendung dieses Feld beim Speichern der Instanz automatisch aus.
4. Geben Sie in das Feld Umlaufbestandsdateneinrichtung die aufzulösende Umlaufbestandsdateneinrichtung ein.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Bearbeiten von Details der Matrix für Umlaufbestandsdateneinrichtung

Gehen Sie folgendermaßen vor, um die Details der Matrix für Umlaufbestandsdateneinrichtung zu bearbeiten:

1. Wählen Sie die Tabellenzeile Umlaufbestandsdateneinrichtung: Details aus.
2. Klicken Sie in der rechten Befehlsleiste auf die Schaltfläche Bearbeiten. Das Popup "Bearbeiten" wird angezeigt.
3. Blättern Sie im Popup nach unten, bis die bearbeitbaren Felder angezeigt werden.
4. Wählen Sie Werte aus oder geben Sie Änderungen ein.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
