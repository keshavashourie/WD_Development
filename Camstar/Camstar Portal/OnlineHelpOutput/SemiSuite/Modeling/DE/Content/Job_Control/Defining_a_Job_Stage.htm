Definieren einer Jobstufe

Eine Jobstufe ist ein Schritt in einem Jobarbeitsplan. Das Jobstufen-Modellierungsobjekt wird verwendet, um eine Jobstufe hinzufügen.

Hinweis: Obwohl der Stufenname eindeutig sein muss, kann es viele Jobs mit demselben Stufennamen geben, jeweils mit eigener Stufeninhaltsdefinition.

Vorgehensweise zum Definieren einer Jobstufe

Gehen Sie folgendermaßen vor, um eine Jobstufe zu definieren:

1. Öffnen Sie die Seite Jobstufe. Die Seite "Jobstufe" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie den Namen der Jobstufe in das Feld Jobstufe ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
