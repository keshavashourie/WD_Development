Automatisierte Joberstellung

Zwei Bereiche von Opcenter Execution Semiconductor können für die automatische Joberstellung konfiguriert werden:

• Wartungsverwaltung
• Statusmodell

Wartungsverwaltung

Mit der Wartungsverwaltungsfunktion von Opcenter Execution Semiconductor können Sie Anforderungen an die Ressourcenwartung definieren und verfolgen. Mit den Transaktionen "Wartungsklassenaktivierung" und "Ressourcenaktivierung" können Sie diese Anforderungen Ressourcen zuweisen. Die Anforderungen werden verfolgt und während der Ausführung von Fertigungsservices durchgesetzt.

Datums-, Wiederholungstermin- und Durchsatz- und Nutzungsmodellierungsobjekte können so konfiguriert werden, dass sie ein zugehöriges Jobmodell enthalten. Wenn die Anwendung eine Wartungsanforderung ausführt, die mit einem Jobmodell konfiguriert ist, erstellt sie automatisch einen Job auf der Basis dieses Jobmodells. Weitere Informationen finden Sie unter "Wartungsverwaltung – Einführung".

Statusmodell und Transaktion "Status festlegen"

Mit dem Statusmodellobjekt können Sie gültige Kombinationen für "Von Status/Zu Status"-Ressourcenstatusänderungen konfigurieren. Jede Statuskombination kann mit einem Grund konfiguriert werden. Jeder Grund kann mit zwei Optionen verknüpft werden:

• Autom. Joberstellung: Jobmodell
• Autom. Joberstellung: Vorbedingung

Wenn die Transaktion "Status festlegen" ein Statusmodell ausführt, das mit einem Jobmodell konfiguriert ist, erstellt sie einen Job auf der Basis dieses Modells.
