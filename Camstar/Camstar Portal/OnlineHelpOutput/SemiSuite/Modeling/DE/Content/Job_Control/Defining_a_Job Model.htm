Definieren eines Jobmodells

Ein Jobmodell ist ein Arbeitsplan, der für die Reparatur oder Routinewartung einer Fertigungsressource durchgeführt wird. Das Jobmodellobjekt wird verwendet, um einen Jobmodell-Arbeitsplan zu konfigurieren. Nach seiner Konfiguration kann ein Jobmodell einer spezifischen Ausrüstungsressource als Prozedur zugewiesen werden, die befolgt werden muss, wenn die Ausrüstung ausfällt.

Vorgehensweise zum Definieren eines Jobmodells

Gehen Sie folgendermaßen vor, um ein Jobmodell zu definieren:

1. Öffnen Sie die Seite Jobmodell. Die Seite "Jobmodell" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das Jobmodell ein.
4. Wählen Sie Jobtyp aus.
5. Verwenden Sie die Tabelle "Details" wie folgt für jede Stufe (Schritt), die (der) dem Jobmodell hinzugefügt werden soll:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung öffnet das Popup "Hinzufügen".
b. Wählen Sie Stufe aus.
c. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
d. Klicken Sie auf OK. Das Dialogfeld wird geschlossen.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
