Definieren von "Versuch: Autom. erg. Spez."-Objekten

Das Modellierungsobjekt für "Versuch: Autom. erg. Spez." gibt den ergänzenden Spezifikationsplan an, der an ein Los angehängt wird, wenn es einen Umlaufbestandsschritt erreicht.

Beachten Sie die folgenden Punkte beim Definieren eines Objekts für die automatische ergänzende Spezifikation für Versuche:

• Bevor Sie ein Objekt für die automatische ergänzende Spezifikation für Versuche definieren, müssen Sie ein Zeitplanobjekt für den ergänzenden Spezifikationsplan definieren. Weitere Informationen finden Sie unter "Definieren von Plänen des Typs "Zeitplan: Erg. Spez.-Plan"".
• Aktivieren Sie nicht das Kontrollkästchen "Automatisch vorbereiten", wenn Sie ein Los erstellen oder starten. Informationen zur Option "Automatisch vorbereiten" für Lose finden Sie im Opcenter Execution Semiconductor Shop Floor-Benutzerhandbuch.

Vorgehensweise zum Definieren einer automatischen ergänzenden Spezifikation für Versuche

Gehen Sie folgendermaßen vor, um eine automatische ergänzende Spezifikation für Versuche zu definieren:

1. Öffnen Sie die Seite Versuch: Autom. erg. Spez.. Die Seite "Versuch: Autom. erg. Spez." wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das "Versuch: Autom. erg. Spez."-Objekt in das Feld Versuch: Autom. erg. Spez. ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
