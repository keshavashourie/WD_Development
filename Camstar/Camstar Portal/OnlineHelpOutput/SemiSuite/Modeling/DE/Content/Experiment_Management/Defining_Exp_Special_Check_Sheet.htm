Definieren von speziellen Prüfblättern für Versuche

Mit dem Modellierungsobjekt für spezielle Prüfblätter für Versuche können Sie das zu verwendende Prüfblatt angeben, wenn ein Versuch bei einer bestimmten Transaktion aktiviert werden soll. Objekte für spezielle Prüfblätter für Versuche überschreiben das Prüfblattmatrix-Objekt.

Hinweis: Prüfblätter werden auch als automatische Abläufe bezeichnet. Informationen zu automatischen Abläufen finden Sie im Opcenter Execution Core Modeling-Benutzerhandbuch.

Felddefinitionen der Seite "Versuch: Spezielles Prüfblatt"

Diese Tabelle definiert die Felder auf der Seite "Versuch: Spezielles Prüfblatt".

Feld

Definition

Typ

Details

Tabelle "Prüfblattdetails"

Details des speziellen Prüfblatts für den Versuch, die durch den Transaktionstyp und automatischen Ablauf definiert werden.

Optional

Transaktionstyp

Gibt an, ob das Prüfblatt für die Einbring-, Ausbring- oder Abmeldetransaktion verwendet werden soll.

Hinweis: Da die Anwendung keine automatischen Abläufe vor der Transaktion "Einbringen" für den Container unterstützt, können Sie keine Prüfblätter für die Verwendung durch Anmeldetransaktionen konfigurieren.

Erforderlich

Automatischer Ablauf

Bezeichnung für eine Folge von Aufgaben, die erforderlich sind, um die erforderlichen Arbeiten zu erledigen.

Hinweis: Die Anwendung verwendet standardmäßig die Standardrevision, wenn Sie keine Revision angeben.

Erforderlich

Fehleraktion

Fehleraktion für das Prüfblatt. Folgende Auswahlmöglichkeiten sind verfügbar:

• Fortsetzen – Gibt an, dass die Transaktion im Falle eines Prüfblattfehlers fortgesetzt werden soll.
• Blockiert – Gibt an, dass die Transaktion im Falle eines Prüfblattfehlers blockiert werden soll. Wenn die Transaktion blockiert wird, gibt die Anwendung das Los nicht an die nächste Transaktion weiter und es wird eine Fehlermeldung angezeigt, die darüber informiert, dass die Transaktion blockiert wurde.

Erforderlich

Vorgehensweise zum Definieren eines speziellen Prüfblatts für Versuche

Gehen Sie folgendermaßen vor, um ein spezielles Prüfblatt für einen Versuch zu definieren:

1. Öffnen Sie die Seite Versuch: Spezielles Prüfblatt. Die Seite "Versuch: Spezielles Prüfblatt" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das spezielle Prüfblattobjekt für Versuche in das Feld Versuch: Spezielles Prüfblatt ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
