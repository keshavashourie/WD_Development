Definieren von Versuchsplänen

Der Versuchsplan definiert eine Reihe von Aktionen, die das für ein Versuchslos vorgesehene Standardverhalten der Prozessspezifikation überschreiben. Sie erstellen ein Versuchslos, wenn Sie die Seite "Los: Versuch zuweisen" verwenden, um den Versuchsplan an ein Los anzuhängen. Informationen zur Seite "Los: Versuch zuweisen" finden Sie im Opcenter Execution Semiconductor Shop Floor-Benutzerhandbuch.

Beim Genehmigen von Versuchsplänen

Wenn Sie einen Versuchsplan erstellen, sendet die Anwendung eine E-Mail an eine Überprüfungs- und Genehmigungsgruppe. Mitglieder dieser Gruppe müssen den Plan dann genehmigen, bevor der Versuchsplan an Lose angehängt werden kann. Sie können einen Versuchsplan erst an Lose anhängen, wenn der Status des Versuchsplans auf "Genehmigt" festgelegt ist.

Die folgende Liste beschreibt jeden Schritt im Genehmigungsprozess des Versuchsplans:

1. Entwurf – Der Versuchsplan ist neu oder ein vorhandener Versuchsplan, der abgelehnt und geändert wurde. Sie müssen den Status auf "Entwurf" festlegen, wenn der Versuchsplan zuerst gespeichert wird. Versuchspläne mit diesem Status können geändert werden.
2. Überprüfung – Der Versuchsplan ist bereit für die Überprüfung. Wenn Sie den Status von "Entwurf" in "Überprüfung" ändern und den Versuchsplan speichern, benachrichtigt die Anwendung die im Feld "Gruppe für Überprüfung und Genehmigung" angegebene Überprüfungs- und Genehmigungsgruppe. Die Mitglieder der Überprüfungs- und Genehmigungsgruppe öffnen den Versuchsplan, überprüfen ihn und legen den Status dann auf "Genehmigt" oder "Abgelehnt" fest.
3. Abgelehnt – Wenn die Überprüfungs- und Genehmigungsgruppe den Versuchsplan ablehnt, muss er geändert werden, bevor er implementiert werden kann. Wenn die Überprüfungs- und Genehmigungsgruppe den Status in "Abgelehnt" ändert, benachrichtigt die Anwendung die im Feld "Eigentümer-Mitarbeitergruppe" angegebene Gruppe, die anschließend die erforderlichen Änderungen vornimmt. Nachdem der Versuchsplan geändert wurde, erhält er den Status "Entwurf" und der Versuchsplan beginnt den Genehmigungsprozess erneut.

Voraussetzungen

Vor dem Definieren von Versuchsplänen sollten Sie eines oder mehrere der folgenden Modellierungsobjekte definieren, um Schritte im Versuchsplan entsprechend den Anforderungen Ihres Unternehmens hinzuzufügen:

• Versuch: Automatisches Anhalten – Weitere Informationen finden Sie unter "Definieren von "Versuch: Automatisches Anhalten"-Objekten".
• Versuch: Autom. Aufteilung – Sie können mehrere automatische Aufteilungen im selben Schritt oder in derselben Spezifikation konfigurieren. Weitere Informationen finden Sie unter "Definieren des automatischen Aufteilens von Versuchen".
• Versuch: Autom. erg. Spez. – Weitere Informationen finden Sie unter "Definieren von "Versuch: Autom. erg. Spez."-Objekten".
• Versuch: Spezielles Prüfblatt – Weitere Informationen finden Sie unter "Definieren von speziellen Prüfblättern für Versuche".
• Versuch: Spezielle Anweisungen – Weitere Informationen finden Sie unter "Definieren von speziellen Anweisungen für Versuche".

Felddefinitionen der Seite "Versuchsplan"

Diese Tabelle definiert die Felder auf der Seite "Versuchsplan".

Feld

Definition

Typ

Versuchsplan: Status

Aktueller Status des Versuchsplans. Der Versuchsplan muss den Genehmigungsprozess in der folgenden Reihenfolge durchlaufen:

1. Entwurf – Der Versuchsplan ist neu oder wurde abgelehnt und geändert.
2. Überprüfung – Der Versuchsplan ist bereit für die Überprüfung. Wenn Sie den Status von "Entwurf" in "Überprüfung" ändern, benachrichtigt die Anwendung die im Feld "Gruppe für Überprüfung und Genehmigung" angegebene Gruppe.
3. Abgelehnt – Der Versuchsplan wird abgelehnt und muss geändert werden. Wenn Sie den Status in "Abgelehnt" ändern, benachrichtigt die Anwendung die im Feld "Eigentümer-Mitarbeitergruppe" angegebene Gruppe. Nachdem der Versuchsplan geändert wurde, ändert die Eigentümer-Mitarbeitergruppe den Status in "Entwurf".

Erforderlich

 

4. Genehmigt – Der Versuchsplan ist genehmigt und kann an Lose angehängt werden. Wenn Sie den Status in "Genehmigt" ändern, benachrichtigt die Anwendung die im Feld "Eigentümer-Mitarbeitergruppe" angegebene Gruppe. Sie können keine Versuchspläne mit einem genehmigten Status ändern.

Wichtig: Wenn Sie einen Versuchsplan auf "Genehmigt" festlegen, können Sie keine weiteren Änderungen vornehmen. Alle Felder sind auf schreibgeschützt festgelegt. Solange der Versuchsplan jedoch noch nicht an ein Los angehängt wurde, können Sie ihn als "Abgelehnt" markieren, speichern, die erforderlichen Änderungen vornehmen und den Status auf "Entwurf" festlegen. Wenn ein genehmigter Versuchsplan an ein Los angehängt wird, können Sie keine Änderungen vornehmen, selbst wenn Sie ihn vom Los abhängen. Informationen zum Anhängen von Versuchsplänen an Lose finden Sie im Opcenter Execution Semiconductor Shop Floor-Benutzerhandbuch.

 

Eigentümer-Mitarbeitergruppe

Mitarbeitergruppe, der der Versuchsplan gehört. Mitarbeiter dieser Gruppe erhalten eine E-Mail-Benachrichtigung, wenn der Status des Versuchsplans in "Genehmigt" oder "Abgelehnt" geändert wird.

Mitarbeitergruppe, die für die Genehmigung des Versuchsplans zuständig ist. Vorgehensweise zum Definieren eines Versuchsplans

Gehen Sie folgendermaßen vor, um einen Versuchsplan zu definieren:

1. Öffnen Sie die Seite Versuchsplan. Die Seite "Versuchsplan" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie die folgenden erforderlichen Informationen ein:
• Versuchsplan
• Revision
• Versuchsplan: Status
• Eigentümer-Mitarbeitergruppe
• Prozessspez.
• Gruppe für Überprüfung und Genehmigung
4. Führen Sie die folgenden Schritte in der Tabelle "Versuchsplan: Details" für jede Aktion durch, die Sie zum Versuchsplan hinzufügen möchten:
a. Klicken Sie auf Neue Zeile hinzufügen. Die Anwendung öffnet das Popup "Hinzufügen".
b. Geben Sie je nach den Anforderungen Ihres Betriebs die Informationen im Popup "Hinzufügen" ein. Weitere Informationen zu den Feldern finden Sie unter "Felddefinitionen des Popups "Hinzufügen" für Versuchspläne".
c. Klicken Sie auf OK.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
