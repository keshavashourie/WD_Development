Definieren des automatischen Aufteilens von Versuchen

Das Modellierungsobjekt für "Versuch: Autom. Aufteilung" definiert, wie Wafer in einem Los für einen Versuchsplan aufgeteilt werden sollten. Wenn Versuchspläne ausgeführt werden, für die "Versuch: Autom. Aufteilung" festgelegt ist, werden Lose entsprechend der unter "Versuch: Autom. Aufteilung" definierten Konfiguration aufgeteilt.

Wenn Sie das Los nach Elementen (Wafern) aufteilen, müssen Sie die Seite "Behälter: Slotzuordnung zuweisen" verwenden, um die Wafer im Versuchslos den Slots im Waferbehälter zuzuordnen, bevor Sie Versuchslose einbringen, für die automatische Aufteilungsschritte festgelegt sind. Informationen zur Seite "Behälter: Slotzuordnung zuweisen" finden Sie im Opcenter Execution Semiconductor Shop Floor-Benutzerhandbuch.

Wenn Sie das Los nach Menge aufteilen (Nicht-Element-Lose) ist kein Behälter erforderlich.

Beim Definieren des automatischen Aufteilens von Versuchen

Bei den meisten Teilungstypen erlauben Versuchspläne mehrere Aufteilungen im selben Schritt. Mehrfachaufteilungen sind nur bei folgenden Teilungstypen möglich:

• Untere N
• Nach Slot
• Nach Menge
• Erste Hälfte
• Letzte Hälfte
• Menge aufteilen
• Obere N

Wenn mehrere Aufteilungen durchgeführt werden, gelten die folgenden Regeln:

• Im Falle der Teilungstypen "Gerade" oder "Ungerade" oder jeder Kombination, die einen geraden oder ungeraden Teilungstyp beinhaltet, können keine Mehrfachaufteilungen durchgeführt werden. Dies gilt z. B. für eine Mehrfachaufteilung mit den Teilungstypen "Untere N" und "Gerade".
• Die folgenden Teilungstypen können nicht mit dem Teilungstyp "Nach Menge" in Mehrfachaufteilungen kombiniert werden:
• Untere N
• Erste Hälfte
• Letzte Hälfte
• Obere N
• Sie müssen bei Mehrfachaufteilungen gewährleisten, dass ein Los nicht öfter aufgeteilt wird, als es die Menge erlaubt. Wenn Sie z. B. ein Los mit einer Menge von 500 mit dem Teilungstyp "Feste Menge aufteilen" und einem Wert von 250 für "Menge aufteilen" aufteilen, können Sie keine weitere Aufteilung mit demselben Wert durchführen.

Felddefinitionen der Seite "Versuche: Autom. Aufteilung"

Diese Tabelle definiert die Felder auf der Seite "Versuch: Autom. Aufteilung".

Feld

Definition

Typ

Details

Teilungstyp

Typ der durchzuführenden Aufteilung. Mögliche Optionen sind:

• Untere N – Teilt die unteren N Wafer dem Kind-Los zu. Wenn Sie diese Option auswählen, müssen Sie einen Wert für das Feld "N-Anzahl für Wafer" festlegen.
• Nach Slot – Teilt Wafer entsprechend der Liste der Slotnummern für den Behälter dem Kind-Los zu. Leere Slots werden von der Anwendung ignoriert. Sie müssen einen Wert für das Feld "Slotnummern" festlegen, wenn Sie diese Option auswählen.
• Gerade – Teilt Wafer mit geraden Nummern dem Kind-Los zu.
• Erste Hälfte – Teilt die erste Hälfte der Wafer dem Kind-Los zu.
• Letzte Hälfte – Teilt die letzte Hälfte der Wafer dem Kind-Los zu.
• Ungerade – Teilt Wafer mit ungeraden Nummern dem Kind-Los zu.
• Nach Menge – Teilt eine feste Menge des Loses einem Kind-Los zu. Sie müssen einen Wert für das Feld "Menge aufteilen" festlegen, wenn Sie diese Option auswählen. Diese Option kann nur für mengenbasierte Lose verwendet werden.
• Gleich – Teilt die Losmenge und das Kind-Los gleichmäßig. Diese Option kann nur für mengenbasierte Lose verwendet werden.
• Obere N – Teilt die oberen N Wafer dem Kind-Los zu. Wenn Sie diese Option auswählen, müssen Sie einen Wert für das Feld "N-Anzahl für Wafer" festlegen.

Erforderlich

N-Anzahl für Wafer

Anzahl der aufzuteilenden Wafer.

Hinweis: Dieses Feld ist erforderlich, wenn "Teilungstyp" auf "Obere N" oder "Untere N" festgelegt ist.

Optional

Slotnummern

Durch Kommas getrennte Liste der aufzuteilenden Slotnummern des Behälters.

Hinweis: Dieses Feld ist erforderlich, wenn "Teilungstyp" auf "Nach Slot" festgelegt ist.

Optional

Menge aufteilen

Feste Aufteilungsmenge für einen bestimmten Teilungstyp. Aktiviert, wenn "Teilungstyp" auf "Nach Menge" festgelegt ist.

Hinweis: Dieses Feld ist erforderlich, wenn "Teilungstyp" auf "Nach Menge" festgelegt ist.

Optional

Spez. f. zuk. Vereinigung

Spezifikation, die zum Kombinieren der Lose verwendet werden soll.

Optional

Aktionsplan nach Teilung

Los, das den Versuchsplan nach der Aufteilung erbt. Zulässige Auswahlwerte:

• Beide – Eltern- und Kind-Los enthalten den Versuchsplan.
• Nur Eltern – Nur das Eltern-Los enthält den Versuchsplan.
• Nur Kind – Nur das Kind-Los enthält den Versuchsplan.

Optional

Kommentare

Kommentare, die für die Aufteilungstransaktion in der automatischen Aufteilungsaktion verwendet werden sollen.

Optional

Vorgehensweise zum Definieren des automatischen Aufteilens von Versuchen

Gehen Sie folgendermaßen vor, um das automatische Aufteilen eines Versuchs zu definieren:

1. Öffnen Sie die Seite Versuch: Autom. Aufteilung. Die Seite "Versuch: Autom. Aufteilung" wird innerhalb der Seite "Modellierung" angezeigt.
2. Klicken Sie auf Neu. Es werden leere Felder zum Definieren einer neuen Instanz angezeigt.
3. Geben Sie einen Namen für das Objekt zum automatischen Aufteilen von Versuchen in das Feld Versuch: Autom. Aufteilung ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
