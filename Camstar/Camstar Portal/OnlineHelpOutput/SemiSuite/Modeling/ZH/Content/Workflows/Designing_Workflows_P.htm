设计工作流程

在“工作流程”页上的“工作流程图”部分，可以查看、设计和修改工作流程。可以通过将规范或工作流程的修订版本拖动到图上来添加工步。通过选择工步上的路径图标并拖动到工作流程中的下一工步来添加路径。

在定义工作流程时

应用程序使用规范名称作为工作流程工步和新添加工步的路径的默认名称。例如，如果添加了“装运”规范作为工步，则工步和工步路径的名称都为“装运”。重命名工步和路径有助于区分工步和规范以及明确路径。可以将“装运”规范工步重命名为正在装运，并将路径重命名为目标装运。

将先前已定义的工作流程添加到当前工作流程时，同样的原则也适用。添加的工作流程将成为子工作流程，并根据添加的工作流程命名。

必须展开规范或工作流程，然后选择特定修订版本，以添加到工作流程图中。

工作流程包含必需的建模定义（规范）。 

工作流程包含以下可选的建模定义，并且也是其中的一个可选字段：

• ERP 路线
• 产品系列

此外，工作流程在事务“启动”、“标准移动（路径 & 工步）”、“非标准移动”和“返工（工步）”中是可选的。

在向工作流程添加工步时

工步名称在工作流程中必须是唯一的。默认情况下，应用程序会将所引用的规范或子工作流程的名称指派给添加到工作流程的工步。如果添加了引用同一规范或工作流程的第二个工步，应用程序将为该工步指派数值扩展名。例如，默认情况下，将名为“可视化检查”的规范添加到工作流程中会导致工步被命名为可视化检查。第二次将“可视化检查”规范添加到工作流程中会导致工步被命名为可视化检查_1。

可以随时更改工步名称。选择工步，然后单击“修改元素”按钮以查看“工步详细信息”弹出窗口。有关查看和修改工步信息的信息，请参考“使用工步详细信息”。

用于描述规范工步和工作流程工步的图标是不同的。此外，无论第一工步是规范还是子工作流程，第一工步的图标都与连续工步的图标不同。

可以通过单击并拖动工步来重新定位工作流程中的工步。通向和从该工步开始的任何路径都将随工步一起重新定位。

重要提示: 默认情况下，Management Studio 中的“返回的最大行数”配置设置设为 15,000。如果具有非常大的工作流程，则可以将该设置修改为大于工作流程中的工步数。有关信息，请参考《Opcenter Execution Core 系统管理指南》。

工步之间添加路径

路径名称在工作流程中必须是唯一的。应用程序使用“目标工步”的名称作为路径的默认名称。例如，将路径从“封装”工步添加到“装运”工步会导致路径被命名为装运。应用程序使用“目标工步”的名称，而不管路径类型是以下哪一种：默认、备选、返工或循环。

路径名称仅在“路径详细信息”弹出窗口中可见。选择路径，然后单击“修改元素”按钮可查看“路径详细信息”弹出窗口。有关查看和修改路径信息的详情，请参考“使用路径详细信息”。

工步图标左侧显示三个路径图标：默认（主要）、备选和返工。使用这些图标可指定从该工步到另一工步的路径类型。只能添加从某工步开始的一个默认路径，但可以添加从某工步到其他工步的多个备选路径和返工路径。还可以将这些路径中的任何一个路径循环回当前工步。单击箭头并将鼠标拖动到一个工步以绘制路径。

注释: 每个工步只能绘制一个循环路径。

应用程序：

• 在“来源工步”和“目标工步”之间只允许有一个路径。如果要更改两个工步之间的路径类型，则必须删除路径后再重新绘制，或者修改路径详细信息。
• 必须先绘制默认路径，再绘制备选路径。如果在绘制默认路径之前绘制备选路径，应用程序会自动将备选路径转换为默认路径。
• 仅允许有一个来自“来源工步”的默认（主要）路径。应用程序会自动将后续的任何默认路径转换为备选路径。如果要将默认路径重定向到另一工步，则必须删除现有默认路径后再重新绘制到另一工步，或修改路径详细信息。
注释: 单击“重置”不会重置工作流程画布。必须手动删除已添加的任何工步或路径。

删除工作流程或工作流程元素

删除工作流有两种方式：

• 删除工作流程及其所有修订版本
• 删除工作流程修订版本但保存工作流程实例。

当存在多个工作流程修订版本时，无法删除记录修订版本。必须首先将指定记录的修订版本指派为不同的修订版本。

如果删除原始的第一工步，则必须指派另一个工步作为第一工步。如果删除第一工步，并且没有将另一个工步指定为第一工步，则应用程序在保存工作流程时将显示错误消息。

删除工步还会从该工步中删除到该工步的所有路径以及源自该工步的所有路径。必须在这些工步之间添加新路径。

试图查看正在使用或已使用过的任何已删除规范或工作流程的历史可能导致错误。如果从工作流程中删除其所在的工步，则容器将失去其当前状态。

删除路径不会影响其链接的工步。但是，删除默认路径将显示“来源工步”中的默认路径图标，使您能够添加新的默认路径。

如何定义工作流程

按照以下步骤定义“工作流程”：

1. 打开工作流程页。“工作流程”页显示在“建模”页中。
2. 单击新建。显示用于定义新实例的空白字段。
3. 在工作流程字段键入工作流程的名称。
4. 在修订版本字段键入此定义的修订版本标识。
5. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
6. 单击保存。应用程序保存建模对象并显示成功消息。
7. 如果需要，完成以下过程，向工作流程图中添加工步和路径：
• “如何向工作流程添加工步”
• “如何在工作流程工步之间添加路径”

如何向工作流程添加工步

按照以下步骤向工作流程添加工步：

1. 执行“如何定义工作流程”过程。

或

选择一个现有“工作流程”实例。

2. 将滚动条滚动至工作流程图部分。
3. 展开要作为工步添加的规范或工作流程以查看所有修订版本。
4. 选择要作为工步添加的修订版本，并将其拖到“工作流程图”中。引用所选规范或工作流程的工步将出现在“工作流程图”中。该工步会出现在将其放到的位置。
5. 重复步骤 3-4 以添加其他工步。
6. 单击保存。应用程序保存建模对象并显示成功消息。

1. 执行“如何定义工作流程”过程。

或

选择一个现有“工作流程”实例。

2. 将滚动条滚动至工作流程图部分。
3. 是否要在两个工步之间添加默认路径、备选路径或返工路径？

默认路径
a. 单击“来源工步”上的默认路径图标，然后将其拖动到“目标工步”。应用程序在两个工步之间添加一个绿色实线。
b. 重复步骤 a，将其他默认路径从“来源工步”添加到其他“目标工步”。
c. 转到步骤 4。

备选路径
a. 单击“来源工步”上的备选路径图标，然后将其拖动到“目标工步”。应用程序在两个工步之间添加一个绿色虚线。
b. 重复步骤 a，将其他备选路径从“来源工步”添加到其他“目标工步”。
c. 转到步骤 4。

返工路径
a. 单击“来源工步”上的返工路径图标，然后将其拖动到“目标工步”。应用程序在两个工步之间添加一条红色虚线，并在“来源工步”中隐藏返工路径图标。
b. 重复步骤 a，将其他返工路径从“来源工步”添加到其他“目标工步”。
c. 转到步骤 4。
4. 根据需要为每个路径完成如何定义路径选择器和返工路径选择器过程。
5. 单击保存。应用程序保存建模对象并显示成功消息。

如何向工作流程工步添加循环路径

按照以下步骤向工作流程工步添加循环路径：

1. 执行“如何定义工作流程”过程。

或

选择一个现有“工作流程”实例。

2. 将滚动条滚动至工作流程图部分。
3. 单击适当的路径图标（默认、备选或返工）并将其拖动到当前工步的中心。将显示一个路径，循环返回到相同的工步。
4. 单击保存。应用程序保存建模对象并显示成功消息。

如何将工步插入到现有工作流程

按照以下步骤将工步插入到现有工作流程：

1. 执行“如何定义工作流程”过程

或

选择一个现有“工作流程”实例。

2. 将滚动条滚动至工作流程图部分。
3. 选择要插入工步的两个工步之间的路径。应用程序将高亮显示该路径。
4. 单击删除。应用程序将移除该路径。
5. 展开要作为工步插入的规范或工作流程以查看所有修订版本。
6. 选择要插入的修订版本并将其拖动到工作流程图。该工步会出现在将其放到的位置。
7. 选择“来源工步”上的适当路径图标，然后将其拖动到新插入工步。应用程序将添加该路径。
8. 选择新插入工步上的适当路径图标，然后将其拖动到下一个适当的工步。
9. 对于要从新插入工步中绘制的任何其他路径，重复步骤 8。
10. 如果需要，从现有工步中绘制适当的路径到新插入工步。
11. 单击保存。应用程序保存建模对象并显示成功消息。

如何修改工步信息

按照以下步骤修改工步信息：

1. 执行“如何定义工作流程”过程。

或

选择一个现有“工作流程”实例。

2. 将滚动条滚动至工作流程图部分。
3. 选择要修改的工步。应用程序将在“工作流程图”工具栏上显示“修改元素”按钮。
4. 单击修改元素。应用程序将显示“工步详细信息”弹出窗口。
5. 如果需要，修改必需字段：
• 规范工步名称
• 规范
6. 根据业务需求输入或键入可选信息。有关可选字段的信息，请参考“工步详细信息弹出窗口字段定义”表。
注释: 有关使用路径选择器的信息，请参考“使用路径选择器”。
7. 单击确定。 工步详细信息弹出窗口关闭。
8. 单击保存。应用程序保存建模对象并显示成功消息。

如何修改路径信息

按照以下步骤修改路径信息：

1. 执行“如何定义工作流程”过程。

或

选择一个现有“工作流程”实例。

2. 将滚动条滚动至工作流程图部分。
3. 选择要修改的路径。应用程序将在“工作流程图”工具栏上显示“修改元素”按钮。
4. 单击修改元素。应用程序将显示返工路径的“返工工步详细信息”弹出窗口和所有其他路径的“工步详细信息”弹出窗口。
5. 如果需要，修改返工路径或路径。
6. 根据业务需求输入或键入可选信息。有关可选字段的信息，请参考“了解工作流程”表。
7. 单击确定。 弹出窗口将关闭。
8. 单击保存。应用程序保存建模对象并显示成功消息。

如何删除工作流程工步或路径

按照以下步骤删除工作流程工步或路径：

1. 执行“如何定义工作流程”过程。

或

选择一个现有“工作流程”实例。

2. 将滚动条滚动至工作流程图部分。
3. 选择要删除的元素。
4. 单击删除。在删除选定工步时，应用程序将移除该工步以及绘制到该工步和从该工步绘制的所有路径。在删除选定路径时，应用程序仅移除该路径。
5. 如果需要，添加新路径。（有关信息，请参考“如何在工作流程工步之间添加路径”。）
6. 单击保存。应用程序保存建模对象并显示成功消息。
