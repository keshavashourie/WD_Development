定义编号规则

编号规则是一种可配置的编号方案，它自动为矩阵对象、质量记录和批次指派唯一的追踪编号。通常，组织为这些实体定义和指派编号方案。应用程序应用适当的编号方案，并将下一个可用的 ID 或编号指派给相应的矩阵对象、质量记录或容器。有关编号规则的其他信息，请参考《Opcenter Execution Core Modeling 用户指南》。

定义容器和批次的编号规则

应用程序使用这些建模对象上指定的编号规则自动生成容器和批次名称：

• 产品
• 产品系列
• 服务设置

编号规则是这些建模定义中的可选字段。

车间用户可以选择在启动父子容器和批次、拆分容器和批次以及拆分数量时自动生成容器名称。有关自动生成容器名称的信息，请参考《Opcenter Execution Core Shop Floor 用户指南》。

应用程序使用此优先级顺序确定在多个建模对象上指定了编号规则时要使用的编号规则：

1. 产品
2. 产品系列
3. 服务设置

字段输入格式要求

编号必须是 30 个字符或更少，包括任何前缀或后缀和序列号。生成的编号按如下方式计算：

编号 = 前缀（如有）+ 序列号（必填）+ 后缀（如有）

例如：EVENT-ORG15-00000001-2014

前缀和后缀字段可用于文本或统一表达式语法项。

两者都需要非常具体的格式，例如：

• 文本前缀可以定义为“ABCCorp_”或“_Smith”。需要给语法项加双引号。
• 统一表达式语法可用于创建动态前缀或后缀，例如：
• 前缀 = "(<Organization.Name>"
• 后缀 ="_"+StrSubstring(String(TruncateTime(GMTToLocal(SetSystemDateGMT()))),(StrLength(String(TruncateTime(GMTToLocal(SetSystemDateGMT()))))-4),4)

有关统一表达式语法的信息，请参考《Opcenter Execution Core Designer 用户指南》。

编号规则类型

此列表包含供选择的编号规则类型。可能的值包括：

• 低音量/不跳过

前缀（动态表达式）

可以定义要添加到序列号的前缀。前缀可以支持静态字符串文本和统一表达式语法以生成动态文本。静态字符串文本前缀的一个示例是“PE-ORG15”。必须在语法项上加双引号，如示例中所示。

后缀（动态表达式）

可以定义要添加到序列号的后缀。后缀可以支持静态字符串文本和统一表达式语法以生成动态文本。静态字符串文本后缀的一个示例是四位数的年份“2014”或产品名称“BPMON”。必须在语法项上加双引号，如示例中所示。

可选

使用基于前缀的上次指派的序列号

表示是否使用基于前缀的排序替代基于规则的排序。

注意：基于前缀的排序适用于使用统一表达式配置的编号规则，因为这些编号规则会动态生成前缀。编号规则首次生成唯一前缀时，应用程序会指派起始序列号值。如果编号规则随后生成同一个前缀，则在生成容器名称时，应用程序会递增该前缀的上次指派的序列号。

有关信息，请参考《Opcenter Execution Core Modeling 用户指南》。

可选

使用十六进制值

表示是否使用十六进制值代替整数值。

可选

使用字母数字值

此复选框表示是否对序列使用字母数字编号。

注意：此选项适用于基于规则和基于前缀的排序。

可选

编号规则选项

此设置控制达到最大序列值时编号规则的行为。编号规则选项包括以下内容：

• 滚动—序列在达到预定义的限制后重新开始。达到最大序列值时，编号规则开始根据值生成升序值，该值在“上次指派的值”字段中指示。

注意：如果选择“滚动”，则检测到重复的容器名称时将发生错误。

• 停止—序列在预定义的限制处停止。达到最大值后，编号规则无法生成更多值。
• 继续—序列增量没有界限。达到最大值后，编号规则继续生成值。

注意：当选中“使用字母数字值”复选框时，将启用此字段。

可选

最大值

可以定义要生成的最大值。如果编号规则不使用十六进制值，则此值应接受整数值；如果使用十六进制值，则应支持十六进制值。如果编号规则生成的值超过定义的最大值，则会显示一条错误消息。

可选

使用值

表示是否使用值列表获取下一个序列而不是序列号长度。

可选

更改前缀时重置值

表示在生成过程中，当前缀的动态值发生更改时，值中使用的索引是否重置为第一个值。

注意：必须选中“使用值字段”才能使用此字段。

可选

更改后缀时重置值

表示在生成过程中，当后缀的动态值发生更改时，值中使用的索引是否重置为第一个值。

注意：必须选中“使用值字段”才能使用此字段。

可选

上次指派的序列号

上次指派给质量记录的序列号。应用程序通过将此编号递增 1 来计算要指派的下一序列号。默认值为 0。

必需

序列号长度

序列号的所需长度。如果未使用前缀和后缀，则计算的序列号的最大长度为 30 个字符。

必需

事务数据键（动态表达式）

使用值列表生成下一序列时使用的字段。事务关键词的解析值将存储在 TxnData 列表中，以允许每个设置有多个序列。例如，多台设备可以使用一个编号规则设置来生成运行编号。因此，为了确保每台设备都有自己的序列，事务关键词应配置为设备名称。

可选

序列值表格

此列表指定使用有序的值序列而不是使用序列号生成序列。设置值的顺序非常重要，因为逻辑在每次需要序列时都选择下一个索引。

如何定义编号规则

按照以下步骤定义编号规则：

1. 打开编号规则页。随即“建模”页中将显示“编号规则”页。
2. 单击新建。显示用于定义新实例的空白字段。
3. 在编号规则字段中输入编号规则的名称。
4. 选择编号规则类型。
5. 在上次指派的序列号字段中输入值。
6. 在序列号长度字段中输入值。
7. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
8. 单击保存。应用程序保存建模对象并显示成功消息。
