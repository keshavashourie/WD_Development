定义用户代码

用户代码属于已命名数据对象 (NDO) 类别。它们由类型中的名称唯一标识。用户代码类型的示例包括工作修复代码、失败类型、擅长原因以及返工原因。

Opcenter EX CR 和 Opcenter Execution Semiconductor 提供默认用户代码。可以使用“建模”页对要添加的用户代码类型轻松添加用户代码。例如，要添加增长原因，则在建模时使用“增长原因”页。

注释: 有关用户代码和 Opcenter EX CR 用户代码默认设置列表的其他信息，请参考《Opcenter Execution Core Modeling 用户指南》。

如何定义用户代码

注释: 以下指示用于将用户代码添加到现有用户代码类型中。请参考《Opcenter Execution Core Modeling 用户指南》，了解如何新建用户代码类型。

按照以下步骤定义用户代码：

1. 打开要定义（添加）的用户代码类型的建模页。
2. 单击新建。显示用于定义新实例的空白字段。
3. 在“用户代码”字段中键入用户代码的名称。
4. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
5. 单击保存。应用程序保存建模对象并显示成功消息。
