定义用户代码组

可以通过创建组对类型中的用户代码进行分类。例如，可以确定与缺陷相对、具体适用于生产订单修订版本的所有返工原因。将用户代码指派给组不会基于类型从父组中移除代码。

定义用户代码组

要使用的建模页取决于要分组的用户代码的类型。例如，使用“返工原因组”页可以定义一组返工原因。

注释: 组建模页通常包含一个“条目类型”字段，该字段默认为从菜单中选择的用户代码组的类型。

如何定义用户代码组

按照以下步骤定义用户代码组：

1. 选择要分组的用户代码类型的组建模页。随即“建模”页中将显示组页。
2. 单击新建。显示用于定义新实例的空白字段。
3. 输入用户代码组的名称。
4. 将条目添加到“条目”表格中，如下所示：
a. 单击表格上的添加新行。将显示一个新行。
b. 从条目表格的已启用字段列表中选择条目。
c. 重复步骤 a-b 添加其他条目。
5. 采取以下步骤添加子组（如果需要）：
a. 单击表格上的添加新行。将显示一个新行。
b. 从组表格的已启用字段列表中选择子组。
c. 重复步骤 a-b 添加其他子组。
6. 单击保存。应用程序保存建模对象并显示成功消息。
