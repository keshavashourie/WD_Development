定义晶元 WIP 数据采样

通过“晶元 WIP 数据采样”页，可以配置用于采样目的的晶元数量或包含晶元的供料槽数量。可以预定义应用程序如何选择批次中晶元数量的方法或规范。通过选中“WIP 数据设置”建模对象上的“强制采样”复选框，可以进一步强制选择。在“WIP 主要”或“设备 WIP 调度”处理期间，“转入”将从方法中（“用户选择”方法除外）标识预选的晶元。如果不强制执行采样，则还可以重新选择晶元。

“晶元 WIP 数据采样”旨在将标准批次采样流程提高到更具体的基于晶元的采样选择，并消除项处理的 100% 数据收集要求。

注释: 基于晶元的采样将优先于 AQL 采样。如果现有默认“AQL 采样”和新的“晶元 WIP 数据采样”在同一工步中配置，则仅执行“晶元 WIP 数据采样”。

在定义晶元 WIP 数据采样时

“晶元 WIP 数据采样”建模对象提供根据以下方法配置晶元采样选择的功能：

• 用户选择 - 用户手动选择。在“转入”前的“WIP 主要”或“设备 WIP 调度”页中的“项”表格中，可以手动选择批次内要采样的单个晶元或包含晶元的供料槽。
• 正数 N 个 - 基于正数 N 个供料槽数自动选择，其中 N 为要采样的供料槽数。如果选择此选项，则必须在“供料槽数”字段中设置一个值。例如，如果将 5 设为“供料槽数”，应用程序将选择包含当前批次晶元的正数（或前）5 个供料槽。
• 倒数 N 个 - 基于倒数 N 个供料槽数自动选择，其中 N 为要采样的供料槽数。如果选择此选项，则必须在“供料槽数”字段中设置一个值。例如，如果将 5 设为供料槽数，应用程序将选择包含当前批次晶元的倒数（或后）5 个供料槽。
• 样本大小 - 按输入的“样本大小”数选择晶元。例如，如果输入 5，则应用程序将选择 5 个晶元进行采样。有关采样计算和选择的信息，请参考“使用“样本大小”或“样本百分数”方法时”。
• 样本百分数 - 按“样本百分数”值选择晶元。例如，如果输入总计 25 个晶元的 20%，则将选择 5 个晶元进行采样。如果需要，应用程序将执行标准舍入并选择最接近的数字。例如，4.8 将舍入为 5。但是，如果计算的样本大小值小于 1，则应用程序将至少选择 1 个晶元。例如，输入的样本百分数为 1%，计算的样本大小为 0.25，应用程序将选择 1 个晶元。有关采样计算和选择的信息，请参考“使用“样本大小”或“样本百分数”方法时”。

使用“样本大小”或“样本百分数”方法时

对于输入的样本大小或样本百分数，应用程序将计算样本工步，以均匀分布批次中的晶元选择。

以下是场景示例，可更好地了解“采样大小”和“样本百分数”选择方法：

注释: 这些示例中说明的计算样本大小是指在“样本大小”字段中输入的值或基于“样本百分数”字段计算的采样大小。
• 如果计算的样本大小 ≥ 批次中晶元总数，则将选择所有晶元。
• 如果计算的样本大小 = 1，则将选择离中间最近的供料槽中的晶元。
• 如果计算的样本大小 = 2，则将选择当前批次的顶部供料槽和底部供料槽中的晶元。
• 如果计算的样本大小 > 2，应用程序将选择位于顶部供料槽、底部供料槽上的晶元，并计算“样本工步”以标识中间供料槽位置的其余部分。计算“样本工步”以获取要跳过的晶元数，该数量标识要采样的下一个晶元。

样本工步 = 总晶元 ÷ (样本大小 - 1)。

例如，物料箱的晶元总数为 25 个，输入的“样本大小”为 5。“样本工步”将为 25 ÷ (5 - 1) = 6.25。应用程序将向下舍入样本工步的小数位，例如，4.66 向下舍入为 4，2.98 向下舍入为 2，6.25 向下舍入为 6。因此，在此示例中，应用程序所得到的样本工步 = 6，并将对每个选定晶元跳过 6 个晶元。要为“转入”采样的选定晶元将是晶元 1、晶元 7、晶元 13、晶元 19 和晶元 25。

“晶元 WIP 数据采样”页字段定义

此表定义“晶元 WIP 数据采样”页中的字段。

字段

定义

类型

晶元 WIP 数据采样

“晶元 WIP 数据采样”建模对象的唯一名称。

必需

详细信息

晶元采样方法

有关如何选择批次内晶元或供料槽进行采样的方法。

• 用户选择
• 正数 N 个
• 倒数 N 个
• 样本大小
• 样本百分数

有关信息，请参考“在定义晶元 WIP 数据采样时”。

必需

供料槽数

要从当前批次中选择的供料槽数。参考“正数 N 个”和“倒数 N 个”方法中的“N”值。

注：仅当已选择“正数 N 个”或“倒数 N 个”时，才会启用该字段。

如果选择“正数 N 个”或“倒数 N 个”方法，则为必填项。

样本大小

要采样的晶元数。

注：仅当已选择“样本大小”方法时，才会启用该字段。

如果已选择“样本大小”方法，则为必填项。

样本百分数

要采样的晶元百分数。

注：仅当已选择“样本百分数”方法时，才会启用该字段。该字段仅接受 1-100 中的值。

如果已选择“样本百分数”方法，则为必填项。

如何定义晶元 WIP 数据采样

按照以下步骤定义“晶元 WIP 数据采样”：

1. 打开晶元 WIP 数据采样页。随即“建模”页中将显示“晶元 WIP 数据采样”页。
2. 单击新建。显示用于定义新实例的空白字段。
3. 在晶元 WIP 数据采样字段中输入唯一的名称。
4. 选择晶元采样方法字段。
5. 如果选择了“正数 N 个”或“倒数 N 个”方法，则输入供料槽数字段。
6. 如果选择“样本大小”或“样本百分数”方法，则输入样本大小或样本百分数值。
7. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
8. 单击保存。应用程序保存建模对象并显示成功消息。
