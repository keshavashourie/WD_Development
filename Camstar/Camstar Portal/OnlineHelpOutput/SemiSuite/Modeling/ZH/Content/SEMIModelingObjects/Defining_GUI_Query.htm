定义 GUI 查询

“GUI 查询”用于获取有关事务期间显示的批次和设备等信息。“GUI 查询”是作为实例数据存储的预定义查询。请注意，当查询定义被定义为实例数据时，查询本身可以用于从实例数据表或元数据表中检索信息。

“参数”表格作为持久列表被实施，使得参数顺序由相应的持久列表自动维护。

GUI 查询要求

“GUI 查询”要求熟悉“对象模型”、理解 SQL 语法，同时具有编写 SQL 查询的经验。您还必须理解最终用户的需求，以便查询将在用户界面上显示正确类型的信息。

当查询被创建和测试后，必须由自定义应用程序来调用。这可通过 Opcenter Execution Semiconductor 服务 API 调用 (WSQuery) 或自定义执行来实现。

如何定义 GUI 查询

按照以下步骤定义“GUI 查询”：

1. 打开 GUI 查询页。随即“建模”页中将显示“GUI 查询”页。
2. 单击新建。显示用于定义新实例的空白字段。
3. 在 GUI 查询字段中输入 GUI 查询名称。
4. 在查询文本字段中输入 SQL 查询语句的文本。
5. 执行以下操作，将参数添加到“参数”表格中：
a. 单击添加新行。 应用程序将向表格中添加一个空行。
b. 在用户查询参数名称字段中输入 GUI 查询参数名称。
c. 在数据类型字段中输入 GUI 查询参数的数据类型。
d. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
6. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
7. 单击保存。应用程序保存建模对象并显示成功消息。
