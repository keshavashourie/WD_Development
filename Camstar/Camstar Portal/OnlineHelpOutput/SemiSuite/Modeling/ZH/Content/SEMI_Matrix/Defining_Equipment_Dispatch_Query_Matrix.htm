定义装备分配查询矩阵

“装备分配查询”矩阵对象用于维护各种分配查询的实例并解决“装备 WIP 追踪”页上显示的分配查询。有关信息，请参考《Opcenter Execution Semiconductor Shop Floor 指南》。

样本分配查询

Opcenter Execution Semiconductor 在“SEMI 0205 GUI 控件 - GUI 查询”（针对 Oracle Portal）或“SEMI 0205 GUI 控件 - GUI 查询”（针对 SQL Portal）中提供样本“分配查询”。样本查询将返回所有规范的所有批次。必须复制和修改提供的查询，以根据“工厂”内的装备使用情况限制查询结果。

定义装备分配查询矩阵

可以定义编号规则对象来自动命名矩阵对象。然后，应用程序将在保存实例时自动填充“名称”字段。有关使用编号规则命名矩阵对象实例的信息，请参考”使用编号规则自动命名实例”。

如何定义装备分配查询矩阵

按照以下步骤定义“装备分配查询矩阵”：

1. 打开装备分配查询页。应用程序将显示“装备分配查询”页。
2. 执行如下表中所述的某个过程：

要定义 ...

执行以下操作 ...

一个新实例

在准则区域中指定设置。有关可用字段的信息，请参考字段定义表。

使用现有实例的实例

选择并编辑现有实例。有关说明，请参考“如何将已编辑的实例另存为新实例”。
3. 在装备分配查询矩阵名称字段中输入装备分配查询矩阵实例的名称。如果不指定名称并且此矩阵对象具有已建模的编号规则对象，则在保存实例时，应用程序会自动填充此字段。
4. 在分配查询字段中输入分配查询。
5. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
6. 单击保存。应用程序保存建模对象并显示成功消息。
