管理实例

创建矩阵对象的实例后，可以通过矩阵建模对象页提供的一些选项，从现有实例中保存新实例，删除、查看事务历史记录，或者为现有实例执行其他操作。本节介绍可在矩阵对象页上执行的下列操作：

• 保存 – 使用此选项可以保存新实例，或者将更改保存到已编辑的实例。
• 另存为新 – 使用此选项可以更改有关现有实例的详细信息，然后将其另存为新实例。
• 查看审核 – 使用此选项可以查看实例的事务历史记录。事务历史记录是从创建对象时开始对实例所做的所有更改的记录。
• 删除 – 使用此选项可以删除实例。
• 重新加载 – 此选项会放弃对当前所选实例所做的所有更改。
• 清除 – 此选项会清除正在定义的新实例的准则和详细信息区域中的所有值。应用程序将页面重置为页面加载时或上次执行保存操作时的初始状态。

将经过编辑的实例另存为新实例时，记住每个实例都需要以下内容：

• 唯一名称。如果未指定名称，并且为矩阵对象建模了编号规则对象，则应用程序将根据编号规则对象指定的编号方案自动命名实例。有关使用编号规则命名矩阵对象实例的信息，请参考“使用编号规则自动命名实例”。
• 唯一准则。每个实例都必须由其自己的一个准则集定义。

如何将已编辑的实例另存为新实例

按照以下步骤将现有实例另存为新实例：

1. 打开矩阵建模页。例如，设备矩阵。
2. 在打开的页上，在所提供的字段中输入准则，然后单击“选择”表格下方的。应用程序显示与指定准则匹配的实例。
3. 在“选择”表格中，单击含有实例的行中的。应用程序使用该实例中的特定信息填充“准则”和“详细信息”区域。
4. 对所选实例进行更改。
重要提示: 必须同时更改名称和准则集。未按此方式更改实例会导致错误，并且应用程序不会保存该实例。
5. 单击另存为新。应用程序使用指定的名称和准则将实例另存为新实例。同时，应用程序用原始值保留修改的实例。如果未指定名称，并且使用编号规则对象命名矩阵对象，则应用程序会为该实例生成由编号规则对象指定的唯一名称。

如何查看实例的事务历史记录

按照以下步骤查看实例的事务历史记录：

1. 打开矩阵建模页。例如，设备矩阵。
2. 在打开的页上，在所提供的字段中输入准则，然后单击“选择”表格下方的。应用程序显示与指定准则匹配的实例。
3. 在“选择”表格中，单击含有实例的行中的。应用程序使用该实例中的特定信息填充“准则”和“详细信息”区域。
4. 单击查看审核。应用程序打开“建模审核追踪”对话框，其中显示实例的以下详细信息：

列

定义

事务日期

行中描述的事务的发生日期和时间。

用户

执行事务的用户的用户名。

执行操作

已执行事务。可能值为添加和更新。

备注

有关该操作的注释（如果提供）。此字段不可用。
5. 如果要查看在特定日期范围内发生的事务，可使用返回以下范围的结果字段中的日期选取器，然后单击转到。有关使用日期选取器来选择日期的信息，请参考《Opcenter Execution Core 入门用户指南》。
6. 如果要查看特定事务的详细信息，可单击。应用程序显示事务的以下详细信息：

列

定义

项

已更改的字段名。

名称

如果可用，则指定对象的名称。仅为某些对象填充。

之前

保存更改之前字段的值。对于“添加”执行操作，这是空的。

之后

保存更改后字段的值。

操作

针对该字段采取的操作。

• “更新”指示字段值已更新。
• “创建”指示第一次添加字段的值。
• “删除”指示已删除字段的值。
7. 单击关闭。应用程序关闭“建模审核追踪”对话框。

如何删除实例

按照以下步骤删除实例：

重要提示: 无法恢复已删除的实例。
1. 打开矩阵建模页。例如，设备矩阵。
2. 在打开的页上，在所提供的字段中输入准则，然后单击“选择”表格下方的。应用程序显示与指定准则匹配的实例。
3. 在“选择”表格中，单击含有实例的行中的。应用程序使用该实例中的特定信息填充“准则”区域。
4. 单击删除。应用程序将删除该实例。

如何重新加载实例

可以在更改后但尚未保存更改之前重新加载实例。

重要提示: 重新加载实例时，应用程序将丢弃对当前所选实例所做的所有更改。自上一次保存操作以来所做的所有更改都将丢失。

按照以下步骤重新加载实例：

1. 打开矩阵建模页。例如，设备矩阵。
2. 在打开的页上，在所提供的字段中输入准则，然后单击“选择”表格下方的。应用程序显示与指定准则匹配的实例。
3. 在“选择”表格中，单击含有实例的行中的。应用程序使用该实例中的特定信息填充“准则”区域。
4. 单击重新加载。应用程序将字段重置为上次保存的值。

如何清除实例的字段

按照以下步骤清除实例的字段：

1. 打开矩阵建模页。例如，设备矩阵。
2. 在打开的页上，在所提供的字段中输入准则，然后单击“选择”表格下方的。应用程序显示与指定准则匹配的实例。
3. 在“选择”表格中，单击含有实例的行中的。应用程序使用该实例中的特定信息填充“准则”区域。
4. 单击清除。应用程序即移除矩阵页上所有字段的值。
