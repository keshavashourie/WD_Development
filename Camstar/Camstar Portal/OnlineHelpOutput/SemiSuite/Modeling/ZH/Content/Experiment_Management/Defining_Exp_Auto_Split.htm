定义实验自动拆分

“实验自动拆分”建模对象定义了在“实验计划”中拆分批次中的晶元的方式。执行时，为“实验计划”指定“实验自动拆分”将导致批次按照“实验自动拆分”配置定义的方式进行拆分。

如果要按项（晶元）拆分批次，则必须使用“指派物料箱供料槽映射”页将实验批次中的晶元指派到晶元物料箱中的供料槽，然后再转入指定自动拆分工步的实验批次。有关“指派物料箱供料槽映射”页的信息，请参考《Opcenter Execution Semiconductor Shop Floor 指南》。

如果要按数量拆分批次（非项批次），则不需要物料箱。

定义实验自动拆分

在大多数拆分类型中，实验计划允许在同一工步中进行多个拆分。只能在以下拆分类型上执行多个拆分：

• 倒数 N 个
• 按供料槽
• 按数量
• 前半部分
• 后半部分
• 拆分固定数量
• 正数 N 个

执行多个拆分时应用以下规则：

• 不能对“偶数”或“奇数”拆分类型或包含“偶数”或“奇数”拆分类型的任何组合执行多个拆分。例如，不能使用“倒数 N 个”和“偶数”拆分类型执行多个拆分。
• 不能在多个拆分中将以下拆分类型与“按数量”拆分类型合并：
• 倒数 N 个
• 前半部分
• 后半部分
• 正数 N 个
• 必须确保使用多个拆分时拆分批次的次数不会超过允许的次数。例如，如果使用“拆分固定数量”拆分类型和值为 250 的“拆分数量”对数量为 500 的批次进行拆分，则不能使用相同的值执行另一个拆分。

实验自动拆分页字段定义

此表定义“实验自动拆分”页中的字段。

字段

定义

类型

详细信息

拆分类型

要执行拆分的类型。选项包括：

• 倒数 N 个 – 将晶元的倒数 N 个数拆分为子批次。如果选择此选项，则必须为“ N 个晶元”字段设置值。
• 按供料槽 – 将晶元按物料箱供料槽编号列表拆分为子批次。如果任何供料槽为空，应用程序将忽略该供料槽。如果选择此选项，则必须为“供料槽编号”字段设置值。
• 偶数 – 将偶数编号的晶元拆分为子批次。
• 前半部分 – 将晶元的前半部分拆分为子批次。
• 后半部分 – 将晶元的后半部分拆分为子批次。
• 奇数 – 将奇数编号的晶元拆分为子批次。
• 按数量 – 将固定数量的批次拆分为子批次。如果选择此选项，则必须为“拆分数量”字段设置值。此选项仅用于基于数量的批次。
• 相等 – 将批次的数量平均拆分为子批次。此选项仅用于基于数量的批次。
• 正数 N 个 – 将正数 N 个晶元拆分为子批次。如果选择此选项，则必须为“ N 个晶元”字段设置值。

必需

N 个晶元

要拆分的晶元数。

注：如果“拆分类型”设为“正数 N 个”或“倒数 N 个”，则此字段为必需字段。

可选

供料槽编号

要拆分的物料箱供料槽编号的列表（以逗号分隔）。

注：如果“拆分类型”设为“按供料槽”，则此字段为必需字段。

可选

拆分数量

特定“拆分类型”的固定拆分数量。“拆分类型”设为“按数量”时启用。

注：如果拆分类型设为“按数量”，则此字段为必需字段。

可选

未来合并规范

用于合并批次的规范。

可选

拆分后操作计划

拆分后将继承“实验计划”的批次。允许选择值：

• 两者 – 无论是父批次还是子批次都将执行“实验计划”。
• 仅父项 – 只有父批次项将执行实验计划。
• 仅子项 – 只有子批次项将执行实验计划。

可选

备注

用于自动拆分操作中的拆分事务的注释。

可选

如何定义实验自动拆分

按照以下步骤定义实验自动拆分：

1. 打开实验自动拆分页。随即“建模”页中将显示“实验自动拆分”页。
2. 单击新建。显示用于定义新实例的空白字段。
3. 在实验自动拆分字段中输入实验自动拆分对象名称。
4. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
5. 单击保存。应用程序保存建模对象并显示成功消息。
