Before Implementing Send Ahead Processing

Before Send Ahead processing can be implemented on the shop floor, you must configure the relevant modeling objects. Before you can configure, you must know the following:

• The Send Ahead Required spec—the WIP spec that prevents the mother lot from moving out until the Send Ahead lot has been created.
• The Block spec—the WIP spec that prevents the mother lot from moving out until the Send Ahead lot has passed validation.
• The Validation spec—the WIP spec that collects the WIP data used for Send Ahead validation.
Note: This spec must be at least one workflow step beyond the Block spec in the workflow.
• The WIP Data Setup that will be used in the validation spec for Send Ahead validation.
• Whether a Lot Combine is required—if so, the spec that will be the "Future Combine" spec.
Note: The Future Combine spec must be at least one workflow step beyond the Validation spec in the workflow.

You can use existing specs and an existing WIP Data Setup or you can create new counterparts specifically for the Send Ahead process. You will always need a Send Ahead matrix defined.
