Specifying the Send Ahead Validation Spec

A Send Ahead Validation spec is a spec configured with a WIP Data Setup that collects the data that will be used to determine the Send Ahead validation status (Pass / Fail).

Before Specifying the Validation Spec

The WIP Data Setup must be defined before it can be associated with the validation spec. Refer to "Defining WIP Data Setup Objects" for information.

When Specifying the Validation Spec

The Validation spec must be selected on the Send Ahead Matrix. The WIP Data Setup that will be used for validation must be selected either on the spec itself or within the process spec details.

Important: The Validation spec must be at least one workflow step beyond the Block spec in the workflow.

How to Specify a Send Ahead Validation Spec

Follow these steps to specify the validation WIP Data Setup on the spec:

1. Access the modeling page for an existing spec.

Or

Create a new spec according to your business requirements.

2. Select the WIP Data Setup.
3. Click Save. The application saves the modeling object and displays a success message.

How to Specify the Validation WIP Data Setup

Follow these steps to specify the validation WIP Data Setup within the process spec details:

1. Access an existing process spec instance.

Or

Create a new one according to your business requirements.

2. Click Add new row on the Details grid. The Add pop-up appears.
3. Select the validation spec from the Spec field.
4. Select the WIP Data Setup from the WIP Data Setup field.
5. Click OK. The pop-up closes and the entry appears in the Details grid on the Process Spec page.
6. Click Save. The application saves the modeling object and displays a success message.
Note: The spec and the WIP Data Setup must be selected in the Send Ahead Matrix. Refer to "Defining a Send Ahead Matrix."
