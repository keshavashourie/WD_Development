Specifying the Send Ahead Required Spec

A Send Ahead Required spec is a spec configured to prevent the mother lot from moving out until the Send Ahead lot has been created.

How to Specify the Send Ahead Required Spec

Follow these steps to specify a spec to be used as a Send Ahead Required Spec:

1. Access the modeling page for the spec you want to use as the Send Ahead Required spec.
2. Click Is Send Ahead Required.
3. Click Save. The application saves the modeling object and displays a success message.
