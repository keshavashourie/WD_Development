Named Data Objects

A named data object (NDO) is a class of main modeling objects that is identified by a unique name. NDO instances are persistent; that is, information on them is written to the database. Because NDOs are designated only by a name, named modeling objects of the same type must have unique names. For example, if you have an Operation modeling object named "Assembly," you cannot create another Operation that is also named "Assembly."

Revision Locking

Revision locking provides the ability to dynamically lock or unlock an instance of a revisioned object.

When locking and unlocking an instance of a revisioned object, remember:

• You do not have to save an instance to lock or unlock it.
• After you lock an instance, you can still access its fields; however, you will not be able to save it.
• You cannot delete a locked instance.

Security administration for Semiconductor Shop Floor is based on a role-based access control model. This security administration sets up user permissions, which in turn affects who can use the revision locking feature.

How to Lock or Unlock an Instance

Follow these steps to lock or unlock an instance:

1. Select Main from the Modeling menu. The application displays the Object selection panel.
2. Click the object type on the Objects list that matches the object type of the instance or revision you want to lock or unlock. The application displays the Instances selection list.
3. Click the instance name that you want to lock or unlock. The application displays the object page for the selected instance.
4. Perform one of the following:

The instance is locked or unlocked and the application displays either the open or closed lock icon to display the appropriate lock status. If you are not authorized to lock or unlock instances, the application displays an error message.

Copying Locked Instances and Revisions

The application enables you to copy locked instances and revisions. You can copy locked instances and revisions by using the following methods:

• Click Copy to create a copy of the locked instance with all of its original information except the name.
• Click Copy Rev to create a copy of the locked revision with all of its original information except the revision.

How to Copy Locked Instances and Revisions

Follow these steps to copy a locked instance or revision:

1. Select Main from the Modeling menu. The application displays the Object selection panel.
2. Click the object type on the Objects list that matches the object type of the instance or revision you want to copy. The application displays the Instances selection list.
3. Click the page that contains the revisioned object with the instance you want to copy. The application displays the Instances selection list.
4. Click the instance name. A page appears displaying the selected instance and the closed lock icon.
5. Perform one of the following:

Note: The copied instance or revision is unlocked, but the original remains locked.
