Revision of Record

The revision of record is the revision currently designated as the default to use in the factory model and on the shop floor, even if other revisions are active and available for use. The revision of record feature reduces model maintenance and ensures the use of correct revisions on the shop floor.

The revision of record is not necessarily the most recent revision of the object. You can specify only one revision as the revision of record, but you can change that designation at any time and make another revision the revision of record.

The advantage of using the revision of record is that when you reference the revision of record, you do not need to update the workflows that use that object every time a new revision of the object is approved for use. For example, when you create a Workflow, you create steps by referencing Spec objects or other Workflow objects. When you reference a Spec, you must select either a specific revision or the revision of record. If you reference a specific revision, the Workflow always uses that revision even if new revisions are created. However, if you reference the revision of record, the Workflow always uses the revision of record, regardless of the actual revision number.

Revisioned Objects in the Instance Selection List

The instance selection list displays in expanded view so that you can see the instances and their associated revisions. The application indicates the revision of record by listing the revision of record after the name of the instance along with a check box after the name of the specific revision.

Clicking an instance name displays the maintenance page for the revision of record of that instance. Clicking the name of a specific revision displays the maintenance page for that revision.

The first instance of a revisioned object you create is the revision of record by default.

You can define a revision of an existing revisioned object instance by using any of the following methods:

• Click New Rev to create a copy of the revision with all fields blank except the name field. You might do this when most attributes will be unique to the new revision.
• Click Copy to create a copy of the revision with all the information from the original revision. You might do this when you want to use an existing revision as the basis for a brand new revision.
• Click Copy Rev to create a copy of the revision with all the information from the original revision except the revision number.

How to Define a New Revision

Follow these steps to define a new revision:

1. Select Main from the Modeling menu. The application displays the Object selection panel.
2. Click the object type on the Objects list that matches the object type of the revision you want to define. The application displays the instance selection list.
3. Click the revision of the instance for which you want to define a new revision. The application displays the selected instance.
Note: If you click the instance name instead of a specific revision, the application selects the revision of record by default.
4. Perform one of the following:

How to Delete an Instance or Revision

Follow these steps to delete an instance or revision:

1. Select Main from the Modeling menu. The application displays the Object selection panel.
2. Click the object type on the Objects list that matches the object type of the instance or revision you want to copy. The instance selection list appears.
3. Click the instance or revision that you want to delete.
Note: If you click the instance name instead of a specific revision, the application selects the revision of record by default.
4. Perform one of the following:

If you want to delete . . .

Then . . .

All revisions
a. Select the revision of record of the modeling object. The Delete All button appears.
b. Click Delete All. The application opens the Delete dialog box.

A specific revision
a. Select a specific revision of the Modeling object. The Delete Rev button appears.
b. Click Delete Rev. The application opens the Delete dialog box.
5. Click Delete in the Delete dialog box. The selected revision or all revisions are deleted, depending on the option you selected in step 5.
