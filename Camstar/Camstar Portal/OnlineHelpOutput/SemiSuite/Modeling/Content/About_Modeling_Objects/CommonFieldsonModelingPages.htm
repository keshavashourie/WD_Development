Common Fields on Modeling Pages

Every modeling object page contains fields common to all modeling objects. These fields appear in the header section of the page and at the bottom of the page.

This table defines fields that appear on the Modeling pages.

Field

Definition

Type

<modeling object>

Unique name for the modeling object.

Required

Revision Locking icon

Indicates the lock status of this revision. When selected, this icon locks this modeling object.

Note: This field is available for revisioned objects only.

Optional

Revision

Revision, or version, of the object instance. Both the name and revision are required to identify the definition.

Note: This field is available for revisioned objects only.

Required

Is Revision of Record

Indicates whether this revision is the revision of record. The application requires one revision to be defined as the revision of record, and only one is allowed.

Note: This field is available for revisioned objects only.

Optional

Filter Tags

Tags assigned to the modeling object instance to facilitate data filtering. Refer to the Opcenter Execution Core Modeling User Guide for information.

Optional

Description

Short description of the modeling object. You can enter a maximum of 255 characters.

Optional

Notes

Relevant comments. You can enter a maximum of 2000 characters.

Optional

Status

Current status (Active or Inactive) or the location.

Note: This field is available for revisioned objects only.

Optional

Setup Access

Sets access control to this instance. Users must have the same access level to modify this instance.

Optional
