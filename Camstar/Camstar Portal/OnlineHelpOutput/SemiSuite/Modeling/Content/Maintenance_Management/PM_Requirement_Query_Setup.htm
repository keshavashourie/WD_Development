Defining a PM Req Query

The PM Req Query enables you to create a query that will return an integer to increment a Usage Requirement counter. The page is similar to the Online Query Setup page.

How to Define a PM Req Query

Follow these steps to define a PM Req Query:

1. Open the PM Req Query page. The PM Req Query page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for this requirement in the PM Req Query field.
4. Enter the column of the query result that will be used to get the usage count in the Result Column Name field.
5. Enter the query code in the Query Text area.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. To test the query:
a. Click Save And Test Query. The application displays the results in a pop-up .
b. Click Close. The application closes the pop-up.
8. Click Save. The application saves the modeling object and displays a success message.
