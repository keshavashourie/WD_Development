Defining Usage Requirements

A Usage Requirement, like a Thruput Requirement, enables you to configure when maintenance becomes due for associated resources. However, a Usage Requirement also enables you to define a counter and how that counter will be incremented. You can configure the counter to be incremented by an integer or an expression that resolves to an integer, or you can create a custom query that will return an integer to increment the counter. You configure the counter with a maximum value and you can set tolerance windows as well.

Note: Use the Resource Activation page to associate the requirement with one or more resources.

How to Define a Usage Requirement

Follow these steps to define a Usage Requirement:

1. Open the Usage Requirement page. The Usage Requirement page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for this requirement in the Usage Requirement field.
4. Select a Maintenance Reason.
5. Enter a Max Usage Count.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Add new row on the Setup Details grid. The application adds a blank row to the grid.
8. Select the transaction from the Txn field. This specifies a transaction that will execute this usage requirement.
9. Select the Usage Count Type.

If you selected . . .

Then . . .

Expression

Enter the expression in the Usage Count Expression field. The expression must resolve to a numeric value. This value will be used to increment the usage count.

Query

Select the query name from the Usage Count Query field.
10. Click Save. The application saves the modeling object and displays a success message.

How to Add Usage Requirement Notifications

Follow these steps to add Usage Requirement notifications:

1. Perform the "How to Define a Usage Requirement" procedure.

Or

Select an existing Usage Requirement instance.

2. Expand the Notifications section.
3. Click Add new row in the Pending E-mail Target, Due E-mail Target, or Past Due E-mail Target grid. A new row appears.
4. Enter an e-mail notification in the newly added row. The notification is added to the grid.
5. Enter the text for the e-mail in the corresponding Pending E-mail Text, Due E-mail Text, or Past Due E-mail Text field. You also have the option to use text variables.
6. Repeat steps 3-5 to set up notifications for additional recipients.
7. Click Save. The application saves the modeling object and displays a success message.

How to Add PM Overrides to a Usage Requirement

Follow these steps to add PM Overrides:

1. Perform the "How to Define a Usage Requirement" procedure.

Or

Select an existing Usage Requirement instance.

2. Expand all sections.
3. Click Add new row in the PM Overrides grid. The application adds a blank row to the grid.
4. Select a Usage Requirement to be included in the override process.
5. Repeat steps 3 and 4 for each additional PM Override to add.
6. Click Save. The application saves the modeling object and displays a success message.
