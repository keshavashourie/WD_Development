Adding Referenced Modeling Object Instances

The Add References page is the third page in the manual Modeling data export pageflow. This page allows you to include modeling objects that are referenced by the modeling objects selected on the Instance Selection page.

When Including References

When you choose to include references, the application adds all instances of all modeling objects referenced by the modeling objects selected on the previous page. Clicking the Include References button adds all the referenced instances to the Current Package Content grid and updates the Object And Instance Counts grid. The application maintains the alphabetical order in this grid also, regardless of whether the added instance is a reference.

Any objects excluded from the reference search are listed in the Object References Not Included field. This list includes any objects selected for exclusion on the Factory page. Refer to " Defining a Factory" for information.

Note: Selecting Add References may automatically add modeling objects to the Current Package Content grid that should not be exported. Siemens recommends you manually remove these instances from the grid to avoid conflicts. Refer to "Before Exporting Modeling Data" for information.

Example:

The Container Level modeling object may contain the optional modeling objects Numbering Rule and UI Preference. If you choose to include references for the selected instances, the application adds the Numbering Rule and UI Preference modeling objects, if referenced by any of the container level instances, to the Current Package Content grid. The application also updates the Object and Instance Counts grid to display the number of referenced modeling objects and the total number of instances of referenced modeling objects.

How to Add Referenced Modeling Object Instances

Follow these steps to add referenced modeling object instances:

1. Complete the "How to Select the Modeling Object Instances to Export" procedure to access the Add References page.
2. Click Include References to add all modeling object instances referenced by the instances you assigned on the Instance Selection page (unless they were exluded on the Factory page). The application adds all the referenced instances to the Current Package Content grid and updates the Object And Instance Counts grid.
Note: Click the expand icon in the Current Package Content grid to view all instances assigned for that modeling object.
3. Expand the object and select any instances you do not want to export and click Delete selected row on the Current Package Content grid. The application removes those instances from the grid.
4. Click Next to move to the next page in the pageflow. The Import/Export Execution Console page appears.
