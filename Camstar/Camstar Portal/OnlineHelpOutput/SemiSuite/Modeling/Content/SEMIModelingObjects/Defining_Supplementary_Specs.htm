Defining Supplementary Specs

The Supplementary Spec object is a subclass of the Process Spec object. It specifies a workflow and optional step-specific details and has a schedule type. A supplementary spec assigned to a lot provides processing options in addition to those of the process spec.

Lot schedulers associate a supplementary spec to a lot by adding it to one of the two supplementary spec grids on either the Lot Schedule page or the Lot Schedule Modify page. The schedule type of the supplementary spec must match the schedule type of the process spec for the lot.

Before Defining a Supplementary Specs

Workflow is a required field for creating a supplementary spec. Therefore, if the required workflow does not exist, create it before creating the supplementary spec.

How to Define a Supplementary Spec

Follow these steps to define a Supplementary Spec:

1. Select Main from the Modeling menu. The application displays the Main tab.
2. Locate and select the Type Scheduled Spec from the list of objects, where Type is the area to which the spec applies. For example, for the assembly area, click Assembly Supplementary Spec.
3. Click New. Blank fields appear for you to define a new instance.
4. Enter a name for the new process spec in the first data entry field.
5. Select a Status.
6. Select a Workflow.
7. Click Expand All to see additional fields. The contracted areas will expand to full view.
8. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
9. Click Save. The application saves the modeling object and displays a success message.
