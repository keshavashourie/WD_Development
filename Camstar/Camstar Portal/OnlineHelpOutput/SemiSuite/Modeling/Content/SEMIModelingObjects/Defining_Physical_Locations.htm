Defining Physical Locations

The Physical Location object enables you to configure an area within a factory. A location can be as broad as the entire shop floor or as specific as Shelf A-1.

Before Defining Physical Locations

The Physical Location object enables you to identify specific areas (positions) within the location you are configuring. You do this by adding instances of the Physical Position object and then selecting them in the Positions grid on the Physical Location page.

How to Define a Physical Location

Follow these steps to define a Physical Location:

1. Open the Physical Location page. The Physical Location page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the location in the Physical Location field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
