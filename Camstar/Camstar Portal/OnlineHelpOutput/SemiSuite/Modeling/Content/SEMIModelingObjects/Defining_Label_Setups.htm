Defining Label Setups

Label Setups define the basic parameters for generating labels.

Before Defining Label Setups

Before defining label setups you must define one or more label types and at least one numbering rule. Refer to "Defining Label Types" for information on label types. Refer to "Defining Numbering Rules" for information on numbering rules.

Label Setup Page Field Definitions

This table defines the fields on the Label Setup page.

Field

Definition

Type

Label Type

Label type of the label. For example, reel or pack.

Required

Numbering Rule

Numbering rule that defines the automatically generated names for the label.

Required

Default Qty Per Label

Quantity per label used to calculate the number of labels to generate.

Required

Printing Setup

Printing setup that defines a printing requirement.

Optional

E Sig Required For Reprint

Indicates whether an e-signature is required to reprint the label.

Optional

How to Define a Label Setup

Follow these steps to define a Label Setup:

1. Open the Label Setup page. The Label Setup page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the label setup in the Label Setup field.
4. Enter the label type in the Label Type field.
5. Enter the numbering rule in the Numbering Rule field.
6. Enter the number of labels to generate in the Default Qty Per Label field.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Save. The application saves the modeling object and displays a success message.
