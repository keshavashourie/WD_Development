Defining Process Specs

A Process Spec is a configurable modeling object used to track lots after they move out of Inventory and into WIP processing. A process spec specifies the workflow steps to execute as well as any runtime parameters and variations on workflow steps. A lot cannot be scheduled until it is associated with a process spec.

The process specs that can be associated to a lot are those that have been configured for the lot product.

Types of Process Specs

Each type of Process Spec corresponds to a manufacturing process operation. Following is a list of Process Spec types:

• Wafer (Item) – Used for tracking lots by wafer count
• Wafer Sort – Used for tracking lots in Wafer Sort area by wafer count
• Back Grind – Used for tracking lots in Back Grind area by die count. Some customers use Assembly to track instead.
• Assembly Mother Lot – Used for tracking lots in Assembly area by die count. In-process split instructions set for die attach will be used to split the lots into smaller sizes. Each child lot split out will have its own schedule and hence be allowed to complete WIP by itself.
• Assembly Sub-Lot – Used for tracking lots in Sub-assembly area by die count. In-process split instructions set for die attach will be used to split the lots into smaller sizes. Each child lot split out will remain within the same schedule as the original lot. All child lots must be combined back to one lot before the parent lot can complete WIP processing.
• Assembly Carrier – Lots are tracked using die count.
• When a lot is tracked into equipment, it is assigned to a carrier. Thereafter, tracking uses Carrier ids instead of lot ids. At subsequent steps where carrier size changes, the application splits the lot automatically as needed. Like the parent lot, each child lot can be assigned to a Carrier id by which it can be tracked.
• During track out, when an output Carrier is selected, the application will check the carrier size and automatically determine whether to split the lot or transfer it as is from the input carrier to the output carrier. A split will occur if the output carrier size capability is smaller than the lot quantity. Note that Opcenter Execution Semiconductor only supports one lot one carrier.
• Test – Lots are tracked using die count. This schedule type is meant for testing lots partially (i.e. build to store).
• Final Test – Lots are tracked using die count. This schedule type is meant for testing lots completely with the intention to ship out or sell.

Before Defining a Process Spec

Workflow is a required field for creating a process spec. You must create a workflow before creating the process spec.

Process Spec Page

All Process Spec add pages contain the same fields. However, the Process Spec field label is prefaced with the type of Process Spec that has been selected.

How to Define a Process Spec

Follow these steps to define a Process Spec:

1. Select Main from the Modeling menu. The application displays the Main tab.
2. Enter Process Spec in the Objects filter field. The list of process objects displays.
3. Select the process spec based on the type of schedule needed (wafer, assembly, etc.) The list of instances and the menu for the selected object type displays.
4. Click New. Blank fields appear for you to define a new instance.
5. Enter a name for the new process spec in the <Type> Process Spec field, where Type is the area to which the process spec applies.
6. Select a Status.
7. Select a Workflow.
8. Click Expand All to see additional fields. The contracted areas will expand to full view.
9. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
10. Click Save. The application saves the modeling object and displays a success message.
