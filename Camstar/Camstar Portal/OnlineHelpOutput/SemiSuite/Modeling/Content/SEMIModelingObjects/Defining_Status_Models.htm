Defining SCS Status Models

Opcenter Execution Semiconductor uses SCS Status Models to validate resource status changes. The SCS Status Model object enables you to define a set of valid resource status transitions. Each transition contains a Status (current or from status) and a To Status, for example, UDT to SBY (Unscheduled Down Time to Standby). A status model can also be configured to trigger maintenance job order creation based on specific reason codes.

Note: Starting from Release 2310+, Status Model page in semiconductor has been renamed to SCS Status Model page. The Status Model objects have also been renamed with the 'scs' prefix as in scsStatusModel, scsStatusModelDetail, and scsStatusModelDetailToReason.

Assigning a Status Model to a Resource

You assign a status model to a resource by selecting the status model when you define the resource.

How to Define a SCS Status Model

Follow these steps to define a SCS Status Model:

1. Open the SCS Status Model page. The SCS Status Model page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the model in the SCS Status Model field.
4. Click Add new row in the Details grid. The Add pop-up appears.
5. Select a Status.
6. Select a To Status.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click OK. The pop-up closes.
9. Click Save. The application saves the modeling object and displays a success message.
