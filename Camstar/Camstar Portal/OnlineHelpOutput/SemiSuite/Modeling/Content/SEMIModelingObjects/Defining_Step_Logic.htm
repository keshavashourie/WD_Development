Defining Step Logic

Step Logic is optional WIP Main processing to which business rules can be applied. Step logic is assigned at the spec level. Opcenter Execution Semiconductor includes the following default Step Logic instances.

• INPROCESSSPLIT—Used to split part of a lot onto a pre-defined "to-lot" during WIP Main processing.
• LOTSIZESAMPLING—Used to conduct non-AQL sampling.
• PACKING—Used to set box quantities for a lot.
• SORTING—Used to grade wafers or items of a lot in WIP processing. Only for item-based steps.
• SORTIQC—Used to inspect incoming wafers or items of a lot in WIP processing.
• SORTSQA—Used to inspect outgoing wafers or items of a lot in WIP processing.
Note: Two default instances require a matrix to be configured. Refer to "Defining a Lot Size Sampling Matrix" and "Defining a Packing Qty Matrix" for information.

You can modify default instances of step logic and create new instances using the Step Logic modeling page.

When Defining Step Logic

The Step Logic page contains the following check boxes, each representing a WIP Main processing point.

• Execute Disposition
• Set Insertion Details (This check box must be selected for lot size sampling to work.)
• Verify WIP Data
• Verify Complete Insertion
• Verify Track In
• Verify Track Out
• Verify Move Out

Directly below each of the above check boxes is a corresponding field to select a business rule. The necessary business rules must already have been created.

Important: There is an additional check box labeled Use Business Rule. This check box must be selected for the application to process any selected business rules.

How to Define New Step Logic

Follow these steps to define a Step Logic:

1. Open the Step Logic page. The Step Logic page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the step logic in the Step Logic field.
4. According to your business requirements:
a. Select each check box that represents a point at which you want to execute a business rule.
b. For each check box selected, select a business rule if you want a rule to be executed for that point.
5. Check the Use Business Rule check box if you want the application to apply your business rule selections during processing.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
Important: Step logic must be assigned to a spec to take effect.

How to Update a Default Step Logic Instance

Follow these steps to update a default Step Logic instance:

1. Select Step Logic from the list of modeling objects. A list of Step Logic instances and a blank Step Logic page appear within the Modeling page.
2. Select the instance to be updated. The selected instance appears within the Modeling page.
3. According to your business requirements:
a. Select each check box that represents a point at which you want to execute a business rule.
b. For each check box selected, select a business rule if you want a rule to be executed for that point.
4. Check the Use Business Rule check box if you want the application to apply your business rule selections during processing.
5. Ensure that the Set Insertion Details check box is selected if you are updating the default LOTSIZESAMPLING instance.
6. Click Save. The application saves the modeling object and displays a success message.
