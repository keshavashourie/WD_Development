Defining Dispatch Plans

A Dispatch Plan enables you to control the order of lots displayed in Portal grids for lot selection. It also enables you to specify a transaction and whether lots must be processed by that transaction in the order they are listed. Three fields on the Dispatch Plan object support this functionality:

• Service Name
• Query
• Enforce Sequence

Before Defining a Dispatch Plan

You are required to specify a query when defining a dispatch plan. This means the query should be defined before the plan. Opcenter Execution Semiconductor provides a default dispatch plan query called DispatchListForTrackIn. You can modify this query or create your own query. The query type should be GUI.

Assigning Dispatch Plans

A Dispatch Plan may be assigned to the following objects listed in order of precedence: 

• Process Spec Details Process Type
• Process Spec Details Step
• Spec

When multiple dispatch plans apply, the application chooses the plan associated with the object that has the highest precedence.

How to Define a Dispatch Plan

Follow these steps to define a Dispatch Plan:

1. Open the Dispatch Plan page. The Dispatch Plan page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a unique name for the Dispatch Plan in the Dispatch Plan field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.

How to Assign a Dispatch Plan to a Process Spec Details Step Process Type

Follow these steps to assign a Dispatch Plan to a process type within a process spec:

1. Select the Process Spec instance.
2. Select the Details grid row listing the step or spec and click Edit row. The application displays the Edit pop-up.
3. Do you want to assign a dispatch plan to an existing process type or do you need to add one first?

How to Assign a Dispatch Plan to a Process Spec Details Step or Spec

Follow these steps to assign a Dispatch Plan to a step or spec within a process spec:

1. Select the Process Spec instance.
2. Select the Details grid row listing the step or spec and click Edit row. The application displays the Edit pop-up.
3. Enter the dispatch plan in the Dispatch Plan field. (Do not confuse this with the Dispatch Plan field in the Process Types grid.)
4. Click Save. The application saves the modeling object and displays a success message.

How to Assign a Dispatch Plan to a Spec

Follow these steps to assign a Dispatch Plan to a spec:

1. Select the Spec instance.
2. Enter the dispatch plan into the Dispatch Plan field.
3. Click Save. The application saves the modeling object and displays a success message.
