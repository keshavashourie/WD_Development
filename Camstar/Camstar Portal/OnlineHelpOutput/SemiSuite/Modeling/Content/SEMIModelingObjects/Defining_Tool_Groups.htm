Defining Tool Groups

A Tool Group is used to group individual Tools together.

When Defining Tool Groups

You must define Tools that will be part of the tool group before you can define a tool group.

Tool Group Page Field Definitions

This table defines the fields on the Tool Group page.

Field

Definition

Type

General

Entry Type

Indicates the type of object contained in this group. For example, Tool for Tool Groups.

Optional

Entries grid

List of tools to add to the Tool Group.

Optional

Groups grid

List of tool groups to add to the Tool Group as subgroups.

Optional

How to Define a Tool Group

Follow these steps to define a Tool Group:

1. Open the Tool Group page. The Tool Group page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the tool group in the Tool Group field.
4. Perform the following steps to add tools to the Entries grid:
a. Click Add new row. Select a Tool from the list that appears in the grid.
b. Repeat steps a for every tool you want to add to the tool group.
5. Perform the following steps to add tool subgroups to the Groups grid:
a. Click Add new row. Select a Tool Group from the list that appears in the grid.
b. Repeat steps a for every too group you want to add as a subgroup.
6. Click Resolved Entries. The application displays a pop-up displaying the list of all of the tools included in the tool group. Tools from the tool groups are listed individually.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Save. The application saves the modeling object and displays a success message.
