Defining Material Types

A Material Type is used to differentiate the types of Material Parts or Products used as materials for a lot and how those materials are consumed. Each material type can specify one or more Specs where the material is to be consumed.

Material Type Page Field Definitions

This table defines the fields on the Material Type page.

Field

Definition

Type

Details

Consume Type (Item Processing)

Indicates how materials are consumed. Valid values are:

• QTY - Materials are consumed using the Qty value. This is the default.
• QTY2 - Materials are consumed using the Qty2 value.

Optional

Consume Qty

Indicates whether to reduce the quantity of the material lot when the material is consumed.

Optional

Is Serialized

Indicates whether a material lot must be started in the application in order to be consumed by a production lot.

Optional

Reference Attribute Number

ID for the material type.

Optional

Attribute to Match Batch

Lot Attributes field against which to compare the material during Track In. If provided, the corresponding Lot Attributes field will be used to check against the Material Lot Name. If the Lot Attributes field is null, the application skips verification.

Optional

Consume Specs grid

Grid that lists the specs (steps) where the main production lot must be to use the material.

Optional

Spec

WIP Spec where processing is to be performed.

Optional

Vendors grid

Grid that lists the vendors for the material type.

Optional

Vendor

Vendor of the material. If specified, the application verifies against the material’s vendor loaded in the equipment.

Optional

How to Define a Material Type

Follow these steps to define a Material Type:

1. Open the Material Type page. The Material Type page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the material type in the Material Type field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
