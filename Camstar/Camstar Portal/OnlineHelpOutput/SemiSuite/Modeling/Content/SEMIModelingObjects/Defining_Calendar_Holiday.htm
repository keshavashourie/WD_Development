Defining Calendar Holidays

Calendar Holidays are used to define holidays in the application. It provides information for reporting purposes only.

How to Define a Calendar Holiday

Follow these steps to define a Calendar Holiday:

1. Open the Calendar Holidays page. The Calendar Holidays page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the object type in the Calendar Holidays field.
4. Enter the start and end dates and times in the Start Timestamp and End Timestamp fields respectively.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
