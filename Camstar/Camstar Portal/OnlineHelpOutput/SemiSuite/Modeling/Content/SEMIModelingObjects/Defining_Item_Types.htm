Defining Item Types

Item Types are used to store configuration information specific to the type. Item Types are associated to Item Categories that build the list of valid types associated to the lot items. Example of item types include wafers, strips, and panels.

How to Define an Item Type

Follow these steps to define an Item Type:

1. Open the Item Type page. The Item Type page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Save. The application saves the modeling object and displays a success message.
