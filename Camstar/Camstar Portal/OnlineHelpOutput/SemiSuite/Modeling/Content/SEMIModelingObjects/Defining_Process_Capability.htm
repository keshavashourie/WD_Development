Defining Process Capabilities

A Process Capability is a condition that determines whether a piece of multi-chamber equipment can be used by the manufacturing process. The condition, called a multi-chamber condition, is an equation that defines the child equipment that must be available for use. For example, you can specify that the equipment defined by one or more parent and child Equipment modeling objects be available in order to use the multi-chamber equipment.

After you create the Process Capability modeling object, you can use it to specify the multi-chamber tool to use in a specific process or supplementary spec.

When Defining a Process Capability

The following rules apply when defining Process Capabilities:

• You must define equipment and child equipment for use by the Process Capability. Equipment objects are defined on the Assembly Equipment, Back Grind Equipment, Test Equipment, Wafer Equipment, and Wafer Sort Equipment pages as required by your business needs. Refer to "Defining Equipment" for information about defining child equipment.
• The equipment must be available.

Constructing a Multi-Chamber Condition

The multi-chamber condition is a Boolean equation that defines the child multi-chamber equipment that is available for use. Each piece of equipment is defined by an operand which consists of two variables separated by a delimiter, as follows:

equipmentType$equipmentLogicalID

Where:

• equipmentType is the type of equipment. This must be set to either CH (for chamber) or LP (for load port).
• equipmentLogicalID is the logical ID of the equipment. You assign the logical ID when you create the equipment modeling object.
• The dollar sign ($) is the delimiter.

You can use any Boolean operator, such as AND and OR, to further define the equation. You must also use parentheses (()) around each operand and to group operands.

For example, the following equation specifies that chamber equipment object A and either chamber equipment object B or C must be available:

(CH$A) AND ((CH$B) OR (CH$C))

User Fields

Multi Chamber Condition

The equation that specifies which equipment can be used. You must enclose each individual operand and each group of operands with parentheses. For example, the following equation specifies chamber equipment A as well as either chamber equipment B or C:

(CH$A) AND ((CH$B) OR (CH$C))

where:

• CH represents a chamber equipment object.
• The dollar sign ($) is a delimiter.
• A, B, and C, represent the logical IDs for each chamber equipment object.

 

Refer to "Constructing a Multi-Chamber Condition" for a complete explanation of how to write equations for the Multi Chamber Condition field.

How to Define a Process Capability

Follow these steps to define a Process Capability:

1. Open the Process Capability page. The Process Capability page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Process Capability in the Process Capability field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
