Defining Wafer Carrier Families

You define Wafer Carrier Family modeling objects to enable you to group wafer carriers that share specific features and settings, such as the number of slots.

Wafer Carrier Family Page Field Definitions

This table defines the fields on the Wafer Carrier Family page.

Field

Definition

Type

General

Job Notification Email Group

Specifies the e-mail group to notify in the event that a failure is detected.

Optional

Status Model

Name of the status model object that specifies, for this Wafer Carrier Family, the allowed set of statuses (carrier status codes) to which a resource status can be transitioned, based on its current status. For example, a Wafer Carrier Family with the status code In Repair can only be assigned to a status that belongs to the status code group Stand By. In this way, the transition of the status can be restricted based on the defined model.

Optional

UOM

The unit of measurement by which to measure the wafers processed by the wafer carriers that are part of this Wafer Carrier Family.

Optional

User Fields

Number of Slots

Required to map slots in wafer carriers. Defines the number of slots in the wafer carriers that are associated with this Wafer Carrier Family. When you create a wafer carrier object and associate it to a Wafer Carrier Family, the application displays the same number of slots in the Slot Map grid of the wafer carrier object. Refer to "Defining Wafer Carriers" for information about the wafer carrier object.

Optional

How to Define a Wafer Carrier Family

Follow these steps to define a Wafer Carrier Family:

1. Open the Wafer Carrier Family page. The Wafer Carrier Family page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a unique name for the wafer carrier in the Wafer Carrier Family field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
