Defining Carrier Status Codes

A Carrier Status Code provides a description of current availability for a carrier. The Carrier Status Code page enables you to add and configure these codes.

Carrier Status Code Page Field Definitions

This table defines the fields unique to the Carrier Status Code page.

Field

Definition

Type

Is Available

Check box that can be selected to signify that a carrier with the status code is available for lot processing.

Optional

Status Reasons grid

Displays a list of reasons configured for the status code. You can click Add new row on the grid toolbar to add a reason.

Optional

Status Reasons

Displays reasons that have been configured for this carrier status code. These reasons will be available for selection when an operator assigns the status code to a carrier.

Optional

How to Define a Carrier Status Code

Follow these steps to define a Carrier Status Code:

1. Open the Carrier Status Code page. The Carrier Status Code page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the code in the Carrier Status Code field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
