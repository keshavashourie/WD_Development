Defining Work Orders

A Work Order (or Manufacturing Order) is a product manufacturing request that is typically originated to fulfill a sales or inventory requirement. A work order often serves as a link between an ERP and MES system. Opcenter Execution Semiconductor enables you to associate work orders to the lots and containers. WIP data is stored in the lot or container data records during manufacturing and is used to provide status information back to the ERP system. Storing information in the lot or container records eliminates the need for you to search through history for the information.

When Defining Work Orders

Work orders can be configured to include any components (consumable materials and sub-assemblies) required to complete the work order. Those components for which consumption is to be recorded using a Opcenter EX CR Component Issue page should be listed on the Material List grid. All other components should be listed on the Materials grid.

Work Order Enforcement

The option to require a work order when a lot is started is set at the process spec level by selecting the Work Order Required check box on the Process Spec page.

How to Define a Work Order

Follow these steps to define a work order:

1. Open the Work Order page. The Work Order page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a unique name for this work order in the Work Order field.
4. Select the product name from the Product Name field.
5. Enter the quantity required to be produced by the work order in the Qty field.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
