Defining Label Plans

Label Plans define the sets of labels generated at certain steps. You can configure each label setup to have its input quantity based on another label setup or to address a particular packing requirement (for example, a reel within a pack, reels within a box, and so on).

The input quantity of any setup detail without a Source Level ID defined will be based off the initial input (typically the quantities of one or more lots). If the Source Level ID is specified, the input quantity of that detail setup will be based off the total labels generated from the specified source setup detail.

Before Defining Label Plans

Before defining label plans, you must define the following:

• One or more label types. Refer to "Defining Label Types" for information.
• One or more label setups. Refer to "Defining Label Setups" for information.

How to Define a Label Plan

Follow these steps to define a Label Plan:

1. Open the Label Plan page. The Label Plan page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the label plan in the Label Plan field.
4. Perform the following for each detail you want to add to the label plan in the Label Plan Details grid:
a. Click Add new row. The application adds a blank row to the grid.
b. Enter values for the Level ID and Label Setup fields.
c. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
d. Repeat steps a-c for every detail you want to add to the label plan.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
