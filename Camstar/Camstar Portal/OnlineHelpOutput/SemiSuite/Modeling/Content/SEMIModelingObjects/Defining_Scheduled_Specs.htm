Defining Scheduled Specs

Scheduled Specs are revisioned objects that define processing instructions for lots being released from inventory to production. Scheduled Specs are used as steps within a Workflow to describe the movement of lots from inventory to WIP.

Scheduled Specs are categorized by manufacturing process operation, which define the specific area in which the Scheduled Spec operates. For example, you would use a Back Grind Scheduled Spec to define a step for a lot in the back grind operation. Semiconductor Shop Floor provides the following Scheduled Specs:

• Assembly Scheduled Specs
• Back Grind Scheduled Specs
• Test Scheduled Specs
• Wafer Scheduled Specs
• Wafer Sort Scheduled Specs

How to Define a Scheduled Spec

Follow these steps to define a Scheduled Spec:

1. Select Main from the Modeling menu. The application displays the Main tab.
2. Locate and select the Type Scheduled Spec from the list of objects, where Type is the area to which the spec applies. For example, for the back grind area, click Back Grind Scheduled Spec.
3. Click New. Blank fields appear for you to define a new instance.
4. Enter the following required information:
a. Enter the name for the Scheduled Spec in the <Type> Scheduled Spec field.
b. Enter the revision of the spec in the Revision field.
c. Enter the manufacturing or processing point where inventory or production activities are tracked in the Operation field.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
