Defining SM Feeder Families

You define Feeder Families to enable grouping of feeders by attributes.

SM Feeder Family Page Field Definitions

This table defines fields on the SM Feeder Family page.

Field

Definition

Type

General

Job Notification Email Group

Specifies the e-mail group to notify in the event that a failure is detected.

Optional

Status Model

Name of the status model object that specifies, for this feeder family, the allowed set of statuses (carrier status codes) to which a resource status can be transitioned based on its current status.

Optional

UOM

Unit of measurement by which to measure wafers processed by feeders belonging to this family.

Optional

Check box to indicate whether adhoc processing of feeders in this family should cause usage requirement counters to be incremented (if configured).

Optional

How to Define a SM Feeder Family

Follow these steps to define a SM Feeder Family:

1. Open the SM Feeder Family page. The SM Feeder Family page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a unique name for the feeder family in the Feeder Family field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
