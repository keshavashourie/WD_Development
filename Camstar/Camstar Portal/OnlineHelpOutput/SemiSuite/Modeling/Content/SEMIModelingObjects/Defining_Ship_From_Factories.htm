Defining Ship From Factories

The Ship From Factory object enables you to add a factory that supplies your factory with lots and materials.

Ship From Factory Page Field Definitions

This table defines the fields unique to the Ship From Factory page.

Field

Definition

Type

Details grid

Grid listing inventory and initial processing information for the ship from factory.

Optional

Ship To Process

The process to be used for lots shipped to the factory.

Note: Entry of this information is not enforced despite the field being marked as required.

In-Transit Location

Location to hold information for a lot that is expected but has not yet physically arrived.

Optional

How to Define a Ship From Factory

Follow these steps to define a Ship From Factory:

1. Open the Ship From Factory page. The Ship From Factory page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the factory in the Ship From Factory field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
