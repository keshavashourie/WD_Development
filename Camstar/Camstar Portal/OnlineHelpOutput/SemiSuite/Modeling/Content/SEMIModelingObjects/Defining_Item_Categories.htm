Defining Item Categories

An Item Category is used to provide a hierarchy of Item Types that can be stored for a lot.

Item Category Page Field Definitions

This table defines the fields on the Item Category page.

Field

Definition

Type

Details

Max Level

Maximum number of hierarchy levels allowed for a category.

Required

Details grid

Grid that lists the Item Levels and Item Types allowed for the Item Category.

Optional

Item Level

Numeric value representing the level of information to the Max Level.

Required

Item Type

Type of item. For example, Wafers, Strips, and Panels. This is used to identify and categorize lot items.

Required

Inheritable Status

Indicates how items defined for the lot is inherited during split and combine actions:

• None – No inheritance required.
• Split – Child lot inherits from the parent lot. The application copies the Item Level and Item Type item from the main lot to the child lots.
• Combine – Parent lot inherits from child lots. The application copies the Item Level and Item Type items from the child lots to the parent.
• Both – Split and combine. The parent and child lots inherit from each other.

Optional

How to Define an Item Category

Follow these steps to define an Item Category:

1. Open the Item Category page. The Item Category page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the item category in the Item Category field.
4. Enter the maximum number of hierarchy levels allowed in the Max Level field.
5. Enter the item level details in the Details grid for each item level you want to add to the Inspection Level object as follows:
a. Click Add new row. The application adds a blank row to the grid.
b. Enter the item level in the Item Level column.
c. Enter the item type in the Item Type column.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
