Defining Task Lists

A Task List enables you to define a set of procedures to be carried out during WIP Processing. You implement the list by assigning it to an electronic procedure and then assigning the electronic procedure to a spec.

A task list can be configured with data collections and with instructions at both the list and individual task level. The instructions can include WIP Data Name variables that are dynamically resolved at runtime. You define a task list using the Task List modeling page.

Refer to the Opcenter Execution Core Modeling User Guide for a complete description of tasks and task lists.

How to Define a Task List

Follow these steps to define a Task List:

1. Open the Task List page. The Task List page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for this task list in the Task List field.
4. Enter the revision of this task list in the Revision field.
5. Select an Execution Mode for this task list.
6. Add at least one task to the Tasks grid using the appropriate procedures below:
a. "How to Add an Instruction Task to a Task List"
b. "How to Add a Computation Task to a Task List
c. "How to Add a Transaction Task to a Task List"
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Save. The application saves the modeling object and displays a success message.

How to Add an Instruction Task to a Task List

Follow these steps to add an instruction task to a Task List:

1. Perform the "How to Define a Task List" procedure.

Or

Select an existing Task List instance.

2. Click Add new row in the Tasks grid. The Select Task Item Type menu appears.
3. Select Instruction. The Instruction Task Details pop-up appears.
4. Enter a name for the task in the Task field.
5. Select a value for the Task Type field.
6. Select a value for the Instruction Type field.
7. Enter a number in the Min Iterations field to indicate the minimum number of times the task can be executed.
8. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
9. Click Save. The application saves the modeling object and displays a success message.

How to Add a Computation Task to a Task List

Follow these steps to add a computation task to a Task List:

1. Perform the "How to Define a Task List" procedure.

Or

Select an existing Task List instance.

2. Click Add new row in the Tasks grid. The Select Task Item Type menu appears.
3. Select Transaction. The Transaction Task Details pop-up appears.
4. Enter a name for the task in the Task field.
5. Select a value for the Task Type field.
6. Enter a number in the Min Iterations field to indicate the minimum number of times the task can be executed.
7. Select a User Data Collection Def.
8. Select a computation from the Computation field. The input variables defined for the computation selected are displayed.
9. Map each variable to the appropriate data point by selecting the data point from the Data Point lists in the grid. You must expand the User Data Collection to see the data points.
10. Select a revision of a Computation Param Spec.
11. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
12. Click OK. The pop-up closes and the task displays the Tasks grid.
13. Click Save. The application saves the modeling object and displays a success message.

How to Add a Transaction Task to a Task List

Follow these steps to add a transaction task to a Task List:

1. Perform the "How to Define a Task List" procedure.

Or

Select an existing Task List instance.

2. Click Add new row in the Tasks grid. The Select Task Item Type menu appears.
3. Select Transaction. The Transaction Task Details pop-up appears.
4. Enter a name for the task in the Task field.
5. Select a value for the Task Type field.
6. Enter a number in the Min Iterations field to indicate the minimum number of times the task can be executed.
7. Select a transaction page from the Transaction Page list.
8. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
9. Click OK. The pop-up closes and the task displays the Tasks grid.
10. Click Save. The application saves the modeling object and displays a success message.

a. Place your cursor where you want the image to appear in the Instruction field.
b. Click the Insert/edit image button. The Insert/edit image pop-up appears.
c. Enter a relative or absolute URL for an image in the Source field.
