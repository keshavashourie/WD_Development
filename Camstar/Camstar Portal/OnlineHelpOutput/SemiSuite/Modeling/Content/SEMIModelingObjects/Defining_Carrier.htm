Defining Carrier

A carrier allows you to carry or hold multiple of materials during production process. It can be used to move around sets of materials on the shop floor.

An example of a situation where a carrier is used; An operator is making a drug in a factory and divides the 100 KG of the first drug ingredient into five trays which hold 20 KG each. The trays in this example are the carriers.

You can assign a container to a carrier. However transaction must be performed on the container, not the carrier.

Carrier Positional Map

Carrier Positional Map grid

A grid that specifies lot positional information in the carrier. Refer to "How to Define Carrier Positional Map in Carrier Modeling Page" for more information.

Display Only

Lot

Name of the lot.

Display Only

Position Number

The position number of the lot. The value displayed in this field is based on the Positional Method selected in the Carrier Families page. There are two types, either Numeric or Vector.

For the Numeric method, the value of the Position Number is based on X-position times Y-position times Z-positions. For example, if the lot is X:2, Y:2, Z:1 (means located at column 2, row 2, in vertical position 1) the Position Numbers will be 1- 4.

For the Vector method, the value of the Position Number is based on X.Y.Z format. For example 2.2.1.

Display Only

Position Level

The position level of the lot in a carrier. The value of this field is based on Z-position set in the Carrier Family page.

Display Only

Status

Status of the lot either Up and Down. You can change the status on the grid by selecting the field's drop-down.

Optional

How to Define a Carrier

Follow these steps to define a Carrier:

1. Open the Carrier page. The Carrier page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the carrier in the Carrier field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.

How to Define Carrier Positional Map in Carrier Modeling Page

Follow these steps to utilize the Carrier Positional Map:

1. Open the Carrier page. The Carrier page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the carrier in the Carrier field.
4. Select a Carrier Family in the Carrier Family field. Selecting a field will populate values in the Carrier Position Map grid. Refer to Defining Carrier Families for information on Carrier Position.
5. Click Save. The application saves the modeling object and displays a success message.
6. The Carrier Positional Map grid will load with information. Refer to the Carrier Positional Map grid for the field definition.
