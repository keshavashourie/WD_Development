Defining Tool Actions

A Tool Action provides a way to categorize tools based on their attributes and according to your business requirements. Each tool can have a single tool family. You select the tool action when using the Tool Management page to manage tools. Refer to the Opcenter Execution Semiconductor Shop Floor Guide for information on the Tool Management page.

How to Define a Tool Action

Follow these steps to define a Tool Action:

1. Open the Tool Action page. The Tool Action page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a unique name of the tool family in the Tool Action field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
