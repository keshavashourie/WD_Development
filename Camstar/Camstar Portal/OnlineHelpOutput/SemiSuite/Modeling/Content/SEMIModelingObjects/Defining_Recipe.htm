Defining Recipes

A Recipe is a document that defines the resource settings for use in manufacturing, such as the timing and temperature of a server. The Recipe definition consists of the recipe file name and location. When defined, the Recipe is typically, but not always, executed by the resource itself.

When you upload the recipe file, the application stores the file in the database as a Character Large Object (CLOB). The application then references the file as needed to configure servers according to the recipe definitions.

Requirements

Your browser must have the appropriate plug-in to view the type of recipe document selected (such as a .pdf file).

When Defining a Recipe

The following rules apply when defining Recipes:

• A Recipe cannot have the same name as a document. For example, if you create a document named "Test," you cannot create a Recipe named "Test."
• The download/upload time of files varies depending on the file size.

How to Define a Recipe

Follow these steps to define a Recipe:

1. Open the Recipe page. The Recipe page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Recipe in the Recipe field.
4. Enter the revision of this Recipe in the Revision field.
5. Click Browse next to the Locate File field. The application opens the File Upload dialog box.
6. Browse for the file and then click Open. The File Upload dialog box closes and the file name appears in the Locate File field.
7. Select the Upload File to Database check box if you want to upload this file to the database when you save.
8. Click Add new row in the Recipe Parameters grid, and enter the following:
a. Enter a parameter name in the Param Name field.
b. Enter a value for the parameter in the Param Value field.
9. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
10. Click Save. The application uploads the recipe file to the database (if you selected Upload File to Database), saves the modeling object, enables the File Actions button, and displays a success message.

1. Open the Recipe page. The Recipe page appears within the Modeling page.
2. Locate and select the Recipe instance from the list of instances.
3. Click File Actions. The application displays the Opening document_name dialog box, where document_name is the name of the document.

5. Click OK. The application performs the specified action.
