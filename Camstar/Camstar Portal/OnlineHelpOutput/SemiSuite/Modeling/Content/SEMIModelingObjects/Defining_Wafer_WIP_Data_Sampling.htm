Defining Wafer WIP Data Sampling

The Wafer WIP Data Sampling page enables you to configure the quantity of wafers or slots containing wafers for sampling purposes. You can predefine a method or specification on how the application selects the number of wafers within a lot. You may further enforce the selection by selecting the Enforce Sampling check box on the WIP Data Setup modeling object. During processing within WIP Main or Equipment WIP Dispatch, Track In will identify the preselected wafers from the method (except for User Selected method). Reselection of wafers is also possible if sampling is not enforced.

Wafer WIP Data Sampling is intended to enhance the standard-lot sampling processes to a more specified wafer-based sampling selections and eliminates the 100% data collection requirement for item processing.

Note: Wafer-based sampling will take precedent over AQL Sampling. If the existing default AQL Sampling and the new Wafer WIP Data Sampling are configured at the same step, only Wafer WIP Data Sampling will be performed. ​

When Defining Wafer WIP Data Sampling

The Wafer WIP Data Sampling modeling object offers you functionality to configure wafer sampling selection based on the following methods:

• User Selected – Manual selection by the user. You can manually select individual wafers or slots containing wafers within a lot to be sampled on the Items grid in WIP Main or Equipment WIP Dispatch page prior to Track In.
• Top N – Auto selection based on the top N number of slots, where N is the number of slots to be sampled. If you select this option, you must set a value in the field Number of Slots. For example, if you set 5 as the Number of Slots, the application will select the top (or first) 5 slots containing wafers of the current lot.
• Bottom N – Auto selection based on the bottom N number of slots, where N is the number of slots to be sampled. If you select this option, you must set a value in the field Number of Slots. For example, if you set 5 as the Number of Slots, the application will select the bottom (or last) 5 slots containing wafers of the current lot.
• Sample Size – Selection of wafers by the entered Sample Size number. For example, if you entered 5, the application will select 5 wafers for sampling. Refer to the "When Using Sample Size or Sample Percentage Method" for information on the sampling calculation and selection.
• Sample Percentage – Selection of wafers by the Sample Percentage value. For example, if you entered 20% out of 25 total wafers, 5 wafers will be selected for sampling. The application will do a standard rounding and choose the nearest number if necessary. For example, 4.8 will be rounded to 5. However, if the calculated sample size value is less than 1, the application will choose a minimum of 1 wafer. For example, the entered Sample Percentage is 1% with the calculated sample size of 0.25, the application will choose 1 wafer. Refer to the "When Using Sample Size or Sample Percentage Method" for information on the sampling calculation and selection.

When Using Sample Size or Sample Percentage Method

For either sample size or sample percentage entered, the application will calculate sample steps to evenly distribute the selection of wafers across the lot.

The following are examples of scenarios to better understand the Sampling Size and Percentage selection methods:

Note: The calculated sample size explained in these examples are referring to the value entered in Sample Size field or the calculated sampling size based on Sample Percentage field.
• If the calculated sample size is ≥ total number of wafers in the lot, all wafers will be selected.
• If calculated sample size = 1, wafer in the slot closest to the middle will be selected.
• If calculated sample size = 2, wafers in the top slot and the bottom slot of the current lot will be selected.
• If calculated sample size > 2, the application will select wafers located on the top slot, bottom slot and calculate the Sample Steps to identify the rest of middle slot positions. Sample Steps is calculated to get the number of wafers to skip which identifies the next wafer to sample.

Sample Steps = Total Wafers ÷ (Sample Size - 1).

For example, the carrier has a total number of 25 wafers and the entered Sample Size is 5. The Sample Steps would be 25 ÷ (5 - 1) = 6.25. The application will round-down sample steps for decimal number for example, 4.66 is rounded down to 4, 2.98 is rounded to 2 and 6.25 is rounded down to 6. Hence, in this example the application will have Sample Step =6 and will skip 6 wafers for every selected wafer. The selected wafer to be sampled for Track In would be Wafer 1, Wafer 7, Wafer 13, Wafer 19 and Wafer 25.

How to Define a Wafer WIP Data Sampling

Follow these steps to define a Wafer WIP Data Sampling:

1. Open the Wafer WIP Data Sampling page. The Wafer WIP Data Sampling page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a unique name in the Wafer WIP Data Sampling field.
4. Select the Wafer Sampling Method field.
5. If the Top N or Bottom N method selected, enter the Number of Slots field.
6. If the Sample Size or Sample Percentage method are selected, enter the Sample Size or the Sample Percentage value.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Save. The application saves the modeling object and displays a success message.
