Defining SM Feeder Plans

A feeder plan defines each feeder slot on an equipment resource and the type of component materials permitted for the slot.

SM Feeder Plan Page Field Definitions

This table defines the fields on the SM Feeder Plan page.

Field

Definition

Type

Details

Details grid

Grid listing slot information for feeders, feeder families, and feeder groups.

Optional

Slot

Identifies a physical slot on a resource. The slot's purpose is to hold a component material feeder.

Optional

Product

Component material that is held by a feeder.

Optional

Feeder

Type of equipment resource that is placed into a slot on a machine. The most common purpose of a feeder is to hold a reel of material that will be consumed by the machine.

Optional

Feeder Family

Category of feeders that share attributes.

Optional

Feeder Group

Collection of feeders with similar characteristics.

Optional

How to Define a SM Feeder Plan

Follow these steps to define a SM Feeder Plan:

1. Open the SM Feeder Plan page. The SM Feeder Plan page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the feeder plan in the Feeder Plan field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
