Defining Carrier Families

Carrier Families enables way to categorize carriers based on the same specified attributes and business requirement. You can use Carrier Family to set maintenance schedules for a group of carriers or use it to define filter criteria for various shop floor transactions. It can also be used to differentiate the Max Qty of the associated carriers based on the PN-defined package type and lead value.

Carrier Positions

Enable Carrier positions is an optional field that allow you to set the size of the carrier and identify the position inside the carrier. By checking the Enable Carrier Positions check box in the Carrier Families page, the application will automatically enables another six (6) fields that will allow you to set the size of the carrier and assign shop floor integration settings. These fields are Positional Method, X-Positions, Y-Positions, Z-Positions, Position Assign Lot Verification and Shop Floor Integration Settings.

The three positions of X, Y and Z help to define the position or size of the carrier as in column and row plus the number of vertical position of identical size. X defines the column, Y defines the row and Z defines the number of vertical positions. For example X:1 means the carrier has 1 column, Y:5 means the carrier has 5 rows and Z:2 means the number of vertical positions is 2 or "2 Tertiary in a Carrier".

Positional Method field on this page allow you to choose how you want to display the value of X, Y and Z positions inside the carrier. It is available in two (2) options, Numeric and Vector.

• Numeric: Describes the carrier positions in sequential number. The number specifies the position of the X, Y and Z. For example, a configuration of X:1, Y:5, and Z:2 means that there are a total of 10 positions in the carrier numbered 1-10. The lowest level (1) contains positions 1-5. Level 2 contains positions 6-10.
• Vector: Describes the carrier positions in vector (x,y,z) format or three-dimentional value. For example, a configuration of X:1, Y:4, and Z:3 means that there are a total of 13 positions in the carrier. Four positions per vertical position. The position will be labeled as the following:
• 1.1.1 - 1.4.1
• 1.1.2 - 1.4.2
• 1.1.3 - 1.4.3

Shop Floor Integration Settings

When Shop Floor Integration Settings is configured on a carrier family, any carrier assigned to the carrier family will inherit these values during creation of the carrier container:

• Owner
• Level

The carrier container inherits these values only if they are specified in the selected Shop Floor Integration Settings.

This setting can be applied when a carrier container is created using Carrier Operation (HPE), Lot Start - Bulk (HPE) or Work Order Dispatch (HPE) pages.

The benefit of setting-up this field is to help you to differentiate between a carrier container/lot and the standard WIP container/lot.

How to Define a Carrier Family

Follow these steps to define a Carrier Family:

1. Open the Carrier Family page. The Carrier Family page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the object type in the Carrier Family field.
4. To set the carrier positions, check the Enable Carrier Positions check box. Checking this field will enable the following fields; Positional Method, X, Y and Z. Refer to Carrier Positions section and field definition table for more information on carrier positioning.
5. Perform the following to add sizing requirements to the Sizing grid:
a. Click Add new row. The application adds a blank row to the grid.
b. Enter a shift number in the Package Type field.
c. Enter the duration of the shift in the Leads field.
d. Enter the name of the shift in the Max Qty field.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
