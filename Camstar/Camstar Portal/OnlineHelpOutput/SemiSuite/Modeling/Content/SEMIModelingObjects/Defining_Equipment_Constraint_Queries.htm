Defining Equipment Constraint Queries

The Equipment Constraint Query page enables you to define a query that extends the constraints of an Equipment Constraint matrix. For example, you want to add a constraint value that can only be obtained from a query. You create the query using the Equipment Constraint Query page and then add the query to the matrix.

How to Define an Equipment Constraint Query

Follow these steps to define an Equipment Constraint Query:

1. Open the Equipment Constraint Query page. The Equipment Constraint Query page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the Equipment Constraint Query in the Equipment Constraint Query field.
4. Enter the text of the SQL query statement in the Query Text field.
5. Perform the following to add each parameter to the Parameters grid:
a. Click Add new row. The application adds a blank row to the grid.
b. Enter the User Query Parameter Name.
c. Enter the Data Type.
d. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Change the default value in Resultset Size Limit or leave the existing default.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Save. The application saves the modeling object and displays a success message.

How to Test the Query

Follow these steps to test an equipment constraint query definition:

1. Perform the steps in "How to Define an Equipment Constraint Query."

Or

Select an existing Equipment Constraint Query instance.

2. Click Save And Test Query to save and test the query. The application opens a pop-up for testing.
3. Enter any parameters required by the query.
4. Click Test Query. Any results matching the query and parameters entered appear in the Query Results grid.
5. Click Close. The pop-up closes.
