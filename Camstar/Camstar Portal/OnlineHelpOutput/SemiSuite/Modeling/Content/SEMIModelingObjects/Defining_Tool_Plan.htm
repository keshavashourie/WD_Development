Defining Tool Plans

A Tool Plan is used to specify the required tools that must be attached to the equipment before processing. You can specify tools, tool families, or both to be part of Tool Plans.

When Defining Tool Plans

Before you can define tool plans, you must define the tool and tool family modeling objects that will be part of the Tool Plan.

How to Define a Tool Plan

Follow these steps to define a Tool Plan:

1. Open the Tool Plan page. The Tool Plan page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Tool Plan in the Tool Plan field.
4. Click Add new row in the Items grid. The application opens the Add dialog box.
5. Perform the following steps in the Add dialog box:
a. Enter a parameter name in the Item Name field.
b. For every tool family and tool to add to the Tool Plan, click Add new row in the Details grid and add a valid entry in either the Tool Family or Tool column.
Note: You cannot add both a tool family and a tool to a single row. Add a new row for each entry.
c. Enter optional information to the Add dialog box according to your business requirements. Refer to "Tool Plan Add Pop-Up Field Definitions" for information on the optional fields.
d. Click OK. The application closes the Add dialog box and adds the item you added to the Items grid.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
