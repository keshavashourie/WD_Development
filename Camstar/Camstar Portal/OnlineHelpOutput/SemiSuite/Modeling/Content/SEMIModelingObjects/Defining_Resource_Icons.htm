Defining Resource Icons

A Resource Icon is an image that you can use as a symbol on the Resource Layout page to graphically represent a resource.

Before Defining Resource Icons

Icon files may be stored in any sub-folder as long as the sub-folder is located within the Camstar / Camstar Portal directory.

Resource Icon Page Field Definitions

This table defines the fields unique to the Resource Icon page.

Field

Definition

Type

Details

 

 

Icon Filename

Image file name.

Note: This field must be entered despite the fact that it is categorized as optional. Failure to enter the filename will cause a system failure.

Optional

Icon Height

Height of the image sized in pixels. Should be set approximately to 30. The size can be adjusted based on the number of resources on each Layout.

Optional

Icon Width

Width of the image sized in pixels. Should be set approximately to 30. The size can be adjusted based on the number of resources on each Layout.

Optional

How to Define a Resource Icon

Follow these steps to define a Resource Icon:

1. Open the Resource Icon page. The Resource Icon page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the service in the Resource Icon field.
4. Select the icon image file from the Icon Filename field. There may be a delay as the application loads the field list for you to make a selection.
5. Enter Icon Height.
6. Enter Icon Width.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Save. The application saves the modeling object and displays a success message.
