Defining Resource Status Codes

A Resource Status Code provides a description of current availability for a resource. The Resource Status Code page enables you to add and configure these codes.

Resource Status Code Page Field Definitions

This table defines the fields unique to the Resource Status Code page.

Field

Definition

Type

Availability

Availability of the resource associated with this status code:

• Up
• Down

Note: This field appears only in the SM-EL Synergy workspace configuration.

Required

Status Code Behavior

Used by Opcenter EX EL IoT and Opcenter EX EL MM to report on the status of a resource. This field has the following options:

• Not set
• Predefined
• Normal (This is the default.)
• Fixed
• Future

You can set the value to Predefined only if the field is currently blank or contains the value "Not set." You cannot change information for the resource status code when the status code behavior is set to "Predefined." You cannot delete the resource status code unless the status code behavior is blank.

Note: This field appears only in the SM-EL Synergy workspace configuration.

Optional

Resource State

State of the resource associated with this status code:

• Engineering Time
• Nonscheduled Time
• Productive Time
• Scheduled Downtime
• Standby Time
• Unscheduled Downtime

Note: This field appears only in the SM-EL Synergy workspace configuration.

Optional

Resource Status Reason Group

Status reason group containing the status reasons that are valid for this status code.

Note: This field appears only in the SM-EL Synergy workspace configuration.

Optional

Is Available

Check box that can be selected to signify that a resource with the status code is available for lot processing.

Optional

Status Reasons grid

Displays a list of reasons configured for the status code. You can click Add new row on the grid toolbar to add a reason.

Optional

Status Reasons

Displays reasons that have been configured for this resource status code. These reasons will be available for selection when an operator assigns the status code to a resource.

Optional

How to Define a Resource Status Code

Follow these steps to define a Resource Status Code:

1. Open the Resource Status Code page. The Resource Status Code page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the code in the Resource Status Code field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
