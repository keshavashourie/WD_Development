Defining Process Specs and Supplementary Specs

A Process Spec specifies a workflow and step-specific processing for lot manufacturing on the shop floor. A Supplementary Spec references a process spec and enables you to specify additional processing for any of the steps in the referenced process spec. The Process Spec modeling object and the Supplementary Spec modeling object are similarly defined. The links below take you to their respective object definition help pages.
