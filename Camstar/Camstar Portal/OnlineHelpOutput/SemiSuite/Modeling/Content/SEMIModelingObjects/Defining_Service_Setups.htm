Defining Service Setups

Service Setup enables you to configure additional logic for an existing transaction (service). The name of the setup must match the existing transaction name. The LotStart service setup, for example, must be called LotStart.

How to Define a Service Setup

Follow these steps to define a Service Setup:

1. Open the Service Setup page. The Service Setup page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the service in the Service Setup field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
