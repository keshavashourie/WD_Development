Defining Container Dimensions

The Container Dimension page enables you to define a template that identifies where product is located within a container. The template is not active for a product until it is referenced in the definition of the product.

Note: Container dimensions are used by the Multi Level Start page which facilitates Single Wafer Processing.

Container Dimension Page Field Definitions

This table defines the fields on the Container Dimension page.

Field

Definition

Type

X-Dimension

Number of rows where lots can be assigned.

Required

Y-Dimension

Number of columns where lots can be assigned.

Required

Starting X-Y Location

Starting point represented by the row, column (x, y) intersection.

Required

How to Define a Container Dimension Template

Follow these steps to define a Container Dimension template:

1. Open the Container Dimension page. The Container Dimension page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the container dimension template in the Container Dimension field.
4. Enter the X-Dimension.
5. Enter the Y-Dimension.
6. Enter the Starting X-Y Location.
7. Click Save. The application saves the modeling object and displays a success message.
