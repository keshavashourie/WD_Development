Defining Lot Surveillance Requirements

Lot Surveillance requirements enforce data collection for resources, resource groups, operations, and work centers based on lot processing counts. These requirements can be configured with options to set tolerance and warning allowances (in days), and e-mail distribution lists for pending, due, and past due notifications.

Before Defining Lot Surveillance Requirements

Surveillance Reason is a required field on the Lot Surveillance page. Make sure that the necessary surveillance reason has been added to the application before defining a lot surveillance requirement.

Count

Maximum number of lots that can be processed before the lot surveillance requirement becomes due and a Due E-mail is sent. For example, a count of 100 means that 100 lots may be processed before a Due E-mail is sent.

Warning Count

Amount subtracted from Count to determine the warning limit, which is when a Pending E-mail is sent. For example, a Count of 100 and a Warning Count of 5 means that a Pending E-Mail will be sent after 95 lots have been processed.

Tolerance Count

Number added to Count to determine when to send a Past Due E-mail. For example, a Count of 100 and a Tolerance Count of 10 means that a Past Due E-Mail will be sent after 110 lots have been processed.

How to Define a Lot Surveillance Requirement

Follow these steps to define a Lot Surveillance Requirement:

1. Open the Lot Surveillance page. The Lot Surveillance page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the requirement in the Lot Surveillance field.
4. Select a Surveillance Reason.
5. Enter the name of the required data collection in the Data Collection Def field.
6. Enter a Count.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Save. The application saves the modeling object and displays a success message.
Note: Surveillance requirements are activated for resources, resource groups, operations, and work centers using the Surveillance Activation shop floor page.

How to Add a Notification to a Lot Surveillance Requirement

Follow these steps to add a notification to a Lot Surveillance requirement:

1. Perform the "How to Define a Lot Surveillance Requirement" procedure.

Or

Select an existing Lot Surveillance instance.

2. Expand the Notifications section.
3. Click Add new row in the Pending E-mail Target, Due E-mail Target, or Past Due E-mail Target grid. A new row appears.
4. Enter an e-mail notification in the newly added row. The notification is added to the grid.
5. Enter the text for the e-mail in the corresponding Pending E-mail Text, Due E-mail Text, or Past Due E-mail Text field. You also have the option to use text variables.
6. Repeat steps 3-5 to set up notifications for additional recipients.
7. Click Save. The application saves the modeling object and displays a success message.
