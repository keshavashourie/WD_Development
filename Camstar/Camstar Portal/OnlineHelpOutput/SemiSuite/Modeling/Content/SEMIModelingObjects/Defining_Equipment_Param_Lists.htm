Defining Equipment Parameter Lists

Equipment parameters provide details on how to set up equipment. For example, a resource may require a specific recipe or may need to be set to a specific temperature before it is used for lot processing. The Equipment Param List page enables you to define a set of parameters. You can assign a defined parameter list to one or more resources. The application displays the parameter during resource setup.

Before Defining Equipment Param Lists

Any parameters to be selected for an equipment param list must first be defined. Refer to "Defining Param Names."

How to Define an Equipment Param List

Follow these steps to define an Equipment Param List:

1. Open the Equipment Param List page. The Equipment Param List page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the equipment param list in the Equipment Param List field.
4. Add parameters to the Details grid as follows:
a. Click Add new row on the grid. A new row appears.
b. Select a Param Object.
c. Select a Param Name.
d. Repeat steps 2-4 to add additional parameters.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.

How to Assign an Equipment Param List to a Resource

Follow these steps to assign an equipment param list to a resource:

1. Open the modeling page for the resource.
2. Expand the Process Data section. The Process Data fields appear.
3. Select the equipment parameter list from the Parm List field.
4. Click Save. The application saves the modeling object and displays a success message.
