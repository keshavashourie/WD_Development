Defining Attribute Setups

The Attribute Setup page enables you to configure permissible modifications to existing lot and container attributes. It also enables you to create user attributes that will be stored in Lot Attributes Ex without any Designer changes.

How to Define an Attribute Setup

Follow these steps to define an Attribute Setup:

1. Open the Attribute Setup page. The Attribute Setup page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the attribute setup in the Attribute Setup field.
4. Click Add new row on the Details grid. A new row appears.
5. Enter a value in the Attribute Value field.
6. Enter a value to which the attribute can be changed based on the attribute value in the Attribute Revision field.
7. Repeat steps 4-6 to add additional items.
8. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
9. Click Save. The application saves the modeling object and displays a success message.
