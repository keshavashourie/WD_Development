Defining Parts

A part is a physical object that is stored in inventory, used on equipment, and then returned to inventory. An example of a part is a nozzle. Each part added to Opcenter Execution Semiconductor must be associated with a resource material part.

Important: You cannot use the Part page in Modeling to define a part. Use the Part Create page. Navigate to Resource > Part Control > Services > Part Create if you use the default menu configuration. You can also access the Part Create page from the Part Create button available on the Material Parts page and the Part Maintenance page.
