Defining a Factory

A Factory is any division, department, or group that is separated for accounting and reporting purposes. One or multiple factories can be contained within an Enterprise. The Factory page enables you to define a factory.

Note: Refer to the Opcenter Execution Core Modeling User Guide for information on defining a factory.

An increased number of scheduling steps will result in increased scheduling integration run time and may possibly trigger a run-time failure. The application will trigger a warning if the max steps exceeds 40 to minimize impact on transaction performance. This value is pre-populated and must have a value.

How to Define a Factory

Follow these steps to define a Factory:

1. Open the Factory page. The Factory page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the factory in the Factory field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
