Defining WIP Data Setup Objects

Opcenter Execution Semiconductor's factory model can be configured to collect data at certain points during the manufacturing process. This configuration is done using the WIP Data Setup modeling object. After configuration, the setup can be referenced in the WIP Data Setup field during spec and process spec modeling.

Dynamically Calculated Data Collection

A Calculated Data collection is configured with a formula that the application uses during WIP processing to calculate the value. Formulas can include "System Parameter Variables." For example, WD$DATA01 + WD$DATA02 tells the application to add DATA01 to DATA02.

Important: Do not place names in parentheses when creating these formulas. For example, use WD$DATA01 instead of WD$(DATA01).

The table below lists the application parameter variables available for calculated data collection points.

Variable Name

Description

PS$parameter_name

Resolves to the value in the process spec parameter with the matching parameter name.

Note: This parameter must be used within the same step.

WD$data_name

Resolves to the value in the WIP Data Collection parameter with the matching name.

LA$attribute_name

Resolves to the value in the lot attribute with the matching attribute name.

EQ$parameter_name

Resolves to the value in the equipment parameter with the matching parameter name. Applicable for Track In and Track Out only.

Note: This parameter must be used within the same step.

QRY$queryname

Resolves to the result passed back from the query with the matching name (by default, the container and equipment. If available) will be passed to the query which must return a single result.

SPC Setup

SPC Setup assigned to analyze the WIP data collection results.

The WIP Data Setup triggers the SPC analysis process during data collection if at least one WIP data entry has an associated SPC Setup to trigger. If you update the data related to the WIP data collection, the SPC analysis process will only be triggered if the WIP Data Name associated to the SPC Setup was the updated data point. If you want to trigger the SPC analysis whenever any data point is updated, you must assign the SPC Setup to each WIP Data Name to be evaluated by the SPC analysis.

Note: An error will occur if multiple SPC Setups are configured within a WIP Data Setup if the SPC Setups are configured differently. Ensure that they were configured correctly with either Legacy (InLine SPC equals false) or Inline (InLine SPC equals True). Refer to Opcenter Execution Semiconductor Statistical Process Control Reference Guide for information on Inline and Legacy SPC.

How to Define a WIP Data Setup

Follow these steps to create a WIP Data Setup:

1. Open the WIP Data Setup page. The WIP Data Setup page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the setup in the WIP Data Setup field.
4. Perform the following for each data collection point in the Details grid. A data entry window displays for you to create a data collection point.
a. Click Add new row. The application opens the Add pop-up.
b. Select the transaction in the Service Name field.
c. Select the data point name in the WIP Data Name field.
d. Click Is Required if the data must be entered.
e. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
f. Click OK. The application closes the Add pop-up and displays the newly created collection point information in the Details grid. Scroll the grid horizontally to see all of the grid information.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
