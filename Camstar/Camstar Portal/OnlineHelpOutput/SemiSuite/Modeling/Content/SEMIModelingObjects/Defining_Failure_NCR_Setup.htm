Defining Failure NCR Setups

Failure NCR Setups are used to hold the default non-conformance report (NCR) failure information for use when generating NCRs. The application generates NCRs based on specific SPC, WIP data collection, and yield limit failures.

How to Define a Failure NCR Setup

Follow these steps to define a failure NCR Setup:

1. Open the Failure NCR Setup page. The Failure NCR Setup page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the mask layer in the Failure NCR Setup field.
4. Enter the Failure Mode Group that can be assigned to the failure NCR in the Failure Mode Group field.
5. Enter at least one failure mode in the Failure Info grid as follows:
a. Click Add new row. The application adds a blank row to the grid.
b. Enter a failure mode in the Failure Mode field.
c. Repeat steps a-b for every failure mode to add.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
