Defining Test IQC Options

The Test IQC Option page enables you to configure internal quality control testing options.

Test IQC Option Page Field Definitions

This table defines the fields on the Test IQC Option page.

Field

Definition

Type

Details

Auto Select Lots

Check box indicating whether the application should automatically select lots for Test IQC during Lot Receiving.

Optional

Auto Select Lots Alert

Check box indicating whether to alert the user if a lot is selected for Test IQC.

Optional

Variable Data Required

Check box indicating whether Variable Data test is required.

Optional

Incoming Solderability Required

Check box that indicates whether incoming solderability test is required.

Optional

Incoming Solderability Test Type

Indicates the type of solderabililty test required: Valid values are:

1 – Every lot. Each lot received must be tested.

2 – Optional continuous weekly monitoring. Used for manual tracking of testing. The application will not automatically select lots.

Optional

Variable Data Test Type

Specifies the type and frequency of variable data test. Valid values are:

1 – Every lot. Each lot received must be tested.

2 – By Package Type & Shipment Number. The package type and shipment number of each lot received will be used to check for testing up to up to Variable Data Lots Required.

3 – By Month & Package Type. The package type and the calendar month when a lot is received will be used to check for testing up to Variable Data Lots Required.

Optional

Variable Data Lots Required

Number of lots required for Variable Data.

Optional

Variable Data Qty Type

Determines the quantity to be tested. Valid values include:

• % – The percentage of Variable Data Qty Value will be used to indicate the quantity required for testing.
• Units – The value of Variable Data Qty Value will be used to indicate the quantity required for testing.

Optional

Variable Data Qty Value

Value that is used together with Variable Data Qty Type to specify the required quantity for testing. A value of 0 means 100%.

Note: The value informs the user of the quantity to test only. It does not trigger automatic logic.

Optional

VM Required

Optional

How to Define a Test IQC Option

Follow these steps to define a Test IQC Option:

1. Open the Test IQC Option page. The Test IQC Option page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the test IQC option in the Test IQC Option field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
