In-Process Status Change

In-Process status change refers to the ability to change equipment status regardless of whether the equipment is actively processing a lot. You select the In-Process Status Change check box on the Equipment page when you want to permit in-process status changes for the equipment being displayed.

Note: Refer to "Defining Equipment Groups" for information on setting in-process status change at the group level.

About Defining Multi-Chamber Equipment

You can use this modeling object to define multi-chamber equipment. Multi-chamber equipment is defined when you assign child equipment to an equipment modeling object that represents a parent piece of equipment. For example, if a piece of multi-chamber equipment contains the equipment to perform three different processes, you would define the main multi-chamber device as the parent equipment, and the components that perform each process as the child equipment.

Automatic Cascading of Parent Status to Child

Changes to parent equipment status usually cascade down to the child equipment. An exception occurs when a parent is brought down, a child is already down, and then the parent is brought back up. The child will not be brought back up because it was not brought down as a result of the parent.

Bringing Child Status up to Parent

Changes to child equipment status may be brought up to the parent depending upon configuration of the Child Status Combination field for the parent.

For example, assume that parent equipment E100 has two children—E110 and E111. The parent is configured with CH$E110 AND CH$E111 in the Child Status Combination field. This configuration indicates that both E110 and E111 must have the same status for the change in child status to be brought up to the parent. If the shop floor operator sets the status of E110 to DOWN and leaves E111 UP, the parent will not be updated. If the shop floor operator sets both E110 and E111 to DOWN, the parent status will be updated.

Note: In the example, E110, and E111 are logical identifiers of sub-equipment.

How to Define an Equipment

Follow these steps to define an Equipment:

1. Open the Equipment page. The Equipment page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Equipment in the Type Equipment field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
