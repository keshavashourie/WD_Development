Defining Online Query Setups

Online Query Setups are used to view runtime data using the Online Query service.

When Defining Online Query Setups

The Resultset Size Limit field must be used to minimize the impact on memory usage.

Online Query Setup Page Field Definitions

This table defines the fields on the Online Query Setup page.

Field

Definition

Type

Query Definition

Query Text

SQL query statement. The default limit for this field is 4000 characters. This limit can be adjusted in Designer. Refer to the Opcenter Execution Core Designer User Guide for information.

Required

Parameters grid

Grid that defines the parameters of the query. It is defined as a named subentity and the parameter name is unique for each.

Required

User Query Parameter Name

Unique name for the query parameter.

Required

Data Type

Data type of the query parameter. You can choose one of the following:

• Boolean
• Decimal
• Fixed
• Float
• Integer
• Object
• String
• Timestamp

Required

Display Text

Text to display for the parameter when the query is run.

Optional

Param Value

Default value for the parameter.

Optional

Dynamic Value

Value used to resolve to actual value to be used for the query. This field is used by the internal logic where an Online Query Setup is triggered internally by a service. An example would be verification of a Dispatch Plan to see whether a lot is the next lot to proceed with the transaction. The default value is used if this field is not set.

Optional

Is Required

Flag indicating whether the parameter is required.

Optional

Use For Block Rows

Indicates whether the parameter is to be used to fetch block rows. This value is used by the Online Query GUI to automate the Next and Back buttons of fetching the rows.

Note: You can set this flag for only one parameter.

Optional

User Fields

Carrier Col Name

Return column name for the carrier. If not specified, logic that requires it will expect CARRIER to be the value.

Optional

Equipment Col Name

Return column name for the equipment. If not specified, logic that requires it will expect EQUIPMENT to be the value.

Optional

Lot Col Name

Return column name for the lot ID. If not specified, logic that requires it will expect LOT to be the value.

Optional

Resultant Size Limit

Maximum number of records expected. This value is used to limit the number of records returned to minimize the impact on memory usage.

Optional

How to Define an Online Query Setup

Follow these steps to define an Online Query Setup:

1. Open the Online Query Setup page. The Online Query Setup page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the Online Query Setup in the Online Query Setup field.
4. Enter the text of the SQL query statement in the Query Text field.
5. Perform the following to add parameters to the Parameters grid:
a. Click Add new row. The application adds a blank row to the grid.
b. Enter the name for the GUI query parameter in the User Query Parameter Name field.
c. Enter the data type of the GUI query parameter in the Data Type field.
d. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.

How to Test the Query

Follow these steps to test an online query definition:

1. Perform the steps in "How to Define an Online Query Setup."

Or

Select an existing Online Query Setup instance.

2. Click Save And Test Query to save and test the query. The application opens the Online Query Setup Test pop-up.
3. Enter any parameters required by the query.
4. Click Test Query. Any results matching the query and parameters entered are displayed in the Query Results grid.
5. Click Close. The Online Query Setup Test pop-up closes.
