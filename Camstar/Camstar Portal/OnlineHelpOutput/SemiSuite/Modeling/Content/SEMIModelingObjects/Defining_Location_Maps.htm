Defining Location Maps

A Location Map is used to map a location to a workflow and workflow step.

How to Define a Location Map

Follow these steps to define a Location Map:

1. Open the Location Map page. The Location Map page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the location map in the Location Map field.
4. Enter the workflow in the Workflow field.
5. Enter the name of the step in the Workflow Step field.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
