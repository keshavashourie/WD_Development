Defining Schedule SS Plans

Schedule SS Plans are used as a reference to modify the currently assigned configuration related to a lot schedule. The contents of the Schedule SS Plan are copied over and the user can modify the schedule if required during Lot Schedule and Lot Schedule Modify transactions.

Schedule SS Plans require the following in this order:

1. Supplementary workflow. A Type Workflow that contains those additional steps for the schedule, where Type indicates the corresponding schedule type of the workflow. Refer to "Defining Workflows" for information on workflows.
2. Supplementary spec. A Type Supplementary Spec that contains the required workflow for the schedule, where Type indicates the corresponding schedule type of the supplementary spec or overrides any part of the base Process Spec. Refer to "Defining Supplementary Specs" for information on supplementary specs.

Move Out From Spec (From Process Spec)

Spec within the process spec workflow from which the lot will leave to go to the spec specified in Move Out To Spec (To SS). Note the following:

• An in-transit spec cannot be selected as a Move Out From Spec.
• One Inventory Spec can be selected as a Move Out From Spec. This is to allow the lot to directly move to the SS instead of going to the Process Spec first and then to the SS.
• Only one supplementary details record is allowed to specify an Inventory Spec as the Move Out From Spec.

WIP or Scheduled Spec within the supplementary spec workflow from which the lot will move back to the process spec. This field is optional since the logic allows the lot to complete in the supplementary spec. However, this field is required if a Move Back To Spec is specified.

WIP or Scheduled Spec within the process spec workflow to which the lot will move from the supplementary spec workflow. This field is required if Move Back From Spec is specified.

How to Define a Schedule SS Plan

Follow these steps to define a Schedule SS Plan:

1. Open the Schedule SS Plan page. The Schedule SS Plan page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the schedule SS plan in the Schedule SS Plan field.
4. Perform the following in the Details grid for every supplementary spec to add:
a. Click Add new row. The application adds a blank row to the grid.
b. Enter the supplementary step in the Supplementary Spec field.
c. Enter the starting process spec in the Move Out From Spec (From Process Spec) field.
d. Enter the destination spec in the Move Out To Spec (To SS) field.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
