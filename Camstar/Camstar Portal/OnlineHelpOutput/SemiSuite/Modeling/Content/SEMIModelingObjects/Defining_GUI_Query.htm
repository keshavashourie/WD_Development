Defining GUI Queries

GUI Queries are used to fetch information about things such as lots and equipment for display purposes during a transaction. The GUI Query is a predefined query stored as instance data. Note that while the query definition is defined as instance data; the query itself can be used to retrieve information from either instance data tables or metadata tables.

The Parameter grid is implemented as a persistent list so that the parameter sequence is automatically maintained by the corresponding persistent list table.

GUI Query Requirements

Writing GUI queries requires that you be familiar with the Object Model, understand SQL syntax, and have experience writing SQL queries. You must also understand the end user requirements so that your queries will present the right kind of information on the user interface.

After the queries are created and tested, they must be called by the custom application. You can do this through Opcenter Execution Semiconductor Services API calls (WSQuery) or through a custom execution.

How to Define a GUI Query

Follow these steps to define a GUI Query:

1. Open the GUI Query page. The GUI Query page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the name of the GUI Query in the GUI Query field.
4. Enter the text of the SQL query statement in the Query Text field.
5. Perform the following to add parameters to the Parameters grid:
a. Click Add new row. The application adds a blank row to the grid.
b. Enter the name for the GUI query parameter in the User Query Parameter Name field.
c. Enter the data type of the GUI query parameter in the Data Type field.
d. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
