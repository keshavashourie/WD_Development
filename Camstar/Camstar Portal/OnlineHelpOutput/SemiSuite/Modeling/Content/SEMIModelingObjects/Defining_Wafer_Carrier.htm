Defining Wafer Carriers

You define Wafer Carrier modeling objects to specify the carriers (for example, cassettes, trays, and so on) that store, transport, and handle the wafers during manufacturing transactions. Wafer Carrier objects can support one or more lots.

To specify the number of slots for the Wafer Carrier, you must first define a Wafer Carrier Family object. You can then specify the Wafer Carrier Family to use while defining the Wafer Carrier.

You must also specify a Wafer Carrier object to use the assign slot map function. The assign slot map function enables you to map specific wafers to a particular position (or slot) in the Wafer Carrier. Refer to "Defining Wafer Carrier Families" for information on Wafer Carrier Family objects. Refer to Opcenter Execution Semiconductor Shop Floor Guide for information on the assign slot map function.

How to Define a Wafer Carrier

Follow these steps to define a Wafer Carrier:

1. Open the Wafer Carrier page. The Wafer Carrier page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a unique name for the Wafer Carrier object in the Wafer Carrier field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
