Defining Cycle Time Holidays

Cycle time refers to the estimated number of days for WIP processing workflow completion. Cycle Time Holidays are used to offset the estimated end date when calculating Lot Schedule end date cycle time.

Cycle Time Holiday Page Field Definitions

This table defines the fields unique to the Cycle Time Holiday page.

Field

Definition

Type

Details

Day Factor

Number of days to use as an offset when calculating the cycle time end date. Must be zero or one.

Required

Holiday Date

Date holiday begins.

Required

Workflow Object Type

Type of workflow processing for which this cycle time holiday will be used to calculate a processing end date.

Required

How to Define a Cycle Time Holiday

Follow these steps to define a Cycle Time Holiday:

1. Open the Cycle Time Holidays page. The Cycle Time Holidays page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Cycle Time Holidays in the Cycle Time Holidays field.
4. Enter a Day Factor.
5. Enter the Holiday Date.
6. Enter the Workflow Object Type.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Save. The application saves the modeling object and displays a success message.
