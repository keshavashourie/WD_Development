Defining Exp Special Check Sheets

The Exp Special Check Sheet modeling object enables you to specify the check sheet to use when an experiment is enabled at a particular transaction. Exp Special Check Sheet objects override the Check Sheet Matrix object.

Note: Check sheets are also referred to as electronic procedures. Refer to the Opcenter Execution Core Modeling User Guide for information on electronic procedures.

Exp Special Check Sheet Page Field Definitions

This table defines the fields on the Exp Special Check Sheet page.

Field

Definition

Type

Details

Check Sheet Details grid

Details of the experiment special check sheet defined by the transaction type and electronic procedure.

Optional

Transaction Type

Specifies whether the check sheet should be used for the Track In, Track Out, or Move Out transaction.

Note: Because the application does not support electronic procedures prior to the Move In transaction on the container, you cannot configure check sheets for use by Move In transactions.

Required

Electronic Procedure

Name given to a series of tasks required to complete the work required.

Note: The application uses the revision of record by default if you do not specify a revision.

Required

Failure Action

Failure action for the check sheet. You can choose one of the following:

• Proceed. Indicates that the transaction should proceed in the event of a check sheet failure.
• Blocked. Indicates that the transaction should be blocked in the event of a check sheet failure. When the transaction is blocked, the application does not move the lot to the next transaction and displays an error message indicating that the transaction has been blocked.

Required

How to Define an Exp Special Check Sheet

Follow these steps to define an Exp Special Check Sheet:

1. Open the Exp Special Check Sheet page. The Exp Special Check Sheet page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Exp Special Check Sheet object in the Exp Special Check Sheet field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
