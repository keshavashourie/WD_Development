Defining Exp Special Instructions

The Exp Special Instructions modeling object displays WIP instructions for an experiment lot when it reaches the specified transaction in a step. You can specify messages for the Move In, Track In, Track Out, and Move Out transactions.

How to Define an Exp Special Instructions Instance

Follow these steps to define Exp Special Instructions:

1. Open the Exp Special Instructions page. The Exp Special Instructions page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the experiment special instructions object in the Exp Special Instructions field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
