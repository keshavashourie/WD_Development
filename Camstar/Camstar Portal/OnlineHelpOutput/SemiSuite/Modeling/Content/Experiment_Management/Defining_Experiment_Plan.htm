Defining Experiment Plans

The Experiment Plan defines a series of actions that override the default Process Spec behavior to perform on an experiment lot. You create an experiment lot when you use the Lot Assign Experiment page to attach the Experiment Plan to a lot. Refer to the Opcenter Execution Semiconductor Shop Floor Guide for information on the Lot Assign Experiment page.

When Approving Experiment Plans

When you create an Experiment Plan, the application sends an e-mail to a review and approve group. Members of that group then must approve the plan before the Experiment Plan can be attached to lots. You cannot attach an Experiment Plan to lots until the status of the Experiment Plan is set to Approved.

The following list describes each step in the Experiment Plan approval process:

1. Draft - The Experiment Plan is new or is an existing Experiment Plan that was rejected and changed. You must set the status to Draft when the Experiment Plan is first saved. Experiment plans with this status can be modified.
2. Review - The Experiment Plan is ready for review. When you change the status from Draft to Review and save the Experiment Plan, the application notifies the review and approve group specified in the Review and Approve Group field. The members of the review and approve group open the Experiment Plan, review it, and then set the status to either Approved or Rejected.
3. Rejected - If the review and approve group rejects the Experiment Plan, it must be changed before it can be implemented. When the review and approve group changes the status to Rejected, the application notifies the owner employee group specified in the Owner Employee Group field, who then makes necessary changes. After the Experiment Plan is changed, it receives a status of Draft and the Experiment Plan begins the approval process again.

Prerequisites

Before defining Experiment Plans, you should define one or more of the following modeling objects to add to steps in the Experiment Plan as required by your business:

• Exp Auto Hold - Refer to "Defining Exp Auto Hold Objects" for information.
• Exp Auto Split - You can configure multiple Auto Splits at the same step or spec. Refer to "Defining Exp Auto Splits" for information.
• Exp Auto SS - Refer to "Defining Exp Auto SS Objects" for information.
• Exp Special Check Sheet - Refer to "Defining Exp Special Check Sheets" for information.
• Exp Special Instructions - Refer to "Defining Exp Special Instructions" for information.

Experiment Plan Status

Current status of the Experiment Plan. The Experiment Plan must go through the approval process in the following order:

1. Draft – The Experiment Plan is new or was rejected and changed.
2. Review – The Experiment Plan is ready for review. When you change the status from Draft to Review, the application notifies the review and approve group specified in the Review and Approve Group field.
3. Rejected – The Experiment Plan is rejected and must be changed. When you change the status to Rejected, the application notifies the owner employee group specified in the Owner Employee Group field. After the Experiment Plan is changed, the owner employee group changes the status to Draft.

4. Approved – The Experiment Plan is approved and can be attached to lots. When you change the status to Approved, the application notifies the owner employee group specified in the Owner Employee Group field. You cannot modify Experiment Plans with an approved status.

Important: When you set an Experiment Plan to Approved, you cannot make any further changes. All fields are set to read-only. However, if the Experiment Plan is not yet attached to a lot, you can mark the Experiment Plan as Rejected, save it, make the required changes, and set the status to Draft. If an approved Experiment Plan is attached to a lot, you cannot make changes even if you detach it from the lot. How to Define an Experiment Plan

Follow these steps to define an Experiment Plan:

1. Open the Experiment Plan page. The Experiment Plan page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the following required information:
• Experiment Plan
• Revision
• Experiment Plan Status
• Owner Employee Group
• Process Spec
• Review and Approve Group
4. Perform the following in the Experiment Plan Details grid for every action you want to add to the Experiment Plan:
a. Click Add new row. The application opens the Add pop-up.
b. Enter the information in the Add pop-up according to your business requirements. Refer to Experiment Plan Add Pop-Up Field Definitions" for information on the fields.
c. Click OK.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
