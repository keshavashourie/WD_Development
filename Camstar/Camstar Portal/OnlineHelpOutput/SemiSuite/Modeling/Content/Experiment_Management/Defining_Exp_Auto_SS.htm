Defining Exp Auto SS Objects

The Exp Auto SS (experiment auto supplementary spec) modeling object specifies the supplementary spec plan to attach to a lot when it arrives at a WIP step.

Keep the following points in mind while defining an Exp Auto SS object:

• Before you define an Exp Auto SS object, you must define a Schedule SS Plan object. Refer to "Defining Schedule SS Plans" for information.
• When creating or starting a lot, do not select the Auto Prepare check box. Refer to the Opcenter Execution Semiconductor Shop Floor Guide for information on the Auto Prepare option in lots.

How to Define an Exp Auto SS

Follow these steps to define an Exp Auto SS:

1. Open the Exp Auto SS page. The Exp Auto SS page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Exp Auto SS object in the Exp Auto SS field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
