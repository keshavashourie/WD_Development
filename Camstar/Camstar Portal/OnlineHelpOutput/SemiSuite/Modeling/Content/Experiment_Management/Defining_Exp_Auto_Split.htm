Defining Exp Auto Splits

The Exp Auto Split modeling object defines the way in which wafers in a lot should be split for an Experiment Plan. When executed, Experiment Plans with Exp Auto Splits specified cause lots to be split as defined by the Exp Auto Split configuration.

If you are splitting the lot by items (wafers), you must use the Assign Carrier Slot Map page to assign the wafers in the experiment lot to slots in the wafer carrier before you track in experiment lots with auto split steps specified. Refer to the Opcenter Execution Semiconductor Shop Floor Guide for information on the Assign Carrier Slot Map page.

If you are splitting the lot by quantity (non-items lots), a carrier is not required.

When Defining Exp Auto Splits

Experiment plans allow for multiple splits within the same step for most split types. You can perform multiple splits on only the following split types:

• Bottom N
• By Slot
• By Qty
• First Half
• Last Half
• Split Fixed Qty
• Top N

The following rules apply when performing multiple splits:

• You cannot perform multiple splits for Even or Odd split types or any combination that includes an Even or Odd split type. For example, you cannot perform a multiple split using the Bottom N and Even split type.
• You cannot combine the following split types with the By Qty split type in multiple splits:
• Bottom N
• First Half
• Last Half
• Top N
• You must ensure that you do not attempt to split a lot more times than the quantity will allow when using multiple splits. For example, if you split a lot with a Qty of 500 using a Split Fixed Qty split type and a Split Qty value of 250, you cannot perform another split with the same value.

Exp Auto Split Page Field Definitions

This table defines the fields on the Exp Auto Split page.

Field

Definition

Type

Details

Split Type

Type of split to perform. Options include:

• Bottom N – Splits the bottom N number of wafers to the child lot. If you select this option, you must set a value for the Wafer N Count field.
• By Slot – Splits wafers by carrier slot numbers list to the child lot. If any slots are empty, the application ignores the slot. You must set a value for the Slot Numbers field if you select this option.
• Even – Splits even numbered wafers to the child lot.
• First Half – Splits the first half of the wafers to the child lot.
• Last Half – Splits the last half of the wafers to the child lot.
• Odd – Splits odd numbered wafers to the child lot.
• By Qty – Splits a fixed quantity of the lot to a child lot. You must set a value for the Split Qty field if you select this option. This option is for use with quantity-based lots only.
• Equal – Splits the quantity of the lot and the child lot equally. This option is for use with quantity-based lots only.
• Top N – Splits the top N number of wafers to child lot. If you select this option, you must set a value for the Wafer N Count field.

Required

Wafer N Count

Number of wafers to split.

Note: This field is required if Split Type is set to Top N or Bottom N.

Optional

Slot Numbers

Comma-delimited list of carrier slot numbers to be split.

Note: This field is required if Split Type is set to By Slot.

Optional

Split Qty

Fixed split qty for a specific Split Type. Enabled when Split Type is set to By Quantity.

Note: This field is required if Split Type is set to By Quantity.

Optional

Future Combine Spec

Spec to use to combine the lots.

Optional

Action Plan After Split

Lot that will inherit the Experiment Plan after the split. Allow selection values:

• Both – Both the parent and child lots will carry the Experiment Plan.
• Parent Only – Only the parent lot will carry the Experiment Plan.
• Child Only – Only the child lot will carry the Experiment Plan.

Optional

Comments

Comments to be used for split transaction in the auto split action.

Optional

How to Define an Exp Auto Split

Follow these steps to define an Exp Auto Split:

1. Open the Exp Auto Split page. The Exp Auto Split page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the experiment auto split object in the Exp Auto Split field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
