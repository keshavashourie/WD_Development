Defining a WIP Data Setup Matrix

The WIP Data Setup matrix is used to resolve the WIP Data Setup that will collect data for lots during the following transactions:

• Track In
• Track Out
• Move Out
• Complete Insertion

When the WIP Data Setup matrix is defined and the Use WIP Data Setup Matrix check box is selected in the WIP Spec, the application determines the WIP Data Setup to use through the highest matching algorithm based on the search criteria defined in the matrix. The resulting WIP Data Setup will override any WIP Data Setup configured at the spec or process spec layer but not WIP Data Setups assigned within Experiment Plans. Refer to "Defining WIP Specs" for information on WIP Specs.

When Defining WIP Data Setup Matrix Objects

Remember the following points when the matrix object uses WIP Step Workflow to define a step in the workflow as one of the criteria:

• Deleting a step from the workflow referenced in the matrix object will render that particular matrix entry invalid.
• Editing a step in the workflow referenced in the matrix object does not render that particular matrix entry as invalid unless the step is removed and then re-entered.

You can define a Numbering Rule object to automatically name the matrix object. The application will then populate the Name field automatically when you save the instance. Refer to "Using Numbering Rules to Name Instances Automatically" for information on using numbering rules to name matrix object instances.

Note: You must click Save on the WIP Data Setup Matrix page for the application to load new changes made on other pages. For example, if you made changes on WIP Data Name, WIP Data Setup, or any modeling instances that are related to WIP Data Setup Matrix entries or grid, it is required to save the matrix page to load the new information.

How to Define a WIP Data Setup Matrix Instance

Follow these steps to define a WIP Data Setup Matrix:

1. Open the WIP Data Setup Matrix page. The application displays the WIP Data Setup Matrix page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Click the Add button on the right-command bar. Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select an existing row instance from the page's grid. Click the Edit button on the right-command bar to display Edit pop-up page. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter a name for the instance in the WIP Data Setup Matrix Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
4. Enter the WIP Data Setup to resolve in the WIP Data Setup field.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.

How to Edit WIP Data Setup Matrix Details

Follow these steps to edit WIP Data Setup Matrix Details:

1. Select the WIP Data Setup Details grid row.
2. Click Edit button on the right-command bar. The Edit pop-up appears.
3. Scroll down the pop-up until the editable fields are in view.
4. Select or enter changes.
5. Click Save. The application saves the modeling object and displays a success message.
