Defining a Scanning Setup Matrix

Scanning Setup used to set up the scanning requirements.

When Defining a Scanning Setup Matrix

You can define a Numbering Rule object to automatically name the matrix object. The application will then populate the Name field automatically when you save the instance. Refer to "Using Numbering Rules to Name Instances Automatically" for information on using numbering rules to name matrix object instances.

How to Define a Scanning Setup Matrix

Follow these steps to define a Scanning Setup matrix:

1. Open the Scanning Setup page. The application displays the Scanning Setup page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit and existing instance. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter a name for the Scanning Setup matrix instance in the Scanning Setup Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
4. Enter the Service Name to which the instance applies in the Service Name field.
5. Enter the Spec to which the instance applies in the Spec field.
6. Perform the following for every process spec collection bin in the Details grid:
a. Click Add new row.
b. Enter a scanning name to use in the Scanning Name field.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Save. The application saves the modeling object and displays a success message.
