Defining a Scheduling Matrix

A Scheduling Matrix determines scheduling behavior for lots that meet the criteria specified in the matrix. The Scheduling Matrix modeling page enables you to view, create, and update Scheduling matrices. The Scheduling Matrix is available if you have Scheduling installed on your Opcenter Execution Semiconductor server.

Note: Refer to "About Matrix Modeling Objects" and "Matrix Modeling Pages" for general information on matrix objects. Refer to "Managing Instances" for information on managing matrix object instances.

How to Define a Scheduling Matrix

Follow these steps to define a Scheduling Matrix:

1. Open the Scheduling Matrix page. The application displays the Scheduling Matrix page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit and existing instance. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter a name for the matrix instance in the Scheduling Matrix Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application saves the modeling object and displays a success message.
