Matrix Modeling Definitions

Matrix objects enable you to define alternate WIP processing as well as the criteria for when the alternate processing should be applied.

Note: Matrix modeling objects were referred to as Setup B objects in Semiconductor Suite Version 6 SU1 and earlier.
