Defining a Recipe Matrix

The recipe matrix modeling object specifies an alternate recipe to use when the specified lot meets the defined criteria.

When Defining Recipe Matrix Objects

In order to define a recipe matrix object, you must first create one or more recipe modeling objects. Refer to "Defining Recipes" for information on recipe modeling objects.

Remember the following points when the matrix object uses WIP Step Workflow to define a step in the workflow as one of the criteria:

• Deleting a step from the workflow referenced in the matrix object will render that particular matrix entry invalid.
• Editing a step in the workflow referenced in the matrix object does not render that particular matrix entry as invalid unless the step is removed and then re-entered.

You can define a Numbering Rule object to automatically name the matrix object. The application will then populate the Name field automatically when you save the instance. Refer to "Using Numbering Rules to Name Instances Automatically" for information on using numbering rules to name matrix object instances.

How to Define a Recipe Matrix

Follow these steps to define a Recipe Matrix:

1. Open the Recipe Matrix page. The application displays the Recipe Matrix page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Click the Add button on the right-command bar. Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select an existing row instance from the page's grid. Click the Edit button on the right-command bar to display Edit pop-up page. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter a name for the Recipe matrix instance in the Recipe Matrix Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
4. Enter a recipe in the Recipe field.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
