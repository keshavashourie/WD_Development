About Matrix Modeling Objects

The application uses matrix modeling objects to determine the behavior of lots that match the criteria defined by the object. You use matrix modeling objects to specify limits, restrictions, and other conditions on lots as they move through the manufacturing process. During the production process, the application evaluates the specified criteria to dynamically determine courses of action based on context.

For example, the WIP Instructions matrix modeling object allows you to configure a message to be displayed to the operator based on a set of criteria, such as spec and owner. In this case, you could configure the application to warn the operator when engineering lots move to a specific inventory step.

Note: Matrix modeling objects were referred to as Setup B objects in Semiconductor Suite Version 6 SU1 and earlier.
