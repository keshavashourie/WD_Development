Defining a Send Ahead Matrix

A Send Ahead Matrix determines processing behavior for lots that meet the criteria specified in the matrix. The Send Ahead Matrix page enables you to view, create, and update Send Ahead matrices. Refer to "About Matrix Modeling Objects" or "Matrix Modeling Pages" for general information on matrix objects. Refer to "Managing Instances" for information on managing matrix object instances.

When Defining Send Ahead Matrix Objects

When you configure a Send Ahead process flow, you need to know your factory's business decision regarding whether to combine the Send Ahead lot back with the mother lot. If the lots are to be combined, you will need to select a Future Combine Spec when defining the Send Ahead Matrix.

Remember the following points when the matrix object uses WIP Step Workflow to define a step in the workflow as one of the criteria:

• Deleting a step from the workflow referenced in the matrix object will render that particular matrix entry invalid.
• Editing a step in the workflow referenced in the matrix object does not render that particular matrix entry as invalid unless the step is removed and then re-entered.

You can define a Numbering Rule object to automatically name the matrix object. The application will then populate the Name field automatically when you save the instance. Refer to "Using Numbering Rules to Name Instances Automatically" for information on using numbering rules to name matrix object instances.

How to Define a Send Ahead Matrix

Follow these steps to define a Send Ahead Matrix:

1. Open the Send Ahead Matrix page. The application displays the Send Ahead Matrix page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit and existing instance. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter the spec to which the matrix instance applies in the Spec field.
4. Enter a name for the matrix instance in the Send Ahead Matrix Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
5. Select the spec that will be used as the Block spec from the Block Spec field.
6. Select the spec that will be used as the Validation spec from the Validation Spec field.
7. Select the name of the WIP Data Setup that will be used in the Validation Spec.
8. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
9. Click Save. The application saves the modeling object and displays a success message.
