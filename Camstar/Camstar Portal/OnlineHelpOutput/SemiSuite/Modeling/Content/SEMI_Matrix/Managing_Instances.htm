Managing Instances

After creating instances of matrix objects, the matrix modeling object pages provide options that enable you to save new instances from existing instances or to delete, view the transaction history, or perform other actions for existing instances. This section describes the following actions you can perform on matrix object pages:

• Save - This option enables you to save a new instance or save the changes to an edited instance.
• Save As New - This option enables you to change details about an existing instance and then save it as a new instance.
• View Audit - This option enables you to view the transaction history for an instance. The transaction history is the record of all changes made to the instance starting at the time the object was created.
• Delete - This option enables you to delete an instance.
• Reload - This option discards all changes made to the currently selected instance.
• Clear -This option clears all values in the Criteria and Details areas for the new instance you are defining. The application resets the page to its initial state on page load or the last save action you performed.

When you save an edited instance as a new instance, keep in mind that each instance requires the following:

• A unique name. If you do not specify a name and there is a Numbering Rule object modeled for the matrix object, the application will automatically name the instance according to the numbering scheme specified by the numbering rule object. Refer to "Using Numbering Rules to Name Instances Automatically" for information on using numbering rules to name matrix object instances.
• Unique criteria. Each instance must be defined by its own set of criteria.

How to Save an Edited Instance as a New Instance

Follow these steps to save an existing instance as a new instance:

1. Open the matrix modeling page. For example, Equipment Matrix.
2. On the page that opens, enter the criteria in the fields provided, and click under the Selection grid. The application displays the instances that match the specified criteria.
3. In the Selection grid, click in the row that contains the instance. The application populates the Criteria and Details areas with the specific information from that instance.
4. Make changes to the selected instance.
Important: You must change both the name and the criteria set. Failure to change the instance in this way will result in an error and the application will not save the instance.
5. Click Save as New. The application saves the instance as a new instance with the name and criteria you specified. The application preserves the instance you modified with its original values. If you did not specify a name and you are using a numbering rule object to name the matrix object, the application generates a unique name for the instance as specified by the numbering rule object.

How to View the Transaction History for the Instance

Follow these steps to view the transaction history for the instance:

1. Open the matrix modeling page. For example, Equipment Matrix.
2. On the page that opens, enter the criteria in the fields provided, and click under the Selection grid. The application displays the instances that match the specified criteria.
3. In the Selection grid, click in the row that contains the instance. The application populates the Criteria and Details areas with the specific information from that instance.
4. Click View Audit. The application opens the Modeling Audit Trail dialog which displays the following details of the instance:

Column

Definition

Txn Date

Date and time the transaction described in the row occurred.

User

User name of the user who performed the transaction.

Execute Action

Transaction performed. Possible values are Add and Update.

Comments

Comments about the action, if provided. This field is unavailable.
5. If you want view transactions that occurred during a specific date range, use the date pickers in the Return Results between fields and click Go. Refer to the Opcenter Execution Core Getting Started User Guide for information on using the date picker to select dates.
6. If you want to see the details for a specific transaction, click . The application displays the following details of the transaction:

Column

Definition

Item

Field name that was changed.

Name

If available, this specifies the name of the object. Populated only for some objects.

Before

Value of the field before the change was saved. This is empty for the Add execute action.

After

Value of the field after the change was saved.

Action

Action taken against the field.

• Update indicates that the value of the field was updated.
• Create indicates that the value of the field was added for the first time.
• Delete indicates that the value of the field was deleted.
7. Click Close. The application closes the Modeling Audit Trail dialog.

How to Delete an Instance

Follow these steps to delete an instance:

Important: You cannot recover deleted instances.
1. Open the matrix modeling page. For example, Equipment Matrix.
2. On the page that opens, enter the criteria in the fields provided, and click under the Selection grid. The application displays the instances that match the specified criteria.
3. In the Selection grid, click in the row that contains the instance. The application populates the Criteria area with the specific information from that instance.
4. Click Delete. The application deletes the instance.

How to Reload an Instance

You can reload instances when you have made changes but have not yet saved the changes.

Important: When you reload the instance, the application discards all changes made to the currently selected instance. All changes made since the previous save action are lost.

Follow these steps to reload an instance:

1. Open the matrix modeling page. For example, Equipment Matrix.
2. On the page that opens, enter the criteria in the fields provided, and click under the Selection grid. The application displays the instances that match the specified criteria.
3. In the Selection grid, click in the row that contains the instance. The application populates the Criteria area with the specific information from that instance.
4. Click Reload. The application resets the fields to the last saved values.

How to Clear the Fields for the Instance

Follow these steps to clear the fields for an instance:

1. Open the matrix modeling page. For example, Equipment Matrix.
2. On the page that opens, enter the criteria in the fields provided, and click under the Selection grid. The application displays the instances that match the specified criteria.
3. In the Selection grid, click in the row that contains the instance. The application populates the Criteria area with the specific information from that instance.
4. Click Clear. The application removes the values from all fields on the matrix page.
