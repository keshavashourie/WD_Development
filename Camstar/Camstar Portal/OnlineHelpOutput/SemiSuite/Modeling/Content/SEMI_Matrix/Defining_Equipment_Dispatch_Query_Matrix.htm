Defining an Equipment Dispatch Query Matrix

The Equipment Dispatch Query matrix object is used to maintain the instances of the various dispatch queries and resolve dispatch queries that are displayed on the Equipment WIP Tracking page. Refer to the Opcenter Execution Semiconductor Shop Floor Guide for information.

Sample Dispatch Query

Opcenter Execution Semiconductor provides a sample Dispatch Query in either SEMI 0205 GUI Control - GUI Query (for Oracle Portal) or SEMI 0205 GUI Control - GUI Query (for SQL Portal). The sample query returns all lots at all specs. You must replicate and modify the supplied query to limit the query results based on equipment usage within the Factory.

When Defining an Equipment Dispatch Query Matrix

You can define a Numbering Rule object to automatically name the matrix object. The application will then populate the Name field automatically when you save the instance. Refer to "Using Numbering Rules to Name Instances Automatically" for information on using numbering rules to name matrix object instances.

How to Define an Equipment Dispatch Query Matrix

Follow these steps to define an Equipment Dispatch Query Matrix:

1. Open the Equipment Dispatch Query page. The application displays the Equipment Dispatch Query page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit and existing instance. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter a name for the equipment dispatch query matrix instance in the Equipment Dispatch Query Matrix Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
4. Enter a dispatch query in the Dispatch Query field.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
