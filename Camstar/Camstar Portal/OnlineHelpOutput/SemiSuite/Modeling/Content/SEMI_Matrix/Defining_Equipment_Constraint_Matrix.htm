Defining an Equipment Constraint Matrix

An Equipment Constraint matrix enables you to configure criteria for equipment to control which lots the equipment may Track In. The application checks the equipment selected for Track In and executes a constraint matrix if one is configured for the equipment.

When Defining Constraint Expressions

You can add multiple constraint expressions to the Equipment Constraint Details grid.

Note: You can define a Numbering Rule object to automatically name the matrix object. The application will then populate the Name field automatically when you save the instance. Refer to "Using Numbering Rules to Name Instances Automatically" for information on using numbering rules to name matrix object instances.

How to Define an Equipment Constraint Matrix

Follow these steps to define an Equipment Constraint Matrix:

1. Open the Equipment Constraint page. The application displays the Equipment Constraint page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit and existing instance. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter a name for the check sheet matrix instance in the Equipment Constraint Matrix Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
4. Click Add new row on the Equipment Constraint Details grid and perform the following:
a. Enter an action that the application should take at Track In in the Action field.
b. Enter an expression that defines the constraint in the Expression field.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
