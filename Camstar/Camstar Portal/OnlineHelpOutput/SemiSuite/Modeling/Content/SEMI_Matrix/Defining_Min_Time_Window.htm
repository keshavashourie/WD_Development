Defining a Min Time Window Matrix

The Min Time Window matrix is used to specify the minimum required time duration is enforced between Track In Lot and Track Out Lot. The time window is started when the lot tracks in and verified during track out.

When Defining Min Time Window Matrix Objects

Remember the following points when the matrix object uses WIP Step Workflow to define a step in the workflow as one of the criteria:

• Deleting a step from the workflow referenced in the matrix object will render that particular matrix entry invalid.
• Editing a step in the workflow referenced in the matrix object does not render that particular matrix entry as invalid unless the step is removed and then re-entered.

You can define a Numbering Rule object to automatically name the matrix object. The application will then populate the Name field automatically when you save the instance. Refer to "Using Numbering Rules to Name Instances Automatically" for information on using numbering rules to name matrix object instances.

Beforetime Action

Action to take if the lot is tracked out before the Min Time. Valid values include:

• Not Allowed (default) – The lot is not allowed to track out before the Min Time.
• Hold – The lot will be put on hold if it is tracked out before the Min Time.
• Warning – An alert message will be returned if the lot is tracked out before the Min Time.

The action to take if the lot is tracked out after the Min Time plus the Overtime Frame. Valid values include:

• HOLD – The lot will be put on hold if any failures are detected. The application will not process any transactions on the lot.
• WARNING – The application issues a warning if any failures are detected, but will continue to process transactions on the lot.

Required

Overtime Frame (Minutes)

The time frame after Min Time the lot is allowed to track out. If the lot is tracked out after the Min Time plus the Overtime Frame, the lot is considered failed overtime.

How to Define a Min Time Window Matrix

Follow these steps to define a Min Time Window matrix:

1. Open the Min Time Window page. The application displays the Min Time Window page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit and existing instance. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter a name for the Min Time Window matrix instance in the Min Time Window Setup Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
4. Enter the number of hours after the lot tracks in before it is allowed to track out in the Min Time (Hours) field.
5. Enter the action to take on the lot in the event that the time window is exceeded in the Overtime Action field.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
