Defining a Max Time Window Matrix

The Max Time Window matrix is used to specify that a lot does not violate the maximum time duration between two steps. The time window is started when the lot tracks out from the required Start Spec and verified through WIP Main when the lot is selected at the required Stop Spec.

When Defining Max Time Window Matrix Objects

If the matrix object uses Start Step Workflow or Stop Step Workflow to define a step in the workflow as one of the Criteria, and the step is deleted or edited, any existing matrix objects that are linked to the step become invalid.

You can define a Numbering Rule object to automatically name the matrix object. The application will then populate the Name field automatically when you save the instance. Refer to "Using Numbering Rules to Name Instances Automatically" for information on using numbering rules to name matrix object instances.

How to Define a Max Time Window Matrix

Follow these steps to define a Max Time Window Matrix:

1. Open the Max Time Window page. The application displays the Max Time Window page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit and existing instance. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter a name for the Max Time Window matrix instance in the Max Time Window Setup Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
4. Enter the spec that marks the beginning of the time duration in the Start Spec field.
5. Enter the spec that marks the end of the time duration in the Stop Spec field.
6. Enter maximum amount of time for the time window in the Max Time (Hours) field.
7. Enter the action to take on the lot in the event that the time window is exceeded in the Overtime Action field.
8. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
9. Click Save. The application saves the modeling object and displays a success message.
