Defining a Service Attrs Setup Matrix

Service Attrs Setup is a matrix object that enables you to define attributes for a service (also called a transaction) that meets the matrix criteria. You use the Service Attrs Setup page to configure an instance of this object.

When Defining a Service Attrs Setup Matrix

You can define a Numbering Rule object to automatically name the matrix object. The application will then populate the Name field automatically when you save the instance. Refer to "Using Numbering Rules to Name Instances Automatically" for information on using numbering rules to name matrix object instances.

How to Define a Service Attrs Setup Matrix

Follow these steps to define a Service Attrs Setup matrix:

1. Open the Service Attrs Setup matrix page. The application displays the Service Attrs Setup matrix page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit and existing instance. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Select a service (transaction) from the Service Name field in the Criteria section.
4. Enter a name for the instance in the Service Attributes Setup Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
5. Click Add new row on the Details grid. The Add pop-up appears.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click OK. The pop-up closes and the select attribute appears in the Details grid.
8. Repeat steps 5-7 to select and configure additional attributes.
9. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
10. Click Save. The application saves the modeling object and displays a success message.
