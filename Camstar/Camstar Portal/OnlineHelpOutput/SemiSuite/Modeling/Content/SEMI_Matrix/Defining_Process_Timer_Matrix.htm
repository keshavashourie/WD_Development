Defining a Process Timer Matrix

The Process Timer matrix enables you to specify process timers and their associated start and end transactions to be used when a lot meets the criteria specified in the matrix.

When Defining a Process Timer Matrix

A process timer is added to a spec. You can specify within the spec a WIP Main transaction that should trigger the timer (a start transaction) and a WIP Main transaction that should stop the timer (an end transaction). The Process Timer Matrix page contains two grids—one for adding timers that start when specific transactions occur and one for adding timers that end when specific transactions occur.

How to Define a Process Timer Matrix

Follow these steps to define a Process Timer Matrix:

1. Open the Process Timer Matrix page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit and existing instance. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter a name for the process timer matrix instance in the Process Timer Matrix Name field.
4. Enter at least one entry in the Start Timer Txn Map grid and one entry in the End Timer Txn Map grid.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
