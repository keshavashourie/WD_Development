Defining a Quantix Integration Matrix

Quantix provides Semiconductor Test analytics software to identify product quality issues not detected through standard tests. The Quantix Integration Matrix automates and enhances data collection for Semiconductor Test operations including:

• Raw test results
• Equipment process time data
• Analytical results
• Failure flags

Quantix analysis searches for marginal products, yield, bin, and parametric data trends for events, identifying issues of quality or reliability not seen during raw test operations.

Note: The Quantix Integration Matrix works slightly different than the typical Semiconductor Matrix. Generally, when a record is retrieved from the Matrix, the configured details of the matrix will override the configuration of all related lower objects such as Process Spec. In the Quantix Integration Matrix, the Matrix controls the execution of multiple process tests and the application will continue to evaluate the configuration of the Process Spec.

For example, if the Process Spec is configured for PAT and the Matrix is configured for SYA, the application will evaluate the Matrix at WIP Main and identify that SYA is required. Even if BIN, PAT, SPM, or OEE are not configured, the application will still review the Process Spec and detect the PAT is required as well.

If PAT, SYA, SPM, or OEE recipes are configured on the Matrix and on the Process Spec, the Matrix value will be utilized.

When Defining Quantix Integration Matrix Objects

Remember the following points when the matrix object uses WIP Step Workflow to define a step in the workflow as one of the criteria:

• Deleting a step from the workflow referenced in the matrix object will render that particular matrix entry invalid.
• Editing a step in the workflow referenced in the matrix object does not render that particular matrix entry as invalid unless the step is removed and then re-entered.

How to Define a Quantix Integration Matrix

Follow these steps to define a Quantix Integration Matrix:

1. Open the Quantix Integration Matrix page. The application displays the Quantix Integration Matrix page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit and existing instance. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter the Quantix Integration details to which the matrix applies in the related fields under the Details section.
4. Enter a name for the Quantix Integration matrix instance in the Quantix Integration Matrix Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
5. Click Save. The application saves the modeling object and displays a success message.
