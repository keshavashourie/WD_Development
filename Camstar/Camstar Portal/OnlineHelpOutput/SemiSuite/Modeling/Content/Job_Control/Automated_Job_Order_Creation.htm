Automated Job Creation

Two areas of Opcenter Execution Semiconductor can be configured for automatic job creation:

• Maintenance Management
• Status Model

Maintenance Management

Opcenter Execution Semiconductor’s Maintenance Management feature enables you to define and track resource maintenance requirements. The Maintenance Class Activation and Resource Activation transactions enable you to assign these requirements to resources. The requirements are tracked and enforced during the execution of shop floor services.

Date, Recurring Date, Thruput, and Usage modeling objects can be configured to include an associated job model. When the application executes a maintenance requirement that is configured with a job model, it automatically creates a job based on that job model. Refer to "Maintenance Management Introduction" for information.

Status Model and Set Status Transaction

The Status Model object enables you to configure valid "From Status/To Status" resource status change combinations. Each status combination can be configured with a Reason. Each reason can be associated with two options:

• Auto Job Create Job Model
• Auto Job Create Precondition

When the Set Status transaction executes a status model configured with a job model, it creates a job based on that job model.
