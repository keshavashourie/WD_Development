Defining Sampling Information for WIP Data Setup Objects

The Sampling Information section of the WIP Data Setup page enables you to create sample tests, which are then grouped to create sample plans. The Sampling Information section of the WIP Data Setup page is for use with AQL Sampling only. Refer to "Defining WIP Data Setup Objects" for details about other sections of the WIP Data Setup page.

Sampling Test Types

The two sampling test types are counted and measured. A counted sample test enables you to record the number of samples tested and the number of rejected samples. Opcenter Execution Semiconductor then uses the sum of all recorded quantities as the total number of rejects.

A measured sample test enables you to enter one or more sample data point values that are evaluated against limits. When a sample data point falls outside of the specified limits, the sample is rejected. You must configure one or more sample data points for measured test types depending on the minimum sample requirement.

You collect sampling values for both counted and measured samples through the Sampling tab on WIP Main. Refer to the Opcenter Execution Semiconductor Shop Floor Guide for information on collecting AQL sampling values.

Managing Samples and Recorded Rejects

Semiconductor Shop Floor provides two further options for managing samples and recorded rejects: Destructive Sample Reason and Scrap Rejects Default Reason. The Destructive Sample Reason causes the application to reduce the lot size or wafer quantity by the sample quantity. The Scrap Rejects Default Reason causes the application to reduce the lot size or wafer quantity only by the quantity recorded as defective. The number of rejected samples will only be scrapped against the Scrap Rejects Default Reason selected in the WIP Data Setup if a Destructive Sample Reason is not provided.

Note: You should not set a Destructive Sample Reason if you are performing lot based sampling at an item step.

You can decrease lot and wafer quantities by sample size (when Destructive Sample Reason is set), decrease the lot by reject count (when Scrap Rejects Default Reason is set), and automatically create a production event in the case of a failure for both counted and measured test types.

If rejects are to be scrapped, select a loss reason from the Scrap Rejects Default Reason field. The sample is rejected if any of the values falls outside the defined limits for measured samples. If you are performing destructive tests, select a reason from the Destructive Sample Reason field.

When Defining Sampling Information

These rules apply when defining Sampling Information for WIP Data Setup objects:

• You can perform lot-based sampling for lots at both item processing steps and non-item processing steps.
• You can perform wafer-based sampling only on lots at item processing steps.
• You must perform sampling at a non-item processing step if you want to decrease your lot sizes by the sample quantity or the number of rejects recorded.
• You must perform sampling at an item processing step if you want to decrease the quantity of each wafer by the sample quantity or the number of rejects recorded.
• You cannot perform sampling on both lots and wafers at the same step.

These rules are not enacted if a sample test is updated after the sampling requirements are determined and written to the lot. Lots in process do not pick up any revision updates, but the revisions are applied to the next lot. When determining the sample size and allowable rejects for a sample test, the lot’s current quantity is used by default, but you can specify that the original lot quantity be used instead.

How to Define Sampling Information for WIP Data Setup Objects

Follow these steps to define sampling information for WIP Data Setup objects:

1. Open the WIP Data Setup page. The WIP Data Setup page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter information for the WIP Data Setup object as described in "Defining WIP Data Setup Objects."
4. In the Sampling Information area, enter the sample test type to associate to the sampling plan in the Sample Type field as follows:

Select . . .

To collect the . . .

Counted

Number of rejected samples.

Measured

Numeric value for each data point.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
