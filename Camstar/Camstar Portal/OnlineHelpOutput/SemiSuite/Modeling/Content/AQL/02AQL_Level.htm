Defining AQL Levels

The AQL Level page enables you to define acceptable quality levels by associating a sample size and rejection quantity to a sample size code. The AQL Level sample size codes must match those defined by the Inspection Level objects. Refer to "Defining Inspection Levels" for information on specifying sample size codes in Inspection Level objects.

Note: The quantities apply to wafers (the container's Qty2) when a lot is at a wafer processing step (Is Item Processing is selected on the Spec).
Note: The application ignores the rejection quantity (Rejection Number field) when creating an AQL Level for wafer selection because the primary purpose is to identify the number of wafers to sample within the lot.

When Defining AQL Levels

These rules apply when modeling AQL Level modeling objects:

• The AQL Level page must include at least one item in the Details grid when modeling the AQL Level.
• The AQL Level sample size codes must match the sample size codes defined by the Inspection Level instances. Refer to "Defining Inspection Levels" for information.

How to Define an AQL Level

Follow these steps to define an AQL Level:

1. Open the AQL Level page. The AQL Level page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the AQL Level object in the AQL Level field. For example, AQL0.25 or AQL1.5.
4. Enter the AQL level details in the Sample Size Details grid as follows:
a. Click Add new row. The application adds a blank row to the grid.
b. Enter the sample size code this AQL level in the Sample Size Code column.
c. Enter the sample size required for the sample size code in the Sample Size column. The Sample Size must be equal to the number of data collection points defined in the Details grid of the WIP Data Setup object. Refer to "Defining WIP Data Setup Objects" for information on the Details grid.
d. Enter maximum allowable reject quantity for the defined sample size in the Rejection Number column. The application rejects lots whose defects are greater than this number.
Note: The application ignores this value if the AQL Level is being used in the wafer selection process.
e. Repeat steps a-d for each AQL Level you want to add.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
