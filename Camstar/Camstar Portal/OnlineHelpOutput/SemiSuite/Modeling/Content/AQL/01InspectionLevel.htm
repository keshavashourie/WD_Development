Defining Inspection Levels

Inspection Level modeling objects establish sample size codes based on a minimum and maximum container or lot size.

By default, the application uses the current quantity when determining sample size and allowable rejects. If the Sample Size Based on Start Qty field of the Sampling Plan is selected, the application bases the quantity of the lot on Qty and Qty2 as specified when the lot was originally started. The application uses the specified Sample Size Code defined by the Inspection Level when a lot's quantity falls between the minimum and maximum (Min. Qty and Max. Qty, respectively) specified for the code.

The AQL Level modeling object uses the Rejection Number and the Sample Size Code defined in the Inspection Level object to define the acceptable quality levels for a lot. Refer to "Defining AQL Levels" for information on the AQL Level modeling object and Rejection Number.

How to Define an Inspection Level

Follow these steps to define an Inspection Level:

1. Open the Inspection Level page. The Inspection Level page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Inspection Level instance in the Inspection Level field. For example Level I or Level II.
4. Enter the inspection level details in the Lot Size Details grid for each sample size you want to add to the Inspection Level object as follows:
a. Click Add new row. The application adds a blank row to the grid.
b. Enter the minimum lot quantity for the sample size code in the Min. Qty column.
c. Enter the maximum lot quantity for the sample size code in the Max Qty column.
d. Enter a sample size code to identify the sample size that corresponds to the minimum and maximum lot quantities in the Sample Size Code column.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
