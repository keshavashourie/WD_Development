Defining a Sampling Plan Setup Matrix

The Sampling Plan Setup matrix page is used to override the Sampling Plan object assigned to a given product. Refer to "About Matrix Modeling Objects" or "Matrix Modeling Pages" for general information on matrix objects. Refer to "Managing Instances" for information on managing matrix object instances.

How to Define a Sampling Plan Setup Matrix Instance

Follow these steps to define a Sampling Plan Setup matrix instance:

1. Open the Sampling Plan Setup page. The application displays the Sampling Plan Setup page.
2. Perform one of the procedures as indicated in the following table:

To define . . .

Perform the following . . .

A new instance

Specify settings in the Criteria area. Refer to the field definitions table for information on the available fields.

An instance using an existing instance

Select and edit and existing instance. Refer to "How to Save an Edited Instance as a New Instance" for instructions.
3. Enter a name for the Sampling Plan Setup matrix instance in the Sampling Plan Setup Name field. If you do not specify a name and there is a numbering rule object modeled for this matrix object, the application populates this field automatically when you save the instance.
4. Enter the Sampling Plan object to apply to the lot in the Sampling Plan field. When selected, the Sampling Plan data is required in WIP for lots that conform to the defined criteria. Enter the revision in the box under this field if applicable. Click the check box if the object should use the revision of record.
Note: You must select a spec for every sample test in the Sampling Plan Details section if a default spec is not selected.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Save. The application saves the modeling object and displays a success message.
