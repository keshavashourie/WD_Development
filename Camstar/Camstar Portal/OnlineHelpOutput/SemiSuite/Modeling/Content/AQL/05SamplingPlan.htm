Defining Sampling Plans

The Sampling Plan page is used to organize the sampling activity for a lot. Updates made to Sample Plans do not affect lots in that are currently in WIP, but the revisions are applied to the next lot.

Sampling Rate

A sampling rate must be defined for either the entire sample plan or each sample test. The sampling rate is a number that specifies the sampling frequency as every number lots. For example, if the sampling frequency is represented by the N variable, N=1 is every lot, N=2 is every other lot, N=3 is every third lot, and so on. A sampling plan can be overridden to enforce 100% inspection (sample rate=1), which means every lot requires sampling.

Maximum Duration

Using the Sample Rate Max Duration field to define a maximum duration ensures that only lots produced within the maximum duration time frame are included when determining if sampling is required based on the sampling rate. The sampling counter is reset to prevent large time lapses from affecting the frequency of sampling when the maximum duration is exceeded by all relevant lots.

For example, every 10th lot is being inspected, but production stops at lot 5. One month later production starts again. Since the maximum duration is set at 15 days, the lot count is now outdated so the application resets back to 1 and starts again. The 10th lot is inspected, instead of the 5th, which would have been inspected had the counter not restarted. This process ensures that lots that are far apart chronologically are not compared to one another.

When Defining Sampling Plans

These rules apply when modeling the Sampling Plan:

• A value in the Details grid overrides the default value defined in the Processing section.
• The default sampling test values apply globally to every sample test unless preempted by the values specific to a particular sample test in the Details grid.
• Either the default field in the Processing section or the same-named field in the Details grid must be populated for these required fields:
• Spec
• AQL Level
• Inspection Level
• Sample Rate
• Either the default field in the Processing section or the same-named field in the Details grid may be populated for the Switching Rule.

Sample Size Based on Start Qty

Indicates that the sample size is based on the lot’s start quantity rather than the lot’s current quantity. If the required sample number exceeds the lot’s current quantity, the entire lot is sampled.

AQL Level

List of all AQL levels. If an AQL level is selected, this sample test is required at the selected AQL level. This value works with the Inspection Level to determine the minimum sample requirement based on type as follows:

• Counted – Determines the total number of samples required for the lot based on Container Qty or the total samples required per wafer based on NDPW.
• Measured –Determines the number of measurements required for the lot or the number of measurements required per wafer.

This AQL level applies to all sample tests unless preempted by a corresponding AQL Level value in the Sampling Plan Details grid.

Note: If a default AQL Level is not specified, then an AQL Level must be selected for every sample test in the Sampling Plan Details grid.

Inspection Level

List of all inspection levels. If an inspection level is selected, this sample test is required at the selected inspection level. This value works with the AQL Level to determine the minimum sample requirement based on type as follows:

• Counted – Determines the total number of samples required for the lot based on Container Qty or the total samples required per wafer based on NDPW.
• Measured –Determines the number of measurements required for the lot or the number of measurements required per wafer.

This inspection level applies to all sample tests unless preempted by a corresponding Inspection Level value in the Sampling Plan Details grid.

Note: If you do not specify a default Inspection Level, then you must select an Inspection Level for every sample test in the Sampling Plan Details grid.

Required

Switching Rule

List of all switching rules. If a switching rule is selected, this sample test is required at the selected switching rule.

This switching rule applies to all sample tests unless preempted by a Switching Rule value in the Sampling Plan Details grid.

The revision indicator goes in the box under this field if applicable. The check box indicates that this revision is the revision of record.

Optional

Sample Rate

This sample rate applies to all sample tests unless preempted by a Sample Rate value in the Sampling Plan Details grid. This field defaults to 1 if not populated.

1 indicates that every lot is sampled. 2 indicates that every second lot is sampled. 3 indicates that every third lot is sampled. The pattern continues with 4, 5, 6, 7, and so on.

Note: When the step is configured for Item Processing, the application sets this to 1. You cannot override this value.

Optional

Sample Rate Max Duration

Maximum number of days since the last sample test before the sample rate is reset.

Optional

Switching Rule Max Duration

Maximum number of days since the last sample test before the switching rule is reset. After completing the sample after the maximum days is reached, the Switching Rule will be evaluated to determine whether a change is necessary.

How to Define a Sampling Plan

Follow these steps to define a Sampling Plan:

1. Open the Sampling Plan page. The Sampling Plan page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter a name for the Sampling Plan object in the Sampling Plan field.
4. Enter the revision, or version, of the instance in the Revision field. The application uses both the name and revision to identify the definition.
5. Enter the sampling plan test data in the Sampling Plan Details grid as follows:
a. Click Add new row. The application opens the Add pop-up.
b. Enter the sample test to add to the sampling plan in the WIP Data Setup field. The sample test is created through the WIP Data Setup page. Refer to "Defining Sampling Information for WIP Data Setup Objects" for information.
c. Enter the spec where sampling is to occur in the Spec field.
d. Enter the AQL levels where sampling is to occur in the AQL Level field.
e. Enter the inspection level where sampling is to occur in the Inspection Level field.
f. Enter optional information according to your business requirements. Refer to "Sampling Plan Optional Add Pop-up Field Definitions" for information on the optional fields.
g. Click OK.
h. Repeat steps a-g for each sampling plan test you want to add.
Note: The values of the fields in the Add pop-up override the values set for the corresponding fields on the Sampling Plan page. For example, the Spec field on the Add pop-up overrides the value for the Spec field on the Sampling Plan page.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Save. The application saves the modeling object and displays a success message.
