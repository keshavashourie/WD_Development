Getting Started with AQL Sampling

AQL Sampling requires some changes to the default data model. This section summarizes things to keep in mind when using Opcenter Execution Semiconductor AQL Sampling.

Note: Wafer WIP Data Sampling will take precedent over AQL Sampling. If the existing default AQL Sampling and the new Wafer WIP Data Sampling are configured at the same step, only Wafer WIP Data Sampling will be performed. You may need to check if there is any configuration of Wafer WIP Data Sampling prior to executing AQL Sampling. Refer to "Defining Wafer WIP Data Sampling" for information.

Before Implementing AQL Sampling in Opcenter Execution Semiconductor

Consider the following configuration options before implementing AQL Sampling in your factory:

• Determine the inspection and AQL levels to use while determining the sample size and reject levels or number of wafers to sample.
• Decide whether a lot’s original or current quantity will be used to determine the sample size.
• Decide whether sample tests will be measured or counted.
• Identify the data points that will be collected for measured sample tests.
• Identify the limits at which the sample test fails for a measured sample test.
• Identify the reject categories to be collected for counted sample tests.
• Decide whether AQL Sampling will be allowed to automatically switch inspection levels based on failure rate and established switching rules.
• Determine switching rules that decide whether to move a sampling plan from one inspection level to another.
• Determine the sampling rate to use.
• Decide how far back in time to go when determining when the cutoff date for including past information in order to determine whether switching rules should apply. AQL Sampling calls this practice Maximum Duration. Refer to "Defining Sampling Plans" for information.

Assumptions and Limitations

The following assumptions and limitations apply to the AQL Sampling module:

• Only Track In, Track Out, and Move Out transactions are supported.
• Only one instance of WIP Data Setup Sampling Information can be used for each specification within a configured Sampling Plan.
• The assigned WIP Data Setup for sampling should be limited to a specific service: either Track In, Track Out, or Move Out.

Modeling Requirements

Opcenter Execution Semiconductor AQL Sampling uses these objects that are specific to or customized for AQL Sampling:

• Inspection Levels
• AQL Levels
• WIP Data Name
• WIP Data Setup
• Switching Rules
• Sampling Plans
• Products (PNs)
• Sampling Plan Setup matrix objects

AQL samples are collected using the Sampling tab on the WIP Main page in OPcenter EX SM Portal. Refer to the Opcenter Execution Semiconductor Shop Floor Guide for information.
