Assigning Sampling Plans to Products

The PN object enables you to assign a sampling plan to a product. The two fields that are specific to AQL Sampling, Sampling Plan and 100% Inspection, assign a sampling plan and indicate whether all lots are to be sample tested.

Note: The application ignores the AQL Sampling values of the PN object if a Sampling Plan Setup matrix is defined.

When Defining the PN Object for AQL Sampling

The Sampling Plan field is required if the optional 100% Inspection Required field is checked.

PN Page Sampling Field Definitions

This table defines the fields relevant to AQL Sampling on the PN page. Refer to "Defining PN and Material Part Products" for information on other fields available in the PN modeling object.

Field

Definition

Type

Sampling Plan

List of all defined sampling plans. Sampling plans define the inspection criteria for the product, such as the sample test required, number of samples, sample rate, where to sample, and the allowed rejects for a container of this product. Select the sampling plan to assign to the product. Refer to "Defining Sampling Plans" for information on sampling plans.

The revision indicator goes in the box under this field if applicable. The check box indicates that this revision is the revision of record.

Note: This field is required if the 100% Inspection Required check box is selected.

Optional

100% Inspection Required

When selected, the sample rate is set to 1, which indicates that every lot of this product is to be inspected.

This option is usually engaged when a production run is having quality issues to minimize losses or when a new product is going into production to verify that everything is set up properly.

Note: A sampling plan is required if this check box is selected.

Optional

How to Define a PN Modeling Object for AQL Sampling

Follow these steps to define a PN modeling object for AQL Sampling:

1. Open the PN page. The PN page appears within the Modeling page.
2. Click New. Blank fields appear for you to define a new instance.
3. Enter the sampling plan to assign to the product in the Sampling Plan field.
4. Select the 100% Inspection Required option if you want every lot to be inspected.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields. Refer to "Defining PN and Material Part Products" for information on the available fields.
6. Click Save. The application saves the modeling object and displays a success message.
