Configuring Industry Solutions

The Industry Solutions Configuration Tool enables you to configure the workspaces necessary to run the industry solution features that includes the Overall Equipment Effectiveness (OEE) feature.

Before Configuring Industry Solutions

A DataStore database must be configured if you are installing OEE. Refer to the Opcenter Execution Core System Administration Guide for information on DataStore databases.

How to Configure Industry Solutions

Follow these steps to configure industry solutions:

1. Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.
2. Expand the Solutions folder in the Sites tree and select the Industry Solutions Configuration node. The Industry Solutions Configuration Tool dialog box appears.
3. Select OEE feature to be installed and the installation type.
4. Click Finish. The DataStore Database Details dialog box appears.
5. Enter the Database Name.
6. Enter the Server Name.
7. Enter the Port Number.
8. Enter the Database Username.
9. Enter the Database Password.
10. Click Next. The Confirm Installation dialog box appears indicating the install type, selected feature workspaces, and the DataStore database details.
11. Click OK. The tool verifies that the connection to the DataStore database is successful. Configuration of the workspace starts. A progress bar appears on the Industry Solutions Configuration Tool dialog box. The Replacement and Application Install dialog box appears when the process finishes.
12. Click OK. The End of Install dialog box appears.
13. Click OK. The Industry Solutions Configuration Tool closes.
Note: Run the "SEMI 0201 GUI Control - Portal Menu Definition Setup (Multi Level).xlsm" to add Opcenter Execution Semiconductor OEE UI menu.
