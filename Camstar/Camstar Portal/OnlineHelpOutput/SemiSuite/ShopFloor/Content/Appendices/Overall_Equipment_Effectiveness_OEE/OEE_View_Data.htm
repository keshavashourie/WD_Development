Viewing OEE Data

You can use the OEE Indicator page to view OEE data for either a selected resource (equipment) or for all resources in a specified resource (equipment) family. Clicking the Load Data button displays OEE data for the selected resource (equipment) family or resource.

OEE Indicator Page Field Definitions

This table defines the fields on the OEE Indicator page.

Field

Definition

Type

Resource (Equipment) Family

List of available resource (equipment) families.

Optional

Resource (Equipment)

List of resources (equipment) associated with the selected resource (equipment) family.

Optional

Timespan

Timespan of calculated OEE data. Options include:

• Shift - Displays OEE data calculated for the current shift.
• Day - Displays OEE data calculated beginning with the first shift of the day as defined on the resource, factory, or manufacturing calendar.

Optional

Custom

Check box indicating the application will display OEE data between times specified in the Start Time and End Time fields.

Optional

Start Time

Specified start time for the calculation of OEE data.

Optional

End Time

Specified end time for the calculation of OEE data.

Optional

How to View OEE Data for a Resource (Equipment) Family

Follow these steps to view OEE data for a resource (equipment) family:

1. Open the OEE Indicator page from the Resource menu. The OEE Indicator page appears.
2. Select a Resource Family from the list.
3. Do you want to display the data based on a time span or on custom parameters?

If . . .

Then . . .

Time span
a. Select a Timespan from the list.
b. Go to step 4.

Custom parameters
a. Select the Custom check box.
b. Select a start time in the Start Time field.
c. Select an end time in the End Time field.
d. Go to step 4.
4. Click Load Data. The application displays a horizontal bar chart with OEE data for all resources associated with the selected resource (equipment) family.

How to View OEE Data for a Resource (Equipment)

Follow these steps to view OEE data for a resource (equipment):

1. Open OEE Indicator page from Resource menu. The OEE Indicator page appears.
2. Select a Resource Family from the list. The application populates the Resource field with a list of resources associated with the selected resource (equipment) family.
3. Select a Resource from the list.
4. Do you want to display the data based on a time span or on custom parameters?
5. Click Load Data. Application displays a horizontal bar chart with OEE data for resource (equipment).

If . . .

Then . . .

Time span
a. Select a Timespan from the list.
b. Go to step 5.

Custom parameters
a. Select the Custom check box.
b. Select a start time in the Start Time field.
c. Select an end time in the End Time field.
d. Go to step 5.
