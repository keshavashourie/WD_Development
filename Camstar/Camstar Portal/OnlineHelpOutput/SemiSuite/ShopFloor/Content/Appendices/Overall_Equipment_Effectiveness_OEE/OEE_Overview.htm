Overall Equipment Effectiveness Overview

Note: The functionality described below is available only when the Industry Solutions workspace is installed. Refer to the Opcenter Execution Core Industry Solutions User Guide for information.

Overall Equipment Effectiveness (OEE) evaluates how effectively manufacturing equipment is performing. OEE represents the true productive time for an equipment relative to its actual capacity. An OEE of 100% means that the equipment is producing only good-quality output with no downtime as fast as that equipment can produce. Manufacturers can use OEE data to improve operations and optimize the capacity of available equipment.

OEE consists of these elements:

• Availability
• Performance
• Quality

The formula for calculating OEE is the product of these elements:

OEE = Availability * Performance * Quality

The OEE data is captured during the TrackOutLot and LotReject transactions in Opcenter Execution Semiconductor. During processing, the application stores the data necessary to calculate OEE in the database in tables. These tables facilitate OEE calculations and provide the ability to analyze each element of OEE.

Note: The OEE in Opcenter Execution Semiconductor is the adaptation from the Opcenter Execution Core base feature. In Semiconductor the following terms carry the same meaning:
• Resource is equivalent to Equipment
• Resource Family is equivalent to Equipment Family
