Create Carrier Container with "scsCarrierPositionAssign" Service

Carrier Containers can be created at an automation service called "scsCarrierPositionAssign" when a container is assigned to a carrier or transferred from another carrier. When a carrier container is created by the “scsCarrierPositionAssign” service, the applicationdetermines whether the following details are included in the XML request: Carrier Start Reason, Carrier Owner and Carrier Level. These values will be used to create the carrier containers.

<scsCarrierStartReason><__name><![CDATA[Carrier Start Reason]]></__name></scsCarrierStartReason>

<scsCarrierOwner><__name><![CDATA[Carrier Owner]]></__name></scsCarrierOwner>

<scsCarrierLevel><__name><![CDATA[Carrier Level]]></__name></scsCarrierLevel>


If these values are not passed in with the request XML, the application evaluates the Shop Floor Integration Settings fields in the carrier family of the carrier. If the settings are configured, the Start Reason, Owner, and Level in the settings will be then used to start a carrier container, else the application will use the Start Reason, Owner, and Level from the first assigned container.

To summarize the priority, the application will use the Start Reason, Owner and Level from:

1. Automation level (script)
2. Shop Floor Integration Settings field specified in the Carrier Family
3. The first assigned container

Carrier Position Assign Automation Service

Sample of Carrier Container Creation with Assigned Container to a Carrier

The code below shows the sample of carrier container creation when container is assigned to a carrier.


<__InSite __version="1.1" __encryption="3">

<__service __serviceType="scsCarrierPositionAssign">

<__utcOffset><![CDATA[-05:00:00]]></__utcOffset>

<__inputData>

<Carrier>

<__name><![CDATA[Carrier Name]]></__name>

</Carrier>

<scsCarrierStartReason>

<__name><![CDATA[Carrier Start Reason]]></__name>

</scsCarrierStartReason>

<scsCarrierOwner><__name><![CDATA[Carrier Owner]]></__name></scsCarrierOwner>

<scsCarrierLevel><__name><![CDATA[Carrier Level]]></__name></scsCarrierLevel>

<Details>

<__listItem>

<Container>

<__name><![CDATA[Child Container Name]]></__name>

</Container>

<PositionLevel><![CDATA[Child Position Level]]></PositionLevel>

<PositionNumber><![CDATA[Child Position Number]]></PositionNumber>

<PositionStatus><![CDATA[Child Position Status]]></PositionStatus>

<SetupAction><![CDATA[0]]></SetupAction>

</__listItem>

</Details>

</__inputData>

<__execute>

</__execute>

<__requestData>

<CompletionMsg>

</CompletionMsg>

</__requestData>

</__service>

</__InSite>

</TransferCarrier>
