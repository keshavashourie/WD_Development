Carrier Unload Automation Service

Containers can be unload from a carrier at automation layer using a service called "scsCarrierPositionAssign". You may either unload specified containers, or unload all containers from a carrier. To unload specified containers, you must specify the container name as well as the carrier name. To unload all containers from carrier, you may speficy the carrier name ans set Unload to True.

You are not required to specify any Slot Position information during the unloading process. The application will automatically identify and resolve the related slot position.

Note: It is important to enter the right container name during the unloading process, if it is not unload all. The application will prompt an error if container is not found in the carrier.

Sample to Unload Specified Containers from a Carrier

The code below shows a sample of unloading specified containers from a carrier. You must provide the carrier name <Carrier>, container name <Container __CDOTypeName="Lot"> and specify the Setup Action for Load (specify "0" ) and Unload (specify "1").

<__InSite __version="1.1" __encryption="3">

<__service __serviceType="scsCarrierPositionAssign">

<__utcOffset><![CDATA[-05:00:00]]></__utcOffset>

<__inputData>

<Carrier>

<__name><![CDATA[Carrier Name]]></__name>

</Carrier>

<CloseCarrierContainer><![CDATA[false]]></CloseCarrierContainer>

<Details>

<__listItem>

<Container __CDOTypeName="Lot">

<__name><![CDATA[Container Name]]></__name>

</Container>

<SetupAction><![CDATA[1]]></SetupAction>

</__listItem>

</Details>

<UnloadAll><![CDATA[false]]></UnloadAll>

</__inputData>

<__execute>

</__execute>

<__requestData>

<CompletionMsg>

</CompletionMsg>

</__requestData>

</__service>

</__InSite>

 

Sample to Unload All Containers from a Carrier

The code below shows the sample of unloading all containers from a carrier. You must provide the carrier name ans set the Unload All to True.

<__InSite __version="1.1" __encryption="3">  

  <__service __serviceType="scsCarrierPositionAssign">        

<__utcOffset><![CDATA[-05:00:00]]></__utcOffset>        

<__inputData>  

          <Carrier>                

<__name><![CDATA[Carrier Name]]></__name>            

</Carrier>  

          <CloseCarrierContainer><![CDATA[false]]></CloseCarrierContainer>  

          <UnloadAll><![CDATA[true]]></UnloadAll>        

</__inputData>        

<__execute>        

</__execute>

      <__requestData>  

          <CompletionMsg>  

          </CompletionMsg>  

      </__requestData>

</__service>

</__InSite>
