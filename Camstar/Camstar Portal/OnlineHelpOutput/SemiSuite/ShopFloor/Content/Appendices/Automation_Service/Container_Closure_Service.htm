Container Closure Automation Service

Containers can be closed using automation service called "scsDBContainerClosure" by just providing the container name. In a situation where you need to close multiple container, the automation service will help to find the parent container to disassociate during the container close transaction.

Container Closure Automation Service

Sample of Container Closure

The code below shows the sample of container closure. You may provide the container name that you want to close at the ContainerNamesStr.

<__InSite __version="1.1" __encryption="2">

<__service __serviceType="scsDBContainerClosure">

<__utcOffset><![CDATA[-04:00:00]]></__utcOffset>

<__inputData>

<ContainerNamesStr><![CDATA[%TID%ALOT001 - 01|%TID%ALOT001 - 02|%TID%ALOT001 - 03|%TID%ALOT001 - 04|%TID%ALOT001 - 05|%TID%ALOT001 - 06|%TID%ALOT001 - 07|%TID%ALOT001 - 08|%TID%ALOT001 - 09|%TID%ALOT001 - 10]]></ContainerNamesStr>

<scsAutoFindParentContainer><![CDATA[true]]></scsAutoFindParentContainer>

<TerminateReason>

<__name><![CDATA[Customer]]></__name>

</TerminateReason>

</__inputData>

<__execute>

</__execute>

<__requestData>

<CompletionMsg>

</CompletionMsg>

<ACEMessage>

</ACEMessage>

<ACEStatus>

</ACEStatus>

</__requestData>

</__service>

</__InSite>
