Request Generated Container Names using "scsDBContainerName" during a HPE Start Service

The "scsDBContainerName" service provides a method to request for container names during the creation of containers via an automation layer. When containers are created using Numbering Rules, identification of the created containers' names might be tricky. This automation service helps to retrieve the container names created by including "scsDBContainerName" in the request script. The container names will then be provided by the application via the response script. This service can be applied when you are creating containers in Work Order Dispatch (HPE) or Lot Start - Bulk (HPE).

Refer to the following sample for request and response script.

Sample of scsDBContainerName used in Lot Start - Bulk (HPE)

The following script shows a sample of request XML to create Individual Container using the Lot Start - Bulk (HPE) page. In this sample, "scsDBContainerName" is added to the request the list of the created container names.

You may customize the criteria to create the containers. For example, the criteria used in the following sample is set as follows:

• scsAutoNumber = True
