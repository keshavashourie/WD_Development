Multi-Lots Modify Attributes (HPE) Service

Multi-Lots Modify Attributes (HPE), or scsDBMultiLotsModifyAttrs is a service that is used to update multiple attributes for one or more lots. To perform the updates, you may provide the following details:

• Container Name (Required)
• Attribute Name (Required)
• Attribute Value (Required)
• Attribute Revision (Only Required for RDO)
• ServiceAttrsModifyAttrsReason (Optional)
• ServiceAttrsRequestForm (Optional)
• ServiceAttrsRequestor (Optional)

Attribute updates can also be applied to child lots by adding the following script:

<scsApplyToChildLots><![CDATA[true]]></scsApplyToChildLots>

The application will update lot attributes based on the provided fields in the transaction.

This table defines the fields for the request code sample above.

Field

Definition

Input Data

ServiceAttrsDetails

Contains container name and list of scsAttrDetails that is going to be utilized on the respective container update.

scsContainerName

Name of the container.

scsAttrDetails

This field contains list of AttributeName, AttributeValue and AttributeRevision that is going to be updated to the specified container. Attribute data will then be used to update the lot’s attributes.

Request Data

CompletionMsg

Request of completion status.

ServiceAttrsModifyAttrsReason

Reason for the attribute modification.

Note: This field is required for any attribute that been modified with Require Modify Attrs Reason flag set to true.

ServiceAttrsRequestForm

Field used for reporting purposes

ServiceAttrsRequestor

Field used for reporting purposes.
