Load Containers with "scsCarrierPositionAssign" Service

Containers can be loaded into a carrier via an automation layer using a service called "scsCarrierPositionAssign". In the request script, you must specify Setup Action to 0 (Load) and specify the slot position number to load the containers.

It is important to check the carrier's slot position status and availability before you proceed to load a single or multiple containers at the same time. The application displays error messages if you perform any of the following actions:

• Load container into an occupied slot position
• Load 2 or more containers into the same slot position in a single submission
• Load container into an "UNAVAILABLE" or "DOWN" slot position.

Sample to Load Specified Containers to a Carrier

The code below shows a sample of loading containers to a carrier. You must provide the Carrier Name, Container Name, Slot Position Level, Slot Position Number and specify Setup Action = 0 (load).


<__InSite __version="1.1" __encryption="3">

<__service __serviceType="scsCarrierPositionAssign">

<__utcOffset><![CDATA[-05:00:00]]></__utcOffset>

<__inputData>

<Carrier>

<__name><![CDATA[CarrierName]]></__name>

</Carrier>

<CloseCarrierContainer><![CDATA[false]]></CloseCarrierContainer>

<Details>

<__listItem>

<Container>

<__name><![CDATA[ContainerToLoadName]]></__name>

</Container>

<PositionLevel><![CDATA[1]]></PositionLevel>

<PositionNumber><![CDATA[1]]></PositionNumber>

<SetupAction><![CDATA[0]]></SetupAction>

</__listItem>

</Details>

<UnloadAll><![CDATA[false]]></UnloadAll>

</__inputData>

<__execute>

</__execute>

<__requestData>

<CompletionMsg>

</CompletionMsg>

</__requestData>

</__service>

</__InSite>
