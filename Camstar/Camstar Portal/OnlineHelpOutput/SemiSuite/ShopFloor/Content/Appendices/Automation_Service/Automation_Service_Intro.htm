Automation Services

This appendix provides the description and samples of HPE services in Opcenter Execution Semiconductor that can be performed via an external automation service or custom user interface (UI).

Opcenter Execution Semiconductor provides the ability to run complex setups via an automation layer for most transactions that helps to provide convenient, time-efficient, predictable, and reduces human error.

For more information on automation services enhanced with High Performance Engine, refer to Opcenter Execution Core Technical Reference: High Performance Engine.

The following topic provides information on Automation Services:

• Create Carrier Container with "scsDBLotStartSimple" Service
• Create Carrier Container with "scsCarrierPositionAssign" Service
• Request Generated Container Names using "scsDBContainerName" during a HPE Start Service
• Load Containers with "scsCarrierPositionAssign" Service
• Unload Containers with "scsCarrierPositionAssign" Service
• Close Containers using "scsDBContainerClosure" Service
• Multi-Lots Modify Attributes (HPE) Service
