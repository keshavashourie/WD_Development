Close Containers using "scsDBContainerClosure" Service

Containers can be closed via an automation layer using a service called "scsDBContainerClosure" by providing the container name. In situation where you need to close multiple containers, the automation service is able to find the parent container to disassociate before proceed with the container close transaction. To perform the parent finding, you must include the AutoFindParentContainer field and set it to true:

<scsAutoFindParentContainer><![CDATA[true]]></scsAutoFindParentContainer>

Note: The AutoFindParentContainer are limited to 1000 containers per transaction.

You can terminate all associated containers using "DisassociateAndTerminateAll" flag. This flag is also applicable to be used on carrier containers. To perform the terminate all transaction, include "DisassociateAndTerminateAll" field and set it to true:

<DisassociateAndTerminateAll><![CDATA[true]]></DisassociateAndTerminateAll>

Refer to the following code for sample of "DisassociateAndTerminateAll".

After all associated containers are terminated, the application will rename the parent/carrier container based on numbering rule set in factory.

Container Closure Automation Service

Sample of Container Closure

The code below shows the sample of closing containers using "scsDBContainerClosure" service that utilize the AutoFindParentContainer field. Container names must be provided at the ContainerNamesStr.


<__InSite __version="1.1" __encryption="2">

<__service __serviceType="scsDBContainerClosure">

<__utcOffset><![CDATA[-04:00:00]]></__utcOffset>

<__inputData>

<ContainerNamesStr><![CDATA[%TID%ALOT001 - 01|%TID%ALOT001 - 02|%TID%ALOT001 - 03|%TID%ALOT001 - 04|%TID%ALOT001 - 05|%TID%ALOT001 - 06|%TID%ALOT001 - 07|%TID%ALOT001 - 08|%TID%ALOT001 - 09|%TID%ALOT001 - 10]]></ContainerNamesStr>

<scsAutoFindParentContainer><![CDATA[true]]></scsAutoFindParentContainer>

<TerminateReason>

<__name><![CDATA[Customer]]></__name>

</TerminateReason>

</__inputData>

<__execute>

</__execute>

<__requestData>

<CompletionMsg>

</CompletionMsg>

<ACEMessage>

</ACEMessage>

<ACEStatus>

</ACEStatus>

</__requestData>

</__service>

</__InSite>

Sample of Disassociate and Terminate All

The code below shows sample of disassociate and terminate all containers using "DisassociateAndTerminateAll" flag. Container details and Terminate Reasons must be included.


<__InSite __version="1.1" __encryption="2">

<__service __serviceType="scsDBContainerClosure">

<__utcOffset cttPrompt="true"><![CDATA[08:00:00]]></__utcOffset>

<__inputData>

<ContainerParentStr><![CDATA[%MID%CARRIER01%TID%]]></ContainerParentStr>

<DisassociateAndTerminateAll><![CDATA[true]]></DisassociateAndTerminateAll>

<TerminateReason>

<__name><![CDATA[Customer]]></__name>

</TerminateReason>

</__inputData>

<__execute cttPrompt="true">

</__execute>

<__requestData>

<CompletionMsg cttPrompt="true">

</CompletionMsg>

</__requestData>

</__service>

</__InSite>
