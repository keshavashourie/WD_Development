Carrier Family Inquiry Service

Carrier Family Inquiry service (scsCarrierFamilyInquiry) can be utilized by automation layer to retrieve details on Carrier Family based on the provided the container name and equipment as input.

You can specify container and equipment name as input to retrieve responses from the inquiry. The service is also able to retrieve other information as follows:

• Input Carrier Family (add <scsInquiryInputCarrierFamily/> in the script)
• Output Carrier Family (add <scsInquiryOutputCarrierFamily/> in the script)
• Inner Input Carrier Family (add <scsInqInnerInputCarrierFamily/> in the script)
• Inner Output Carrier Family add <scsInqInnerOutputCarrierFamily> in the script)

The following section shows sample of request and response for Carrier Family inquiry service.

Request Data

CompletionMsg

Request of completion status.

Equipment

Request of the name of the equipment object to which the instance applies.

Request of the input carrier family name associated with the provided Equipment.

Request of the output carrier family name associated with the provided Equipment.

Request of the inner input carrier family name associated with the provided child equipment.

Request of the inner output carrier family name associated with the provided child equipment.

Parent Resource

Request of parent source name of the child equipment.
