Recipe Inquiry Service

Recipe Inquiry is a service that used to be utilized at automation layer to retrieve Recipes based on the Equipment setup. Based on the provided Container Name, the current steps will be resolved and the inquiry will return the current details Recipes assigned. The inquiry will also return all child equipment details and recipes associated to the child equipment (if any).

The inquiry service will call and retrieve response data based on the following priority order:

1. Experiment Plan
2. Blanket Experiment Matrix
3. Recipe Matrix
4. Process Spec - Process Spec Details Process Type
5. Process Type - Process Spec Details

You must specify Container and Equipment name as input to retrieve responses from the inquiry. The following section shows sample of request and response of Recipe Inquiry service.
