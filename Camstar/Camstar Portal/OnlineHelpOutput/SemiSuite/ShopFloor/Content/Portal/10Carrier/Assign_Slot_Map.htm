Assign Carrier Slot Map

Assign Carrier Slot Map enables you to indicate the location of a wafer in a wafer carrier. You can load multiple lots into a single wafer carrier, however, you cannot split lots between carriers. You must assign an entire lot to a single carrier.

Before Assigning Wafers to Wafer Carrier Slots

Keep the following points in mind when assigning wafers to wafer carrier slots:

• The following modeling objects must be created before you can assign wafers to wafer carrier slots:
• Wafer Carrier
• Wafer Carrier Family

Refer to Opcenter Execution Semiconductor Modeling Guide for more information on Wafer Carrier and Wafer Carrier Family modeling objects.

• If you want to map all the wafers contained in a lot to a single wafer carrier, the Wafer Carrier Family must specify the same or more number of slots.
• You can assign wafers from multiple lots to a single carrier.
• You must assign all wafers from the lot to a single carrier.
• If you map multiple lots to a single wafer carrier, the lots must be at the same transaction step.
• The equipment specified while tracking in lots must be part of the same factory as the lots.

When Working with Wafer Carrier Slots

Keep these facts in mind when working with wafer carrier slots:

• You cannot map a wafer to a slot that is down.
• You can remove wafers only from those wafer carriers that have not been moved into WIP or wafer carriers that are not currently processing on equipment.
• You must remove all of the wafers from a single lot before you submit the carrier when you remove wafers from the wafer carrier.
• You cannot submit a carrier that contains partial lots.

How to Assign Individual Wafers to Wafer Carrier Slots

Follow these steps to assign individual wafers to wafer carrier slots:

1. Open the Assign Carrier Slot Map page. The application displays the Assign Carrier Slot Map page.
2. For each lot, enter the lot in the Selection Id field or click and the application will display Lots in the Lots grid and list the Wafers of each Lot in the corresponding Wafer List or Slot Map grid.
3. A Wafer Handler may be selected within the Wafer Handler Equipment drop-down. This drop-down will only display Wafer Handler equipment that has been associated to a Equipment Family configured with Wafer Handler.
4. If a Wafer Handler Equipment is selected then the Recipe field will be displayed. Recipes must be assigned to a Recipe Group that is assigned to the Equipment.
5. If you want to enter a different employee from the one that is currently logged in, enter the employee ID of the employee in the Employee field. The application records the transaction as being performed by this employee.
6. Select a Wafer Carrier from the To Carrier field. The application populates the To Carrier field with wafers carriers that are available or linked to one of lots in the lots grid. By default, the system will set the To Carrier field to the Carrier assigned to the Lot selected in the Lots grid.
7. If you want a specific method of slot assignment, select Slot Assignment Method field. Refer to "When Selecting Slot Assignment Method" for more information.
8. Select the slot number to which you want to map the wafer from the Slot Number field.
9. In the Wafer List grid, select lots by clicking the check box on the first column. If you are mapping wafers from more than one lot, click the arrow for the lot to map. The application displays the wafers from that lot in the Wafer List grid.
10. Click Add button at Command Bar. The application displays the wafer information for the mapped slot in the Carrier Slot Map grid.
11. Repeat steps 8-10 until all the wafers in the lot are mapped to a slot.
12. Click Submit. The application assigns the wafers to the slots and displays a success message.
13. Assign Slots button is available if the selected Slot Assignment Method is not Manual.

How to Assign All Wafers in a Lot to Wafer Carrier Slots

Follow these steps to assign all wafers in a lot to wafer carrier slots:

1. Open the Assign Carrier Slot Map page and the application displays the Assign Carrier Slot Map page.
2. For each lot, enter the lot in the Selection Id field or click and the application will display Lots in the Lots grid and list the Wafers of each Lot in the corresponding Wafer List or Slot Map grid.
3. A Wafer Handler may be selected within the Wafer Handler Equipment drop-down. This drop-down will only display Wafer Handler equipment that has been associated to a Equipment Family configured with Wafer Handler.
4. If a Wafer Handler Equipment is selected then the Recipe field will be displayed. Recipes must be assigned to a Recipe Group that is assigned to the Equipment.
5. If you want to enter a different employee from the one that is currently logged in, enter the employee ID of the employee in the Employee field. The application records the transaction as being performed by this employee.
6. Select a Wafer Carrier from the To Carrier field. The application populates the To Carrier field with wafers carriers that are available or linked to one of lots in the lots grid. By default, the system will set the To Carrier field to the Carrier assigned to the Lot selected in the Lots grid.
7. If you are mapping wafers from more than one lot, click the arrow for the lot to map. The application displays the wafers from that lot in the Wafer List grid.
8. Click Add ALL. The application maps the wafers to the slots in order and displays the wafer information for the mapped slot in the Carrier Slot Map grid. For example, wafer number 1 is mapped to slot number 001, wafer number 2 is mapped to slot number 002, and so on.
9. Repeat steps 2-8 for each lot.
10. Click Submit. The application assigns the wafers to the slots and displays a success message.
11. Assign Slots button is available if the selected Slot Assignment Method is not Manual.

How to Remove Wafers from Wafer Carrier Slots

Follow these steps to remove wafers from wafer carrier slots:

1. Open the Assign Carrier Slot Map page. The application displays the Assign Carrier Slot Map page.
2. For each lot, enter the lot in the Selection Id field or click and the application lists the wafers in the Wafer List grid.
3. You may select Wafer Handler Equipment, Recipe and Employee. Refer steps 3 to 5 in "How to Assign Individual Wafers to Wafer Carrier Slots" for information.
4. Select To Carrier to choose which wafer carriers to be assigned to. The application populates wafer carriers that are available or linked to one of lots in the lots grid. By default, it will first populate wafer carrier associated to the entered lots.
5. If the carrier contains wafers from more than one lot, click the arrow to select the lot to which the wafers you are removing from the Wafer Carrier belong. The application displays the wafers from that lot in the Wafer List grid.
6. Perform one of the following for each lot to which the wafers belong:

If you are
removing . . .

Perform the following . . .

A single wafer from the carrier
a. Select the slot number that contains the wafer you want to remove from the Slot Number field.
b. Click Remove. The application removes the wafer information from the mapped slot in the Carrier Slot Map grid.

All of the wafers from the carrier

Click Remove ALL. The application removes all wafer information from the Carrier Slot Map grid.
7. To replace the carrier slots with wafers from another lot, follow the procedure in "How to Assign Individual Wafers to Wafer Carrier Slots" or " How to Assign All Wafers in a Lot to Wafer Carrier Slots".
8. Click Submit. The application displays a success message.
9. Assign Slots button is available if the selected Slot Assignment Method is not Manual.

When Selecting Slot Assignment Method

Slot Assignment Method helps to specify method used to assign wafers to specific slots of the Wafer Carrier. There are five (5) different Slot Order Methods available;

• Ascending All
• Descending All
• Ascending Fill
• Descending Fill
• Manual

Slot Assignment Method fields are available in Lot Combine By Items page, Lot Split By Items page and Assign Carrier Slot Map page.

Note: The term “Ascending” and “Descending” referring to the order applied to the wafers. Wafers will always be assigned based on the Wafer Scribe ID either in ascending or descending order. Meanwhile the term “All” and “Fill” are referring to the slot where the wafer assignment process will begin. “All” will always begin with Slot 1 unless it is not available from a status perspective. “Fill” will look for the first available “empty” slot.

The table below summarized how the page will perform for each Slot Assignment Method selected:

Slot Assignment Method

Description

The page will perform the following . . .

Ascending All

Carrier is mapped starting from slot 1 assuming the availability is up.

Lots will be added based on their Wafer Scribe ID in Ascending order from lowest to highest regardless of lot association unless duplication is detected.

Note: This method does not consider current Slot Assignments. Wafers will be assigned to new Slots.

Descending All

Carrier is mapped starting from slot 1 assuming the availability is up.

Lots will be added based on their Wafer Scribe ID in Descending order from highest to lowest regardless of lot association unless duplication is detected.

Note: This method does not consider current Slot Assignments . Wafers will be assigned to new Slots.

Ascending Fill

Carrier is mapped from the first available Empty slot starting from slot position 1.

Wafers will be added based on their Wafer Scribe ID in Ascending order from lowest to highest regardless of lot association unless duplication is detected.

Note: Existing wafers on the “To Carrier” will not be reassigned.

Descending Fill

Carrier is mapped from the first available Empty slot starting from slot position 1.

Wafers will be added based on their Wafer Scribe ID in Descending order from highest to lowest regardless of lot association unless duplication is detected.

Note: Existing wafers on the “To Carrier” will not be reassigned.

Manual

The default method if other method is not selected.

 
Note: If unique Wafer Scribe IDs in the system is not maintained, the system will utilize Lot and Wafer Scribe Item when conflicts are detected.
