Carrier Operations (HPE)

Carrier Operations (HPE) page offers five functionality to configure relationship of carriers and containers as follows;

• To load container into a specific carrier,
• To unload container from a specific carrier,
• To transfer all containers from a carrier to another carrier,
• To unload all containers from a carrier,
• To close or terminate carrier container while executing the Unload All and Transfer All.

This page helps you to specify which slot position to load the container to, and allow you to track the position of containers inside a carrier. During load, all containers will be associated to a traceable carrier container. Meanwhile during unload, containers will be disassociated from the assigned traceable carrier container. In this page, the application will display the assigned Carrier Container, if available. Otherwise, Carrier Container will automatically be created upon Submit.

During the execution of Unload All and Transfer All, you have the option to close and terminate the carrier by checking the Close Carrier Container check-box. After the execution, you are free to reuse the carrier name.

You are able to reuse carrier and containers that has been moved back to Inventory using Carrier Operations (HPE) page as long as it is located within the same workflow. For example, if a container has been unloaded from a carrier at WIP Main's workflow, you are not able to load the container back into the carrier after it been transferred to an Inventory workflow. Alternatively, you may independently move the container out from inventory.

When a carrier container is closed or terminated, the application automatically archives it with a new name based on numbering rules. This renaming serves as a means of tracking, which allows for the reuse of the original carrier container in future transactions.

Before Using Opcenter Semiconductor Carrier Operations (HPE)

A carrier must be configured within Modeling with an assigned Carrier Family that was previously configured with "Enable Carrier Positions" set to true along with the appropriate carrier configuration utilizing the X, Y, and Z positions. Refer to Defining Carrier Families in the Opcenter Semiconductor Modeling Guide for information.

The process of loading containers into a carrier can be configured to occur automatically or manually. Selecting Auto, the application will automatically assign the container to the first available position in the carrier.

The Carrier Operations (HPE) process is intended to provide additional functionality related to Single Wafer (Item) Tracking described in Chapter 21.

When Using Inner Input or Inner Output Carrier Family

When an Inner Input Carrier Family or Inner Output Carrier Family is specified in the Carrier Family Matrix, the application prevents the selection of alternative values by displaying an error message. To enable verification, it is crucial to either select the "Auto Create First Insertion" check-box in the WIP Spec modeling or manually scan the container in the WIP Main page. This rule applies to both manual and automated configurations of Carrier Operations (HPE).

The application checks for the presence of the Inner Input Carrier Family when the carrier is waiting to be tracked in and verifies the requirement for the Inner Output Carrier Family when the carrier is waiting to be tracked out. This ensures that the carrier is properly tracked throughout its entire journey, whether it's being loaded or unloaded.

Automation Services for Carrier Operations (HPE)

Optionally, you can utilize automation services to perform transactions of Carrier Operations (HPE).

• Create carriers when a container is assigned to a carrier or transferred to a carrier. Refer to "Create Carrier Container with "scsCarrierPositionAssign" Service" for information.
• Load single or multiple containers to a carrier. You must specify the slot position number for this transaction. Refer to "Load Containers with "scsCarrierPositionAssign" Service" for information.
• Unload specified or all containers from carriers. You do not need to provide slot position during the unloading process. Refer to "Unload Containers with "scsCarrierPositionAssign" Service" for information.
• Close containers without specifying the parent name. The automation service will help to find the parent container to disassociate during the container close transaction. Refer to "Close Containers using "scsDBContainerClosure" Service" for information.
Carrier Operations (HPE) Page Field Definitions

This table defines the fields on the Carrier Operations (HPE) page.

Field

Definition

Type

Carrier

Field to specify the Carrier. The field offers selection of all Carriers that has been assigned with "Enabled Carrier Positions" with a defined Position Map in Carrier Family modeling page.

Required

Load / Unload

Radio button indicating whether the transaction is assigning (Load) or unassign-ing (Unload) container to the specified slot position. Selecting Load will assign the container to the specified Slot Position during execution. On the other hand, selecting Unload will unassigned the container from the specified Slot Position during execution.

Optional

Manual / Auto

Indicates how to assign container into the slot position. By default, the application uses manual where you must select the position for each container to load or unload. Auto is only available for Load transaction. By selecting Auto, the application will select the first available position.

Optional

Carrier Container

Indicates the carrier container that is currently linked to the container. The application will display the assigned carrier container if its already been assigned. Else, the application will automatically create a new carrier container upon submit.

An out-of-the-box (OOB) carrier can only be linked to a single container. An OOB container can be linked to more than one OOB carrier. If the carrier is configured with a carrier family and positions are defined, then the carrier can only be linked to one carrier.

Display Only

Slot Position

Slot position to assign the container to. The field offers lists of all "Up" or available slot positions.

Note The field will be disabled if Unload is selected. The field will also be disabled if Auto is selected as the application will automatically assign the container to the first available slot.

Optional

Container

Container or Lot to be loaded to or unloaded from a position. Entering a container value in this field will auto-populate the "Container" column in the Details Selection grid.

Optional

Close Carrier Container

Check box to close or terminate any carrier container with no child container. If you wish to close a carrier container that has associated children, you must first unload all child containers. After closing the carrier container, you are able to create a new carrier using the same carrier container name.

Note: This feature is considered optional as Carrier Container automatically closed under certain process conditions.

Optional

Transfer Carrier

Target carrier to transfer all containers. Selecting this field will allow the transfers of all containers from the current carrier to the targeted carrier. You can only transfer all containers to an empty Carrier that has no filled slot position.

Note: Refer to Defining Carrier Families in the Opcenter Execution Semiconductor Modeling Guide for information.

Optional

Details Selection

Position Number

Sequential identifier of the physical position of the carrier. The display of the position number is based on Positional Method field set in Carrier Family modeling page. If the selected Positional Method is Numeric, the display will be 1,2,3... On the other hand, if Vector is selected the Display will be in 1.2.2, 1.2.3 etc.

Display Only

Position Level

Vertical position of the lot in a carrier or the Z-position. The value is defined in Z Positions field in Carrier Family page.

Display Only

Position Status

Position availability status, either up or down.

Display Only

Setup Action

Load or Unload setup. By default the column will be blank until Containers are entered.

Display Only

Container

Name of the container to be associate to or disassociate from the Carrier Container.

Display Only

Mfg Order

Mfg Order or Work Order associated to the Container.

Display Only

Product

Product or PN associated to the Container.

Display Only

How to Load Container using Carrier Operations (HPE) page

Follow these steps to perform load container into a carrier's slot position in carrier operations (HPE) page:

1. Access the carrier operations (HPE) page from Carrier menu.
2. Select a carrier from the Carrier drop-down field. The field offers selection of all Carriers that has been assigned with "Enabled Carrier Positions" with a defined Position Map in Carrier Family modeling page.
3. Choose Load. Refer to carrier operations Page Field Definition for description of the field.
4. You may choose Manual or Auto. By default, Manual is selected which you need to select Slot Position field. If you select Auto, the application will auto select the first available position.
5. Select Slot Position to load the container into. If Auto is selected, Slot Position will be assigned automatically for you.
6. Enter container name in the Container field. The Details Selection grid will auto-populate entered container name in Container column.
7. Click Submit. The application displays a success message.
How to Unload Container using Carrier Operations (HPE) page

Follow these steps to perform container unload from carrier's slot position in carrier operations (HPE) page:

1. Access the Carrier Operations (HPE) page from Carrier menu.
2. Select a carrier from the Carrier drop-down field. The field offers selection of all Carriers that have been assigned with "Enabled Carrier Positions" with a defined Position Map in Carrier Family modeling page.
3. Choose Unload. Refer to carrier operations Page Field Definition for description of the field.
4. In Container field, enter the container name that you wish to unload from the carrier. Once entered, the application will populate "Unload" in Setup Action column in the Details Selection grid.
5. Click Submit. The application displays a success message.
How to Unload All Carrier Containers using Carrier Operations (HPE) page

Follow these steps to unload all containers from a carrier using the carrier operations (HPE) page:

1. Access the Carrier Operations (HPE) page from Carrier menu.
2. Select a carrier from the Carrier drop-down field. The field list contains all Carriers that have been configured with the Enabled Carrier Position option selected and also have a Position Map configured on the Carrier Family modeling page. To execute Unload All, all slot positions within the carrier must be occupied with containers.
3. Select the Unload All button from the command menu.
4. Click Yes on the confirmation message pop-up. The application displays a success message.
How to Close Carrier Container while executing Unload All using Carrier Operations (HPE) page

Follow these steps to close carrier container in carrier operations (HPE) page:

1. Access the Carrier Operations (HPE) page from Carrier menu.
2. Select a carrier from the Carrier drop-down field. The field list contains all Carriers that have been configured with the Enabled Carrier Position option selected and also have a Position Map configured on the Carrier Family.
3. Check the Close Carrier Container check-box. To perform Close Container while executing Unload All, all slot positions within the carrier must be populated.
4. Select the Unload All button from the command menu.
5. Click Yes on the confirmation message pop-up. The application displays a success message containing "Unload All for specified carrier is executed successfully. The Carrier Container was successfully closed".
How to Transfer All Containers from a Carrier to another Carrier

Follow these steps to transfer all containers from a carrier to another carrier in Carrier Operations (HPE) page:

1. Access the Carrier Operations (HPE) page from Carrier menu.
2. Select a carrier from the Carrier drop-down field. The field offers selection of all Carriers that has been assigned with "Enabled Carrier Positions" with a defined Position Map in Carrier Family modeling page.
3. Select the targeted carrier that you wish to transfer in the Transfer Carrier field.
4. If you want to close the selected carrier upon the execution of transfer all, you may checked the Close Carrier Container check-box.
5. Click Transfer All button in the command bar. The application displays a success message.
