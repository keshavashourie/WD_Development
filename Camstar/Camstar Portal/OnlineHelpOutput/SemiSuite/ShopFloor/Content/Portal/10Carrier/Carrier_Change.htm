Carrier Change

Carrier Change is used to load or unload a lot into or from a Carrier. One Carrier can only load one lot for Assembly Carrier Process Spec. One Carrier can load multiple lots, for other processes. Note that a lot can only be assigned to one Carrier for all processes.

Carrier Change Page Field Definitions

This table defines the fields on the Carrier Change page.

Field

Definition

Type

Selection Id

Field to specify the lot to load to a new Carrier or unload from its current Carrier.

The lot:

• Must not be processing in the Equipment.
• Must not be loaded in the Equipment as a material.

Required

Employee

Employee performing this transaction if different than the user currently logged in.

Optional

New Carrier

Field used to specify the new Carrier to load the lot into. Leaving this field blank results in unloading the lot from its current Carrier.

If specified:

• The Carrier must not be the current Carrier the lot is loaded into. A change is expected.
• The lot must be in the Active state.
• The lot must have a schedule.
• The lot must be in a Scheduled or WIP step.
• For Assembly Carrier Process Spec, the Carrier must not be used by another lot.
• The Carrier must be available.
• The Carrier must not have outstanding Jobs.
• The Carrier must not violate any maintenance requirements.
• If the Carrier has a Package Group assigned, the lot’s Product’s Package Type and Leads must exist as one of the Details in the Package Group.

If not specified the lot must be loaded in the Carrier. A change is expected.

Note: You cannot save this page unless a New Carrier is selected.

Optional

Show/Hide additional fields

 

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.

Optional

How to Perform Carrier change.

Follow these steps to perform a carrier change:

1. Access the Carrier Change page.
2. Select the lot using the Selection Id field. The application populates the Lots grid.
3. Select the New Carrier.
4. Click Submit. The application displays a success message.
