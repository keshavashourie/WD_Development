Equipment Carriers Setup

Equipment Carriers Setup is used to load or unload one or more Carriers at the output of the Equipment.

Equipment Carriers Setup Page Field Definitions

This table defines the fields on the Equipment Carriers Setup page.

Field

Definition

Selection Id

Required field to specify the Equipment to set the Carriers for.

The Equipment must not violate any maintenance requirements.

Employee

Employee performing this transaction if different than the user currently logged in.

Carrier

List field to specify zero, one, or more Carriers to setup at the output of the Equipment.

If specified the Equipment must be processing at least one lot. That means that the output of the Equipment cannot be loaded with Carriers if there are no lots processing in it. The lot processing in the Equipment:

• Must be scheduled with the Assembly Carrier Process Spec.
• Must be at a Spec with an Output Carrier Family assigned.

Each Carrier:

• Must not be loaded in other Equipment.
• Must not be used by another lot.
• Must be available.
• Must not violate any maintenance requirements if it is not currently loaded in any Equipment.
• Resource Family must match the Spec’s Output Carrier Family.
• One lot Product’s Package Type and Leads must exist as one of the Details in the Package Group for Assembly Carrier Process Spec.
• A Sizing entry in the Carrier’s Family must be found for the lot’s Product’s Package Type and Leads. This is required when a lot is tracking out of the Equipment to determine whether auto split or combine is required.

The Equipment must have at least one Carrier loaded at its output. This is to ensure that there is a change of Carriers for every transaction.

Carriers grid

Read-only list field to return the current Carriers loaded at the output of the Equipment.
