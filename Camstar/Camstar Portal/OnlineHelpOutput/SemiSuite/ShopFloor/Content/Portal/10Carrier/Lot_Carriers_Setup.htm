Lot Carriers Setup

Lot Carriers Setup is used to associate and disassociate carriers to or from lots. You can assign one or more carriers to a lot, but the carriers you assign to lots must adhere to the following requirements:

• Maintenance requirements must be valid. Transactions cannot proceed if the application detects a failure.
• Status must be available.
• Must not be assigned to another lot.
• Must not have outstanding jobs.

How to Associate Carriers to Lots

Follow these steps to associate carriers to a lot:

1. Open the Lot Carriers Setup page.
2. Enter the name of the lot to which you want to assign carriers in the Selection Id field. The application displays the name and lot details in the Lots grid. If carriers have already been assigned to the lot, the application displays the assigned carriers in the Carriers grid.
3. For every carrier to associate with the lot, select the name of the carrier from the Carriers field. The application adds the name of the carrier to the Carriers grid. The application displays the carriers in the order in which they are added.
4. Do the following if you need to change the sequential order of a carrier:
a. Click the check box of the carrier in the Carriers grid.

How to Disassociate Carriers from Lots

Follow these steps to disassociate carriers from a lot:

1. Open the Lot Carriers Setup page.
2. Enter the name of the lot from which you want to disassociate carriers in the Selection Id field. The application displays the name and lot details in the Lots grid and the carriers assigned to the lot in the Carriers grid.
3. Click the selection box in the Carriers grid for the carriers you want to remove.
4. Click . The application removes the selected carriers from the Carriers grid.
5. Click Submit. The application displays a success message.
