Material Create

Material Create enables you to start a Material Lot in an Inventory step.

Material Create Page Field Definitions

This table defines the fields on the Material Create page.

Field

Definition

Type

Material Lot Id

Name of the material lot.

Required

Employee

Employee performing this transaction if different than the user currently logged in.

Optional

Material Part

Material Part which represents the consumable product of the lot that is being created. Examples of consumable products are epoxies and substrates.

Required

Start Reason

Reason for creating the material lot.

Note: The application uses the product's default start reason if this field is left blank.

Optional

Workflow (Inventory Area)

Inventory workflow for the material lot start. The object category and object type of the workflow must match the workflow object category and workflow object type of the transaction. This ensures that the right service is used to start the lot in the right location.

Note: The application uses the product's default start workflow if this field is left blank.

Optional

Workflow Step (Inventory Location)

Inventory step for the material lot start. The Workflow Step Spec’s Object Category and Object Type must match the service’s Spec Object Category and Spec Object Type. This is to ensure the right service is used to start the lot in the right location.

Note: The application uses the product's default start location if this field is left blank.

Optional

Owner

Owner used to start the material lot. The Product’s Default Start Owner will be used if blank.

Required

Vendor

Vendor where the lot originated. The application uses the vendors attached to the product to populate the Vendor list on the Lot Start and Lot Create pages.

Optional

Factory

Factory used to start the lot. The factory assigned to the Employee is used by default.

Optional

Level

Container level field. Typical values include batch, lot, or pallet.

Optional

Qty 2

Number of wafers in lot.

Note: A value greater than zero is required for wafer spec object types.

Optional

UOM 2

Specifies the unit of measure for Qty 2.

Note: The UOM 2 assigned to the start Spec will be used if this field is left blank. WAFER will be used If the Spec has no UOM 2 specified.

Optional

Ship From Factory

Factory from which the lot was shipped. Provides the valid selection list for Ship To Process.

Optional

Ship To Process

Specifies the ship to process assigned to the lot. Ship To Processes are configured for a Ship From Factory.

Optional

Reuse Lot

Check box indicating whether to reuse an existing lot with the same Container Name. The check box must be selected if the lot or container name is already in use. Conditions to reuse an existing lot include:

• Lot must be either Closed (terminated) or Shipped.
• Either Qty or Qty 2 must be greater than zero to allow reuse only if the lot was terminated or shipped. Lots that are split, combine or reject to zero are not allowed to restart.

Optional

Qty

Quantity of die in lot.

Optional

UOM

Unit of measure for Qty.

Optional

Service Attributes grid

Grid that lists attributes configured for the current transaction using the Service Attrs Setup matrix. Attribute values can be changed directly on the grid.

Note: Optionally, you can create an attribute called "Material Manufacturer Expiry Date" to set material expiry. When configured, the system validates this value during Material Withdrawal and Usage operations, both while loading materials on equipment and when using WIP Main Advanced.

Optional

Attribute

Name of attribute.

Optional

Attribute Value

Value of attribute.

Optional

Attribute Revision

Revision number of the attribute.

Optional

Items grid

Grid specifying wafers within the selected lot.

The number of wafer records should match Qty 2. Lot Modify Wafers (Items) can be used to add, remove or change the details.

Optional

Item Id

Item ID of the wafer.

Optional

Item Number

Sequential order of wafer within lot.

Optional

Require Tracking

Check box indicating whether the wafer must be tracked.

Optional

Require Data Collection

Check box indicating whether transactions against the wafer must have a data collection.

Optional

Item Qty

Net Die Per Wafer (NDPW) or the first quantity for the wafer or item.

Optional

Item Qty 2

Good or final quantity for the wafer or item. Typically, Item Qty 2 is used if its value is greater than 0. Otherwise Item Qty is used. Ultimately, the implementation decides which quantity to use.

Optional

Vendor Lot Number

Vendor assigned lot number.

Optional

Vendor Name

Vendor that originated the lot.

Optional

Run Numbers

Grid specifying the Wafer Run Numbers of the lot.

Optional

Run Number

Represents the Fabrication Lot Number. Wafers received into the assembly plant have the run number assigned to the lot. Run numbers are copied when the lot splits and combines resulting in additional run numbers.

Optional

Reference Attribute Number

Used to cross reference a run number to an external attribute.

Optional

Work Order

Manufacturing order used to start the lot.

Note: This field should only be used if the lot is to be automatically scheduled when started.

Optional

Expected Start Date

Expected Start Date for the schedule.

Note: The work order's Planned Start Date will be used if this field is left blank.

Optional

Cycle Time

Estimate of time (in days [optional], hours, minutes, and seconds) required to process product under normal circumstances. The application uses the first non-blank cycle time that it finds by evaluating the following fields in the following order:

1.

Manufacturing order's planned cycle time (PlannedCompletionDate – PlannedStartDate)

2.

Cycle time entered by user

3.

Process spec's cycle time.

The application uses a value of 1 if no value can be found.

Optional

Auto Prepare

Check box to indicate whether to automatically prepare the lot. Selecting the Auto Prepare check box causes the lot to be automatically prepared as in Lot Schedule Preparation.

Note: Lot is automatically scheduled by providing the process spec.

Optional

BOM

Bill of materials.

Optional

Process Spec

Field to select a Process Spec with which to schedule a lot. A process spec is used to track lots after they move out of Inventory and into WIP processing. It specifies the workflow steps to execute and any parameters and variations on workflow steps. The Manufacturing Order’s process spec will be used if a process spec value is not entered.

Note: Field list is populated with Process Specs attached to the product.

Optional

First WIP Step Workflow

Workflow or sub-workflow step in which the lot should begin WIP processing. Selection of the step results in population of both the First WIP Step Workflow and the First WIP Step fields.

Optional

First WIP Spec

First WIP step (also the default) within the Process Spec’s Workflow.

Optional

Auto Set New Lot Id

Check box indicating whether to set the New Lot Id during Lot Schedule Preparation which will cause the lot to be split.

Optional

Sales Order Number

Additional information for a schedule. Typically used to store the sales order number from an ERP application.

Optional

Priority Code

Specifies the priority for the lot.

Optional

Packing Type

Used to calculate the quantity per box.

Optional

Show/Hide additional fields

 

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.

Optional

How to Create a Material Lot

Follow these steps to create a material lot:

1. Access the Material Create page.
2. Enter a name for the material lot in the Material Lot Id field.
3. Select the Material Part. The application populates the fields that have default values configured for the select material part.
4. Select Start Reason if the field is blank or the default is not correct.
5. Select Workflow (Inventory Area) if the field is blank or the default is not correct.
6. Select Workflow Step (Inventory Location) if the field is blank or the default is not correct.
7. Select Owner if the field is blank or the default is not correct.
8. Select Factory.
9. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
10. Click Submit. The application displays a success message.
