Container Search in Opcenter Execution Semiconductor

Opcenter Execution Semiconductor uses a slightly modified adaptation of the Opcenter EX CR container search feature. This chapter explains the modifications made for Opcenter Execution Semiconductor.

Changes for Opcenter Execution Semiconductor

Added these search criteria fields:

• Factory
• Process Spec
• Material Part
• Material Lot Name

Removed these fields:

• Issued Container
• Issued Container Product
• From Issued Lot
• From Issued Stock Point

Added these default Shop Floor Txns:

• Lot Combine
• Lot Combine By Wafers
• Lot Hold
• Lot Split
• Lot Modify Attributes
• Lot Modify Items
• Lot Split By Wafers
• Lot Release
• WIP Main
Note: A system administrator can add default actions using Portal Studio.

Refer to the Opcenter Execution Core Shop Floor Guide for information on the container search feature in general. Refer to the Opcenter Execution Core Portal Studio 1.0 User Guide for information on adding default actions.
