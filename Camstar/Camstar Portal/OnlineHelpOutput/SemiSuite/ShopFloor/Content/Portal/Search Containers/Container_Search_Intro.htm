Searching for Containers

Container Search is an Opcenter Execution Core feature enabling you to search for and retrieve containers based on specified criteria. You can search current and historical container data using provided filters or user-defined queries. When the application returns containers meeting the specified criteria, you can select one or more containers on which you want to perform a transaction. The application displays only those transactions relevant to the selected containers.
