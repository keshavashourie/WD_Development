Pre-Track In Verification and Setup

Pre-Track In Verification and Setup page offers a comprehensive view to the current configuration of a specific piece of equipment. Helping you to compare the current and next configuration, and allow you to set requirements for the next lot. You can configure requirements for Mask, Materials, Tools and Tool Family for the next lot. For example, if the next lot requires a different Mask, Material or Tool then you are able to assign those changes to the equipment. This functionality will eventually improves efficiency and helps to minimize the downtime of the equipment changeover from lot to lot by having early setup and preparation.

After equipment setup is completed for a selected lot, the lot will not be available to be processed on the WIP Main. It will still be necessary to assign any mask or tooling requirement within the Equipment Setup of WIP Main. This process removes the items from their currently assigned Physical Locations and Positions. Thus, preventing another user from reassigning to another piece of equipment.

Pre-Track In Verification and Setup Page Layout

The Pre-Track In Verification and Setup page contains the following areas:

1. The top header of the page contains Lot ID field to select lot to be assigned, Process Type field and optional Employee field.
2. The left panel contains Equipment tiles which display a list of existing Equipment from the resolved Equipment or Equipment Group. Each tile displays a description of the equipment, the assigned recipe, equipment status, and availability. Selecting equipment on this tile populates information in the central pane.
3. The central pane of the page contain lists of available configuration setups. The application populates the central pane with these requirement configurations when you select an equipment tile:
• Mask Requirement - Displays all Masks that can satisfy the specific Mask Layer defined within the Process Spec. Each Mask Tile displays details of the State (In Use or Not In Use), current equipment assignment, current physical location and current physical position. The tile will be in Green if the State is Not In Use but has an assigned Equipment, Red if it is in use at a different equipment and White if it is not in use and has not been assigned to any piece of equipment. You are able to assign a new Physical Location and Physical Position for the White Tile Mask.
• Material Requirement - Displays the required materials based on the associated Product BOM of the selected Lot. Only materials with an assigned Spec within the Product BOM or with a defined Consume Spec on the Material Type will be displayed. You may assign material lot with quantity until the requested quantity is fully compliant.
• Tool Requirement - Displays the individual Tool requirements as defined in the resolved Tool Plan of the selected Lot and Equipment. After Lot and Equipment is selected, the tile displays the same fields and information as the above Mask Requirement configuration.
• Tool Family Requirement - Displays the associated Tool Family with the required quantity of tools based on the resolved Tool Plan. After an equipment is manually or automatically selected, the system identifies the required Tool Plan Details. If there's any Tool Plan resolved, the Tool Family Requirement pane will be populated.

The tile will populate sets of Tool fields based on number of the required quantity. For example, if Tool Family A has a Quantity of 2. The pane will populate 2 sets of fields that allow you to set the Tool, New Physical Location and New Physical Position.

The application will combine the quantity of the same the Tool Family. For example, if an equipment has Tool Family B with the quantity of 5 and another Tool Family B with the quantity of 2, the application will display a total quantity of 7.
