Reserve Equipment for Lot

The Reserve Equipment for Lot page enables you to hold equipment for processing of a lot at one or more specified steps.

When Reserving Equipment

These are the equipment reservation rules:

1. Reservations must be made at the workflow step level.
2. Lots must have the same product and workflow when equipment is reserved for multiple lots.
3. Reservations cannot be changed when the step is active in WIP processing.
4. There can be only one equipment item reserved per step. The application replaces the reserved equipment with the newly reserved equipment if you add equipment to a step that already has an equipment reservation.

You can determine whether equipment is optional or mandatory when reserving equipment for lots. The user must select the recommended equipment when the reserved equipment is mandatory. The user can select other equipment when the reserved equipment is optional. The application displays a warning message if the user selects equipment that was not recommended.

You can see a list of reservations for the preferred equipment when reserving equipment. The application displays a list of those reservations when you enter the Step and the Equipment. The reservations appear in the lower right grid on the page.

WIP Main Advanced Reserved Equipment Tile Messaging

The WIP Main Advanced page displays activity messages indicating the lot has equipment reserved for it. The user selects the equipment based on the message on the tile.

The Reserved Equipment tile appears in the Track In phase as optional if the equipment was not set as mandatory. The tile appears in the Track In phase as required if the equipment was set as mandatory.

How to Reserve Equipment for a Lot

Follow these steps to reserve equipment for a single lot.

1. Select Reserve Equipment for Lot from the Primary Navigation bar. (Location and label depend upon your menu configuration.) The Reserve Equipment for Lot page displays.
2. Select or enter the Lot. Lot appears in Lots grid just below Selection Id. Any existing equipment reservations for the lot display in the lower-left grid.
3. Select the Step.
4. Select the Equipment. Any existing reservations for the selected equipment item appear in the lower-right grid.
5. Select Is Mandatory to make this equipment the only option on the WIP processing equipment list. Leave unchecked to permit selection of other equipment accompanied by a warning message.
6. Click Submit.

How to Reserve Equipment for Multiple Lots

Follow these steps to reserve equipment for multiple lots.

1. Access the Reserve Equipment for Lot page.
2. Select or enter each Lot. Lots appear in Lots grid below Selection Id. Any existing equipment reservations for the lots display in the lower-left grid.
3. Select the Step.
4. Select the Equipment. Any existing reservations for the selected equipment item appear in the lower-right grid.
5. Select Is Mandatory to make this equipment the only option on the WIP processing equipment list. Leave unchecked to permit selection of other equipment accompanied by a warning message.
6. Click Submit. The application displays a success message.
