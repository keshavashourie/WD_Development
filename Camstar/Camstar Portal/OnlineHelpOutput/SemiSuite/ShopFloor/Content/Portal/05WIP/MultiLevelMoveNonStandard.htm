Multi-Level Move NonStd

The Multi-Level Move NonStd transaction enables you to move a lot to a step in either a main workflow or sub-workflow.

Note: You can only move one lot at a time using the Multi-Level Move NonStd page.

When Using Multi-Level Move NonStd

These requirements must be met when using the Multi-Level Move NonStd page:

• Lot must be in a WIP step.
• Lot must not be processing in equipment.
• Insertion must be completed or canceled, or the Cancel WIP Tracking check box on the page must be selected.
Note: The process spec’s object type will be verified against the service’s object type to ensure the correct service is used to transact the lot.

Multi-Level Move NonStd Page Field Definitions

This table defines the fields on the Multi-Level Move NonStd page.

Field

Definition

Selection Id

ID for a lot, carrier, batch, or piece of equipment.

Employee

Employee performing this transaction if different than the user currently logged in.

Lot grid

Grid that lists information on selected lot.

Trigger Move In

Flag indicating whether to trigger Move In. Move In is required if the lot’s current Operation’s Use Queue flag is set to true and a Move In transaction has not been carried out.

Cancel WIP Tracking

Flag used as an acknowledgment that the lot’s insertion is required to be canceled before moving out.

This flag must be true if the lot has an insertion and has yet to be completed with at least one required process. It must be false for all other scenarios.

Yield Off Rejects

Flag indicating whether to yield off the rejects collected at the step plus defects if the Spec’s Yield Off Defects flag is set to true.

This flag can only be set to true if the insertion has been completed.

To Workflow

Main workflow or sub-workflow and WIP step to which to move the lot.

To Workflow Step

WIP step to which to move the lot. This value is set by the To Workflow field.

How to Use Multi-Level Move NonStd to Move a Lot

Follow these steps to use Multi-Level Move NonStd to move a lot:

1. Access the Multi-Level Move Non Standard page.
2. Enter the lot name in the Selection Id field. The application displays the lot details in the Lot grid.
3. Enter the workflow or sub-workflow and step to which you want to move the lot in the To Workflow field. The application displays the selected step in the To Workflow Step field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Submit. The application displays a success message.
