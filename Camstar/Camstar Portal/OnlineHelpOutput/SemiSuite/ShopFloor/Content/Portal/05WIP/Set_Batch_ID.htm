Set Batch ID

Set Batch ID enables you to set or remove Batch ID for one or more lots. Batch ID is a String value that can be manually entered. The application automatically generates a Batch ID using the Numbering Rule if a value is not entered.

When Setting a Batch ID

The lots must be active and at the same step.

Transaction scenarios:

• No Batch ID and no Containers. This is not allowed since there is no instruction to do anything.
• No Batch ID but Containers exist. The application will auto generate the Batch ID using the Numbering Rule and set Batch ID lot attributes for the lots.
• Batch ID exists but no Containers. This is done to remove the Batch ID from Containers having the value.
• Batch ID and Containers exist. The Batch ID will be set to the lots’ attribute.

Set Batch ID Page Field Definitions

This table defines the fields on the Set Batch ID page.

Field

Definition

Selection Id

List field to specify one or more lots to set the Batch ID for.

Employee

Employee performing this transaction if different than the user currently logged in.

Batch Id

Required field to specify the ID to set or remove from one or more lots.

The “SetBatchId” numbering rule will be used to auto generate an ID if a value is not specified.

Adjust Reason

The reason for any adjustments to the selection.

Show/Hide additional fields

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.
