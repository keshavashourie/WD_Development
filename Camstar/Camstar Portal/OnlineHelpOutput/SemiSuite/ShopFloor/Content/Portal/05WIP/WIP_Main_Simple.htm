Using WIP Main Simple

The WIP Main Simple page provides a centralize location to perform multiple configurations for multiple lots. The page displays a comprehensive view of lots, equipment status and available actions to be performed.

When Accessing WIP Main Simple

The WIP Main Simple page can be accessed from the menu bar by selecting WIP > WIP Main Simple page. By default, the page displays list of lots and equipments based on the Line Assignment settings. The page appears blank if no configuration of Line Assignment. Refer to "How to Setup Line Assignment" for information.

WIP Main Simple Page Layout

The WIP Main Simple page contains the following areas:

1. The header page contains fields to filter information that includes Lot, Equipment, Carrier/Batch and more.
1. The left panel of the page contains Dispatch List for lots.
2. The center of the page contains Equipment Status, Process Type selection and Activity Status.
3. The right panel of the page contains list of available commands.

The following topics describe these areas.

Dispatch List

The Dispatch List card displays lots that are in processing state. The application displays sort lot based on the highest priority of scanned lot and matched line assignment criteria.

Prior to filtering, the page displays list of lots based on the Line Assignment settings. You can filter the lots based on the processing state by selecting the icon (Move In, Track In, Track Out and Move Out). The application automatically load lots with the same processing state if one tile is selected. For example, if you select Lot 001 that is in Track Out state, the Dispatch List will auto-popuate the rest of the section with tiles that are in Track Out state. You can use search bar to look for specific lots.

Each tile displays information for the dispatch lots. The information includes:

• Name
• Quantity (Quantity of die in lot)
• Quantity 2 (Quantity of wafers in lot)
• Current WIP Step
• Process Type and
• Lot Hold Status

Tiles highlighted in red color indicates that the lot is on hold.

Equipment Status

The equipment status section displays tiles of equipment information that includes the description of equipment, manufacturing status, and the number of WIP lots assigned to the equipment. The list of equipment displayed in this section can be set in the Work Center modeling object by filtering the Resource Group drop-down. You can further filter the Resource / Operation / Work Center based on our requirement using the option available in the Set Line assignment settings.

You can search for specific equipment by entering the name in the Equipment Filters field, and use Availability filter to show equipments based on Available/Maintenance status.

The color of the tiles represent the availability status of the equipment, where Green is Available, and Red is Unavailable. The number displayed at the right corner of each tile represents the number of WIP lots assigned to the equipment. Refer to the "Using WIP Main Simple" for information.
