Lot Modify Time Window

Lot Modify Time Window enables you to modify both the Min Time Windows and Max Time Windows for a lot.

Lot Modify Time Window Page Field Definitions

This table defines the fields on the Lot Modify Time Window page.

Field

Definition

Selection Id

Required field to specify the lot to modify both Min and Max Time Windows.

Employee

Employee performing this transaction if different than the user currently logged in.

Min Time Window Details grid

Sub-entity list used to modify the Min Time Windows for the lot. At least one record must exist if Max Details has no details.

Refer to "Equipment Modify Time Window" for the fields.

Max Time Window Details grid

Sub-entity list used to modify the Max Time Windows for the lot. At least one record must exist if Min Details has no details.

Start Spec

Required field and together with Stop Spec must be a record in the lot’s Lot Max Time Window sub-entity list.

Stop Spec

Required field and together with Start Spec must be a record in the lot’s Lot Max Time Window sub-entity list.

Max Time

Required field specified in hours. Cannot be set less than zero.

Overtime Action

Required field to specify the overtime action. Must be set to either HOLD or WARNING.

Email Group

Optional field to specify the Email Group to send email to in the event a failure is detected during WIP Main.

Show/Hide additional fields

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.
