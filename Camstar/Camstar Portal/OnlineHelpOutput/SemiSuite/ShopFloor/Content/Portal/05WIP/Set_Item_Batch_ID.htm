Set Item Batch ID

Set Item Batch ID is similar to Set Batch ID but is used to set or remove Wafer Batch ID for one or more wafers (items). Wafer Batch ID is a String value that can be manually entered or automatically generated by the application using the Numbering Rule.

Set Item Batch ID Page Field Definitions

This table defines the fields on the Set Item Batch ID page.

Field

Definition

Selection Id

List to specify one or more wafers for which to set the Wafer Batch ID.

Fields include:

Container – Required field to specify the lot. The lot:

• Must be active.
• Must be at the same Spec if multiple lots are specified.

Wafer Scribe Number (Item ID) – Required field to specify the wafer to set for. The wafer must exist in the Container specified.

Transaction scenarios:

• No Batch ID and no Wafers. This is not allowed since there is no instruction to do anything.
• No Batch ID but Wafers exist. The application will auto generate the Batch ID using the Numbering Rule and set Wafer Batch ID wafer attributes for the wafers.
• Batch ID exists but no Wafers. This is done to remove the Batch ID from Wafers having the value.
• Batch ID and Wafers exist. The Batch ID will be set to the wafers’ attribute.

Employee

Employee performing this transaction if different than the user currently logged in.

Item Batch Id

Required field to specify the ID to set or remove from one or more lots.

The “WaferBatchId” numbering rule will be used to auto generate an ID If a value is not specified.

Show/Hide additional fields

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.
