Stop Max Time Window

Stop Max Time Window enables you to temporarily stop the Max Time Window for one or more lots. The Max Time Window ensures that the lot does not violate the maximum time duration between two steps. The time window is started when the lot tracks out from the required Start Spec and verified through WIP Main when the lot is selected at the required Stop Spec.

How to Stop the Maximum Time Window in a Lot

Follow these steps to stop a Maximum Time Window:

1. Open the Stop Max Time Window page.
2. Enter the ID of the lot in the Selection Id field. The application displays the lot details for the resource in the Lots grid.
3. Click Submit. The application displays a success message.
