Set Carrier

Set Carrier enables you to load or unload one or more lots to or from a Carrier.

Note: The Assembly Carrier process spec permits one lot per carrier. All other process specs permit multiple lots per carrier.

When Using Set Carrier

The lots must be active and at the same step.

Transaction scenarios:

• No Carrier and no Containers. This is not allowed since there is no instruction to do anything.
• No Carrier but Containers exist. The Containers will be unloaded from the Carriers they are loaded in.
• Carrier exists but no Containers. The lots loaded in the Carrier will be unloaded.
• Carrier and Containers exist. The specified lots will be loaded into the Carrier and lots that are already loaded to the Carrier but not specified will be unloaded from the Carrier.

Set Carrier Page Field Definitions

This table defines the fields on the Set Carrier page.

Definition

Selection Id

List field to specify one or more lots to load into or unload from the Carrier.

Field to specify the Carrier to set or remove from one or more lots.
