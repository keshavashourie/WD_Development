Create New Insertion

Create New Insertion enables you to create an insertion for a lot before WIP tracking services are allowed.

Create New Insertion Page Field Definitions

This table defines the fields on the Create New Insertion page.

Field

Definition

Selection Id

Required field to specify the lot used to create the insertion.

The lot:

• Must be active and not on hold.
• Must be in a WIP step.
• Must have a schedule.
• Not allowed if an insertion has already been created but have not completed.
• Not allowed if it is already loaded in the Equipment as a material.
• Not allowed if the lot has reached the Max Insertion allowed for the insertion. Max Insertion is copied over to the first insertion from the Spec when the first insertion was created. Modification of the insertion’s Max Insertion can be done using Modify Insertion and will affect only the lot and not the Spec.
• Qty 2 must be greater than zero and must match the number of wafers records for Wafer Processing.
• For Create First Insertion sub-class, the lot’s Insertion Number must be zero.
• For Create New Insertion, the lot’s Insertion Number must be greater than zero since it is used to add additional insertion records.

Employee

Employee performing this transaction if different than the user currently logged in.

Insertion Reason

Reason for the insertion.

Service Details

Optional sub-entity list to specify the processes required. The number of records here must match the expected number of records as specified in Insertion Details.

Insertion Details will be set as Service Details if blank.

Fields include:

• Process Type – Required field to specify the process as setup in the Process Spec’s Details’ Process Types. If no setup, the NORMAL Process Type will be used.
• Process Status – Indicate whether the process is required. Valid values include ACTIVE and CANCELED. For Create First Insertion without any custom step logic, the value is set to ACTIVE. For Create New Insertion, the user is allowed to select the status. At least one ACTIVE status is required to create a new insertion.
• Allow Qty Override – Flag indicating whether the Qty To Process can be modified using Modify Insertion. The default is set to true.
• Qty To Process – The quantity required for the process.

For Wafer Processing, lot’s Qty 2 must be greater than zero and must match the number of wafers record (i.e. Lot Wafers). Qty To Process is set by selecting the lot’s wafers. For Create First Insertion, wafers with their Require Tracking flag set to true will be automatically selected if there is no custom step logic.

For Qty To Process, the value cannot be set greater than the lot’s main quantity.

• Min Qty To Process – Optional field to set the minimum quantity required for the process. Used to verify Qty To Process changes during Modify Insertion.
• Max Qty To Process – Optional field to set the maximum quantity required for the process. Used to verify Qty To Process changes during Modify Insertion.
• Test Status – Optional additional information.
• WIP Test Status – Optional additional information.
• Test Plan – Optional additional information.
• Test Sub-Plan – Optional additional information.
• Test Sub-Plan Type – Optional additional information.

Show/Hide additional fields

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.
