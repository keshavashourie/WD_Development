Modify Insertion

Modify Insertion enables you to modify insertion details for a lot. Modify Insertion should be used rarely and only in special cases where there is an urgent need.

Modify Insertion Page Field Definitions

This table defines the fields on the Modify Insertion page.

Field

Definition

Selection Id

Required field to specify the lot to modify the insertion.

Employee

Employee performing this transaction if different than the user currently logged in.

WIP Status

This insertion field is used to indicate its status. Refer to the Objects Design document for the details of all possible statuses.

For this service only the following statuses are allowed:

• ACTIVE – Allowed only if the current status is CANCELED. This is to re-activate the insertion after canceling it.
• CANCELED – Allowed only if the current status is ACTIVE. This is to terminate the entire insertion to allow the lot to move out without further processing.
• (Same as current) – This means no changes required.

Process Type

Required field to specify the process to modify for. It must be one of the processes for the insertion.

Process Status

Specify the status for the Process Type within the insertion. Refer to the Objects Design document for the details of all possible statuses.

Valid values include:

• ACTIVE – Used to reactivate the process.
• INPROCESS – Used to set the process to processing mode.
• CANCELED – Used to cancel a process.

Failure Action

The overall Failure Action for the insertion. This insertion detail is used to decide whether to put the lot on hold during Lot Move Out.

Valid values include:

• HOLD – The lot will be put on hold if any failures are detected. This is the default value.
• HOLDALL – The lot and other lots in its schedule will be put on hold if any failures are detected.
• WAIVE – The lot will not be put on hold even if failures detected.

Max Insertion

Copied over from Spec field during Create First Insertion. This field is used to indicate the number of re-screening allowed for a lot. A value greater than one allows a new insertion to be created using the Create New Insertion service.

This value cannot be set less than the current insertion number.

By copying the setup to the insertion, changes done here will only affect one lot.

Auto Rejects Rescreens

Field used to specify whether to automatically create a new insertion if there is a reject detected. A value of 3 means rescreen will be automatically created up to the 3rd insertion (up to 2nd rescreen). For Wafer Processing, only wafers selected to be yielded off will be considered. Value 0 or less means no auto rescreen.

Hold Lot If Limits Not Found

Copied over from the Spec field during Create First Insertion. This field is used during Yield and PDA calculations to fail the lot if a setup limit could not be found.

By copying the setup to the insertion, changes done here will only affect one lot.

Auto Move Out

Copied over from Spec field during Create First Insertion. This field is used during last Track Out (when insertion completes) to determine whether to automatically trigger Lot Move Out. The logic is carried out by WIP Main.

By copying the setup to the insertion, changes done here will only affect one lot.

Show/Hide additional fields

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.
