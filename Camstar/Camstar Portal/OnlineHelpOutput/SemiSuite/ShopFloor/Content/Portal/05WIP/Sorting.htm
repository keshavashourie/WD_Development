Sorting

Sorting enables you to grade the wafers or items of a lot in WIP. You use sorting to collect information during yield calculation and lot move out. Lot move out will put the lot on hold or split the wafers if any of the data collected failed.

When Using Sorting

The sort information has a corresponding lot sub-entity list used to store information for one or more transactions.

Information can be collected continuously during an insertion and is considered completed if the following are true:

• All wafers are accounted for.
• Grade is assigned for each wafer when the Product has at least one Sorting Grades (for wafer processing).
• The NDPW of each wafer is greater than zero and Lot Qty is equal to zero.

Or

Both the Good Qty and Lot Qty of each wafer is greater than zero.

The application does not move out lots if the information is incomplete.

How to Use Sorting to Grade Wafers

Follow these steps to perform test correlations:

1. Open the Sorting page.
2. Enter the ID of the lot in the Selection Id field. The application displays the lot details for the resource in the Lots grid.
3. Click Submit. The application displays a success message.
