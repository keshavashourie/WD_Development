Canceling Equipment Reservations

The Cancel Equipment Reservation page enables you to cancel equipment reservations.

Cancel Equipment Reservation Page Field Definitions

This table defines the fields on the Cancel Equipment Reservation page.

Definition

Selection Id

Field to specify the lot for which equipment reservation is to be canceled.

Lots grid

How to Cancel an Equipment Reservation

Follow these steps to cancel an equipment reservation:

1. Access the Cancel Equipment Reservation page. (Location and label depend upon your menu configuration.)
2. Select or enter the Lot. Lot appears in Lots grid just below Selection Id. Any existing equipment reservations for the lot appear in the lower-left grid.
3. Select the row with the reservation that you want to cancel. A right arrow displays in the first column of the selected row and the row is highlighted.
4. Click the trash can on the grid toolbar. The row disappears from the grid.
5. Click Submit. The application displays a success message.
