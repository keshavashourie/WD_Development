Equipment Modify Time Window

Equipment Modify Time Window allows you to change the minimum amount of time permitted for the lot to process within a specific piece of equipment.

Equipment Modify Time Window Page Field Definitions

This table defines the fields on the Equipment Modify Time Window page.

Field

Definition

Equipment

Required field to specify the Equipment to modify the Min Time Window of the lots processing in it.

Employee

Employee performing this transaction if different than the user currently logged in.

Min Current Details grid

Required sub-entity list to specify the lots to modify.

Container

Required field to specify the lot. The lot must be processing in the Equipment with a minimum time created. For Equipment Modify Time Window only.

Equipment

Required field to specify the Equipment the lot is currently processing in. For Lot Modify Time Window only.

Min Time

Required field to specify the time in hours. Cannot be set less than zero.

Alert Frame

Required field to specify the alert frame in minutes. Cannot be set less than zero.

Overtime Frame

Required field to specify the overtime frame in minutes. Cannot be set less than zero.

Beforetime Action

Required field to specify the beforetime action. Must be set to NOTALLOWED, HOLD, or WARNING.

Overtime Action

Required field to specify the overtime action. Must be set to HOLD or WARNING.

Email Group

Optional field to specify the Email Group to send email to in the event a failure is detected during Track Out Lot.
