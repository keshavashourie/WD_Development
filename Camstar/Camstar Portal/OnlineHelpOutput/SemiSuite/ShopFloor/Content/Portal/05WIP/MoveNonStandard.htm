Move Non Standard

The Move Non Standard transaction enables you to move a lot to another step in a workflow.

Note: You can only move one lot at a time using the Move Non Standard page.

When Using Move Non Standard

These requirements must be met when using the Move Non Standard page:

• Lot must be in a WIP step.
• Lot must not be processing in equipment.
• Insertion must be completed or canceled, or the Cancel WIP Tracking check box on the page must be selected.
Note: The process spec’s object type will be verified against the service’s object type to ensure the correct service is used to transact the lot.

Move Non Standard Page Field Definitions

This table defines the fields on the Move Non Standard page.

Field

Definition

Selection Id

ID for a lot, carrier, batch, or piece of equipment.

Employee

Employee performing this transaction if different than the user currently logged in.

Lot grid

Grid that lists information on selected lot.

Trigger Move In

Flag indicating whether to trigger Move In. Move In is required if the lot’s current Operation’s Use Queue flag is set to true and a Move In transaction has not been carried out.

Cancel WIP Tracking

Flag used as an acknowledgment that the lot’s insertion is required to be canceled before moving out.

This flag must be true if the lot has an insertion and has yet to be completed with at least one required process. It must be false for all other scenarios.

Yield Off Rejects

Flag indicating whether to yield off the rejects collected at the step plus defects if the Spec’s Yield Off Defects flag is set to true.

This flag can only be set to true if the insertion has been completed.

Split Bins

Indicates whether to split the bins. This flag can only be set to true if the insertion has been completed and the WIP Spec’s Bin Split Required flag is set to true.

To Step Type

Step type to which to move the lot. Options include:

• NEXTSTEPS – Enables you to return the lot to steps ahead of the current step. The standard paths will be used to determine the next steps.
• PREVIOUSMOVES – Enables you to return the lot to steps from which the lot was previously moved out.
• PREVIOUSSTEPS – Enables you to return the lot to steps before and including the current step.
• WIPSTEPS – Enables you to return the lot to WIP steps within the lot’s current WIP Workflow.

To Workflow Step

WIP step to which to move the lot. This value cannot be the same as the lot’s current step. Valid steps are taken from the lot’s current Workflow.

To Path

Path to which to move the lot. The application returns standard paths linked from the current step.

Note: This field overwrites To Workflow Step.

How to Use Move Non Standard to Move a Lot

Follow these steps to use Move Non Standard to move a lot:

1. Access the Move Non Standard page.
2. Enter the lot name in the Selection Id field. The application displays the lot details in the Lot grid.
3. Enter the step type to which you want to move the lot in the To Step Type field.
4. Enter values for the following fields as necessary:
• To Workflow Step
• To Path
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
