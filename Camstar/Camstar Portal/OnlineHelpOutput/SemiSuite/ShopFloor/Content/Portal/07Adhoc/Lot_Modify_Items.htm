Lot Modify Items

An item-based (wafer-based) lot can be started without any wafers. Wafers will be required when the lot reaches an item-based processing step. Lot Modify Items enables you to add wafers to a lot. It also enables you to remove wafers and to update the attributes of existing wafers.

When Using Lot Modify Items

Keep in mind:

• Qty refers to the total Net Die per Wafer (NDPW) or Good Qty of all wafers.
• Qty 2 refers to the number of wafers and items.
• Good Qty is used by default if it is greater than 0. Otherwise NDPW is used.
Important: There can be cases where not all of the wafers within a lot are passed to this page. You must check the Update Only check box before saving this page to avoid wafers being removed from the lot inadvertently.

How to Modify Lot Items

Follow these steps to modify lot items:

1. Access the Lot Modify Items page.
2. Select the lot using the Selection Id field. The application displays lot details in the Lots grid and any wafer details in the Item Details grid.
3. Select (or leave selected) the Update Only check box if you want to avoid inadvertent removal of wafer items already existing for the lot but not displayed on the page.
4. What do you need to do?

If you want to. . .

Then . . .

Add all of the wafers for the lot.
a. Click Auto Generate below the Item Details grid. The application generates the wafer information and displays it in the grid.
b. Go to step 5.

Add a wafer to the lot.
a. Click Add new row on the Item Details grid toolbar. A row is activated in the grid.
b. Add the wafer information on the activated row.
c. Go to step 5.

Update an existing wafer
a. Select the Item Details grid row for the wafer that you want to update. The application enables the fields on the selected row.
b. Update the fields as needed.
c. Go to step 5.

Remove an existing wafer
a. Select the Item Details grid row for the wafer that you want to remove. The application enables the Delete selected row icon on the grid toolbar.
b. Click Delete selected row.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
