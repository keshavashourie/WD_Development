Surveillance Activation

The Surveillance Activation page enables you to select a surveillance requirement and bind it to any of these items:

• Resource
• Resource Group
• Operation
• Work Center

How to Activate a Surveillance Requirement

Follow these steps to activate a surveillance requirement:

1. Open the Surveillance Activation page.
2. Select the surveillance requirement from the Surveillance field.
3. Select the Surveillance Type. The application displays all instances of the selected type. A check box that is already selected indicates that the selected requirement is already activated for that instance. The Resource Group Filter field is also displayed if you have selected Resource.
4. Select the check box of each surveillance type instance for which you want to activate the requirement.
5. Click Submit. The application displays a success message.
