Lot Combine

Lot Combine enables you to combine two or more lots either fully or partially. You can also split onto a new lot if a New Lot ID is entered or if the Auto Set New Lot Id check box is selected. Combine does not occur if only one lot is specified.

Important: You must use Lot Combine By Items for lots at a wafer or item processing step. Refer to "Lot Combine By Items" for information.

How to Perform Lot Combine

Follow these steps to perform Lot Combine:

1. Access the Lot Combine page.
2. Select one or more lots using the Selection Id field. The application populates the Lots grid with the selected lot or lots, the Target (Main) Lot grid with the first lot selected, and also the Source Lot(s) grid with any additional lots selected.
3. What is your target lot?

If you want to. . .

Then . . .

Use the default target displayed in the Main Lot field.

Go to step 4.

Change the target lot
a. Select the new target lot from the Main Lot list. The application moves the old target lot to the source grid and moves the new target lot to the target grid.
b. Go to step 4.

Create a new target lot

Either enter a New Lot Id or select the Auto Set New Lot Id check box. The application moves all of the Target Item(s) grid rows to the Source Item(s) grid.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Submit. The application displays a success message.
