Lot Reject

Lot Reject enables you to reject quantity from a lot. Rejects are done at the Qty level. Reject Qty for lots at an item-processing step is specified within individual wafers. Rejecting the entire Qty from a wafer removes the wafer from the lot.

How to Use Lot Reject to Remove Quantity From a Lot

Follow these steps to use Lot Reject to remove quantity from a lot:

1. Open the Lot Reject page.
2. Select the lot using the Selection Id field. The application displays the lot details in the Lot Info grid. It also displays wafers in the Items grid if the lot is in an item-processing step.
3. Is the selected lot in an item processing step?

If . . .

Then . . .

Yes, the lot is in an item-processing step
a. Click Add new row on the Details grid toolbar. A row is activated in the grid.
b. Select the Item Id.
c. Select a reason for the reject from the Loss Reasons field.
d. Enter the Qty being rejected in the Defects Qty field.
e. Go to step 4.

No, the lot is not in an item-processing step
a. Click Add new row on the Details grid toolbar. A row is activated in the grid.
b. Select a reason for the reject from the Loss Reasons field.
c. Enter the Qty being rejected in the Reject Qty field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Submit. The application displays a success message.
