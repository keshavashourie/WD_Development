Lot Modify Run Numbers

Lot Modify Run Numbers enables you to add, update, or remove run numbers for a lot. Run numbers generally represent the Fabrication Lot Numbers that form a lot. For example, wafers received into the assembly plant have a run number assigned to the lot. Run numbers are copied when a lot splits and combines, resulting in additional run numbers.

You have the option of specifying run numbers for a lot during Lot Start. Subsequent transactions like Split and Combine automatically copy the run numbers to the child or parent lots respectively.

How to Add, Update, or Remove Run Numbers

Follow these steps to add, update, or remove run numbers for a lot:

1. Access the Lot Modify Run Numbers page.
2. Select a lot using the Selection Id field. The application displays lot details in the Lots grid and any existing run numbers for the lot in the Run Numbers grid.
3. What type of maintenance do you want to do?

If you want to. . .

Then . . .

Add a run number
a. Click Add new row on the Run Numbers grid toolbar. A row is activated in the grid.
b. Enter the Run Number.
c. Go to step 4.

Update an existing run number
a. Click any of the columns on the row with the run number that you want to update. The application enables the fields.
b. Change the field or fields on the selected row as needed.
c. Go to step 4.

Remove an existing run number
a. Select the row with the run number that you want to remove. Delete selected row is enabled on the grid toolbar.
b. Click Delete selected row.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Submit. The application displays a success message.
