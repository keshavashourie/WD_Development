Track Label Detail Update

The Track Label Detail Update page enables you to update details about previously generated labels. The changes you make to labels through this page affect only that particular label for future printings. The transaction does not change the related Label Plan modeling object and will not affect future labels printed with the same label plan.

Track Label Detail Update Page Field Definitions

This table defines the fields on the Track Label Detail Update page.

Field

Definition

Type

Label ID

Bar code value of the label to be updated. Contact the system administrator to obtain this value if you cannot scan the label or if the content is illegible.

Required

Employee

Employee performing this transaction if different than the user currently logged in.

Optional

Label Status

Status of the label. Available values are UNUSED and INUSE.

Optional

Label Qty

Quantity value of the label.

Required

Packed Into ID

Label ID into which the label is packed.

Optional

Print On Update

Indicates whether the label should be reprinted when it is updated.

Optional

Apply status to all labels in the same set

Check box to indicate whether to apply status to all labels within a set.

Note: The status will be applied to all labels of the same level if the status is INUSE or UNUSED. The status will be applied to all labels including the child labels if the status is INVALID.

Optional

Label Sources Details grid

Source names and quantities that make up the entire label quantity. You can add, edit, or remove label sources to the grid as long as the sources are valid.

Required

Source ID

Identifier of the label source.

Note: The source ID must belong to the label.

Required

Qty

Total number of labels printed in the set. The total of all values in the Qty column must match the value of the Label Qty field.

Required

How to Update Label Details

Follow these steps to update label details:

1. Open the Track Label Detail Update page.
2. Enter the label ID of the label to update in the Label ID field and press the Tab key. The application displays the label details.
3. Make updates to the label details according to your business requirements.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Submit. The application displays a success message.
