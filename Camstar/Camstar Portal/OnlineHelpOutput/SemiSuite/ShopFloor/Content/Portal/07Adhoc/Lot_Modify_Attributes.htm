Lot Modify Attributes

Attributes are used to store and update information about containers and lots as they go through the manufacturing process. There are three types of attributes:

• Container
• Lot Attributes
• Lot AttributesEx

You can update an existing attribute value using the Lot Modify Attributes page.

Note: A developer or system administrator must create new attributes before they will appear on the Lot Modify Attributes page. Container and Lot Attributes must be created in Designer and then set up using the Attribute Setup modeling page. New attributes of type Lot AttributesEx can be created at the same time they are set up using the Attribute Setup page without having to be established in Designer first.

When Using Lot Modify Attributes

This table lists attribute specific validations and processing notes.

Attribute

Validations and Notes

Qty or Qty2
• Lot must be in Inventory or WIP.
• A value is required and cannot be less than zero.
• Cannot be modified if the lot has schedules not prepared and the current value is zero. This is to ensure that the scheduling logic is not affected.
• For Qty only—Cannot be set to zero if the lot’s Qty is not zero. This is to ensure that the primary tracking quantity is not removed, as it will affect WIP tracking. Use Lot Bonus or Lot Reject instead.
• For Qty2 only—Cannot be set to zero if the lot’s Qty is zero. This is to ensure that the lot has a quantity to track. It cannot be modified if the lot is in a Wafer or Item Processing step. This is to ensure WIP tracking details are not affected.

The quantity is added to the schedule's Total Bonus Qty if the lot has a schedule and the quantity type matches the attribute. The quantity reduced is added to its schedule's Total Scrap Reject Qty.

Product

• Cannot be null.
• Cannot be modified if a schedule has been assigned.
• Product must have Is Available flag set to true.

Note:  If the Attribute is Product - OPN, Revision, or both, the Product will be set for the lot if the lot’s corresponding attributes are different.

How to Use the Lot Modify Attributes Page

Follow these steps to assign and modify one or more attributes for a lot:

1. Access the Lot Modify Attributes page.
2. Select the lot using the Selection Id field. The application displays lot details in the Lots grid and any configured attributes in the Service Attributes grid.
3. Perform these steps to modify an attribute value:
• Click the Service Attributes grid row with the attribute to be modified. The application enables the Attribute Value field.
• Enter the Attribute Value.

Or

Click to select a value from a pop-up of configured valid values.
4. Repeat step 3 as needed.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
