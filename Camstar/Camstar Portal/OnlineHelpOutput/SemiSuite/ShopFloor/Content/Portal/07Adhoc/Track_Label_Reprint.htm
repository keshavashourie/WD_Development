Track Label Reprint

The Track Label Reprint page enables you to manually reprint labels from a label plan.

This table defines the fields on the Track Label Reprint page.

How to Reprint Labels

Follow these steps to reprint labels:

1. Open the Track Label Reprint page.
2. Enter one of the following:

To print . . .

Perform the following . . .

One or more labels
a. Enter a lot ID in the Lot Id field. The application displays all of the label IDs associated with the lot in the Label ID To Reprint grid.
b. Select one or more labels to reprint in the Label ID To Reprint grid.

A single label
a. Enter a specific label ID to reprint in the Label ID field. The application displays the label ID in the Label ID To Reprint grid.
b. Select the Label ID of the label in the Label ID To Reprint grid.
3. Click Submit. The application displays a success message.
