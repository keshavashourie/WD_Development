Ad-Hoc WIP Data

The Ad-Hoc WIP Data page enables you to collect WIP data on an as-needed basis instead of only when processing within a configured spec or process spec. You can also use this page to update existing Ad-Hoc WIP data.

WIP Data collected using the Ad-Hoc WIP Data page is stored separately from other WIP Data. The Ad-Hoc WIP Data Record stores transaction and object-level information. The Ad-Hoc WIP Data Details records store the actual data collected. Each details record represents a specific data value that was collected.

Note: In 8.7, Ad-Hoc WIP Data has been integrated with Inline SPC where the page is supporting inline SPC data collection based on setting configuration. For information on Inline SPC, refer to Opcenter Execution Semiconductor Statistical Process Control Reference Guide.

Before Using the Ad-Hoc WIP Data Page

The Ad-Hoc WIP Data and related objects must be configured in Modeling before you can successfully use the Ad-Hoc WIP Data page.

How to Record Ad-Hoc WIP Data

Follow these steps to record ad-hoc WIP data:

1. Access the Ad-Hoc WIP Data page.
2. Select the Object Type (Ad-Hoc WIP Data Setup). The application populates the WIP Data Setup field list and automatically selects the first entry.  Any existing Ad-Hoc records for the selected entry are displayed in the upper grid. Any WIP Data Names configured for the selected entry are displayed in the lower grid.
3. Select a different WIP Data Setup if the default is not the one you need. The application updates the Details grid to reflect the WIP Data Names configured for your selection.
4. Do you need to add a new Ad-Hoc WIP Data collection record or update an existing one?

If you want to. . .

Then . . .

Add a new record.
a. Select the Object Name.
b. Update the Details grid by entering each WIP Data Value collected by clicking the blank WIP Data Value cell for the appropriate WIP Data Name.
c. Go to step 5.

Update an existing record.
a. Select the sequence record from the upper grid. The application populates the Details grid with ad-hoc data values of the selected record.
b. Update the Details grid WIP Data Value entries as needed.
5. Click Submit. The application displays a success message.
