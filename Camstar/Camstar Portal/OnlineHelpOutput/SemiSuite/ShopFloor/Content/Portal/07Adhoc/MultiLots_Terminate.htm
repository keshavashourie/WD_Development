Multi-Lots Terminate

Multi-Lots Terminate is used to terminate carrier containers or lots.

When a carrier is terminated, the application automatically archives it with a new name based on numbering rules (Carrier Rename Rule configuration at Factories modeling). This renaming serves as a means of tracking, allowing for the reuse of the original lot name in future transactions.

Note: Numbering rule must be set prior to termination a carrier container or lot. For Semiconductor, numbering rule can be set at Carrier Rename Rule in Factories modeling. Meanwhile for Industry Solution, numbering rule can be set at Carrier Numbering Rule field. The Numbering Rule Type field must be set to "High Volume/Skip" only. If you have both Semiconductor and Industry Solution numbering rules configurations, the application will prioritize Carrier Rename Rule set in Semiconductor.

Multi-Lots Terminate Page Field Definitions

This table defines the fields on the Multi-Lots Terminate page.

Field

Definition

Selection Id

List field to specify one or more lots to terminate. This field requires at least one lot if the Container field is not set.

The lots:

• Must be active.
• Must not be on hold.
• For Carrier Container, it must not have any child containers.
• For Carrier Container, it must have numbering rule type set to High Volume / Skip.
• Must not be processing in the Equipment.
• Must not be loaded in the Equipment.
• Not allowed to terminate if in Inventory with schedules not prepared.
• Must not be on loan.
• Must not have any Test IQC results still in the PENDING state. This is required to ensure all tests out carried out for the lot.
• Must not have any Test IQC results for Incoming Solderability test still in the FAIL state. This is required to ensure the lot has been properly disposed.

Employee

Employee performing this transaction if different than the user currently logged in.

Terminate Reason

Required field to specify the reason to terminate the lot or lots.

An error will be generated if the reason used to terminate lots in WIP but with its Allow In WIP flag set to false.

Terminate Account

Optional field to specify the account to charge to for the termination. This is used for reporting purpose.

Show/Hide additional fields

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.
