Multi-Lots Un-Terminate

Multi-Lots Un-Terminate is used to un-terminate one or more lots.

Multi-Lots Un-Terminate Page Field Definitions

This table defines the fields on the Multi-Lots Un-Terminate page.

Field

Definition

Selection Id

List field to specify one or more lots to un-terminate. This field requires at least one lot if the Container field is not set.

Employee

Employee performing this transaction if different than the user currently logged in.

Un-Terminate Reason

Required field to specify the reason to un-terminate the lot or lots in WIP.

Un-Terminate Workflow

Workflow to move the lot to after un-terminate. Must be specified for the following scenario:

• Lot is in WIP.
• Lot has no schedule.

All other scenarios are not allowed to specify the Un-Terminate Workflow and Workflow Step.

Un-Terminate Workflow Step

Inventory step within the Un-Terminate Workflow. Same requirement as Un-Terminate Workflow.

Show/Hide additional fields

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.
