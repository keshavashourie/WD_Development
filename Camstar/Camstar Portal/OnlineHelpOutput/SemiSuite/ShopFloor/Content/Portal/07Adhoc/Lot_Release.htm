Lot Release

Lot Release is used to release one or more lots from hold or further hold. Further holds can be released one or more at a time without releasing the lot from the first hold.

How to Release a Lot from Hold

Follow these steps to release a lot from Hold:

1. Access the Lot Release page.
2. Select the lot or lots using the Selection Id field. The application populates the Details grid with the selected lot or lots.
3. Select a Release Reason for each lot displayed in the grid.
4. Click Submit. The application displays a success message.
