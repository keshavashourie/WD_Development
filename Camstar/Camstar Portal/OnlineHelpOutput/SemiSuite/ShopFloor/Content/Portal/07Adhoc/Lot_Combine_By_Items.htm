Lot Combine By Items

Lot Combine By Items enables you to combine two or more wafer-based lots either fully or partially. You can also split wafers onto a new lot if a New Lot Id is entered or if the Auto Set New Lot Id check box is selected. Combine is skipped if only one lot is specified.

Note: You must use this page—not Lot Combine—for lots at wafer or item processing steps.

How to Perform Lot Combine By Items

Follow these steps to perform Lot Combine By Items:

1. Access the Lot Combine By Items page.
2. Select one or more wafer-based lots using the Selection Id field. The application populates the page as follows:
• Populates the Lots grid with details of the selected lot or lots.
• Populates the Main Lot field with the first lot selected.
• Populates the Target Item(s) grid with wafers in the first lot that was selected.
• Populates the Source Item(s) grid with wafers in the second lot (if one was selected).
3. What is your target lot?

If you want to. . .

Then . . .

Use the default target displayed in the Main Lot field.

Go to step 4.

Change the target lot
a. Select the new target lot from the Main Lotlist. The application moves the old target lot to the source grid and moves the new target lot to the target grid.
b. Go to step 4.

Create a new target lot

Either enter a New Lot Id or select the Auto Set New Lot Id check box. The application moves all of the Target Item(s) grid rows to the Source Item(s) grid.
Note: When combining wafers with different products, the combined wafers will inherit the Product information from the Main Lot.
4. Select the check box for each Source Item(s) grid wafer that you want to move to the target lot.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
