Surveillance Management

Surveillance Requirements enforce data collection for any of the following:

• Resources
• Resource Groups
• Operations
• Work Centers

The Surveillance Management page enables you to complete a surveillance data collection that has become due. The page contains multiple search filters for finding surveillance requirements . It displays search results in a grid. Clicking Search without selecting filters produces a list of all surveillance requirements that have been activated for at least one Operation, Resource, Resource Group, or Work Center.

Selecting a requirement in the grid causes the application to populate the fields below the grid with information from the selected requirement. Clicking Complete causes the application to display a pop-up with fields for any data collections (user-defined or parametric) that have been configured for the selected requirement.

How to Complete a Surveillance Requirement for a Resource

Follow these steps to complete a surveillance requirement for a resource:

1. Open the Surveillance Management page.
2. Enter values in the Enter Search Criteria fields to limit the display of resources.
3. Click Search. The Search Results grid displays status information for activated surveillance requirements that match the search criteria entered. All possible results are displayed if no search criteria is selected.
4. Click the row to select a requirement that is either pending, due, or past-due. Details of the requirement appear in the display only fields below the grid .
5. Click Complete. The application displays a success message.
