Modify Multi-Lots Attributes

Lot Attributes are used to store and update information about containers and lots as they go through the manufacturing process. Modify Multi-Lots Attributes enables you to modify one attribute for one or more lots.

Attribute

Field to specify the attribute to update or add (for Lot Attributes Ex type).

Note: Only those attributes to which the user has access can be updated.

Additional verification if the Attribute is Qty or Qty2:

• Lot must be in Inventory or WIP.
• A value must be set and cannot be less than 0.
• Cannot be modified if the lot has schedules not prepared and the current value is 0. This is to ensure the scheduling logic is not affected.
• For Qty only: It cannot be set to 0 if the lot’s Qty is not 0. This is to ensure the primary tracking quantity is not removed as it will affect WIP tracking. Use Lot Bonus or Lot Reject instead.
• For Qty2 only: It cannot be set to 0 if the lot’s Qty is 0. This is to ensure the lot has a quantity to track. It cannot be modified if the lot is in a Wafer or Item Processing step. This is to ensure WIP tracking details are not affected.
• Additional logic if the Attribute is Qty or Qty2: If the lot has a schedule and the schedule quantity type matches the attribute, the additional quantity will be added to its schedule’s Total Bonus Qty. The quantity reduced will be added to its schedule’s Total Scrap Reject Qty.

Additional verification if the Attribute is Product:

• Cannot be nullified.
• Cannot be modified if a schedule has been assigned.
• The Product must be available (Is Available flag is true).

Additional logic if the Attribute is Product - OPN, Revision, or both of the Product will be set for the lot if the lot’s corresponding attributes are different.

How to Modify a Lot Attribute for Multiple Lots

Follow these steps to modify a lot attribute for multiple lots:

1. Access the Modify Multi-Lots Attributes page.
2. Select the lots to be modified using the Selection Id field. The application displays lot details in the Lots grid.
3. Select the Attribute to be modified (unless the default is the one you want).
4. Do you want to enter the Attribute Value directly or select from a list of valid values?

If you want to. . .

Then . . .

Enter the value
a. Enter the value into the Attribute Value field.
b. Go to step 5.

Select the value from a list of valid values
a. Click the field icon next to the Attribute Value field. The application displays a pop-up or else a message that no selections are available.
b. Select the value and click OK if the pop-up is displayed. Otherwise, enter the value into the Attribute Value field.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
