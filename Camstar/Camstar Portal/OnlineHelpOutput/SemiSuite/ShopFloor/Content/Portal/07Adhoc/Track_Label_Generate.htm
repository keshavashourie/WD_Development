Track Label Generate

The Track Label Generate page enables you to manually generate all the labels required for packing wafers (for example, reels, boxes, bags, and so on) based on the selected label plan. The Track Label Generate page prints all the parent and child labels at one time based on the label setup. You can use the Track Label Generate page to print all labels before packaging or use WIP Main to print labels on-demand during the packaging step. You cannot print labels for the same lot in the same step from both WIP Main and the Track Label Generate page.

About Parent and Child Labels

Parent and child relationships are determined by the selected label plan. For example, during tape and reel packing, a lot quantity is split and packed into multiple individual reels. Each reel is uniquely identified and requires a label. Each reel is further packed into additional packaging (dry pack) before being packed into a larger box (multiple reels in a single box). The dry packs and boxes also require labels. You can print all of the labels required for packing (for reels, dry packs, and boxes) by creating a parent-child relationship between the label types.

For example, you have two lots: P_LOT001 with 100 units and P_LOT002 with 50 units. Each reel consists of 50 units. This means that the quantity of the two lots requires three reels. Each reel requires its own label.

In addition, each reel is packed in a dry bag. Each dry bag requires a label.

Finally, the dry bags are packed two per box. Each box requires a label.

Based on the above quantity requirements, the labels to generate are:

• 3 reel labels: (100 units + 50 units)/50 units per reel = 3 reels at 1 label per reel.
• 3 dry bag labels: 3 reels/ 1 dry bag per reel = 3 dry bags at 1 label per dry bag.
• 2 box labels: 3 dry bags/ 2 dry bags per box = 2 boxes at 1 label per box.

In this case, the number of labels required for the dry packs is determined by the number of reels, and the number of labels required for the boxes that contain each dry pack is determined by the number of dry packs. This forms a parent-child relationship between the reel labels and dry bag labels, and between the dry bag labels and the box labels.

Determining Number of Labels

The application calculates the number of labels to print based on quantity per label and either lot quantity or number of items in the lot. By default, the application uses the number of items if the lot is in an item-based processing step and lot quantity if the lot is in a quantity-based processing step.

The Track Label Generate page contains a Qty Based check box and an Item Based check box. The application disables the check box representing the applicable default and enables you to select the other check box. You can switch from a default quantity basis by selecting the Item Based check box. You can switch from a default item basis by selecting the Qty Based check box.

Before Generating Labels

Before you can generate labels, you must define one or more label plans. Refer to Opcenter Execution Semiconductor Modeling Guide for information on creating label plans.

How to Generate Labels

Follow these steps to generate labels:

1. Open the Track Label Generate page.
2. Enter an identifier for the lot in the Lot Id field. The application displays the lot details in the Lots grid.
3. Enter the label plan to use to generate the label for the lot in the Label Plan field. The application displays the label plan details in the Label Plan Details grid.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Submit. The application displays a success message.
