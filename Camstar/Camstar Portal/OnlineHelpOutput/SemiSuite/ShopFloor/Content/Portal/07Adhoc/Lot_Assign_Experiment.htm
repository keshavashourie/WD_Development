Lot Assign Experiment

The Lot Assign Experiment page enables you to assign an Experiment Plan to a lot. Experiment plans are controlled, atypical processing plans that allow an engineer to test an idea.

You model experiments through an Experiment Plan object, which itself is made up of other named data objects. Experiment Plans enable you to define auto-splits, auto-holds, alternate check sheets, special WIP and slot instructions, and alternate supplementary specs for the lot. Experiment Plans must be approved before you can assign the experiment plan to a lot. Refer to the Opcenter Execution Semiconductor Modeling Guide for more information about the Experiment Plan modeling object.

You can also use the Lot Assign Experiment page to assign wafers to slots in carriers that are not serialized. This means that you can further limit the experiment plan to only certain wafers in a single carrier.

When Assigning Experiment Plans to Lots

When assigning Experiment Plans to lots:

• You can assign experiment plans to lots using the Lot Assign Experiment page or the Blanket Experiments matrix object. Experiment plan assignments set on the Lot Assign Experiment page override experiment plans assigned by the Blanket Experiments matrix object. Refer to the Opcenter Execution Semiconductor Modeling Guide for information on the Blanket Experiments matrix object.
• You can only attach Experiment Plans whose Experiment Plan Status field is set to Approved. Refer to the Opcenter Execution Semiconductor Modeling Guide for information on the Experiment Plan approval process.
• You can attach the same Experiment Plan to multiple lots.
• You can attach multiple Experiment Plans to a lot.
• You can assign the location of a wafer to specific slots in a serialized wafer carrier. In order to assign wafers to specific slots in the wafer carrier, you must first define a wafer carrier. Refer to the Opcenter Execution Semiconductor Modeling Guide for information about wafer carriers.
• You can assign a wafer carrier based on the selection of a Wafer Carrier Family that coincides with the carrier structure used within manufacturing if you do not work with serialized wafer carriers.

When Working with Wafer Carrier Family Slots

Keep these facts in mind when working with wafer carrier family slots:

• You cannot map a wafer to a slot that is down.
• You can remove wafers only from those wafer carriers that have not been moved into WIP or wafer carriers that are not currently processing on equipment.
• You must remove all of the wafers from a single lot before you submit the carrier when you remove wafers from the wafer carrier.
• You cannot submit a carrier that contains partial lots.
• You cannot create and assign wafer carrier family slots if the lot already has an assigned serialized wafer carrier.

Before Assigning Experiment Plans to Lots

Before you can assign an Experiment Plan to a lot, you must perform the following:

1. Create instances of the following modeling objects as required by the Experiment Plan.
• Exp Auto Hold
• Exp Auto Split
• Exp Auto SS
• Exp Special Instructions
• Exp Special Check Sheet

Refer to the Opcenter Execution Semiconductor Modeling Guide for information on these modeling objects.

2. Create and approve an Experiment Plan. Refer to the Opcenter Execution Semiconductor Modeling Guide for information on the Experiment Plan modeling object and the approval process.
3. Create and schedule the lots to which you want to attach Experiment Plans.

How to Assign Experiment Plans to Lots

Follow these steps to assign Experiment Plans to lots:

1. Open the Lot Assign Experiment page.
2. Enter the name of the lot to which you will assign the Experiment Plan in the Selection Id field. The application displays the lot in the Lots grid and wafer information in the Wafer List grid.
3. In the Lot Assign Exp Details grid, specify the Experiment Plan to attach to the lot in the Experiment Plan column.
4. Select the Is Activated check box if you want to make the Experiment Plan active.
Important: The application ignores any overrides specified by the experiment plan if you do not select the Is Activated check box.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Complete the procedure in "How to Assign Wafers to Slots" to assign wafers to slots.
Note: You do have to assign wafers to slots when working with a quantity-based lot or if you have already assigned a serialized wafer carrier to the lot using the Assign Carrier Slot Map page. Refer to "Assign Carrier Slot Map" for information on the Assign Carrier Slot Map page.

Or

Click Submit.The application assigns the Experiment Plan to the lot and displays a success message. The application populates the Assign by User with the ID of the users that assigned the Experiment Plan to the lot. If you selected the Is Activated check box, the application populates the Activated By User column with the ID of the user that activated the Experiment Plan.

How to Assign Wafers to Slots

Follow these steps to assign individual wafers to slots:

Note: You do have to assign wafers to slots when working with a quantity-based lot or if you have already assigned a serialized wafer carrier to the lot using the Assign Carrier Slot Map page. Refer to "Assign Carrier Slot Map" for information on the Assign Carrier Slot Map page.
1. Complete the procedure in "How to Assign Experiment Plans to Lots."
2. Enter a wafer carrier family in the Wafer Carrier Family field.
Note: Wafer Carriers are not always required. You do not need to do this if working with a Qty based lot. Also, you do not need to do this if you already assigned a serialized Wafer Carrier via Assign Carrier Slot Map.
3. Perform one of the following:

If you are assigning . . .

Perform the following . . .

A single wafer to a slot
a. Click the arrow in the row of the Wafer List grid that contains the wafer you want to assign to a slot.
b. Enter the slot number to which the wafer from the selected row will be assigned in the Slot Number field.
c. Click Add. The application displays the wafer information in the Carrier Slot Map grid.

All of the wafers to slots

Click Add ALL. The application displays the wafer information in the Carrier Slot Map grid.

How to Remove Wafers from Carrier Slots

Follow these steps to remove wafers from wafer slots:

1. Open the Lot Assign Experiment page.
2. Enter the name of the lot from which you want to remove wafers from slots in the Selection Id field and click . The application displays the lot in the Lots grid and wafer information in the Wafer List grid.
3. Perform one of the following:

If you are removing. . .

Perform the following. . .

A single wafer from the carrier
a. Select the slot number that contains the wafer you want to remove from the Slot Number field.
b. Click Remove. The application removes the wafer information from the mapped slot in the Carrier Slot Map grid.

All of the wafers from the carrier

Click Remove ALL. The application removes all wafer information from the Carrier Slot Map grid.
