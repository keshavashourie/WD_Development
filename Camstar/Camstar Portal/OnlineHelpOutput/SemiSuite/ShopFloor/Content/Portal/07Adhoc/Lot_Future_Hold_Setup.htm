Lot Future Hold Setup

Lot Future Hold Setup is used to add or remove future hold instructions for one or more lots.

How to Set Up Future Holds for One or More Lots

Follow these steps to set up future holds for one or more lots:

1. Access the Lot Future Hold Setup page.
2. Select one or more lots using the Selection Id field. The application populates the Lots grid with details of the selected lot or lots.
3. Click Add new row on the Details grid. A row is activated in the grid.
4. Select a Spec or WIP Step.
5. Select a Hold Reason.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Submit. The application displays a success message.
