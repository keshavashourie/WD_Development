Lot Modify Defects

Lot Modify Defects enables you to modify defects collected previously at a WIP processing step. Defects collected during WIP processing are added to the lot’s Lot Defects sub-entity list. Defects collected are transacted using a WIP Spec with the Yield Off Defects flag set to true during Lot Move Out. A lot's quantity may change as it moves through the workflow before defects are yielded off. Lot Modify Defects can be used to correct the defects information if required.

How to Modify Defect Information

Follow these steps to modify defect information:

1. Access the Lot Modify Defects page.
2. Select the lot using the Selection Id field. The application displays lot details in the Lots grid and any defect information in the Lot Defects grid.
3. Select the Lot Defects grid row with the defect information you want to modify. The grid row fields become enabled.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Repeat steps 3-5 for each additional bin you want to modify.
6. Click Submit. The application displays a success message.
