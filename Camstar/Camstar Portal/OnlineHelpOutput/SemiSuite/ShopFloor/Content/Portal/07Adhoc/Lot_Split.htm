Lot Split

Lot Split is used to split a lot that is not in an item processing step into one or more child lots.

Important: You must use Lot Split By Items for lots at a wafer or item processing step.

Lot Split Page Field Definitions

This table defines the fields on the Lot Split page.

Field

Selection Id

Field to specify the lot to split. The lot:

• Must be active.
• Must not be on hold.
• Must not have schedules not prepared.
• Must not be on loan.

For Qty Processing:

• The lot’s insertion must not have any quantity processed if it has not completed the insertion.

Note: These Qty Processing verifications are done to ensure the quantity to process will not be affected since the insertion is done using Qty Processing but wafers or items are used to split instead.

Split To Work Order

Specifies the Work Order for the child lot. Conditions if specified:

• The lot must not be in In-Transit or Inventory.
• The work order must be in the available status.
• If the work order has a product defined, the Split To Product (if specified) must match the value. This is to ensure the right Product is used.
• If the work order has a process spec defined, the Split To Process Spec (if specified) must match the value. This is to ensure the right Process Spec is used.
• If the work order has a schedule type defined and Split To Process Spec is specified, the Split To Process Spec’s object type must match the value.

How to Split a Lot

Follow these steps to split a lot:

1. Access the Lot Split page.
2. Select the lot to be split using the Selection Id field. The application populates the Lots grid with details of the selected lot .
3. Click Add new row on the Details grid toolbar. A row is activated in the grid.
4. Enter the Split Qty (Standby Qty).
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
