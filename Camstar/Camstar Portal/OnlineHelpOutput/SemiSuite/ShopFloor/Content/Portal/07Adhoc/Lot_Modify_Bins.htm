Lot Modify Bins

Lot Modify Bins enables you to modify bin information collected at a binning step. The last binning information collected is copied to the Lot Bins sub-entity list for the lot. This enables the lot to be split at subsequent steps. A lot's quantity may change as it moves through the workflow before splitting is required. Lot Modify Bins enables you to correct the binning information as needed.

How to Modify Binning Information using Lot Modify Bins

Follow these steps to modify binning information using the Lot Modify Bins page:

1. Access the Lot Modify Bins page.
2. Select the lot using the Selection Id field. The application displays lot details in the Lots grid and any binning information in the Bins grid.
3. Select the Bins grid row with the bin you want to modify. The grid row fields become enabled.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Repeat steps 3-5 for each additional bin you want to modify.
6. Click Submit. The application displays a success message.
