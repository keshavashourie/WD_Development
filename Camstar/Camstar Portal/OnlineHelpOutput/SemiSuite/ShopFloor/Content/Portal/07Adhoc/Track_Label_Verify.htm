Track Label Verify

The Track Label Verify page enables you to verify label correctness by association. You can use this screen to perform two different types of verification:

• Parent-child verification – Enables you to verify the parent-child relationship of label IDs (for example, reels to a box).
• Set verification – Enables you to verify whether a given group of labels are part of one set. You might use this verification to verify that the given labels belong to the same lot.

How to Verify Labels

Follow these steps to verify labels:

1. Open the Track Label Verify page.
2. Perform one of the following:

To verify . . .

Perform the following . . .

The parent-child relationship between labels.
a. Enter Parent-Child in the Verification Plan field.
b. Enter a parent label ID in the Main Label ID field.
c. Enter a child label in the Child Label ID field and press the Tab key. The application displays the child label ID in the Child Label ID grid.
d. Repeat step c for all child labels.

That the labels are all part of the same set.
a. Enter Set Verification in the Verification Plan field.
b. Enter a label in the Child Label ID field and press the Tab key. The application displays the child label ID in the Child Label ID grid.
c. Repeat step b for all labels in the set.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit. The application displays a success message.
