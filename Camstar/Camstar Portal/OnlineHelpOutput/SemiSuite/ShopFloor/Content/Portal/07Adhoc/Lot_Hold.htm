Lot Hold

Lot Hold enables you to put one or more lots on hold. You can put an additional hold on a lot even if the lot is already on hold.

Before Using Lot Hold

At least one Hold Reason must be added in Modeling before you can place a lot on hold. Also, keep in mind that the Hold Location options available for a lot are based on which locations have been configured for the step at which the lot currently resides.

How to Place a Lot on Hold

Follow these steps to use Lot Hold to place a lot on hold:

1. Open the Lot Hold page.
2. Enter the lot name in the Selection Id field. The application displays the lot details in the Details grid.
3. Click the Hold Reason cell on the row with the lot that you want to place on hold. The application enables the field.
4. Select the Hold Reason.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
