Lot Split By Items

Lot Split By Items is used to split lots at the Wafer or Item Processing step into one or more child lots.

To Carrier

Specifies the Wafer Carrier where the newly Split Lot will be assigned. The application populates all standard carriers, carriers that currently with no assigned slots and carriers that assigned to the parent Lot being split.

• If a Wafer Carrier is selected or the Parent Lot is already assigned to a Wafer Carrier, the Assign Slots button and three fields will be enabled. The three fields are Wafer Handler Equipment, Recipe and Slot Assignment Method.
• If a non-Wafer Carrier is selected, the button and the three fields will be disabled.

Note: If a “To Carrier” is not selected but the Parent Lot is on a Carrier, the Split Lots will remain on the current Carrier.

If the Parent Lot is already assigned to a Wafer Carrier, each Split records in the Details grid can default the “To Carrier” field to the same Wafer Carrier.

Split To Work Order

Specifies the Work Order for the child lot. Conditions if specified:

• The lot must not be in In-Transit or Inventory.
• The work order must be in the available status.
• If the work order has a product defined, the Split To Product (if specified) must match the value. This is to ensure the right Product is used.
• If the work order has a process spec defined, the Split To Process Spec (if specified) must match the value. This is to ensure the right Process Spec is used.
• If the work order has a schedule type defined and Split To Process Spec is specified, the Split To Process Spec’s object type must match the value.

How to Split a Lot By Items

Follow these steps to split a lot by items:

1. Access the Lot Split By Items page.
2. Select the lot to be split using the Selection Id field. The application populates the Lots grid with details of the selected lot .
3. Click Add new row on the Details grid toolbar. A row is activated in the grid.
4. Enter the To Lot Id in the Details grid.
5. Click anywhere within the Items grid. The application populates the Items grid with items in selected source lot.
6. Select the check box on the Items grid for each item from which you want to split.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Submit. The application displays a success message.
