Container Closure (HPE)

The Container Closure (HPE) page offers functionality to terminate multiple or all containers at the same time. The page accepts individual containers, carriers, work orders and manufacturing orders. If a parent container is entered at the Selection ID field, the application will display all child containers associated with the entered parent. You are able to select carrier containers or child containers from the grid to terminate. Selecting a child container will automatically disassociate it from its carrier (parent) prior to termination.

If all associated containers are terminated, the application will rename the parent/carrier container based on numbering rule set in Factory.

The Container Closure process is intended to provide additional functionality related to Single Wafer (Item) Tracking "described in Chapter 21.

Note: Container Closure (HPE) page has been integrated with High Performance Engine (HPE). HPE increases transaction efficiency as the application processes transactions on the database rather than the application server. Refer to Opcenter™ Execution Core Technical Reference: High Performance Engine for information.

Automation Services for Container Closure (HPE)

Optionally, you can utilize automation services to perform Container Closure (HPE) transactions. Refer to "Close Containers using "scsDBContainerClosure" Service" for information.

How to Terminate Containers

Follow these steps to terminate containers in Container Closure (HPE) page:

1. Open the Container Closure (HPE) page.
2. Enter the name of the container which you want to terminate in Selection Id field or using the Scan to select a group of containers (Parent Container / Work Order) field . The application displays all containers and child containers in the Container Closure Details grid.
3. In the Container Closure Details grid, select set of carrier or individual containers to be terminated by checking the left check-box on the grid.
4. Enter Terminate Reason.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application terminates all the selected container and child containers.
