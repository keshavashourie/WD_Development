Equipment Setup

The Equipment Setup tab enables you to set up equipment parameters, tools, and other information.

Equipment Setup Tab Field Definitions

This table defines the fields on the Equipment Setup tab.

Field

Definition

Mask

Mask placed on the resource.

Note: The mast list contains all Masks associated to the Mask Set configured on the PN. Only Masks not linked to other equipment and are currently not under maintenance will be displayed.

Recipe

Recipe used to set up the resource.

Note: The recipe list contains Active recipes only. Inactive recipes are not available for selection. The recipes are limited to those within an assigned recipe group if a recipe group has been assigned for the selected equipment.

Scan to Add Tools

Enter or scan a tool to use for the resource.

Tools grid

Grid listing tools used for the selected resource.

Params grid

Grid listing parameters that must be entered for the selected resource.

Comments

Enter free form comments for association with the selected resource.

Recipe Messages

Messages about recipe requirements and availability appear on the Activities panel on the Main tab.

These are examples of the types of recipe-related messages that may appear:

• Recipe X Rev Y is required—This message means that a specific recipe is required and that the user must review the Equipment Setup tab to ensure the correct recipe is selected. The user must change the current configuration to the correct recipe If the recipe is not correct.
• Recipe X Rev Y is currently configured—This message means that a recipe is not required for the current lot but the selected equipment is currently set up with a specific recipe. The user may wish to remove the assigned recipe in this case.

The application displays an error message if a recipe is required and no applicable recipe could be identified.

Viewing Recipe Parameters

Parameters configured for a recipe used in processing the lot can be viewed from the Lot Info pop-up:

• Param Name
• Param Value
• Param Data Type
• Param Min Data Value
• Param Max Data Value
• Param Valid Values

How to View Recipe Parameters

Follow these steps to view recipe parameters:

1. Click Lot Info on the WIP Main toolbar. The Lot Information pop-up appears.
2. Click the Recipe tab. The recipe parameters are displayed.
3. Click Close. The pop-up closes.
