Process Timers

Process timers can be added to specific steps or tasks in the manufacturing process to provide tighter control over the workflow. Process timers control the timing between one WIP Main transaction and another.

A process timer associated with a lot appears in the WIP Main Lots grid in the Timers column. Click the arrows in the Timers column to view timer details.

Disposition Actions

Disposition Actions can be configured for a process timer so that the application performs the actions automatically if the process timer's constraints are violated. This is the list of actions that can be configured as process timer disposition actions:

• Business Rule
• Production Event
• Rework
• Move Non-Std
• Hold
• Future Hold

Refer to the Opcenter Execution Core Shop Floor User Guide for detailed information on the Process Time Enforcement feature. Refer to "Process Time Enforcement" in this guide for aspects of the feature specific to Opcenter Execution Semiconductor.
