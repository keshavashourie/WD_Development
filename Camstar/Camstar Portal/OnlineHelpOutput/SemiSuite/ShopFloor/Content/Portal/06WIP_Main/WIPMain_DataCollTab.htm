Data Collection

WIP processing can be configured to require data collection. The data collection is associated with a spec and can be specified for Track In, Track Out, Complete Insertion and Move Out transactions. The WIP Main page displays a message stating that data collection is required and displays a Data tab next to the Main tab when data collection has been set up for what you are processing. The Data tab enables you to enter data points.

WIP Data Valid Values Pop-up Field Definitions

This table defines the fields on the WIP Data Valid Values pop-up.

Field

Definition

Min Data Value

Lowest value the application allows you to record. The application rejects any value lower than this and the data collection transaction fails. For example, assuming that a scale can read values between 10 oz and 100 oz, a value of 8 oz would not be valid.

Max Data Value

Highest value the application allows you to record. The application rejects any value higher than this and the data collection transaction fails.

Lower Limit

Lower spec limit. Any value lower than this is considered out of acceptable range for making good product.

Upper Limit

Upper spec limit. Any value higher than this is considered out of acceptable range for making good product.

Calculation Formula Expression

Formula configured in WIP Data Setup for the application to calculate a data point value. For an application-calculated data collection, this field holds the formula defined by WIP Data Setup and is used to generate the value.

How to Enter Data Collection Points

Follow these steps to add a data collection point:

1. Select the Data tab. The Data tab displays the data points configured in WIP Data Setup.
2. If a value has not been entered for a data collection point, click the blank cell next to the data collection point name. The application displays a data entry field.
3. Click the notepad next to a data point for which you need help. The application displays the Valid Values pop-up, which enables you to see how the field is edited.
4. Close the Valid Values pop-up when finished viewing.
5. Enter the data point value.
6. Repeat steps 2-5 to enter all other data collection points.
7. Click Submit. The application displays a success message.
8. Click the Main tab to continue with WIP processing.
Note: Each row in the By Item Ids grid represents a wafer item. The data entered on that row should apply to the wafer item on the selected row.
