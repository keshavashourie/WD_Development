Move In

The application enables WIP Main Move In after you select a lot. The lot is moved in from the queue and is ready to process.

WIP Main Move In Page Field Definitions

This table defines the fields on the WIP Main Move In page.

Field

Definition

Required Activities

List of activities that must be completed for the selected lots.

Track in Qty

Amount of product put on the equipment for processing.

Source Equipment grid

Grid displays if the selected lots are at a step that does not require item processing and the lots are currently tracked in to another piece of equipment.

Comments

Free form text box to enter transaction information about the move.

WIP Main Move In Page Button Definitions

This table defines the buttons on the WIP Main Move In page.

Button

Click this button to . . .

EProcedure

Open EProcedure tab for the currently selected lot.

Production Event

Open the Create Production Event tab for the currently selection lot.

Check Sheet

Open the Check Sheet to perform tasks for the currently selected lot.

Modify Maintenance

Open the Maintenance Management pop-up to modify maintenance due.

Clear

Clear all fields on the tab.

Submit

Save the data on the tab.
