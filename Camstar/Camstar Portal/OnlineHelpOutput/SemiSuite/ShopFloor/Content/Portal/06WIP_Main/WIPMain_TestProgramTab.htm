Test Program

Test Program Tab Field Definitions

This table defines the fields on the Test Program tab.

Field

Definition

In Use

Indicates the test programs which are in use.

Process Type

Process to which the test programs are applied.

Test Program Name

Name of the program.

Test Program Major Revision

Major revision number for the program.

Test Program Minor Revision

Minor revision number for the program.

Test Code

Alternate identifier for the test.
