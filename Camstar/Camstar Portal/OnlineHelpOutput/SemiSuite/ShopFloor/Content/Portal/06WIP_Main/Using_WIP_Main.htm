Using WIP Main

The WIP Main page provides a centralized location to perform actions on lots and equipment. The page also serves as a resource for lot and equipment information.

Note: This version of WIP Main is being replaced with "WIP Main Advanced Overview". Some of the newer functionality released in Opcenter Connect Semiconductor 8.0 and later may not be functional in WIP Main.
When Accessing WIP Main

The WIP Main grid is blank when you access WIP Main from the menu. You must select lots or equipment to view data.

WIP Main Lot and Equipment Field Definitions

This table defines the lot and equipment selection fields on the WIP Main page.

Field

Definition

Lot

Select the radio button to access the Lot Selection pop-up.

Equipment

Select the radio button to access the equipment based Lot Selection pop-up.

Selection Id

Enter the ID for a lot, carrier, batch, or piece of equipment.

Employee

Enter the employee ID of the user who is responsible for completing this transaction.

Process Type

One or more sub-processes within a Step or Spec, primarily used in auto-line setups where multiple equipment types are connected in a single step. A lot must complete all assigned Process Types before proceeding to the next step. If no Process Types are specified for the Step Name or Spec, the system automatically applies the default "NORMAL" Process Type. During Move Out transactions, the Process Type Value defaults to "NORMAL" and the field will be disabled.

Equipment

Category of equipment.

Load Port

A Load Port is a piece of equipment. This field appears when the selected Equipment in the Equipment field is modeled as a Parent Resource. At least one piece of the child equipments must be configured with an Equipment Type (Load Port) with an assigned Sub-Equipment Logical ID. The Load Port is required for the Track In transaction if at least one Load Port is configured for the Equipment. The Load Port drop-down displays only the Load Ports with the status currently set to Available.

Note: Lot Maintenance requirements for Load Port will be validated during tracking. The requirements include Date Requirement, Recurring Date Requirement, Thruput Requirement and Usage Requirement.

Refer to the Opcenter Execution Semiconductor Modeling Guide for information.

Lot Tab Field Definitions

The Lot tab provides a display-only grid that displays lot details. This table defines the fields on the Lot tab.

Field

Definition

Container

Displays the list of lots to be processed.

Timers

Displays elapsed time of a process timer associated with the lot. Click field arrows to view timer detail.

Quantity

For items at an item processing step, this is the sum of all the die on all wafers at the item processing step.

For a lot that is not at an item processing step, this is the number of die.

Qty2

Displays the number of items (wafers) on the lot.

Spec

Name of the Specification (Spec) referenced by a lot's current workflow step.

Days Here

Number of days the lot has been at the current step.

Queue Time

Amount of time the lot has been at this process since the last recorded Move Out Time.

Product

Product associated with the lot.

Status

Status of the lot. The following statuses are allowed:

• ACTIVE – Allowed only if the current status is CANCELED. This is to reactivate the insertion after canceling it.
• TERMINATED – The lot is terminated.
• SHIPPED – The lot is shipped.

Is On Hold

Indicates whether the lot is on hold.

In Rework

Indicates whether the lot is currently in a rework state.

Insertion

Number of times the lot has been processed in the current step.

Insertion Process Spec

Process spec that defines the insertion.

Insertion SS

Supplementary spec that defines the insertion.

Rejects

Number of rejected wafers in the lot.

Move Out Qty

Number of die to move out.

WIP Status

Indicates the WIP status of the lot. The application can display the possible statuses:

• Active
• Completed

WIP Type

Type of WIP transaction the lot is on. For example, Track.

WIP Yield Result

Indicates whether the entire lot passed or failed the yield. If the lot fails the yield, the yield failures are added to the WIP Lot Failures. Possible values are:

• NULL - Not calculated yet.
• PASS - All yield checks passed.
• FAIL - One or more yield checks failed.

Batch No

Batch ID of the lot.

Eqp Count

Number of times the equipment has been used on the lot.

Eqp Loading Count

Number of times the equipment was loaded for the lot.

Future Hold Exists

Indicates whether the lot is scheduled to be put on hold in a future step.

In Schedule

Indicates whether the lot is scheduled.

Spec Pass

Current spec (step) the lot is on.

Spec Category

Category of the spec (step). For example, WIP.

Spec Type

Indicates the type of WIP spec. The application displays one of the following:

• Assembly
• Back grind
• Test
• Wafer sort
• Wafer

Spec Description

Description of the WIP spec associated with the lot.

Field

Definition

WaferScribeNumber

Id of the wafer.

Container

Net die per wafer. The current quantity for the wafer.

GoodQty

Final quantity or active quantity.

WaferNumber

IsBadWafer
