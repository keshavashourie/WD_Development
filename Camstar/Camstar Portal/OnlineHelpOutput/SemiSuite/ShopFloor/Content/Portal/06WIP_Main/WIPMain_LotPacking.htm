Lot Packing

The Lot Packing tab enable you to manage packaging activities through boxes configuration, recording, and tracking. The Lot Packing tab, when configured in Modeling, allows you to define box types, specify packing dimensions, set required box quantities per lot, and ensure all packaging specifications are properly documented and maintained for each lot.

To enable this functionality, configure packing in the WIP Spec by selecting 'Step Logic = PACKING' in the Modeling module.

Lot Packing Tab Field Definitions

This table defines the fields on the Lot Packing tab.

Field

Definition

Details Data grid

Displays a list of lots currently available in the schedule that can be selected for the combination process.

Packing Instructions grid

Display a list of scheduled packing instructions, including Container Name and Quantity specifications. When lots are saved, their quantities are automatically deducted from the total values shown in this grid.

Packing Type

Type of the packaging with quantities set. Default modeling configuration includes the following options:

• Packing Type 1 has a Packing Size of 400
• Packing Type 2 has a Packing Size of 500
• Packing Type 3 has a Packing Size of 600

Packing Size (Qty Per Box)

Number of items that go into each box. This information is set in Packing Qty matrix. For example, if Packing Type 1 is selected, the packing size will be 400 item per box.

Number of Boxes

Total number of boxes after all items have been packed into each packaging size per box. For example, a total item of 1000 with Packaging Type 1 would have 3 number of boxes (Box 1: 400, Box 2: 400, and Box 3: 200).

Partial Box Qty

Number of items placed in the final box when the total quantity cannot be evenly distributed across full boxes. For example, with a total of 1000 items and Packaging Type 1 (capacity: 400 items per box), the distribution would be:

• Box 1: 400 items (full box)
• Box 2: 400 items (full box)
• Box 3: 200 items (partial box)

Hence in this example, the partial box quantity is 200.

Partial Box Number

Application-calculated number for the last box.

Packing Qty

Application-calculated number of items (from all lots) to pack.

Total Lot Qty

Application-calculated total quantity of all selected lots. . Displays the sum of quantities from all selected lots in the Details grid.
