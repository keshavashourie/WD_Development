Modify Maintenance

You cannot Track In equipment that has outstanding maintenance requirements. You can use the Modify Maintenance tab to waive and delay requirements that have been configured to allow these options.

Errors that Can Occur when Attempting to Delay Maintenance

These errors can occur when attempting to delay maintenance:

• Maximum Delay Usage Count Exceeded: This occurs when you attempt to delay maintenance and enter a value in the Delay Usage Count field that exceeds the configured maximum.
• Maximum Delay Period Exceeded: This occurs when you attempt to delay maintenance based on a date or recurring date requirement configured with a Maximum Delay Period and your delay would cause the maximum to be exceeded.
• Maximum Thruput Quantity or Quantity 2 Exceeded: This occurs when you attempt to delay maintenance based on a throughput requirement configured with a throughput maximum (Quantity or Qty2) and your delay would exceed the maximum.

How to Waive an Outstanding Maintenance Requirement for a Resource

Follow these steps to waive the maintenance requirement for a resource while processing a lot in WIP Main:

1. Click Modify Maintenance on the WIP Main page. The Maintenance Management pop-up appears.
2. In the Search Criteria section of the pop-up, select the Resource.
3. Click Search. Maintenance requirements for the resource display in the Search Results grid.
4. Select the grid row listing the requirement that you want to waive.
5. In the Maintenance Details section, select Waive from the Maintenance Action Type field.
6. Click Modify Maintenance. The application processes your request and displays a status message.
Note: The application displays the electronic signature pop-up if the feature was configured to require electronic signature.

How to Delay an Outstanding Maintenance Requirement for a Resource

Follow these steps to delay the maintenance requirement for a resource while processing a lot in WIP Main:

1. Click Modify Maintenance on the WIP Main page. The Maintenance Management pop-up appears.
2. In the Search Criteria section of the pop-up, select the Resource.
3. Click Search. Maintenance requirements for the resource display in the Search Results grid.
4. Select the grid row listing the requirement that you want to delay.
5. In the Maintenance Details section, select Delay from the Maintenance Action Type field.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Modify Maintenance. The application processes your request and displays a status message.
Note: The application displays the electronic signature pop-up if the feature was configured to require electronic signature.
Important: The system administrator can make changes to a maintenance requirement causing existing delays to be cleared or applied to the modified requirement. Refer to the Opcenter Execution Semiconductor Modeling Guide for information.
