In-Process Split

The In-Process Split tab enables you to split a lot into multiple lots.

The Activities area of the Main tab displays a message indicating that the lot in WIP Main should be split. Additionally, the application displays the In-Process Split tab, which enables you to split lots.

The application does not allow further WIP processing (Move In, Track In, Track Out, or Move Out) if the associated lot split process is not performed.

In-Process Split Tab Field Definitions

This table defines the fields on the In-Process Split tab.

Field

Definition

Max In-Process Qty

Number of wafers currently in process.

Details Selection grid

List of the lots into which the in process lot will be split.

To Lot Id

Lot ID of the lots into which the in process lot is split.

In Process Qty

Quantity into which the lot will be split.

In-Process Split Tab Button Definitions

This table defines the buttons on the In-Process Split tab.

Button

Click this button to . . .

Reset

Clear all data on the page.

Submit

Save the data on the page.

How to Split a Lot

Follow these steps to split a lot:

1. Select the In-Process Split tab on the WIP Main page.
2. Select the To Lot Id.
3. Click Submit. The application displays a success message.
