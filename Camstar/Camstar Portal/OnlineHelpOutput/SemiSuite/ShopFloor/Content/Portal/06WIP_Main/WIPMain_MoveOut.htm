Move Out

The application enables WIP Main Move Out only if the lot has completed its processing. Move Out moves the lot to the next step. The next step can be determined by a path selector or a supplementary spec based on the schedule, or the step can be manually selected based on setup.

Note: Effective with version 8.7, the Move Out transaction contains a subset HPE logic empowered by High Performance Engine (HPE) to increase larger transaction efficiency as the application processes transactions on the database rather than the application server. This new HPE logic is only trigger when processing lots with a parent/child relationship. Refer to Opcenter™ Execution Core Technical Reference: High Performance Engine for information.
