Rejects

The Rejects Items tab on the WIP Main page enables you to specify bad product. The tab displays during WIP Processing if the spec in use has been configured with the Allow Rejects Recording flag set to true.

Rejects are not immediately processed; they are stored in WIP Tracking tables to allow re-screening, correction and disposition. Rejects collected after Track In but before Track Out are called In-Process Rejects. These rejects are stored by the lot and the equipment in which they are processing. At Track Out, the rejects are consolidated. After the required quantity has been processed, a Move Out can be transacted on the lot. At Move Out, the consolidated In-Process Rejects are referred to as Post-Process Rejects and are stored by lot only.

The tab to record rejects for item level processing looks and behaves different than the tab to record rejects for quantity level processing.

How to Record Rejects at the Item Level

Follow these steps to record rejects at the item level:

1. Click the Rejects Items tab on the WIP Main page. The tab displays on the right side of the page. If this is the first time processing rejects for the lot, the Item Id (wafer identifier) defaults to the first one in the lot.
2. Keep the selected Item Id or select a different one.
3. Select the Loss Reason.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Follow these steps if the selected lot has mutli-product wafers and you want to reject based on sub product:
a. Select the Sub Product.
b. Select Reject Whole Sub Product to reject all die of the selected sub product. The application will determine the reject quantity automatically.
6. Click Add when finished. The details are displayed in the grid.
7. Repeat above steps for remaining lot items as necessary.
8. Click Submit. The application displays a status message.

How to Record Rejects at Quantity Level

Follow these steps to record rejects at the quantity level:

1. Select the Rejects tab on the WIP Main page. The Rejects grid displays a list of loss reasons and fields to process any loss amounts for those reasons.
2. For each loss reason that applies to one or more rejects:
a. Enter the Reject Qty—the number of units being rejected for the selected loss reason. The Reject Qty field below the grid is incremented by the number entered.
b. Enter the number of Non Yield Off Units—the number (if any) out of that reject quantity that will not be yielded off. The Non Yield Off Units field below the grid is incremented by the number entered.
c. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
3. Click Submit. The application displays a success message.
