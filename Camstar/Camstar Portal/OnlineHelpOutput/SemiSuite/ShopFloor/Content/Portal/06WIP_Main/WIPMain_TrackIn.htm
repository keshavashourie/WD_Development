Track In

WIP Main Track In starts lot processing in equipment. The application enables Track In under these conditions:

• The step is configured for equipment processing.
• Processing has not been completed for the lot or the lot is able to be re-processed.

The application ensures that a recipe is active if a recipe is associated with the equipment being tracked in.

WIP Main Track In Page Field Definitions

This table defines the fields on the WIP Main Track In page.

Field

Definition

Required Activities

List of activities that must be completed for the selected lots and the selected transaction such as Track In and Track Out. Examples of activities include Materials Required, Data Collection, and Mask Required.

Track in Qty

Amount of product put on the equipment for processing.

Note: Lot can be tracked into different Load Ports. The Track In transaction will fail if a different lot is tracked into the same Load Port. The transaction is allowed only if the lots are on the same carrier.

Source Equipment grid

Grid displays if the selected lots are at a step that does not require item processing and the lots are currently tracked in to another piece of equipment.

Comments

Free form text box to enter transaction information.

Load Port

A Load Port is a piece of equipment. This field appears when the selected Equipment in the Equipment field is modeled as a Parent Resource. At least one of the child equipments must be configured with an Equipment Type (Load Port) with an assigned Sub-Equipment Logical ID. The Load Port is required for the Track In transaction if at least one Load Port is configured for the Equipment. The Load Port drop-down displays only the Load Ports with the status currently set to Available.

Note: Lot Maintenance requirements for Load Port will be validated during tracking. The requirements include Date Requirement, Recurring Date Requirement, Thruput Requirement and Usage Requirement.

Refer to the Opcenter Execution Semiconductor Modeling Guide for information.
