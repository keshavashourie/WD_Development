Materials Setup

The Materials Setup tab enables you to:

• View the BOM material requirements for the selected lot or equipment.
• Load material lots onto a piece of equipment.
Note: The fields for material setup are displayed as a pop-up when accessed from the Resource Layout View page. Refer to "Resource Layout View" for information.

Materials Setup Tab Field Definitions

This table defines the fields on the Materials Setup tab.

Field

Definition

Material Required grid

Grid listing material products required by the selected lot and process specification.

Material Lot

Name of the lot to be consumed.

Material Part

Product of the material that will be consumed.

Auto Return Material

Select to indicate that remaining material quantity is automatically returned. The last inventory withdraw step will return the material.

Auto Combine Inventory

Select to automatically combine the returned material lot to an existing material lot in inventory using the same FirstName Container application attribute.

Material Details grid

Grid listing currently loaded materials on the resource.

How to Set Up Materials

Follow these steps to set up materials:

1. Enter the lot or batch Id in the Material Lot field.
2. Click the Material Part field to activate it.
3. Enter the material part from the Material Part field.
4. Click Add if the information was not automatically added to the Material Details grid.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
