Simple Mode

In Simple Mode, the Job Progress transaction presents the first configured step; after that step is completed, the transaction progresses to the last configured step. The Simple Mode check box can be updated on the Job Model and Job Create pages.

Repair Code

Repair code entered by technician (if required in performed job step) indicating the repair that was done to correct the problem with the resource.

Display Only

Allow Complete

Check box on the Job Model object Details grid Add pop-up. When this check box is selected for a step, it means that the supervisor will be able to execute the Job Complete transaction for any job that is in this step and was created using this job model.

Technician Jobs Page Button Definitions

This table defines options you may see on the Shop Floor Txns menu.

Note: These buttons appear under Shop Floor Txns on the right side of the page and are enabled or disabled depending upon the selected row.

Button

Click this button to . . .

Display Resource Parts pop-up for selected resource.

Job Acknowledge

Execute the Job Acknowledge transaction. Enabled for newly assigned jobs.

Job Clock On

Execute Job Clock On transaction. Enabled for jobs acknowledged without Auto Clock On selected.

Job Progress

Progress from one step to the next within the job. Executes the Job Progress transaction. This transaction can be used once or many times, depending upon the number of job steps (also known as stages) to be performed and how many times you clock off of those steps. Enabled for jobs that are INPROGRESS.

Job Clock Off

Execute the Job Clock Off transaction. Enabled for INPROGRESS jobs.
