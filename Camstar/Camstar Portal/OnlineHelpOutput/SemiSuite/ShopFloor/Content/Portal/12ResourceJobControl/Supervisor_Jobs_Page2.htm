Supervisor Jobs

The Supervisor Jobs page serves as a base from which a resource job control supervisor can perform tasks associated with their role.

Supervisor Jobs Page Field Definitions

This table defines the fields on the Supervisor Jobs page.

Field

Definition

Type

Search Criteria

Search Criteria field definitions are identical to their counterparts defined in the Search Results grid below.

Optional

Search Results grid

Grid that displays the results of the search.

Display Only

Job Status

Indicates the job's current point in the Job Control process flow

Display Only

Resource

Equipment, tool, mask, or other non-material item used in the manufacturing process. In this context, it is the unique name of the resource for which the job was created,

Display Only

Job Order

ID of job order associated with job.

Display Only

Job Model

Job Model on which job is based. The Job Model object is where the steps are configured.

Display Only

Simple Mode

In Simple Mode, the Job Progress transaction presents the first configured step; after that step is completed, the transaction progresses to the last configured step. The Simple Mode check box can be updated on the Job Model and Job Create pages.

Display Only

Job Type

Identifies a general reason for the job, for example, Normal, PM (Preventative Maintenance), or Recondition.

Display Only

Resource Family

Categorization of manufacturing resources based on their attributes and factory business requirements.

Display Only

Stage

Job step. In this context, it is the job's current step.

Display Only

Stage Sequence

Sequential order of job's current step.

Display Only

Expected Start Date

Date entered by technician during Job Acknowledge transaction.

Display Only

Symptom Code

Symptom code selected by technician (when required) to identify symptom indicative of the need to repair the resource.

Display Only

Cause Code

Cause code selected by technician (when required) indicating the reason for the problem with the resource.

Display Only

Repair Code

Repair code entered by technician (when required) indicating the repair that was done to correct the problem with the resource.

Display Only

Allow Complete

Check box on the Job Model Details grid Add pop-up. When this check box is selected for a step, it means that the supervisor will be able to execute the Job Complete transaction for any job that is in this step and was created using this job model.

Display Only
