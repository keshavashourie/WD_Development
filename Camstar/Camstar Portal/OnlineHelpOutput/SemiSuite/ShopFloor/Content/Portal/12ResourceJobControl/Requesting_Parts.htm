Requesting Parts

The technician can request parts when using the Job Progress page by clicking Part Request to bring up the Part Request pop-up. Refer to "Part Request" for information.

How Part Requests are Processed

This is the required sequence of actions for processing part requests:

1. Inventory must acknowledge the request using the Part Request Acknowledge transaction.
2. Inventory must assign the part or parts to the job using the Part Request Assign transaction.
3. Inventory must complete the request using the Part Request Complete transaction.
4. The technician must issue the parts using the Part Issue transaction.
Note: These actions must take place before the supervisor can execute a Job Complete transaction for a job containing a part request.
