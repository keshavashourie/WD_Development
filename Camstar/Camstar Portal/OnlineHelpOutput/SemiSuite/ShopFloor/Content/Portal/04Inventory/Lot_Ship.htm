Lot Ship

Lot Ship is an Inventory transaction available within inventory type, for example, Die Bank Inventory | Lot Ship. The Lot Ship page enables you to ship one or more active lots or re-ship one or more shipped lots to another factory. A lot is marked as In Transit after it is shipped and until it is received in the destination factory.

About Document Numbers and Shipment Numbers

A Ship To Factory can be configured with one or more Ship From Spec and Ship To Process combinations. Each of these combinations has an associated Is Lot Complete check box. Leaving the check box blank indicates that lots are not complete and must be sent to another factory for further processing if they are being shipped from that spec using that process. The Lot Ship transaction requires a Document Number and a Shipment Number in such cases.

How to Perform the Lot Ship Transaction

Follow these steps to perform the Lot Ship transaction:

1. Access the Lot Ship page for the appropriate inventory type.
2. Select one or more lots using the Selection Id field. The application populates the Lots grid with selected lot information.
3. Select a Ship To Factory.
4. Select a Ship To Process.
5. Click the Document Number field icon to have a document number automatically generated or else enter a document number if the shipment requires a document number.
Note: You can leave the field blank and be prompted after you click Submit if you are unsure whether the field is required.
6. Enter a Shipment Number if the shipment requires a shipment number.
Note: You can leave the field blank and be prompted after you click Submit if you are unsure whether the field is required.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Submit. The application displays a success message.
Note: The application prompts you if a required Document Number or Shipment Number is not provided.
