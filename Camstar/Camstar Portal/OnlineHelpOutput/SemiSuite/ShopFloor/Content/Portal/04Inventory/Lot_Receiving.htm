Lot Receiving

Lot Receiving is an Inventory transaction available within inventory type, for example, Die Bank Inventory | Lot Receiving. The Lot Receiving page enables you to move one or more lots that were started in In-Transit to an Inventory step.

Lot Receiving Page Field Definitions

This table defines the fields on the Lot Receiving page.

Field

Definition

Type

Selection Id

ID for a lot, carrier, batch, or piece of equipment.

Required

Employee

Employee performing this transaction if different than the user currently logged in.

Optional

Receiving Location

List field containing receiving locations associated with the first Ship From Factory assigned to the first lot selected.

Note: This field is required if To Workflow and To Step are left blank.

Optional

To Workflow

Workflow to which the lot or lots should be moved. The workflow from the Receiving Location is used if this field is left blank.

Note: The object category and object type of the To Workflow must match those of the transaction (service) to ensure that lots are received in the correct location.

Optional

To Step

Step within To Workflow where processing should begin. The workflow from the Receiving Location is used if this field is left blank

Note: The object category and object type of the To Step must match those of the transaction (service) to ensure that lots are received in the correct location.

Optional

Service Attributes grid

Grid that lists attributes configured for the current transaction using the Service Attrs Setup matrix. Attribute values can be changed directly on the grid.

How to Perform the Lot Receiving Transaction

Follow these steps to perform a Lot Receiving transaction using the Lot Receiving page:

1. Access the Lot Receiving page for the appropriate inventory type.
2. Select the lot or lots using the Selection Id field. The application populates the Lots grid with selected lot details.
3. Select the Receiving Location.
4. Select the To Workflow.
5. Select the To Step.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Submit. The application displays a success message.
