Lot Ship Cancel

Lot Ship Cancel is an Inventory transaction available within inventory type, for example, Die Bank Inventory | Lot Ship Cancel. The Lot Ship Cancel page enables you to re-activate shipped lots, inform the receiving site through email, or both.

Check box indicating whether to skip the notification email. The application automatically sends an email to all recipients within the email group configured for the Ship To Factory unless this check box is selected.

Reactivate Lot

Check box indicating whether to re-activate the lot. The lot will be set to the Active status if this check box is selected.

Note: This check box must be selected if the Skip Email check box is selected. This is to ensure that at least one action is carried out when canceling a shipment— sending the email, reactivating the lot, or both.

How to Perform the Lot Ship Cancel Transaction

Follow these steps to perform the Lot Ship Cancel transaction:

1. Access the Lot Ship Cancel page for the appropriate inventory type.
2. Select one or more lots using the Selection Id field. The application populates the Lots grid with selected lot information.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit. The application displays a success message.
