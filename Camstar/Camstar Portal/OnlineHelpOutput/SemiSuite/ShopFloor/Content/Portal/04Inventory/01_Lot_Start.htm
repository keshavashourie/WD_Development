Lot Start

Lot Start enables you to create lots in both In-Transit and Inventory steps. Starting lots in In-Transit indicates that the lots are not physically present.

Lot Start Page Field Definitions

This table defines the fields on the Lot Start page.

Field

Definition

Type

Lot Id

Lot identifier.

Note: The application generates a lot ID if it is left blank.

Required

Employee

Employee performing this transaction if different than the user currently logged in.

Optional

Product

Product used to start the lot. The application uses the product assigned to the manufacturing order if Product is blank.

Note: The corresponding Product Is Available flag must be selected for the lot to start.

Start Reason

Indicates the reason a lot is being created, for example, Engineering, Order, and Reclaim. The product’s Default Start Reason will be used if Start Reason is blank.

Required

Inventory workflow used to begin processing the lot. The application uses the product's Default Start Location if Inventory (Workflow Area) is left blank. Object Category and Object Type on the selected workflow must match those on the transaction (service) to ensure that the correct transaction and start location are used.

This is to ensure that the right service is used to start the lot in the right location.

Person or team responsible for the lot. The application uses the product’s Default Start Owner if the owner field is left blank. Typical values include Manufacturing, Engineering, and Research and Development.

How to Start a Lot

Follow these steps to start a lot:

1. Access the Lot Start page.
2. Enter an identifier for the lot in the Lot Id field.
3. Select a Product. The application populates required fields for which data has been configured.
4. Select a Start Reason if the field is blank or the default does not apply.
5. Select a Workflow (Inventory Area) if the field is blank or the default does not apply.
6. Select a Workflow Step (Inventory Location) if the field is blank or the default does not apply.
7. Select an Owner if the field is blank or the default does not apply.
8. Select a Factory if the field is blank or the default does not apply.
9. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
10. Click Submit. The application displays a success message.
