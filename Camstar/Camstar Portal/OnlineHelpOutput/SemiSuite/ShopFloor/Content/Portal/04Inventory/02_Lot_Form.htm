Lot Form

Lot Form enables you to create a new lot by combining and splitting existing lots in Inventory and WIP.

Note: Lot Form by Items is the counterpart page designed for wafer based lots.

Lot Form Page Field Definitions

This table defines the fields on the Lot Form page.

ID for a lot, carrier, batch, or piece of equipment.

Specifies which lot or container in the Details grid is the main lot. By default the first lot selected will be set as the main lot.

Equipment to use for the combined or split lot.

Create New Schedule

Flag indicating whether to create a new schedule for the New Container Name.

It will be used by the Split Lot transaction provided the main Lot contains a schedule.

Setting the value to false means the New Container Name will be split out using the same schedule.

Optional

New Lot Id

Name of lot to be created if you do not specify a new lot Id.

Required

Carrier (for WIP)

Specifies the carrier for the lot. The application sets the carrier using the Carrier Change transaction after a carrier is selected.
Note: You cannot remove a carrier assignment by leaving it blank or deleting the field value. You must use Carrier Change if you need to remove a carrier from a lot.

Optional

Due Date

Date and time when this container is scheduled for completion. This information is used alongside the projected completion time for performance reporting.

Note: The field is required if the processing container\lot has Remaining Process Time (RPT) enabled.

Optional

Work Order

Manufacturing order used to start the lot.

Note: This field should only be used if the lot is to be automatically scheduled when started or to set the new lot without scheduling if a split is executed (Split Lot Details' Split To Mfg Order field).

Optional

Expected Start Date

Expected Start Date for the schedule.

The Mfg Order’s Planned Start Date is used if this field is left blank.

Optional

Cycle Time

Estimate of time (in days [optional], hours, minutes, and seconds) required to process product under normal circumstances. The application uses the first non-blank cycle time that it finds by evaluating the following fields in the following order:

1.

Manufacturing order's planned cycle time (PlannedCompletionDate – PlannedStartDate)

2.

Cycle time entered by user

3.

Process spec's cycle time.

The application uses a value of 1 if no value can be found.

Optional

Sales Order Number

Additional information for a schedule. Typically used to store the sales order number from an ERP application.

Optional

Product

Product used to start the lot. The application uses the product assigned to the manufacturing order if Product is blank.

Note: The corresponding Product Is Available flag must be selected for the lot to start.

Optional

BOM

BOM with which to schedule the lot. The Mfg Order’s Product BOM is used if this field is left blank. The application populates this field with the product BOM list.

Optional

Process Spec

Field to select a Process Spec with which to schedule a lot. A process spec is used to track lots after they move out of Inventory and into WIP processing. It specifies the workflow steps to execute and any parameters and variations on workflow steps. The Manufacturing Order’s process spec will be used if a process spec value is not entered.

Optional

First WIP Step

First WIP step (also the default) within the Process Spec’s Workflow.

This is the WIP step to move the lot to when it is being prepared or released to production.

Optional

Ship To Factory

Specifies the Ship To Factory for the schedule. The application uses the main lot’s Ship To Factory if this field is left blank.

Optional

Owner

Person or team responsible for the lot. The application uses the product’s Default Start Owner if the owner field is left blank. Typical values include Manufacturing, Engineering, and Research and Development.

Optional

Priority

Specifies the Priority Code for the schedule.

Optional

Packing Type

Specifies the required packing for the lot. Process Spec’s Packing Type is used if this field is left blank.

Optional

Auto Prepare

Check box to indicate whether to automatically prepare the lot. Selecting the Auto Prepare check box causes the lot to be automatically prepared as in Lot Schedule Preparation.

Optional

Show/Hide additional fields

 

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.

Optional

How to Form a New Lot from One or More Existing Lots

Follow these steps to create a new lot from one or more existing lots:

1. Access the Lot Form page.
2. Select one or more source lots from the Selection Id field. The application populates the Details grid with selected lot information.
3. Enter the Combine Qty for each lot.
4. Enter a New Lot Id. This field is a couple of rows below the grid.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
