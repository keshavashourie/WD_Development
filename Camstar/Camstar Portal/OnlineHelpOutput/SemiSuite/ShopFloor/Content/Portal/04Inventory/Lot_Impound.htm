Lot Impound

Lot Impound is an Inventory transaction available within inventory type, for example, Die Bank Inventory | Lot Impound. The Lot Impound page enables you to move one or more aged lots from an inventory step to an impound step or from an impound step to an inventory step.

Note: An Impound step is a step with an Impound Type assigned to its Operation.

Variations of Lot Impound include:

• Wafer Inventory Lot Impound: Used to move lots within a Wafer Inventory Workflow.
• Wafer Sort Inventory Lot Impound: Used to move lots within a Wafer Sort Inventory Workflow.
• Die Bank Lot Impound: Used to move lots within a Die Bank Workflow.
• Test Store Lot Impound:  Used to move lots within a Test Store Workflow.

When Using Lot Impound

When using the Lot Impound page keep these facts in mind:

• The lot you select must be in an inventory step if moving it to an impound step.
• You must select a To Step if Move to Impound is selected.

How to Perform a Lot Impound

Follow these steps to perform a Lot Impound:

1. Access the Lot Impound page.
2. Enter the lot ID in the Selection Id field. The application displays the lot in the Lots grid.
3. Select the To Workflow.
4. Select the To Step.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
