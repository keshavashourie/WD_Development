Lot Move

Lot Move is an Inventory transaction available within inventory type, for example, Die Bank Inventory | Lot Move. The Lot Move page enables you to move one or more lots from one Inventory step to another Inventory step.

How to Perform a Lot Move

Follow these steps to perform a Lot Move transaction using the Lot Move page:

1. Access the Lot Move page for the appropriate inventory type.
2. Select the lot or lots using the Selection Id field. The application populates the Lots grid with selected lot details.
3. Select the To Workflow.
4. Select the To Step.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
