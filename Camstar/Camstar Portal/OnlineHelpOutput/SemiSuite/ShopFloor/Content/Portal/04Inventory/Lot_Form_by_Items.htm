Lot Form by Items

Lot Form by Items enables you to create a new wafer lot by splitting off one or more wafers from one or more existing lots.

How to Form a New Wafer Lot from One or More Existing Lots

Follow these steps to form a new wafer lot from one or more existing lots:

1. Access the Lot Form by Items page.
2. Select one or more source lots from the Selection Id field. The application populates the Details grid with selected lot information. It also populates the Items grid with one row for each wafer (item) in the selected lot or lots.
3. Use the first column of the Items grid to select the check box of each wafer that you want to split off onto a new lot.
4. Enter a New Lot Id. This field is a couple of rows below the Items grid.
5. Click Auto Generate To Item Id. The application generates a new item ID for each wafer selected in the Items grid.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Submit. The application displays a success message.
