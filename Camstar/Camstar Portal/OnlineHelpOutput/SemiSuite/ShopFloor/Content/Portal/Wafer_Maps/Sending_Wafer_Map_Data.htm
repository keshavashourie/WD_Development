Sending Map Data to Siemens

The Map Data must be in a format that coincides with the Semiconductor E142 Map Data XML specification. The Map Data is submitted to Opcenter Connect MOM (Opcenter CN MOM) using the File Adapter method. Siemens does not perform data or structural validations against the external data. The external data is the System of Record. Opcenter CN MOM maps the data to a maintenance transaction that stores the data into the defined Opcenter Execution Semiconductor database schema.
