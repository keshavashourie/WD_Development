Map Data Visualization

Opcenter Execution Semiconductor’s Map Data Visualization feature enables operators to perform virtual binning. An external location, such as a manufacturing plant, sends map data to Siemens. The external data is the System of Record. Siemens does not perform data or structural validations against the external data. Siemens transfers a copy of the data to Opcenter Execution Semiconductor.

Operators use the Opcenter Execution Semiconductor Map Data Visualization page to display a graphical representation of the map and select individual map locations for visual inspection. The application displays any bin codes for selected locations and enables the operator to “tag” those locations with new bin codes. Updated bin code information is stored in Semiconductor Suite and retrieved by the sender. The sender retrieves the updated bin code information and performs the actual updates to the source map.
