Using the Map Data Visualization Page

The Map Data Visualization page enables you to review and edit the last submitted set of bin code results based on the provided Substrate ID and Lot ID if provided. You can view a data map, select a location within the map for visual inspection, and electronically "tag" the location with a new bin code. The application displays data as a color-coded grid map to facilitate defect tracking and enables you to view all binning information prior to submitting the information.

When Using the Map Data Visualization Page

The canvas working area is 1500 x 600 pixels. The maximum pixel area for the canvas is limited to 8000 x 8000 pixels. The size of a single location (X, Y) in the map depends on the device size of the map itself. The application shrinks a map but maintains the map’s proportions if the map size exceeds the maximum canvas display area. The canvas working area is scrollable when the canvas area is bigger than the working area.

Map Legend

The legend displayed to the right of the map data is dynamically generated based on the bin codes encountered on the map.

Bin Definition Details Grid

The Bin Definition Details grid below the map is collapsed by default. Expanding the grid displays the map's current bin definitions.

How to View an Entire Map in Full View

You can display a map full screen by clicking Full Screen View. The pop-up is for viewing purposes only. When finished viewing, you click Close to close the pop-up.

How to Update Binning Data

Follow these steps to update binning data:

1. Open the Map Data Visualization page.
2. Enter the Substrate ID.
3. Select a Lot Id if the substrate Id is tied to multiple Lot Ids.
4. Click a location on the map. The application displays the X Dimension, Y Dimension, and current bin code of the selected location.
5. Enter the New Bin Code.
6. Click Add to Grid. The application updates the Bin Code Update Details grid with the data in the fields directly above the grid, including the New Bin Code.
7. Click Submit. The application submits the data in the Bin Code Update Details grid to the MapDataMaint service.
