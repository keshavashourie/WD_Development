Material Component Consumption

Semiconductor manufacturing often requires lots and containers to consume materials and components at specified workflow steps. Operators load required materials onto resources in preparation for these steps. Opcenter Execution Semiconductor automatically records material consumption if the operator enters resource setup information for the step. The operator has the option to record consumption manually using the Consume Materials page or one of the Component Issue pages depending upon configuration. The application evaluates relevant work orders and product BOMs that can specify at the component level which page should be used.

Note: Keep in mind that work orders can be populated automatically by an ERP system if you are considering changes to your work orders.
