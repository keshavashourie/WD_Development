Consume Materials

The Consume Materials page is Opcenter Execution Semiconductor's default page for manually recording material consumption for a lot in a workflow step. This page is primarily used on an ad-hoc basis, as Opcenter Execution Semiconductor is designed to automatically record consumption of materials that have been “set up” for a resource.

Note: The setup to enable automatic recording of consumption for a step is done using either the Materials Setup tab during WIP Main Track In (after selecting a resource) or the Equipment Materials Setup page available under the Resource option on the main menu.

Serialized vs Non-Serialized Material Components
• Serialized: A material component that must be tracked is labeled "serialized." Each serialized material component must belong to a material lot. The application requires the lot to be referenced for setup and consumption of the material component.
• Non-Serialized: A material component that is not serialized does not have to be formally tracked and does not require a material lot. The vendor's batch Id should be used as the Lot Id for setting up resources with non-serialized components to provide traceability.

Reference Designators for Material Components with Sub-Components

Finished goods such as computer processors contain individual sub-components referenced by location. These locations are referred to as Reference Designators. Reference designators for a material component can be specified in the associated product BOM or work order. The Consume Materials transaction requires you to enter the reference designator when one has been configured for the material.

How to Record Material Consumption on a Quantity Basis

Follow these steps to record material consumption using the Consume Materials page:

1. Open the Consume Materials page. (Default menu access is WIP > Material Processing > Consume Materials.)
2. Enter the lot Id in the Selection Id field. The application populates the Service Details grid with information on the materials currently set up on the resource into which the lot is tracked.
3. Take the following steps for each required material on the Service Details grid:
a. Select the Service Details grid row with the material part.
b. Enter the Material Lot Name.
c. Enter the Qty to Consume.
d. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit. The application displays a success message.
