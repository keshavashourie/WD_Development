Lot Schedule

Lot Schedule enables you to create a manufacturing schedule for one or more lots that are in inventory. Scheduling is typically done by planners. It is required before lots can be released for WIP processing. The Lot Schedule page to use depends upon the schedule type needed, for example, Item Lot Scheduling, Assembly Mother Lot Scheduling, and Test Lot Scheduling.

When Using Lot Schedule

The application determines a default value for the Schedule Qty field. It uses a lot's Qty by default but uses Qty2 if any of these scenarios is true for the lot:

• Current spec is a Wafer Inventory Spec.
• Current spec is an Inventory Spec with the Is Wafer Processing flag set to true.
• Current spec is a Wafer Sort Inventory Spec and has a zero value for its Qty.
Note: The application sums the Qty or Qty2 (whichever applies) of all lots when multiple lots are selected.

You can change the default Schedule Qty. Keep in mind that you can only schedule what a lot has available. For example, a lot with a Qty of 1000, out of which a quantity of 100 has already been scheduled, has an available Qty of 900. The application does not take previously scheduled quantities into account when determining the default Schedule Qty but does display an error message if the Schedule Qty exceeds what is available.

Supplementary Processing

Lot Schedule allows you to specify supplementary processing at the spec or step level. Step-level specification enables you to select sub-workflow steps.

Possible Error Messages

This table lists possible error messages and their explanations.

Error Message

Explanation

A Partial Lot is required since the selected lots have more than the Schedule Qty.

You must select the lot from which the partial amount will be taken. The reason is that only part of the total available quantity is being scheduled. The application takes all of the quantity from one lot but needs to take just part of the quantity from another lot.

The Main Lot cannot be the Partial Lot if there is more than 1 lot selected

The selected Main Lot and Partial Lot must be different. The reason is that the application uses all of the main lot before using part of another lot.

A New Lot Id is required since the Main Lot available schedule quantity is not all used

You must enter a name for a new lot that will be created for the schedule in the New Lot Id field (or select the Auto Set New Lot Id check box). The reason is that the application cannot schedule the Main Lot because only part of that lot is needed.

There are not enough lots to meet the Schedule Qty

You have attempted to schedule more than what is available. This can occur when part of a selected lot has already been scheduled.

First step within the selected First WIP Step Workflow where lot begins processing after Lot Schedule Preparation or Lot Schedule Release.

Lot Schedule Preparation will move the lot to a SCHEDULED step only if it is the first step. Otherwise it will directly move to the First WIP Step.

Lot Schedule Release is used to release the lot from a SCHEDULED step to the First WIP Step only if the SCHEDULED step is the first step in the Process Spec’s Workflow. Otherwise, it will move the lot to the next step.

Expected Start Date

Specifies the schedule's expected start date.

Required

Cycle Time

Estimate of time (in days [optional], hours, minutes, and seconds) required to process product under normal circumstances. The application uses the first non-blank cycle time that it finds by evaluating the following fields in the following order:

1.

Manufacturing order's planned cycle time (PlannedCompletionDate – PlannedStartDate)

2.

Cycle time entered by user

3.

Process spec's cycle time.

The application uses a value of 1 if no value can be found.

Required

Expected End Date

Application-calculated date of when the production schedule is expected to end. The value is calculated as: (Expected Start Date) + (Cycle Time) – (Total Duration of Cycle Time Holidays).

Note: Total Duration of Cycle Time Holidays is calculated as follows:

For each Cycle Time Holiday within date range (Expected Start Date + Cycle Time):

• Cycle Time Offset = Cycle Time Holiday’s Day Factor (one minus Day Factor).
• Expected End Date = Expected End date + Cycle Time Offset.

Required

Owner

Specifies the owner of the schedule.

Priority

The work order's priority is used if it exists; otherwise the application defaults this field to the first selected lot’s priority if a value is not selected.

Schedule Qty

Quantity to schedule. The application uses Qty by default when determining Schedule Qty. It uses Qty2 if the lot meets any of these criteria:

• Current spec is a Wafer Inventory Spec.
• Current spec is an Inventory Spec with the Is Wafer Processing flag set to true.
• Current spec is a Wafer Sort Inventory Spec and has a zero value for its Qty.

The application moves the value of Qty or Qty2 (whichever applies) to the Schedule Qty field if only one lot is selected. The value is added to a running total if multiple lots are selected and then added to Schedule Qty after all lots have been factored into the total.

Note: A value of zero is added for lots that are not active or are not in an inventory or in-transit step.

Required

Main Lot

Specifies the Main Lot for the schedule.

The lot:

• Must be in the Active status.
• Must not be on hold.
• Must exist as one of the selected lots in Details.

Either a New Lot Id or the Auto Set New Lot Id must be set to true if the Main Lot is also selected as the Partial Lot. This is to allow splitting of the Main Lot.

Either a New Lot Id or the Auto Set New Lot Id must be set to true if the Main Lot is the only lot selected and its Available Schedule Qty is greater than the Schedule Qty. This is to allow splitting of the Main Lot.

The Main Lot cannot be set as the Partial Lot if there is only one lot selected.

This field cannot be used for Batch Lot Schedule since each lot will have its own schedule and thus is its own Main Lot.

Optional

Partial Lot

Specifies the lot to be used as the Partial Lot.

A Partial Lot is required if all of these are true:

• The Total Available Schedule Qty does not match the Schedule Qty.
• There is more than one lot selected.

All other scenarios do not allow a Partial Lot.

The Partial Lot must also exist as one of the selected lots in the Details field.

This field cannot be used for Batch Lot Schedule since each lot will have its own schedule.

Optional

Auto Set New Lot Id

This field cannot be used for Batch Lot Schedule since each lot will have its own.

New Lot Id

The Lot Split’s Verify Service Rules method will be called to validate the ID for splitting. Refer to the Lot Split Ad-Hoc Txn functional spec for more information.

SS Plan Ref Details grid

Grid to specify supplementary spec processing which occurs on top of the process spec processing. A lot can be in the process spec or in a supplementary spec but not both. The lot is moved to and from the supplementary spec during the Move Lot transaction. Move Lot searches for a record with a Move Out From Spec matching the current Spec. If found and other conditions are met, the move to Workflow and Workflow Step for the lot will be set according to the record. Each test step (spec with Is Test set to true) within the SS Workflows must have at least one set of test parameters.

Note: Use the SS By Step Details grid for all new schedules. This grid supports sub-workflows.

RPT Bulk Delta

Difference in the overall processing time for a batch of operations when comparing the original workflow to the updated Experimental Plan.

The delta shows how the time to process the batch or set of tasks changes due to adjustments in the workflow, experimental design, or resource allocation. It's calculated by finding the diffence in bulk processing time between the original plan and modified plan.

Units for this field is expressed in hours, with values rounded to two (2) significant digits for precision and consistency. These values can be positive, negative, or zero.

Optional

RPT Unit Delta

Difference in processing time for a single unit or individual task between the original workflow and the updated Experimental Plan.

The delta reflects how the time required to complete one unit of work, task, or experiment changes when comparing the two workflows. It's calculated by finding the difference in processing time per unit between the original plan and the modified plan.

Units for this field is expressed in hours, with values rounded to two (2) significant digits for precision and consistency. These values can be positive, negative, or zero.

In Process Split Details grid

Grid used to specify in-process split requirement for specs with INPROCESSSPLIT Step Logic. In-process split is done when the lot is processing in the equipment (after Track In Lot but before Track Out Lot). The split out lot will share the same schedule as the main lot. For example, Assembly Sub-Lot process typically splits a lot at Die Attach into smaller manageable lots. The lots are then combined at the Packing step before completing WIP. Note that In-Process Split Details cannot be used for Qty 2 processing. The Assembly Carrier Process Spec is not allowed to specify in-process split. Assembly Carrier is a totally different way of tracking. It uses Carriers to track the lot. The application will auto split or combine when the Carriers are changed during Track Out Lot.

Optional

Packing Details grid

Grid specifying packing instructions for specs with packing logic. Packing instructions are used to combine some of the lots within the same schedule and then split out to a new lot with a new schedule. This will allow the new lot to complete WIP without requiring other lots to reach the packing step.

For example, when an Assembly Sub-Lot Main Lot has been split into multiple sub-lots during Die Attach, instead of combining all sub-lots at the packing step, the Packing instructions can be used to combine a few sub-lots and then split out to a new lot with a new schedule. This will allow combined sub-lots to complete WIP without waiting for the rest of the sub-lots to reach the packing step. Packing details cannot be used for Qty2 processing.

How to Schedule a Lot

Follow these steps to schedule one or more lots:

1. Access the Lot Schedule page for the type of schedule you need.
2. Select the product using one of the Product field icons. The first icon displays a list of products that are (PN objects). The second icon displays a list of products that are consumable material products. The application populates the BOM field.
3. Select the Process Spec. The application populates the Cycle Time field.
4. Change the Expected Start Date and Expected End Date if necessary.
5. Select the Owner.
6. Select the Priority.
7. Select the lot or lots to be scheduled using the Selection Id field. The application populates the Details grid with information pertaining to the selected lot or lots. It also defaults the Schedule Qty field and defaults the Main Lot field to the first selected lot.
8. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
9. Click Submit. The application displays a success message.
