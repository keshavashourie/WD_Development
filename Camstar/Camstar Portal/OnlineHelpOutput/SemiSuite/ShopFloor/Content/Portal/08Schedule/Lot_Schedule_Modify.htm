Lot Schedule Modify

Lot Schedule Modify enables you to modify a manufacturing schedule. Lot Schedule Modify also enables you to specify supplementary spec processing at the spec or at the step level. Step level specification enables you to select sub-workflow steps.

RPT Bulk Delta

Difference in the overall processing time for a batch of operations when comparing the original workflow to the updated Experimental Plan.

The delta shows how the time to process the batch or set of tasks changes due to adjustments in the workflow, experimental design, or resource allocation. It's calculated by finding the diffence in bulk processing time between the original plan and modified plan.

Units for this field is expressed in hours, with values rounded to two (2)significant digits for precision and consistency. These values can be positive, negative, or zero.

Optional

RPT Unit Delta

Difference in processing time for a single unit or individual task between the original workflow and the updated Experimental Plan.

The delta reflects how the time required to complete one unit of work, task, or experiment changes when comparing the two workflows. It's calculated by finding the difference in processing time per unit between the original plan and the modified plan.

Units for this field is expressed in hours, with values rounded to two (2)significant digits for precision and consistency. These values can be positive, negative, or zero.

In Process Split Details grid

Grid to specify in-process split requirement for Specs with INPROCESSSPLIT Step Logic. In-process split is done when the lot is processing in the Equipment (after Track In Lot but before Track Out Lot). The split out lot will share the same schedule as the main lot. For example, Assembly Sub-Lot process typically splits a lot at Die Attach into smaller manageable lots. The lots are then combined at the Packing step before completing WIP.

Note: In-Process Split Details cannot be used for Qty 2 processing. The Assembly Carrier Process Spec is not allowed to specify in-process split. Assembly Carrier is a totally different way of tracking. It uses Carriers to track the lot. The application will auto split or combine when the Carriers are changed during Track Out Lot.

Optional

Spec

Specifies the spec to use the information. The spec must be assigned the INPROCESSSPLIT step Logic.

Optional

Lot Id

Specifies the ID of the sub-lot that will be the target of the split. It must be different from the schedule’s New Lot Id and must not be used by the Packing instructions. This is to minimize conflicting Lot Ids.

Optional

Optional

Optional

Optional

Update Packing Details

Optional

Packing Details grid

Grid specifying packing instructions for specs with packing logic. An example can be found in the case where an Assembly lot is split into multiple sub-lots during Die Attach. Packing instructions can be used to combine sub-lots that are at the packing step and to split out the other lots onto a new lot with a new schedule. This allows the lots at the packing step to complete WIP processing without having to wait for the others.

Note: Packing details cannot be used for Qty2 processing.

How to Modify a Schedule

Follow these steps to modify a schedule:

1. Access the Lot Schedule Modify page for the type of schedule being modified.
2. Enter the Lot ID in the Selection Id field. The application populates fields with information pertaining to the lot entered.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit. The application displays a success message.
