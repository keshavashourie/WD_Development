Lot Schedule Preparation

Lot Schedule Preparation prepares lots for WIP processing. The Lot Schedule Prep page enables you to set the actual schedule quantity of a schedule. The transaction combines lots if the schedule contains multiple lots. It splits a lot if the schedule contains a New Lot Id.

Required

Lot

Lot identifier. Each lot specified must be displayed in this grid. Lot requirements:

• Must be in an Inventory step.
• Must be in the Inventory step as specified in the SS Details if they exist.
• Must have results collected for any VM and Variable Data Test IQC records (each Test IQC result must not be PENDING).

Actual Schedule Qty

Specifies the actual quantity (either Qty or Qty 2 depending on Schedule Qty Type) taken from the lot. Rules for this field:

• Cannot be set greater than the lot’s corresponding quantity.
• Must be less than the lot’s corresponding quantity if more than one schedule is assigned to the lot. This ensures that the other schedules have quantity available to them.
• Must equal the Schedule Qty if the lot is not a partial lot and the schedule has multiple lots.
• The total wafers used for each lot (if wafers exist) must match the Actual Schedule Qty.

How to Prepare a Schedule

Follow these steps to prepare a schedule:

1. Access the Lot Schedule Prep page for the type of schedule being prepared.
2. Enter a Lot ID in the Selection Id field. You can enter just the first lot of a multi-lot schedule. The application populates fields with information pertaining to the lot or lots in the schedule.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit. The application displays a success message.
