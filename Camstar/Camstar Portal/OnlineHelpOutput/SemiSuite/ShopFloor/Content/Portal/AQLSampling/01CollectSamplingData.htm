Collecting Sampling Data

The WIP Main page and the WIP Main Advanced page enables you to collect sampling data during production. The page returns all sample tests currently required for a given lot based on specification and product. The application displays the Sampling tab and a list of sampling related required actions for lots with sampling required. You enter the sampling data on the Sampling tab from the WIP Main page or you can enter the sampling data on the WIP Main Advanced page through Sampling tile.

If the corresponding sample type is a measured sample type, you enter the numeric value for each data point. If the sample type is a counted sample type, you record the number of rejected samples for each reason code. When a sample test is executed, the total tested samples, passed samples, and failed samples are recorded.

Based on the configuration of the associated WIP Data Setup, the container quantity is decreased by the sample size or by the reject quantity.

When Collecting Sampling Data

These rules apply when collecting sampling data:

• You cannot track in or track out a lot until the sampling is complete.
• You cannot move a lot if sampling fails, unless specified during modeling.

How to Collect AQL Sampling Data

Follow these steps to collect AQL sampling data:

1. Select the Sampling tab on the WIP Main page. The application displays the Sampling tab.
Note: The application displays the Sampling pop-up when you select the Sampling tile on the WIP Main Advanced page.
2. Specify the name of the transaction that the sampling data is collected against in the Service Name field. The application populates the By Lot grid or By Item Ids grid with the WIP Data Name for each data collection point.
3. Enter the number of samples you are testing in the Samples Tested field if you are collecting AQL sampling data for a counted test type.
4. Enter a value in the WIP Data Value column for every WIP Data Name in the By Lot grid. Click to open the WIP Data Valid Values pop-up in which you can view the sampling data points for a specific item.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
