Performing Maintenance Management

You use the Maintenance Management transaction to mark a resource's maintenance requirement as complete after the maintenance has been performed. The Maintenance Management page enables you to specify search criteria for resources with maintenance requirements that are ready for completion.

If you click Search without changing the default filters, the Search results will include all types of maintenance requirements.

When you select a row in the Search Results grid:

• The corresponding fields in the Maintenance Details section are populated automatically. All Maintenance Details fields are read-only except the Comments field.
• Any requirements linked to the selected requirement appear in the PM Overrides grid. The application automatically updates linked requirements to have a completed status when it updates the base requirement to have a completed status.
• Any checklists configured for the selected requirement appear in the Checklists grid.

Viewing Associated Documents

If the View Documents icon is enabled, you can click it to access the View Documents pop-up with links to view the associated documents.

Collecting Data

Upon clicking Submit, the application presents a Data Collection pop-up containing fields for user-defined or parametric data collections if they were configured from the Maintenance Requirement's Data Collection or the Maintenance Requirement's Checklist's Data Collection. If any checklists are configured, you must first select the corresponding checklist row before clicking the Submit button.

How to Complete Required Maintenance for a Resource

Follow these steps to complete required maintenance for a resource:

1. Open the Maintenance Management page. The Maintenance Management page appears.
2. Enter values in the Enter Search Criteria fields to limit the display of resources.
3. Click Search. The Search Results grid displays maintenance status information for the resources that match the search criteria entered. If no search criteria is entered, then all possible results are displayed.
4. Click the row for the resource that has a maintenance requirement that is either in the Warning period (Pending), is Due, or is Past Due. Details of the maintenance requirement appear in the display only Maintenance Details fields.
5. Click the View Documents icon if enabled and if you want to view a list of documents associated with the selected resource. The View Document pop-up appears.
6. Click the associated link to view a document. When finished, click Close to close the View Documents pop-up.
7. Click Show additional fields to enter comments specific to this maintenance requirement.
8. For any checklist that appears in the Checklists grid, select the check box on the grid row and perform the checklist.
9. Click Complete.
10. Enter data point value for each sample in the Data Collection pop-up, if necessary.
11. Is an Electronic Signature required for this transaction?

Yes

The ESig Complete pop-up appears. Complete the required information and click Submit. The electronic signature is submitted and the maintenance requirement for the selected resource is completed.

The maintenance requirement for the selected resource is completed.
