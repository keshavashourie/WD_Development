Online Traveler

The Online Traveler page allows you to view the workflow history for a specified lot. When you first navigate to the page, enter the lot name in the Selection ID field. The application populates the workflow history for the entered lot. You can collapse the Filter panel by clicking the Filter icon at the top of the Online Traveler grid.

In addition, the Online Traveler page can also be accessed through the original WIP Main page and WIP Main Advanced page.

How to View Online Traveler Information for a Lot

Follow these steps to view Online Traveler information for a lot:

1. Access the Online Traveler page.
2. Enter the lot Id in the Selection Id field. The application displays current step information in the top area of the screen and workflow path history in the grid.
3. Click Reset if you want to clear all data from the fields and view information for another lot.
