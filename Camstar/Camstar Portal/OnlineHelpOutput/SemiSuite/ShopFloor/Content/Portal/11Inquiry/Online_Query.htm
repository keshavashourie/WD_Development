Online Query

The Online Query page enables you to execute a data query that has been created with Online Query Setup.

How to Execute an Online Query

Follow these steps to execute an Online Query:

1. Access the Online Query page.
2. Select the query from the Query Name field. The application displays any parameters configured for the query in the Parameters Selection grid.
3. Change parameter values as needed.
4. Click Fetch. The application executes the query and displays the results in the Results grid.
Note: The Results grid heading displays "No records to view" if the query returns zero records.
