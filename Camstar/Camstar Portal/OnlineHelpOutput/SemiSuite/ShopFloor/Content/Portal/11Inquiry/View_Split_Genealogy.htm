View Split Genealogy

View Split Genealogy is used to trace the genealogy of split lots.

View Split Genealogy Page Field Definitions

This table defines the fields on the View Split Genealogy page.

Field

Definition

Lot

Enter a lot to view.

Product

Product used to start the lot.

Product Revision

Product revision for the lot.

Workflow

Inventory workflow for the lot.

Workflow Rev

Workflow revision for the inventory workflow.

Step

Current workflow step for the lot.

Next Step

Next workflow step for the lot.

Factory

Factory used to start the lot.

Qty

Number of items (wafers) on the lot.

Qty2

Sum of all the die on all wafers at the item processing step for items at an item processing step.
View Split Genealogy Page Command Bar Icon Definitions

This table defines the icons on the View Split Genealogy page command bar. The command bar is available if your default theme is set to Horizon.

Icon

Click this icon to . . .

Clear

Clear all fields on the page.

Online Traveler

Display the Online Traveler pop-up. Use to view the workflow history for the selected lot.

Document Sets

Display the View Documents pop-up. Use to view a list of the document sets associated with the selected lot.

Materials Required

Display the Material Required pop-up. Use this pop-up to view a list of material products required by the lot.

Lot Info

Display the Lot Information pop-up for the selected lot. Use to view the attributes, process spec parameters, consumable materials, tool plans, and recipes for the lot.
