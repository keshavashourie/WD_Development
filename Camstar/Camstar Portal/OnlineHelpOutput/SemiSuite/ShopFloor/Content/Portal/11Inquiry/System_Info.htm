System Info

System Info displays system information about the application.

System Info Page Field Definitions

This table defines the fields on the System Info page.

Field

Definition

System Info grid

Grid that lists key system variables related to the current installation.

Info Source

Application or database from which the information was taken.

Info Name

Name of the information .

Info Value

Value of the system information.

Info Sequence

Numeric sequence related to the order of the InfoSource.

Active Workspace grid

Grid that lists all active workspaces within the current environment.

Code

Code related to the current workspace.

Description

Description of the workspace code.
