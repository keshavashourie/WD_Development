View Lot Status

View Lot Status is used to trace the status of lots.

Main Qty

Indicates whether the lot is using item or non-item tracking. If the lot is using:

• Item tracking – The value is the same as the Qty2 field.
• Non-item tracking – The value is the same as the Qty field.

Status of the lot. Possible statuses are:

• ACTIVE – The lot is active.

Code used to separate lots for inquiry and processing. For example, "Manufacturing," "Engineering," "Prototypes," "SalesSamples," and so on.

Schedule type of the process spec. For example, Assembly Mother Lot.

Supplementary Spec

Supplementary spec assigned to the lot.

Supplementary Spec Revision

Revision of the supplementary spec.

SS Object Category

Manufacturing operation associated with the supplementary spec. For example, Assembly.

SS Object Type

Schedule type of the supplementary spec. For example, Assembly Mother Lot.

WIP Status

Indicates the status of the current WIP insertion. Possible values are:

• ACTIVE – The lot is waiting to be processed if the WIP Type is TRACK. If the WIP Type is MOVE the lot is allowed to move out.
• COMPLETED – schedule has been completed (lot has moved from WIP to In-Transit or Inventory). All schedule information is copied to the schedule history and deleted.
• PASS – The lot has completed its insertion and it has passed its yield calculation.
• FAIL – The lot has completed its insertion but it has failed its yield calculation.
• RELEASED – The lot was released from hold after it was automatically put on hold when it moved out with a FAIL WIP Status.
• CANCELED – The insertion is cancelled. The lot is allowed to move out without completing its Qty To Process. The Modify Insertion service is used to change the status.

WIP Type

Type of WIP tracking required. Possible values are:

• TRACK – A Resource Group was detected for the spec. This means equipment processing is required to Track In or Track Out the lot. The lot cannot move out until its insertion is completed.
• MOVE – A Resource Group was not detected for the spec. This means equipment processing is not required. The lot is allowed to move out. The insertion is considered completed.

WIP Yield Result

Indicates whether the entire lot passes or fails the yield. If the lot fails the yield, the yield failures will be added to the WIP Lot Failures. Possible values are:

• NULL – Not yet calculated.
• PASS – All yield checks passed.
• FAIL – One or more yield checks failed.

How to View Lot Statuses

Follow these steps to view lot statuses:

1. Open the View Lot Status page.
2. Enter the lot name in the Selection Id field. The application displays the lot details.
3. Click one of the following to view additional lot information:

Click the . . .

4. Click Clear to clear the lot information.
