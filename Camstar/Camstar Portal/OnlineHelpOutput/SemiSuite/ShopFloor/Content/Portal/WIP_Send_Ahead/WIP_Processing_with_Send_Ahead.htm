WIP Processing with Send Ahead

Send Ahead WIP processing includes these stages:

1. Moving the mother lot through WIP Main until the step with the "Is Send Ahead Required" flag is detected as being true.
2. Creating the Send Ahead lot.
3. Continuing to process the Send Ahead lot and the mother lot (depending upon configuration) until the Block Spec prevents the mother lot from Move Out.
4. Processing the Send Ahead lot through WIP Main, eventually reaching the Validation step. The operator collects the required WIP Data Collection which the application will use to determine the Pass or Fail status based on configuration.
5. Continuing to process the mother lot if the WIP Data Collection contains a pass status or creating another Send Ahead lot if the WIP Data Collection contains a fail status.

How it Works

The mother lot proceeds through WIP Main. It reaches the step configured with the “Is Send Ahead Required” flag set to true. At this step, it cannot Move Out until a Send Ahead lot is created. After the Send Ahead lot is created, the mother lot and the Send Ahead lot proceed through WIP Main.

At the “Block Spec” the Send Ahead lot continues processing while the mother lot is prevented from Move Out until the Send Ahead lot successfully passes Validation.

At the "Validation" step, the results of the WIP Data Collection are used to update the mother lot. If the Send Ahead process was successful, the mother lot can Move Out of the Block spec and proceed through WIP Main. (If a Lot Combine is configured for the workflow, the Send Ahead and mother lots are combined at the configure Future Lot Combine step before the workflow can be completed.)

If the Send Ahead process has failed, the first action to perform is to create a new Send Ahead lot.
