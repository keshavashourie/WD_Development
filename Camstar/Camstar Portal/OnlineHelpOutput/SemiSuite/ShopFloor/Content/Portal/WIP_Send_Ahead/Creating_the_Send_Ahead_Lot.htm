Creating the Send Ahead Lot

Wafer Send Ahead Processing and Lot Send Ahead Processing are transactions to create Send Ahead lots. Use the Wafer Send Ahead Processing page to create a Send Ahead lot by splitting off one or more wafers. Use the Lot Send Ahead Processing page to create a Send Ahead lot by splitting off quantity from one or more mother lots.

When Creating a Send Ahead Lot from a Multi-Level Start Process Lot

To create a Send Ahead lot utilizing a lot created with the Multi-Level Start process, you must disassociate the desired child lot from the parent lot to create the Send Ahead lot. Only one child lot can be used to create the Send Ahead lot and there must be at least one child lot present. In the event that a multi-level parent-child relationship has been created, only the first-level child lot of the parent lot will be selectable for disassociation to form the Send Ahead lot. The parent lot can only have one active Send Ahead lot.

Note: You can specify an additional Future Combine Spec to allow the Send Ahead lot to recombine with the parent lot.

How to Create a Wafer (Item Based) Send Ahead Lot

Follow these steps to create a Send Ahead lot using the Wafer Send Ahead Processing page:

1. Access the Wafer Send Ahead Processing page.
2. Enter the ID of the mother lot in the Selection Id field. This is a lot from which you will split off one ore more wafers to create the Send Ahead lot. The lot displays in the Lots grid.
3. For any additional mother lots, repeat step 2.
4. Select the Main Lot ID.
5. Select the From Lot to populate the Source Item(s) grid. The items for the selected lot appear in the Source Item(s) grid.
6. For each item that you want to split off onto the new Send Ahead lot, select the item in the Source Item(s) grid and click Add. The selected item appears in the Items grid.
7. For any additional mother lots, repeat steps 5-6.
8. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields
9. Click Submit. The application displays a success message.
Note: The status message includes the application-generated Send Ahead Lot name if you chose not to enter a name.

How to Create a Send Ahead Lot (Quantity Based)

Follow these steps to create a Send Ahead lot using the Lot Send Ahead Processing page:

1. Access the Lot Send Ahead Processing page.
2. Enter the ID of the mother lot in the Selection Id field. This is a lot from which you will create the Send Ahead lot. The lot displays in the Selection pop-up.
3. For any additional mother lots, repeat step 2.
4. Select the Main Lot ID—the lot to populate the Source Lot(s) grid. The selected lot appears in the Source Lot(s) grid.
5. Select the From Lot.
6. Enter the Processed Qty on the selected row.
7. For any additional mother lots, repeat steps 4-6.
8. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
9. Click Submit. The application displays a success message.
Note: The status message indicates the application-generated Send Ahead lot name if you chose not to enter a name.

How to Create a Multi-Level Send Ahead Lot

Follow these steps to create a Milti-Level Send Ahead lot using the Multi-Level Send Ahead Processing page:

1. Access the Multi-Level Send Ahead Processing page.
2. Enter the id of the parent lot in the Selection Id field. This is a lot from which you will create the Multi-Level Send Ahead lot. The lot displays in the Selection pop-up.
3. Select the row associated with the Child Lot to send ahead for processing.
4. Click Submit. The application displays a success message.

Multi-Level Send Ahead Complete Page

The purpose of Multi-Level Send Ahead Complete is to allow you to associate the Child Lot back with the original Parent Lot.

How to Create a Multi-Level Send Ahead Complete

Follow these steps to create a Send Ahead lot using the Multi-Level Send Ahead Complete page:

1. Access the Multi-Level Send Ahead Complete page.
2. Enter the ID of the Child or Parent Lot in the Selection Id field.
3. The Parent Lot and the Send Ahead lot fields will be automatically populated.
4. Click Submit. The application displays a success message.
