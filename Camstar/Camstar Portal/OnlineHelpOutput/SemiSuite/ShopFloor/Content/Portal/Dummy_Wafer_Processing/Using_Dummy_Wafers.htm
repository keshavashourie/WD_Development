Using Dummy Wafers

A dummy wafer lot is an item or wafer based lot containing dummy product. Dummy wafers can be used for these manufacturing purposes:

• To calibrate an equipment resource each time it reaches a configured thruput value or has been idle for a configured maximum idle time.
• To verify process data against non-production wafers prior to Move Out.
• To meet a resource's minimum wafer requirement that the production lot alone cannot meet.

Dummy Wafer Lifespan

A dummy wafer can be used multiple times until it reaches its lifespan limit. Dummy wafers that have reached their lifespan cannot be Tracked In and must be scrapped. Lifespan can be configured using the following criteria:

• Maximum Processing Count: This maximum is configured for the dummy product. Each wafer containing this product starts with a counter that has the maximum value. The counter is decremented each time the wafer is tracked in. The wafer has reached the end of its lifespan when the counter reaches zero.
• Maximum Processing Time: This maximum is configured for the dummy product. Processing time for a wafer containing this product is compared to this maximum. A wafer that exceeds this maximum has reached the end of its lifespan.
• Wafer Attribute Validation: A maximum can be configured in Process Spec Details for a specified wafer attribute. For example, the attribute might be Wafer Thickness and the value might be .80. The thickness measurement of the wafer is compared to this configured value. A wafer that exceeds this maximum has reach the end of its lifespan.
