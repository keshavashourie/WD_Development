WIP Main and Dummy Wafer Processing

WIP Main processing includes validations and verifications, some of which are specific to dummy wafer processing and some of which can result in the need to Track In dummy wafers.

You Track In one or more dummy wafer lots simultaneously with one or more production lots when you need to use dummy wafers. You Track Out the dummy wafer lot or lots before you Track Out the production lot or lots.

Before Using Dummy Wafers

Dummy wafer tracking depends upon configuration done in Modeling. The PN (product), Process Spec, and equipment modeling objects are designed to support dummy wafer processing on the shop floor. The system administrator configures instances of these objects to suit your manufacturing requirements. At least one dummy wafer product must be configured before you can use dummy wafer processing. Refer to the Opcenter Execution Semiconductor Modeling Guide for information.

Starting a Dummy Wafer Lot

You need a dummy wafer lot to Track In dummy wafers. Create the lot by using Lot Start and selecting a dummy product. The application moves the Dummy Product Life Span into the lot wafers object.

Note: The dummy wafer lot and production lot must be in the same WIP status to be Tracked In.

Track In Validations

The application performs these validations against the resource:

• Compares the number of wafers tracked in with the minimum wafer requirement for the resource. Dummy wafers can be tracked in along with the production wafers if the number of production wafers fails to meet the minimum.
• Compares the number of dummy wafers tracked in with the minimum dummy wafer requirement for the resource.
Note: You will receive an error message after clicking Submit if a minimum dummy wafer requirement is not met.
• Compares the amount of time that has passed since the equipment was last used against the maximum idle time configured for the resource. Permits Track Out but sets the equipment status to DOWN if the idle time exceeds the maximum.
Note: The application permits dummy wafers to track into equipment in a Down state. However, the existence of dummy wafers in a lot does not permit the production wafers to be tracked in.

The application performs these validations against any dummy wafers:

• Compares each wafer's configured wafer attribute maximum against the WIP Data value collected for that attribute. The application prevents Track In if the wafer attribute value exceeds the maximum.
Note: This error would have been displayed in a pop-up message when the wafer was tracked out of the prior step. However, failure processing is executed when you attempt to Track In.
• Compares each wafer's actual processing time against the configured maximum processing time and prevents Track In if the maximum has been exceeded.
• Prohibits Track In if a wafer's lifespan counter is down to zero. Otherwise it permits Track In and decrements the counter.

Track Out Validations

The application checks the Last Dummy Wafer Data Collection Status. It permits Track Out if the status is FAIL but places a hold on both the production and dummy lots that will prevent Move Out. The application Moves the dummy lot Id to the Last Passed Dummy Lot field if the status is PASS.

Note: Any dummy wafers that are still processing must finish before Track Out can be completed All dummy wafers must be tracked out before any of the production wafers can be tracked out.

Move Out Validations

Both the dummy and production wafers can be Moved Out provided that no validation errors prevent this. You may be able to Move Out the dummy wafer lot but not the production lot. You may not be able to move out either lot. The specific error determines what can be Moved Out.

How to Track In a Dummy Wafer Lot with a Production Lot

Follow these steps to Track In a dummy wafer lot with a production lot:

1. Select the production lot using the Selection Id field. The application displays the selected lot in the Lot grid.
2. Proceed to Track In.
3. Select the Equipment. The application indicates whether dummy wafers are required or your lot does not meet the minimum wafer requirement.
4. Select the dummy wafer lot using the Selection Id field. The application adds the selected dummy wafer lot to the Lot grid.
5. Enter any required information for the dummy wafers.
6. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
7. Click Submit. The application displays a success message.

How to Track Out a Dummy Wafer Lot

Follow these steps to track out a dummy wafer lot:

1. Proceed to Track Out the dummy wafer lot only. The application displays the Data tab if a data collection is configured for the dummy wafers.
2. Follow these steps if the Data tab is displayed:
a. Open the Data tab.
b. Enter required data.
c. Click Submit.The application displays a status message.
d. Return to the Main tab.
3. Click Submit to Track Out the dummy wafer lot. The application displays an alert pop-up listing any dummy wafers that failed processing.
