Check Sheets

A Check Sheet executes one or more Electronic Procedures, each of which has one or more tasks to be performed during WIP processing. A Check Sheet is configured to execute for a selected spec and transaction, such as Track In Lot, Track Out Lot or Move Out Lot.

Advantages to configuring WIP processing to execute Check Sheets rather than individual Electronic Procedures include:

• The ability to configure specifically for Track In Lot, Track Out Lot and Move Out Lot levels
• The ability to block further processing or to proceed with a work flow based on the outcome of the tasks performed by the operator

Viewing Process Timers

The application displays a time field near the upper right corner of the page if the selected lot has an active process timer. Click the arrow next to the word Timers to view active process timers for the lot.

Refer to the Opcenter Execution Core Shop Floor User Guide for detailed information on the Process Time Enforcement feature. Refer to "Process Time Enforcement" in this guide for aspects of the feature specific to Opcenter Execution Semiconductor.

How to Complete a Check Sheet

Follow these steps to complete a check sheet:

1. Click Check Sheet tile on the WIP main Advanced page. The Check Sheet opens in a separate tab. The application populates the lot, header, task list pane, task pane, and working pane.
2. Use the default task selection or select a different task. Your ability to do so depends on whether the task list and electronic procedure are enforcing sequential processing.
3. Complete the required fields.
4. Are you executing an instruction, computation, or transaction task?

If you are executing . . .

Then . . .

An instruction or computation task

Click Execute. The application displays a success message and updates the status and execution count in the task tile. If the minimum number of iterations has been executed, the application updates the font color in Count accordingly.

A transaction task

When the selected task is a transaction task, the application displays the shop floor transaction page in the working pane and replaces Execute with a button labeled with the transaction name.

Click the transaction button to execute the transaction and the task simultaneously. The application displays a success message and updates the status and execution count in the task tile. If the minimum number of iterations has been executed, the application updates the font color in Count accordingly.
5. Repeat steps 3-4 to finish the tasks.
