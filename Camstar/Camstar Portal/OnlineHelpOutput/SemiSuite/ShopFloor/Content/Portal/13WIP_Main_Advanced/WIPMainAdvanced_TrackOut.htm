Track Out

The application enables WIP Main Advanced Track Out only if the lot is tracked into equipment. Track Out is used to fully or partially complete the processing of a lot in the Equipment.

Note: The application verifies requirements for the Inner Output Carrier Family when the Carrier is pending for Track Out. An error message will be prompted if an incorrect Inner Output Family is detected.

WIP Main Advanced Track Out Page Field Definitions

This table defines the fields on the WIP Main Advanced Track Out page.

Field

Definition

Activities Tiles

List of activities that are available for the selected lots. Each tile has an activity message, status and color (green for Passed, yellow for Not Executed, blue for Optional and red for Incomplete Prerequisite Step).

Track Out Qty

Amount of material processed on the server.

Dummy Qty

Number of empty positions on a strip.

Number of Strips

Number of empty positions on a strip.

Remain in Equipment

When checked, the difference between the track in quantity and the track out quantity will remain on the server. The transaction will fail if you track out the entire tracked in quantity.

Remain in Equipment If Possible

When checked, the difference between the track in quantity and the track out quantity will remain on the server. The transaction will not fail if you track out the entire tracked in quantity.

Cancel Track In

When checked, the previous Track In process will be canceled.

Note: Displayed only if the "Is Item Processing" in Assembly WIP Spec page is checked and the Lot grid has more than 1 lot.

Next Step

Next step in the workflow. This is visible if Auto-Move Out is true on the spec for the selected lots.

Split Unprocessed Qty

Boolean field that allows the operator to split off into a new lot the quantity of the lot that was not processed. Applies only to Quantity processing (not item processing).

Split Unprocessed Lot Id

Name of the split lot.

Binning

Display the Lot Bins pop-up to sort units out of a lot and into separate bins. Refer to "WIP Main Advanced Binning Tile Messaging" for information on tile messaging definitions.

Check Sheet

Display the Check Sheet page for the selected lot if Check Sheet was resolved from Blanket Experiments Matrix or Check Sheet Matrix. Refer to "WIP Main Advanced Check Sheet Tile Messaging" for information on tile messaging definitions.

Open the EProcedure page for the selected lot if e-procedure was defined. Refer to "WIP Main Advanced EProcedure Tile Messaging" for information on tile messaging definitions.

Future Hold

Display activity messages indicating the Future Hold will be executed upon completion of the Move Out. The Future Hold tile appears in the Track Out or Move Out phase depending on whether the Auto Move Out is modeled in the WIP Spec. By default, Future Hold messaging tile detects the default path. If the default path has future hold, the tile appears. The user can select the alternate path from the Next Step field, if alternate path is modeled in the Workflow.

In-Process Split (Step Logic)

Display the In-Process Split pop-up to split a lot into multiple lots. Refer to "WIP Main Advanced In-Process Split Tile Messaging" for information on tile messaging definitions.

Material Setup

Display the Equipment Materials Setup pop-up to load material lots to the equipment. Refer to "WIP Main Advanced Material Setup Tile Messaging" for information on tile messaging definitions.

Modify Maintenance

Display the Maintenance Management pop-up to complete maintenance requirements currently due for the resource being tracked in. Refer to "WIP Main Advanced Modify Maintenance Tile Messaging" for information on tile messaging definitions.

Reject Item

Display the Item Rejects pop-up to record rejects when processing at the item level. Refer to "WIP Main Advanced Reject Items Tile Messaging" for information on tile messaging definitions.

Reject Lot

Display the Item Rejects pop-up to record rejects when processing at the quantity level. Refer to "WIP Main Advanced Reject Lot Tile Messaging" for information on tile messaging definitions.

Sampling

Display the Sampling pop-up to collect sampling data during production. Refer to "WIP Main Advanced Sampling Tile Messaging" for information on tile messaging definitions.

Sorting

Display the Sorting pop-up to grade the wafers or items of a lot in WIP. Refer to "WIP Main Advanced Sorting Tile Messaging" for information on tile messaging definitions.

WIP Data

Display the WIP Data pop-up to perform data collection. Refer to "WIP Main Advanced WIP Data Tile Messaging" for information on tile messaging definitions.
