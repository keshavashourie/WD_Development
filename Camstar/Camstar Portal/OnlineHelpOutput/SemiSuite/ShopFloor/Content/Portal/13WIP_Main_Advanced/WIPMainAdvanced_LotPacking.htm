Lot Packing

The Lot Packing pop-up enables you to set the box quantities for a lot.

Lot Packing Field Definitions

This table defines the fields on the Lot Packing pop-up.

Field

Definition

Details Data grid

List of lots available in the schedule to combine.

Packing Instructions grid

List of packing instructions set in the schedule.

Packing Type

Used to calculate the quantity per box.

Packing Size (Qty Per Box)

Number of items that go into each box. This information is set in Packing Qty matrix.

Number of Boxes

Application-calculated number of boxes.

Partial Box Qty

Application-calculated number of items that go into the last box.

Partial Box Number

Application-calculated number for the last box.

Packing Qty

Application-calculated number of items (from all lots) to pack.

Total Lot Qty

Application-calculated total quantity of all selected lots.
