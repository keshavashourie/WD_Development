Track In

WIP Main Advanced Track In starts lot processing in equipment. The application enables Track In under these conditions:

• The step is configured for equipment processing.
• Processing has not been completed for the lot or the lot is able to be re-processed.

The application ensures that a recipe is active if a recipe is associated with the equipment being tracked in.

Note: The application verifies requirements for the Inner Input Carrier Family when the Carrier is pending for Track In. An error message will be prompted if an incorrect Inner Input Carrier Family is detected.

WIP Main Advanced Track In Page Field Definitions

This table defines the fields on the WIP Main Advanced Track In page.

Field

Definition

Activities Tiles

List of activities that are available for the selected lots. Each tile has an activity message, status and color (green for Passed, yellow for Not Executed, blue for Optional and red for Incomplete Prerequisite Step).

Track in Qty

Amount of product put on the equipment for processing.

Note: A Lot can be tracked into different Load Ports. The Track In transaction will fail if a different lot is tracked into the same Load Port. The transaction is allowed only if the lots are on the same carrier.

Source Equipment grid

Grid displays if the selected lots are at a step that does not require item processing and the lots are currently tracked in to another piece of equipment.

Comments

Free form text box to enter transaction information.

Load Port

A Load Port is a piece of equipment. This field appears when the selected Equipment in the Equipment field is modeled as a Parent Resource. At least one of the child equipments must be configured with an Equipment Type (Load Port) with an assigned Sub-Equipment Logical ID. The Load Port is required for the Track In transaction if at least one Load Port is configured for the Equipment. The Load Port drop-down displays only the Load Ports with the status currently set to Available.

Note: Lot Maintenance requirements for Load Port will be validated during tracking. The requirements include Date Requirement, Recurring Date Requirement, Thruput Requirement and Usage Requirement.

Refer to the Opcenter Execution Semiconductor Modeling Guide for more information.

How to Cancel a Track-In for Non-Processing Item

You are able to manually cancel a Track-In without using the "Cancel Track-In" check box by adjusting the quantity value during the next Track-Out process. Note that these steps are only applicable to a quantity-based lot and not for a wafer-based lot. Follow these steps to cancel a Track-In:

1. Access the WIP Main Advanced page to access a lot that was previously tracked in.
2. Enter the Lot ID in the Selection Id field for the Track Out process. The application populates fields with information of the lot entered.
3. Enter value "0" in the Track Out Qty field to cancel the previous Track-In quantity.
4. Click Submit to Track Out the lot. The application displays a success message. The page now returns to the previous Track In and when you enter the same Lot ID in the Selection ID field, it will display the previous quantity during Track In.
