Equipment Setup

The Equipment Setup pop-up enables you to set up equipment parameters, tools, and other information.

Equipment Setup Field Definitions

This table defines the fields on the Equipment Setup pop-up.

Field

Definition

Mask

Mask placed on the resource.

Note: The mast list contains all Masks associated to the Mask Set configured on the PN. Only Masks not linked to other equipment and are currently not under maintenance will be displayed.

Recipe

Recipe used to set up the resource.

Note: The recipe list contains Active recipes only. Inactive recipes are not available for selection. The recipes are limited to those within an assigned recipe group if a recipe group has been assigned for the selected equipment.

Scan to Add Tools

Enter or scan a tool to use for the resource.

Tools grid

Grid listing tools used for the selected resource.

Params grid

Grid listing parameters that must be entered for the selected resource.

Comments

Enter free form comments for association with the selected resource.

WIP Main Advanced Mask Tile Messaging

This table defines the tile messages on the WIP Main Advanced Mask tile.

Message

Message Definition

Display Condition

Mask Required for Layer XXX

Not Executed

The lot at the current step requires Mask to be validated as the Mask is set up in Process Spec.

Validation status: Not Executed

Mask tile appears when the Mask Layer value matches the Spec and WIP Main Phase (Track In) of the lot.

The message is displayed when the transaction has yet to be executed for the current WIP Main Phase.

Mask Required for Layer XXX

Passed

The lot at the current step requires Mask to be validated as the Mask is set up in Process Spec.

There is no need for any more mask transactions to be executed.

Validation status: Passed

Mask tile appears when the Mask Layer value matches the Spec and WIP Main Phase (Track In) of the lot.

The message is displayed when the transaction is successfully executed for the current WIP Main Phase.

Mask Required for Layer XXX

(Bypass allowed)

Passed

Mask is set to bypass and will not be required for execution.

Validation status: Passed

A Mask can be bypassed if WIP Spec of specific equipment is configured with the Bypass Mask Verification checked.

Mask tile appears when the Process Spec, Lot Experiments, Blanket Experiments or Recipe Matrix entry matches the Spec and WIP Main Phase (Track In) of the lot.

The message is displayed when the Mask is not required for execution as the Mask is set to bypass verification for the current WIP Main Phase.
