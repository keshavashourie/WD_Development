Wafer WIP Data Sampling

Wafer WIP Data Sampling can be configured on the WIP Main Advanced page or the Equipment WIP Dispatch page prior to Track In. Wafer WIP Data Sampling is detected when the lot has been configured with Wafer WIP Data Sampling and has Item Processing only set to true and loaded into slots of a wafer carrier. In the WIP Main Advanced page, when a lot is entered prior to Track In, the activity tile displays a message indicating wafer sampling is detected. It also indicates whether lots must be selected. You may identify if the lot has been assigned to a carrier by checking the Slot Position column in the Item grid tab.

You an reselect wafers or slots to sample in the Item grid. This is only applicable if the Sampling Method is User Selected or for any other method that is not enforced. If the Wafer Sampling is enforced for Top N, Bottom N, Sample Size, and Sample Percentage method, reselection is disabled. Refer to the Opcenter Execution Semiconductor Modeling Guide for information on the Wafer WIP Data Sampling, WIP Data Setup, and Assign Carrier Slot Map pages.

Note: Wafer Sampling takes precedence over AQL Sampling. If the existing default AQL Sampling and the Wafer WIP Data Sampling are configured at the same step, only Wafer WIP Data Sampling is performed.

The application does not allow lots with required wafer sampling to be tracked In together with non-required wafer sampling lots. You must perform the WIP Processing separately. Lots that have been partially tracked in to equipment are not allowed to perform wafer sampling.

The following explains WIP Main Advanced (Track In) page's expectation for every Wafer Sampling Method selected:

• User Selected - Either wafer sampling is enforced or not, at least 1 wafer must be selected for sampling on the Item grid. Optionally, you may select more wafers to be sampled.
• Top N - The application will automatically select the top N number of slots, where N is the number of wafers to be sampled. If wafer sampling is enforced, reselection will be disabled. If the wafer sampling is not enforced, you may optionally reselect wafers in the Item grid with quantity of N. The application will not allow further WIP processing (Track In, Track Out, or Move a quantity Out) if the required number of slots are not fulfilled.
• Bottom N - The application will automatically select the bottom N number of slots, where N is the number of wafers to be sampled. If wafer sampling is enforced, reselection will be disabled. If wafer sampling is not enforced, you may optionally reselect wafers in the Item grid with quantity of N. The application will not allow further WIP processing (Track In, Track Out, or Move a quantiry Out) if the required number of slots are not fulfilled.
• Sample Size - The application will preselect the number of slots based on the entered sample size. If the wafer sampling is enforced, reselection will be disabled. If wafer sampling is not enforced, you may optionally reselect the slot in the Item tab grid with the same specified quantity. The application will not allow further WIP processing (Track In, Track Out, or Move Out) if the required number of slots are not fulfilled. Refer to "Defining Wafer WIP Data Sampling" in Opcenter Execution Semiconductor Modeling Guide for information on sampling selected calculations based on the entered sample size and percentage.
• Sample Percentage - The application will preselect number of slots based on the entered sample percentage. If wafer sampling is enforced, reselection will be disabled. If wafer sampling is not enforced, you may optionally reselect the slot in the Item tab grid with the same specified quantity. The application will not allow further WIP processing (Track In, Track Out, or Move Out) if the required number of slots are not fulfilled. Refer to "Defining Wafer WIP Data Sampling" in the Opcenter Execution Semiconductor Modeling Guide for information on sampling selected calculations based on the entered sample size and percentage.

After Track In, the unselected wafers will proceed to the Move Out step.

The WIP Main Advanced page displays interactive messages on tiles whe wafer sampling is detected, slots are selected, and current selection is enforced. Each tile contains an activity message, status, and color.
