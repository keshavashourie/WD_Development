Carrier Validate

The Carrier Validate pop-up enables you to verify that the carriers assigned to a lot are available for processing.

You configure carrier validation by creating an instance of the Carrier Validation Setup matrix object. The Carrier Validation Setup matrix object defines the number of carriers to be validated and at which WIP transaction to enforce carrier validation. Refer to Opcenter Execution Semiconductor Modeling Guide for information.

The Activities tile displays a message indicating carrier validation is required when a lot in WIP Main matches the criteria specified by the Carrier Validation Setup matrix object. Selecting the Carrier Validation tiles displays the Carrier Validate pop-up, which enables you to verify the carriers.

The application does not allow further WIP processing (Move In, Track In, Track Out, or Move Out) if the associated carrier validation process is not performed.

How to Validate Carriers for a Lot

Follow these steps to validate carriers for a lot:

1. Select the Carrier Validation tile on the WIP Main Advanced page.
2. For each carrier to validate for the lot, enter the name of the carrier in the Carrier field and press TAB. The application adds the carrier to the Carriers to Validate grid.
3. Click Submit. The application validates the carriers in the Carriers to Validate grid.
