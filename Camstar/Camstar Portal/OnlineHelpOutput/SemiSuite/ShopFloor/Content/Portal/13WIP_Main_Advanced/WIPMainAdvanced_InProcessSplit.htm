In-Process Split

The In-Process Split pop-up enables you to split a lot into multiple lots.

The WIP Main Advanced page displays a tile activities message indicating that the lot in WIP Main Advanced should be split. Selecting the In-Process Split (Step Logic) tile prompt In-Process Split pop-up which enables you to split lots.

The application does not allow further WIP processing (Move In, Track In, Track Out, or Move Out) if the associated lot split process is not performed.

In-Process Split Field Definitions

This table defines the fields on the In-Process Split pop-up.

Field

Definition

Max In-Process Qty

To Lot Id

Lot ID of the lots into which the in process lot is split.

In-Process Qty

Quantity into which the lot will be split.

How to Split a Lot

Follow these steps to split a lot:

1. Select the In-Process Split (Step Logic) tile on the WIP Main Advanced page. The In-Process Split pop-up appears.
2. Select the To Lot Id.
3. Enter the In-Process Qty.
4. Click Submit. The application displays a success message.
