Electronic Procedures

Opcenter Execution Semiconductorcan be configured with Electronic Procedures that group multiple related tasks into one spec. Electronic procedures reduce the amount of transacting required during WIP processing. The operator can click E-Procedures tile on the WIP Main Advanced page to bring up the Electronic Procedure page.

Viewing Process Timers

The application displays a time field near the upper right corner of the page if the selected lot has an active process timer. Click the arrow next to the word Timers to view active process timers for the lot.

Note: Refer to the Opcenter Execution Core Shop Floor User Guide for detailed information on the Process Time Enforcement feature. Refer to "Process Time Enforcement" in this guide for aspects of the feature specific to Opcenter Execution Semiconductor.

EProcedure Page Field Definitions

This table defines the fields on the EProcedure page.

Field

Definition

Container/Lot Information

Details of selected container or lot

Task List Pane

One or more Task Lists assigned to the electronic procedure. If the task lists are sequential, indicated by an arrow at the end of the task list, you must complete the task lists in the order they appear. If the task lists are non-sequential, indicated by the lack of arrows, you can select any task list to perform.

Task Pane

Tasks for the selected task list. The application displays each task in a separate tile. The following definitions describe the fields that may appear in a single tile.

Sequence

Sequence number assigned to the task based on the sequence in which it appears in the Tasks grid of the Task List modeling object.

Optional

Visual cue indicating the task is not required. A task is optional when the Min Iterations value is 0. If the application does not display the Optional indicator, the task is required.

Status

Status of task: Not Executed, Passed, or Failed.

Task Name

Name of Task.

Count

Number of times the task has been executed, the minimum number of iterations required, and the maximum number of iterations allowed. When the minimum number of iterations have been executed, the application changes the background color and font accordingly.

Working Pane

Dynamic area displaying task name, instructions, and fields for the selected task. The name of the task appears in the working pane header. Depending on the task item type, some tasks may have required fields while others have only optional fields.

Instructions

Highlighted area displaying any task completion instructions.

Workstation

Workstation on which the task will be performed. The application requires you to select a workstation when the task type is a Start Process task. If the application defaults to a workstation, this field is display-only. Additionally, the application displays a visual cue indicating whether the selected workstation is available for processing.

Note: The application displays this field only for instruction and computation tasks.

How to Complete Electronic Procedure Tasks

Follow these steps to complete electronic procedure tasks:

1. For each task in the vertical task menu:
a. Select the task block. The relevant task information appears.
b. Complete the task.
Note: Some tasks are configured to be executed sequentially.
c. Click Submit. The workflow can proceed to the next step when all required tasks have been completed, along with any requirements on the main page.
