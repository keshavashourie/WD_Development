Lot Information

The Lot Info pop-up enables you to view the details of the selected lot that includes the attributes, process spec parameters, consumable materials, tool plans, recipes, historical WIP Data and historical user data collection.

Lot Information Pop-up Field Definitions

This table defines the fields on the Lot Information pop-up.

Field

Definition

Attributes grid

Grid listing information of the lot's attributes.

Process Spec grid

Grid listing information on the process spec for the selected lot.

Consumables grid

Grid listing information of the lots corresponding consumable material information.

Tool Plan grid

Grid listing information of the tooling type used to process the lot.

Recipe Plan grid

Grid listing information of the recipe plan used to process the lot.

Historic WIP Data grid

Grid listing the history of data collection records during WIP processing or production of the selected lot.

Step Name

Workflow step name when the data collection is performed on the selected lot.

WIP State

State of the WIP Step when the data collection is performed on the selected lot.

Wafer Scribe Number

Unique identifier of the wafer where the lot is in. This can be either system-generated or provided by the supplier.

Data Name

Data name used during the WIP data collection.

Data Value

Data value recorded during the WIP Data collection.

Lower Limit

Lower spec limit specified. Any value lower than this is considered out of acceptable range for making good product.

Upper Limit

Upper spec limit specified. Any value higher than this is considered out of acceptable range for making good product.

Yield Result

Indicates whether the entire lot passed or failed the yield. If the lot fails the yield, the yield failures are added to the WIP Lot Failures. Possible values are:

• NULL - Not calculated yet.
• PASS - All yield checks passed.
• FAIL - One or more yield checks failed.

Historic UDC grid

Grid listing the history of user data collection for the selected lot.

Step Name

Workflow step name when the user data collection is performed on the selected lot.

Data Collection Def Name

Name of the user's Data Collection Definition.

Data Name

Data name used during user data collection.

Data Value

Data value recorded during user data collection.

Lower Limit

Lower spec limit. Any value lower than this is considered out of acceptable range for making good product.

Upper Limit

Upper spec limit. Any value higher than this is considered out of acceptable range for making good product.
