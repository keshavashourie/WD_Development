Binning

Binning enables you to sort units out of a lot and into separate bins. For example, units may be grouped by test results. The lot may be split into new lots or continue being processed as one lot when all of the units have been tested and binned appropriately.

You perform binning during WIP processing using the Lot Bins pop-up. Binning can be configured to occur before or after Track Out. The application displays the Lot Bins pop-up if the operative WIP Spec includes a Bin Type.

How to Perform Binning for non Item-level Processing

Follow these steps to perform non item-level binning:

1. Click the Binning tile on the WIP Main Advanced page. The Lot Bins pop-up appears.
2. Use the Bins Details grid to perform binning.
a. Click the Bin Qty cell of the row with the target bin. The data entry fields display for that bin.
b. Enter the quantity to be moved to the bin.
3. When finished using the binning grid, click Submit.

How to Perform Binning for Item-level Processing

Follow these steps to perform item-level binning:

1. Click the Binning tile on the WIP Main Advanced page. The Lot Bins pop-up appears.
2. Select the Item Id to identify the wafer.
3. Use the Bins Details grid to perform binning for the selected wafer. For each bin to which you want to move quantity:
a. Click the Bin Qty cell of the row with the target bin. The data entry fields display for that bin.
b. Enter the quantity to be moved to the bin.
4. Repeat steps 2 - 3 for remaining wafer items as necessary.
5. Click Submit when you have finished binning for the selected wafer item. The Lot Bins pop-up closes.

How to Perform Binning for Item-level Processing of Multi-Product Wafers

Follow these steps to perform binning for item-level processing of multi-product wafers:

1. Click the Binning tile on the WIP Main Advanced page. The Lot Bins pop-up appears.
2. Select the Item Id to identify the wafer.
3. Select the Sub Product.
4. Use the Bins Details grid to perform binning for the selected wafer and sub-product. For each bin to which you want to move quantity:
a. Click on the Bin Qty cell of the row with the target bin. The data entry fields display for that bin.
b. Enter the quantity to be moved to the bin.
5. Repeat steps 3 - 5 for each sub-product to be binned from the selected wafer.
6. Repeat steps 2 - 6 for remaining wafer items as necessary.
7. Click Submit when you have finished binning for the selected sub product. The Lot Bins pop-up closes.
