Move In

The application enables WIP Main Advanced Move In after you select a lot. The lot is moved in from the queue and is ready to process.

WIP Main Advanced Move In Page Field Definitions

This table defines the fields on the WIP Main Advanced Move In page.

Field

Definition

Activities Tiles

List of activities that are available for the selected lots. Each tile has an activity message, status and color (green for Passed, yellow for Not Executed and blue for Optional).

Comments

Free form text box to enter transaction information about the move.
