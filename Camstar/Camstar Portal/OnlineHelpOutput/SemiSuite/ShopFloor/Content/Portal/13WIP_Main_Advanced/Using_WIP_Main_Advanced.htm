Using WIP Main Advanced

The WIP Main Advanced page is a refactored WIP Main page that provides a centralized location to perform actions on lots and equipment. The page also serves as a resource for lot and equipment information.

When Accessing WIP Main Advanced

The WIP Main Advanced grid initially appears blank when accessed from the menu. To populate the grid, you must either enter or select a lot or equipment. By default, the page operates based on lot selection.

WIP Main Advanced Lot and Equipment Field Definitions

This table defines the lot and equipment selection fields on the WIP Main Advanced page.

Field

Definition

Lot / Equipment

Selecting the Lot option toggles the page to display the Lot Selection pop-up. Meanwhile selecting Equipment option will toggle the page to display equipment-based Lot Selection pop-up.

Selection Id

ID for a lot, carrier, batch, or piece of equipment. Refer to "Using WIP Main Advanced" for information.

Employee

ID of the user who is responsible for completing this transaction.

Process Type

Used to provide one or more sub-processes for the Step or Spec. It is used mainly for auto-line setups where different types of equipment are linked together within a step. A lot must complete all the Process Types before it is allowed to move out to the next step. If no Process Types are assigned to the Step Name or Spec, the default NORMAL Process Type will be used.

Equipment

Used to select the equipment where the current Lot will be processed.

Activities

List of activities that are available for the selected lots in WIP Main Advanced phases (Move In, Track In, Track Out, and Move Out). Each tile has an activity message, status and color (green for Passed, yellow for Not Executed, blue for Optional and red for Incomplete).

Lot Tab Field Definitions

The Lot tab provides a display-only grid that displays lot details. This table defines the fields on the Lot tab.

Field

Definition

Container

Displays the list of lots to be processed.

Timers

Displays elapsed time of a process timer associated with the lot. Click field arrows to view timer detail.

Quantity

For items at an item processing step, this is the sum of all the die on all wafers at the item processing step.

For a lot that is not at an item processing step, this is the number of die.

Qty

Displays the number of die on the lot.

Qty2

Displays the number of items (wafers) on the lot.

Spec

Name of the Specification (Spec) referenced by a lot's current workflow step.

Step

Displays the process step of the lot.

Days Here

Number of days the lot has been at the current step.

Queue Time

Amount of time the lot has been at this process since the last recorded Move Out Time.

Product

Product associated with the lot.

Status

Status of the lot. The following statuses are allowed:

• ACTIVE – Allowed only if the current status is CANCELED. This is to reactivate the insertion after canceling it.
• TERMINATED – The lot is terminated.
• SHIPPED – The lot is shipped.

Is On Hold

Indicates whether the lot is on hold.

In Rework

Indicates whether the lot is currently in a rework state.

Insertion

Number of times the lot has been processed in the current step.

Insertion Process Spec

Process spec that defines the insertion.

Insertion SS

Supplementary spec that defines the insertion.

Rejects

Number of rejected wafers in the lot.

Move Out Qty

Number of die to move out.

WIP Status

Indicates the WIP status of the lot. The application can display the possible statuses:

• Active
• Completed

WIP Type

Type of WIP transaction the lot is on. For example, Track.

WIP Yield Result

Indicates whether the entire lot passed or failed the yield. If the lot fails the yield, the yield failures are added to the WIP Lot Failures. Possible values are:

• NULL - Not calculated yet.
• PASS - All yield checks passed.
• FAIL - One or more yield checks failed.

Batch No

Batch ID of the lot.

Eqp Count

Number of times the equipment has been used on the lot.

Eqp Loading Count

Number of times the equipment was loaded for the lot.

Future Hold Exists

Indicates whether the lot is scheduled to be put on hold in a future step.

In Schedule

Indicates whether the lot is scheduled.

Spec Pass

Current spec (step) the lot is on.

Spec Category

Category of the spec (step). For example, WIP.

Spec Type

Indicates the type of WIP spec. The application displays one of the following:

• Assembly
• Back grind
• Test
• Wafer sort
• Wafer

Spec Description

Description of the WIP spec associated with the lot.

Timers Count

Number of process timer for the lot.

WIP Main Advanced Activities Tiles

The Activities window has interactive tiles that assist and guide the user to the appropriate required activities.

Each tile has Activity message, status and color. The status and colors are updated dynamically based on current verifications or as transactions are successfully executed. The colors and status definitions are:

• Green - Passed
• Yellow - Not Executed
• Blue - Optional
• Red - Incomplete Prerequisite Step
WIP Instruction Pop-up on WIP Main Advanced Page

When a lot is configured with WIP Instructions (as modeled in the WIP Instruction Matrix page), the system displays a WIP Instruction pop-up during lot selection in the WIP Main Advanced page. This pop-up contains essential descriptions and messages required for the four transactions.

The WIP Instruction pop-up appears automatically when a lot is scanned or selected. For multiple lot selections, the system displays a paginated pop-up showing WIP instructions for each lot separately.
