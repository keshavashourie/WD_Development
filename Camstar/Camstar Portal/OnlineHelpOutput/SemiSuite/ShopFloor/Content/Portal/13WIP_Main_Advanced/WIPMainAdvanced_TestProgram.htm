Test Program

The Test Program pop-up enables you to select test parameters.

Test Program Field Definitions

This table defines the fields on the Test Program pop-up.

Field

Definition

In Use

Indicates the test programs which are in use.

Process Type

Process to which the test programs are applied.

Test Program Name

Name of the program.

Test Program Major Revision

Major revision number for the program.

Test Program Minor Revision

Minor revision number for the program.

Test Code

Alternate identifier for the test.

Test Temperature

Field that is fetched from Test Program Setup. If a test step has multiple sets of test parameters, you can remove some of them as long as there is one remaining for the Process Spec, Process Type and Spec.

WIP Main Advanced Test Program Validation Tile Messaging

This table defines the tile messages on the WIP Main Advanced Test Program Validation tile.

Message

Message Definition

Display Condition

Test Program Required (Lots 0 of 1 processed.) Not Executed

The lot at the current step requires Test Program to be validated.

There is a total of 1 lot required to perform Test Program.

Validation status: Not Executed

The Test Program Validation tile appears when the existing WIP Spec (Is Test status) entry matches the Spec and WIP Main Phase (Track In) of the lot.

The message is displayed when the Test Program Validation transaction has yet to be executed for the current WIP Main Phase.

Test Program Required (Lots 1 of 1 processed.) Passed

The lot at the current step has completed Test Program.

There is a total of 1 lot required to perform Test Program.

Validation status: Passed

 

The Test Program Validation tile appears when the existing WIP Spec (Is Test status) entry matches the Spec and WIP Main Phase (Track In) of the lot.

The message is displayed when the Test Program Validation transaction is successfully executed for the current WIP Main Phase.
