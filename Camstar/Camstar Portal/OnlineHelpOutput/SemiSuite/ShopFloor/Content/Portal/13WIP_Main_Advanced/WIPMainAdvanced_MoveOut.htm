Move Out

The application enables WIP Main Advanced Move Out only if the lot has completed its processing. Move Out moves the lot to the next step. The next step can be determined by a path selector or a supplementary spec based on the schedule, or the step can be manually selected based on setup.

Note: Effective with version 8.7, the Move Out transaction contains a subset HPE logic empowered by High Performance Engine (HPE) to increase larger transaction efficiency as the application processes transactions on the database rather than the application server. This new HPE logic is only trigger when processing lots with a parent/child relationship. Refer to Opcenter™ Execution Core Technical Reference: High Performance Engine for information.

Check Sheet

Future Hold

Display activity messages indicating the Future Hold will be executed upon completion of the Move Out. The Future Hold tile appears in the Track Out or Move Out phase depending on whether the Auto Move Out is modeled in the WIP Spec. By default, Future Hold messaging tile detects the default path. If the default path has future hold, the tile appears. The user can select the alternate path from the Next Step field, if alternate path is modeled in the Workflow.
