Single Wafer (Item) Tracking

Single Wafer (Item) Tracking enables you to process and track an individual wafer (item) as a quantity-based lot. This methodology does not require the use of the Multi-Level Start. It takes advantage of the existing functionality from both Opcenter Execution Core and Opcenter Execution Semiconductor.

Note: Single Wafer (Item) Tracking has been further enhanced with the addition of the following features; Carrier Operations (HPE), Work Order Dispatch (HPE) and Container Closure (HPE).

How to Utilize a Single Wafer (Item) Tracking

Follow these steps to initiate a Single Wafer (Item) Tracking:

1. Open the Lot Start page on the existing Opcenter Execution Semiconductor. Start individual lots with a base Qty of 1 or more. Optionally you may set the Qty2 value to 1 to indicate a single individual wafer (item) depending on how you configure the triggered for Equipment Maintenance. Since each wafer (item) is an individual lot, then it is not required to populate the Items grid.
Note: To take advantage of a parent-child relationship it is required to create a parent lot with a qty of zero (0). This is only possible if the PN (Part Number) is configured with "Allow Zero Qty".
Note: Starting a lot with Qty2=0, and Qty=1 is only applicable to non-Wafer Object Type.
2. Schedule and release the parent and/or child lots to WIP. Now it can be individually processed through WIP Main Advanced as normal containers.
3. Ensure that all WIP Specifications within the defined Workflow are configured with Is Item Processing check box as unchecked. Additionally confirm that Require Track In Qty check box is also unchecked.
4. If the lot is to be processed in a parent-child configuration, utilize Opcenter Execution Core Associate page to create the necessary hierarchy relationship. This page contains fewer restrictions than what was purposely designed for the WIP Associate process.

Once the association is complete then the parent lot becomes the trackable lot within WIP Main Advanced. All actions will be created and executed against the parent lot. When desired you can utilize the Opcenter Execution Core Disassociate page to remove the current parent-child relationship.

Keep in mind that Opcenter Execution Semiconductor has also provided configuration on the Spec and Process Spec that allows you to notify the user when a Manual Associate or Manual Disassociate must be performed. Additionally it can be configured for Auto Disassociate when needed. These features can be triggered at Move In, Move Out, and Rework. In Release 8.6, Track in and Track Out has been disabled.
