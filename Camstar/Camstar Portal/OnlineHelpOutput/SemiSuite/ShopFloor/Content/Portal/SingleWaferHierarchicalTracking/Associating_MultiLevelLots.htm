WIP Associate

The WIP Associate page enables you to rejoin (associate) parent and child lots that were created using Multi Level Start and disassociated during WIP processing.

How to Associate Multi-Level Child Lots to the Parent

Follow these steps to associate multi-level child lots with the parent:

1. Access the WIP Associate page.
2. Enter the ID of the parent lot in the Lot field or else enter the ID of a child lot in the Child Lot field. The application populates the Associate Child Lots grid.
3. Select the check box in the Associate Child Lots grid column header to select all child lots.

Or

Select the individual check box for each child to be rejoined (associated) with the parent.
4. Click Submit. The application displays a success message.
