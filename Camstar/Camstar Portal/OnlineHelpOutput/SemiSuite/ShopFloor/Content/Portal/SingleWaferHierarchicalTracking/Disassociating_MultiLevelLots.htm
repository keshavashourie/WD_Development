WIP Disassociate

The WIP Disassociate page enables you to remove the association between a parent and its child lots that were created with Multi Level Start. Multi-Level WIP processing contains a step that requires disassociation so that only the child lots can be Tracked In. The step can be configured to disassociate the children automatically. Otherwise, you manually disassociate the lots using the WIP Disassociate page.

How to Disassociate Multi-Level Child Lots from the Parent Lot

Follow these steps to disassociate multi-level child lots from the parent lot:

1. Access the WIP Disassociate page.
2. Enter the ID of the parent lot in the Lot field. The application populates the Disassociate Child Lots grid.
3. Select the check box in the Disassociate Child Lots grid column header to select all child lots.

Or

Select the individual check box for each child to be disassociated from the parent.
4. Click Submit. The application displays a success message.
