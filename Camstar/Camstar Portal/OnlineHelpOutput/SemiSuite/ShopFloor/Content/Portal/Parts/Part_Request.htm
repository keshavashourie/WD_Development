Part Request

The Part Request page enables you to request resource material parts from inventory or to return resource material parts from a resource back to inventory. The parts available for request are based on the BOM of the resource or maintenance request. A Request Order is created for each request.

How to Request a Part or Parts for a Resource

Follow these steps to request a part or parts for a resource:

1. Access the Part Request page.
2. Select a resource in the Resource field. The Job Order will be filled in automatically if you are using the page from within the technician's Job Progress transaction.
3. Select Request from the Request Type field. The application fills the Request Parts grid with material parts listed on the Resource BOM or Maintenance Req BOM for the selected resource.
4. Select a row with a material part that you want to request.
5. Enter a value greater than zero in the Request Part Qty field of the selected row.
6. Repeat steps 4-5 for each additional material part that you want to request for the resource.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Submit. The application displays a success message.

How to Return a Part or Parts from a Resource

Follow these steps to return a part or parts from a resource:

1. Access the Part Request page.
2. Select a resource in the Resource field. Job Order is filled in automatically if the page was launched from the Job Progress transaction.
3. Select Return from the Request Type field. The application fills the Request Parts grid with material parts listed on the Resource BOM or Mainteance Req BOM for the selected resource.
4. Select a row with a material part that you want to return.
5. Enter a value greater than zero in the Part Qty field of the selected row.
6. Repeat steps 4-5 for each additional material part that you want to return from the resource.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Submit. The application displays a success message.
