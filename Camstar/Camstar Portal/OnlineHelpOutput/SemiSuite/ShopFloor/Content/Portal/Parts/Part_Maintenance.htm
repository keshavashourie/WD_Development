Part Maintenance

The Part Maintenance page enables you to search for and maintain resource parts. It also enables you to select a material part and bring up the Part Create page to create a new part that will use the selected material part.

Part Type

Represents how material parts are to be inventoried and tracked. There are three such types:

• Serialized: Requires a new lot to be created for each shipment
• Bulk: Requires a new lot the first time the material part is shipped. Subsequent shipments from the same mother lot can be inventoried by increasing the quantity of the lot initially created.
• Non-serialized: No lot is created. It generally suffices to record the lot number for traceability purposes.

How to Create a Part

Follow these steps to create a part:

1. Access the Part Maintenance page.
2. Select search values in the search criteria area.
3. Click Search. The application populates the Search Results grid.
4. Select the part row on the Search Results grid. The application enables additional buttons under Shop Floor Txns.
5. Click Part Create. The Part Create pop-up appears with the Material Part and Part Qty fields filled in based on your selection.
6. Enter a name in the Part Name field.
7. Change the Material Part carried over from your selection on the parent page if necessary.
8. Change the Part Qty carried over from your selection on the parent page if necessary.
9. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
10. Click Part Create. The pop-up closes and the application displays a success message.

How to Set the Status of a Part

Follow these steps to set the status of a part:

1. Access the Part Maintenance page.
2. Select the part row on the Search Results grid. The application enables additional buttons under Shop Floor Txns.
3. Click Part Set Status. The Resource Set Status pop-up appears.
4. Select a status from the Status field.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.

How to to Set Up a Part

Follow these steps to set up a part:

1. Access the Part Maintenance page.
2. Select search values in the search criteria area.
3. Click Search. The application populates the Search Results grid.
4. Select the part row on the Search Results grid. The application enables additional buttons under Shop Floor Txns.
5. Click Part Setup. The Part Setup pop-up appears.
6. Select a material part from the Material Part field if necessary.
7. Select a setup from the Setup field if necessary
8. Enter a part quantity in the Part Qty field.
9. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
10. Click Part Setup. The pop-up closes and the application displays a success message.

How to Scrap a Part

Follow these steps to scrap a part:

1. Access the Part Maintenance page.
2. Select search values in the search criteria area.
3. Click Search. The application populates the Search Results grid.
4. Select the part row on the Search Results grid. The application enables additional buttons under Shop Floor Txns.
5. Click Part Scrap. The Part Scrap pop-up appears.
6. Enter the quantity to be scrapped in the Part Qty field.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Part Scrap. The pop-up closes and the application displays a success message.
