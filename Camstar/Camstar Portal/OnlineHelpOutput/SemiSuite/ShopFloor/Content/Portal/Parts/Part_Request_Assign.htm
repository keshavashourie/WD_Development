Part Request Assign

The Part Request Assign page enables you to assign resource material parts to a part request order. The user may assign partial quantities and assign multiple times until the full request quantity is satisfied.

How to Assign Material Parts to a Part Request

Follow these steps to assign material parts to a part request:

1. Access the Part Request Assign page.
2. Select a resource in the Resource field. The application fills in the Job Order if one applies, the Request Order, the Request Type, and the Request Order Material Parts grid.
3. Click Add new row on the Assigned Parts grid. A row is activated in the grid.
4. Select the Part.
5. Select the Material Part.
6. Enter the quantity you are assigning in the Assign Part Qty field.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Submit. The application displays a success message.
