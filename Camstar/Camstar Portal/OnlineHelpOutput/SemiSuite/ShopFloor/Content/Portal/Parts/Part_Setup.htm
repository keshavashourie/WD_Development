Part Setup

The Part Setup page enables you to specify all materials to be loaded onto equipment for Track In requirements. These materials can be consumable material parts such as substrates and epoxies as well as PNs comprised of material parts. Materials can be serialized or non-serialized.

How to Set Up a Part

Follow these steps to set up a part:

1. Access the Part Setup page.
2. Select the part from the Part field. The application populates any fields for which there is data.
3. Enter or select the material part (and revision number) from the Material Part field if it is currently blank or incorrect.
4. Enter a value in the Part Qty field. You may enter a zero if necessary.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
