Material Parts

The Material Parts page enables you to search for and select a resource material part that you can use to create a part. Refer to "About Parts and Resource Material Parts."

Note: This page relates to resource material parts—not material parts consumed by the product.

Part Type

Represents how material parts are to be inventoried and tracked. There are three such types:

• Serialized: Requires a new lot to be created for each shipment.
• Bulk: Requires a new lot the first time the material part is shipped. Subsequent shipments from the same mother lot can be inventoried by increasing the quantity of the lot initially created.
• Non-serialized: No lot is created. It generally suffices to record the batch Id for traceability purposes.

How to Create a Part from the Material Parts Page

Follow these steps to create a part:

1. Access the Material Parts page.
2. Select a Material Part, a Part Type, or both in the search criteria area.
3. Click Search. The application populates the Search Results grid.
4. Select the material part row on the Search Results grid.
5. Click Shop Floor Txns. The application displays a list of transactions.
6. Click Part Create. The Part Create pop-up appears with the selected material part and Part Qty displayed.
7. Enter a name in the Part Name field.
8. You can change the Material Part you selected if necessary.
9. You can change the Part Qty field if necessary.
10. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
11. Click Part Create. The pop-up closes and the application displays a success message.
