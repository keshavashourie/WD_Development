Part Create

The Part Create page enables you to create a part that requires a resource material part. This page can be accessed as follows:

• Directly from the Part Create transaction.
• By clicking Part Create on the Material Parts page.
• By clicking Part Create on the Part Maintenance page.

How to Create a Part

Follow these steps to create a part:

1. Access the Part Create page.
2. Select a Material Part, a Part Type, or both in the search criteria area.
3. Click Search. The application populates the Search Results grid.
4. Select the material part row on the Search Results grid.
5. Click Part Create. The Part Create pop-up appears.
6. Enter a name in the Part Name field.
7. Select the Material Part.
8. Enter the Part Qty.
9. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
10. Click Part Create. The pop-up closes and the application displays a success message.
