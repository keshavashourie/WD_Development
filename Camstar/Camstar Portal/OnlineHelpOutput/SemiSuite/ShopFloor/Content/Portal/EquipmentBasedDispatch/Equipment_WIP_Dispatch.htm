Equipment WIP Dispatch

The Equipment WIP Dispatch page provides a centralized location to move in, track in, track out, and move out equipment. It also provides lot and equipment information. The Equipment WIP Dispatch page is blank when you access it from the menu. The application displays the state of the selected equipment and the transactions you can perform after you select Equipment or an Equipment Group to dispatch.

Modeling Equipment WIP Dispatch

You must model the following objects before using Equipment WIP Dispatch:

• GUI Query
• Equipment Dispatch Query matrix

Refer to the Opcenter Execution Semiconductor Modeling Guide for information on modeling objects.

Lots and Transactions Under Process Timer Control

The Timers column in the Dispatch List Lot(s) grid and the Lot tab grid display a time field if the lot has an active process timer. Click the arrows next to the Timers field to display timer details.

The Shop Floor Txns listed for a selected lot may include transactions that are actively under process timer control. Attempting to perform a transaction outside of the process timer's constraints results in an error message.

Refer to the Opcenter Execution Core Shop Floor User Guide for detailed information on the Process Time Enforcement feature. Refer to "Process Time Enforcement" in this guide for aspects of the feature specific to Opcenter Execution Semiconductor.

Load Port

A Load Port is a piece of Equipment. This field appears when the selected Equipment in the Equipment field is modeled as a Parent Resource. At least one of the child equipments must be configured with an Equipment Type (Load Port) with an assigned Sub-Equipment Logical ID. The Load Port is required for the Track In transaction if at least one Load Port is configured for the Equipment. The Load Port drop-down displays only the Load Ports with the status currently set to Available.

Note: Lot Maintenance requirements for Load Port will be validated during tracking. The requirements include Date Requirement, Recurring Date Requirement, Thruput Requirement and Usage Requirement.

Refer to the Opcenter Execution Semiconductor Modeling Guide for information.

How to Perform Transactions on Equipment

Follow these steps to perform transactions on equipment:

1. Open the Equipment WIP Dispatch page. The Equipment WIP Dispatch page appears.
2. Enter the name of the equipment group, equipment, or both on which to perform transactions in the Equipment Group and Equipment fields respectively.
3. Click Reload. The application displays the lots you can dispatch in the Dispatch List Lots grid.
4. Select the lot on which to perform the transaction from the Dispatch List Lot(s) grid. The application displays the transactions you can perform on the lot in the Shop Floor Txns section. The transactions available for the lot are different depending on the lot.
5. Click one of the following in the Shop Floor Txns section to enter transaction data according to your business requirements:
