Equipment Setup

The Setup pop-up enables you to set up the equipment parameters, tools, and other information for lots dispatched using the Equipment WIP Dispatch page.

You can also access the Setup pop-up by clicking Setup on the Resource Layout View page. Refer to "Resource Layout View" for information on the Resource Layout View page.

Equipment Setup Pop-up Field Definitions

This table defines the fields on the Equipment Setup pop-up.

Field

Definition

Equipment

Name of equipment .

Employee

Employee performing this transaction if different than the user currently logged in.

Document Set

Document Set describing the Setup or any related information.

Parent Resource

Name of the parent resource.

Machine Group

Name of the Machine Group associated with the resource.

Package Group

Package Group to which the resource belongs. If configured, the lot's Leads must exist as one of the Details in the Package Group.

Max Lots

Maximum number of lots allowed in the resource.

Max Units

Maximum number of units allowed in the resource.

Multi Lots Flag

Indicates whether to check multi-lots during track in. You can select one of the following options:

• Not required.
• All lots must have the same Device, Package and Leads.
• All lots must have the same Package and Leads (Device can be the same or different).
• All lots must have different Package and Leads (Device can be the same or different).

Mask

Mask placed on the resource.

Note: The mast list contains all Masks associated to the Mask Set configured on the PN. Only Masks not linked to other equipment and are currently not under maintenance will be displayed.

Physical Location

Physical location of the resource.

Physical Position

Position of the resource within the physical location.

Product

Product associated to the resource.

Recipe

Recipe used to set up the resource.

Tool Plan

Tool Plan

Type of tooling required for the equipment. Each resource can be assigned a Tool Plan. If a Tool Plan is assigned to the resource, the required tools must be set up in the resource before it can be used to process lots.

Tool Plan Description

Description of the tool plan.

Tool Plan Details grid

Grid displaying the tools that are part of the assigned tool plans.

Scan to Add Tools

Enter or scan a tool to use for the resource.

Tools grid

Grid listing tools used for the selected resource.

Params grid

Grid listing parameters that must be entered for the selected resource.

Reference Lot Info

Reference Lot

Existing lot or setup from which to copy lot values.

Reference Lot Step Name

Workflow step name the referenced lot is in.

Reference Lot Process Type

Process available in the Process Spec Detail of the referenced lot.

Reference Lot Mask

Mask ID of the reference lot spec.

Comments

Enter free form comments for association with the selected resource.

How to Define Equipment Setup Parameters

Follow these steps to define equipment setup parameters:

1. Click Equipment Setup on the Equipment WIP Dispatch page.

Or

Click Setup on the Resource Layout View page.

The application displays the Setup pop-up.

2. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
3. Click Submit. The application displays a success message.
