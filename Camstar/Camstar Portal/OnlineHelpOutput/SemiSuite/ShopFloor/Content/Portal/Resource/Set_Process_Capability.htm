Set Process Capability

You use the Set Process Capability page to assign additional processing capabilities to equipment. Capabilities must be added to the application before they can be assigned. This is done in Modeling using the Process Capability page. Note that you cannot assign a process capability to equipment that is actively processing a lot.

Before Using the Set Process Capability Page

Process capabilities must be defined before they can be assigned. The Process Capability modeling page enables you to define process capabilities. Note that you cannot assign a process capability to an actively processing equipment.

How to Set Process Capability for Equipment

Follow these steps to set process capability for equipment:

1. Open the Set Process Capability page.
2. Select the equipment name from the Equipment field. The application displays any process capabilities currently assigned for the selected equipment in the Current Equipment Process Capability grid.
3. Click Add new row on the grid toolbar. A row is activated in the grid.
4. Select a process capability from the Process Capability field.
5. Select the Is Activated check box if applicable.
6. Repeat steps 3-5 for each additional process capability that you want to assign for the resource.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Submit. The application displays a success message.
