Container Feeder

The Container Feeder page enables you to assign a feeder to a serialized material lot or container.

Container Feeder Page Field Definitions

This table defines the fields on the Container Feeder page.

Field

Definition

Type

Selection Id

Field to select a serialized material lot.

Required

Lots grid

Grid listing details of the selected lots.

Display Only

Current Feeder

Feeder currently assigned to the selected lot.

Note: Field is blank if no feeder is currently assigned.

Display Only

New Feeder

Field to enter the name of a feeder to assign to the lot.

Note: New Feeder replaces any existing feeder currently assigned to the lot.

Optional

How to Assign a Feeder to a Serialized Material Lot

Follow these steps to assign a feeder to a serialized material lot:

1. Select the lot using the Selection Id field. The application populates the Lots grid with details about the selected lot and populates the Current Feeder field if a feeder is currently assigned to the selected lot.
2. Enter a New Feeder .
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit. The application displays a success message.
