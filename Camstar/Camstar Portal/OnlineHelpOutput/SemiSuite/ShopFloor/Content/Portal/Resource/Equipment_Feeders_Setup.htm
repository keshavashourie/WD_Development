Equipment Feeders Setup

Feeders are used to load components onto machines such as a chip shooters and universal GSM machines. Each feeder holds a reel and is placed into a machine slot. A machine can require multiple components and can have multiple slots. Another way to load components is to use a feeder bank. The feeder bank itself contains slots into which feeders are loaded and the bank is attached to the machine.

The Equipment Feeders Setup page enables you to load feeders and feeder banks onto equipment.

Note: You must select at least one feeder. You cannot select a feeder bank only.

How to Set Up a Feeder for Equipment

Follow these steps to set up a feeder for a resource:

1. Select the equipment from the Equipment field.
2. Select a From Feeder .
3. Select a From Feeder Slot.
4. Click Add. The application moves the selected values to the Eqp Feeders Materials Details grid.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
