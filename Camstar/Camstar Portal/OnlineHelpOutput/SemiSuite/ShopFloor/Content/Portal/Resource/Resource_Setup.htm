Resource Setup

Setup enables you to configure resources to run a specific configuration in production. You can use the Setup page to configure the following resources:

• Equipment (assembly, back grind, item, test, and wafer sort)
• Carriers
• Masks
• Tools

How to Set Up Resources

Follow these steps to set up equipment, masks, tools, and carriers:

1. Open the Setup page. The application displays the Setup page.
2. Enter the name of the resource for which you want to set the status in the field according to the kind of resource, as follows:

Resource

Field

Item equipment

Item Equipment

Wafer sort equipment

Item Sort Equipment

Back grind equipment

Back Grind Equipment

Assembly equipment

Assembly Equipment

Test equipment

Test Equipment

Mask

Mask

Tool

Tool

Carrier

Carrier

The application displays the details of the resource in the relevant fields.

3. Click Copy Reference to copy the reference lot values if you entered information in the Reference Lot Info section.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Submit. The application displays a success message.
