Tool Management

The Tool Management page enables you to manage tool statuses. Statuses determine such things as whether a tool is reserved for specific equipment or employee or whether the tool should be stored in a specific location. The Tool Management function updates the tool status as the tool is used on the shop floor.

You specify the tool to manage by entering search criteria and then selecting the tool from the instances that match the criteria you define. You can search for tools by name, tool family, tool status, reserved equipment, or a combination of two or more. The application displays the search results in the results grid.

When Managing Tools

Before using the Tool Management page, you must:

• Define all Tool Actions you will require. Refer to the Opcenter Execution Semiconductor Modeling Guide for information on the Tool Action modeling object.
• Set the status of the tool using the Set Status page. Refer to "Set Status" for information on the Set Status page.

How to Manage Tools

Follow these steps to manage tools:

1. Open the Tool Management page. The application displays the Tool Management page.
2. Enter the search criteria that matches the tool you want to manage.
3. Click Search. The application displays the search results in the grid.
4. Click the arrow in the row of the tool whose action you want to manage.
5. Click the action to take in the Tool Action list. The application displays the tool action button with the same name as the tool action. For example, if you click Store from the Tool Action list, the button is named Store.
6. Click the tool action button. The application displays the Tool Update Status pop-up.
7. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
8. Click Submit. The application closes the Tool Update Status pop-up and displays a confirmation message indicating that the tool was updated successfully.
