Resource Layout View

The Resource Layout View page presents a graphical view of status information for a selected resource and a menu of transactions that you can execute for the resource.

Modeling Resource Layout

You must model the following objects before using Resource Layout View:

• Equipment
• Resource Layout

Refer to the Opcenter Execution Semiconductor Modeling Guide for information on modeling objects.

How to Perform Transactions on Resources

Follow these steps to perform transactions on resources:

1. Open the Resource Layout View page. The Resource Layout View page appears.
2. Enter the name of the resource layout in the Resource Layout field. The application displays the resource layout.
3. Select the resource on which to perform the transaction from the Resource field. The application displays the transactions you can perform in the Shop Floor Txns section.
4. Click one of the following in the Shop Floor Txns section to enter transaction data according to your business requirements:
