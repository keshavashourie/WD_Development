Automation Setup

The Automation Setup page enables you to assign the type of automation that will be configured for the resource.

You can also access the automation setup fields by clicking Automation Setup on the Resource Layout View page. The application displays the automation setup fields on the Equipment Automation Setup pop-up when accessed this way. Refer to "Resource Layout View" for information on the Resource Layout View page.

Automation Setup Page Field Definitions

This table defines the fields on the Automation Setup page.

Field

Definition

Type

Equipment

Name of the equipment.

Required

Employee

Employee performing this transaction if different than the user currently logged in.

Optional

Automation Plan

Automation plan to use to track in or track out the resource.

Note: This field is required to Save the page.

Optional

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.

Optional

How to Define Automation Setup Parameters

Follow these steps to define automation setup parameters:

1. Open the Automation Setup page. The application displays the Automation Setup page.

Or

Click Automation Setup on the Resource Layout View page. The application displays the Equipment Automation Setup pop-up.

2. Enter the name of the equipment for which you are automating transactions in the Equipment field.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit. The application displays a success message.
