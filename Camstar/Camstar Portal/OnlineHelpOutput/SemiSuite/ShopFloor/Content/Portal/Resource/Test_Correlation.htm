Test Correlation

Test Correlation is used to record the completion of correlation testing done on equipment, masks, and tools. Correlation testing is specified during Equipment Setup and WIP tracking.

Note: Test Correlation does not track the correlation process, but completes test correlation by resetting the counters to allow lot processing on the equipment, mask, or tool.

When Using Test Correlation

The following are the types of correlation testing:

• Time – Correlation testing is required for every given time limit.
• Setup – Correlation testing is required if a parameter or Tool is updated.
• Shift – Correlation testing is required for each shift.

Test Correlation is done for all types in one transaction. You can also perform correlation if none of the required types has failed the limits.

Test Correlation is used for the following:

• Equipment Setup – The application verifies setup correlation when a parameter (with Require Setup Correlation flag set to true) or tool is updated.
• Tracking in lots – The application verifies all correlation types. You cannot track in a lot if any of the following occur:
• Last correlation date has passed the specified Time Correlation Limit.
• Setup correlation was set during Equipment Setup.
• Missed one Shift correlation.

How to Perform Test Correlation on a Resource

Follow these steps to perform test correlations:

1. Open the Test Correlation page.
2. Enter the resource name in the Equipment field. The application displays the correlation details for the resource.
3. Enter the number of correlation good units required for the equipment in the Good Units field.
4. Select Completed Correlation (PASS).
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Submit. The application displays a success message.
