Feeder Bank Set Status

The feeder bank Set Status page works much the same as the resource and feeder Set Status pages but is limited to setting the status of a feeder bank. The status represents the availability and accessibility of the feeder bank.

Feeder Bank Set Status Page Field Definitions

This table defines the fields on the feeder bank Set Status page.

Field

Definition

Type

Feeder Bank

Equipment resource that can hold multiple feeders and be attached to a machine.

Required

Status

Field to select a status to assign to the feeder bank. Displays the current status by default.

Required

Status Reason

Added level of detail describing the reason for the status of the feeder bank.

Optional

How to Set the Status of a Feeder Bank

Follow these steps to set the status of a feeder bank:

1. Open the Set Status page from the Feeder Bank menu. The application displays the Set Status page.
2. Select the feeder bank from the Feeder Bank field. The application displays the current status of the feeder bank in the Status field.
3. Enter the new status in the Status field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Submit. The application displays a success message.
