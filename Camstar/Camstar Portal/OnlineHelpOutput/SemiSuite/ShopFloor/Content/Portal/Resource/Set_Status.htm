Set Status

Set Status enables you to set the statuses for resources. Statuses are user-defined indicators of the availability and accessibility of resources. For example, you can use statuses to specify that a resource is available for use or that it is reserved for a particular area on the shop floor.

You can set the statuses for the following resources:

• Equipment (assembly, back grind, item, test, and wafer sort)
• Carriers
• Masks
• Tools
• Feeders
• Feeder Banks

When Setting Tool Statuses

Define all Tool Actions you will require and set the status for the tools you want to manage. Refer to the Opcenter Execution Semiconductor Modeling Guide for information on defining Tool Actions.

Equipment In Use

You cannot change the status of equipment that is in use (actively processing a lot) unless your application has been configured with the Allow In-Process Status Change check box selected. This check box is available at the individual equipment level and at the equipment group level. Specific logic governs which level's setting takes precedence. Refer to the Opcenter Execution Semiconductor Modeling Guide for information.

Status Changes of Parent and Child Equipment

A change to the status of parent equipment usually cascades down to any child equipment. An exception occurs when a parent is brought down, a child is already down, and then the parent is brought back up. The child will not be brought back up because it was not brought down as a result of the parent.

A change to the status of child equipment may update the parent status depending upon the configuration of the Child Status Combination field for the parent. The Allow In-Process Status Change option must be selected for the parent to enable updating the parent when it is actively in use.

Refer to the Opcenter Execution Semiconductor Modeling Guide for information.

Set Status Page Field Definitions

This table defines the fields on the Set Status page.

Field

Definition

Type

Type Name

Name of the equipment, mask, tool, or carrier for which you want to set the status. For example, the field name is Item Equipment if you are setting the status for item equipment, the field name is Tool for tools, and so on.

Required

Employee

Employee performing this transaction if different than the user currently logged in.

Optional

Status

Initial status for the resource, as specified by the Initial Status (To Set Null Status) field. This value is the Carrier Status Code for carriers and the Resource Status Code for all other resources.

Required

Status Reason

Reason for the resource status. The status reason provides an added level of detail describing the reason for the current status of a resource. For example, if the current status is Repair, you could provide a status reason to indicate the type of repair that is being performed.

This value is the Carrier Status Reason for carriers and the Resource Status Reason for all other resources.

Optional

Comments

Additional information or instructions. The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.

Optional

How to Set Statuses

Follow these steps to set the status for equipment, masks, tools, and carriers:

1. Open the Set Status page. The application displays the Set Status page.
2. Enter the name of the resource for which you want to set the status in the field according to the kind of resource, as follows:

Item Equipment

The application displays the current status of the resource in the Status field.

3. Enter the new status in the Status field.
4. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
5. Click Save. The application displays a success message confirming that the tool status was changed successfully.
