Feeder Container

The Feeder Container page enables you to assign a serialized material lot or container to a feeder.

Feeder Container Page Field Definitions

This table defines the fields on the Feeder Container page.

Field

Definition

Type

Feeder

Field to select a feeder.

Required

Current Container

Serialized material lot currently assigned to the selected feeder.

Display Only

New Container

Field to enter the name of the serialized material lot to be loaded onto the feeder.

Note: New Container replaces any existing container or lot assigned to the selected feeder.

Optional

How to Assign a Serialized Material Container to a Feeder

Follow these steps to assign a serialized material container to a feeder:

1. Select the feeder from the Feeder field. The application populates the Current Container field if a container is currently assigned to the selected feeder.
2. Enter a New Container.
3. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
4. Click Submit. The application displays a success message.
