Getting Started

Siemens provides the Portal Shop Floor user interface (UI) to enable you to perform shop floor transactions in the application. Refer to the Opcenter Execution Core Shop Floor User Guide for information on the default shop floor transaction pages provided by Siemens when you install Opcenter Execution Core. Refer to the Opcenter Execution Core Getting Started User Guide for information on logging on to the application, navigating the application, and using common shop floor fields and functionality.

Additional menu items are added to the primary navigation menu by default when Opcenter Execution Semiconductor is installed. These menu items provide access to pages that enable you to perform Opcenter Execution Semiconductor shop floor transactions.
