Nachverfolgungsbeschriftung überprüfen

Auf der Seite "Nachverfolgungsbeschriftung überprüfen" können Sie die Richtigkeit einer Beschriftung überprüfen. Auf dieser Seite können Sie zwei verschiedenartige Überprüfungen durchführen:

• Eltern-Kind-Verifizierung – Bietet die Möglichkeit, die Eltern-Kind-Beziehung von Beschriftungs-IDs zu überprüfen (z. B. Rollen zu einer Schachtel).
• Satzverifizierung – Bietet die Möglichkeit, zu überprüfen, ob eine bestimmte Gruppe von Beschriftungen Teil eines Satzes ist. Sie können anhand dieser Verifizierung überprüfen, ob die angegebenen Beschriftungen zum gleichen Los gehören.

Vorgehensweise zum Verifizieren von Beschriftungen

Gehen Sie folgendermaßen vor, um Beschriftungen zu verifizieren:

1. Öffnen Sie die Seite "Nachverfolgungsbeschriftung überprüfen".
2. Führen Sie einen der folgenden Schritte durch:

Zum Verifizieren von . . .

Gehen Sie wie folgt vor . . .

Eltern-Kind-Beziehung zwischen Beschriftungen
a. Geben Sie Eltern-Kind-Verifizierung im Feld Verifizierungsplan ein.
b. Geben Sie eine Eltern-Beschriftungs-ID in das Feld Hauptbeschriftungs-ID ein.
c. Geben Sie eine Kind-Beschriftung in das Feld Kind-Beschriftungs-ID ein und drücken Sie die Tabulatortaste. Die Anwendung zeigt die Kind-Beschriftungs-ID in der Tabelle "Kind-Beschriftungs-ID" an.
d. Wiederholen Sie Schritt c für alle Kind-Beschriftungen.

Zugehörigkeit aller Beschriftungen zu einem Satz
a. Geben Sie Satzverifizierung im Feld Verifizierungsplan ein.
b. Geben Sie eine Beschriftung in das Feld Kind-Beschriftungs-ID ein und drücken Sie die Tabulatortaste. Die Anwendung zeigt die Kind-Beschriftungs-ID in der Tabelle "Kind-Beschriftungs-ID" an.
c. Wiederholen Sie Schritt b für alle Beschriftungen im Satz.
3. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
4. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
