Verwenden von Dummywafern

Ein Dummywaferlos ist ein element- oder waferbasiertes Los, das ein Dummyprodukt enthält. Dummywafer können für die folgenden Produktionszwecke verwendet werden:

• Kalibrieren einer Ausrüstungsressource immer dann, wenn sie einen konfigurierten Durchsatzwert erreicht hat oder für die konfigurierte maximale Leerlaufzeit im Leerlauf war.
• Überprüfen von Prozessdaten bezogen auf Nicht-Produktionswafer vor dem Abmelden.
• Erfüllen der Mindestwaferanforderung, die das Produktionslos allein nicht erfüllen kann.

Lebensdauer eines Dummywafers

Ein Dummywafer kann mehrfach verwendet werden, bis er seine Lebensdauergrenze erreicht hat. Dummywafer, die ihre Lebensdauer erreicht haben, können nicht eingebracht und müssen als Ausschuss deklariert werden. Die Lebensdauer kann anhand der folgenden Kriterien konfiguriert werden:

• Maximale Verarbeitungsanzahl: Dieses Maximum ist für das Dummyprodukt konfiguriert. Jeder Wafer, der dieses Produkt enthält, beginnt mit einem Zähler, der den maximalen Wert hat. Der Zähler wird jedes Mal um eins verringert, wenn der Wafer eingebracht wird. Die Wafer hat das Ende seiner Lebensdauer erreicht, wenn der Zähler null erreicht hat.
• Maximale Verarbeitungszeit: Dieses Maximum ist für das Dummyprodukt konfiguriert. Die Bearbeitungszeit für einen Wafer, der dieses Produkt enthält, wird mit diesem Maximum verglichen. Ein Wafer, der dieses Maximum überschreitet, hat das Ende seiner Lebensdauer erreicht.
• Waferattributvalidierung: In "Prozessspez.: Details" kann ein maximaler Wert für ein angegebenes Waferattribut konfiguriert werden. Das Attribut könnte z. B. "Waferdicke" und der Wert könnte "0,80" sein. Das Dickenmaß des Wafers wird mit diesem konfigurierten Wert verglichen. Ein Wafer, der dieses Maximum überschreitet, hat das Ende seiner Lebensdauer erreicht.
