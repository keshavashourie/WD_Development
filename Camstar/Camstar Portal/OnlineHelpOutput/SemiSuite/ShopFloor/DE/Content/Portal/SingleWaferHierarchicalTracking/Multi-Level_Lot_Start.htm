Mehrstufiger Start

Die Seite "Mehrstufiger Start" ermöglicht es Ihnen, ein Elternlos mit Kindlosen zu erstellen. Das Produkt selbst kann waferbasiert sein, aber die erstellten Lose sind mengenbasiert und durchlaufen eine mengenbasierte Verarbeitung. Sie können Kindlose mit X-, Y-Koordinaten identifizieren, wenn dem Produkt eine Vorlage "Containerabmessung" zugewiesen wurde.

Containerabmessungen

Eine Vorlage "Containerabmessung" gibt die Position an, die das Produkt im Container hat, und gibt an, wo Kindlose innerhalb dieser Position zugewiesen werden können. Eine Containerabmessung umfasst drei erforderliche Felder:

• X-Maß – Anzahl der Spalten, in denen Kindlose zugewiesen werden können.
• Y-Maß – Anzahl der Zeilen, in denen Kindlose zugewiesen werden können.
• X-Y-Startposition – Anfangsposition: "Oben links", "Oben rechts", "Unten links", "Unten rechts"

Das X- und das Y-Maß (Positionen) bestimmen die maximale Anzahl von Kindlosen, die erstellt werden können. Multiplizieren Sie X mit Y, um die maximale Anzahl von Kindlosen zu ermitteln, die erstellt werden können.

Die markierten Zellen in dieser Tabelle entsprechen den Positionen, an denen Kindlose für einen Container bestimmt werden können, der mit dem X- bzw. Y-Maß von 4 bzw. 3 und der Anfangsposition "Oben links" angegeben ist.

Vor dem Verwenden von "Mehrstufiger Start"

Der Systemadministrator oder zuständige Modellierer konfiguriert einige oder alle der folgenden Modellierungsobjekte zur Unterstützung von "Mehrstufiger Start" und Einzelwaferverarbeitung:

Objekt

Konfiguration für Mehrstufigkeit und Einzelwafer

Containerabmessung

Wird zum Erstellen einer Vorlage verwendet, die ein Paar aus X-Maß und Y-Maß und eine Anfangsposition enthält, die einem PN-Produkt zugeordnet werden können.

PN

Enthält das Feld "Vorlage 'Containerabmessung'", um dem Produkt eine Vorlage zuzuordnen.

Prozessspez.: Details

Das Popup "Hinzufügen" enthält die folgenden Felder für "Mehrstufigkeit":

• Ist 'Mehrstufige Aufteilung': Bestimmt, ob der Schritt erfordert, dass ein mehrstufiges Elternlos manuell von seinen Kindlosen getrennt wird.
• Arbeitsplanschritt für Vereinigen bei Mehrstufigkeit: Schritt, in dem die abgetrennten Kindlose wieder mit dem Elternlos verbunden werden.
• Autom. mehrstufige Aufteilung: Bestimmt, ob in dem Schritt ein mehrstufiges Elternlos automatisch von seinen Kindlosen getrennt wird.

Vorgehensweise zum Starten eines mehrstufigen Loses

Gehen Sie folgendermaßen vor, um ein mehrstufiges Los zu starten:

1. Rufen Sie die Seite Mehrstufiger Start auf.
2. Geben Sie einen Bezeichner für den Elterncontainer oder das Elternlos in das Feld Los-ID ein.
3. Wählen Sie ein Produkt aus, das eine zugeordnete Vorlage "Containerabmessung" hat. Die Anwendung füllt die Felder mit den Standardwerten des Produkts.
4. Klicken Sie auf Neue Zeile hinzufügen in der Tabelle Kindlose zuordnen. Eine Zeile wird in der Tabelle aktiviert.
5. Geben Sie eine ID für das neue Kindlos in das Feld Containername ein.
6. Geben Sie die Menge für das Kindlos ein.
7. Ist dem Produkt eine Vorlage "Containerabmessung" zugeordnet?

Antwort . . .

Dann . . .

Ja
a. Geben Sie die X-Position für das Kindlos ein.
b. Geben Sie die Y-Position für das Kindlos ein.

Nein
a. Belassen Sie X-Position und Y-Position leer.
8. Wiederholen Sie die Schritte 4 bis 7 für jedes weitere Kindlos, das erstellt werden soll.
9. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
10. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.

Nach einem Verwenden von "Mehrstufiger Start"

Das Elternlos, das mit "Mehrstufiger Start" erstellt wurde, ist zunächst seinen Kindlosen zugeordnet. Das Los muss geplant sein, bevor es verarbeitet werden kann. Sie wählen nur das Elternlos aus, um das Los und dessen zugehörige untergeordneten Kindlose zu planen, vorzubereiten und freizugeben.
