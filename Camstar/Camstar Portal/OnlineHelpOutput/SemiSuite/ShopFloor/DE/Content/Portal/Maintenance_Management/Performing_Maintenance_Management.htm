Durchführen von Wartungsverwaltung

Sie verwenden die Transaktion "Wartungsverwaltung", um die Wartungsanforderung einer Ressource als abgeschlossen zu markieren, nachdem die Wartung durchgeführt wurde. Die Transaktion "Wartungsverwaltung" ermöglicht es Ihnen, Suchkriterien für Ressourcen mit Wartungsanforderungen anzugeben, die abgeschlossen werden können.

Wenn Sie auf "Suchen" klicken, ohne die Standardfilter geändert zu haben, enthalten die Suchergebnisse alle Typen von Wartungsanforderungen.

Wenn Sie eine Zeile in der Tabelle "Suchergebnisse" auswählen, passiert Folgendes:

• Die entsprechenden Felder im Abschnitt "Wartungsdetails" werden automatisch ausgefüllt. Alle "Wartungsdetails"-Felder sind schreibgeschützt, abgesehen von den Kommentar-Feldern.
• Alle Anforderungen, die mit der ausgewählten Anforderung verknüpft sind, werden in der Tabelle "PM-Überschreibungen" angezeigt. Die Anwendung aktualisiert verknüpfte Anforderungen automatisch in den Status "Ist beendet", wenn sie die Basisanforderung in den Status "Ist beendet" aktualisiert.
• Alle Checklisten, die für die ausgewählte Anforderung konfiguriert sind, werden in der Tabelle "Checklisten" angezeigt.

Anzeigen zugeordneter Dokumente

Wenn das Symbol "Dokumente anzeigen" aktiviert ist, können Sie darauf klicken, um das Popup "Dokumente anzeigen" zu öffnen, das Verknüpfungen enthält, über die die zugeordneten Dokumente angezeigt werden können.

Daten sammeln

Wenn Sie auf "Abschicken" klicken, zeigt die Anwendung ein Popup-Fenster "Datensammlung" mit Feldern für benutzerdefinierte oder parametrische Datensammlungen an, wenn diese über die Datenerfassung der Wartungsanforderung oder die Datenerfassung der Checkliste der Wartungsanforderung konfiguriert wurden. Wenn Checklisten konfiguriert sind, müssen Sie zuerst die entsprechende Checklistenzeile auswählen, bevor Sie auf die Schaltfläche "Abschicken" klicken.

Vorgehensweise zum Durchführen einer erforderlichen Wartung für eine Ressource

Gehen Sie folgendermaßen vor, um die erforderliche Wartung für eine Ressource durchzuführen:

1. Öffnen Sie die Seite "Wartungsverwaltung". Die Seite "Wartungsverwaltung" wird angezeigt.
2. Geben Sie Werte in die Felder Suchkriterien eingeben ein, um die Anzeige von Ressourcen zu beschränken.
3. Klicken Sie auf Suchen. Die Tabelle "Suchergebnisse" zeigt die Wartungsstatus-Informationen der Ressourcen an, die den eingegebenen Suchkriterien entsprechen. Falls keine Suchkriterien eingegeben werden, werden alle möglichen Ergebnisse angezeigt.
4. Klicken Sie auf die Zeile für die Ressource, die eine Wartungsanforderung hat, die entweder in der Warnungsfrist ("Ausstehend"), "Fällig" oder "Überfällig" ist. Details der Wartungsanforderung werden in den schreibgeschützten "Wartungsdetails"-Feldern angezeigt.
5. Klicken Sie auf das Symbol "Dokumente anzeigen", falls dieses aktiviert ist, und falls Sie eine Liste der Dokumente anzeigen möchten, die der ausgewählten Ressource zugeordnet sind. Das Popup "Dokument anzeigen" wird angezeigt.
6. Klicken Sie auf den zugehörigen Link, um ein Dokument anzuzeigen. Wenn Sie fertig sind, klicken Sie auf Schließen, um das Popup "Dokumente anzeigen" zu schließen.
7. Klicken Sie auf Zusätzliche Felder anzeigen, um Kommentare einzugeben, die speziell für diese Wartungsanforderung gelten.
8. Aktivieren Sie für jede Checkliste, die in der Tabelle "Checklisten" angezeigt wird, das Kontrollkästchen in der Tabellenzeile und führen Sie die Checkliste aus.
9. Klicken Sie auf Beendet.
10. Geben Sie bei Bedarf einen Datenpunktwert für jede Stichprobe im Popup-Fenster "Datensammlung" ein.
11. Ist eine elektronische Unterschrift für diese Transaktion erforderlich?
