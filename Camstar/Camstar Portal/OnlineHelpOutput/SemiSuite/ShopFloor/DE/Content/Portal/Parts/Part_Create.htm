Teileerstellung

Die Seite "Teileerstellung" ermöglicht es Ihnen, ein Teil zu erstellen, für das ein Ressourcenmaterialteil erforderlich ist. Diese Seite kann wie folgt aufgerufen werden:

• Direkt aus der Transaktion "Teileerstellung".
• Durch Klicken auf "Teileerstellung" auf der Seite "Materialteile".
• Durch Klicken auf "Teileerstellung" auf der Seite "Teilewartung".

Vorgehensweise zum Erstellen eines Teils

Gehen Sie folgendermaßen vor, um ein Teil zu erstellen:

1. Rufen Sie die Seite "Teileerstellung" auf.
2. Wählen Sie im Suchkriterienbereich ein Materialteil, einen Teiletyp oder beides aus.
3. Klicken Sie auf Suchen. Die Anwendung füllt die Tabelle "Suchergebnisse".
4. Wählen Sie in der Tabelle "Suchergebnisse" die Zeile des Materialteils aus.
5. Klicken Sie auf Teileerstellung. Das Popup "Teileerstellung" wird angezeigt.
6. Geben Sie einen Namen in das Feld Teilename ein.
7. Wählen Sie das Materialteil aus.
8. Geben Sie die Teilemenge ein.
9. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
10. Klicken Sie auf Teileerstellung. Das Popup wird geschlossen und die Anwendung zeigt eine Erfolgsmeldung an.
