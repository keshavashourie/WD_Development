Losfreigabe

"Losfreigabe" wird verwendet, um angehaltene Lose oder Lose mit zukünftigen Halts freizugeben. Es ist möglich, mehrere zukünftige Halts gleichzeitig freizugeben, ohne das Los aus dem ersten Halt freizugeben.

Felddefinitionen der Seite "Losfreigabe"

Diese Tabelle definiert die Felder auf der Seite "Losfreigabe".

Feld

Definition

Typ

Auswahl-ID

ID für ein Los, einen Behälter, einen Batch oder einen Ausrüstungsgegenstand.

Erforderlich

Mitarbeiter

Mitarbeiter, der diese Transaktion ausführt, wenn er nicht der derzeit angemeldete Benutzer ist.

Optional

Tabelle "Details"

Zeigt die für die Freigabe ausgewählten Lose an.

Hinweis: Diese Tabelle muss mindestens ein Los enthalten.

Erforderlich

Los

Das zur Freigabe ausgewählte Los.

Nur Anzeige

Alle Anhaltepositionen freigeben

Kontrollkästchen, um anzugeben, ob alle Anhaltepositionen freigegeben werden sollen.

Optional

Nur Anhaltepositionen freigeben

Wenn dieses Kontrollkästchen aktiviert ist, wird das Los nur aus den Anhaltepositionen freigegeben und das Los verbleibt bei der ersten Anhalteposition ("Aktuelle Anzahl Angehalten" = 1).

Hinweis: Aktivieren Sie das Kontrollkästchen, wenn das Los angehalten bleiben muss.

Optional

Beim Klicken auf diese Option wird das Popup "Anhaltepositionen" angezeigt.

Optional

Freigabegrund

Gibt den Grund für die Freigabe an.

Erforderlich

Regalposition

Gibt die Regalposition für das Los an.

Optional

Auf Zeitplanlose anwenden

Kontrollkästchen, um anzugeben, ob Lose, die zum gleichen Zeitplan wie das Los gehören, freigegeben werden sollen. Lose, die zum gleichen Zeitplan gehören, werden freigegeben, wenn das Kontrollkästchen aktiviert ist.

Optional

Standardgrund f. Freigabe

Gibt den Standard-Freigabegrund für die Detaildatensätze an, für die kein Grund angegeben wurde.

Optional

E-Mail-Gruppe

E-Mail-Gruppe, die E-Mails erhalten soll.

Optional

Zusätzliche Felder anzeigen/ausblenden

 

Kommentare

Zusätzliche Informationen oder Anweisungen. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional
Befehlsleistensymboldefinitionen der Seite "Losfreigabe"

Diese Tabelle definiert die Symbole in der Befehlsleiste auf der Seite "Losfreigabe". Die Befehlsleiste ist verfügbar, wenn Ihr Standardthema auf "Horizon" festgelegt ist.

Symbol

Funktion des Symbols . . .

Abschicken

Speichert die Daten auf der Seite.

Zurücksetzen

Löscht alle Felder auf der Seite.

Onlinedurchläufer

Zeigt das Popup "Onlinedurchläufer" an. Verwenden Sie dieses Symbol, um die Arbeitsplanhistorie für das ausgewählte Los anzuzeigen.

Fehler

Zeigt das Popup "Fehler" für das ausgewählte Los oder die ausgewählte Ausrüstung an. Bietet die Möglichkeit, die Ertragsfehler für das Los im aktuellen Schritt und bei abgeschlossener Einsetzung anzuzeigen.

Erforderliche Materialien

Zeigt das Popup "Erforderliche Materialien" an. Verwenden Sie dieses Popup, um eine Liste der Materialprodukte anzuzeigen, die für das Los erforderlich sind.

Anhaltepositionen für Los

Zeigt das Popup "Anhaltepositionen" an. Verwenden Sie diese Option, um "Spezifikation", "Anhaltegründe", "Anhalteposition", "Anhalten: Anzahl", "Erwartete Anhaltetage", "Anhalten: Benutzername" und "Start-Regalposition" für das ausgewählte Los anzuzeigen.

Dokumentensätze

Zeigt das Popup "Dokumente anzeigen" an. Verwenden Sie diese Option, um eine Liste der Dokumentsätze für das ausgewählte Los anzuzeigen.

Vorgehensweise zum Freigeben eines angehaltenen Loses

Gehen Sie folgendermaßen vor, um ein angehaltenes Los freizugeben:

1. Rufen Sie die Seite "Losfreigabe" auf.
2. Wählen Sie das Los bzw. die Lose über das Feld Auswahl-ID aus. Die Anwendung füllt die Tabelle "Details" mit den ausgewählten Losen.
3. Wählen Sie für jedes in der Tabelle angezeigte Los einen Freigabegrund aus.
4. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
