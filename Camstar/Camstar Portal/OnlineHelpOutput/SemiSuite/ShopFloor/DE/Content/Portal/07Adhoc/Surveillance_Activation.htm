Überwachungsaktivierung

Auf der Seite "Überwachungsaktivierung" können Sie eine Überwachungsanforderung auswählen und mit den folgenden Elementen verbinden:

• Ressource
• Ressourcengruppe
• Operation
• Arbeitsbereich

Felddefinitionen der Seite "Überwachungsaktivierung"

Diese Tabelle definiert die Felder auf der Seite "Überwachungsaktivierung".

Feld

Definition

Typ

Überwachung

Die Überwachungsanforderung.

Erforderlich

Überwachungstyp

Typ des Überwachungsziels: "Ressource", "Ressourcengruppe", "Operation" oder "Arbeitsbereich".

Hinweis: Dieses Feld ist technisch gesehen optional. Eine Aktivierung erfüllt aber ohne dieses Feld keinen Zweck.

Optional

Ressourcengruppen-Filter

Feld, das angezeigt wird, wenn Sie "Ressource" als Überwachungstyp auswählen. Bietet die Möglichkeit, die angezeigten Ressourcen auf eine Ressourcengruppe einzugrenzen.

Optional

Tabelle "Servicedetails"

Enthält eine Liste der Suchergebnisse und ermöglicht eine Auswahl.

 

Aktiviert

Kontrollkästchen, um eine zu erledigende Anforderung auszuwählen.

Optional

Ressource Name

Nicht-Materialelemente (keine Produkte) wie Ausrüstung, Maschinen und Personen, die am Fertigungsprozess beteiligt sind. Feld ist leer, es sei denn, Sie haben "Ressource" als Überwachungstyp ausgewählt.

Nur Anzeige

Ressourcengruppenname

Gruppiert Ausrüstung oder Werkzeuge, die gleich sind und möglicherweise gegenseitig austauschbar verwendet werden können. Feld ist leer, es sei denn, Sie haben "Ressourcengruppe" als Überwachungstyp ausgewählt.

Nur Anzeige

Operationsname

Produktions- oder Bearbeitungspunkt, an dem Lager- und Produktionsaktivitäten verfolgt werden. Feld ist leer, es sei denn, Sie haben "Operation" als Überwachungstyp ausgewählt.

Nur Anzeige

Arbeitsbereichsname

Bereich, in dem ähnliche Arbeiten durchgeführt werden. Beispiele hierfür sind das Verpacken oder Qualitätsprüfungen. Feld ist leer, es sei denn, Sie haben "Arbeitsbereich" als Überwachungstyp ausgewählt.

Nur Anzeige

Vorgehensweise zum Aktivieren einer Überwachungsanforderung

Gehen Sie folgendermaßen vor, um eine Überwachungsanforderung zu aktivieren:

1. Öffnen Sie die Seite "Überwachungsaktivierung".
2. Wählen Sie die Überwachungsanforderung im Feld Überwachung aus.
3. Wählen Sie einen Überwachungstyp aus. Die Anwendung zeigt alle Instanzen des ausgewählten Typs an. Ein bereits aktiviertes Kontrollkästchen bedeutet, dass die ausgewählte Anforderung für die betreffende Instanz bereits aktiviert ist. Das Feld "Ressourcengruppenfilter" wird auch angezeigt, wenn Sie eine Ressource ausgewählt haben.
4. Aktivieren Sie das Kontrollkästchen der einzelnen Überwachungstypinstanzen, für die Sie die Anforderung aktivieren möchten.
5. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
