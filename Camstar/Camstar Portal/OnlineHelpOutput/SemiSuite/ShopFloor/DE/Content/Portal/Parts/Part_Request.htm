Teileanforderung

Die Seite "Teileanforderung" ermöglicht es Ihnen, Ressourcenmaterialteile aus dem Lagerbestand anzufordern oder Ressourcenmaterialteile aus einer Ressource wieder in den Lagerbestand zurückzuführen. Die zum Anfordern verfügbaren Teile ergeben sich aus der Stückliste der Ressourcen- oder Wartungsanforderung. Für jede Anforderung wird ein Anforderungsauftrag erstellt.

Felddefinitionen der Seite "Teileanforderung"

Diese Tabelle definiert die Felder auf der Seite "Teileanforderung".

Feld

Definition

Typ

Ressource

Ausrüstungsressource, für die Sie Teile anfordern oder aus der Sie Teile zurückführen möchten.

Erforderlich

Jobauftrag

Jobauftragsnummer eines aktiven Wartungsjobs für die Ressource. Dieses Feld wird automatisch ausgefüllt, wenn die Seite "Teileanforderung" während der Transaktion "Jobfortschritt" angezeigt wurde.

Hinweis: Wird ein Jobauftrag auf der Seite "Teileanforderung" gespeichert, wird dieser Job mit der Teileanforderung verknüpft. Dies hat später zur Folge, dass der Wartungsjob erst abgeschlossen oder abgebrochen werden kann, wenn die verknüpfte Teileanforderung abgeschlossen, verbraucht oder abgebrochen wurde.

Optional

Anforderungstyp

"Anforderung" oder "Rücklauf".

Erforderlich

Tabelle "Anforderungsteile"

Die Tabelle listet Ressourcenmaterialteile auf, die in der Ressourcenstückliste für die ausgewählte Ressource enthalten sind.

Ressourcenmaterialteil, das von einem anderen Ressourcenteil verwendet wird.

Hinweis: Das Teil muss entweder in der Stückliste, die der Ressource zugewiesen ist, oder in einer Stückliste vorhanden sein, die einer Wartungsanforderung für die Ressource zugewiesen ist.

Vorgehensweise zum Anfordern von Teilen für eine Ressource

Gehen Sie folgendermaßen vor, um Teile für eine Ressource anzufordern:

1. Rufen Sie die Seite "Teileanforderung" auf.
2. Wählen Sie im Feld Ressource eine Ressource aus. Der Jobauftrag wird automatisch ausgefüllt, wenn Sie die Seite innerhalb der "Jobfortschritt"-Transaktion des Technikers verwenden.
3. Wählen Sie "Anforderung" im Feld Anforderungstyp aus. Die Anwendung füllt die Tabelle "Anforderungsteile" mit Materialteilen, die auf der Ressourcenstückliste oder der Wartungsanforderungsstückliste der ausgewählten Ressource aufgeführt sind.
4. Wählen Sie eine Zeile mit einem Materialteil aus, das Sie anfordern möchten.
5. Geben Sie einen Wert größer als null in das Feld Angeforderte Teilemenge der ausgewählten Zeile ein.
6. Wiederholen Sie die Schritte 4 bis 5 für jedes weitere Materialteil, das Sie für die Ressource anfordern möchten.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Einreichen. Die Anwendung zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Zurückführen von Teilen aus einer Ressource

Gehen Sie folgendermaßen vor, um Teile aus einer Ressource zurückzuführen:

1. Rufen Sie die Seite "Teileanforderung" auf.
2. Wählen Sie im Feld Ressource eine Ressource aus. "Jobauftrag" wird automatisch ausgefüllt, wenn die Seite aus der Transaktion "Jobfortschritt" aufgerufen wurde.
3. Wählen Sie "Rücklauf" im Feld Anforderungstyp aus. Die Anwendung füllt die Tabelle "Anforderungsteile" mit Materialteilen, die auf der Ressourcenstückliste oder der Wartungsanforderungsstückliste der ausgewählten Ressource aufgeführt sind.
4. Wählen Sie eine Zeile mit einem Materialteil aus, das Sie zurückführen möchten.
5. Geben Sie einen Wert größer als null in das Feld Teilemenge der ausgewählten Zeile ein.
6. Wiederholen Sie die Schritte 4 bis 5 für jedes weitere Materialteil, das Sie aus der Ressource zurückführen möchten.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Einreichen. Die Anwendung zeigt eine Erfolgsmeldung an.
