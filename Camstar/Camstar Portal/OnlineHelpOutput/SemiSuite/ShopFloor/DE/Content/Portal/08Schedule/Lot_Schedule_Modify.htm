Loszeitplan ändern

Auf der Seite "Loszeitplan ändern" können Sie einen Produktionszeitplan ändern. Auf der Seite "Loszeitplan ändern" können Sie auch eine Verarbeitung mit einer ergänzenden Spezifikation auf Spezifikations- oder Schrittebene angeben. Bei einer Spezifikation auf Schrittebene können Sie Unterarbeitsplanschritte auswählen.

Felddefinitionen der Seite "Loszeitplan ändern"

Diese Tabelle definiert die Felder auf der Seite "Loszeitplan ändern".

Feld

Definition

Typ

Auswahl-ID

ID des Loses in dem Zeitplan, den Sie ändern möchten.

Wichtig: Dieses Feld ist nicht als erforderlich markiert, muss aber eingegeben werden, damit die Anwendung die erforderlichen Felder füllen kann.

Optional

Zeitplandaten

Die ID des Loszeitplans.

Hinweis: Die Anwendung füllt automatisch das Feld für die Zeitplan-ID aus, wenn Sie eine gültige Los-ID in das Feld "Auswahl-ID" eingeben.

Erforderlich

Arbeitsauftrag

Produktionsauftrag, der zum Starten des Loses verwendet wird.

Optional

Produkt

Fertigungsprodukt, das produziert wird.

Erforderlich

Stückliste

Stückliste für den Zeitplan.

Optional

Prozessspez.

Die verwendete Spezifikation, um Lose zu verfolgen, nachdem sie aus dem Lagerbestand abgemeldet und in die Umlaufbestandsverarbeitung angemeldet wurden. Sie legt die auszuführenden Arbeitsplanschritte und alle Parameter und Variationen in Arbeitsplanschritten fest.

Hinweis: Sie müssen die jeweilige Revision auswählen, die in der Prozessspez.-Liste des Produkts konfiguriert ist.

Erforderlich

Eigentümer

Eigentümer des Zeitplans.

Erforderlich

Priorität des Zeitplans.

Verpackungstyp

Optional

Externe Kommentare

Feld für zusätzliche Kommentare, das in der Regel verwendet wird, um Informationen für eine externe Anwendung, z. B. eine ERP-Anwendung, zur Verfügung zu stellen.

Optional

Verkaufsauftragsnummer

Zusätzliche Information für einen Zeitplan. Wird in der Regel verwendet, um die Verkaufsauftragsnummer aus einer ERP-Anwendung zu speichern.

Optional

Änderungsgrund

Der Grund für die Änderung eines Losattributs. Dieses Feld ist erforderlich, wenn für ein geändertes Losattribut ein Grund erforderlich ist.

Hinweis: Die Losattribute umfassen:

• Produkt
• Prozessspez.
• Eigentümer
• Priorität
• Externe Kommentare
• Verkaufsauftragsnummer
• Empfängerfabrik
• Produktstückliste

Optional

Neue Los-ID

ID für ein erstelltes Los oder ein Los, das durch eine Aufteilung erstellt werden soll. Die ID wird mit der Methode zum Verifizieren von Regeln für den Service von "Los aufteilen" überprüft.

Hinweis: Dieses Feld kann nicht für einen Batch-Loszeitplan verwendet werden, da die einzelnen Lose über einen eigenen Zeitplan verfügen.

Optional

Neue Los-ID autom. festlegen

Flag, das angibt, ob die neue Los-ID bei der Loszeitplanvorbereitung festgelegt werden soll, was dazu führt, dass das Los aufgeteilt wird.

Hinweis: Dieses Feld kann nicht für einen Batch-Loszeitplan verwendet werden, da die einzelnen Lose über einen eigenen Zeitplan verfügen.

Optional

Arbeitsplanschritt

Dieses Feld ist erforderlich, wenn die Prozessspezifikation geändert wird.

Hinweis: Dieses Feld wird ignoriert, wenn der Zeitplanstatus geplante (SCHEDULED) ist, da dadurch keine Losbewegungstransaktion verursacht wird.

Optional

Fertigungslinie

Fertigungslinie ist eine Ausrüstungsgruppe, mit der ein Los verarbeitet wird. Dieses Feld wird zunächst mit der Fertigungslinie gefüllt, die im Arbeitsauftrag angegeben ist.

Optional

Zeitplandurchläufer aktualisieren

Kontrollkästchen, um anzugeben, ob der Begleitschein für den Zeitplan aktualisiert werden soll, wenn eine Änderung im Arbeitsplan vorliegt.

Optional

Empfängerfabrik

Gibt die Empfängerfabrik an, die am Ende des Prozesses verwendet wird.

Optional

Zusätzliche Felder anzeigen/ausblenden

 

Zeitplankommentare

Bereich für zusätzliche Informationen. Standardmäßig werden die Kommentare angezeigt, die bei der Loszeitplanung eingegeben wurden. Der Benutzer darf diese ändern.

Optional

Ergänz. Spez.: Details aktualisieren

Wenn dieses Kontrollkästchen aktiviert ist, füllt die Anwendung die Tabelle "Ergänz. Spez.: Details" mit Daten aus "Referenz für erg. Spez.-Plan".

Optional

Referenz für erg. Spez.-Plan

Wird für die Eingabe von Details der ergänzenden Spezifikation verwendet. Die in "Referenz für erg. Spez.-Plan" festgelegten Details können abgerufen und automatisch zu "Erg. Spez.: Details" hinzugefügt werden. Die Felder sind identisch, außer dass in "Zeitplan: Erg. Spez.-Plan" das Feld "Los-ID" nicht vorhanden ist. Eine ausführliche Beschreibung der Felder finden Sie im nächsten Element.

Optional

Tabelle "Ergänz. Spez.: Details"

Tabelle, um die Verarbeitung durch eine ergänzende Spezifikation anzugeben, die über der Verarbeitung durch die Prozessspezifikation durchgeführt wird.

Hinweis: Verwenden Sie für alle neuen Zeitpläne die Tabelle "Erg. Spez. nach Schritt: Details", die eine Unterstützung von Unterarbeitsplänen ermöglicht.

Optional

Ergänz. Spez.

Zu verwendende ergänzende Spezifikation. Deren Zeitplantyp muss mit dem Zeitplantyp der Prozessspezifikation identisch sein. Zum Beispiel kann für eine "Zusammenbau-Hauptlos: Prozessspez." nur eine "Zusammenbau-Hauptlos: Ergänz. Spez." verwendet werden. Das "Prozessspez.: Status"-Flag "Ist verfügbar" muss aktiviert sein, wenn die ergänzende Spezifikation erstmals dem Zeitplan zugewiesen wird.

Optional

Abmelden von Spez.

Spezifikation innerhalb des Arbeitsplans der Prozessspezifikation, die das Los verlässt, um zu "Abmelden zu Spez." zu gelangen. Beachten Sie folgende Informationen:

• Eine Unterwegs-Spezifikation kann nicht als "Abmelden zu Spez." ausgewählt werden.
• Eine Lagerbestandsspezifikation kann als "Abmelden zu Spez." ausgewählt werden. Dies erfolgt deshalb, damit das Los direkt zur ergänzenden Spezifikation bewegt wird, anstatt zuerst zur Prozessspezifikation und dann zur ergänzenden Spezifikation gehen zu müssen.
• Nur ein ergänzender Detaildatensatz darf eine Lagerbestandsspezifikation als "Abmelden von Spez." angeben.

Optional

Abmelden zu Spez.

Umlaufbestandsspezifikation oder GEPLANTE Spezifikation im Arbeitsplan der ergänzenden Spezifikation, zu der das Los bewegt wird, nachdem "Abmelden von Spez." verlassen wurde.

Optional

Zurückmelden von Spez.

Umlaufbestandsspezifikation oder GEPLANTE Spezifikation im Arbeitsplan der ergänzenden Spezifikation, von der das Los zurück zur Prozessspezifikation bewegt wird. Dieses Feld ist optional, da die Logik die Möglichkeit bietet, die Losbearbeitung in der ergänzenden Spezifikation durchzuführen. Dieses Feld ist jedoch erforderlich, wenn "Zurückmelden zu Spez." angegeben ist.

Optional

Zurückmelden zu Spez.

Umlaufbestandsspezifikation oder GEPLANTE Spezifikation im Arbeitsplan der Prozessspezifikation, zu der das Los vom Arbeitsplan der ergänzenden Spezifikation bewegt wird. Dieses Feld ist erforderlich, wenn "Zurückmelden von Spez." angegeben ist.

Optional

Hauptlos ignorieren

Kontrollkästchen, um anzugeben, ob das Hauptlos beim Abmelden des Loses berücksichtigt wird. Wenn aktiviert, überspringt das Hauptlos den Detaildatensatz der ergänzenden Spezifikation.

Optional

Los-ID

Gibt die Los-ID im Zeitplan an, der beim Abmelden des Loses berücksichtigt werden soll. Der Detaildatensatz der ergänzenden Spezifikation wird verwendet, wenn der Wert festgelegt ist und mit dem Los beim Abmelden des Loses übereinstimmt.

Optional

RPT Großmengendelta

Differenz der Gesamtverarbeitungszeit für einen Batch von Vorgängen, wenn der ursprüngliche Arbeitsplan mit dem aktualisierten Versuchsplan verglichen wird.

Das Delta zeigt, wie sich die Zeit zum Verarbeiten des Batches oder Aufgabensatzes aufgrund von Anpassungen im Workflow, im Versuchsdesign oder in der Ressourcenzuweisung ändert. Es wird berechnet, indem die Differenz der Großmengenverarbeitungszeit zwischen dem ursprünglichen Plan und dem geänderten Plan ermittelt wird.

Die Einheiten für dieses Feld werden in Stunden ausgedrückt, wobei die Werte aus Gründen der Genauigkeit und Konsistenz auf zwei (2) signifikante Stellen gerundet werden. Diese Werte können positiv, negativ oder null sein.

Optional

RPT Einheitendelta

Differenz der Verarbeitungszeit für eine einzelne Einheit oder einzelne Aufgabe zwischen dem ursprünglichen Arbeitsplan und dem aktualisierten Versuchsplan.

Das Delta spiegelt wider, wie sich die Zeit, die zum Abschließen einer Arbeitseinheit, einer Aufgabe oder eines Experiments erforderlich ist, ändert, wenn die beiden Workflows verglichen werden. Es wird berechnet, indem die Differenz der Verarbeitungszeit pro Einheit zwischen dem ursprünglichen Plan und dem geänderten Plan ermittelt wird.

Die Einheiten für dieses Feld werden in Stunden ausgedrückt, wobei die Werte aus Gründen der Genauigkeit und Konsistenz auf zwei (2) signifikante Stellen gerundet werden. Diese Werte können positiv, negativ oder null sein.

Optional

Tabelle "Aufteilung in Bearbeitung: Details"

Tabelle, um die Anforderung zur Aufteilung in Bearbeitung für Spezifikationen mit einer INPROCESSSPLIT-Schrittlogik anzugeben. Die Aufteilung in Bearbeitung erfolgt, wenn das Los in der Ausrüstung (nach dem Einbringen des Loses, aber vor dem Ausbringen des Loses) verarbeitet wird. Die aufgeteilte Menge verwendet den gleichen Zeitplan wie das Hauptlos. Der Prozess "Zusammenbau-Unterlos" teilt ein Los normalerweise beim Anhängen von Dies in kleinere überschaubare Lose. Die Lose werden dann im Verpackungsschritt vereinigt, bevor der Umlaufbestand fertiggestellt wird.

Hinweis: "Aufteilung in Bearbeitung: Details" kann nicht für eine Verarbeitung von Menge 2 verwendet werden. In der Prozessspezifikation "Zusammenbaubehälter" darf keine Aufteilung in Bearbeitung angegeben werden. Bei "Zusammenbaubehälter" handelt es sich um eine vollkommen andersartige Nachverfolgung. Dabei werden Behälter für die Losnachverfolgung verwendet. Die Anwendung führt eine automatische Aufteilung oder Vereinigung durch, wenn die Behälter beim Ausbringen des Loses geändert werden.

Verpackungsdetails aktualisieren

Kontrollkästchen, um anzugeben, ob die in die Tabelle "Verpackungsdetails" eingegebenen Daten gespeichert werden sollen.

Optional

Tabelle "Verpackungsdetails"

Tabelle, in der die Packanweisungen für Spezifikationen mit einer Verpackungslogik angegeben werden. Ein Beispiel dafür ist die Aufteilung eines Zusammenbauloses in mehrere Unterlose beim Anhängen von Dies. Packanweisungen können verwendet werden, um Unterlose zu vereinigen, die sich im Verpackungsschritt befinden, und die anderen Lose in ein neues Los mit einem neuen Zeitplan aufzuteilen. Dies bietet die Möglichkeit, dass die Lose im Verpackungsschritt die Umlaufbestandsverarbeitung beenden können, ohne auf die anderen Lose warten zu müssen.

Hinweis: "Verpackungsdetails" kann nicht für eine Menge2-Verarbeitung verwendet werden.

Optional

Spez.

Name der Spezifikation mit Packanweisungen.

Optional

Los-ID

Gibt die Los-ID an.

Gibt die Losmenge an.

Vorgehensweise zum Ändern eines Zeitplans

Gehen Sie folgendermaßen vor, um einen Zeitplan zu ändern:

1. Rufen Sie die Seite "Loszeitplan ändern" für den zu ändernden Zeitplantyp auf.
2. Geben Sie die Los-ID in das Feld Auswahl-ID ein. Die Anwendung füllt die Felder mit Informationen für das eingegebene Los.
3. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
4. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
