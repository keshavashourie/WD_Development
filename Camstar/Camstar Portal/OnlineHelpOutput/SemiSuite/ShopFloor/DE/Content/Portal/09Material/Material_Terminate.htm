Materialabbruch

Auf der Seite "Materialabbruch" können Sie Materiallose abbrechen.

Felddefinitionen der Seite "Materialabbruch"

Diese Tabelle definiert die Felder auf der Seite "Materialabbruch".

Feld

Definition

Typ

Auswahl-ID

ID für ein Los, einen Behälter, einen Batch oder einen Ausrüstungsgegenstand.

Erforderlich

Mitarbeiter

Mitarbeiter, der diese Transaktion ausführt, wenn er nicht der derzeit angemeldete Benutzer ist.

Optional

Tabelle, in der die Details der ausgewählten Lose aufgelistet sind.

Optional

Zusätzliche Felder anzeigen/ausblenden

 

Kommentare

Zusätzliche Informationen oder Anweisungen. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Abbrechen eines Materialloses

Gehen Sie folgendermaßen vor, um ein Materiallos abzubrechen:

1. Rufen Sie die Seite "Materialabbruch" auf.
2. Wählen Sie das Materiallos im Feld Auswahl-ID aus oder geben Sie es in das Feld ein. Die Anwendung füllt die Tabelle "Lose" mit Informationen zum ausgewählten Los.
3. Wählen Sie den Abbruchgrund aus.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
