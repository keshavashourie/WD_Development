Hauptumlaufbestands- und Dummywaferverarbeitung

Hauptumlaufbestandsverarbeitung umfasst Validierungen und Überprüfungen, von denen einige speziell für die Verarbeitung von Dummywafern gelten und von denen einige zu der Notwendigkeit führen können, dass Dummywafer eingebracht werden.

Sie bringen ein oder mehrere Dummywaferlose gleichzeitig mit einem oder mehreren Produktionslosen ein, wenn Sie Dummywafer verwenden müssen. Sie bringen das oder die Dummywaferlose aus, bevor Sie das oder die Produktionslose ausbringen.

Vor dem Verwenden von Dummywafern

"Einbringen" von Dummywafern hängt von der Konfiguration ab, die in der Modellierung vorgenommen wurde. Die Modellierungsobjekte "PN" (Produkt), "Prozessspez." und "Ausrüstung" unterstützen Dummywaferverarbeitung in der Fertigung. Der Systemadministrator konfiguriert Instanzen dieser Objekte entsprechend den Anforderungen Ihrer Produktion. Es muss mindestens ein Dummywaferprodukt konfiguriert sein, damit Sie Dummywaferverarbeitung verwenden können. Weitere Informationen finden Sie unter Opcenter Execution Semiconductor Modeling-Benutzerhandbuch.

Starten eines Dummywaferloses

Sie benötigen ein Dummywaferlos, um Dummywafer einbringen zu können. Erstellen Sie das Los, indem Sie "Los starten" verwenden und ein Dummyprodukt auswählen. Die Anwendung verschiebt die Lebensspanne des Dummyprodukts in das Objekt für die Loswafer.

Hinweis: Das Dummywaferlos und das Produktionslos müssen denselben Umlaufbestandsstatus haben, damit sie eingebracht werden können.

Validierungen für Einbringen

Die Anwendung führt die folgenden Validierungen für die Ressource aus:

• Sie vergleicht die Anzahl der eingebrachten Wafer mit der Mindestwaferanforderung für die Ressource. Dummywafer können zusammen mit den Produktionswafern eingebracht werden, wenn die Anzahl der Produktionswafer kleiner ist als die Mindestanzahl.
• Sie vergleicht die Anzahl der eingebrachten Dummywafer mit den Dummywafer-Mindestanforderungen für die Ressource.
Hinweis: Sie erhalten nach Klicken auf "Abschicken" eine Fehlermeldung, wenn eine Dummywafer-Mindestanforderung nicht erfüllt ist.
• Sie vergleicht die Zeit, die seit der letzten Verwendung der Ausrüstung vergangen ist, mit der maximalen Leerlaufzeit, die für die Ressource konfiguriert ist. "Ausbringen" wird erlaubt, der Ausrüstungsstatus wird aber auf DOWN festgelegt, wenn die maximale Leerlaufzeit überschritten ist.
Hinweis: Die Anwendung erlaubt ein Einbringen von Dummywafern in Ausrüstung, die den Status DOWN hat. Ein Vorhandensein von Dummywafern in einem Los bewirkt aber nicht, dass es möglich ist, Produktionswafer einzubringen.

Die Anwendung führt die folgenden Validierungen für alle Dummywafer aus:

• Sie vergleicht das konfigurierte Waferattributmaximum jedes Wafers mit dem Umlaufbestandsdatenwert für dieses Attribut. Die Anwendung verhindert das Einbringen, wenn der Waferattributwert das Maximum überschreitet.
Hinweis: Dieser Fehler wäre in einer Popup-Nachricht angezeigt worden, wenn der Wafer im vorherigen Schritt ausgebracht worden wäre. Die Fehlerverarbeitung wird aber ausgeführt, wenn Sie versuchen, den Befehl "Einbringen" auszuführen.
• Sie vergleicht die tatsächliche Verarbeitungszeit jedes Wafers mit der konfigurierten maximalen Verarbeitungszeit und verhindert das Einbringen, wenn das Maximum überschritten wurde.
• Sie verhindert das Einbringen, wenn der Lebensdauerzähler eines Wafers den Wert 0 hat. Andernfalls erlaubt sie das Einbringen und verringert den die Zähler.

Validierungen für Ausbringen

Die Anwendung überprüft den Wert von "Letzter Datensammlungsstatus für Dummywafer". Sie erlaubt das Ausbringen, wenn der Status gleich "Fehler" ist, legt aber sowohl das Produktions- als auch das Dummylos auf "Anhalten" fest, wodurch das Abmelden verhindert wird. Die Anwendung verschiebt die Dummylos-ID in das Feld "Letztes bestandenes Dummylos", wenn der Status gleich "Bestanden" ist.

Hinweis: Alle Dummywafer, die noch verarbeitet werden, müssen beendet sein, bevor "Ausbringen" abgeschlossen werden kann. Alle Dummywafer müssen ausgebracht sein, bevor ein Produktionswafer ausgebracht werden kann.

Validierungen für Abmelden

Sowohl der Dummy- als auch der Produktionswafer können abgemeldet werden, sofern es keine Validierungsfehler gibt, die dies verhindern. Möglicherweise können Sie das Dummywaferlos, aber nicht das Produktionslos abmelden. Es kann aber auch sein, dass Sie keines der beiden Lose abmelden können. Der spezielle Fehler bestimmt, was abgemeldet werden kann.

Vorgehensweise zum Einbringen eines Dummywaferloses mit einem Produktionslos

Gehen Sie folgendermaßen vor, um ein Dummywaferlos mit einem Produktionslos einzubringen:

1. Wählen Sie das Produktionslos über das Feld Auswahl-ID aus. Die Anwendung zeigt das ausgewählte Los in der Tabelle "Los" an.
2. Navigieren Sie zu Einbringen.
3. Wählen Sie die Ausrüstung aus. Die Anwendung gibt an, ob Dummywafer erforderlich sind oder das Los nicht der Mindestwaferanforderung genügt.
4. Wählen Sie den Dummywafer über das Feld Auswahl-ID aus. Die Anwendung fügt den ausgewählten Dummywafer zur Tabelle "Los" hinzu.
5. Geben Sie alle erforderlichen Informationen für die Dummywafer ein.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Ausbringen eines Dummywaferloses

Gehen Sie folgendermaßen vor, um ein Dummywaferlos auszubringen:

1. Führen Sie den Befehl Ausbringen nur für das Dummywaferlos aus. Die Anwendung zeigt die Registerkarte "Daten" an, wenn für die Dummywafer eine Datensammlung konfiguriert ist.
2. Gehen Sie folgendermaßen vor, wenn die Registerkarte Daten angezeigt wird:
a. Öffnen Sie die Registerkarte Daten.
b. Geben Sie die erforderlichen Daten ein.
c. Klicken Sie auf Abschicken.Die Anwendung zeigt eine Statusnachricht an.
d. Kehren Sie zur Registerkarte Haupt zurück.
3. Klicken Sie auf Abschicken, um das Dummywaferlos auszubringen. Die Anwendung zeigt ein Warnungspopup an, in dem alle Dummywafer aufgelistet werden, deren Verarbeitung fehlgeschlagen ist.
