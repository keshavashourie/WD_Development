Systeminformationen

"Systeminformationen" zeigt Systeminformationen über die Anwendung an.

Felddefinitionen der Seite "Systeminformationen"

Diese Tabelle definiert die Felder auf der Seite "Systeminformationen".

Feld

Definition

Tabelle "Systeminformationen"

Tabelle, in der wichtige Systemvariablen für die aktuelle Installation aufgelistet werden.

Info-Quelle

Anwendung oder Datenbank, aus der die Informationen abgerufen wurden.

Informationsname

Name für die Information.

Info-Wert

Wert der Systeminformation.

Info-Reihenfolge

Numerische Reihenfolge in Bezug auf die Reihenfolge der Info-Quelle.

Tabelle "Active Workspace"

Tabelle, in der alle aktiven Arbeitsbereiche aufgelistet werden, die es in der aktuellen Umgebung gibt.

Code

Code in Bezug auf den aktuellen Arbeitsbereich.

Beschreibung

Beschreibung des Arbeitsbereichscodes.
