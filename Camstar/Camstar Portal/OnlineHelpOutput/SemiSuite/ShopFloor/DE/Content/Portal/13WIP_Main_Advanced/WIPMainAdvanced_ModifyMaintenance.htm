Wartung ändern

Sie können keine Ausrüstung einbringen, für die Wartungsanforderungen ausstehen. Über die Kachel "Wartung ändern" können Sie Anforderungen aufheben und verzögern, die entsprechend konfiguriert wurden.

Fehler, die auftreten können, wenn Sie versuchen, eine Wartung zu verzögern

Die folgenden Fehler können auftreten, wenn Sie versuchen, eine Wartung zu verzögern:

• Maximale Nutzungsanzahl bei Verzögerung überschritten: Dieser Fehler tritt auf, wenn Sie versuchen, eine Wartung zu verzögern und einen Wert in das Feld "Nutzungsanzahl bei Verzögerung" eingeben, der das konfigurierte Maximum überschreitet.
• Maximaler Verzögerungszeitraum überschritten: Dieser Fehler tritt auf, wenn Sie versuchen, eine auf einer Termin- oder Wiederholungsterminanforderung basierende Wartung zu verzögern, für die ein maximaler Verzögerungszeitraum konfiguriert ist und dadurch das Maximum überschritten würde.
• Maximale Durchsatzmenge oder Durchsatzmenge2 überschritten: Dieser Fehler tritt auf, wenn Sie versuchen, eine auf einer Durchsatzanforderung basierende Wartung zu verzögern, für die ein maximaler Durchsatz (Mengte oder Menge2) konfiguriert ist und durch die Verzögerung das Maximum überschritten würde.

Vorgehensweise zum Aufheben einer ausstehenden Wartungsanforderung für eine Ressource

Gehen Sie folgendermaßen vor, um die Wartungsanforderung für eine Ressource während der Verarbeitung eines Loses in "Hauptumlaufbestand - Erweitert" aufzuheben:

1. Klicken Sie auf der Seite "Hauptumlaufbestand - Erweitert" auf Wartung ändern. Das Popup "Wartungsverwaltung" wird angezeigt.
2. Wählen Sie im Abschnitt "Suchkriterien" des Popups die Ressource aus.
3. Klicken Sie auf Suchen. Die Wartungsanforderungen für die Ressource werden in der Tabelle "Suchergebnisse" angezeigt.
4. Wählen Sie die Tabellenzeile mit der Anforderung aus, auf die Sie verzichten möchten.
5. Wählen Sie im Abschnitt "Wartungsdetails" die Option Verzichten im Feld Wartungsaktionstyp aus.
6. Klicken Sie auf Wartung ändern. Die Anwendung verarbeitet die Anforderung und zeigt eine Statusnachricht an.
Hinweis: Die Anwendung zeigt das Popup für elektronische Unterschriften an, wenn die Funktion so konfiguriert wurde, dass eine elektronische Unterschrift erforderlich ist.

Vorgehensweise zum Verzögern einer ausstehenden Wartungsanforderung für eine Ressource

Gehen Sie folgendermaßen vor, um die Wartungsanforderung für eine Ressource während der Verarbeitung eines Loses in "Hauptumlaufbestand - Erweitert" zu verzögern:

1. Klicken Sie auf der Seite "Hauptumlaufbestand - Erweitert" auf Wartung ändern. Das Popup "Wartungsverwaltung" wird angezeigt.
2. Wählen Sie im Abschnitt "Suchkriterien" des Popups die Ressource aus.
3. Klicken Sie auf Suchen. Die Wartungsanforderungen für die Ressource werden in der Tabelle "Suchergebnisse" angezeigt.
4. Wählen Sie die Tabellenzeile mit der Anforderung aus, die Sie verzögern möchten.
5. Wählen Sie im Abschnitt "Wartungsdetails" die Option Verzögern im Feld Wartungsaktionstyp aus.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Wartung ändern. Die Anwendung verarbeitet die Anforderung und zeigt eine Statusnachricht an.
Hinweis: Die Anwendung zeigt das Popup für elektronische Unterschriften an, wenn die Funktion so konfiguriert wurde, dass eine elektronische Unterschrift erforderlich ist.
Wichtig: Der Systemadministrator kann Änderungen an einer Wartungsanforderung vornehmen, die bewirken, dass vorhandene Verzögerungen deaktiviert oder auf die geänderte Anforderung übernommen werden. Weitere Informationen finden Sie unter Opcenter Execution Semiconductor Modeling-Benutzerhandbuch.
