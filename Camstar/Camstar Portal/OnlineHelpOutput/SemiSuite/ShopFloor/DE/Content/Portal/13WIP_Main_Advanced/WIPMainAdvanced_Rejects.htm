Ablehnungen

Im Popup "Ablehnungselemente" auf der Seite "Hauptumlaufbestand - Erweitert" können Sie fehlerhafte Produkte angeben. Die Kachel wird bei der Umlaufbestandsverarbeitung angezeigt, wenn die verwendete Spezifikation mit aktiviertem Flag "Aufzeichnung von Ablehnungen erlauben" konfiguriert wurde.

Ablehnungen werden nicht sofort verarbeitet, sondern in Umlaufbestandsnachverfolgungstabellen gespeichert, um Neuselektion, Korrektur und Verteilung zu ermöglichen. Ablehnungen, die nach dem Einbringen, aber vor dem Ausbringen gesammelt werden, werden "Ablehnung in Bearbeitung" genannt. Diese Ablehnungen werden nach Los und Ausrüstung gespeichert, in der sie verarbeitet werden. Beim Ausbringen werden die Ablehnungen konsolidiert. Nachdem die erforderliche Menge verarbeitet wurde, kann eine Abmelden-Transaktion für das Los durchgeführt werden. Beim Abmelden werden die konsolidierten Ablehnungen in Bearbeitung als Ablehnungen nach Bearbeitung bezeichnet und nur nach Los gespeichert.

Aussehen und Verhalten des Popups zum Aufzeichnen von Ablehnungen für eine Verarbeitung auf Elementebene sind anders als Aussehen und Verhalten des Popups zum Aufzeichnen von Ablehnungen für eine Verarbeitung auf Mengenebene.

Felddefinitionen für "Ablehnungselemente"

Diese Tabelle definiert die Felder im Popup "Ablehnungselemente".

Feld

Definition

Max. Ablehnungsmenge

Die maximal zulässige Ablehnungsmenge nach Los.

Element-ID

Feld, um eine Wafer-ID auszuwählen.

Ablehnungs-/Defektkategorie

Für den Verlust definierte Kategorie (z. B. Ausrüstung, Material).

Defekttyp

Feld, um die Ebene auszuwählen, auf der Ablehnungen für die ausgewählte Element-ID erfolgen. ("Ganz" bedeutet, dass der gesamte Wafer abgelehnt wird. "Position" bedeutet, dass bestimmte Abschnitte auf dem Wafer abgelehnt werden.)

Defektmenge

Die insgesamt abgelehnte Menge für das ausgewählte Los.

Verlustgrund

Grund für die Ablehnung oder Ablehnungen.

Aussondern

Mit diesem Flag wird angegeben, ob der gesamte Wafer abgelehnt und dessen Menge beim Abmelden des Loses aus der Gesamtmenge entfernt werden soll.

Unterprodukt

Feld, um das Produkt auf einem Multiprodukt-Wafer auszuwählen.

Hinweis: Dieses Feld wird angezeigt, wenn das ausgewählte Los über Multiprodukt-Wafer verfügt.

Gesamtes Unterprodukt ablehnen

Kontrollkästchen, um anzugeben, ob der gesamte Unterproduktbereich auf dem Wafer abgelehnt werden soll.

Hinweis: Dieses Feld wird angezeigt, wenn das ausgewählte Los über Multiprodukt-Wafer verfügt.

Schaltfläche "Hinzufügen"

Schaltfläche, um Ablehnungsdaten hinzuzufügen, die im oberen Fensterbereich eingegeben wurden.

Tabelle "Ablehnungen-/Defektedetails"

Tabelle mit einer Liste zusätzlicher Defekte. Die Tabellenfelder können geändert werden.

Element-ID

ID des ausgewählten Wafers im Los.

Defekttyp

Feld, um die Ebene auszuwählen, auf der Ablehnungen für die ausgewählte Element-ID erfolgen. ("Ganz" bedeutet, dass der gesamte Wafer abgelehnt wird. "Position" bedeutet, dass bestimmte Abschnitte auf dem Wafer abgelehnt werden.)

Verlustgrund

Grund für die Ablehnung oder Ablehnungen.

Defektmenge

Die insgesamt abgelehnte Menge für das ausgewählte Los.

Aussondern

Mit diesem Flag wird angegeben, ob der gesamte Wafer abgelehnt und dessen Menge beim Abmelden des Loses aus der Gesamtmenge entfernt werden soll.

Defekt: X-Position

X-Koordinate auf dem Wafer, an der die Ablehnung vorhanden ist.

Hinweis: Dieses Feld wird angezeigt, wenn "Position" als Defekttyp ausgewählt ist.

Defekt: Y-Position

Y-Koordinate auf dem Wafer, an der die Ablehnung vorhanden ist.

Hinweis: Dieses Feld wird angezeigt, wenn "Position" als Defekttyp ausgewählt ist.

Defekt: Z-Position

Z-Koordinate auf einem 3D-Wafer, an der die Ablehnung vorhanden ist.

Hinweis: Dieses Feld wird angezeigt, wenn "Position" als Defekttyp ausgewählt ist.

Ablehnungs-/Defektkategorie

Für den Verlust definierte Kategorie (z. B. Ausrüstung, Material).

Ablehnungs-/Defektursache

Grund für die Ablehnung oder Ablehnungen.

Ablehnungs-/Defektkommentar

Unformatiertes Textfeld, um Kommentare zur Ablehnung einzugeben.

Unterprodukt

Gibt an, ob die abgelehnten Elemente Unterprodukt eines Multiprodukt-Wafers sind.

Gesamtes Unterprodukt ablehnen

Gibt an, ob alle Dies auf dem ausgewählten Multiprodukt-Wafer abgelehnt werden sollen.

Vorgehensweise zum Aufzeichnen von Ablehnungen auf der Elementebene

Gehen Sie folgendermaßen vor, um Ablehnungen auf der Elementebene aufzuzeichnen:

1. Klicken Sie auf die Kachel Ablehnungselemente auf der Seite "Hauptumlaufbestand - Erweitert". Das Popup "Ablehnungselemente" wird angezeigt. Wenn zum ersten Mal Ablehnungen für das Los verarbeitet werden, ist die Element-ID (Wafer-ID) standardmäßig die erste ID im Los.
2. Übernehmen Sie die ausgewählte Element-ID oder wählen Sie eine andere aus.
3. Wählen Sie den Verlustgrund aus.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Gehen Sie folgendermaßen vor, wenn das ausgewählte Los über Multiprodukt-Wafer verfügt und die Ablehnung basierend auf dem Unterprodukt erfolgen soll:
a. Wählen Sie das Unterprodukt aus.
b. Wählen Sie Gesamtes Unterprodukt ablehnen aus, um alle Dies des ausgewählten Unterprodukts abzulehnen. Die Anwendung bestimmt automatisch die abgelehnte Menge.
6. Klicken Sie auf Hinzufügen, wenn Sie fertig sind. Die Details werden in der Tabelle angezeigt.
7. Wiederholen Sie die oben aufgeführten Schritte ggf. für die verbleibenden Loselemente.
8. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Statusnachricht an.

Vorgehensweise zum Aufzeichnen von Ablehnungen auf Mengenebene

Gehen Sie folgendermaßen vor, um Ablehnungen auf der Mengenebene aufzuzeichnen:

1. Wählen Sie die Kachel Ablehnungslose auf der Seite "Hauptumlaufbestand - Erweitert" aus. Das Popup "Losablehnungen" zeigt eine Liste der Verlustgründe und Felder für die Verarbeitung der Verluste für den jeweiligen Grund an.
2. Führen Sie für jeden Verlustgrund, der für mindestens eine Ablehnung gilt, folgende Aktionen durch:
a. Geben Sie die Ablehnungsmenge ein (die Anzahl der Einheiten, die für den ausgewählten Verlustgrund abgelehnt wird). Das Feld "Ablehnungsmenge" unter der Tabelle wird um die eingegebene Zahl erhöht.
b. Geben Sie ggf. eine Zahl für Nicht ausgesonderte Einheiten ein (die Anzahl der Ablehnungsmenge, die nicht ausgesondert wird). Das Feld "Nicht ausgesonderte Einheiten" unter der Tabelle wird um die eingegebene Zahl erhöht.
c. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
3. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
