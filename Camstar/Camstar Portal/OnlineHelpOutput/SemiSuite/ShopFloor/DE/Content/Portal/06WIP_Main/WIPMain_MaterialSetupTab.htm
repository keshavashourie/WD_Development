Materialieneinrichtung

Die Registerkarte "Materialieneinrichtung" bietet folgende Möglichkeiten:

• Anzeigen der Materialanforderungen der Stückliste für das ausgewählte Los oder die ausgewählte Ausrüstung.
• Laden von Materiallosen in einen Ausrüstungsgegenstand.
Hinweis: Die Felder für die Materialeinrichtung werden als Popup angezeigt, wenn sie auf der Seite "Ressourcenlayoutansicht" aufgerufen werden. Weitere Informationen finden Sie unter "Ressourcenlayoutansicht".

Felddefinitionen der Registerkarte "Materialieneinrichtung"

Diese Tabelle definiert die Felder auf der Registerkarte "Materialieneinrichtung".

Feld

Definition

Tabelle "Erforderliches Material"

Tabelle mit einer Liste der Materialprodukte, die für das ausgewählte Los und die Prozessspezifikation erforderlich sind.

Materiallos

Name des Loses, das verbraucht werden soll.

Materialteil

Produkt des Materials, das verbraucht wird.

Material autom. zurückgeben

Wählen Sie die Option aus, um anzugeben, dass die Materialrestmenge automatisch zurückgegeben wird. Das Material wird im letzten Lagerbestandsentnahmeschritt zurückgegeben.

Lagerbestand autom. kombinieren

Wählen Sie diese Option aus, wenn das zurückgegebene Materiallos automatisch mit einem vorhandenen Materiallos im Lagerbestand vereinigt werden soll, das den gleichen Containernamen aufweist.

Tabelle "Materialdetails"

Tabelle mit einer Liste der derzeit geladenen Materialien für die Ressource.

Die folgende Tabelle definiert die Schaltflächen auf der Seite "Materialieneinrichtung".

Schaltfläche

Funktion der Schaltfläche . . .

Zurücksetzen

Löscht alle Daten auf der Seite.

Abschicken

Speichert die Daten auf der Seite.

Vorgehensweise zum Einrichten von Materialien

Gehen Sie folgendermaßen vor, um Materialien einzurichten:

1. Geben Sie die Los- oder Batch-ID in das Feld Materiallos ein.
2. Klicken Sie auf das Feld Materialteil, um es zu aktivieren.
3. Geben Sie das Materialteil aus dem Feld Materialteil ein.
4. Klicken Sie auf Hinzufügen, wenn die Informationen nicht automatisch zur Tabelle Materialdetails hinzugefügt wurden.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
