Teilewartung

Die Seite "Teilewartung" ermöglicht es Ihnen, nach Ressourcenteilen zu suchen und diese zu warten. Außerdem können Sie über diese Seite ein Materialteil auswählen und die Seite "Teileerstellung" öffnen, um ein neues Teil zu erstellen, für das das ausgewählte Materialteil verwendet wird.

Optional

Optional

Teiletyp

Gibt an, wie Materialteile in den Lagerbestand aufgenommen und verfolgt werden sollen. Hierfür gibt es drei Typen:

• Serialisiert: Erfordert, dass für jede Sendung ein neues Los erstellt wird.
• Großmenge: Erfordert ein neues Los, wenn das Materialteil erstmalig versandt wird. Nachfolgende Sendungen aus demselben Hauptlos können in den Lagerbestand aufgenommen werden, indem die Menge des Loses erhöht wird, das anfänglich erstellt wurde.
• Nicht serialisiert: Es wird kein Los erstellt. Grundsätzlich genügt es, für Nachverfolgbarkeitszwecke die Losnummer zu speichern.

Optional

Physischer Ort

Fabrikstandort. Dieser kann die gesamte Fabrik oder ein Bereich innerhalb der Fabrik bis hinunter auf die Ebene eines einzelnen Gefäßes in einem Lagerplatz der Fabrik sein.

Optional

Physische Position

Definiert einen Bereich eines physischen Orts, z. B. einen Wartungsplatz.

Vorgehensweise zum Erstellen eines Teils

Gehen Sie folgendermaßen vor, um ein Teil zu erstellen:

1. Rufen Sie die Seite "Teilewartung" auf.
2. Wählen Sie Suchwerte im Suchkriterienbereich aus.
3. Klicken Sie auf Suchen. Die Anwendung füllt die Tabelle "Suchergebnisse".
4. Wählen Sie in der Tabelle "Suchergebnisse" die Zeile des Teils aus. Die Anwendung aktiviert weitere Schaltflächen unter "Fertigungsaktionen".
5. Klicken Sie auf Teileerstellung. Das Popup "Teileerstellung" wird angezeigt, wobei die Felder "Materialteil" und "Teilemenge" entsprechend Ihrer Auswahl ausgefüllt sind.
6. Geben Sie einen Namen in das Feld Teilename ein.
7. Ändern Sie, falls erforderlich, das Materialteil, das aus Ihrer Auswahl auf der Eltern-Seite übernommen wurde.
8. Ändern Sie, falls erforderlich, die Teilemenge, die aus Ihrer Auswahl auf der Eltern-Seite übernommen wurde.
9. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
10. Klicken Sie auf Teileerstellung. Das Popup wird geschlossen und die Anwendung zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Festlegen des Status eines Teils

Gehen Sie folgendermaßen vor, um den Status eines Teils festzulegen:

1. Rufen Sie die Seite "Teilewartung" auf.
2. Wählen Sie in der Tabelle "Suchergebnisse" die Zeile des Teils aus. Die Anwendung aktiviert weitere Schaltflächen unter "Fertigungsaktionen".
3. Klicken Sie auf Teilestatus festlegen. Das Popup "Teilestatus festlegen" wird angezeigt.
4. Wählen Sie im Feld Status einen Status aus.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Einrichten eines Teils

Gehen Sie folgendermaßen vor, um ein Teil einzurichten:

1. Rufen Sie die Seite "Teilewartung" auf.
2. Wählen Sie Suchwerte im Suchkriterienbereich aus.
3. Klicken Sie auf Suchen. Die Anwendung füllt die Tabelle "Suchergebnisse".
4. Wählen Sie in der Tabelle "Suchergebnisse" die Zeile des Teils aus. Die Anwendung aktiviert weitere Schaltflächen unter "Fertigungsaktionen".
5. Klicken Sie auf Teil einrichten. Das Popup "Teil einrichten" wird angezeigt.
6. Wählen Sie ggf. ein Materialteil im Feld Materialteil aus.
7. Wählen Sie ggf. eine Einrichtung im Feld Einrichtung aus.
8. Geben Sie im Feld Teilemenge eine Teilemenge ein.
9. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
10. Klicken Sie auf Teil einrichten. Das Popup wird geschlossen und die Anwendung zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Festlegen eines Teils als Ausschuss

Gehen Sie folgendermaßen vor, um ein Teil als Ausschuss festzulegen:

1. Rufen Sie die Seite "Teilewartung" auf.
2. Wählen Sie Suchwerte im Suchkriterienbereich aus.
3. Klicken Sie auf Suchen. Die Anwendung füllt die Tabelle "Suchergebnisse".
4. Wählen Sie in der Tabelle "Suchergebnisse" die Zeile des Teils aus. Die Anwendung aktiviert weitere Schaltflächen unter "Fertigungsaktionen".
5. Klicken Sie auf Teileausschuss. Das Popup "Teileausschuss" wird angezeigt.
6. Geben Sie die Menge, die als Ausschuss festgelegt werden soll, in das Feld Teilemenge ein.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Teileausschuss.Das Popup wird geschlossen und die Anwendung zeigt eine Erfolgsmeldung an.
