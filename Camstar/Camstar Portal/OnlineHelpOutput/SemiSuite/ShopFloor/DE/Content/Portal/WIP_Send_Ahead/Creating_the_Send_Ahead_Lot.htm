Erstellen des Voraussendeloses

"Wafer-Voraussendeverarbeitung" und "Los-Voraussendeverarbeitung" sind Transaktionen zum Erstellen von Voraussendelosen. Verwenden Sie die Seite "Wafer-Voraussendeverarbeitung", um ein Voraussendelos zu erstellen, indem Sie mindestens einen Wafer aufteilen. Verwenden Sie die Seite "Los-Voraussendeverarbeitung", um ein Voraussendelos zu erstellen, indem Sie eine Menge von mindestens einem Los abtrennen.

Beim Erstellen eines Voraussendeloses aus einem mehrstufigen Startprozesslos

Zum Erstellen eines Voraussendeloses, für das ein mit dem mehrstufigen Startprozess erzeugtes Los genutzt wird,, müssen Sie das gewünschte Kindlos vom Elternlos abtrennen, um das Voraussendelos zu erzeugen. Es kann nur ein Kindlos zum Erstellen des Voraussendeloses verwendet werden und es muss mindestens ein Kindlos vorhanden sein. Wenn eine mehrstufige Eltern-Kind-Beziehung erstellt wurde, ist nur das Kindlos der ersten Ebene des Elternloses zur Abtrennung auswählbar, um das Voraussendelos zu bilden. Das Elternlos kann nur über ein aktives Voraussendelos verfügen.

Hinweis: Sie können eine weitere Spezifikation für die zukünftige Vereinigung angeben, damit das Voraussendelos erneut mit dem Elternlos vereinigt werden kann.

Vorgehensweise zum Erstellen eines Wafer-Voraussendeloses (elementbasiertes Voraussendelos)

Gehen Sie folgendermaßen vor, um über die Seite "Wafer-Voraussendeverarbeitung" ein Voraussendelos zu erstellen.

1. Öffnen Sie die Seite "Wafer-Voraussendeverarbeitung".
2. Geben Sie die ID des Hauptloses in das Feld Auswahl-ID ein. Dies ist ein Los, aus dem Sie mindestens einen Wafer abtrennen, um das Voraussendelos zu erstellen. Das Los wird in der Tabelle "Lose" angezeigt.
3. Wiederholen Sie Schritt 2 für alle weiteren Hauptlose.
4. Wählen Sie die Hauptlos-ID aus.
5. Wählen Sie das Von Los aus, um die Tabelle "Quellelement(e)" zu füllen. Die Elemente für das ausgewählte Los werden in der Tabelle "Quellelement(e)" angezeigt.
6. Wählen Sie für jedes Element, das Sie in das neue Voraussendelos abtrennen möchten, das Element in der Tabelle "Quellelement(e)" aus und klicken Sie auf Hinzufügen. Das jeweils ausgewählte Element wird in der Tabelle "Elemente" angezeigt.
7. Wiederholen Sie die Schritte 5 bis 6 für alle weiteren Hauptlose.
8. Geben Sie abhängig von den Anforderungen Ihres Unternehmens optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern
9. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
Hinweis: Die Statusmeldung enthält den von der Anwendung generierten Namen des Voraussendeloses, wenn Sie keinen Namen eingegeben haben.

Vorgehensweise zum Erstellen eines Voraussendeloses (mengenbasiert)

Gehen Sie folgendermaßen vor, um über die Seite "Los-Voraussendeverarbeitung" ein Voraussendelos zu erstellen.

1. Öffnen Sie die Seite "Los-Voraussendeverarbeitung)".
2. Geben Sie die ID des Hauptloses in das Feld Auswahl-ID ein. Dies ist ein Los, aus dem Sie das Voraussendelos erstellen. Das Los wird im Popup "Auswahl" angezeigt.
3. Wiederholen Sie Schritt 2 für alle weiteren Hauptlose.
4. Wählen Sie die Hauptlos-ID aus – sie gibt das Los an, mit dem die Tabelle die "Quelllos(e)" gefüllt wird. Das ausgewählte Los wird in der Tabelle "Quelllos(e)" angezeigt.
5. Wählen Sie das Von Los aus.
6. Geben Sie die Verarbeitete Menge in die ausgewählte Zeile ein.
7. Wiederholen Sie die Schritte 4 bis 6 für alle weiteren Hauptlose.
8. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
9. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
Hinweis: Die Statusmeldung enthält den von der Anwendung generierten Namen des Voraussendeloses, wenn Sie keinen Namen eingegeben haben.

Vorgehensweise zum Erstellen eines mehrstufigen Voraussendeloses
