Startseite

Die Startseite bietet eine zentrale Anzeige von Echtzeit-Fertigungsaktivitäten und Zusammenfassungen zur Anzeige des gesamten Fertigungsprozesses. Die Seite bietet eine interaktive Erfahrung mit Sichtbarkeit und einer QuickInfo-Navigation. Informationen werden vereinfacht mit Charts und Tastenkombinationen aufgerufen und implementierte Änderungen in der Fertigung werden dynamisch angezeigt, um genaue zeitbasierte Informationen zu bieten.

Um zu gewährleisten, dass die Startseite als Standardanzeige mit Ihren bevorzugten Datenkonfigurationen angezeigt wird, empfiehlt es sich, "Arbeitsbereich", "Mitarbeiter" und "Einstellungen der Linienzuordnung" einzurichten. Die Auswahl der entsprechenden Werte hilft dabei, die auf der Startseite angezeigten Daten einzugrenzen. Die folgende Erklärung beschreibt im Allgemeinen, wie sich die Auswahl auf die angezeigten Daten auswirkt:

• Die Auswahl des Felds "Ressourcengruppe" auf der Modellierungsseite "Arbeitsbereich" hilft, die im Abschnitt "Erledigungsliste" angezeigten Daten zu identifizieren.
• Durch die Konfiguration der Einstellungen der Linienzuordnung können Sie die Informationen angeben, die in den Abschnitten "Erledigungsliste" und "Ausrüstungsliste" angezeigt werden. Erklärungen dazu, wie die Anwendung Daten basierend auf der Einstellung der Linienzuordnung anzeigt, finden Sie im Abschnitt "Erledigungsliste " und "Ausrüstungsstatus".
Vorgehensweise zum Einrichten des Felds "Ressourcengruppe" im Arbeitsbereich

Sie müssen eine "Ressourcengruppe" auf der Modellierungsseite "Arbeitsbereich" auswählen. Gehen Sie folgendermaßen vor, um den Arbeitsbereich einzurichten:

1. Melden Sie sich bei Opcenter Execution Semiconductor an.
2. Öffnen Sie die Modellierungsseite Arbeitsbereich, indem Sie die Schaltfläche Modellierung und dann Haupt auswählen. Die Seite "Arbeitsbereich" wird innerhalb der Seite "Modellierung" angezeigt.
3. Geben Sie für die neue Instanz den Namen in das Feld Arbeitsbereich ein.
4. Wählen Sie im Feld Ressourcengruppe eine Ressourcengruppe aus. Mit der Auswahl des Felds "Ressourcengruppe" auf dieser Seite werden Daten identifiziert, die im Abschnitt "Erledigungsliste" der Startseite angezeigt werden.
5. Klicken Sie auf Speichern. Die Anwendung speichert das Modellierungsobjekt und zeigt eine Erfolgsmeldung an.
Vorgehensweise zum Einrichten eines Mitarbeiters

Sie müssen die Felder "Arbeitsbereich", "Operation" und "Startseite" auf der Modellierungsseite "Mitarbeiter" auswählen. Führen Sie die folgenden Schritte aus, um ein Modellierungsobjekt vom Typ "Mitarbeiter" einzurichten:

1. Melden Sie sich bei Opcenter Execution Semiconductor an.
2. Öffnen Sie die Modellierungsseite Mitarbeiter, indem Sie die Schaltfläche Modellierung und dann Haupt auswählen. Die Seite "Mitarbeiter" wird innerhalb der Seite "Modellierung" angezeigt.
3. Geben Sie für die neue Instanz den Namen in das Feld Mitarbeiter ein.
4. Wählen Sie im Abschnitt "Details" den zuvor konfigurierten Arbeitsbereich aus. Mit der Auswahl von "Arbeitsbereich" werden Daten identifiziert, die im Abschnitt "Erledigungsliste" der Startseite angezeigt werden.
5. Wählen Sie im selben Abschnitt "Details" das Feld Operation aus. Mit der Auswahl des Felds "Operation" werden Daten identifiziert, die im Abschnitt "Ausrüstungsstatus" der Startseite angezeigt werden.
6. Falls noch nicht konfiguriert, wählen Sie im Portalabschnitt im Feld Startseite die Option "scsLandingPage_vp" aus.
7. Geben Sie abhängig von den jeweiligen Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Speichern. Die Anwendung zeigt eine Erfolgsmeldung an.
Vorgehensweise zum Einrichten der Linienzuordnung

Die Startseite kann so konfiguriert werden, dass bestimmte Ressourcen, Spez., Operationen oder Arbeitsbereiche basierend auf der Einstellung der Linienzuordnung angezeigt werden. Die Einstellungen der Linienzuordnung helfen dabei, die Gesamtzahl der Objekte zu begrenzen, die auf der Startseite angezeigt werden. Andernfalls werden möglicherweise Hunderte von Objekten angezeigt.

Gehen Sie folgendermaßen vor, um Ihre Einstellung der Linienzuordnung zu ändern oder zu aktualisieren:

1. Melden Sie sich bei Opcenter Execution Semiconductor an.
2. Klicken Sie unten links in der Menüleiste auf die Schaltfläche Einstellungen. Klicken Sie anschließend auf den Link Linienzuordnung setzen. Das Popup "Linienzuordnung setzen" wird angezeigt.
3. Wählen Sie Werte aus einem oder mehreren der folgenden Felder:
• Arbeitsbereich. Der Dropdown-Wert "Arbeitsbereich" wird nach Ihrer Benutzer-ID und Fabrik gefiltert.
• Operation. Der Dropdown-Wert "Operation" wird nach Arbeitsbereich gefiltert.
• Spezifikation. Der Dropdown-Wert "Spez." wird nach Operation gefiltert.
• Ressource/Arbeitszelle.Der Dropdown-Wert "Ressource / Arbeitszelle" wird nach Spez. und Arbeitsbereich gefiltert.
• Arbeitsplatz. Der Dropdown-Wert "Arbeitsplatz" wird nach Ressource / Arbeitszelle, Spez. und Arbeitsbereich gefiltert.
4. Optional können Sie das Kontrollkästchen Nicht anzeigen, wenn ich mich anmelde auswählen. Wenn ausgewählt, zeigt die Anwendung die Seite "Linienzuordnung setzen" nicht an, wenn Sie sich anmelden. Wenn Sie das Häkchen aus dem Ankreuzfeld entfernen, zeigt die Anwendung die Seite "Linienzuordnung setzen" bei der Anmeldung an, aber nur, wenn Ihr Systemadministrator die Seite so eingestellt hat, dass Sie bei der Anmeldung für Sie sichtbar ist.
5. Klicken Sie auf Linienzuordnung setzen. Die Anwendung speichert Ihre Änderungen, schließt das Popup und zeigt ihre aktualisierten Zuordnungen in der globalen Kopfzeile an. Wenn Sie oben links in der Menüleiste auf die Schaltfläche "Startseite" klicken, wird die Startseite mit der konfigurierten Einstellung der Linienzuordnung angezeigt.

Weitere Informationen zur Linienzuordnung finden Sie im Opcenter Execution Core Shop Floor-Benutzerhandbuch.

Layout der Startseite

Die Startseite beinhaltet die folgenden Bereiche:

1. Der Bereich oben links auf der Seite beinhaltet Aktivität und Status der Erledigungsliste .
2. Der Bereich oben rechts auf der Seite beinhaltet Details zum Ausrüstungsstatus.
3. Der Bereich unten links auf der Seite beinhaltet die Leiste Ablehnungen für vorherige 3 Tage.
4. Die untere Mitte der Seite enthält die Informationen zum WIP-Chart.
5. Der Bereich unten rechts auf der Seite beinhaltet die Ausrüstungshistorie.

In den folgenden Themen werden diese Bereiche beschrieben.

Erledigungsliste

Die Karte "Erledigungsliste" zeigt die 9 wichtigsten Lose an, die sich in Bearbeitungszuständen befinden (entweder Anmelden, Einbringen, Ausbringen oder Abmelden).

Standardmäßig zeigt dieser Abschnitt das Los basierend auf der Einstellung der Linienzuordnung an. Wenn z. B. in der Einstellung der Linienzuordnung die Option "Arbeitsbereich-MNT" ausgewählt ist, werden in den Erledigungslistenkacheln nur die obersten 9 Lose angezeigt, die MNT zugewiesen sind. Im Folgenden wird erläutert, wie die Anwendung Daten basierend auf der Einstellung der Linienzuordnung anzeigt:

• Ressource: Wenn Ressource in der Linienzuordnung festgelegt ist, zeigt die Erledigungsliste Lose an, die für diese Ressource ausgeführt werden können.  
• Spez.: Wenn Spez. in der Linienzuordnung festgelegt ist, zeigt die Erledigungsliste Lose innerhalb der aktuellen Spez. an.
• Operation: Wenn Operation in der Linienzuordnung festgelegt ist, zeigt die Erledigungsliste Lose an, in denen die aktuelle WIP-Spez. mit dieser Operation verknüpft ist.
• Arbeitsbereich: Wenn Arbeitsbereich in der Linienzuordnung festgelegt ist, zeigt die Erledigungsliste Lose an, in denen die aktuelle Operation mit dem ausgewählten Arbeitsbereich verknüpft ist.

Um nach Losen zu suchen, geben Sie einfach den Losnamen in das Feld "Losfilter" ein. Darüber hinaus können Lose basierend auf ihrem Verarbeitungsstatus (Anmelden, Einbringen, Ausbringen oder Abmelden) weiter gefiltert werden, indem sie die relevanten Filtersymbole auswählen.

Jede Kachel zeigt Informationen für die Erledigungslose an. Die Informationen umfassen:

• Name
• Menge (Menge des Dies im Los)
• Menge 2 (Menge der Wafer im Los)
• Produkt
• Aktueller WIP-Schritt
• Symbol "Prozesstyp" und
• Los Anhaltestatus

Kacheln, die rot hervorgehoben sind, zeigen an, dass das Los angehalten ist.

Ausrüstungsstatus

Im Abschnitt "Ausrüstungsstatus" werden Kacheln mit Ausrüstungsinformationen angezeigt, die die Beschreibung der Ausrüstung, den Fertigungsstatus und die Anzahl der WIP-Lose enthalten, die der Ausrüstung zugewiesen sind. Die In diesem Abschnitt angezeigte Ausrüstungsliste kann im Modellierungsobjekt "Arbeitsbereich" festgelegt werden, indem die Dropdown-Liste "Ressourcengruppe" gefiltert wird. Sie können die Ressource / den Arbeitsbereich anhand unserer Anforderung weiter filtern, indem Sie die in den Einstellungen der Linienzuordnung verfügbare Option verwenden.

Wenn Sie zum ersten Mal bei der Startseite angemeldet sind, werden im Abschnitt "Ausrüstungsstatus" Kriterien basierend auf der Einstellung der Linienzuordnung angezeigt. Im Folgenden wird erläutert, wie die Anwendung Daten basierend auf der Einstellung der Linienzuordnung anzeigt:

• Ressource: Wenn Ressource in der Einstellung der Linienzuordnung festgelegt ist, zeigt "Ausrüstungsstatus" die Liste der ausgewählten Ressource an.
• Spez.: Wenn Spez. in der Einstellung der Linienzuordnung festgelegt ist, zeigt "Ausrüstungsstatus" die Ausrüstung innerhalb der ausgewählten Spezifikation an.
• Operation: Wenn Operation in der Linienzuordnung festgelegt ist, zeigt "Ausrüstungsstatus" die Ausrüstung an, die derzeit mit Operation > WIP-Spez. > Ausrüstungsgruppe verknüpft ist.
• Arbeitsbereich: Wenn Arbeitsbereich in der Linienzuordnung festgelegt ist, löst der Abschnitt die Ressourcengruppe auf, die mit dem ausgewählten Arbeitsbereich verknüpft ist.

Um nach Ausrüstung zu suchen, geben Sie einfach den Ausrüstungsnamen in das Feld "Ausrüstungsfilter" ein. Darüber hinaus können Ausrüstungen basierend auf der Verfügbarkeit weiter gefiltert werden, indem Sie das Symbol des Verfügbarkeitsfilters auswählen.

Die Kacheln zeigen die obersten 6 Ausrüstungen basierend auf den Einstellungen der Linienzuordnung oder gefilterten Kriterien an und werden basierend auf der höchsten Priorität von oben links nach rechts basierend auf der ausgewählten Loskachel sortiert.

Wenn Sie auf eine Kachel "Ausrüstungsstatus" klicken, können Sie das PM-Schiebereglerfenster in der rechten Befehlsleiste ausfüllen. Durch Ausfüllen des PM-Schiebereglerfensters wird automatisch der Abschnitt "Ausrüstungsstatus" unten rechts auf der Seite gefüllt. Dieses Feld ist nur verfügbar, wenn "Industry Solutions" installiert ist.

Ablehnungen für vorherige 3 Tage

Das Balken-Chart "Ablehnungen für vorherige 3 Tage" veranschaulicht die Menge der abgelehnten Lose (Y-Achse) mit ihren jeweiligen Verlustgründen (X-Achse) für die letzten 3 Tage. Das Balken-Chart wird basierend auf dem Arbeitsbereich oder der Operation ausgefüllt, der/die in der Einstellung der Linienzuordnung festgelegt ist. Die in diesem Chart angezeigten Daten werden von der Seite "Losablehnung" abgerufen.

Weitere Informationen finden Sie unter "Anzeigedefinitionen der Startseite".

WIP-Chart

Das WIP-Balken-Chart zeigt den Namen des WIP-Schritts (X-Achse) und die Menge der Lose (Y-Achse) im aktuellen Verarbeitungszustand an. Die in diesem Chart angezeigten Daten basieren auf der Einrichtung von "Ressource" und "Operation" in der Einstellung der Linienzuordnung.

Das Chart lädt dynamisch basierend auf der Anzahl der Lose an den einzelnen Schritten. Klicken Sie auf die Schaltfläche "Aktualisieren", um die neuesten Informationen abzurufen. Weitere Informationen finden Sie unter "Anzeigedefinitionen der Startseite".

Ausrüstungshistorie

Im Abschnitt "Ausrüstungshistorie" werden Charts detaillierter OEE-Metriken basierend auf der ausgewählten Ressource in der Einstellung der Linienzuordnung angezeigt. Die Gesamtanlageneffektivität (OEE) gibt die tatsächliche produktive Zeit einer Ausrüstung relativ zu deren tatsächlicher Kapazität an. Diese Funktion hilft jedem Systemadministrator, basierend auf vier Hauptmatrizen wie Verfügbarkeit, Leistung, Qualität und OEE zu konfigurieren und zu bewerten, wie effektiv eine Fertigungsressource ausgeführt wird.

Hinweis: Die Funktionalität des Bereichs "Ausrüstungshistorie" ist nur verfügbar, wenn der Arbeitsbereich von Industry Solutions installiert ist. Weitere Informationen finden Sie im Opcenter Execution Core Industry Solutions-Benutzerhandbuch.

Verfügbarkeit

Gibt die Verfügbarkeitshistorie der Ausrüstung an. Verfügbar wird basierend auf Daten von OEEResourceDetailsByShift und der Tabelle "Kalenderschicht" im Modellierungsobjekt "Produktionskalender" berechnet. Die Verfügbarkeit einer Ressource wird mit der Formel Verfügbarkeit = Betriebszeit / Geplante Produktionszeit berechnet.

Hinweis: Dieses Feld ist nur verfügbar, wenn der Industry Solutions-Arbeitsbereich installiert ist. Weitere Informationen finden Sie im Opcenter Execution Core Industry Solutions-Benutzerhandbuch.

Optional

Leistung

Gibt die Leistung der Ressource an. Die Leistung einer Ressource wird mit der Formel Leistung = (Ideale Zykluszeit * Gesamtmenge) / (Betriebszeit) berechnet.

Hinweis: Dieses Feld ist nur verfügbar, wenn der Industry Solutions-Arbeitsbereich installiert ist. Weitere Informationen finden Sie im Opcenter Execution Core Industry Solutions-Benutzerhandbuch.

Nur Anzeige

Qualität

Gibt die Qualität der Ressource an. Die Qualität einer Ressource wird mit der Formel Qualität = Gutmenge / Gesamtmenge berechnet, wobei Folgendes gilt:

• Gutmenge ist die Summe der Werte "Gutmenge" aus der OEEThruputDetails-Tabelle für die Kombination aus Kalenderschicht, Kalenderdatum und Ressource.
• Gesamtmenge ist die Summe der Werte "Gesamtmenge" aus der OEEThruputDetails-Tabelle für die Kombination aus Kalenderschicht, Kalenderdatum und Ressource.

Hinweis: Dieses Feld ist nur verfügbar, wenn der Industry Solutions-Arbeitsbereich installiert ist. Weitere Informationen finden Sie im Opcenter Execution Core Industry Solutions-Benutzerhandbuch.

Nur Anzeige

OEE

Gibt die Gesamtanlageneffektivität der Ausrüstung an, die die produktive Zeit für eine Ausrüstung relativ zu ihrer tatsächlichen Kapazität darstellt. Die Formel zur Berechnung der Gesamtanlageneffektivität entspricht dem Produkt der anderen Elemente:

• GAE = Verfügbarkeit * Leistung * Qualität

Hinweis: Dieses Feld ist nur verfügbar, wenn der Industry Solutions-Arbeitsbereich installiert ist. Weitere Informationen finden Sie im Opcenter Execution Core Industry Solutions-Benutzerhandbuch.
