Einzelwaferverfolgung (Element)

Die Einzelwaferverfolgung (Element) ermöglicht es Ihnen, einen einzelnen Wafer (ein einzelnes Element) als mengenbasiertes Los zu verarbeiten und zu verfolgen. Diese Methodik erfordert nicht die Verwendung von "Mehrstufiger Start". Sie nutzt die vorhandene Funktionalität von Opcenter Execution Core und Opcenter Execution Semiconductor.

Hinweis: Einzelwaferverfolgung (Element) wurde um die folgenden Funktionen erweitert: Behälter-Operationen (HPE), Arbeitsauftragserledigung (HPE) und Containerabschluss (HPE).

Vorgehensweise zur Nutzung einer Einzelwaferverfolgung (Element)

Gehen Sie folgendermaßen vor, um eine Einzelwaferverfolgung (Element) zu starten:

1. Öffnen Sie die Seite Los starten im bestehenden Opcenter Execution Semiconductor. Starten Sie einzelne Lose mit einer "Basismenge" von 1 oder mehr. Optional können Sie den Wert "Menge2" auf 1 setzen, um einen einzelnen individuellen Wafer (Element) anzuzeigen, je nachdem, wie Sie den Auslöser für die Ausrüstungswartung konfigurieren. Da es sich bei jedem Wafer (Element) um ein einzelnes Los handelt, ist es nicht erforderlich, die Elementtabelle zu füllen.
Hinweis: Um die Vorteile einer Eltern-Kind-Beziehung nutzen zu können, ist es erforderlich, ein Elternlos mit einer Menge von Null (0) zu erstellen. Dies ist nur möglich, wenn die PN (Teilenummer) mit "Nullmenge erlauben" konfiguriert ist.
Hinweis: Das Starten eines Loses mit Menge2=0 und Menge=1 gilt nur für Nicht-Wafer-Objekttypen.
2. Planen sie die Eltern- und/oder Kindlose für den Umlaufbestand und geben Sie sie frei. Jetzt können sie einzeln über "Hauptumlaufbestand - Erweitert" als normale Container verarbeitet werden.
3. Gewährleisten Sie, dass alle Umlaufbestandsspezifikationen innerhalb des definierten Arbeitsplans mit dem Kontrollkästchen Ist Elementverarbeitung als deaktiviert konfiguriert sind. Bestätigen Sie außerdem, dass das Kontrollkästchen Einbringmenge erforderlich auch deaktiviert ist.
4. Wenn das Los in einer Eltern-Kind-Konfiguration verarbeitet werden soll, verwenden Sie die Opcenter Execution Core-Seite Verbinden, um die erforderliche Hierarchiebeziehung zu erstellen. Diese Seite enthält weniger Einschränkungen als das, was für den Prozess "Umlaufbestand zuordnen" konzipiert wurde.

Sobald die Zuordnung abgeschlossen ist, wird das Elternlos zum nachverfolgbaren Los in "Hauptumlaufbestand - Erweitert". Alle Aktionen werden für das Elternlos erstellt und ausgeführt. Bei Bedarf können Sie die Opcenter Execution Core-Seite Abtrennen verwenden, um die aktuelle Eltern-Kind-Beziehung zu entfernen.

Beachten Sie, dass Opcenter Execution Semiconductor auch eine Konfiguration für die Spezifikationen und Prozessspezifikationen bereitgestellt hat, mit denen Sie den Benutzer benachrichtigen können, wenn "Manuell verknüpfen" oder "Manuell abtrennen" durchgeführt werden muss. Darüber hinaus kann sie bei Bedarf für "Autom. abtrennen" konfiguriert werden. Diese Funktionen können bei "Anmelden", "Abmelden" und "Nacharbeit" ausgelöst werden. In Release 8.6 wurden "Einbringen" und "Ausbringen" deaktiviert.
