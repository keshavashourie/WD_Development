Jobfortschritt (Abschließen der Stufen)

Die Transaktion "Jobfortschritt" wird für einen Job verfügbar, nachdem der Techniker den Job bestätigt und angestempelt hat. Diese Transaktion zeigt das Popup "Jobfortschritt" für die Stufe an, die aktuell abgeschlossen werden muss.

Felddefinitionen des Popups "Jobfortschritt"

Diese Tabelle definiert die Felder des Popups "Jobfortschritt".

Feld

Definition

Typ

Ressource

Ausrüstung, Werkzeug, Maske oder ein anderes Nicht-Materialelement, das im Fertigungsprozess verwendet wird. In diesem Zusammenhang ist dies der eindeutige Name der Ressource, für die der Job erstellt wurde.

Nur Anzeige

Jobauftrag

ID des Jobauftrags, der dem Job zugeordnet ist.

Nur Anzeige

Jobmodell

Jobmodell, auf dem der Job basiert. Das Jobmodell gibt die Schritte an, die bei einer Reparatur oder Wartung der Ressource ausgeführt werden müssen.

Nur Anzeige

Jobtyp

Gibt den Typ der Arbeit an, die für die Ressource ausgeführt werden muss, z. B. "Normal", "Vorbeugende Wartung" und "Reparatur".

Nur Anzeige

Einfacher Modus

Im einfachen Modus ist die Transaktion "Jobfortschritt" der erste konfigurierte Schritt. Wenn dieser Schritt abgeschlossen ist, wechselt die Transaktion zum letzten konfigurierten Schritt. Das Kontrollkästchen "Einfacher Modus" kann auf den Seiten "Jobmodell" und "Job erstellen" aktualisiert werden.

Nur Anzeige

Phase

Jobschritt. In diesem Zusammenhang ist dies der aktuelle Schritt.

Nur Anzeige

Entwicklung der Umformstufen

Sequenzielle Reihenfolge der Stufe (Phase).

Nur Anzeige

Zu Stufe

Listet alle Schritte auf, zu denen der Techniker vom aktuellen Schritt gelangen kann. Diese "Gelangen zu"-Schritte müssen im Jobmodell konfiguriert sein, damit sie in diesem Listenfeld angezeigt werden.

Optional

Sequenzielle Reihenfolge der ausgewählten "Zu Stufe". Wird automatisch gefüllt, wenn der Benutzer "Zu Stufe" auswählt.

Symptomcode

Ursachencode

Feld zum Auswählen eines Codes, der die Ursache für das Problem kennzeichnet, das es für die Ressource gibt.

Feld zum Auswählen eines Codes, der die Reparatur kennzeichnet, die für die Ressource ausgeführt wird.

Optional

Vorgehensweise zum Abschließen einer Jobstufe

Gehen Sie folgendermaßen vor, um eine Jobstufe oder einen Schritt abzuschließen:

1. Rufen Sie die Seite "Technikerjobs" auf.
2. Wählen Sie den Job in der Liste aus.
3. Klicken Sie auf Fertigungsaktionen. Eine Transaktionsliste wird angezeigt.
4. Klicken Sie auf Jobfortschritt. Das Popup "Jobfortschritt" wird angezeigt.
Hinweis: Ein Schritt kann erforderliche Felder, Checklisten und Datensammlungen haben, die zunächst nicht in der Ansicht zu sehen sind. Scrollen Sie nach unten und reduzieren Sie die Tabellen "Techniker" und "Wartungsstatus", um besser sehen zu können, was sich im Fenster befindet.
5. Wählen Sie den entsprechenden Symptomcode, Ursachencode und Reparaturcode aus, wenn diese Felder aktiviert sind.
6. Führen Sie für jede Checkliste, die in der Tabelle "Checkliste" aufgeführt ist, folgende Schritte aus:
a. Aktivieren Sie das Kontrollkästchen für die Tabelle. Die Zeile wird blau hervorgehoben.
b. Scrollen Sie unter die Tabelle "Checkliste", damit alle erforderlichen Datensammlungen zu sehen sind. Die Datensammlungspunkte werden unter der Tabelle angezeigt.
c. Geben Sie jeden erforderlichen Datenpunkt ein.
d. Klicken Sie auf Jobfortschritt. Die Hervorhebungsfarbe der ausgewählten Checklistenzeile wechselt zu grün.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Teileanforderung, um das Popup "Teileanforderung" anzuzeigen, wenn Sie mindestens ein Teil anfordern müssen. Weitere Informationen finden Sie unter "Anfordern von Teilen".
9. Klicken Sie auf Jobfortschritt, wenn Sie fertig sind. Eine Ergebnismeldung wird angezeigt und das Popup "Jobfortschritt" wird geschlossen.
