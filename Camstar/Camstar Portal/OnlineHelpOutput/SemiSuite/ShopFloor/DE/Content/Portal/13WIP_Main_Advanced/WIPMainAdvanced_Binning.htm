Gefäßeinsortierung

Die Gefäßeinsortierung bietet die Möglichkeit, Einheiten aus einem Los auszusortieren und in getrennte Gefäße einzusortieren. Die Einheiten können z. B. anhand der Testergebnisse gruppiert werden. Das Los kann in neue Lose aufgeteilt oder weiter als ein Los verarbeitet werden, wenn alle Einheiten geprüft und entsprechend einsortiert wurden.

Sie führen eine Gefäßeinsortierung während der Umlaufbestandsverarbeitung mit dem Popup "Losgefäße" durch. Die Gefäßeinsortierung kann so konfiguriert werden, dass sie vor oder nach dem Ausbringen durchgeführt wird. Die Anwendung zeigt das Popup "Losgefäße" an, wenn die operative Umlaufbestandsspezifikation einen Gefäßtyp enthält.

Vorgehensweise zum Durchführen einer Gefäßeinsortierung für eine Verarbeitung, die nicht auf Elementebene erfolgt

Gehen Sie folgendermaßen vor, um eine Gefäßeinsortierung durchzuführen, die nicht auf Elementebene erfolgt:

1. Klicken Sie auf der Seite "Hauptumlaufbestand - Erweitert" auf die Kachel Gefäßeinsortierung. Das Popup "Losgefäße" wird angezeigt.
2. Führen Sie die Gefäßeinsortierung in der Tabelle "Gefäßedetails" durch.
a. Klicken Sie auf die Zelle Gefäßmenge der Zeile mit dem Zielgefäß. Die Dateneingabefelder für das betreffende Gefäß werden angezeigt.
b. Geben Sie die Menge ein, die in das Gefäß einsortiert werden soll.
3. Klicken Sie auf Abschicken, wenn Sie die Gefäßeinsortierung in der Tabelle vorgenommen haben.

Vorgehensweise zum Durchführen einer Gefäßeinsortierung für eine Verarbeitung auf Elementebene

Gehen Sie folgendermaßen vor, um eine Gefäßeinsortierung auf Elementebene durchzuführen:

1. Klicken Sie auf der Seite "Hauptumlaufbestand - Erweitert" auf die Kachel Gefäßeinsortierung. Das Popup "Losgefäße" wird angezeigt.
2. Wählen Sie die Element-ID aus, um den Wafer anzugeben.
3. Führen Sie die Gefäßeinsortierung für den ausgewählten Wafer in der Tabelle "Gefäßedetails" durch. Führen Sie für jedes Gefäß, in das Elemente verschoben werden sollen, folgende Aktionen durch:
a. Klicken Sie auf die Zelle Gefäßmenge der Zeile mit dem Zielgefäß. Die Dateneingabefelder für das betreffende Gefäß werden angezeigt.
b. Geben Sie die Menge ein, die in das Gefäß einsortiert werden soll.
4. Wiederholen Sie die Schritte 2-3 ggf. für die restlichen Waferelemente.
5. Klicken Sie auf Abschicken, wenn die Gefäßeinsortierung für das ausgewählte Waferelement durchgeführt wurde. Das Popup "Losgefäße" wird geschlossen.

Vorgehensweise zum Durchführen einer Gefäßeinsortierung für eine Verarbeitung auf Elementebene mit Multiprodukt-Wafern

Gehen Sie folgendermaßen vor, um eine Gefäßeinsortierung für eine Verarbeitung auf Elementebene mit Multiprodukt-Wafern durchzuführen:

1. Klicken Sie auf der Seite "Hauptumlaufbestand - Erweitert" auf die Kachel Gefäßeinsortierung. Das Popup "Losgefäße" wird angezeigt.
2. Wählen Sie die Element-ID aus, um den Wafer anzugeben.
3. Wählen Sie das Unterprodukt aus.
4. Führen Sie die Gefäßeinsortierung für den ausgewählten Wafer und das ausgewählte Unterprodukt in der Tabelle "Gefäßedetails" durch. Führen Sie für jedes Gefäß, in das Elemente verschoben werden sollen, folgende Aktionen durch:
a. Klicken Sie auf die Zelle Gefäßmenge der Zeile mit dem Zielgefäß. Die Dateneingabefelder für das betreffende Gefäß werden angezeigt.
b. Geben Sie die Menge ein, die in das Gefäß einsortiert werden soll.
5. Wiederholen Sie die Schritte 3-5 für jedes Unterprodukt des ausgewählten Wafers, das einsortiert werden soll.
6. Wiederholen Sie die Schritte 2-6 ggf. für die restlichen Waferelemente.
7. Klicken Sie auf Abschicken, wenn die Gefäßeinsortierung für das ausgewählte Unterprodukt durchgeführt wurde. Das Popup "Losgefäße" wird geschlossen.
