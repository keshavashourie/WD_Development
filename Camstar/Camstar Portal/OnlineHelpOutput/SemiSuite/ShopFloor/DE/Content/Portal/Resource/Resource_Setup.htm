Ressourceneinrichtung

Einrichtung ermöglicht es Ihnen, Ressourcen zu konfigurieren, um eine bestimmte Konfiguration in der Produktion auszuführen. Sie können die Seite für Einrichtung verwenden, um die folgenden Ressourcen zu konfigurieren:

• Ausrüstung (Zusammenbau, Backgrind, Element, Test und Wafersortierung)
• Behälter
• Masken
• Werkzeuge

Felddefinitionen der Seite "Ressourceneinrichtung"

Diese Tabelle definiert die Felder auf der Seite für Einrichtung.

Feld

Definition

Typ

Typname

Name des Elements (Ausrüstung, Maske, Werkzeug oder Behälter), das Sie einrichten möchten. Das Feld hat z. B. den Namen "Elementausrüstung", wenn Sie den Status für Elementausrüstung festlegen, den Feldnamen "Werkzeug" für Werkzeuge usw.

Erforderlich

Fertigungslinie

Fertigungslinie, der diese Ausrüstung zugewiesen ist.

Optional

Mitarbeiter

Mitarbeiter, der diese Transaktion ausführt, wenn er nicht der derzeit angemeldete Benutzer ist.

Optional

Dokumentsatz

Dokumentsatz, in dem die Einrichtung oder alle zugehörigen Informationen beschrieben sind.

Optional

Eltern-Ressource

Name der Eltern-Ressource.

Optional

Maschinengruppe

Name der Maschinengruppe, die der Ressource zugewiesen ist.

Optional

Paketgruppe

Paketgruppe, zu der die Ressource gehört. Sind Zuführungen konfiguriert, müssen diese als eines der Details in der Paketgruppe vorhanden sein.

Optional

Max. Lose

Maximale Anzahl Lose, die in der Ressource erlaubt ist.

Optional

Max. Einheiten

Maximale Anzahl Einheiten, die in der Ressource erlaubt ist.

Optional

Mehrere Lose

Gibt an, ob beim Einbringen mehrerer Lose eine Prüfung erfolgen soll. Folgende Optionen stehen zur Auswahl:

• Nicht erforderlich.
• Alle Lose müssen dasselbe Gerät, dasselbe Paket und dieselben Zuführungen haben.
• Alle Lose müssen dasselbe Paket und dieselben Zuführungen haben (das Gerät kann dasselbe oder ein anderes sein).
• Alle Lose müssen ein unterschiedliches Paket und unterschiedliche Zuführungen haben (das Gerät kann dasselbe oder ein anderes sein).

Optional

Maske

Maske, die auf die Ressource angewendet werden soll.

Optional

Physischer Ort

Physischer Standort der Ressource.

Optional

Physische Position

Position der Ressource im physischen Standort.

Optional

Produkt

Produkt, das der Ressource zugewiesen ist.

Optional

Rezept

Rezept, das der Ressource zugewiesen ist.

Hinweis: Die Rezeptliste enthält nur aktive Rezepte. Inaktive Rezepte können nicht ausgewählt werden. Die Rezepte sind auf die Rezepte in einer zugewiesenen Rezeptgruppe beschränkt, wenn eine Rezeptgruppe für die ausgewählte Ausrüstung zugewiesen wurde.

Optional

Werkzeugplan

 

Werkzeugplan

Richtet die Art der Werkzeugbestückung ein, die für die Ausrüstung erforderlich ist. Jeder Ressource kann ein Werkzeugplan zugewiesen werden. Ist der Ressource ein Werkzeugplan zugewiesen, müssen die erforderlichen Werkzeuge in der Ressource eingerichtet sein, bevor diese zum Verarbeiten von Losen verwendet werden kann.

Optional

Werkzeugplanbeschreibung

Beschreibung des Werkzeugplans.

Optional

Tabelle "Werkzeugplandetails"

Tabelle, in der die Werkzeuge angezeigt werden, die zu den zugewiesenen Werkzeugplänen gehören.

Optional

Scannen, um Werkzeuge hinzuzufügen

Werkzeuge, die der Ressource zugewiesen werden sollen.

Optional

Tabelle "Tools"

Tabelle, die die Werkzeuge anzeigt, die der Ressource zugewiesen sind.

Optional

Tabelle "Parameter"

Tabelle, die die Parameter anzeigt, die durch die Parametergruppe definiert sind.

Optional

Tabelle "Werkzeug/Maske"

Eine Tabelle, in der vorhandene Werkzeuge oder Masken angezeigt werden, die der Ressource zugewiesen sind.

Nur Anzeige

Werkzeug/Maske

Der Ressource zugewiesenes Werkzeug oder zugewiesene Maske.

Nur Anzeige

Typ

Typ der Lagerung. Beispielsweise Werkzeug oder Maske.

Nur Anzeige

Physischer Ort

Physischer Ort des Werkzeugs oder der Maske in einer Fabrik.

Nur Anzeige

Physische Position

Position des Werkzeugs oder der Maske im physischen Standort.

Nur Anzeige

Referenzlosinformationen

 

Referenzlos

Vorhandenes Los oder vorhandene Einrichtung, aus dem oder der Loswerte kopiert werden sollen.

Optional

Schrittname für Referenzlos

Name des Arbeitsplanschritts, in dem sich das Los befindet, auf das verwiesen wird.

Optional

Referenzlos: Prozesstyp

Prozess, der in den "Prozessspez.: Details" des Loses verfügbar ist, auf das verwiesen wird.

Optional

Maske für Referenzlos

Masken-ID der Referenzlosspezifikation.

Optional

Kommentare

Zusätzliche Informationen oder Anweisungen. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Einrichten von Ressourcen

Gehen Sie folgendermaßen vor, um Ausrüstung, Masken, Werkzeuge und Behälter einzurichten:

1. Öffnen Sie die Seite Einrichtung. Die Anwendung zeigt die Seite "Einrichtung" an.
2. Geben Sie den Namen der Ressource, für die Sie den Status festlegen möchten, in das Feld ein, das der Art der Ressource entspricht:

Ressource

Feld

Elementausrüstung

Elementausrüstung

Wafersortierungsausrüstung

Elementsortierungsausrüstung

Backgrind-Ausrüstung

Backgrind-Ausrüstung

Zusammenbauausrüstung

Zusammenbauausrüstung

Testausrüstung

Testausrüstung

Maske

Maske

Werkzeug

Werkzeug

Behälter

Behälter

Die Anwendung zeigt die Details der Ressource in den entsprechenden Feldern an.

3. Klicken Sie auf Referenzlos kopieren, um die Werte des Referenzloses zu kopieren, wenn Sie Informationen im Abschnitt Referenzlosinformationen eingegeben haben.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
