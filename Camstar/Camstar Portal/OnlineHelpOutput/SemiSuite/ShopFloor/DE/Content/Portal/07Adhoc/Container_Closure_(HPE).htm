Containerabschluss (HPE)

Die Seite "Containerabschluss (HPE)" bietet Funktionen zum gleichzeitigen Abbruch mehrerer oder aller Container. Die Seite akzeptiert einzelne Container, Behälter, Arbeitsaufträge und Produktionsaufträge. Wenn ein Eltern-Container im Feld "Auswahl-ID" eingegeben wird, zeigt die Anwendung alle Kind-Container an, die dem eingegebenen Eltern-Container zugeordnet sind. Sie können Behälter- oder Kind-Container aus der Tabelle zum Abbruch auswählen. Wenn Sie einen Kind-Container auswählen, wird er vor dem Beenden automatisch von seinem Behälter (Eltern) abgetrennt.

Wenn alle verknüpften Container beendet werden, benennt die Anwendung den Eltern-Behälter-Container basierend auf der in "Fabrik" festgelegten Nummerierungsregel um.

Der Prozess "Containerabschluss" soll zusätzliche Funktionen im Zusammenhang mit der Einzelwaferverfolgung (Element) bereitstellen, die in Kapitel 21 beschrieben ist.

Hinweis: Die Seite "Containerabschluss (HPE)" wurde auf High Performance Engine (HPE) abgestimmt. HPE erhöht die Transaktionseffizienz, da die Anwendung Transaktionen in der Datenbank und nicht auf dem Anwendungsserver verarbeitet. Informationen finden Sie unter Opcenter™ Execution Core – Technische Referenz: High Performance Engine.

Felddefinitionen der Seite "Containerabschluss (HPE)"

Diese Tabelle definiert die Felder auf der Seite "Containerabschluss (HPE)".

Feld

Definition

Typ

Auswahl-ID

Feld zum Angeben des Containers, Behältercontainers, Arbeitsauftrags oder Produktionsauftrags, der beendet werden soll. Sie können mehrere Container gleichzeitig eingeben oder den gesamten Arbeitsauftrag auswählen. Kind-Container, die dem Eltern-Container zugeordnet sind, werden in der Tabelle mit Details angezeigt.

Erforderlich

Scannen, um eine Gruppe von Containern auszuwählen (Eltern-Container/Arbeitsauftrag)

Feld zum Scannen von Arbeitsauftrag, Produktionsauftrag oder Behältercontainer. Die Anwendung füllt alle Container, die dem gescannten Arbeitsauftrag/Produktionsauftrag/Behälter in der Tabelle mit Details zum Containerabschluss zugeordnet sind. Sie können dieses Feld verwenden, um eine Gruppe von Containern auszuwählen, die in einer einzelnen Transaktion basierend auf dem Eltern-Container oder dem zugehörigen Arbeitsauftrag geschlossen werden sollen.

Optional

Mitarbeiter

Person oder Team, die/das diese Transaktion ausführt, wenn es sich nicht um den aktuell angemeldeten Benutzer handelt.

Optional

Tabelle mit Details zum Containerabschluss

Tabelle, die Informationen zum angegebenen Behältercontainer oder Container im Feld "Ausgewählte ID" enthält.

Hinweis: Die Liste der Container in dieser Tabelle wird alphabetisch nach jedem Behältercontainer (Eltern) sortiert, sofern dieser enthalten ist. Wenn der Container nicht zu einem Eltern-Container gehört, wird er als "ohne Eltern" aufgelistet und nach allen Eltern-Containern am Ende aufgeführt. Mithilfe des Kontrollkästchens können Sie Ihre Auswahl von Behältern oder einzelnen Kind-Containern, die abgebrochen werden sollen, basierend auf Ihrer Geschäftsanforderung anpassen.

Optional

Container

Zeigt Behälter- und Containernamen an, die im Feld "Auswahl-ID" angegeben sind.

Nur Anzeige

Arbeitsauftrag

Produktionsauftrag, der zum Starten des Containers verwendet wird.

Nur Anzeige

Schritt

Arbeitsplanschritt, der dem Container zugewiesen ist.

Nur Anzeige

Ausstehender Losstatus

Aktueller Status des Containers im Hauptumlaufbestand. Beispielsweise Anmelden, Einverfolgen, Ausverfolgen oder Abmelden.

Nur Anzeige

Ausrüstung

Ausrüstung mit aktuell verarbeitetem Container, wenn sein aktueller Status "Einbringen" lautet.

Nur Anzeige

Grund für Qualitätsstatus

Defektgrund oder Qualitätsstatus, der mit dem Container verknüpft ist.

Nur Anzeige

Grund für Qualitätsstatus – Eltern-Container

Gruppe des Defektgrunds oder Qualitätsstatus, der mit dem Container verknüpft ist.

Nur Anzeige

Abbruchgrund

Erforderliches Feld, mit dem der Grund für den Abbruch oder das Schließen des Containers/der Container angegeben wird.

Erforderlich

Abbruchkonto

Optionales Feld, um das Konto anzugeben, das für den Abbruch verantwortlich ist. Wird für Berichterstellungszwecke verwendet.

Optional

Zusätzliche Felder anzeigen/ausblenden

Kommentare

Zusätzliche Informationen oder Anweisungen. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Abbrechen von Containern

Gehen Sie folgendermaßen vor, um Container auf der Seite "Containerabschluss (HPE)" abzubrechen:

1. Öffnen Sie die Seite Containerabschluss (HPE).
2. Geben Sie den Namen des Containers, den Sie abbrechen möchten, in das Feld Auswahl-ID ein oder verwenden Sie das Feld Scannen, um eine Gruppe von Containern auszuwählen (Eltern-Container/Arbeitsauftrag). Die Anwendung zeigt alle Container und die Kind-Container in der Tabelle mit Details zum Containerabschluss an.
3. Wählen Sie einen Satz abzubrechender Behälter- oder einzelner Container in der Tabelle mit Details zum Containerabschluss aus, indem Sie das linke Kontrollkästchen in der Tabelle aktivieren.
4. Geben Sie den Abbruchgrund ein.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Übergeben. Die Anwendung bricht alle ausgewählten Container und Kind-Container ab.
