Überwachung

Überwachungsanforderungen erzwingen eine Datensammlung für Ressourcen, Ressourcengruppen, Operationen und Arbeitsbereiche. Auf der Registerkarte "Hauptumlaufbestand - Erweitert – Überwachung" können Sie aktive Überwachungsanforderungen in Echtzeit anzeigen. Eine Aktualisierung ist nicht erforderlich.

Die Aktualisierungsrate hängt vom Zeitplan einer unterstützenden geplanten Geschäftsregel in Opcenter Execution Semiconductor-Modellierung ab. Wenden Sie sich an Ihren Systemadministrator, wenn Sie Informationen zur Konfiguration der Aktualisierungsrate benötigen.

Im linken Bereich des Popups befinden sich Filterfelder. (Filter schließen sich gegenseitig aus.) Die Filter minimieren den angezeigten Inhalt basierend auf den ausgewählten Kriterien. Der rechte Teil des Popups enthält eine Tabelle, in die alle aktiven Überwachungsanforderungen eingetragen werden, wenn die Popup-Seite "Überwachung" angezeigt wird. Das Überwachungsabonnement wird beim Laden der Seite automatisch aktiv. Bei einem Abonnementfehler muss das Popup erneut geöffnet werden. Weitere Informationen finden Sie unter "Überwachungsanforderungen".

Vorgehensweise zum Anzeigen von Überwachungsanforderungen

Gehen Sie folgendermaßen vor, um auf der Seite "Hauptumlaufbestand - Erweitert" Überwachungsanforderungen anzuzeigen:

1. Klicken Sie auf die Schaltfläche Überwachung auf der Seite Hauptumlaufbestand - Erweitert. Das Popup "Überwachung" wird angezeigt. Die Anwendung abonniert automatisch die SignalR-Verbindung und trägt "Abonniert" in das Feld "Status" ein.
2. Wählen Sie einen oder mehrere Filterparameter aus, um Ihre Suche einzugrenzen.
3. Klicken Sie auf Filtern. Die Anwendung füllt die Tabelle mit allen Suchergebnissen, sobald der erste vordefinierte Aktualisierungszeitraum abgelaufen ist.
Hinweis: Sie können die Filterkriterien ändern, ohne erneut auf Filtern klicken zu müssen. Die überarbeiteten Suchergebnisse werden angezeigt, wenn eine automatische Aktualisierung erfolgt.
