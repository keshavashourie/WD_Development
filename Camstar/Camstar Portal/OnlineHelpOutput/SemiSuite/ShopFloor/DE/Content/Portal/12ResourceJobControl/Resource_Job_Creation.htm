Joberstellung

Ressourcenwartungsjobs können manuell oder automatisch erstellt werden. Eine manuelle Joberstellung wird von einem Benutzer vorgenommen, der autorisiert ist, die Transaktion "Joberstellung" zu verwenden. Eine automatische Joberstellung kann vom Systemadministrator für die folgenden Modellierungsobjekte konfiguriert werden:

• Datumsanforderungen
• Wiederholungsterminanforderungen
• Durchsatzanforderungen
• Verwendungsanforderungen
• Transaktion zur Statusfestlegung

Weitere Informationen finden Sie unter Opcenter Execution Semiconductor Modeling-Benutzerhandbuch.
