Teileanforderung zuweisen

Die Seite "Teileanforderung zuweisen" ermöglicht es Ihnen, einem Teileanforderungsauftrag Ressourcenmaterialteile zuzuweisen. Der Benutzer kann mehrmals Teilmengen zuweisen, bis die vollständige Anforderungsmenge erreicht ist.

Felddefinitionen der Seite "Teileanforderung zuweisen"

Diese Tabelle definiert die Felder auf der Seite "Teilanforderung zuweisen".

Vorgehensweise zum Zuweisen von Materialteilen zu einer Teileanforderung

Gehen Sie folgendermaßen vor, um einer Teileanforderung Materialteile zuzuweisen:

1. Rufen Sie die Seite "Teileanforderung zuweisen" auf.
2. Wählen Sie im Feld Ressource eine Ressource aus. Die Anwendung füllt Folgendes aus: das Feld "Jobauftrag" (sofern zutreffend), die Felder "Anforderungsauftrag" und "Anforderungstyp" und die Tabelle "Anforderungsauftrag: Materialteile".
3. Klicken Sie in der Tabelle "Zugewiesene Teile" auf Neue Zeile hinzufügen. Eine Zeile wird in der Tabelle aktiviert.
4. Wählen Sie das Teil aus.
5. Wählen Sie das Materialteil aus.
6. Geben Sie die Menge, die Sie zuweisen möchten, in das Feld Teilemenge zuweisen ein.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Einreichen. Die Anwendung zeigt eine Erfolgsmeldung an.
