Automatisierungseinrichtung

Die Seite "Automatisierungseinrichtung" ermöglicht es Ihnen, die Art der Automatisierung zuzuweisen, die für die Ressource konfiguriert wird.

Auf die Felder für die Automatisierungseinrichtung können Sie auch zugreifen, indem Sie auf der Seite "Ressourcenlayoutansicht" auf "Automatisierungseinrichtung" klicken. Wenn Sie so auf die Felder für die Automatisierungseinrichtung zugreifen, werden diese im Popup "Ausrüstung: Automatisierungseinrichtung" angezeigt. Weitere Informationen zur Seite" Ressourcenlayoutansicht" finden Sie unter "Ressourcenlayoutansicht".

Felddefinitionen der Seite "Automatisierungseinrichtung"

Diese Tabelle definiert die Felder auf der Seite "Automatisierungseinrichtung".

Feld

Definition

Typ

Ausrüstung

Der Name der Ausrüstung.

Erforderlich

Mitarbeiter

Mitarbeiter, der diese Transaktion ausführt, wenn er nicht der derzeit angemeldete Benutzer ist.

Optional

Automatisierungsplan

Der Automatisierungsplan, der dazu verwendet wird, die Ressource einzubringen oder auszubringen.

Hinweis: Dieses Feld ist erforderlich, um die Seite zu speichern.

Optional

Kommentare

Zusätzliche Informationen oder Anweisungen. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Definieren von Automatisierungseinrichtungsparametern

Gehen Sie folgendermaßen vor, um Automatisierungseinrichtungsparameter zu definieren:

1. Öffnen Sie die Seite "Automatisierungseinrichtung". Die Anwendung zeigt die Seite "Automatisierungseinrichtung" an.

Oder

Klicken Sie auf der Seite "Ressourcenlayoutansicht" auf Automatisierungseinrichtung. Die Anwendung zeigt das Popup "Ausrüstung: Automatisierungseinrichtung" an.

2. Geben Sie den Namen der Ausrüstung, für die Sie Transaktionen automatisieren, in das Feld Ausrüstung ein.
3. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
4. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
