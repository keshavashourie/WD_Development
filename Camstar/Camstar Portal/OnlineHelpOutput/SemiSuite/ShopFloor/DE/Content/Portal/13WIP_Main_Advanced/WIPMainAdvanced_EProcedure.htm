Automatische Abläufe

Opcenter Execution Semiconductorkann mit automatischen Abläufen konfiguriert werden, die mehrere zusammengehörige Aufgaben in einer Spezifikation gruppieren. Automatische Abläufe verringern die Anzahl der erforderlichen Transaktionen während der Umlaufbestandsverarbeitung. Der Bediener kann auf der Seite "Hauptumlaufbestand - Erweitert" auf die Kachel "Automatische Abläufe" klicken, um die Seite "Automatischer Ablauf" aufzurufen.

Anzeigen von Prozesstimern

Die Anwendung zeigt ein Uhrzeitfeld in der Nähe der rechten oberen Ecke der Seite an, wenn das ausgewählte Los einen aktiven Prozesstimer hat. Klicken Sie auf den Pfeil neben dem Wort "Timer", um die aktiven Prozesstimer für das Los anzuzeigen.

Hinweis: Im Opcenter Execution Core Shop Floor-Benutzerhandbuch finden Sie ausführliche Informationen zur Funktion "Prozesszeiterzwingung". Unter "Prozesszeiterzwingung" in diesem Handbuch werden verschiedene, für Opcenter Execution Semiconductor spezifische Aspekte dieser Funktion beschrieben.

Felddefinitionen der "Automatischen Ablauf-Seite"

Diese Tabelle definiert die Felder auf einer "Automatischer Ablauf"-Seite.

Feld

Definition

Container-/Losinformationen

Details des ausgewählten Containers oder Loses

Aufgabenliste

Eine oder mehrere Aufgabenlisten, die dem automatischen Ablauf zugewiesen sind. Wenn die Aufgabenlisten sequenziell sind, was durch einen Pfeil am Ende der Aufgabenliste gekennzeichnet wird, müssen Sie die Aufgabenliste in der Reihenfolge abarbeiten, in der die Aufgaben angezeigt werden. Wenn die Aufgabenlisten nicht sequenziell sind, was durch das Fehlen von Pfeilen am Ende der Aufgabenliste angezeigt wird, können Sie jede beliebige Aufgabe zur Bearbeitung auswählen.

Aufgabenleiste

Aufgaben für die ausgewählte Aufgabenliste. Die Anwendung zeigt jede Aufgabe in einer separaten Kachel an. Die folgenden Definitionen beschreiben die Felder, die in einer einzelnen Kachel angezeigt werden können.

Sequence

Die Sequenznummer, die der Aufgabe zugeordnet wird, hängt von der Reihenfolge ab, in der sie in der Tabelle "Aufgaben" der "Aufgabenliste" des Modellierungsobjektes angezeigt wird.

Optional

Visueller Hinweis, der angibt, dass die Aufgabe nicht erforderlich ist. Eine Aufgabe ist freiwillig, wenn die minimale Wiederholungszahl 0 ist. Wenn die Anwendung den Optionalen Indikator nicht anzeigt, ist die Aufgabe erforderlich.

Status

Status der Aufgabe: "Nicht ausgeführt", "Bestanden" oder "Fehlgeschlagen".

Aufgabenname

Name der Aufgabe.

Anzahl

Die Anzahl, wie oft die Aufgabe ausgeführt wurde, die Mindestanzahl an benötigten Wiederholungen und die maximale Anzahl an erlaubten Wiederholungen. Wenn die minimale Anzahl von Iterationen ausgeführt wurde, ändert die Anwendung die Hintergrundfarbe und Schriftart entsprechend.

Arbeitsleiste

Dynamischer Bereich, der den Aufgabennamen, Anweisungen und Felder der ausgewählten Aufgabe anzeigt. Der Name der Aufgabe wird in der Überschrift der Arbeitsleiste angezeigt. Je nach Aufgabenelementtyp haben einige Aufgaben Pflichtfelder, während andere nur Optionale Felder haben.

Anweisungen

Hervorgehobener Bereich, in dem Anweisungen zur Durchführung der Aufgabe angezeigt werden.

Arbeitsplatz

Arbeitsplatz, an dem die Aufgabe ausgeführt wird. Die Anwendung verlangt, dass Sie einen Arbeitsplatz auswählen, wenn der Aufgabentyp "Start Prozess" ist. Wenn die Anwendung standardmäßig einen Arbeitsplatz auswählt, ist dieses Feld schreibgeschützt. Darüber hinaus zeigt die Anwendung einen visuellen Hinweis an, ob der ausgewählte Arbeitsplatz zur Bearbeitung bereit ist.

Hinweis: Die Anwendung zeigt dieses Feld nur für Anweisungen und Berechnungsaufgaben an.

Vorgehensweise zum Durchführen automatischer Ablaufaufgaben

Gehen Sie folgendermaßen vor, um automatische Ablaufaufgaben durchzuführen:

1. Führen Sie für jede Aufgabe im vertikalen Aufgabenmenü folgende Aktionen durch:
a. Wählen Sie den Aufgabenblock aus. Die relevanten Aufgabeninformationen werden angezeigt.
b. Führen Sie die Aufgabe durch.
Hinweis: Einige Aufgaben sind so konfiguriert, dass sie sequenziell ausgeführt werden.
c. Klicken Sie auf Abschicken. Der Arbeitsplan kann zum nächsten Schritt wechseln, wenn alle erforderlichen Aufgaben zusammen mit den Anforderungen auf der Hauptseite abgeschlossen wurden.
