Losaufbewahrung

"Losaufbewahrung" ist eine Lagerbestandstransaktion, die im Lagerbestandstyp verfügbar ist, z. B. "Die-Bank | Losaufbewahrung". Auf der Seite "Losaufbewahrung" können Sie alte Lose aus einem Lagerbestandsschritt in einen Aufbewahrungsschritt oder aus einem Aufbewahrungsschritt in einen Lagerbestandsschritt bewegen.

Hinweis: Ein Aufbewahrungsschritt ist ein Schritt, dessen Operation ein Aufbewahrungstyp zugewiesen ist.

Es gibt folgende Losaufbewahrungsvarianten:

• Wafer: Losaufbewahrung: Wird verwendet, um Lose innerhalb eines Wafer-Lagerbestandsarbeitsplans zu bewegen
• Wafersortierung: Losaufbewahrung: Wird verwendet, um Lose innerhalb eines Wafersortierungs-Lagerbestandsarbeitsplans zu bewegen.
• Die-Bank: Losaufbewahrung: Wird verwendet, um Lose innerhalb eines Die-Bank-Arbeitsplans zu bewegen.
• Testspeicher: Losaufbewahrung: Wird verwendet, um Lose innerhalb eines Testspeicherarbeitsplans zu bewegen.

Beim Verwenden von "Losaufbewahrung"

Beachten Sie beim Verwenden der Seite "Losaufbewahrung" Folgendes:

• Das ausgewählte Los muss sich in einem Lagerbestandsschritt befinden, wenn es in einen Losaufbewahrungsschritt bewegt werden soll.
• Sie müssen in "Zu Schritt" einen Zielschritt auswählen, wenn "In Aufbewahrung verschieben" ausgewählt ist.

Vorgehensweise zum Durchführen einer Losaufbewahrung

Gehen Sie folgendermaßen vor, um eine Losaufbewahrung durchzuführen:

1. Rufen Sie die Seite "Losaufbewahrung" auf.
2. Geben Sie die Los-ID in das Feld Auswahl-ID ein. Die Anwendung zeigt die Lose in der Tabelle "Lose" an.
3. Wählen Sie in Zu Arbeitsplan den Zielarbeitsplan aus.
4. Wählen Sie in Zu Schritt den Zielschritt aus.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
