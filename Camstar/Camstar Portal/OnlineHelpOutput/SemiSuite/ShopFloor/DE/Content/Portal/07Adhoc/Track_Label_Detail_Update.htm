Nachverfolgungsbeschriftung: Detail aktualisieren

Auf der Seite "Nachverfolgungsbeschriftung: Detail aktualisieren" können Sie Details für zuvor generierte Beschriftungen aktualisieren. Die Änderungen, die Sie auf dieser Seite an Beschriftungen vornehmen, wirken sich lediglich auf spätere Ausdrucke der jeweiligen Beschriftung aus. Die Transaktion ändert das zugehörige Modellierungsobjekt "Beschriftungsplan" und hat keinen Einfluss auf Beschriftungen, die später mit dem gleichen Beschriftungsplan gedruckt werden.

Felddefinitionen der Seite "Nachverfolgungsbeschriftung: Detail aktualisieren"

Diese Tabelle definiert die Felder auf der Seite "Nachverfolgungsbeschriftung: Detail aktualisieren".

Feld

Definition

Typ

Beschriftungs-ID

Barcodewert der zu aktualisierenden Beschriftung. Wenden Sie sich an den Systemadministrator, um diesen Wert zu erhalten, wenn Sie die Beschriftung nicht scannen können oder der Inhalt unleserlich ist.

Erforderlich

Mitarbeiter

Mitarbeiter, der diese Transaktion ausführt, wenn er nicht der derzeit angemeldete Benutzer ist.

Optional

Beschriftungsstatus

Status der Beschriftung. Die verfügbaren Werte sind UNUSED und INUSE.

Optional

Beschriftungsmenge

Mengenwert der Beschriftung.

Erforderlich

ID für Verpackt in

Beschriftungs-ID für die Verpackung der Beschriftung.

Optional

Drucken bei Aktualisierung

Gibt an, ob die Beschriftung erneut gedruckt werden soll, wenn sie aktualisiert wird.

Optional

Status auf alle Beschriftungen im selben Satz anwenden

Kontrollkästchen, um anzugeben, ob der Status auf alle Beschriftungen ein einem Satz übernommen werden soll.

Hinweis: Der Status wird für alle Beschriftungen der gleichen Ebene übernommen, wenn der Status INUSE oder UNUSED ist. Der Status wird für alle Beschriftungen übernommen (einschließlich der untergeordneten Beschriftungen), wenn der Status INVALID ist.

Optional

Tabelle "Beschriftungsquellen: Details"

Quellennamen und Mengen, die die Gesamtmenge der Beschriftung bilden. Sie können Beschriftungsquellen zur Tabelle hinzufügen, bearbeiten oder entfernen, solange die Quellen gültig sind.

Erforderlich

Quell-ID

ID der Beschriftungsquelle.

Hinweis: Die Quell-ID muss zur Beschriftung gehören.

Erforderlich

Menge

Die Gesamtzahl der im Satz gedruckten Beschriftungen. Die Summe aller Werte in der Spalte "Menge" muss mit dem Wert des Felds "Beschriftungsmenge" übereinstimmen.

Erforderlich

Vorgehensweise zum Aktualisieren von Etikettendetails

Gehen Sie folgendermaßen vor, um Etikettendetails zu aktualisieren:

1. Öffnen Sie die Seite "Nachverfolgungsbeschriftung: Detail aktualisieren".
2. Geben Sie die Beschriftungs-ID der zu aktualisierenden Beschriftung in das Feld Beschriftungs-ID ein und drücken Sie die Tabulatortaste. Die Anwendung zeigt die Etikettendetails an.
3. Aktualisieren Sie die Etikettendetails den Geschäftsanforderungen entsprechend.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
