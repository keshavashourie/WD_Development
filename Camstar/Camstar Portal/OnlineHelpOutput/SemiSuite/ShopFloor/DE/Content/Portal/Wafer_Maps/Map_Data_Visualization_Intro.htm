Visualisierung von Zuordnungsdaten

Die Funktion "Visualisierung von Zuordnungsdaten" von Opcenter Execution Semiconductor ermöglicht es Bedienern, eine virtuelle Gefäßeinsortierung auszuführen. Ein externer Standort, z. B. eine Fertigungsanlage, sendet Zuordnungsdaten an Siemens. Die externen Daten sind das Aufzeichnungssystem. Siemens führt keine Daten- oder Strukturvalidierungen für die externen Daten aus. Siemens überträgt eine Kopie der Daten an Opcenter Execution Semiconductor.

Bediener verwenden die Seite "Visualisierung von Zuordnungsdaten" von Opcenter Execution Semiconductor, um eine grafische Darstellung der Zuordnung anzuzeigen und einzelne Zuordnungspositionen für die visuelle Prüfung auszuwählen. Die Anwendung zeigt jegliche Gefäß-Codes für ausgewählte Positionen an und bietet dem Bediener die Möglichkeit, diese Positionen mit neuen Gefäß-Codes zu "markieren". Aktualisierte Gefäß-Code-Informationen werden in Semiconductor Suite gespeichert und vom Absender abgerufen. Der Absender ruft die aktualisierten Gefäß-Code-Informationen ab und führt die tatsächlichen Aktualisierungen für die Quellzuordnung aus.

Weitere Informationen finden Sie in den folgenden Themen:

• Senden von Zuordnungsdaten an Siemens
• Verwenden der Seite "Visualisierung von Zuordnungsdaten"
• Anfordern und Zurückgeben von Zuordnungsdatenaktualisierungen
