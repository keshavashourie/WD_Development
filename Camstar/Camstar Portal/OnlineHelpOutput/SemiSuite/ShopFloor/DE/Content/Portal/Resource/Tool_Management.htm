Werkzeugverwaltung

Über die Seite "Werkzeugverwaltung" können Sie Werkzeugstatus verwalten. Die jeweiligen Status bestimmen z. B., ob ein Werkzeug für eine bestimmte Ausrüstung oder einen bestimmten Mitarbeiter reserviert ist oder ob das Werkzeug an einem bestimmten Ort gelagert werden soll. Die Funktion "Werkzeugverwaltung" aktualisiert den Werkzeugstatus, wenn das Werkzeug in der Fertigung verwendet wird.

Sie geben das zu verwaltende Werkzeug an, indem Sie Suchkriterien eingeben und dann das Werkzeug in den Instanzen auswählen, das den von Ihnen angegebenen Kriterien entspricht. Eine Suche nach Werkzeugen können Sie über den Namen, die Werkzeugfamilie, den Werkzeugstatus, die reservierte Ausrüstung oder eine Kombination dieser Kriterien ausführen. Die Anwendung zeigt die Suchergebnisse in der Tabelle "Ergebnisse" an.

Beim Verwalten von Werkzeugen

Bevor Sie die Seite "Werkzeugverwaltung" verwenden können, müssen Sie folgende Schritte ausführen:

• Definieren aller Werkzeugaktionen, die Sie benötigen. Informationen zum Modellierungsobjekt "Werkzeugaktion" finden Sie unter Opcenter Execution Semiconductor Modeling-Benutzerhandbuch.
• Festlegen des Status des Werkzeugs über die Seite "Status festlegen". Informationen zu "Status festlegen" finden Sie auf der Seite "Status festlegen".

Vorgehensweise zum Verwalten von Werkzeugen

Gehen Sie folgendermaßen vor, um Werkzeuge zu verwalten:

1. Öffnen Sie die Seite "Werkzeugverwaltung".Die Anwendung zeigt die Seite "Werkzeugverwaltung" an.
2. Geben Sie die Suchkriterien ein, die dem Werkzeug entsprechen, das Sie verwalten möchten.
3. Klicken Sie auf Suchen. Die Anwendung zeigt die Suchergebnisse in der Tabelle an.
4. Klicken Sie auf den Pfeil in der Zeile des Werkzeugs, dessen Aktion Sie verwalten möchten.
5. Klicken Sie in der Liste Werkzeugaktion auf die durchzuführende Aktion. Die Anwendung zeigt die Werkzeugaktionsschaltfläche an, wobei diese demselben Namen hat wie die Werkzeugaktion. Wenn Sie z. B. in der Liste "Werkzeugaktion" auf "Speichern" klicken, hat die Schaltfläche den Namen "Speichern".
6. Klicken Sie auf die Werkzeugaktionsschaltfläche. Die Anwendung zeigt das Popup "Werkzeugstatus aktualisieren" an.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Abschicken. Die Anwendung schließt das Popup "Werkzeugstatus aktualisieren" und zeigt eine Bestätigungsmeldung an, die angibt, dass das Werkzeug erfolgreich aktualisiert wurde.
