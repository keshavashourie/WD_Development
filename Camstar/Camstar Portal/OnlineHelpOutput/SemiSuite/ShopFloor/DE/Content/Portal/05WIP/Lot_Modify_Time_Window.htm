Los: Zeitfenster ändern

"Los: Zeitfenster ändern" bietet die Möglichkeit, das minimale Zeitfenster und das maximale Zeitfenster für ein Los zu ändern.

Felddefinitionen der Seite "Los: Zeitfenster ändern"

Diese Tabelle definiert die Felder auf der Seite "Los: Zeitfenster ändern".

Feld

Definition

Auswahl-ID

Erforderliches Feld, um das Los anzugeben, für das min. und max. Zeitfenster geändert werden sollen.

Mitarbeiter

Mitarbeiter, der diese Transaktion ausführt, wenn er nicht der derzeit angemeldete Benutzer ist.

Tabelle "Minimales Zeitfenster: Details"

Liste der verwendeten Unterobjekte zum Ändern der minimalen Zeitfenster für das Los. Wenn keine Details für das max. Zeitfenster vorhanden sind, muss mindestens ein Datensatz vorhanden sein.

Weitere Informationen zu den Feldern finden Sie unter Ausrüstung: Zeitfenster ändern.

Tabelle "Maximales Zeitfenster: Details"

Liste der verwendeten Unterobjekte zum Ändern der maximalen Zeitfenster für das Los. Wenn keine Details für das min. Zeitfenster vorhanden sind, muss mindestens ein Datensatz vorhanden sein.

Startspez.

Erforderliches Feld; muss zusammen mit "Stoppspez." ein Datensatz in der Unterobjektliste "Max. Zeitfenster für Los" des Loses sein.

Stoppspez.

Erforderliches Feld; muss zusammen mit "Startspez." ein Datensatz in der Unterobjektliste "Max. Zeitfenster für Los" des Loses sein.

Maximale Zeit

Erforderliches Feld, das in Stunden angegeben wird. Kann nicht auf einen Wert kleiner als Null festgelegt werden.

Aktion für Verspätet

Erforderliches Feld, um die Aktion für Verspätet anzugeben. Muss auf Anhalten (HOLD) oder Warnung (WARNING) festgelegt werden.

E-Mail-Gruppe

Optionales Feld, um die E-Mail-Gruppe anzugeben, an die eine E-Mail gesendet werden soll, falls im Hauptumlaufbestand ein Fehler erkannt wird.

Zusätzliche Felder anzeigen/ausblenden

Kommentare

Zusätzliche Informationen oder Anweisungen. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.
