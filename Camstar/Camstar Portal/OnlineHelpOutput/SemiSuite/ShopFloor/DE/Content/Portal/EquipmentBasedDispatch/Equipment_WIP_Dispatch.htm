Ausrüstungsumlaufbestand: Erledigung

Die Seite "Ausrüstungsumlaufbestand: Erledigung" bietet einen zentralen Ort, um Ausrüstung anzumelden, einzubringen, auszubringen und abzumelden. Sie stellt außerdem Los- und Ausrüstungsinformationen bereit. Die Seite "Ausrüstungsumlaufbestand: Erledigung" ist leer, wenn Sie über das Menü auf sie zugreifen. Die Anwendung zeigt den Status der ausgewählten Ausrüstung und die Transaktionen an, die Sie ausführen können, nachdem Sie eine zu erledigende Ausrüstung oder Ausrüstungsgruppe ausgewählt haben.

Modellieren von "Ausrüstungsumlaufbestand: Erledigung"

Sie müssen die folgenden Objekte modellieren, bevor Sie "Ausrüstungsumlaufbestand: Erledigung" verwenden:

• GUI-Abfrage
• Matrix "Ausrüstung: Erledigungsabfrage"

Im Opcenter Execution Semiconductor Modeling-Benutzerhandbuch finden Sie Informationen zu Modellierungsobjekten.

Lose und Transaktionen unter Prozesstimersteuerung

In der Tabelle "Erledigungslistenlos(e)" in der Spalte "Timer" und in der Tabelle auf der Registerkarte "Los" wird ein Uhrzeitfeld angezeigt, wenn das Los einen aktiven Prozesstimer hat. Klicken Sie auf den Pfeil neben dem Feld "Timer", um Timerdetails anzuzeigen.

Die Fertigungsaktionen, die für ein ausgewähltes Los aufgelistet werden, enthalten möglicherweise Transaktionen, die unter Prozesstimersteuerung aktiv sind. Ein Versuch, eine Transaktion außerhalb der Bedingungen des Prozesstimers auszuführen, führt zu einer Fehlermeldung.

Im Opcenter Execution Core Shop Floor-Benutzerhandbuch finden Sie ausführliche Informationen zur Funktion "Prozesszeiterzwingung". Unter "Prozesszeiterzwingung" in diesem Handbuch werden verschiedene, für Opcenter Execution Semiconductor spezifische Aspekte dieser Funktion beschrieben.

Informationen

Aktion und Hilfeoptionen, die für das Los verfügbar sind. Die Anwendung zeigt Informationen in einem Popup an, wenn Sie eine Option auswählen und auf klicken. Diese Optionen sind verfügbar:

• Umlaufbestandsnachrichten—Popup "Umlaufbestand: Anweisung" für das ausgewählte Los oder die ausgewählte Ausrüstung. Verwenden Sie diese Option, um kriterienbasierte Umlaufbestandsanweisungen anzuzeigen. Verwenden Sie das Matrixobjekt "Umlaufbestand: Anweisungen" für die entsprechende Einrichtung. Im Opcenter Execution Semiconductor Modeling-Benutzerhandbuch finden Sie weitere Informationen zum Matrixobjekt "Umlaufbestand: Anweisungen".
• Onlinedurchläufer—Arbeitsplanschritte (bisherige, aktuelle und zukünftige) für das ausgewählte Los. Verwenden Sie dieses Symbol, um die Umlaufbestandsschritte für das ausgewählte Los anzuzeigen.
• Dokumente—Popup für Dokumentauswahl für das ausgewählte Los oder die ausgewählte Ausrüstung. Hiermit können Sie die Dokumentsätze anzeigen, die verschiedenen Einrichtungen, etwa "Spez." und "Prozessspez.", zugewiesen sind.
• Losinformationen—Popup "Losinformationen" für das ausgewählte Los. Verwenden Sie es, um die Attribute, prozessspezifischen Parameter, Verbrauchsmaterialien, Werkzeugpläne und Rezepte für das Los anzuzeigen.
• Resourcendetails—Liste der Lose, die derzeit in der Ausrüstung ausgeführt werden (in sie eingebracht sind), die in der Dropdownliste "Ausrüstung" ausgewählt ist.
• SPC-Chart—Zeigt das SPC-Chart an, das bei der Verarbeitung der Umlaufbestandsdaten erstellt wurde.

Prozesstyp

Der Prozesstyp des ersten ausgewählten Loses.

Ladeport

Ein Ladeport ist ein Ausrüstungsgegenstand. Dieses Feld wird angezeigt, wenn die im Feld "Ausrüstung" ausgewählte Ausrüstung als Eltern-Ressource modelliert ist. Mindestens eine der Kind-Ausrüstungen muss als Ausrüstungstyp (Ladeport) mit einer zugewiesenen logischen Unterausrüstungs-ID konfiguriert werden. Der Ladeport ist für die Transaktion "Einbringen“ erforderlich, sofern für die Ausrüstung mindestens ein Ladeport konfiguriert ist. In der Dropdown-Liste "Ladeport" werden nur die Ladeports angezeigt, deren Status aktuell auf "Verfügbar" festgelegt ist.

Hinweis: Die Loswartungsanforderungen für den Ladeport werden während der Nachverfolgung validiert. Die Anforderungen sind Datumsanforderung, Wiederholungsterminanforderung, Durchsatzanforderung und Verwendungsanforderung.

Weitere Informationen finden Sie im Opcenter Execution Semiconductor Modeling-Handbuch.

Anmelden

Kennzeichnet, dass die Ausrüstung angemeldet werden kann. Dies ist nur sichtbar, wenn sich die Ausrüstung im Status "Anmelden" befindet.

Einbringen

Kennzeichnet, dass die Ausrüstung eingebracht werden kann. Dies ist nur sichtbar, wenn sich die Ausrüstung im Status "Einbringen" oder "Ausbringen" befindet.

Ausbringen

Kennzeichnet, dass die Ausrüstung ausgebracht werden kann. Dies ist nur sichtbar, wenn sich die Ausrüstung im Status "Einbringen" oder "Ausbringen" befindet.

Abmelden

Kennzeichnet, dass die Ausrüstung abgemeldet werden kann. Dies ist nur sichtbar, wenn sich die Ausrüstung im Status "Abmelden" befindet.

Kommentare

Zusätzliche Informationen oder Anweisungen. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Vorgehensweise zum Ausführen von Transaktionen für Ausrüstung

Gehen Sie folgendermaßen vor, um Transaktionen für Ausrüstung auszuführen:

1. Öffnen Sie die Seite "Ausrüstungsumlaufbestand: Erledigung". Die Seite "Ausrüstungsumlaufbestand: Erledigung" wird angezeigt.
2. Geben Sie den Namen der Ausrüstungsgruppe und/oder Ausrüstung, für die Transaktionen ausgeführt werden sollen, in die Felder Ausrüstungsgruppe bzw. Ausrüstung ein.
3. Klicken Sie auf Neu laden. Die Anwendung zeigt die Lose, die Sie erledigen können, in der Tabelle "Erledigungslistenlos(e)" an.
4. Wählen Sie in der Tabelle "Erledigungslistenlos(e)" das Los aus, für das Sie die Transaktion ausführen möchten. Die Anwendung zeigt die Transaktionen, die Sie für das Los ausführen können, im Abschnitt "Fertigungsaktionen" an. Die für das Los verfügbaren Transaktionen sind je nach Los unterschiedlich.
5. Klicken Sie im Abschnitt Fertigungsaktionen auf eine der folgenden Optionen, um Transaktionsdaten entsprechend den Anforderungen Ihres Unternehmens einzugeben:

Nach Klicken auf . . .
