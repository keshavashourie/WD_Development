Überwachungsverwaltung

Überwachungsanforderungen erzwingen eine Datensammlung für folgende Elemente:

• Ressourcen
• Ressourcengruppen
• Operationen
• Arbeitsbereiche

Auf der Seite "Überwachungsverwaltung" können Sie eine Überwachungsdatensammlung durchführen, die fällig geworden ist. Die Seite enthält mehrere Suchfilter für die Suche nach Überwachungsanforderungen. Die Suchergebnisse werden in einer Tabelle angezeigt. Durch Klicken auf "Suchen", ohne Filter auszuwählen, wird eine Liste aller Überwachungsanforderungen erzeugt, die für mindestens eine Operation, eine Ressource, eine Ressourcengruppe oder einen Arbeitsbereich aktiviert wurden.

Wenn Sie eine Anforderung in der Tabelle auswählen, füllt die Anwendung die Felder unter der Tabelle mit den Informationen der ausgewählten Anforderung. Durch Klicken auf "Beendet" zeigt die Anwendung ein Popup mit Feldern für alle Datensammlungen (benutzerdefiniert oder parametrisch) an, die für die ausgewählte Anforderung konfiguriert wurden.

Vorgehensweise zum Erledigen einer Überwachungsanforderung für eine Ressource

Gehen Sie folgendermaßen vor, um eine Überwachungsanforderung für eine Ressource zu erledigen:

1. Öffnen Sie die Seite "Überwachungsverwaltung".
2. Geben Sie Werte in die Felder Suchkriterien eingeben ein, um die Anzeige von Ressourcen zu beschränken.
3. Klicken Sie auf Suchen. In der Tabelle "Suchergebnisse" werden die Statusinformationen der aktivierten Überwachungsanforderungen angezeigt, die den eingegebenen Suchkriterien entsprechen. Wenn keine Suchkriterien ausgewählt sind, werden alle möglichen Ergebnisse angezeigt.
4. Klicken Sie auf die betreffende Zeile, um eine Anforderung auszuwählen, die ausstehend, fällig oder überfällig ist. Die Details der Anforderung werden in den schreibgeschützten Feldern unter der Tabelle angezeigt.
5. Klicken Sie auf Beendet. Die Anwendung zeigt eine Erfolgsmeldung an.
