Nachverfolgungsbeschriftung erstellen

Auf der Seite "Nachverfolgungsbeschriftung erstellen" können Sie manuell alle erforderlichen Beschriftungen für die Verpackung von Wafern (z. B. Rollen, Schachteln, Taschen usw.) basierend auf dem ausgewählten Beschriftungsplan erstellen. Auf der Seite "Nachverfolgungsbeschriftung erstellen" können Sie alle Eltern- und Kind-Beschriftungen abhängig von der Beschriftungseinrichtung gleichzeitig drucken. Sie können die Seite "Nachverfolgungsbeschriftung erstellen" verwenden, um alle Beschriftungen vor dem Verpacken zu drucken, oder die Seite für den Hauptumlaufbestand verwenden, um Beschriftungen bei Bedarf im Verpackungsschritt zu drucken. Es ist nicht möglich, Beschriftungen für das gleiche Los im gleichen Schritt auf der Seite "Hauptumlaufbestand" und der Seite "Nachverfolgungsbeschriftung erstellen" zu drucken.

Informationen zu Eltern- und Kind-Beschriftungen

Eltern- und Kind-Beziehungen werden durch den ausgewählten Beschriftungsplan bestimmt. Bei der Verpackung auf Bändern und Rollen wird eine Losmenge aufgeteilt und in mehreren einzelnen Rollen verpackt. Jede Rolle wird eindeutig gekennzeichnet und erfordert eine Beschriftung. Jede Rolle wird weiter in eine zusätzliche Verpackung (Trockenpackung) verpackt, bevor sie in eine größere Schachtel (mehrere Rollen in einer einzigen Schachtel) verpackt wird. Für die Trockenpackungen und Schachteln sind ebenfalls Beschriftungen erforderlich. Sie können alle für die Verpackung erforderlichen Beschriftungen (für Rollen, Trockenpackungen und Schachteln) drucken, indem Sie eine Eltern-Kind-Beziehung zwischen den Beschriftungstypen erstellen.

Sie haben z. B. zwei Lose: P_LOT001 mit 100 Einheiten und P_LOT002 mit 50 Einheiten. Jede Rolle umfasst 50 Einheiten. Dies bedeutet, dass für die Menge der beiden Lose drei Rollen erforderlich sind. Für jede Rolle ist eine eigene Beschriftung erforderlich.

Darüber hinaus wird jede Rolle in einem Trockenbeutel verpackt. Für jeden Trockenbeutel ist eine Beschriftung erforderlich.

Schließlich werden jeweils zwei Trockenbeutel in einer Schachtel verpackt. Für jede Schachtel ist eine Beschriftung erforderlich.

Basierend auf den oben genannten Mengenanforderungen müssen folgende Beschriftungen erstellt werden:

• 3 Rollenbeschriftungen: (100 Einheiten + 50 Einheiten)/50 Einheiten pro Rolle = 3 Rollen bei 1 Beschriftung pro Rolle.
• 3 Trockenbeutelbeschriftungen: 3 Rollen/1 Trockenbeutel pro Rolle = 3 Trockenbeutel bei 1 Etikett pro Trockenbeutel.
• 2 Schachtelbeschriftungen: 3 Trockenbeutel/2 Trockenbeutel pro Schachtel = 2 Schachteln bei 1 Beschriftung pro Schachtel.

In diesem Fall wird die Anzahl der Beschriftungen, die für die Trockenbeutel erforderlich ist, durch die Anzahl der Rollen bestimmt. Die Anzahl der Beschriftungen, die für die Schachteln mit den jeweiligen Trockenbeuteln erforderlich sind, wird durch die Anzahl der Trockenpackungen bestimmt. Dies bildet eine Eltern-Kind-Beziehung zwischen den Rollenbeschriftungen und den Trockenbeutelbeschriftungen sowie zwischen den Trockenbeutelbeschriftungen und den Schachtelbeschriftungen.

Bestimmen der Anzahl von Beschriftungen

Die Anwendung berechnet die Anzahl der zu druckenden Beschriftungen anhand der Menge pro Beschriftung und der Losmenge oder der Anzahl der Elemente im Los. Standardmäßig verwendet die Anwendung die Anzahl der Elemente, wenn sich das Los in einem elementbasierten Verarbeitungsschritt befindet, und die Losmenge, wenn sich das Los in einem mengenbasierten Schritt befindet.

Die Seite "Nachverfolgungsbeschriftung erstellen" enthält die Kontrollkästchen "Mengenbasiert" und "Elementbasiert". Die Anwendung deaktiviert das Kontrollkästchen, das die jeweilige Standardeinstellung darstellt, und bietet die Möglichkeit, das andere Kontrollkästchen zu aktivieren. Sie können von einer standardmäßigen Mengenbasis zur Elementbasis wechseln, indem Sie das Kontrollkästchen "Elementbasiert" aktivieren. Sie können von einer standardmäßigen Elementbasis zur Mengenbasis wechseln, indem Sie das Kontrollkästchen "Mengenbasiert" aktivieren.

Vor dem Erstellen von Beschriftungen

Damit Sie Etiketten erstellen können, müssen Sie mindestens einen Beschriftungsplan definieren. Weitere Informationen zur Erstellung von Beschriftungsplänen finden Sie unter Opcenter Execution Semiconductor Modeling-Benutzerhandbuch.

Vorgehensweise zum Erstellen von Beschriftungen

Gehen Sie folgendermaßen vor, um Beschriftungen zu erstellen:

1. Öffnen Sie die Seite "Nachverfolgungsbeschriftung erstellen".
2. Geben Sie einen Bezeichner für das Los in das Feld Los-ID ein. Die Anwendung zeigt die Losdetails in der Tabelle "Lose" an.
3. Geben Sie den Beschriftungsplan, der zum Erstellen der Beschriftung für das Los verwendet werden soll, im Feld Beschriftungsplan ein. Die Anwendung zeigt die Beschriftungsplandetails in der Tabelle "Beschriftungsplandetails" an.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
