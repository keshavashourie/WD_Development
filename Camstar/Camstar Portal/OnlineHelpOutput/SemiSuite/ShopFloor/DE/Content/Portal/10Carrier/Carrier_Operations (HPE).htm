Behälter-Operationen (HPE)

Die Seite "Behälter-Operationen (HPE)" bietet fünf Funktionen, um die Beziehungen von Behältern und Containern wie folgt zu konfigurieren.

• Um Container in einen bestimmten Behälter zu laden,
• Um Container aus einem bestimmten Behälter zu entladen,
• Um alle Container von einem Behälter in einen anderen Behälter zu übertragen,
• Um alle Container aus einem Behälter zu entladen,
• Um Behälter-Container beim Ausführen von "Alle entladen" und "Alle übertragen" zu schließen oder abzubrechen.

Auf der Seite können Sie die zu ladende Slot-Position angeben und die Position von Containern innerhalb des Behälters verfolgen. Beim Laden werden alle Container einem nachverfolgbaren Behältercontainer zugeordnet. Während des Entladens wird die Zuordnung eines Containers zu einem nachverfolgbaren Behältercontainer abgetrennt. Auf dieser Seite zeigt die Anwendung den zugewiesenen Behältercontainer an (sofern verfügbar). Andernfalls erstellt die Anwendung bei der Übergabe automatisch einen Behältercontainer.

Während der Ausführung von "Alle Container aus einem Behälter entladen" und "Alle Container von einem Behälter in einen anderen übertragen" haben Sie die Möglichkeit, den Behälter zu schließen oder abzubrechen, indem Sie das Kontrollkästchen "Behälter-Container schließen" aktivieren. Nach der Ausführung können Sie den Behälternamen wiederverwenden.

Sie können Behälter und Container wiederverwenden, die über die Seite "Behälter-Operationen (HPE)" zurück in den Lagerbestand verschoben wurden, solange diese sich im selben Arbeitsplan befinden. Wenn z. B. ein Container aus einem Behälter im Arbeitsplan des Hauptumlaufbestands entladen wurde, können Sie den Container nicht wieder in den Behälter laden, nachdem dieser an einen Lagerbestands-Arbeitsplan übertragen wurde. Alternativ können Sie den Container unabhängig aus dem Lagerbestand entnehmen.

Vor der Verwendung von Opcenter Semiconductor Carrier Operations (HPE)

Ein Behälter muss in der Modellierung mit einer zugewiesenen Behälterfamilie konfiguriert werden, die zuvor mit "Behälterpositionen aktivieren" auf "wahr" konfiguriert wurde, zusammen mit der entsprechenden Behälterkonfiguration unter Verwendung der Positionen X, Y und Z. Weitere Informationen finden Sie unter "Definieren von Behälterfamilien" im Opcenter Semiconductor Modeling-Handbuch.

Der Prozess des Ladens von Containern in einen Behälter kann so konfiguriert werden, dass er automatisch oder manuell erfolgt. Wenn Sie "Automatisch" auswählen, weist die Anwendung den Container automatisch der ersten verfügbaren Position im Behälter zu.

Der Prozess "Behälter-Operationen (HPE)" soll zusätzliche Funktionen im Zusammenhang mit der Einzelwaferverfolgung (Element) bereitstellen, die in Kapitel 21 beschrieben ist.

Felddefinitionen der Seite "Behälter-Operationen (HPE)"

Diese Tabelle definiert die Felder der Seite "Behälter-Operationen (HPE)".

Feld

Definition

Typ

Behälter

Feld, um den Behälter anzugeben. Das Feld bietet eine Auswahl aller Behälter, die mit "Behälterpositionen aktivieren" mit einer definierten Positionszuordnung auf der Seite zur Modellierung der Behälterfamilie zugewiesen wurden.

Erforderlich

Laden/Entladen

Optionsfeld, das angibt, ob die Transaktion den Container der angegebenen Slot-Position zuweist (lädt) oder die Zuweisung aufhebt (entlädt). Wenn Sie "Laden" auswählen, wird der Container während der Ausführung der angegebenen Slot-Position zugewiesen. Wenn Sie dagegen "Entladen" auswählen, wird die Zuweisung des Containers zur angegebenen Slot-Position während der Ausführung aufgehoben.

Optional

Manuell/Automatisch

Gibt an, wie Container der Slot-Position zugewiesen werden. Standardmäßig verwendet die Anwendung "manuell", in welchem Fall Sie die Position für jeden zu ladenden oder zu entladenden Container auswählen müssen. "Automatisch" ist nur für die Transaktion "Laden" verfügbar. Durch Auswahl von "Automatisch" wählt die Anwendung automatisch die erste verfügbare Position aus.

Optional

Behältercontainer

Gibt den Behältercontainer an, der derzeit mit dem Container verknüpft ist. Die Anwendung zeigt den zugewiesenen Behältercontainer an, wenn er bereits zugewiesen wurde. Andernfalls erstellt die Anwendung bei der Übergabe automatisch einen neuen Behältercontainer.

Ein OOB-Behälter (Out-of-the-Box) kann nur mit einem einzelnen Container verknüpft werden. Ein OOB-Container kann mit mehr als einem OOB-Behälter verknüpft werden. Wenn der Behälter mit einer Behälterfamilie konfiguriert ist und Positionen definiert sind, kann der Behälter nur mit einem Behälter verknüpft werden.

Nur Anzeige

Slot-Position

Slot-Position, der der Container zugewiesen werden soll. Das Feld bietet Listen aller verfügbaren Slot-Positionen.

Hinweis: Das Feld wird deaktiviert, wenn "Entladen" ausgewählt ist. Das Feld wird auch deaktiviert, wenn "Automatisch" ausgewählt ist, da die Anwendung den Container automatisch dem ersten verfügbaren Slot zuweist.

Optional

Container

Container oder Los, der/das in eine Position geladen oder aus einer Position entladen werden soll. Wenn Sie einen Containerwert in dieses Feld eingeben, wird die Spalte "Container" in der Tabelle "Detailauswahl" automatisch ausgefüllt.

Optional

Behältercontainer schließen

Kontrollkästchen, um Behältercontainer ohne Kind-Container zu schließen oder zu beenden. Wenn Sie einen Behältercontainer mit zugeordnetem Kind-Container schließen möchten, müssen Sie zuerst alle Kind-Container entladen. Nach dem Schließen des Behältercontainers können Sie einen neuen Behälter mit demselben Behältercontainernamen erstellen.

Hinweis: Diese Funktion gilt als optional, da Behältercontainer unter bestimmten Prozessbedingungen automatisch geschlossen werden.

Optional

Behälter übertragen

Zielbehälter, in den alle Container übertragen werden sollen. Wenn Sie dieses Feld auswählen, können alle Container vom aktuellen Behälter zum Zielbehälter transferiert werden. Sie können alle Container nur in einen leeren Behälter ohne zugewiesene Slot-Position übertragen.

Hinweis: Weitere Informationen finden Sie unter "Definieren von Behälterfamilien" im Opcenter Execution Semiconductor Modeling-Handbuch.

Optional

Detailauswahl

Positionsnummer

Sequenzieller Bezeichner der physischen Position des Behälters. Die Anzeige der Positionsnummer basiert auf dem Feld "Positionsmethode", das auf der Seite zur Modellierung der Behälterfamilie festgelegt wurde. Wenn die Positionsmethode "Numerisch" ist, ist die Anzeige 1,2,3... Wenn dagegen "Vektor" ausgewählt ist, ist die Anzeige 1.2.2, 1.2.3 usw.

Nur Anzeige

Positionsebene

Vertikale Position des Loses in einem Behälter oder Z-Position. Der Wert wird im Feld "Z-Positionen" auf der Seite "Behälterfamilie" definiert.

Nur Anzeige

Positionsstatus

Status der Positionsverfügbarkeit, entweder "verfügbar" oder "nicht verfügbar".

Nur Anzeige

Einrichtungsaktion

Einrichtung von "Laden" oder "Entladen". Standardmäßig ist die Spalte leer, bis Container eingegeben werden.

Nur Anzeige

Container

Name des Containers, der dem Behältercontainer zugeordnet werden soll oder dessen Zuordnung abgetrennt werden soll.

Nur Anzeige

Produktionsauftrag

Dem Container zugeordneter Produktions- oder Arbeitsauftrag.

Nur Anzeige

Produkt

Dem Container zugeordnete(s) Produkt oder PN.

Nur Anzeige

Vorgehensweise zum Laden von Containern über die Seite "Behälter-Operationen (HPE)"

Gehen Sie folgendermaßen vor, um das Laden von Container in die Slot-Position eines Behälters auf der Seite "Behälter-Operationen (HPE)" durchzuführen:

1. Greifen Sie auf die Seite Behälter-Operationen (HPE) über das Menü "Behälter" zu.
2. Wählen Sie im Dropdown-Feld Behälter einen Behälter aus. Das Feld bietet eine Auswahl aller Behälter, die mit "Behälterpositionen aktivieren" mit einer definierten Positionszuordnung auf der Seite zur Modellierung der Behälterfamilie zugewiesen wurden.
3. Wählen Sie Laden aus. Weitere Informationen zu diesem Feld finden Sie unter "Felddefinition der Seite 'Behälter-Operationen'".
4. Sie können "Manuell" oder "Automatisch" auswählen. Standardmäßig ist "Manuell" ausgewählt, was zur Auswahl des Felds "Slot-Position" erforderlich ist. Wenn Sie "Automatisch" auswählen, wählt die Anwendung automatisch die erste verfügbare Position aus.
5. Wählen Sie die Slot-Position aus, in die der Container geladen werden soll. Wenn "Automatisch" ausgewählt ist, wird die Slot-Position automatisch zugewiesen.
6. Geben Sie den Containernamen in das Feld Container ein. Die Tabelle "Detailauswahl" füllt den eingegebenen Containernamen in der Spalte "Container" automatisch aus.
7. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
Vorgehensweise zum Entladen von Containern über die Seite "Behälter-Operationen (HPE)"

Gehen Sie folgendermaßen vor, um das Entladen von Containern aus der Slot-Position des Behälters auf der Seite "Behälter-Operationen (HPE)" durchzuführen:

1. Greifen Sie auf die Seite Behälter-Operationen (HPE) über das Menü "Behälter" zu.
2. Wählen Sie im Dropdown-Feld Behälter einen Behälter aus. Das Feld bietet eine Auswahl aller Behälter, die mit "Behälterpositionen aktivieren" mit einer definierten Positionszuordnung auf der Seite zur Modellierung der Behälterfamilie zugewiesen wurden.
3. Wählen Sie Entladen aus. Weitere Informationen zu diesem Feld finden Sie unter "Felddefinition der Seite 'Behälter-Operationen'".
4. Geben Sie im Feld Container den Containernamen ein, den Sie aus dem Behälter entladen möchten. Nach der Eingabe füllt die Anwendung "Entladen" in der Spalte "Einrichtungsaktion" in der Tabelle "Detailauswahl" aus.
5. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
Vorgehensweise zum Entladen aller Behälter-Container über die Seite "Behälter-Operationen (HPE)"

Gehen Sie folgendermaßen vor, um alle Container über die Seite "Behälter-Operationen (HPE)" aus einem Behälter zu entladen:

1. Greifen Sie auf die Seite Behälter-Operationen (HPE) über das Menü "Behälter" zu.
2. Wählen Sie im Dropdown-Feld Behälter einen Behälter aus. Die Feldliste enthält alle Behälter, die mit der Option "Behälterpositionen aktivieren" konfiguriert wurden und für die auf der Seite zur Modellierung der Behälterfamilie eine Positionszuordnung konfiguriert ist. Um "Alle entladen" auszuführen, müssen alle Slot-Positionen innerhalb des Behälters mit Containern belegt sein.
3. Klicken Sie im Befehlsmenü auf die Schaltfläche Alle entladen.
4. Klicken Sie im Popup "Bestätigungsmeldung" auf Ja. Die Anwendung zeigt eine Erfolgsmeldung an.
Vorgehensweise zum Schließen von Behälter-Containern beim Ausführen von "Alle entladen" über die Seite "Behälter-Operationen (HPE)"

Gehen Sie folgendermaßen vor, um Behälter-Container auf der Seite "Behälter-Operationen (HPE)" zu schließen:

1. Greifen Sie auf die Seite Behälter-Operationen (HPE) über das Menü "Behälter" zu.
2. Wählen Sie im Dropdown-Feld Behälter einen Behälter aus. Die Feldliste enthält alle Behälter, die mit der Option "Behälterpositionen aktivieren" konfiguriert wurden und für die in der Behälterfamilie eine Positionszuordnung konfiguriert ist.
3. Aktivieren Sie das Kontrollkästchen Behälter-Container schließen. Um "Container schließen" beim Ausführen von "Alle entladen" durchzuführen, müssen alle Slot-Positionen innerhalb des Behälters ausgefüllt sein.
4. Klicken Sie im Befehlsmenü auf die Schaltfläche Alle entladen.
5. Klicken Sie im Popup "Bestätigungsmeldung" auf Ja. Die Anwendung zeigt eine Erfolgsmeldung mit dem Text "'Alle entladen' wurde erfolgreich für den angegebenen Behälter ausgeführt. Der Behälter-Container wurde erfolgreich geschlossen."
Vorgehensweise zum Übertragen aller Container von einem Behälter in einen anderen Behälter

Gehen Sie folgendermaßen vor, um alle Container von einem Behälter über die Seite "Behälter-Operationen (HPE)" in einen anderen Behälter zu übertragen:

1. Greifen Sie auf die Seite Behälter-Operationen (HPE) über das Menü "Behälter" zu.
2. Wählen Sie im Dropdown-Feld Behälter einen Behälter aus. Das Feld bietet eine Auswahl aller Behälter, die mit "Behälterpositionen aktivieren" mit einer definierten Positionszuordnung auf der Seite zur Modellierung der Behälterfamilie zugewiesen wurden.
3. Wählen Sie den Zielbehälter, den Sie übertragen möchten, im Feld Behälter übertragen aus.
4. Wenn Sie den ausgewählten Behälter nach der Ausführung aller Übertragungen schließen möchten, können Sie das Kontrollkästchen Behältercontainer aktivieren aktivieren.
5. Klicken Sie in der Befehlsleiste auf die Schaltfläche Alle übertragen. Die Anwendung zeigt eine Erfolgsmeldung an.
