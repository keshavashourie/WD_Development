Losverpackung

Auf Registerkarte "Losverpackung" können Sie die Schachtelmengen für ein Los festlegen.

Felddefinitionen der Registerkarte "Losverpackung"

Diese Tabelle definiert die Felder auf der Registerkarte "Losverpackung".

Feld

Definition

Detaildatentabelle

Liste der im Zeitplan für eine Vereinigung verfügbaren Lose.

Tabelle "Packanweisungen"

Liste der im Zeitplan festgelegten Packanweisungen.

Verpackungstyp

Wird verwendet, um die Menge pro Schachtel zu berechnen.

Verpackungsgröße (Menge pro Schachtel)

Anzahl der Elemente, die in einer Schachtel verpackt werden. Diese Informationen werden in der Matrix "Verpackungsmenge" festgelegt.

Anzahl von Schachteln

Die von der Anwendung berechnete Anzahl von Schachteln.

Teilschachtelmenge

Die von der Anwendung berechnete Anzahl von Elemente, die in die letzte Schachtel gepackt werden.

Teilschachtelnummer

Die von der Anwendung berechnete Zahl für das letzte Feld.

Verpackungsmenge

Die von der Anwendung berechnete Anzahl von Elementen (aus allen Losen), die zu verpacken sind.

Gesamte Losmenge

Die von der Anwendung berechnete Gesamtmenge aller ausgewählten Lose.
