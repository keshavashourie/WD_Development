Job erstellen

Der Vorgesetzte verwendet die Transaktion "Job erstellen", um einen Job zu erstellen. Auf diese Transaktion kann direkt oder über die Seite "Jobs für Vorgesetzten" zugegriffen werden. Durch Klicken auf die Schaltfläche "Job erstellen" wird das Popup "Job erstellen" geöffnet.

Informationen zu "Einfacher Modus"

"Einfacher Modus" ist ein Kontrollkästchen, das auf der Objektseite "Jobmodell" und auf der Transaktionsseite "Job erstellen" verfügbar ist. Jobs, die für den einfachen Modus konfiguriert sind, werden von der Transaktion "Jobfortschritt" anders verarbeitet. Nachdem die erste konfigurierte Stufe abgeschlossen ist, geht die Transaktion direkt zur letzten konfigurierten Stufe weiter.

Beim Konfigurieren eines Jobs für den einfachen Modus

Damit der einfache Modus erwartungsgemäß funktioniert, muss Folgendes zutreffen:

• Im letzten konfigurierten Schritt muss "Beendet erlauben" aktiviert sein.
• Entweder der erste oder der letzte Schritt muss so konfiguriert sein, dass er Symptomcode, Ursachencode und Reparaturcode erfordert.

Felddefinitionen des Popups "Job erstellen"

Diese Tabelle definiert die Felder im Popup "Job erstellen".

Feld

Definition

Typ

Ressource

Ausrüstung, Werkzeug, Maske oder ein anderes Nicht-Materialelement, das im Fertigungsprozess verwendet wird. In diesem Zusammenhang ist dies der eindeutige Name der Ressource, für die der Job erstellt wird.

Erforderlich

Jobauftrag

ID des Jobauftrags.

Optional

Jobmodell

Jobmodell, auf dem der Job basiert. Das "Jobmodell"-Objekt ist das Element, in dem die Schritte konfiguriert sind.

Optional

Einfacher Modus

Im einfachen Modus ist die Transaktion "Jobfortschritt" der erste konfigurierte Schritt. Wenn dieser Schritt abgeschlossen ist, wechselt die Transaktion zum letzten konfigurierten Schritt. Das Kontrollkästchen "Einfacher Modus" kann auf den Seiten "Jobmodell" und "Job erstellen" aktualisiert werden.

Optional

Zusätzliche Informationen ausblenden

Schaltfläche, über die alle Felder außer "Ressource", "Jobauftrag", "Jobmodell" und "Einfacher Modus" ausgeblendet oder angezeigt werden.

Optional

Phase

Jobschritt. In diesem Zusammenhang ist die ausgewählte Stufe (Phase) der erste Schritt, der auf der Seite "Jobfortschritt" angezeigt wird. Hat als Standardwert den ersten konfigurierten Jobschritt.

Optional

Entwicklung der Umformstufen

Sequenzielle Reihenfolge der ausgewählten Stufe. Wird automatisch auf Basis der ausgewählten Stufe gefüllt.

Nur Anzeige

Tabelle "Techniker"

Liste der Techniker, die dem Jobauftrag zugewiesen sind. Diese können in "Job erstellen" überschrieben werden.

Optional

Kommentare

Unformatierter Textbereich zum Hinzufügen von Informationen.

Optional

Vorgehensweise zum Erstellen eines Jobs

Gehen Sie folgendermaßen vor, um einen Job zu erstellen:

1. Rufen Sie die Seite "Jobs für Vorgesetzten" auf.
2. Klicken Sie auf Fertigungsaktionen. Eine Transaktionsliste wird angezeigt.
3. Klicken Sie auf Job erstellen. Das Popup "Job erstellen" wird angezeigt.
4. Wählen Sie Ressource aus. Ist ein Job für die ausgewählte Ressource vorhanden, zeigt die Anwendung den neuesten Jobauftrag und das neueste Jobmodell an und befüllt damit eine Feldliste.
5. Stellen Sie sicher, dass Jobauftrag die richtige Jobauftragsnummer enthält oder ist leer.
6. Wählen Sie das Jobmodell aus.
7. Aktivieren oder deaktivieren Sie ggf. Einfacher Modus.
8. Klicken Sie in der Tabelle "Techniker" auf den Technikernamen (oder den leeren Bereich, in dem der Name stehen soll). Wählen Sie den Techniker im aktivierten Feld aus.
9. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
10. Klicken Sie auf Job erstellen. Eine Statusmeldung wird angezeigt. Die Meldung enthält die Jobauftrag-ID, sofern eine erstellt wurde. Das Popup wird geschlossen.
