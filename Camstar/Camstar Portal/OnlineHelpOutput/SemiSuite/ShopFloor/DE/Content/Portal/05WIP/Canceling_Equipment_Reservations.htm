Abbrechen von Ausrüstungsreservierungen

Auf der Seite "Ausrüstungsreservierung abbrechen" können Sie Ausrüstungsreservierungen abbrechen.

Felddefinitionen der Seite "Ausrüstungsreservierung abbrechen"

Diese Tabelle definiert die Felder auf der Seite "Ausrüstungsreservierung abbrechen".

Feld

Definition

Auswahl-ID

Feld, um das Los anzugeben, für das die Ausrüstungsreservierung abgebrochen werden soll.

Tabelle "Lose"

Schreibgeschützte Tabelle mit einer Liste der ausgewählten oder eingegebenen Lose.

Spalte, in der ein Pfeil angezeigt wird, wenn die Zeile ausgewählt ist.

Los

Das ausgewählte oder eingegebene Los.

Produkt

Produkt.

Prozessspez.

Die Prozessspezifikation für das Los.

Aktueller Schritt

Die aktuelle Spezifikation des Loses.

Ist erforderlich

Kontrollkästchen, das angibt, ob die Auswahl der Ausrüstung erforderlich ist.

Tabelle "Reservierte Ausrüstungen"

Schreibgeschützte Tabelle mit einer Liste der für das ausgewählte oder eingegebene Los reservierten Ausrüstung.

Schritt

Arbeitsplan und Schritt, in denen die Reservierung erfolgt.

Reservierte Ausrüstung

ID der reservierten Ausrüstung.

Ist erforderlich

Gibt an, ob die reservierte Ausrüstung die einzig zulässige Auswahl für den Operator ist, der den Umlaufbestandsschritt verarbeitet.

Reserviert durch

Benutzer, der die Ausrüstung reserviert hat.

Vorgehensweise zum Abbrechen einer Ausrüstungsreservierung

Gehen Sie folgendermaßen vor, um eine Ausrüstungsreservierung abzubrechen:

1. Rufen Sie die Seite "Ausrüstungsreservierung abbrechen" auf. (Position und Beschriftung hängen von der jeweiligen Menükonfiguration ab.)
2. Geben Sie das Los an. Das Los wird in der Tabelle "Lose" direkt unter der Auswahl-ID angezeigt. Alle vorhandenen Ausrüstungsreservierungen für das Los werden in der Tabelle links unten angezeigt.
3. Wählen Sie die Zeile mit der Reservierung aus, die Sie abbrechen möchten. In der ersten Spalte der ausgewählten Zeile wird ein Pfeil nach rechts angezeigt und die Zeile wird hervorgehoben.
4. Klicken Sie auf den Papierkorb in der Symbolleiste der Tabelle. Die Zeile wird aus der Tabelle entfernt.
5. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
