Testkorrelation

"Testkorrelation" wird verwendet, um den Abschluss der Korrelationsprüfung festzuhalten, die für Ausrüstung, Masken und Werkzeuge vorgenommen wurde. Korrelationsprüfung wird in "Ausrüstungseinrichtung" und "Umlaufbestandsnachverfolgung" angegeben.

Hinweis: "Testkorrelation" verfolgt nicht den Korrelationsprozess, sondern schließt das Testen einer Korrelation ab, indem die Zähler zurückgesetzt werden, damit Losverarbeitung für die Ausrüstung, die Maske oder das Werkzeug erlaubt wird.

Beim Verwenden von "Testkorrelation"

Die folgenden Typen sind die Typen einer Korrelationsprüfung:

• Zeit – Korrelationsprüfung ist für jedes angegebene Zeitlimit erforderlich.
• Einrichtung – Korrelationsprüfung ist erforderlich, wenn ein Parameter oder Werkzeug aktualisiert wird.
• Schicht – Korrelationsprüfung ist für jede Schicht erforderlich.

"Testkorrelation" wird für alle Typen in einer Transaktion ausgeführt. Sie können eine Korrelationsprüfung auch ausführen, wenn für keinen der erforderlichen Typen die Limits überschritten wurden.

"Testkorrelation" wird für folgende Vorgänge verwendet:

• Ausrüstungseinrichtung – Die Anwendung überprüft die Einrichtungskorrelation, wenn ein Parameter (für den "Einrichtungskorrelation erforderlich" aktiviert ist) oder ein Werkzeug aktualisiert wird.
• Einbringen von Losen – Die Anwendung überprüft alle Korrelationstypen. Sie können ein Los nicht einbringen, wenn eine der folgenden Bedingungen zutrifft:
• Das letzte Korrelationsdatum hat das angegebene Zeitkorrelationslimit überschritten.
• Einrichtungskorrelation wurde im Verlauf von "Ausrüstungseinrichtung" festgelegt.
• Eine Schichtkorrelation wurde verfehlt.

Felddefinitionen der Seite "Testkorrelation"

Diese Tabelle definiert die Felder auf der Seite "Testkorrelation".

Feld

Definition

Typ

Ausrüstung

Ressource (Ausrüstung, Maske oder Werkzeug), für die eine Korrelationsprüfung ausgeführt werden soll. Die Ressource:

• Darf kein Los verarbeiten.
• Muss mindestens einen Korrelationstest erfordern.

Erforderlich

Mitarbeiter

Mitarbeiter, der diese Transaktion ausführt, wenn er nicht der derzeit angemeldete Benutzer ist.

Optional

Korrelationsmarkierung

Kennzeichnet den Korrelationsstatus für die Ressource. Gültige Werte sind:

• 0 – Korrelationsprüfung ist nicht erforderlich.
• 1 – Korrelationsprüfung ist erforderlich und es dürfen Lose in die Ausrüstung eingebracht werden.
• 2 – Korrelationsprüfung ist erforderlich, aber es dürfen KEINE Lose in die Ausrüstung eingebracht werden.

Optional

Vorgehensweise zum Durchführen von Testkorrelation für eine Ressource

Gehen Sie folgendermaßen vor, um Testkorrelationen durchzuführen:

1. Öffnen Sie die Seite "Testkorrelation".
2. Geben Sie den Ressourcennamen in das Feld Ausrüstung ein. Die Anwendung zeigt die Korrelationsdetails für die Ressource an.
3. Geben Sie die Anzahl der Korrelationsguteinheiten, die für die Ausrüstung erforderlich sind, in das Feld Guteinheiten ein.
4. Wählen Sie Korrelation abgeschlossen (Bestanden) aus.
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
