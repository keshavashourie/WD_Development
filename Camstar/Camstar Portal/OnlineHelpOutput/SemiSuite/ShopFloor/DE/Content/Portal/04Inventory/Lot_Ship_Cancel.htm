Losversand abbrechen

"Losversand abbrechen" ist eine Lagerbestandstransaktion, die im Lagerbestandstyp verfügbar ist, z. B. "Die-Bank | Losversand abbrechen". Auf der Seite "Losversand abbrechen" können Sie versendete Lose erneut aktivieren und/oder den Empfangsstandort per E-Mail informieren.

Felddefinitionen der Seite "Losversand abbrechen"

Diese Tabelle definiert die Felder auf der Seite "Losversand abbrechen".

Feld

Definition

Typ

Auswahl-ID

ID für ein Los, einen Behälter, einen Batch oder einen Ausrüstungsgegenstand.

Erforderlich

Mitarbeiter

Mitarbeiter, der diese Transaktion ausführt, wenn er nicht der derzeit angemeldete Benutzer ist.

Optional

Lose

Los-ID.

Optional

E-Mail überspringen

Kontrollkästchen, das angibt, ob die E-Mail-Benachrichtigung übersprungen werden soll. Die Anwendung sendet automatisch eine E-Mail an alle Empfänger in der E-Mail-Gruppe, die für die Empfängerfabrik konfiguriert ist, wenn dieses Kontrollkästchen nicht aktiviert ist.

Optional

Los erneut aktivieren

Kontrollkästchen, das angibt, ob das Los erneut aktiviert werden soll. Das Los wird in den Status "Aktiv" versetzt, wenn dieses Kontrollkästchen aktiviert ist.

Hinweis: Dieses Kontrollkästchen muss ausgewählt werden, wenn das Kontrollkästchen "E-Mail überspringen" aktiviert ist. Dadurch wird gewährleistet, dass mindestens eine Aktion durchgeführt wird, wenn eine Sendung abgebrochen wird – E-Mail senden und/oder Los erneut aktivieren.

Optional

Tabelle, in der Attribute aufgelistet werden, die über die Matrix "Serviceattribute: Einrichtung" für die aktuelle Transaktion konfiguriert sind. Die Attributwerte können direkt in der Tabelle geändert werden.

Vorgehensweise zum Durchführen der Transaktion "Losversand abbrechen"

Gehen Sie folgendermaßen vor, um die Transaktion "Losversand abbrechen" durchzuführen:

1. Rufen Sie die Seite "Losversand abbrechen" für den entsprechenden Lagerbestandstyp auf.
2. Wählen Sie über das Feld Auswahl-ID mindestens ein Los aus. Die Anwendung füllt die Tabelle "Lose" mit Informationen für das ausgewählte Los.
3. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
4. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
