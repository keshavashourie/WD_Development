Ausrüstung für Los reservieren

Auf der Seite "Ausrüstung für Los reservieren" können Sie Ausrüstung für die Verarbeitung eines Loses für einen oder mehrere angegebene Schritte reservieren.

Beim Reservieren von Ausrüstung

Es gelten folgende Ausrüstungsreservierungsregeln:

1. Reservierungen müssen auf Arbeitsplanschrittebene erfolgen.
2. Lose müssen das gleiche Produkt und den gleichen Arbeitsplan aufweisen, wenn Ausrüstung für mehrere Lose reserviert wird.
3. Reservierungen können nicht geändert werden, wenn der Schritt in der Umlaufbestandsverarbeitung aktiv ist.
4. Es kann nur ein Ausrüstungselement pro Schritt reserviert werden. Die Anwendung ersetzt die reservierte Ausrüstung mit der neu reservierten Ausrüstung, wenn Sie Ausrüstung zu einem Schritt hinzufügen, für den bereits eine Ausrüstung reserviert ist.

Sie können bestimmen, ob Ausrüstung optional oder erforderlich ist, wenn Sie Ausrüstung für Lose reservieren. Der Benutzer muss die empfohlene Ausrüstung auswählen, wenn die reservierte Ausrüstung erforderlich ist. Der Benutzer kann eine andere Ausrüstung auswählen, wenn die reservierte Ausrüstung optional ist. Die Anwendung zeigt eine Warnmeldung an, wenn der Benutzer Ausrüstung auswählt, die nicht empfohlen wurde.

Sie können eine Liste der Reservierungen für die bevorzugte Ausrüstung anzeigen, wenn Sie Ausrüstung reservieren. Die Anwendung zeigt eine Liste der betreffenden Reservierungen an, wenn Sie Schritt und Ausrüstung eingeben. Die Reservierungen werden in der Tabelle unten rechts auf der Seite angezeigt.

Hauptumlaufbestand - Erweitert – Reservierte Ausrüstung – Kachelnachrichten

Die Seite "Hauptumlaufbestand - Erweitert" zeigt Aktivitätsnachrichten an, die darauf hinweisen, dass für das Los Ausrüstung reserviert ist. Der Benutzer wählt die Ausrüstung abhängig von der Nachricht auf der Kachel aus.

Die Kachel "Reservierte Ausrüstung" wird in der Phase "Einbringen" als optional angezeigt, wenn die Ausrüstung nicht als erforderlich festgelegt wurde. Die Kachel wird in der Phase "Einbringen" als erforderlich angezeigt, wenn die Ausrüstung als erforderlich festgelegt wurde.

Vorgehensweise zum Reservieren von Ausrüstung für ein Los

Gehen Sie folgendermaßen vor, um Ausrüstung für ein einzelnes Los zu reservieren:

1. Wählen Sie in der primären Navigationsleiste Ausrüstung für Los reservieren aus. (Position und Beschriftung hängen von der jeweiligen Menükonfiguration ab.) Die Seite "Ausrüstung für Los reservieren" wird angezeigt.
2. Geben Sie das Los an. Das Los wird in der Tabelle "Lose" direkt unter der Auswahl-ID angezeigt. Alle vorhandenen Ausrüstungsreservierungen für das Los werden in der Tabelle links unten angezeigt.
3. Wählen Sie den Schritt aus.
4. Wählen Sie die Ausrüstung aus. Alle vorhandenen Reservierungen für das ausgewählte Ausrüstungselement werden in der Tabelle rechts unten angezeigt.
5. Wählen Sie Ist erforderlich aus, um diese Ausrüstung als einzige Option in der Ausrüstungsliste für die Umlaufbestandsverarbeitung festzulegen. Lassen Sie dieses Kontrollkästchen deaktiviert, um die Auswahl einer anderen Ausrüstung zu ermöglichen, wobei eine entsprechende Warnmeldung angezeigt wird.
6. Klicken Sie auf Abschicken.

Vorgehensweise zum Reservieren von Ausrüstung für mehrere Lose

Gehen Sie folgendermaßen vor, um Ausrüstung für mehrere Lose zu reservieren:

1. Rufen Sie die Seite Ausrüstung für Los reservieren auf.
2. Geben Sie die einzelnen Lose an. Die Lose werden in der Tabelle "Lose" unter der Auswahl-ID angezeigt. Alle vorhandenen Ausrüstungsreservierungen für die Lose werden in der Tabelle links unten angezeigt.
3. Wählen Sie den Schritt aus.
4. Wählen Sie die Ausrüstung aus. Alle vorhandenen Reservierungen für das ausgewählte Ausrüstungselement werden in der Tabelle rechts unten angezeigt.
5. Wählen Sie Ist erforderlich aus, um diese Ausrüstung als einzige Option in der Ausrüstungsliste für die Umlaufbestandsverarbeitung festzulegen. Lassen Sie dieses Kontrollkästchen deaktiviert, um die Auswahl einer anderen Ausrüstung zu ermöglichen, wobei eine entsprechende Warnmeldung angezeigt wird.
6. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
