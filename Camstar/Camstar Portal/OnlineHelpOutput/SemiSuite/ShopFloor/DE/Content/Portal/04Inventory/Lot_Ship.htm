Losversand

"Losversand" ist eine Lagerbestandstransaktion, die im Lagerbestandstyp verfügbar ist, z. B. "Die-Bank | Losversand". Auf der Seite "Losversand" können Sie aktive Lose versenden oder versandte Lose an eine andere Fabrik neu versenden. Ein Los wird nach dem Versand bis zum Empfang an der Zielfabrik als "Unterwegs" markiert.

Informationen zu Dokumentnummern und Versandnummern

Eine Empfängerfabrik kann mit einer oder mehreren Kombinationen von "Absenderspez." und "Empfängerprozess" konfiguriert werden. Für jede Kombination gibt es jeweils ein entsprechendes Kontrollkästchen "Los ist abgeschlossen". Ein leeres Kontrollkästchen bedeutet, dass Lose nicht abgeschlossen sind und zur weiteren Verarbeitung an eine andere Fabrik versendet werden müssen, wenn sie von der betreffenden Spezifikation mit diesem Prozess versendet werden. Die Transaktion "Losversand" erfordert in solchen Fällen eine Dokumentnummer und eine Versandnummer.

Vorgehensweise zum Durchführen der Transaktion "Losversand"

Gehen Sie folgendermaßen vor, um die Losversandtransaktion durchzuführen:

1. Rufen Sie die Seite "Losversand" für den entsprechenden Lagerbestandstyp auf.
2. Wählen Sie über das Feld Auswahl-ID mindestens ein Los aus. Die Anwendung füllt die Tabelle "Lose" mit Informationen für das ausgewählte Los.
3. Wählen Sie eine Empfängerfabrik aus.
4. Wählen Sie einen Empfängerprozess aus.
5. Klicken Sie auf das Symbol für das Feld Dokumentnummer, damit automatisch eine Dokumentnummer erstellt wird. Geben Sie andernfalls eine Dokumentnummer ein, wenn für die Sendung eine Dokumentnummer erforderlich ist.
Hinweis: Sie können das Feld leer lassen, wenn Sie sich nicht sicher sind, ob das Feld erforderlich ist. Nach dem Klicken auf Abschicken werden Sie dann ggf. aufgefordert, einen Wert einzugeben.
6. Geben Sie eine Versandnummer ein, wenn für die Sendung eine Versandnummer erforderlich ist.
Hinweis: Sie können das Feld leer lassen, wenn Sie sich nicht sicher sind, ob das Feld erforderlich ist. Nach dem Klicken auf Abschicken werden Sie dann ggf. aufgefordert, einen Wert einzugeben.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
Hinweis: Die Anwendung zeigt eine entsprechende Eingabeaufforderung an, wenn eine erforderliche Dokumentnummer oder Versandnummer nicht angegeben wurde.
