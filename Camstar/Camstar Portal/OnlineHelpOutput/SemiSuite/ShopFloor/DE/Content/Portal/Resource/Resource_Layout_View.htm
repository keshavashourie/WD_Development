Ressourcenlayoutansicht

Auf der Seite "Ressourcenlayoutansicht" werden eine grafische Ansicht der Statusinformationen für eine ausgewählte Ressource und ein Menü mit den Transaktionen angezeigt, die Sie für die Ressource ausführen können.

Modellieren des Ressourcenlayouts

Sie müssen die folgenden Objekte modellieren, bevor Sie "Ressourcenlayoutansicht" verwenden:

• Ausrüstung
• Ressourcenlayout

Im Opcenter Execution Semiconductor Modeling-Benutzerhandbuch finden Sie Informationen zu Modellierungsobjekten.

Ressourcenstatus

Die Anwendung zeigt den Status der Ressourcen durch Farbe an. In dieser Tabelle werden die Ressourcensymbole nach Farbe gezeigt und wird die Bedeutung jeder Farbe erläutert.

Symbol

Status

Ressource ist aktiv und führt aktuell eine Verarbeitung aus.

Ressource ist nicht aktiv und kann nicht verwendet werden.

Ressource ist im Bereitschaftsmodus und kann verwendet werden.

Felddefinitionen der Seite "Ressourcenlayoutansicht"

Diese Tabelle definiert die Felder auf der Seite "Ressourcenlayoutansicht".

Feld

Definition

Typ

Ressourcenlayout

Das anzuzeigende Ressourcenlayout.

Erforderlich

Ressource

Ressource im Ressourcenlayout, die verarbeitet werden soll.

Erforderlich

Aktualisierungsintervall

Intervall (in Sekunden), in dem der Status der angezeigten Ressourcen aktualisiert werden soll.

Optional

Vorgehensweise zum Ausführen von Transaktionen für Ressourcen

Gehen Sie folgendermaßen vor, um Transaktionen für Ressourcen auszuführen:

1. Öffnen Sie die Seite "Ressourcenlayoutansicht". Die Seite "Ressourcenlayoutansicht" wird angezeigt.
2. Geben Sie den Namen des Ressourcenlayouts in das Feld Ressourcenlayout ein. Die Anwendung zeigt das Ressourcenlayout an.
3. Wählen Sie im Feld Ressource die Ressource aus, für die Sie die Transaktion ausführen möchten. Die Anwendung zeigt die Transaktionen, die Sie ausführen können, im Abschnitt "Fertigungsaktionen" an.
4. Klicken Sie im Abschnitt Fertigungsaktionen auf eine der folgenden Optionen, um Transaktionsdaten entsprechend den Anforderungen Ihres Unternehmens einzugeben:
