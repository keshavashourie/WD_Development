Los gestalten anhand von Elementen

Auf der Seite "Los gestalten anhand von Elementen" können Sie ein neues Waferlos erstellen, indem Sie mindestens einen Wafer aus mindestens einem vorhandenen Los abtrennen.

Feld, um eine Prozessspezifikation auszuwählen, mit der das Los geplant werden soll. Sie legt die auszuführenden Arbeitsplanschritte und alle Parameter und Variationen in Arbeitsplanschritten fest. Die Prozessspezifikation des Produktionsauftrags wird verwendet werden, wenn kein Wert für "Prozessspez." eingegeben wurde.

Vorgehensweise zum Gestalten eines neuen Waferloses aus mindestens einem vorhandenen Los

Gehen Sie folgendermaßen vor, um ein neues Waferlos aus mindestens einem vorhandenen Los zu gestalten:

1. Rufen Sie die Seite "Los gestalten anhand von Elementen" auf.
2. Wählen Sie im Feld Auswahl-ID mindestens ein Quelllos aus. Die Anwendung füllt die Tabelle "Details" mit Informationen für das ausgewählte Los. Darüber hinaus wird für jeden Wafer (jedes Element) in den ausgewählten Losen eine Zeile in die Tabelle "Elemente" eingetragen.
3. Aktivieren Sie in der ersten Spalte der Tabelle "Elemente" das Kontrollkästchen der Wafer, die in ein neues Los aufgeteilt werden sollen.
4. Geben Sie eine neue Los-ID ein. Dieses Feld befindet sich einige Zeilen unterhalb der Tabelle "Elemente".
5. Klicken Sie auf Zielelement-ID automatisch erstellen. Die Anwendung erstellt eine neue Element-ID für jeden Wafer, der in der Tabelle "Elemente" ausgewählt ist.
6. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
7. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
