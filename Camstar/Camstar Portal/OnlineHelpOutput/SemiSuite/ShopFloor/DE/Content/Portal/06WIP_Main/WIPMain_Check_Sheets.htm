Prüfblatt

Ein Prüfblatt wird für einen oder mehrere automatische Abläufe mit jeweils mindestens einer Aufgabe ausgeführt, die während der Umlaufbestandsverarbeitung durchgeführt werden soll. Ein Prüfblatt ist so konfiguriert, dass es für eine ausgewählte Spezifikation und Transaktion ausgeführt wird, z. B. Los einbringen, Los ausbringen oder Los abmelden.

Die Konfiguration von Prüfblättern für die Umlaufbestandsverarbeitung anstelle einzelner automatische Abläufe bietet folgende Vorteile:

• Spezielle Konfigurationsmöglichkeit für die Ebenen "Los einbringen", "Los ausbringen" und "Los abmelden"
• Möglichkeit abhängig vom Ergebnis der vom Operator durchgeführten Aufgaben, die weitere Bearbeitung zu sperren oder einen Arbeitsplan fortzusetzen

Anzeigen von Prozesstimern

Die Anwendung zeigt ein Uhrzeitfeld in der Nähe der rechten oberen Ecke der Seite an, wenn das ausgewählte Los einen aktiven Prozesstimer hat. Klicken Sie auf den Pfeil neben dem Wort "Timer", um die aktiven Prozesstimer für das Los anzuzeigen.

Im Opcenter Execution Core Shop Floor-Benutzerhandbuch finden Sie ausführliche Informationen zur Funktion "Prozesszeiterzwingung". Unter "Prozesszeiterzwingung" in diesem Handbuch werden verschiedene, für Opcenter Execution Semiconductor spezifische Aspekte dieser Funktion beschrieben.

Vorgehensweise zum Abarbeiten eines Prüfblatts

Gehen Sie folgendermaßen vor, um ein Prüfblatt abzuarbeiten:

1. Klicken Sie auf der Seite "Hauptumlaufbestand" auf Prüfblatt. Das Prüfblatt wird in einer neuen Registerkarte geöffnet. Die Anwendung füllt Los, Kopf, Aufgabenliste, Aufgabenbereich und Arbeitsbereich aus.
2. Verwenden Sie die standardmäßig ausgewählte Aufgabe oder wählen Sie eine andere Aufgabe aus. Diese Möglichkeit hängt davon ab, ob die Aufgabenliste und der automatische Ablauf eine sequentielle Verarbeitung vorschreiben.
3. Füllen Sie die benötigten Felder aus.
4. Führen Sie eine Anweisung, Berechnung oder Transaktion aus?

Eine Anweisungs- oder Berechnungs-Aufgabe

Klicken Sie auf Ausführen. Die Anwendung zeigt eine Erfolgsmeldung an und aktualisiert den Status und die Zähler in der Aufgaben-Kachel. Wenn die Mindestanzahl an Iterationen ausgeführt wurde, aktualisiert die Anwendung die Schriftfarbe in Anzahl entsprechend.

Eine Transaktionsaufgabe

Wenn die ausgewählte Aufgabe eine Transaktionsaufgabe ist, zeigt die Anwendung die Fertigungstransaktionsseite im Arbeitsbereich an. Ausführenwird durch eine Schaltfläche mit dem Namen der Transaktion ersetzt.

Wenn Sie auf die Transaktionsschaltfläche klicken, werden Transaktion und Aufgabe gleichzeitig ausgeführt. Die Anwendung zeigt eine Erfolgsmeldung an und aktualisiert den Status und die Zähler in der Aufgaben-Kachel. Wenn die Mindestanzahl an Iterationen ausgeführt wurde, aktualisiert die Anwendung die Schriftfarbe in Anzahl entsprechend.
5. Wiederholen Sie die Schritte 2-4, um die Aufgaben zu beenden.
