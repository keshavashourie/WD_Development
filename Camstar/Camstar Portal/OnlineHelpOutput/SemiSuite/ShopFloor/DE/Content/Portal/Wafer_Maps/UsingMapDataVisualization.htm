Verwenden der Seite "Visualisierung von Zuordnungsdaten"

Auf der Seite "Visualisierung von Zuordnungsdaten" können Sie den zuletzt übermittelten Satz von Gefäß-Codeergebnissen anhand der bereitgestellten Substrat-ID und Los-ID überprüfen und bearbeiten. Sie können eine Datenzuordnung anzeigen, eine Position in der Zuordnung zur visuellen Prüfung auswählen und die Position elektronisch mit einem Gefäß-Code "markieren". Die Anwendung zeigt Daten als eine farblich gekennzeichnete Rasterzuordnung an, um Defektverfolgung zu unterstützen, und ermöglicht es Ihnen, alle Gefäßeinsortierungsinformationen anzuzeigen, bevor die Informationen übermittelt werden.

Verwenden der Seite "Visualisierung von Zuordnungsdaten"

Der Abbildungsarbeitsbereich ist 1500 x 600 Pixel groß. Der maximale Pixelbereich für die Abbildung ist auf 8000 x 8000 Pixel beschränkt. Die Größe einer einzelnen Stelle (X, Y) in der Zuordnung hängt von der Gerätegröße der Zuordnung selbst ab. Die Anwendung verkleinert eine Zuordnung, behält aber die Proportionen der Zuordnung bei, wenn die Zuordnungsgröße den maximalen Arbeitsbereich der Abbildung überschreitet. Im Abbildungsarbeitsbereich kann gescrollt werden, wenn der Abbildungsbereich größer ist als der Arbeitsbereich.

Zuordnungslegende

Die Legende, die rechts neben den Zuordnungsdaten angezeigt wird, wird dynamisch anhand der Gefäß-Codes erstellt, die auf der Zuordnung zu finden sind.

Tabelle "Gefäß-Definitionsdetails"

Die Tabelle "Gefäß-Definitionsdetails" unter der Zuordnung ist standardmäßig reduziert. Wird die Tabelle erweitert, werden die aktuellen Gefäßdefinitionen der Zuordnung angezeigt.

Vorgehensweise zum Anzeigen einer gesamten Zuordnung in Vollansicht

Sie können eine Vollbildansicht der jeweiligen Zuordnung anzeigen, indem Sie auf "Vollbildansicht" klicken. Das Popup ist nur für Anzeigezwecke vorgesehen. Wenn Sie das Popup nicht mehr benötigen, klicken Sie auf "Schließen", um es zu schließen.

Vorgehensweise zum Aktualisieren von Gefäßeinsortierungsdaten

Gehen Sie folgendermaßen vor, um Gefäßeinsortierungsdaten zu aktualisieren:

1. Öffnen Sie die Seite Visualisierung von Zuordnungsdaten.
2. Geben Sie die Trägerschicht-ID ein.
3. Wählen Sie eine Los-ID aus, wenn die Trägerschicht-ID an mehrere Los-IDs gebunden ist.
4. Klicken Sie auf eine Stelle auf der Zuordnung. Die Anwendung zeigt das "X-Maß", das "Y-Maß" und den aktuellen Gefäß-Code für die ausgewählte Stelle an.
5. Geben Sie den Wert für Neuer Gefäß-Code ein.
6. Klicken Sie auf Zur Tabelle hinzufügen. Die Anwendung aktualisiert die Tabelle "Gefäß-Codeaktualisierungsdetails" mit den Daten in den Feldern direkt über der Tabelle, wozu auch der Wert von "Neuer Gefäß-Code" gehört.
7. Klicken Sie auf Abschicken. Die Anwendung sendet die Daten in der Tabelle "Gefäß-Codeaktualisierungsdetails" an den MapDataMaint-Dienst.
