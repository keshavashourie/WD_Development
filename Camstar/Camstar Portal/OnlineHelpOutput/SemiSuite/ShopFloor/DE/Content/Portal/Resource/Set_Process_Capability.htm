Prozessfähigkeit festlegen

Sie verwenden die Seite "Prozessfähigkeit festlegen", um Ausrüstung weitere Verarbeitungsfähigkeiten zuzuordnen. Fähigkeiten müssen der Anwendung hinzugefügt worden sein, bevor sie zugewiesen werden können. Dies erfolgt in der Modellierung über die Seite "Prozessfähigkeit". Hinweis: Ausrüstung, die aktiv ein Los verarbeitet, kann keine Prozessfähigkeit zugewiesen werden.

Vor der Verwendung der Seite "Prozessfähigkeit festlegen"

Prozessfähigkeiten müssen definiert sein, bevor sie zugewiesen werden können. Über die Modellierungsseite "Prozessfähigkeit" können Sie Prozessfähigkeiten definieren. Hinweis: Ausrüstung in aktiver Verarbeitung kann keine Prozessfähigkeit zugewiesen werden.

Vorgehensweise zum Festlegen von Prozessfähigkeit für Ausrüstung

Gehen Sie folgendermaßen vor, um Prozessfähigkeit für Ausrüstung festzulegen:

1. Öffnen Sie die Seite "Prozessfähigkeit festlegen".
2. Wählen Sie den Namen der Ausrüstung im Feld Ausrüstung aus. Die Anwendung zeigt in der Tabelle "Aktuelle Ausrüstung: Prozessfähigkeit" alle Prozessfähigkeiten an, die der ausgewählten Ausrüstung aktuell zugewiesen sind.
3. Klicken Sie in der Symbolleiste der Tabelle auf Neue Zeile hinzufügen. Eine Zeile wird in der Tabelle aktiviert.
4. Wählen Sie im Feld Prozessfähigkeit eine Prozessfähigkeit aus.
5. Aktivieren Sie das Kontrollkästchen Ist aktiviert, falls zutreffend.
6. Wiederholen Sie die Schritte 3 bis 5 für jede weitere Prozessfähigkeit, die Sie der Ressource zuweisen möchten.
7. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
8. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
