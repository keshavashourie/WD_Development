Ausrüstungsfeedereinrichtung

Feeder werden verwendet, um Komponenten in Maschinen, etwa Chip-Shooter und universelle GSM-Maschinen, zu laden. Jeder Feeder hält eine Rolle und wird in einem Maschinenslot platziert. Eine Maschine kann mehrere Komponenten erfordern und mehrere Slots haben. Eine weitere Möglichkeit zum Laden von Komponenten besteht darin, eine Feederbank zu verwenden. Die Feederbank enthält Slots, in die Feeder geladen werden. Die Bank wird an der Maschine angebracht.

Die Seite "Ausrüstungsfeedereinrichtung" ermöglicht es Ihnen, Feeder und Feederbänke in Ausrüstung zu laden.

Hinweis: Sie müssen mindestens einen Feeder auswählen. Es ist nicht möglich, nur eine Feederbank auszuwählen.

Vorgehensweise zum Einrichten eines Feeders für Ausrüstung

Gehen Sie folgendermaßen vor, um einen Feeder für eine Ressource einzurichten:

1. Wählen Sie die Ausrüstung im Feld Ausrüstung aus.
2. Wählen Sie einen Von Feeder aus.
3. Wählen Sie einen Von Feederslot aus.
4. Klicken Sie auf Hinzufügen. Die Anwendung verschiebt die ausgewählten Werte in die Tabelle "Ausrüst.-Feedermaterialien: Details".
5. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
6. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
