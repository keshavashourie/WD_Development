Containersuche in Opcenter Execution Semiconductor

Opcenter Execution Semiconductor verwendet eine leicht modifizierte Adaptation der Funktion für die Containersuche von Opcenter EX CR. In diesem Kapitel werden die Änderungen erläutert, die für Opcenter Execution Semiconductor vorgenommen wurden.

Änderungen für Opcenter Execution Semiconductor

Diese Suchkriterienfelder wurden hinzugefügt:

• Fabrik
• Prozessspez.
• Materialteil
• Materiallosname

Diese Felder wurden entfernt:

• Verbrauchter Container
• Verbrauchtes Containerprodukt
• Aus verbrauchtem Los
• Aus Verbrauchslagerort

Folgende Standard-Fertigungsaktionen wurden hinzugefügt:

• Losvereinigung
• Losvereinigung nach Wafern
• Los anhalten
• Los aufteilen
• Los: Attribute ändern
• Los: Elemente ändern
• Los nach Wafern aufteilen
• Losfreigabe
• Hauptumlaufbestand
Hinweis: Ein Systemadministrator kann über Portal Studio Standardaktionen hinzufügen.

Informationen zur Funktion für die Containersuche im Allgemeinen finden Sie im Opcenter Execution Core Shop Floor-Benutzerhandbuch. Informationen zum Hinzufügen von Standardaktionen finden Sie im Opcenter Execution Core Portal Studio 1.0-Benutzerhandbuch.
