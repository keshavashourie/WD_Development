Umlaufbestand zuordnen

Die Seite "Umlaufbestand zuordnen" ermöglicht es Ihnen, Eltern- und Kindlose erneut zu verbinden (zuzuordnen), die mit "Mehrstufiger Start" erstellt und während der Verarbeitung des Umlaufbestands abgetrennt wurden.

Felddefinitionen der Seite "Umlaufbestand zuordnen"

Diese Tabelle definiert die Felder auf der Seite "Umlaufbestand zuordnen".

Feld

Definition

Typ

Los

Die ID des Elternloses.

Erforderlich

Kindlos

Die ID eines Kindloses, das seinem Elternlos zugeordnet oder von diesem abgetrennt ist.

Optional

Tabelle "Kindlose zuweisen"

Tabelle für Kindlose.

Erforderlich

[Kontrollkästchen]

Kontrollkästchen zum Auswählen eines Kindloses, das zugeordnet werden soll.

Hinweis: Sie können das Kontrollkästchen in der Spaltenüberschrift der Tabelle aktivieren, um automatisch alle Kindlose auszuwählen. Mindestens ein Kindlos muss ausgewählt werden.

Optional

Kindlos

Die ID des Kindloses.

Nur Anzeige

Menge

Die Menge des Kindloses.

Nur Anzeige

X-Position

Die X- und die Y-Position, die für ein Kindlos angegeben wurden, werden entfernt, wenn das Los abgetrennt wird. Sie müssen die X-Position erneut eingeben, wenn Sie ein Kindlos zuweisen, das ursprünglich eine X-Position hatte.

Optional

Y-Position

Die X- und die Y-Position, die für ein Kindlos angegeben wurden, werden entfernt, wenn das Los abgetrennt wird. Sie müssen die Y-Position erneut eingeben, wenn Sie ein Kindlos zuweisen, das ursprünglich eine Y-Position hatte.

Optional

Spez.

Spezifikation, bei der sich das Kindlos momentan befindet.

Nur Anzeige

Tabelle "Vorhandene Kindlose"

Tabelle, in der die Kindlose aufgelistet werden, die bereits dem Elternlos zugewiesen sind.

Nur Anzeige

Kindlos

Die ID des Kindloses.

Nur Anzeige

Menge

Die Menge des Kindloses.

Nur Anzeige

X-Position

Die X-Position, die zum Kennzeichnen des Kindloses verwendet wurde, als es erstellt wurde.

Nur Anzeige

Y-Position

Die Y-Position, die zum Kennzeichnen des Kindloses verwendet wurde, als es erstellt wurde.

Nur Anzeige

Vorgehensweise zum Zuordnen von mehrstufigen Kindlosen zu einem Elternlos

Gehen Sie folgendermaßen vor, um mehrstufige Kindlose dem Elternlos zuzuordnen:

1. Öffnen Sie die Seite Umlaufbestand zuordnen.
2. Geben Sie die ID des Elternloses in das Feld Los ein oder geben Sie die ID eines Kindloses in das Feld Kindlos ein. Die Anwendung füllt die Tabelle Kindlose zuweisen.
3. Aktivieren Sie das Kontrollkästchen in der Spaltenüberschrift der Tabelle Kindlose zuweisen, damit alle Kindlose ausgewählt werden.

Oder

Aktivieren Sie das einzelne Kontrollkästchen für jedes Kindlos, das erneut mit dem Elternlos verbunden (ihm zugewiesen) werden soll.
4. Klicken Sie auf Abschicken. Die Anwendung zeigt eine Erfolgsmeldung an.
