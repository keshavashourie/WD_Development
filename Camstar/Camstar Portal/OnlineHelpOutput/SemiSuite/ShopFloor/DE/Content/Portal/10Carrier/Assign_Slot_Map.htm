Behälter-Slotzuordnung zuweisen

Mit "Behälter-Slotzuordnung zuweisen" können Sie die Position eines Wafers in einem Waferbehälter angeben. Sie können mehrere Lose in einen einzelnen Waferbehälter laden, Sie können aber kein Los auf mehrere Behälter aufteilen. Sie müssen ein gesamtes Los einem einzigen Behälter zuweisen.

Voraussetzungen für das Zuweisen von Wafern zu Waferbehälterslots

Sie müssen die folgenden Punkte beachten, wenn Sie Wafer zu Waferbehälterslots zuweisen:

• Die folgenden Modellierungsobjekte müssen erstellt sein, bevor Sie Wafer zu Waferbehälterslots zuweisen können:
• Waferbehälter
• Waferbehälter: Familie

Weitere Informationen zu Modellierungsobjekten für Waferbehälter und Waferbehälter-Familie finden Sie im Opcenter Execution Semiconductor Modeling-Benutzerhandbuch.

• Wenn Sie alle Wafer, die in einem Los enthalten sind, einem einzelnen Waferbehälter zuordnen möchten, muss in "Waferbehälter: Familie" die gleiche oder eine größere Anzahl von Slots angegeben sein.
• Sie können Wafer aus mehreren Losen einem einzigen Behälter zuweisen.
• Sie müssen alle Wafer aus dem Los einem einzigen Behälter zuweisen.
• Wenn Sie mehrere Lose einem einzelnen Waferbehälter zuordnen, müssen sich die Lose im selben Transaktionsschritt befinden.
• Die Ausrüstung, die beim Einbringen von Losen angegeben wird, muss zur selben Fabrik gehören wie die Lose.

Beim Arbeiten mit Waferbehälterslots

Bedenken Sie diese Fakten, wenn Sie mit Waferbehälterslots arbeiten:

• Sie können einem Slot, der nicht aktiv ist, keinen Wafer zuordnen.
• Sie können Wafer nur aus solchen Waferbehältern, die nicht im Umlaufbestand angemeldet wurden, oder aus Waferbehältern entfernen, die derzeit nicht mit Ausrüstung verarbeitet werden.
• Sie müssen, wenn Sie Wafer aus einem Waferbehälter entfernen, alle Wafer aus einem einzelnen Los entfernen, bevor Sie den Behälter übermitteln.
• Einen Behälter, der Teillose enthält, können Sie nicht übermitteln.

Vorgehensweise beim Zuweisen einzelner Wafer zu Waferbehälterslots

Führen Sie die folgenden Schritte aus, wenn Sie einzelne Wafer zu Waferbehälterslots zuweisen möchten:

1. Öffnen Sie die Seite "Behälter-Slotzuordnung zuweisen". Die Anwendung zeigt die Seite "Behälter-Slotzuordnung zuweisen" an.
2. Geben Sie für jedes Los das Los in das Feld Auswahl-ID ein oder klicken Sie auf . Die Anwendung zeigt Lose in der Tabelle "Lose" an und listet die Wafer der einzelnen Lose in der entsprechenden Tabelle "Waferliste" oder "Slotzuordnung" auf.
3. Ein Wafer-Handler kann im Dropdown-Bereich Wafer-Handler-Ausrüstung ausgewählt werden. In diesem Dropdown-Bereich werden nur Wafer-Handler-Ausrüstungen angezeigt, die mit einer Ausrüstungsfamilie verknüpft wurden, die mit Wafer-Handler konfiguriert ist.
4. Wenn eine Wafer-Handler-Ausrüstung ausgewählt ist, wird das Feld Rezept angezeigt. Rezepte müssen einer Rezeptgruppe zugewiesen werden, die der Ausrüstung zugewiesen ist.
5. Möchten Sie nicht den momentan angemeldeten Mitarbeiter, sondern einen anderen Mitarbeiter eingeben, geben Sie die Mitarbeiter-ID in das Feld Mitarbeiter ein. Die Anwendung protokolliert die Transaktion als Transaktion, die von diesem Mitarbeiter ausgeführt wurde.
6. Wählen Sie im Feld Zu Behälter einen Waferbehälter aus. Die Anwendung füllt das Feld "Zu Behälter" mit Wafern, die in der Tabelle "Lose" verfügbar sind oder mit einem der Lose in der Tabelle verknüpft sind. Standardmäßig setzt das System das Feld "Zu Behälter" auf den Behälter, der dem in der Tabelle "Lose" ausgewählten Los zugewiesen ist.
7. Wenn Sie eine bestimmte Methode für die Slotzuweisung wünschen, wählen Sie das Feld Slotzuweisungsmethode aus. Weitere Informationen finden Sie unter "Beim Auswählen der Slotzuweisungsmethode".
8. Wählen Sie die Slotnummer, der Sie den Wafer zuordnen möchten, im Feld Slotnummer aus.
9. Wählen Sie in der Tabelle "Waferliste" Lose aus, indem Sie in der ersten Spalte auf das Kontrollkästchen klicken. Wenn Sie Wafer aus mehreren Losen zuordnen, klicken Sie auf den Pfeil für das zuzuordnende Los. Die Anwendung zeigt die Wafer aus diesem Los in der Tabelle "Waferliste" an.
10. Klicken Sie in der Befehlsleiste auf die Schaltfläche Hinzufügen. Die Anwendung zeigt die Waferinformationen für den zugeordneten Slot in der Tabelle "Behälter-Slotzuordnung" an.
11. Wiederholen Sie die Schritte 8 bis 10, bis alle Wafer im Los einem Slot zugeordnet sind.
12. Klicken Sie auf Einreichen. Die Anwendung weist die Wafer den Slots zu und zeigt eine Erfolgsmeldung an.
13. Die SchaltflächeSlots zuweisen ist verfügbar, wenn die ausgewählte "Slotzuweisungsmethode" nicht "Manuell" ist.

4. Wenn eine Wafer-Handler-Ausrüstung ausgewählt ist, wird das Feld Rezept angezeigt. Rezepte müssen einer Rezeptgruppe zugewiesen werden, die der Ausrüstung zugewiesen ist.
5. Möchten Sie nicht den momentan angemeldeten Mitarbeiter, sondern einen anderen Mitarbeiter eingeben, geben Sie die Mitarbeiter-ID in das Feld Mitarbeiter ein. Die Anwendung protokolliert die Transaktion als Transaktion, die von diesem Mitarbeiter ausgeführt wurde.
6. Wählen Sie im Feld Zu Behälter einen Waferbehälter aus. Die Anwendung füllt das Feld "Zu Behälter" mit Wafern, die in der Tabelle "Lose" verfügbar sind oder mit einem der Lose in der Tabelle verknüpft sind. Standardmäßig setzt das System das Feld "Zu Behälter" auf den Behälter, der dem in der Tabelle "Lose" ausgewählten Los zugewiesen ist.
7. Wenn Sie Wafer aus mehreren Losen zuordnen, klicken Sie auf den Pfeil für das zuzuordnende Los. Die Anwendung zeigt die Wafer aus diesem Los in der Tabelle "Waferliste" an.
8. Klicken Sie auf ALLE hinzufügen. Die Anwendung ordnet die Wafer den Slots der Reihe nach zu und zeigt die Waferinformationen für den zugeordneten Slot in der Tabelle "Behälter-Slotzuordnung" an. 10. Klicken Sie auf Einreichen. Die Anwendung weist die Wafer den Slots zu und zeigt eine Erfolgsmeldung an.
11. Die Schaltfläche Slots zuweisen ist verfügbar, wenn die ausgewählte "Slotzuweisungsmethode" nicht "Manuell" ist.

Vorgehensweise beim Entfernen von Wafern aus Waferbehälterslots

Führen Sie die folgenden Schritte aus, wenn Sie Wafer aus Waferbehälterslots entfernen möchten:

1. Öffnen Sie die Seite "Behälter-Slotzuordnung zuweisen". Die Anwendung zeigt die Seite "Behälter-Slotzuordnung zuweisen" an.
2. Geben Sie für jedes Los das Los in das Feld Auswahl-ID ein oder klicken Sie auf und die Anwendung listet die Wafer in der Tabelle "Waferliste" auf.
3. Sie können Wafer-Handler-Ausrüstung, Rezept und Mitarbeiter auswählen. Weitere Informationen finden Sie in den Schritten 3 bis 5 in "Vorgehensweise beim Zuweisen einzelner Wafer zu Waferbehälterslots
4. Wählen Sie Zu Behälter aus, um auszuwählen, welchen Waferbehältern zugewiesen werden soll. Die Anwendung füllt Waferbehälter aus, die in der Tabelle "Lose" verfügbar sind oder mit einem der Lose in der Tabelle verknüpft sind. Standardmäßig wird zuerst der Waferbehälter ausgefüllt, der den eingegebenen Losen zugeordnet ist.
5. Wenn der Behälter Wafer aus mehreren Losen enthält, klicken Sie auf den Pfeil, um das Los auszuwählen, zu dem die Wafer gehören, die Sie aus dem Waferbehälter entfernen möchten. Die Anwendung zeigt die Wafer aus diesem Los in der Tabelle "Waferliste" an.
6. Führen Sie eine der folgenden Vorgehensweisen für jedes Los aus, zu dem die Wafer gehören:

7. Gehen Sie wie unter "Vorgehensweise beim Zuweisen einzelner Wafer zu Waferbehälterslots" oder "Vorgehensweise beim Zuweisen aller Wafer eines Loses zu Waferbehälterslots" beschrieben vor, um die Behälterslots mit Wafern aus einem anderen Los zu ersetzen.
8. Klicken Sie auf Einreichen. Die Anwendung zeigt eine Erfolgsmeldung an.
9. Die Schaltfläche Slots zuweisen ist verfügbar, wenn die ausgewählte "Slotzuweisungsmethode" nicht "Manuell" ist.

Beim Auswählen der Slotzuweisungsmethode

Die Slotzuweisungsmethode hilft dabei, die Methode anzugeben, die zum Zuweisen von Wafern zu bestimmten Slots des Waferbehälters verwendet wird. Es sind fünf (5) verschiedene Slotauftragsmethoden verfügbar.

• Alle aufsteigend
• Alle absteigend
• Aufsteigende Füllung
• Absteigende Füllung
• Manuell

Felder für die Slotzuweisungsmethode sind auf der Seite Los nach Elementen vereinigen, auf der Seite Los nach Elementen aufteilen und auf der Seite Behälter-Slotzuordnung zuweisen verfügbar.

Hinweis: Der Begriff "Aufsteigend" und "Absteigend" bezieht sich auf die Reihenfolge, die auf die Wafer angewendet wird. Wafer werden immer basierend auf der Wafermarkierungs-ID in aufsteigender oder absteigender Reihenfolge zugewiesen. Währenddessen beziehen sich die Begriffe "Alle" und "Füllen" auf den Slot, an dem der Waferzuweisungsprozess beginnt. "Alle" beginnt immer mit Slot 1, es sei denn, er ist aus Statusperspektive nicht verfügbar. "Füllen" sucht nach dem ersten verfügbaren "leeren" Slot.

In der folgenden Tabelle ist zusammengefasst, wie die Seite für jede ausgewählte Slotzuweisungsmethode funktioniert:

Slotzuweisungsmethode

Beschreibung

Die Seite führt Folgendes aus . . .

Alle aufsteigend

Der Behälter wird ab Slot 1 zugeordnet, sofern die Verfügbarkeit vorhanden ist.

Lose werden basierend auf ihrer Wafermarkierungs-ID in aufsteigender Reihenfolge von der niedrigsten zur höchsten ID hinzugefügt, unabhängig von der Loszuweisung, es sei denn, es wird eine Duplizierung erkannt.

Hinweis: Bei dieser Methode werden aktuelle Slotzuweisungen nicht verwendet. Wafer werden neuen Slots zugewiesen.

Alle absteigend

Der Behälter wird ab Slot 1 zugeordnet, sofern die Verfügbarkeit vorhanden ist.

Lose werden basierend auf ihrer Wafermarkierungs-ID in absteigender Reihenfolge von der höchsten zur niedrigsten ID hinzugefügt, unabhängig von der Loszuweisung, es sei denn, es wird eine Duplizierung erkannt.

Hinweis: Bei dieser Methode werden aktuelle Slotzuweisungen nicht verwendet. Wafer werden neuen Slots zugewiesen.

Aufsteigende Füllung

Der Behälter wird ab dem ersten verfügbaren leeren Slot ab Slotposition 1 zugeordnet.

Wafer werden basierend auf ihrer Wafermarkierungs-ID in aufsteigender Reihenfolge von der niedrigsten zur höchsten ID hinzugefügt, unabhängig von der Loszuweisung, es sei denn, es wird eine Duplizierung erkannt.

Hinweis: Vorhandene Wafer auf dem "Zu Behälter" werden nicht neu zugewiesen.

Absteigende Füllung

Der Behälter wird ab dem ersten verfügbaren leeren Slot ab Slotposition 1 zugeordnet.

Wafer werden basierend auf ihrer Wafermarkierungs-ID in absteigender Reihenfolge von der höchsten zur niedrigsten ID hinzugefügt, unabhängig von der Loszuweisung, es sei denn, es wird eine Duplizierung erkannt.

Hinweis: Vorhandene Wafer auf dem "Zu Behälter" werden nicht neu zugewiesen.

Manuell

Die Standardmethode, wenn keine andere Methode ausgewählt ist.

 
Hinweis: Wenn eindeutige Wafermarkierungs-IDs nicht im System gepflegt werden, verwendet das System in einem Konfliktfall Los- und Wafermarkierungselement.
