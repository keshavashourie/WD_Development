Status festlegen

"Status festlegen" ermöglicht es Ihnen, die Status für Ressourcen festzulegen. Status sind benutzerdefinierte Indikatoren für die Verfügbarkeit und Zugänglichkeit von Ressourcen. Zum Beispiel können Sie Status verwenden, um anzugeben, dass eine Ressource zur Nutzung verfügbar ist oder dass sie für einen bestimmten Bereich in der Fertigung reserviert ist.

Sie können die Status für die folgenden Ressourcen festlegen:

• Ausrüstung (Zusammenbau, Backgrind, Element, Test und Wafersortierung)
• Behälter
• Masken
• Werkzeuge
• Feeder
• Feederbanken

Beim Festlegen von Werkzeugstatus

Definieren Sie alle Werkzeugaktionen, die Sie benötigen, und legen Sie den Status für die Werkzeuge fest, die Sie verwalten möchten. Weitere Informationen zum Definieren von Werkzeugaktionen finden Sie unter Opcenter Execution Semiconductor Modeling-Benutzerhandbuch.

Aktive Ausrüstung

Sie können den Status von Ausrüstung, die derzeit verwendet wird (aktiv ein Los verarbeitet), nicht ändern, es sei denn, die Anwendung ist so konfiguriert, dass das Kontrollkästchen "In Bearbeitung-Statusänderung erlauben" aktiviert ist. Dieses Kontrollkästchen ist auf der Ebene einer einzelnen Ausrüstung und auf der Ausrüstungsgruppenebene verfügbar. Mit einer speziellen Logik wird bestimmt, welche Ebene samt Einstellung jeweils Vorrang hat. Weitere Informationen finden Sie unter Opcenter Execution Semiconductor Modeling-Benutzerhandbuch.

Statusänderungen von Eltern- und Kindausrüstung

Eine Änderung des Status einer Elternausrüstung wird in der Regel an jegliche Kindausrüstung weitergegeben. Eine Ausnahme ergibt sich für folgenden Fall: Ein Elternelement wird heruntergefahren, ein Kindelement ist bereits heruntergefahren, und das Elternelement wird dann wieder hochgefahren. Das Kindelement wird nicht wieder hochgefahren, weil es nicht als Ergebnis des Elternelements heruntergefahren wurde.

Eine Änderung am Status von Kindausrüstung kann abhängig davon, wie das Feld "Kind-Statuskombination" der Elternausrüstung konfiguriert ist, zu einer Aktualisierung des Status der Elternausrüstung führen. Soll Elternausrüstung aktualisiert werden, wenn sie aktiv verwendet wird, muss die Option "In Bearbeitung-Statusänderung erlauben" für sie aktiviert sein.

Weitere Informationen finden Sie unter Opcenter Execution Semiconductor Modeling-Benutzerhandbuch.

Felddefinitionen der Seite "Status festlegen"

Diese Tabelle definiert die Felder auf der Seite "Status festlegen".

Feld

Definition

Typ

Typname

Name des Elements (Ausrüstung, Maske, Werkzeug oder Behälter), für das Sie den Status festlegen möchten. Das Feld hat z. B. den Namen "Elementausrüstung", wenn Sie den Status für Elementausrüstung festlegen, den Feldnamen "Werkzeug" für Werkzeuge usw.

Erforderlich

Mitarbeiter

Mitarbeiter, der diese Transaktion ausführt, wenn er nicht der derzeit angemeldete Benutzer ist.

Optional

Status

Anfangsstatus für die Ressource wie er im Feld "Anfangsstatus (festzulegender Null-Status)" angegeben ist. Für Behälter ist dieser Wert gleich "Behälterstatuscode" und für alle anderen Ressourcen gleich "Ressourcenstatuscode".

Erforderlich

Statusgrund

Grund für den Ressourcenstatus. Der Statusgrund bietet eine zusätzliche Detailebene zur Beschreibung des Grunds für den aktuellen Status einer Ressource. Ist der aktuelle Status z. B. gleich "Reparatur", könnten Sie einen Statusgrund angeben, um die Art der Reparatur zu kennzeichnen, die derzeit ausgeführt wird.

Für Behälter ist dieser Wert gleich "Behälterstatusgrund" und für alle anderen Ressourcen gleich "Ressourcenstatusursache".

Optional

Kommentare

Zusätzliche Informationen oder Anweisungen. Das Feld akzeptiert maximal 255 Zeichen. Wenn die Kommentare 255 Zeichen überschreiten, verkürzt die Anwendung die Daten.

Optional

Vorgehensweise zum Festlegen von Status

Gehen Sie folgendermaßen vor, um den Status für Ausrüstung, Masken, Werkzeuge und Behälter festzulegen:

1. Öffnen Sie die Seite "Status festlegen". Die Anwendung zeigt die Seite "Status festlegen" an.
2. Geben Sie den Namen der Ressource, für die Sie den Status festlegen möchten, in das Feld ein, das der Art der Ressource entspricht:

Die Anwendung zeigt den aktuellen Status der Ressource im Feld "Status" an.

3. Geben Sie den neuen Status in das Feld Status ein.
4. Geben Sie entsprechend Ihren Geschäftsanforderungen optionale Informationen ein. In der Felddefinitionstabelle finden Sie Informationen zu den optionalen Feldern.
5. Klicken Sie auf Speichern. Die Anwendung zeigt eine Erfolgsmeldung an, in der bestätigt wird, dass der Werkzeugstatus erfolgreich geändert wurde.
