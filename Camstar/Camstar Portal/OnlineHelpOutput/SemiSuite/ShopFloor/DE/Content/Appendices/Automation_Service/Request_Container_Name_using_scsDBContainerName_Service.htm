Anforderungsgenerierte Containernamen mit "scsDBContainerName" während eines HPE-Startdienstes

Der "scsDBContainerName"-Dienst bietet eine Methode, um während der Erstellung von Containern Containernamen über einen Automatisierungslayer anzufordern. Wenn Container mit Nummerierungsregeln erstellt werden, kann es schwierig sein, die Namen der erstellten Container zu identifizieren. Dieser Automatisierungsdienst hilft dabei, die Containernamen abzurufen, die mit "scsDBContainerName" im Anforderungsskript erstellt wurden. Die Containernamen werden dann von der Anwendung über das Antwortskript bereitgestellt. Dieser Dienst kann angewendet werden, wenn Sie Container in Arbeitsauftragserledigung (HPE) oder Los starten - Großmenge (HPE) erstellen.

Weitere Informationen zum Anforderungs- und Antwortskript finden Sie im Beispiel unten.
