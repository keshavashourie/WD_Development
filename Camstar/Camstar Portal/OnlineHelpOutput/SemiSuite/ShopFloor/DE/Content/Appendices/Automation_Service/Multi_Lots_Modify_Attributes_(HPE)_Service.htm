Dienst "Mehrere Lose: Attribute ändern (HPE)"

Mehrere Lose: Attribute ändern (HPE) oder scsDBMultiLotsModifyAttrs ist ein Dienst, der verwendet wird, um mehrere Attribute für ein oder mehrere Lose zu aktualisieren. Um die Aktualisierungen durchzuführen, können Sie folgende Details angeben:

• Containername (erforderlich)
• Attributname (erforderlich)
• Attributwert (erforderlich)
• Attributrevision (Nur für RDO erforderlich)
• ServiceAttrsModifyAttrsReason (Optional)
• ServiceAttrsRequestForm (Optional)
• ServiceAttrsRequestor (Optional)

Attributaktualisierungen können auch auf Kindlose angewendet werden, indem sie das folgende Skript hinzufügen:

<scsApplyToChildLots><![CDATA[true]]></scsApplyToChildLots>

Die Anwendung aktualisiert Losattribute basierend auf den bereitgestellten Feldern in der Transaktion.

Diese Tabelle definiert die Felder für das Anforderungscodebeispiel oben.

Feld

Definition

Eingabedaten

ServiceAttrsDetails

Enthält den Containernamen und die Liste der scsAttrDetails, die für die jeweilige Containeraktualisierung verwendet werden sollen.

scsContainerName

Name des Containers.

scsAttrDetails

Dieses Feld enthält eine Liste mit AttributeName, AttributValue und AttributRevision, die auf den angegebenen Container aktualisiert werden. Dann werden Attributdaten verwendet, um die Attribute des Loses zu aktualisieren.

Daten anfordern

CompletionMsg

Anforderung des Ausführungsstatus.

ServiceAttrsModifyAttrsReason

Grund für die Änderung des Attributs.

Anmerkung: Dieses Feld ist erforderlich, wenn das geänderte Attribut so konfiguriert ist, dass das Flag "'Attribute ändern: Grund' erforderlich" auf "wahr" festgelegt ist.

ServiceAttrsRequestForm

Dieses Feld wird für Berichterstellungszwecke verwendet

ServiceAttrsRequestor

Dieses Feld wird für Berichterstellungszwecke verwendet.
