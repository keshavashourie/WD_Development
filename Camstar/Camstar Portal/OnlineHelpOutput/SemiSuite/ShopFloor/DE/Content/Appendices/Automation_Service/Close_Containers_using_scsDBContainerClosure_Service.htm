Schließen von Containern mit dem "scsDBContainerClosure"-Dienst

Container können über eine Automatisierungsebene über einen Dienst namens "scsDBContainerClosure" geschlossen werden. Dazu müssen Sie den Containernamen angeben. In einer Situation, in der Sie mehrere Container schließen müssen, kann der Automatisierungsdienst den Eltern-Container finden, der vor der Containerabschluss-Transaktion abgetrennt werden soll. Um die Suche nach dem Eltern-Container durchzuführen, müssen Sie das Feld "AutoFindParentContainer" einschließen und auf "wahr" festlegen:

<scsAutoFindParentContainer><![CDATA[true]]></scsAutoFindParentContainer>

Hinweis: Der Wert für AutoFindParentContainer ist auf 1000 Container pro Transaktion beschränkt.

Sie können alle zugehörigen Container mit dem Flag "DisassociateAndTerminateAll" beenden. Dieses Flag kann auch für Behälter-Container verwendet werden. Um die Abbruchtransaktion durchzuführen, schließen Sie das Feld "DisassociateAndTerminateAll" ein und legen Sie diese auf "wahr" fest:

<DisassociateAndTerminateAll><![CDATA[true]]></DisassociateAndTerminateAll>

Im folgenden Code finden Sie ein Beispiel für "DisassociateAndTerminateAll".

Nachdem alle zugehörigen Container beendet wurden, benennt die Anwendung den Eltern-/Behälter-Container basierend auf der Nummerierungsregel um, die in der Fabrik festgelegt ist.

Automatisierungsdienst zum Containerabschluss

Beispiel für einen Containerabschluss

Der folgende Code zeigt das Beispiel für einen Containerabschluss mit dem "scsDBContainerClosure"-Dienst, der das Feld "AutoFindParentContainer" verwendet. Containernamen müssen im ContainerNamesStr angegeben werden.


<__InSite __version="1.1" __encryption="2">

<__service __serviceType="scsDBContainerClosure">

<__utcOffset><![CDATA[-04:00:00]]></__utcOffset>

<__inputData>

<ContainerNamesStr><![CDATA[%TID%ALOT001 - 01|%TID%ALOT001 - 02|%TID%ALOT001 - 03|%TID%ALOT001 - 04|%TID%ALOT001 - 05|%TID%ALOT001 - 06|%TID%ALOT001 - 07|%TID%ALOT001 - 08|%TID%ALOT001 - 09|%TID%ALOT001 - 10]]></ContainerNamesStr>

<scsAutoFindParentContainer><![CDATA[true]]></scsAutoFindParentContainer>

<TerminateReason>

<__name><![CDATA[Customer]]></__name>

</TerminateReason>

</__inputData>

<__execute>

</__execute>

<__requestData>

<CompletionMsg>

</CompletionMsg>

<ACEMessage>

</ACEMessage>

<ACEStatus>

</ACEStatus>

</__requestData>

</__service>

</__InSite>

Beispiel für "Abtrennen" und "Alle beenden"

Der folgende Code zeigt ein Beispiel für die Abtrennung und Beendigung aller Container mit dem Flag "DisassociateAndTerminateAll". Containerdetails und Abbruchgründe müssen enthalten sein.


<__InSite __version="1.1" __encryption="2">

<__service __serviceType="scsDBContainerClosure">

<__utcOffset cttPrompt="true"><![CDATA[08:00:00]]></__utcOffset>

<__inputData>

<ContainerParentStr><![CDATA[%MID%CARRIER01%TID%]]></ContainerParentStr>

<DisassociateAndTerminateAll><![CDATA[true]]></DisassociateAndTerminateAll>

<TerminateReason>

<__name><![CDATA[Customer]]></__name>

</TerminateReason>

</__inputData>

<__execute cttPrompt="true">

</__execute>

<__requestData>

<CompletionMsg cttPrompt="true">

</CompletionMsg>

</__requestData>

</__service>

</__InSite>
