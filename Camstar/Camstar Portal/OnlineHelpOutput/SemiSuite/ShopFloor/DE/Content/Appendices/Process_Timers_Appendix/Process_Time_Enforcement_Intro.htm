Prozesszeiterzwingung

Mit der Opcenter Execution Core-Funktion "Prozesszeiterzwingung" kann ein Systemadministrator Prozesstimer konfigurieren und an bestimmte Schritte im Fertigungsprozess anhängen. Dies ermöglicht eine genauere Kontrolle des Arbeitsplans. Opcenter Execution Semiconductor verwendet eine leicht modifizierte Adaptation dieser Funktion.

Hinweis: Informationen zur Funktion zur Prozesszeiterzwingung im Allgemeinen finden Sie im Opcenter Execution Core Shop Floor-Benutzerhandbuch.
