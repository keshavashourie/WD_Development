Erstellen von Behälter-Containern mit dem "scsCarrierPositionAssign"-Dienst

Behälter-Container können in einem Automatisierungsdienst vom Typ "scsCarrierPositionAssign" erstellt werden, wenn ein Container einem Behälter zugewiesen oder von einem anderen Behälter übertragen wird. Wenn ein Behälter-Container vom "scsCarrierPositionAssign"-Dienst erstellt wird, bestimmt die Anwendung, ob die folgenden Details in der XML-Anforderung enthalten sind: "Behälter-Startgrund", "Behälter-Eigentümer" und "Behälter-Level". Diese Werte werden verwendet, um die Behälter-Container zu erstellen.

<scsCarrierStartReason><__name><![CDATA[Carrier Start Reason]]></__name></scsCarrierStartReason>

<scsCarrierOwner><__name><![CDATA[Carrier Owner]]></__name></scsCarrierOwner>

<scsCarrierLevel><__name><![CDATA[Carrier Level]]></__name></scsCarrierLevel>


Wenn diese Werte nicht innerhalb der Anforderungs-XML übergeben werden, wertet die Anwendung die Felder "Einstellungen für die Fertigungsintegration" in der Behälterfamilie des Behälters aus. Wenn die Einstellungen konfiguriert sind, werden Startgrund, Eigentümer und Level in den Einstellungen verwendet, um einen Behälter-Container zu starten. Andernfalls verwendet die Anwendung die Werte für Startgrund, Eigentümer und Level aus dem ersten zugewiesenen Container.

Um die Priorität zusammenzufassen, verwendet die Anwendung die Werte für Startgrund, Eigentümer und Level von:

1. Automatisierungsebene (Skript)
2. Feld "Einstellungen der Fertigungsintegration", das in der Behälterfamilie angegeben ist
3. Dem ersten zugewiesenen Container

Automatisierungsdienst zum Zuweisen der Behälterposition

Beispiel für die Erstellung von Behälter-Containern mit zugewiesenem Container zu einem Behälter

Der folgende Code zeigt das Beispiel für die Erstellung von Behälter-Containern, wenn ein Container einem Behälter zugewiesen ist.


<__InSite __version="1.1" __encryption="3">

<__service __serviceType="scsCarrierPositionAssign">

<__utcOffset><![CDATA[-05:00:00]]></__utcOffset>

<__inputData>

<Carrier>

<__name><![CDATA[Carrier Name]]></__name>

</Carrier>

<scsCarrierStartReason>

<__name><![CDATA[Carrier Start Reason]]></__name>

</scsCarrierStartReason>

<scsCarrierOwner><__name><![CDATA[Carrier Owner]]></__name></scsCarrierOwner>

<scsCarrierLevel><__name><![CDATA[Carrier Level]]></__name></scsCarrierLevel>

<Details>

<__listItem>

<Container>

<__name><![CDATA[Child Container Name]]></__name>

</Container>

<PositionLevel><![CDATA[Child Position Level]]></PositionLevel>

<PositionNumber><![CDATA[Child Position Number]]></PositionNumber>

<PositionStatus><![CDATA[Child Position Status]]></PositionStatus>

<SetupAction><![CDATA[0]]></SetupAction>

</__listItem>

</Details>

</__inputData>

<__execute>

</__execute>

<__requestData>

<CompletionMsg>

</CompletionMsg>

</__requestData>

</__service>

</__InSite>

 

Beispiel für die Erstellung von Behälter-Containern mit Behälterübertragung

Dieser Code unten ist ein Beispiel für die Erstellung von Behälter-Containern, wenn ein Behälter von einem anderen Behälter übertragen wird.

<__InSite __version="1.1" __encryption="3">

<__service __serviceType="scsCarrierPositionAssign">

<__utcOffset><![CDATA[-05:00:00]]></__utcOffset>

<__inputData>

<Carrier>

<__name><![CDATA[From Carrier Name]]></__name>

</Carrier>

<scsCarrierStartReason>

<__name><![CDATA[Carrier Start Reason]]></__name>

</scsCarrierStartReason>

<scsCarrierOwner><__name><![CDATA[Carrier Owner]]></__name></scsCarrierOwner>

<scsCarrierLevel><__name><![CDATA[Carrier Level]]></__name></scsCarrierLevel>

<TransferAll><![CDATA[true]]></TransferAll>

<TransferCarrier>

<__name><![CDATA[To Carrier Name]]></__name>

</TransferCarrier>

</__inputData>

<__execute>

</__execute>

<__requestData>

<CompletionMsg>

</CompletionMsg>

</__requestData>

</__service>

</__InSite>
