Laden von Containern mit dem "scsCarrierPositionAssign"-Dienst

Container können über einen Automatisierungslayer in einen Behälter geladen werden, indem ein Dienst namens "scsCarrierPositionAssign" verwendet wird. Im Anforderungsskript müssen Sie die Einrichtungsaktion mit 0 (Laden) angeben und die Nummer der Slot-Position angeben, um die Container zu laden.

Es ist wichtig, den Status der Slot-Position und die Verfügbarkeit des Behälters zu prüfen, bevor Sie mit dem Laden eines einzelnen oder mehrerer Container gleichzeitig fortfahren. Wenn Sie eine der folgenden Aktionen ausführen, zeigt die Anwendung Fehlermeldungen an:

• Laden eines Containers in eine belegte Slot-Position
• Laden von 2 oder mehr Containern in dieselbe Slot-Position in einer einzigen Übermittlung
• Laden eines Containers in eine Slot-Position vom Typ "UNAVAILABLE" oder "DOWN" (Nicht verfügbar).

Beispiel für das Laden angegebener Container in einen Behälter

Der folgende Code zeigt ein Beispiel für das Laden von Containern in einen Behälter. Sie müssen Behältername, Containername, Level der Slot-Position, Nummer der Slot-Position und Einrichtungsaktion = 0 (Last) angeben.


<__InSite __version="1.1" __encryption="3">

<__service __serviceType="scsCarrierPositionAssign">

<__utcOffset><![CDATA[-05:00:00]]></__utcOffset>

<__inputData>

<Carrier>

<__name><![CDATA[CarrierName]]></__name>

</Carrier>

<CloseCarrierContainer><![CDATA[false]]></CloseCarrierContainer>

<Details>

<__listItem>

<Container>

<__name><![CDATA[ContainerToLoadName]]></__name>

</Container>

<PositionLevel><![CDATA[1]]></PositionLevel>

<PositionNumber><![CDATA[1]]></PositionNumber>

<SetupAction><![CDATA[0]]></SetupAction>

</__listItem>

</Details>

<UnloadAll><![CDATA[false]]></UnloadAll>

</__inputData>

<__execute>

</__execute>

<__requestData>

<CompletionMsg>

</CompletionMsg>

</__requestData>

</__service>

</__InSite>
