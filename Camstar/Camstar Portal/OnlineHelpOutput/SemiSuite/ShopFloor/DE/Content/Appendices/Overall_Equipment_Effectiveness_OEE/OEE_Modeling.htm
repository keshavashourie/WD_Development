Definieren der Gesamtanlageneffektivität

Die Modellierung ist der Teil von Opcenter Execution Semiconductor (Opcenter EX SM), mit dem die Elemente eines Produktionsanlagenmodells definiert und gewartet werden. Diese Elemente enthalten Daten wie Produkte, Operationen, Spezifikationen und Arbeitspläne, die verwendet werden, um die Verarbeitungsprozesse zu beschreiben und zu steuern. In diesem Abschnitt werden die wichtigsten Modellierungsobjekte für die Gesamtanlageneffektivität beschrieben.

Definieren von OEE-Einstellungen

Das Feld "Dauer für Echtzeit-OEE" im Modellierungsobjekt "OEE-Einstellungen" (OEE Settings) ermöglicht es Ihnen, die Zeitspanne festzulegen, für die die Anwendung Echtzeit-OEE berechnet. Operanden schließen ein:

• Tag
• Schicht
• Arbeit

Sie können den folgenden Modellierungsobjekten OEE-Einstellungen zuweisen:

• Fabrik
• Ausrüstung
• Ausrüstungsfamilie
• Ressourcenstatuscodes
• Produktionskalender

Definieren einer Fabrik

Eine Fabrik ist ein Geschäftsbereich, eine Abteilung oder eine Gruppe, die für die Buchhaltung und das Berichtswesen separat verwaltet wird. Ein Unternehmen kann eine oder mehrere Fabriken enthalten.

Zuweisen von OEE-Einstellungen für die Fabrik

Wählen Sie im Abschnitt "OEE" das Kontrollkästchen "OEE-Einstellungen" aus, wenn Sie die Zeitspanne festlegen möchten, für die die Anwendung Overall Equipment Effectiveness (OEE, Gesamtanlageneffektivität) für die ausgewählte Fabrik berechnen soll. Sie können auch GAE-Einstellungen für die Ausrüstung und die Ausrüstungsfamilie zuweisen.

Die folgenden Regeln gelten beim Zuweisen von OEE-Einstellungen:

• Die GAE-Einstellungen, die dem Modellierungsobjekt "Ausrüstung" zugewiesen wurden, haben Vorrang vor den GAE-Einstellungen, die dem Modellierungsobjekt "Ausrüstungsfamilie" zugewiesen wurden.
• Die GAE-Einstellungen, die dem Modellierungsobjekt "Ausrüstungsfamilie" zugewiesen wurden, haben Vorrang vor den GAE-Einstellungen, die dem Modellierungsobjekt "Fabrik" zugewiesen wurden.

Definieren von Ausrüstung und Ausrüstungsfamilien

Es gibt fünf Unterklassen für Ausrüstung und Ausrüstungsfamilien in Opcenter Execution Semiconductor. Die fünf Unterklassen für Ausrüstung und Ausrüstungsfamilien sind:

• Zusammenbauausrüstung
• Backgrind-Ausrüstung
• Testausrüstung
• Waferausrüstung
• Wafersortierung: Ausrüstung

Ausrüstungsmodellierungsobjekte definieren die Ausrüstung, die für Fertigungsoperationen verfügbar ist. Eine Ausrüstungsfamilie bietet eine Möglichkeit, Ausrüstung nach deren Attributen und entsprechend Ihren Geschäftsanforderungen zu kategorisieren. Sie können eine Ausrüstungsfamilie als Filter für verschiedene Fertigungstransaktionen verwenden.

Beim Definieren einer Ausrüstung und einer Ausrüstungsfamilie für GAE

Aktivieren Sie das Kontrollkästchen "In GAE-Daten einschließen", wenn die Anwendung GAE-Übersichtsdaten für die Ressource akkumulieren soll.

Sie können die Tabelle "Ideale Zykluszeit" verwenden, um die ideale Zykluszeit für ein Produkt oder eine Produktfamilie zu definieren. Beim Definieren einer idealen Zykluszeit gelten folgende Regeln:

• Die ideale Zykluszeit, die auf der Seite "Ausrüstung" definiert wurde, hat Vorrang vor der idealen Zykluszeit, die auf der Seite "Ausrüstungsfamilie" definiert wurde.
• Sie müssen für jede ideale Zykluszeit, die in der Tabelle "Ideale Zykluszeiten" definiert wird, ein Produkt (PN) oder eine Produktfamilie angeben.
• Sie können ein Produkt (PN) oder eine Produktfamilie nur einmal in der Tabelle "Ideale Zykluszeiten" angeben. Das Produkt (PN) oder die Produktfamilie muss für jede ideale Zykluszeit eindeutig sein.
• Die ideale Zykluszeit, die für ein Produkt (PN) definiert wird, hat Vorrang vor der idealen Zykluszeit, die für eine Produktfamilie definiert ist.

Definieren von Ressourcenstatuscodes

Ein Ressourcenstatuscode beschreibt den Status, der einer Ausrüstung zunächst bei der Einrichtung und später bei jeder Statusänderung zugewiesen werden kann. Mögliche Beispiele sind "Verfügbar", "Reserviert" und "Eingelagert".

Beim Definieren eines Ressourcenstatuscodes für OEE

Zum Ausführen von GAE-Berechnungen muss die Anwendung die Ressourcenstatuscodedaten für jede Schicht zusammenfassen. Die Anwendung fasst die Daten am Ende jeder Schicht mithilfe einer gespeicherten Prozedur zusammen, um die Zeit zu berechnen, die die Ausrüstung jeden Status aufgewiesen hat.

Im Feld "GAE-Verlustkategorie" auf der Seite "Ressourcenstatuscode" können Sie den Typ des Verlusts für jede geplante Ausfallzeit angeben. Operanden schließen ein:

• Verfügbarkeit - Gibt an, dass die Zeit in diesem Ressourcenstatuscode als Verfügbarkeitsverlust für eine Ressource zählt.
• Leistung – Gibt an, dass die Zeit in diesem Ressourcenstatuscode als Leistungsverlust für eine Ausrüstung zählt.
• Zeitplan - Gibt an, dass die Zeit in diesem Ressourcenstatuscode als Zeitplanverlust für eine Ressource zählt.

Definieren von Produktionskalendern

Ein Produktionskalender wird verwendet, um den Zeitstempel einer Transaktion in ein bestimmtes Fertigungsdatum und eine bestimmte Schicht zu übersetzen.

Beim Definieren eines Produktionskalenders für OEE

Im Feld "Ungeplante Zeit" in der Tabelle "Kalenderschicht" können Sie die Zeit eingeben, für die Ressourcen während einer Schicht ungeplant sind. Ungeplante Zeit darf die Dauer einer Schicht nicht überschreiten.
