Automatisierungsdienste

Dieser Anhang enthält die Beschreibung und Beispiele von HPE-Diensten in Opcenter Execution Semiconductor, die über einen externen Automatisierungsdienst oder eine benutzerdefinierte Benutzeroberfläche (UI) ausgeführt werden können.

Opcenter Execution Semiconductor bietet die Möglichkeit, für die meisten Transaktionen komplexe Einrichtungen über eine Automatisierungsebene auszuführen, die ihnen helfen, bequem, zeiteffizient und vorhersagbar zu arbeiten und menschliche Fehler zu reduzieren.

Weitere Informationen zu Automatisierungsdiensten, die mit High Performance Engine erweitert wurden, finden Sie unter Opcenter Execution Core – Technische Referenz: High Performance Engine.

Das folgende Thema enthält Informationen zu Automatisierungsdiensten:

• Erstellen von Behälter-Containern mit dem "scsDBLotStartSimple"-Dienst
• Erstellen von Behälter-Containern mit dem "scsCarrierPositionAssign"-Dienst
• Anforderungsgenerierte Containernamen mit "scsDBContainerName" während eines HPE-Startdienstes
• Laden von Containern mit dem "scsCarrierPositionAssign"-Dienst
• Entladen von Containern mit dem "scsCarrierPositionAssign"-Dienst
• Schließen von Containern mit dem "scsDBContainerClosure"-Dienst
• Dienst "Mehrere Lose: Attribute ändern (HPE)"
