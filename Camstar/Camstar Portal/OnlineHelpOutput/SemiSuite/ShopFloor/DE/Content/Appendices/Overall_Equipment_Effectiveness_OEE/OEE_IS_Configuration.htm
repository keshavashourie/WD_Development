Konfigurieren von Industry Solutions

Mit dem Industry Solutions Configuration Tool können Sie die Arbeitsbereiche konfigurieren, die für die Ausführung der Industry Solution-Funktionen erforderlich sind, in denen die Funktion "Overall Equipment Effectiveness (OEE)" enthalten ist.

Vor dem Konfigurieren von Industry Solutions

Wenn Sie OEE installieren, muss eine DataStore-Datenbank konfiguriert werden. Informationen zu DataStore-Datenbanken finden Sie in der Opcenter Execution Core-Anleitung zur Systemadministration.

Vorgehensweise zum Konfigurieren von Industry Solutions

Gehen Sie folgendermaßen vor, um Industry Solutions zu konfigurieren:

1. Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.
2. Erweitern Sie den Ordner Lösungen in der Struktur "Standorte" und wählen Sie den Knoten Industry Solutions-Konfiguration aus. Das Dialogfeld "Industry Solutions Configuration Tool" wird angezeigt.
3. Wählen Sie die zu installierende OEE-Funktion und den Installationstyp aus.
4. Klicken Sie auf Fertig stellen. Das Dialogfeld "DataStore-Datenbankdetails" wird angezeigt.
5. Geben Sie in Datenbankname den Datenbanknamen ein.
6. Geben Sie in Servername den Servernamen ein.
7. Geben Sie die Portnummer ein.
8. Geben Sie in Datenbankbenutzername den Datenbankbenutzernamen ein.
9. Geben Sie das Datenbankkennwort ein.
10. Klicken Sie auf Weiter. Das Dialogfeld "Installation bestätigen" mit Angaben zum Installationstyp, zu den ausgewählten Funktionsarbeitsbereichen und zu den DataStore-Datenbankdetails wird angezeigt.
11. Klicken Sie auf OK. Das Tool überprüft, ob die Verbindung zur DataStore-Datenbank erfolgreich hergestellt wurde. Die Konfiguration des Arbeitsbereichs beginnt. Im Industry Solutions Configuration Tool-Dialogfeld wird eine Fortschrittsanzeige angezeigt. Das Dialogfeld "Ersatz- und Anwendungsinstallation" wird angezeigt, wenn der Prozess abgeschlossen ist.
12. Klicken Sie auf OK. Das Dialogfeld "Installation abgeschlossen" wird angezeigt.
13. Klicken Sie auf OK. Das Industry Solutions-Konfigurationswerkzeug wird geschlossen.
Hinweis: Führen Sie "SEMI 0201 GUI Control - Portal Menu Definition Setup (Multi Level).xlsm“ aus, um das Menü für die Opcenter Execution Semiconductor OEE-Benutzeroberfläche hinzuzufügen.
