Erstellen von Behälter-Containern mit dem "scsDBLotStartSimple"-Dienst

Behälter-Container können mit dem scsDBLotStartSimple-Dienst erstellt werden, wenn der Behälter in der Anforderungs-XML angegeben ist. Wenn der Behälter-Container mit dem "scsDBLotStartSimple"-Dienst erstellt wird, können Sie optional dem Behälter-Container einen eigenen Startgrund, Eigentümer und Level-Wert zuweisen, indem Sie die folgenden Skripte zur XML-Anforderung hinzufügen:

<scsCarrierStartReason><__name><![CDATA[Carrier Start Reason]]></__name></scsCarrierStartReason>

<scsCarrierOwner><__name><![CDATA[Carrier Owner]]></__name></scsCarrierOwner>

<scsCarrierLevel><__name><![CDATA[Carrier Level]]></__name></scsCarrierLevel>


Wenn die Werte für "Startgrund", "Eigentümer" und "Level" nicht aus der XML "Anforderung" übernommen werden, bestimmt die Anwendung, ob der Behälterfamilie Einstellungen der Fertigungsintegration zugeordnet sind. Wenn Einstellungen der Fertigungsintegration mit der Behälterfamilie verknüpft sind, verwendet die Anwendung diese Werte für Startgrund, Eigentümer und Level. Wenn die Werte "Startgrund", "Eigentümer" und "Level" nicht über die Anforderungs-XML oder in den Einstellungen der Fertigungsintegration angegeben sind, verwendet die Anwendung die Werte, die auf der Seite Los starten - Großmenge (HPE) oder auf der Seite Arbeitsauftragserledigung (HPE) angegeben wurden.

Um die Priorität zusammenzufassen, verwendet die Anwendung die Felder "Startgrund", "Eigentümer" und "Level" basierend auf der folgenden Rangfolge:

1. Anforderungs-XML-Skript,
2. Einstellungen der Fertigungsintegration, die in der Behälterfamilie angegeben sind
3. Wenn Sie die Seite "Los starten - Großmenge (HPE)" oder "Arbeitsauftragserledigung (HPE)" verwenden. Dies wird auf Benutzeroberflächenebene und nicht auf Automatisierungsebene angegeben.
Hinweis: Wenn Sie Nummerierungsregeln verwenden, um Container auf der Automatisierungsebene zu erstellen (mit DBLotStartSimple), müssen Sie gewährleisten, dass die entsprechende Nummerierungsregel auf Containerlevel oder PN konfiguriert wurde. Wenn keine Nummerierungsregel erkannt wird, zeigt die Anwendung eine Fehlermeldung an. Die folgenden Einrichtungen müssen angewendet werden:
• Eine Nummerierungsregel muss bei PN/Produktfamilie/Diensteinrichtung konfiguriert werden.
• Eine Nummerierungsregel muss auf Kind-Containerlevel konfiguriert werden, wenn "Kind automatisch erstellen" auf "Wahr" festgelegt wurde.
• Das Kind-Containerlevel muss bereitgestellt werden, wenn "Kind automatisch erzeugen" auf "wahr" festgelegt wurde.
