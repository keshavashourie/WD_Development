Entladen von Containern mit dem "scsCarrierPositionAssign"-Dienst

Container können über einen Automatisierungslayer aus einem Behälter entladen werden, indem ein Dienst namens "scsCarrierPositionAssign" verwendet wird. Sie können bestimmte Container entladen oder alle Container aus einem Behälter entladen. Um die angegebenen Container zu entladen, müssen Sie den Containernamen und Behälternamen angeben und die Einrichtungsaktion mit 1 angeben. Um alle Container aus dem Behälter zu entladen, können Sie den Behälternamen angeben und "Alle entladen" auf "Wahr" festlegen.

Sie müssen keine Informationen zur Slot-Position während des Entladeprozesses angeben. Die Anwendung ermittelt die zugehörige Slot-Position automatisch und löst sie.

Hinweis: Es ist wichtig, den richtigen Containernamen während des Entladeprozesses einzugeben, wenn für ihn nicht "Alle entladen" mit "Wahr" konfiguriert ist. Wenn der Container nicht im Behälter gefunden wird, zeigt die Anwendung einen Fehler an.

Beispiel zum Entladen angegebener Container aus einem Behälter

Der folgende Code zeigt ein Beispiel für das Entladen angegebener Container aus einem Behälter. Sie müssen den Behälternamen <Behälter> und den Containernamen <Container __CDOTypeName="Lot"> angeben und die Einrichtungsaktion für das Entladen (1) angeben.


<__InSite __version="1.1" __encryption="3">

<__service __serviceType="scsCarrierPositionAssign">

<__utcOffset><![CDATA[-05:00:00]]></__utcOffset>

<__inputData>

<Carrier>

<__name><![CDATA[Carrier Name]]></__name>

</Carrier>

<CloseCarrierContainer><![CDATA[false]]></CloseCarrierContainer>

<Details>

<__listItem>

<Container __CDOTypeName="Lot">

<__name><![CDATA[Container Name]]></__name>

</Container>

<SetupAction><![CDATA[1]]></SetupAction>

</__listItem>

</Details>

<UnloadAll><![CDATA[false]]></UnloadAll>

</__inputData>

<__execute>

</__execute>

<__requestData>

<CompletionMsg>

</CompletionMsg>

</__requestData>

</__service>

</__InSite>

 

Beispiel zum Entlsaden aller Container aus einem Behälter

Der folgende Code zeigt das Beispiel zum Entladen aller Container aus einem Behälter. Sie müssen den Behälternamen angeben und "Alle entladen" auf "Wahr" festlegen.

<__InSite __version="1.1" __encryption="3">  

  <__service __serviceType="scsCarrierPositionAssign">        

<__utcOffset><![CDATA[-05:00:00]]></__utcOffset>        

<__inputData>  

          <Carrier>                

<__name><![CDATA[Carrier Name]]></__name>            

</Carrier>  

          <CloseCarrierContainer><![CDATA[false]]></CloseCarrierContainer>  

        <UnloadAll><![CDATA[true]]></UnloadAll>        

</__inputData>        

<__execute>        

</__execute>

      <__requestData>  

          <CompletionMsg>  

          </CompletionMsg>  

      </__requestData>

</__service>

</__InSite>
