设置批 ID

通过“设置批 ID”，可以为一个或多个批次设置或移除批 ID。批 ID 是一个字符串值，可以手动输入。如果未输入值，应用程序将使用编号规则自动生成批 ID。

设置批 ID

批次必须处于活动状态，并且处于同一个工步中。

事务方案：

• 不存在任何批 ID，也不存在任何容器。不允许使用此方案，因为没有执行任何操作的指示。
• 不存在任何批 ID，但容器存在。应用程序将使用编号规则自动生成批 ID，并为批次设置“批 ID”批次属性。
• 批 ID 存在，但不存在任何容器。此方案的用途是从具有值的容器移除批 ID。
• 批 ID 和容器都存在。批 ID 将设为批次的属性。

设置批 ID 页字段定义

此表定义“设置批 ID”页中的字段。

字段

定义

选择 Id

此列表字段用于指定要为其设置批 ID 的一个或多个批次。

员工

执行此事务的员工（如果不同于当前登录的用户）。

批 ID

此必填字段用于指定要设置的 ID，或者指定要从一个或多个批次移除的 ID。

如果未指定值，将使用 "SetBatchId" 编号规则自动生成 ID。

调整原因

对选择内容进行的任何调整的原因。

其他信息或指示。此字段最多接受 255 个字符。如果备注超过 255 个字符，应用程序将截断数据。
