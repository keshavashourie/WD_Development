晶元 WIP 数据采样

可以在“转入”前在“WIP 主要高级”页或“设备 WIP 调度”页中配置“晶元 WIP 数据采样”。当批次已使用“晶元 WIP 数据采样”配置且“项处理”仅设为 true 并加载到晶元物料箱的供料槽时，将检测“晶元 WIP 数据采样”。在“WIP 主要高级”页中，在“转入”前输入批次时，活动图块将显示一条消息，指示检测到晶元采样。它还表示是否必须选择批次。通过检查“项”表格选项卡中的“槽位置”列，可以标识是否已将批次指派给物料箱。

在“项”表格中重新选择要采样的晶元或供料槽。仅当采样方法为“用户选择”或不强制执行的任何其他方法时，此选项才适用。如果对“整数 N 个”、“倒数 N 个”、“样本大小”和“样本百分数”方法强制执行晶元采样，则禁用重新选择。有关“晶元 WIP 数据采样”、“WIP 数据设置”和“指派物料箱供料槽映射”页的信息，请参考《Opcenter Execution Semiconductor Modeling 指南》。

注释: 晶元采样优先于 AQL 采样。如果现有默认“AQL 采样”和“晶元 WIP 数据采样”在同一工步中配置，则仅执行“晶元 WIP 数据采样”。

应用程序不允许将具有必需晶元采样的批次与非必需晶元采样批次一起转入。必须单独执行 WIP 处理。不允许对已部分转入设备的批次执行晶元采样。

下面说明了“WIP 主要高级（转入）”页对所选的每个晶元采样方法的期望：

• 用户选择 - 无论是否强制执行晶元采样，都必须在“项”表格上至少选择 1 个晶元进行采样。（可选）可以选择更多晶元进行采样。
• 正数 N 个 - 应用程序将自动选择正数 N 个供料槽，其中 N 是要采样的晶元数。如果强制执行晶元采样，将禁用重新选择。如果不强制执行晶元采样，可以在“项”表格中重新选择数量为 N 的晶元。如果未满足所需的供料槽数，应用程序将不允许进一步 WIP 处理（转入、转出或移出某个数量）。
• 倒数 N 个 - 应用程序将自动选择倒数 N 个供料槽，其中 N 是要采样的晶元数。如果强制执行晶元采样，将禁用重新选择。如果不强制执行晶元采样，可以在“项”表格中重新选择数量为 N 的晶元。如果未满足所需的供料槽数，则应用程序将不允许进一步 WIP 处理（转入、转出或移出某个数量）。
• 样本大小 - 应用程序将根据输入的样本大小预选供料槽数。如果强制执行晶元采样，将禁用重新选择。如果不强制执行晶元采样，可以在“项”选项卡表格中重新选择具有相同指定数量的供料槽。如果未满足所需的供料槽数，应用程序将不允许进一步 WIP 处理（转入、转出或移出）。有关根据输入的样本大小和百分数对所选计算进行采样的信息，请参考《Opcenter Execution Semiconductor Modeling 指南》中的“定义晶元 WIP 数据采样”。
• 样本百分数 - 应用程序将根据输入的样本百分数预选供料槽数。如果强制执行晶元采样，将禁用重新选择。如果不强制执行晶元采样，可以在“项”选项卡表格中重新选择具有相同指定数量的供料槽。如果未满足所需的供料槽数，应用程序将不允许进一步 WIP 处理（转入、转出或移出）。有关根据输入的样本大小和百分数对所选计算进行采样的信息，请参考《Opcenter Execution Semiconductor Modeling 指南》中的“定义晶元 WIP 数据采样”。

“转入”后，未选择的晶元将前进至“移出”工步。

检测到晶元采样、选择供料槽并强制执行当前选择时，“WIP 主要高级”页在图块上显示交互式消息。每个图块都包含活动消息、状态和颜色。
