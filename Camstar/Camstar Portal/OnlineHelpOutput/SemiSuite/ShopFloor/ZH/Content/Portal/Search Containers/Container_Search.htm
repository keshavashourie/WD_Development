Opcenter Execution Semiconductor 中的容器搜索

Opcenter Execution Semiconductor 使用略微修改过的 Opcenter EX CR 容器搜索功能。本章介绍了为 Opcenter Execution Semiconductor 所做的修改。

对 Opcenter Execution Semiconductor 所做的更改

已添加这些搜索准则字段：

• 工厂
• 流程规范
• 物料零件
• 物料批次名称

已移除这些字段：

• 分发的容器
• 分发的容器产品
• 分发来源批次
• 分发来源存货点

添加了以下默认车间事务：

• 批次合并
• 按晶元合并批次
• 批次搁置
• 批次拆分
• 批次修改属性
• 批次修改项
• 按晶元拆分批次
• 批次发布
• WIP 主要
注释: 系统管理员可以使用 Portal Studio 添加默认操作。

有关常规容器搜索功能的信息，请参考《Opcenter Execution Core Shop Floor 指南》。有关添加默认操作的信息，请参考 Opcenter Execution Core Portal Studio 1.0 用户指南。
