追踪标签验证

通过“追踪标签验证”页，可以按关联验证标签正确性。可以在此屏幕中执行两种不同类型的验证：

• 父子验证 – 可用于验证标签 ID 的父子关系（例如片盘与盒子的关系）。
• 集验证 – 可用于验证给定标签组是否属于一个集。可以使用此验证来验证给定标签是否属于同一个批次。

如何验证标签

按照以下步骤验证标签：

1. 打开“追踪标签验证”页。
2. 执行以下一项操作：

要验证 ...

执行以下操作 ...

标签之间的父子关系。
a. 在验证计划字段中输入父子。
b. 在主标签 ID 字段中输入父标签 ID。
c. 在子标签 ID 字段中输入子标签，然后按 Tab 键。应用程序将在“子标签 ID”表格中显示子标签 ID。
d. 对所有子标签重复步骤 c。

标签是否全部属于同一个集。
a. 在验证计划字段中输入集验证。
b. 在子标签 ID 字段中输入标签，然后按 Tab 键。应用程序将在“子标签 ID”表格中显示子标签 ID。
c. 对集中的所有标签重复步骤 b。
3. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
4. 单击提交。应用程序显示成功消息。
