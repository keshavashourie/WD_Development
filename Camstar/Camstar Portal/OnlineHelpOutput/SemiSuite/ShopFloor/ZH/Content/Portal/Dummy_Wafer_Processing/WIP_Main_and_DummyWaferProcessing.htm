WIP 主要和假片晶元处理

WIP 主要处理包括验证与核实，其中一部分特定于假片晶元处理，一部分会导致需要转入假片晶元。

如果需要使用假片晶元，可以同时转入一个或多个假片晶元批次以及一个或多个生产批次。必须先转出一个或多个假片晶元批次，然后再转出一个或多个生产批次。

使用假片晶元之前

假片晶元追踪取决于在“建模”中进行的配置。PN（产品）建模对象和流程规范建模对象和设备建模对象设计用于支持车间的假片晶元处理。系统管理员将配置这些对象的实例以满足制造要求。必须先配置至少一个假片晶元产品，然后才能使用假片晶元处理。有关信息，请参考 Opcenter Execution Semiconductor Modeling 指南。

开始假片晶元批次

要转入假片晶元，需要假片晶元批次。通过使用“批次开始”并选择一个假片产品来创建批次。应用程序会将假片产品寿命移动到批次晶元对象。

注释: 假片晶元批次和生产批次必须处于同一 WIP 状态才能转入。

转入验证

应用程序将对资源执行以下验证：

• 将已转入的晶元数量与资源的最低晶元要求进行比较。如果生产晶元数量不满足最低要求，则假片晶元可以与生产晶元一起转入。
• 将已转入的假片晶元数量与资源的最低假片晶元要求进行比较。
注释: 如果不满足最低假片晶元要求，则单击“提交”之后会显示错误消息。
• 将上次使用设备以来经过的时间量与为资源配置的最大空闲时间进行比较。如果空闲时间超过最大值，将允许转出，但会将设备状态设为“停用”。
注释: 应用程序允许向处于“停用”状态的设备转入假片晶元。但是，如果批次中存在假片晶元，则不允许转入生产晶元。

应用程序将对任何假片晶元执行以下验证：

• 将每个晶元已配置的晶元属性最大值与为该属性收集的 WIP 数据值进行比较。如果晶元属性值超过最大值，应用程序将阻止转入。
注释: 如果从上一个工步转出晶元，弹出窗口消息中将显示此错误。但是，如果尝试转入，将执行失败处理。
• 将每个晶元的实际处理时间与已配置的最大处理时间进行比较，如果已超过最大值，则阻止转入。
• 如果晶元的寿命计数器已到达零位，则禁止转入。否则，应用程序将允许转入并减少计数器读数。

转出验证

应用程序将检查最后假片晶元数据收集状态。如果状态为“失败”，应用程序将允许转出，但会同时搁置生产批次和假片批次，从而阻止移出。如果状态为“通过”，应用程序会将假片批次 ID 移动到“最后通过的假片批次”字段。

注释: 必须先等待任何仍在处理的假片晶元完成，然后才能完成转出。必须先转出所有假片晶元，然后才能转出任何生产晶元。

移出验证

假设未发生任何验证错误，则假片晶元和生产晶元都可以移出。可能可以移出假片晶元批次但无法移出生产批次，也可能两个批次都无法移出。可移出的批次由特定错误决定。

如何转入假片晶元批次和生产批次

按照以下步骤转入假片晶元批次和生产批次：

1. 使用选择 ID 字段选择生产批次。应用程序将在“批次”表格中显示所选批次。
2. 继续转入。
3. 选择设备。应用程序将指示需要假片晶元，或者指示批次不满足最低晶元要求。
4. 使用选择 ID 字段选择假片晶元批次。应用程序会将所选假片晶元批次添加到“批次”表格。
5. 输入假片晶元所需的任何信息。
6. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
7. 单击提交。应用程序显示成功消息。

如何转出假片晶元批次

按照以下步骤转出假片晶元批次：

1. 继续仅转出假片晶元批次。如果为假片晶元配置了数据收集，应用程序将显示“数据”选项卡。
2. 如果显示数据选项卡，则执行以下步骤：
a. 打开数据选项卡。
b. 输入所需的数据。
c. 单击提交。应用程序将显示状态消息。
d. 返回到主要选项卡。
3. 单击提交以移出假片晶元批次。应用程序将显示警报弹出窗口，其中列出任何处理失败的假片晶元。
