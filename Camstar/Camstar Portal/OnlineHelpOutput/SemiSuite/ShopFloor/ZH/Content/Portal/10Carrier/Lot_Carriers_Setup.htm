批次物料箱设置

批次物料箱设置用于将物料箱关联到批次或取消物料箱与批次的关联关系。可以将一个或多个物料箱指派给批次，但指派给批次的物料箱必须满足以下要求：

• 维护要求必须有效。如果应用程序检测到故障，事务将无法推进。
• 状态必须可用。
• 不得指派给另一个批次。
• 不得具有未完成的工作。

如何将物料箱与批次关联起来

按照以下步骤将物料箱与批次关联起来：

1. 打开“批次物料箱设置”页。
2. 在选择 Id 字段中输入要为其指派物料箱的批次的名称。应用程序会在“批次”表格中显示名称和批次详细信息。如果物料箱已经指派给该批次，应用程序将在“物料箱”表格中显示指派的物料箱。
3. 要将每个物料箱与批次关联起来，从物料箱字段中选择物料箱的名称。应用程序会将物料箱的名称添加到“物料箱”表格中。应用程序按物料箱添加顺序显示各个物料箱。
4. 如果需要更改物料箱的顺序，执行以下操作：
a. 单击“物料箱”表格中物料箱的复选框。
b. 如下所示使用箭头：

要移动物料箱 ...

单击 ...

向上

向下

5. 单击提交。应用程序显示成功消息。

如何取消物料箱与批次的关联

按照以下步骤将物料箱与批次取消关联：

1. 打开“批次物料箱设置”页。
2. 在选择 Id 字段中输入要与物料箱取消关联的批次的名称。应用程序会在“批次”表格中显示名称和批次详细信息，并在“物料箱”表格中显示已指派给批次的物料箱。
3. 在“物料箱”表格中单击要移除的物料箱的选择框。
4. 单击. 应用程序会从“物料箱”表格中移除选定的物料箱。
5. 单击提交。应用程序显示成功消息。
