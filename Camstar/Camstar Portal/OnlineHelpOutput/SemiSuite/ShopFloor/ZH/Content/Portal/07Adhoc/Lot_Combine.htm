批次合并

通过批次合并，可以将两个或更多批次完全或部分合并起来。如果输入了“新批次 ID”或选中了“自动设置新批次 Id”复选框，还可以拆分到新批次。如果只指定了一个批次，则不会发生合并。

重要提示: 在晶元或项处理工步中，必须为批次使用“按项合并批次”。有关信息，请参考“按项批次合并”。

如何执行批次合并

按照以下步骤执行批次合并：

1. 访问“批次合并”页。
2. 使用选择 Id 字段选择一个或多个批次。应用程序使用所选的一个或多个批次填充“批次”表格，使用所选的第一个批次填充“目标（主）批次”表格，以及使用所选的任何其他批次填充“源批次”表格。
3. 什么是目标批次？

如果您想完成以下操作...

操作步骤 ...

使用主批次字段中显示的默认目标。

转到步骤 4。

更改目标批次
a. 从主批次列表中选择新的目标批次。应用程序将旧的目标批次移动到源表格，并将新的目标批次移动到目标表格。
b. 转到步骤 4。

新建目标批次

输入新批次 Id 或选中自动设置新批次 Id 复选框。应用程序将所有“目标项”表格行移动到“源项”表格中。
4. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
5. 单击提交。应用程序显示成功消息。
