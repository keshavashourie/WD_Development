追踪标签详细信息更新

通过“追踪标签详细信息更新”页，可以更新有关先前生成的标签的详细信息。通过此页面对标签进行的更改仅在将来打印该特定标签时生效。事务不会更改相关的“标签计划”建模对象，也不会影响将来使用同一个标签计划打印的标签。

追踪标签详细信息更新页字段定义

此表定义“追踪标签详细信息更新”页中的字段。

字段

定义

类型

标签 ID

要更新的标签的条形码值。如果无法扫描标签或者内容模糊不清，则与系统管理员联系以获取该值。

必需

员工

执行此事务的员工（如果不同于当前登录的用户）。

可选

标签状态

标签的状态。可用值为“未使用”和“使用中”。

可选

标签数量

标签的数量值。

必需

打包至 ID

将标签打包到的标签 ID。

可选

更新时打印

表示更新后是否应重新打印标签。

可选

将状态应用到相同集中的所有标签

此复选框表示是否将状态应用于一个集中的所有标签。

注：如果状态为“使用中”或“未使用”，则状态将应用于同一个级别的所有标签。如果状态为“无效”，则状态将应用于所有标签（包括子标签）。

可选

标签源详细信息表格

构成整个标签数量的源名称和数量。只要源有效，就可以在此表格中添加、编辑或移除标签源。

必需

源 ID

标签源的标识。

注：源 ID 必须属于该标签。

必需

数量

在该集中打印的标签的总数。“数量”列中所有值的总和必须与“标签数量”字段的值匹配。

必需

如何更新标签详细信息

按照以下步骤更新标签详细信息：

1. 打开“追踪标签详细信息更新”页。
2. 在标签 ID 字段中输入要更新的标签的标签 ID，然后按 Tab 键。应用程序将显示标签详细信息。
3. 根据业务需求对标签详细信息进行更新。
4. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
5. 单击提交。应用程序显示成功消息。
