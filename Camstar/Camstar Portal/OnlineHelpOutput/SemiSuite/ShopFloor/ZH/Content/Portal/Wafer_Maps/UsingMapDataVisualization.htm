使用映射数据可视化页

通过“映射数据可视化”页，可以根据提供的基板 ID 和批次 ID（如果已提供）审核并编辑上次提交的分选代码集。可以查看数据图，在图中选择一个位置进行目视检查，并使用新的分选代码以电子方式“标记”该位置。应用程序将数据显示为有助于追踪缺陷的已着色表格图，并允许在提交信息之前查看所有分选信息。

使用映射数据可视化页

画布工作区域的大小为 1500 x 600 像素。画布的最大像素区域限制在 8000 x 8000 像素以内。图中单个位置 (X, Y) 的大小取决于图本身的设备大小。如果图大小超过画布的最大显示区域，应用程序会缩小该图并保持其比例。当画布区域大于工作区域时，画布工作区域可滚动。

如何更新分选数据

按照以下步骤更新分选数据：

1. 打开映射数据可视化页。
2. 输入基板 ID。
3. 如果基板 ID 与多个批次 ID 关联，则选择一个批次 ID。
4. 在图上单击一个位置。应用程序将显示所选位置的 X 尺寸、Y 尺寸和当前分选代码。
5. 输入新分选代码。
6. 单击添加到表格。应用程序会将表格正上方的字段（包括“新分选代码”）中的数据更新到“分选代码更新详细信息”表格中。
7. 单击提交。应用程序会将“分选代码更新详细信息”表格中的数据提交到 MapDataMaint 服务。
