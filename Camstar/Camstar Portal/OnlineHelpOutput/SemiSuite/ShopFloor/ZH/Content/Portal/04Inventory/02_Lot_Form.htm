批次形成

通过“批次形成”，可以合并和拆分库存和 WIP 中的现有批次来创建新的批次。

注释: “按项形成批次”是针对基于晶元的批次而设计的对应页面。

批次形成页字段定义

此表定义“批次形成”页中的字段。

定义

类型

选择 Id

必需

创建新计划

将该值设为 false 意味着将使用相同的计划拆分“新建容器名称”。

截止日期

计划完成此容器的日期和时间。此信息将与预计完成时间一起用于绩效报告。

注意：如果处理容器\批次启用了剩余处理时间 (RPT)，则此字段是必需的。

工作订单

用于启动批次的制造订单。

注：仅当启动后自动计划批次，或者执行拆分后在未计划的情况下设置新批次（“拆分批次详细信息”的“拆分到制造订单”字段）时，才使用此字段。

可选

预期开始日期

计划的预期开始日期。

如果此字段留空，则使用制造订单的“计划开始日期”。

可选

周期时间

标准环境下处理产品所需的估计时间（以天 [可选]、小时、分和秒计）。应用程序使用按以下顺序评估以下字段找到的第一个非空白周期时间：

1.

制造订单的计划的周期时间 (PlannedCompletionDate – PlannedStartDate)

2.

用户输入的周期时间

3.

流程规范的周期时间。

如果找不到值，应用程序将使用值 1。

可选

销售订单编号

计划的其他信息。通常用于从 ERP 应用程序中存储销售订单编号。

可选

产品

用于启动批次的产品。如果“产品”为空，应用程序将使用指派给制造订单的产品。

注：要开始批次，必须选择相应的“产品可用”标志。

可选

物料清单

用于计划批次的物料清单。如果此字段留空，则使用制造订单的“产品物料清单”。应用程序会使用产品物料清单列表填充此字段。

可选

流程规范

此字段选择计划批次的“流程规范”。将批次从“库存”移出到“WIP 处理”后，此流程规范用于追踪这些批次。它会指定要执行的工作流程工步以及工作流程工步上的任何参数和变量。如果未输入流程规范值，将使用“制造订单”的流程规范。

可选

第一个 WIP 工步

“流程规范”的“工作流程”中第一个 WIP 工步（也是默认值）。

此 WIP 工步用于在准备批次或将批次发布到生产时移动批次。

可选

装运目标工厂

指定计划的“装运目标工厂”。如果此字段留空，则应用程序会使用主批次的“装运目标工厂”。

可选

所有者

负责该批次的人员或团队。如果所有者字段留空，应用程序将使用该产品的“默认开始所有者”。典型值包括“制造”、“工程”和“开发”。

可选

优先级

指定计划的“优先级代码”。

可选

打包类型

指定批次需要的打包。如果此字段留空，则使用“流程规范”的“打包类型”。

可选

自动准备

此复选框表示是否自动准备批次。选中“自动准备”复选框会导致批次自动准备，如同在“批次计划准备”中那样。

可选

显示/隐藏其他字段

 

备注

其他信息或指示。此字段最多接受 255 个字符。如果备注超过 255 个字符，应用程序将截断数据。

可选

如何从一个或多个现有批次形成新批次

按照以下步骤从一个或多个现有批次创建新批次：

1. 访问“批次形成”页。
2. 从选择 Id 字段中选择一个或多个源批次。应用程序使用所选的批次信息填充“详细信息”表格。
3. 输入各批次的合并数量。
4. 输入新批次 Id。此字段位于表格下方的几行。
5. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
6. 单击提交。应用程序显示成功消息。
