设置项批 ID

“设置项批 ID”与“设置批 ID”相似，但用于设置或移除一个或多个晶元（项）的晶元批 ID。晶元批 ID 是一个字符串值，可以手动输入，也可以由应用程序使用编号规则自动生成。

设置项批 ID 页字段定义

此表定义“设置项批 ID”页中的字段。

字段

定义

选择 Id

此列表用于指定要设置晶元批 ID 的一个或多个晶元。

字段包括：

“容器”- 必填字段，用于指定批次。该批次：

• 必须处于活动状态。
• 如果指定多个批次，则必须位于同一个规范中。

“晶元刻印号”（项 ID）- 必填字段，用于指定要设置的晶元。晶元在指定的容器中必须存在。

事务方案：

• 不存在任何批 ID，也不存在任何晶元。不允许使用此方案，因为没有执行任何操作的指示。
• 不存在任何批 ID，但晶元存在。应用程序将使用编号规则自动生成批 ID，并为晶元设置“晶元批 ID”晶元属性。
• 批 ID 存在，但不存在任何晶元。此方案的用途是从具有值的晶元移除批 ID。
• 批 ID 和晶元都存在。批 ID 将设为晶元的属性。

员工

执行此事务的员工（如果不同于当前登录的用户）。

项批 ID

此必填字段用于指定要设置的 ID，或者指定要从一个或多个批次移除的 ID。

如果未指定值，将使用 "WaferBatchId" 编号规则自动生成 ID。

备注

其他信息或指示。此字段最多接受 255 个字符。如果备注超过 255 个字符，应用程序将截断数据。
