使用 WIP 主要高级

“WIP 主要高级”页是重构的“WIP 主要”页，用于提供一个集中位置来对批次和设备执行操作。此页面还提供有关批次和设备的信息。

访问 WIP 主要高级

从菜单访问“WIP 主要高级”时，“WIP 主要高级”表格为空。必须选择批次或设备才能查看数据。默认情况下，该页面根据批次选择执行。（可选）用户可以选择切换到“设备”。

WIP 主要高级批次和设备字段定义

此表定义“WIP 主要高级”页中的批次和设备选择字段。

字段

定义

批次/设备

选择“批次”选项时，页面将切换为显示“批次选择”弹出窗口。同时选择“设备”选项将使页面切换为显示基于设备的“批次选择”弹出窗口。

选择 Id

批次、物料箱、批或设备的 ID。有关信息，请参考“使用 WIP 主要高级”。

员工

负责完成此事务的用户的 ID。

流程类型

用于为“工步”或“规范”提供一个或多个子流程。此字段主要用于自动线路设置，在自动线路设置中，不同类型的设备在工步中链接到一起。批次必须完成所有的“流程类型”才允许移出到下一工步。如果没有将“流程类型”指派到“工步名称”或“规范”，将使用默认的“正常流程类型”。

设备

用于选择将要处理当前批次的设备。

活动

适用于“WIP 主要高级”阶段（移入、转入、转出和移出）中已选批次的活动列表。每个图块都具有活动消息、状态和颜色（绿色表示“通过”、黄色表示“未执行”、蓝色表示“可选”、红色表示“不完整”）。

WIP 主要高级图标

这些表介绍“WIP 主要高级”页的命令栏中的操作和帮助图标。单击图标可访问这些仅提供信息的弹出窗口。

注释: 默认情况下，这些按钮将评估表格中的第一个批次。当用户在表格中选择第二个或任何批次时，这些按钮将填充高亮显示的批次。

操作图标

此表定义“WIP 主要高级”页中的操作图标。

图标

所选批次或设备的“WIP 指示”弹出窗口。用于根据 WIP 指示查看准则。使用“WIP 指示”矩阵对象或实验对象进行相应设置。有关 WIP 指示矩阵对象和实验对象的信息，请参考 Opcenter Execution Semiconductor Modeling 指南。

所选批次的工作流程工步（过去、当前和未来）。用于查看所选批次的 WIP 工步。

所选批次或设备的“文档选择”弹出窗口。用于查看指派给各项设置（例如“规范”和“流程规范”）的文档集。

所选批次或设备的失败弹出窗口。用于查看批次在当前工步和已完成的插入的产量失败。

所选批次的“批次信息”弹出窗口。用于查看批次的属性、流程规范参数、消耗品物料、工具计划和配方。

批次选项卡字段定义

“批次”选项卡提供一个仅显示表格，其中显示批次详细信息。此表定义“批次”选项卡中的字段。

字段

定义

容器

显示要处理的批次的列表。

计时器

显示与批次关联的流程计时器的已经过时间。单击字段箭头可查看计时器详细信息。

数量

对于项处理工步中的项，这是项处理工步中所有晶元上所有晶片的总和。

对于不在项处理工步中的批次，这是晶片数量。

数量

显示批次中的晶片数量。

数量 2

显示批次中的项（晶元）数量。

规范

批次的当前工作流程工步引用的规范的名称。

工步

显示批次的流程工步。

此处天数

批次已在当前工步中停留的天数。

队列时间

自上次记录的移出时间以来批次已在此流程中停留的时间量。

产品

与批次关联的产品。

状态

批次的状态。允许的状态如下：

• 活动 – 仅当当前状态为“已取消”时才允许。这是为了在取消插入后重新激活插入。
• 已终止 – 批次已终止。
• 已装运 – 批次已装运。

搁置中

表示批次是否搁置。

返工中

表示批次当前是否处于返工状态。

插入

批次在当前工步中的处理次数。

插入流程规范

定义插入的流程规范。

插入 SS

定义插入的补充规范。

拒绝

批次中的已拒绝晶元数量。

移出数量

要移出的晶片数量。

WIP 状态

表示批次的 WIP 状态。应用程序会显示以下可能状态：

• 活动
• 完成

WIP 类型

批次处于的 WIP 事务的类型。例如“追踪”。

WIP 产量结果

指示整个批次通过还是未通过产量。如果批次未通过产量，则会将产量失败添加到 WIP 批次失败。可能的值包括：

• 空 – 尚未计算。
• 通过 – 所有产量检查均通过。
• 失败 – 一个或多个产量检查失败。

批号

批次的批 ID。

设备数

已在批次中使用该设备的次数。

设备加载数

已为批次加载该设备的次数。

存在未来搁置

表示批次是否计划为在将来工步中搁置。

在时间表中

表示批次是否已计划。

规范通过

批次处于的当前规范（工步）。

规范类别

规范（工步）的类别。例如，WIP。

规范类型

表示 WIP 规范的类型。应用程序将显示以下类型之一：

• 组装
• 背磨
• 测试
• 晶元分类
• 晶元

规范描述

与批次关联的 WIP 规范的描述。

计时器计数

批次的流程计时器数。

项选项卡字段定义

“项”选项卡提供一个仅显示表格，其中显示批次中的晶元的详细信息。此表定义“项”选项卡上显示的字段。

字段

定义

晶元刻印号

晶元的 ID。

容器

批次的名称。

槽位置

批次中晶元的槽位置编号。如果晶元采样方法为“用户选择”方法或其他不强制的方法，则可重新选择晶元或槽位置。如果对“整数 N 个”、“倒数 N 个”、“样本大小”和“样本百分数”方法强制执行晶元采样，将禁用重新选择。

有关“晶元 WIP 数据采样”、“WIP 数据设置”和“指派物料箱供料槽映射”页的信息，请参考《Opcenter Execution Semiconductor Modeling 指南》。

NDPW

每个晶元的晶片净量。晶元的当前数量。

良品数量

最终数量或活动数量。

晶元编号

晶元的简短 ID，用于在批次中标识该晶元。例如，01、02 和 03 等。

是劣质晶元

表示晶元是否不合格。

晶元排除出产量

表示是否从批次中移除晶元。

WIP 主要高级活动图块

“活动”窗口具有交互式图块，用于帮助引导用户完成相应的所需活动。

每个图块都具有“活动”消息、状态和颜色。状态和颜色将根据当前验证或在事务成功执行后进行动态更新。颜色和状态定义如下：

• 绿色 - 通过
• 黄色 - 未执行
• 蓝色 - 可选
• 红色 - 不完整的必要条件工步
