主页

“主页”提供了实时车间活动和汇总的集中化显示，有助于查看整个制造流程。该页面通过可视化和工具提示导航提供交互式体验，它将信息简化为图表、提供捷径并动态显示更新的车间更改，以提供基于时间的准确信息。

要确保主页显示为采用首选数据配置的默认显示，建议设置工作中心、员工和生产线指派设置。 选择适当的值有助于缩小主页上显示的数据的范围。 以下解释概述了此选择如何影响显示的数据：

• 在“工作中心”建模页中选择“资源组”字段有助于标识“调度列表”区段中显示的数据。
• 配置生产线指派设置有助于指定“调度列表”和“设备列表”区段中显示的信息。 有关应用程序如何根据生产线指派设置显示数据的说明，请参见“调度列表 ”和“装备状态”章节。
如何在工作中心中设置资源组字段

必须在“工作中心”建模页中选择“资源组”字段。按照以下步骤设置工作中心：

1. 登录 Opcenter Execution Semiconductor。
2. 通过选择建模 > 主要按钮，打开工作中心建模页。随即“建模”页中将显示“工作中心”页。
3. 对于新实例，在工作中心字段中输入名称。
4. 在资源组字段中选择资源组。在此页面中选择的“资源组”字段用于标识在“主页”的“调度列表”部分中显示的数据。
5. 单击保存。应用程序保存建模对象并显示成功消息。
如何设置员工

必须在“员工”建模页中选择“工作中心”、“工序”和“主页”字段。按照以下步骤设置员工建模对象：

1. 登录 Opcenter Execution Semiconductor。
2. 通过选择建模 > 主要按钮，打开员工建模页。随即“建模”页中将显示“员工”页。
3. 对于新实例，在员工字段中输入名称。
4. 在详细信息区段中，选择之前配置的工作中心。 选择的“工作中心”用于标识在“主页”的“调度列表”部分中显示的数据。
5. 在同一“详细信息”部分中，选择工序字段。选择的“工序”字段用于标识在“主页”的“装备状态”部分中显示的数据。
6. 在“门户”区段，在主页字段中选择 "scsLandingPage_vp"（如果尚未配置）。
7. 根据您的业务需求输入可选信息。有关可选字段的信息，请参见字段定义表。
8. 单击保存。应用程序显示成功消息。
如何设置生产线指派

“主页”可以配置为根据生产线指派设置显示特定资源、规范、工序或工作中心。生产线指派设置有助于限制在主页上显示的对象总数，否则，可能会显示数百个对象。

按照以下步骤更改或更新生产线指派设置：

1. 登录 Opcenter Execution Semiconductor。
2. 单击左下角菜单栏中的设置按钮。然后，单击设置生产线指派链接。将显示“设置生产线指派”弹出窗口。
3. 从以下一个或多个字段中选择值：
• 工作中心。工作中心下拉列表值按用户 ID 和工厂进行过滤。
• 工序。工序下拉列表值按工作中心进行过滤。
• 规范。 规范下拉列表值按工序进行过滤。
• 资源/工作单元。资源/工作单元下拉列表值按规范和工作中心过滤。
• 工作站。工作站下拉列表值按资源/工作单元、规范和工作中心进行过滤。
4. （可选）可以选中当我登录时不显示此内容复选框。选中时，登录后应用程序不会显示“设置生产线指派”页。如果清除该复选框，应用程序将在登录时显示“设置生产线指派”页，但前提是系统管理员将页面设为登录时可见。
5. 单击设置生产线指派。应用程序保存所做的更改，关闭弹出窗口，并在全局页眉中显示更新后的指派。选择左上角菜单栏中的“主页”按钮时，主页将显示并且已配置生产线指派设置。

有关生产线指派的信息，请参考《Opcenter Execution Core 车间指南》。

主页布局

主页包含以下区域：

1. 页面左上角包含调度列表 活动和状态。
2. 页面右上角包含装备状态详细信息。
3. 页面左下角包含前 3 天的拒绝条形图。
4. 页面的底部中间位置包含有关 WIP 图表的信息。
5. 页面右下角包含装备历史。

以下主题介绍了上述区域。

调度列表

调度列表卡片显示（移入、转入、转出或移出）处理状态的前 9 个批次。

默认情况下，此区段根据生产线指派设置显示批次。 例如，如果在生产线指派设置中选择了工作中心 MNT，调度列表图块将仅显示指派给 MNT 的前 9 个批次。下面说明了应用程序如何根据生产线指派设置显示数据：

• 资源：如果在生产线指派中设置了资源，调度列表将显示可以在此资源上运行的批次。  
• 规范：如果在生产线指派中设置了规范，调度列表将显示当前规范中的批次。
• 工序：如果在生产线指派中设置了工序，调度列表将显示当前 WIP 规范与此工序链接的批次。
• 工作中心：如果在生产线指派中设置了工作中心，调度列表将显示当前工序与所选工作中心链接的批次。

要搜索批次，只需在批次过滤器字段中输入批次名称。 此外，通过选择相关的过滤器图标，可以根据其处理状态（移入、转入、转出或移出）进一步过滤批次。

每个图块显示调度批次的信息。这些信息包括：

• 名称
• 数量（批次中的模具数量）
• 数量 2（批次中的晶元数量）
• 产品
• 当前 WIP 工步
• 流程类型图标，及
• 批次搁置状态

以红色高亮显示的图块表示批次在搁置中。

装备状态

装备状态部分显示多个装备信息图块，其中包括装备描述、制造状态以及指派给装备的 WIP 批次数。可通过过滤“资源组”下拉列表在“工作中心”建模对象中设置在此部分中显示的装备列表。可以根据要求使用“设置生产线指派”设置中的可用选项进一步过滤资源/工作中心。

首次登录主页时，设备状态区段根据生产线指派设置显示准则。 下面说明了应用程序如何根据生产线指派设置显示数据：

• 资源：如果在生产线指派设置中设置了资源，设备状态将显示所选资源的列表。
• 规范：如果在生产线指派设置中设置了规范，设备状态将在所选规范中显示设备。
• 工序：如果在生产线指派中设置了工序，设备状态将显示当前与作业 > WIP 规范 > 设备组关联的设备。
• 工作中心：如果在生产线指派中设置了工作中心，区段将解析与所选工作中心关联的资源组。

要搜索设备，只需在设备过滤器字段中输入设备名称。 此外，还可以通过选择可用性过滤器图标进一步过滤设备。

图块根据生产线指派设置或过滤的准则显示前 6 个设备，它们根据所选批次图块从左到右的最高优先级进行排序。

下图显示了“主页”中的“装备状态”部分的示例。

图块的颜色表示设备的可用性状态：绿色表示设备可用，红色表示设备不可用。 每个图块右角显示的数值表示指派给装备的 WIP 批次数。有关信息，请参考“主页显示定义”。

前 3 天的拒绝

“前 3 天的拒绝”条形图阐明了过去 3 天中已拒绝批次（Y 轴）数及其各自的损失原因（X 轴）。条形图根据在生产线指派设置中设置的“工作中心”或“工序”进行填充。此图表中显示的数据获取自“批次拒绝”页。

有关信息，请参考“主页显示定义”。

WIP 图表

WIP 条形图显示当前处理状态下的 WIP 工步名称（X 轴）和批次数量（Y 轴）。此图表中显示的数据基于生产线指派设置中的资源和工序设置。

图表根据每个工步的批次数动态加载。 单击“刷新”按钮可获取最新信息。有关信息，请参考“主页显示定义”。

装备历史

“装备历史”部分根据生产线指派设置中的选定资源显示详细的 OEE 指标图表。装备综合效率 (OEE) 表示装备相对于其实际产能的真正生产时间。此功能可帮助所有系统管理员根据可用性、性能、质量和 OEE 这四个主要指标配置和评估制造资源的效率。

注释: 仅当安装行业解决方案工作区时，“装备历史”部分的功能才可用。有关信息，请参考《Opcenter Execution Core Industry Solutions 用户指南》。

质量

表示资源的质量。资源的质量将使用公式“质量 = 优良数量/总数量”来计算，其中：

• 优良数量是 OEEThruputDetails 表中针对日历班次、日历日期和资源的组合统计的优良数量值的总和。
• 总数量是 OEEThruputDetails 表中针对日历班次、日历日期和资源的组合统计的总数量值的总和。

注：仅当安装了行业解决方案工作区时，此字段才可用。有关信息，请参考《Opcenter Execution Core Industry Solutions 用户指南》。

仅显示

OEE

表示装备的装备综合效率，该效率表示装备相对于其实际产能的生产时间。OEE 计算公式为其他要素的乘积：

• OEE = 可用性 * 性能 * 质量

注：仅当安装了行业解决方案工作区时，此字段才可用。有关信息，请参考《Opcenter Execution Core Industry Solutions 用户指南》。
