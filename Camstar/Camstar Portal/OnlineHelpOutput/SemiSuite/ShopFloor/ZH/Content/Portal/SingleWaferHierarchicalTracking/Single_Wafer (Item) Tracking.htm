单个晶元（项）追踪

通过单个晶元（项）追踪，可以将单独晶元（项）作为基于数量的批次进行处理和追踪。此方法不需要使用多级别开始。它利用 Opcenter Execution Core 和 Opcenter Execution Semiconductor 的现有功能。

注释: “单个晶元（项）追踪”已得到进一步增强，添加了以下功能，即物料箱作业 (HPE)、生产订单调度 (HPE) 和容器关闭 (HPE)。

如何使用单个晶元（项）追踪

按照以下步骤启动单个晶元（项）追踪：

1. 打开现有 Opcenter Execution Semiconductor 上的批次开始页。开始基础数量为 1 或更多的单独批次。（可选）可以将数量 2 值设为 1 以指示单个单独晶元（项），具体取决于为装备维护配置的触发。因为每个晶元（项）都是一个单独批次，所以不需要填充项表格。
注释: 要利用父子关系，需要创建数量为零 (0) 的父批次。只有当 PN（零件号）配置为“允许数量为零”时，才能这样操作。
注释: 在 Qty2=0 且数量=1 的情况下开始批次仅适用于非晶元对象类型。
2. 对父批次和/或子批次进行计划并发布到 WIP。现在，可以通过“WIP 主要高级”作为正常容器单独处理该操作。
3. 确保已定义工作流程内的所有 WIP 规范都配置为没有选中是项处理复选框。此外，确认没有选中需要转入数量复选框。
4. 如果要在父子配置中处理该批次，使用 Opcenter Execution Core 关联页创建必要的层次结构关系。此页面包含的限制比专为 WIP 关联流程设计的限制少。

关联完成后，父批次将成为“WIP 主要高级”中的可追踪批次。所有操作都将根据父批次创建并执行。如果需要，可以使用 Opcenter Execution Core 取消关联页移除当前父子关系。

记住，Opcenter Execution Semiconductor 还在规范和流程规范中提供了配置，用于在必须执行手动关联或手动取消关联时通知用户。此外，还可以根据需要为自动取消关联配置该功能。可在移入、移出和返工时触发这些功能。在发行版 8.6 中，已禁用转入和转出。
