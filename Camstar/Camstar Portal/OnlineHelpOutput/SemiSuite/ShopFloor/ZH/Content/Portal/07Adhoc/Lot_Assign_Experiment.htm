批次指派实验

“批次指派实验”页使您能够将“实验计划”指派给批次。实验计划是受控的，是非典型的处理计划，允许工程师测试想法。

通过“实验计划”对象进行模型实验，它本身是由其他已命名数据对象组成的。通过“实验计划”，可以定义自动拆分、自动搁置、备选检查单、特殊 WIP 和供料槽指示以及批次的备选补充规范。“实验计划”必须经过审批，才能将实验计划指派给批次。有关“实验计划”建模对象的更多信息，请参考 Opcenter Execution Semiconductor Modeling 指南。

还可以使用“批次指派实验”页将晶元指派给未序列化的物料箱中的供料槽。这意味着，可以进一步将实验计划限制在单个物料箱中的特定晶元上。

将实验计划指派给批次

在将“实验计划”指派给批次时：

• 可以使用“批次指派实验”页或“覆盖实验”矩阵对象，将实验计划指派给批次。在“批次指派实验”页上设置的实验计划指派会替代由“覆盖实验”矩阵对象指派的实验计划。有关覆盖实验矩阵对象的信息，请参考 Opcenter Execution Semiconductor Modeling 指南。
• 只能附加“实验计划状态”字段设为“已批准”的“实验计划”。有关实验计划审批流程的信息，请参考 Opcenter Execution Semiconductor Modeling 指南。
• 可以将相同的“实验计划”附加到多个批次。
• 可以将多个“实验计划”附加到一个批次。
• 可以将晶元的位置指派到序列化晶元物料箱的特定供料槽中。为了将晶元指派到晶元物料箱的特定供料槽中，必须首先定义晶元物料箱。有关晶元物料箱的信息，请参考 Opcenter Execution Semiconductor Modeling 指南。
• 如果不使用序列化的晶元物料箱，则可以根据所选择的与制造中使用的物料箱结构一致的“晶元物料箱系列”来指派晶元物料箱。

使用晶元物料箱系列供料槽

在使用晶元物料箱系列供料槽时，记住以下要点：

• 不能将晶元映射到停用的供料槽。
• 只能从尚未移入 WIP 的晶元物料箱或当前未在设备中处理的晶元物料箱移除晶元。
• 从晶元物料箱移除晶元时，必须在提交物料箱之前移除单个批次中的所有晶元。
• 不能提交包含部分批次的物料箱。
• 如果批次已经具有指派的序列化晶元物料箱，则无法创建和指派晶元物料箱系列供料槽。

在将实验计划指派给批次前

在将“实验计划”指派给批次之前，必须执行以下操作：

1. 根据“实验计划”的要求，创建以下建模对象的实例。
• 实验自动搁置
• 实验自动拆分
• 实验自动 SS
• 实验特殊指示
• 实验特殊检查单

有关这些建模对象的信息，请参考 Opcenter Execution Semiconductor Modeling 指南。

2. 创建和审批“实验计划”。有关实验计划建模对象和审批流程的信息，请参考 Opcenter Execution Semiconductor Modeling 指南。
3. 创建和计划要附加“实验计划”的批次。

如何将实验计划指派给批次

按照以下步骤将“实验计划”指派给批次：

1. 打开批次指派实验页。
2. 在选择 Id 字段中输入要将“实验计划”指派到的批次的名称。该应用程序显示“批次”表格中的批次以及“晶元列表”表格中的晶元信息。
3. 在“批次指派实验详细信息”表格中，指定在实验计划列中附加到批次的“实验计划”。
4. 如果要使“实验计划”处于活动状态，选中是激活的复选框。
重要提示: 如果未选中是激活的复选框，应用程序将忽略由实验计划指定的任何替代。
5. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
6. 完成“如何将晶元指派给供料槽”中的过程，将晶元指派到供料槽。
注释: 在使用基于数量的批次时，或者如果已经使用“指派物料箱供料槽映射”页将序列化的晶元物料箱指派给批次，则必须将晶元指派给供料槽。有关“指派物料箱供料槽映射”页上的信息，请参考“指派物料箱供料槽图”。

或

单击提交。 应用程序将“实验计划”指派给批次，并显示一条成功消息。应用程序使用将“实验计划”指派给批次的用户的 ID 来填充“指派用户”。如果选中了“是激活的”复选框，则应用程序将使用激活“实验计划”的用户的 ID 填充“激活用户”列。

如何将晶元指派给供料槽

按照以下步骤将单个晶元指派给供料槽：

注释: 在使用基于数量的批次时，或者如果已经使用“指派物料箱供料槽映射”页将序列化的晶元物料箱指派给批次，则必须将晶元指派给供料槽。有关“指派物料箱供料槽映射”页上的信息，请参考“指派物料箱供料槽图”。
1. 完成“如何将实验计划指派给批次”中的过程。
2. 在晶元物料箱系列字段中输入晶元物料箱系列。
注释: 并非总是需要晶元物料箱。如果使用基于数量的批次，则无需执行此操作。此外，如果已经通过“指派物料箱供料槽映射”指派了序列化晶元物料箱，则不需要执行此操作.
3. 执行以下一项操作：

如果要指派 ...

执行以下操作 ...

单个晶元到供料槽
a. 单击“晶元列表”表格的行上的箭头，该晶元列表包含要指派给供料槽的晶元。
b. 在供料槽编号字段中输入所选行中的晶元将被指派到的供料槽编号。
c. 单击添加。应用程序将在“物料箱供料槽映射”表格中显示晶元信息。

所有的晶元到供料槽

单击全部添加。应用程序将在“物料箱供料槽映射”表格中显示晶元信息。

如何从物料箱供料槽中移除晶元

按照以下步骤从晶元供料槽中移除晶元：

1. 打开“批次指派实验”页。
2. 在选择 Id 字段中输入要从供料槽中移除晶元的批次名称，然后单击。该应用程序显示“批次”表格中的批次以及“晶元列表”表格中的晶元信息。
3. 执行以下一项操作：

如果要移除...

执行以下操作 ...

物料箱的单个晶元
a. 从供料槽编号字段中选择包含要移除的晶元的供料槽编号。
b. 单击移除。应用程序将在“物料箱供料槽映射”表格中移除映射供料槽的晶元信息。

物料箱的所有晶元

单击全部移除。应用程序将从“物料箱供料槽映射”表格中移除所有晶元信息。
