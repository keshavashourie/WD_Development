转入

WIP 主要高级转入将在装备中开始批次处理。在下列情况下，应用程序将启用转入：

• 工步配置用于装备处理。
• 批次的处理尚未完成，或者批次可以重新处理。

如果配方与要转入的装备关联，应用程序将确保配方处于活动状态。

注释: 当物料箱待转入时，应用程序将验证“内部输入物料箱系列”的要求。 如果检测到不正确的“内部输入物料箱系列”，系统会提示出错消息。

加载端口

加载端口是一个装备。当“装备”字段中的所选装备建模为“父资源”时，将显示此字段。至少有一个子装备必须配置装备类型（加载端口）并具有指派的子装备逻辑 ID。如果为装备至少配置了一个加载端口，则“转入”事务需要“加载端口”。“加载端口”下拉列表仅显示状态当前设为“可用”的加载端口。

注：将在跟踪期间验证加载端口的批次维护要求。这些要求包括“日期要求”、“重复日期要求”、“生产量要求”和“使用要求”。

有关详细信息，请参考《Opcenter Execution Semiconductor Modeling 指南》。

如何取消非处理项的转入

通过调整下一个转出流程中的数量值，可以手动取消转入，而无需使用取消转入复选框。 注意，这些工步仅适用于基于数量的批次，不适用于基于晶元的批次。 按照以下步骤取消转入：

1. 访问 WIP 主要高级页，以访问之前转入的批次。
2. 在选择 Id 字段中为转出流程输入批次 ID。 应用程序使用输入的批次的信息填充字段。
3. 在转出数量字段中输入值 "0" 以取消上一个转入数量。
4. 单击提交以转出批次。应用程序显示成功消息。现在，该页将返回到上一个转入，当您在选择 ID 字段中输入相同的批次 ID 时，该页将在转入时显示上一个数量。
