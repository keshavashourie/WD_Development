自动化服务

此附录提供 Opcenter Execution Semiconductor 中 HPE 服务的描述和样本，这些服务可通过外部自动化服务或定制用户界面 (UI) 执行。

对于大多数事务，Opcenter Execution Semiconductor 提供了通过自动化层运行复杂设置的功能，该功能便捷、省时、可预测并且可减少人为错误。

有关使用高性能引擎增强的自动化服务的详细信息，请参考《Opcenter Execution Core 技术参考：高性能引擎》。

以下主题提供有关自动化服务的信息：

• 使用 “scsDBLotStartSimple” 服务创建物料箱容器
• 使用 “scsCarrierPositionAssign” 服务创建物料箱容器
• 在 HPE 启动服务期间使用 "scsDBContainerName" 请求生成的容器名称
• 使用 “scsCarrierPositionAssign” 服务加载容器
• 使用 “scsCarrierPositionAssign” 服务卸载容器
• 使用 "scsDBContainerClosure" 服务关闭容器
• 多批次修改属性 (HPE) 服务
