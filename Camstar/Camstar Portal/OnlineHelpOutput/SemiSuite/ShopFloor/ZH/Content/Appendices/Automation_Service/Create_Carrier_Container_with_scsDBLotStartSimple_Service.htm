使用 “scsDBLotStartSimple” 服务创建物料箱容器

如果在请求 XML 中指定了物料箱，则可以使用 "scsDBLotStartSimple" 服务创建物料箱容器。使用 “scsDBLotStartSimple” 服务创建物料箱容器时，可通过将以下脚本添加至 XML 请求，选择向物料箱容器指派其自己的“启动原因”、“所有者”和“级别”值：

<scsCarrierStartReason><__name><![CDATA[Carrier Start Reason]]></__name></scsCarrierStartReason>

<scsCarrierOwner><__name><![CDATA[Carrier Owner]]></__name></scsCarrierOwner>

<scsCarrierLevel><__name><![CDATA[Carrier Level]]></__name></scsCarrierLevel>


如果未在请求 XML 中传递“启动原因”、“所有者”和“级别”值，则应用程序将确定是否存在与物料箱的物料箱系列关联的车间集成设置。如果存在与物料箱系列关联的车间集成设置，应用程序将使用这些“启动原因”、“所有者”和“级别”值。如果“请求 XML”或任何“车间集成设置”未指定“启动原因”、“所有者”和“级别”值，则应用程序将使用在批次开始 - 批量 (HPE) 页或生产订单调度 (HPE) 页中指定的值。

为了汇总优先级，应用程序将根据以下优先级使用“启动原因”、“所有者”和“级别”字段：

1. 请求 XML 脚本，
2. “物料箱系列”中指定的“车间集成设置”，
3. 如果正在使用“批次开始 - 批量 (HPE)”页或“生产订单调度 (HPE)”页。这将在用户界面级别指定，而不是自动化。
注释: 如果正在使用编号规则在自动化层（使用 DBLotStartSimple）创建容器，则必须确保已在容器级别或 PN 中配置适当的编号规则。如果未检测到编号规则，应用程序将显示一条错误消息。必须应用以下设置：
• 必须在 Pn/产品系列/服务设置中配置编号规则。
• 如果“自动生成子项”设为 true，则必须在子项的容器级别下配置编号规则。
• 如果“自动生成子项”设为 true，则必须提供子项的容器级别。
