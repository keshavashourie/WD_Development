Opcenter Execution Semiconductor 中的流程计时器

流程时间强制通过流程计时器实现。所有流程计时器均配置了最短时间或最长时间，或者同时配置了两者。可以为流程计时器配置处置操作，当发生流程计时器违规时，应用程序将自动执行这些处置操作。

Opcenter Execution Semiconductor使用 Opcenter Execution Core 的标准流程时间强制功能，但进行了少量修改。

对 Opcenter Execution Semiconductor所做的更改
1. 添加了“未来搁置”作为处置操作。对于 Opcenter Execution Semiconductor，处置操作包括：
a. 业务规则
b. 生产事件
c. 返工
d. 非标准移动
e. 停工
f. 未来搁置
2. 已将“转入”、“转出”和“检查表”添加到支持流程计时器的事务的列表。对于 Opcenter Execution Semiconductor，默认情况下支持流程计时器的事务包括：
a. 移入
b. 移出
c. 移入
d. 移出
e. 电子流程（任务）
f. 检查表（任务）
3. “WIP 主要”页中的“批次选项卡”表格显示所选批次的任何流程计时器。
4. “设备 WIP 调度”页上的“调度列表批次”表格和“批次选项卡”表格都包含用于流程计时器显示的列。

流程计时器搜索页

“流程计时器搜索”页是 Opcenter Execution Core 的一个功能，通过该页面可以搜索和查看所有当前流程计时器和历史流程计时器。通过该页面还可以停止流程计时器。Opcenter Execution Semiconductor按原样使用该页面，并未进行任何修改。“流程计时器搜索”在Opcenter Execution Semiconductor主菜单“搜索”选项下提供。有关“流程计时器搜索”页的信息，请参考 Opcenter Execution Semiconductor Shop Floor 指南。

流程计时器阻止转入

在标准Opcenter Execution Semiconductor处理中，将批次转入设备资源后，无法通过“非标准移动”或“返工”事务处理批次。当计时器停止且计时器未能满足其时间限制时，批次可能处于转入事务中。如果将流程计时器配置为在其停止时完成事务，然后转入至返工或非标准移动工步，可能会出现问题。为避免此问题，在这些情况下，应用程序旨在绕过转入（流程计时器在此期间停止）并完成流程计时器中指定的处置操作（例如返工或非标准移动）。
