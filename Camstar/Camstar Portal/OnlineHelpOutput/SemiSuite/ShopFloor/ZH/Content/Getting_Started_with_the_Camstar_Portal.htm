入门

Siemens 提供 Portal Shop Floor 用户界面 (UI)，用于在应用程序中执行车间事务。有关 Siemens 在安装 Opcenter Execution Core 时提供的默认车间事务页的信息，请参考《Opcenter Execution Core Shop Floor 用户指南》。有关登录到应用程序、导航应用程序以及使用公用车间字段和功能的信息，请参考《Opcenter Execution Core 入门用户指南》。

安装 Opcenter Execution Semiconductor 后，默认情况下会将其他菜单项添加到主导航菜单中。通过这些菜单项可访问各个页面，从而能够执行 Opcenter Execution Semiconductor 车间事务。
