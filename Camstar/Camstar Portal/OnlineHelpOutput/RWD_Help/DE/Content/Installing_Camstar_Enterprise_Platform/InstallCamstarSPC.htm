[US290819 2210 RF] Gesamten Abschnitt entfernen Installieren von Opcenter EX CR Legacy Statistical Process Control

Dieser Abschnitt befasst sich mit der Installation von Opcenter Execution Core Legacy Statistical Process Control (Opcenter EX CR Legacy SPC). Die von Siemens bereitgestellte Seriennummer bestimmt, welche Produkte und Module Sie mit Ihrer Lizenz installieren können.

Lizenzierung

Vor der Installation dieser Produkte müssen Sie Lizenzen für Statit Software e-Server und ggf. für Statit Software CustomQC erwerben. Fordern Sie Lizenzen über den Produkt-Support an. Beachten Sie dabei, dass das Generieren der Softwarelizenzen von Drittanbietern länger dauern kann als das Generieren von Opcenter EX MDD- und Opcenter EX CR-Lizenzen. Kontaktieren Sie den Produktsupport vorzugsweise über das Support Center unter https://support.sw.siemens.com/. Eröffnen Sie ein Standard-Support-Ticket, um Lizenzen anzufordern.

Voraussetzungen

Die Voraussetzungen für einen Server mit dem Portal lauten wie folgt:

Opcenter EX CR Legacy SPC muss auf jedem Anwendungsserver installiert werden.

Der Server, auf dem Opcenter EX CR Legacy SPC installiert ist, muss eine Verbindung zur Produktionsdatenbank herstellen können.

Bei der Installation von Opcenter EX CR Legacy Statistical Process Control

Sie können Opcenter EX CR Legacy Statistical Process Control bei der Installation von Opcenter EX MDD oder Opcenter EX CR installieren. Sie können das Kontrollkästchen neben "SPC" und "Legacy SPC" im Dialogfeld "Installationsauswahl" aktivieren. Weitere Informationen finden Sie unter "Vorgehensweise zum Installieren in einer eigenständigen Umgebung". Sie können Opcenter EX CR Legacy SPC auch später installieren, indem Sie Ihre Installation verändern.

Sie müssen Opcenter EX CR SPC konfigurieren, nachdem Sie es installiert haben. Weitere Informationen finden Sie im Opcenter Execution Core Statistical Process Control-Referenzhandbuch.

Vorgehensweise zum Deinstallieren einer älteren Version

Führen Sie die folgenden Schritte aus, um eine ältere Version zu deinstallieren:

Heben Sie die Registrierung von "StatitCOMWrapper.dll" unter "<Laufwerksbuchstabe:>\Programme (x86)\Camstar\SPC\DLLs" mit dem Befehl "regsvr32 StatitCOMWrapper.dll /u" auf.

Löschen Sie die alte Datei "StatitCOMWrapper.dll" in allen Ordnern, in denen Sie die Datei finden können.

Löschen Sie die alte Datei "CamstarxxxxSPC.dll" im DLL-Ordner und in allen Ordnern, in denen Sie die Datei finden können.

Löschen Sie die alte SPC VB-Testanwendung in allen Ordnern, in denen Sie die Anwendung finden können, nachdem Sie alle Anpassungen aufgezeichnet haben.

Vorgehensweise zum Einrichten der COM-Sicherheit

Führen Sie die folgenden Schritte aus, um die COM-Sicherheit einzurichten:

Klicken Sie auf Start > Windows-Verwaltungsprogramme > Komponentendienste. Das Fenster "Komponentendienste" wird angezeigt.

Erweitern Sie Komponentendienste und dann Computer, sodass "Arbeitsplatz" angezeigt wird.

Klicken Sie mit der rechten Maustaste darauf und wählen Sie Eigenschaften aus. Das Dialogfeld "Eigenschaften von Arbeitsplatz" wird angezeigt.

Klicken Sie auf COM-Sicherheit (COM Security).

Klicken Sie auf Standard bearbeiten im Bereich "Zugriffsberechtigungen" (Access Permissions) und gewährleisten Sie, dass die folgenden Konten lokalen Zugriff und Remotezugriff haben:

ASPNET

nnn\IUSR_nnn (wobei nnn der Name des Computers ist)

nnn\IWAM_nnn (wobei nnn der Name des Computers ist)

Interaktiv (Interactive)

Netzwerkdienst (Network Service)

System

Eigenes Konto

Klicken Sie auf OK, um zum Dialogfeld "Eigenschaften von Arbeitsplatz" zurückzukehren.

Klicken Sie auf Standard bearbeiten im Bereich "Start- und Aktivierungsberechtigungen" (Launch and Activation Permissions) und geben Sie folgenden Konten Startberechtigungen:

ASPNET

XXX\IUSR_XXX (wobei XXX der Name des Computers ist)

XXX\IWAM_XXX (wobei XXX der Name des Computers ist)

Interaktiv (Interactive)

Netzwerkdienst (Network Service)

Administratoren (Administrators)

System

Eigenes Konto

Klicken Sie zweimal auf OK. Die COM-Sicherheit ist eingerichtet.

Vorgehensweise zum Einrichten einer ODBC-Verbindung (Oracle)

Führen Sie die folgenden Schritte aus, um eine ODBC-Verbindung für SPC (Oracle) einzurichten:

Klicken Sie auf Start > Opcenter Execution Core.

Oder

Klicken Sie auf Start > Opcenter Execution Medical Device and Diagnostics.

Klicken Sie mit der rechten Maustaste auf die Anwendung Management Studio und klicken Sie dann auf Als Administrator ausführen.

Wählen Sie ODBC-Datenquellenadministrator (32-Bit) (ODBC Data Source Administrator (32-bit)) im Menü Tools aus. Das Dialogfeld "ODBC-Datenquellenadministrator (32-Bit)" (ODBC Data Source Administrator (32-bit)) wird angezeigt.

Klicken Sie auf die Registerkarte System-DSN (System DSN). Die verfügbaren Systemdatenquellen werden angezeigt.

Klicken Sie auf Hinzufügen. Das Dialogfeld "Neue Datenquelle erstellen" wird angezeigt.

Wählen Sie den Oracle 18-Treiber und klicken Sie auf Beenden. Das Dialogfeld "Oracle-ODBC-Treiberkonfiguration" (Oracle ODBC Driver Configuration) wird angezeigt.

Geben Sie CamstarMfgSPC als Name der Datenquelle ein.

Wählen Sie den TNS-Dienstnamen (TNS Service Name) aus.

Geben Sie eine Benutzer-ID (User ID) ein und überprüfen Sie die Verbindung.

Vorgehensweise zum Einrichten einer ODBC-Verbindung (SQL)

Führen Sie die folgenden Schritte aus, um eine ODBC-Verbindung für SPC (SQL) einzurichten:

Klicken Sie auf Start > Opcenter Execution Core.

Oder

Klicken Sie auf Start > Opcenter Execution Medical Device and Diagnostics.

Klicken Sie mit der rechten Maustaste auf die Anwendung Management Studio und klicken Sie dann auf Als Administrator ausführen.

Wählen Sie ODBC-Datenquellenadministrator (32-Bit) (ODBC Data Source Administrator (32-bit)) im Menü Tools aus. Das Dialogfeld "ODBC-Datenquellenadministrator (32-Bit)" (ODBC Data Source Administrator (32-bit)) wird angezeigt.

Klicken Sie auf die Registerkarte System-DSN (System DSN). Die verfügbaren Systemdatenquellen werden angezeigt.

Klicken Sie auf Hinzufügen. Das Dialogfeld "Neue Datenquelle erstellen" wird angezeigt.

Wählen Sie SQL Server aus und klicken Sie auf Fertig stellen. Das Dialogfeld "Neue Datenquelle für SQL Server erstellen" (Create New DataSource to SQL Server) wird angezeigt.

Geben Sie CamstarMfgSPC als Treibernamen ein.

Wählen Sie den Server aus, der verwendet werden soll.

Das Dialogfeld "DSN-Konfiguration" (DSN Configuration) wird angezeigt.

Wählen Sie den Authentifizierungstyp aus und geben Sie Anmelde-ID (Login ID) und Kennwort ein.

Wählen Sie die Datenbank aus und klicken Sie auf Weiter .

Klicken Sie auf Fertig stellen und überprüfen Sie die Verbindung.

Klicken Sie auf OK, bis sie wieder im Dialogfeld "ODBC-Datenquellenadministrator" (ODBC Data Source Administrator) sind.

Vorgehensweise zum Installieren von Opcenter EX CR Legacy SPC während der Erstinstallation

Gehen Sie folgendermaßen vor, um Opcenter EX CR Legacy SPC unter Windows Server 2019 während der Erstinstallation von Opcenter EX MDD oder Opcenter EX CR zu installieren:

Führen Sie die Schritte 1–11 unter "Vorgehensweise zum Installieren in einer eigenständigen Umgebung" aus.

Aktivieren Sie die Kontrollkästchen SPC und "Legacy SPC" im Dialogfeld "Einrichtungsauswahl", das angezeigt wird, wenn Sie Opcenter EX MDD oder Opcenter EX CR installieren, und klicken Sie auf Weiter.

Die Kontrollkästchen in der Opcenter EX MDD-Version des Dialogfelds "Installationsauswahl" werden mit "MDD" beschriftet. Der offizielle Name des Moduls ist Opcenter Execution Core Statistical Process Control (Opcenter EX CR SPC).

Nach der Anzeige des Dialogfelds für das Dienstkonto und Kennwort wird ein Dialogfeld mit der Frage angezeigt, ob Sie den Statit e-Server installieren möchten.

Klicken Sie auf Ja. Das Dialogfeld "Statit-Installationsinformation" (Statit Installation Information) wird angezeigt.

Geben Sie den Site-Namen, die Site-ID sowie einen gültigen Site-Code ein.

Übernehmen Sie den Standardwert für Zielordner (Destination Folder).

Wenn Sie die Statit-Installation an einem beliebigen Punkt abbrechen, betrifft dies nur die Statit-Installation selbst. Die Opcenter EX MDD- oder Opcenter EX CR-Installation wird nicht zurückgesetzt.

Das Dialogfeld "Auswahl bestätigen" (Confirm Selections) wird angezeigt.

Führen Sie die Schritte unter "Vorgehensweise zum Installieren in einer eigenständigen Umgebung" aus.

Vorgehensweise zum Hinzufügen von Opcenter EX CR Legacy SPC zu einer bestehenden Installation

Führen Sie die folgenden Schritte aus, um Opcenter EX CR Legacy SPC zu einer bestehenden Installation hinzuzufügen:

Fordern Sie die neue Lizenzdatei und die Seriennummer von Siemens an.

Öffnen Sie die Systemsteuerung. Das Fenster "Systemsteuerung" (Control Panel) wird angezeigt.

Klicken Sie auf Programme (Programs). Das Fenster "Programme" (Programs) wird angezeigt.

Klicken Sie auf Programme und Funktionen . Das Fenster "Programme und Funktionen" wird angezeigt.

Wählen Sie Opcenter Execution Medical Device and Diagnostics 8<n>oder Opcenter Execution Core 8<n> aus und klicken Sie auf Ändern. Das Dialogfeld "Willkommen" wird mit den Aktionen "Ändern", "Reparieren" und "Entfernen" angezeigt.

Lassen Sie die Option Ändern (Modify) aktiviert und klicken Sie auf Weiter . Das Dialogfeld "Sicherheitshinweise" wird angezeigt.

Das Installationsprogramm unterstützt keine Hyperlinks. Weitere Informationen zu Industrial Security finden Sie unter http://www.siemens.com/industrialsecurity.

Das Dialogfeld "Seriennummer" wird angezeigt.

Geben Sie die neue Seriennummer, die Sie von Siemens erhalten haben, in das Feld Seriennummer (Serial #) ein und klicken Sie auf "Weiter" . Das Dialogfeld "Funktionen auswählen" (Select Features) wird angezeigt.

Aktivieren Sie die Kontrollkästchen für SPC und "Legacy SPC" sowie die anderen Produkte oder Module, die Sie benötigen, und klicken Sie anschließend auf Weiter.

Die Kontrollkästchen in der Opcenter EX MDD-Version des Dialogfelds "Installationsauswahl" werden mit "MDD" beschriftet. Der offizielle Name des Moduls ist Opcenter Execution Core Statistical Process Control (Opcenter EX CR SPC).

Das Dialogfeld "Serverhost" (Server Host) wird angezeigt. Die Werte in den Feldern sind die Einstellungen für alle Standardkonfigurationsdateien.

Füllen Sie folgende Felder aus:

Geben Sie den Namen des Hostservers im Feld Anwendungshostserver (Application Host Server) ein.

Geben Sie die Port-Nummer für den Anwendungshost im Feld “Anwendungshostport“ ein.

Lassen Sie die Standard-URL für WCF-Dienste unverändert oder geben Sie eine neue URL in das Feld URL für WCF-Dienste ein.

Das Dialogfeld "Dienstkonto" (Service Account) wird angezeigt.

Geben Sie einen Active Directory-Benutzernamen und ein Kennwort für den Benutzer ein, unter dem alle Dienste ausgeführt werden, falls Sie eine Komponente ausgewählt haben, die als Dienst ausgeführt werden soll.

Nach der Anzeige des Dialogfelds für das Dienstkonto und Kennwort wird ein Dialogfeld mit der Frage angezeigt, ob Sie den Statit e-Server installieren möchten.

Klicken Sie auf Ja. Das Dialogfeld "Statit-Installationsinformation" (Statit Installation Information) wird angezeigt.

Geben Sie den Site-Namen, die Site-ID sowie einen gültigen Site-Code ein.

Übernehmen Sie den Standardwert für Zielordner (Destination Folder).

Wenn Sie die Statit-Installation an einem beliebigen Punkt abbrechen, betrifft dies nur die Statit-Installation selbst. Die Opcenter EX MDD- oder Opcenter EX CR-Installation wird nicht zurückgesetzt.

Das Dialogfeld "Auswahl bestätigen" (Confirm Selections) wird angezeigt.

Überprüfen Sie Ihre Auswahl und klicken Sie auf Weiter . Das Dialogfeld "Installationsstatus" (Setup Status) wird angezeigt und die Konfiguration der Softwareinstallation beginnt. Nach Abschluss der Installation wird das Dialogfeld "Wartung abgeschlossen" (Maintenance Complete) angezeigt.

Klicken Sie auf Fertigstellen. Das Installationsprogramm installiert Opcenter EX CR SPC und andere Produkte und Module, die Sie ausgewählt haben.

Führen Sie das Siemens PLM License Server-Installationsprogramm erneut aus und geben Sie die neue Lizenzdatei an, die Sie von Siemens erhalten haben. Dadurch werden die neuen Funktionen aktiviert.

Wenn Statit nicht installiert werden kann

Falls Sie Statit installieren und der Lizenzschlüssel nach drei Versuchen nicht bestätigt werden kann, wird eine Fehlermeldung angezeigt.

Führen Sie die folgenden Schritte aus, um Statit unabhängig zu installieren:

Wechseln Sie in den Ordner "C:\Programme (x86)\StatiteServer".

Öffnen Sie serverOEM.ini. Geben Sie Werte für SiteName, SiteID, SiteCode ein (ohne Leerzeichen nach dem =)

[General]

Update=1

Dir=C:\Programme (x86)\Statit e-Server

ResultsDir=C:\Programme (x86)\Camstar\SPC\Chart Output

ResultsURL=http://LocalMachineName/SPC

Log=C:\INSTALLATIONS\Camstar4.6\x64\Statit\e-ServerOEM.log

 

[License]

Eval=0

SiteName= Test

SiteId=1234

SiteCode=ABC12-3456D-EDCBA-54321-012YZ-4M5N6

 

[Config]

AbsoluteURL=1

SampleData=0

 

Führen Sie Statite-ServerOEM.exe aus.

Aufgaben nach der Installation

Nach der Installation von SPC sollten Sie die Standardmakros aktualisieren, falls Sie diese verwenden möchten.

ODBC-Verbindungsinformationen: ODBC-Verbindung, Benutzer, Kennwort

Beachten Sie, dass Opcenter EX CR SPC eine 64-Bit-ODBC-Verbindung erfordert.
