Installieren von Opcenter EX CR Inline Statistical Process Control

Dieser Abschnitt befasst sich mit der Installation von Opcenter Execution Core Inline Statistical Process Control (Opcenter EX CR SPC). Opcenter EX CR Inline SPC verwendet die gemeinsame SPC-Komponente. Die von Siemens bereitgestellte Seriennummer bestimmt, welche Produkte und Module Sie mit Ihrer Lizenz installieren können.

Voraussetzungen

Die Voraussetzungen für einen Server mit dem Portal lauten wie folgt:

Opcenter EX CR Inline SPC muss auf jedem Anwendungsserver installiert werden.

Der Server, auf dem Opcenter EX CR SPC installiert ist, muss eine Verbindung zur Produktionsdatenbank herstellen können.

Weitere Anforderungen finden Sie in der Release-Matrix für Ihre Version im Siemens Support Center.

Weitere Anforderungen finden Sie in der Release-Matrix für Ihre Version im Siemens Support Center.

Beim Installieren von Opcenter EX CR Inline SPC

Sie können Opcenter EX CR Inline Statistical Process Control bei der Installation von Opcenter EX MDD oder Opcenter EX CR installieren. Sie können das Kontrollkästchen "Inline SPC" im Dialogfeld "Installationsauswahl" aktivieren. Weitere Informationen finden Sie unter "Vorgehensweise zum Installieren in einer eigenständigen Umgebung". Sie können Opcenter EX CR Inline SPC auch später installieren, indem Sie Ihre Installation verändern.

Die folgenden Skripte sind in der Installation enthalten:

SPCConfiguration.cfg für SQL

SPCConfiguration.ORA.cfg für Oracle

Sie müssen das entsprechende Skript ausführen, nachdem Sie die Installation abgeschlossen haben. Weitere Informationen finden Sie im Opcenter™ Execution Core Transaction Tester-Benutzerhandbuch.

Sie müssen Opcenter EX CR Inline SPC konfigurieren, nachdem Sie es installiert haben. Weitere Informationen finden Sie im Opcenter Execution Core Inline Statistical Process Control-Referenzhandbuch.

Vorgehensweise zum Einrichten einer benutzerdefinierten ODBC64-Verbindung für Oracle

Gehen Sie folgendermaßen vor, um eine benutzerdefinierte Oracle-ODBC64-Verbindung für Inline SPC einzurichten:

Laden Sie die ODBC- und Basispakete für Windows x64 von der Oracle-Website herunter: https://www.oracle.com/database/technologies/instant-client/winx64-64-downloads.html.

Extrahieren und speichern Sie die Oracle-Pakete in C:\Oracle\instantclient_[Versionsnummer]. Die Oracle-Dateien werden im Oracle-Ordner entpackt.

Führen Sie die Eingabeaufforderungsanwendung als Administrator aus und geben Sie cd c:\Oracle\instantclient* ein. Drücken Sie die Eingabetaste. Das Verzeichnis wird in der Eingabeaufforderung geöffnet.

Geben Sie den Befehl odbc_install.exe ein und drücken Sie die Eingabetaste. Die Meldung "Oracle-ODBC-Treiber wurde erfolgreich installiert" wird angezeigt.

Öffnen Sie die ODBC64-Anwendung und wählen Sie die Registerkarte System-DSN aus. Das Dialogfeld "ODBC-Datenquellenadministrator (64-Bit)" wird angezeigt.

Klicken Sie auf Hinzufügen. Das Dialogfeld "Neue Datenquelle erstellen" wird angezeigt.

Wählen Sie den neu installierten Oracle-Treiber aus (er wird als "Oracle in instantclient_[Release-Nummer]" angezeigt) und klicken Sie auf Fertigstellen. Das Dialogfeld "Oracle-ODBC-Treiberkonfiguration" wird angezeigt.

Füllen Sie die folgenden Felder aus:

Datenquellenname: Inline SPC

TNS-Dienstname: (Datenbankname)

Benutzer: (Benutzer-ID)

Öffnen Sie Management Studio, um den entsprechenden Datenbanknamen für das Feld "TNS-Dienstname" und die Benutzer-ID für das Feld "Benutzer" zu suchen.


Klicken Sie im Dialogfeld "Oracle-ODBC-Treiberkonfiguration" auf Verbindung testen. Das Dialogfeld "Oracle-ODBC-Treiberverbindung" wird angezeigt.

Geben Sie den entsprechenden Benutzernamen und das Kennwort für die Datenbank ein und klicken Sie auf OK. Eine Erfolgsmeldung wird angezeigt.

Klicken Sie auf OK. Das Meldungsdialogfeld wird geschlossen und der neue Treiber wird jetzt in der Liste der Systemdatenbankquellen im Dialogfeld "ODBC-Datenquellenadministrator (64-Bit)" angezeigt.

Öffnen Sie die Seite "SPC-Verbindung" in der Modellierung, um die Verbindung zu konfigurieren.

Vorgehensweise zum Einrichten einer benutzerdefinierten ODBC64-Verbindung für SQL

Gehen Sie folgendermaßen vor, um eine benutzerdefinierte SQL-ODBC64-Verbindung für Inline SPC einzurichten:

Öffnen Sie die ODBC64-Anwendung und wählen Sie die Registerkarte System-DSN aus. Das Dialogfeld "ODBC-Datenquellenadministrator (64-Bit)" wird angezeigt.

Klicken Sie auf Hinzufügen. Das Dialogfeld "Neue Datenquelle erstellen" wird angezeigt.

Wählen Sie "SQL Server" aus und klicken Sie auf Fertigstellen. Das Assistentendialogfeld "Neue Datenquelle für SQL Server erstellen" wird angezeigt.

Füllen Sie die folgenden Felder aus:

Name: InlineDriver

Server: [SQL Server-Name]

Klicken Sie auf Weiter. Das nächste Dialogfeld im Assistenten wird angezeigt.

Geben Sie den Anmeldenamen und das Kennwort für den SQL Server ein und klicken Sie auf Weiter. Das nächste Dialogfeld im Assistenten wird angezeigt.

Wählen Sie die Standarddatenbank aus und klicken Sie auf Weiter. Das nächste Dialogfeld im Assistenten wird angezeigt.

Klicken Sie auf Fertigstellen. Das Zusammenfassungsdialogfeld für den Assistenten wird angezeigt.

Klicken Sie auf Datenquelle testen (Test Data Source). Die Testergebnisse werden mit einer Erfolgsmeldung angezeigt.

Klicken Sie auf OK. Das Meldungsdialogfeld wird geschlossen und der neue Treiber wird jetzt in der Liste der Systemdatenbankquellen im Dialogfeld "ODBC-Datenquellenadministrator (64-Bit)" angezeigt.

Öffnen Sie die Seite "SPC-Verbindung" in der Modellierung, um die Verbindung zu konfigurieren.

Vorgehensweise zum Installieren von Opcenter EX CR Inline SPC während der Erstinstallation

Gehen Sie folgendermaßen vor, um Opcenter EX CR Inline SPC unter Windows Server während der Erstinstallation von Opcenter EX MDD oder Opcenter EX CR zu installieren:

Führen Sie die Schritte 1–11 unter "Vorgehensweise zum Installieren in einer eigenständigen Umgebung" aus.

Aktivieren Sie das Kontrollkästchen Inline SPC im Dialogfeld "Installationsauswahl", das angezeigt wird, wenn Sie Opcenter EX MDD oder Opcenter EX CR installieren, und klicken Sie auf Weiter.

Das Kontrollkästchen in der Opcenter EX MDD-Version des Dialogfelds "Installationsauswahl" wird mit "MDD" beschriftet. Der offizielle Name des Moduls lautet Opcenter Execution Core Inline Statistical Process Control (Opcenter EX CR SPC).

Führen Sie die Schritte unter "Vorgehensweise zum Installieren in einer eigenständigen Umgebung" aus. Das Dialogfeld des Installationsassistenten für die gemeinsamen SPC-Komponenten wird angezeigt.

Das Dialogfeld "Fehlende Abhängigkeiten" wird angezeigt, wenn der Assistent nicht bestätigen kann, dass die richtigen Versionen unterstützender Software installiert sind. Weitere Informationen finden Sie unter "Voraussetzungen".

Das Dialogfeld "Zielordner" wird angezeigt.

Das Dialogfeld "Bereit zum Installieren der gemeinsamen Komponenten" wird angezeigt.

Das Dialogfeld "Gemeinsame SPC-Komponente installieren" wird angezeigt.

Das Dialogfeld des Installationsassistenten für die gemeinsamen SPC-Komponenten wird angezeigt, wenn die Installation abgeschlossen ist.

Klicken Sie auf Fertigstellen. Die Installation der gemeinsamen SPC-Komponenteninstallation ist abgeschlossen.

Vorgehensweise zum Hinzufügen von Opcenter EX CR Inline SPC zu einer bestehenden Installation

Führen Sie die folgenden Schritte aus, um Opcenter EX CR Inline SPC zu einer bestehenden Installation hinzuzufügen:

Fordern Sie die neue Lizenzdatei und die Seriennummer von Siemens an.

Öffnen Sie die Systemsteuerung. Das Fenster "Systemsteuerung" (Control Panel) wird angezeigt.

Klicken Sie auf Programme (Programs). Das Fenster "Programme" (Programs) wird angezeigt.

Klicken Sie auf Programme und Funktionen . Das Fenster "Programme und Funktionen" wird angezeigt.

Wählen Sie Opcenter Execution Medical Device and Diagnostics 2410 oder Opcenter Execution Core 2410 aus und klicken Sie auf Ändern. Das Dialogfeld "Willkommen" wird mit den Aktionen "Ändern", "Reparieren" und "Entfernen" angezeigt.

Lassen Sie die Option Ändern (Modify) aktiviert und klicken Sie auf Weiter . Das Dialogfeld "Sicherheitshinweise" wird angezeigt.

Das Installationsprogramm unterstützt keine Hyperlinks. Weitere Informationen zu Industrial Security finden Sie unter http://www.siemens.com/industrialsecurity.

Das Dialogfeld "Seriennummer" wird angezeigt.

Geben Sie die neue Seriennummer, die Sie von Siemens erhalten haben, in das Feld Seriennummer (Serial #) ein und klicken Sie auf "Weiter" . Das Dialogfeld "Funktionen auswählen" (Select Features) wird angezeigt.

Aktivieren Sie das Kontrollkästchen Inline-SPC im Dialogfeld "Installationsauswahl" und klicken Sie dann auf Weiter.

Das Kontrollkästchen in der Opcenter EX MDD-Version des Dialogfelds "Installationsauswahl" wird mit "MDD" beschriftet. Der offizielle Name des Moduls ist Opcenter Execution Core Statistical Process Control (Opcenter EX CR SPC).

Das Dialogfeld "Serverhost" (Server Host) wird angezeigt. Die Werte in den Feldern sind die Einstellungen für alle Standardkonfigurationsdateien.

Führen Sie das Verfahren "Vorgehensweise zum Installieren von Opcenter EX CR Inline SPC während der Erstinstallation", Schritte 3–7, aus.
