许可证管理

Opcenter EX MDD 和 Opcenter EX CR 包含基本产品。还包含可单独获得许可的各个产品和模块。要安装 Opcenter EX MDD 或 Opcenter EX CR，需要有效的许可证文件和序列号。还必须使用 Siemens Licensing 应用程序安装 Siemens License Server。

许可证文件基于您在购买 Opcenter EX MDD 或 Opcenter EX CR 时许可的产品和模块生成。有一个许可证文件。安装 Siemens License Server 时需要许可证文件。

序列号是在安装 Opcenter EX MDD 或 Opcenter EX CR 时输入的密钥。它决定了可供安装的产品和模块。唯一序列号包含购买的其他产品或模块。如果未购买任何其他模块，则与这些模块相关的所有实体将在 Designer 中显示为红色。

有关许可的信息，请参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。

许可证服务器

Designer 使用 Siemens PLM License Server。安装服务器后将创建新的 Windows 服务。 Designer 需要许可证服务器。

许可证密钥文件

许可证文件包含服务器和 Designer 的运行时许可证。许可证服务器将验证用户是否有权使用单独许可的模块。如果未安装许可证服务器，将无法使用这些功能。

注释: 如果有新许可证文件和新序列号，则可以升级现有 Opcenter EX MDD 或 Opcenter EX CR 安装来添加其他模块。有关信息，请参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。

许可将影响在 Designer 中选择不同实体时，这些实体的工作方式。下一部分中的 Designer 主题介绍安装功能许可后实体的行为。

注释: Designer 中实体旁边的红色图标表示模块未获得许可，或未安装许可证服务器。黄色图标表示已正确获得许可的单独许可模块。

更新许可证密钥

使用 Opcenter EX MDD 和 Opcenter EX CR，无需关闭服务器便可更新生产许可证。在紧急情况下（例如，由于许可证过期而无法访问 Opcenter EX MDD 或 Opcenter EX CR），可以生成临时许可证。有关信息，请参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。

按照以下步骤更新许可证密钥：

1. 生成临时许可证文件。
2. 使用许可应用程序将许可证文件替换为许可证服务器上的临时文件。
注释: 这不会影响正在运行的安全服务器或应用程序服务器。在执行定期许可证刷新和过期检查时，安全服务器将使用新的许可证信息。
