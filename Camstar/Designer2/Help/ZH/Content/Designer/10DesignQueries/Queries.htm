查询

Opcenter EX MDD 或 Opcenter EX CR 提供四种类别的查询：

• 高级查询
• CDO 查询
• NonQuery SQL 语句
• SQL 查询

通过系统执行查询的优势在于：

• 可以使用从 Opcenter EX MDD 或 Opcenter EX CR 到数据库服务器的现有数据库连接来运行查询，无需创建新的数据库连接。
• 集成了 Opcenter EX MDD 和 Opcenter EX CR 安全，无需依赖数据库服务器安全。

在 Opcenter EX MDD 和 Opcenter EX CR 中保留 SQL 查询和 CDO 查询只是为了确保向后兼容性。在编写新的查询时，Siemens 将建议编写高级查询。
