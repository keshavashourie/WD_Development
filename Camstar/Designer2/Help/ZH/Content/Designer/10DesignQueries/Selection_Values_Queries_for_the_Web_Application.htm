门户的选择值查询

必要条件

在门户中构建选择值查询时，有一些规则适用。对于给定查询，仅当存在下表中所示的列时，门户才能正确处理查询。

查询

列

SelectionValuesEx_NDO

InstanceID、Name

SelectionValuesEx_RDO

InstanceID、Name、Revision、RevOfRcd、Status

SelectionValuesEx_NSEofNDO

InstanceID、Name

SelectionValuesEx_NSEofRDO

InstanceID、Name

示例

如果要检索名称列为 OperationName 的作业，则必须使用以下 SQL 语句来检索：

Select OperationName As "Name" From Operation

过滤器标记

默认情况下，很多选择值查询都包含过滤器标记逻辑。可以向其他选择值查询和自定义查询添加过滤器标记逻辑，方法是在 where 子句中包含以下代码（其中，"$$cdo" 是在查询中引用的 CDO 别名）：

a. ##csiFilterTagMatch($$cdo.FilterTags, ? __filterTags, ? __allowUntaggedInstances) = 1

重要提示: 删除过滤器标记或移除过滤器标记逻辑可能会使引用已删除标记或逻辑的实例在应用程序中无法使用。
