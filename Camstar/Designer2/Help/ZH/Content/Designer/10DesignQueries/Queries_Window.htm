查询窗口

单击工具栏上的“查询”按钮将打开“查询定义”窗口。

窗口区域

“查询定义”窗口分为左右两个窗格。

左窗格包含一个用于显示以下查询类别的选择树：高级查询、CDO 查询、NonQuery SQL 语句和 SQL 查询。可以展开每个类别以显示该类别中的查询。

也可以通过在左窗格中右键单击来访问快捷菜单。快捷菜单选项包括：

• 添加查询定义
• 重命名查询定义（对默认查询禁用）
• 查找查询定义
• 移除查询定义（对默认查询禁用）
• 复制查询定义（如果展开类别并选择查询，则启用）

右窗格包含若干选项卡，每个选项卡都显示关于所选查询的特定详细信息。选项卡名称为：

• 常规选项卡
• 详细信息选项卡
• 参数选项卡
• 何处使用选项卡

选择树中的查询名称前面有一个问号图标。查询名称前有两个问号图标指示已定义了多个版本的查询语句，以处理不同类型的数据库需要不同查询语法的情况。

NonQuery SQL 语句类型

在执行 SELECT 以外的其他 SQL 语句时，使用 Designer NonQuery SQL 语句类型。例如，批量更新功能可以将 UPDATE 语句或存储程序用作业务逻辑的一部分。

对于 Oracle，用 BEGIN 和 END 将存储程序调用括起来，从而使用匿名块：

BEGIN MyStoreProcedure (?Parm1,?Parm2); END

要在 SQL Server 中调用存储程序，可使用不带圆括号的 EXEC 语法：

EXEC MyStoredProcedure ?Parm1,?Parm2;

NonQuery SQL 语句类型只能定义为 Designer 查询，并作为 Designer 查询执行，而不能是用户查询或特别查询。
