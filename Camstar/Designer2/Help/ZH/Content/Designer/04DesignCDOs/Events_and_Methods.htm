事件和方法

CDO 使用事件或方法启动 CLF。事件和方法充当从 CDO 到 CLF 的指针。事件和方法定义如下：

• 事件

事件是可能包含对 CLF 的引用的委托。

CDO 和字段具有一组预定义的事件，它们由系统自动触发。例如，当客户端应用程序在 CDO 字段上设置值时，系统将触发 Validate 事件等等。这一组事件不能由用户扩展。

可以通过将 CLF 附加到事件、修改关联 CLF 的函数参数值或从事件拆离 CLF 来修改系统行为。

• 方法

方法是包含对 CLF 的引用的委托。

由 Siemens 定义的 CDO 通常附加有方法。这些方法由服务的逻辑流、CLF 和事件触发，或直接从客户端应用程序触发。附加到 CDO 的这一组方法可由用户扩展。可以通过附加 CLF 来创建方法，通过拆离 CLF 来移除方法，以及通过修改函数参数值来改变方法。要将复杂的 CLF 分成按顺序执行的可重用组件，创建方法是一种常用的手段。

有关使用 Siemens .NET 客户端 API 的信息，请参考《Opcenter Execution Medical Device and Diagnostics 技术参考：客户端 API》或《Opcenter Execution Core 技术参考：客户端 API》。

注释: CDO 的事件或方法只能与一个 CLF 相关联。这样一来，每种类型的 CDO 便能以唯一的方式响应同一事件。

如果调用或触发 CLF，将按顺序调用每个函数，一次调用一个。
