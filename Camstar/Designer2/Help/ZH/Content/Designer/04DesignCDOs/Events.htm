事件

重要提示: 本主题与 Transaction::__Return 内置变量的使用相关。

事件由系统在 CDO 或字段上触发，并且可以通过将其与 CLF 相关联或通过修改 CLF 中的函数参数来进行修改。

在本主题中，事件分为 CDO 事件、字段事件和列表字段事件。有关信息，请参考“常见 情况”。

CDO 事件

是

执行服务时，在 cdo_validate 成功之后。

返回 true 或 false。如果 CLF 返回 false，则执行将中止。

AfterExecute

是

执行服务时，在 BeforeExecute 成功之后。

无。

注：在将事务实际提交到数据库之前调用 AfterExecute。

AfterCommit

是

在将事务成功提交到数据库之后。

如果在此事件中发生错误，不会导致服务回滚。

注：在此事件中发生未处理的错误时，会在触发 AfterCommitEventFailure 事件之前以相应的错误消息更新 ACEStatus 和 ACEMessage 字段。

AfterCommitEvent

是

如果在附加到 AfterCommit 事件的逻辑中发生未处理的异常。

可以通过 try-catch 块来捕捉错误。通过 catch 捕捉的错误不会触发 AfterCommitEventFailure 事件。

注：在此事件中发生未处理的错误时，会在触发 AfterCommitEventFailure 事件之前以相应的错误消息更新 ACEStatus 和 ACEMessage 字段。

Validate

是

设置字段时，在实际设置字段之前。

返回 true 或 false。如果 CLF 返回 false，则返回 FieldValidationFailed 错误，从而中止设置字段。

BeforeUpdate

是

设置字段时，在实际设置字段之前，但在触发 Validate 事件之后。

返回 true 或 false。如果 CLF 返回 false，则不会设置字段。

AfterUpdate

是

设置字段时，在设置字段之后。

返回一个字段。

AddItem

是

在将项添加到列表字段时。

返回 true 或 false。如果 CLF 返回 false，则不会添加该项。

RemoveItem

是

在从列表字段中移除项时。

返回 true 或 false。如果 CLF 返回 false，则不会移除该项。

DeleteItem

是

在从列表字段中删除子实体时。

返回 true 或 false。如果 CLF 返回 false，则不会删除该项。

注：首先触发 RemoveItem，如果该函数返回 true，然后再触发 DeleteItem。

MoveItem

是

在列表字段中移动项时。

返回 true 或 false。如果 CLF 返回 false，则不会移动该项。

ChangeItem

是

在更新列表字段中的项时。

返回 true 或 false。如果 CLF 返回 false，则不会设置该项。

GetItem

是

在请求列表字段中的项时。

返回一个值。如果需要，CLF 可以替代项值并返回不同的值。
