应用 Designer 更改和维护 Designer 用户

使用 Designer 对工厂模型所做的更改均记录在 Microsoft Access 文件的 InSite.mdb 中。在该过程之后，需要将更改传播到事务数据库 Siteinfo.mdb，如果适用，还要传播到 DataStore 数据库。

应用 Designer 更改

每次使用 Designer 进行更改时，均必须将这些更改应用于事务数据库和 DataStore 数据库。执行该操作的方法是：

• 单击工具栏中的更新 DB 按钮。

或

• 在 Management Studio 中执行更新数据库任务。

更改将应用于在 Management Studio 中设置的最高活动工作区。Designer 标题会显示工作区代码和描述，表示要应用更改的工作区。有关信息，请参考“Designer 标题”。

利用成批更新

可以利用成批更新设置来对大型数据集执行事务，例如处理大量容器或一个大型批事务时。要获取配置设计器以利用成批更新的帮助，可通过支持中心联系产品支持。

详细信息

有关更多详细信息，请参考《Opcenter Execution Medical Device and Diagnostics 系统管理指南》或《Opcenter Execution Core 系统管理指南》。
