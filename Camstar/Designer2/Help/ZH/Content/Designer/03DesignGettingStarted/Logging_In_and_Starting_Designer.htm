登录和启动 Designer

Siemens 提供三个默认的员工登录：CamstarAdmin、管理员和 InSiteAdmin。如果要使用其中一个角色作为登录 Designer 的默认值，则这些用户必须具有有效的 Windows 帐户。

登录 Designer 之前

对 Designer 的访问基于 Windows 的安全性。确保 Designer 用户具有有效的 Windows 帐户，并已将它们作为 Management Studio 中的 Designer 用户进行添加。有关将用户添加到 Designer 中的信息，请参考《Opcenter Execution Medical Device and Diagnostics 系统管理指南》或《Opcenter Execution Core 系统管理指南》。

Siemens License Server 必须已安装且正在运行，并且安全服务必须正在运行。有关启动服务的信息，请参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。

登录和启动 Designer

Designer“登录”窗口默认为首次登录 Designer 时用于登录到服务器的名称。Designer“登录”窗口默认将前一 Designer 用户名和密码用于后续的登录尝试。

如果 Designer 用户名与用于登录到服务器的用户名相同，则 Designer 不要求用户输入密码。如果 Designer 用户名与 Windows 登录用户名不同，则 Designer 要求用户输入密码。

如果 CSI 是最高的活动工作区，则系统会显示一条错误消息，阻止登录到 Designer。必须在 Management Studio 中激活另一个工作区，然后登录到 Designer。有关激活工作区的信息，请参考《Opcenter Execution Medical Device and Diagnostics 系统管理指南》或《Opcenter Execution Core 系统管理指南》。

如何登录 Designer

按照以下步骤登录到 Designer：

1. 单击开始 > Opcenter Execution MDD > Designer。将显示“Designer 登录”窗口。

或

单击开始 > Opcenter Execution Core > Designer。将显示“Designer 登录”窗口。

2. 保留当前用户名，或输入授权的 Designer 用户名。
3. 输入密码。
4. 验证到 MDB 的路径。如果数据库已移动到其他目录，则输入这些路径。
5. 单击登录。将显示 Designer 主窗口。
