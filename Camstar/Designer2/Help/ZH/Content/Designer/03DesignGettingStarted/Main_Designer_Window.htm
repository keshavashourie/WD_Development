Designer 主窗口

初始化时，Designer 窗口具有以下区域：

• 登录时指定的 InSite.mdb 的路径
• 菜单栏
• 工具栏


如果选择某个工具栏按钮或对应的菜单栏选项，其他窗口会显示特定的信息。选中时，工具栏按钮周围会显示蓝色边框。包含边框的按钮表示当前窗口。

Designer 标题

Designer 标题显示登录时指定的 InSite.mdb 的路径以及最高活动工作区的代码和描述。

在 Designer 标题中，最高活动工作区的代码和描述括在括号中，显示在 InSite.mdb 路径之前。工作区代码和描述指示哪个工作区接收在 Designer 中进行的更新。例如，可能会显示“Designer [工作区 [200 - 客户]]”，表示 Designer 中的任何更新都将应用到工作区代码为 200、描述为客户的对应工作区。

最高活动工作区在 Management Studio 中设置。有关信息，请参考《Opcenter Execution Medical Device and Diagnostics 系统管理指南》或《Opcenter Execution Core 系统管理指南》。

打开 Metadata Export 实用程序。Metadata Export 实用程序将比较两个数据库，并允许有选择地将差异（增量）导出至 XML 文件。有关信息，请参考“运行 Metadata Export 实用程序”。

首选项

包含两个选项卡：一个用于选择首选 XML 编辑器，一个用于在更新数据库时设置首选项。有关更新数据库时可用的首选项的信息，请参考应用 Designer 更改和维护 Designer 用户。

工具栏

除了帮助和更新 DB 外，每个工具栏按钮都显示一个 Designer 定义窗口，用户可在其中根据特定需求创建和修改 InSite 元数据。

此表介绍工具栏按钮选项。

按钮

按钮功能 ...

CDO

显示 CDO 定义窗口，可以在其中创建和修改可配置数据对象，以满足工厂模型的需要。使用它来定义对象和关联项（如字段、字段属性、表和映射）。系统按“视图”设置（“基本”或“高级”）来显示 CDO。

CLF

显示“逻辑流定义”窗口，该窗口按类别显示可配置逻辑流 (CLF)。CLF 指定对象的行为，并提供执行一个或多个任务的函数列表。在此窗口中，可以查看、添加、修改、移除或禁用 CLF。

字段

显示“字段类型定义”窗口，该窗口显示所有支持的字段类型。在此窗口中，可以添加、修改或移除用户定义的字段类型。

表

显示“表定义”窗口，该窗口按类别显示数据库表和列的列表。

函数

显示“函数定义”窗口，其中显示 Opcenter EX MDD 函数或 Opcenter EX CR 函数及其参数的列表。在此窗口中，可以查看默认函数，也可以添加、修改或移除用户定义的函数。

查询

显示“查询定义”窗口，该窗口包含预定义查询的列表以及自行创建的预定义查询的列表。在此窗口中，可以查看预定义查询，也可以创建和更新事务逻辑要使用的查询。

标签

显示“标签”窗口，该窗口列出了所有系统标签和用户标签。可以自定义所有文本（例如，注释和用户界面标签）。

类别

显示“类别定义”窗口。在此窗口中，可以定义表类别和存储类别。表类别用于对表进行分组。这些类别仅用于组织目的。存储类别用于存储对表类别的引用，以指示 CDO 非持久、不需要存储，还是将在以后确定存储类别。

帮助

在浏览器窗口中显示联机帮助。如果有已翻译版本的帮助，帮助会以浏览器中设置的首选语言显示。默认情况下，帮助以英语显示。

更新 DB

更新事务和 DataStore 数据库。将显示一个确认对话框，表示应用程序将根据首选项对话框中的设置保存当前 MDB 文件并更新数据库。如果选择“是”，则会在窗口底部显示一个状态栏，以指示更新正在进行中。
