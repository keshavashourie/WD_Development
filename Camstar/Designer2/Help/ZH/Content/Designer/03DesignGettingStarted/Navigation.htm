导航

每个 Designer 窗口有两个窗格：包含选择树的左窗格，包含有关所选树对象的详细信息的右窗格。

注释: 要刷新窗口，需要将其关闭。Designer 不支持 F5 刷新功能。

选择树

选择树包含所选工具栏选项的选项列表。单击加号可展开并显示更多选项。有关所选内容的详细信息显示在右窗格中。

搜索对象

在过滤字段中输入对象名称的前几个字符或完整对象名称可搜索特定对象。输入字符串将显示名称以该字符串开头的对象的字母顺序列表。

从列表中选择所需对象，或输入完整对象名称，然后单击转到。应用程序将展开选择树并高亮选定的对象。

命令按钮

命令按钮位于选择树的底部，在“标签”菜单栏或工具栏选项中没有命令按钮。

• 后退 - 返回到之前选定的对象。
• 添加 - 添加定制 CDO、CLF、字段、表、函数、查询和类别。
• 重命名 - 更改用户定义的 CDO、CLF、字段、表、函数和查询的名称。
• 移除 - 移除用户定义的 CDO、CLF、字段、表、函数、查询和类别。

右窗格中的命令按钮专用于显示的定义窗口：CDO 和 CLF 在有关这些选项的主题中介绍。

快捷菜单

右键单击鼠标时，所选区域中会出现快捷菜单。双击所选区域可显示用于设置属性的其他窗口，或移动到当前所选内容所引用的区域。这些内容在整个指南的其他主题中阐述。

打开和关闭 Designer 定义窗口

如果单击工具栏上的某选项，默认情况下将打开定义窗口。如果单击另一个按钮，一个定义窗口将打开并保持在焦点位置，但不关闭上一个窗口。可以打开多个定义窗口，通过菜单栏上的“窗口”选项可以排列窗口的布局。

要关闭任何定义窗口，单击 X 按钮。在 Designer 主窗口顶部最右侧也有一个 X 按钮，该按钮可终止 Designer 应用程序。

保存数据库更改

可以通过选择文件菜单上的保存来保存对数据库的更改。选择另存为以使用不同的 MDB 名称保存更改。

如何退出 Designer

要退出 Designer，选择“文件”菜单上的“退出”，或者单击 Designer 窗口右上角的 X。如果尝试退出 Designer 而不保存所做的更改，则会显示一个确认对话框。
