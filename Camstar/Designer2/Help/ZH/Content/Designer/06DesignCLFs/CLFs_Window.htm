CLF 窗口

CLF 窗口用于查看、添加、修改、移除或禁用可配置的逻辑流 (CLF)。单击工具栏上的 CLF 按钮即可打开 CLF 窗口。CLF 按类别进行分组。

CLF 选择树

左窗格包含一个选择树，其中列出了所有可用的 CLF 类别。在此选择窗格中右键单击可打开包含以下选项的快捷菜单：

• 添加 CLF 定义
• 重命名 CLF 定义（对默认 CLF 禁用）
• 移除 CLF 定义（对默认 CLF 禁用）
• 复制
• 粘贴

上述选项（“复制”和“粘贴”选项除外）也可以通过 CLF 选择窗格下方的按钮获得。注意，不能使用标准键盘快捷键进行复制和粘贴。

CLF 详细信息

右窗格包含有关选定 CLF 的详细信息。此窗格包含以下选项卡：

• 常规选项卡
• 函数选项卡
• CLF 参数选项卡
• 何处使用选项卡
• 功能授权选项卡

常规选项卡

CLF 的“常规”选项卡包含以下元素：

• 一个包含 CLF 描述的字段。当选择特定的 CLF 时，此字段会显示信息。它不在 CLF 类别级别显示信息。
• Designer 中的可见性 - 此区域包含三个选项按钮，它们表示选定的 CLF 是在 Designer 的基本视图中可见、在高级视图中可见，还是处于隐藏状态。保留以供 Siemens 使用的 CLF 处于隐藏状态。

函数选项卡

当展开类别并选择某个 CLF 时，函数选项卡将显示有关该 CLF 的详细信息。在工具栏上首次单击 CLF 时，将打开 CLF 定义窗口的“函数”选项卡。

“函数”选项卡包含三个区域：

• 逻辑流

此区域列出了组成 CLF 的函数的序列及其描述。

• 可用函数

此区域列出了可添加到逻辑流的函数。可以通过从列出的组中选择函数，或使用过滤器字段来搜索函数，来访问这些函数。在过滤器字段中输入函数名称的前几个字符或整个函数名称可搜索特定的函数。输入字符串将显示名称以该字符串开头的函数的字母顺序列表。从列表中选择所需的函数，或输入整个函数名称，然后单击转到。

注释: 对标准 CLF 可以使用数据库函数；而对高性能 CLF 可以使用标准函数。有关高性能 CLF 的信息，请参考“添加高性能 CLF”。
• 函数参数

此区域列出了特定于在逻辑流窗格中所选函数的参数的相关信息。根据选择的函数，将显示以下信息：

• 参数名称
• 使用某些数据库函数时，参数名称指示 SQLStatementName。可参考“添加高性能 CLF”。
• 值
• 方向
• “入”表示参数将值或引用传递给 CLF。
• “出”表示在 CLF 中设置参数。
• “入/出”表示参数将值传递给 CLF，且 CLF 将参数设为新的值或引用。
• “返回”表示 CLF 生成值。
• 动态

如果要使用查找表达式将参数作为动态值传递，选中“动态”复选框。如果要将参数作为实际值传递，保留其取消选中状态。如果函数强制实施参数类型（在“函数”窗口中通过“强制实施参数类型”标志来设置），则“动态”复选框会消失，而“多样性”和“数据类型”列会出现。
• 多样性

此属性指定参数可以或必须接受的值的数量。可能的值包括 0...*（零个或多个，因此是可选的列表）、0...1（零个或一个，因此是可选的）、1...1（一个，因此是必需的）和 1...*（一个或多个，因此是必需的列表）。
• 数据类型

“数据类型”列由参数数据类型或类型类和类型多样性连接而成。

“逻辑流”区域下方有四个按钮，这些按钮的用途由各自的名称表示：

• 添加
• 插入
• 移除
• 禁用

默认情况下，只有“禁用”按钮处于启用状态。从可用函数中选择函数时，“添加”和“插入”按钮将对用户定义的函数启用。函数已添加到或插入逻辑流时，“移除”按钮将对用户定义的函数启用。

此选项卡用于查看或修改组成 CLF 的函数（以及相应的参数）。

CLF 参数选项卡

CLF 参数可供 CLF 中的所有函数使用。

“CLF 参数”选项卡包含两个区域：

• 上方区域显示 CLF 范围内的现有参数。
• 下方区域包含用于定义或修改参数的字段。

参数列表下方是用于添加、插入或移除参数的按钮。

以下字段用于定义 CLF 参数：

• 参数名称

参数名称在 CLF 中的关联函数定义的关联中必须唯一。此名称（用作名称-值对构造的一部分）用于在运行时获取或设置参数值。

• 特殊处理

通过“特殊处理”字段，在与 CLF 相关联期间设置参数的字段值时，Designer 可以为某些处理项显示选择列表：

• CDO 名称
显示 CDO 名称的列表。
• DB 表名称
显示 DB 表名称的列表。
• 字段表达式
显示字段表达式构建器弹出窗口。
• 字段映射 ID
显示字段映射列表的列表。
• 标签 ID
显示标签列表。
• 标签名称
保留以供将来使用。
• 方法名称
显示附加到包括继承的方法的当前 CDO 的方法列表（仅事件视图）。
• 密码
保留以供将来使用。
• 查询名称-任意
显示查询定义的列表。
• 查询名称-CDO
显示 CDO 查询定义的列表。
• 查询名称-SQL
显示 SQL 查询定义的显示列表。
• [默认值]
• 方向
• 如果要将值或引用传递给 CLF，选择“入”。
• 如果要在 CLF 中设置参数，选择“出”。
• 如果要传递值并且希望 CLF 将参数设为新的值或引用，选择“入/出”。
• 如果希望 CLF 生成值，选择“返回”。
• 多样性

此属性指定参数可以或必须接受的值的数量。选项包括 0...*（零个或多个，因此是可选的列表）、0...1（零个或一个，因此是可选的）、1...1（一个，因此是必需的）和 1...*（一个或多个，因此是必需的列表）。

• 描述

“描述”字段用于描述如何使用参数。

• 数据类型

此字段显示相应参数的数据类型。

• 类型多样性

类型多样性进一步描述参数数据类型的特征。这意味着，可以指定参数为标量、列表还是这两者之中的任意一个 (ListOrScalar)。

• 特定类型

如果数据类型为“对象”，将显示“特定类型”字段，其中显示此字段的对象类型。

• 注释

何处使用选项卡

“何处使用”选项卡显示选定 CLF 的信息。该选项卡显示两种类型的信息：何处使用 CDO 事件，以及字段事件使用 CLF 的 CDO。

何处使用选项卡包含以下元素：

• CDO 名称
这是使用 CLF 时所在的 CDO 的名称。
或
这是包含正在使用 CLF 的字段的 CDO 的名称。
• 字段名称
这是包含调用 CLF 的事件的字段的名称。
• 事件名称
这是调用方法的 CDO 事件的名称。
或
这是调用 CLF 的字段事件的名称。
• 方法名称
这是调用 CLF 的 CDO 方法的名称。

功能授权选项卡

“功能授权”选项卡显示选定 CLF 的功能成员资格组。有关功能授权的信息，请参考“功能授权选项卡”。
