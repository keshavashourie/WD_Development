添加高性能 CLF

高性能 CLF 是 CLF 的一个类别，它们在数据库而非应用程序服务器上进行处理。高性能 CLF 定义为事务的一部分，并以一个或多个数据库语句（INSERT、UPDATE 和 DELETE）的形式发送到数据库。在数据库上执行 SQL 语句可提高处理效率。

High Performance Engine 是一项单独许可的功能。如果未获得该功能的许可，则不会显示高性能 CLF 类别。

有关 High Performance Engine 的信息，可参考《Opcenter Execution Core 技术参考：High Performance Engine》或《Opcenter Execution Medical Device and Diagnostics 技术参考：High Performance Engine》。

添加高性能 CLF

应用程序会在“可用函数”列表中显示标准函数和特定于数据库的函数。与其他 CLF 一样，可以添加、重命名和移除高性能 CLF。

向高性能 CLF 添加函数时，参数在高性能 CLF 的整个生命周期都可用并带有 DBCLF:: 前缀。DBCLF:: 变量由数据库存储程序创建。DBCLF:: 变量引用仅在数据库上使用。应用程序服务器会忽略 DBCLF:: 前缀，并将其传递到数据库。

在“可用函数”列表中选择某些数据库函数（例如 ExecuteSingleSQL）并将其拖动到“逻辑流”区域中时，应用程序会将 SQLStatementName 填充到“函数参数”区域的“参数名称”中。其他数据库函数没有 SQLStatementName 参数；例如，SQLParameter 具有“值”参数，数据库类型为 Any 且“多重性”设为 0..1

SQLStatementName 使用特殊处理。单击该字段的省略号时，将显示“选择查询”弹出窗口。可以在该弹出窗口中选择现有查询、编辑现有查询或创建新查询。只有高级查询和 NonQuery SQL 类型的查询可用。默认情况下未选中“包含所有工作区”复选框，表示只有工作区中的查询可供选择。通过选中该复选框，可以从其他工作区中选择查询。

仅当选择要编辑查询时，才会显示“查询定义”弹出窗口。只能编辑正在操作的工作区中定义的查询。

选择或编辑查询后，与该查询关联的任何参数都会返回到高性能 CLF。应用程序会将查询名称填充到 SQLStatementName 参数的“值”列中。所有查询参数都会显示在“逻辑流”区域中。这使您可以填充与查询关联的参数。

如果尝试将查询更改为新查询，将显示警告，询问您是否要重置当前 SQL 语句的 SQL 参数列表。如果是，应用程序将重置查询名称和参数。否则，应用程序会保留现有参数。

单击“选择查询”弹出窗口中的“新建”按钮可创建新查询。将显示空的“查询定义”弹出窗口。

如何添加高性能 CLF

按照以下步骤添加高性能 CLF：

1. 打开 Designer。
2. 单击 CLF。
3. 选择高性能类别。
4. 单击位于 CLF 列表框下方的添加按钮。应用程序将添加新的 CLF 并为其指派默认名称。
注释: 也可以右键单击选择树区域，然后选择添加 CLF 定义。

第一次添加 CLF 时，它处于重命名模式。

5. 输入此新 CLF 的名称。
6. 在常规选项卡中输入此 CLF 的描述。
7. 如果需要，更改 Designer 中的可见性设置。
8. 单击函数选项卡。

如果您想完成以下操作 ...

操作步骤 ...

选择一个查询
a. 从列表中选择一个查询，然后单击选择。应用程序会将查询名称填充到 SQLStatementName 参数的“值”列中。

编辑查询
a. 从列表中选择一个查询，然后单击编辑。将显示“查询定义”弹出窗口。
b. 编辑查询的定义，然后单击确定。将显示“选择查询”弹出窗口。
c. 确保选择所编辑的查询，然后单击选择。应用程序会将查询名称填充到 SQLStatementName 参数的“值”列中。

创建新查询

a. 单击新建。将显示“查询定义”弹出窗口。
b. 定义查询，然后单击确定。将显示“选择查询”弹出窗口。
c. 确保选择新查询，然后单击选择。应用程序会将查询名称填充到 SQLStatementName 参数的“值”列中。
14. 从文件菜单中选择保存。应用程序保存更改。
