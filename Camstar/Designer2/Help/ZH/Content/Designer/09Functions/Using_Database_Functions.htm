使用数据库函数

使用数据库函数可在数据库而非应用程序服务器上执行业务逻辑。在数据库上执行 SQL 语句可提高处理效率。此功能在单独许可的 High Performance Engine 功能部件中可用。

有关 High Performance Engine 的信息，可参考《Opcenter Execution Core 技术参考：High Performance Engine》或《Opcenter Execution Medical Device and Diagnostics 技术参考：High Performance Engine》。

使用数据库函数

应用程序会在“可用函数”列表中显示标准函数和特定于数据库的函数。与其他函数一样，可以添加、重命名和移除数据库函数。与大多数其他函数一样，大多数数据库函数的“描述”字段都包含介绍所选函数及其预期参数的用法的文档。

以下限制适用于数据库函数：

• 所有数据库函数的 GUID 都带有前缀 "DBE"。
• 不要在函数名称中包含空格。
• 每种 Execute 类型的函数都包含参数 "SQLStatementName"。
• SQLStatementName 参数的“特殊处理”设为“带有参数的 SQL 语句”。
注释: 某些数据库函数不包含 SQLStatementName 参数。包含 SQLStatementName 参数的 SQLStatementName 表征仅支持高级查询和 NonQuery SQL 类型的查询。
