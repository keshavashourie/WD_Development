查看函数

可以从“函数定义”窗口中查看函数库，也可以从 CLF 窗口中查看特定 CLF 的函数。

函数类型

函数按类型组织。Designer 中包含以下函数类型：

• DataObjectSpecific 函数
• CrossRefs 函数
• ServiceSpecific 函数
• Query 函数
• OnGetValue 函数
• ObjectProcessing 函数
• ObjectSpecificValidations 函数
• FieldProcessing 函数
• GenericValidation 函数
• String 函数
• TemplateProcessing 函数
• DatatypeConversion 函数
• FlowControl 函数
• 数据库函数
• List 函数
• UserFunctions 函数
• Date 函数

 

有关特定函数的描述，请参考 Designer 应用程序。

如何查看函数库

按照以下步骤查看函数库：

1. 打开 Designer。
2. 单击工具栏中的函数。将显示“函数定义”窗口。

 

3. 展开“函数”树并选择一个函数，即可在“常规”选项卡中查看它的描述。
4. 单击参数选项卡可查看函数参数和有关这些参数的信息，如用法、描述和数据类型。
5. 单击何处使用选项卡以查看关联的 CLF 及其描述。

 

6. 双击 CLF 可转到定义窗口。
