参数

参数是函数和 CLF 运行时所需值的占位符。参数具有唯一名称、输入/输出方向、多重性、数据类型、默认值和描述以及其他属性。给定函数或 CLF 的参数规范集定义了其在 Opcenter EX MDD 或 Opcenter EX CR 中的接口或通信协议。

定义函数参数

CLF 和函数通过唯一参数名称访问输入参数。参数值可以在函数或 CLF 设计时设置（称为参数的默认值），或在另一个函数或 CLF 运行时设置。指定参数可以像提供字段名称一样简单，也可以像将参数扩展为复杂表达式那样复杂。参数可以定义为：

• 数值或字符串常量
• FieldName
• FieldExpression
• 变量
• FieldExpression 从变量开始
• 内置变量
• Label 或 LabelID 指示符

如果选择使用表达式来表示参数，请参考“统一表达式”了解有关正确语法的信息。

参数数据类型

如果在函数的“常规”选项卡上设置了函数的“强制参数类型”标志，则可以根据以下四类参数数据类型进一步定义参数：

1. 次要

类型类别为“次要”的参数可以是以下任何类型：字符串型、布尔型、时间戳以及数值类型（整型、固定、浮点型、十进制）

2. 基本

此类别的类型由基本参数数据类型组成。其包括“次要”数据类型以及“对象”和“数值”。

3. 对象

对 CDO 的引用。如果参数类型为“对象”，还会指定对象名称。

4. 数值

类型类别为“数值”的参数可以为以下任一类型：

a. 整型：32 位整数
b. 浮点型：浮点数字
c. 固定：固定位数的小数和整数。定点数数据类型用于在数据库中将定点数存储为浮点数。浮点值是定点值的近似值。注意，“十进制”类型可用，应该用于存储精确的数值。
d. 十进制：固定点类型，与浮点型等近似数值类型不同，数值是精确的。
e. 任意：类型类别为“任意”的参数可以是任何其他数据类型和类型类别，以及：
• 结果集：参数是记录集。例如，参数是高级查询的结果。
• 参数：传递名称/值对的参数；例如，传递给查询的参数。

类型多样性

类型多样性进一步描述参数数据类型的特征。这意味着，可以指定参数为标量、列表还是这两者之中的任意一个 (ListOrScalar)。

多样性

此属性指定参数可以或必须接受的值的数量。选项包括 0...*（零个或多个，因此是可选的列表）、0...1（零个或一个，因此是可选的）、1...1（一个，因此是必需的）和 1...*（一个或多个，因此是必需的列表）。

参数和变量关联

CLF 编写者可以随时引入变量。变量寿命在首次设置其值时开始。参数和变量关联是指变量所在的关联。变量所属的范围或关联，变量的生命周期有所不同。

用于表达这些参数变量的三个范围或关联为：

• Transaction (Transaction::)

事务关联存在于服务 CDO 的关联中，它的存在贯穿 CDO 实例的整个寿命。如果需要在 CLF 之间保留或传递数据，则使用事务范围变量。事务关联是为特定服务的每个实例创建的，它们对于每个服务都是唯一的。设置事务范围变量的值之后，此值将保持不变，除非被更改，例如，由 CLF 更改。所有事务关联变量在其所属的服务被移除后立即被丢弃。

• CLF (CLF::)

只有执行 CLF 时，才会创建 CLF 关联。CLF 范围变量通常用于在 CLF 内的执行之间传递临时数据。如果需要在执行之间保留或传递数据，则使用 CLF 范围变量。避免在事务关联范围中使用本身属于 CLF 关联的变量。CLF 关联变量也用于将参数传递给 CLF。这些参数可通过 CLF 范围从 CLF 内访问。

注释: CLF:: 变量由应用程序服务器创建，但可以由数据库函数引用。高性能 CLF 参数带有 DBCLF:: 前缀，而 DBCLF:: 变量由数据库存储程序创建。DBCLF:: 变量引用仅在数据库上使用。应用程序服务器会忽略 DBCLF:: 前缀，并将其传递到数据库。有关高性能 CLF 的信息，请参考“添加高性能 CLF”。
• 功能 (Exe::)

函数关联用于函数参数。函数参数可通过 Exe 范围从函数内访问。函数关联在执行函数时创建。函数还可以使用可通过本地范围访问的变量引入本地关联。本地关联变量当前用于错误消息处理。

CLF 关联用于函数 1 和 2 的参数。这是因为参数值可以在函数之间传递。可能已选择了事务关联，但该值的存续期可能超出 CLF 的寿命期，这是不必要的。同样，函数关联无法在函数之间传递参数值，因为执行函数 1 后，参数即不再存在。

内置变量

内置 变量由应用程序服务器在 CLF 调用之前设为某些值，或者由应用程序服务器用于确定 CLF 返回的内容。

CLF::__CDOID

类型：对象引用

由应用程序服务器在调用 CLF 之前设为当前 CDO（CDO 和字段级别 CLF）

用法：在 CLF 中用于引用当前 CDO（CLF 附加到的 CDO）

Transaction::__Return

类型： 由用户设置

应用程序服务器要求 CLF 在响应某些 CDO 或字段事件时在此变量中返回一个值。

重要提示: 本章的“事件”部分内容均与 Transaction::__Return 内置变量有关。有关信息，请参考“编辑函数的参数值”。

用法：在 CLF 中用于返回用户设置的值

Transaction::__CurrentService

类型： 对象引用

由应用程序服务器在服务执行或验证开始时设为当前服务

该变量可由附加到 BeforeValidate、AfterValidate、BeforeExecute 和 AfterExecute 的 CLF 使用。

注释: 在客户端代码调用 Service.Execute 之前，不会设置此变量。此变量在执行 CompoundTxn 时设为每个 SubService。

用法：在 CLF 中用于引用当前服务（与 CLF 附加到的 CDO 无关）

CLF::__FieldValue

类型：与字段类型相同

由应用程序服务器在调用标量字段的 CLF 之前设为当前字段值

用法：用于附加到标量字段的字段事件的 CLF

CLF::__Index

类型： 整数

由应用程序服务器在调用列表字段事件的 CLF 之前设为当前列表字段项索引

以下是变量的可能值，具体取决于字段事件：

• 对于 AddItem 事件，值 = 新项索引
• 对于 ChangeItem 和 GetItem 事件，值 = 当前项索引
• 对于 RemoveItem 事件，值 = 当前项索引
或
如果项被值移除，则 RemoveItem 为 -1
• 对于 MoveItem 事件，值 = 源项索引

（CLF::__FromIndex 和 CLF::__ToIndex 变量也在 MoveItem 之前设置）

• 对于所有其他列表字段事件，值 = -1

用法：（很少使用）用于附加到列表字段的字段事件的 CLF

CLF::__ItemValue

类型： 与字段类型相同

由应用程序服务器在调用列表字段的 CLF 之前设为当前列表字段项值

用法：（很少使用）用于附加到列表字段的字段事件的 CLF

CLF::SessionValues

类型： 对象

允许访问与登录用户关联的 SessionValues CDO

由系统设置

用法：仅存在于 CVE 中并在其中使用

编辑函数的参数值

只能修改用户定义的函数的参数。

如何编辑函数的参数值

按照以下步骤编辑函数的参数值：

1. 打开 Designer。
2. 单击函数。将显示“函数定义”窗口。
3. 选择要为其编辑参数的用户函数。
4. 单击参数选项卡。

 

5. 选择要修改的参数。
6. 根据业务要求修改参数。
注释: 更改在函数库中进行。如果更改了默认值中的值，则使用此修改后的函数的所有 CLF 都不会受到修改的影响。必须打开 CLF，移除该函数，然后再将其添加回来。
7. 从文件菜单中选择保存。应用程序保存更改。

如何添加函数参数

只能将函数参数添加到用户定义的函数中。注意，当参数值添加到附加到 CDO 事件或方法的函数时，仅会影响 CLF 的模板版本。如果要对以前附加到 CDO 事件或方法的 CLF 使用新参数，则将 CLF 与该 CDO 拆离，并附加修改后的 CLF 定义。

按照以下步骤添加函数参数：

1. 打开 Designer。
2. 单击函数。将显示“函数定义”窗口。
3. 选择要向其添加参数的用户定义函数。
4. 单击参数选项卡。
5. 在“参数”选项卡上单击添加。列表中会显示一个使用默认名称的通用参数。

 

6. 在参数名称字段中输入新名称。
7. 在参数列表窗格上单击该通用参数以保存名称。新名称将替换通用名称。
8. 为特殊处理选择一个条目。
9. 选择函数参数的方向。
10. 选择多重性的值。
11. 输入函数参数的描述。
12. 从数据类型和类型重数列表中选择数据类型和类型重数。
13. 酌情输入参数的默认值。
14. 根据业务要求，在新函数参数的注释字段中输入注释和备注。
15. 单击另一个选项卡或选择要保存的其他函数。
16. 从文件菜单中选择保存。应用程序保存更改。

如何移除函数参数

只能从用户定义的函数中移除参数。

按照以下步骤移除函数参数：

1. 打开 Designer。
2. 单击函数。将显示“函数定义”窗口。
3. 选择要从中移除参数的用户函数。
4. 单击参数选项卡。
5. 选择要移除的参数。
6. 右键单击参数，然后在快捷菜单中单击“移除参数”，或在“参数”选项卡上单击移除。将显示一个确认对话框，提示确认移除参数。
7. 单击是。参数将从列表中移除。
8. 从文件菜单中选择保存。应用程序保存更改。

如何修改 CLF 函数中的默认参数

向 CDO 添加新的 CLF 时，已经提供函数的许多参数值。这些值称为 CLF 默认参数值。要修改这些默认值，必须修改 CLF 的定义。注意，更改默认参数值时，只会影响 CLF 的模板版本。因此，已附加到事件或方法的 CLF 参数值及其函数不会受到影响。如果要针对先前附加到事件或方法的 CLF 使用修改后的参数值，则需先拆离该 CLF 再附加修改后的 CLF 定义。

这些修改只会影响所选 CLF 的函数。有关修改函数参数的信息，请参考“编辑函数的参数值”。

按照以下步骤修改 CLF 函数中的默认参数：

1. 打开 Designer。
2. 单击 CLF。逻辑流定义窗口将在函数选项卡上打开。
3. 从选择窗口中选择 CLF。该示例显示了 ServiceProcessing 下的 MoveIn_Execute。
4. 在逻辑流窗格中选择要修改的函数。所选函数的默认参数值显示在函数参数块中：

可用函数显示在可用函数窗格中。

5. 根据需要修改默认参数值。
6. 或者，选中动态复选框以使用查找表达式将参数作为动态值传递。如果希望将参数作为实际值传递，则将其保留为未选中状态。
注释: 如果函数强制执行参数类型（通过“函数”窗口中的标志进行设置），则不会显示“动态”复选框，而会显示“多重性”和“数据类型”列。此窗口中的“多重性”和“数据类型”是只读的。要更改这些列的值，必须转到“函数定义”窗口，可以在此窗口中修改用户定义的函数。
7. 从文件菜单中选择保存。应用程序保存更改。
