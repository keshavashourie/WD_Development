列选项卡

“列”选项卡列出了列名称及其描述。列名称旁边的键符号表示主键。

列选项卡按钮定义

此表定义“列”选项卡上的按钮。

按钮

按钮功能 ...

添加

打开“DB 列属性”窗口，它用于定义正在添加的列的属性。

移除

移除创建的列。

属性

打开“DB 列属性”窗口，并查看或更新选定列的属性。

DB 列属性窗口

单击“添加”或“属性”按钮时，将打开“DB 列属性”窗口。“DB 列属性”窗口用于定义或更新选定列的属性。

DB 列属性窗口字段定义

此表定义“DB 列属性”窗口中的字段。

字段

定义

类型

列名称

数据库列的名称。

必需

描述

用于描述如何在 DB 表中使用此列的说明文字。

可选

数据类型

列的 ODBC 数据类型。

必需

精度

此条目所描述的列中数据的最大长度（字符串）或小数点左边的最大位数。

必需

小数位数

此条目所描述的列中数据的小数点右边的最大位数。

必需

列用法

标识与此列相关联的任何特殊处理（如 InstanceID）。每个值都与系统中实施的特定处理相关。

必需

详细信息

键顺序

键入除 0 以外的数字可使此列成为此表的主键的一部分。该数字即为此列属于键（可能是多部分键）的顺序。

必需

DB 列属性的何处使用选项卡

单击何处使用选项卡并选择显示在何处使用此列可查看使用此列的 CDO 字段。
