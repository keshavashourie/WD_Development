为表定义索引

根据业务要求，可能需要为表定义新索引以快速访问信息。

为表定义索引

Opcenter EX MDD 和 Opcenter EX CR 提供的部分表已编制索引。在创建 CDO 的子类过程中创建新表时，不会继承在 Designer 中为表定义的索引。如果在添加 CDO 子类时创建表，始终会为 ID 字段创建索引，如 <CDO>ID。

注释: 为事务数据库创建新的数据库表时，将会创建索引。有关信息，请参考“如何创建索引”。

如果添加了新的表和列，需按本主题中介绍的过程手动为它们创建索引。

如何定义索引

按照以下步骤定义索引：

1. 打开 Designer。
2. 单击表。将显示“表定义”窗口。
3. 选择索引选项卡。
4. 选择表所在的表类别，然后选择要添加索引的表。
5. 单击现有索引字段旁边的添加。Opcenter EX MDD 和 Opcenter EX CR 会自动在现有索引字段中输入表名称。Opcenter EX MDD 和 Opcenter EX CR 还会为索引指派唯一 ID。
6. 为新索引输入唯一的名称和有意义的描述。

有关应避免使用的非法字符和保留字的列表，请参考“有效字符和保留字”。

7. 选择要添加为索引条目的列名称。
注释: 默认情况下，列未配置为索引条目（选中了“不包括”按钮）。
8. 按以下方式排序：
• 右键单击并选择升序排序或降序排序。

或

• 选择升序排序或降序排序单选按钮。
注释: 如果有两个或更多索引条目，可以使用“上移”或“下移”按钮来更改条目的排序顺序。
9. 单击选项卡上的任意位置以保存所做的更改。

使用新索引

要在事务数据库中使用新索引，需要创建并运行索引脚本。与数据库管理员 (DBA) 协作，并参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》以了解有关如何运行新索引的脚本的信息。此过程可能需要很长时间，所以可能需要适当安排脚本运行计划。

如何创建索引

按照以下步骤在事务数据库中创建索引：

1. 打开 Management Studio。
2. 展开 <sitename> 节点。
3. 展开数据库文件夹。
4. 右键单击事务数据库，然后从显示的菜单中选择新建数据库表。将显示“为 <数据库> 创建表”窗口。
5. 使所有复选框保持选中状态。
6. 单击确定。应用程序将创建新表，关闭“为 <数据库> 创建表”窗口，并显示一条消息，说明新数据库已成功创建。
