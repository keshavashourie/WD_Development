修改表

修改表不是一项常见任务，但有时确实需要修改数据库中已存在的表。例如，如果更改了字符串字段定义，将其增加到 15 到 20 个字符，则需要修改表。

修改表

表不会随字段定义一起更改，因为系统有意将 Opcenter EX MDD 表和 Opcenter EX CR 表与字段定义保持分离。因此，可能需要更改表宽度，使之符合字符串字段宽度的要求。

如果已为最高的活动工作区指派前缀，添加新项时，将自动在项名称前面插入工作区前缀。工作区前缀指示 Designer 会将更改应用到哪个工作区。例如，前缀 "C200" 将与 Management Studio 中前缀设为 "C200" 的工作区关联。建议在添加新项时使用 Designer 提供的前缀。

可以在 Management Studio 中指派或修改工作区前缀。有关信息，请参考《Opcenter Execution Medical Device and Diagnostics 系统管理指南》或《Opcenter Execution Core 系统管理指南》。

注释: 不能为应用程序基本工作区 (csi) 指派工作区前缀。

如何更改表类别

按照以下步骤更改表类别：

1. 打开 Designer。
2. 单击表。将显示“表定义”窗口。
3. 单击要修改的表所在的表类别。
4. 选择要修改的表。
5. 在表类别中，选择一个新类别。
6. 从文件菜单中选择保存。应用程序保存更改。

如何 添加表列

按照以下步骤添加表列：

1. 打开 Designer。
2. 单击表。将显示“表定义”窗口。
3. 选择列选项卡。
4. 选择要向其中添加列的表。
5. 单击列名称和说明下面的添加。将出现“DB 列属性”窗口，其中包含一个标有默认名称的新列。
注释: 也可以右键单击“列”列表中的任意位置，然后从快捷菜单中选择“添加列”。
6. 输入列的新名称、描述以及其他属性信息。有关应避免使用的非法字符和保留字的列表，请参考“有效字符和保留字”。
7. 单击确定。
8. 从文件菜单中选择保存。应用程序保存更改。

如何移除表列

不能移除默认列。

注释: 在 Designer 中移除表列不会移除生产数据库中的对应实体。这样可以防止历史数据丢失。

按照以下步骤移除表列：

1. 打开 Designer。
2. 单击表。将显示“表定义”窗口。
3. 选择列选项卡。
4. 选择要从中移除列的表。
5. 选择要移除的列。

如果“移除”按钮处于禁用状态，则表示该列正由一个或多个 CDO 字段使用。要移除关联：

a. 当列名称处于选中状态时，对其双击打开“DB 列属性”窗口。
b. 单击何处使用选项卡。
c. 注意列表中显示的 CDO 和字段，然后单击“取消”关闭窗口。
d. 对于使用要移除的 DB 列的每个 CDO 字段，移除该字段或通过属性窗口的常规选项卡更改其 DB 列指派。
e. 针对使用 DB 列的所有字段重复此操作。
6. 再次选择 DB 列，然后单击移除，或右键单击并选择移除列。
7. 从文件菜单中选择保存。应用程序保存更改。

如何修改表列

按照以下步骤修改表列：

1. 打开 Designer。
2. 单击表。将显示“表定义”窗口。
3. 选择列选项卡。
4. 选择要修改的列所在的表。
5. 选择要修改的列。
6. 单击属性。将显示“DB 列属性”窗口。
7. 根据业务需求修改属性。
8. 从文件菜单中选择保存。应用程序保存更改。

如何更改表名

重要提示: 如果正在 Designer 中重命名某些表，应了解该操作的影响，尤其是某些对象已经在使用这些表时。更改表名不会编写 SQL 类型的代码来复制、创建和删除数据库中的旧表。

按照以下步骤更改表名：

1. 打开 Designer。
2. 单击表。将显示“表定义”窗口。
3. 打开表所在的类别。
4. 选择要重命名的表。
5. 稍等片刻并再次选择，或单击重命名按钮。表名变为重命名模式。
6. 重命名该表。

有关应避免使用的非法字符和保留字的列表，请参考“有效字符和保留字”。

7. 从文件菜单中选择保存。应用程序保存更改。
