CDO 字段属性

字段由其属性定义。选择一个 CDO 字段，然后单击属性按钮以访问 CDO 字段属性窗口。可用的属性特定于您选择的 CDO 字段。“字段属性”窗口具有六个选项卡：

• 常规
• 选项
• 高级选项
• 表达式
• 选择值
• 事件

“将相同的更改应用于关联维护事务中的相应字段”复选框对所有选项卡通用。如果选中此复选框，则会对关联的维护对象进行相同的更改。

注释: 如果未对 CDO 字段的属性进行任何更改，则在选中“将相同的更改应用于关联维护事务中的相应字段”复选框时，应用程序不会将任何信息保存到关联的维护对象。

高级选项选项卡字段定义

此表定义“高级选项”选项卡中的字段。

字段

定义

所有权

无

如果选中此选项，则不拥有此字段引用的对象。它表示关联。

强

如果选中此选项，则此字段引用的对象为子实体；它完全由此 CDO（称为父项）拥有并共享父项的生命周期。删除父实例也将删除此字段中引用的子实体实例。该关系表示一个组合。

序列化

无

如果选中此选项，则此字段将从 XML 传输文档中排除。

默认值

字段将基于其引用类型的所有权设置进行序列化（未指定所有权时为浅，否则为深）。基本类型将被序列化。

浅

如果选中此选项，则对象引用的值将包含在 XML 传输文档中。这通常包括对象的实例 ID 以及适当的替代引用。

深

仅当字段为对象引用时，才启用此选项。如果选中此选项，则引用的对象将包含在 XML 传输文档中。

特殊处理

替代文本变量

仅当字段为字符串类型时，才启用此选项。如果选中此选项，则将解析字符串中的文本变量；该属性将扫描字符串以查找任何特殊语法。例如，CompareValue。

在初始化时创建

此属性用于对象字段类型。创建（初始化）包含此字段的 CDO 实例时，还会创建另一个（第二个）CDO（数据类型和字段类型与此字段相同）的实例，并将第二个 CDO 的实例 ID 放入此字段中。

事务撤消

撤消

如果选中此选项，则在撤消事务时，将还原执行最后一个事务之前的值。

补偿

仅当字段为固定、小数、浮点或整数类型时，才启用此选项。如果选中此选项并撤消事务，则此字段的值符号将在撤消记录中切换以确保数量平衡。

Designer 中的可见性

基本

如果选中此选项，则在 Designer 中，字段在“用户”和“系统”模式的“基本”和“高级”视图中均可见。

高级

如果选中此选项，则在 Designer 中，字段在“用户”和“系统”模式的“高级”视图中均可见。

隐藏

选项仅在“系统”模式的“高级”视图中可用，保留以供 Siemens 使用。

在“表达式”选项卡中，指定：

• 当前值表达式 (CVE)

表达式选项卡字段定义

此表定义“表达式”选项卡中的字段。

字段

定义

当前值表达式 (CVE)

当前值表达式用于动态确定 CDO 中的字段值。CVE 旨在使字段可以在运行时确定值。

默认值 (DV)

默认值是在未指定任何其他值的情况下指定字段将采用的值。

注意：Siemens 建议仅对车间事务使用默认值。

默认值表达式 (DVE)

默认值表达式用于动态确定默认值。

注意：Siemens 建议仅对车间事务使用默认值表达式。

支持的表达式

仅 CVE 和 DVE 支持表达式；DV 不支持。初始化对象时，系统会尝试从数据库中获取字段的值（如果存在）。

注释: 初始化时不计算 CVE。仅在请求时间字段值时才计算 CVE。

请求获取字段值时，将返回以下某个值。这些表达式按以下顺序执行：

1. 实例数据，设置的值
2. OnGetValue 事件返回的值（如果存在）
3. CVE 返回的值（如果存在）

如果此处理计算为某个值，则其结果（仍有可能为空）将设为字段。获取值时将返回为字段设置的任何值。

可通过调用获取默认值 csigetdefaultvalue。

不管是当前值表达式还是默认值表达式，都用于动态确定 CDO 中的字段值。两者的语法类似；区别在于当前值表达式可以包含对字段当前实例数据值的引用。

字段表达式（CVE 或 DVE）可以包含按顺序列出且以分号分隔的多个表达式。字段表达式的计算顺序从第一个表达式开始，到最后一个结束。当字段表达式生成值时，计算停止。首先输入保留字，后跟分号。字段表达式的当前保留字为：

This_Value;

This_Value 使用用户在字段中输入的值。

表达式表示一个值，但可以包含用句点分隔的多个字段名称。为字段输入字段表达式时约定如下：

FieldName(ObjectReference).FieldName(ObjectReference).FieldName(any type)

其中：

FieldName(ObjectReference) 是 CDO 中 OID 类型的字段，其中字段引用 CDO。

并且：

FieldName(type any) 是 CDO 中任何类型的字段。

示例 1

This_Value;Container.Workflow.FirstStep

此表达式指示应用程序使用用户输入的值。如果未输入任何内容，则此表达式将返回容器的工作流程中包含的 FirstStep 字段中的实例 ID。

示例 2

This_Value;Details.Container.Operation;0;

此字段表达式计算如下：

1. This_Value 检索用户输入的值。如果未产生值，则：
2. Details.Container.Operation 从“详细信息”CDO 内“容器”CDO 中的“作业”字段检索值。如果该 CVE 不产生值，则：
3. 值设为 0、NULL 或空字符串，具体取决于字段类型。

示例 3

This_Value;ProductFamily.Workflow

此字段表达式计算如下：

1. 在 CVE 中使用 This_Value 来引用字段的当前实例数据值。
2. ProductFamily.Workflow 从“产品系列”CDO 中的“工作流程”字段检索值。

使用表达式构建器

表达式构建器将在窗口中显示 CDO 和字段的列表，这样用户就不必键入 CVE 或 DVE。用户选择 CDO 和字段，构建器将自动输入适当的分隔符。

修改表达式

可以使用与“如何输入 CVE 或 DVE 字段表达式”相同的过程修改当前或默认值表达式，也可以使用以下替代过程来编辑当前或默认值字符串。如果已自行创建字段并希望编辑多个表达式以使用字段，则此替代方法非常有用。

选择值选项卡

在“CDO 字段属性”窗口的“选择值”选项卡中，可以指定如何为最终用户图形用户界面中的字段生成选择值。可以将这些值用于新字段，也可以更改已指派给现有字段的方法。

有关如何使用字段选择值的信息，请参考“查看字段选择值”。

如何输入 CVE 或 DVE 字段表达式

按照以下步骤输入 CVE 或 DVE 字段表达式：

1. 打开 Designer 工具栏。
2. 单击 CDO。将显示“CDO 定义”窗口。
3. 选择包含要向其添加 CVE 或 DVE 的字段的 CDO。
4. 选择字段选项卡。
5. 选择所需的字段，然后单击属性。
6. 选择“CDO 字段属性”窗口上的表达式选项卡。
7. 为 CVE 或 DVE 设置值：
• 在当前值表达式或默认值表达式字段中键入表达式。

或

• 单击构建，然后使用表达式构建器设置 CVE 或 DVE。
8. 单击确定或选择其他选项卡以获得更多选项。请参考“统一表达式”。
9. 从文件菜单中选择保存。应用程序保存更改。

如何使用表达式构建器

按照以下步骤使用表达式构建器：

1. 单击当前值表达式或默认值表达式字段旁边的构建。将显示“构建表达式”窗口。
2. 双击 CDO 定义列表中的 CDO。随即“字段”页中将显示 CDO 字段。
3. 双击要在表达式中列出的所需字段。随即“表达式”下方将显示所选字段。
4. 重复步骤 2-3，直到表达式完成。
注释: 系统将在添加到表达式的每个字段之间自动插入一个句点 (.)。
5. 单击保存并关闭。
6. 要在将从左到右进行解析的系列中添加其他表达式，在完整表达式的末尾插入一个分号，然后从此列表中的步骤 2 开始。
7. 从文件菜单中选择保存。应用程序保存更改。

如何编辑当前或默认值字符串

按照以下步骤编辑当前或默认值字符串：

1. 右键单击所选 CDO 字段，然后选择表达式。将显示以下窗口：

本示例针对容器的详细信息字段。默认值和当前值表达式分两列单独显示。默认情况下，窗口在查找内容和替换内容字段中输入当前字段。

2. 在查找内容中键入要替换的字符串。
3. 在替换内容中键入替换字符串。
4. 单击查找以查找要替换的字符串的实例。
重要提示: 在步骤 5，所做的更改无需确认即可立即生效。
5. 单击查找和替换以替换字符串。
6. 单击窗口右上角的 X 将其关闭。
7. 从文件菜单中选择保存。应用程序保存更改。
