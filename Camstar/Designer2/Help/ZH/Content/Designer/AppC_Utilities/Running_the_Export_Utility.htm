运行 Metadata Export 实用程序

Siemens 提供了 Metadata Export 实用程序，用于查看基本元数据数据库 (MDB) 和修改后的 MDB 之间的差异。该实用程序将比较两个数据库，并支持选择性地将差异（增量）导出为 XML 文件。该实用程序还能够生成可详细说明两个数据库之间差异的报告。

在运行 Metadata Export 实用程序时

Metadata Export 实用程序显示为一个窗口，其中包含依次显示的三个屏幕，用于指导导出和报告生成过程。每个屏幕在窗口的右上角显示屏幕编号，以帮助追踪进度。

这些屏幕按以下顺序显示在实用程序中：

• 选择要比较的文件
• 选择要输出的更改
• 选择输出选项

单击“下一步”按钮可在实用程序中从一个屏幕导航至下一个屏幕。单击“上一步”按钮可返回到上一个屏幕。单击“取消”将关闭 Metadata Export 窗口，不会执行导出，也不会生成元数据报告。

从“帮助”菜单中选择“关于”时，将显示“关于 Metadata Export”弹出窗口，并显示有关 Metadata Export 实用程序的产品和版本信息。单击“关闭”按钮可以关闭“关于 Metadata Export”弹出窗口。

在导出过程中出错时，该实用程序将显示一条错误消息。该错误信息包含有关该实用程序在过程中的哪一步遇到错误以及其无法编译哪些对象的信息。错误会记录在事件查看器和一个日志文件中，该文件包含解释过程失败原因的详细信息。默认情况下，日志文件保存在以下文件路径：C:\Program Files (x86)\Camstar\Logs。

选择要比较的文件屏幕

在“选择要比较的文件”屏幕上，必须指定要进行比较的基本 MDB 和修改后的 MDB。基本 MDB 和修改后的 MDB 不用使用同一 MDB 文件。该实用程序显示每个数据库最活跃的工作区，这些工作区必须相同才能继续。该实用程序只比较具有相同工作区的数据库。默认情况下，这些字段中会显示上次使用实用程序时指定的最后一个 MDB。

注释: 工作区将在 Management Studio 中激活。有关信息，请参考《Opcenter Execution Medical Device and Diagnostics 系统管理指南》或《Opcenter Execution Core 系统管理指南》。

在“基本 MDB”或“修改后的 MDB”字段中指定数据库后，该实用程序开始编译数据库。该字段旁边将显示文本“正在编译”，当实用程序成功完成数据库编译后，将显示文本“已编译”。当两个数据库都完成编译后，该实用程序将启用“下一步”按钮。

在“选择要比较的文件”屏幕上单击“下一步”按钮时，该实用程序将比较基本 MDB 和修改后的 MDB。将显示一个“状态”弹出窗口，其中显示比较过程中发现的文本更新。此过程完成后，“状态”弹出窗口将关闭。

选择要输出的更改屏幕

“选择要输出的更改”屏幕将为在 MDB 比较期间找到的已修改对象在一系列树中显示定义列表，这些定义按对象类型排列。

此屏幕上显示以下对象类型：

• CDO
• CLF
• 字段
• 数据库表
• 函数
• 查询
• 标签
• 特征
注释: 在执行包含有资格的功能的导出时，ID 不会与目标环境同步。Siemens 建议使用“替换工作区数据”实用程序来确保在替换过程中更新 ID。请参考有关替换工作区数据实用程序的信息。Opcenter Execution Medical Device and Diagnostics 安装指南或 Opcenter Execution Core 安装指南。

可以展开树，选择要包括在导出或元数据报告中的特定对象定义。选择对象定义时，屏幕右窗格中会显示其他对象定义信息。单击“全选”按钮可以选择所有可用的对象定义。也可以单击“全部展开”按钮来展开所有树，查看已修改对象定义的完整列表。

注释: 当单击“全部展开”按钮时，将显示一条警告消息，通知如果有大量已修改对象，则展开全部树的过程可能需要花费几分钟。单击“确定”关闭警告消息。

在“搜索”字段中输入对象名称并单击“搜索”按钮，可以搜索特定对象。

如果未选择任何定义即单击“下一步”，则会出现一条警告消息，指出未选择导出任何更改。单击“确定”关闭警告消息，然后选择至少一个定义。

选择输出选项屏幕

“选择输出选项”屏幕可用于控制导出工具是否生成以下内容：

• 元数据导出 XML 文件，
• 元数据导出报告（HTML 或 DOC），或
• 以上两者。

选中：

• “导出文件”复选框可生成元数据导出 XML 文件。
• “报告文件”复选框可生成元数据报告文件。
• “包含 ID 以进行功能升级”复选框可在元数据导出 XML 文件中包含元数据 ID。

选中“导出文件”或“报告文件”复选框可启用关联的文本框和文件选择功能，以便指定输出文件和路径。

在指定所需的输出、文件和文件位置后，元数据导出工具将启用“完成”按钮。单击“完成”按钮即开始生成文件。将显示“状态”弹出窗口，并在文件生成完成时显示一条成功消息。

生成导出和元数据报告文件

默认情况下，该实用程序以 XML 格式保存导出，以 HTML 格式保存元数据报告。该实用程序支持元数据报告使用 HTML 和 DOC 格式。

导出的 XML 文件和元数据报告文件的默认路径为 C:\Users\<user folder>\Desktop（例如，C:\Users\msmith\Desktop）。

XML 文件的默认文件名为修改后的文件名后跟工作区和 "export" 一词，所有部分均以下划线分隔。例如，如果修改后的文件名为 ModifiedMDB.mdb、工作区为 csi，则默认文件名将为 ModifiedMDB_csi_export.xml。

生成的报告文件的默认文件名为修改后的文件名后跟工作区和短语 "exportReport"，所有部分均以下划线分隔。例如，如果修改后的文件名为 ModifiedMDB.mdb、工作区为 csi，则默认文件名将为 ModifiedMDB_csi_exportReport.html。

单击“浏览导出文件”字段，可以为导出指定其他路径和文件名。单击“浏览报告文件”字段，可以为报告指定其他路径、文件名和文件类型。

从命令提示符运行 Metadata Export 实用程序

可以从命令提示符运行 Metadata Export 实用程序。使用以下命令调用该实用程序：

"MetadataExport [-a] [-b baseFileName] [-m modifiedMDBFileName] [-o outputXMLFileName] [-r reportHMTLFileName]"

每个参数都由一个空格隔开并以破折号开头。替换变量的值与该实用程序各屏幕上的字段需要的值相同。有关信息，请参考“Camstar Metadata Export 窗口字段定义”。

此表定义必须在命令行中替换变量的信息。

变量

值

-a

在不使用 UI 交互或过滤的命令行模式下导出所有差异。

注：从命令提示符运行实用程序时，必须包含此参数。

baseFileName

基本元数据数据库的完整路径。

modifiedMDBFileName

修改后的元数据数据库的完整路径。

outputXMLFileName

导出的 XML 文件的完整路径和文件名。

reportHTMLFileName

生成的报告的完整路径和文件名。

如果该实用程序出现错误，将显示一条错误消息和帮助信息。还可以输入“MetadataExport 帮助”并按 Enter 以显示帮助信息。可以查看这些信息，然后尝试重新输入命令并按 Enter 来运行该实用程序。

注释: 通过命令提示符只能导出整个 MDB。

如何运行 Camstar Metadata Export 实用程序

按照以下步骤运行 Camstar Metadata Export 实用程序：

1. 转到“应用程序”视图。
2. 单击 Metadata Export 应用程序。将显示 Camstar Metadata Export 窗口。
3. 单击基本 MDB 字段的浏览。将显示“打开”窗口。
4. 导航至基本 MDB，然后单击打开。“打开”窗口将关闭，基本 MDB 的路径显示在“基本 MDB”字段中，“工作区”字段中显示标识基本 MDB 的最活跃工作区的代码，“基本 MDB”字段旁会显示“正在编译”。当数据库完成编译时，“基本 MDB”字段旁随即显示“已编译”。
5. 单击修改后的 MDB 字段的浏览。将显示“打开”窗口。
6. 导航至修改后的 MDB，然后单击打开。“打开”窗口将关闭，修改后的 MDB 的路径显示在“修改后的 MDB”字段中，“工作区”字段中显示标识修改后的 MDB 的最活跃工作区的代码，“修改后的 MDB”字段旁会显示“正在编译”。当数据库完成编译时，“修改后的 MDB”字段旁随即显示“已编译”，实用程序将启用“下一步”按钮。
7. 单击下一步。将显示“选择要输出的更改”屏幕和“状态”弹出窗口。当实用程序比较两个数据库时，“状态”弹出窗口将显示文本更新。此过程完成时，“状态”弹出窗口将关闭。
8. 根据需要选择修改后的对象定义，然后单击下一步。将显示“选择输出选项”屏幕。
9. 要执行导出、生成元数据报告、还是同时执行导出和生成元数据报告？

如果您想完成以下操作 ...

操作步骤 ...

执行导出
a. 选中导出文件复选框。
b. 单击导出文件字段的浏览。将显示“另存为”窗口，并显示默认文件名和位置。
c. 如果需要，指定其他路径或文件名。
d. 单击保存。“另存为”窗口将关闭，导出文件的路径和文件名将显示在“导出文件”字段中，实用程序将启用“完成”按钮。
e. 转到步骤 10。

生成元数据报告
a. 选中报告文件复选框。
b. 单击报告文件字段的浏览。将显示“另存为”窗口，并显示默认文件名和位置。
c. 如果需要，指定其他路径、文件名或文件类型。
d. 单击保存。“另存为”窗口将关闭，元数据报告的路径和文件名将显示在“报告文件”字段中，实用程序将启用“完成”按钮。
e. 转到步骤 10。

执行导出和生成元数据报告
a. 选中导出文件复选框。
b. 单击导出文件字段的浏览。将显示“另存为”窗口，并显示默认文件名和位置。
c. 如果需要，指定其他路径或文件名。
d. 单击保存。“另存为”窗口将关闭，导出的路径和文件名将显示在“导出文件”字段中，实用程序将启用“完成”按钮。
e. 选中报告文件复选框。
f. 单击报告文件字段的浏览。将显示“另存为”窗口，并显示默认文件名和位置。
g. 如果需要，指定其他路径、文件名或文件类型。
h. 单击保存。“另存为”窗口将关闭，元数据报告的路径和文件名将显示在“报告文件”字段中。
i. 转到步骤 10。
10. 单击比较和导出完成。实用程序将生成的文件保存在指定的路径中，并显示“状态”弹出窗口以及一条成功消息。
11. 单击确定。“状态”弹出窗口和 Camstar Metadata Export 窗口将关闭。
