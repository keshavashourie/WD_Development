Erstellen der Dienstunterklasse mit dem Assistenten

Erstellen Sie Ihren eigenen ChgContainerAttribute-Dienst, damit Sie die Attribute angeben können, die Sie basierend auf Ihren Geschäftsregeln ändern möchten. Der Designer stellt einen Assistenten bereit, um die ChgContainerAttribute-Unterklasse, die zugehörigen Historienobjekte und die Feldzuordnungsdefinitionen zu erstellen.

Beim Erstellen der Dienstunterklasse mit dem Assistenten

Arbeitsbereichspräfixe werden beim Hinzufügen eines neuen Elements automatisch vor dem Namen des Elements eingefügt, sofern dem höchsten aktiven Arbeitsbereich ein Präfix zugewiesen wurde. Arbeitsbereichspräfixe geben an, auf welchen Arbeitsbereich Designer Änderungen anwendet. Dem Arbeitsbereich würde z. B. das Präfix "C200" zugeordnet werden, wenn für diesen in Management Studio das Präfix "C200" festgelegt wurde. Siemens empfiehlt die Verwendung der von Designer bereitgestellten Präfixe, wenn Sie neue Elemente hinzufügen.

Sie können Arbeitsbereichspräfixe in Management Studio zuweisen oder ändern. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Hinweis: Dem Basisarbeitsbereich der Anwendung (csi) kann kein Arbeitsbereichspräfix zugewiesen sein.
Assistent "Attributdienste ändern" (Change Attributes Services)

Die Änderung des Dienstes umfasst das Hinzufügen, Entfernen und Umbenennen von Feldern. Anstatt die Änderungen direkt an den CDOs vorzunehmen, empfiehlt Siemens die Verwendung des Assistenten "Attributdienste ändern" (Changes Attribute Services), um zu gewährleisten, dass die Änderungen an die zugehörigen Historienobjekte weitergegeben und auch die Zuordnungsinformationen aktualisiert werden.

Der ChgContainerAttribute-Dienst-Assistent:

• Wird für mehrstufige Unterklassen des ChgContainerAttribute-Dienstes aktiviert
• Deaktiviert Aktualisierungen an geerbten Feldzuordnungen, die in Hellgrün angezeigt werden
• Umfasst einen Unterklasse-Assistenten, um anstelle aller Containeruntertypen nur die Untertypen des Containertyps anzuzeigen, der im Elterndienst definiert ist
Hinweis: Der Assistent "Attributdienste ändern" (Changes Attribute Services) steht über das CDO-Kontextmenü für jede ChgContainerAttribute-Unterklasse zur Verfügung. In diesem Beispiel wird der Assistent durch die MyContainerMaint-Unterklasse aufgerufen.

Vorgehensweise zum Erstellen des ChgContainerAttribute-Dienstes

Gehen Sie folgendermaßen vor, um den ChgContainerAttribute-Dienst zu erstellen:

1. Melden Sie sich bei Designer an.
2. Klicken Sie in der Symbolleiste auf CDOs.
3. Suchen Sie das ChgContainerAttribute-CDO und wählen Sie es aus.
4. Klicken Sie mit der rechten Maustaste, um das CDO-Kontextmenü zu öffnen und wählen Sie Unterklasse hinzufügen aus.
5. Geben Sie einen Namen für die Unterklasse (z. B. MyContainerMaint) und eine Beschreibung ein.
6. Wählen Sie aus der Liste Zielcontainertyp für die Attributänderung (Change Attribute Target Container Type) den Containertyp aus, für den Sie diesen Dienst erstellen.

Wenn Sie z. B. den Dienst für Ihre eigene Container-Unterklasse mit dem Namen MyContainer erstellen, wählen Sie diesen aus der Liste aus. Verwenden Sie nicht die Unterklassen "GroupContainer" und "UnitContainer". Diese werden nur aus Gründen der Rückwärtskompatibilität zur Verfügung gestellt.

7. Klicken Sie auf Erstellen. Das Fenster des Assistenten "Attributdienste ändern" (Changes Attribute Services) wird mit einer Liste von Feldern angezeigt, die die Attribute darstellen, die Sie ändern können.
8. Wählen Sie die Kontrollkästchen neben den Feldern aus (einschließlich benutzerdefinierte Felder), die Sie zu Ihrem Dienst hinzufügen möchten.

Die von Ihnen ausgewählten Felder stellen die Containerattribute dar, die Sie über diesen Dienst ändern möchten. Wenn Ihr Dienst z. B. zum Ändern der Felder "Customer", "DueDate", "Level", "MfgOrder", "Owner", "Priority" und von benutzerdefinierten Feldern verwendet wird, klicken Sie nur auf diese Felder.

9. Klicken Sie auf Validieren (Validate), um zu gewährleisten, dass Ihr Dienst keine doppelten Feldnamen umfasst.

Wenn Sie den Dienst zum ersten Mal erstellen, sollten Sie keine Duplikate finden. Doch wenn der Dienst bereits vorhanden ist und Sie ihm Ihre eigenen Felder hinzufügen müssen, findet der Assistent möglicherweise doppelte Namen, sodass Sie eines der Felder umbenennen müssen. Doppelklicken Sie dazu auf den Feldnamen und geben Sie einen eindeutigen Namen ein.

10. Klicken Sie auf OK, um das Erstellen Ihres Dienstes abzuschließen, und warten Sie einige Minuten, bis der Vorgang beendet ist.

Wenn Sie stattdessen auf "Abbrechen" klicken, wird die Dienstunterklasse trotzdem zur CDO-Bibliothek hinzugefügt.

Für den Dienst werden zwei Felder erstellt:

• "HistorySummary", das "MyContainerMaintHistory" referenziert
• "ServiceDetail" mit dem Unterobjekt "MyContainerMaintDetail"
11. Gehen Sie zum Unterobjekt MyContainerMaintDetail, um die Felder anzuzeigen.
12. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Von "MyContainerMaintDetail" werden die folgenden Zuordnungen erstellt:

• MyContainerMaintDetailTo<YourContainer>
In dieser Zuordnung werden die Felder "Customer", "DueDate", "Level", "MfgOrder", "Owner" und "Priority" zugeordnet.
• MyContainerMaintDetailToCurrentStatus
• MyContainerMaintDetailToContainerDetail

Wenn Sie für die beiden nächsten Zuordnungen die Felder zu "CurrentStatus" und "ContainerDetail" hinzugefügt haben, werden diese nicht automatisch zugeordnet. Sie müssen die Nutzerfelder in "MyContainerDetail" kopieren und diese Felder anschließend zuordnen.

Wichtig: Nachdem der Dienst erstellt wurde, darf der Containertyp nicht mehr geändert werden, da die erneute Zuordnung sehr komplex ist und manuell erfolgen müsste.

Vorgehensweise zum Ändern des ChgContainerAttribute-Dienstes

Gehen Sie folgendermaßen vor, um den ChgContainerAttribute-Dienst zu ändern:

1. Wählen Sie die zuvor erstellte Dienstunterklasse aus (in diesem Fall MyContainerMaint) und klicken Sie mit der rechten Maustaste, um das CDO-Kontextmenü zu öffnen.
2. Wählen Sie den Assistenten zum Ändern von Attributdiensten (Change Attribute Service Wizard) aus. Der Assistent wird geöffnet und es werden die Felder angezeigt, die Sie dem Dienst hinzugefügt haben.
3. Passen Sie den Dienst wie folgt an die Anforderungen Ihres Unternehmens an:
• Zum Hinzufügen von Feldern aktivieren Sie das Kästchen neben dem hinzuzufügenden Feld.
• Zum Umbenennen eines Felds, das dem Dienst hinzugefügt wurde, doppelklicken Sie auf den Namen. Alternativ wählen Sie das Feld aus und klicken auf die Schaltfläche Umbenennen. Anschließend geben Sie den neuen Namen in das Dialogfeld ein.
Hinweis: Sie können das Feld, das sich in den entsprechenden Dienstdetail- und Historiendetail-CDOs befindet, wahlweise umbenennen.
• Zum Entfernen eines zuvor hinzugefügten Felds deaktivieren Sie das Kontrollkästchen.
4. Klicken Sie auf OK.
5. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
