Definieren einer Container-CDO-Unterklasse

Die folgenden Aufgaben werden automatisch ausgeführt, wenn Sie beim Hinzufügen eines Container-CDOs das Kontrollkästchen "Startdienst erstellen & konfigurieren" (Create & Configure a Start Service) im Fenster "Neue CDO-Definition erstellen" aktivieren.

• Hinzufügen einer StartService-CDO-Unterklasse
• Hinzufügen einer StartDetails-Unterobjekt-Unterklasse
• Hinzufügen der StartHistoryDetail-Unterklasse
• Hinzufügen von Containerfeldern zum Diensthistoriendetails-CDO

Wenn das Dienst-CDO ein ServiceDetails-CDO verwendet, muss das Dienst-CDO sein ServiceDetails-Unterobjekt über das Feld "Details" im Dienst-CDO referenzieren. Wenn ein ServiceDetails-Unterobjekt für einen Container vorhanden ist, wird das Feld "Container" im ServiceDetails-Unterobjekt überprüft, sodass das Unterobjekt das richtige Container-CDO referenzieren muss. Wenn Sie das Kontrollkästchen "Startdienst erstellen & konfigurieren" (Create & Configure a Start Service) im Fenster "Neue CDO-Definition erstellen" aktivieren, wird diese Aufgabe automatisch für Sie ausgeführt. Weitere Informationen zum Überschreiben von CDO-Referenzen finden Sie unter "Erstellen von Feldüberschreibungen".

Wenn Sie einem Container-CDO Felder hinzufügen und das Kontrollkästchen "Felder zu den zugehörigen Dienstobjekten hinzufügen" (Add Fields to the Associated Service Objects) aktivieren, werden die im Folgenden aufgelisteten erforderlichen Aufgaben automatisch ausgeführt:

• Hinzufügen von Feldern zur StartDetails-CDO-Unterklasse
• Hinzufügen von Feldern zur StartHistoryDetails-CDO-Unterklasse
• Zuordnen von Feldern zwischen CDOs

Beim Zuordnen von Feldern werden Felder in den angegebenen CDO-Zielen aus den von Ihnen festgelegten CDO-Quellen aktualisiert. Der neuen Container-Unterklasse und den StartServiceDetails- sowie StartHistoryDetails-CDOs hinzugefügte Felder werden aus den neuen Feldern im StartDetails-CDO den neuen Feldern "Container" hinzugefügt und anschließend vom neuen Container-CDO dem neuen StartHistoryDetails-CDO zugeordnet. Die Zuordnung erfolgt in dieser Reihenfolge, weil die Änderungen des Endbenutzers von der Benutzeroberfläche zuerst an das StartDetails-CDO weitergeleitet werden. Weitere Informationen finden Sie unter "Anzeigen von Feldzuordnungen".

Hinzufügen einer StartService-CDO-Unterklasse

Jedes Container-CDO muss sein eigenes StartService-CDO aufweisen. Die Vorgehensweise zum Erstellen eines StartService-CDOs für den neuen Container wurde für Sie automatisiert. Aktivieren Sie dazu beim Erstellen des neuen Container-CDOs das Kontrollkästchen "Startdienst erstellen & konfigurieren" (Create & Configure a Start Service). Eine Unterklasse des Startdienst-CDOs wird hinzugefügt, um den Startdienst für das neue Container-CDO zu verwalten. Außerdem wird die Containerreferenz im Startdienst-CDO geändert, um das neue Container-CDO zu referenzieren.

Weitere Informationen finden Sie unter "Vorgehensweise zum Hinzufügen eines Dienst-CDOs".

Hinzufügen einer StartDetails-Unterobjekt-Unterklasse

ServiceDetails-CDOs enthalten die Änderungsdaten (Details) zu den Containertransaktionen, die von ihrem Startdienst (StartService) ausgeführt werden, sodass jedes StartService-CDO über ein eigenes StartDetails-CDO verfügt. Ein neues StartDetails-Unterobjekt-CDO wird unter der neuen StartService-Unterklasse hinzugefügt. Diese Vorgehensweise wird für Sie automatisiert, wenn Sie beim Erstellen eines Container-CDOs das Kontrollkästchen "Startdienst erstellen & konfigurieren" (Create & Configure a Start Service) aktivieren.

Weitere Informationen finden Sie unter "Erstellen der Dienstunterklasse mit dem Assistenten".

Hinzufügen der StartHistoryDetail-Unterklasse

Eine Unterklasse des StartHistoryDetail-CDOs wird für das neue Container-CDO erstellt. Dieses neue CDO wird verwendet, um Änderungen an Ihrem Container zu verfolgen, wenn er an Transaktionen beteiligt ist. Dieses CDO wird für Sie automatisch erstellt, wenn Sie beim Erstellen eines Container-CDOs das Kontrollkästchen "Startdienst erstellen & konfigurieren" (Create & Configure a Start Service) aktivieren.

Hinzufügen von Containerfeldern zum Diensthistoriendetails-CDO

In dieser Übung fügen Sie Felder zum Historiendetails-CDO hinzu, um die Historiendaten aus den Feldern "MyField1" und "MyField2" zu erfassen, die Sie zum Aufzeichnen von Historiendaten zu "MyContainer" hinzugefügt haben. Wenn beim Hinzufügen der Felder das Kontrollkästchen "Felder zu zugeordneten Dienstobjekten hinzufügen" (Add Fields to Associated Service Objects) aktiviert war, wird dieser Schritt für Sie automatisiert.

Vorgehensweise zum Hinzufügen von Feldern

Gehen Sie folgendermaßen vor, um Felder hinzuzufügen:

1. Öffnen Sie Designer.
2. Suchen Sie das folgende CDO in der CDO-Klassenbibliothek:

Subentity>HistoryDetails>StartHistoryDetail>MyContainerHistory Detail

3. Wählen Sie MyContainerHistoryDetail aus und öffnen Sie die Registerkarte Felder (Fields).
4. Fügen Sie die Felder MyField1 und MyField2 auf dieselbe Weise zu MyContainerHistoryDetail hinzu, wie Sie sie zu MyContainer hinzugefügt haben.
Hinweis: Dadurch werden der StartHistoryDetail-CDO-Unterklasse Felder hinzugefügt, doch es ist nicht gewährleistet, dass die Felder beim Aktualisieren des Container-CDOs aktualisiert werden. Um sie richtig zu verbinden, müssen Sie die Felder zuordnen. Die Zuordnung wird unter "Anzeigen von Feldzuordnungen" erläutert. Wenn beim Hinzufügen der Felder das Kontrollkästchen "Felder zu zugeordneten Dienstobjekten hinzufügen" (Add Fields to Associated Service Objects) aktiviert war, wird dieser Schritt für Sie automatisiert.
5. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
