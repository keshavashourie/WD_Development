Hinzufügen von Funktionen zu CLFs und Anzeigen der Funktionen eines CLFs

Sie können Benutzer-CLFs Funktionen hinzufügen. Beim Hinzufügen von Funktionen müssen Sie zudem bestimmen, an welcher Stelle (Reihenfolge) die Funktion in den logischen Ablauf eingefügt wird. Sie können die Funktionen am Anfang, in der Mitte oder am Ende des Ablaufs hinzufügen. Sie können mehrere Funktionen gleichzeitig auswählen.

Beim Hinzufügen von Funktionen zu CLFs und beim Anzeigen der Funktionen eines CLFs

Die Anwendung zeigt Standardfunktionen und datenbankspezifische Funktionen in der Liste der verfügbaren Funktionen an. Sie können Funktionen nach Gruppen anzeigen oder indem Sie mithilfe des Filterfelds "Verfügbare Funktionen" nach Funktionen suchen.

• Zum Auswählen einer Funktion aus einer Gruppe, erweitern Sie die Gruppe mit der gewünschten Funktion und wählen Sie sie aus.
• Geben Sie zum Suchen nach einer Funktion die ersten Zeichen des Funktionsnamens oder den ganzen Funktionsnamen ein. Wenn Sie eine Zeichenkette eingeben, wird eine alphabetische Liste von Funktionen angezeigt, deren Namen mit dieser Zeichenkette beginnen. Wählen Sie die gewünschte Funktion aus der Liste aus oder geben Sie den gesamten Funktionsnamen ein und klicken Sie auf "Start".

Vorgehensweise zum Hinzufügen von Funktionen zu einem Benutzer-CLF

Gehen Sie folgendermaßen vor, um einem Benutzer-CLF Funktionen hinzuzufügen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs.
3. Wählen Sie den Benutzer-CLF aus.
4. Klicken Sie auf die Registerkarte Funktionen.
5. Möchten Sie dem CLF Standardfunktionen oder Datenbankfunktionen hinzufügen?

Standardfunktionen

Datenbankfunktionen

6. Verwenden Sie zum Hinzufügen der Funktion eine der folgenden Methoden:
a. Wählen Sie eine vorhandene Funktion im Bereich "Logischer Ablauf" aus und klicken Sie auf Einfügen. Die hinzugefügte Funktion wird am unteren Rand des Ablaufs angezeigt.
b. Wählen Sie eine Funktion aus dem Listenfeld Verfügbare Funktionen aus und klicken Sie auf Anhängen.
c. Wählen Sie eine Funktion aus dem Listenfeld Verfügbare Funktionen aus und ziehen Sie sie in den Bereich "Logischer Ablauf".
7. Klicken Sie auf den geänderten Benutzer-CLF im Auswahlbereich und aktualisieren Sie die Anzeige. Die hinzugefügte Funktion wird im Ablauf an der richtigen Position angezeigt.
8. Ändern Sie die Funktionsparameter nach Bedarf.
Hinweis: Ihre hier vorgenommenen Änderungen wirken sich nur auf den CLF, nicht jedoch auf die Funktion aus, da diese ursprünglich in der Funktionsbibliothek definiert wurde.
9. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Anzeigen von Funktionen für einen bestimmten CLF

Gehen Sie folgendermaßen vor, um die Funktionen für einen bestimmten CLF anzuzeigen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs. Das Fenster "CLF-Definitionen " wird angezeigt.
3. Erweitern Sie eine Kategorie im Auswahlfenster und wählen Sie den CLF aus. Die Funktionen für den CLF werden in der Liste "Logischer Ablauf" in der Reihenfolge angezeigt, in der sie ausgeführt werden.
4. Optional wählen Sie die Funktion in der Liste "Logischer Ablauf" aus, um die Parameter für eine Funktion innerhalb des CLFs anzuzeigen. Die Funktionsparameter (falls vorhanden) werden im Abschnitt "Funktionsparameter" des Fensters angezeigt.
