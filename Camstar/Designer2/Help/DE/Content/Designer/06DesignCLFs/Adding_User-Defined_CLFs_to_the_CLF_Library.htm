Hinzufügen benutzerdefinierter CLFs zur CLF-Bibliothek

Sie können einen benutzerdefinierten CLF hinzufügen, indem Sie einen CLF von Grund auf neu erstellen oder einen Standard-CLF kopieren und anschließend erweitern.

Beim Hinzufügen benutzerdefinierter CLFs zur CLF-Bibliothek

Arbeitsbereichspräfixe werden beim Hinzufügen eines neuen Elements automatisch vor dem Namen des Elements eingefügt, sofern dem höchsten aktiven Arbeitsbereich ein Präfix zugewiesen wurde. Arbeitsbereichspräfixe geben an, auf welchen Arbeitsbereich Designer Änderungen anwendet. Dem Arbeitsbereich würde z. B. das Präfix "C200" zugeordnet werden, wenn für diesen in Management Studio das Präfix "C200" festgelegt wurde. Es wird empfohlen, beim Hinzufügen neuer Elemente die von Designer bereitgestellten Präfixe zu verwenden.

Sie können Arbeitsbereichspräfixe in Management Studio zuweisen oder ändern. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Hinweis: Dem Basisarbeitsbereich der Anwendung (csi) kann kein Arbeitsbereichspräfix zugewiesen sein.
Hinweis: Fügen Sie zu Organisationszwecken einen CLF hinzu oder erweitern Sie einen Standard-CLF in der Kategorie "UserFunctions". Es werden jedoch keine Probleme auftreten, wenn Sie Ihre CLFs in anderen Kategorien hinzufügen.

Vorgehensweise zum Erstellen eines CLFs

Gehen Sie folgendermaßen vor, um einen CLF zu erstellen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs.
3. Wählen Sie die Kategorie UserFunctions (oder eine andere Kategorie) aus.
4. Klicken Sie auf die Schaltfläche Hinzufügen, die sich unter dem Listenfeld "CLF" befindet. Am Ende der CLF-Liste der Kategorie wird ein neuer CLF hinzugefügt, dem ein Standardname zugewiesen ist.
Hinweis: Sie können auch mit der rechten Maustaste im Bereich des Auswahlbaums klicken und "CLF-Definition hinzufügen" (Add CLF Definition) auswählen.

Wenn ein CLF zum ersten Mal hinzugefügt wird, ist der Umbenennungsmodus aktiv.

5. Geben Sie einen Namen für diesen neuen CLF ein.
6. Geben Sie auf der Registerkarte Allgemein eine Beschreibung für diesen CLF ein.

 

7. Bei Bedarf ändern Sie die Einstellung für die Sichtbarkeit in Designer.
8. Fügen Sie auf der Registerkarte Funktionen bei Bedarf Funktionen hinzu.
9. Klicken Sie außerhalb des CLFs, um ihn zu speichern. Der CLF wird der Bibliothek hinzugefügt und kann verwendet werden.
Hinweis: Später können Sie diesen CLF an ein CDO oder Feldereignis anhängen.
10. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Erweitern der Kopie eines Standard-CLFs

Gehen Sie folgendermaßen vor, um die Kopie eines Standard-CLFs zu erweitern:

1. Wählen Sie einen Standard-CLF aus, dessen Funktionalität ähnlich der von Ihnen gewünschte Funktionalität ist.
2. Klicken Sie mit der rechten Maustaste auf den gewünschten CLF und wählen Sie Kopieren (Copy) aus der Liste aus.
3. Klicken Sie mit der rechten Maustaste auf die Kategorie UserFunctions (oder eine beliebige andere Kategorie, der Sie die Kopie hinzufügen möchten) und wählen Sie in der Liste Einfügen [Name des Standard-CLFs] aus. Eine Kopie des CLFs wird hinzugefügt.

Der Umbenennungsmodus ist aktiv. Der kopierte CLF umfasst dieselben Funktionen und Parameter wie das Original von Siemens.

4. Geben Sie einen Namen für diesen erweiterten CLF ein.
5. Klicken Sie auf die Registerkarte Allgemein und geben Sie eine Beschreibung für den CLF ein.
6. Passen Sie den CLF an, indem Sie folgendermaßen vorgehen:
• Hinzufügen, Entfernen, Deaktivieren und Neuanordnen der Funktionen im logischen Ablauf
• Ändern der Parameter, die den (weiter hinten in diesem Kapitel beschriebenen) Funktionen zugeordnet sind
7. Klicken Sie außerhalb des CLFs, um ihn zu speichern. Der CLF wird der Bibliothek hinzugefügt und kann verwendet werden.
Hinweis: Später können Sie diesen CLF an ein CDO oder Feldereignis anhängen.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
