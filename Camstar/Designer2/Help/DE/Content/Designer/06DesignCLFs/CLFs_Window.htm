Fenster "CLFs"

Das Fenster "CLFs" wird verwendet, um konfigurierbare logische Abläufe anzuzeigen, hinzuzufügen, zu ändern, zu entfernen oder zu deaktivieren. Durch Klicken auf die Schaltfläche "CLFs" in der Symbolleiste wird das Fenster "CLFs" geöffnet. CLFs werden entsprechend der Kategorie gruppiert.

CLF-Auswahlbaum

Der linke Bereich enthält einen Auswahlbaum, in dem alle verfügbaren CLF-Kategorien aufgelistet sind. Klicken Sie mit der rechten Maustaste in diesen Auswahlbereich, um das Kontextmenü mit den folgenden Optionen zu öffnen:

• CLF-Definition hinzufügen
• CLF-Definition umbenennen – für Standard-CLFs deaktiviert
• CLF-Definition entfernen – für Standard-CLFs deaktiviert
• Kopieren
• Einfügen

Die oben genannten Optionen, außer "Kopieren"und "Einfügen", sind auch über die Schaltflächen unter dem Bereich zur CLF-Auswahl verfügbar. Beachten Sie, dass Sie die Standardtastaturkürzel für Kopieren und Einfügen nicht verwenden können.

CLF-Details

Der rechte Bereich enthält Details zum ausgewählten CLF. Der Bereich enthält die folgenden Registerkarten:

• Registerkarte "Allgemein"
• Registerkarte "Funktionen"
• Registerkarte "CLF-Parameter"
• Registerkarte "Wo genutzt"
• Registerkarte "Funktionsberechtigung"

Registerkarte "Allgemein"

Die Registerkarte "Allgemein" für CLFs enthält folgende Elemente:

• Ein Feld mit einer Beschreibung des CLFs. In diesem Feld werden Informationen angezeigt, wenn ein bestimmter CLF ausgewählt ist. Es werden keine Informationen auf der Ebene der CLF-Kategorie angezeigt.
• Sichtbarkeit in Designer – Dieser Bereich enthält drei Optionsschaltflächen, die angeben, ob der ausgewählte CLF in der Basisansicht oder in der erweiterten Ansicht von Designer sichtbar ist oder ob er ausgeblendet wird. CLFs, die für die Verwendung durch Siemens reserviert sind, werden ausgeblendet.

Registerkarte "Funktionen"

Die Registerkarte "Funktionen" zeigt Informationen über diesen CLF an, wenn Sie eine Kategorie erweitern und einen CLF auswählen. Wenn Sie zuerst auf CLFs in der Symbolleiste klicken, wird das Fenster "CLF-Definition" auf der Registerkarte "Funktionen" geöffnet.

Die Registerkarte "Funktionen" ist in drei Bereiche unterteilt:

• Logischer Ablauf

In diesem Bereich werden die Reihenfolge der Funktionen, aus denen der CLF besteht, und deren Beschreibungen aufgelistet.

• Verfügbare Funktionen

In diesem Bereich werden die Funktionen aufgelistet, die zum Hinzufügen zum logischen Ablauf verfügbar sind. Sie können auf Funktionen zugreifen, indem Sie sie in den aufgelisteten Gruppen auswählen oder nach ihnen mithilfe des Filterfelds suchen. Geben Sie die ersten Buchstaben oder den gesamten Namen der Funktion in das Filterfeld ein, um nach einer bestimmten Funktion zu suchen. Wenn Sie eine Zeichenkette eingeben, wird eine alphabetische Liste von Funktionen angezeigt, deren Namen mit dieser Zeichenkette beginnen. Wählen Sie die gewünschte Funktion aus der Liste aus oder geben Sie den gesamten Funktionsnamen ein und klicken Sie auf "Start".

Hinweis: Sie können Datenbankfunktionen für standardmäßige CLFs und Standardfunktionen für High Performance-CLFs verwenden. Weitere Informationen zu High Performance-CLFs finden Sie unter "Hinzufügen von High Performance-CLFs".
• Funktionsparameter

In diesem Bereich werden Informationen zu speziellen Parametern der Funktion aufgelistet, die im Bereich "Logischer Ablauf" ausgewählt ist. Abhängig von der ausgewählten Funktion werden die folgenden Informationen angezeigt:

• Parametername
• Das Feld "Parametername" enthält den Eintrag "SQLStatementName", wenn Sie mit bestimmten Datenbankfunktionen arbeiten. Weitere Informationen finden Sie unter "Hinzufügen von High Performance-CLFs".
• Wert
• Richtung
• "Ein" bedeutet, dass der Parameter einen Wert oder eine Referenz an einen CLF übergibt.
• "Aus" bedeutet, dass der Parameter innerhalb des CLFs festgelegt wird.
• "Ein/Aus" bedeutet, dass der Parameter einen Wert an den CLF übergibt und der CLF den Parameter auf einen neuen Wert oder eine neue Referenz festlegt.
• "Rücklauf" gibt an, dass der CLF einen Wert ergibt.
• Dynamisch

Aktivieren Sie das Kontrollkästchen "Dynamisch", wenn der Parameter mithilfe von Suchausdrücken als dynamischer Wert übergeben werden soll. Lassen Sie es deaktiviert, wenn der Parameter als tatsächlicher Wert übergeben werden soll. Wenn die Funktion den Parametertyp erzwingt (festgelegt durch das Flag "Parametertypen erzwingen" (Enforce Parameter Types) im Fenster "Funktionen"), wird das Kontrollkästchen "Dynamisch" (Dynamic) ausgeblendet und die Spalten "Multiplizität" (Multiplicity) und "Datentyp" (Data Type) werden angezeigt.
• Multiplizität

Dieses Attribut gibt die Anzahl der Werte an, die der Parameter übernehmen kann oder muss. Mögliche Werte sind "0...*" (null oder mehr, daher eine optionale Liste), "0...1" (null oder eins, daher optional), "1...1" (eins, daher erforderlich), "1...*" (eins oder mehr, daher eine erforderliche Liste).
• Datentyp

Die Spalte "Datentyp"ist eine Verkettung des Parameterdatentyps oder der Parametertypklasse und der Typmultiplizität.

Unter dem Bereich "Logischer Ablauf" befinden sich vier Schaltflächen, deren Namen Aufschluss über ihre Verwendung geben:

• Anhängen
• Einfügen
• Entfernen
• Deaktivieren

Nur die Schaltfläche "Deaktivieren" ist standardmäßig aktiviert. "Anhängen" und "Einfügen" sind für die benutzerdefinierten Funktionen aktiviert, wenn Sie eine Funktion aus den verfügbaren Funktionen auswählen. "Entfernen" ist für benutzerdefinierte Funktionen aktiviert, wenn eine Funktion an den logischen Ablauf angehängt oder in diesen eingefügt wurde.

Diese Registerkarte wird verwendet, um die Funktionen (und die entsprechenden Parameter), aus denen ein CLF besteht, anzuzeigen oder zu ändern.

Registerkarte "CLF-Parameter"

CLF-Parameter stehen für alle Funktionen im CLF zur Verfügung.

Die Registerkarte "CLF-Parameter" ist in zwei Bereiche unterteilt:

• Im oberen Bereich werden vorhandene Parameter innerhalb des CLF-Bereichs angezeigt.
• Der untere Bereich enthält die Felder zum Definieren oder Ändern der Parameter.

Unter der Parameterliste werden Schaltflächen zum Hinzufügen, Einfügen oder Entfernen von Parametern angezeigt.

Die folgenden Felder dienen zum Definieren der CLF-Parameter:

• Parametername

Der Name des Parameters muss innerhalb des Kontextes der zugeordneten Funktionsdefinitionen im CLF eindeutig sein. Dieser Name wird (als Teil eines Name-Wert-Paar-Konstrukts) zum Abrufen oder Festlegen von Parameterwerten während der Laufzeit verwendet.

• Spezielle Verarbeitung

Das Feld "Spezielle Verarbeitung" ermöglicht Designer die Anzeige einer Auswahlliste für bestimmte Verarbeitungselemente, wenn während der Zuordnung zu einem CLF Feldwerte für Parameter festgelegt werden:

• CDO-Name
Zeigt die Liste der CDO-Namen an.
• Name der DB-Tabelle
Zeigt die Liste der DB-Tabellennamen an.
• Feldausdruck
Zeigt das Popup-Fenster für den Feldausdrucks-Builder an.
• Feldzuordnungs-ID
Zeigt die Liste der Feldzuordnungen an.
• Beschrift.-Id
Zeigt eine Liste der Beschriftungen an.
• Beschriftungsname
Für die zukünftige Verwendung reserviert.
• Methodenname
Zeigt eine Liste der Methoden an, die an das aktuelle CDO angehängt sind, einschließlich geerbter Methoden (nur Ereignisansicht).
• Password
Für die zukünftige Verwendung reserviert.
• Abfragename-Beliebig
Zeigt eine Liste der Abfragedefinitionen an.
• Abfragename-CDO
Zeigt eine Liste der CDO-Abfragedefinitionen an.
• Abfragename-SQL
Zeigt eine Liste der SQL-Abfragedefinitionen an.
• [Standardwert]
• Richtung
• Wählen Sie "Ein" aus, wenn Sie einen Wert oder eine Referenz an einen CLF übergeben möchten.
• Wählen Sie "Aus" aus, wenn Sie einen Parameter innerhalb des CLFs festlegen möchten.
• Wählen Sie "Ein/Aus" aus, wenn Sie einen Wert übergeben möchten und erwarten, dass der CLF den Parameter auf einen neuen Wert oder eine Referenz festlegt.
• Wählen Sie "Rücklauf" aus, wenn der CLF einen Wert ermitteln soll.
• Multiplizität

Dieses Attribut gibt die Anzahl der Werte an, die der Parameter übernehmen kann oder muss. Die Auswahlmöglichkeiten sind "0...*" (null oder mehr, daher eine optionale Liste), "0...1" (null oder eins, daher optional), "1...1" (eins, daher erforderlich), "1...*" (eins oder mehr, daher eine erforderliche Liste).

• Beschreibung

Im Feld "Beschreibung" ist beschrieben, wie der Parameter verwendet wird.

• Datentyp

In diesem Feld wird der Datentyp dieses Parameters angezeigt.

• Typmultiplizität

Parameterdatentypen werden durch Typmultiplizität näher gekennzeichnet. Dies bedeutet, dass Sie angeben können, ob der Parameter skalar oder eine Liste oder beides (ListOrScalar) ist.

• Bestimmter Typ

Wenn der Datentyp "Objekt" ist, wird das Feld "Bestimmter Typ" mit dem Objekttyp für dieses Feld angezeigt.

• Hinweise

Registerkarte "Wo genutzt"

Die Registerkarte "Wo genutzt" zeigt Informationen für den ausgewählten CLF an. Auf der Registerkarte werden zwei Informationstypen angezeigt: wo CDO-Ereignisse verwendet werden und die CDOs, bei denen Feldereignisse den CLF verwenden.

Die Registerkarte "Wo genutzt" enthält folgende Elemente:

• CDO-Name
Dies ist der Name des CDOs, in dem der CLF verwendet wird.
Oder
Dies ist der Name des CDOs mit dem Feld, das den CLF verwendet.
• Feldname
Dies ist der Name des Felds mit dem Ereignis, das den CLF aufruft.
• Ereignisname
Dies ist der Name des CDO-Ereignisses, das die Methode aufruft.
Oder
Dies ist der Name des Feldereignisses, das den CLF aufruft.
• Methodenname
Dies ist der Name der CDO-Methode, die den CLF aufruft.

Registerkarte "Funktionsberechtigung"

Die Registerkarte "Funktionsberechtigung" zeigt die Funktionsmitgliedschaft (Function Membership) für den ausgewählten CLF an. Weitere Informationen zur Funktionsberechtigung finden Sie unter Registerkarte "Funktionsberechtigung".
