Entfernen von CLFs

Sie können nur benutzerdefinierte CLFs entfernen. Wenn Sie einen CLF im Fenster "CLFs" entfernen, wird der CLF aus der CLF-Bibliothek entfernt und nicht mehr in der Auswahl angezeigt, wenn Sie einen CLF an ein CDO-Ereignis oder eine CDO-Methode anhängen möchten.

Wenn der CLF an ein CDO-Ereignis oder eine CDO-Methode angehängt ist, wechseln Sie zu diesem CDO und trennen Sie den CLF zunächst von diesen Ereignissen oder Methoden ab. Wenn der CLF an mehrere CDOs angehängt ist, müssen Sie gewährleisten, dass der CLF von allen CDOs abgehängt wird. Weitere Informationen finden Sie unter "Vorgehensweise zum Abtrennen eines CLFs von einem Ereignis oder einer Methode".

Vorgehensweise zum Entfernen eines CLFs

Gehen Sie folgendermaßen vor, um einen CLF zu entfernen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs.
3. Erweitern Sie die CLF-Kategorie und wählen Sie den zu entfernenden benutzerdefinierten CLF aus.
4. Vergewissern Sie sich, dass die Schaltfläche "Entfernen" (Remove) aktiviert ist. Die Schaltfläche "Entfernen" (Remove) ist deaktiviert, wenn der Benutzer-CLF an ein beliebiges CDO angehängt wurde.
5. Wenn die Schaltfläche "Entfernen" (Remove) deaktiviert ist, klicken Sie auf die Registerkarte Wo genutzt (Where Used), um anzuzeigen, ob der Benutzer-CLF an ein CDO angehängt wurde.
6. Wiederholen Sie die Schritte, um den Benutzer-CLF erneut auszuwählen.
7. Klicken Sie auf die Schaltfläche Entfernen (Remove). Der CLF wird entfernt.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
