Deaktivieren oder Entfernen von Funktionen

Sie können Funktionen aus dem logischen Ablauf der Benutzer-CLFs entfernen. In manchen Fällen ist es sinnvoll, die Funktion und ihre Parameter ohne Löschung beizubehalten, selbst wenn Sie keine Verwendung für eine Funktion in einem CLF haben. Das Deaktivieren einer Funktion ist daher zu bevorzugen, weil Sie die Möglichkeit haben, diese bei Bedarf wieder zu aktivieren. Beim Entfernen einer Funktion aus einem CLF wird die Funktion nicht dauerhaft aus der Bibliothek entfernt.

Sie können z. B. die Funktion "Call" für "FromContainer.ValidateExpirationDate" deaktivieren, indem Sie die Funktion im CLF "ActualsContainer_Validate" und im CLF "ActualsSerialContainer_Validate" deaktivieren. Weitere Informationen finden Sie unter "Vorgehensweise zum Deaktivieren einer Funktion in einem Benutzer-CLF".

Beim Deaktivieren oder Entfernen von Funktionen

Gehen Sie folgendermaßen vor, um Funktionen zu deaktivieren oder zu entfernen:

• Wählen Sie die Funktion(en) im Fenster "Logischer Ablauf"aus und klicken Sie dann nach Bedarf auf die Schaltfläche "Deaktivieren" oder "Entfernen" (Remove).
• Wählen Sie die Funktion(en) im Fenster "Logischer Ablauf"aus, klicken Sie mit der rechten Maustaste und wählen Sie anschließend die Option "Deaktivieren" oder "Entfernen" (Remove) aus.

Vorgehensweise zum Entfernen einer Funktion aus einem Benutzer-CLF

Gehen Sie folgendermaßen vor, um eine Funktion aus einem Benutzer-CLF zu entfernen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs.
3. Wählen Sie den Benutzer-CLF aus.
4. Wählen Sie die Registerkarte Funktionen aus.
5. Wählen Sie die zu entfernende(n) Funktion(en) im Bereich "Logischer Ablauf"aus.
6. Klicken Sie auf Entfernen. Es wird ein Dialogfeld angezeigt, in dem Sie aufgefordert werden, das Entfernen der Funktion zu bestätigen.
7. Klicken Sie auf Ja. Die Funktion wird aus dem CLF, aber nicht aus der Funktionsbibliothek entfernt.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Deaktivieren einer Funktion in einem Benutzer-CLF

Gehen Sie folgendermaßen vor, um eine Funktion in einem Benutzer-CLF zu deaktivieren:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs.
3. Wählen Sie den Benutzer-CLF aus.
4. Wählen Sie die Registerkarte Funktionen aus.
5. Wählen Sie die zu deaktivierende(n) Funktion(en) im Bereich "Logischer Ablauf" aus.
6. Klicken Sie auf Deaktivieren. Die Funktion wird deaktiviert und die Schaltfläche "Deaktivieren" wird durch die Schaltfläche "Aktivieren" (Enable) ersetzt.
Hinweis: Wenn Sie eine Funktion deaktivieren, wird die Änderung für alle angehängten Instanzen des CLFs ebenfalls wirksam. Diese Änderung wird sofort wirksam. Es ist nicht erforderlich, den geänderten CLF erneut anzuhängen.
7. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
