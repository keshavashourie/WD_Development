Ändern der Standardparameterwerte von Funktionen für einen CLF

Wenn Sie einen neuen CLF zu einem CDO hinzufügen, sind viele der Parameterwerte für die Funktionen bereits vorhanden. Diese werden auch als CLF-Standardparameter bezeichnet. Zum Ändern dieser Standardwerte muss die Definition des CLFs geändert werden. Beachten Sie, dass sich das Ändern der Standardparameterwerte nur auf die Vorlagenversion des CLFs auswirkt. Daher sind die Parameterwerte eines CLFs und seine Funktionen, die bereits an ein Ereignis oder eine Methode angehängt sind, nicht betroffen. Wenn Sie die geänderten Parameterwerte für den CLF verwenden möchten, der zuvor an ein Ereignis oder eine Methode angehängt wurde, trennen Sie den CLF dort ab und hängen Sie die geänderte CLF-Definition an.

Diese Änderungen wirken sich nur auf die Funktion des ausgewählten CLFs aus. Weitere Informationen zum Ändern der Funktionsparameter im Allgemeinen finden Sie unter "Bearbeiten von Parameterwerten für eine Funktion".

Vorgehensweise zum Ändern der Standardparameter in einer Funktion für einen CLF

Gehen Sie folgendermaßen vor, um Standardparameter in einer Funktion für einen CLF zu ändern:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs.
3. Wählen Sie den CLF im Auswahlfenster aus.

Im Beispiel wird "MoveIn_Execute" unter "ServiceProcessing" angezeigt.

4. Wählen Sie im Bereich Logischer Ablaufdie zu ändernde Funktion aus. Die Standardparameterwerte für die ausgewählte Funktion werden im Block "Funktionsparameter" (Function parameters) angezeigt.

 

5. Ändern Sie die Standardparameterwerte wie gewünscht.
6. Aktivieren Sie optional das Kontrollkästchen Dynamisch, damit der Parameter als dynamischer Wert mithilfe von Suchausdrücken übergeben werden kann. Lassen Sie es deaktiviert, wenn der Parameter als tatsächlicher Wert übergeben werden soll.
Hinweis: Wenn die Funktion Parametertypen erzwingt (festgelegt durch ein Flag im Fenster "Funktionen"), wird das Kontrollkästchen "Dynamisch" (Dynamic) ausgeblendet und die Spalten "Multiplizität" (Multiplicity) und "Datentyp" (Data Type) werden angezeigt. "Multiplizität" und "Datentyp" sind in diesem Fenster schreibgeschützt. Zum Ändern der Werte für diese Spalten wechseln Sie in das Fenster "Funktionsdefinition", in dem Sie benutzerdefinierte Funktionen ändern können.
7. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
