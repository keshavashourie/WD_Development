Hinzufügen von High Performance-CLFs

High Performance-CLFs sind eine Kategorie von CLFs, die in der Datenbank und nicht auf dem Anwendungsserver verarbeitet werden. Ein High Performance-CLF wird als Teil einer Transaktion definiert und in Form einer oder mehrerer Datenbankanweisungen an die Datenbank gesendet (INSERT, UPDATE, DELETE). Durch das Ausführen von SQL-Anweisungen in der Datenbank wird die Verarbeitung effizienter.

Die High Performance Engine ist eine separat lizenzierte Funktion. Die Kategorie High Performance-CLF wird nicht angezeigt, wenn Sie für diese Funktion nicht lizenziert sind.

Weitere Informationen zur High Performance Engine finden Sie in Opcenter Execution Core – Technische Referenz: High Performance Engine oder Opcenter Execution Medical Device and Diagnostics – Technische Referenz: High Performance Engine.

Beim Hinzufügen von High Performance-CLFs

Die Anwendung zeigt Standardfunktionen und datenbankspezifische Funktionen in der Liste der verfügbaren Funktionen an. Sie können High Performance-CLFs wie andere CLFs hinzufügen, umbenennen und entfernen.

Wenn Sie eine Funktion zu einem High Performance-CLF hinzufügen, stehen Parameter für die Lebensdauer des High Performance-CLF zur Verfügung, die mit dem Präfix "DBCLF::" versehen werden. DBCLF:: Variablen werden von den in der Datenbank gespeicherten Prozeduren erstellt. DBCLF:: Variable Referenzen werden nur in der Datenbank verwendet. Der Anwendungsserver ignoriert das DBCLF::-Präfix und leitet es an die Datenbank weiter.

Wenn Sie einige Datenbankfunktionen wie "ExecuteSingleSQL" in der Liste "Verfügbare Funktionen" auswählen und in den Bereich "Logische Abläufe" ziehen, füllt die Anwendung die Option "Parametername" im Bereich "Funktionsparameter" mit "SQLStatementName" aus. Andere Datenbankfunktionen haben keinen SQLStatementName-Parameter. "SQLParameter" hat beispielsweise den Wertparameter mit dem Datentyp "Beliebig" und "Multiplizität" auf 0 gesetzt. 1.

SQLStatementName verwendet eine spezielle Verarbeitung. Das Popup "Abfrage auswählen" wird angezeigt, wenn Sie auf die Ellipse für dieses Feld klicken. Sie können eine vorhandene Abfrage auswählen, eine vorhandene Abfrage bearbeiten oder mithilfe dieses Popups eine neue Abfrage erstellen. Es sind nur die SQL-Abfragetypen "Erweiterte Abfrage" und "Keine Abfrage" verfügbar. Das Kontrollkästchen "Alle Arbeitsbereiche einbeziehen" ist nicht standardmäßig aktiviert, was darauf hinweist, dass nur Abfragen in Ihrem Arbeitsbereich zur Auswahl zur Verfügung stehen. Wenn Sie dieses Kontrollkästchen aktivieren, können Sie eine Abfrage aus anderen Arbeitsbereichen auswählen.

Das Dialogfenster "Abfragedefinition" wird angezeigt, wenn Sie eine Abfrage bearbeiten möchten. Sie können nur Abfragen bearbeiten, die in dem Arbeitsbereich definiert sind, in dem Sie arbeiten.

Alle mit der Abfrage verknüpften Parameter werden an den High Performance-CLF zurückgegeben, nachdem Sie eine Abfrage ausgewählt oder bearbeitet haben. Die Anwendung füllt die Spalte "Wert" für den SQLStatementName-Parameter mit dem Abfragenamen. Die Liste aller Abfrageparameter wird im Bereich "Logischer Ablauf" angezeigt. Auf diese Weise können Sie die Parameter ausfüllen, die mit der Abfrage verknüpft sind.

Wenn Sie versuchen, die Abfrage in eine neue Abfrage zu ändern, wird eine Warnung angezeigt, in der Sie gefragt werden, ob Sie die SQL-Parameterliste für die aktuelle SQL-Anweisung zurücksetzen möchten. Wenn ja, setzt die Anwendung den Abfragenamen und die Parameter zurück. Wenn dies nicht der Fall ist, behält die Anwendung die vorhandenen Parameter bei.

Sie können auf die Schaltfläche "Neu" im Popupmenü "Abfrage auswählen" klicken, um eine neue Abfrage zu erstellen. Es wird eine leere Abfragedefinition angezeigt.

Vorgehensweise zum Hinzufügen eines High Performance-CLF

Gehen Sie folgendermaßen vor, um ein High Performance-CLF hinzuzufügen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs.
3. Wählen Sie die Kategorie HighPerformance aus.
4. Klicken Sie auf die Schaltfläche Hinzufügen, die sich unter dem Listenfeld "CLF" befindet. Die Anwendung fügt einen neuen CLF mit einem zugewiesenen Standardnamen hinzu.
Hinweis: Sie können auch mit der rechten Maustaste im Bereich des Auswahlbaums klicken und CLF-Definition hinzufügen auswählen.

Wenn ein CLF zum ersten Mal hinzugefügt wird, ist der Umbenennungsmodus aktiv.

5. Geben Sie einen Namen für diesen neuen CLF ein.
6. Geben Sie auf der Registerkarte Allgemein eine Beschreibung für diesen CLF ein.
7. Ändern Sie bei Bedarf die Einstellung für die Sichtbarkeit in Designer.
8. Klicken Sie auf die Registerkarte Funktionen.
