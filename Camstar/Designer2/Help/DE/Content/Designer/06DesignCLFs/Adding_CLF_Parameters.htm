Hinzufügen von CLF-Parametern

Sie können benutzerdefinierten CLFs CLF-Parameter hinzufügen.

Beim Hinzufügen von CLF-Parametern

Während die Werte für Funktionsparameter bei der Konfiguration vom Benutzer festgelegt werden können, werden die Werte für CLF-Parameter durch einige Funktionen, z. B. "Aufruf" und "Wenn", bei ihrer Ausführung festgelegt. CLF-Parameter sind für die Lebensdauer des CLFs verfügbar und weisen das Präfix CLF:: auf. High Performance-CLF-Parameter werden mit dem Präfix "DBCLF::" versehen.

Wenn Sie die hinzugefügten Parameter für den CLF, der zuvor an ein Ereignis oder eine Methode angehängt war, hinzufügen möchten, trennen Sie den CLF dort ab und hängen Sie die geänderte CLF-Definition an.

Vorgehensweise zum Hinzufügen von CLF-Parametern

Gehen Sie folgendermaßen vor, um CLF-Parameter hinzuzufügen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs. Das Fenster CLF-Definitionen wird angezeigt.
3. Wählen Sie den Benutzer-CLF aus, dem Sie Parameter hinzufügen möchten.
4. Klicken Sie auf die Registerkarte CLF-Parameter.
5. Klicken Sie auf Hinzufügen. Ein generischer Parameter mit dem Standardnamen "Parameter1" wird im Listenfenster mit den Parametern angezeigt.
6. Geben Sie einen neuen Namen in das Feld Parametername ein.
7. Klicken Sie auf den generischen Parameter, um den Namen zu speichern. Der neue Name ersetzt den generischen Namen.
8. Wählen Sie eine Eingabe für Spezielle Verarbeitung aus.
9. Wählen Sie eine Richtung für den CLF-Parameter aus.
10. Wählen Sie eine Eingabe für Multiplizität aus.
11. Geben Sie eine Beschreibung Ihres CLF-Parameters ein.
12. Wählen Sie einen Datentyp und die Typmultiplizität aus den Listen Datentyp und Typmultiplizität aus.
13. Geben Sie Hinweise und Kommentare entsprechend den Anforderungen Ihres Unternehmens ein.
14. Klicken Sie außerhalb der Registerkarte "Parameter", um Ihre Änderungen zu speichern.
15. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
