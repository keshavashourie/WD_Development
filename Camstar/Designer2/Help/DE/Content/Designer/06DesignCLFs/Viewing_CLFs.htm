Anzeigen von CLFs

Es gibt zwei Möglichkeiten zum Anzeigen von CLFs:

• Anzeigen der CLF-Bibliothek
• Anzeigen des CDOs und der CDO-Felder, die den CLF verwenden (CLFs können an ein CDO oder die Ereignisse eines CDO-Felds angehängt sein).
Hinweis: Sie können High Performance-CLFs nicht an CDO-Feldereignisse anhängen.

Vorgehensweise zum Anzeigen der vollständigen CLF-Liste in der Bibliothek

Gehen Sie folgendermaßen vor, um die vollständige Liste der CLFs in der Bibliothek anzuzeigen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs. Das Fenster CLF-Definitionen (CLF Definitions) wird mit der CLF-Bibliothek auf der Registerkarte "Funktionen" angezeigt.
3. Erweitern Sie die Kategorien und prüfen Sie die darin enthaltenen CLFs.
4. Wählen Sie einen CLF aus und überprüfen Sie die Funktionen in seinem logischen Ablauf.
5. Wählen Sie eine Funktion aus dem Ablauf aus und überprüfen Sie die Parameterdefinitionen für die Funktion. Wiederholen Sie diese Vorgehensweise für andere Funktionen im logischen Ablauf.
6. Prüfen Sie, ob auf der Registerkarte CLF-Parameter Parameter für den Umfang der gesamten CLFs definiert sind.

Vorgehensweise zum Anzeigen von CLFs, die an ein CDO oder an Feldereignisse angehängt sind

Gehen Sie folgendermaßen vor, um CLFs anzuzeigen, die an ein CDO oder an Feldereignisse angehängt sind:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs.
3. Erweitern Sie eine Kategorie und wählen Sie einen CLF aus.
4. Klicken Sie auf die Registerkarte Wo genutzt.
5. Doppelklicken Sie in einer der Tabellen auf einen CDO-Namen. Das Definitionsfenster des CDOs wird angezeigt.
6. Wenn der CLF vom CDO-Ereignis verwendet wird:

Klicken Sie auf die Registerkarte Ereignisse und erweitern Sie die Methode, die in der Tabelle angegeben ist, um den angehängten CLF anzuzeigen.

Oder

Wenn der CLF vom Ereignis eines CDO-Felds verwendet wird:

a. Doppelklicken Sie auf das Feld, das in der Tabelle angegeben ist, um sein Eigenschaftenfenster zu öffnen.
b. Klicken Sie auf die Registerkarte Ereignisse der Feldeigenschaften.
c. Erweitern Sie das in der Tabelle angegebene Ereignis. Der angehängte CLF wird als Knoten unter dem Ereignis angezeigt.
