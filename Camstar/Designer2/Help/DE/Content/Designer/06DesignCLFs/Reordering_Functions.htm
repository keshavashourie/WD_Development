Neuanordnen von Funktionen

Sie können die Funktionen innerhalb eines Benutzer-CLFs über die Registerkarte "Funktionen" neu anordnen.

Vorgehensweise zum Neuanordnen von Funktionen innerhalb eines Benutzer-CLFs

Gehen Sie folgendermaßen vor, um Funktionen innerhalb eines Benutzer-CLFs neu anzuordnen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CLFs.
3. Wählen Sie den Benutzer-CLF aus.
4. Wählen Sie die Registerkarte Funktionen aus.
5. Wählen Sie eine Funktion im Bereich "Logischer Ablauf"aus.
6. Halten Sie die Maustaste gedrückt und ziehen Sie die Funktion innerhalb des Listenfelds Logischer Ablaufan die neue Position (vor oder hinter einer anderen Funktion).
7. Klicken Sie auf den geänderten Benutzer-CLF im Auswahlbereich und aktualisieren Sie die Anzeige. Die hinzugefügte Funktion wird im Ablauf an der richtigen Position angezeigt.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
