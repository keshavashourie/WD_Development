Importfunktion

Die Importfunktion von Designer fügt Objektdefinitionen (CDO, CLF, Feld usw.), die in einem Importdokument enthalten sind, der aktuellen Metadatenkonfiguration hinzu und erstellt optional ein Protokoll. Das Format des Importdokuments ist gemäß der Struktur der Opcenter EX MDD- oder Opcenter EX CR-Metadaten-XML. Die Struktur ähnelt der Anzeige in Designer, sodass sie relativ leicht zu verstehen ist.

Wenn das Dienstprogramm eine Abweichung feststellt, z. B. wenn der aktuelle Wert nicht dem erwarteten Wert entspricht, werden Sie aufgefordert, die Abweichung zu beheben. Weitere Informationen finden Sie unter "Verarbeitung eines erwarteten Werts".

Für das Beheben von Abweichungen haben Sie folgende Möglichkeiten:

• Der aktuelle Wert bleibt unverändert
• Die Verarbeitung für dieses Dokument wird unterbrochen
• Die Änderung wird angewendet

Die Importfunktion zeigt eine Fehlermeldung an, wenn während des Imports ein Fehler auftritt. Die Fehlermeldung versucht, eine bestimmte Ursache für den Fehler bereitzustellen. Möglicherweise liegt ein Problem mit einem bestimmten Objekt vor. Fehler werden im Ereignisviewer und in einer Protokolldatei mit detaillierten Informationen protokolliert, um zu erläutern, warum der Vorgang fehlgeschlagen ist. Protokolldateien werden standardmäßig im Dateipfad "C:\Program Files (x86)\Camstar\Logs" gespeichert.

Vorgehensweise zum Importieren von Metadaten

Gehen Sie folgendermaßen vor, um Opcenter EX MDD- oder Opcenter EX CR-Metadaten zu importieren:

1. Starten Sie Designer. Das Fenster "Anmelden" wird angezeigt.
2. Gewährleisten Sie, dass das Feld "Metadaten-Datenbank" im Anmeldefenster auf die MDB zeigt, in die Sie Konfigurationen importieren möchten, und melden Sie sich wie erforderlich an.
3. Wählen Sie Importieren (Import) im Menü Datei aus. Das Fenster "InSite-Metadaten importieren" (Import InSite-Metadata) wird angezeigt.

 

4. Klicken Sie auf die Schaltfläche Durchsuchen, um ein Importdokument auszuwählen. Ein Fenster wird geöffnet, in dem Sie die Datei suchen und auswählen können.
5. Wählen Sie das Importdokument aus (falls erforderlich wählen Sie den vollständigen Pfad aus) und klicken Sie auf Öffnen. Das Fenster "InSite-Metadaten importieren" wird angezeigt.
6. Klicken Sie auf Dokument anzeigen, um das Importdokument anzuzeigen, und prüfen Sie bei Bedarf den Inhalt.
7. Klicken Sie auf Importieren (Import), um die Metadaten, die im Importdokument enthalten sind, der aktuellen Konfiguration hinzuzufügen. Ein Eintrag der Änderungen, die an der aktuellen Metadatenkonfiguration vorgenommen wurden, wird nach Abschluss des Imports angezeigt. Die Änderungen werden standardmäßig in einer Protokolldatei gespeichert.
Hinweis: Warten Sie einige Zeit, bis der Import abgeschlossen ist. Die Dauer hängt vom Umfang der zu importierenden Definitionen ab. Der Status des Importvorgangs wird im Statusfenster angezeigt.
8. Wählen Sie die entsprechende Aktion aus und klicken Sie auf Fortsetzen.

Sie müssen alle erkannten Abweichungen beheben.

9. Klicken Sie nach Abschluss des Imports auf Schließen. Die importierten Metadatenänderungen werden in Designer angezeigt.
10. Klicken Sie auf DB aktualisieren. In einem Dialogfeld werden Sie aufgefordert, das Speichern der aktuellen MDB-Datei und die Aktualisierung der Datenbank gemäß den Einstellungen im Dialogfeld "Voreinstellungen" (Preferences) zu bestätigen.
11. Klicken Sie auf Ja. Eine Statusleiste wird am unteren Rand des Fensters angezeigt, um darauf hinzuweisen, dass die Aktualisierung ausgeführt wird. Die Anwendung speichert und aktualisiert die Datenbank.
