Operatorprioritäten

Die Verarbeitungsreihenfolge hängt von den Operator-Prioritäten ab. Mithilfe von Klammern können Operatorprioritäten überschrieben werden.

Leerzeichen in Ausdrücken

Leerzeichen sind erlaubt und werden zwischen Tokens innerhalb von Ausdrücken ignoriert. Beispiele für Tokens sind Feldnamen, Variablennamen, Schlüsselwörter, Operatoren wie ">=" usw. Tokens dürfen keine Leerzeichen enthalten. Die Leerzeichen innerhalb der Zeichenkettenliterale werden unverändert beibehalten.

Unterscheidung zwischen Groß- und Kleinschreibung

Bei Opcenter EX MDD- und Opcenter EX CR-Ausdrücken spielt die Groß-/Kleinschreibung keine Rolle. Dennoch wird empfohlen, die bevorzugte Schreibweise für Variablen, Felder und Schlüsselwörter zu verwenden. Verwenden Sie z. B. "This_Value" anstelle von "this_value" oder verwenden Sie "Transaction::__Return" anstelle von "transaction::__RETURN".

Arithmetische Ausdrücke

Die Semantik arithmetischer Ausdrücke hängt von den Operandentypen ab. Für Integeroperanden wird Integerarithmetik verwendet. Wenn eine Operation sowohl einen Integeroperanden als auch einen Operanden mit Dezimalstelle umfasst, wird die Dezimalstellenarithmetik verwendet. Z. B. wird 1/4 zu 0, aber 1/4. (beachten Sie den Dezimalpunkt hinter 1/4) wird zu .25.

Verarbeitung der Textvariablenersetzung

Die von Opcenter EX MDD und Opcenter EX CR unterstützten Beschriftungen können Textvariablen enthalten, die für Fehlerdetailinformationen, Nachrichten zu Historienabfragen usw. verwendet werden. Die Variablen werden entweder implizit ersetzt, während der erste Feldwert für ein Feld abgerufen wird, für das das Flag zur Verarbeitung von Textvariablen festgelegt ist (z. B. Service.CompletionMsg), oder explizit durch die Funktion "ExpandMessage" (z. B. HistoryMainline.DisplayName). Im ersten Fall wird, da der Beschriftungsbezeichner tatsächlich als Feldwert gespeichert wird, die Syntax der Textvariablen verwendet. Beispiel: #Label::CompletionMoveIn wird anstelle von Label::CompletionMoveIn verwendet.

Die Verarbeitung von Textvariablen wird als optionaler Schritt bei der Ausdrucksauswertung betrachtet. Weitere Informationen finden Sie unter "Beschriftungen mit Textvariablen".

Zeichenketten

Zeichenfolgen müssen in doppelte Anführungszeichen eingeschlossen werden.

Zahlen

Zahlen mit Dezimalpunkt werden mit dezimalen Datentypen verarbeitet.

Nicht unterstützte Operationen

Opcenter EX MDD- und Opcenter EX CR-Ausdrücke unterstützen nicht die folgenden Vorgänge:

• Multiplikativ (%)
• Bitweises AND, XOR, OR
