Implizite Konvertierung

Zu den Typkonvertierungsregeln gehören:

• Boolesche Werte werden nicht in einen anderen Datentyp konvertiert.
• Ein Zeitstempel wird in einen booleschen Wert konvertiert.
• Ein Gleitkommawert wird in einen booleschen Wert konvertiert.
• Eine Zeichenkette wird in einen booleschen Wert konvertiert.
• Ein Objekt wird in einen booleschen Wert konvertiert.
• Ein Dezimaltrennzeichen wird in einen booleschen Wert konvertiert.
• Ein fester Wert wird in einen Dezimal- oder booleschen Wert konvertiert.

Ein Integerwert wird in einen festen, Dezimal-, Gleitkomma- oder booleschen Wert konvertiert. Wenn z. B. ein Mengenfeld (Qty) den Typ "Fixed" aufweist, wird "Qty/4" nicht mithilfe der Integerarithmetik berechnet: Das Literal (die Zeichenkette) 4 wird auf einen festen Typ hochgestuft und die feste Arithmetik wird angewendet.

Für einen Ausdruck wie "Qty/4.0" wird "Qty" auf den Dezimaltyp hochgestuft, da alle Literale mit Gleitkomma als Werte des Typs "Dezimal" dargestellt werden. Anschließend wird die dezimale Arithmetik angewendet.
