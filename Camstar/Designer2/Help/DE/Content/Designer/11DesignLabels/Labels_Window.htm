Fenster "Beschriftungen" (Labels)

Das Fenster "Beschriftungen" (Labels) dient zum Anzeigen von Systembeschriftungen und zum Hinzufügen, Entfernen und Suchen von Benutzerbeschriftungen. Sie können die Schaltflächen im Fenster "Beschriftungen" (Labels) zum Ausführen dieser Funktionen verwenden. Alternativ klicken Sie mit der rechten Maustaste im Auswahlbereich, um das Kontextmenü zu öffnen, und wählen Sie die folgenden Optionen aus:

• Beschriftung hinzufügen (Add Label)

Diese Option ist nur aktiv, wenn Sie eine Beschriftung aus der Benutzerkategorie ausgewählt haben.

• Beschriftung entfernen (Remove Label)

Diese Option ist nur für benutzerdefinierte Beschriftungen aktiv.

• Beschriftung suchen (Find Label)

Diese Option ist nur aktiv, wenn Sie eine definierte Beschriftung (Beschriftung ist nicht leer) ausgewählt haben.

• Nächste Beschriftung suchen

Diese Option ist nur aktiv, nachdem Sie zuvor einmal die Option "Beschriftung suchen" (Find Label) ausgewählt haben.

• Beschriftung kopieren (Copy Label)
• Beschriftung einfügen (Paste Label)

Durch Klicken auf die Schaltfläche "Beschriftungen" (Labels) in der Symbolleiste wird das Fenster "Beschriftungen" (Labels) geöffnet.

Im rechten Bereich wird eine Liste der Beschriftungen angezeigt, die zur ausgewählten Kategorie gehören, unterteilt nach Beschriftungs-ID, Beschriftungsname und Standardbeschriftungstext. Die Schaltflächen unter dieser Liste dienen zum Hinzufügen, Entfernen (Remove) oder Suchen (Find) von Beschriftungen. Das Kontrollkästchen "Details anzeigen" (Show details) ist standardmäßig aktiviert und dient zum Anzeigen eines Abschnitts unter der Beschriftungsliste, in dem Sie den Namen und die Standardbeschriftung einer ausgewählten Beschriftung ändern können.
