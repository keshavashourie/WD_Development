Systembeschriftungen und Benutzerbeschriftungen

Es gibt zwei allgemeine Beschriftungstypen: "System" und "Benutzer".

Systembeschriftungen werden mit Opcenter EX MDD und Opcenter EX CR bereitgestellt und verwendet. Systembeschriftungsnamen haben das Präfix "CSI". Diese Beschriftungen sind in verschiedene Kategorien unterteilt. Beispiele für diese Kategorien:

• CSIAdminSys – Diese Beschriftungen werden in verschiedenen Fehlermeldungen verwendet, z. B. "Ungültige CDO-Definition" (Invalid CDO Definition). Diese Kategorie weist keine zugehörige Kategorie im Benutzerbereich auf.
• CSIField – Diese Beschriftungen werden als Feldüberschriften in der Clientschnittstelle angezeigt, z. B. im Portal.

Benutzerbeschriftungen enthalten leere Kategorien, denen das Präfix "Sonstige" (Other) vorangestellt ist, sodass Sie Ihre eigenen benutzerdefinierten Beschriftungen hinzufügen können. Für die meisten Systembeschriftungen gibt es eine entsprechende Benutzerbeschriftungskategorie. Wenn Sie Beschriftungen anpassen, erstellen Sie sie unter der Kategorie, zu der der Feldwert am ehesten passt (abhängig von der Bedeutung der Beschriftung). Wenn keine andere Kategorie passend ist, verwenden Sie die Kategorie "MiscAppText".

Allen Beschriftungen wird eine eindeutige ID zugewiesen, anhand der sie aufgerufen werden können, wenn von einer Anwendung Beschriftungen verwendet werden.
