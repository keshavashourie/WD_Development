Entfernen einer Beschriftung

Systembeschriftungen können nicht entfernt werden. Sie können nur benutzerdefinierte Beschriftungen entfernen. Sie können jedoch keine Beschriftung entfernen, die derzeit von einem CDO verwendet wird.

Vorgehensweise zum Entfernen einer Beschriftung

Gehen Sie folgendermaßen vor, um eine Beschriftung zu entfernen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Beschriftungen (Labels). Das Fenster "Beschriftungen" (Labels) wird angezeigt.
3. Erweitern Sie die Liste "Benutzerbeschriftungen" (User labels).
4. Wählen Sie die Kategorie aus, zu der die Beschriftung gehört.
5. Wählen Sie die zu entfernende Beschriftung aus.
6. Klicken Sie mit der rechten Maustaste und wählen Sie "Beschriftung entfernen" (Remove Label) aus oder klicken Sie auf die Schaltfläche Entfernen (Remove). Ein Dialogfeld wird angezeigt, damit Sie bestätigen können, dass Sie die Beschriftung entfernen möchten.
7. Klicken Sie auf Ja. Der Pfad wird entfernt.
Hinweis: Wenn die Beschriftung von einem CDO verwendet wird, wird die Nachricht angezeigt, dass die Beschriftung verwendet wird und nicht entfernt werden kann.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
