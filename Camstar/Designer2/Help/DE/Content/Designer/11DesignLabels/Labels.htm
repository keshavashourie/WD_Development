Beschriftungen

Beschriftungen dienen zum Anpassen von Nachrichten und Text, z. B. von angezeigten Feldüberschriften, Fehlermeldungen, Beendigungsnachrichten für Transaktionen, Zeichenkettenauswahlwerten usw. Beschriftungen für Feld- und CDO-Namen werden automatisch der Beschriftungsbibliothek hinzugefügt, wenn Sie in das Feld "Überschrift" im CDO oder in den Fenstern zur Felddefinition einen neuen Wert eingeben.

Sie haben die Möglichkeit, die Beschriftungen so anzupassen, dass sie für Ihr Unternehmen aussagekräftiger sind. Beschriftungen werden nach Beschriftungs-ID, Name und Beschriftungswert (LabelValue) kategorisiert. Die Beschriftungs-ID wird beim Erstellen der Beschriftung vom System zugewiesen. Der Name ist eine optionale Zeichenkette zum Identifizieren der Beschriftung. Bei dem Namen kann es sich um die abgekürzte Version des Beschriftungswerts (LabelValue) oder um eine aussagekräftigere Beschreibung handeln. "LabelValue" ist der eigentliche Text, der in der Benutzeroberfläche angezeigt wird.

Ihre Konfigurationen in diesem Bereich haben im Gegensatz zu den Beschriftungsänderungen, die innerhalb von CDOs an Feldeigenschaften vorgenommen werden, globale Auswirkungen. In den CDO-Feldeigenschaften ist die Änderung einer Feldbeschriftung auf den Kontext des CDOs beschränkt. Die Änderung der Beschriftung für "Qty" innerhalb des MoveTxn-CDOs hat z. B. keine Auswirkungen auf die Beschriftung von "Qty" in anderen Transaktionen. Wenn Sie die Beschriftung hier ändern, werden jedoch alle Beschriftungen für "Qty" geändert.

Beschriftungen können durch Ändern der Überschriften des Felds "IssueControlEnum" in Designer geändert werden.

Hinweis: Opcenter EX MDD oder Opcenter EX CR bietet auch die Möglichkeit, Beschriftungen mithilfe des Portals für Beschriftungen zu erstellen, die keine Beziehung zu Opcenter EX MDD- und Opcenter EX CR-Objekten aufweisen. Diese Benutzerbeschriftungen werden beim Erstellen der Portal-Formulare verwendet. Weitere Informationen zu Benutzerbeschriftungen finden Sie im Opcenter Execution Medical Device and Diagnostics Modeling-Benutzerhandbuch oder im Opcenter Execution Core Modeling-Benutzerhandbuch.
