Beschriftungen mit Textvariablen

Neben statischen Beschriftungen können Sie Daten während der Laufzeit mit der Beschriftung zusammenführen, indem Sie Textvariablen verwenden. Textvariablen beschreiben, wie ein Wert zur Laufzeit abgeleitet wird, der in eine Nachrichtenzeichenkette integriert werden soll. Diese werden von verschiedenen Objekten (z. B. Umlaufbestandsnachrichten oder Historienabfragen) verwendet, um die Variablen in Zeichenketten zu integrieren.

Wenn Sie z. B. eine Starttransaktion ausführen und diese erfolgreich ist, wird die folgende Nachricht angezeigt:

<Containername> started at <Startschritt> on <Datum> by <Benutzer>

Diese Beendigungsnachricht ruft tatsächlich "StartCompletion" auf, also eine Beschriftung unter "CSICompletion". Wenn Sie diese Beschriftung in der Beschriftungsbibliothek anzeigen, lautet der Text für diese Beschriftung wie folgt:

#HistInq.Container started at #HistInq.StartStep on #HistInq.Date by #HistInq.User.

Die Variablen (denen das Zeichen # vorangestellt ist), werden durch entsprechenden Text ersetzt, z. B. den Containernamen, den Namen des Startschritts im Arbeitsplan, das Transaktionsdatum und den Benutzer, der die Transaktion eingegeben hat. Dieser Text wird aus der Datenbanktabelle "HistoryMainline" abgerufen.

Das TextVariable-CDO

"TextVariable" ist ein benanntes Datenobjekt, mit dem Werte bereitgestellt werden, die während der Laufzeit aufgelöst und dann in eine Nachrichtenzeichenkette integriert werden.

Das Textvariable-CDO weist zwei Typen auf, die von Opcenter EX MDD und Opcenter EX CR zur Verarbeitung von Beschriftungen verwendet werden:

• ErrorMsg

Stellt die Werte bereit, die zum Erstellen von Fehlermeldungen verwendet werden

• HistInq

Enthält die Werte, die aus dem HistoryMainline-CDO abgerufen wurden

Diese Tabelle listet alle Felder im TextVariable-CDO auf.

Feldname

Beschreibung

ChangeHistory

Details zur letzten Änderung.

UnresolvedValue

Dieser Wert wird verwendet, falls der Ausdruck nicht erfolgreich ausgewertet werden kann. Hierbei kann es sich um eine leere Zeichenkette (dann wird die Tatsache, dass der Ausdruck nicht ausgewertet werden kann, ignoriert) oder um einen anderen Wert (z. B. "FEHLER!") handeln, um deutlich zu machen, dass der Text (der erstellten Nachricht) nicht vollständig oder nicht exakt ist.

VariableExpression

Die auszuwertende Zeichenkette, die den Wert zur Laufzeit erzeugt. Der Wert ersetzt den Identifikator innerhalb der Laufzeitversion der Zeichenkette.

Das Format ist "CDO.Feld".

VariableUsage

Definiert den Typ von "TextVariable". Zum Beispiel:

1 = Allgemein (kann in jedem Text verwendet werden)

2 = Umlaufbestandsnachricht

3 = Alarmmeldung

4 = Anweisungstext

Die folgenden Felder werden von der Basisklasse geerbt.

CDOTypeID

Eine Zeichenfolgendarstellung eines 24-Bit-Objekttypidentifikators, der von Opcenter EX MDD oder Opcenter EX CR zugewiesen wurde.

ChangeCount

Systemfeld, das verwendet wird, um die Datenintegrität zu gewährleisten, wenn mehrere Benutzer gleichzeitig dasselbe Objekt ändern.

Beschreibung

Beschreibung dieses Objekts. Der Standardwert ist der Name dieses Objekts, sofern nicht angegeben

DisplayName

"DisplayName" ist das Feld, das in der Regel verwendet wird, um ein Objekt in einer Benutzeroberfläche darzustellen, vor allem, wenn die Benutzeroberfläche ein Objekt mit nur einem Datenelement darstellen muss. Normalerweise würden zur Darstellung eines revisionierten Objekts z. B. einfach der Name und die Revision des Objekts angezeigt. Der Anzeigename umfasst genügend erforderliche Elemente zur Darstellung des Objekts. Für ein revisioniertes Objekt würde es z. B. den Namen und die Revision mit einem Trennzeichen enthalten. Dies ist besonders hilfreich, wenn Objekte in Kombinationsfeldern und anderen einspaltigen Listen angezeigt und der Anzeigename verwendet werden sollte. "DisplayName" ist in der Regel ein nicht persistentes Feld.

IconID

Identifikator für das Symbol, das diesem Basisobjekt zugeordnet ist

InstanceID

Eindeutige ID für eine Instanz dieses Objekts, die vom System erzeugt wurde.

IsFrozen

Bestimmt, ob Änderungen an dieser Instanz (oder an den zugehörigen Revisionen) erlaubt sind.

Name

Der Wert, der in eine statische Zeichenkette eingebettet ist und dem ein Zeichen vorangestellt ist, das ihn als Textvariable kennzeichnet.

WhereUsed

Eine Liste dieses Typs wird durch die Funktion "Wo genutzt" (Where used) eines Wartungsdienstes zurückgegeben. Eine Instanz dieses CDOs gibt eines der Objekte mithilfe des zu ändernden Objekts an. Die Felder in diesem CDO werden verwendet, um beim Modellieren eines Objekts eine Baumansicht auszufüllen.

Jede Instanz von "TextVariable" enthält neben ihren Attributen einen Namen und einen Ausdruck und beschreibt, wie vorzugehen ist, wenn der Ausdruck nicht erfolgreich ausgewertet werden kann.

Der Name ist ein in die statische Zeichenkette eingebetteter Wert, dem ein Zeichen vorangestellt ist, das ihn als Textvariable kennzeichnet. Beispiel für eine Instanz von "TextVariable" mit dem Namen "TEMPERATURE", die in die Standardbeschriftung eingeschlossen wird:

Set Temperature to #TEMPERATURE.

Warten und Verwenden von Textvariablen

Unter der Wartung von Textvariablen versteht man das Erstellen von Instanzen des Textvariablen-NDOs im Fabrikmodell und das anschließende Erstellen von Beschriftungen, die sich auf die Instanzen der Textvariablen beziehen. Wenn Sie Textvariablen verwenden, definieren Sie ein Feld zum Aufrufen von Beschriftungen, die Textvariablen verwenden.

In diesem Szenario liegt ein Dienst-CDO mit einem Feld mit der Bezeichnung "SpecialInstruction" vor. Sie möchten im Feld die Nachricht "Set Temperatur to 700" anzeigen. Sie haben auch die erforderlichen Definitionen für den Temperaturwert erstellt, der in einem anderen CDO gespeichert werden soll.

Vorgehensweise zum Warten von Textvariablen

Gehen Sie folgendermaßen vor, um Textvariablen zu warten:

1. Melden Sie sich beim Portal an und erstellen Sie eine Instanz von "TextVariable", indem Sie für diese einen Namen und einen Ausdruck angeben.

Verwenden Sie z. B. "Temperatur" als Namen und "CDO.Feld" als Format für den Ausdruck. Der Ausdruck enthält das Feld "CDO" aus dem der Wert, also die Temperatur 700, abgerufen wird.

2. Melden Sie sich bei Designer oder beim Portal an und erstellen Sie eine Beschriftung mit der Bezeichnung "MyInstruction", die die Textvariableninstanz referenzieren wird. Geben Sie im Beschriftungswert den Nachrichtentext, der die Zeichenkette "#Temperature" enthält, so ein, dass er dem Instanznamen der Textvariablen entspricht.

Richtlinien zur Eingabe von Textvariablen in Standardbeschriftungswerte:

a. Legen Sie einen Platzhalter für die Textvariable fest, die während der Laufzeit mit Ihrem Beschriftungswert zusammengeführt wird.
b. Geben Sie für das Format des Platzhalters den Instanznamen der Textvariablen an.

Der Beschriftungswert für "MyInstruction" kann z. B. in etwa wie folgt aussehen:

Set the temperature to #Temperature.

Verwenden von Textvariablen

Weitere Informationen zur Verwendung der Beschriftung mit den Textvariablen finden Sie unter "Verwenden von Beschriftungen". In diesem Fall konfigurieren Sie das Dienst-CDO, um "MyInstruction" abzurufen, also die Beschriftung mit der Textvariablen "Temperature", und sie im Feld "SpecialInstruction" anzuzeigen.

Während der Dienstverarbeitung ruft das Feld den Beschriftungswert mit dem entsprechenden Text ab, der die Variable ersetzt.

Vorgehensweise zum Auswerten von Variablenausdrücken

Wenn Sie eine Textvariable (TextVariable) definieren, geben Sie einen Ausdruck an, der zum Suchen der Daten verwendet wird. Der Ausdruck ist eine Zeichenkette, die während der Laufzeit ausgewertet wird, um den Wert zu ermitteln, der die Kennung innerhalb der Laufzeitversion der Zeichenkette ersetzt. Diese Daten stammen in der Regel aus einem CDO. Das zu verwendende CDO wird vor dem Abrufen des Felds bestimmt.

Beachten Sie den folgenden Standardbeschriftungswert für eine Beendigungsnachricht:

#HistInq.Container started at #HistInq.StartStep on #HistInq.Date by #HistInq.User.

Der Ausdruck enthält Platzhalter für die Daten aus "TextVariable", die zusammengeführt werden sollen. Die Platzhalter geben den Typ und den Namen der Textvariablen an. Bei Fehlermeldungen lautet das Format #ErrorMsg.CDOName, in Historiennachrichten lautet es #HistInq.Step.

Im Fall der oben aufgeführten Variablen "StartStep" lautet der angegebene Ausdruck z. B. wie folgt:

Transaction::InProcessHistoryCDO.WorkflowStep.Name

Standardmäßig führt "ContainerTxn" als eine der letzten Aufgaben die Funktion "SetFieldEx" aus, um "Transaction::InProcessHistoryCDO" für diese Transaktion auf die ID des HistoryMainline-CDOs festzulegen (beachten Sie, dass dieser Prozess nicht für den Benutzer verfügbar gemacht wird). Beim Verarbeiten des Felds "CompletionMsg" wird der oben aufgeführte Beschriftungswert gefunden. Das System prüft das Flag zum Ersetzen von Textvariablen (Substitute Text Variables) und erkennt, dass es gesetzt ist. Daher durchläuft es die Zeichenkette und erkennt die Platzhalter, einschließlich #HistInq.StartStep. Anschließend ruft die es die Textvariable "HistInq" mit dem Namen "StartStep" auf, wertet den Ausdruck "Transaction::InProcessHistoryCDO.WorkflowStep.Name" aus und ersetzt den Platzhalter durch das Ergebnis (der Name des Schritts, in dem der Container gestartet wurde).

Wie genau eine gültige Ausdruckszeichenkette aussieht, hängt vom Typ der Nachricht ab, die die Textvariable referenziert. Einige Ausdrücke (und somit Textvariablen) können von allen Nachrichtentypen verwendet werden. Mithilfe einer Textvariablen können z. B. Werte für die aktuellen SessionValues integriert werden. Andere Ausdrücke ergeben nur im Kontext eines bestimmten Nachrichtentyps einen Sinn. Eine Umlaufbestandsnachricht kann z. B. eine Variable für das Produkt enthalten, das momentan auf der Maschine bearbeitet wird, wobei die Anmeldetransaktion die Umlaufbestandsnachricht anzeigt.
