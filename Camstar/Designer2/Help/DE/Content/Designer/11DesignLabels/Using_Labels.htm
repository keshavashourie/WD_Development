Verwenden von Beschriftungen

Wenn Sie Beschriftungen verwenden, bedeutet dies, dass Sie den Beschriftungswert auf der Benutzeroberfläche anzeigen möchten. Feldüberschriften werden angezeigt, wenn Sie die Eigenschaften des CDO-Felds so konfigurieren, dass sie eine Beschriftung als Überschrift verwenden.

Wenn Beschriftungen während der Ausführung als Nachrichten einer Transaktion angezeigt werden sollen, sind weitere Konfigurationen erforderlich. Sie müssen mit CDOs (in der Regel Dienst-CDOs), Feldern, CLFs, Funktionen, Parametern, Ereignissen und Methoden vertraut sein, um Beschriftungen als Textnachrichten verwenden zu können.

In diesem Thema ist beschrieben, wie Sie vorgehen müssen, um eine Beschriftung so zu verwenden, dass der Beschriftungstext während der Transaktionsverarbeitung in einem CDO-Feld angezeigt wird. Die genaue Vorgehensweise, z. B. das Erstellen von CLFs, Festlegen von Funktionsparametern und Anhängen von CLFs an Ereignisse und Methoden finden Sie in anderen Themen.

Vorgehensweise zum Verwenden einer Beschriftung

Gehen Sie folgendermaßen vor, um eine Beschriftung aus der Bibliothek zu verwenden:

1. Öffnen Sie Designer.
2. Erstellen Sie eine Beschriftung (z. B. LabelName) oder bestimmen Sie eine vorhandene Opcenter EX MDD- oder Opcenter EX CR-Beschriftung, die Sie verwenden möchten.
3. Wählen Sie das Dienst-CDO aus, das die Beschriftung verwenden wird, oder erstellen Sie es.
4. Wählen Sie das Feld aus, das den Beschriftungswert abrufen wird, oder fügen Sie es hinzu.
5. Konfigurieren Sie die Eigenschaften des Felds wie folgt:
a. Klicken Sie auf die Registerkarte Erweiterte Optionen.
b. Klicken Sie unter Spezielle Verarbeitung (Special Processing) auf das boolesche Feld Textvariablen ersetzen (Substitute Text Variables).
6. Erstellen Sie einen CLF mit den folgenden Konfigurationen:
a. Fügen Sie die Funktion SetFieldEx hinzu (diese stammt aus der Kategorie "FieldProcessing").
b. Legen Sie für den Parameter Von (From) den folgenden Wert fest, der den Namen der Beschriftung in Schritt 1 aufweist:

#Label::LabelName

c. Legen Sie für den Parameter Nach (To) den Namen des Felds in Schritt 4 fest. Dieser CLF legt als Wert des Felds die Beschriftung fest.
7. Wählen Sie das CDO in Schritt 3 aus und klicken Sie auf die Registerkarte Ereignisse.
8. Hängen Sie den in Schritt 6 erstellten CLF an ein Ereignis oder eine Methode an.
9. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

In der obigen Vorgehensweise wird veranschaulicht, wie Sie eine statische Beschriftung verwenden. Weitere Informationen zum Auflösen und Anzeigen einiger Beschriftungswerte während der Laufzeit finden Sie unter "Beschriftungen mit Textvariablen".
