Ausführen des Dienstprogramms "Metadata Export"

Siemens stellt das Dienstprogramm "Metadata Export" zum Anzeigen der Unterschiede zwischen Ihrer Basismetadaten-Datenbank (MDB) und einer geänderten MDB zur Verfügung. Das Dienstprogramm vergleicht die beiden Datenbanken und erlaubt Ihnen den gezielten Export der Unterschiede (Delta) in eine XML-Datei. Das Dienstprogramm bietet auch die Möglichkeit, einen Bericht über die Unterschiede zwischen den beiden Datenbanken zu generieren.

Beim Ausführen des Dienstprogramms "Metadata Export"

Das Dienstprogramm "Metadata Export" wird in einem Fenster angezeigt, das drei Bildschirme enthält, die Sie durch den Vorgang zum Exportieren und zum Generieren des Berichts führen. In jedem Bildschirm wird oben rechts eine Bildschirmnummer angezeigt, die Ihnen die Verfolgung des Vorgangs erleichtert.

Diese Bildschirme werden im Dienstprogramm in der folgenden Reihenfolge angezeigt:

• Zu vergleichende Dateien auswählen (Select Files to Compare)
• Auszugebende Änderungen auswählen (Select Changes to Output)
• Ausgabeoptionen auswählen

Im Dienstprogramm können Sie von einem Bildschirm zum nächsten wechseln, indem Sie auf die Schaltfläche "Weiter" klicken. Durch Klicken auf die Schaltfläche "Vorhergehende" (Previous) gelangen Sie zu einer vorherigen Anzeige zurück. Durch Klicken auf "Abbrechen" wird das Fenster des Dienstprogramms "Metadata Export" geschlossen, es wird kein Export ausgeführt und kein Metadatenbericht generiert.

Wenn Sie im Hilfemenü "Über" auswählen, wird das Popup-Fenster "Über Metadata Export" mit den Produkt- und Versionsinformationen zum Dienstprogramm "Metadata Export" angezeigt. Sie können das Popup "Über Metadata Export" (About Metadata Export) schließen, indem Sie auf die Schaltfläche "Schließen" klicken.

Das Dienstprogramm zeigt eine Fehlermeldung an, wenn während des Exports ein Fehler auftritt. Die Fehlermeldung enthält Informationen dazu, wo das Dienstprogramm beim Export den Fehler erkannt hat und welche Objekte nicht kompiliert werden können. Fehler werden im Ereignisviewer (Event Viewer) und in einer Protokolldatei mit detaillierten Informationen protokolliert, um zu erläutern, warum der Vorgang fehlgeschlagen ist. Protokolldateien werden standardmäßig im Dateipfad "C:\Program Files (x86)\Camstar\Logs" gespeichert.

Bildschirm "Zu vergleichende Dateien auswählen" (Select Files to Compare)

Für den Vergleich im Bildschirm "Zu vergleichende Dateien auswählen" (Select Files to Compare) müssen Sie eine Basis-MDB und eine geänderte MDB angeben. Für die Basis- und die geänderte MDB kann nicht die gleiche MDB-Datei verwendet werden. Das Dienstprogramm zeigt den höchsten aktiven Arbeitsbereich für jede Datenbank an und die Arbeitsbereiche müssen die gleiche Reihenfolge aufweisen, damit Sie fortfahren können. Das Dienstprogramm vergleicht nur Datenbanken mit dem gleichen Arbeitsbereich. Standardmäßig werden in diesen Feldern die letzten MDBs angezeigt, die zuvor bei der Verwendung des Dienstprogramms angegeben wurden.

Hinweis: Arbeitsbereiche werden in Management Studio aktiviert. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Das Dienstprogramm beginnt mit der Kompilierung einer Datenbank, nachdem Sie eine Datenbank in den Feldern "Basis-MDB" (Base MDB) oder "Geänderte MDB" (Modified MDB) angegeben haben. Der Text "Kompilierung" (Compiling) wird neben dem Feld angezeigt. Nach erfolgreicher Kompilierung der Datenbank wird der Text "Kompiliert" (Compiled) angezeigt. Das Dienstprogramm aktiviert die Schaltfläche "Weiter" , wenn die Kompilierung beider Datenbanken abgeschlossen wurde.

Das Dienstprogramm vergleicht die Basis- und die geänderte MDB, wenn Sie im Bildschirm "Zu vergleichende Dateien auswählen" (Select Files to Compare) auf die Schaltfläche "Weiter" klicken. Während des Vergleichs wird ein Status-Popup mit Textaktualisierungen angezeigt. Nach Abschluss des Vorgangs wird das Status-Popup geschlossen.

Bildschirm "Auszugebende Änderungen auswählen" (Select Changes to Output)

Im Bildschirm "Auszugebende Änderungen auswählen" (Select Changes to Output) wird eine Liste mit Definitionen in einer Reihe von Baumstrukturen angezeigt, die nach Objekttyp für die geänderten Objekte angeordnet sind, die während des MDB-Vergleichs gefunden wurden.

In diesem Bildschirm werden die folgenden Objekttypen angezeigt:

• CDOs
• CLFs
• Felder
• Datenbanktabellen
• Funktionen
• Abfragen
• Beschriftungen
• Funktionen
Hinweis: IDs werden nicht mit Ihrer Zielumgebung synchronisiert, wenn Sie einen Export ausführen, der berechtigte Funktionen enthält. Siemens empfiehlt die Verwendung des Dienstprogramms Replace Workspace Data, um zu gewährleisten, dass IDs im Rahmen des Ersetzungsvorgangs aktualisiert werden. Informationen zum Dienstprogramm zum Ersetzen von Arbeitsbereichsdaten finden Sie in der Installationsanleitung.Opcenter Execution Medical Device and Diagnostics Installationsanleitung oder Opcenter Execution Core Installationsanleitung.

Sie können einen Baum erweitern und bestimmte Objektdefinitionen auswählen, die im Export- oder Metadatenbericht berücksichtigt werden sollen. Im rechten Bereich des Bildschirms werden bei Auswahl einer Objektdefinition zusätzliche Informationen zur Objektdefinition angezeigt. Sie können alle verfügbaren Objektdefinitionen durch Klicken auf die Schaltfläche "Alle auswählen" (Select All) auswählen. Zudem können Sie auf die Schaltfläche "Alle erweitern" klicken, um alle Baumstrukturen zu erweitern und die vollständige Liste der geänderten Objektdefinitionen anzuzeigen.

Hinweis: Beim Klicken auf die Schaltfläche "Alles erweitern" (Expand All) wird eine Warnmeldung angezeigt, um Sie darüber zu informieren, dass der Vorgang zum Erweitern aller Baumstrukturen einige Minuten dauern kann, wenn zahlreiche geänderte Objekte vorliegen. Klicken Sie auf "OK", um die Warnmeldung zu schließen.

Sie können nach bestimmten Objekten suchen, indem Sie den Namen des Objekts in das Suchfeld eingeben und auf die Schaltfläche "Suchen" klicken.

Wenn Sie auf "Weiter" klicken, ohne mindestens eine Definition ausgewählt zu haben, wird eine Warnmeldung angezeigt, um Sie darüber zu informieren, dass keine Änderungen für den Export ausgewählt wurden. Klicken Sie auf "OK", um die Warnmeldung zu schließen, und wählen Sie dann mindestens eine Definition aus.

Bildschirm "Ausgabeoptionen auswählen"

Über den Bildschirm "Ausgabeoptionen auswählen" können Sie steuern, was mit dem Export-Tool generiert wird:

• Eine Metadatenexportdatei im XML-Format
• Ein Metadatenexportbericht (im HTML- oder DOC-Format) oder
• Beides

Aktivieren Sie Folgendes:

• Kontrollkästchen "Exportdatei", um die Metadatenexportdatei im XML-Format zu generieren.
• Kontrollkästchen "Berichtsdatei", um die Metadatenberichtsdatei zu generieren.
• Kontrollkästchen "IDs für die Höherstufung von Funktionen einschließen" (Include IDs for Feature Promotion), um die Metadaten-IDs in die Metadatenexportdatei im XML-Format einzuschließen.

Wenn Sie das Kontrollkästchen "Exportdatei" oder "Berichtsdatei" aktivieren, wird das zugehörige Textfeld und die Dateiauswahlfunktion aktiviert, damit Sie die Ausgabedatei und den entsprechenden Pfad angeben können.

Das Metadatenexporttool aktiviert die Schaltfläche "Beenden", nachdem Sie die gewünschte Ausgabe, Datei und den gewünschten Speicherort für die Datei angegeben haben. Durch Klicken auf die Schaltfläche "Beenden" wird mit der Dateigenerierung begonnen. Nach Abschluss der Dateigenerierung wird ein Status-Popup mit einer Erfolgsmeldung angezeigt.

Beim Generieren von Export- und Metadatenberichtsdateien

Das Dienstprogramm speichert Exportdaten standardmäßig im XML-Format und Metadatenberichte im HTML-Format. Das Dienstprogramm unterstützt HTML- und DOC-Formate für Metadatenberichte.

Der Standardpfad für exportierte XML-Dateien und Metadatenberichtsdateien lautet wie folgt: C:\Users\<Benutzerordner>\Desktop (z. B. C:\Users\msmith\Desktop).

Der Standarddateiname für XML-Dateien ist der geänderte Dateiname, gefolgt vom Arbeitsbereich und dem Wort "export", jeweils durch Unterstriche getrennt. Wenn z. B. der geänderte Dateiname "ModifiedMDB.mdb" lautet und der Arbeitsbereich "csi" ist, dann wäre der Standarddateiname "ModifiedMDB_csi_export.xml".

Der Standarddateiname für generierte Berichtsdateien ist der geänderte Dateiname, gefolgt vom Arbeitsbereich und dem Ausdruck "exportReport", jeweils durch Unterstriche getrennt. Wenn z. B. der geänderte Dateiname "ModifiedMDB.mdb" lautet und der Arbeitsbereich "csi" ist, dann wäre der Standarddateiname "ModifiedMDB_csi_exportReport.html".

Sie können für Exporte einen anderen Pfad und Dateinamen angeben, indem Sie für das Feld "Exportdatei" auf "Durchsuchen" klicken. Sie können einen anderen Pfad, Dateinamen und Dateityp für Berichte angeben, indem Sie für das Feld "Berichtsdatei" auf "Durchsuchen" klicken.

Ausführen des Dienstprogramms "Metadata Export" über die Eingabeaufforderung

Sie können das Dienstprogramm "Metadata Export" über die Eingabeaufforderung ausführen. Rufen Sie das Dienstprogramm mit dem folgenden Befehl auf:

"MetadataExport [-a] [-b baseFileName] [-m modifiedMDBFileName] [-o outputXMLFileName] [-r reportHMTLFileName]"

Die einzelnen Parameter werden durch ein Leerzeichen getrennt und beginnen mit einem Gedankenstrich. Die Werte, mit denen Sie die Variablen ersetzen, sind mit den Werten identisch, die von den Feldern in den Bildschirmen des Dienstprogramms erwartet werden. Weitere Informationen finden Sie unter "Felddefinitionen des Fensters "Camstar Metadata Export"".

Diese Tabelle definiert die Informationen, mit denen Sie die Variablen in der Befehlszeile ersetzen müssen.

Variable

Value

-a

Exportiert alle Unterschiede im Befehlszeilenmodus ohne UI-Interaktion oder Filterung.

Hinweis: Sie müssen diesen Parameter angeben, wenn Sie das Dienstprogramm über die Eingabeaufforderung ausführen.

baseFileName

Der vollständige Pfad zur Basismetadaten-Datenbank.

modifiedMDBFileName

Der vollständige Pfad zur geänderten Metadaten-Datenbank.

outputXMLFileName

Der vollständige Pfad und Dateiname für die exportierte XML-Datei.

reportHTMLFileName

Der vollständige Pfad und Dateiname für den generierten Bericht.

Wenn das Dienstprogramm einen Fehler feststellt, werden eine Fehlermeldung und Hilfeinformationen angezeigt. Sie können auch "MetadataExport help" eingeben und die Eingabetaste drücken, um Hilfeinformationen anzuzeigen. Sie können die Informationen überprüfen und anschließend versuchen, das Dienstprogramm auszuführen, indem Sie den Befehl erneut eingeben und die Eingabetaste drücken.

Hinweis: Über die Eingabeaufforderung kann nur die gesamte MDB exportiert werden.

Vorgehensweise zum Ausführen des Dienstprogramms Camstar Metadata Export

Gehen Sie folgendermaßen vor, um das Dienstprogramm Camstar Metadata Export auszuführen:

1. Gehen Sie zur Ansicht "Apps".
2. Klicken Sie auf die App Metadata Export. Das Fenster "Camstar Metadata Export" wird angezeigt.
3. Klicken Sie auf Durchsuchen für das Feld Basis-MDB (Base MDB). Das Fenster "Öffnen" wird angezeigt.
4. Navigieren Sie zur Basis-MDB und klicken Sie auf Öffnen. Das Fenster "Öffnen" wird geschlossen. Der Pfad zur Basis-MDB wird im Feld "Basis-MDB" (Base MDB) angezeigt, der Code, der den höchsten aktiven Arbeitsbereichs für die Basis-MDB angibt, wird im Feld "Arbeitsbereich" (Workspace) angezeigt und "Kompilieren" (Compiling) wird neben dem Feld "Basis-MDB" (Base MDB) angezeigt. Anschließend wird "Kompiliert" (Compiled) neben dem Feld "Basis-MDB" (Base MDB) angezeigt, wenn die Kompilierung der Datenbank abgeschlossen ist.
5. Klicken Sie auf Durchsuchen für das Feld Geänderte MDB (Modified MDB). Das Fenster "Öffnen" wird angezeigt.
6. Navigieren Sie zur geänderten MDB und klicken Sie auf Öffnen. Das Fenster "Öffnen" wird geschlossen. Der Pfad zur geänderten MDB wird im Feld "Geänderte MDB" (Modified MDB) angezeigt, der Code, der den höchsten aktiven Arbeitsbereich für die geänderte MDB angibt, wird im Feld "Arbeitsbereich" (Workspace) angezeigt und "Kompilieren" (Compiling) wird neben dem Feld "Geänderte MDB" (Modified MDB) angezeigt. Anschließend wird "Kompiliert" (Compiled) neben dem Feld "Geänderte MDB" (Modified MDB) angezeigt, wenn die Kompilierung der Datenbank abgeschlossen ist. Zudem aktiviert das Dienstprogramm die Schaltfläche "Weiter" .
7. Klicken Sie auf Weiter. Der Bildschirm "Auszugebende Änderungen auswählen" (Select Changes to Output) und ein Status-Popup werden angezeigt. Das Status-Popup zeigt Textaktualisierungen an, während das Dienstprogramm die beiden Datenbanken vergleicht. Nach Abschluss des Vorgangs wird das Status-Popup geschlossen.
8. Wählen Sie geänderte Objektdefinitionen nach Bedarf aus und klicken Sie auf Weiter . Der Bildschirm "Ausgabeoptionen auswählen" wird angezeigt.
9. Möchten Sie den Export ausführen, den Metadatenbericht generieren oder beides?

Sie möchten . . .

Dann . . .

Den Export ausführen
a. Aktivieren Sie das Kontrollkästchen Exportdatei.
b. Klicken Sie auf Durchsuchen für das Feld Exportdatei. Das Fenster "Speichern unter" wird mit dem Standarddateinamen und dem Speicherort angezeigt.
c. Geben Sie bei Bedarf einen anderen Pfad oder Dateinamen an.
d. Klicken Sie auf Speichern. Das Fenster "Speichern unter" wird geschlossen. Der Pfad zur Exportdatei und der Dateiname werden im Feld "Exportdatei" angezeigt und das Dienstprogramm aktiviert die Schaltfläche "Beenden".
e. Gehen Sie zu Schritt 10.

Generieren des Metadatenberichts
a. Aktivieren Sie das Kontrollkästchen Berichtsdatei.
b. Klicken Sie auf die Schaltfläche Durchsuchen für das Feld Berichtsdatei. Das Fenster "Speichern unter" wird mit dem Standarddateinamen und dem Speicherort angezeigt.
c. Geben Sie bei Bedarf einen anderen Pfad, Dateinamen oder Dateityp an.
d. Klicken Sie auf Speichern. Das Fenster "Speichern unter" wird geschlossen. Der Pfad zum Metadatenbericht und der Dateiname werden im Feld "Berichtsdatei" angezeigt und das Dienstprogramm aktiviert die Schaltfläche "Beenden".
e. Gehen Sie zu Schritt 10.

Ausführen des Exports und Generieren des Metadatenberichts
a. Aktivieren Sie das Kontrollkästchen Exportdatei.
b. Klicken Sie auf Durchsuchen für das Feld Exportdatei. Das Fenster "Speichern unter" wird mit dem Standarddateinamen und dem Speicherort angezeigt.
c. Geben Sie bei Bedarf einen anderen Pfad oder Dateinamen an.
d. Klicken Sie auf Speichern. Das Fenster "Speichern unter" wird geschlossen. Der Pfad zur Exportdatei und der Dateiname werden im Feld "Exportdatei" angezeigt und das Dienstprogramm aktiviert die Schaltfläche "Beenden".
e. Aktivieren Sie das Kontrollkästchen Berichtsdatei.
f. Klicken Sie auf die Schaltfläche Durchsuchen für das Feld Berichtsdatei. Das Fenster "Speichern unter" wird mit dem Standarddateinamen und dem Speicherort angezeigt.
g. Geben Sie bei Bedarf einen anderen Pfad, Dateinamen oder Dateityp an.
h. Klicken Sie auf Speichern. Das Fenster "Speichern unter" wird geschlossen, der Pfad zum Metadatenbericht und der Dateiname werden im Feld "Berichtsdatei" angezeigt.
i. Gehen Sie zu Schritt 10.
10. Klicken Sie auf Beenden von Vergleich und Export (Compare and Export Finish). Das Dienstprogramm speichert die generierten Dateien in den angegebenen Pfaden und ein Status-Popup wird mit einer Erfolgsmeldung angezeigt.
11. Klicken Sie auf OK. Das Status-Popup und das Fenster "Camstar Export Metadata" werden geschlossen.
