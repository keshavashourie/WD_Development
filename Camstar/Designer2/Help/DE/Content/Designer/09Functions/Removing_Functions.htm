Entfernen von Funktionen

Sie können nur benutzerdefinierte Funktionen entfernen. Standardfunktionen können nicht entfernt werden.

Mit der folgenden Vorgehensweise wird die Funktion dauerhaft aus der Bibliothek entfernt.

Vorgehensweise zum Entfernen einer benutzerdefinierten Funktion

Gehen Sie folgendermaßen vor, um eine benutzerdefinierte Funktion zu entfernen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Funktionen. Das Fenster "Funktionsdefinitionen" (Function Definitions) wird angezeigt.
3. Wählen Sie die Benutzerfunktion aus. In diesem Beispiel wird die Funktion gelöscht, die Sie zuvor erstellt haben.
4. Vergewissern Sie sich, dass die Benutzerfunktion, die Sie löschen möchten, nicht verwendet wird:
a. Klicken Sie auf die Registerkarte Wo genutzt.
b. Wenn alle CLFs die Funktion verwenden, wechseln Sie zu jedem CLF und entfernen Sie die Funktion aus dem logischen Ablauf (vorherige Vorgehensweise).
c. Kehren Sie zur Funktionsbibliothek zurück und wählen Sie die Benutzerfunktion erneut aus.
5. Klicken Sie auf die Schaltfläche Entfernen (Remove) oder wählen Sie die Option "Funktionsdefinition entfernen" (Remove Function Definition) aus dem Kontextmenü aus. Ein Dialogfeld wird angezeigt, damit Sie bestätigen können, dass Sie die Funktion entfernen möchten.
6. Klicken Sie auf Ja. Die Funktion wird entfernt.
7. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
