Funktionen

Funktionen wurden geschrieben, um eine Vielzahl von Aufgaben auszuführen, z. B. einfache Arithmetik, Suchen nach komplexen Datenstrukturen, Datenbankabfragen, Schreiben von Berichten, Datenerfassung und Datenvalidierung.

Eine Funktion hat null oder mehrere Parameter und wird durch eine ActiveX-Komponente implementiert. Die Funktion, die in einem CLF enthalten ist, führt die Arbeit aus. Eine Funktion hat Zugriff auf das interne Objektdesign des Systems, das sie bearbeitet, um die Arbeit auszuführen.

Die folgenden Themen enthalten Informationen zu Funktionen:

• Anzeigen von Funktionen
