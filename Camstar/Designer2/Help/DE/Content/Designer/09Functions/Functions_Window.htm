Fenster "Funktionen"

Das Fenster "Funktionsdefinition" (Function Definition) wird angezeigt, wenn Sie auf die Schaltfläche "Funktionen" in der Symbolleiste klicken oder im Menü "Fenster" (Window) die Option "Funktionsdefinitionen" (Function definitions) auswählen. Das Fenster "Funktionsdefinition" (Function Definition) kann zum Anzeigen von Standardfunktionen verwendet werden, mit denen benutzerdefinierte Funktionen hinzugefügt, geändert oder entfernt werden können.

Der linke Bereich enthält einen Auswahlbaum, in dem alle verfügbaren Funktionskategorien aufgeführt werden. Klicken Sie mit der rechten Maustaste in diesen Auswahlbereich, um ein Kontextmenü mit den folgenden Optionen anzuzeigen:

• Funktionsdefinition hinzufügen
• Funktionsdefinition umbenennen – für Standardfunktionen deaktiviert
• Funktionsdefinition suchen
• Funktionsdefinition entfernen – für Standardfunktionen deaktiviert

Im rechten Bereich werden auf den folgenden Registerkarten Details zur ausgewählten Funktion angezeigt:

• Registerkarte "Allgemein"
• Registerkarte "Parameter"
• Registerkarte "Wo genutzt"
• Registerkarte "Funktionsberechtigung"

Registerkarte "Allgemein"

Es gibt vier Felder auf der Registerkarte "Allgemein", die für Standardfunktionen schreibgeschützt, aber für benutzerdefinierte Funktionen aktiviert sind.

Felddefinitionen der Registerkarte "Allgemein"

Diese Tabelle definiert die Felder auf der Registerkarte "Allgemein".

Feld

Definition

Typ

"OCX GUID (Ausführung)"

Enthält die global eindeutige ID (GUID) für das OCX, das die Programmlogik bereitstellt. Wird vom System verwendet, um das Programm zu instanziieren und aufzurufen.

Nur Anzeige

Erzwingen von Parametertypen

Gibt an, ob eine Funktion die Eingabe starker Parameter erzwingt oder nicht. Wenn dieses Kontrollkästchen deaktiviert ist, werden die Parameterwerte während der Verarbeitung des CLFs, an das die Funktion angehängt ist, dynamisch festgelegt. Weitere Informationen finden Sie unter "Parameterdatentypen".

Nur Anzeige

Beschreibung

Enthält eine Beschreibung der Verwendung der ausgewählten Funktion, Parameterwerte, Rückgabewerte sowie weitere Informationen, die einem CLF-Ersteller den Zweck der Funktion erläutern.

Nur Anzeige

Hinweise

Enthält weitere Informationen zur Verwendung der ausgewählten Funktion.

Nur Anzeige

Registerkarte "Parameter"

Auf der Registerkarte "Parameter" werden eine Tabelle mit Parameterwerten für die Funktion und eine Reihe von Feldern angezeigt, die zum Definieren der in der Tabelle angezeigten Werte dienen.

Die Schaltflächen "Hinzufügen", "Einfügen" (Insert) und "Entfernen" (Remove) unter der Tabelle erlauben Ihnen das Hinzufügen eines Parameters am Ende der Liste, das Einfügen eines Parameters unter einem ausgewählten Parameter oder das Entfernen eines ausgewählten Parameters. Sie können auch mit der rechten Maustaste in den Tabellenbereich klicken, um ein Kontextmenü mit den folgenden Optionen anzuzeigen: "Parameter hinzufügen", "Parameter einfügen" und "Parameter entfernen".

Die Schaltflächen und die Optionen im Kontextmenü sind nur für benutzerdefinierte Funktionen aktiviert.

Felddefinitionen der Registerkarte "Parameter"

Diese Tabelle definiert die Felder auf der Registerkarte "Parameter".

Feld

Definition

Typ

Parametername

Enthält den Namen des Parameters. Dieser muss im Kontext der zugeordneten Funktionsdefinition eindeutig sein. Dieser Name wird (als Teil eines Name-Wert-Paar-Konstrukts) zum Abrufen oder Festlegen von Parameterwerten während der Laufzeit verwendet.

Erforderlich

Spezielle Verarbeitung

Erlaubt Designer die Anzeige einer Auswahlliste für bestimmte Verarbeitungselemente, wenn während der Zuordnung zu einer Funktion Feldwerte für Parameter festgelegt werden.

Erforderlich

Richtung

Gibt die Richtung der Funktion an:

• Wählen Sie "Ein" aus, wenn Sie einen Wert oder eine Referenz an eine Funktion übergeben möchten.
• Wählen Sie "Aus" aus, wenn Sie einen Parameter innerhalb der Funktion festlegen möchten.
• Wählen Sie "Ein/Aus" aus, wenn Sie einen Wert übergeben möchten und erwarten, dass die Funktion den Parameter auf einen neuen Wert/eine neue Referenz festlegt.
• Wählen Sie "Zurückgeben" aus, wenn die Funktion einen Wert ermitteln soll.

Erforderlich

Multiplizität

Gibt die Anzahl der Werte an, die der Parameter annehmen kann oder muss. Die Auswahlmöglichkeiten sind "0...*" (null oder mehr, daher eine optionale Liste), "0...1" (null oder eins, daher optional), "1...1" (eins, daher erforderlich), 1...* (eins oder mehr, daher eine erforderliche Liste).

Erforderlich

Beschreibung

Zeigt Informationen zur Verwendung des Parameters an.

Erforderlich

Datentyp

Zeigt den Datentyp dieses Parameters an. Weitere Informationen finden Sie unter "Parameterdatentypen".

Erforderlich

Typmultiplizität

Gibt an, ob der Parameter skalar oder eine Liste oder beides (ListOrScalar) ist.

Erforderlich

Standardwert

Legt den Wert fest, den das Feld aufweist, wenn kein anderer Wert angegeben wurde.

Optional

Registerkarte "Wo genutzt"

Die Registerkarte "Wo genutzt" zeigt Informationen zur ausgewählten Funktion an. Es wird eine Tabelle mit einer Liste der CLFs angezeigt, die ggf. die Funktion verwenden. Die Tabelle enthält auch eine Beschreibung des CLFs. Diese Informationen sind schreibgeschützt. 

Doppelklicken Sie auf einen CLF-Namen in der Liste, um das Definitionsfenster für den CLF zu öffnen.

Registerkarte "Funktionsberechtigung"

Auf der Registerkarte "Funktionsberechtigung" wird die Gruppe "Funktionsmitgliedschaft" (Feature Membership) für die ausgewählte Funktion angezeigt. Weitere Informationen zur Funktionsberechtigung finden Sie unter Registerkarte "Funktionsberechtigung".
