Verwenden von Datenbankfunktionen

Mit Datenbankfunktionen können Sie die Geschäftslogik in der Datenbank statt auf dem Anwendungsserver ausführen. Durch das Ausführen von SQL-Anweisungen in der Datenbank wird die Verarbeitung effizienter. Diese Funktionalität ist mit der separat lizenzierten Funktion "High Performance Engine" verfügbar.

Weitere Informationen zur High Performance Engine finden Sie in Opcenter Execution Core – Technische Referenz: High Performance Engine oder Opcenter Execution Medical Device and Diagnostics – Technische Referenz: High Performance Engine.

Beim Verwenden von Datenbankfunktionen

Die Anwendung zeigt Standardfunktionen und datenbankspezifische Funktionen in der Liste der verfügbaren Funktionen an. Sie können Datenbankfunktionen wie andere Funktionen hinzufügen, umbenennen und entfernen. Wie bei den meisten anderen Funktionen enthält das Feld "Beschreibung" für die meisten Datenbankfunktionen eine Dokumentation, die die Verwendung der ausgewählten Funktion und ihrer erwarteten Parameter beschreibt.

Für Datenbankfunktionen gilt Folgendes:

• Die GUID für alle Datenbankfunktionen weist das Präfix "DBE" auf.
• Verwenden Sie keine Leerzeichen in Funktionsnamen.
• Jede Execute-Type-Funktion enthält den Parameter "SQLStatementName".
• Für den SQLStatementName-Parameter ist eine spezielle Verarbeitung auf "SQL-Anweisung mit Parametern" festgelegt.
Hinweis: Einige Datenbankfunktionen enthalten nicht den Parameter "SQLStatementName". SQLStatementName-Charakterisierungen, die SQLStatementName-Parameter enthalten, unterstützen nur die SQL-Abfragetypen "Erweiterte Abfrage" und "Keine Abfrage".
