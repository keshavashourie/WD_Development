Hinzufügen von Funktionen

Sie fügen der Bibliothek oder dem bestehenden logischen Ablauf eines CLFs Benutzerfunktionen hinzu.

Beim Hinzufügen von Funktionen

Sie können der Bibliothek Benutzerfunktionen hinzufügen, sodass Sie diese später an Ihren Benutzer-CLF anhängen können.

Arbeitsbereichspräfixe werden beim Hinzufügen eines neuen Elements automatisch vor dem Namen des Elements eingefügt, sofern dem höchsten aktiven Arbeitsbereich ein Präfix zugewiesen wurde. Arbeitsbereichspräfixe geben an, auf welchen Arbeitsbereich Designer Änderungen anwendet. Dem Arbeitsbereich würde z. B. das Präfix "C200" zugeordnet werden, wenn für diesen in Management Studio das Präfix "C200" festgelegt wurde. Es wird empfohlen, beim Hinzufügen neuer Elemente die von Designer bereitgestellten Präfixe zu verwenden.

Sie können Arbeitsbereichspräfixe in Management Studio zuweisen oder ändern. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Hinweis: Dem Basisarbeitsbereich der Anwendung (csi) kann kein Arbeitsbereichspräfix zugewiesen sein.

Vorgehensweise zum Hinzufügen von Funktionen zur Funktionsbibliothek

Gehen Sie folgendermaßen vor, um der Funktionsbibliothek Funktionen hinzuzufügen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Funktionen. Das Fenster "Funktionsdefinitionen" (Function Definitions) wird angezeigt.
3. Wählen Sie die Kategorie UserFunctions aus.
4. Klicken Sie auf die Schaltfläche Hinzufügen oder mit der rechten Maustaste auf UserFunctions und wählen Sie aus dem Kontextmenü die Option Funktionsdefinition hinzufügen (Add Function Definition) aus. Die neue Funktion wird mit einem generischen Namen angezeigt und der Umbenennungsmodus ist aktiviert.
5. Geben Sie den neuen Namen für die Funktion ein, der den generischen Namen ersetzen soll, und drücken Sie die Eingabetaste.
6. Definieren Sie die Attribute der Funktion auf den Registerkarten Allgemein und Parameter gemäß den Geschäftsanforderungen. Die Registerkarte "Wo genutzt" (Where Used) wird beim Hinzufügen dieser Funktion zu einem CLF vom System festgelegt.

Weitere Informationen zu den Feldern auf diesen Registerkarten finden Sie unter "Fenster "Funktionen"".

7. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
