Fenster "Kategorien" (Categories)

Durch Klicken auf die Schaltfläche "Kategorien" in der Designer-Symbolleiste wird das Fenster "Kategoriedefinition" (Category Definition) geöffnet.

Der linke Bereich enthält einen Auswahlbaum, in dem alle verfügbaren Kategorien aufgelistet sind. Klicken Sie mit der rechten Maustaste in diesen Auswahlbereich, um ein Kontextmenü mit den folgenden Optionen zu öffnen:

• Kategoriedefinition hinzufügen (Add Category Definition)
• Kategoriedefinition entfernen (Remove Category Definition)

Felddefinitionen im Fenster "Kategorien" (Categories)

Diese Tabelle definiert die Felder im Fenster "Kategorien" (Categories).

Feld

Definition

Typ

Beschreibung

Enthält die Dokumentation dazu, wie die Tabellen in dieser Kategorie verwendet werden.

Optional

Standardtabellentyp (Default Table Type)

Bestimmt den Typ der zu definierenden Datenbanktabelle. Jeder Typ entspricht einer bestimmten Verarbeitung, die durch das System implementiert wird.

Nur Anzeige

DataStore-Weitergabe aktivieren

Erlaubt das Schreiben von Informationen in die DataStore-Tabellen.

Optional

Verfügbar für Tabellenkategorie

Wenn Sie dieses Kontrollkästchen aktivieren, wird die Kategorie als Tabellenkategorie definiert. Benutzer können dieses Attribut nur für benutzerdefinierte Kategorien festlegen.

Optional

Verfügbar für Speicherkategorie

Wenn Sie dieses Kontrollkästchen aktivieren, wird die Kategorie als Speicherkategorie definiert. Benutzer können dieses Attribut nur für benutzerdefinierte Kategorien festlegen.
