Hinzufügen von Kategorien

Zum Hinzufügen einer neuen Kategorie können Sie die Schaltfläche "Hinzufügen" verwenden oder aus dem Kontextmenü die Option "Kategoriedefinition hinzufügen" (Add Category Definition) auswählen.

Beim Hinzufügen von Kategorien

Arbeitsbereichspräfixe werden beim Hinzufügen eines neuen Elements automatisch vor dem Namen des Elements eingefügt, sofern dem höchsten aktiven Arbeitsbereich ein Präfix zugewiesen wurde. Arbeitsbereichspräfixe geben an, auf welchen Arbeitsbereich Designer Änderungen anwendet. Dem Arbeitsbereich würde z. B. das Präfix "C200" zugeordnet werden, wenn für diesen in Management Studio das Präfix "C200" festgelegt wurde. Es wird empfohlen, beim Hinzufügen neuer Elemente die von Designer bereitgestellten Präfixe zu verwenden.

Sie können Arbeitsbereichspräfixe in Management Studio zuweisen oder ändern. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Hinweis: Dem Basisarbeitsbereich der Anwendung (csi) kann kein Arbeitsbereichspräfix zugewiesen sein.

Vorgehensweise zum Hinzufügen einer Kategorie

Gehen Sie folgendermaßen vor, um eine Kategorie hinzuzufügen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Kategorien (Categories). Das Fenster "Kategoriedefinition" (Category definition) wird angezeigt.
3. Klicken Sie auf Hinzufügen oder klicken Sie im Kontextmenü mit der rechten Maustaste auf Kategoriedefinition hinzufügen (Add Category Definition). Eine neue Kategorie wird mit einer generischen Beschriftung wie z. B. "UserCategory1" hinzugefügt.
4. Geben Sie eine aussagekräftige Beschreibung der Kategorie ein. Diese wird als Name für Ihre Kategorie verwendet.
5. Wählen Sie DataStore-Weitergabe aktivieren aus, wenn Ihre Tabellenänderungen aus Opcenter EX MDD oder Opcenter EX CR in den DataStore kopiert werden sollen.
6. Wählen Sie Für Tabellenkategorie verfügbar aus, wenn es sich bei dieser Kategorie um eine Tabellenkategorie handelt.
7. Wählen Sie Für Speicherkategorie verfügbar aus, wenn es sich bei dieser Kategorie um eine Speicherkategorie handelt.
8. Zum Speichern klicken Sie im linken Bereich auf die Beschriftung.
9. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
