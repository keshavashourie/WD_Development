Entfernen von Kategorien

Sie können Kategorien mithilfe der Schaltfläche "Entfernen" (Remove) oder durch Auswahl der Option "Kategoriedefinition entfernen" (Remove Category Definition) im Kontextmenü entfernen. Sie können jedoch keine Standardkategorie entfernen. Daher ist weder die Schaltfläche "Entfernen" (Remove) noch die Option "Entfernen" (Remove) im Kontextmenü aktiviert, wenn Sie eine Standardkategorie auswählen.

Vorgehensweise zum Entfernen einer Kategorie

Gehen Sie folgendermaßen vor, um eine Kategorie zu entfernen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Kategorien (Categories). Das Fenster "Kategoriedefinition" (Category definition) wird angezeigt.
3. Wählen Sie die zu entfernende Kategorie aus.
4. Klicken Sie auf Entfernen (Remove) oder klicken Sie mit der rechten Maustaste im linken Bereich. Wählen Sie dann im Kontextmenü die Option Kategoriedefinition entfernen (Remove Category Definition) aus. Ein Dialogfeld wird angezeigt, um zu bestätigen, dass Sie die Kategorie entfernen möchten.
5. Klicken Sie auf Ja. Die Kategorie wird entfernt.
6. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
