Methoden

Benutzer können Methoden erstellen, indem sie ein CLF aufrufen und an ein neues Ereignis anhängen. Siemens hat bereits fünf Methoden ohne vorab vorhandene Logik an einige Ereignisse in den Fertigungstransaktionen angehängt, um den Benutzern die Anpassung dieser Transaktionen zu erleichtern. Die Methoden, auch Benutzerexits genannt, sind:

1. PreValidate_User

Diese Methode wird vom Ereignis "BeforeValidate" aufgerufen. Sie können zusätzliche Verarbeitungslogik einfügen, die nach der Standardausführungslogik ausgeführt wird.

2. Validate_User

Diese Methode wird nach dem Ereignis "AfterValidate" aufgerufen. Sie können zusätzliche Verarbeitungslogik einfügen, die nach den erforderlichen Wertvalidierungen ausgeführt wird.

3. PreExecute_User

Diese Methode wird vom Ereignis "BeforeExecute" aufgerufen. Sie können zusätzliche Verarbeitungslogik einfügen, die vor der Standardtransaktionsausführungslogik ausgeführt wird.

4. Execute_User

Diese Methode wird vom Ereignis "BeforeExecute" aufgerufen. Sie können zusätzliche Verarbeitungslogik einfügen, die nach der Standardtransaktionsausführungslogik ausgeführt wird.

5. ExportInfo_Initialize_User

Diese Methode wird vererbt und vom Ereignis "BeforeExecute" aufgerufen. Sie können die Logik für das Erstellen oder Initialisieren zusätzlicher Objekte "ExportInfo" einfügen.

6. ProcessAfterCommit_User

Diese Methode wird nach dem Ereignis "AfterCommit" aufgerufen. Sie können zusätzliche Verarbeitungslogik einfügen, die nach der Logik nach dem Festschreiben der Standardtransaktion ausgeführt wird.

Beispiele für benutzerdefinierte Logik

Sie werden wahrscheinlich eine Transaktion unter "ShopFloor" anpassen, indem Sie zunächst eine Unterklasse und anschließend verschiedene benutzerdefinierte Felder hinzufügen. Ihre Unterklasse wird anschließend die Ereignisse "ShopFloor" erben. Einige Beispiele für die Vorgehensweise zum Anpassen benutzerdefinierter Logik:

• Sie können einen CLF an das Ereignis "Validate_User" anhängen, um die neuen Felder zu validieren, oder Sie können einen CLF anhängen und die neuen Felder in einigen CDOs dem Ereignis "Execute_User" zuordnen.
• Sie können auch Aufrufe für Ihre COM-konformen, benutzerdefinierten Ausführungen erstellen.

Einschränkung

Es besteht die Möglichkeit, dass die von Ihnen erweiterte Transaktion fehlschlägt. Sie können z. B. eine Variable im Transaktionsumfang verwenden, die bereits von Opcenter EX MDD oder Opcenter EX CR verwendet wird.

Vorgehensweise zum Anzeigen der Benutzerexits

Gehen Sie folgendermaßen vor, um Benutzerexits anzuzeigen:

1. Klicken Sie in der Designer-Symbolleiste auf CDOs.
2. Wählen Sie das ShopFloor-CDO aus.
3. Rufen Sie die Registerkarte Ereignisse auf und klicken Sie auf Geerbte einschließen. Geerbte Ereignisse und Methoden werden zur Anzeige hinzugefügt.
4. Blättern Sie nach unten zum Methodenabschnitt und suchen Sie die fünf Benutzerexits.
5. Sehen Sie sich ein Beispiel für ein Systemereignis an, das eine der Methoden aufruft:
a. Erweitern Sie das Ereignis BeforeValidate.
b. Erweitern Sie den angehängten CLF ShopFloor::Call.
c. Erweitern Sie die Funktion Aufrufen (Call).

Die Funktion ruft die Methode "PreValidate" auf. Wenn Sie Ihre eigene Logik zum Ereignis "BeforeValidate" hinzufügen möchten, wählen Sie die Methode "PreValidate" aus. Diese Methode ruft drei weitere Methoden auf: "PreValidate_User", "PreValidate_Specific" und "PreValidate_Generic".

Der Aufrufbaum führt Sie zu weiteren Methoden, die aufgerufen werden und jeweils zielgerichtet sind. Die zuletzt aufgerufene Methode stellt eine Platzhalterfunktion zur Verfügung, "_Comments", in die Sie Ihre Logik einfügen können.
