Definieren einer Container-CDO-Unterklasse

Container-CDO-Unterklassen enthalten die Definition für den Container, der die grundlegende Verfolgungseinheit darstellt. Sie beziehen sich auf das Los oder Batch von Produkten in Ihrem Fabrikmodell. Der Container wird durch einen Namen und einen Level identifiziert. Dieses Thema erläutert die Schritte, die zum Definieren einer Container-CDO-Unterklasse erforderlich sind. Die meisten Schritte sind automatisiert.

Beim Definieren einer Container-CDO-Unterklasse

Sie können auch das Container-CDO erweitern, das eine komplexere Datenstruktur aufweist, z. B. ein Unterobjekt-CDO.

Arbeitsbereichspräfixe werden beim Hinzufügen eines neuen Elements automatisch vor dem Namen des Elements eingefügt, sofern dem höchsten aktiven Arbeitsbereich ein Präfix zugewiesen wurde. Arbeitsbereichspräfixe geben an, auf welchen Arbeitsbereich Designer Änderungen anwendet. Dem Arbeitsbereich würde z. B. das Präfix "C200" zugeordnet werden, wenn für diesen in Management Studio das Präfix "C200" festgelegt wurde. Es wird empfohlen, beim Hinzufügen neuer Elemente die von Designer bereitgestellten Präfixe zu verwenden.

Sie können Arbeitsbereichspräfixe in Management Studio zuweisen oder ändern. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Hinweis: Dem Basisarbeitsbereich der Anwendung (csi) kann kein Arbeitsbereichspräfix zugewiesen sein.

Automatisch generierte, zugeordnete CDOs und Referenzen

Wenn Sie ein Container-CDO hinzufügen und das Kontrollkästchen "Startdienst erstellen & konfigurieren" (Create & Configure a Start Service) im Fenster "Neue CDO-Definition erstellen" aktivieren, werden diese erforderlichen Aufgaben automatisch ausgeführt. Diese Tabelle definiert die erforderlichen Aufgaben.

Aufgabe

Definition

Hinzufügen einer Startdienst-Unterklasse

Eine Unterklasse des Startdienst-CDOs wird hinzugefügt, um den Startdienst für das neue Container-CDO zu verwalten. Außerdem wird die Containerreferenz im Startdienst-CDO geändert, um das neue Container-CDO zu referenzieren.

Hinzufügen einer StartDetails-Unterobjekt-Unterklasse

ServiceDetails-CDOs enthalten die Änderungsdaten zu den Container-Transaktionen, die von ihrem Startdienst (StartService) ausgeführt werden, sodass jedes StartService-CDO sein eigenes StartDetails-CDO erfordert. Ein neues StartDetails-Unterobjekt-CDO wird unter der neuen StartService-Unterklasse hinzugefügt.

Hinzufügen der StartHistoryDetail-Unterklasse

Eine Unterklasse des StartHistoryDetail-CDOs wird für das neue Container-CDO erstellt. Dieses neue CDO wird verwendet, um Änderungen an Ihrem Container zu verfolgen, wenn er an Transaktionen beteiligt ist.

Ändern der CDO-Referenzen

Wenn das Dienst-CDO ein ServiceDetails-CDO verwendet, muss das Dienst-CDO sein ServiceDetails-Unterobjekt über das Feld "Details" im Dienst-CDO referenzieren. Wenn ein ServiceDetails-Unterobjekt für einen Container vorhanden ist, wird das Feld "Container" im ServiceDetails-Unterobjekt überprüft, sodass das Unterobjekt das richtige Container-CDO referenzieren muss. Wenn Sie das Kontrollkästchen "Startdienst erstellen & konfigurieren" (Create & Configure a Start Service) im Fenster "Neue CDO-Definition erstellen" aktivieren, wird diese Aufgabe automatisch für Sie ausgeführt. Weitere Informationen zum Überschreiben von CDO-Referenzen finden Sie unter "Erstellen von Feldüberschreibungen".

Hinzufügen von Feldern

Fügen Sie der neuen Container-Unterklasse Felder hinzu, damit dieses CDO die Eigenschaften aufweist, die für Ihr Unternehmen erforderlich sind. Dies wird in der folgenden Übung veranschaulicht. Weitere Informationen zum Hinzufügen von Listenfeldern zu einem CDO finden Sie unter "Definieren von Listenfeldern".

Wenn Sie einem Container-CDO Felder hinzufügen und das Kontrollkästchen "Felder zu den zugehörigen Dienstobjekten hinzufügen" (Add Fields to the Associated Service Objects) aktivieren, werden die im Folgenden aufgelisteten erforderlichen Aufgaben automatisch ausgeführt:

• Hinzufügen von Feldern zur Dienst-CDO-Unterklasse
• Hinzufügen von Feldern zur ServiceDetails-CDO-Unterklasse
• Hinzufügen von Feldern zur ServiceHistoryDetails-CDO-Unterklasse
• Zuordnen von Feldern zwischen CDOs

Vorgehensweise zum Hinzufügen einer Container-CDO-Unterklasse

Gehen Sie folgendermaßen vor, um eine Container-CDO-Unterklasse hinzuzufügen:

1. Öffnen Sie Designer.
2. Klicken Sie in der Symbolleiste auf CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
3. Wählen Sie Container aus.
4. Klicken Sie unter dem Auswahlbaum auf Hinzufügen. Sie können auch mit der rechten Maustaste auf den Container klicken und Unterklasse hinzufügen auswählen. Das Fenster "Neue CDO-Definition erstellen" wird angezeigt.
5. Geben Sie den neuen Objektnamen (CDO-Namen) in das Feld Neuer CDO-Name ein.
Wichtig: Der Name des CDOs kann bis zu 30 Zeichen lang sein und darf keine Leerzeichen, unzulässigen Zeichen oder reservierten Wörter enthalten. Weitere Informationen finden Sie unter "Gültige Zeichen und reservierte Wörter".
6. Geben Sie eine Beschreibung ein.
Hinweis: Die Schaltfläche "Erstellen" wird erst aktiviert, wenn Sie eine Beschreibung eingeben.
7. Behalten Sie die Standardwerte in anderen Feldern bei.
8. Klicken Sie auf Erstellen. Das neue CDO wird in der Liste der CDOs angezeigt.
9. Klicken Sie auf DB aktualisieren. In einem Dialogfeld werden Sie aufgefordert, das Speichern der aktuellen MDB-Datei und die Aktualisierung der Datenbank gemäß den Einstellungen im Dialogfeld "Voreinstellungen" (Preferences) zu bestätigen.
10. Klicken Sie auf Ja. Eine Statusleiste wird am unteren Rand des Fensters angezeigt, um darauf hinzuweisen, dass die Aktualisierung ausgeführt wird. Die Anwendung speichert und aktualisiert die Datenbank.

Automatisierte Schritte

Die folgenden zugehörigen CDOs wurden automatisch definiert:

• "MyContainerStart" wird unter "Dienst > Aktualisieren > Fertigung > Containertransaktion > Start" (Service > Update > Shopfloor > Container Txn > Start) hinzugefügt
• "MyContainerStartDetails" wird unter "Unterobjekt > ServiceData > ServiceDetails > StartDetails" (Subentity > ServiceData > ServiceDetails > StartDetails) hinzugefügt
• "MyContainerHistoryDetail" wird unter "Unterobjekt > HistoryDetails > StartHistoryDetail" (Subentity > HistoryDetails > StartHistoryDetail) hinzugefügt
• "MyContainerStart" referenziert "MyContainerStartDetails" über das Feld "Details".
• "MyContainerStart" referenziert "MyContainerHistoryDetail" über das Feld "HistorySummary".
• "MyContainerStartDetails" referenziert "MyContainerStartDetails" im Feld "ChildContainers" und referenziert "MyContainer" im Feld "Container".
• "MyContainerStartDetails" referenziert "MyContainerStart" im Feld "Eltern" (Parent).

Ausführliche Informationen zu den automatisierten Schritten finden Sie unter "Automatisierte Schritte beim Definieren einer CDO-Unterklasse".

Hinweis: Weitere Informationen zu den im Dialogfeld "Voreinstellungen" (Preferences) verfügbaren Einstellungen finden Sie unter "Dialogfeld "Voreinstellungen" (Preferences), Registerkarte "DB-Aktualisierung" (DB Update)". Vorgehensweise zum Hinzufügen von Feldern zum MyContainer-CDO

Gehen Sie folgendermaßen vor, um Felder zur MyContainer-Unterklasse hinzuzufügen:

1. Öffnen Sie Designer.
2. Klicken Sie in der Symbolleiste auf CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
3. Wählen Sie MyContainer aus und klicken Sie anschließend auf die Registerkarte Felder (Fields).
4. Klicken Sie am unteren Rand der Registerkarte "Felder" (Fields) auf Hinzufügen und wählen Sie Feld hinzufügen (Add field) aus. Das Fenster "Neues CDO-Feld hinzufügen" (Add a new CDO Field) wird angezeigt.
5. Behalten Sie den Standardwert Zeichenkette im Feld "Datentyp" (Data Type) bei.
6. Wählen Sie [Zeichenkette] (String) in der Liste Feldtyp (Field type) aus.
7. Geben Sie MyField1 in das Feld Name ein. Die Schaltfläche "Erstellen" wird aktiviert.
Wichtig: Feldnamen dürfen keine Leerzeichen, unzulässigen Zeichen oder reservierte Wörter enthalten. Weitere Informationen finden Sie unter "Gültige Zeichen und reservierte Wörter".
8. Geben Sie eine Überschrift für das Feld ein oder klicken Sie auf die Schaltfläche "...", um eine Überschrift auszuwählen.
9. Geben Sie eine Beschreibung in das Feld Beschreibung (Description) ein.
10. Lassen Sie das Kontrollkästchen Felder zu zugeordneten Dienstobjekten hinzufügen (Add Fields to Associated Service Objects) aktiviert.
11. Klicken Sie auf Erstellen. Das Fenster "CDO-Feldeigenschaften" (CDO Field Properties) wird angezeigt.
12. Wählen Sie die Registerkarte Optionen aus.
13. Wählen Sie im Bereich "Zwangsbedingungen" (Constraints) die Option Nutzer erforderlich (User required) aus.
14. Wählen Sie im Bereich "Accessibility" (Zugänglichkeit) die Option Lesen/Schreiben (Read/Write) aus.
15. Gewährleisten Sie, dass das Feld Die gleichen Änderungen auf die entsprechenden Felder in den zugehörigen Dienst- und Historienobjekten anwenden (Apply the same changes to the corresponding fields in the associated Service and History objects) ausgewählt ist.
16. Klicken Sie auf OK.
17. Wiederholen Sie die Schritte 4 bis 16, um das Feld MyField2 zu MyContainer hinzuzufügen.
18. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

"MyField1" und "MyField2" werden dem MyContainer-CDO hinzugefügt. Folgendes wurde ebenfalls automatisch definiert:

• "MyField1" und "MyField2" im MyContainerStartDetails-CDO werden "MyField1" und "MyField2" im MyContainer-CDO zugeordnet. Bei der Zuordnung werden Feldwerte von einem CDO an andere CDOs weitergegeben, wenn die Werte durch Dienste geändert werden. Diese Vorgehensweise wird unter "Anzeigen von Feldzuordnungen" erläutert.
• "MyField1" und "MyField2" werden auch zum Historiendetails-CDO, "MyContainerHistoryDetail", hinzugefügt, um Historiendaten aus den Feldern "MyField1" und "MyField2" zu erfassen, die Sie zu "MyContainer" hinzugefügt haben.

Vorgehensweise zum Entfernen einer Container-CDO-Unterklasse

Soll die von Ihnen erstellte Container-CDO-Unterklasse gelöscht werden, müssen Sie die Änderungen in umgekehrter Reihenfolge rückgängig machen. Wenn ein CDO Felder aufweist, die seine Eltern- oder Kind-CDOs referenzieren, müssen Sie diese Referenzfelder in der Regel entfernen, bevor Sie das CDO entfernen können.

Gehen Sie folgendermaßen vor, um eine Container-CDO-Unterklasse zu entfernen:

1. Löschen Sie Überschreibungen in Feldern, die Referenzen auf Eltern- und Kind-CDOs für jedes erstellte CDO enthalten.

Das neue Dienstdetails-Unterobjekt-CDO (MyContainerStartDetails) weist z. B. ein Feld Container auf, das das Container-Unterklassen-CDO (MyContainer) referenziert, und ein Feld Eltern (Parent), das das Eltern-CDO des Unterobjekts referenziert. Löschen Sie die Überschreibungen für beide Felder. Wechseln Sie hierzu auf die Registerkarte "Felder" (Fields) für das Unterobjekt-CDO. Weitere Informationen zum Überschreiben von Feldern finden Sie unter "Erstellen von Feldüberschreibungen".

2. Löschen Sie in der Dienst-CDO-Unterklasse (MyContainerStart) die Überschreibung im Feld Details, das das Dienstdetail-Unterobjekt (MyContainerStartDetails) referenziert, und im Feld HistorySummary, das MyContainerHistoryDetail referenziert.
3. Löschen Sie im Dienstdetail-Unterobjekt (MyContainerStartDetails) die Überschreibungen für das Feld ChildContainers.
4. Entfernen Sie die neue Dienst-CDO-Unterklasse (MyContainerStart), indem Sie sie im CDO-Auswahlbaum auswählen und auf die Schaltfläche Entfernen (Remove) klicken.
5. Entfernen Sie das neue Container-Unterklassen-CDO (MyContainer).
6. Entfernen Sie das neue Service-Unterobjekt-CDO (MyContainerStartDetails).
7. Entfernen Sie das neue HistoryDetails-Unterobjekt-CDO (MyContainerHistoryDetail).
8. Klicken Sie auf DB aktualisieren. In einem Dialogfeld werden Sie aufgefordert, das Speichern der aktuellen MDB-Datei und die Aktualisierung der Datenbank gemäß den Einstellungen im Dialogfeld "Voreinstellungen" (Preferences) zu bestätigen.
9. Klicken Sie auf Ja. Eine Statusleiste wird am unteren Rand des Fensters angezeigt, um darauf hinzuweisen, dass die Aktualisierung ausgeführt wird. Die Anwendung speichert und aktualisiert die Datenbank.
Hinweis: Weitere Informationen zu den im Dialogfeld "Voreinstellungen" (Preferences) verfügbaren Einstellungen finden Sie unter "Dialogfeld "Voreinstellungen" (Preferences), Registerkarte "DB-Aktualisierung" (DB Update)". Weitere Informationen zum Aktualisieren der Datenbank finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration oder der Opcenter Execution Core-Anleitung zur Systemadministration.
