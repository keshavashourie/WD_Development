Ereignisse und Methoden

Ein CDO initiiert einen CLF entweder mithilfe eines Ereignisses oder einer Methode. Ereignisse und Methoden dienen als Zeiger von CDOs auf einen CLF. Ereignisse und Methoden werden wie folgt definiert:

• Event

Ein Ereignis ist ein Delegat, der eine Referenz auf einen CLF enthalten kann.

Für CDOs und Felder gibt es eine vordefinierte Gruppe von Ereignissen, die vom System automatisch ausgelöst werden. Wenn z. B. eine Clientanwendung einen Wert für ein CDO-Feld festlegt, löst das System unter anderem das Validierungsereignis (Validate) aus. Die Ereignisgruppe kann vom Benutzer nicht erweitert werden.

Das Systemverhalten kann geändert werden, indem CLFs an Ereignisse angehängt, Funktionsparameterwerte der zugehörigen CLFs geändert oder CLFs von Ereignissen abgetrennt werden.

• Methode

Eine Methode ist ein Delegat, der eine Referenz auf einen CLF enthält.

An von Siemens definierte CDOs sind normalerweise Methoden angehängt. Diese Methoden werden durch den logischen Ablauf eines Dienstes, einen CLF, ein Ereignis oder direkt über eine Clientanwendung ausgelöst. Die an ein CDO angehängten Methoden können vom Benutzer erweitert werden. Eine Methode wird durch Anhängen eines CLFs erstellt, durch Abtrennen eines CLFs entfernt und durch Ändern der Funktionsparameterwerte geändert. Die Erstellung von Methoden ist eine gängige Vorgehensweise, um komplexe CLFs in wiederverwendbare Komponenten zu partitionieren, die nacheinander ausgeführt werden.

Informationen zur Verwendung der .NET-Client-APIs von Siemens finden Sie in Opcenter Execution Medical Device and Diagnostics – Technische Referenz: Client-APIs oder Opcenter Execution Core – Technische Referenz: Client-APIs.

Hinweis: Ein Ereignis oder eine Methode für ein CDO kann nur mit einem CLF zugeordnet werden. So kann jeder CDO-Typ auf einzigartige Weise auf das gleiche Ereignis reagieren.

Beim Aufrufen oder Auslösen eines CLFs wird eine Funktion nach der anderen aufgerufen.
