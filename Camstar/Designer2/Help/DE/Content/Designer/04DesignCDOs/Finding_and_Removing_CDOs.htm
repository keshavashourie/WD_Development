Suchen und Entfernen von CDOs

Die folgende Vorgehensweise erläutert, wie Sie durch Eingabe von Suchkriterien schnell ein bestimmtes CDO finden oder wie Sie eine benutzerdefinierte CDO-Unterklasse entfernen.

Sie können nur benutzerdefinierte CDO-Unterklassen entfernen. Wenn Sie Unterklassen unter Unterklassen erstellen, können Sie diese ausgehend vom untersten Level entfernen. Die folgende Liste enthält eine Zusammenfassung der Schritte zum Entfernen des generischen CDOs. Ausführliche Anweisungen zum Entfernen bestimmter CDO-Typen finden Sie jedoch in den einzelnen Übungen dieses Kapitels.

Vorgehensweise zum Suchen eines CDOs

Gehen Sie folgendermaßen vor, um ein CDO zu suchen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
3. Geben Sie die ersten Zeichen des CDO-Namens in das Filterfeld oberhalb der Auswahlstruktur ein. Es wird eine Liste mit Objekten angezeigt, die die Zeichen enthalten.
4. Suchen Sie das gewünschte CDO und wählen Sie es aus der Liste aus. Die Anwendung erweitert die Auswahlstruktur, hebt das ausgewählte CDO hervor und zeigt das zugehörige CDO-Definitionsfenster an.

Vorgehensweise zum Entfernen eines CDOs

Gehen Sie folgendermaßen vor, um ein benutzerdefiniertes CDO zu entfernen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
3. Wählen Sie das zu entfernende benutzerdefinierte CDO aus.
Hinweis: Die Schaltfläche "Entfernen" ist deaktiviert, wenn Sie ein Standard-CDO auswählen.
4. Wenn die Schaltfläche Entfernen (Remove) für ein benutzerdefiniertes CDO deaktiviert ist, klicken Sie auf die Registerkarte Wo genutzt (Where Used). Suchen Sie die CDOs, die das zu entfernende CDO referenzieren, und löschen Sie alle Feldüberschreibungen. Weitere Informationen finden Sie unter "Erstellen von Feldüberschreibungen".
Hinweis: Wenn Sie alle Referenzen auf das zu entfernende CDO gelöscht haben, wird die Schaltfläche "Entfernen" (Remove) aktiviert.
5. Klicken Sie unter dem CDO-Auswahlbaum im linken Bereich auf Entfernen (Remove). Das CDO wird entfernt.
6. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
