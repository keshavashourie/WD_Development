Vorgehensweisen für Ereignisse und Methoden

Sie können einen CLF an ein Ereignis anhängen oder eine neue Methode erstellen. Für ein Ereignis oder eine Methode kann immer nur ein CLF aktiv sein. Sie können einen vorhandenen CLF, der von Ihrem aktuellen CDO geerbt wird, überschreiben.

Wenn ein CLF auf dem aktuellen CDO-Level an ein Ereignis oder eine Methode angehängt wird, müssen Sie diesen CLF abtrennen, bevor Sie einen anderen anhängen können.

Anzeigen von Ereignissen und Methoden

Ereignisse sind mit Blitzsymbolen gekennzeichnet.

Vorgehensweise zum Anzeigen der Ereignisse und Methoden, die an ein CDO angehängt sind

Gehen Sie folgendermaßen vor, um die an ein CDO angehängten Ereignisse und Methoden anzuzeigen:

1. Öffnen Sie Designer.
2. Klicken Sie in der Symbolleiste auf CDOs. Das Fenster "CDO-Definition" wird angezeigt.
3. Wählen Sie das CDO aus, für das Sie die zugehörigen Ereignisse anzeigen möchten. Wählen Sie z. B. Container aus.
4. Klicken Sie auf die Registerkarte Ereignisse. Die Ereignisse und Methoden für das ausgewählte CDO werden angezeigt:
Hinweis: Für Basisklassen wie "Container" werden die in dieser Klasse definierten Methoden angezeigt. Wenn Sie jedoch Unterklassen ausgewählt haben, werden die geerbten Methoden nur angezeigt, wenn Sie das Kontrollkästchen "Geerbte einschließen" aktivieren.
5. Klicken Sie auf Variablen anzeigen, um die für die Methoden des CDOs und die CLFs definierten Variablen anzuzeigen.

Vorgehensweise zum Anhängen eines CLFs an ein Ereignis oder eine Methode

Gehen Sie folgendermaßen vor, um einen CLF an ein Ereignis oder eine Methode anzuhängen:

1. Öffnen Sie Designer.
2. Klicken Sie in der Symbolleiste auf CDOs. Das Fenster "CDO-Definition" wird angezeigt.
3. Wählen Sie ein benutzerdefiniertes CDO aus.
4. Klicken Sie auf die Registerkarte Ereignisse.
5. Aktivieren Sie das Kontrollkästchen Geerbte einschließen, um die geerbten Ereignisse und Methoden anzuzeigen.
6. Wählen Sie das Ereignis oder die Methode aus, das bzw. die Sie an einen CLF anhängen möchten. Die Schaltfläche "CLF anhängen" ist aktiviert.
7. Klicken Sie auf CLF anhängen. Das Fenster "Definition suchen" wird mit der Bibliothek der verfügbaren CLFs angezeigt. High Performance-CLFs stehen zur Auswahl, wenn Sie für diese Funktion lizenziert sind.
Hinweis: Sie können auch mit der rechten Maustaste auf das Ereignis oder die Methode klicken und "CLF anhängen" auswählen.
8. Erweitern Sie die CLF-Kategorie, die den erforderlichen CLF enthält.
9. Wählen Sie den gewünschten CLF aus.
10. Klicken Sie auf Auswählen.
11. Klicken Sie auf das Ereignis oder die Methode, das bzw. die Sie gerade geändert haben, um Ihre Änderungen zu speichern.
12. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
13. Wenn Sie anzeigen möchten, welcher CLF aktiv ist und welche CLFs überschrieben werden, können Sie optional auf das entsprechende Ereignis oder die Methode klicken, dem bzw. der der CLF hinzugefügt wurde. Neben dem neuen CLF wird ein CLF-Symbol angezeigt.
Hinweis: Neben dem bisherigen CLF wird das Symbol angezeigt, das darauf hinweist, dass er überschrieben wurde. Es kann ein Stapel überschriebener CLFs vorliegen, wobei der letzte CLF in dieser Liste stets der aktive CLF ist.
Hinweis: Sie können einen CLF über das Kontextmenü erneut anhängen, anstatt ihn zu entfernen und dann anzuhängen.

Vorgehensweise zum Abtrennen eines CLFs von einem Ereignis oder einer Methode

Mit der folgenden Vorgehensweise wird ein zuvor angehängter CLF entfernt. Er verbleibt jedoch in der CLF-Bibliothek, sodass er jederzeit verfügbar ist. Ein geerbter CLF kann nicht abgetrennt werden.

Gehen Sie folgendermaßen vor, um einen CLF von einem Ereignis oder einer Methode abzutrennen:

1. Öffnen Sie Designer.
2. Klicken Sie in der Symbolleiste auf CDOs. Das Fenster "CDO-Definition" wird angezeigt.
3. Klicken Sie auf die Registerkarte Ereignisse.
4. Wählen Sie das gewünschte CDO aus. Die Ereignisse und Methoden, die dem ausgewählten CDO zugeordnet sind, werden angezeigt.
5. Aktivieren Sie das Kontrollkästchen Geerbte einschließen, um die geerbten Ereignisse und Methoden anzuzeigen.
6. Klicken Sie, um das Ereignis oder die Methode zu öffnen, von dem bzw. der der CLF abgetrennt werden soll.
7. Wählen Sie den abzutrennenden CLF aus.
8. Klicken Sie auf CLF abtrennen oder klicken Sie mit der rechten Maustaste auf den CLF und wählen Sie CLF abtrennen aus. Ein Bestätigungsdialogfeld wird geöffnet und Sie werden gefragt, ob Sie sicher sind, dass Sie diesen CLF abtrennen möchten.
Hinweis: Wenn die Schaltfläche "CLF abtrennen" nicht aktiviert ist, handelt es sich um einen geerbten CLF, der nur überschrieben werden kann.
9. Klicken Sie auf Ja. Der CLF wird aus dem Ereignis oder der Methode entfernt. Der überschriebene CLF, der sich direkt über dem entfernten CLF befindet, wird aktiv (das Symbolwird entfernt).
10. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Hinzufügen einer Methode zu einem CDO

CDOs erben in der Regel alle erforderlichen Methoden, die zum Ausführen der gewünschten Aufgabe erforderlich sind. Manchmal sind jedoch zusätzliche Methoden erforderlich. Beim Hinzufügen einer Methode zu einem CDO fügen Sie auch einen CLF hinzu, der zur neuen Methode gehört. Die neue Methode weist standardmäßig den Namen des angehängten CLFs auf. Sie können die Methode für Ihre Zwecke umbenennen.

Gehen Sie folgendermaßen vor, um eine Methode einem CDO hinzuzufügen:

1. Öffnen Sie Designer.
2. Klicken Sie in der Symbolleiste auf CDOs. Das Fenster "CDO-Definition" wird angezeigt.
3. Klicken Sie auf die Registerkarte Ereignisse.
4. Wählen Sie das CDO aus.
5. Aktivieren Sie das Kontrollkästchen Geerbte einschließen, um die geerbten Ereignisse und Methoden anzuzeigen.
6. Klicken Sie auf die Schaltfläche Neue Methode oder klicken Sie mit der rechten Maustaste auf die Liste der Ereignisse und wählen Sie Neue Methode aus. Das Fenster "Definition suchen" wird angezeigt.
Hinweis: Das Fenster "Definition suchen" enthält eine Liste der CLFs. High Performance-CLFs stehen zur Auswahl, wenn Sie für diese Funktion lizenziert sind. Der CLF wird als Methode hinzugefügt und erhält den Standardnamen des ausgewählten CLFs.
7. Erweitern Sie die CLF-Kategorie, die den gewünschten CLF enthält, und wählen Sie diesen CLF aus.
8. Klicken Sie auf Auswählen. Die neue Methode wird ganz unten in der Liste der benutzerdefinierten Methoden angezeigt.
9. Benennen Sie Ihre Methode bei Bedarf wie folgt um:
a. Wählen Sie die neue Methode aus.
b. Warten Sie kurz und klicken Sie erneut auf die neue Methode, um den Umbenennungsmodus zu aktivieren.
c. Geben Sie den neuen Namen ein.
d. Drücken Sie die Eingabetaste, um Ihre Eingabe zu speichern. Die Methode ist jetzt verfügbar und kann verwendet werden.
10. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Entfernen einer Methode von einem CDO

Gehen Sie folgendermaßen vor, um eine Methode aus einem CDO zu entfernen:

1. Öffnen Sie Designer.
2. Klicken Sie in der Symbolleiste auf CDOs. Das Fenster "CDO-Definition" wird angezeigt.
3. Klicken Sie auf die Registerkarte Ereignisse.
4. Wählen Sie das CDO aus.
5. Aktivieren Sie das Kontrollkästchen Geerbte einschließen, um die geerbten Ereignisse und Methoden anzuzeigen.
6. Erweitern Sie die zu entfernende Methode. Der angehängte CLF wird angezeigt. Möglicherweise ist ein Stapel mit CLFs angehängt, von denen jedoch nur der letzte aktiv ist.
7. Wählen Sie den aktiven CLF aus, der an die Methode angehängt wurde. (Wenn Sie den Namen der Methode anstelle des angehängten aktiven CLFs auswählen, bleibt die Schaltfläche CLF abtrennen deaktiviert.)
8. Klicken Sie auf CLF abtrennen. Ein Bestätigungsfenster wird angezeigt und Sie werden gefragt, ob Sie den CLF wirklich abtrennen möchten.
9. Klicken Sie auf Ja. Der zuletzt überschriebene CLF wird aktiviert.
10. Wiederholen Sie die Schritte 7 bis 9 so oft wie erforderlich, um einen Stapel überschriebener CLFs zu entfernen. Nachdem der letzte angehängte CLF abgetrennt wurde, wird die Methode entfernt.
11. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
