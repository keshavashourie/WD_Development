Registerkarte "Funktionsberechtigung"

Die Registerkarte "Funktionsberechtigung" ist für CDOs, CLFs und Funktionen verfügbar. Es gibt zwei verschiedene Ansichten der Registerkarte "Funktionsberechtigung": eine für die Ansicht "Objektdefinition" (Entity Definition) und eine für die Ansicht "Ereignis-/Methodendetail" (Event/Method detail). Allerdings ist die Ansicht "Ereignis-/Methodendetail" (Event/Method detail) nur für CDOs verfügbar.

Eine Liste der standardmäßig enthaltenen Standard- und optionalen Funktionen finden Sie in der Release-Matrix für Opcenter EX MDD im Siemens Support Center oder in der Release-Matrix für Opcenter EX CR im Siemens Support Center.

Ansicht "Objektdefinition" (Entity Definition)

Wenn Sie ein Objekt auswählen, z. B. ein CDO, können Sie die Registerkarte "Funktionsberechtigung" anzeigen. Wenn Sie die Registerkarte "Funktionsberechtigung" auswählen, steht das Feld "Funktionsmitgliedschaft" (Feature Membership) zur Verfügung, in dem die Funktionsberechtigungsmitgliedschaft für das Objekt angezeigt wird. Neu hinzugefügte CLFs und Funktionen weisen standardmäßig die Funktionen auf, die dem entsprechenden Arbeitsbereich zugeordnet sind. Sie können beim Hinzufügen eines neuen Objekts eine alternative berechtigte Funktion auswählen. Das Feld "Funktionsmitgliedschaft" (Feature Membership) enthält nur Funktionen, die für den aktuell aktiven Arbeitsbereich berechtigt sind. Weitere Informationen zum Erteilen von Berechtigungen für Funktionen in Ihrem höchsten aktiven Arbeitsbereich finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Hinweis: Die Funktionsmitgliedschaft weist standardmäßig die Basisfunktionsberechtigung auf, wenn Sie ein vorhandenes CDO mit einer Funktionsmitgliedschaft überschreiben.

Ansicht "Ereignis-/Methodendetail" (Event/Method detail)

Auf der Registerkarte "Ereignisse" können Sie auch die Informationen zur Funktionsberechtigung für CDO-Objekte anzeigen.

Vorgehensweise zum Anzeigen von Funktionsberechtigungen auf der Registerkarte "Ereignisse"

Gehen Sie folgendermaßen vor, um die Funktionsberechtigung auf der Registerkarte "Ereignisse" anzuzeigen:

1. Wählen Sie ein CDO aus.
2. Klicken Sie auf die Registerkarte Ereignisse.
3. Klicken Sie auf Details.
4. Wählen Sie ein Ereignis aus. Im Feld "Funktionsberechtigung" wird die Funktionsmitgliedschaft für das ausgewählte Ereignis angezeigt.
