Designer

Farbige Symbole zeigen an, welche Elemente in Designer lizenziert oder nicht lizenziert sind.

Konfigurierbare Datenobjekte (CDOs)

Bei Auswahl eines lizenzierten CDOs gilt Folgendes:

• Sie können Änderungen am CDO vornehmen. Weitere Informationen finden Sie unter "Konfigurierbare Datenobjekte".
• Allerdings können Sie kein Objektreferenzfeld hinzufügen, das ein eingeschränktes oder nicht lizenziertes CDO referenziert.

Wenn Sie ein nicht lizenziertes CDO auswählen:

• Designer erlaubt Ihnen nur die Anzeige der Registerkarte "Funktionsberechtigung". Sie können die anderen Registerkarten für ein CDO nicht anzeigen.
• Am CDO oder an den zugehörigen Objekten (z. B. Felder, Zuordnungen oder Ereignisse/Methoden) dürfen keine Änderungen vorgenommen werden.

Mit verschiedenfarbigen Symbolen wird der Status der einzelnen CDOs angezeigt.

Die folgende Tabelle enthält die verschiedenfarbigen Symbole, die für CDOs verwendet werden, und eine Beschreibung für jedes Symbol.

Hinzufügen eines neuen CDO-Felds

Das Feldsymbol im Fenster "Neues CDO-Feld hinzufügen" gibt an, ob das Feld ein Standard-CDO (grün), ein lizenziertes CDO (gelb) oder ein nicht lizenziertes CDO (rot) referenziert. Felder, die nicht lizenzierte CDOs referenzieren, können nicht hinzugefügt werden.


Fenster "Definition suchen"

Das Fenster "Definition suchen" wird angezeigt, wenn Sie einen CLF anhängen oder eine neue Methode hinzufügen. Das Fenster "Definition suchen" filtert die nicht lizenzierten CLFs und Funktionen heraus. Daher werden in diesem Fenster nur die Basis-CLFs und die lizenzierten Objekte angezeigt. Basis-CLFs sind grün, während lizenzierte CLFs gelb sind.

CDO-Feldeigenschaften

Im Fenster "Feldeigenschaften" werden nur Standard- und lizenzierte CLFs angezeigt.

Auf der Registerkarte "Ereignisse" im Fenster "CDO-Feldeigenschaften" (CDO Field Properties) wird eine Liste der Ereignisse angezeigt, die dem Feld zugeordnet sind. Das gelbe Blitzsymbol weist darauf hin, dass es sich um Standardereignisse handelt. Diese Ereignisse sind nicht eingeschränkt. Es ist jedoch möglich, dass einem Standardereignis ein eingeschränkter CLF angehängt wurde.

Konfigurierbare logische Abläufe (CLFs)

Bei Auswahl einer lizenzierten CLF-Definition gilt Folgendes:

• Sie können Änderungen genau wie im Abschnitt "Ändern der Standardparameterwerte von Funktionen für einen CLF" beschrieben vornehmen.
• Allerdings können Sie einen nicht lizenzierten CLF nicht an ein Ereignis oder eine Methode anhängen.

Wenn Sie die Definition eines nicht lizenzierten CLFs auswählen:

• Designer erlaubt Ihnen nur die Anzeige der Registerkarte "Funktionsberechtigung". Sie können die anderen Registerkarten für einen CLF nicht anzeigen.
• Sie können ein Ereignis, eine Methode, einen CLF oder eine CLF-Funktion nicht erweitern. Sie erhalten eine Warnmeldung, wenn Sie versuchen, diese zu erweitern.

Funktionen

Bei Auswahl einer lizenzierten Funktion gilt Folgendes:

• Sie können Änderungen genau wie im Kapitel zu CLFs beschrieben vornehmen.

Wenn Sie eine nicht lizenzierte Funktion auswählen:

• Designer erlaubt Ihnen nur die Anzeige der Registerkarte "Funktionsberechtigung". Sie können die anderen Registerkarten für eine Funktion nicht anzeigen.
• Sie können keine Details wie GUID und Parameter anzeigen.

Das Fenster mit den Funktionen verwendet mehrere verschiedene Symboltypen. Die Modullizenzierung verwendet Symbole in verschiedenen Farben, um auf Funktionen hinzuweisen, die Parametertypen erzwingen. Die folgende Tabelle enthält die für Funktionen verwendeten Symbole.
