Gleichzeitige Lizenzierung

Kunden erwerben eine begrenzte Anzahl von Lizenzen von Siemens, wenn Sie Opcenter EX MDD oder Opcenter EX CR erwerben. Es können nur so viele Benutzer gleichzeitig beim Portal angemeldet sein, wie Lizenzen erworben wurden.

Wenn sich jemand beim Portal anmeldet, wird eine Sitzung gestartet und wird eine Lizenz für dieses spezifische Benutzerkonto verwendet.

Sobald die Anzahl der angemeldeten Benutzer der Anzahl der verfügbaren Lizenzen entspricht, können sich keine neuen Benutzer mehr anmelden, bis eine Lizenz verfügbar wird (z. B. wenn ein anderer Benutzer eine Sitzung beendet).

Versucht ein Benutzer, sich anzumelden, wenn der Lizenzgrenzwert erreicht ist, wird eine Fehlermeldung angezeigt, die darüber informiert, dass keine Lizenzen mehr verfügbar sind.

Sobald Benutzer angemeldet sind, können sie auf alle lizenzierten Funktionen und Module zugreifen. Insofern unterscheidet sich die gleichzeitige Lizenzierung von der Funktionslizenzierung, bei der bestimmt wird, welche Module lizenziert wurden.

Hinweis: Wenn Ihr Unternehmen mehr gleichzeitige Lizenzen benötigt als Sie derzeit besitzen, wenden Sie sich an den Produkt-Support, um zusätzliche Lizenzen zu erwerben.
