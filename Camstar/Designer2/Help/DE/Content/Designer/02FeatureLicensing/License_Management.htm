Lizenzverwaltung

Opcenter EX MDD und Opcenter EX CR enthalten das Basisprodukt. Darüber hinaus umfasst das Programm einzelne Produkte und Module, die getrennt lizenziert werden können. Für die Installation von Opcenter EX MDD oder Opcenter EX CR benötigen Sie eine gültige Lizenzdatei und Seriennummer. Sie müssen auch Siemens License Server mithilfe der Siemens Lizenzierungsanwendung installieren.

Die Lizenzdatei wird basierend auf den Produkten und Modulen generiert, die Sie beim Erwerb von Opcenter EX MDD oder Opcenter EX CR lizenziert haben. Es gibt eine Lizenzdatei. Sie benötigen die Lizenzdatei zur Installation von Siemens License Server.

Die Seriennummer ist der Schlüssel, den Sie bei der Installation von Opcenter EX MDD oder Opcenter EX CR eingeben. Diese bestimmt, welche Produkte und Module für die Installation zur Verfügung stehen. Ihre eindeutige Seriennummer umfasst alle weiteren Produkte oder Module, die Sie erworben haben. Wenn Sie keine zusätzlichen Module erwerben, werden in Designer alle Objekte, die sich auf diese Objekte beziehen, rot dargestellt.

Weitere Informationen zur Lizenzierung finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung und der Opcenter Execution Core-Installationsanleitung.

Lizenzserver

Designer verwendet Siemens License Server. Nach der Installation des Servers wird ein neuer Windows-Dienst erstellt. Für Designer ist der Lizenzserver erforderlich.

Lizenzschlüsseldatei

Die Lizenzdatei enthält die Laufzeitlizenz für den Server und für Designer. Der Lizenzserver validiert, ob Sie berechtigt sind, separat lizenzierte Module zu verwenden. Wenn der Lizenzserver nicht verfügbar ist, können Sie diese Funktionen nicht verwenden.

Hinweis: Sie können eine vorhandene Opcenter EX MDD- oder Opcenter EX CR-Installation aktualisieren, um weitere Module hinzuzufügen, wenn Sie über eine neue Lizenzdatei und eine neue Seriennummer verfügen. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung und der Opcenter Execution Core-Installationsanleitung.

Die Lizenzierung beeinflusst das Verhalten verschiedener Objekte, wenn sie in Designer ausgewählt werden. Unter dem Thema "Designer" im nächsten Abschnitt ist das Verhalten von Objekten mit installierter Funktionslizenzierung beschrieben.

Hinweis: Ein rotes Symbol neben einem Objekt in Designer weist darauf hin, dass das Modul nicht lizenziert ist oder der Lizenzserver nicht verfügbar ist. Ein gelbes Symbol weist auf ein separat lizenziertes Modul hin, das ordnungsgemäß lizenziert wurde.

Aktualisieren von Lizenzschlüsseln

Mit Opcenter EX MDD und Opcenter EX CR können Sie eine Produktionslizenz aktualisieren, ohne den Server herunterfahren zu müssen. Bei einem Notfall können Sie eine temporäre Lizenz erstellen, z. B. wenn Opcenter EX MDD oder Opcenter EX CR gesperrt wurde, weil die Lizenz abgelaufen ist. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung oder in der Opcenter Execution Core-Installationsanleitung.

Gehen Sie folgendermaßen vor, um die Lizenzschlüssel zu aktualisieren:

1. Erstellen Sie eine temporäre Lizenzdatei.
2. Ersetzen Sie die Lizenzdatei durch die temporäre Datei auf dem Lizenzserver. Verwenden Sie dazu die Lizenzierungsanwendung.
Hinweis: Dadurch wird die Ausführung des Sicherheitsservers oder des Anwendungsservers nicht beeinträchtigt. Der Sicherheitsserver verwendet die neuen Lizenzinformationen automatisch, wenn er die regelmäßige Aktualisierungs- und Ablaufprüfung für die Lizenz durchführt.
