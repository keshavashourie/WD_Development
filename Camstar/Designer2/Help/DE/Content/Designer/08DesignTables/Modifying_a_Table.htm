Ändern einer Tabelle

Das Ändern von Tabellen ist keine häufig ausgeführte Aufgabe. Dennoch ist es manchmal erforderlich, eine vorhandene Tabelle innerhalb der Datenbank zu ändern. Möglicherweise muss eine Tabelle geändert werden, wenn Sie die Definition eines Zeichenkettenfelds geändert haben, um das Feld von 15 auf 20 Zeichen zu erweitern.

Beim Ändern einer Tabelle

Wenn Sie die Felddefinition ändern, ändert sich die Tabelle nicht, da Opcenter EX MDD- und Opcenter EX CR-Tabellen absichtlich getrennt von den Felddefinitionen aufbewahrt werden. Daher können Sie die Tabellenbreite an die Breite des Zeichenkettenfelds anpassen.

Arbeitsbereichspräfixe werden beim Hinzufügen eines neuen Elements automatisch vor dem Namen des Elements eingefügt, sofern dem höchsten aktiven Arbeitsbereich ein Präfix zugewiesen wurde. Arbeitsbereichspräfixe geben an, auf welchen Arbeitsbereich Designer Änderungen anwendet. Dem Arbeitsbereich würde z. B. das Präfix "C200" zugeordnet werden, wenn für diesen in Management Studio das Präfix "C200" festgelegt wurde. Es wird empfohlen, beim Hinzufügen neuer Elemente die von Designer bereitgestellten Präfixe zu verwenden.

Sie können Arbeitsbereichspräfixe in Management Studio zuweisen oder ändern. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Hinweis: Dem Basisarbeitsbereich der Anwendung (csi) kann kein Arbeitsbereichspräfix zugewiesen sein.

Vorgehensweise zum Ändern einer Tabellenkategorie

Gehen Sie folgendermaßen vor, um eine Tabellenkategorie zu ändern:

1. Öffnen Sie Designer.
2. Klicken Sie auf Tabellen (Tables). Das Fenster "Tabellendefinitionen" (Table Definitions) wird angezeigt.
3. Klicken Sie auf die Tabellenkategorie, in der sich die zu ändernde Tabelle befindet.
4. Wählen Sie die zu ändernde Tabelle aus.
5. Wählen Sie in Tabellenkategorie (Table Category) eine neue Kategorie aus.
6. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Hinzufügen von Tabellenspalten

Gehen Sie folgendermaßen vor, um Tabellenspalten hinzuzufügen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Tabellen (Tables). Das Fenster "Tabellendefinitionen" (Table Definitions) wird angezeigt.
3. Wählen Sie die Registerkarte Spalten aus.
4. Wählen Sie die Tabelle aus, der Sie eine Spalte hinzufügen möchten.
5. Klicken Sie unter dem Spaltennamen und der Beschreibung auf Hinzufügen. Das Fenster "DB-Spalteneigenschaften" (DB Column Properties) wird angezeigt. Es enthält eine neue Spalte mit einem Standardnamen.
Hinweis: Sie können auch an einer beliebigen Stelle in der Spaltenliste mit der rechten Maustaste klicken und im Kontextmenü die Option "Spalte hinzufügen" (Add column) auswählen.
6. Geben Sie den Namen für die neue Spalte, eine Beschreibung und die anderen Eigenschaftsinformationen für die Spalte ein. Eine Liste der unzulässigen Zeichen und reservierten Wörter, die vermieden werden müssen, finden Sie unter "Gültige Zeichen und reservierte Wörter".
7. Klicken Sie auf OK.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Entfernen von Tabellenspalten

Standardspalten können nicht entfernt werden.

Hinweis: Durch das Entfernen einer Tabellenspalte in Designer wird das entsprechende Objekt in der Produktionsdatenbank nicht gelöscht. Dadurch wird verhindert, dass historische Daten verloren gehen.

Gehen Sie folgendermaßen vor, um Tabellenspalten zu entfernen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Tabellen (Tables). Das Fenster "Tabellendefinitionen" (Table Definitions) wird angezeigt.
3. Wählen Sie die Registerkarte Spalten aus.
4. Wählen Sie die Tabelle aus, aus der die Spalte entfernt werden soll.
5. Wählen Sie die zu entfernende Spalte aus.

Wenn die Schaltfläche "Entfernen" (Remove) deaktiviert ist, wird die Spalte von mindestens einem CDO-Feld verwendet. Gehen Sie folgendermaßen vor, um diese Zuordnung zu entfernen:

a. Wählen Sie den Spaltennamen aus und doppelklicken Sie darauf, um das Fenster "DB-Spalteneigenschaften" (DB Column Properties) zu öffnen.
b. Klicken Sie auf die Registerkarte Wo genutzt.
c. Notieren Sie sich die CDOs und Felder, die in der Liste angezeigt werden, und klicken Sie auf "Abbrechen", um das Fenster zu schließen.
d. Für jedes CDO-Feld, das die zu entfernende DB-Spalte verwendet, müssen Sie entweder das Feld entfernen oder seine DB-Spaltenzuordnung über das Eigenschaftsfenster der Registerkarte Allgemein ändern.
e. Wiederholen Sie diese Schritte für alle Felder, die die DB-Spalte verwenden.
6. Wählen Sie die DB-Spalte erneut aus und klicken Sie auf Entfernen oder klicken Sie mit der rechten Maustaste und wählen Sie Spalte entfernen (Remove Column) aus.
7. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Ändern von Tabellenspalten

Gehen Sie folgendermaßen vor, um Tabellenspalten zu ändern:

1. Öffnen Sie Designer.
2. Klicken Sie auf Tabellen (Tables). Das Fenster "Tabellendefinitionen" (Table Definitions) wird angezeigt.
3. Wählen Sie die Registerkarte Spalten aus.
4. Wählen Sie die Tabelle aus, die die zu ändernden Spalten enthält.
5. Wählen Sie die zu ändernde Spalte aus.
6. Klicken Sie auf Eigenschaften. Das Fenster "DB-Spalteneigenschaften" (DB Column Properties) wird angezeigt.
7. Passen Sie die Eigenschaften an die Anforderungen Ihres Unternehmens an.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Ändern eines Tabellennamens

Wichtig: Wenn Sie Tabellen in Designer umbenennen, müssen Sie die Auswirkungen Ihrer Aktion kennen (insbesondere, wenn bestimmte Objekte die Tabellen bereits verwenden). Durch das Ändern der Tabellennamen wird kein SQL-Code geschrieben, um die alten Tabellen in der Datenbank zu kopieren, zu erstellen und zu löschen.

Gehen Sie folgendermaßen vor, um einen Tabellennamen zu ändern:

1. Öffnen Sie Designer.
2. Klicken Sie auf Tabellen (Tables). Das Fenster "Tabellendefinitionen" (Table Definitions) wird angezeigt.
3. Öffnen Sie die Kategorie, unter der sich die Tabelle befindet.
4. Wählen Sie die Tabelle aus, die Sie umbenennen möchten.
5. Warten Sie kurz und wählen Sie sie dann erneut aus oder klicken Sie auf die Schaltfläche Umbenennen. Der Tabellenname wechselt in den Umbenennungsmodus.
6. Benennen Sie die Tabelle um.

Eine Liste der unzulässigen Zeichen und reservierten Wörter, die vermieden werden müssen, finden Sie unter "Gültige Zeichen und reservierte Wörter".

7. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
