Registerkarte "Indizes" (Indexes)

Felddefinitionen der Registerkarte "Indizes" (Indexes)

Diese Tabelle definiert die Felder auf der Registerkarte "Indizes" (Indexes).

Feld

Definition

Typ

Vorhandene Indizes (Existing Indexes)

Zeigt alle Indizes an, die der ausgewählten Tabelle zugeordnet sind.

Erforderlich

Details

Name

Der Name, der zum Identifizieren des Index bei dessen Erstellung verwendet wird. Jeder Name muss eindeutig sein.

Erforderlich

Index ist eindeutig (Index is unique)

Erstellt einen eindeutigen Index für die ausgewählte Tabelle.

Optional

Beschreibung

Enthält eine Beschreibung, wie dieser Index verwendet wird.

Optional

Optionen

Aufsteigend sortieren (Sort Ascending)

Legt für die ausgewählte Spalte eine aufsteigende Sortierreihenfolge fest.

Optional

Absteigend sortieren (Sort Descending)

Legt für die ausgewählte Spalte eine absteigende Sortierreihenfolge fest.

Optional

Nicht einschließen (Do Not Include)

Schließt die Spalte aus dem Index aus.

Optional

Schaltflächendefinitionen der Registerkarte "Indizes" (Indexes)

Diese Tabelle definiert die Schaltflächen auf der Registerkarte "Indizes" (Indexes).

Schaltfläche

Funktion der Schaltfläche . . .

Hinzufügen

Fügt der ausgewählten Tabelle einen Index hinzu.

Entfernen...

Entfernt einen Index aus der ausgewählten Tabelle.

Nach oben verschieben (Move Up)

Ändert die Struktur des Index, indem eine ausgewählte Spalte in der Liste nach oben verschoben wird.

Nach unten verschieben (Move Down)

Ändert die Struktur des Index, indem eine ausgewählte Spalte in der Liste nach unten verschoben wird.
