Definieren von Indizes für Tabellen

Möglicherweise müssen Sie für Ihre Tabellen neue Indizes definieren, um die Anforderungen Ihres Unternehmens hinsichtlich eines schnellen Zugriffs auf Informationen zu erfüllen.

Beim Definieren von Indizes für Tabellen

Einige von Opcenter EX MDD und Opcenter EX CR bereitgestellte Tabellen werden indiziert. Indizes, die für eine Tabelle in Designer definiert wurden, werden nicht vererbt, wenn Sie eine Unterklasse des CDOs und eine neue Tabelle in diesem Prozess erstellen. Wenn Sie beim Erstellen einer Tabelle eine CDO-Unterklasse hinzufügen, wird stets ein Index für das Feld "ID" erstellt, z. B. "<CDO>Id".

Hinweis: Der Index wird erstellt, wenn Sie neue Datenbanktabellen für die Transaktionsdatenbank erstellen. Weitere Informationen finden Sie unter "Vorgehensweise zum Erstellen von Indizes".

Wenn Sie neue Tabellen und Spalten hinzugefügt haben, müssen Sie für diese manuell Indizes erstellen. Führen Sie dazu die Schritte in diesem Thema aus.

Vorgehensweise zum Definieren eines Index

Gehen Sie folgendermaßen vor, um einen Index zu definieren:

1. Öffnen Sie Designer.
2. Klicken Sie auf Tabellen (Tables). Das Fenster "Tabellendefinitionen" (Table Definitions) wird angezeigt.
3. Wählen Sie die Registerkarte Indizes (Indexes) aus.
4. Wählen Sie die Tabellenkategorie aus, in der sich die Tabelle befindet, und wählen Sie die Tabelle aus, die Sie Ihrem Index hinzufügen möchten.
5. Klicken Sie auf Hinzufügen neben dem Feld Vorhandene Indizes (Existing Indexes). Der Tabellenname wird von Opcenter EX MDD und Opcenter EX CR automatisch in das Feld "Vorhandene Indizes" (Existing Indexes) eingegeben. Von Opcenter EX MDD oder Opcenter EX CR wird auch eine eindeutige ID für den Index zugewiesen.
6. Geben Sie einen eindeutigen Namen und eine aussagekräftige Beschreibung für den neuen Index ein.

Eine Liste der unzulässigen Zeichen und reservierten Wörter, die vermieden werden müssen, finden Sie unter "Gültige Zeichen und reservierte Wörter".

7. Wählen Sie den Spaltennamen aus, der als Indexeintrag hinzugefügt werden soll.
Hinweis: Standardmäßig sind die Spalten nicht als Indexeinträge konfiguriert (die Schaltfläche "Nicht einschließen" (Do not include) ist ausgewählt).
8. Gehen Sie folgendermaßen vor, um den Index zu sortieren:
• Klicken Sie mit der rechten Maustaste und wählen Sie entweder Aufsteigend sortieren (Sort Ascending) oder Absteigend sortieren (Sort Descending) aus.

Oder

• Verwenden Sie die Optionsfelder, um entweder Aufsteigend sortieren (Sort Ascending) oder Absteigend sortieren (Sort Descending) auszuwählen.
Hinweis: Wenn zwei oder mehr Indexeinträge vorliegen, können Sie mithilfe der Schaltfläche "Nach oben verschieben" (Move Up) oder "Nach unten verschieben" (Move Down) die Sortierreihenfolge eines Eintrags ändern.
9. Klicken Sie an einer beliebigen Stelle auf der Registerkarte, um Ihre Änderungen zu speichern.

Verwendung der neuen Indizes

Zur Verwendung des neuen Index in Ihrer Transaktionsdatenbank müssen Sie das Indexskript erstellen und ausführen. Koordinieren Sie dies mit dem Datenbankadministrator (DBA). Weitere Informationen zum Ausführen des Skripts für die neuen Indizes finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung und der Opcenter Execution Core-Installationsanleitung. Dieser Vorgang kann lange dauern, sodass Sie das Ausführen der Skripte entsprechend planen müssen.

Vorgehensweise zum Erstellen von Indizes

Gehen Sie folgendermaßen vor, um die Indizes in Ihrer Transaktionsdatenbank zu erstellen:

1. Öffnen Sie Management Studio.
2. Erweitern Sie den Knoten <Standortname>.
3. Erweitern Sie den Ordner Datenbanken.
4. Klicken Sie mit der rechten Maustaste auf die Transaktionsdatenbank und wählen Sie im daraufhin angezeigten Menü die Option Neue Datenbanktabellen erstellen aus. Das Fenster "Tabellen für <Datenbank> erstellen" (Create Tables For <database>) wird angezeigt.
5. Lassen Sie alle Kontrollkästchen aktiviert.
6. Klicken Sie auf OK. Die Anwendung erstellt die neuen Tabellen, schließt das Fenster "Tabellen für <Datenbank> erstellen" (Create Tables For <database>) und zeigt eine Meldung an, dass die neue Datenbank erfolgreich erstellt wurde.
