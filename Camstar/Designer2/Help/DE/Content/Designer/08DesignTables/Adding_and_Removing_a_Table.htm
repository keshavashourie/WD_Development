Hinzufügen und Entfernen einer Tabelle

Sie haben die Möglichkeit, der Datenbank eine neue Tabelle hinzuzufügen oder die Eigenschaften einer vorhandenen Tabelle zu ändern. Beim Erstellen einer Tabelle über Designer erstellen Sie tatsächlich eine Tabellendefinition, die in der Transaktionsdatenbank zu einer Tabelle wird. Weitere Informationen zum Erstellen von Tabellen aus Tabellendefinitionen finden Sie unter "Vorgehensweise zum Erstellen neuer Tabellen".

Beim Hinzufügen und Entfernen einer Tabelle

Zum Erstellen einer Tabelle gibt es zwei Möglichkeiten:

• Hinzufügen einer Tabelle, wenn Sie eine CDO-Unterklasse hinzufügen (über das Fenster "Neue CDO-Definition erstellen")
• Hinzufügen einer Tabelle mithilfe der Schaltfläche "Tabellen" (Tables) im Designer-Hauptfenster (diese Option zum Hinzufügen von Tabellen wird selten verwendet)
Hinweis: Sie werden niemals eine Tabelle für Container-CDO-Unterklassen erstellen, da Ihre Container-CDO-Unterklasse dieselbe Tabelle verwenden wird wie die übergeordnete Klasse, aus der Ihre Container-CDO-Unterklasse abgeleitet wurde.

Arbeitsbereichspräfixe werden beim Hinzufügen eines neuen Elements automatisch vor dem Namen des Elements eingefügt. Arbeitsbereichspräfixe geben an, auf welchen Arbeitsbereich Designer Änderungen anwendet. Dem Arbeitsbereich würde z. B. das Präfix "C200" zugeordnet werden, wenn für diesen in Management Studio das Präfix "C200" festgelegt wurde. Es wird empfohlen, beim Hinzufügen neuer Elemente die von Designer bereitgestellten Präfixe zu verwenden.

Sie können Arbeitsbereichspräfixe in Management Studio zuweisen oder ändern. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Hinweis: Dem Basisarbeitsbereich der Anwendung (csi) kann kein Arbeitsbereichspräfix zugewiesen sein.

Vorgehensweise zum Erstellen einer Tabellendefinition während der Erstellung einer CDO-Unterklasse

Gehen Sie folgendermaßen vor, um während der Erstellung einer CDO-Unterklasse eine Tabelle zu erstellen:

1. Öffnen Sie Designer.
2. Klicken Sie auf CDOs.
3. Wählen Sie den Objekttyp aus, den Sie aus der Liste der Objekte auf der linken Seite hinzufügen möchten, und klicken Sie auf Hinzufügen. Das Fenster "Neue CDO-Definition erstellen" wird angezeigt.
4. Geben Sie einen Namen und eine Beschreibung für das neue Objekt ein.
Wichtig: Der Name darf keine Leerzeichen, unzulässigen Zeichen oder reservierten Wörter enthalten. Siehe "Gültige Zeichen und reservierte Wörter".
5. Wählen Sie eine Speicherkategorie (Storage Category) aus.

Wählen Sie eine Kategorie aus, die auch eine Tabellenkategorie ist. Wenn Sie "Modellierung" auswählen, wird der Unterklasse das Feld IsFrozen automatisch hinzugefügt, wenn das Feld durch Vererbung nicht bereits vorhanden ist.

6. Wählen Sie Neue Tabelle erstellen (Create a new Table) aus. Tabellenname und -beschreibung werden aus den CDO-Informationen automatisch übernommen.
Hinweis: Wenn das Kontrollkästchen "Neue Tabelle erstellen" (Create a new Table) deaktiviert ist, können Sie keine neue Tabelle für die ausgewählte CDO-Kategorie erstellen. Sehr wahrscheinlich ist das jeweilige CDO nicht persistent, z. B. wenn es sich um Dienst-CDOs handelt, oder Sie erstellen ein Container-CDO.
7. Klicken Sie auf Erstellen.

Zum Anzeigen der neuen Tabellendefinition klicken Sie in der Symbolleiste auf "Tabellen" (Tables). Erweitern Sie die Kategorie, in der Sie die neue Tabelle erstellt haben, und wählen Sie den Namen der erstellten Tabelle aus. Sie können die Eigenschaften der Tabelle in diesem Fenster ändern. Weitere Informationen finden Sie unter "Ändern einer Tabelle".

8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Erstellen einer Tabellendefinition mithilfe der Schaltfläche "Tabellen" (Tables)

Gehen Sie folgendermaßen vor, um eine Tabelle mithilfe der Schaltfläche "Tabellen" (Tables) zu erstellen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Tabellen (Tables). Das Fenster "Tabellendefinitionen" (Table Definitions) wird angezeigt.
3. Wählen Sie eine Tabellenkategorie aus dem linken Bereich aus.
4. Klicken Sie am unteren Rand des Bereichs auf Hinzufügen. Es wird ein neuer Tabellenname angezeigt, der umbenannt werden kann.
Hinweis: Sie können auch mit der rechten Maustaste im Bereich des Auswahlbaums klicken, um das Kontextmenü zu öffnen und Tabellendefinition hinzufügen (Add a Table Definition) auszuwählen.
5. Benennen Sie die neue Tabelle um und klicken Sie außerhalb des neuen Eintrags, um sie zu speichern.

Eine Liste der unzulässigen Zeichen und reservierten Wörter, die Sie dabei vermeiden sollten, finden Sie unter "Gültige Zeichen und reservierte Wörter".

6. Klicken Sie auf die Registerkarte Allgemein und geben Sie eine aussagekräftige Beschreibung ein.
7. Wählen Sie eine Tabellenkategorie und einen Tabellentyp aus.
8. Fügen Sie Spalten entsprechend den Anforderungen Ihres Unternehmens hinzu. Weitere Informationen finden Sie unter "Vorgehensweise zum Hinzufügen von Tabellenspalten".
Wichtig: Wenn Sie zuvor bereits eine CDO-Unterklasse erstellt haben, die diese Tabelle verwenden wird, muss für jedes der geerbten Felder in der abgeleiteten CDO-Tabelle eine Tabellenspalte vorhanden sein. Ist dies nicht der Fall, wird ein ODBC-Fehler angezeigt, der darüber informiert, dass Opcenter EX MDD oder Opcenter EX CR die Spalten für die geerbten Felder nicht finden konnte.
9. Klicken Sie außerhalb der Registerkarte, um Ihre Änderungen zu speichern.
10. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Definieren eines vorhandenen CDOs, sodass es die neue Tabelle verwendet

Gehen Sie folgendermaßen vor, um ein vorhandenes CDO so zu definieren, dass es die neue Tabelle verwendet:

1. Öffnen Sie Designer.
2. Klicken Sie auf CDOs.
3. Wählen Sie das zu konfigurierende CDO aus.
4. Klicken Sie auf die Registerkarte Allgemein des CDOs.
5. Wählen Sie im Feld Speicherkategorie (Storage Category) die entsprechende Kategorie aus.
6. Klicken Sie im Feld Daten für Tabelle persistent machen (Persist Data to Table) auf die Suchschaltfläche, um nach der gewünschten Tabelle zu suchen und sie auszuwählen.
7. Klicken Sie auf die Registerkarte Felder (Fields).
8. Öffnen Sie für jedes Feld das Fenster Eigenschaften – klicken Sie auf Ja zum Überschreiben – und gehen Sie folgendermaßen vor:
a. Klicken Sie auf die Registerkarte Allgemein.
b. Wählen Sie im Feld Spaltenname eine vorhandene Spalte aus. Falls keine Spalte vorhanden ist und Sie eine Spalte von der Anwendung erstellen lassen möchten, klicken Sie auf Neue Spalte erstellen.
Hinweis: Diese Schaltfläche ist aktiviert, wenn Sie eine Tabelle zum ersten Mal zuweisen oder wenn Sie die zugewiesene Tabelle eines CDOs ändern.
c. Klicken Sie auf OK, um das Fenster mit den Feldeigenschaften zu schließen.
9. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Entfernen einer Tabelle

Durch das Entfernen einer Tabelle in Designer wird das entsprechende Objekt in der Produktionsdatenbank nicht gelöscht. Dadurch wird verhindert, dass historische Daten verloren gehen.

Gehen Sie folgendermaßen vor, um eine Tabelle aus der Tabellenbibliothek zu entfernen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Tabellen (Tables). Das Fenster "Tabellendefinitionen" (Table Definitions) wird angezeigt.
3. Klicken Sie auf die Tabellenkategorie, in der sich die Tabelle befindet.
4. Wählen Sie die zu entfernende Tabelle aus.
5. Wenn die Schaltfläche Entfernen (Remove) deaktiviert ist, klicken Sie auf die Registerkarte Wo genutzt (Where Used) und notieren Sie sich die CDOs, die die Tabelle verwenden.
6. Verwenden Sie eine dieser Methoden, um die Tabelle verfügbar zu machen, damit sie entfernt werden kann:
• Entfernen Sie die CDOs, die die Tabelle verwenden
• Geben Sie eine andere Tabelle an, die von CDOs verwendet werden kann
Hinweis: Weitere Informationen finden Sie unter "Suchen und Entfernen von CDOs".
7. Klicken Sie auf Entfernen.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Erstellen neuer Tabellen

Gehen Sie folgendermaßen vor, um die neuen Tabellen in Ihrer Transaktionsdatenbank zu erstellen:

1. Öffnen Sie Management Studio.
2. Erweitern Sie den Knoten <Standortname>.
3. Erweitern Sie den Ordner Datenbanken.
4. Klicken Sie mit der rechten Maustaste auf die Transaktionsdatenbank und wählen Sie im daraufhin angezeigten Menü die Option Neue Datenbanktabellen erstellen aus. Das Fenster "Tabellen für <Datenbank> erstellen" (Create Tables For <database>) wird angezeigt.
5. Lassen Sie alle Kontrollkästchen aktiviert.
6. Klicken Sie auf OK. Die Anwendung erstellt die neuen Tabellen, schließt das Fenster "Tabellen für <Datenbank> erstellen" (Create Tables For <database>) und zeigt eine Meldung an, dass die neue Datenbank erfolgreich erstellt wurde.
