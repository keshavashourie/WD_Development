Registerkarte "Spalten"

Auf der Registerkarte "Spalten" werden die Namen und Beschreibungen der Spalten aufgelistet. Das Schlüsselsymbol neben einem Spaltennamen weist auf einen primären Schlüssel hin.

Schaltflächendefinitionen der Registerkarte "Spalten"

Diese Tabelle definiert die Schaltflächen auf der Registerkarte "Spalten".

Schaltfläche

Funktion der Schaltfläche . . .

Hinzufügen

Öffnen des Fensters "DB-Spalteneigenschaften" (DB Column Properties), in dem Sie die Eigenschaften der Spalte definieren, die Sie hinzufügen möchten.

Entfernen

Entfernen der von Ihnen erstellten Spalte.

Eigenschaften

Öffnen des Fensters "DB-Spalteneigenschaften" (DB Column Properties) und Anzeigen oder Aktualisieren der Eigenschaften der ausgewählten Spalte.

Fenster DB-Spalteneigenschaften (DB Column Properties)

Durch Klicken auf die Schaltfläche "Hinzufügen" oder "Eigenschaften" wird das Fenster "DB-Spalteneigenschaften" (DB Column Properties) geöffnet. Im Fenster "DB-Spalteneigenschaften" (DB Column Properties) können Sie Eigenschaften einer ausgewählten Spalte definieren oder aktualisieren.

Felddefinitionen des Fensters "DB-Spalteneigenschaften" (DB Column Properties)

Diese Tabelle definiert die Felder im Fenster "DB-Spalteneigenschaften" (DB Column Properties).

Feld

Definition

Typ

Spaltenname (Column Name)

Der Name der Datenbankspalte.

Erforderlich

Beschreibung

Dokumentation, die beschreibt, wie diese Spalte innerhalb der DB-Tabelle verwendet wird.

Optional

Datentyp

ODBC-Datentyp der Spalte.

Erforderlich

Genauigkeit

Maximale Länge (Zeichenkette) oder die maximale Anzahl der Stellen links vom Dezimalzeichen für die Daten in der Spalte, die dieser Eintrag beschreibt.

Erforderlich

Waage

Maximale Anzahl der Stellen rechts vom Dezimalzeichen für die Daten in der Spalte, die dieser Eintrag beschreibt.

Erforderlich

Verwendung der Spalte (Column Usage)

Gibt eine spezielle Verarbeitung an, die dieser Spalte zugeordnet ist (z. B. "InstanceID"). Jeder Wert bezieht sich auf eine bestimmte Verarbeitung, die im System implementiert ist.

Erforderlich

Details

Schlüsselreihenfolge (Key Sequence)

Durch Eingabe einer Zahl ungleich 0 wird diese Spalte Teil des primären Schlüssels für diese Tabelle. Die Zahl entspricht der Reihenfolge, in der diese Spalte innerhalb des (möglicherweise mehrteiligen) Schlüssels liegt.

Erforderlich

Registerkarte "Wo genutzt" (Where Used) im Fenster "DB-Spalteneigenschaften" (DB Column Properties)

Klicken Sie auf die Registerkarte "Wo genutzt" (Where Used) und aktivieren Sie das Kontrollkästchen Anzeigen, wo diese Spalte verwendet wird (Show where this column is used), um das Feld "CDO" anzuzeigen, das diese Spalte verwendet.
