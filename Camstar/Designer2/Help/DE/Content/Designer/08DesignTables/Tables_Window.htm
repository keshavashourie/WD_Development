Fenster "Tabellen" (Tables)

Tabellen werden in Opcenter EX MDD und Opcenter EX CR zum Speichern persistenter Daten verwendet.

Beim Erstellen einer Tabelle über Designer erstellen Sie tatsächlich eine Tabellendefinition, die in der Transaktionsdatenbank zu einer Tabelle wird. Weitere Informationen zum Erstellen von Tabellendefinitionen und Tabellen finden Sie unter "Hinzufügen und Entfernen einer Tabelle".

Durch Klicken auf die Schaltfläche "Tabellen" (Tables) in der Symbolleiste wird das Fenster "Tabellen" (Tables) geöffnet, in dem Sie die Eigenschaften einer ausgewählten Tabelle anzeigen können.

Der Auswahlbaum enthält Tabellenkategorien. Weitere Informationen finden Sie unter "Tabellenkategorien".

Wählen Sie eine Tabellenkategorie aus und klicken Sie mit der rechten Maustaste, um das Kontextmenü mit den folgenden Optionen anzuzeigen:

• Tabellendefinition hinzufügen (Add Table Definition)
• Tabellendefinition umbenennen (Rename Table Definition)
• Tabellendefinition suchen (Find Table Definition)
• Tabellendefinition entfernen (Remove Table Definition)

"Tabellendefinition umbenennen" (Rename Table Definition) und "Tabellendefinition entfernen" (Remove Table Definition) sind nur für benutzerdefinierte Tabellendefinitionen aktiv.

Im Fenster "Tabellen" (Tables) befinden sich vier Registerkarten:

• Registerkarte "Allgemein"
• Registerkarte "Spalten"
• Registerkarte "Indizes" (Indexes)
• Registerkarte "Wo genutzt" (Where Used)
