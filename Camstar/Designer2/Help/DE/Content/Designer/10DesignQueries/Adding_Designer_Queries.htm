Hinzufügen von Designer-Abfragen

Sie können benutzerdefinierte Abfragen hinzufügen, die Anweisungen und Objektdefinitionen in Designer verwenden.

Beim Hinzufügen von Designer-Abfragen

Arbeitsbereichspräfixe werden beim Hinzufügen eines neuen Elements automatisch vor dem Namen des Elements eingefügt, sofern dem höchsten aktiven Arbeitsbereich ein Präfix zugewiesen wurde. Arbeitsbereichspräfixe geben an, auf welchen Arbeitsbereich Designer Änderungen anwendet. Dem Arbeitsbereich würde z. B. das Präfix "C200" zugeordnet werden, wenn für diesen in Management Studio das Präfix "C200" festgelegt wurde. Es wird empfohlen, beim Hinzufügen neuer Elemente die von Designer bereitgestellten Präfixe zu verwenden.

Sie können Arbeitsbereichspräfixe in Management Studio zuweisen oder ändern. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Hinweis: Dem Basisarbeitsbereich der Anwendung (csi) kann kein Arbeitsbereichspräfix zugewiesen sein.

Vorgehensweise zum Hinzufügen einer Abfrage

Gehen Sie folgendermaßen vor, um eine Abfrage hinzuzufügen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Abfragen (Queries). Das Fenster "Abfragedefinition" (Query Definition) wird angezeigt.
3. Wählen Sie im linken Bereich eine Abfragekategorie aus und klicken Sie auf Hinzufügen.
4. Geben Sie einen Abfragenamen ein.
5. Klicken Sie auf die Registerkarte Allgemein und geben Sie eine Beschreibung für die Abfrage ein.
6. Klicken Sie auf die Registerkarte Details.
7. Wählen Sie die entsprechende Datenbank aus.
8. Geben Sie den gewünschten Abfragetext in den Bereich Abfragetext (Query Text) ein.
Hinweis: Sie können die Schaltflächen für die Anweisungen SELECT, FROM, WHERE usw. am unteren Rand des Bereichs "Abfragetext" (Query text) verwenden, um Ihren Abfragetext schneller einzugeben. Sie können auch eine Objektdefinition aus dem Auswahlbaum auswählen, um die Objektfelder anzuzeigen. Doppelklicken Sie auf einen Objekt- oder Feldnamen, um ihn in den Abfragetext einzugeben.
9. Optional können Sie auch eine andere Datenbank aus der Liste auswählen und einen Abfragetext für diese Datenbank eingeben.
10. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
