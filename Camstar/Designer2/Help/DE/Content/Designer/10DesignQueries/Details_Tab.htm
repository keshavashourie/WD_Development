Registerkarte "Details"

Die Registerkarte "Details" zeigt die Abfrageanweisung für die ausgewählte Abfrage an. Verwenden Sie diese Registerkarte, wenn Sie eine Abfrageanweisung aktualisieren möchten.

Felddefinitionen der Registerkarte "Details"

Diese Tabelle definiert die Felder auf der Registerkarte "Details".

Feld

Definition

Datenbank

Abfragen, deren Syntax für alle unterstützten Datenbanken identisch ist, umfassen einen einzelnen Abfragetexteintrag unter dem Standarddatenbankeintrag.

Abfragen, die datenbankspezifische Syntax erfordern, enthalten auch Abfragetext für mindestens eine der spezifischen Datenbanken. Wenn der datenbankspezifische Abfragetext nicht für eine bestimmte Datenbank bereitgestellt wurde, verwendet das System den Standardabfragetext.

Verwenden Sie die Datenbankliste, um anzugeben, welchen Abfragetext Sie anzeigen oder ändern möchten.

Abfragetext

Enthält die Abfrageanweisungen. Verwenden Sie die Schaltflächen unter dem Feld, um häufig verwendete Wörter und Symbole in Abfrageanweisungen einzufügen, anstatt sie einzugeben.

Der Standardbegrenzung für dieses Feld beträgt 4.000 Zeichen. Diese Standardeinstellung wird durch das Feld "Genauigkeit" (Precision) im Fenster "DB-Spalteneigenschaften" (DB Column Properties) auf der Registerkarte "Spalten" bestimmt.

Diese Tabelle definiert die Felder auf der Registerkarte "Details" für erweiterte und CDO-Abfragen.

Feld

Definition

Objektdefinitionen

Enthält alle in Opcenter EX MDD und Opcenter EX CR vorhandenen Objekte. Wenn Sie Ihre eigenen vordefinierten Abfragen erstellen, können Sie eine Objektdefinition auswählen. Die CDO-Felder werden dann im Listenfeld "Felder" (Fields) angezeigt.

Felder

Zeigt die Felder des Objekts an, das im Listenfenster "Objektdefinitionen" (Object definitions) ausgewählt ist. Verwenden Sie dieses Feld, um den Text der vordefinierten Abfrage zu erstellen.
