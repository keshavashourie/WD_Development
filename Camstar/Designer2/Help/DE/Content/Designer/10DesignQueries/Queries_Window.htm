Fenster "Abfragen" (Queries)

Durch Klicken auf die Schaltfläche "Abfragen" in der Symbolleiste wird das Fenster "Abfragedefinition" (Query Definition) geöffnet.

Fensterbereiche

Das Fenster "Abfragedefinition" (Query Definition) ist in einen linken und einen rechten Bereich unterteilt.

Der linke Bereich enthält einen Auswahlbaum mit den Abfragekategorien: erweiterte Abfragen, CDO-Abfragen, NonQuery SQL-Anweisungen und SQL-Abfragen. Sie können jede Kategorie erweitern, um die Abfragen innerhalb dieser Kategorie anzuzeigen.

Sie können auch ein Kontextmenü aufrufen, indem Sie mit der rechten Maustaste in den linken Bereich klicken. Optionen im Kontextmenü:

• Abfragedefinition hinzufügen (Add Query Definition)
• Umbenennen der Abfragedefinition (Rename Query Definition) (für die Standardabfragen deaktiviert)
• Abfragedefinition suchen (Find Query Definition)
• Abfragedefinition entfernen (Remove Query Definition) (für Standardabfragen deaktiviert)
• Abfragedefinition kopieren (Copy Query Definition) (aktiviert, wenn Sie eine Kategorie erweitern und eine Abfrage auswählen)

Der rechte Bereich enthält Registerkarten, von denen jede bestimmte Details zur ausgewählten Abfrage anzeigt. Namen der Registerkarten:

• Registerkarte "Allgemein"
• Registerkarte "Details"
• Registerkarte "Parameter"
• Registerkarte "Wo genutzt" (Where Used)

Dem Abfragenamen ist im Auswahlbaum ein Fragezeichen vorangestellt. Zwei Fragezeichen vor dem Abfragenamen bedeuten, dass für Szenarien, in denen verschiedene Datenbanktypen jeweils eine andere Abfragesyntax erfordern, mehrere Versionen der Abfrageanweisung definiert wurden.

Typ "NonQuery SQL-Anweisungen"

Der Designer-Typ "NonQuery SQL-Anweisungen" wird verwendet, wenn SQL-Anweisungen ausgeführt werden, die keine SELECT-Anweisungen sind. Die Funktion "Massenaktualisierung" (Mass Update) kann z. B. UPDATE-Anweisungen oder gespeicherte Vorgehensweisen als Teil der Geschäftslogik verwenden.

Verwenden Sie für Oracle einen anonymen Block, indem Sie die gespeicherte Vorgehensweise in BEGIN und END einschließen:

BEGIN MyStoreProcedure (?Parm1,?Parm2); END

Zum Aufrufen einer gespeicherten Vorgehensweise in SQL Server verwenden Sie die EXEC-Syntax ohne Klammern:

EXEC MyStoredProcedure ?Parm1,?Parm2;

Der Typ "NonQuery SQL-Anweisungen" kann nur als Designer-Abfrage und nicht als Benutzer- oder Ad-hoc-Abfrage definiert und ausgeführt werden.
