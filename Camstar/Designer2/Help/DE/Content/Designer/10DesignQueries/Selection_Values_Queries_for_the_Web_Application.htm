Abfragen mit Auswahlwerten für das Portal

Anforderungen

Im Portal gelten beim Erstellen von Abfragen mit Auswahlwerten bestimmte Regeln. Die Spalten in dieser Tabelle müssen für eine bestimmte Abfrage vorhanden sein, damit das Portal die Abfragen ordnungsgemäß verarbeitet.

Abfrage

Spalte

SelectionValuesEx_NDO

InstanceID, Name

SelectionValuesEx_RDO

InstanceID, Name, Revision, RevOfRcd, Status

SelectionValuesEx_NSEofNDO

InstanceID, Name

SelectionValuesEx_NSEofRDO

InstanceID, Name

Beispiele

Wenn Sie die Operation abrufen und die Spalte für den Namen "OperationName" lautet, müssen Sie diese mit der folgenden SQL-Anweisung abrufen:

Select OperationName As "Name" From Operation

Filter-Tags

Viele Abfragen mit Auswahlwerten enthalten standardmäßig Filter-Tag-Logik. Sie können Filter-Tag-Logik zu anderen Auswahlwerten und zu benutzerdefinierten Abfragen hinzufügen, indem Sie diesen Code in die Where-Klausel einschließen, wobei "$$cdo" ein Alias für das in der Abfrage referenzierte CDO ist:

a. ##csiFilterTagMatch($$cdo.FilterTags, ? __filterTags, ? __allowUntaggedInstances) = 1

Wichtig: Wenn Sie einen Filter-Tag löschen oder Filter-Tag-Logik entfernen, können Instanzen, die den gelöschten Tag oder die entfernte Logik referenzieren, in der Anwendung unbrauchbar werden.
