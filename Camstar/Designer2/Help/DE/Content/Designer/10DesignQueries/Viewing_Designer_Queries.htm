Anzeigen von Designer-Abfragen

Sie können Abfragen anzeigen, indem Sie in der Symbolleiste auf die Schaltfläche "Designer-Abfragen" (Designer Queries) klicken. Zum Erstellen von Abfragen müssen Sie mit SQL-Anweisungen vertraut sein.

Vorgehensweise zum Anzeigen von Abfragen

Gehen Sie folgendermaßen vor, um Abfragen anzuzeigen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Abfragen (Queries). Das Fenster "Abfragedefinition" (Query Definition) wird angezeigt. Hier sind Designer-Abfragen gespeichert.
3. Klicken Sie auf das Pluszeichen (+) neben einer Kategorie, um sie zu erweitern.
4. Wählen Sie die anzuzeigende Abfrage aus. Die Abfrageanweisungen für die ausgewählte Abfrage werden im oberen Bereich auf der rechten Seite angezeigt. Die verschiedenen Tabellen und die entsprechenden Spalten werden im unteren Bereich der Registerkarte "Details" angezeigt.
