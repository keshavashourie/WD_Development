Registerkarte "Parameter"

Auf der Registerkarte "Parameter" werden die Parameter der ausgewählten Abfrage angezeigt.

Felddefinitionen der Registerkarte "Parameter"

Diese Tabelle definiert die Felder auf der Registerkarte "Parameter".

Feld

Definition

Typ

Abfragetext

Zeigt den Text der Abfrage so an, wie er auf der Registerkarte "Details" angezeigt wird.

Nur Anzeige

Name

Enthält den Namen dieses Parameters, der während der Laufzeit Parameterwerte (in Name-Wert-Paaren) zur Verfügung stellt. Der Name muss im Kontext der zugeordneten Abfragedefinition eindeutig sein. Wenn Sie einen Parameter aus der Liste auswählen, wird sein Vorkommen in der Abfrage blau markiert.

Nur Anzeige

Typ

Gibt den Datentyp des Parameters an.

Nur Anzeige

Eingabe (Input)

Gibt an, ob der Abfrageparameter ein Eingabetyp ist.

Nur Anzeige

Parameterdetails (Parameter details)

Name

Zeigt den Namen des Parameters an.

Optional

Datentyp

Zeigt den Datentyp an, der diesem Parameter zugewiesen ist, z. B. "Boolesch" (Boolean) oder "Zeichenkette".

Optional

Listenfeld

Zeigt das Listenfeld an, das diesem Parameter zugewiesen ist.

Optional

Sie können den Parameternamen und den Datentyp benutzerdefinierter Abfragen im Bereich "Parameterdetails" (Parameter Details) ändern. Wenn der Parameter ein Objekt ist, verwenden Sie den Datentyp "Objekt" (Object). Andernfalls konvertiert der Server das Objekt nicht in eine hexadezimale ID.
