Anmelden und Starten von Designer

Siemens stellt drei Standardanmeldungen für Mitarbeiter zur Verfügung: "CamstarAdmin", "Administrator" und "InSiteAdmin". Diese Benutzer müssen über ein gültiges Windows-Konto verfügen, wenn Sie einen davon als Standardanmeldung für Designer verwenden möchten.

Vor dem Anmelden bei Designer

Der Zugriff auf Designer basiert auf der Windows-Sicherheit. Gewährleisten Sie, dass Designer-Benutzer ein gültiges Windows-Konto haben und als Designer-Benutzer in Management Studio hinzugefügt wurden. Weitere Informationen zum Hinzufügen von Benutzern zu Designer finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Der Siemens License Server muss installiert sein und ausgeführt werden, und die Sicherheitsdienste müssen ausgeführt werden. Weitere Informationen zum Starten von Diensten finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung oder in der Opcenter Execution Core-Installationsanleitung.

Beim Anmelden bei und Starten von Designer

Das Anmeldefenster für Designer weist standardmäßig den Namen auf, der für die Anmeldung am Server bei der ersten Anmeldung bei Designer verwendet wurde. Das Anmeldefenster für Designer zeigt bei künftigen Anmeldeversuchen standardmäßig den Namen und das Kennwort des vorherigen Designer-Benutzers an.

Der Benutzer muss in Designer kein Kennwort eingeben, wenn sein Designer-Benutzername mit dem Benutzernamen übereinstimmt, der für die Anmeldung am Server verwendet wurde. Der Benutzer muss jedoch in Designer ein Kennwort eingeben, wenn sich der Designer-Benutzername vom Benutzernamen für die Windows-Anmeldung unterscheidet.

Wenn CSI der höchste aktive Arbeitsbereich ist, wird eine Fehlermeldung angezeigt und Sie können sich nicht bei Designer anmelden. Sie müssen einen anderen Arbeitsbereich in Management Studio aktivieren und sich anschließend bei Designer anmelden. Weitere Informationen zum Aktivieren von Arbeitsbereichen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und in der Opcenter Execution Core-Anleitung zur Systemadministration.

Vorgehensweise zum Anmelden bei Designer

Gehen Sie folgendermaßen vor, um sich bei Designer anzumelden:

1. Klicken Sie auf Start > Opcenter Execution MDD > Designer. Das Anmeldefenster für Designer wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Designer. Das Anmeldefenster für Designer wird angezeigt.

2. Behalten Sie den aktuellen Benutzernamen bei oder geben Sie einen autorisierten Designer-Benutzernamen ein.
3. Geben Sie Ihr Kennwort ein.
4. Überprüfen Sie die Pfade zu den MDBs. Geben Sie die entsprechenden Pfade ein, wenn die Datenbanken in ein anderes Verzeichnis verschoben wurden.
5. Klicken Sie auf Anmelden. Das Designer-Hauptfenster wird angezeigt.
