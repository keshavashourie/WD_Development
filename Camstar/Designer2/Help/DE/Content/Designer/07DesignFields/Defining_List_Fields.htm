Definieren von Listenfeldern

Ein Feld ist als Listenfeld definiert, wenn Sie im Fenster "Neues CDO-Feld hinzufügen" (Add a New CDO Field) die Schaltfläche "Feld ist eine Liste" (Field is a list) aktivieren. Sie können eine Liste von Objekten entweder statisch oder dynamisch speichern, wenn die Liste der Objekte innerhalb von Daten-CDOs vorliegt.

Festlegen von Werten

Eine Liste von Objekten wird durch eine Liste von Objektinstanz-IDs dargestellt. Diese Liste kann entweder in einer separaten Tabelle gespeichert oder dynamisch erstellt werden, wenn die Beziehung zwischen den Objekten bereits vorhanden ist.

Dynamisches Abrufen

Im Idealfall sollten Sie das dynamische Abrufen verwenden, da diese Liste keine separate Tabelle für die Liste erfordert. Ohne separate Tabelle wird weniger Datenbankspeicherplatz benötigt.

Das Objekt, das das Listenfeld enthält, referenziert ein Objekt, das eine Liste von Objekten enthält. Es ist ein einzelnes Feld, auf dessen Basis die Sortierung für diesen Abfragetyp vorgenommen wird.

Vorgehensweise zum Anzeigen der Einstellungen für dynamisches Abrufen

Gehen Sie folgendermaßen vor, um die Einstellungen für dynamisches Abrufen anzuzeigen:

Wichtig: Das Listenfeld muss den Datentyp Objekt (Object) aufweisen.
1. Wählen Sie im Fenster "CDO-Definition" (CDO Definition) ein CDO aus und klicken Sie anschließend auf die Registerkarte Felder (Fields).
2. Wählen Sie das Listenfeld aus, für das Sie die Einträge dynamisch abrufen können.

In diesem Beispiel wird das Feld Produkte (Products) für das ProductFamily-CDO verwendet.

3. Klicken Sie auf Eigenschaften am unteren Rand der Registerkarte Felder (Fields). Das Fenster "CDO-Feldeigenschaften" (CDO Field Properties) wird angezeigt.
4. Klicken Sie auf die Registerkarte Allgemein. Die Registerkarte "Allgemein" wird angezeigt.
Hinweis: "Feld ist eine Liste" (Field is a list) ist aktiviert und kann nicht geändert werden. Diese Einstellung eignet sich für Felder, die für das dynamische Abrufen der Liste konfiguriert sind. "Listeneinträge werden dynamisch abgerufen" (List entries are retrieved dynamically) ist ausgewählt. Auch dies ist erforderlich.

Auf der Registerkarte befinden sich drei Felder mit Listen am unteren Rand:

• Feld aus <CDO>, mit dem beim Erstellen der Liste eine Übereinstimmung erforderlich ist (Field from <CDO> to match when building list)
Dies ist der Name des Felds im CDO ("Product" in diesem Fall, da dies der Feldtyp ist), der als Grundlage für die Erstellung eines Listenfelds dient. In diesem Beispiel wird das Feld "ProductFamily" des Produkt-CDOs angezeigt.
• Feld aus <CDO>, mit dem beim Erstellen der Liste eine Übereinstimmung erforderlich ist (Field from <CDO> to match when building list)
Dies ist das Feld, das sich im Basisobjekt befindet ("ProductFamily" in diesem Fall), mit dem das Feld im Listenobjekt übereinstimmen muss. Dies ist das übereinstimmende Kriterium und das Kriterium definiert die Beziehung zwischen den beiden Objekten. In diesem Beispiel wird "InstanceID of ProductFamily from" angezeigt.
• Feld aus <CDO>, das beim Sequenzieren der Liste verwendet wird (Field from <CDO> to use when sequencing list)
Dies ist das Feld, das sich im Basisobjekt befindet ("Product" in diesem Fall), das Sie zu Sortierungszwecken verwenden möchten. In diesem Beispiel wird "ProductBase.Name of Product" angezeigt. "Product" ist ein revisioniertes Objekt und dies ist die Basis, die für das Objekt verwendet wird. Wenn es sich hierbei um eine Liste für benannte Datenobjekte handeln würde, wäre es die Instanz-ID.
Hinweis: Das <CDO> in den Überschriften für diese drei Listenfelder ändert sich abhängig von der Auswahl.
5. Klicken Sie auf OK.

Statisches Abrufen einer Liste

Für das statische Abrufen des Listeneintrags ist eine neue Tabelle erforderlich. Die neue Tabelle dient zum Warten und Speichern der Listeneinträge, die entweder gewartet oder beibehalten werden müssen (z. B. wenn die Reihenfolge in einer Liste unverändert bleiben soll). Dies kann in folgenden Fällen erforderlich sein:

• Sie benötigen eine Liste, um die Reihenfolge der Objekte zu verwalten.
• Eine Liste weist eine Viele-zu-viele-Beziehung auf.
• Eine Liste enthält eine Liste mit Datenwerten (im Gegensatz zu einer Liste mit Referenzen auf vorhandene Objekte).

Vorgehensweise zum Festlegen der Werte für statisches Abrufen

Gehen Sie folgendermaßen vor, um die Werte für statisches Abrufen festzulegen:

1. Wählen Sie ein CDO im Fenster CDO-Definition (CDO Definition) aus und klicken Sie anschließend auf die Registerkarte Felder (Fields).
2. Wählen Sie das Listenfeld aus, für das Sie die Einträge statisch abrufen können.
3. Klicken Sie auf Eigenschaften, um das Fenster CDO-Feldeigenschaften (CDO Field Properties) anzuzeigen.
4. Klicken Sie auf die Registerkarte Allgemein. Die Option "Feld ist eine Liste" (Field is a list) ist ausgewählt.
5. Klicken Sie auf Neue Tabelle erstellen (Create a New Table). Ein Standardtabellenname und ein Standardspaltenname werden angezeigt.
6. Benennen Sie die Tabelle und die Spalte um und verwenden Sie dabei aussagekräftige Namen.
7. Klicken Sie auf OK.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
