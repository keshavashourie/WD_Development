Anzeigen von Feldauswahlwerten

Felder können so konfiguriert werden, dass Sie eine Liste von Werten anbieten, die über eine Opcenter EX MDD- oder Opcenter EX CR-Auswahlwertabfrage abgerufen werden, aus der ein Benutzer einen Wert auswählen kann. Auf der Registerkarte "Auswahlwerte" (Selection Values) können Sie die am häufigsten verwendeten Optionen für die Generierung der Auswahlwerte für ein Feld auswählen. Opcenter EX MDD und Opcenter EX CR hängen automatisch den entsprechenden Auswahlwerte-CLF an das Feld an.

Wenn an das Feld bereits ein Auswahlwerte-CLF angehängt wurde, wird dieser CLF-Name in der Liste der Auswahlwertoptionen angezeigt.

Auswahlwerte werden im Dienstobjekt oder im Änderungsobjekt festgelegt. Es gibt zwei Gruppen von Auswahlwerten:

• Grundlegend
Grundlegende Auswahlwerte werden mit ServerLink, dem InSite COM-Client, verwendet. Sie werden ausschließlich beibehalten, um die Rückwärtskompatibilität zu gewährleisten, damit die aktuellen Benutzer genügend Zeit haben, um ihre Auswahlwerte mit den erweiterten Auswahlwerten neu zu definieren. Verwenden Sie die erweiterten Auswahlwerte für neue Definitionen in Opcenter EX MDD oder Opcenter EX CR.
• Erweitert (Extended)
Für Felder mit definierten Auswahlwerten sind auf der Registerkarte "Auswahlwerte" (Selection Values) erweiterte Auswahlwerte die Standardeinstellung. Viele, doch nicht alle, Abfragenamen für erweiterte Auswahlwerte beginnen mit "SelectionValuesEx". Erweiterte Auswahlwerte verwenden den XML-Anwendungsserver für die Verarbeitung und werden nicht von ServerLink unterstützt.

Es stehen fünf Optionen zur Bestimmung der Auswahlwerte zur Verfügung:

• Statische Auswahlwerte (Static Selection Values)
• Abfrageauswahlwerte (Query Selection Values)
• Listenfeld-Auswahlwerte (List Field Selection Values)
• Aufzählungsauswahlwerte (Enumeration Selection Values)
Hinweis: Erweiterte Auswahlwerte sind standardmäßig statisch, wenn Sie einem Modellierungsänderungs-CDO oder einem Fertigungsdienst-CDO ein NDO-, RO- oder ein Nummerierungsfeld hinzufügen.

Beachten Sie, dass dieses Feld, "TextVariableChanges.VariableUsage", ein CDO-Feld ist und seine Auswahlwerte bereits durch die Aufzählungsmethode bestimmt wurden. Seine Schlüsselwerte (zu Speicherungszwecken) und seine Anzeigezeichenketten sind bereits definiert. Sie können eine beliebige Anzeigezeichenkette ändern, indem Sie dieses Feld erneut in dieses Fenster eingeben, wobei einige Felder eingegebene Literale (Anführungszeichen sind nicht erforderlich) und andere Feldnamen enthalten.

• CLF-Auswahlwerte (CLF Selection Values)
Die Optionen für Auswahlwerte, die über dieses Fenster verfügbar sind, werden in den folgenden Abschnitten erläutert.

Statische Auswahlwerte (Static Selection Values)

Dieses Thema erläutert, wie die Option "Statische Auswahlwerte" (Static Selection Values) zum Anzeigen aller Instanzen von Objekten verwendet wird, die den gleichen Feldtyp aufweisen. Mit der Option "Statisch" (Static) können Sie die Auswahlwertabfrage nicht ändern. Sie verwendet die Auswahlwertedefinition des Feldtyps.

Wenn Sie ein CDO hinzufügen, wird es auch als Feldtyp innerhalb des Objektdatentyps hinzugefügt. Wenn Sie einen Auswahlwert für das CDO im Fenster "CDO-Definition" (CDO Definition) festlegen, wird dieser Auswahlwert zum Auswahlwert dieses Feldtyps.

Der Eintrag im Feld "Auswahlwertabfrage" (Selection Values Query) ändert sich abhängig vom Feldtyp.

Vorgehensweise zum Anzeigen der Option "Statische Auswahlwerte" (Static Selection Values)

Gehen Sie folgendermaßen vor, um die Option "Statische Auswahlwerte" (Static Selection Values) in Designer anzuzeigen:

1. Wählen Sie das CDO aus, das das gewünschte Feld enthält.
2. Klicken Sie auf die Registerkarte Felder (Fields) für dieses CDO im Fenster CDO-Definition (CDO Definition).
3. Wählen Sie das gewünschte Feld im CDO aus.
4. Klicken Sie auf der Registerkarte "Felder" (Fields) auf die Schaltfläche Eigenschaften. Das Fenster "CDO-Feldeigenschaften" (CDO Field Properties) wird angezeigt.
5. Klicken Sie auf die Registerkarte Auswahlwerte (Selection Values) im Fenster CDO-Feldeigenschaften (CDO Field Properties).
6. Klicken Sie auf Abbrechen, um das Fenster zu schließen.

Abfrageauswahlwerte (Query Selection Values)

Diese Option erlaubt Ihnen die Definition der Auswahlwerte eines Felds basierend auf einer Abfrage. Diese Tabelle definiert die verschiedenen Abfragen.

Abfrage

Definition

ContainerHistoryMainlines_ASCEx

Ruft HistoryMainline-Einträge für einen bestimmten Container ab und sortiert sie so, dass die ältesten Transaktionen zuerst angezeigt werden.

ContainerHistoryMainlines_DescEx

Ruft HistoryMainline-Einträge für einen bestimmten Container ab und sortiert sie so, dass die letzten Transaktionen zuerst angezeigt werden.

GetContainersForMfgOrder

Ruft alle Containernamen für einen bestimmten Produktionsauftrag ab.

GetHistoryObjects

Gibt die Historienobjekte zurück. Diese Option wird von der Anwendung Audit Trail verwendet.

GetLabelIDbyCategoryValueNameFilter

Ruft alle Beschriftungs-IDs basierend auf der angegebenen Kategorie-ID, dem Wertefilter und dem Namensfilter ab.

GetLocalSite

Ruft die Instanz-ID des lokalen Standorts ab.

MfgCalShiftMaint_LoadShifts

Lädt eine Teilmenge von CalendarShift, basierend auf MfgCalendar und dem Start-/Ende-Zeitstempel.

SelectionValuesEx_AllQueryDefs

Ruft alle Auswahlwerte für alle Abfragedefinitionen nach Abfragenamen ab.

SelectionValuesEx_AssociateCandidates

Ruft eine Liste von Containern ab, die dem angegebenen Container zugeordnet werden dürfen.

SelectionValuesEx_CombineCandidates

Ruft eine Liste von Kind-Containern ab, die mit dem angegebenen Container kombiniert werden dürfen.

SelectionValuesEx_DisassociateCandidates

Ruft eine Liste von Kind-Containern ab, deren Zuordnung zum angegebenen Container aufgehoben werden darf.

SelectionValuesEx_Enumeration

Ruft Aufzählungsobjekte ab.

SelectionValuesEx_IssueActuals_FromContainer

Ruft Container ab, die für den ausgewählten Container verbraucht werden dürfen. Zurückgegebene Container entsprechen den folgenden Kriterien: sie wurden nicht angehalten, sie sind aktiv und das Attribut "Produkt" (Product) stimmt mit dem Produkt des Stücklisteneintrags (oder einem gültigen Ersatz) überein.

SelectionValuesEx_LabelCategory

Ruft die Auswahlwerte des Felds "Kategorie" von "DictionaryMaint" basierend auf der Metatabelle "LabelCategory" ab.

SelectionValuesEx_NDO

Ruft die Auswahlwerte eines benannten Datenobjekts ab.

SelectionValuesEx_NSEofNDO

Ruft die Auswahlwerte eines benannten Unterobjekts ab, dessen Elternobjekt den Typ "Benanntes Datenobjekt" (Named Data Object) aufweist.

SelectionValuesEx_NSEofRDO

Ruft die Auswahlwerte eines benannten Unterobjekts ab, dessen Elternobjekt den Typ "Revisioniertes Objekt" (Revisioned Object) aufweist.

SelectionValuesEx_RDO

Ruft die Auswahlwerte eines revisionierten Objekts ab.

SelectionValuesEx_Resource

Ruft eine Liste aller Ressourcen ab.

SelectionValuesEx_SplitCandidates

Ruft eine Liste von Kind-Containern ab, die vom angegebenen Container abgeteilt werden dürfen.

Weitere Informationen zum Definieren von Abfragen finden Sie unter "Abfragen".

Listenfeld-Auswahlwerte (List Field Selection Values)

Listenfeld-Auswahlwerte werden verwendet, um eine Werteliste für ein Listenfeld abzurufen. Opcenter EX MDD und Opcenter EX CR verwenden CLFs, um die Liste abzurufen, und verfügen bei Verwendung der Option "Listenfeld" über kein Standardbeispiel für ein Feld. Mit der folgenden Vorgehensweise wird veranschaulicht, wie Auswahlwerte basierend auf einem angegebenen Listenfeld eingerichtet werden. Das Beispiel verwendet ein benutzerdefiniertes Feld, das eine Liste von benannten Datenobjekten referenziert.

Vorgehensweise zum Verwenden der ListField-Option "Erweiterte Auswahlwerte" (Extended Selection Values)

Gehen Sie folgendermaßen vor, um die ListField-Option "Erweiterte Auswahlwerte" (Extended Selection Values)" in Designer zu verwenden:

1. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
2. Wählen Sie das CDO aus, für dessen Listenfeld Sie Auswahlwerte festlegen möchten.
3. Wählen Sie die Registerkarte Felder (Fields) aus, sofern sie noch nicht ausgewählt ist.
4. Wählen Sie das Listenfeld aus und klicken Sie auf Eigenschaften. Das Fenster "CDO-Feldeigenschaften" (CDO Field Properties) wird angezeigt.
5. Wählen Sie die Registerkarte Auswahlwerte (Selection Values) aus.
6. Wählen Sie Listenfeld: Auswahlwerte basieren auf einem angegebenen Listenfeld (ListField: selection values are based on a specified list field) aus der Liste aus.
7. Geben Sie einen Ausdruck in das Feld mit der Beschriftung Feldausdruck für das Listenfeld (Field expression for the list field) ein.

Oder

8. Klicken Sie auf Erstellen (Build), um den Ausdrucks-Builder zu öffnen. Weitere Informationen finden Sie unter "Vereinheitlichte Ausdrücke".
9. Wählen Sie ein Feld aus der Liste unter Verfügbare Felder (Available Fields) aus und klicken Sie dann auf Hinzufügen, um zusätzliche Informationen für jedes Objekt in der Liste hinzuzufügen. Das Feld wird zur Liste "Einzuschließende Felder" (Fields to include) hinzugefügt.
10. Geben Sie den Ausdruck in Verfügbare Felder (Available Fields) ein, um einen Feldausdruck hinzuzufügen.

Oder

11. Klicken Sie auf Erstellen (Build), um den Ausdrucks-Builder zu öffnen.
12. Klicken Sie auf Hinzufügen, um den Ausdruck zur Liste Einzuschließende Felder (Fields to include) hinzuzufügen.
Hinweis: Wenn das referenzierte Objekt ein NDO ist, lauten die einzuschließenden Felder "Name" und "InstanceID". Wenn das Objekt ein RO ist, lauten die Felder "Name", "Revision", "RevOfRcd", "InstanceID" und "Status".
13. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Anzeigen der Option "Auswahlwertaufzählung" (Selection Values Enumeration)

Gehen Sie folgendermaßen Sie vor, um die Option "Auswahlwertaufzählung" (Selection Values Enumeration) anzuzeigen:

1. Wählen Sie das CDO aus.

In diesem Beispiel ist Enterprise ausgewählt.

6. Wählen Sie die Methode zum Bestimmen der Auswahlwerte aus.

In diesem Beispiel ist Aufzählung: Auswahlwerte basieren auf einer statischen Liste mit (Wert, Anzeigezeichenkette)-Paaren (Enumeration: selection values are based on a static list of (Value, Display String) pairs) ausgewählt.

7. Geben Sie einen Wert in die erste Spalte der Zeile ein.
8. Möchten Sie eine Anzeigezeichenkette eingeben oder eine Beschriftung auswählen?

Sie möchten . . .

Dann . . .

Eine Anzeigezeichenkette eingeben

CLF-Auswahlwerte (CLF Selection Values)

Diese Option weist den Benutzer an, den CLF über Feldereignisse zu warten.

Zum Überprüfen des Feldereignisses, an das der CLF angehängt ist, klicken Sie im Fenster "Eigenschaften" auf die Registerkarte "Ereignisse" und erweitern Sie das Ereignis "SelectValuesEx".

Vorgehensweise zum Anhängen eines Auswahlwerts an ein Feld

Gehen Sie folgendermaßen vor, um einen Auswahlwert an ein Feld anzuhängen:

1. Öffnen Sie die Designer-Symbolleiste.
2. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
3. Wählen Sie das CDO aus, das das Feld enthält, an das Sie die Auswahlwerte anhängen möchten.
4. Klicken Sie auf der Registerkarte Felder (Fields) im Fenster CDO-Definition (CDO Definition).
5. Wählen Sie ein benutzerdefiniertes Listenfeld aus und klicken Sie auf Eigenschaften. Das Fenster "CDO-Feldeigenschaften" (CDO Field Properties) wird angezeigt.
6. Klicken Sie auf die Registerkarte Auswahlwerte (Selection Values). Die Registerkarte "Auswahlwerte" (Selection Values) wird angezeigt.
7. Klicken Sie im Bereich Erweiterte Auswahlwerte auf die Liste, um eine Methode zur Bestimmung der Auswahlwerte auszuwählen. Der Bereich unter dem Listenfeld ändert sich abhängig von der von Ihnen ausgewählten Option.
8. Klicken Sie auf OK, um Ihre Auswahl zu bestätigen.
9. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
