Anzeigen von Feldzuordnungen

Eine Zuordnung ist eine Verknüpfung zwischen zwei CDOs, die das Übergeben von Feldwerten vom CDO-Quellfeld an das CDO-Zielfeld erlaubt. Sie können ein Feld zuordnen, indem Sie eine CDO-Zuordnung erweitern oder Ihre eigene Zuordnung hinzufügen.

Wenn Sie eine Zuordnung erweitern, beginnen Sie mit einer in Opcenter EX MDD oder Opcenter EX CR vorhandenen Zuordnung und geben eine Unterklasse des aktuell zugeordneten CDOs an. Sobald die Zuordnung erweitert wurde, können Sie einen beliebigen Feldwert von der Quelle den Zielfeldern zuordnen.

Indem Sie eine Zuordnung hinzufügen, wird Ihr Quell-CDO im Fenster "CDO-Definition" (CDO Definition) ausgewählt. Sie werden das Ziel-CDO auswählen, wenn Sie die Zuordnung hinzufügen. Sobald die Zuordnung hinzugefügt wurde, können Sie einen beliebigen Feldwert von den Quellenfeldern den Zielfeldern zuordnen.

Hinweis: Wenn Sie Felder zu Fertigungsdiensten hinzufügen, fügen Sie in der Regel die gleichen Felder dem Historiendetails-CDO hinzu und ordnen diese zu. Auf diese Weise ist gewährleistet, dass die Werte dieser Felder beim Ausführen des Dienstes in die Historie geschrieben werden.

Vorgehensweise zum Anzeigen vorhandener Zuordnungen für ein CDO

Zuordnungen für ein CDO sind nach Richtung, Zuordnung vom oder Zuordnung zum CDO gruppiert. Gehen Sie folgendermaßen vor, um vorhandene Zuordnungen für ein CDO in Designer anzuzeigen:

1. Wählen Sie das CDO aus. Z. B. MoveTxn.
2. Wählen Sie die Registerkarte Zuordnungen (Maps) aus. Die Registerkarte "Zuordnungen" (Maps) wird geöffnet.
Hinweis: "Zuordnung von" (Map from) ist ausgewählt. Diese Ansicht zeigt, dass die Richtung der Informationszuordnung vom aktuellen CDO ausgeht.
3. Klicken Sie auf Zuordnung nach (Map to). Im Fenster "Zuordnungen" (Maps) werden jetzt verschiedene Zuordnungen angezeigt.
Hinweis: Wenn eine der Zuordnungsdefinitionen in dieser Ansicht vorhanden ist, verläuft die Informationszuordnung von anderen CDOs zum aktuellen CDO.

Vorgehensweise zum Zuordnen eines Felds durch Erweitern einer vorhandenen Zuordnung

Gehen Sie folgendermaßen vor, um ein Feld durch Erweitern einer vorhandenen Zuordnung in Designer zuordnen:

1. Klicken Sie auf die Schaltfläche CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
2. Doppelklicken Sie im linken Bereich auf ein CDO, auf das Sie eine Zuordnung erweitern möchten.
3. Wählen Sie die Registerkarte Zuordnungen (Maps) aus. Die Registerkarte "Zuordnungen" (Maps) wird angezeigt.
4. Wählen Sie die zu erweiternde Zuordnung aus, z. B. Container_to_StartHistoryDetail im Bereich In Vorgänger-CDOs definierte Zuordnungen (Maps defined in Ancestors CDOs).
5. Klicken Sie auf Erweitern (Extend). Das Fenster "Felddefinition" wird angezeigt.
6. Wählen Sie ein CDO zur Darstellung Ihres neuen Ziel-CDOs aus.
7. Klicken Sie auf Auswählen. Die erweiterte Zuordnung wird im Bereich "Zuordnungsdefinitionen" (Map definitions) angezeigt.
8. Wählen Sie die neue Zuordnung im Bereich Zuordnungsdefinitionen (Map definitions) aus.
9. Klicken Sie auf Details unterhalb des Bereichs Zuordnungsdefinitionen (Map definitions). (Es werden zwei Schaltflächen "Details" angezeigt. Klicken Sie nicht auf die Schaltfläche "Details" unter "In Vorgänger-CDOs definierte Zuordnungen" (Maps defined in Ancestor CDOs).) Das Fenster "CDO-Feldzuordnung" (CDO Field Map) wird angezeigt.
10. Wählen Sie die Registerkarte Felder (Fields) aus, sofern sie noch nicht ausgewählt ist.
11. Ordnen Sie das Quellfeld "Von" dem Zielfeld "Nach" mithilfe einer der folgenden Methoden zu:

Ziehen Sie das Quellfeld an den Anfang des Zielfelds.

Oder

a. Wählen Sie das Quellfeld aus.
b. Wählen Sie das Zielfeld aus.
c. Klicken Sie auf Feld zuordnen>> (Map Field>>). Das Quellfeld wird unter der Spalte "Quellfeldname" (Source Field Name) angezeigt.
12. Wiederholen Sie Schritt 11 für jedes gewünschte Feld.
13. Klicken Sie auf das [X] oben rechts im Fenster, um Ihre zugeordneten Felder zu speichern.
14. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Zuordnen eines Felds durch Hinzufügen einer Zuordnung

Gewährleisten Sie, dass die Felder, die Sie zuordnen möchten, in den zuzuordnenden CDOs vorhanden sind. Gehen Sie folgendermaßen vor, um ein Feld durch Hinzufügen einer Zuordnung in Designer zuzuordnen:

1. Klicken Sie auf die Schaltfläche CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
2. Doppelklicken Sie auf das CDO im linken Bereich, dem Sie eine Zuordnung hinzufügen.
3. Wählen Sie die Registerkarte Zuordnungen (Maps) aus.
4. Klicken Sie auf Hinzufügen im Fenster Zuordnung (Map). Das Fenster "Felddefinition" wird angezeigt.
5. Wählen Sie ein CDO zur Darstellung Ihres neuen Ziel-CDOs aus.
6. Klicken Sie auf Auswählen. Die neue Zuordnung wird im Bereich "Zuordnungsdefinitionen" (Map definitions) mit dem Quell- und Ziel-CDO als Zuordnungsname angezeigt.
7. Klicken Sie auf Details unter Zuordnungsdefinitionen (Map definitions). (Es werden zwei Schaltflächen "Details" angezeigt. Klicken Sie nicht auf die Schaltfläche "Details" unter "In Vorgänger-CDOs definierte Zuordnungen" (Maps defined in Ancestor CDOs).) Das Fenster "CDO-Feldzuordnung" (CDO Field Map) wird geöffnet.
8. Wählen Sie die Registerkarte Felder (Fields) aus, sofern sie noch nicht ausgewählt ist.
9. Ordnen Sie das Quellfeld "Von" dem Zielfeld "Nach" mithilfe einer der folgenden Methoden zu:

Ziehen Sie das Quellfeld an den Anfang des Zielfelds.

Oder

a. Wählen Sie das Quellfeld aus.
b. Wählen Sie das Zielfeld aus.
c. Klicken Sie auf Feld zuordnen>> (Map Field>>). Das Quellfeld wird unter der Spalte "Quellfeldname" (Source Field Name) angezeigt.
10. Wählen Sie Übernehmen (Carry forward) aus, um den aktuellen Wert im Zielfeld beizubehalten. Dadurch wird verhindert, dass das System den aktuellen Wert im Feld überschreibt, wenn die Zuordnung erneut aufgerufen wird.
11. Aktivieren Sie Accumulate (Sammeln), wenn ein Wert in einem numerischen Feld einem vorhandenen Wert hinzugefügt werden soll.
12. Wiederholen Sie die Schritte 9-11 für jedes gewünschte Feld.
13. Klicken Sie auf das [X] oben rechts im Fenster, um Ihre zugeordneten Felder zu speichern.
Hinweis: Ein CLF muss geändert werden, damit die neue Zuordnung ausgeführt werden kann.
14. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Entfernen einer Zuordnung

Sie können weder Standardzuordnungen noch geerbte Zuordnungen entfernen. Sie können keine benutzerdefinierten Zuordnungen entfernen, die durch eine Unterklasse des CDOs erweitert wurden.

Wenn ein CLF zum Aufrufen der zu entfernenden Zuordnung erstellt wurde, muss vor dem Entfernen der Zuordnung dieser CLF gelöscht oder geändert werden, damit die Zuordnung nicht mehr referenziert wird. Weitere Informationen zum Bestimmen, wo Zuordnungen in CLFs verwendet werden, finden Sie unter "Vorgehensweise zum Anzeigen von Referenzen auf eine Zuordnung".

Gehen Sie folgendermaßen vor, um eine Zuordnung zu entfernen:

1. Öffnen Sie die Designer-Symbolleiste.
2. Klicken Sie auf die Schaltfläche CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
3. Doppelklicken Sie im linken Bereich auf das CDO für das Sie eine Zuordnung entfernen.
4. Wählen Sie die Registerkarte Zuordnungen (Maps) aus.
5. Wählen Sie die zu entfernende Zuordnung im Bereich Zuordnungsdefinitionen (Map definitions) aus.
6. Klicken Sie auf Entfernen. Ein Dialogfeld fordert Sie auf, das Entfernen der Zuordnung aus der CDO-Definition zu bestätigen.
7. Klicken Sie auf Ja.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Löschen von Feldzuordnungen

Durch das Löschen von Feldzuordnungen wird das Feld nicht entfernt. Sie entfernen einfach die Zuordnungsbeziehung.

Hinweis: Die Vorgehensweise zum Löschen einer Feldzuordnung bezieht sich nur auf die aktuell ausgewählte Zuordnung.

Gehen Sie folgendermaßen vor, um Feldzuordnungen in Designer zu löschen:

1. Klicken Sie auf die Schaltfläche CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
2. Doppelklicken Sie im linken Bereich auf das CDO, aus dem Sie das zugeordnete Feld entfernen.
3. Wählen Sie die Registerkarte Zuordnungen (Maps) aus.
4. Wählen Sie im Bereich Zuordnungsdefinitionen (Map definitions) die Zuordnung aus, aus der Sie das zugeordnete Feld entfernen möchten.
5. Klicken Sie auf Details unterhalb des Bereichs Zuordnungsdefinitionen (Map definitions). (Es werden zwei Schaltflächen "Details" angezeigt. Klicken Sie nicht auf die Schaltfläche "Details" unter "In Vorgänger-CDOs definierte Zuordnungen" (Maps defined in Ancestor CDOs).) Das Fenster "CDO-Feldzuordnung" (CDO Field Map) wird geöffnet.
6. Wählen Sie die Registerkarte Felder (Fields) aus, sofern sie noch nicht ausgewählt ist.
7. Wählen Sie das zugeordnete Quellfeld (Von) aus.
8. Wählen Sie das zugeordnete Zielfeld (Nach) aus.
9. Klicken Sie auf Zuordnung löschen (Clear mapping). Die Zuordnungsdefinition wird für dieses Feld entfernt.
10. Wiederholen Sie die Schritte 7 bis 9 für jedes gewünschte Feld.
11. Klicken Sie auf das [X] oben rechts im Fenster, um Ihre entfernten Feldzuordnungen zu speichern.
12. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Anzeigen von Referenzen auf eine Zuordnung

Sie können die CLFs, CDOs sowie die Ereignisse und Methoden anzeigen, die eine Zuordnung referenzieren. Gehen Sie folgendermaßen vor, um die Referenzen auf eine Zuordnung in Designer anzuzeigen:

1. Klicken Sie auf die Schaltfläche CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
2. Doppelklicken Sie in der CDO-Liste im Auswahlbereich auf das CDO.
3. Wählen Sie die Registerkarte Zuordnungen (Maps) aus.
4. Wählen Sie eine Zuordnung aus und klicken Sie auf die Schaltfläche Details. Das Fenster "CDO-Feldzuordnung" (CDO Field Map) wird angezeigt.
5. Wählen Sie die Registerkarte Allgemein aus.
6. Aktivieren Sie das Kontrollkästchen Anzeigen, wo diese Zuordnung referenziert wird (Show where this map is referenced). Alle CDOs, CLFs, Ereignisse und Methoden, die diese Zuordnung referenzieren, werden unter dem Kontrollkästchen aufgelistet.
