Felder

Felder sind einem CDO zugeordnet und können Attribute aufweisen, die vom CDO abhängig oder unabhängig sind.

Hinweis: Für ein CDO stehen maximal 1000 Felder zur Verfügung.

Die folgenden Themen enthalten Informationen zu Feldern:

• Feldtypdefinitionen
• CDO-Felder
• CDO-Feldeigenschaften
• Anzeigen von Feldauswahlwerten
• Anzeigen und Ändern von Feldereignissen
• Erstellen von Feldüberschreibungen
• Definieren von Listenfeldern
• Anzeigen von Feldzuordnungen
• Hinzufügen von Feldüberschriften
• Ändern von Feldeigenschaften
• Verschlüsseln und Maskieren von Feldern
