Anzeigen und Ändern von Feldereignissen

Feldereignisse sind Ereignisse, die an ein CDO-Feld angehängt sind. Weitere Informationen zum Anzeigen von Ereignissen finden Sie unter "Ereignisse und Methoden".

Vorgehensweise zum Anzeigen der Feldereignisse

Gehen Sie folgendermaßen vor, um Feldereignisse anzuzeigen:

1. Öffnen Sie die Designer-Symbolleiste.
2. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" wird angezeigt.
3. Doppelklicken Sie auf ein beliebiges CDO in der Liste.
4. Wählen Sie die Registerkarte Felder aus. Das Fenster "CDO-Felder" wird angezeigt. Es enthält die eindeutigen Felder für dieses CDO.
5. Wählen Sie Geerbte Felder einschließen aus, um Felder anzuzeigen, die von der Basisklasse geerbt wurden.
6. Wählen Sie das Feld aus, dessen Ereignisse Sie anzeigen möchten.
7. Klicken Sie auf die Schaltfläche Eigenschaften in diesem Fenster Felder (Fields). Das Fenster "CDO-Feldeigenschaften" wird geöffnet.
8. Klicken Sie auf die Registerkarte Ereignisse. Alle Ereignisse, die an das Feld angehängt sind, werden angezeigt:
9. Wählen Sie Geerbte einschließen aus, um die von der Elternklasse geerbten Ereignisse anzuzeigen, wenn das ausgewählte Feld geerbt ist. Die geerbten Ereignisse, die dem ausgewählten Feld zugeordnet sind, werden angezeigt.
10. Klicken Sie auf Abbrechen, um das Fenster "Feldereignisse" zu schließen.

Ändern von Feldereignissen

Sie können CLFs an Feldereignisse anhängen und benutzerdefinierte CLFs abtrennen. Sie können High Performance-CLFs nicht an Feldereignisse anhängen. Weitere Informationen zum Verwenden von CLFs finden Sie unter "Konfigurierbare logische Abläufe".

Vorgehensweise zum Anhängen eines CLFs an ein Feldereignis

Gehen Sie folgendermaßen vor, um ein CLF an ein Feldereignis anzuhängen:

1. Öffnen Sie die Designer-Symbolleiste.
2. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" wird angezeigt.
3. Wählen Sie ein beliebiges CDO aus der Liste aus.
4. Wählen Sie die Registerkarte Felder aus. Das Fenster "CDO-Felder" wird angezeigt. Es enthält die eindeutigen Felder für dieses CDO.
5. Wählen Sie Geerbte Felder einschließen aus, um Felder anzuzeigen, die von der Basisklasse geerbt wurden.
6. Wählen Sie das Feld aus, dessen Ereignisse Sie anzeigen möchten.
7. Klicken Sie auf die Schaltfläche Eigenschaften in diesem Fenster "Felder" (Fields). Das Fenster "CDO-Feldeigenschaften" wird angezeigt.
8. Klicken Sie auf die Registerkarte Ereignisse. Alle Ereignisse, die an das Feld angehängt sind, werden angezeigt:
9. Wählen Sie Geerbte einschließen aus, um Ereignisse anzuzeigen, die von der Basisklasse geerbt wurden. Die dem ausgewählten Feld zugeordneten Ereignisse werden angezeigt.
10. Wählen Sie das Ereignis aus, an das Sie einen CLF anhängen möchten. Die Schaltfläche "CLF anhängen" ist aktiviert.
11. Klicken Sie auf CLF anhängen. Das Fenster "Definition suchen" wird geöffnet und die Bibliothek der verfügbaren CLFs wird angezeigt:
12. Erweitern Sie die CLF-Kategorie, die den gewünschten CLF enthält.
13. Wählen Sie den entsprechenden CLF aus und klicken Sie auf Auswählen. Der ausgewählte CLF wird an das ausgewählte Ereignis angehängt.
14. Klicken Sie auf OK.
15. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Abtrennen eines CLFs von einem Feldereignis

Sie können nur benutzerdefinierte CLFs von Feldereignissen abtrennen. Gehen Sie folgendermaßen vor, um einen CLF von einem Feldereignis abzutrennen:

1. Öffnen Sie die Designer-Symbolleiste.
2. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" wird angezeigt.
3. Wählen Sie ein beliebiges CDO aus.
4. Wählen Sie die Registerkarte Felder aus. Das Fenster "CDO-Felder" wird angezeigt. Es enthält die eindeutigen Felder für dieses CDO.
5. Wählen Sie Geerbte Felder einschließen aus, um Felder anzuzeigen, die von der Basisklasse geerbt wurden.
6. Wählen Sie das Feld aus, dessen Ereignisse Sie anzeigen möchten.
7. Klicken Sie auf die Schaltfläche Eigenschaften in diesem Fenster "Felder". Das Fenster "CDO-Feldeigenschaften" wird angezeigt.
8. Klicken Sie im Fenster "Eigenschaften" auf die Registerkarte Ereignisse. Im Fenster werden alle Ereignisse angezeigt, die an das Feld angehängt sind.
9. Wählen Sie Geerbte einschließen aus, um Ereignisse anzuzeigen, die von der Elternklasse geerbt wurden. Die dem ausgewählten Feld zugeordneten Ereignisse werden angezeigt.
10. Wählen Sie das Ereignis aus, das Sie von einem CLF abtrennen möchten. Die Schaltfläche "CLF abtrennen" wird aktiviert.
11. Klicken Sie auf CLF abtrennen.
12. Klicken Sie auf OK.
13. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
