Ändern von Feldeigenschaften

Die Änderung ist eine Überschreibung, wenn das zu ändernde Feld geerbt wurde. Weitere Informationen zum Ändern geerbter Felder finden Sie unter "Erstellen von Feldüberschreibungen".

Durch Änderungen an Feldeigenschaften wird die verknüpfte Spalte in der Opcenter EX MDD- oder Opcenter EX CR-Tabelle, in der dieses Feld gespeichert ist, nicht aktualisiert. Sie müssen die Registerkarte "Wo genutzt" (Where Used) für das Feld auswählen, um die Tabellen anzuzeigen, in denen dieses Feld verwendet wird. Nehmen Sie anschließend die gleiche Eigenschaftsänderung an allen betroffenen Tabellen vor. Weitere Informationen zum Zugriff auf die Tabellen finden Sie unter "Tabellen".

Vorgehensweise zum Ändern von Feldeigenschaften

Gehen Sie folgendermaßen vor, um Feldeigenschaften zu ändern:

1. Öffnen Sie die Designer-Symbolleiste.
2. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
3. Wählen Sie im Fenster "CDO-Definition" (CDO Definition) ein CDO und anschließend die Registerkarte Felder (Fields) aus.
4. Wählen Sie das Feld aus, dessen Eigenschaften Sie ändern werden.
5. Klicken Sie auf Eigenschaften. Das Fenster "CDO-Feldeigenschaften" (CDO Field Properties) wird angezeigt.
6. Ändern Sie alle Feldeigenschaften, die Sie an Ihre Unternehmensanforderungen anpassen möchten.
7. Wenn Sie die Eigenschaft eines NDO- oder RO-Felds ändern möchten, aktivieren Sie das Kontrollkästchen Die gleichen Änderungen auf das entsprechende Feld in der zugehörigen Wartungstransaktion anwenden (Apply the same changes to the corresponding field in the associated Maintenance transaction).
8. Klicken Sie auf OK.
9. Wenden Sie die Designer-Änderungen an.
10. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
