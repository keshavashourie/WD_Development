Erstellen von Feldüberschreibungen

In der Regel verwendet eine CDO-Unterklasse die geerbten Felder ihrer übergeordneten Klasse. Durch Überschreibung wird eine bestimmte Eigenschaft des geerbten Felds in der CDO-Unterklasse angepasst. Überschreibungen können an geerbten Feldern vorgenommen werden. In der Überschreibung vorgenommene Änderungen werden nur auf das ausgewählte CDO und beliebige Unterklassen des ausgewählten CDOs angewendet. Ein überschriebener Feldwert kann von einer Beschreibungsänderung bis hin zu einer Änderung der Objektreferenzen und Wertausdrücke reichen.

Für Überschreibungen gelten die folgenden Richtlinien:

• Sie können den Datentyp in Designer ändern. Ihre Änderungen wirken sich nicht auf die Datenbank aus.
• Wenn der Datentyp ein CDO ist, können Sie ihn überschreiben, indem Sie ein anderes CDO für die Referenzierung auswählen. Beachten Sie, dass der Feldtyp zum Namen des referenzierten CDOs wird, doch der Feldname unverändert bleibt.
• Die Hintergrundfarbe eines Felds mit einem überschriebenen Wert im Designer-Fenster entspricht der Farbe, die dem Arbeitsbereich zugeordnet ist, in dem das Feld überschrieben wurde.
• Durch Änderungen an Feldeigenschaften wird die verknüpfte Spalte in der Opcenter EX MDD- oder Opcenter EX CR-Tabelle, in der dieses Feld gespeichert ist, nicht aktualisiert. Sie müssen die Registerkarte "Wo genutzt" (Where Used) für das Feld auswählen, um die Tabellen anzuzeigen, in denen dieses Feld verwendet wird. Nehmen Sie anschließend die gleiche Eigenschaftsänderung an allen betroffenen Tabellen vor. Weitere Informationen zum Zugriff auf die Tabellen finden Sie unter "Tabellen".
• Wenn das Feld über ein entsprechendes Feld in einer Wartungstransaktion verfügt, wird Ihnen die Standardoption zum Vornehmen der gleichen Änderungen im entsprechenden Feld der zugehörigen Wartungstransaktion angezeigt.
• Die Verwendung einer größeren Anzahl von Überschreibungen kann dazu führen, dass mehr GDI-Objekte zugewiesen werden, als das Windows-Betriebssystem standardmäßig pro Prozess zulässt. Sie können den Wert des folgenden Registrierungsschlüssels bearbeiten, um den maximalen Wert zu erhöhen und die erforderlichen GDI-Objekte zu verarbeiten:

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\
CurrentVersion\Windows\GDIProcessHandleQuota

Der Standardwert ist 10,000. Der zulässige Bereich liegt zwischen 256 und 65,536.

Vorgehensweise zum Erstellen einer Feldüberschreibung

Gehen Sie folgendermaßen vor, um eine Feldüberschreibung zu erstellen:

1. Öffnen Sie die Designer-Symbolleiste.
2. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
3. Wählen Sie im Fenster "CDO-Definition" (CDO Definition) ein CDO aus und klicken Sie auf die Registerkarte "Felder" (Fields).
4. Wählen Sie Geerbte Felder einschließen (Include inherited fields) aus.
5. Wählen Sie das Feld aus, für das Sie eine Überschreibung erstellen möchten.
6. Klicken Sie auf Eigenschaften. In einem Dialogfeld werden Sie aufgefordert, die Erstellung einer Überschreibung zu bestätigen.
7. Klicken Sie auf Ja. Das Fenster "CDO-Feldeigenschaften" (CDO Field Properties) wird angezeigt.
Hinweis: Wenn Sie auf "Nein" klicken, überschreiben Sie das Feld im Vorgänger-CDO, wo das Feld ursprünglich definiert wurde. Diese Überschreibung wird von allen Unterklassen des Vorgänger-CDOs geerbt.
8. Ändern Sie alle Feldeigenschaften, die Sie an Ihre Unternehmensanforderungen anpassen möchten. Die Hintergrundfarbe der überschriebenen Felder ändert sich in die Farbe, die dem Arbeitsbereich zugeordnet ist, in dem das Feld überschrieben wurde.
9. Klicken Sie auf OK.
10. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
