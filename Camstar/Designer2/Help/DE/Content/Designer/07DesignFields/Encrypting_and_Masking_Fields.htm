Verschlüsseln und Maskieren von Feldern

Sie können Feldwerte vor der Datenübertragung verschlüsseln. Die Verschlüsselung ist hilfreich, wenn Sie Benutzerkennwörter, Umlaufbestandsnachrichten, elektronische Unterschriften oder andere Informationen übertragen, da vertrauliche Informationen so auch bei der Fehlerbehebung sicher sind. Die Feldverschlüsselung wirkt sich auf folgende Elemente aus:

• XML-Transaktionsdokumente
• Transaktionsverfolgungsprotokolle
• Fenster "DBMON"

Beim Verschlüsseln von Feldern

Wenn Sie die Option "Kennwort" unter "Feldverwendung" auf der Registerkarte "Optionen" verwenden, können Sie Felder verschlüsseln. Es kann jedoch immer nur ein Feld pro CDO verschlüsselt werden. Weitere Informationen zu den Feldern auf der Registerkarte "Optionen" finden Sie unter "Felddefinitionen der Registerkarte "Optionen"".

Vorgehensweise zum Verschlüsseln eines Felds

Gehen Sie folgendermaßen vor, um ein Feld zu verschlüsseln:

1. Klicken Sie auf die Schaltfläche CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
2. Wählen Sie das CDO im linken Bereich aus.
3. Wählen Sie aus der Liste "Feldname" (Field name) ein zu verschlüsselndes Feld aus und klicken Sie auf die Schaltfläche Eigenschaften. Das Fenster "CDO-Feldeigenschaften" (CDO Field Properties) wird angezeigt.
Wichtig: Sie können ein Feld nur dort verschlüsseln, wo es zum ersten Mal definiert wurde. Sie können es nicht in einer Unterklasse verschlüsseln, z. B. überschreiben.
4. Klicken Sie auf die Registerkarte Optionen.
5. Wählen Sie Nur Schreiben (Write-Only) im Bereich "Zugänglichkeit" (Accessibility) aus.

Oder

6. Wählen Sie Lesen/Schreiben (Read/Write) im Bereich "Zugänglichkeit" (Accessibility) aus.
7. Wählen Sie Kennwort aus der Liste "Feldverwendung" aus.
8. Klicken Sie auf OK.
9. Wenden Sie die Designer-Änderungen an.
Hinweis: Mithilfe des Feldverzeichnisses oder der Toolbox können Sie dem Formular verschlüsselte Felder hinzufügen.
10. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Maskieren von Feldern

Sie können Felder im Portal maskieren, sodass bei der Eingabe von Werten in ein Feld Aufzählungszeichen angezeigt werden. Wenn ein Objekt, das ein maskiertes Feld enthält, abgerufen oder angezeigt wird:

• Das Feld wird leer angezeigt.
• Wenn ein neuer Wert eingegeben wird, ist dieser verschlüsselt und wird als Teil der Anforderungsdaten für die Transaktion gesendet.
• Gibt der Benutzer keinen Wert ein, wird das Feld nicht als Teil der Anforderungsdaten für die Transaktion gesendet und der aktuelle Wert wird beibehalten.
• Gibt der Benutzer mindestens ein Leerzeichen ein, wird das Feld als Teil der Anforderungsdaten für die Transaktion gesendet und weist in der Datenbank einen Nullwert auf.

Beim Maskieren von Feldern

Sie können Felder maskieren, indem Sie auf der Registerkarte "Allgemein" unter "Feldtyp" (Field type) die Option "Kennwort" auswählen. Informationen zu den Feldern auf der Registerkarte "Allgemein" finden Sie unter "CDO-Feldeigenschaften".

Vorgehensweise zum Maskieren eines Felds

Gehen Sie folgendermaßen vor, um ein Feld zu maskieren:

1. Klicken Sie auf die Schaltfläche CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
2. Wählen Sie das CDO im linken Bereich aus.
3. Wählen Sie aus der Liste "Feldname" (Field name) ein zu maskierendes Feld aus und klicken Sie auf die Schaltfläche Eigenschaften. Das Fenster "CDO-Feldeigenschaften" (CDO Field Properties) wird angezeigt.
4. Klicken Sie auf die Registerkarte Allgemein.
5. Wählen Sie aus der Liste "Datentyp" (Data Type) die Option Zeichenkette und anschließend aus der Liste "Feldtyp" (Field type) die Option Kennwort aus.
6. Klicken Sie auf OK.
7. Wenden Sie die Designer-Änderungen an.
Hinweis: Mithilfe des Feldverzeichnisses oder der Toolbox können Sie dem Formular maskierte Felder hinzufügen.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
