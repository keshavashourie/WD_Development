CDO-Feldeigenschaften

Ein Feld wird durch seine Eigenschaften definiert. Wählen Sie ein CDO-Feld aus und klicken Sie auf die Schaltfläche "Eigenschaften", um das Fenster "CDO-Feldeigenschaften" aufzurufen. Die verfügbaren Eigenschaften gelten speziell für das von Ihnen ausgewählte CDO-Feld. Das Fenster "Feldeigenschaften" enthält sechs Registerkarten:

• Allgemein
• Optionen
• Erweiterte Optionen
• Ausdrücke
• Selection Values
• Geschehen

Auf allen Registerkarten befindet sich das Kontrollkästchen "Die gleichen Änderungen auf das entsprechende Feld in der zugehörigen Wartungstransaktion anwenden". Wenn dieses Kontrollkästchen aktiviert ist, werden die gleichen Änderungen am zugehörigen Wartungsobjekt vorgenommen.

Hinweis: Die Anwendung speichert keine Informationen im zugehörigen Wartungsobjekt, wenn das Kontrollkästchen "Die gleichen Änderungen auf das entsprechende Feld in der zugehörigen Wartungstransaktion anwenden" aktiviert ist und keine Änderungen an den Eigenschaften des Felds "CDO" vorgenommen wurden.

Eigentümerschaft

Stark

Flach

Wenn diese Option ausgewählt ist, wird der Wert der Objektreferenz in ein XML-Übertragungsdokument eingeschlossen. Dabei wird in der Regel die Instanz-ID und die entsprechende alternative Referenz für das Objekt eingeschlossen.

Tief

Felddefinitionen der Registerkarte "Ausdrücke"

Diese Tabelle definiert die Felder auf der Registerkarte "Ausdrücke".

Feld

Definition

Aktueller Wertausdruck (CVE)

Aktuelle Wertausdrücke (CVE) dienen zur dynamischen Bestimmung des Werts eines Felds in einem CDO. Mithilfe eines CVEs kann das Feld während der Laufzeit einen Wert bestimmen.

Standardwert (DV)

Der Standardwert ist der von Ihnen bestimmte Wert, den das Feld annimmt, wenn kein anderer Wert angegeben wurde.

Hinweis: Siemens empfiehlt, Standardwerte nur für Transaktionen in der Fertigung zu verwenden.

Standardwertausdruck (DVE)

Ein Standardwertausdruck dient zur dynamischen Bestimmung des Standardwerts.

Hinweis: Siemens empfiehlt, Standardwertausdrücke nur für Transaktionen in der Fertigung zu verwenden.

Unterstützte Ausdrücke

Nur CVEs und DVEs unterstützen Ausdrücke, nicht jedoch der Standardwert (DV). Beim Initialisieren eines Objekts versucht das System, den Wert eines Felds aus der Datenbank abzurufen, sofern dieser persistent ist.

Hinweis: Der CVE wird während der Initialisierung nicht ausgewertet. Der CVE wird nur beim Anfordern des Feldwerts ausgewertet.

Bei einer Anforderung zum Abrufen des Feldwerts wird einer der folgenden Werte zurückgegeben. Diese werden in der folgenden Reihenfolge ausgeführt:

1. Instanzdaten, der festgelegte Wert
2. Wert, der vom Ereignis "OnGetValue" zurückgegeben wurde, falls vorhanden
3. Wert, der durch den CVE zurückgegeben wurde, falls vorhanden

Das Ergebnis dieser Verarbeitung, das noch immer leer sein kann, wird auf das Feld festgelegt, wenn sich bei der Auswertung ein Wert ergibt. Beim Abrufen des Werts wird ein beliebiger Wert zurückgegeben, auf den das Feld festgelegt ist.

Es gibt einen Aufruf, der das Abrufen des Standardwerts "csigetdefaultvalue" erlaubt.

Ausdrücke dienen zum dynamischen Bestimmen des Werts eines Felds im CDO, ganz gleich, ob es sich um einen aktuellen Wertausdruck oder um einen Standardwertausdruck handelt. Die Syntax ist ähnlich. Der Unterschied besteht darin, dass der aktuelle Wertausdruck eine Referenz auf den aktuellen Datenwert eines Felds enthalten kann.

Ein Feldausdruck – ein CVE oder ein DVE – bezieht sich auf mehrere Ausdrücke, die nacheinander aufgelistet sind, getrennt durch Semikolons. Die Auswertungsreihenfolge eines Feldausdrucks beginnt mit dem ersten Ausdruck und endet beim letzten Ausdruck. Die Auswertung stoppt, wenn ein Feldausdruck einen Wert ergibt. Das reservierte Wort wird zuerst eingegeben, gefolgt von einem Semikolon. Das aktuell reservierte Wort für einen Feldausdruck lautet:

This_Value;

"This_Value" verwendet den Wert, den der Benutzer in das Feld eingegeben hat.

Ein Ausdruck stellt einen Wert dar, kann aber mehrere Feldnamen aufweisen, die innerhalb des Ausdrucks durch Punkte getrennt sind. Die Konvention für die Eingabe eines Feldausdrucks für ein Feld lautet:

FieldName(ObjectReference).FieldName(ObjecReference).FieldName(beliebiger Typ)

Dabei gilt:

FieldName(ObjectReference) ist ein Feld in einem CDO vom Typ "OID", wobei sich das Feld auf ein CDO bezieht.

und:

FieldName(beliebiger Typ) ist ein Feld in einem CDO eines beliebigen Typs.

Beispiel 1

This_Value;Container.Workflow.FirstStep

Dieser Ausdruck weist die Anwendung an, den durch den Benutzer eingegebenen Wert zu verwenden. Wenn nichts eingegeben wurde, gibt dieser Ausdruck die Instanz-ID im Feld "FirstStep" an, das in dem Arbeitsplan enthalten ist, der zu dem Container gehört.

Beispiel 2

This_Value;Details.Container.Operation;0;

Die Auswertung für diesen Feldausdruck wird wie folgt vorgenommen:

1. "This_Value" ruft den vom Benutzer eingegebenen Wert ab. Wenn sich daraus kein Wert ergibt, gilt Folgendes:
2. "Details.Container.Operation" ruft den Wert aus dem Feld "Operation" im Container-CDO innerhalb des Details-CDOs ab. Wenn sich aus diesem CVE kein Wert ergibt, gilt Folgendes:
3. Der Wert wird auf 0, NULL, oder abhängig vom Feldtyp auf eine leere Zeichenkette festgelegt.

Beispiel 3

This_Value;ProductFamily.Workflow

Die Auswertung für diesen Feldausdruck wird wie folgt vorgenommen:

1. "This_Value" wird im CVE verwendet, um auf den aktuellen Instanzdatenwert eines Felds zu verweisen.
2. "ProductFamily.Workflow" ruft den Wert aus dem Feld "Arbeitsplan" im Produktfamilien-CDO ab.

Vorgehensweise zum Eingeben eines CVE- oder DVE-Feldausdrucks

Gehen Sie folgendermaßen vor, um einen CVE- oder DVE-Feldausdruck einzugeben:

1. Öffnen Sie die Designer-Symbolleiste.
2. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" wird angezeigt.
3. Wählen Sie das CDO aus, das das Feld enthält, dem ein CVE oder DVE hinzugefügt werden soll.
4. Wählen Sie die Registerkarte Felder aus.
5. Wählen Sie das gewünschte Feld aus und klicken Sie auf Eigenschaften.
6. Wählen Sie die Registerkarte Ausdruck im Fenster "CDO-Feldeigenschaften" aus.
7. Legen Sie einen Wert für den CVE oder DVE fest:
• Geben Sie einen Ausdruck in das Feld Aktueller Wertausdruck oder Standardwertausdruck ein.

Oder

• Klicken Sie auf Erstellen und legen Sie den gewünschten CVE oder DVE mithilfe des Ausdrucks-Builders fest.
8. Klicken Sie auf OK oder wählen Sie eine andere Registerkarte aus, um weitere Optionen festzulegen. Siehe "Vereinheitlichte Ausdrücke".
9. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Verwenden des Ausdrucks-Builders

Gehen Sie folgendermaßen vor, um den Ausdrucks-Builder zu verwenden:

1. Klicken Sie auf Erstellen, neben dem Feld Aktueller Wertausdruck oder Standardwertausdruck. Das Fenster "Ausdruck erstellen" wird angezeigt.
2. Doppelklicken Sie auf den CDO in der Liste CDO-Definition. Die CDO-Felder werden in der Liste "Feld" angezeigt.
3. Doppelklicken Sie auf das gewünschte Feld, das im Ausdruck aufgeführt werden soll. Das ausgewählte Feld wird unter "Ausdruck" angezeigt.
4. Wiederholen Sie die Schritte 2 und 3, bis der Ausdruck vollständig ist.
Hinweis: Ein Punkt (.) wird automatisch zwischen den Feldern eingefügt, die Sie zum Ausdruck hinzufügen.
5. Klicken Sie auf Speichern und schließen.
6. Zum Hinzufügen weiterer Ausdrücke in einer Reihe, die von links nach rechts aufgelöst wird, fügen Sie am Ende eines vollständigen Ausdrucks ein Semikolon ein und beginnen Sie mit Schritt 2 in dieser Liste.
7. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
