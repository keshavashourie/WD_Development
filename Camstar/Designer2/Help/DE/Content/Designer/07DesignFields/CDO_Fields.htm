CDO-Felder

Die Feldtypen und Datentypen im Fenster "Felder" (Fields) werden als Attribute der CDO-Felder verwendet. CDO-Felder befinden sich im Fenster "CDO-Definition" (CDO Definition) auf der Registerkarte "Felder" (Fields). In diesem Thema wird Folgendes erläutert:

• Hinzufügen eines CDO-Felds
• Auswahl des richtigen Datentyps und Feldtyps
• Entfernen von Feldern

Beim Hinzufügen eines CDO-Felds

Sie müssen einem CDO ein Feld hinzufügen, wenn Sie Opcenter EX MDD oder Opcenter EX CR anpassen. Beim Hinzufügen eines CDO-Felds müssen Sie anders vorgehen als beim Hinzufügen eines Feldtyps.

Wenn Sie ein CDO-Feld hinzufügen, geben Sie den singulären Datentyp und Feldtyp an. Sobald das Feld hinzugefügt wurde, bezieht es sich auf das CDO, dem es hinzugefügt wurde.

Geben Sie beim Hinzufügen eines CDO-Felds nicht für zwei Dienste die gleiche Überschrift ein. Designer erlaubt Ihnen die Benennung zweier Dienste mit der gleichen Überschrift. Sie können jedoch nicht angeben, welchen Dienst Sie ausführen.

Wenn Sie ein CDO-Feld hinzufügen, wirkt sich dies nicht auf die Felddefinitionen aus. Wird allerdings ein CDO der Klassenbibliothek hinzugefügt, handelt es sich dabei um ein Datentypobjektfeld.

Arbeitsbereichspräfixe werden beim Hinzufügen eines neuen Elements automatisch vor dem Namen des Elements eingefügt, sofern dem höchsten aktiven Arbeitsbereich ein Präfix zugewiesen wurde. Arbeitsbereichspräfixe geben an, auf welchen Arbeitsbereich Designer Änderungen anwendet. Dem Arbeitsbereich würde z. B. das Präfix "C200" zugeordnet werden, wenn für diesen in Management Studio das Präfix "C200" festgelegt wurde. Es wird empfohlen, beim Hinzufügen neuer Elemente die von Designer bereitgestellten Präfixe zu verwenden.

Sie können Arbeitsbereichspräfixe in Management Studio zuweisen oder ändern. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Hinweis: Dem Basisarbeitsbereich der Anwendung (csi) kann kein Arbeitsbereichspräfix zugewiesen sein.

Regeln

Im Folgenden sind die benutzerdefinierten Feldregeln aufgeführt:

• Einem CDO hinzugefügte Felder werden von all seinen Unterklassen geerbt. Je mehr Unterklassen ein Objekt hat, desto länger kann dieser Vorgang dauern.
• Sie können Standard- und benutzerdefinierte CDO-Felder als Steuerelemente in Portal-Formularen ablegen.
• Wenn Sie Ihrer ParametricData-Unterklasse Felder hinzufügen, legen Sie die Felder als Steuerelemente auf dem Formular "Parametrische Datenkontrolle" (Parametric Data Control) im Portal ab.
• Wenn Sie benutzerdefinierte Felder in einem Dienst-CDO hinzufügen, werden die Felder auf dem Steuerelement "UserDefined" des Portals geladen.
• Listen, Unterobjekte und Unterobjektlisten erfordern eine benutzerdefinierte Benutzeroberfläche. Diese wird mit dem Portal definiert.
• Weisen Sie zwei Objektfeldern im gleichen CDO nicht die gleiche Feldverwendung zu.
• Weitere Informationen zu Einschränkungen bei der Feldbenennung finden Sie unter Gültige Zeichen und reservierte Wörter".

Auswahl des richtigen Datentyps und Feldtyps

Sie müssen den richtigen Datentyp und Feldtyp für ein Feld auswählen, um die Anforderungen Ihres Datenelements zu erfüllen. Beachten Sie beim Auswählen eines Datentyps und Feldtyps die folgenden Richtlinien:

• Beachten Sie bei der Auswahl eines Datentyps und Feldtyps die Beschreibung und die bestimmungsgemäße Verwendung. Die Beschreibungen der Datentypen sind in der Tabelle "Datentyp und Feldtyp" enthalten. Die Beschreibungen der Feldtypen sind in der Tabelle "Feldtypeigenschaften" enthalten.
• Überprüfen Sie die Eigenschaften des Feldtyps, um zu gewährleisten, dass diese mit den Anforderungen Ihres Datenelements übereinstimmen.

Vorgehensweise zum Hinzufügen eines CDO-Felds

Gehen Sie folgendermaßen vor, um in Designer ein CDO-Feld hinzuzufügen:

1. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
2. Wählen Sie die benutzerdefinierte CDO-Unterklasse aus, der Sie die Felder hinzufügen.
3. Wählen Sie die Registerkarte Felder (Fields) aus.
4. Klicken Sie auf Hinzufügen am unteren Rand der Registerkarte Felder (Fields). Das Fenster "Neues CDO-Feld hinzufügen" wird angezeigt.
5. Wählen Sie aus der Liste Datentyp (Data Type) einen Datentyp aus. Weitere Informationen zum Auswählen von Datentypen und Feldtypen finden Sie unter "Auswahl des richtigen Datentyps und Feldtyps".
Hinweis: Bei persistenten Objekten wird eine Tabelle für das Listenfeld in der Datenbank erstellt, wenn Sie das Kontrollkästchen "Feld ist eine Liste" (Field is a list) aktivieren.
6. Wählen Sie aus dem Feld Feldtyp (Field Type) einen Feldtyp aus.
7. Geben Sie einen Namen für das neue Feld ein und vermeiden Sie dabei unzulässige Zeichen und reservierte Wörter.
Wichtig: Der Name des CDOs kann bis zu 30 Zeichen lang sein und darf keine Leerzeichen, unzulässigen Zeichen oder reservierten Wörter enthalten. Siehe "Gültige Zeichen und reservierte Wörter".
8. Wählen Sie aus der Liste Überschrift eine vorhandene Beschriftung aus, die als Überschrift verwendet werden soll.

Oder

Geben Sie eine Beschriftung ein. Wenn Sie Ihre eigene Beschriftung hinzufügen, wird die neue Beschriftung der Bibliothek mit Benutzerbeschriftungen unter der Kategorie OtherField hinzugefügt.

9. Geben Sie eine Beschreibung in das Feld Beschreibung (Description) ein.
10. Aktivieren Sie das Kontrollkästchen Feld zu zugeordneten Dienstobjekten hinzufügen (Add Field to Associated Service Objects). In diesem Schritt wird das gleiche Feld zu den verbundenen Dienstobjekten hinzugefügt. Wenn Sie z. B. ein Feld zur Unterklasse Mitarbeiter hinzufügen, wird dasselbe Feld der entsprechenden Unterklasse Mitarbeiteränderungen (EmployeeChanges) hinzugefügt.
11. Klicken Sie auf Erstellen. Das Fenster "CDO-Feldeigenschaften" (CDO Field Properties) wird angezeigt.
12. Bestätigen oder ändern Sie die Feldeigenschaften.
13. Klicken Sie auf OK.
14. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Entfernen von Feldern

Sie können benutzerdefinierte Felder, jedoch keine Standardfelder entfernen. Gehen Sie folgendermaßen vor, um in Designer CDO-Felder zu entfernen:

1. Klicken Sie auf CDOs. Das Fenster "CDO-Definition" (CDO Definition) wird angezeigt.
2. Wählen Sie die CDO-Unterklasse aus, um ein Feld zu entfernen.
3. Wählen Sie die Registerkarte Felder (Fields) aus.
4. Wählen Sie das zu löschende benutzerdefinierte Feld aus.

Die Schaltfläche Entfernen ist deaktiviert, wenn Sie ein Standardfeld oder ein benutzerdefiniertes Feld ausgewählt haben, das zugeordnet ist oder Überschreibungen aufweist.

5. Löschen Sie alle Feldüberschreibungen und entfernen Sie die Feldzuordnungen. Siehe "Erstellen von Feldüberschreibungen" und "Anzeigen von Feldzuordnungen".
6. Klicken Sie auf Entfernen. In einem Dialogfeld werden Sie aufgefordert, die Löschung des CDO-Felds zu bestätigen.
7. Klicken Sie auf Ja. Das Feld wird entfernt. Wenn das Feld über eine Datenbankspalte verfügt, wird diese Spalte ebenfalls gelöscht.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
