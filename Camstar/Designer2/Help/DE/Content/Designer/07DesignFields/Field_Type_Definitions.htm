Feldtypdefinitionen

Feldtypdefinitionen fungieren als Datenwörterbuch und bieten einen begrenzten Satz von Datenelementen, die in Opcenter EX MDD und Opcenter EX CR verwendet werden. Alle CDO-Felder basieren auf dem Satz von Datenelementen, die durch dieses Datenwörterbuch definiert sind. Feldtypen sind unter Datentypen gruppiert.

In diesem Kapitel wird Folgendes erläutert:

• Datentyp und Feldtyp
• Feldtypeigenschaften
• Hinzufügen oder Ändern von Feldtypen

Arbeitsbereichspräfixe werden beim Hinzufügen eines neuen Elements automatisch vor dem Namen des Elements eingefügt, sofern dem höchsten aktiven Arbeitsbereich ein Präfix zugewiesen wurde. Arbeitsbereichspräfixe geben an, auf welchen Arbeitsbereich Designer Änderungen anwendet. Dem Arbeitsbereich würde z. B. das Präfix "C200" zugeordnet werden, wenn für diesen in Management Studio das Präfix "C200" festgelegt wurde. Es wird empfohlen, beim Hinzufügen neuer Elemente die von Designer bereitgestellten Präfixe zu verwenden.

Sie können Arbeitsbereichspräfixe in Management Studio zuweisen oder ändern. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Anleitung zur Systemadministration und der Opcenter Execution Core-Anleitung zur Systemadministration.

Hinweis: Dem Basisarbeitsbereich der Anwendung (csi) kann kein Arbeitsbereichspräfix zugewiesen sein.

Datentyp und Feldtyp

Der Datentyp ist das Element, durch das Feldtypen kategorisiert sind. Jeder Datentyp stellt eine Liste der verfügbaren Feldtypen bereit, die zum Definieren eindeutiger Felder verwendet werden.

Dezimal

Festkommatyp, ein exakter Wert im Gegensatz zu einem ungefähren numerischen Typ wie z. B. Gleitkomma oder reell. Er wird durch Genauigkeit und Einteilung definiert. Die Genauigkeit p bezieht sich auf die Gesamtzahl der Ziffern links und rechts vom Dezimalzeichen. Die Einteilung s bezieht sich auf die Anzahl der Ziffern rechts vom Dezimalzeichen, auch als Bruchkomponente bezeichnet.

Beachten Sie beim Arbeiten mit dem Dezimaldatentyp die folgenden Richtlinien:

• Der Anwendungsserver unterstützt eine maximale Genauigkeit von 29, die der statischen Standardeinstellung entspricht, und eine dynamische Einteilung. Die Überschreitung dieses Werts für die Genauigkeit führt beim Speichern der Definition zu einer Ausnahme.
• Die von Designer angegebenen Werte für Genauigkeit und Einteilung werden vom Anwendungsserver ignoriert.
• Die von Designer angegebenen Werte für Genauigkeit und Einteilung werden vom Datenbankmanagementsystem (DBMS) erzwungen. Die Handhabung bei einer Überschreitung der Genauigkeits- oder Einteilungsgrenzwerte hängt vom verwendeten DBMS ab. Informationen zu Dezimaltypen, Grenzwerten und zur Fehlerbehandlung erhalten Sie von Ihrem Datenbankadministrator.
• Solange sich der Dezimalwert im Server-Cache befindet, wird der zwischengespeicherte Wert auch dann zurückgegeben, wenn er die für die Datenbankspalte definierte Einteilung überschreitet.
• Der Dienst "Attribut ändern" (Change Attribute) muss entsprechend konfiguriert werden, um den Datentyp "Decimal" (Dezimal) zu unterstützen. Dies liegt daran, dass die Spalte in der Historientabelle mit der Dezimaltypspezifikation des zu ändernden Felds übereinstimmen muss.

Feldtypeigenschaften

Die Feldtypdefinition besteht aus Feldtypeigenschaften. Alle Felder desselben Typs erben die Feldeigenschaften, bis sie überschrieben werden. Diese Tabelle listet die Feldeigenschaften und die Datentypen mit diesen Eigenschaften auf.

Eigenschaft

Definition

Datentypen

Enumeration

Reihe von Elementen, die auf einem beliebigen grundlegenden Datentyp basieren können. Sie werden als Unterklassen für den CDO-Typ "Aufzählung" (Enumeration) implementiert. Die Elemente werden durch die Felder dargestellt und die Reihenfolge wird durch den Standardwert zugewiesen.

Alle Datentypen außer "Objekt" (Object)

Genauigkeit

Anzahl der Ziffern, die in einer Zahl erlaubt sind. Dieser Datentyp wird derzeit nur für den Datentyp "Dezimal" (Decimal) unterstützt.

Decimal, Fixed, Float, Integer

Waage

Anzahl der Ziffern rechts vom Dezimalzeichen in einem Gleitkommafeld. Die Zahl 123,45 weist z. B. eine Genauigkeit von 5 und eine Einteilung von 2 auf. Die Einteilung wird derzeit nur für den Datentyp "Dezimal" (Decimal) unterstützt.

Decimal, Fixed, Float

Maximale Länge

Feldlänge, d. h. Anzahl der Zeichen für Zeichenkettenfelder. Wenn Sie z. B. ein Feld mit einer maximalen Länge von 5 für fünf Zeichen festlegen und ein Benutzer beim Definieren von Instanzen in einer Clientanwendung sechs Zeichen eingibt, gibt das System eine Fehlermeldung zurück.

Vorgehensweise zum Anzeigen von Feldtypen

Gehen Sie folgendermaßen vor, um Feldtypen anzuzeigen:

1. Öffnen Sie Designer.
2. Klicken Sie auf Felder (Fields). Das Fenster "Feldtypdefinitionen" (Field Type Definitions) wird angezeigt.
3. Erweitern Sie jeden Datentyp, um die verfügbaren Feldtypen anzuzeigen.

Vorgehensweise zum Hinzufügen eines Feldtyps

Gehen Sie folgendermaßen vor, um in Designer einen Feldtyp hinzuzufügen:

1. Klicken Sie auf Felder (Fields). Das Fenster "Feldtypdefinitionen" (Field Type Definitions) wird angezeigt.
2. Wählen Sie die Datentypkategorie aus, um einen Feldtyp hinzuzufügen.
Hinweis: Sie können einen Feldtyp nicht direkt zum Datentyp "Objekt" (Object) hinzufügen. Ein Feldtyp für "Objekt" (Object) wird automatisch erstellt, wenn Sie eine CDO-Unterklasse hinzufügen.
3. Klicken Sie auf Hinzufügen. Ein neuer Feldtyp wird angezeigt.
4. Name des Felds.
5. Geben Sie eine Beschreibung in das Feld Beschreibung (Description) ein.
6. Wählen Sie rechts unter Datentyp (Data Type) einen Datentyp aus oder behalten Sie die Standardeinstellung bei.
Hinweis: Wenn Sie den Datentyp ändern, wird der Feldtyp, den Sie definieren, unter dem neuen Datentyp gespeichert. Designer zeigt Ihnen zudem Anweisungen zum Vornehmen der Änderungen an der Datenbankspalte an, falls das Feld einer Datenbankspalte zugeordnet ist.
7. Legen Sie die anderen Attribute für den Feldtyp fest.
Hinweis: Wenn Sie eine maximale Länge für Zeichenkettenfelder angeben, zeigt Ihnen Designer zudem Anweisungen zum Ändern der Größe der Datenbankspalte an, falls das Feld einer Datenbankspalte zugeordnet ist.
8. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Ändern von Feldtypeigenschaften

Wenn Sie eine vorhandene Feldeigenschaft ändern, wird sie automatisch angewendet. Der Feldtyp für "Revision" fällt z. B. in die Kategorie des Zeichenkettendatentyps und weist eine Zeichenkettenlänge von 15 Zeichen auf. Wenn Ihr Revisionsdatenelement eine Zeichenkettenlänge von 3 Zeichen erfordert, können Sie den Feldtyp ändern, indem Sie die Eigenschaft der aus 15 Zeichen bestehenden Zeichenkette mit der Feldtypdefinition in eine dreistellige Zeichenkette ändern.

Gehen Sie folgendermaßen vor, um die Feldtypeigenschaften in Designer zu ändern:

1. Klicken Sie auf Felder (Fields). Das Fenster "Feldtypdefinitionen" (Field Type Definitions) wird angezeigt.
2. Erweitern Sie die Datentypkategorie, die die Feldtypdefinition enthält.
3. Wählen Sie die zu ändernde Feldtypdefinition aus.
4. Ändern Sie die Eigenschaften.
Wichtig: Die Feldtypinformationen werden zum Erstellen einer Spaltendefinition verwendet. Sobald die Spalte definiert wurde, wirken sich Änderungen am Feldtyp nicht mehr auf die Spalte aus. Sie müssen die Spaltendefinition nach Bedarf manuell aktualisieren.
5. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.

Vorgehensweise zum Aktualisieren der Spaltendefinition

Gehen Sie folgendermaßen vor, um die Spaltendefinition zu aktualisieren:

1. Wählen Sie den Feldtyp aus.
2. Klicken Sie auf die Registerkarte Wo genutzt (Where Used).
3. Doppelklicken Sie auf den Namen der zu ändernden Spalte, um das Fenster DB-Spalteneigenschaften (DB Column Properties) zu öffnen.
4. Ändern Sie die Spalteneigenschaften.
Hinweis: Weitere Informationen zum Verwenden von Tabellen und Tabellenspalten finden Sie unter "Tabellen".
5. Wählen Sie Speichern im Menü Datei aus. Die Anwendung speichert Ihre Änderungen.
