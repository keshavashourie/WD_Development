Fenster "Feldtypdefinitionen" (Field Type Definitions)

Durch Klicken auf die Schaltfläche "Felder" (Fields) in der Symbolleiste wird das Fenster "Feldtypdefinitionen" (Field Type Definitions) geöffnet.

Felddefinitionen des Fensters "Feldtypdefinitionen" (Field Type Definitions)

Der Bereich ganz links enthält einen Auswahlbaum, in dem alle verfügbaren Feldtypkategorien aufgelistet sind. Durch die Erweiterung einer Kategorie werden spezifischere Feldtypdefinitionen angezeigt. Klicken Sie mit der rechten Maustaste auf einen Feldtyp, um die folgenden Aufgaben auszuführen:

• Hinzufügen einer Felddefinition
• Umbenennen einer Felddefinition
• Entfernen einer Felddefinition

Die Funktionen zum Umbenennen und Entfernen von Felddefinitionen sind für die Standardfeldtypen deaktiviert.

Der Bereich ganz rechts enthält Details zur ausgewählten Feldtypdefinition. Der Bereich enthält die folgenden Registerkarten:

• Registerkarte "Allgemein"
• Registerkarte "Wo genutzt" (Where Used)

Felddefinitionen der Registerkarte "Allgemein"

Diese Tabelle definiert die Felder auf der Registerkarte "Allgemein".

Feld

Definition

Typ

Beschreibung

Enthält eine Beschreibung des Felds und seiner Verwendung.

Klicken Sie mit der rechten Maustaste auf dieses Feld, um die folgenden Optionen anzuzeigen:

• Rückgängig machen
• Ausschneiden
• Kopieren
• Einfügen
• Löschen
• Alle auswählen
• Leserichtung von rechts nach links
• Unicode-Steuerzeichen anzeigen
• Unicode-Steuerzeichen einfügen
• IME öffnen
• Rückumwandlung

Erforderlich

Datentyp

Ein Elementtyp, nach dem Feldtypen kategorisiert werden. Es gibt acht Datentypen.

Erforderlich

Enumeration

Eine Reihe von Elementen, die auf einem beliebigen Datentyp basieren können. Sie werden als Unterklassen für den CDO-Typ "Aufzählung" (Enumeration) implementiert. Die Elemente werden durch die Felder dargestellt und die Reihenfolge wird durch den Standardwert zugewiesen.

Optional

Zudem weisen einige Feldtypen andere Attribute auf:

• Genauigkeit

Die Gesamtzahl der Ziffern links und rechts vom Dezimalzeichen. Wird für den dezimalen Datentyp unterstützt.

• Waage

Die Anzahl der Ziffern rechts neben dem Dezimalzeichen. Wird für den dezimalen Datentyp unterstützt.

• Maximale Länge

Die Anzahl der Zeichen, die für ein Zeichenkettenfeld eingegeben werden können. Alle Felder sind für Siemens-Feldtypendefinitionen schreibgeschützt, doch für Benutzerdefinitionen aktiviert.

Tabellen auf der Registerkarte "Wo genutzt" (Where Used)

Auf der Registerkarte "Wo genutzt" (Where Used) werden zwei Informationstypen angezeigt: CDOs, bei denen ein ausgewählter Feldtyp verwendet wird, und Datenbanktabellen und -spalten, in denen ein Feldtyp verwendet wird. Doppelklicken Sie in der Liste auf einen CDO- oder Tabellennamen, um zum Definitionsfenster des CDOs oder der Tabelle zu gelangen.
