Import Feature

The Import feature of the Designer adds object definitions (CDO, CLF, Field, and so on) contained in an import document to the current metadata configuration and optionally produces an audit log. The format of the Import document is XML following the structure of the Opcenter EX MDD or Opcenter EX CR metadata. The structure is very similar to what is displayed in the Designer, making it relatively easy to comprehend.

If the utility encounters a discrepancy, for example, if the current value does not match the expected value, you are prompted to resolve the discrepancy. Refer to “Expected Value Processing” for information.

The choices for resolving discrepancies are:

• Leave the current value unchanged
• Discontinue processing for this document
• Apply the change

The import feature displays an error message when an error occurs during the import process. The error message attempts to provide a specific reason for the failure. For example, there may be an issue with a specific object. Errors are logged in the Event Viewer and in a log file containing detailed information explaining why the process failed. Log files are saved at the file path C:\Program Files (x86)\Camstar\Logs by default.

How to Import Metadata

Follow these steps to import Opcenter EX MDD or Opcenter EX CR metadata:

1. Start Designer. The Login window appears.
2. Make sure the Metadata database field on the login window is pointing to the MDB into which you want to import configurations, and log in as required.
3. Select Import from the File menu. The Import InSite Metadata window appears.

 

4. Click the Browse button to select an import document. A window opens from which you can find and select the file.
5. Select the import document (select the full path if necessary) and click Open. The Import InSite Metadata window appears.
6. Click View Document to view the import document and examine the contents if you want.
7. Click Import to add the metadata contained in the import document to the current configuration. A record of the changes that were made to the current metadata configuration is displayed when the import process is completed. The changes are saved to a log file by default.
Note: Allow some time for the import process to complete; the duration depends upon the volume of definitions being imported. The status of the import process is displayed in the status window.
8. Select the appropriate action and click Continue.

You need to resolve the discrepancy each time you encounter one.

9. Click Close at the completion of the import process. The imported metadata changes appear in the Designer.
10. Click Update DB. A dialog box appears asking you to confirm you want to save the current MDB file and update the database according to the settings in the Preferences dialog box.
11. Click Yes. A status bar appears at the bottom of the window to indicate the update is in progress. The application saves and updates the database.
