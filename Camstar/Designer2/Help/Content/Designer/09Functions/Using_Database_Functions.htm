Using Database Functions

Database functions enable you to perform business logic on the database rather than the application server. Executing SQL statements on the database makes processing more efficient. This functionality is available with the separately licensed High Performance Engine feature.

Refer to the Opcenter Execution Core Technical Reference: High Performance Engine or the Opcenter Execution Medical Device and Diagnostics Technical Reference: High Performance Engine for information on High Performance Engine.

When Using Database Functions

The application displays standard functions and database-specific functions in the list of Available Functions. You can add, rename, and remove database functions like other functions. As with most other functions, the Description field for most database functions contains documentation describing the use of the selected function and its expected parameters.

The following apply to database functions:

• The GUID for all database functions will have the prefix "DBE."
• Do not use spaces in function names.
• Each Execute-type function contains the parameter "SQLStatementName."
• The SQLStatementName parameter has Special Processing set to "SQL Statement with Parameters."
Note: Some database functions do not contain the SQLStatementName parameter. SQLStatementName characterizations that do include SQLStatementName parameters only support Advanced Query and NonQuery SQL types of queries.
