Introduction to Functions

Opcenter EX MDD and Opcenter EX CR functions are grouped into these categories:

1. DataObjectSpecific

Each function in this category is specific to a CDO type: Container, named data objects, revisioned objects, and so on.

2. ServiceSpecific

These functions are for Service CDOs like Inquiry, Shop Floor transactions, and Maintenance transactions.

3. OnGetValue

These functions are specifically tied to a field’s OnGetValue event and are used to calculate field values.

4. ObjectSpecificValidations

Using the same principle as DataObjectSpecific, these functions perform validations on specific object types.

5. GenericValidations

These functions perform validations at the high level.

6. TemplateProcessing

These functions are for the template behavior of Shop Floor and Maintenance services.

7. FlowControl

These functions are used to determine paths or movements of the flow, including calling user methods, conditions, and exits.

8. List

These functions are used to manipulate items on a list.

9. Dates

These functions are used to set dates

10. CrossRefs

These functions are used for multilevel container tracking.

11. Query

These functions contain query statements to process queries.

12. ObjectProcessing

These functions manipulate objects at a high level such as deleting or removing a CDO. Each function can be used in all objects.

13. FieldProcessing

These functions are used for field values.

14. String

These functions are used for manipulating strings.

15. DatatypeConversion

These functions are used for converting data types.

16. Database

These functions enable you to execute SQL statements on the database rather than the application server, making the execution more efficient. The icons for the Database function group and database functions are blue.

17. UserFunctions

This area is for customers to store their customized functions. The Opcenter EX MDD and Opcenter EX CR conversion program does not use functions in this category.
