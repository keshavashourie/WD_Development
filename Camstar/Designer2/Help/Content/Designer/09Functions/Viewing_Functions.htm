Viewing Functions

You can view the Functions library from the Function Definitions window, or you can view functions for a specific CLF from the CLFs window.

Function Types

Functions are organized by type. These function types are available in Designer:

• DataObjectSpecific Functions
• CrossRefs Functions
• ServiceSpecific Functions
• Query Functions
• OnGetValue Functions
• ObjectProcessing Functions
• ObjectSpecificValidations Functions
• FieldProcessing Functions
• GenericValidation Functions
• String Functions
• TemplateProcessing Functions
• DatatypeConversion Functions
• FlowControl Functions
• Database Functions
• List Functions
• UserFunctions Functions
• Date Functions

 

Refer to the Designer application for descriptions of specific functions.

How to View the Functions Library

Follow these steps to view the Functions library:

1. Open Designer.
2. Click Functions in the toolbar. The Function Definitions window appears.

 

3. Expand the Functions tree and select a function to view its description in the General tab.
4. Click the Parameters tab to view function parameters and information about the parameters, such as usage, a description, and the data type.
5. Click the Where Used tab to view the associated CLFs and their descriptions.

 

6. Double-click a CLF to go to its definition window.
