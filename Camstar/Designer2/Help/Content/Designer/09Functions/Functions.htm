Functions

Functions have been written to perform a wide variety of tasks such as simple arithmetic, searching complex data structures, database queries, report writing, data collection, data validation, and more.

A function has zero or more parameters and is implemented by an ActiveX component. The function, contained within a CLF, performs the work. A function has access to the system’s internal object design, which it manipulates to accomplish the work.
