Functions Window

The Function Definition window appears when you click the Functions button on the toolbar or select Function definitions from the Window menu. The Functions Definition window can be used to view default functions and to add, modify, or remove user-defined functions.

The left pane contains a selection tree that lists all the available categories of functions. Right-click in this selection pane to display a shortcut menu with the following options:

• Add Function Definition
• Rename Function Definition (disabled for default functions)
• Find Function Definition
• Remove Function Definition (disabled for default functions)

The right pane displays details about a selected function through the following tabs:

• General Tab
• Parameters Tab
• Where Used Tab
• Feature Entitlement Tab

General Tab

There are four fields on the General tab that are read-only for default functions but enabled for user-defined functions.

General Tab Field Definitions

This table defines the fields on the General tab.

Contains the globally unique identifier (GUID) for the OCX that provides the program logic. This is used by the system to instantiate and invoke the program.

Indicates whether or not a function will enforce strong typing for parameters. If unchecked, this means parameter values are to be set dynamically during processing of the CLF to which the function is attached. Refer to "Parameter Data Types" for information."

Parameters Tab

The Parameters tab displays a table of parameter values for the function and a series of fields used to define the values displayed in the table.

The Add, Insert, and Remove buttons below the table allow you to add a parameter to the end of the list, insert a parameter below a selected parameter, or remove a selected parameter. You can also right-click in the table area to display a shortcut menu with the following options: Add parameter, Insert parameter, and Remove parameter.

The buttons and the shortcut menu options are enabled only for user-defined functions.

Parameters Tab Field Definitions

This table defines the fields on the Parameters tab.

Field

Definition

Type

Parameter Name

Contains the Parameter name. It must be unique within the context of the associated Function Definition. This name is used (as part of a name-value pair construct) for getting or setting Parameter Values at runtime.

Required

Special Processing

Enables Designer to show a selection list for certain processing items when setting field values for parameters during association with a function.

Required

Direction

Specifies the direction of the function:

• Select In if you want to pass a value or reference to a function.
• Select Out if you want to set a parameter from within the function.
• Select In/Out if you want to pass a value and also expect the function to set the parameter to a new value/reference.
• Select Return if you want the function to yield a value.

Required

Multiplicity

Specifies the number of values the parameter can or must take. The choices are 0...* (zero or more, therefore an optional list), 0...1 (zero or one, therefore optional), 1...1 (one, therefore required), 1...* (one or more, therefore a required list).

Required

Description

Displays information on how the parameter is used.

Required

Data Type

Displays the data type of this parameter. Refer to "Parameter Data Types" for information.

Required

Type Multiplicity

Specifies if the parameter will be Scalar, or a List, or either (ListOrScalar).

Required

Default Value

Designates the value the field will take in the absence of any other specified value.

Optional

Notes

Relevant comments about the parameter.

Optional

Where Used Tab

The Where Used tab displays information for the selected function. It displays a table listing the CLFs that use the function, if any. The table also provides a description of the CLF. This information is display only. 

Double-click a CLF name in the list to open the definition window for the CLF.

Feature Entitlement Tab

The Feature Entitlement tab displays the Feature Membership group for the selected function. Refer to "Feature Entitlement Tab" for information on feature entitlement.
