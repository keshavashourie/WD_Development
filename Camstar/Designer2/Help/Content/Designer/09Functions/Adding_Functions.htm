Adding Functions

You add user functions to the library or add them to a user CLF’s existing logic flow.

When Adding Functions

You can add user functions to the library so that you can attach them later to your user CLF.

Workspace prefixes are automatically inserted before the name of an item when adding a new item, if a prefix has been assigned to the highest active workspace. Workspace prefixes indicate which workspace Designer is applying changes to. For example, the prefix "C200" would be associated to the workspace with a prefix set as "C200" in Management Studio. It is recommended you use the prefix supplied by Designer when adding new items.

You can assign or modify workspace prefixes in Management Studio. Refer to theOpcenter Execution Medical Device and Diagnostics System Administration Guide or the Opcenter Execution Core System Administration Guide for information.

Note: The base application workspace (csi) cannot have a workspace prefix assigned to it.

How to Add Functions to the Functions Library

Follow these steps to add functions to the Functions library:

1. Open Designer.
2. Click Functions. The Function Definitions window appears.
3. Select the UserFunctions category.
4. Click the Add button, or right-click UserFunctions and select Add Function Definition from the shortcut menu. The new function appears with a generic name; it is in rename mode.
5. Enter the new name for the function to replace the generic name and press Enter.
6. Define the function’s attributes in the General and Parameters tabs according to business requirements. The Where Used tab will be set by the system when this function is added to a CLF.

Refer to “Functions Window” for information on the fields on those tabs.

7. Select Save from the File menu. The application saves your changes.
