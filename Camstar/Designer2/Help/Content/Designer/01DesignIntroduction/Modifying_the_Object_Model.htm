Modifying the Object Model

The Opcenter EX MDD or Opcenter EX CR object model consists of data and service CDOs, CLFs, functions, and other definitions. Designer allows you to modify and extend the object model. Any objects that you have modified since the last time you saved are displayed in green.

Inheritance

Inheritance is the concept of deriving an object type from an existing one, hence creating a subclass to the object type. The subclass inherits the data elements and behavior of the object type. This concept not only reduces the time to configure the system to your specific business model needs; it also ensures an inherent validity of the defined subclass.

Creating a Subclass

The recommended approach to customizing the Opcenter EX MDD or Opcenter EX CR object model is to create subclasses of default object types and then customize the subclasses to meet your requirements. The Designer application allows you access to the fields of the subclass and their properties as well as to the CLFs attached to the subclass. You can add, remove, or modify fields, attach or detach CLFs, and change function parameters.

Subentities

The process of adding fields to a subclass may result in an object type with a large number of fields. Instead of directly adding your fields to the subclass, you can choose to add your fields to an object type that is an integral part of the subclass you are trying to extend. In Opcenter EX MDD and Opcenter EX CR, these integral object types are referred to as Subentity CDOs. The relationship between one of your subclasses and the integral Subentity object type is established by adding a field of the Subentity object type to your subclass.
