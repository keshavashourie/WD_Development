Defining a ChgContainerAttribute Subclass

ChgContainerAttribute is a subclass of ContainerTxn. This service allows you to change container attributes. ChgContainerAttribute is defined in the Opcenter Execution Medical Device and Diagnostics Technical Reference: WCF Services or the Opcenter Execution Core Technical Reference: WCF Services.

This image shows the sequence of configurations for a ChgContainerAttribute service. Most configurations are automatically created for you if you use the ChgContainerAttribute wizard.

Prerequisites
• The Container subclass

Before using the wizard to create a subclass of the ChgContainerAttribute service, the Container subclass for the service must exist. This is because at the time of service creation, you will be specifying the container type. The wizard then reads all the fields in the Container subclass and also creates the required CDO maps.

Important: After you create the ChgContainerAttribute subclass, do not change the container type.
• User-defined fields

You can add user-defined fields to the Container subclass anytime: before or after creating the ChgContAttribute service. The existing user-defined fields in the Container subclass will be picked up by the wizard. If you add fields you add to the Container subclass at another time, you can add the fields to the service by launching the wizard again.
