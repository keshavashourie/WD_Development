Main Designer Window

At initialization, the Designer window has the following areas:

• Path to InSite.mdb as specified at login
• The menu bar
• The toolbar


Additional windows display specific information if you select a toolbar button or the corresponding menu bar option. A blue border displays around a toolbar button when you select it. The button containing the border indicates your current window.

Designer Header

The Designer Header displays both the path to the InSite.mdb that was specified at the login and the code and description of the highest active workspace.

The highest active workspace code and description displays in the brackets in the Designer header before the path to the InSite.mdb. The workspace code and description signals which workspace receives the updates made in Designer. For example, you could expect to see "Designer [Workspace [200 - Customer]]," indicating that any updates in Designer will be applied to the corresponding workspace with a workspace code of 200 and a description of Customer.

The highest active workspace is set in Management Studio. Refer to the Opcenter Execution Medical Device and Diagnostics System Administration Guide or the Opcenter Execution Core System Administration Guide for information.

Menu Bar

This table describes the Menu bar options.

Menu Item

Option Name

Description

File

Save

Saves database changes to the current MDB file. The current MDB file is listed in the path near the top of the window.

Save As

Enables you to save database changes with a different MDB file name.

Import

Adds object definitions contained in an import document to the current metadata configuration, and optionally produces an audit log. The import document can be generated by the Designer Export feature or can be created manually. Refer to "Opcenter EX MDD and Opcenter EX CR" for information.

Export

Opens the Metadata Export utility. The Metadata Export utility compares the two databases and allows you to selectively export the differences (delta) to an XML file. Refer to "Running the Metadata Export Utility" for information.

Preferences

Contains two tabs: a tab to choose your preferred XML editor and a tab to set your preferences when updating the database. Refer to "Applying Designer Changes and Maintaining Designer Users" for information on the preferences available when updating the database.

Exit

Terminates the current Designer session.

Advanced

Controls whether to view Changes type CDOs in the list of CDOs. With Basic selected, you do not see Changes type CDOs and Siemens internal definitions. The default is Basic.

Hidden

Displays hidden objects such as CDOs, CLFs, and fields.

Hide Unused CLF Function Parameters

Hides CLF function parameters that have no values on two tabs: the Events tab of the CDO Definition window and the Events tab of the Field Properties window.

Display Only My Workspace Overrides

Hides workspace color overrides when set to On. You will only see the bold names for objects overridden in your workspace. Set to On by default.

Note: You may need to close and reopen any open windows after changing this setting before workspace color overrides will become visible in your windows.

Toolbar

Except for Help and Update DB, each toolbar button displays a Designer definition window where users create and modify InSite metadata according to their specific requirements.

This table describes the toolbar button options.

Button

Click this button to . . .

CDOs

Display the CDO Definition window where you create and modify configurable data objects to meet your factory model needs. Use it to define an object and associated items such as fields, field properties, tables, and maps. The exposed CDOs are based upon the View setting: Basic or Advanced.

CLFs

Display the Logic Flow Definitions window that displays configurable logic flows (CLFs) by category. CLFs specify an object’s behavior and provide a list of functions that perform one or more tasks. Use it to view, add, modify, remove, or disable CLFs.

Fields

Display the Field Type Definitions window that displays all of the supported field types. Use it to add, modify, or remove user-defined field types.

Tables

Display the Table Definitions window that displays lists of database tables and columns by category.

Functions

Display the Function Definitions window that displays lists of Opcenter EX MDD or Opcenter EX CR functions and their parameters. Use it to view default functions and to add, modify, or remove user-defined functions.

Queries

Display the Query Definition window, which contains lists of predefined queries and any predefined queries you create. Use it to view predefined queries and to create and update queries to be used by the transaction logic.

Labels

Display the Labels window, which lists all system and user labels. You can customize all text (for example, comments and user interface labels).

Categories

Display the Category Definition window. Use it to define table and storage categories. Table categories are used to group tables. The categories are used only for organizational purposes. Storage categories are used to store a reference to a table category, to indicate if the CDO is nonpersistent and does not require storage, or if the storage Category is to be determined later.

Help

Display the online Help in a browser window. Help appears in the preferred language set in your browser if translated help is available. Help appears in English by default.

Update DB

Update the transaction and DataStore databases. A confirmation dialog box appears indicating that the application will save the current MDB file and update the database according to the settings in the Preferences dialog box. If you select Yes, a status bar appears at the bottom of the window to indicate the update is in progress.
