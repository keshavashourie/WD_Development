Managing Workspace Overrides

Workspaces provide the ability for customers, partners, and Siemens to change or customize Opcenter Execution Medical Device and Diagnostics (Opcenter EX MDD) and Opcenter Execution Core (Opcenter EX CR) without overwriting changes made by others. Making changes in a workspace isolates those changes from any updates made to any other workspace. For example, changes made in the highest level workspace do not affect the base application workspace. Similarly, if a customer accepts an update to the base application workspace, customizations in their workspace are not overwritten.

Siemens provides four types of workspaces:

• Opcenter EX MDD or Opcenter EX CR base
• Opcenter EX MDD or Opcenter EX CR industry solution
• Partner
• Customer

The active workspace with the highest sequence number takes priority and is where all work and user content is saved. The customer workspace is the highest priority workspace. You cannot deactivate a workspace after working in the workspace in Designer.

A default color is associated with each workspace. You can change the default color in Management Studio. It is recommended that you specify light colors so that the colors have better visibility in Designer. This table lists the default colors for each workspace.

When Managing Workspace Overrides

Designer works with the highest active workspace as set in Management Studio. Designer uses visual indicators to identify objects that have been overridden by workspace updates. The type of indicator that appears depends on how the object was overridden.

Designer uses these rules when managing workspace overrides:

• Color highlighting appears on the name of the object when the object was overridden by another workspace. The color of the highlighting indicates the workspace in which the object was overridden. CDO Maps and CDO Field Maps appear bold and do not use a color highlighting visual indicator.
• The background color of overridden CDOs turns to the color associated with the worskpace in which the CDO was overridden.
• Objects that you override in Designer in your own workspace appear in bold text. The values that are overridden will be highlighted using the workspace color after your select the object.
• The field name displays in bold if it has been overridden on the Fields tab. The Overridden/Defined In column shows the workspace code for the workspace in which the field was overridden, for example, MoveIn (Workspace - 100).
• Field overrides at the lowest level appear as new fields, not overrides.
• Fields defined in a CDO (not inherited) that are overridden in another workspace at the same level do not appear as overrides.
• Tooltips do not appear on disabled fields.
Note: Background colors on objects overridden in other workspaces are hidden by default. You must set Display Only My Workspace Overrides to Off in the View menu to display highlighting for objects overidden in other workspaces. Refer to "Main Designer Window" for information.

This table defines the visual indicators used by various object types.

Visual Indicators

CDO Details

Color highlighting appears on the name of the object with tooltips that reference the workspace it was overridden in.

Color highlighting appears on the name of the object.

CDO Field Maps

Object name appears bold and displays a tooltip that references the workspace it was overidden in if the field map has been hidden or removed.

Field Lists

Color highlighting appears on the name of the object.

Field Details

Color highlighting appears on the name of the object with tooltips that reference the workspace it was overridden in.

Table Lists

Color highlighting appears on the name of the object.

Table Details

Color highlighting appears on the name of the object. Color highlighting does not appear on the object on the Columns tab. Tooltips that reference the workspace it was overridden in appear.

CLF Lists

Color highlighting of the workspace the object was created in appears on the name of the object. The name of the object will not have tooltips as the tooltip is already being used to display the description of the CLF.

Function Lists

Color highlighting of the workspace the object was created in appears on the name of the object.

Query Lists

Color highlighting of the workspace the object was created in appears on the name of the object.

Label Lists

Color of the font of the name of the object changes instead of the background and displays tooltips that reference the workspace it was overridden in.

Label Details

Color highlighting appears on the name of the object with tooltips that reference the workspace it was overridden in.
