Navigation

Each Designer window has two panes: the left pane with a selection tree and the right pane with details about the selected tree object.

Note: You may need to close a window to refresh it. Designer does not support the F5 refresh function.

Selection Tree

The selection tree contains a list of choices available for the selected toolbar option. Click the plus sign to expand and expose more options. Details about the selection appear on the right pane.

Searching for Objects

Enter the first few characters or the entire object name in the filter field to search for a specific object. Entering a string displays an alphabetical list of objects with names beginning with that string.

Select the object you want from the list or enter the entire object name and click Go. The application expands the selection tree and highlights the selected object.

Command Buttons

Command buttons are located at the bottom of the selection tree and are not available with the Labels menu bar or toolbar options.

• Back - returns you to the previously selected object.
• Add - adds custom CDOs, CLFs, fields, tables, functions, queries, and categories.
• Rename - changes the name of user-defined CDOs, CLFs, fields, tables, functions, and queries.
• Remove - removes user-defined CDOs, CLFs, fields, tables, functions, queries, and categories.

Command buttons on the right pane are specific to the displayed definition window: CDOs and CLFs are described in the topics about those options.

Shortcut Menus

Shortcut menus are available in selected areas when you right-click your mouse. Double-clicking on selected areas display additional windows for property settings, or allows you to move to an area being referenced by the current selection. These are documented in topics throughout the guide.

Opening and Closing Designer Definition Windows

A definition window opens by default if an option on the toolbar is clicked. If another button is clicked, a definition window opens and remains in focus without closing the previous window. Multiple definition windows can be open, and you can arrange the layout of the windows through the Window option on the menu bar.

To close any definition window, click the X button. The main Designer window has another X button on the topmost right that terminates the Designer application.

Saving Database Changes

You can save changes to the database by selecting Save on the File menu. Select Save As to save changes with a different MDB name.

How to Exit Designer

To exit Designer, either select Exit on the File menu, or click the X in the upper right corner of the Designer window. A confirmation dialog box appears if you try to exit Designer without saving your changes.
