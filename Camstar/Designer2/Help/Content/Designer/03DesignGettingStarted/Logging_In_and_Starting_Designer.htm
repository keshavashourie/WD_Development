Logging In and Starting Designer

Siemens provides three default employee logins: CamstarAdmin, Administrator, and InSiteAdmin. These users must have a valid Windows account if you want to use one of them as the default login to Designer.

Before Logging In to Designer

Access to Designer is based on Windows security. Ensure Designer users have a valid Windows account and that they have been added as Designer users in Management Studio. Refer to the Opcenter Execution Medical Device and Diagnostics System Administration Guide or the Opcenter Execution Core System Administration Guide for information on adding users to Designer.

The Siemens License Server must be installed and running, and the Security Services must be running. Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information on starting services.

When Logging In and Starting Designer

The Designer Login window defaults to the name used to log on to the server the first time you log in to Designer. The Designer Login window defaults to the previous Designer user name and password for future log in attempts.

Designer does not require a user to enter a password when the Designer user name is the same as the user name used to log on to the server. Designer requires a user to enter a password when the Designer user name is different from the Windows logon user name.

An error message appears preventing you from logging into Designer if CSI is the highest active workspace. You must activate another workspace in Management Studio and then log in to Designer. Refer to the Opcenter Execution Medical Device and Diagnostics System Administration Guide or the Opcenter Execution Core System Administration Guide for information on activating workspaces.

How to Log into Designer

Follow these steps to log into Designer:

1. Click Start > Opcenter Execution MDD> Designer. The Designer Login window appears.

Or

Click Start > Opcenter Execution Core> Designer. The Designer Login window appears.

2. Keep the current User Name, or enter an authorized Designer user name.
3. Enter your Password.
4. Verify the paths to the MDBs. If the databases were moved to a different directory, enter those paths.
5. Click Login. The main Designer window appears.
