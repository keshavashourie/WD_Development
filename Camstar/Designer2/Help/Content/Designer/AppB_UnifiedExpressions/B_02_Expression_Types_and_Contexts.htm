Operator priorities

Order of processing is based on operator priorities. Parentheses can be used to override operator priorities.

Whitespace characters in expressions

Whitespaces are allowed and ignored anywhere between tokens inside expressions. Token examples are Field Names, Variable Names, keywords, operators like “>=”, and so on. Tokens must not contain whitespaces. The whitespaces inside string literals are preserved as is.

Case sensitivity

Opcenter EX MDD and Opcenter EX CR expressions are case insensitive. Nevertheless, it is recommended to use preferred spelling for variables, fields, and keywords. For instance, use “This_Value” instead of “this_value” or use “Transaction::__Return” instead of “transaction::__RETURN”.

Arithmetic expressions

Arithmetic expression semantics depends on the operand types. For integer operands integer arithmetic is applied. If an operation has both integer operand and an operand with a decimal point, then decimal point arithmetic is applied. For example, 1/4 evaluates to 0, but 1/4. (note the decimal point after 1/4) evaluates to .25.

Text variable substitution processing

The labels supported by Opcenter EX MDD and Opcenter EX CR may contain text variables that are used for error detail information, history inquiry messages, and so on. The variables are substituted either implicitly while getting a field value of a field having the Process text variables flag set (for instance, Service.CompletionMsg), or explicitly by the ExpandMessage function (for instance, HistoryMainline.DisplayName). In the former case, since the label designator is actually stored as a field value, the text variable syntax is used. An example is #Label::CompletionMoveIn is used instead of Label::CompletionMoveIn..

Text variable processing is considered as an optional step in the expression evaluation process. Refer to “Labels With Text Variables” for information.

Strings

Strings must be in double quotes.

Numbers

Numbers with decimal point are processed using decimal data type.

Operations Not Supported

Opcenter EX MDD and Opcenter EX CR expressions do not support the following operations:

• Multiplicative (%)
• Bitwise and, xor, or
