Implicit Conversion

The type conversion rules include:

• Boolean does not convert to any other data type.
• TimeStamp converts to Boolean.
• Float converts to Boolean.
• String converts to Boolean.
• Object converts to Boolean.
• Decimal converts to Boolean.
• Fixed converts to Decimal or Boolean.

Integer converts to Fixed, Decimal, Float, or Boolean. For example, if a Qty field is of type Fixed, then Qty/4 is not calculated using integer arithmetic: Literal (string) 4 is promoted to fixed type and fixed arithmetic is applied.

For an expression like Qty/4.0, Qty is promoted to Decimal type since all literals with floating point are represented as values of type "decimal." Then decimal arithmetic is applied.
