Unified Expressions

This appendix contains information on the unified expressions used by Opcenter EX MDD and Opcenter EX CR. Opcenter EX MDD and Opcenter EX CR use expressions in the following contexts:

• Current Value Expressions (CVEs)
• Default Value Expressions (DVEs)
• CLF and Function Parameters
• Path Selectors
• WIP Message Configuration
• Constants
• Computations

Unified expression syntax is not officially supported in function parameters other than the following:

All functions that have the Enforce parameter types flag set on the General tab of the Function Definition window in Designer.

• SetFieldEx
• AddItem
• CloseWhenEmpty
• New functions released with InSite 3.4 and later
