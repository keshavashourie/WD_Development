Events and Methods Procedures

You can attach a CLF to an event or create a new method. Only one CLF can be active for each event or method. You can override an existing CLF that is inherited from your current CDO.

If a CLF is attached to an event or method at your current CDO level, you must detach that CLF before you can attach another one.

Viewing Events and Methods

Events are marked with lightning bolt icons.

How to View the Events and Methods Attached to a CDO

Follow these steps to view the events and methods attached to a CDO:

1. Open Designer.
2. Click CDOs on the toolbar. The CDO Definition window appears.
3. Select the CDO for which you will view the associated events. For example, select Container.
4. Click the Events tab. The events and methods for the selected CDO are displayed:
Note: For base classes like Container, the methods defined at that class are displayed. But if you selected subclasses, the inherited methods are displayed only if you click Include inherited.
5. Click Show Variables to view the variables defined for the CDO’s methods and CLFs.

How to Attach a CLF to an Event or Method

Follow these steps to attach a CLF to an event or method:

1. Open Designer.
2. Click CDOs on the toolbar. The CDO Definition window appears.
3. Select a user-defined CDO.
4. Click the Events tab.
5. Check the Include Inherited check box to view inherited events and methods.
6. Select the event or method to which you want to attach a CLF. The Attach CLF button is enabled.
7. Click Attach CLF. The Find Definition window appears, displaying the library of available CLFs. High Performance CLFs are available for selection if you are licensed for this feature.
Note: You can also right-click on the event or method and select Attach CLF.
8. Expand the CLF category containing the needed CLF.
9. Select the desired CLF.
10. Click Select.
11. Click on the event or method you just modified to save your changes.
12. Select Save from the File menu. The application saves your changes.
13. Optionally, to view which CLF is active and which ones are overridden, click to open the event or method to which the CLF was added. The new CLF appears with a CLF icon next to it.
Note: The former CLF appears with an icon next to it, indicating that it is overridden. You can have a stack of overridden CLFs; the last CLF on the list is always the active CLF.
Note: You can reattach a CLF from the context menu instead of detaching then attaching the CLF.

How to Detach a CLF From an Event or Method

This procedure detaches a CLF previously attached, but keeps it in the CLF library, making the CLF available anytime. You cannot detach an inherited CLF.

Follow these steps to detach a CLF from an event or method:

1. Open Designer.
2. Click CDOs on the toolbar. The CDO Definition window appears.
3. Click the Events tab.
4. Select the desired CDO. The events and methods associated with the selected CDO appear.
5. Check the Include Inherited check box to view inherited events and methods.
6. Click to open the event or method from which you will detach the CLF.
7. Select the CLF to be detached.
8. Click Detach CLF or right-click on the CLF and select Detach CLF. A confirmation dialog box opens, asking you if you are sure you want to detach this CLF.
Note: If the Detach CLF button is not enabled, the CLF is inherited and can only be overridden.
9. Click Yes. The CLF is removed from the event or method. The overridden CLF that was immediately above the removed CLF becomes active (theicon is removed).
10. Select Save from the File menu. The application saves your changes.

How to Add a Method to a CDO

CDOs typically inherit all of the methods necessary to perform the desired task. However, some cases might require additional methods. When you add a method to a CDO, you are also adding a CLF that comes with the new method. The new method defaults to the name of the attached CLF. You can rename the method for your own use.

Follow these steps to add a method to a CDO:

1. Open Designer.
2. Click CDOs on the toolbar. The CDO Definition window appears.
3. Click the Events tab.
4. Select the CDO.
5. Check the Include Inherited check box to view inherited events and methods.
6. Click the New Method button, or right-click on the list of events and select New Method. The Find Definition window appears.
Note: The Find Definition window provides you a list of CLFs. High Performance CLFs are available for selection if you are licensed for this feature. The CLF will be added as a method and given the default name of the selected CLF.
7. Expand the CLF category containing the desired CLF and select that CLF.
8. Click Select. The new method appears at the bottom of the user-defined methods.
9. Rename your method if needed, as follows:
a. Select the new method.
b. Pause, then click on the new method again to place it in rename mode.
c. Enter the new name.
d. Press Enter to save your entry. The method is now available to be used.
10. Select Save from the File menu. The application saves your changes.

How to Remove a Method From a CDO

Follow these steps to remove a method from a CDO:

1. Open Designer.
2. Click CDOs on the toolbar. The CDO Definition window appears.
3. Click the Events tab.
4. Select the CDO.
5. Check the Include Inherited check box to view inherited events and methods.
6. Expand the method to be removed. The attached CLF is displayed. A stack of CLFs might be attached, but only the last one is active.
7. Select the active CLF attached to the method. (If you select the method name instead of the attached active CLF, the Detach CLF button remains disabled.)
8. Click Detach CLF. A confirmation dialog box appears, asking if you are sure you want to detach the CLF.
9. Click Yes. The last overridden CLF becomes active.
10. Repeat steps 7-9 as many times as necessary to remove a stack of overridden CLFs. The method is removed after the last attached CLF is detached.
11. Select Save from the File menu. The application saves your changes.
