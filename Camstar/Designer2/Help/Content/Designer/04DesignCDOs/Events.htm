Events

Important: This topic is related to the use of the Transaction::__Return built-in variable.

Events are triggered by the system on a CDO or a field and can be modified by either associating them with a CLF or by modifying the parameters of the functions within the CLF.

In this topic, events are grouped into CDO Events, Field Events, and List Field Events. Refer to “Common Scenarios” for information.

AfterCommit

Yes

After the transaction is committed successfully to the database.

Errors occurring in this event do not cause the service to be rolled back.

Note: When unhandled errors occur in this event, ACEStatus and ACEMessage fields are updated with the corresponding error message before the AfterCommitEventFailure event is triggered.

AfterCommitEvent

Yes

If an unhandled exception occurs in the logic attached to the AfterCommit event.

Errors can be caught with a try-catch block. Errors caught with the catch do not trigger the AfterCommitEventFailure event.

Note: When unhandled errors occur in this event, ACEStatus and ACEMessage fields are updated with the corresponding error message before the AfterCommitEventFailure event is triggered.

List Field Events

This table describes list field events and their details.

Event

Implemented

Triggered

Side Effect

AddItem

Yes

When an item is added to a list field.

Returns true or false. If the CLF returns false, the item is not added.

RemoveItem

Yes

When an item is removed from a list field.

Returns true or false. If the CLF returns false, the item is not removed.

DeleteItem

Yes

When a subentity is deleted from a list field.

Returns true or false. If the CLF returns false, the item is not deleted.

Note: RemoveItem is triggered first, then, if that returns true, DeleteItem is triggered.

MoveItem

Yes

When an item is moved within a list field.

Returns true or false. If the CLF returns false, the item is not moved.

ChangeItem

Yes

When an item in a list field is updated.

Returns true or false. If the CLF returns false, the item is not set.

GetItem

Yes

When an item is a list field is requested.

Returns a value. The CLF can override the item value and return a different value, if needed.
