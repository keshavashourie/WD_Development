Finding and Removing CDOs

The following procedures explain how to quickly find a specific CDO by entering search criteria, and how to remove a user-defined CDO subclass.

You can remove only CDO subclasses that are user-defined. If you create subclasses under subclasses, you can remove them by starting from the bottom level. The following list summarizes the steps for removing the generic CDO, but you should refer to each exercise in this chapter for detailed steps on removing specific types of CDOs.

How to Find a CDO

Follow these steps to find a CDO:

1. Open Designer.
2. Click CDOs. The CDO Definition window appears.
3. Enter the first few characters of the CDO name in the filter field above the selection tree. A list of objects containing the characters displays.
4. Locate and select the CDO you want from the list. The application expands the selection tree, highlights the selected CDO, and displays the related CDO Definition window.

How to Remove a CDO

Follow these steps to remove a user-defined CDO:

1. Open Designer.
2. Click CDOs. The CDO Definition window appears.
3. Select the user-defined CDO to be removed.
Note: The Remove button is disabled if you select a default CDO.
4. If the Remove button is disabled for a user-defined CDO, click the Where Used tab and find the CDOs that reference the CDO you want to remove and clear any field overrides. Refer to “Creating Field Overrides” for information.
Note: When you have cleared all references to the CDO you are removing, the Remove button will be enabled.
5. Click Remove, located below the CDO selection tree in the left pane. The CDO is removed.
6. Select Save from the File menu. The application saves your changes.
