CDO Definition Window

The process of configuring or adding CDOs is performed in the CDO Definition window. The structure of the classes is listed in the left window pane when you click the CDO button. The first level objects are under the BaseObject.

Click the CDOs button on the toolbar to open the CDO Definition window. The leftmost pane contains a selection tree that lists all the available CDOs. The topmost CDO, BaseObject and the Fields tab are the default selections displayed.

The Back button enables you to navigate back through your history of CDO selections.

CDO Shortcut Menu

Right-click a CDO to display the CDO shortcut menu. These tasks are available on the shortcut menu:

• Add Subclass
• Paste field–A field copied from the Fields tab of any object can be pasted into another object.

User-defined Menu Options

The disabled options are enabled after you derive and select your own subclass. You cannot modify default CDOs, but you can modify your own subclasses. These options are enabled on the shortcut menu:

• Rename a CDO Definition
• Add Associated Service CDO–enabled only for user-defined NDOs, ROs, and Subentities
• Remove CDO Definition
• Go to Database Table Definition–enabled only for persistent CDOs, default or user defined (BaseObject is not persistent, but the Container CDO is). Select the option to go to the database table definition for the selected persistent CDO.

Since BaseObject is a default CDO, other options are disabled.

Additional Menu Options

This table defines the additional options on the CDO shortcut menu.

Option

Description

Associated Start Service

Available for Container CDOs. Select it to go to the Start service CDO definition window associated with the selected container.

Associated Maintenance CDO

Available for NamedDataObject, RevisionedObject, RevisionBase, and history CDOs (generally called data CDOs). Select it to go to the Maintenance CDO definition window associated with the selected data CDO.

Associated Revision CDO

Available for RevisionBase CDOs. Select it to go to the RevisionedObject CDO definition window associated with the selected CDO.

Associated Base CDO

Available for RevisionedObject CDOs. Select it to go to the Base CDO definition window associated with the selected RevisionedObject.

Associated Data CDO

Available for Maintenance Service CDOs (in Basic View) and the Changes CDOs (in Advanced View). Select it to go to the NamedDataObject, RevisionedObject, or ServiceData CDO definition windows associated with the selected Maintenance CDO.

Associated Service CDO

Available for Subentity CDOs. Select it to find the Service CDO associated with the selected subentity.

Parent CDO Type

Available for Subentity CDOs. Select it to find the Parent CDO.
