Labels Window

The Labels window is used to view System labels and to Add, Remove, and Find User labels. You can use the buttons in the Labels window to perform these functions, or you can right-click in the selection tree area to open the shortcut menu and select the following options:

• Add Label

Add Label is active only if you selected a label from the User category.

• Remove Label

Remove Label is active only for user-defined labels.

• Find Label

Find Label is active only if you selected a defined label (label is not empty).

• Find next label

Find next label is active after you have previously selected Find Label once.

• Copy Label
• Paste Label

Clicking the Labels button on the toolbar opens the Labels window.

The right pane displays a list of labels belonging to the selected category according to label ID, label name, and default label text. The buttons below the list are used to Add, Remove, or Find labels. The Show details check box (checked by default) displays a section below the list of labels where you can modify a selected label’s name and Default Label.
