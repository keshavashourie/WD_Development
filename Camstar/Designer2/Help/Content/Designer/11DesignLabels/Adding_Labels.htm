Adding Labels

This topic describes the generic procedures to add labels. If you are adding your own field captions, you can follow the procedures here; or add the caption at the time you are adding a user field. Refer to “CDO Fields” for information.

You cannot add or remove System labels. You can only add User labels.

How to Add a Label

Follow these steps to add a label in Designer:

1. Open Designer.
2. Click Labels. The Labels window appears.
3. Select a category under User.
Note: Allow some time to retrieve the information for the category you selected. Some categories have more entries than others, requiring a few seconds to update the window.
4. Click Add. A new Labeled with a Default Label of New Label appears:

 

5. Enter a label name in the Name field. This is an alternate (and optional unique) identifier for a Label.
6. Enter a label value (the content of the label) in the Default Label field.
Note: This is the text that will appear on the User Interface. The text can include embedded text variables that are resolved at runtime. You can enter a maximum of 255 characters.
7. Click the LabelId for your new label. Your new label appears on the list in the upper right pane with the name you chose.
8. Select Save from the File menu. The application saves your changes.
