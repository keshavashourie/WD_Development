Using Labels

Using labels means you want to display the label value on the user interface. Field captions are displayed by configuring the CDO field’s properties to use a label as a caption.

Displaying labels as messages at some point during the execution of a transaction requires additional configurations. You need to have a thorough understanding of CDOs (typically Service CDOs), fields, CLFs, functions, parameters, events, and methods to be able to use labels as text messages.

This topic describes the general process of using a label to display the label text on a CDO field during transaction processing. Refer to other topics for specific steps such as creating CLFs, setting function parameters, and attaching CLFs to events and methods.

How to Use a Label

Follow these steps to use a label from the library:

1. Open Designer.
2. Create a label (for example, LabelName) or identify an existing Opcenter EX MDD or Opcenter EX CR label you want to use.
3. Select or create the Service CDO that will use the label.
4. Select or add the field that will retrieve the label value.
5. Configure the field’s properties as follows:
a. Click the Advanced Options tab.
b. Under Special Processing, click the Substitute Text Variables boolean field.
6. Create a CLF with the following configurations:
a. Add the SetFieldEx function (this is from the FieldProcessing category).
b. Set the From parameter with the following value that includes the name of the label in step 1:

#Label::LabelName

c. Set the To parameter with the name of the field in step 4. This CLF sets the value of the field to the label.
7. Select the CDO in step 3 and click the Events tab.
8. Attach the CLF you created in step 6 to an event or method.
9. Select Save from the File menu. The application saves your changes.

The above procedure shows how to use a static label. Refer to “Labels With Text Variables” for information on resolving and displaying some label values at runtime.
