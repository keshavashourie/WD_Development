Labels

Labels are used to customize messages and text, such as displayed field captions, error messages, transaction completion messages, string selection values, and so on. Field and CDO name labels are automatically added to the Labels library when you fill in the Caption field in the CDO or field definition windows with a new value.

You have the option to customize labels so that they are more meaningful to your business. Labels are categorized by label ID, name, and LabelValue. The label ID is assigned by the system at the time of label creation. The name is an optional string to identify the label. The name can be the abbreviated version of the LabelValue or it can be something more descriptive. LabelValue is the actual text that will appear on the user interface.

Your configurations in this area have a global impact as opposed to label changes made to field properties within CDOs. In CDO field properties, the change to a field label is limited to the context of the CDO. For example, changing the label for Qty within the MoveTxn CDO will not affect the label for Qty in other transactions. Changing it here will change all labels for Qty.

Labels can be changed by modifying the IssueControlEnum field captions in Designer.

Note: Either Opcenter EX MDD or Opcenter EXCR also provides the ability to create labels using the Portal for labels that do not have any relation to Opcenter EX MDD and Opcenter EX CR objects. These user labels are used in building Portal forms. Refer to the Opcenter Execution Medical Device and Diagnostics Modeling User Guide or the Opcenter Execution Core Modeling User Guide for information on user labels.
