System Labels and User Labels

There are two general types of labels: System and User.

System labels are provided with and used by Opcenter EX MDD and Opcenter EX CR. System label names have the prefix CSI. These labels are separated into various categories. Examples of the categories are:

• CSIAdminSys - These labels are used in various error messages, such as Invalid CDO Definition. This particular category has no corresponding category in the user area.
• CSIField - These labels are displayed as field captions on the Client interface such as the Portal.

User labels contain empty categories, prefixed by Other, for you to add your own user-defined labels. For most system labels, there exists a corresponding user label category. If you are customizing labels, create them under the best category that fits the field value (what the label says). Use the MiscAppText category as the last resort.

All labels are given a unique ID, enabling them to be called by this ID whenever labels are used by an application.
