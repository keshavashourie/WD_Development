Finding a Label

You can find a label using different methods:

• Using the Find Label option
• Using the Filter field
• Sorting the label list alphabetically

The Find Label option enables you to search for text matches of either the name or the default label text. You access the Find Label option by:

• Right-clicking on a label category or label subcategory in the left pane
• Right-clicking the Label ID, Name, or Default Label in the right pane
• Clicking the Find button in the right pane

You can select whether you want to search the current category or all categories, and whether you want to match case and/or match entire column when using the Find Label option. Selecting Match Entire Column indicates that the search text must match the full name or value of the label in order to be found.

To find a label using the filter field, select a subcategory in the left pane and then enter the first few characters or the entire label name in the filter field at the top of the right pane. Entering a string displays an alphabetical list of labels with names beginning with that string. Select the label you want from the list or enter the entire label name and click Go.

You can also sort the list alphabetically and scroll through the list until you find the label you want. To search by sorting alphabetically, click the column title Default Label. The list of default label text is sorted alphabetically, so you can scroll up or down the list until you find the label you want.

How to Use the Find Label Option

Follow these steps to use the Find Label option:

1. Open Designer.
2. Click Labels. The Labels definition window appears.
3. Select the label category and subcategory in the left pane to display the list of labels in the right pane.
4. Right-click the subcategory in the left pane.

Or

Right-click the Label ID, Name, or Default Label in the right pane.

Or

Click Find in the right pane. The Find Label dialog box appears.

 

5. Enter the text string in the text box.
6. Select whether you want to search in the Current Category or in All Categories.
7. Select the options to Match Case and/or Match Entire Column if needed.
8. Click Find. The label names, values, and associated workspaces appear in the Find Label dialog box.
9. Click the label you want and close the dialog box. The selected label and its details appear in the Labels definition window.
