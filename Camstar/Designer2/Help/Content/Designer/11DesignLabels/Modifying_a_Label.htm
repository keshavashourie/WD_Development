Modifying a Label

You can modify the label’s name or default label.

How to Modify a Label

Follow these steps to modify a label:

1. Open Designer.
2. Click Labels. The Labels definition window appears.
3. Expand the category to which the label belongs.
4. Select the label to be modified.
5. Modify the label’s Name or Default Label in the Details section.
6. Click the label ID on the label list to save.
7. Select Save from the File menu. The application saves your changes.
