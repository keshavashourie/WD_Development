Feature Entitlement Tab

The Feature Entitlement tab is available for CDOs, CLFs, and Functions. There are two different views of the Feature Entitlement tab; one for Entity Definition view and one for Event/Method detail view. However, the Event/Method detail view is only available for CDOs.

Refer to the Release Matrix for Opcenter EX MDD on the Siemens Support Center or the Release Matrix for Opcenter EX CR on the Siemens Support Center for a list of standard and optional features included by default.

Entity Definition View

When you select an entity, such as a CDO, you can view the Feature Entitlement tab. When you select the Feature Entitlement tab, there is a Feature Membership field that displays the feature entitlement membership for the entity. Newly added CLFs and Functions default to the default feature set associated with the corresponding workspace. You can select an alternate entitled feature when adding a new entity. The Feature Membership field only provides features that are entitled in the current active workspace. Refer to the Opcenter Execution Medical Device and Diagnostics System Administration Guide or the Opcenter Execution Core System Administration Guide for information on entitling features in your highest active workspace.

Note: The feature membership defaults to the base feature entitlement when you override an existing CDO that has feature membership.

Event/Method Detail View

You can also view feature entitlement information for CDO entities on the Events tab.

How to View Feature Entitlement on the Events Tab

Follow these steps to view feature entitlement on the Events tab:

1. Select a CDO.
2. Click the Events tab.
3. Select Details.
4. Select an event. The Feature Entitlement field displays the feature membership for the selected event.
