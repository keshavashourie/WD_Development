License Management

Opcenter EX MDD and Opcenter EX CR contain the base product. It also includes individual products and modules you can license separately. You need a valid license file and serial number to install Opcenter EX MDD or Opcenter EX CR. You must also install the Siemens License Server using the Siemens Licensing application.

The license file is generated based on the products and modules you licensed when you purchased Opcenter EX MDD or Opcenter EX CR. There is one license file. You need the license file to install the Siemens License Server.

The serial number is the key you enter when installing Opcenter EX MDD or Opcenter EX CR. It determines the products and modules available for installation. Your unique serial number includes any additional products or modules you purchased. If you do not purchase any additional modules, then all entities related to these modules will appear red in Designer.

Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information on licensing.

License Server

Designer utilizes the Siemens License Server. A new Windows service is created after you install the server. Designer requires the license server.

License Key File

The license file contains the runtime license for the server and the Designer. The license server validates you are entitled to use separately licensed modules. If the license server is not available, you will be unable to use these features.

Note: You can upgrade an existing Opcenter EX MDD or Opcenter EX CR installation to include additional modules if you have a new license file and new serial number. Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information.

Licensing affects how different entities perform when selected in Designer. The Designer topic in the next section describes the behavior of entities with feature licensing installed.

Note: A red icon next to an entity in Designer indicates the module is not licensed or the license server is not available. A yellow icon indicates a separately licensed module that has been properly licensed.

Updating License Keys

Opcenter EX MDD and Opcenter EX CR allow you to update a production license without having to take the server down. You can generate a temporary license in event of emergency; for example, if you are locked out of of Opcenter EX MDD or Opcenter EX CR due to expiration. Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information.

Follow these steps to update the license keys:

1. Generate a temporary license file.
2. Replace the license file with the temporary file on the license server using the licensing application.
Note: This does not disturb the running security server or the application server. The security server will use the new license information when it performs its periodic license refresh and expiration check.
