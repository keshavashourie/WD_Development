Designer

Colored icons indicate which items are licensed or not licensed in Designer.

Configurable Data Objects (CDOs)

If you select a licensed CDO:

• You can make modifications to the CDO. Refer to "Configurable Data Objects" for information.
• However, you cannot add an object reference field that references a restricted or unlicensed CDO.

If you select an unlicensed CDO:

• Designer only allows you to view the Feature Entitlement tab. You cannot view the other tabs for a CDO.
• No changes are allowed to the CDO or its associated objects (such as fields, maps, or events/methods).

Different colored icons are used to indicate the status of each individual CDO.

Adding a New CDO Field

The field icon in the Add a New CDO Field window indicates whether the field references a standard CDO (green), licensed CDO (yellow), or unlicensed CDO (red). You cannot add a field that references an unlicensed CDO.


CDO Find Definition Window

The Find Definition window appears when you are attaching a CLF or adding a new Method. The Find Definition window filters out unlicensed CLFs and Functions. Therefore, you only see base CLFs and licensed entities in this window. Base CLFs are green while licensed CLFs are yellow.

CDO Field Properties

Only standard and licensed CLFs are shown in the Field Properties window.

The Events tab of the CDO Field Properties window displays a list of events associated with the field. The yellow lightning bolt indicates default events. These events are not restricted. However, it is possible for a default event to have a restricted CLF attached to it.

Configurable Logic Flows (CLFs)

If you select a licensed CLF definition:

• You can make changes exactly as described in "Modifying Default Function Parameter Values for a CLF."
• However, you cannot attach an unlicensed CLF to an event or method.

If you select an unlicensed CLF definition:

• Designer only allows you to view the Feature Entitlement tab. You cannot view the other tabs for a CLF.
• You cannot expand an event, method, CLF, or CLF function. You will receive a warning message if you try to expand them.

Functions

If you select a licensed function:

• You can make changes exactly as described in the chapter on CLFs.

If you select an unlicensed function:

• Designer only allows you to view the Feature Entitlement tab. You cannot view the other tabs for a function.
• You cannot view details such as GUID and parameters.
