Categories Window

Clicking the Categories button on the Designer toolbar opens the Category Definition window.

The left pane contains a selection tree that lists all the available categories. Right-click on this selection pane to open a shortcut menu with the following options:

• Add Category Definition
• Remove Category Definition

Categories Window Field Definitions

This table defines the fields on the Categories window.

Field

Definition

Type

Description

Contains documentation on how the tables in this category are used.

Optional

Default Table Type

Identifies the type of database table being defined. Each type corresponds to specific processing implemented by the System.

Display Only

Enable DataStore Propagation

Allows information to be written to DataStore tables.

Optional

Exposed to table category

If you select this check box, the category will be defined as a table category. Users can set this attribute only for user-defined categories.

Optional

Exposed to storage category

If you select this check box, the category will be defined as a storage category. Users can set this attribute only for user-defined categories.
