Categories

The Categories window is used to define new Storage and Table categories. The categories are:

• History

This category pertains to information on service history.

• Modeling

If you select the Modeling storage category for your CDO, an IsFrozen field will be added to the CDO if it does not exist.

• None

This storage category indicates that the object is nonpersistent and does not need data to be stored in the database.

• System
• Tracking
• Undefined

This storage category indicates that the CDO can later be assigned to any table category.

• Unknown

Tables in this category are possibly orphaned tables remaining from a CDO with a list field reference that is no longer in use. The reason may be that the field or even the CDO owning the field has been removed from the object model. The user needs to decide whether to keep and reclassify the table, or simply remove its definition as it is no longer in needed. Users are not expected to add tables to the Unknown category.
