Finding Categories

You can use the find feature to locate a particular category. This is especially useful when you have a lot of categories defined.

How to Find a Category

Follow these steps to find a category:

1. Open Designer.
2. Click Categories. The Category definition window appears.
3. Enter the first few characters of the category name in the filter field above the selection tree.A list of categories containing the characters displays.
4. Locate and select the category you want from the list. The application highlights the selected category and displays the related Category Definition window.
