Adding Designer Queries

You can add custom queries that use statements and object definitions in Designer.

When Adding Designer Queries

Workspace prefixes are automatically inserted before the name of an item when adding a new item, if a prefix has been assigned to the highest active workspace. Workspace prefixes indicate which workspace Designer is applying changes to. For example, the prefix "C200" would be associated to the workspace with a prefix set as "C200" in Management Studio. It is recommended you use the prefix supplied by Designer when adding new items.

You can assign or modify workspace prefixes in Management Studio. Refer to the Opcenter Execution Medical Device and Diagnostics System Administration Guide or the Opcenter Execution Core System Administration Guide for information.

Note: The base application workspace (csi) cannot have a workspace prefix assigned to it.

How to Add a Query

Follow these steps to add a query:

1. Open Designer.
2. Click Queries. The Query Definition window appears.
3. Select a query category in the left pane and click Add.
4. Enter a query name.
5. Click the General tab and enter a description for the query.
6. Click the Details tab.
7. Select the appropriate database.
8. Enter your query text in the Query text pane.
Note: You can use the SELECT, FROM, WHERE and other statement buttons, located at the bottom of the Query text pane, to more quickly enter your query text. You can also select an object definition from the selection tree to display the objects fields. Double-click an object name or field name to enter it in the query text.
9. As an option, you can select another database from the list and enter query text for that database.
10. Select Save from the File menu. The application saves your changes.
