Parameters Tab

The Parameters tab displays the parameters of the selected query.

Parameters Tab Field Definitions

This table defines the fields on the Parameters tab.

Field

Definition

Type

Query Text

Displays the text of the query as it appears on the Details tab.

Display Only

Name

Contains the name of this parameter, used to provide Parameter Values (in name-value pairs) at runtime. The name must be unique within the context of the associated Query Definition. When you select a parameter from the list, its occurrence in the Query is highlighted in blue.

Display Only

Type

Identifies the data type of the parameter.

Display Only

Input

Indicates whether the query parameter is an input type.

Display Only

Parameter details

Name

Displays the parameter name.

Optional

Data Type

Displays the data type assigned to this parameter, for example, Boolean or String.

Optional

List Field

Displays the list field assigned to this parameter.

Optional

You can change the Parameter name and data type of user-defined queries in the Parameter Details area. If the parameter is an object, use the data type Object; otherwise, the server will not convert it to a hex ID.
