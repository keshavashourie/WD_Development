Queries Window

Clicking the Queries button on the toolbar opens the Query Definition window.

Window Areas

The Query Definition window is divided into left and right panes.

The left pane contains a selection tree that shows the query categories: Advanced Queries, CDO Queries, NonQuery SQL Statements, and SQL Queries. You can expand each category to display the queries within that category.

You can also access a shortcut menu by right-clicking in the left pane. The shortcut menu options are:

• Add Query Definition
• Rename Query Definition (disabled for default queries)
• Find Query Definition
• Remove Query Definition (disabled for default queries)
• Copy Query Definition (enabled if you expand a category and select a query)

The right pane contains tabs, each of which displays specific details about the selected query. The tab names are:

• General Tab
• Details Tab
• Parameters Tab
• Where Used Tab

A question mark icon precedes a query name in the selection tree. A double question mark icon before the query name indicates that multiple versions of the query statement have been defined to handle scenarios where the different types of databases require different query syntax.

NonQuery SQL Statements Type

The Designer NonQuery SQL statements type is used when executing SQL statements that are not SELECTs. For example, the Mass Update functionality can use UPDATE statements or stored procedures as part of the business logic.

For Oracle, use an anonymous block by surrounding the stored procedure call with a BEGIN and END:

BEGIN MyStoreProcedure (?Parm1,?Parm2); END

To call a stored procedure in SQL Server, use the EXEC syntax without parenthesis:

EXEC MyStoredProcedure ?Parm1,?Parm2;

The NonQuery SQL statements type can only be defined and executed as a Designer query and not as a user query or an ad-hoc query.
