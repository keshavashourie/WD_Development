Queries

Either Opcenter EX MDD or Opcenter EX CR provides four categories of queries:

• Advanced Queries
• CDO Queries
• NonQuery SQL Statements
• SQL Queries

The benefit of executing queries through the system are that you can use:

• The existing database connection from either Opcenter EX MDD or Opcenter EX CR to the database server instead of creating a new database connection to run queries.
• Integrated Opcenter EX MDD and Opcenter EX CR security instead of depending on database server security.

SQL queries and CDO queries are maintained in Opcenter EX MDD and Opcenter EX CR for backward compatibility only. When writing new queries, Siemens recommends that you write advanced queries.
