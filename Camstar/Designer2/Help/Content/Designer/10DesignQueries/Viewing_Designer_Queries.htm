Viewing Designer Queries

You can view queries using the Designer Queries button on the toolbar. Creating queries requires knowledge of SQL statements.

How to View Queries

Follow these steps to view queries:

1. Open Designer.
2. Click Queries. The Query Definition window appears. All the Designer queries are stored here.
3. Click + next to a category to expand it.
4. Select the query you want to view. The query statements for the selected query appears in the upper pane on the right. The various tables and corresponding columns appear in the lower panes of the Details tab.
