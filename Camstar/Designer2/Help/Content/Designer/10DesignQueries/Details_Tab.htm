Details Tab

The Details tab displays the query statement for the selected query. Use this tab when you want to update a query statement.

Details Tab Field Definitions

This table defines the fields on the Details tab.

Field

Definition

Database

Queries whose syntax is identical for all supported databases include a single Query text entry under the Standard database entry.

Queries that require database-specific syntax also include query text for one or more of the specific databases. If database-specific query text has not been provided for a particular database, the system will use the Standard query text.

Use the Database list to specify which query text you would like to view or modify.

Query Text

Contains the query statements. Use the buttons below the field to add commonly used words and symbols in query statements instead of typing them.

Default limit for this field is 4000 characters. This default is determined by the Precision field on the DB Column Properties window of the Columns tab.

This table defines fields on the Details tab for Advanced and CDO queries.

Field

Definition

Object Definitions

Contains all existing objects within Opcenter EX MDD or Opcenter EX CR. When creating your own predefined queries, you can select an object definition. The CDO fields are then displayed in the Fields list box.

Fields

Displays the fields of the object selected in the Object definitions list box. Use this to build the text of your predefined query.
