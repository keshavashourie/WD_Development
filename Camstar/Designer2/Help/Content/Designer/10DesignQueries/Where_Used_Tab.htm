Where Used Tab

The Where Used tab displays the CDOs that use the selected query.

Where Used Tab Field Definitions

This table defines the fields on the Where Used tab.

Field

Definition

Type

CDO Name

Indicates the CDOs that use the query. If the CDO shown has subclasses, then all of its subclasses use the query unless this is overridden at the subclass.

to open the definition window for this CDO, double-click the CDO name.

Display Only

CDO Name, Field Name

Indicates the CDO fields that use the query.

Display Only

CDOName, EventName, CLFName, FunctionName

Indicates the CDO event that uses the query.

Display Only

CDOName, FieldName, EventName, CLFName

Indicates the CDO field event that uses the query.

Display Only
