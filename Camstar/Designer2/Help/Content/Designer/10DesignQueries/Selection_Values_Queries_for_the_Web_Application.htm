Selection Values Queries for the Portal

Requirements

In the Portal, certain rules apply when building selection values queries. The columns in this table must be present for a given query for the Portal to process the queries correctly.

Query

Column

SelectionValuesEx_NDO

InstanceID, Name

SelectionValuesEx_RDO

InstanceID, Name, Revision, RevOfRcd, Status

SelectionValuesEx_NSEofNDO

InstanceID, Name

SelectionValuesEx_NSEofRDO

InstanceID, Name

Examples

If you are retrieving the Operation and the column for the name is called OperationName, then you must retrieve it with the following SQL statement:

Select OperationName As "Name" From Operation

Filter Tags

Many selection values queries contain filter tag logic by default. You can add filter tag logic to other selection values and custom queries by including this code in your where clause, where "$$cdo" is an alias to the CDO referenced in the query:

a. ##csiFilterTagMatch($$cdo.FilterTags, ? __filterTags, ? __allowUntaggedInstances) = 1

Important: Deleting a filter tag or removing filter tag logic may render instances that reference the deleted tag or logic unusable in the application.
