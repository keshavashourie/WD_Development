Field Type Definitions

Field type definitions function as a data dictionary, providing a finite set of data elements that are used in the Opcenter EX MDD and Opcenter EX CR. All CDO fields are based on the set of data elements defined by this data dictionary. Field types are grouped under data types.

This topic discusses the following:

• Data Type and Field Type
• Field Type Properties
• Adding or Modifying Field Types

Workspace prefixes are automatically inserted before the name of an item when adding a new item, if a prefix has been assigned to the highest active workspace. Workspace prefixes indicate which workspace Designer is applying changes to. For example, the prefix "C200" would be associated to the workspace with a prefix set as "C200" in Management Studio. It is recommended you use the prefix supplied by Designer when adding new items.

You can assign or modify workspace prefixes in Management Studio. Refer to the Opcenter Execution Medical Device and Diagnostics System Administration Guide or the Opcenter Execution Core System Administration Guide for information.

Note: The base application workspace (csi) cannot have a workspace prefix assigned to it.

Data Type and Field Type

Data Type is the element by which field types are categorized. Each data type yields a list of available field types that are used to define unique fields.

This table provides the data type, definition, and the field type for each data type definition.

Data Type

Definition

Field Types

Boolean

True or False

[Boolean], IsEnabled, IsFrozen, IsRevisionOfRecord

Decimal

Fixed point type, an exact numeric value as opposed to an approximate numeric type like float or real. It is defined by a precision and scale. The precision p refers to the overall number of digits both to the left and right of the decimal point. The scale s refers to the number of digits to the right of the decimal point, also referred to as fractional component.

When working with the Decimal data type, consider the following guidelines:

• The application server supports a maximum precision of 29, which is the static default setting, and a dynamic scale. Exceeding precision will result in an exception when saving the definition.
• The Designer-specified values for precision and scale are ignored by the application server.
• The Designer-specified values for precision and scale are enforced by the database management system (DBMS). Exceeding precision or scale handling is dependent on the DBMS that you are using. Consult your database administrator or database reference manual for details on decimal types, limitations, and error handling.
• As long as the decimal value is in the Server cache, the cached value is returned, even if it exceeds the scale defined for the database column.
• The Change Attribute service requires configuration to support the Decimal data type. This is because the history table’s column must match the decimal type specification of the field that is to be changed.

[Decimal]

Fixed

Fixed number of decimal and whole number positions. The fixed data type is used to store a fixed point number as a floating point number in the database. A floating point value is an approximation of a fixed point value. Note that a Decimal type is available and should be used to store an exact numeric value with defined precision and scale.

[Fixed], Cost, Percentage, Qty, Qty2, Yield

Field Type Properties

Field type properties make up the field type definition. All fields of the same type inherit the field properties until they are overridden. This table lists the field properties and the data types that have these properties.

Property

Definition

Data Types

Enumeration

Series of elements that can be based on one of any basic data type. It is implemented as subclasses to the Enumeration CDO type. The elements are represented by the fields and the order is assigned by the default value.

All data types except Object

Precision

Number of digits allowed in a number. Precision is currently supported only for the Decimal data type.

Decimal, Fixed, Float, Integer

Scale

Number of digits to the right of the decimal in a float field. For example, the number 123.45 has a precision of 5 and a scale of 2. Scale is currently supported only for the Decimal data type.

Decimal, Fixed, Float

Maximum length

Field length by number of characters for string fields. For example, if you design a field to have a maximum length of 5 for five characters and a user types six characters when defining instances in a client application, the system returns an error message.

String

How to View Field Types

Follow these steps to view field types:

1. Open Designer.
2. Click Fields. The Field Type Definitions window appears.
3. Expand each data type to view the available field types.

How to Add a Field Type

Follow these steps to add a field type in Designer:

1. Click Fields. The Field Type Definitions window appears.
2. Select the data type category to add a field type.
Note: You cannot add a field type directly to the Object data type. A field type for Object is automatically created when you add a CDO subclass.
3. Click Add. A new field type appears.
4. Name the field.
5. Enter a description in the Description field.
6. Select a data type from Data Type on the right or keep the default.
Note: If you change the data type, the field type you are defining is saved under the new data type. Designer additionally instructs you on how to make changes to the database column, in case the field is associated with a database column.
7. Set the other attributes for the field type.
Note: If you specify a maximum length for string fields, Designer additionally instructs you on how to change database column size, in case the field is associated with a database column.
8. Select Save from the File menu. The application saves your changes.

How to Modify Field Type Properties

If you modify an existing field property, it is automatically applied. For example, the field type for Revision falls within the String data type category and has a 15-character string length. If your revision data element requires a 3-character string, you can modify the field type by changing the property of the 15-character string to a 3-character string within the field type definition.

Follow these steps to modify field type properties in Designer:

1. Click Fields. The Field Type Definitions window appears.
2. Expand the data type category that contains the field type definition.
3. Select the field type definition to be modified.
4. Change the properties.
Important: The field type information is used when creating a column definition. Once the column is defined, changes to the field type do not affect the column. You need to manually update the column definition as appropriate.
5. Select Save from the File menu. The application saves your changes.

How to Update the Column Definition

Follow these steps to update the column definition:

1. Select the field type.
2. Click the WhereUsed tab.
3. Double-click the name of the column to be modified to open the DB Column Properties window.
4. Modify the column properties.
Note: Refer to “Tables” for information about using tables and table columns.
5. Select Save from the File menu. The application saves your changes.
