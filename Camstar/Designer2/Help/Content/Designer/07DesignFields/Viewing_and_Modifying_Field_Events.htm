Viewing and Modifying Field Events

Field events are events that are attached to a CDO field. Refer to “Events and Methods” for information about viewing events.

How to View Field Events

Follow these steps to view field events:

1. Open the Designer toolbar.
2. Click CDOs. The CDO Definition window appears.
3. Double-click any CDO in the list.
4. Select the Fields tab. The CDO Fields window appears, displaying the fields unique to this CDO.
5. Select Include Inherited fields to view fields inherited from the base class.
6. Select the field whose events you want to view.
7. Click the Properties button on this Fields window. The CDO Field Properties window opens.
8. Click the Events tab. Any events attached to the field are displayed:
9. Select Include Inherited to view events inherited from the parent class if the field you selected is inherited. The inherited events associated with the selected field appear.
10. Select Cancel to close the Field Events window.

Modifying Field Events

You can attach CLFs to field events and detach user-defined CLFs. You cannot attach High Performance CLFs to field events. Refer to “Configurable Logic Flows” for information about using CLFs.

How to Attach a CLF to a Field Event

Follow these steps to attach a CLF to a field event:

1. Open the Designer toolbar.
2. Click CDOs. The CDO Definition window appears.
3. Select any CDO from the list.
4. Select the Fields tab. The CDO Fields window appears, displaying the fields unique to this CDO.
5. Select Include inherited fields to view fields inherited from the base class.
6. Select the field whose events you want to view.
7. Click the Properties button on this Fields window. The CDO Field Properties window appears.
8. Click the Events tab. Any events attached to the field are displayed:
9. Select Include inherited to view events inherited from the base class. The events associated with the selected field appear.
10. Select the event to which you want to attach a CLF. The Attach CLF button is enabled.
11. Click Attach CLF. The Find Definition window opens, displaying the library of available CLFs:
12. Expand the CLF category containing the desired CLF.
13. Select the appropriate CLF and click Select. The selected CLF is attached to the selected event.
14. Click OK.
15. Select Save from the File menu. The application saves your changes.

How to Detach a CLF from a Field Event

You can only detach user-defined CLFs from field events. Follow these steps to detach a CLF from a field event:

1. Open the Designer toolbar.
2. Click CDOs. The CDO Definition window appears.
3. Select any CDO.
4. Select the Fields tab. The CDO Fields window appears, displaying the fields unique to this CDO.
5. Select Include inherited fields to view fields inherited from the base class.
6. Select the field whose events you want to view.
7. Click the Properties button on this Fields window. The CDO Field Properties window appears.
8. Click the Events tab on the Properties window. The window shows any events attached to the field.
9. Select Include inherited to view events inherited from the parent class. The events associated with the selected field appear.
10. Select the event from which you want to detach a CLF. The Detach CLF button is enabled.
11. Click Detach CLF.
12. Click OK.
13. Select Save from the File menu. The application saves your changes.
