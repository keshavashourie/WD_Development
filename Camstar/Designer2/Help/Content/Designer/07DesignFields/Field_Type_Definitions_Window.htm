Field Type Definitions Window

The Fields button on the toolbar opens the Field Type Definition window.

Field Type Definition Window Field Definitions

The leftmost pane contains a selection tree that lists all the available categories of field types. Expanding a category displays more specific field type definitions. Right-click on a field type to perform the following tasks:

• Add Field Definition
• Rename Field Definition
• Remove Field Definition

Rename Field Definition and Remove Field Definition are disabled for default field types.

The rightmost pane contains details about the selected field type definition. The pane has the following tabs:

• General Tab
• Where Used Tab

Enumeration

A series of elements that can be based on any data type. It is implemented as subclasses to the Enumeration CDO type. The elements are represented by the fields and the order is assigned by the default value.

Optional

Additionally, some field types have other attributes:

• Precision

The overall number of digits both to the left and right of the decimal point, and is supported for the decimal data type.

• Scale

The number of digits to the right of the decimal point, and is supported for the decimal data type.

• Maximum Length

The number of characters that can be entered for a string field. All fields are display-only for Siemens field type definitions, but are enabled for user definitions.

Where Used Tab Tables

The Where Used tab displays two types of information: CDOs where a selected field type is used and database tables and columns where a field type is used. Double-click a CDO or table name in the list to go to that CDO’s or table's definition window.
