Viewing Field Selection Values

Fields can be configured to offer a list of values, obtained through an Opcenter EX MDD or Opcenter EX CR selection values query, from which a user can select a value. In the Selection Values tab, you can choose from the most commonly used options for generating selection values for a field. Opcenter EX MDD and Opcenter EX CR automatically attach the corresponding Selection Values CLF to the field.

If the field already has a Selection Values CLF attached to it, that CLF name will appear in the list of Selection Values options.

Selection values are set in the Service object or the Changes object. There are two groups of Selection Values:

• Basic
Basic Selection Values are used with ServerLink, the InSite COM Client. They are maintained for backward compatibility only to give time for current users to redefine their selection values using the Extended Selection Values. Use the Extended Selection Values For new definitions in Opcenter EX MDD or Opcenter EX CR.
• Extended
For fields with selection values defined, extended selection values is the default in the Selection Values tab. Many, but not all, query names for extended selection values start with SelectionValuesEx. Extended Selection Values use the XML Application Server for processing and are not supported by ServerLink.

Five options for determining selection values are available:

• Static Selection Values
• Query Selection Values
• List Field Selection Values
• Enumeration Selection Values
Note: Extended Selection Values default to “Static” when adding an NDO, RO, or enumeration field to a Modeling changes CDO or Shop Floor Service CDO.

Notice that this field, TextVariableChanges.VariableUsage, is a CDO field, and already has its selection values determined by the Enumeration method. Its key values (for storage purposes) and its display strings are already defined. You can change any display string by retyping that field in this window, with some fields containing entered literals (no quotes needed) and others containing field names.

• CLF Selection Values
The Selection Values options available through this window are explained in the following sections.

Static Selection Values

This topic explains how to use the Static Selection Values option to display all the instances of objects that have the same Field Type. The Static option does not allow you to change the Selection Values Query. It uses the Selection Values definition of the field’s type.

When you add a CDO, it is also added as a field type within the Object data type. When you set a Selection Value for the CDO in the CDO Definition window, it is this selection value that becomes the selection value of that field type.

The entry in the Selection Values Query field changes according to the field type.

How to View the Static Selection Values Option

Follow these steps to view the static selection values option in Designer:

1. Select the CDO containing the desired field.
2. Click on the Fields tab for this CDO in the CDO Definition window.
3. Select the desired field in the CDO.
4. Click the Properties button on the Fields tab. The CDO Field Properties window appears.
5. Click the Selection Values tab on the CDO Field Properties window.
6. Click Cancel to close the window.

Query Selection Values

This option allows you to define a field’s selection values based on a query. This table defines the different queries.

Query

Definition

ContainerHistoryMainlines_ASCEx

Gets HistoryMainline records for a specific Container and sorts by the oldest transactions first.

ContainerHistoryMainlines_DescEx

Gets HistoryMainline records for a specific Container and sorts by most recent transactions first.

GetContainersForMfgOrder

Retrieves all container names for a specified manufacturing order.

GetHistoryObjects

Returns the History objects. It is used by the Audit Trail application.

GetLabelIDbyCategoryValueNameFilter

Retrieves all label Ids based on the specified category ID, value filter, and name filter.

GetLocalSite

Retrieves the Instance ID of the local site.

MfgCalShiftMaint_LoadShifts

Loads a subset of CalendarShift based on the MfgCalendar and the start/end time stamp.

SelectionValuesEx_AllQueryDefs

Retrieves all selection values for all query definitions by query name.

SelectionValuesEx_AssociateCandidates

Retrieves a list of containers eligible to be associated with the specified container.

SelectionValuesEx_CombineCandidates

Retrieves a list of child containers eligible to be combined with the specified container.

SelectionValuesEx_DisassociateCandidates

Retrieves a list of child containers eligible to be disassociated from the specified container.

SelectionValuesEx_Enumeration

Retrieves Enumeration objects.

SelectionValuesEx_IssueActuals_FromContainer

Retrieves containers that are eligible to be issued to the selected container. Returned containers match the following criteria: they are not on hold, are active, and the Product attribute matches the bill of material item’s Product (or a valid substitute).

SelectionValuesEx_LabelCategory

Retrieves the selection values of Category field of DictionaryMaint based on the meta table LabelCategory.

SelectionValuesEx_NDO

Retrieves the selection values of a named data object.

SelectionValuesEx_NSEofNDO

Retrieves the selection values of a named subentity whose parent is of named data object type.

SelectionValuesEx_NSEofRDO

Retrieves the selection values of a named subentity whose parent is of revisioned object type.

SelectionValuesEx_RDO

Retrieves the selection values of a revisioned object.

SelectionValuesEx_Resource

Retrieves a list of all resources.

SelectionValuesEx_SplitCandidates

Retrieves a list of child containers eligible to be split from the specified container.

Refer to “Queries” for information about defining queries.

List Field Selection Values

List Field selection values are used to retrieve a list of values for a list field. Either Opcenter EX MDD or Opcenter EX CR uses CLFs to retrieve the list and does not have a default example of a field using the List Field option. The following procedure explains how to set up selection values based on a specified list field. The example uses a user-defined field that references a list of named data objects.

How to Use the ListField Extended Selection Values Option

Follow these steps to use the ListField Extended Selection Values option in Designer:

1. Click CDOs. The CDO Definition window appears.
2. Select the CDO for whose list field you want to set selection values.
3. Select the Fields tab if it is not already selected.
4. Select the list field and click Properties. The CDO Field Properties window appears.
5. Select the Selection Values tab.
6. Select ListField: selection values are based on a specified list field from the list.
7. Type an expression in the field labeled Field expression for the list field.

Or

8. Click Build to open the Expression Builder. Refer to "Unified Expressions" for information.
9. Select a field from the list under Available Fields, and then click Add to add additional information on each object on the list. The field is added to Fields to include.
10. Enter the expression in the Available Fields to add a field expression.

Or

11. Click Build to open the Expression Builder.
12. Click Add to add the expression to Fields to include.
Note: If the referenced object is an NDO, the fields to include are Name and InstanceID. If the object is an RO. the fields are Name, Revision, RevOfRcd, InstanceID, and Status.
13. Select Save from the File menu. The application saves your changes.

Enumeration Selection Values

This topic explains how to set up selection values using a list of strings as input.

How to View the Selection Values Enumeration Option

Follow these steps to view the Selection Values Enumeration option:

1. Select the CDO.

For this example, Enterprise is selected.

2. Click the Fields tab if not already displayed.
3. Select the field in the CDO.

For this example, the EntDecimal field is selected.

4. Click the Properties button on the Fields tab. The CDOField Properties window appears.
5. Click the Selection Values tab on the CDO Field Properties window.
6. Select the method to determine selection values.

For this example, Enumeration: selection values are based on a static list of (Value, Display String) pairs is selected.

7. Enter a value in the first column of the row.
8. Do you want to enter a display string or select a label?

If you want to . . .

Then . . .

Enter a display string
a. Enter the display string (without quotation marks) in the second column.

Select a label
a. Double-click in the second column. The Select a Label dialog box appears.
b. Select a label and click Select. The label appears in the second column.
9. Repeat steps 7-8 for each value.
10. Click OK.
11. Select Save from the File menu. The application saves your changes.

CLF Selection Values

This option directs the user to maintain the CLF through Field Events.

To examine the field event to which the CLF is attached, click the Events tab on the properties window and expand the SelectValuesEx event.

How to Attach a Selection Value to a Field

Follow these steps to attach a selection value to a field:

1. Open the Designer toolbar.
2. Click CDOs. The CDO Definition window appears.
3. Select the CDO containing the field to which you want to attach selection values.
4. Click the Fields tab in the CDO Definition window.
5. Select a user-defined list field and click Properties. The CDO Field Properties window appears.
6. Click the Selection Values tab. The Selection Values tab is displayed.
7. In the Extended Selection Values area, click the list to select a method for determining selection values. The area below the list box changes according to the option you select.
8. Click OK to save your selection.
9. Select Save from the File menu. The application saves your changes.
