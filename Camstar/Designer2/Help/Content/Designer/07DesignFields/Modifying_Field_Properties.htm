Modifying Field Properties

The modification is an override if the field you want to modify is inherited. Refer to "Creating Field Overrides" for information on modifying inherited fields.

Making changes to field properties does not update the associated column in the Opcenter EX MDD or Opcenter EX CR table that stores that field. You must select the field’s Where Used tab to view the tables that use this field. Then make the same property change to all the affected tables. Refer to "Tables" for information on accessing the tables.

How to Modify Field Properties

Follow these steps to modify field properties:

1. Open the Designer toolbar.
2. Click CDOs. The CDO Definition window appears.
3. With a CDO selected in the CDO Definition window, select the Fields tab.
4. Select the field whose properties you will modify.
5. Click Properties. The CDO Field Properties window appears.
6. Change any field properties you want to modify according to your business requirements.
7. If you are modifying an NDO or RO field property, click the Apply the same changes to the corresponding field in the associated Maintenance transaction check box.
8. Click OK.
9. Apply the Designer changes.
10. Select Save from the File menu. The application saves your changes.
