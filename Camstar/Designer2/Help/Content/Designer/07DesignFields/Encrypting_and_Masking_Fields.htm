Encrypting and Masking Fields

You can encrypt field values before transmitting data. Encryption is useful when you transmit user passwords, WIP messages, Electronic Signatures, or other information, as sensitive information is secure even in troubleshooting situations. Field encryption impacts:

• XML transaction documents
• Transaction trace logs
• DBMON window

When Encrypting Fields

Using Password under Field Usage on the Options tab, you can encrypt fields; however, only one field for each CDO can be encrypted. Refer to “Options Tab Field Definitions” for information about the Options tab’s fields.

How to Encrypt a Field

Follow these steps to encrypt a field:

1. Click the CDOs button. The CDO Definition window appears.
2. Select the CDO in the left pane.
3. Select a field to encrypt from the Field name list, and click the Properties button. The CDO Field Properties window appears.
Important: You can only encrypt a field where it is initially defined, not in a subclass, for example, override.
4. Click the Options tab.
5. Select Write-Only in the Accessibility area.

Or

6. Select Read/Write in the Accessibility area.
7. Select Password from the Field Usage list.
8. Click OK.
9. Apply the Designer changes.
Note: Using the Field Directory or Toolbox, you can add encrypted fields to the form.
10. Select Save from the File menu. The application saves your changes.

Masking Fields

You can mask fields in the Portal, and bullets will display when you enter values in a field. If an object that includes a masked field is retrieved or displayed:

• The field appears blank.
• If a new value is entered, it is encrypted and sent as part of the request data for the transaction.
• If no value is entered, the field is not sent as part of the request data for the transaction and the current value is retained.
• If one or more spaces are entered, the field is sent as part of the request data for the transaction and has a null value in the database.

When Masking Fields

You can mask fields by selecting Password under Field type on the General tab. Refer to “CDO Field Properties” for information about the General tab’s fields.

How to Mask a Field

Follow these steps to mask a field:

1. Click the CDOs button. The CDO Definition window appears.
2. Select the CDO in the left pane.
3. Select a field to mask from the Field name list, and then click the Properties button. The CDO Field Properties window appears.
4. Click the General tab.
5. Select String from the Data Type list, and then select Password from the Field type list.
6. Click OK.
7. Apply Designer changes.
Note: Using the Field Directory or Toolbox, you can add masked fields to the form.
8. Select Save from the File menu. The application saves your changes.
