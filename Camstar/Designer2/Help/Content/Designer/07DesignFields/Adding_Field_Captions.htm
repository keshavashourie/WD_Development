Adding Field Captions

Define CDO field captions in the General tab on the CDO Field Properties window.

How to Enter a Field Caption

Follow these steps to enter a field caption in Designer:

1. Access the CDO Field Properties window, and then select the General tab.
2. Select the desired label for the Caption field.
3. Enter it into this field.

Or

Click the button beside the field to select from the list of labels.

4. Click OK. If you enter a new caption rather than select from the list, it is saved in the Labels library under the User label category, Other Field, and is also available in the list.
5. Select Save from the File menu. The application saves your changes.
