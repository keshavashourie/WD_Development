Viewing Field Maps

A map is a link between two CDOs that allows field values to be passed from the source CDO field to the target CDO field. You can map a field by extending a CDO map or by adding your own.

By extending a map, you start with an existing map within Opcenter EX MDD or Opcenter EX CR and specify a subclass of the currently mapped CDO. Once the map is extended, you can map any of the field values from the source to the target fields.

By adding a map, your source CDO is the one selected in the CDO Definition window. The target CDO will be the one you select when you add the map. Once the map is added, you can map any of the field values from the source to the target fields.

Note: When you add fields to Shop Floor services, you will typically add the same fields to the history details CDO and map them. This ensures that the values of these fields are written to the history when the service is executed.

How to View Existing Maps for a CDO

Maps for a CDO are grouped according to direction, Map from or Map to the CDO. Follow these steps to view existing maps for a CDO in Designer:

1. Select the CDO. For example, MoveTxn.
2. Select the Maps tab. The Maps tab opens.
Note: Map from is selected. This view shows that the direction of information mapping starts from the current CDO.
3. Click Map to. The Maps window changes to show different maps.
Note: If any map definitions exist in this view, the direction of information mapping will be from other CDOs to the current CDO.

How to Map a Field by Extending an Existing Map

Follow these steps to map a field by extending an existing maps in Designer:

1. Click the CDOs button. The CDO Definition window appears.
2. Double-click a CDO in the left pane that you want to extend a map to.
3. Select the Maps tab. The Maps tab appears.
4. Select the map to extend, for example, Container_to_StartHistoryDetail, in the Maps defined in Ancestors CDOs pane.
5. Click Extend. The Find definition window appears.
6. Select a CDO to represent your new target CDO.
7. Click Select. The extended map appears in Map definitions.
8. Select the new map in Map definitions.
9. Click Details located below Map definitions. (There are two Details buttons. Do not click the Details button below Maps defined in Ancestor CDOs.) The CDO Field Map window appears.
10. Select the Fields tab if it is not already selected.
11. Map the source (from) field to the target (to) field in one of the following ways:

Drag the source field to the top of the target field.

Or

a. Select the source field.
b. Select the target field.
c. Click Map Field>>. The source field appears under the Source Field Name column.
12. Repeat step 11 for each desired field.
13. Click the [X] located in the upper, right corner of the window to save your mapped fields.
14. Select Save from the File menu. The application saves your changes.

How to Map a Field by Adding a Map

Make sure that the fields you want to map exist in the CDOs you want to map. Then, follow these steps to map a field by adding a map in Designer:

1. Click the CDOs button. The CDO Definition window appears.
2. Double-click the CDO in the left pane on that you are adding a map to.
3. Select the Maps tab.
4. Click Add located in the Map window. The Find definition window appears.
5. Select a CDO to represent your new target CDO.
6. Click Select. The new map appears in the Map definitions pane with the source and target CDO shown as the map name.
7. Click Details located below the Map definitions. (There are two Details buttons. Do not click the Details button below Maps defined in Ancestor CDOs.) The CDO Field Map window opens.
8. Select the Fields tab if it is not already selected.
9. Map the source (from) field to the target (to) field in one of the following ways:

Drag the source field to the top of the target field.

Or

a. Select the source field.
b. Select the target field.
c. Click Map Field>>. The source field appears under the Source Field Name column.
10. Select Carry Forward to retain the current value in the target (mapped to) field. This prevents the system from overwriting the current value in the field when the map is called again.
11. Check Accumulate if you need to add a value in a numerical field to an existing value
12. Repeat steps 9-11 for each desired field.
13. Click the [X] located in the upper right corner of the window to save your mapped fields.
Note: A CLF must be modified to run the new map.
14. Select Save from the File menu. The application saves your changes.

How to Remove a Map

You cannot remove default maps or inherited ones. You cannot remove user-defined maps that have been extended by a subclass of the CDO.

If a CLF was created to call the map to be removed, this CLF must be deleted or modified to no longer reference the map before the map can be removed. To identify where maps are used in CLFs refer to "How to View References to a Map."

Follow these steps to remove a map:

1. Open the Designer toolbar.
2. Click the CDOs button. The CDO Definition window appears.
3. Double-click the CDO in the left pane that you are removing a map.
4. Select the Maps tab.
5. Select the map to be removed in Map definitions.
6. Click Remove. A dialog box prompts you to confirm the map removal from the CDO definition.
7. Click Yes.
8. Select Save from the File menu. The application saves your changes.

How to Clear Field Maps

Clearing field maps does not remove the field. You are simply removing the mapping relationship.

Note: The process of clearing a field map is specific to the currently selected map.

Follow these steps to clear field maps in Designer:

1. Click the CDOs button. The CDO Definition window appears.
2. Double-click the CDO in the left pane that you are removing the mapped field.
3. Select the Maps tab.
4. Select the map in Map definitions from which to remove the mapped field.
5. Click Details located below Map definitions. (There are two Details buttons. Do not click the Details button below Maps defined in Ancestor CDOs.) The CDO Field Map window opens.
6. Select the Fields tab if it is not already selected.
7. Select the mapped source (from) field.
8. Select the mapped target (to) field.
9. Click Clear mapping. The map definition is removed for that field.
10. Repeat steps 7-9 for each desired field.
11. Click the [X] located in the upper, right corner of the window to save your removed field maps.
12. Select Save from the File menu. The application saves your changes.

How to View References to a Map

You can view the CLFs, CDOs, and the Events and Methods that reference a map. Follow these steps to view references to a map in Designer:

1. Click the CDOs button. The CDO Definition window appears.
2. Double-click the CDO in the CDO list in the selection pane.
3. Select the Maps tab.
4. Select a map and click the Details button. The CDO Field Map window appears.
5. Select the General tab.
6. Select the Show where this map is referenced check box. All of the CDOs, CLFs, Events, and Methods that reference this map are listed below the check box.
