Filtering on Organizations and Roles

The ability to filter on organizations, roles, and combinations of the two are critical for interfacing with a system using a role-based access control security model. A Designer user, report designer, or anyone can use filtering in the following situations:

• When writing designs in the query
• When designing reports
• Wherever else they want to write a query and want to filter on organizations and roles

Database Functions

Siemens provides database functions that enable filtering on organizations, roles, and combinations of the two. All of the functions respect propagation of the Organization (where the Organizational hierarchy is maintained via the Parent Organization field in the Organization, and where the Propagate flag is set in the Role Membership).

The database function examples provided for each scenario are simple examples to give you an idea of functionality. To view how the application uses the database functions by default, look in the Designer.
