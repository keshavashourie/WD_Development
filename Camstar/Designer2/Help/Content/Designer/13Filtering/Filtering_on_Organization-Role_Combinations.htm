Filtering on Organization/Role Combinations

This section provides guidance for retrieving a list of employees for a particular organization/role combination. When filtering on an organization and role combination, use the csiAuthGetAllowedUsers database function and optional parameters for Organization Name and Role Name to return a table of employees (Employee Id / Employee Name).

The combination of parameters that you pass in determines the results returned:

• If you pass in the Organization Name parameter only, the results will include users for that Organization for any Role.
• If pass in the Role Name parameter only, the results will include users for that Role for any Organization.
• If you pass in both the Organization Name and Role Name parameters, the results will include users for that Role in that Organization.
• If you do not include either Organization Name or Role Name, the results will include employees with any kind of Role in any Organization.

Example Query 1: Determining If the Employee Is Valid for an Organization

 

SELECT COUNT(*)

FROM csiAuthGetAllowedUsers('Corporate','Default Quality')

WHERE EmployeeName = 'CamstarAdmin'

Use

I want to validate that the logged in user is valid for the Role in the Organization for a particular Quality Object. I can join to the csiAuthGetAllowedUsers function in order to determine if the Employee is in the list of Organization/Role combinations returned.

Default Implementation

The csiAuthGetAllowedUsers function is used in QualityTxn.ValidatePermissions logic. The Designer query using the function is ValidateEmployeeRoleOrgCombination.

Example Query 2: Retrieving a List of Employees for an Organization/Role

 

SELECT Employee.EmployeeName, Employee.EmployeeId

FROM csiAuthGetAllowedUsers('Corporate','Default Quality') USERS

JOIN Employee on USERS.EmployeeId = Employee.EmployeeId

Use

I want the selection values for my Owner field to return a list of Employees valid for the Role in the Organization for the Quality Record. I can join to the csiAutGetAllowedUsers function in order to get the list of Employees for the Organization/Role combination.

Default Implementation

The csiAuthGetAllowedUsers function is used in ChangeOwner.Owner selection values. The Designer query using the function is SelectionValuesEx_GetAllowedUsers.
