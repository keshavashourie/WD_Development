Indexes Tab

Indexes Tab Field Definitions

This table defines the fields on the Indexes tab.

Field

Definition

Type

Existing Indexes

Displays any indexes associated with the selected table.

Required

Details

Name

The name used to identify the index when it is created. Each name must be unique.

Required

Index is unique

Creates a unique index for the selected table.

Optional

Description

Contains a description of how this index is used.

Optional

Options

Sort Ascending

Specifies the sort order for the selected column as ascending.

Optional

Sort Descending

Specifies the sort order for the selected column as descending.

Optional

Do Not Include

Omits the column from the index.

Optional

Indexes Tab Button Definitions

This table defines the buttons on the Indexes tab.

Button

Click this button to . . .

Add

Add an index to the selected table.

Remove...

Remove an index from the selected table.

Move Up

Change the structure of the index by moving a selected column up on the list.

Move Down

Change the structure of the index by moving a selected column down on the list.
