Tables Window

Tables are used within Opcenter EX MDD and Opcenter EX CR to store persistent data.

When you create a table through Designer, you are actually creating a table definition that will become a table in the transaction database. Refer to “Adding and Removing a Table” for information on creating table definitions and tables.

Clicking the Tables button on the toolbar opens the Tables window from which you can view the properties of a selected table.

The selection tree shows four categories of tables. Refer to "Table Categories" for information.

Select a table category and right-click to display the shortcut menu with the following options:

• Add Table Definition
• Rename Table Definition
• Find Table Definition
• Remove Table Definition

Rename Table Definition and Remove Table Definition are active only for user-defined table definitions.

The Tables window has four tabs:

• General Tab
• Columns Tab
• Indexes Tab
• Where Used Tab
