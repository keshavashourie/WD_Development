Defining Indexes for Tables

Your business requirements might require that you define new indexes for your tables for quick access to information.

When Defining Indexes for Tables

Some tables provided by Opcenter EX MDD and Opcenter EX CR are indexed. Indexes defined for a table in the Designer are not inherited when creating a subclass of the CDO and creating a new table in that process. If you create a table when you add a CDO subclass, an index is always created for the ID field, like <CDO>Id.

Note: The index is created when you create new database tables for the transaction database. Refer to “How to Create Indexes (Indices)” for information.

If you added new tables and columns, you need to create indexes for them manually following the procedures in this topic.

How to Define an Index

Follow these steps to define an index:

1. Open Designer.
2. Click Tables. The Table Definitions window appears.
3. Select the Indexes tab.
4. Select the table category where the table is located and select the table to which you will add your index.
5. Click Add next to the Existing Indexes field. Opcenter EX MDD and Opcenter EX CR automatically enters the table name in the Existing Indexes field. Opcenter EX MDD and Opcenter EX CR also assigns a unique ID for the index.
6. Enter a unique name and meaningful description for the new index.

Refer to “Valid Characters and Reserved Words” for a list of illegal characters and reserved words to avoid.

7. Select the column name to be added as an index entry.
Note: By default, columns are not configured as index entries (the Do not include button is selected).
8. Sort as follows:
• Right-click and select either Sort Ascending or Sort Descending.

Or

• Use the radio buttons to select either Sort Ascending or Sort Descending.
Note: If you have two or more index entries, you can use the Move Up or Move Down button to change an entry’s sort order.
9. Click anywhere on the tab to save your changes.

Using the New Indexes

To use the new index in your transaction database, you need to create and run the index script. Coordinate with your Data Base Administrator (DBA) and refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information about how to run the script for the new indexes. This process can take a long time, so you might need to schedule running the scripts accordingly.

How to Create Indexes (Indices)

Follow these steps to create indexes in your transaction database:

1. Open Management Studio.
2. Expand the <sitename> node.
3. Expand the Databases folder.
4. Right-click the transaction database and select Create New Database Tables from the menu that appears. The Create Tables For <database> window appears.
5. Leave all check boxes selected.
6. Click OK. The application creates the new tables, closes the Create Tables for <database> window, and displays a message that the new database was created successfully.
