Modifying a Table

Modifying tables is not a common task, but there are occasions when it is necessary to modify an existing table within the database. A possible reason for modifying a table might be if you changed a string field definition to extend it from 15 to 20 characters.

When Modifying a Table

Changing the field definition does not change the table because Opcenter EX MDD and Opcenter EX CR tables are intentionally kept separate from the field definitions. Therefore, you might want to change the table width to match the string field width.

Workspace prefixes are automatically inserted before the name of an item when adding a new item, if a prefix has been assigned to the highest active workspace. Workspace prefixes indicate which workspace Designer is applying changes to. For example, the prefix "C200" would be associated to the workspace with a prefix set as "C200" in Management Studio. It is recommended you use the prefix supplied by Designer when adding new items.

You can assign or modify workspace prefixes in Management Studio. Refer to the Opcenter Execution Medical Device and Diagnostics System Administration Guide or the Opcenter Execution Core System Administration Guide for information.

Note: The base application workspace (csi) cannot have a workspace prefix assigned to it.

How to Change a Table Category

Follow these steps to change a table category:

1. Open Designer.
2. Click Tables. The Table Definitions window appears.
3. Click on the table category where the table you want to modify is located.
4. Select the table you want to modify.
5. In Table Category, select a new category.
6. Select Save from the File menu. The application saves your changes.

How to Add Table Columns

Follow these steps to add table columns:

1. Open Designer.
2. Click Tables. The Table Definitions window appears.
3. Select the Columns tab.
4. Select the table to which you want to add a column.
5. Click Add located below the column name and description. The DB Column Properties window appears with a new column labeled with a default name.
Note: You can also right-click anywhere in the columns list and select Add Column from the shortcut menu.
6. Enter the new column name, a description, and the other property information for the column. Refer to “Valid Characters and Reserved Words” for a list of illegal characters and reserved words to avoid.
7. Click OK.
8. Select Save from the File menu. The application saves your changes.

How to Remove Table Columns

You cannot remove default columns.

Note: Removing a table column in the Designer will not delete the corresponding entity in the production database. This prevents loss of historical data.

Follow these steps to remove table columns:

1. Open Designer.
2. Click Tables. The Table Definitions window appears.
3. Select the Columns tab.
4. Select the table from where the column is to be removed.
5. Select the column you want to remove.

If the Remove button is disabled, the column is being used by one or more CDO fields. To remove the association:

a. While the column name is selected, double-click it to open the DB Column Properties window.
b. Click the Where Used tab.
c. Note the CDOs and fields that appear on the list, then click Cancel to close the window.
d. For each CDO field that uses the DB column to be removed, either remove the field or change its DB column assignment through the property window’s General tab.
e. Repeat for all fields that use the DB column.
6. Select the DB column again and click Remove, or right-click and select Remove Column.
7. Select Save from the File menu. The application saves your changes.

How to Modify Table Columns

Follow these steps to modify table columns:

1. Open Designer.
2. Click Tables. The Table Definitions window appears.
3. Select the Columns tab.
4. Select the table that contains the columns you want to modify.
5. Select the column you want to modify.
6. Click Properties. The DB Column Properties window appears.
7. Modify the properties according to your business requirements.
8. Select Save from the File menu. The application saves your changes.

How to Change a Table Name

Important: If you are renaming tables in Designer, understand the impact of your action, especially if certain objects are already using the tables. Changing table names does not write SQL-type code to copy, create, and delete the old tables in the database.

Follow these steps to change a table name:

1. Open Designer.
2. Click Tables. The Table Definitions window appears.
3. Open the category under which the table resides.
4. Select the table you want to rename.
5. Pause and select again, or click the Rename button. The table name changes to the rename mode.
6. Rename the table.

Refer to “Valid Characters and Reserved Words” for a list of illegal characters and reserved words to avoid.

7. Select Save from the File menu. The application saves your changes.
