Table Types

A table’s type is displayed on the table’s General tab. Either Opcenter EX MDD or Opcenter EX CR has four table types:

• Instance Table (key InstanceID)

Most Modeling tables have a default table type of Instance.

• List Table (key InstanceID, fieldID) ordered by Sequence

Many History and Tracking tables have a default table type of List.

• ReversalInfo Table (key InstanceID, TxnID, Sequence)

Some System tables like ContainerRI and CurrentStatusRI have a default type of ReversalInfo.

• System Table that contains no specific constraints

Most System tables have a default type of System.
