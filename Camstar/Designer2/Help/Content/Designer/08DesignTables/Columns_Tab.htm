Columns Tab

The Columns tab lists the column names and their descriptions. The key symbol beside a column name indicates a primary key.

Columns Tab Button Definitions

This table defines the buttons on the Columns tab.

Button

Click this button to . . .

Add

Open the DB Column Properties window that allows you to define the properties of the column you are adding.

Remove

Remove the column you created.

Properties

Open the DB Column Properties window and view or update the properties of the selected column.

DB Column Properties Window

Clicking the Add or Properties button opens the DB Column Properties window. The DB Column Properties window allows you to define or update properties of a selected column.

Identifies any special processing associated with this column (such as InstanceID). Each value relates to specific processing implemented in the System.

Typing a number other than 0 makes this column a part of the primary key for this table. The number is the sequence in which this column falls within the (potentially multi-part) key.

Required
