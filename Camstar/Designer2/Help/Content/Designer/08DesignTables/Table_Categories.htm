Table Categories

A table’s category is displayed on the table’s General tab. Table categories are used as a way to group the tables. The categories are for organizational purposes only. The table categories Opcenter EX MDD and Opcenter EX CR provide include:

Modeling

This category contains tables for the model or structure, such as factory, location, and operation. Tables related to NamedDataObject and RevisionedObject classes are usually found here.

History

This category contains tables that contain history information. For example, when a transaction is executed, a history record is written.

Unknown

Tables in this category are possibly orphaned tables remaining from a CDO with a list field reference that is no longer in use. The reason may be that the field or even the CDO owning the field has been removed from the object model. In the Opcenter EX MDD and Opcenter EX CR conversion process, any table whose category cannot be resolved will be assigned this category. The user needs to decide whether to keep and reclassify the table, or simply remove its definition because it is no longer needed. Users are not expected to add tables to the Unknown category.

System

This category contains system internal information and is reserved for Siemens use only.

Tracking

This category contains tables for tracking objects and their status in the system, like Container and Production Status.

Refer to “Categories Window” for information on creating new categories.
