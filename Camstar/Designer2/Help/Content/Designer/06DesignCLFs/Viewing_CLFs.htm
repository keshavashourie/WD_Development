Viewing CLFs

There are two ways you can view CLFs:

• View the CLF library
• View the CDO and CDO fields that are using the CLF (CLFs can be attached to a CDO or a CDO field’s events.)
Note: You cannot attach High Performance CLFs to CDO field events.

How to View the Complete List of CLFs in the Library

Follow these steps to view the complete list of CLFs in the library:

1. Open Designer.
2. Click CLFs. The CLF Definitions window appears, displaying the CLF library at the Functions tab.
3. Expand the categories and examine the CLFs under them.
4. Select a CLF and examine the functions in its logic flow.
5. Select a function from the flow and examine the parameter definitions for the function. Repeat for other functions in the logic flow.
6. Examine the CLF Parameters tab if there are parameters defined for the scope of the entire CLF.

How to View CLFs Attached to a CDO or Field Events

Follow these steps to viewCLFs attached to a CDO or Field Events:

1. Open Designer.
2. Click CLFs.
3. Expand a category and select a CLF.
4. Click the Where Used tab.
5. Double-click a CDO name on one of the tables. The CDO’s definition window appears.
6. If the CLF is being used by the CDO’s event:

Click the Events tab and expand the method specified in the table to view the attached CLF.

Or

If the CLF is being used by a CDO field’s event:

a. Double-click the field specified in the table to open its properties window.
b. Click the field properties’ Events tab.
c. Expand the event specified in the table. The attached CLF is displayed as a node below the event.
