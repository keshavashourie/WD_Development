CLFs Window

The CLFs window is used to view, add, modify, remove, or disable Configurable Logic Flows (CLFs). Clicking the CLFs button on the toolbar opens the CLFs window. CLFs are grouped according to category.

CLF Selection Tree

The left pane contains a selection tree that lists all the available categories of CLFs. Right-click in this selection pane to open the shortcut menu with the following options:

• Add CLF Definition
• Rename CLF Definition (disabled for default CLFs)
• Remove CLF Definition (disabled for default CLFs)
• Copy
• Paste

The above options, other than the Copy and Paste options, are also available through the buttons below the CLF selection pane. Note that you cannot use the standard keyboard shortcuts for Copy and Paste.

CLF Details

The right pane contains details about the selected CLF. The pane has the following tabs:

• General Tab
• Functions Tab
• CLF Parameters Tab
• Where Used Tab
• Feature Entitlement Tab

General Tab

The CLFs General tab contains the following elements:

• A field containing a description of the CLF. This field displays information when a particular CLF is selected. It does not display information at the CLF category level.
• Visibility in Designer - this area contains three options buttons that indicate if the selected CLF is visible in the Designer Basic view or Advanced view, or if it is Hidden. CLFs reserved for Siemens use are hidden.

Functions Tab

The Functions tab displays details about that CLF when you expand a category and select a CLF. When you first click CLFs on the toolbar, the CLF definition window opens at the Functions tab.

The Functions tab has three areas:

• Logic Flow

This area lists the sequence of functions and their descriptions that comprise the CLF.

• Available Functions

This area lists the functions that are available to add to the logic flow. You can access functions by selecting them from the groups listed or by searching for them using the filter field. Enter the first few characters or the entire function name in the filter field to search for a specific function. Entering a string displays an alphabetical list of functions with names beginning with that string. Select the function you want from the list or enter the entire function name and click Go.

Note: You can use database functions on standard CLFs and standard functions on High Performance CLFs. Refer to "Adding High Performance CLFs" for information on High Performance CLFs.
• Function Parameters

This area lists information about parameters specific to the function that is selected on the logic flow pane. Depending on the function you selected, the following information is displayed:

• Parameter Name
• Parameter Name indicates SQLStatementName when you are working with some database functions. Refer to "Adding High Performance CLFs."
• Value
• Direction
• In indicates that the parameter passes a value or reference to a CLF.
• Out indicates that the parameter is set from within the CLF.
• In/Out indicates that the parameter passes a value to the CLF and the CLF sets the parameter to a new value or reference.
• Return indicates that the CLF yields a value.
• Dynamic

Select the Dynamic check box if you want the parameter to be passed as a dynamic value using look-up expressions. Leave it unchecked if you want the parameter to be passed as an actual value. If the function enforces parameters type (set by the Enforce Parameter Types flag in the Functions window), the Dynamic check box disappears and the Multiplicity and Data Type columns appear.
• Multiplicity

This attribute specifies the number of values the parameter can or must take. The possible values are 0...* (zero or more, therefore an optional list), 0...1 (zero or one, therefore optional), 1...1 (one, therefore required), 1...* (one or more, therefore a required list).
• Data Type

The Data Type column is a concatenation of the Parameter data type or type class and the Type Multiplicity.

Below the Logic flow area are four buttons whose use are indicated by their names:

• Append
• Insert
• Remove
• Disable

Only the Disable button is enabled by default. Append and Insert are enabled for user-defined functions when you select a function from available functions. Remove is enabled for user-defined functions when a function has been appended to or inserted in the Logic Flow.

This tab is used to view or modify the functions (and corresponding parameters) that comprise a CLF.

CLF Parameters Tab

CLF parameters are available to all functions in the CLF.

The CLF Parameters tab has two areas:

• The top area displays existing parameters within the CLF scope.
• The lower area contains the fields to define or modify parameters.

Below the parameter list are buttons to Add, Insert, or Remove parameters.

The following fields are used to define CLF parameters:

• Parameter Name

The Parameter Name must be unique within the context of the associated function definitions in the CLF. This name is used (as part of a name-value pair construct) for getting or setting parameter values at runtime.

• Special Processing

The Special Processing field enables Designer to show a selection list for certain processing items when setting field values for parameters during association with a CLF:

• CDO Name
Displays the list of CDO Names .
• DB Table Name
Displays the list of DB Table Names.
• Field Expression
Displays Field Expression Builder pop-up.
• Field Map Id
Displays the list of list of Field Maps.
• Label Id
Displays list of Labels.
• Label Name
Reserved for future use.
• Method Name
Displays a list of methods attached to current CDO including inherited methods (Events view only).
• Password
Reserved for future use.
• Query Name-Any
Displays list of Query Definitions.
• Query Name-CDO
Displays list of CDO query definitions.
• Query Name-SQL
Displays Shows list of SQL query definitions.
• [Default]
• Direction
• Select In if you want to pass a value or reference to a CLF.
• Select Out if you want to set a parameter from within the CLF.
• Select In/Out if you want to pass a value and also expect the CLF to set the parameter to a new value or reference.
• Select Return if you want the CLF to yield a value.
• Multiplicity

This attribute specifies the number of values the parameter can or must take. The choices are 0...* (zero or more, therefore an optional list), 0...1 (zero or one, therefore optional), 1...1 (one, therefore required), 1...* (one or more, therefore a required list).

• Description

The description field describes how the parameter is used.

• Data Type

This field shows the data type of this parameter.

• Type Multiplicity

Parameter data types are further characterized by type multiplicity. This means that you can specify if the parameter will be Scalar, or a List, or either (ListOrScalar).

• Specific Type

If the Data Type is Object, a Specific Type field appears, showing the Object type for this field.

• Notes

Where Used Tab

The Where Used tab displays information for the selected CLF. The tab displays two types of information: where CDO events are used and the CDOs where Field events are using the CLF.

The Where Used tab contains these elements:

• CDO Name
This is the name of the CDO where the CLF is used.
Or
This is the name of the CDO that has the field that is using the CLF.
• Field Name
This is the name of the Field with the Event that calls the CLF.
• Event Name
This is the name of the CDO Event that calls the method.
Or
This is the name of the Field Event that calls the CLF.
• Method Name
This is the name of the CDO Method that calls the CLF.

Feature Entitlement Tab

The Feature Entitlement tab displays the Feature Membership group for the selected CLF. Refer to "Feature Entitlement Tab" for information on feature entitlement.
