Disabling or Removing Functions

You can remove functions from logic flow of user CLFs. In some cases, even if you have no use for a function in a CLF, you might want to preserve the function and its parameters without deleting. Disabling a function is therefore preferred, because you have the option to enable it again as needed. Removing a function from a CLF does not permanently remove the function from the library.

For example, you can disable the Call function to FromContainer.ValidateExpirationDate by disabling the function in the ActualsContainer_Validate CLF and the ActualsSerialContainer_Validate CLF. Refer to “How to Disable a Function in a User CLF” for information.

When Disabling or Removing Functions

You can disable or remove functions by:

• Selecting the function or functions in the Logic flow pane and then clicking the Disable or Remove buttons as needed.
• Selecting the function or functions in the Logic flow pane, right-clicking, and then selecting the Disable or Remove options as needed.

How to Remove a Function from a User CLF

Follow these steps to remove a function from a user CLF:

1. Open Designer.
2. Click CLFs.
3. Select the user CLF.
4. Select the Functions tab.
5. Select the function or functions in the Logic flow pane to be removed.
6. Click Remove. A dialog box appears asking you to confirm removing the function.
7. Click Yes. The function is removed from the CLF, but not the Functions library.
8. Select Save from the File menu. The application saves your changes.

How to Disable a Function in a User CLF

Follow these steps to disable a function in a user CLF:

1. Open Designer.
2. Click CLFs.
3. Select the user CLF.
4. Select the Functions tab.
5. Select the function or functions in the Logic flow pane to be disabled.
6. Click Disable. The function is disabled, and the Enable button replaces the Disable button.
Note: When you disable a function, the change is effective on all attached instances of the CLF as well. This change is effective immediately. There is no need to reattach the changed CLF.
7. Select Save from the File menu. The application saves your changes.
