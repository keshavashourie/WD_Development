Removing CLFs

You can only remove user-defined CLFs. Removing a CLF in the CLFs window removes the CLF from the CLF library and it will no longer show up among the choices when you want to attach a CLF to a CDO event or method.

If the CLF is attached to any CDO event or method, go to that CDO and detach the CLF first from those events or methods. If the CLF is attached to multiple CDOs, make sure to detach the CLF from all of them. Refer to "How to Detach a CLF From an Event or Method" for information.

How to Remove a CLF

Follow these steps to remove a CLF:

1. Open Designer.
2. Click CLFs.
3. Expand the CLF category and select the user-defined CLF to be removed.
4. Verify that the Remove button is enabled. The Remove button is disabled if the user CLF is attached to any CDO.
5. If the Remove button is disabled, click the WhereUsed tab to see if the user CLF is attached to any CDO.
6. Repeat the procedure to select the user CLF again.
7. Click the Remove button. The CLF is removed.
8. Select Save from the File menu. The application saves your changes.
