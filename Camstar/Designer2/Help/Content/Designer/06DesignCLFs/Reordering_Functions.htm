Reordering Functions

You can reorder functions within a user CLF from the Functions tab.

How to Reorder Functions Within a User CLF

Follow these steps to reorder functions within a user CLF:

1. Open Designer.
2. Click CLFs.
3. Select the user CLF.
4. Select the Functions tab.
5. Select a function in the Logic flow pane.
6. Hold down the mouse and drag the function to the new location within the Logic flow list box (before or after another function).
7. Click the modified user CLF on the selection pane to save and refresh the screen. The added function appears in the proper position on the flow.
8. Select Save from the File menu. The application saves your changes.
