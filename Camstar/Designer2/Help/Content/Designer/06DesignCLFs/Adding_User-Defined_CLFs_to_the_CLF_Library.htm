Adding User-Defined CLFs to the CLF Library

You can add a user-defined CLF by creating one from scratch or by copying a default CLF and then extending it.

When Adding User-Defined CLFs to the CLF Library

Workspace prefixes are automatically inserted before the name of an item when adding a new item, if a prefix has been assigned to the highest active workspace. Workspace prefixes indicate which workspace Designer is applying changes to. For example, the prefix "C200" would be associated to the workspace with a prefix set as "C200" in Management Studio. It is recommended you use the prefix supplied by Designer when adding new items.

You can assign or modify workspace prefixes in Management Studio. Refer to the Opcenter Execution Medical Device and Diagnostics System Administration Guide or the Opcenter Execution Core System Administration Guide for information.

Note: The base application workspace (csi) cannot have a workspace prefix assigned to it.
Note: For organization purposes, add a CLF or extend a default CLF in the UserFunctions category. However, you will not encounter problems if you add your CLFs in other categories.

How to Create a CLF

Follow these steps to create a CLF:

1. Open Designer.
2. Click CLFs.
3. Select the UserFunctions category (or select another category).
4. Click the Add button located below the CLF list box. A new CLF is added to the bottom of the category’s CLF list with a default name assigned to it.
Note: You can also right-click in the selection tree area and select Add CLF Definition.

When a CLF is first added, it is in the Rename mode.

5. Enter a name for this new CLF.
6. Enter a description for this CLF in the General tab.

 

7. If desired, change the setting for Visibility in Designer.
8. Add functions in the Functions tab, as desired.
9. Click away from the CLF to save it. The CLF is added to the library, ready for use.
Note: Later, you can attach this CLF to a CDO or field event.
10. Select Save from the File menu. The application saves your changes.

How to Extend a Copy of a Default CLF

Follow these steps to extend a copy of a default CLF:

1. Select a default CLF, one with functionality that is similar to what you want.
2. Right-click the desired CLF and select Copy from the list.
3. Right-click the UserFunctions category (or any category to which you want to add the copy) and select Paste [Name of default CLF] from the list. A copy of the CLF is added.

It is in rename mode. The copied CLF includes the same functions and parameters as the original from Siemens.

4. Enter a name for this extended CLF.
5. Click the General tab and Enter a description for the CLF.
6. Customize the CLF by:
• Adding, removing, disabling, and reordering the functions on the logic flow
• Changing parameters associated with the functions (described later in this chapter)
7. Click away from the CLF to save it. The CLF is added to the library, ready for use.
Note: Later, you can attach this CLF to a CDO or field event.
8. Select Save from the File menu. The application saves your changes.
