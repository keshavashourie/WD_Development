Introduction to CLFs

CLFs are grouped into these categories:

1. SystemFunctions - Single function CLFs
2. DataMethod - Methods called on data objects
3. ServiceValidations - Called by the validation events of a service
4. ServiceProcessing - Called by the processing events of a service
5. OnGetValue - Called by the OnGetValue event of a field
6. SelectionValues - Called by the SelectionValues event of a field
7. OtherFieldEvents - Called by the field Initialize, Update, and Validate events
8. TemplateProcessing - Called as part of the shell processing
9. High Performance - Called by the database in the form of one or more database statements (INSERT, UPDATE, DELETE).
Note: High Performance Engine is a separately licensed feature. The HighPerformance CLF category does not appear if you are not licensed for this feature. Refer to "Adding High Performance CLFs" for more information.
10. UserFunctions - Written by users for users
11. Obsolete - No longer used or needed

A function has zero or more parameters and is implemented as an ActiveX (or OCX) control. Parameters are explained further in the Functions chapter. The function, contained within a CLF, performs the work. A function has access to the system’s core objects and methods that it uses to accomplish its work. Opcenter EX MDD or Opcenter EX CR functions have been written to perform a wide variety of tasks that include: simple arithmetic, searching complex data structures, database queries, report writing, data collection, data validation, and more.

Note: You can modify a CLF by adding, removing, or reordering the functions contained within.

CLF Composed of Functions

You can expand the capabilities of a CLF by introducing a new function or by changing the order of the existing functions. While in the CLF Definitions window, you can view all of the functions listed for a CLF in the Logic flow selection list. The functions are displayed in the order they are executed. The Available Functions list displays all of the functions that can be obtained for a CLF. From this window, you can view, add, or remove functions from a CLF.
