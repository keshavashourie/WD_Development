Adding Functions to CLFs and Viewing a CLF’s Functions

You can add functions to user CLFs. Adding functions also means you need to determine the function’s position (sequence) in the logic flow. You can add functions in the beginning, middle, or end of the flow. You can select multiple functions at a time.

When Adding Functions to CLFs and Viewing a CLF's Functions

The application displays standard functions and database-specific functions in the list of Available Functions. You can view functions either by group or by searching for functions using the Available Functions filter field:

• To select a function from a group, expand the group that contains the function you want and select it.
• To search for a function, enter the first few characters or the entire function name. Entering a string displays an alphabetical list of functions with names beginning with that string. Select the function you want from the list or enter the entire function name and click Go.

How to Add Functions to a User CLF

Follow these steps to add functions to a user CLF:

1. Open Designer.
2. Click CLFs.
3. Select the user CLF.
4. Click the Functions tab.
5. Do you want to add standard functions or database functions to the CLF?

Standard functions

Go to step 6.

Database functions

Complete steps 10-14 of "How to Add a High Performance CLF."
6. Use one of the following methods to add the function:
a. Select an existing function in the Logic flow pane and click Insert. The added function appears at the bottom of the flow.
b. Select a function from Available Functions and click Append.
c. Select a function from Available Functions and drag and drop it into the Logic flow pane.
7. Click the modified user CLF on the selection pane to save and refresh the screen. The added function appears in the proper position on the flow.
8. Modify the function parameters as required.
Note: Your modifications here will only affect the CLF but not the function as it was originally defined in the Functions library.
9. Select Save from the File menu. The application saves your changes.

How to View the Functions for a Specific CLF

Follow these steps to view the functions for a specific CLF:

1. Open Designer.
2. Click CLFs. The CLF Definitionswindow appears.
3. Expand a category from the selection window and select the CLF. The functions for the CLF appear in the Logic flow list in the order they are executed.
4. Optionally, select the function in the Logic flow list to view the parameters for a function within the CLF. The function parameters (if any) appear in the Functions parameters section of the window.
