Adding CLF Parameters

You can add CLF parameters to user-defined CLFs.

When Adding CLF Parameters

While the values for function parameters may be set by the user at configuration time, values for CLF parameters are set by some functions such as Call and If as they run. CLF parameters are available for the life of the CLF and are prefixed with CLF::. High Performance CLF parameters are prefixed with DBCLF::.

If you want to use the added parameters for the CLF that had been previously attached to an event or method, detach the CLF there and attach the modified CLF definition.

How to Add CLF Parameters

Follow these steps to add CLF parameters:

1. Open Designer.
2. Click CLFs. The CLF Definitions window appears.
3. Select the user CLF to which you want to add parameters.
4. Click the CLF Parameters tab.
5. Click Add. A generic parameter appears on the parameter list pane with the default name of Parameter1.
6. Enter a new name in the Parameter name field.
7. Click the generic parameter to save the name. The new name replaces the generic name.
8. Select an entry for Special processing.
9. Select a Direction for the CLF parameter.
10. Select an entry for Multiplicity.
11. Enter a Description of your CLF parameter.
12. Select a data type and type multiplicity from the Data Type and Type Multiplicity lists.
13. Enter notes and comments according to your business requirements.
14. Click away from the Parameters tab to save your changes.
15. Select Save from the File menu. The application saves your changes.
