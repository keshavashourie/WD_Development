Modifying Default Function Parameter Values for a CLF

When you add a new CLF to a CDO, many of the parameter values for the functions are already provided. These are referred to as the CLF default parameter values. To modify these default values, the definition of the CLF must be modified. Note that when the default parameter values are changed, only the template version of the CLF will be affected. Consequently, parameter values of a CLF and its functions already attached to an event or method will not be affected. If you want to use the modified parameter values for the CLF previously attached to an event or method, detach the CLF there and attach the modified CLF definition.

These modifications will affect only the function for the selected CLF. Refer to “Editing Parameter Values for a Function” for information on modifying the function parameters in general.

How to Modify Default Parameters in a Function for a CLF

Follow these steps to modify default parameters in a function for a CLF:

1. Open Designer.
2. Click CLFs.
3. Select the CLF from the selection window.

The example shows MoveIn_Execute under ServiceProcessing.

4. Select the function to be modified in the Logic flow pane. The default parameter values for the selected function appear in the Function parameters block.

 

5. Modify default parameter values as desired.
6. Optionally, select the Dynamic check box to have the parameter passed as a dynamic value using look-up expressions. Leave it deselected if you want the parameter to be passed as an actual value.
Note: If the function enforces parameter types (set by a flag in the Functions window), the Dynamic check box will not be visible and Multiplicity and Data Type columns will be visible instead. Multiplicity and Data Type are read-only in this window. To change the values for these columns, you must go to the Function definition window where you can modify user-defined functions.
7. Select Save from the File menu. The application saves your changes.
