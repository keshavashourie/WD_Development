Running the Metadata Export Utility

Siemens provides the Metadata Export utility for viewing the differences between your base metadata database (MDB) and a modified MDB. The utility compares the two databases and allows you to selectively export the differences (delta) to an XML file. The utility also provides the ability to generate a report detailing the differences between the two databases.

When Running the Metadata Export Utility

The Metadata Export utility appears as a window containing a series of three screens that guide the export and report generation process. Each screen displays a screen number in the upper right corner of the window to help track your progress.

These screens appear in the utility in the following order:

• Select Files to Compare
• Select Changes to Output
• Select Output Options

You can navigate from one screen to the next in the utility by clicking the Next button. You can return to a previous screen by clicking the Previous button. Clicking Cancel will close the Metadata Export window and an export will not be performed and a metadata report will not be generated.

The About Metadata Export pop-up appears when you select About from the Help menu and displays product and version information about the Metadata Export utility. You can close the About Metadata Export pop-up by clicking the Close button.

The utility displays an error message when an error occurs during the export process. The error message contains information on where in the process the utility encountered the error and what objects it cannot compile. Errors are logged in the Event Viewer and in a log file containing detailed information explaining why the process failed. Log files are saved at the file path C:\Program Files (x86)\Camstar\Logs by default.

Select Files to Compare Screen

You must specify a base MDB and a modified MDB to compare on the Select Files to Compare screen. The same MDB file cannot be used for both the base and modified MDB. The utility displays the highest active workspace for each database, and the workspaces must be the same in order to proceed. The utility only compares databases with the same workspace. The last MDBs that were previously specified when using the utility will appear in these fields by default.

Note: Workspaces are activated in Management Studio. Refer to the Opcenter Execution Medical Device and Diagnostics System Administration Guide or the Opcenter Execution Core System Administration Guide for information.

The utility begins compiling a database after you specify a database in the Base MDB or Modified MDB fields. The text "Compiling" appears next to the field and the text "Compiled" then appears when the utility successfully finishes compiling the database. The utility enables the Next button when both databases have finished compiling.

The utility compares the base and modified MDBs when you click the Next button on the Select Files to Compare screen. A Status pop-up appears and provides text updates during the comparison process. The Status pop-up closes when the process finishes.

Select Changes to Output Screen

The Select Changes to Output screen displays a list of definitions in a series of trees arranged by object type for the modified objects found during the MDB comparison.

The following object types appear on this screen:

• CDOs
• CLFs
• Fields
• Database Tables
• Functions
• Queries
• Labels
• Features
Note: IDs will not be in sync with your target environment when performing an export that includes entitled features. Siemens recommends that you use the Replace Workspace Data utility to ensure IDs are updated as part of the replacement process. Refer to the for information on the Replace Workspace Data utility.Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide.

You can expand a tree and select specific object definitions to include in the export or metadata report. Additional object definition information appears in the right pane of the screen when you select an object definition. You can select all the available object definitions by clicking the Select All button. You can also click the Expand All button to expand all the trees to view the complete list of modified object definitions.

Note: A warning message appears when the Expand All button is clicked to notify you that the process of expanding all the trees may take a few minutes if there is a large number of modified objects. Click OK to close the warning message.

You can search for specific objects by entering the object's name in the Search field and clicking the Search button.

A warning message stating that no changes have been selected for export appears if you click Next without selecting at least one definition. Click OK to close the warning message and then select at least one definition.

Select Output Options Screen

The Select Output Options screen allows you to control whether the export tool generates:

• A metadata export XML file,
• A metadata export report (HTML or DOC), or
• Both.

Select the:

• Export File check box to generate the metadata export XML file.
• Report File check box to generate the metadata report file.
• Include IDs for Feature Promotion check box to include the metadata IDs in the metadata export XML file.

Selecting either the Export File or Report File check boxes enables the associated text box and file selection functionality so you can specify the output file and path.

The metadata export tool enables the Finish button after you specify the desired output, file, and file location. Clicking the Finish button begins the file generation. A Status pop-up appears and displays a success message when file generation is complete.

When Generating Export and Metadata Report Files

The utility saves exports in an XML format and metadata reports in an HTML format by default. The utility supports both HTML and DOC formats for metadata reports.

The default path for exported XML files and metadata report files is C:\Users\<user folder>\Desktop (for example, C:\Users\msmith\Desktop).

The default file name for XML files is the modified file name followed by the workspace and the word "export" all separated by underscores. For example, if the modified file name is ModifiedMDB.mdb and the workspace is csi, then the default file name would be ModifiedMDB_csi_export.xml.

The default file name for generated report files is the modified file name followed by the workspace and the phrase "exportReport" all separated by underscores. For example, if the modified file name is ModifiedMDB.mdb and the workspace is csi, then the default file name would be ModifiedMDB_csi_exportReport.html.

You can specify a different path and file name for exports by clicking Browse for the Export File field. You can specify a different path, file name, and file type for reports by clicking Browse for the Report File field.

Running the Metadata Export Utility from the Command Prompt

You can run the Metadata Export utility from the command prompt. You call the utility using the following command:

"MetadataExport [-a] [-b baseFileName] [-m modifiedMDBFileName] [-o outputXMLFileName] [-r reportHMTLFileName]"

Each parameter is separated by a single space and starts with a dash. The values you replace the variables with are identical to the values expected by the fields across the utility's screens. Refer to "Camstar Metadata Export Window Field Definitions" for information.

This table defines the information you must replace the variables with in the command line.

Variable

Value

-a

Exports all differences in command line mode with no UI interaction or filtering.

Note: You must include this parameter when running the utility from the command prompt.

baseFileName

The full path to the base metadata database.

modifiedMDBFileName

The full path to the modified metadata database.

outputXMLFileName

The full path and file name for the exported XML file.

reportHTMLFileName

The full path and file name for the generated report.

An error message and help information appear if the utility encounters an error. You can also enter "MetadataExport help" and press Enter to display help information. You can review the information and then attempt to run the utility by reentering your command and pressing Enter.

Note: Only the entire MDB can be exported via the command prompt.

How to Run the Camstar Metadata Export Utility

Follow these steps to run the Camstar Metadata Export utility:

1. Go to the Apps view.
2. Click the Metadata Export app. The Camstar Metadata Export window appears.
3. Click Browse for the Base MDB field. The Open window appears.
4. Navigate to the base MDB and click Open. The Open window closes, the path to the base MDB appears in the Base MDB field, the code identifying the highest active workspace for the base MDB appears in the Workspace field, and "Compiling" appears next to the Base MDB field. "Compiled" then appears next to the Base MDB field when the database finishes compiling.
5. Click Browse for the Modified MDB field. The Open window appears.
6. Navigate to the modified MDB and click Open. The Open window closes, the path to the modified MDB appears in the Modified MDB field, the code identifying the highest active workspace for the modified MDB appears in the Workspace field, and "Compiling" appears next to the Modified MDB field. "Compiled" then appears next to the Modified MDB field when the database finishes compiling and the utility enables the Next button.
7. Click Next. The Select Changes to Output screen and a Status pop-up appear. The Status pop-up displays text updates while the utility compares the two databases. The Status pop-up closes when the process completes.
8. Select modified object definitions as needed and then click Next. The Select Output Options screen appears.
9. Do you want to perform the export, generate the metadata report, or perform both the export and generate the metadata report?

If you want to . . .

Then . . .

Perform the export
a. Select the Export File check box.
b. Click Browse for the Export File field. The Save As window appears and displays the default file name and location.
c. Specify a different path or file name if necessary.
d. Click Save. The Save As window closes, the path to the export file and file name appear in the Export File field, and the utility enables the Finish button.
e. Go to step 10.

Generate the metadata report
a. Select the Report File check box.
b. Click Browse for the Report File field. The Save As window appears and displays the default file name and location.
c. Specify a different path, file name, or file type if necessary.
d. Click Save. The Save As window closes, the path to the metadata report and file name appear in the Report File field, and the utility enables the Finish button.
e. Go to step 10.

Perform both the export and generate the metadata report
a. Select the Export File check box.
b. Click Browse for the Export File field. The Save As window appears and displays the default file name and location.
c. Specify a different path or file name if necessary.
d. Click Save. The Save As window closes, the path to the export and file name appear in the Export File field, and the utility enables the Finish button.
e. Select the Report File check box.
f. Click Browse for the Report File field. The Save As window appears and displays the default file name and location.
g. Specify a different path, file name, or file type if necessary.
h. Click Save. The Save As window closes, the path to the metadata report and file name appear in the Report File field.
i. Go to step 10.
10. Click Compare and Export Finish. The utility saves the generated files in the specified paths and a Status pop-up appears and displays a success message.
11. Click OK. The status pop-up and Camstar Metadata Export window close.
