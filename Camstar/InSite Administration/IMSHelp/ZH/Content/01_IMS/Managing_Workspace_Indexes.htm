管理工作区索引

在 Designer 中定义的索引由在定义中读取并创建数据库索引的存储过程创建。在某些情况下，需要对现有索引（例如集群索引）进行更改，但 Designer 不支持更改，或者特定工作区需要其他列。为了支持这些情况，可以在索引创建流程中编写工作区特定存储过程以进行调用。这允许修改现有索引。每个活动工作区都可以有自己的过程，而索引创建流程则从最低到最高的活动工作区调用每一个过程。

管理工作区索引

在更新事务数据库或选中“创建索引”复选框的情况下创建数据库表时，将执行存储过程。执行 csiCreateIndexes 存储过程以在定义中读取并基于这些定义创建索引。

根据工作区顺序按升序为每个活动工作区创建索引后，该过程将检查具有特定名称的存储过程是否存在，并在存在时调用它。例如，如果工作区 180、190 和 200 处于活动状态，且每个工作区都有一个自定义存储过程文件，则应用程序将按照 180、190 和 200 的顺序执行过程。

注释: 对索引所做的任何更改都将记录在替换工作区数据实用程序的日志文件中。有关替换工作区数据实用程序的信息，请参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。

每个活动工作区只能存在一个存储过程。您必须遵循命名约定“Workspace_WSCode_CreateIndexes”，其中“WSCode”是工作区的代码，例如“180”或“190”。例如，“Workspace_200_CreateIndexes”必须是工作区 200 的存储过程的名称。

这里提供了 SQL Server 和 Oracle 数据库的示例存储程序文件，可作为创建自定义索引存储程序的起始点。示例文件位于以下位置：

• C:\Program Files (x86)\Camstar\Insite Administration\Scripts\Oracle for Oracle databases。
• C:\Program Files (x86)\Camstar\Insite Administration\Scripts\SqlServer for SQL databases。

必须在 Management Studio 中执行为数据库创建的脚本以创建存储过程。在更新事务数据库或选中“创建索引”复选框的情况下创建数据库表时，将执行存储过程。然后，csiCreateIndexes 过程将查找自定义过程并在索引创建流程中调用它。
