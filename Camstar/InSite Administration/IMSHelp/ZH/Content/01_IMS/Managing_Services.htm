管理服务

Opcenter EX MDD 服务器和 Opcenter EX CR 服务器注册为服务。可以从“服务”窗格查看这些服务的状态。也可以从“服务”窗格启动、停止和重新启动它们。

服务信息

从“管理”文件夹中选择服务时，产品相关服务的信息将显示在 Management Studio 窗口的右窗格中。右窗格包含一个表，其中会列出服务及其当前状态。

默认情况下，站点包含以下服务：

• Camstar App Server
• Camstar 部署服务器
• Camstar 通知服务器
• Camstar 安全服务
• Camstar WCF 服务
• Portal
• REST API 标签
• REST API 建模
• REST API 查询
• REST API 车间

在“管理”文件夹中选择“服务”节点后，“服务”菜单将显示在 Management Studio 窗口中。有关“服务”菜单的信息，请参考“服务菜单”。

重要提示: 开始和停止服务只会影响它们在“<服务器> 的服务”字段上当前选定服务器中的状态。选择其他服务器将刷新服务列表及其当前状态。

有关停止和重新启动服务的建议顺序的信息，请参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。某些服务在 IIS 中作为应用程序池运行，其他服务作为服务在 Windows 管理工具中运行。

如何启动一个服务

按照以下步骤启动一个服务：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开管理文件夹并选择服务节点。服务信息会显示在右窗格中。
3. 从<服务器> 的服务字段中选择服务器。“服务”网格将刷新并显示服务列表及其当前状态。
4. 右键单击已停止的服务，然后选择启动一个服务。服务的状态更改为“正在运行”。
5. 重复步骤 3，根据需要启动其他已停止的服务。

如何停止一个服务

按照以下步骤停止一个服务：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开管理文件夹并选择服务节点。服务信息会显示在右窗格中。
3. 从<服务器> 的服务字段中选择服务器。“服务”网格将刷新并显示服务列表及其当前状态。
4. 右键单击正在运行的服务，然后选择停止一个服务。服务的状态更改为“已停止”。
5. 重复步骤 3，根据需要停止其他正在运行的服务。

如何停止所有服务

按照以下步骤停止所有服务：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开管理文件夹并选择服务节点。服务信息会显示在右窗格中。
3. 从<服务器> 的服务字段中选择服务器。“服务”网格将刷新并显示服务列表及其当前状态。
4. 右键单击某个服务，然后选择停止多个服务。所有服务都将停止，并且它们的状态显示为“已停止”。

如何重新启动多个服务

按照以下步骤重新启动多个服务：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开管理文件夹并选择服务节点。服务信息会显示在右窗格中。
3. 从<服务器> 的服务字段中选择服务器。“服务”网格将刷新并显示服务列表及其当前状态。
4. 右键单击某个服务，然后选择重新启动多个服务。所有服务都将重新启动，并且它们的状态显示为“正在运行”。
