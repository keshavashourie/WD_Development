更新事务数据库

Management Studio 中的“更新数据库”任务可用于更新事务数据库和操作 DataStore 数据库，前提是数据库配置已就绪。在 Designer 中进行配置更改之后，并且仅在已执行“创建新的数据库表”任务之后，执行此任务。有关信息，请参考“创建新的数据库表”。

通过 Designer 输入的更改会记录在 InSite.mdb 文件中。必须将这些更改应用于事务数据库，如果相关，还必须应用于 DataStore 数据库。执行数据库更新时，事务数据库和 DataStore 数据库必须是不同的数据库。将 Designer 类进行子类化并添加字段时，应用程序将更新事务数据库中的表和列。

重要提示: 只能从集群环境的集群中的任何成员执行一次创建或更新过程。

更新数据库任务的要求

Opcenter EX MDD 或 Opcenter EX CR 数据库用户需要具有这些默认用户视图的无限制访问权限，才能执行“更新数据库”任务：

• 对于 Oracle
USER_TABLES
USER_TAB_COLUMNS
USER_CONSTRAINTS
USER_CONS_COLUMNS
• 对于 SQL Server
INFORMATION_SCHEMA.TABLES
INFORMATION_SCHEMA.COLUMNS
INFORMATION_SCHEMA.KEY_COLUMN_USAGE

更新数据库后何时应重新启动应用程序池和服务

应用程序通常不会在更新数据库时挂起应用程序池和服务。这使应用程序可以继续处理车间事务。以下情况需要停止应用程序池和服务，然后在更新数据库后重新启动它们：

• 重新生成 WCF 服务需要回收 Portal 和 Camstar WCF 服务应用程序池。
• 重新生成 REST API 服务，需要回收 Portal 和 REST API 应用程序池。
• 修改数据库连接信息需要重新启动 Camstar 安全服务和 Camstar App Server 应用程序池。
• 手动更改数据库架构需要重新启动 Camstar App Server 应用程序池。
注释: 如果执行其他需要重新启动的操作，可能会在 Management Studio 中显示一条消息，指明需要重新启动 Camstar App Server。有应用程序池和服务的信息，请参考“管理服务”。

如何更新事务数据库

在 Designer 中进行更改后，按照以下步骤更新事务数据库：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开数据库，然后右键单击事务数据库。
3. 选择更新数据库。将显示“更新数据库”对话框。
4. 根据业务要求选择或清除更新选项。有关复选框的信息，请参考复选框定义表。
5. 单击确定。进度行表示进程正在运行，并且会显示“SQL 脚本”弹出窗口，其中显示执行中的脚本的进度。如果遇到错误，将启用并填充“错误信息”部分。如果选择其他文件，则脚本名称会更新到“错误信息”部分中。
6. 如果发生错误，则执行以下操作之一：
• 单击查看... 按钮，在记事本（或关联的程序）中打开脚本文件。
• 单击运行脚本按钮以从头开始重新运行所有脚本。
