配置 Industry Solutions

使用 Industry Solutions 配置工具可以配置运行行业解决方案功能所需的工作区。行业解决方案功能所需的文件随 Opcenter Execution MDD 或 Opcenter Execution CR 一起提供，但您必须使用该工具配置这些文件。如果要使用以下任意功能，则必须运行该工具：

• CIO
• Opcenter EX CR Scheduling
• Overall Equipment Effectiveness (OEE)
• Medical Device
• Batch Processing
• Shop Floor Resource Configuration (SRC)

Industry Solutions 配置工具提供了一个机制，实现了允许将出站消息从 Opcenter Execution MDD 或 Opcenter Execution CR 发送到外部应用程序的 CIO 功能。

Industry Solutions 工作区提供了一个机制，借助该机制可以轻松地交付特定于医疗设备行业的功能。这些功能在 Industry Solutions 工作区中进行开发，因此它们彼此分离。这使特定于医疗设备的功能可以保持分离，同时仍可以继承后续的 Opcenter Execution MDD 或 Opcenter Execution CR 更改。

必须获取 Opcenter Execution Core Batch Processing 许可，才能使用 Batch Processing 功能。必须为 Opcenter EX CR Scheduling 许可，才能使用 Opcenter EX CR Scheduling 功能。

有关安装 Opcenter Execution MDD 或 Opcenter Execution CR 及其组件的信息，请参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。

有关特定于安装、配置和使用这些功能的信息，请参考以下指南：

• Opcenter Execution Medical Device and Diagnostics Scheduling 用户指南或 Opcenter Execution Core Scheduling 用户指南
• Opcenter Execution Medical Device and Diagnostics Industry Solutions 用户指南或 Opcenter Execution Core Industry Solutions 用户指南
• Opcenter Execution Medical Device and Diagnostics Medical Device 用户指南或 Opcenter Execution Core Medical Device 用户指南
• Opcenter Execution Medical Device and Diagnostics Batch Processing 用户指南或 Opcenter Execution Core Batch Processing 用户指南
• Opcenter Execution Medical Device and Diagnostics Modeling 用户指南或 Opcenter Execution Core Modeling 用户指南

配置 Industry Solutions

使用 Industry Solutions 配置工具可以合并数据库以及运行与工作区关联的脚本。该工具还能验证相依项。例如，必须先安装 CIO，然后才能安装 Industry Solutions 工作区或 Batch Processing 工作区。

选择要安装的工作区。可用的工作区包括：

• CIO
• Industry
• OEE
• Medical Device
• Batch Processing
• SRC

进行选择并单击“完成”后，Industry Solutions 配置工具将执行以下步骤：

1. 显示“确认安装”对话框，其中会显示安装类型和选定的功能工作区等信息。可以单击“确定”来继续安装，也可以取消。
2. 验证已是否安装正确版本的 Opcenter Execution MDD 或 Opcenter Execution CR
注释: 如果未安装正确版本，该工具将返回错误。
3. 如果选择了 Industry 或 Batch Processing，则指出 CIO 是必需的
注释: 必须选择 CIO 才能继续安装。如果仅选择 Medical Device，则该工具不会指出 CIO 是必需的。
4. 提示输入 DataStore 数据库详细信息（如果选择了 OEE）
注释: 如果未输入所有详细信息，该工具将返回错误。OEE 选项需要行业工作区。如果未选择行业工作区，该工具将返回错误。该工具将验证与 DataStore 数据库的连接是否成功。如果未提供正确的连接信息，该工具将返回错误。
5. 对每个所选工作区运行替换工作区数据实用程序
6. 将每个所选工作区的 .js、.css 和 .cs 文件复制到 \Camstar\Industry Solutions\<feature>\Camstar Portal 文件夹中的相应位置
7. 将每个所选工作区的 CDOForms 设置更新到 settings.xml 文件中
8. 生成 WCF 服务
9. 将每个所选工作区的虚拟页面 .xml 文件移动到 InsiteAdministration\PortalData 文件夹中
10. 执行数据库更新 (dbupdate)
11. 导入每个所选工作区的门户表单
12. 执行每个所选工作区的菜单定义和角色脚本
13. 重新启动 CamstarAppServer 和 CamstarSecurityServices 应用程序池
14. 如果选择 Industry 且所需的数据为 ，则执行 Industry Solutions IPL 集成配置脚本
15. 执行 Industry Solutions OEE 脚本（如果选择了 OEE）

“Industry Solutions 配置工具”对话框上会显示进度条，以指示配置状态。整个过程完成时，该工具会显示一个对话框。

配置完成后，便可使用行业解决方案功能。Opcenter EX CR Scheduling 要求您安装和配置 Preactor。有关信息，请参考 Opcenter Execution Medical Device and Diagnostics Scheduling 用户指南或 Opcenter Execution Core Scheduling 用户指南。

在 Industry Solutions 中配置 Shop Floor Resource Configuration (SRC)

Shop Floor Resource Configuration (SRC) 功能用于管理 IPL 智能设置，是使用 Industry Solutions 配置工具安装的。 要使 SRC 发挥完全功能，还必须安装和配置 Valor MSS Shop Floor Application Server。

配置 SRC 安装之前

SRC 需要安装 ASP.NET Core 8.x Windows 托管捆绑包和 .NET Desktop Runtime 8.x。 如果尚未安装这两个应用程序，将显示一个对话框，提示您是否要下载并安装 ASP.NET Core 8.x Windows 托管捆绑包和 .NET Desktop Runtime 8.x 支持。 单击确定按钮后，将定向到 Microsoft 站点以下载 .NET Desktop Runtime 8.x 的安装程序。 如果在对话框中选择否，SRC 安装将不会继续。 安装 .NET Desktop Runtime 8.x 后，需要重新打开 Industry Solutions 配置工具并重新选择 SRC 才能完成安装。可以在不安装 ASP.NET Core 8.x Windows 托管捆绑包的情况下继续进行 SRC 安装，但 SRC 将无法正常运行，因此必须安装 ASP.NET Core 8.x Windows 托管捆绑包。

请参考 Siemens 支持中心的版本矩阵，了解有关托管绑定包受支持版本的信息。

如何配置 Shop Floor Resource Configuration

按照以下步骤配置 Shop Floor Resource Configuration：

1. 确保已执行“如何配置 Industry Solutions”的前六个步骤。
2. 启动 SRC 安装程序后，将显示初始安装程序对话框。 单击下一步。安装程序对话框显示关于 IPL 文件夹信息的“安装文件夹”字段。
3. 在组件文件夹和 Home 文件夹字段中，根据业务需求进行更改。 单击下一步。安装程序对话框显示“许可证服务器”字段，指示 Mentor Graphics License Server 的位置
4. 输入许可证服务器名称、许可证服务器端口和超时。 单击下一步。将自动执行测试以检查与服务器的连接是否有效。 完成后，安装程序对话框会提示输入 Opcenter Connect MOM Web API 适配器信息，供 IPL 应用程序用于向 Opcenter Execution Core 发送消息。
5. 输入 WebAPI 适配器 Ip/主机名、Web API 适配器端口和 Web API 适配器协议。 单击下一步。 安装程序对话框会提示输入 Opcenter EX CR Rest API 凭证。
注释: 无需安装 Opcenter Connect MOM 即可安装或正常运行 SRC。 SRC 请求此信息以将其提供给与之通信的其他应用程序。
注释: 以前 SRC 要求同时安装 Opcenter Execution Electronics，并运行相应的 Opcenter Connect MOM 配置脚本 (ES_MIO_ConfigurationLoad.cfg) 以创建所需的 CN MOM 对象。但是，es_valorinbound Web API 适配器的硬编码使用已移除。 这将支持非 Electronics 环境，此环境中仅安装了提供 is_valorinbound Web API 适配器的 Industry。如果已安装 Opcenter Execution Electronics，则将使用 es_valorinbound Web API 适配器。
6. 输入用户名和密码。单击下一步。将显示“SRC 服务器配置”字段。
重要提示: 必须配置 Opcenter Execution REST API 用户名和密码，以避免服务器连接测试未通过。
7. 根据业务需求选择网络协议选项。
8. 输入 SRC 服务器主机名或 IP、选定的 Http 端口或 Https 端口，以及 SSL 证书。单击下一步。将显示“预安装汇总”对话框。
9. 单击安装。。“SRC 安装程序”对话框中将显示进度条。 安装完成后，屏幕将显示完整的安装消息。
10. 单击关闭。“SRC 安装”对话框将关闭。

完整功能的附加建模

必须创建或更新车间实例，在其中必须配置 SRC API 以使 SRC 功能完全。 然后，必须将此车间集成设置实例指派给与员工关联的工厂。 因此，在“车间集成设置”对象中，SRC API 必须配置适当的值。 通常配置如下：

https://servername:5443/

其中，'servername' 是安装了 SRC 的服务器的适当值。

有关更多信息，请参考《Opcenter Execution Core Modeling 用户指南》。

如何卸载 SRC

按照以下步骤卸载 SRC。

1. 转到“控制面板”。将显示“控制面板”窗口。
2. 单击卸载程序。将显示“程序和功能”窗口。
3. 选择 Opcenter Execution Core SRC [版本号]，然后单击卸载。
