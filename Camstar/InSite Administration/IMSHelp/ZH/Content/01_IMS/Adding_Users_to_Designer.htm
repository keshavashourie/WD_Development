向 Designer 添加用户

可以向 Designer 中添加用户和删除其中的用户。

Designer 用户信息

从“管理”文件夹中选择“Designer 用户管理”时，Designer 用户信息将显示在 Management Studio 窗口的右窗格中。

Siemens 提供三个默认用户：

• CamstarAdmin
• 管理员
• InSiteAdmin

对 Designer 的访问基于 Windows 的安全性。确保 Designer 用户具有有效的 Windows 帐户，并已将它们作为 Management Studio 中的 Designer 用户进行添加。有关使用 Designer 的信息，请参考《Opcenter Execution Medical Device and Diagnostics Modeling 用户指南》或《Opcenter Execution Core 用户指南》。

可以通过单击第一个空白行并输入用户名来添加用户。单击“保存”以添加用户。可以通过选择用户行并按 Delete 键或单击与用户名关联的红色删除图标来删除用户。红色删除图标显示在 deleteLink 列中。单击删除图标将显示“删除行”确认消息。单击“删除行”确认消息中的“是”以删除用户并关闭消息。

如何添加 Designer 用户

按照以下步骤添加 Designer 用户：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开“站点”树中的管理文件夹，然后选择Designer 用户管理。Designer 用户管理信息显示在右窗格中。
3. 在第一个空白用户名字段中单击，然后输入新用户名。
4. 重复步骤 3，根据需要添加其他用户。
5. 单击保存。 Management Studio 将显示成功消息。

如何删除 Designer 用户

按照以下步骤删除 Designer 用户：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

2. 单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。
3. 展开“站点”树中的管理文件夹，然后选择Designer 用户管理。 Designer 用户管理信息显示在右窗格中。
4. 选择要删除的用户行。
5. 按 Delete。 应用程序将删除该用户。
6. 重复步骤 3-4，根据需要删除其他用户。
7. 单击保存。 Management Studio 将显示成功消息。
