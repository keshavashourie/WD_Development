启用服务器跟踪日志

可以从“<服务器名称> - 日志”菜单中启用不同级别的服务器跟踪日志记录。服务器跟踪使您能够捕获各种请求和响应的调试信息。

启用服务器跟踪日志

通过从 Camstar 服务器文件夹中选择一个服务器节点，然后从“<服务器名称> - 日志”菜单中选择服务器跟踪日志，可启用服务器跟踪日志。有关“<服务器名称> - 日志”菜单的信息，请参考“<服务器名称> - 日志菜单”。

注释: 在完成数据库更新 (dbupdate) 后，必须重新启用服务器跟踪日志。必须重新启用日志，因为在执行 dbupdate 时会重新启动服务器并禁用服务器跟踪日志。

此表定义了在每个服务器跟踪日志级别捕获的信息。

级别

捕获的信息

低

函数名称和参数。

中

函数名称、参数和解析值。

高

函数名称、参数、解析值和 XML 请求和响应。

服务器上一次只能有三个服务器跟踪日志级别（低、中或高）中的一个处于活动状态。例如，选择“低”，然后选择“中”，则只会启用中级服务器跟踪日志。可以同时在每个服务器的不同级别上运行单独的服务器跟踪。

通过选择当前运行服务器跟踪的服务器节点，然后从“日志”菜单中选择“禁用服务器跟踪日志”，可以禁用活动服务器跟踪日志。

默认情况下，日志文件存储在以下位置：Program Files (x86)\Camstar\Logs\Transaction Logs。

还可以通过从“<服务器名称> - 日志”菜单中选择“启用客户端跟踪日志”来启用客户端跟踪日志。客户端跟踪日志捕获由客户端生成的 WCF 提交和响应文档。还可以通过从“<服务器名称> - 日志”菜单中选择“禁用客户端跟踪日志”来禁用客户端跟踪日志。

启用服务器跟踪日志时，可能会出现“打开文件 - 安全警告”弹出窗口。单击“运行”可启用服务器跟踪日志并关闭弹出窗口。单击“取消”可取消服务器跟踪日志并关闭弹出窗口。如果从“打开文件 - 安全警告”弹出窗口中取消服务器跟踪日志，可能会出现错误弹出窗口。单击“确定”关闭出现的任何错误弹出窗口。

可以选择将服务器跟踪日志可执行文件的路径添加到本地 Intranet 设置中，以避免显示“打开文件 - 安全警告”弹出窗口。将此路径添加到本地内部网络设置中，且使用应用程序服务器的主机名或 IP 地址替换 <hostname>：

file://<hostname>\c$\Program Files (x86)\Camstar\InSite Server

如何启用服务器跟踪日志

按照以下步骤启用服务器跟踪日志：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开 Camstar 服务器并选择一个服务器节点。此时将显示“<服务器名称> - 日志”菜单。
3. 从日志菜单中选择服务器跟踪日志。应用程序将根据所选服务器跟踪日志的级别开始捕获信息。
4. 执行任何必要的工作。
5. 选择同一服务器节点，然后从日志菜单中选择禁用服务器跟踪日志。应用程序停止捕获信息并创建日志文件。
