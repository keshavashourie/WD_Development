查看许可证信息

通过 Management Studio 可查看企业可用的许可证数量、查看当前使用 Opcenter EX MDD 或 Opcenter EX CR 的已许可用户数以及许可证的到期日期。

查看许可证信息

从“管理”文件夹中选择许可证信息时，许可证信息会显示在 Management Studio 窗口的右窗格中。

如果发现正在使用的许可证数量总是接近或等于可用的许可证数量，则可能需要更多许可证。有关购买更多许可证的信息，请与产品支持联系。

许可证信息页显示时，将捕获正在使用的许可证数量。要查看当前正在使用的许可证数量，只需离开“许可证信息”页，然后再次显示“许可证信息”页即可。

还可以查看事件日志，确认尝试登录到应用程序的用户数量是否超过了可用许可证的数量。

在紧急情况下，可以通过产品支持获取临时许可证。例如，如果您订购其他许可证，Siemens 可以在处理您的新许可证订单之前提供临时许可证。有关安装新许可证的信息，请参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。

如何查看正在使用的许可证数量

按照以下步骤查看正在使用的许可证数量：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开“站点”树中的“管理”文件夹并选择许可证信息。许可证信息会显示在右窗格中。
3. 查看正在使用的许可证字段中的信息。

如何检查日志以了解超出的并发用户数

按照以下步骤检查事件日志以了解超出的并发用户数：

1. 单击开始 > Windows 管理工具 > 事件查看器。 此时将显示“事件查看器”窗口。
2. 展开应用程序和服务日志。
3. 单击 Camstar。
4. 查找 Camstar Security 作为源的错误。
5. 选择错误以查看详细信息。例如，它可能指示“已达到最大并发用户数，请稍后再试”。

如何检查日志以查看许可证是否过期

按照以下步骤检查事件日志以查看许可证是否过期：

1. 单击开始 > Windows 管理工具 > 事件查看器。 此时将显示“事件查看器”窗口。
2. 展开应用程序和服务日志。
3. 单击 Camstar。
4. 查找 Camstar Security 作为源的错误。
5. 选择错误以查看详细信息。 例如，它可能指示“由于以下错误，服务初始化失败：CamstarServerApplication 的许可证已过期，请与许可管理员联系。”
