配置 Inline SPC

Inline Statistical Process Control (SPC) 支持制造和工程在 Opcenter EX MDD 或 Opcenter EX CR 实施中配置和包含 SPC 控制图表。控制图表可以在收集质量数据时进行更新，并可对操作人员显示及时反馈。工程还可以审核历史图表，并将其作为研究特定事件的一部分。

配置 Inline SPC 时

通过 Inline SPC，可以自动将显示的图表保存至位于服务器上的文件路径中。 在 Inline SPC 安装过程中，创建默认文件路径 (C:\ProgramData\Camstar\InlineSPC\Chart Output)。 也可根据需要更改路径。 保存图表的其他选项在 SPC 图表建模页上定义。 请参考《Opcenter Execution Medical Device and Diagnostics Inline SPC 参考指南》或《Opcenter Execution Core Inline SPC 参考指南》。

Inline SPC 选项卡仅在安装了 Inline SPC 时显示。 请参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。

Inline SPC 许可

Inline SPC 许可在配置许可证选项卡上启用。 访问“许可证选”项卡，并单击保存以激活 Inline SPC 许可证，然后使用 appsettings 文件中的 Inline SPC 值更新 Flexlm 许可证服务器。

如何配置 Inline SPC 图表路径

按照以下步骤配置 Inline SPC 图表路径：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 在“站点”树中展开配置文件夹，然后选择配置图标。配置窗格即会显示。
3. 单击 Inline SPC 选项卡。 此时将显示“Industry Solutions 配置工具”对话框。
4. 单击浏览按钮。“浏览文件夹”弹出窗口即会显示。
5. 选择要用于 Inline SPC 图表路径的文件夹，然后单击确定。 “浏览文件夹”弹出窗口即会关闭。 “Inline SPC 图表路径”字段将更新为选定的文件夹。
6. 单击保存。新的 Inline SPC 图表路径配置完成。
注释: 访问“许可证”选项卡，然后单击保存以激活 Inline SPC 许可证。
