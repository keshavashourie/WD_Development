Management Studio Interface

The Management Studio client gives you the ability to maintain a list of sites and configuration information for each site. The Management Studio interface displays a tree view of the configuration. The right pane displays information specific to your selection in the left pane.

Management Studio Warning Messages

Warning message pop-ups appear when a change you make requires additional actions before the change can take effect. For example, a Warning message pop-up can tell you that you must perform a database update, restart a server, or regenerate WCF services. Clicking the OK button closes the Warning message pop-up.

• File
• Tools
• Help

<Server Name> - Logs Menu

The <Server Name> - Logs menu appears when you select a server node from the Camstar Servers folder.

Note: The <Server Name> - Logs menu only affects server and client trace logs for the currently selected server. Refer to "Enabling Server Trace Logs" for information.

This table describes the options on the <Server Name> - Logs menu.

Select this option:

To . . .

Enable Server Trace logs (Low)

Enables a server trace log that captures function name and parameter information. Refer to "Enabling Server Trace Logs" for information.

Enable Server Trace logs (Med)

Enables a server trace log that captures function name, parameter, and resolved values information. Refer to "Enabling Server Trace Logs" for information.

Enable Server Trace logs (High)

Enables a server trace log that captures function name, parameter, resolved values, and XML request and response information. Refer to "Enabling Server Trace Logs" for information.

Disable Server Trace logs

Disables any active server trace log.

Purge Server Trace logs

Clear all server trace logs in the file directory.

Note: A confirmation message appears when you select this option. Click Yes to close the confirmation message and clear all server trace logs in the file directory. A success message appears when the process has cleared all server trace logs. Click OK to close the success message.

Enable Client Trace logs

Enables a client trace log that captures the WCF submit and response documents generated by the client.

Note: This option is only available when a client trace log is not currently enabled.

Disable Client Trace logs

Disables the active client trace log.

Note: This option is only available when a client trace log is enabled.

Purge Client Trace logs

Clear all client trace logs in the file directory.

Note: A confirmation message appears when you select this option. Click Yes to close the confirmation message and clear all client trace logs in the file directory. A success message appears when the process has cleared all client trace logs. Click OK to close the success message.

Configuration File Name and Location

The configuration information you enter or change is saved to a configuration file. The default configuration file name is Config.ims. It is stored in the InSite Administration directory.

You can save your changes to this file or to a different file name or location. The Open Configuration option on the File menu enables you to open any Management Studio configuration file.

Note: The uninstall process backs up the Management Studio configuration file only if the default file name and file location are used.

How to Open Management Studio

You open Management Studio from the Start menu:

Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.
