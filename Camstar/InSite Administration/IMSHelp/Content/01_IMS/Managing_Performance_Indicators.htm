Managing Performance Counters

You can manage performance counters for your sites to capture performance information in Management Studio.

Performance Counters Information

Performance counter information appears in the right pane of the Management Studio window when you select the Performance Counters node from the Administration folder. The performance counter within Management Studio collects raw data from one counter at a time based on the counter selected. The application saves performance counter logs as CSV files. The default file name is PerformanceCounter.csv. The default location for the saved logs is C:\Program Files (x86)\Camstar\Logs.

The application overwrites the PerformanceCounter.csv file every time you start a performance counter.

The performance logs contain column header information. The first column is DateTimestamp. DateTimestamp includes the date and time the sample was collected. Three additional column headers may be included based on your selected performance counter settings:

• Category
• Counter
• Instance

Each performance counter setting header is separated by "[]" and "." in the name.

Examples:

DateTimestamp,[category].[counter].[instance]

DateTimestamp,[ASP.NET Applications].[% Managed Processor Time Base (estimated)].[__Total__]

Performance counters use the Microsoft Performance Monitor and Performance Counters. Refer to Microsoft's Support site for information on the Microsoft Performance Monitor and Performance Counters.

The application displays an error message when an error occurs. Errors are logged in the Event Viewer.

How to Start and Stop Performance Counters

Follow these steps to start and stop performance counters:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Administration folder and select the Performance Counters node. Performance counter information appears in the right pane.
3. Select a server from the Server field.
4. Select a category from the Category field. The Counter field is enabled and the list of counters is populated based on the category selected.
5. Select a counter from the Counter field. The Instance field is enabled and the list of instances is populated based on the counter selected.
6. Select an instance from the Instance field. The Start button is enabled.
7. Set the number of samples to capture from the Samples to Collect field.
8. Set the frequency at which samples are captured in the Sample Frequency (sec) field.
9. Click Start. Management Studio displays the message "Samples are being collected." and starts capturing performance information. Management Studio then displays the message "Stopped collecting samples." and saves the performance information to a log file once the specified number of samples are collected.
10. Click the Output File (Click to open) field to display the log file.
