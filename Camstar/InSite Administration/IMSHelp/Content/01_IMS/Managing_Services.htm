Managing Services

The Opcenter EX MDD and Opcenter EX CR servers are registered as services. You can view the status of these services from the Services pane. You can also start, stop, and restart them from the Services pane.

Services Information

Information for product-related services appears in the right pane of the Management Studio window when you select Services from the Administration folder. The right pane contains a table that lists the services and their current status.

Sites contain these services by default:

• Camstar App Server
• Camstar Deployment Server
• Camstar Notification Server
• Camstar Security Services
• Camstar WCF Services
• Portal
• REST API Label
• REST API Modeling
• REST API Query
• REST API Shopfloor

A Services menu appears on the Management Studio window when you select the Services node in the Administration folder. Refer to "Services Menu" for information on the Services menu.

Important: Starting and stopping services only affects their status on the currently selected server on the Services for <server> field. Selecting another server refreshes the list of services and their current status.

Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information on the recommended order to stop and restart services. Some of the services run as application pools in IIS and others run as services in Windows Administrative Tools.

How to Start a Service

Follow these steps to start a service:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Administration folder and select the Services node. The Services information appears in the right pane.
3. Select a server from the Services for <server> field. The Services grid refreshes and displays a list of services and their current status.
4. Right-click a stopped service and select Start Service. The service's status changes to Running.
5. Repeat step 3 to start additional stopped services as needed.

How to Stop a Service

Follow these steps to stop a service:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Administration folder and select the Services node. The Services information appears in the right pane.
3. Select a server from the Services for <server> field. The Services grid refreshes and displays a list of services and their current status.
4. Right-click a running service and select Stop Service. The service's status changes to Stopped.
5. Repeat step 3 to stop additional running services as needed.

How to Stop All Services

Follow these steps to stop all services:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Administration folder and select the Services node. The Services information appears in the right pane.
3. Select a server from the Services for <server> field. The Services grid refreshes and displays a list of services and their current status.
4. Right-click a service and select Stop Services. All services are stopped and their statuses appear as Stopped.

How to Restart Services

Follow these steps to restart services:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Administration folder and select the Services node. The Services information appears in the right pane.
3. Select a server from the Services for <server> field. The Services grid refreshes and displays a list of services and their current status.
4. Right-click a service and select Restart Services. All services are restarted and their statuses appear as Running.
