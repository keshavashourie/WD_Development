Updating the Transaction Database

The Update Database task in Management Studio updates your transaction and operational DataStore databases assuming the database configurations are in place. Perform this task after making configuration changes in Designer and only after the Create New Database Tables task has been performed. Refer to "Creating New Database Tables" for information.

Changes entered through Designer are recorded in the InSite.mdb files. You must apply these changes to your transaction database and, if relevant, your DataStore database. Your Transaction and DataStore databases must be different databases when performing a database update. The application updates tables and columns in the transaction database when the Designer classes are subclassed and fields are added.

Important: Perform the Create or Update process only once from any member in the cluster in a clustered environment.

Requirement for Update Database Tasks

The Opcenter EX MDD or Opcenter EX CR database user requires unrestricted access to these default user views for Update Database tasks:

• For Oracle
USER_TABLES
USER_TAB_COLUMNS
USER_CONSTRAINTS
USER_CONS_COLUMNS
• For SQL Server
INFORMATION_SCHEMA.TABLES
INFORMATION_SCHEMA.COLUMNS
INFORMATION_SCHEMA.KEY_COLUMN_USAGE

When to Restart Application Pools and Services after Updating the Database

The application typically does not suspend application pools and services while updating the database. This enables the application to continue processing shop floor transactions. These situations require stopping the application pools and services and then restarting them after updating the database:

• Regenerating WCF services requires a recycle of the Portal and Camstar WCF Services application pools.
• Regenerating REST API services requires a recycle of the Portal and REST API application pools.
• Modifying the database connection information requires a restart of the Camstar Security Services and Camstar App Server application pools.
• Manually changing the database schema requires a restart of the Camstar App Server application pool.
Note: A message stating to restart the Camstar App Server may appear in Management Studio if you perform other actions that require restarting. Refer to "Managing Services" for information on application pools and services.

How to Update the Transaction Database

Follow these steps to update the transaction database after making changes in Designer:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand Databases, and then right-click Transaction Database.
3. Select Update Database. The Update Database dialog box appears.
4. Select or clear the update options according to your business requirements. Refer to the check box definitions table for information on the check boxes.
5. Click OK. The progress line indicates that the process is running and a SQL Script pop-up appears, showing the progress of the scripts as they execute. If an error is encountered, the Error Information section is enabled and populated. If you select a different file, the Error Information section updates with the Script name.
6. Do one of the following if an error occurs:
• Click the View… button to open the script file in Notepad (or the associated program).
• Click the Run Scripts button to re-run all scripts from the beginning.
