Managing Workspace Indexes

Indexes defined in Designer are created by a stored procedure that reads in the definition and creates the database indexes. There are some cases where changes to an existing index are required but not supported by Designer, such as clustered indexes or where additional columns are required for a specific workspace. To support these cases, workspace specific stored procedures can be written to be called during the index creation process. This allows for modification of existing indexes. Each active workspace can have its own procedure, and the index creation process calls each one from your lowest to highest active workspace.

When Managing Workspace Indexes

A stored procedure is executed when updating the Transaction database or creating database tables with the Create Indices check box selected. The csiCreateIndexes stored procedure is executed to read in the definitions and create indexes based on those definitions.

After the indexes are created for each active workspace in ascending order according to the workspace sequence, the procedure checks for the existence of a stored procedure with a specific name and calls it if it exists. For example, if you have workspaces 180, 190, and 200 active with a custom stored procedure file for each workspace, the application would execute the procedures in the order 180, 190, and then 200.

Note: Any changes made to indexes are logged in the Replace Workspace Data utility's log file. Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information on the Replace Workspace Data utility.

Only one stored procedure can exist for each active workspace. You must follow the naming convention "Workspace_WSCode_CreateIndexes" where "WSCode" is the workspace's code, such as "180" or "190". For example, "Workspace_200_CreateIndexes" must be the name for workspace 200’s stored procedure.

Sample stored procedure files are provided for both SQL Server and Oracle databases as a starting point for creating your custom index stored procedures. The sample files are available in these locations:

• C:\Program Files (x86)\Camstar\Insite Administration\Scripts\Oracle for Oracle databases.
• C:\Program Files (x86)\Camstar\Insite Administration\Scripts\SqlServer for SQL databases.

You must execute the scripts you created for your database in Management Studio to create the stored procedure. A stored procedure is executed when updating the Transaction database or creating database tables with the Create Indices check box selected. The csiCreateIndexes procedure then finds the custom procedure and calls it during the Index Creation process.
