Verification and Deletion Procedures

These procedures explain how to verify the database connection settings in Management Studio and how to delete a database in Management Studio.

Note: A Databases menu appears on the Management Studio window when the Databases folder or database nodes are selected. Refer to "Databases Menu" for information on the Databases menu.

How to Verify the Database Connection Settings

Follow these steps to verify the database connection settings:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Select the database for which you want to verify the connection. The configuration information for that database appears in the right pane.
3. Click Test Connect. Management Studio displays a "Connection Established" message if the connection is successful. Otherwise, Management Studio displays an error message.
Note: The Test Connect button for the Transaction and DataStore databases validates only the user name and the password. It does not validate the schema.

How to Delete a Database

Follow these steps to delete any database:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Right-click the database you want to delete and select Delete Database. A confirmation dialog box appears.
3. Click Yes. The database entry is deleted.
