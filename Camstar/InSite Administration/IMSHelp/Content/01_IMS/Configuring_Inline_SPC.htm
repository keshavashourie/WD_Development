Configuring Inline SPC

Inline Statistical Process Control (SPC) enables manufacturing and engineering to configure and include SPC control charts in a Opcenter EX MDD or Opcenter EX CR implementation. Control charts can be updated as quality data is collected, and can be displayed to the operator for immediate feedback. Engineering can also review historical charts as a part of research into specific events.

When Configuring Inline SPC

Inline SPC provides the ability to automatically save displayed charts to a file path located on your server. A default file path (C:\ProgramData\Camstar\InlineSPC\Chart Output) is created during Inline SPC installation. You can change the path as needed. Additional options for saving charts are defined on the SPC Chart modeling page. Refer to the Opcenter Execution Medical Device and Diagnostics Inline SPC Reference Guide or the Opcenter Execution Core Inline SPC Reference Guide.

The Inline SPC tab only appears when Inline SPC is installed. Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide.

Inline SPC Licensing

Inline SPC licensing is enabled on the configuration License tab. Access the License tab and click Save to activate the Inline SPC license and update the Flexlm license server with the Inline SPC value in the appsettings file.

How to Configure the Inline SPC Chart Path

Follow these steps to configure the Inline SPC Chart Path:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Configuration folder in the Sites tree and select the Configuration icon. The configuration pane appears.
3. Click the Inline SPC tab. The Industry Solutions Configuration Tool dialog box appears.
4. Click the browse button. The Browse for Folder pop-up appears.
5. Select the file folder to use for the Inline SPC Chart Path and click OK. The Browse for Folder pop-up closes. The Inline SPC Chart Path field is updated with the selected file folder.
6. Click Save. The new Inline SPC Chart Path is configured.
Note: Access the License tab and click Save to activate the Inline SPC license.
