Configuring License Expiration Notifications

Opcenter EX MDD and Opcenter EX CR provide the ability to automatically notify designated recipients when their license expires. You can also use Management Studio to configure settings to send e-mail notices at intervals before the license expires. There are two intervals you can set:

• Warning Period
• Critical Period

The application sends the e-mail notification once per period: once for warning and once for critical. For example, if you set the warning period to 30 days and the critical period to 15 days, you will receive a warning notice 30 days before your license expires followed by a critical notice 15 days before your license expires. You will also receive an e-mail when the license expires.

When Configuring License Expiration Notifications

You can set the Warning Period to zero to disable Warning Period e-mail notifications.

You can set the Critical Period to zero to disable Critical Period e-mail notifications.

Note: The maximum number of days you can enter in the Warning Period and Critical Period fields is 365.

Separate e-mail recipient addresses with a semicolon. At least one address is required.

The license period expiration date is reset when a new license is issued.

Subject and text for each of the e-mail notifications is system-defined.

You must define an SMTP transport for the Exchange server and a new site that uses the SMTP transport. The site name must match the site name used in Management Studio. SMTP transports and sites are defined in Modeling.

Temporary licenses are available on an emergency basis through Product Support. For example, if you order additional licenses, Siemens can provide temporary licenses until your new license order is processed.

Note: The application adds the Siemens PLM License Server port number (28000) as a prefix to the license server fields after you save configuration information.

Licensing Errors

Certain log on and log off procedures can affect the number of available licenses. Follow this basic procedure when logging on to the Portal from your web browser to prevent errors:

1. Start a new session of your web browser.
2. Log on to the Portal.

Refer to the Opcenter Execution Medical Device and Diagnostics Getting Started User Guide or the Opcenter Execution Core Getting Started User Guide for information on logging in.

Starting a browser using any of these methods results in a license error. Do not start your browser using one of these procedures:

• Launching a new browser session using the .exe file (such as selecting it from the Start menu)
• Opening a new window from an existing browser session
• Launching a new tab from an existing browser session

Siemens does not support multiple instances of the application in the same browser.

Installing a new license without restarting the product-related application pools and services can affect the license information displayed in Management Studio. Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information on installing new license files.

How to Configure License Expiration Notifications

Follow these steps to configure license expiration notifications:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the site for which you want to configure license expiration notifications.
3. Expand the Configuration folder in the Sites tree and select the Configuration node. The site configuration information appears in the right pane.
4. Click the License tab. The License tab appears.
5. Select Enable Notification E-mails.
6. Select the number of days in the Warning Period field to define when a warning notification is sent.
7. Select the number of days in the Critical Period field to define when a critical notification is sent.
8. Enter the e-mail address to be recorded as the E-mail Sender of the notification e-mail.
9. Enter the list of e-mail addresses, separated by semicolons, to which the e-mail notification will be sent.
10. Click Save. Management Studio displays a success message.
