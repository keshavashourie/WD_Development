Managing Metadata Database Configuration

You must create a Metadata database before creating the other databases.

Metadata Database Configuration Information

Configuration information for the Metadata database appears in the right pane of the Management Studio window when you add or select the Metadata database.

A Databases menu appears on the Management Studio window when the Databases folder or database nodes are selected. Refer to "Databases Menu" for information on the Databases menu.

These fields display the Metadata database (InSite.mdb) and the Site Info database (SiteInfo.mdb) connection information. The Database file names are display only, but you can browse for the file.

How to Add and Configure a Metadata Database

Follow these steps to add and configure a Metadata database:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Right-click the Databases folder and select Add Metadata Database. A Metadata Database icon appears and the Metadata Database Configuration information appears in the right pane.
3. Click Browse for the Designer Metadata Database field to open the Select a metadata database window. The InSite.mdb is the default selection.
4. Click Open to select the default database or select a different database if necessary. The database selection appears in the Designer Metadata Database field.
5. Click Browse for the Site Info Database Filename field to open the Select a site info database window. The SiteInfo.mdb is the default selection.
6. Click Open to select the default database or select a different database if necessary. The database selection appears in the Site Info Database Filename field.
7. Click Test Connect for each database. Management Studio displays a “Connection Established” message if the connection is successfully established. Otherwise, the application displays an error message.
8. Click OK to close the message.
9. Click Save. Management Studio displays a success message.
