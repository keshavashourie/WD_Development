Encrypting the REST API Password

REST APIs provide an easy-to-use Web API abstraction layer for executing transactions supported by the Application Server. REST APIs enable you to execute transactions more efficiently than if using WCF services. The Encryption Utility enables you to encrypt the password you use with REST API if you want to specify your credentials manually. After the utility encrypts the password, you can copy it into to the appsettings.json file for each API service manually.

Note: Instead of encrypting the password using this utility and then manually copying the encrypted password into the appsettings.json files, you can specify your REST API credentials in Management Studio and have Management Studio automatically encrypt the password and copy the credentials to the appsettings.json file for each API service. Refer to "REST API Settings" for information.

Refer to the Opcenter Execution Medical Device and Diagnostics Technical Reference: REST API or the Opcenter Execution Core Technical Reference: REST API for information on installing and using REST APIs.

How to Encrypt the REST API Password

Follow these steps to encrypt the REST API password:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Select Encrypt Utility from the Tools menu. The Encrypt Utility window appears.
3. Enter the REST API password you want to use in the Input field.
4. Click Encrypt. The encrypted password appears in the Output field.
5. Select the encrypted password.
6. Right-click and select Copy.
7. Paste the encrypted password into the appsettings.json file for each API service. Refer to the Opcenter Execution Medical Device and Diagnostics Technical Reference: REST API or the Opcenter Execution Core Technical Reference: REST API for information on the appsettings.json files and inserting the password into these files.
