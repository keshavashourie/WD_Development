Enabling Server Trace Logs

You can enable different levels of server trace logging from the <Server Name> - Logs menu. Server traces allow you to capture debugging information for various requests and responses.

When Enabling Server Trace Logs

You enable Server trace logs by selecting a server node from the Camstar Servers folder and then selecting a server trace log from the <Server Name> - Logs menu. Refer to "<Server Name> - Logs Menu" for information on the <Server Name> - Logs menu.

Note: You must re-enable the Server trace logs after completing a database update (dbupdate). Re-enabling the logs is required because the server is restarted and server trace logs are disabled when a dbupdate is performed.

This table defines what information is captured at each server trace log level.

Level

Information captured

Low

Function names and parameters.

Med

Function names, parameters, and resolved values.

High

Function names, parameters, resolved values, and XML requests and responses.

Only one of the three server trace log levels (Low, Med, or High) can be active on a server at a time. For example, selecting Low, and then selecting Med would only enable the medium level server trace log. You can run separate server traces at different levels on each of your servers simultaneously.

You can disable an active server trace log by selecting a server node currently running a server trace and then selecting Disable Server Trace logs from the Logs menu.

Log files are stored at Program Files (x86)\Camstar\Logs\Transaction Logs by default.

You can also enable a client trace log by selecting Enable Client Trace logs from the <Server Name> - Logs menu. The client trace log captures the WCF submit and response documents generated by the client. You can then disable the client trace log by selecting Disable Client Trace logs from the <Server Name> - Logs menu.

An Open File - Security Warning pop-up may appear when you enable a server trace log. Click Run to enable the server trace log and close the pop-up. Click Cancel to cancel the server trace log and close the pop-up. Error pop-ups may appear if you cancel your server trace log from the Open File - Security Warning pop-up. Click OK to close any Error pop-ups that appear.

You can optionally add the path to the server trace log executable file to your local intranet settings to avoid displaying the Open File - Security Warning pop-up. Add this path to your local intranet settings, replacing <hostname> with the hostname or IP address of your Application server:

file://<hostname>\c$\Program Files (x86)\Camstar\InSite Server

How to Enable Server Trace Logs

Follow these steps to enable server trace logs:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand Camstar Servers and select a server node. The <Server Name> - Logs menu appears.
3. Select a server trace log from the Logs menu. The application starts capturing information based on the level of the selected server trace log.
4. Perform any necessary work.
5. Select the same server node and then Select Disable Server Trace logs from the Logs menu. The application stops capturing information and creates a log file.
