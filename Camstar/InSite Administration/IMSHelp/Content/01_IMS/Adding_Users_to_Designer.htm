Adding Users to Designer

You can add users to and delete users from Designer.

Designer User Information

Designer user information appears in the right pane of the Management Studio window when you select Designer User Administration from the Administration folder.

Siemens provides three default users:

• CamstarAdmin
• Administrator
• InSiteAdmin

Access to Designer is based on Windows security. Ensure Designer users have a valid Windows account and that they have been added as Designer users in Management Studio. Refer to the Opcenter Execution Medical Device and Diagnostics Designer User Guide or the Opcenter Execution Core User Guide for information on using Designer.

You can add users by clicking in the first blank row and entering the username. Click Save to add the user. You can delete users by selecting the row of a user and pressing the Delete key or by clicking the red delete icon associated with the UserName. that appears in the deleteLink column. Clicking the delete icon displays a Delete Row confirmation message. Click Yes on the Delete Row confirmation message to delete the user and close the message.

How to Add Designer Users

Follow these steps to add Designer users:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Administration folder in the Sites tree and select Designer User Administration. The Designer User administration information appears in the right pane.
3. Click in the first blank UserName field and enter the name of the new user.
4. Repeat step 3 to add additional users as needed.
5. Click Save. Management Studio displays a success message.

How to Delete Designer Users

Follow these steps to delete Designer users:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

2. Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.
3. Expand the Administration folder in the Sites tree and select Designer User Administration. The Designer User administration information appears in the right pane.
4. Select the row of the user you want to delete.
5. Press Delete. The application deletes the user.
6. Repeat steps 3-4 to delete additional users as needed.
7. Click Save. Management Studio displays a success message.
