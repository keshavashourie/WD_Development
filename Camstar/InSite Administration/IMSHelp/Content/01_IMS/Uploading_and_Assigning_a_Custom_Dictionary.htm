Uploading and Assigning a Custom Dictionary

You can create custom dictionaries to organize your custom or translated system and user labels. You can assign dictionaries to employees on an individual basis.

When Uploading and Assigning a Custom Dictionary

You can upload dictionary labels using custom .csv files in Management Studio. The application displays the appropriate labels contained in the dictionary when an employee with a designated dictionary logs into Portal. If an employee does not have a designated dictionary, the default labels appear.

Dictionary labels are cached in both Application Server and Portal application caches. Dictionary labels are stored within the database and cached in Portal's IIS cache. You must recycle the IIS application pool to refresh the cache. The dictionary label cache is updated when a dictionary modeling instance is updated.

On saving of a dictionary Modeling instance, the label cache is automatically refreshed out of the box if the save includes changes.

Refer to the Opcenter Execution Medical Device and Diagnostics Modeling User Guide or the Opcenter Execution Core Modeling User Guide for information on defining dictionaries. Refer to the Opcenter Execution Medical Device and Diagnostics Designer User Guide or the Opcenter Execution Core Designer User Guide for information on labels.

How to Upload a Custom Dictionary

Follow these steps to upload a custom dictionary:

1. Export the labels file.
2. Ensure the spreadsheet is formatted correctly. The following columns are required: LabelID, Name, CategoryID, LabelValue, WorkspaceCode, and NewValue.
Note: The last column is named Column1 when it is exported, so the column must be renamed to NewValue.
3. Enter the translations of each entry into the NewValue column.
4. Save the spreadsheet as a .csv file using the name you want to use as your Dictionary modeling object.
5. Copy the .csv file to: C:\Program Files (x86)\Camstar\InSite Administration\Dictionaries.
6. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

7. Expand Databases, and then right-click Transaction Database.
8. Select Update Database. The Update Database dialog box appears.
9. Select Load Camstar Dictionaries and Reload All.
10. Click OK. The dictionary modeling object and associated translations are created.
11. Assign the foreign language dictionary to the desired employee. Refer to “How to Assign a Custom Dictionary.”
12. Log out of Opcenter EX MDD or Opcenter EX CR.
13. Restart the application pools and services.
Note: Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for the best order in which to start the application pools and services.
14. Perform an IISReset if necessary.
15. Clear the browser’s cache.

How to Assign a Custom Dictionary

Follow these steps to assign a custom dictionary:

1. Log on to the Portal.
2. Select Modeling from the Modeling menu. The Modeling page appears.
3. Click Employee. The Employee page appears within the Modeling page.
4. Select an Employee instance.
5. Select the appropriate dictionary from the Language Dictionary list.
6. Click Save. The application displays a success message indicating the modeling object was updated.
7. Log off of the Portal.
8. Log on to the Portal as the employee to whom you assigned the new dictionary. The labels now appear in the foreign language.
Note: Some items like page names and menu items are not controlled by labels. You must change those items to the foreign language in Portal Studio.
