Accessing Online Help

You can use the Help menu to open the:

• Online help project for Management Studio
• About pop-up

The Management Studio Help provides online Help for every topic in this section.

When Accessing Online Help

Online Help appears in the preferred language set in your browser if translated help is available. Ensure you have the latest language packages installed for your preferred language. Help appears in English by default.

How to Access Management Studio Help

Follow these steps to access Management Studio Help:

1. Select Management Studio Help from the Help menu. The online Help file appears.
2. Use the navigation on the left or search for specific topics.

How to Access the About Pop-up

Follow these steps to access the About pop-up:

1. Select About from the Help menu. The About pop-up appears.
2. Click Close when finished viewing information about Management Studio. The About pop-up closes.
