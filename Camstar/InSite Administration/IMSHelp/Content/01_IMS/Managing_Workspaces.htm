Managing Workspaces

Siemens provides workspaces for metadata to make development, deployment, and upgrading of partner offerings and customer customizations easier and more manageable. Metadata records are assigned to a customer, partner, industry solution, or base (csi) workspace.

Note: Metadata databases must be converted following an upgrade to Opcenter EX MDD or Opcenter EX CR  to enable proper workspace functionality.

Understanding Workspaces

Workspaces provide the ability for customers, partners, and Siemens to change or customize Opcenter EX MDD or Opcenter EX CR without overwriting changes made by others. Making changes in a workspace isolates those changes from any updates made to any other workspace. For example, changes made in the highest level workspace do not affect the base workspace. Similarly, if a customer accepts an update to the base workspace, customizations in their workspace are not overwritten.

Siemens provides four types of workspaces:

• Base (csi)
• Industry solution
• Partner
• Customer - (Corporate, Division, and Site workspaces)

The active workspace with the highest sequence number takes priority and is where all work and user content is saved. The Site workspace is the highest priority workspace. Once you begin working in a workspace in the Designer, you cannot deactivate it.

When Managing Workspaces

The base and Site workspaces are active by default. You can activate additional workspaces through Management Studio.

You can also make workspaces inactive with the exception of the base workspace. You cannot make the base workspace inactive. Do not make the Site workspace inactive.

Customers should always work in the Site workspace (200). If a customer deactivates the Site workspace and works only in the base (csi) workspace, any changes made to the base workspace are overwritten when the customer installs a software update.

You must update your Transaction database, including generating the WCF services, after making workspaces active or inactive.

You cannot activate or deactivate workspaces if the InSite.mdb file is set to Read Only. Management Studio displays a warning message when attempting to manage workspaces if the InSite.mdb file is Read Only.

Note: A warning message appears when activating workspace 220. Activating workspace 220 and saving changes will prevent any future changes in workspace 200.

How to Activate a Workspace

Follow these steps to activate a workspace:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Workspace Administration folder and select the Workspace Administration node. The workspace administration information appears in the right pane.
3. Select the Active check box of the workspace you want to activate.
4. Enter optional information according to your business requirements. Refer to the field definitions tables for information on the optional fields.
5. Click Save. Management Studio displays a success message.
6. Perform the "How to Update the Transaction Database for Workspace Changes" procedure.

How to Update the Transaction Database for Workspace Changes

Follow these steps to update the Transaction database for workspace changes:

1. Expand the Database folder in the Sites tree and then right-click Transaction Database.
2. Select Update Database.... The Update Database dialog box appears.
3. Select the Generate WCF Services check box.
4. Select or clear the other update options according to your business requirements. Refer to "Updating the Transaction Database" for information on the check boxes. Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information on regenerating WCF services, including managing files.
5. Click OK. The update process starts and Management Studio displays a success message when it completes.
