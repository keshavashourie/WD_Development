Verwalten von Anwendungscodedateien für Arbeitsbereiche

Siemens stellt die ausführbare Datei "MergeAppCode" zur Verfügung, mit der die Anwendungscodedateien der aktiven Arbeitsbereiche zusammengeführt werden können.

Beim Verwalten von Anwendungscodedateien für Arbeitsbereiche

Die ausführbare Datei "MergeAppCode.exe" verarbeitet die Unterordner der einzelnen Arbeitsbereiche und legt die Erbfolge der einzelnen Anwendungscodedateien so fest, dass die Vererbung vom darüber liegenden Arbeitsbereich erfolgt. Wenn z. B. die Arbeitsbereiche "csi", "180" und "190" aktiv sind, wird die Erbfolge von MoveStd_190 von ":MoveStd" in ":MoveStd_180" geändert. Die ausführbare Datei befindet sich im Dateipfad "C:\Programme (x86)\Camstar\Insite Conversion Tool\MergeAppCode".

Eine Konfigurationsdatei (MergeAppCode.exe.config) zum Ändern der ausführbaren Datei befindet sich ebenfalls im Dateipfad "C:\Programme (x86)\Camstar\Insite Conversion Tool\MergeAppCode". Sie können den Schlüssel "WebPortletPath" in den relativen oder absoluten Pfad zum Ordner "WebPortlet" ändern.

Wichtig: Ändern Sie keinesfalls den Schlüssel "mdbConnectionString" in der Datei "MergeAppCode.config".

Sie müssen Arbeitsbereichsunterordner zum Dateipfad "C:\Programme (x86)\Camstar\Camstar Portal\App_Code\WebPortlets\Workspaces" hinzufügen und darin die Anwendungscodedateien speichern, die zusammengeführt werden sollen. Die Arbeitsbereichsunterordner müssen entsprechend dem Code des zugehörigen Arbeitsbereichs benannt werden. Der Name des Unterordners für den Arbeitsbereich "200" muss z. B. "200" sein.

Sie müssen den zugehörigen Arbeitsbereichscode an alle Namen von benutzerdefinierten Steuerelementen, Funktionen und Eigenschaften anhängen. Ein Steuerelement namens "ControlName" im Arbeitsbereich "200" muss den Namen "ControlName_200" aufweisen, damit die ausführbare Datei den zugehörigen Arbeitsbereich und die Erbfolge bestimmen kann. Alle Dateien müssen im zugehörigen Arbeitsbereichsunterordner gespeichert werden.

Wenn außer dem Basisarbeitsbereich "csi" keine aktiven Arbeitsbereiche verfügbar sind oder WebPortletPath nicht gefunden werden kann, wird eine Fehlermeldung angezeigt. Fehler werden in der Ereignisanzeige protokolliert.

Vorgehensweise zum Zusammenführen von Anwendungscodedateien

Gehen Sie folgendermaßen vor, um Anwendungscodedateien zusammenzuführen:

1. Navigieren Sie zum Dateipfad "C:\Programme (x86)\Camstar\Insite Conversion Tool\MergeAppCode".
2. Doppelklicken Sie auf MergeAppCode.exe. Während die ausführbare Datei die Anwendungscodedateien zusammenführt, wird ein Popup "Eingabeaufforderung" angezeigt. Nach Abschluss wird eine Erfolgsmeldung angezeigt.
