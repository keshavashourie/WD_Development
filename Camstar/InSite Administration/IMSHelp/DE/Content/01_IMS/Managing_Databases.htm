Verwalten von Datenbanken

Im nächsten Schritt des Konfigurationsprozesses werden die Datenbanken erstellt. Es gibt drei Typen von Datenbanken, die Sie hinzufügen können.

Typ

Definition

Metadaten

Die Datenbanken "InSite.mdb" und "SiteInfo.mdb" werden von Designer verwendet. Diese Datenbanken enthalten Konfigurationsinformationen zu Opcenter EX MDD oder Opcenter EX CR.

Transaktion

Die Transaktionsdatenbank ist die wichtigste Produktionsdatenbank, die von Opcenter EX MDD oder Opcenter EX CR verwendet wird. Sie speichert alle Ihre Opcenter EX MDD- oder Opcenter EX CR-Informationen wie Tabellen und Instanzen. Sie wird auch als OLTP-Datenbank bezeichnet.

DataStore

DataStore ist eine Betriebsdatenbank, die von der Transaktionsdatenbank (Produktionsdatenbank) getrennt ist. Sie ist nur erforderlich, wenn Sie DataStore verwenden.

Metadatenfelder, Tabellen, Beziehungen, Instanzdaten, Indizes, gespeicherte Prozeduren und Primärschlüssel in der Produktionsdatenbank werden:

• Über den Menübefehl "Neue Datenbanktabellen erstellen" erstellt und
• Über den Menübefehl "Datenbank aktualisieren" aktualisiert.

Informationen zu den unterstützten Datenbankversionen finden Sie in der aktuellen Release-Matrix für OC EX MDD im Support Center.

Informationen zu den unterstützten Datenbankversionen finden Sie in der aktuellen Release-Matrix für OC EX CR im Support Center.

Beim Erstellen von Datenbanken

Müssen Sie Folgendes erstellen:

• Eine Metadaten-Datenbank, bevor Sie eine Transaktionsdatenbank erstellen können.
• Eine Transaktionsdatenbank, bevor Sie eine DataStore-Datenbank erstellen können.

Diese beiden Datenbanken sind erforderlich. Die DataStore-Datenbank ist nur erforderlich, wenn Sie DataStore installiert haben.

Die Metadaten-Datenbank verwendet die Designer-Datenquellen, "InSite.mdb" und "SiteInfo.mdb", die während der Installation erstellt werden. Die Designer und InSite SiteInfo werden automatisch bei der Installation zusammen mit der Verwaltungs- und -Konfigurationskomponente definiert.

Hinweis: Vergewissern Sie sich in einer Clusterumgebung, dass jedes Mitglied des Clusters dieselben Einstellungen auf den Registerkarten hat, auf denen sich die ODBC-Informationen und die Standortinformationen befinden.

Beim Aktualisieren von Datenbanken

Die Auswahl "Datenbank aktualisieren" kann Aktualisierungen an Ihre verschiedenen Datenbanktypen senden, z. B. Transaktions- oder Betriebsdatenbanken, solange die Datenbankkonfigurationen vorhanden sind.

Spezieller Hinweis zu Oracle-Datenbanken

Oracle Enterprise Edition sperrt keine Datenbanktabellen, während die Indizes neu erstellt werden. Daher werden alle Transaktionen von Opcenter EX MDD oder Opcenter EX CR während dieses Aktualisierungsvorgangs erfolgreich ausgeführt.

Wenn Sie aber die Oracle Standard Edition verwenden, können Datenbanktabellen vorübergehend gesperrt werden, während die Indizes neu erstellt werden. Bei einigen Opcenter EX MDD- oder Opcenter EX CR-Transaktionen können Fehler auftreten, wenn die Transaktion versucht, auf eine temporär gesperrte Tabelle zuzugreifen. Daher wird empfohlen, dass Sie während einer Datenbankaktualisierung mit der Oracle Standard Edition keine Opcenter EX MDD- oder Opcenter EX CR-Transaktionen ausführen.

Beim Löschen von Datenbanken

Datenbanken müssen entgegengesetzt zu der Reihenfolge gelöscht werden, in der sie erstellt wurden. Sie müssen z. B. zuerst die DataStore-Datenbank löschen, bevor Sie die Transaktionsdatenbank löschen können. Sie müssen ebenso die Transaktionsdatenbank löschen, bevor Sie die Metadaten-Datenbank löschen.

Wenn Sie eine Datenbank in Management Studio löschen, hat das keine Auswirkungen auf die Daten in der Datenbank. Es wird nur der Eintrag aus der .mdb entfernt.
