Management Studio-Benutzeroberfläche

Der Management Studio-Client ermöglicht es Ihnen, eine Liste von Standorten und Konfigurationsinformationen für jeden Standort zu verwalten. Die Management Studio-Benutzeroberfläche zeigt eine Strukturansicht der Konfiguration an. Die rechte Bereich zeigt Informationen zu dem Element an, das im linken Bereich ausgewählt ist.

Management Studio-Warnmeldungen

Popup-Fenster mit Warnmeldungen werden angezeigt, wenn eine durch Sie durchgeführte Änderung weitere Aktionen erfordert, bevor die Änderung wirksam werden kann. In einem Warnmeldungs-Popupfenster können Sie z. B. darauf hingewiesen werden, dass Sie eine Datenbankaktualisierung durchführen, einen Server neu starten oder WCF-Dienste erneut erstellen müssen. Durch Klicken auf die Schaltfläche "OK" wird das Warnmeldungs-Popupfenster geschlossen.

Name und Speicherort der Konfigurationsdatei

Die Konfigurationsinformationen, die Sie eingeben oder ändern, werden in einer Konfigurationsdatei gespeichert. Der Standardname der Konfigurationsdatei ist "Config.ims". Sie wird im Verzeichnis "InSite Administration" gespeichert.

Sie können Ihre Änderungen in dieser Datei oder in einer anderen Datei oder in einem anderen Speicherort speichern. Über den Befehl "Konfiguration öffnen" im Menü "Datei" können Sie jede Management Studio-Konfigurationsdatei öffnen.

Hinweis: Die Deinstallation sichert die Management Studio-Konfigurationsdatei nur, wenn der Standard-Dateiname und der Standard-Dateispeicherort verwendet werden.

Vorgehensweise zum Öffnen von Management Studio

Sie öffnen Management Studio im Startmenü:

Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.
