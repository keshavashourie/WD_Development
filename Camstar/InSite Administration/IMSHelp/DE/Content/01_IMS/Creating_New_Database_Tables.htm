Erstellen von neuen Datenbanktabellen

Der nächste Schritt nach dem Hinzufügen von Datenbanken in Management Studio besteht darin, Ihr Datenbank-Managementsystem (DBMS) mit produktbezogenen Tabellen zu füllen. Sie können Tabellen für die Transaktionsdatenbank und die DataStore-Datenbank erstellen.

Hinweis: Dieses Thema beschreibt die Erstellung von Datenbanktabellen für die Transaktionsdatenbank. Weitere Informationen zum Erstellen von Tabellen für die DataStore-Datenbank finden Sie im Opcenter Execution Medical Device and Diagnostics DataStore-Referenzhandbuch oder im Opcenter Execution Core DataStore-Referenzhandbuch.

Beim Erstellen von neuen Datenbanktabellen

Die Metadatenfelder, Tabellen, Beziehungen, Instanzdaten, Indizes, gespeicherten Prozeduren und Primärschlüssel in der Produktionsdatenbank werden durch Ausführen der Aufgabe "Neue Datenbanktabellen erstellen" erstellt. Diese Aufgabe führen Sie durch, nachdem Sie Opcenter EX MDD oder Opcenter EX CR zum ersten Mal installiert haben.

Die Aufgabe "Neue Datenbanktabelle erstellen" ist so konzipiert, dass sie die folgenden Prozesse automatisiert:

• Erstellen von produktbezogenen Tabellen, Datenbankindizes und gespeicherten Prozeduren in Ihrem DBMS
• Laden der anfänglichen Standarddaten in Ihr DBMS, einschließlich der Standardrollen für die Sicherheitsverwaltung und der Standardberechtigungen

Sie können ggf. die Standard-Portal-Quelldaten laden.

Die SSL-Sicherheit ist standardmäßig aktiviert, was darauf hinweist, dass die Opcenter EX MDD- und Opcenter EX CR-Produkte und -Module in einer sicheren Umgebung ausgeführt werden. Wenn Sie die SSL-Sicherheit deaktiviert haben, können Sie beim Generieren von WCF-Diensten das Kontrollkästchen "Web-Datenverkehr verschlüsseln" deaktivieren. Weitere Informationen zur SSL-Sicherheit finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung oder in der Opcenter Execution Core-Installationsanleitung.

Im Management Studio-Fenster wird ein Menü "Datenbanken" angezeigt, wenn der Ordner "Datenbanken" oder ein Datenbankknoten ausgewählt wird. Weitere Informationen zum Menü für Datenbanken finden Sie unter "Menü "Datenbanken"".

In Clusterumgebungen

Führen Sie das Erstellen oder Aktualisieren nur einmal für jedes Mitglied des Clusters in einer Clusterumgebung aus.

Definitionen der Kontrollkästchen des Dialogfelds "Tabellen erstellen"

Diese Tabelle definiert die Kontrollkästchen im Dialogfeld "Tabellen erstellen".

Option

Definition

Typ

Metadaten und Schema aktualisieren

Bei der Erstellung von Datenbanktabellen deaktiviert. Aktiviert, wenn eine Datenbankaktualisierung ausgeführt wird.

Optional

Aktualisierung des Datenbankschemas erzwingen

Bei der Erstellung von Datenbanktabellen deaktiviert. Aktiviert, wenn eine Datenbankaktualisierung ausgeführt wird.

Optional

Aktualisierung des ODS-Datenbankschemas erzwingen

Bei der Erstellung von Datenbanktabellen deaktiviert. Aktiviert, wenn eine Datenbankaktualisierung ausgeführt wird.

Hinweis: Wenn ODS nicht vorhanden ist oder wenn ODS deaktiviert ist, wird das Kontrollkästchen "Aktualisierung des ODS-Datenbankschemas erzwingen" deaktiviert. Wenn ODS vorhanden ist, wird das Kontrollkästchen "Aktualisierung des ODS-Datenbankschemas erzwingen" automatisch aktiviert, wenn die Option zum Erzwingen der Aktualisierung des Datenbankschemas ausgewählt ist.

Optional

Gespeicherte Prozeduren erstellen

Führt die Datei "InstallProcedures.bat" aus. Die gespeicherten Prozeduren für Opcenter EX MDD oder Opcenter EX CR sind eine Sammlung von SQL-Anweisungen und logischen Steuerelementen, die in der Datenbank definiert und gespeichert sind und von Programmen aufgerufen werden. Die standardmäßigen gespeicherten Prozeduren enthalten plattformspezifische Regeln, verbessern die Leistung und verringern den Netzwerkverkehr. Da Datenobjekte einen gemeinsamen Satz an Regeln verwenden, ist die Logik zentralisiert.

Aktivieren Sie diese Option, wenn Sie irgendwelche dieser gespeicherten Prozeduren ändern oder hinzufügen oder wenn Sie die anfängliche Datenbank erstellen.

Optional

Indizes erstellen

Löst die Erstellung neuer oder geänderter Indizes aus. Diese Option sollte immer aktiviert sein.

Hinweis: Alle Änderungen, die an Indizes vorgenommen werden, werden in der Protokolldatei des Dienstprogramms zum Ersetzen von Arbeitsbereichsdaten protokolliert. Weitere Informationen zum Hilfsprogramm zum Ersetzen von Arbeitsbereichsdaten finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung oder in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung.

Optional

Konfiguration laden

Aktualisiert die Datenbank mit allen Konfigurationsänderungen, die im Bereich "Konfiguration" vorgenommen wurden.

Hinweis: Diese Option ist immer ausgewählt und deaktiviert.

Optional

Anfängliche Daten laden

Führt das Skript "csiPopulateReleaseData.bat" aus, um Instanzen wie die Standardanmeldungen (CamstarAdmin, Administrator und InSiteAdmin), Primärschlüssel usw. in den Datenbanktabellen zu erstellen. Dies stellt Ihnen die ersten Modellierungsdefinitionen als Ausgangspunkt für Ihre erstmalige Installation zur Verfügung.

Dieses Skript lädt auch die anfänglichen Standardrollen und die zugehörigen Berechtigungen.

Optional

Menüs neu laden

Stellt die Standard-Portalmenüs wieder her. Jegliche Änderungen an den Standardmenüs werden überschrieben. Benutzerdefinierte Menüs werden nicht überschrieben oder gelöscht. Benutzerdefinierte Menüs bleiben in Portal Studio verfügbar.

Hinweis: Dieses Kontrollkästchen ist beim Erstellen von Tabellen nicht zur Auswahl verfügbar.

Optional

Änderungsverwaltungs-Quelldaten neu laden

Lädt die anfänglichen Daten neu, die mit der Change Management-Anwendung verwendet werden sollen. Änderungen, die an den Standardspezifikationen der Änderungsverwaltung und an den Arbeitsplanmodellierungsobjekten der Änderungsverwaltung vorgenommen wurden, werden überschrieben. Benutzerdefinierte Änderungsverwaltungs-Modellierungsobjekte werden nicht überschrieben oder gelöscht.

Wichtig: Siemens empfiehlt, diese Option nicht in Ihrer Produktionsumgebung zu verwenden. Wenn diese Option verwendet wird, werden alle ursprünglichen Änderungsverwaltungsinstanzen auf den Zustand nach der Erstinstallation zurückgesetzt und ihre IDs werden geändert. Darüber hinaus werden alle vorhandenen Änderungsverwaltungspakete verwaist.

Hinweis: Dieses Kontrollkästchen ist beim Erstellen von Tabellen nicht zur Auswahl verfügbar.

Optional

SPC-Tester-Daten füllen

Lädt Daten herunter, die mit der SPC Testseite verwendet werden können.

Optional

Verwaiste Berechtigungen bereinigen

Bei der Erstellung von Datenbanktabellen deaktiviert. Ist aktiviert, wenn eine Datenbankaktualisierung ausgeführt wird.

Optional

Camstar Portal-Objekte laden

Füllt das Portal mit Objekten, die in der Modellierung erstellt wurden. Weitere Informationen zum Erstellen und Ändern von Definitionen für die Portalmodellierung finden Sie im Opcenter Execution Medical Device and Diagnostics Modeling-Benutzerhandbuch oder im Opcenter Execution Core Modeling-Benutzerhandbuch.

Optional

Alles neu laden

Lädt alle Objekte neu, wenn aktiviert.

Optional

Camstar-Wörterbücher laden

Füllt das Portal mit Wörterbuchbeschriftungen aus CSV-Dateien, die sich im Ordner "Insite Administration\Dictionaries" befinden. Das Platzieren von CSV-Dateien, die Übersetzungen für Beschriftungen enthalten, aktiviert fremdsprachliche Beschriftungen oder angepasste Beschriftungen, die im Portal angezeigt werden sollen. Weitere Informationen zum Erstellen und Ändern von Wörterbuchdefinitionen finden Sie im Opcenter Execution Medical Device and Diagnostics Modeling-Benutzerhandbuch oder im Opcenter Execution Core Modeling-Benutzerhandbuch.

Optional

Alles neu laden

Lädt alle Wörterbücher neu, wenn aktiviert.

Hinweis: Dieses Kontrollkästchen ist beim Erstellen von Tabellen nicht zur Auswahl verfügbar.

Optional

WCF-Dienste erstellen

Erstellt die DLL, die die bereitgestellten Dienste und Datenverträge enthält, indem deren Definitionen aus der MDB extrahiert werden. Sie sollten diese Option aktivieren, wenn Sie Arbeitsbereiche aktivieren oder deaktivieren. Weitere Informationen zum Generieren von WCF-Diensten finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung oder in der Opcenter Execution Core-Installationsanleitung.

Optional

Web-Datenverkehr verschlüsseln

Ermöglicht das Generieren von WCF-Diensten mit SSL-Sicherheit. "Web-Datenverkehr verschlüsseln" ist standardmäßig ausgewählt.

Optional

Erstellen von REST-API-Diensten

Erzeugt das gesamte REST-API-Modell und startet die REST-API-Dienste, sofern ausgewählt. Diese Option ist nur gültig, wenn Sie statische DLLs verwenden, wie standardmäßig in der Datei "appsettings.json" festgelegt. Wenn ein Fehler auftritt, finden Sie Informationen zu Fehlerantworten in Opcenter Execution Medical Device and Diagnostics – Technische Referenz: REST API oder in Opcenter Execution Core – Technische Referenz: REST API.

Optional

Vorgehensweise zum Erstellen von neuen Datenbanktabellen für die Transaktionsdatenbank

Gehen Sie folgendermaßen vor, um neue Datenbanktabellen für die Transaktionsdatenbank zu erstellen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie Datenbanken und klicken Sie dann mit der rechten Maustaste auf Transaktionsdatenbank.
3. Klicken Sie auf Neue Datenbanktabellen erstellen. Das Dialogfeld "Tabellen erstellen" wird angezeigt.
4. Belassen Sie die Standardauswahlen, wie sie sind.

 

5. Klicken Sie auf OK. Die Meldung "Neue Transaktionsdatenbank erfolgreich erstellt" wird unten im Management Studio-Fenster angezeigt.
