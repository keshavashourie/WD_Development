Überprüfungs- und Löschverfahren

Diese Verfahren erläutern, wie die Datenbankverbindungseinstellungen in Management Studio überprüft werden und wie eine Datenbank in Management Studio gelöscht wird.

Hinweis: Im Management Studio-Fenster wird ein Menü "Datenbanken" angezeigt, wenn der Ordner "Datenbanken" oder ein Datenbankknoten ausgewählt wird. Weitere Informationen zum Menü für Datenbanken finden Sie unter "Menü "Datenbanken"".

Vorgehensweise zum Überprüfen der Datenbankverbindungseinstellungen

Gehen Sie folgendermaßen vor, um die Datenbankverbindungseinstellungen zu überprüfen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Wählen Sie die Datenbank aus, für die Sie die Verbindung überprüfen möchten. Die Konfigurationsinformationen für diese Datenbank werden im rechten Bereich angezeigt.
3. Klicken Sie auf Verbindung testen. Management Studio zeigt die Meldung "Verbindung hergestellt" an, wenn die Verbindung erfolgreich hergestellt wurde. Andernfalls zeigt Management Studio eine Fehlermeldung an.
Hinweis: Über die Schaltfläche "Verbindung testen" für die Transaktions- und die DataStore-Datenbank werden nur der Benutzername und das Kennwort überprüft. Es erfolgt keine Überprüfung des Schemas.

Vorgehensweise zum Löschen einer Datenbank

Gehen Sie folgendermaßen vor, um eine Datenbank zu löschen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Klicken Sie mit der rechten Maustaste auf die Datenbank, die Sie löschen möchten, und wählen Sie Datenbank löschen aus. Ein Bestätigungsdialogfeld wird angezeigt.
3. Klicken Sie auf Ja. Der Datenbankeintrag wird gelöscht.
