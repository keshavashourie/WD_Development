Verwalten von Diensten

Die Opcenter EX MDD- und Opcenter EX CR-Server werden als Dienste registriert. Sie können den Status von Diensten im Bereich "Dienste" anzeigen. Sie können diese Dienste im Bereich "Services" auch starten, beenden und neu starten.

Informationen zu Diensten

Die Informationen für produktbezogene Dienste werden im rechten Bereich des Management Studio-Fensters angezeigt, wenn Sie "Dienste" im Ordner "Verwaltung" auswählen. Der rechte Bereich enthält eine Tabelle mit einer Liste der Dienste und deren aktuellen Status.

Standorte umfassen standardmäßig folgende Dienste:

• Camstar App Server
• Camstar-Bereitstellungsserver
• Camstar-Benachrichtigungsserver
• Camstar-Sicherheitsdienste
• Camstar WCF-Dienste
• Portal
• REST API-Bezeichnung
• REST API-Modellierung
• REST API-Abfrage
• REST API-Fertigung

Im Management Studio-Fenster wird ein Menü "Dienste" angezeigt, wenn Sie den Knoten "Dienste" im Ordner "Verwaltung" auswählen. Weitere Informationen zum Menü für Dienste finden Sie unter "Menü "Dienste"".

Wichtig: Das Starten und Beenden von Diensten betrifft nur deren Status auf dem derzeit im Feld "Dienste für <Server>" ausgewählten Server. Wenn Sie einen anderen Server auswählen, wird die Liste der Dienste mit dem jeweils aktuellen Status aktualisiert.

Weitere Informationen zur empfohlenen Reihenfolge beim Beenden und Neustarten von Diensten finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung oder in der Opcenter Execution Core-Installationsanleitung. Einige der Dienste werden als Anwendungspools in IIS und andere als Dienste in den Windows-Verwaltungsprogrammen ausgeführt.

Felddefinitionen des Bereichs "Dienste"

Diese Tabelle definiert die Felder im Bereich "Dienste".

Feld

Typ

Dienste für <Server> (Services for <server>)

Bietet die Möglichkeit, einen Server auszuwählen und die zugehörigen Dienste des Servers in der Tabelle "Dienste" anzuzeigen. Wenn Sie einen Server auswählen, wird die Tabelle "Dienste" aktualisiert.

Vorgehensweise zum Starten eines Dienstes

Gehen Sie folgendermaßen vor, um einen Dienst zu starten:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Verwaltung und wählen Sie den Knoten Dienste aus. Die Dienstinformationen werden im rechten Bereich angezeigt.
3. Wählen Sie einen Server im Feld Dienste für <Server> (Services for <Server>) aus. Die Tabelle "Dienste" wird aktualisiert und zeigt eine Liste der Dienste mit deren aktuellem Status an.
4. Klicken Sie mit der rechten Maustaste auf einen beendeten Dienst und wählen Sie Dienst starten aus. Der Status des Dienstes wird in "Aktiv" geändert.
5. Wiederholen Sie ggf. Schritt 3, um weitere beendete Dienste zu starten.

Vorgehensweise zum Beenden eines Dienstes

Gehen Sie folgendermaßen vor, um einen Dienst zu beenden:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Verwaltung und wählen Sie den Knoten Dienste aus. Die Dienstinformationen werden im rechten Bereich angezeigt.
3. Wählen Sie einen Server im Feld Dienste für <Server> (Services for <Server>) aus. Die Tabelle "Dienste" wird aktualisiert und zeigt eine Liste der Dienste mit deren aktuellem Status an.
4. Klicken Sie mit der rechten Maustaste auf einen aktiven Dienst und wählen Sie Dienst beenden aus. Der Status des Dienstes wird in "Beendet" geändert.
5. Wiederholen Sie ggf. Schritt 3, um weitere aktive Dienste zu beenden.

Vorgehensweise zum Beenden aller Dienste

Gehen Sie folgendermaßen vor, um alle Dienste zu beenden:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Verwaltung und wählen Sie den Knoten Dienste aus. Die Dienstinformationen werden im rechten Bereich angezeigt.
3. Wählen Sie einen Server im Feld Dienste für <Server> (Services for <Server>) aus. Die Tabelle "Dienste" wird aktualisiert und zeigt eine Liste der Dienste mit deren aktuellem Status an.
4. Klicken Sie mit der rechten Maustaste auf einen Dienst und wählen Sie Dienste beenden aus. Alle Dienste werden beendet und deren Status wird als "Beendet" angezeigt.

Vorgehensweise zum Neustarten der Dienste

Gehen Sie folgendermaßen vor, um Dienste neu zu starten:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Verwaltung und wählen Sie den Knoten Dienste aus. Die Dienstinformationen werden im rechten Bereich angezeigt.
3. Wählen Sie einen Server im Feld Dienste für <Server> (Services for <Server>) aus. Die Tabelle "Dienste" wird aktualisiert und zeigt eine Liste der Dienste mit deren aktuellem Status an.
4. Klicken Sie mit der rechten Maustaste auf einen Dienst und wählen Sie Dienste neu starten aus. Alle Dienste werden neu gestartet und deren Status wird als "Aktiv" angezeigt.
