Notwendige Verfahren nach Änderung des Kennworts eines Datenbankbenutzers

Wenn Sie das Benutzer-/Schemakennwort auf Datenbankebene geändert haben, sind zugehörige Verfahren notwendig, um das Kennwort des Benutzers für die Transaktionsdatenbank (OLTP) und ggf. die DataStore-Datenbank zu ändern.

Verfahren für die Transaktionsdatenbank

Führen Sie diese Management Studio-Verfahren in der angegebenen Reihenfolge aus, um das Kennwort für einen Transaktionsdatenbankbenutzer zu ändern:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Datenbanken und wählen Sie die Transaktion-Datenbank aus. Die Konfigurationsinformationen für die Transaktionsdatenbank werden im rechten Bereich angezeigt.
3. Aktualisieren Sie den Eintrag im Feld Kennwort, so dass er das Kennwort angibt, das Sie für das DBMS eingegeben haben.
4. Klicken Sie auf die Schaltfläche Verbindung testen, um sicherzustellen, dass tatsächlich eine Verbindung zwischen der Datenbank und der Datenquelle hergestellt wurde. Management Studio zeigt eine Meldung für hergestellte Verbindung an.
5. Klicken Sie auf Speichern.
6. Führen Sie die Schritte unter "Vorgehensweise zum Aktualisieren der Transaktionsdatenbank" aus.

Verfahren für die DataStore-Datenbank

Führen Sie diese Management Studio-Verfahren in der angegebenen Reihenfolge aus, um das Kennwort für einen DataStore-Datenbankbenutzer zu ändern:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Datenbanken und wählen Sie die DataStore-Datenbank aus. Die Konfigurationsinformationen für die DataStore-Datenbank werden im rechten Bereich angezeigt.
3. Aktualisieren Sie den Eintrag im Feld Kennwort, so dass er das Kennwort angibt, das Sie für das DBMS eingegeben haben.
4. Klicken Sie auf die Schaltfläche Verbindung testen, um sicherzustellen, dass tatsächlich eine Verbindung zwischen der Datenbank und der Datenquelle hergestellt wurde. Management Studio zeigt eine Meldung für hergestellte Verbindung an.
5. Klicken Sie auf Speichern.
6. Führen Sie die Schritte unter "Vorgehensweise zum Aktualisieren der Transaktionsdatenbank" aus.
Hinweis: Wurde das Kennwort für die DataStore-Datenbank geändert, werden Transaktionen weiterhin verarbeitet und DataStore arbeitet normal weiter.
