Konfigurieren von Industry Solutions

Mit dem Industry Solutions Configuration Tool können Sie die Arbeitsbereiche konfigurieren, die für die Ausführung von Industry Solution-Funktionen benötigt werden. Die für branchenspezifische Funktionen erforderlichen Dateien werden mit Opcenter Execution MDD oder Opcenter Execution CR bereitgestellt, müssen aber mit dem Tool konfiguriert werden. Sie müssen das Tool ausführen, wenn Sie eine der folgenden Funktionen verwenden möchten:

• CIO
• Opcenter EX CR Scheduling
• Overall Equipment Effectiveness (OEE)
• Medical Device
• Batch Processing
• Konfiguration von Fertigungsressourcen (SRC)

Das Industry Solutions Configuration Tool stellt einen Mechanismus zur Verfügung, der CIO-Funktionalität bereitstellt, mit der Sie ausgehende Nachrichten aus Opcenter Execution MDD oder Opcenter Execution CR an externe Anwendungen senden können.

Die Industry Solutions-Arbeitsbereiche bieten einen Mechanismus, mit dem sich auf einfache Weise für die Medizinproduktbranche spezifische Funktionen bereitstellen lassen. Die Funktionen werden in den Industry Solutions-Arbeitsbereichen entwickelt und sind daher isoliert. So kann die für Medizinprodukte spezifische Funktionalität getrennt angeboten werden, während dennoch spätere Änderungen an Opcenter Execution MDD oder Opcenter Execution CR übernommen werden können.

Sie müssen über eine Opcenter Execution Core Batch Processing-Lizenz verfügen, damit Batch Processing-Funktionen verwendet werden können. Sie müssen über eine Opcenter Ex CR Scheduling-Lizenz verfügen, damit die Opcenter EX CR Scheduling-Funktionen verwendet werden können.

Weitere Informationen zum Installieren von Opcenter Execution MDD oder Opcenter Execution CR und den zugehörigen Komponenten finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung oder in der Opcenter Execution Core-Installationsanleitung.

Für die Installation, Konfiguration und Verwendung dieser Funktionen spezifische Informationen können Sie den folgenden Handbüchern entnehmen:

• Opcenter Execution Medical Device and Diagnostics Scheduling-Benutzerhandbuch oder Opcenter Execution Core Scheduling-Benutzerhandbuch
• Opcenter Execution Medical Device and Diagnostics Industry Solutions-Benutzerhandbuch oder Opcenter Execution Core Industry Solutions-Benutzerhandbuch
• Opcenter Execution Medical Device and Diagnostics Medical Device-Benutzerhandbuch oder Opcenter Execution Core Medical Device-Benutzerhandbuch
• Opcenter Execution Medical Device and Diagnostics Batch Processing-Benutzerhandbuch oder Opcenter Execution Core Batch Processing-Benutzerhandbuch
• Opcenter Execution Medical Device and Diagnostics Modeling-Benutzerhandbuch oder Opcenter Execution Core Modeling-Benutzerhandbuch

Wenn Sie Overall Equipment Effectiveness installieren, muss eine DataStore-Datenbank konfiguriert werden. Informationen zu DataStore-Datenbanken finden Sie unter "Verwalten der Konfiguration der DataStore-Datenbank".

Löschen Sie die Datei "BackUpMDB" im Ordner "C:\Programme (x86)\Camstar\InSite Administration", bevor Sie das Industry Solutions Configuration Tool ausführen.

Bei der Konfiguration des Medical Device-Arbeitsbereichs müssen zusätzliche Schritte durchgeführt werden. Bei der Aktualisierung eines vorhandenen Medical Device-Arbeitsbereichs von einer Version vor Version 6 SU6 müssen Sie die folgenden Dateien entfernen:

• ManageTeamEmployees.cs
• TeamTrackingTxn.cs

Erforderlicher Oracle 64-Bit-Client

Stellen Sie sicher, dass der Oracle 64-Bit-Client für die aktuelle Version der Oracle-Datenbank installiert ist.

Beim Konfigurieren von Industry Solutions

Mit dem Industry Solutions Configuration Tool können Sie die Datenbanken zusammenführen und die jeweiligen Skripts für die Arbeitsbereiche ausführen. Das Tool überprüft auch Abhängigkeiten. So muss z. B. CIO installiert sein, damit die Industry Solutions- oder Batch Processing-Arbeitsbereiche installiert werden können.

Sie wählen die Arbeitsbereiche aus, die Sie installieren möchten. Verfügbare Arbeitsbereiche sind:

• CIO
• Industry
• OEE
• Medical Device
• Batch Processing
• SRC

Das Industry Solutions Configuration Tool führt die folgenden Aktionen durch, nachdem Sie Ihre Auswahl vorgenommen und auf "Beenden" geklickt haben:

1. Zeigt das Dialogfeld "Installation bestätigen" an, das Informationen wie den Installationstyp und ausgewählte Funktionsarbeitsbereiche enthält. Sie können auf "OK" klicken, um mit der Installation fortzufahren, oder den Vorgang abbrechen.
2. Überprüft, ob die richtige Version von Opcenter Execution MDD oder Opcenter Execution CR installiert ist.
Hinweis: Das Tool gibt eine Fehlermeldung aus, wenn nicht die richtige Version installiert ist.
3. Gibt an, dass CIO erforderlich ist, wenn Sie "Industry Solutions" oder "Batch Processing" ausgewählt haben.
Hinweis: Sie müssen "CIO" auswählen, um mit der Installation fortzufahren. Das Tool gibt nicht an, dass CIO erforderlich ist, wenn Sie nur "Medical Device" auswählen.
4. Bei Auswahl von "OEE" werden Sie aufgefordert, die DataStore-Datenbankdetails einzugeben.
Hinweis: Das Tool zeigt eine Fehlermeldung an, wenn Sie nicht alle Details eingeben. Für die OEE-Option ist der Arbeitsbereich "Industrie" erforderlich. Das Tool zeigt eine Fehlermeldung an, wenn Sie nicht den Arbeitsbereich "Industrie" auswählen. Das Tool überprüft, ob die Verbindung zur DataStore-Datenbank erfolgreich hergestellt wurde. Das Tool zeigt eine Fehlermeldung an, wenn Sie nicht die richtigen Verbindungsinformationen angeben.
5. Für jeden ausgewählten Arbeitsbereich wird das Dienstprogramm "Replace Workspace Data" ausgeführt.
6. Die .js-, .css- und .cs-Dateien für den jeweils ausgewählten Arbeitsbereich werden in die entsprechenden Verzeichnisse im Ordner "\Camstar\Industry Solutions\<Funktion>\Camstar Portal" kopiert.
7. Die Datei "settings.xml" wird mit den CDOForms-Einstellungen für die einzelnen ausgewählten Arbeitsbereiche aktualisiert.
8. Die WCF-Dienste werden generiert.
9. Die .xml-Dateien virtueller Seiten der jeweils ausgewählten Arbeitsbereiche werden in den Ordner "InsiteAdministration\PortalData" kopiert.
10. Es wird eine Datenbankaktualisierung durchgeführt (dbupdate).
11. Die Portalformulare der jeweils ausgewählten Arbeitsbereiche werden importiert.
12. Die Menüdefinitions- und Rollenskripts der jeweils ausgewählten Arbeitsbereiche werden ausgeführt.
13. Startet die CamstarAppServer- und CamstarSecurityServices-Anwendungspools neu
14. Führt die Industry Solutions IPL-Integrationskonfigurationsskripte aus, wenn "Industrie" ausgewählt ist und die erforderlichen Daten eingegeben werden.
15. Bei Auswahl von OEE werden die Industry Solutions OEE-Skripts ausgeführt.

Im Industry Solutions Configuration Tool-Dialogfeld wird eine Fortschrittsanzeige mit dem Status der Konfiguration angezeigt. Das Werkzeug zeigt ein Dialogfenster an, wenn der Prozess abgeschlossen ist.

Sie können die Industry Solution-Funktionen verwenden, sobald die Konfiguration beendet wurde. Für Opcenter EX CR Scheduling muss Preactor installiert und konfiguriert sein. Weitere Informationen finden Sie im Opcenter Execution Medical Device and Diagnostics Scheduling-Benutzerhandbuch oder im Opcenter Execution Core Scheduling-Benutzerhandbuch.

Konfigurieren der Konfiguration von Fertigungsressourcen (SRC) in Industry Solutions

Die Funktion "Shop Floor Resource Configuration (SRC)" für die Verwaltung der intelligenten IPL-Einstellungen wird mit dem Industry Solutions Configuration Tool installiert. Damit SRC voll funktionsfähig ist, muss auch der Valor MSS Shop Floor-Anwendungsserver installiert und konfiguriert sein.

Vor dem Konfigurieren der SRC-Installation

SRC erfordert, dass ASP.NET Core 8.x Windows Hosting Bundle und .NET Desktop Runtime 8.x installiert werden. Wenn diese noch nicht installiert sind, wird ein Dialogfenster angezeigt, in dem Sie aufgefordert werden, ASP.NET Core 8.x Windows Hosting Bundle und .NET Desktop Runtime 8.x-Unterstützung herunterzuladen und zu installieren. Nachdem Sie auf die Schaltfläche OK geklickt haben, werden Sie an die Microsoft-Website weitergeleitet, um das Installationsprogramm für .NET Desktop Runtime 8.x herunterzuladen. Die SRC-Installation wird nicht fortgesetzt, wenn Sie im Dialogfenster Nein auswählen. Nachdem .NET Desktop Runtime 8.x installiert wurde, müssen Sie das Industry Solutions Configuration Tool erneut öffnen und SRC erneut auswählen, um die Installation abzuschließen. Es ist möglich, mit der SRC-Installation fortzufahren, ohne das ASP.NET Core 8 Windows Hosting Bundle zu installieren, jedoch kann SRC nur funktionieren, wenn das ASP.NET Core 8.x Windows Hosting Bundle installiert ist.

Informationen zur unterstützten Version für das Hosting-Bundle finden Sie in der Release-Matrix im Siemens Support Center.

Vorgehensweise zum Konfigurieren der Fertigungsressourcenkonfiguration

Gehen Sie folgendermaßen vor, um die Fertigungsressourcenkonfiguration zu konfigurieren:

1. Stellen Sie sicher, dass Sie die ersten sechs Schritte von "Vorgehensweise zum Konfigurieren von Industry Solutions" durchgeführt haben.
2. Sobald das SRC-Installationsprogramm gestartet wird, wird ein Dialogfenster für das erste Installationsprogramm angezeigt. Klicken Sie auf Weiter. Im Installationsprogramm-Dialogfenster werden die Felder "Installationsordner" mit IPL-Ordner-Informationen angezeigt.
3. Nehmen Sie in den Feldern Komponentenordner und Stammordner Änderungen entsprechend Ihren Geschäftsanforderungen vor. Klicken Sie auf Weiter. Das Installationsprogramm-Dialogfenster zeigt die Felder "Lizenzserver" an, die den Speicherort des Mentor Graphics License Servers angeben.
4. Geben Sie den Lizenzservernamen, den Lizenzserver-Port und das TimeOut ein. Klicken Sie auf Weiter. Ein Test wird automatisch durchgeführt, um zu prüfen, ob die Verbindung zum Server gültig ist. Nach Abschluss des Tests fordert das Installationsprogramm-Dialogfenster zur Eingabe von Informationen zum Web-API-Adapter von Opcenter Connect MOM auf, die von IPL-Anwendungen verwendet werden, um Nachrichten an Opcenter Execution Core zu senden.
5. Geben Sie den IP-/Hostnamen des Web-API-Adapters, den Port des Web-API-Adapters und das Protokoll des Web-API-Adapters ein. Klicken Sie auf Weiter. Das Installationsprogramm-Dialogfenster fordert Sie auf, Anmeldeinformationen für Opcenter EX CR Rest API einzugeben.
Hinweis: SRC erfordert keine Installation von Opcenter Connect MOM, damit SRC installiert oder funktioniert. Es fordert diese Informationen an, um sie anderen Anwendungen zur Verfügung zu stellen, die mit SRC kommunizieren.
Hinweis: Bisher erforderte SRC, dass Opcenter Execution Electronics ebenfalls installiert ist und dass das entsprechende Opcenter Connect MOM-Konfigurationsskript (ES_MIO_ConfigurationLoad.cfg) ausgeführt wird, um die erforderlichen CN MOM-Objekte zu erstellen. Die hartcodierte Verwendung des es_valorinbound Web-API-Adapters wurde jedoch entfernt. Dies unterstützt Nicht-Elektronik-Umgebungen, in denen nur "Industrie" installiert ist, die den is_valorinbound Web-API-Adapter bereitstellt. Wenn Sie Opcenter Execution Electronics installiert haben, wird der es_valorinbound-Web-API-Adapter verwendet.
6. Geben Sie den Benutzernamen und das Kennwort ein. Klicken Sie auf Weiter. Felder zur SRC-Serverkonfiguration werden angezeigt.
Wichtig: Der Benutzername und das Kennwort der Opcenter Execution REST API müssen konfiguriert werden, um zu vermeiden, dass der Verbindungstest mit dem Server fehlschlägt.
7. Wählen Sie die Netzwerkprotokolloptionen entsprechend Ihren Geschäftsanforderungen aus.
8. Geben Sie Hostname oder IP des SRC-Servers ein, wählen Sie den Http-Port oder Https-Port und das SSL-Zertifikat aus. Klicken Sie auf Weiter. Ein Dialogfenster "Zusammenfassung der Vorinstallation" wird angezeigt.
9. Klicken Sie auf Installieren. Im Dialogfenster "SRC-Installationsprogramm" wird eine Fortschrittsleiste angezeigt. Nachdem die Installation abgeschlossen ist, zeigt der Bildschirm eine Meldung an, dass die Installation vollständig abgeschlossen ist.
10. Klicken Sie auf Schließen. Das Dialogfenster "SRC-Installation" wird geschlossen.

Zusätzliche Modellierung für die vollständige Funktionalität

Es ist erforderlich, eine Fertigungsinstanz zu erstellen oder zu aktualisieren, in der die SRC-API konfiguriert werden muss, damit SRC voll funktionsfähig ist. Diese Instanz der Einstellungen für die Fertigungsintegration muss dann der Fabrik zugewiesen werden, die mit den Mitarbeitern verknüpft ist. Daher muss im Objekt "Einstellungen für die Fertigungsintegration" die SRC-API mit dem entsprechenden Wert konfiguriert werden. In der Regel wären das der folgende:

https://servername:5443/

Dabei ist "Servername" der entsprechende Wert für den Server, auf dem SRC installiert ist.

Weitere Informationen finden Sie im Opcenter Execution Core Modeling-Benutzerhandbuch.

Vorgehensweise zur Deinstallation von SRC

Gehen Sie folgendermaßen vor, um SRC zu deinstallieren:

1. Öffnen Sie die Systemsteuerung. Das Fenster "Systemsteuerung" (Control Panel) wird angezeigt.
2. Klicken Sie auf Programm deinstallieren (Uninstall a Program). Das Fenster "Programme und Funktionen" wird angezeigt.
3. Wählen Sie Opcenter Execution Core SRC [Versionsnummer] aus und klicken Sie auf Deinstallieren.
