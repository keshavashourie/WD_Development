Verwalten von Leistungsindikatoren

Mithilfe von Leistungszählern können Sie in Management Studio Leistungsinformationen für Ihre Standorte erfassen.

Informationen zu Leistungszählern

Die Informationen für Leistungsindikatoren werden im rechten Bereich des Management Studio-Fensters angezeigt, wenn Sie den Knoten "Leistungsindikatoren" im Ordner "Administration" auswählen. Der Leistungsindikator in Management Studio erfasst Rohdaten von einem Zähler zu einem Zeitpunkt, der vom ausgewählten Zähler abhängt. Die Anwendung speichert Leistungsindikatorprotokolle als CSV-Dateien. Der Standarddateiname lautet "PerformanceCounter.csv". Der Standardspeicherort für die gespeicherten Protokolle ist "C:\Programme (x86) \Camstar\Logs".

Die Anwendung überschreibt die Datei "PerformanceCounter.csv" jedes Mal, wenn Sie einen Leistungsindikator starten.

Die Leistungsprotokolle enthalten Kopfzeileninformationen für Spalten. Die erste Spalte ist "DateTimestamp". "DateTimestamp" enthält das Datum und die Uhrzeit, zu der die Probe erfasst wurde. Abhängig von den ausgewählten Leistungsindikatoreinstellungen können drei weitere Spaltenkopfzeilen vorhanden sein:

• Kategorie
• Leistungsindikator
• Instanz

Die einzelnen Kopfzeileneinträge für Leistungsindikatoreinstellungen werden durch "[]" und "." im Namen getrennt.

Beispiele:

DateTimestamp,[category].[counter].[instance]

DateTimestamp,[ASP.NET Applications].[% Managed Processor Time Base (estimated)].[__Total__]

Leistungszähler verwenden die Microsoft Leistungsüberwachung und Leistungszähler. Informationen zur Microsoft Leistungsüberwachung und zu Leistungsindikatoren finden Sie auf der Support-Website von Microsoft.

Die Anwendung zeigt eine Fehlermeldung an, wenn ein Fehler auftritt. Fehler werden in der Ereignisanzeige protokolliert.

Einstellungen für Leistungsindikatoren

Kategorie

Gibt die Kategorie der zu erfassenden Informationen beim Erfassen von Leistungsinformationen an. Durch Auswahl einer Kategorie wird das Feld "Leistungsindikator" aktiviert und abhängig von der ausgewählten Kategorie ausgefüllt.

Leistungsindikator

Gibt den Leistungsindikator an, der beim Erfassen von Leistungsinformationen verwendet werden soll. Durch Auswahl eines Leistungsindikators wird das Feld "Instanz" aktiviert und abhängig vom ausgewählten Leistungsindikator ausgefüllt.

Instanz

Gibt die Instanz an, die beim Erfassen von Leistungsinformationen verwendet werden soll. Durch Auswahl einer Instanz wird die Schaltfläche "Start" aktiviert.

Schaltflächendefinitionen des Bereichs "Leistungszähler"

Diese Tabelle definiert die Schaltflächen im Bereich "Leistungszähler".

Schaltfläche

Funktion der Schaltfläche . . .

Start

Startet die Erfassung von Leistungsinformationen. Der Prozess wird ausgeführt, bis die angegebene Anzahl von Stichproben erfasst wurde oder Sie auf die Schaltfläche "Stopp" klicken.

Beenden

Beendet die Erfassung von Leistungsinformationen.

Vorgehensweise zum Starten und Stoppen der Erfassung von Leistungszählern

Gehen Sie folgendermaßen vor, um die Erfassung von Leistungszählern zu starten oder zu stoppen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Verwaltung und wählen Sie den Knoten Leistungszähler aus. Informationen zu den Leistungszählern werden im rechten Bereich angezeigt.
3. Wählen Sie einen Server im Feld Server aus.
4. Wählen Sie im Feld Kategorie eine Kategorie aus. Das Feld "Leistungsindikator" wird aktiviert und die Liste der Leistungsindikatoren wird abhängig von der ausgewählten Kategorie gefüllt.
5. Wählen Sie im Feld Leistungsindikator einen Leistungsindikator aus. Das Feld "Instanz" wird aktiviert und die Liste der Instanzen wird abhängig vom ausgewählten Leistungsindikator gefüllt.
6. Wählen Sie im Feld Instanz eine Instanz aus. Die Schaltfläche "Start" wird aktiviert.
7. Legen Sie im Feld Zu erfassende Stichproben die Anzahl der zu erfassenden Stichproben fest.
8. Legen Sie die Häufigkeit, mit der Stichproben erfasst werden, im Feld Erfassungshäufigkeit (Sek.) fest.
9. Klicken Sie auf Start. Management Studio zeigt die Meldung "Stichproben werden erfasst." an und beginnt mit dem Erfassen von Leistungsinformationen. Management Studio zeigt dann die Meldung "Stichprobenerfassung beendet." (Stopped collecting samples.) an und speichert die Leistungsinformationen in einer Protokolldatei, nachdem die angegebene Anzahl von Stichproben erfasst wurde.
10. Klicken Sie in das Feld Ausgabedatei (zum Öffnen klicken), um die Protokolldatei anzuzeigen.
