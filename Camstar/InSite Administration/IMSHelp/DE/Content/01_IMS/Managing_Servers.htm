Verwalten von Servern

Sie können einem Standort einen oder mehrere Server hinzufügen.

Der Anwendungsserver ist der zentrale Transaktionsserver, auf dem die Geschäftslogik ausgeführt wird. Alle Transaktionen werden vom Anwendungsserver verarbeitet, der diese Dienste bereitstellt:

• Enthält das Produkt- und Fabrikinformationsmodell für Opcenter EX MDD oder Opcenter EX CR, das die Geschäftsregeln und die Logik kapselt.
• Er ermöglicht Benutzern das Definieren der jeweiligen Geschäftsregeln mit konfigurierbaren Datenobjekten (Configurable Data Objects, CDOs) und konfigurierbaren Logikabläufen (Configurable Logic Flows, CLFs).
• Kommuniziert mit Clientanwendungen über XML-Dokumente. Es lauscht auf eingehende XML-Dokumente von HTTP/S-Clientanforderungen, analysiert die Dokumente und verarbeitet sie als Opcenter EX MDD- oder Opcenter EX CR-Transaktionen. und gibt ein XML-Dokument mit den Ergebnissen zurück.
• Speichern und Abrufen von Informationen.
• Er stellt die Übersetzung zwischen dem Objektmodell und relationalen Datenbanken nach Industriestandard bereit, um Daten zu speichern und abzurufen.
Hinweis: Server müssen dieselbe Transaktionsdatenbank in Management Studio verwenden. Der lokale Host und ein zusätzlicher Remote-Server müssen z. B. beide die gleiche Transaktionsdatenbank verwenden.
Wichtig: Der Anwendungsserver, die Transaktionsdatenbank (OLTP) und der DataStore-Datenbankserver (ODS) müssen sich geografisch in demselben Rechenzentrum befinden. Diese Server müssen für dieselbe Zeitzone konfiguriert sein und sich physisch in demselben VLAN (ein Hop) befinden. Idealerweise sind alle Server mit demselben Netzwerk-Switch verbunden. Die Netzwerklatenz vom Anwendungsserver zum OLTP-Datenbankserver sollte optimalerweise weniger als 1 Millisekunde betragen, aber nicht mehr als 5 Millisekunden, um die beste Leistung von Opcenter EX MDD- und Opcenter EX CR-Produkten zu gewährleisten.

Beim Hinzufügen von Hostinformationen für einen Server

Die Hostinformation für einen Server werden im rechten Bereich des Management Studio-Fensters angezeigt, wenn Sie einen vorhandenen Server auswählen oder einen neuen Server hinzufügen.

Im Management Studio-Fenster wird ein Menü "Camstar-Server" angezeigt, wenn der Ordner "Camstar-Server" oder ein Serverknoten ausgewählt wird. Weitere Informationen zum Menü für Camstar-Server finden Sie unter "Menü "Camstar-Server"".

Die Schaltflächen "Speichern" und "Verwerfen" sind deaktiviert, bis Sie Text in das Feld "Hostname oder IP-Adresse" eingegeben haben. Klicken Sie auf "Speichern", um Ihre Änderungen zu speichern. Klicken Sie auf "Verwerfen", um Ihre Änderungen zu verwerfen und die vorherigen Feldwerte wiederherzustellen.

In einer Meldung werden Sie zum Speichern oder Abbrechen aufgefordert, wenn Sie versuchen, den Bereich mit den Hostinformationen zu schließen, ohne Ihre Änderungen gespeichert oder verworfen zu haben. Folgen Sie den Anweisungen, um Ihre Änderungen zu speichern oder zu verwerfen.

Vorgehensweise zum Hinzufügen eines Servers

Gehen Sie folgendermaßen vor, um einen Server hinzuzufügen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Klicken Sie mit der rechten Maustaste auf den Ordner Camstar Server und wählen Sie Camstar Server hinzufügen aus. Ein neues Serversymbol wird im Ordner "Camstar Server" angezeigt, im rechten Bereich werden die Felder mit den Hostinformationen angezeigt und der Servername kann bearbeitet werden.
3. Geben Sie den Namen Ihres neuen Servers in den markierten Knoten Neuer Server (NewServer) ein.
4. Geben Sie Hostname oder IP-Adresse für den Server ein.
5. Vergewissern Sie sich, dass das Feld Port den Wert 443 enthält.
6. Klicken Sie auf Speichern. Management Studio zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Umbenennen eines Servers

Gehen Sie folgendermaßen vor, um einen Server umzubenennen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Klicken Sie mit der rechten Maustaste auf den Server, den Sie im Ordner "Camstar Server" umbenennen möchten und wählen Sie Umbenennen aus. Der Servername kann nun bearbeitet werden.
3. Geben Sie den neuen Servernamen ein.
4. Klicken Sie auf Speichern. Management Studio zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Löschen eines Servers

Gehen Sie folgendermaßen vor, um einen Server zu löschen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Klicken Sie mit der rechten Maustaste in der Struktur "Standorte" auf den Server, den Sie löschen möchten, und wählen Sie Löschen aus. Die Meldung zum Bestätigen des Löschens des Servers wird angezeigt.
3. Klicken Sie auf Ja. Der Server wird aus der Struktur "Standorte" gelöscht.
