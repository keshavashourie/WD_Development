Verwalten von Standorten

Standortspezifische Informationen sind extrem wichtig für die Zuordnung von eindeutigen Identifikatoren und Datenbankaktualisierungen. Es ist zu erwarten, dass sie nur sehr selten geändert werden.

Der Standortname ist ein eindeutiger, aber aussagekräftiger Name, der der Installation von Opcenter EX MDD oder Opcenter EX CR zugeordnet ist. Zum Beispiel könnten Sie einen Standortnamen zuweisen, der dem geografischen Standort entspricht.

Beim Verwalten von Standorten

Die Opcenter EX MDD- oder Opcenter EX CR-Konfiguration beginnt mit der Erstellung eines neuen Standorts. Eine neue Standortstruktur wird angezeigt, wenn Sie "Standort hinzufügen" im Menü "Standorte" oder im Kontextmenü auswählen.

Im Management Studio-Fenster wird ein Menü "Standorte" angezeigt, wenn der Ordner "Standorte" oder ein Standortknoten ausgewählt wird. Weitere Informationen zum Menü für Standorte finden Sie unter "Menü "Standorte"".

Sie können Standorte umbenennen und löschen. Außerdem können Sie die Konfigurationsdatei eines Standorts zu Test- und Sicherungszwecken in einen anderen Speicherort exportieren. Sie können auch einen Standort aus einer zuvor exportierten XML-Datei, die alle Konfigurationsinformationen des Standorts enthält, in Management Studio importieren.

Vorgehensweise zum Hinzufügen eines Standorts

Gehen Sie folgendermaßen vor, um einen Standort hinzuzufügen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Klicken Sie mit der rechten Maustaste auf den Ordner Standorte und wählen Sie Standort hinzufügen aus. Eine neue Standortstruktur wird angezeigt und der Standardstandortname kann bearbeitet werden.
3. Geben Sie einen Namen für Ihren Standort in den markierten Knoten Neuer Standort ein.
Wichtig: Der Name des Standortes ist mit der Standort-ID in früheren Versionen der Software identisch. Deshalb müssen Sie die Standort-ID eingeben, wenn Sie von einer vorherigen Version aus aktualisieren.
4. Drücken Sie die Eingabetaste. Eine Bestätigungsmeldung wird angezeigt.
5. Klicken Sie auf Ja, um den neuen Standortnamen in der Konfigurationsdatei für diesen Standort zu speichern, oder auf Nein, um das Hinzufügen des Standorts abzubrechen.

Umbenennen ein Standorts

Gehen Sie folgendermaßen vor, um einen Standort umzubenennen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Standorte.
3. Klicken Sie mit der rechten Maustaste auf den Standort in der Struktur "Standorte" und wählen Sie Standort umbenennen aus. Der Standortname ist nun editierbar.
4. Geben Sie den neuen Standortnamen ein und drücken Sie die Eingabetaste. Eine Bestätigungsmeldung wird angezeigt.
5. Klicken Sie auf Ja, um den neuen Standortnamen in der Konfigurationsdatei für diesen Standort zu speichern.

Oder

Klicken Sie auf Nein, um den neuen Standortnamen abzubrechen.

Vorgehensweise zum Löschen eines Standorts

Gehen Sie folgendermaßen vor, um einen Standort zu löschen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Standorte.
3. Klicken Sie mit der rechten Maustaste in der Struktur "Standorte" auf den Standort, den Sie löschen möchten, und wählen Sie Standort löschen aus. Das Dialogfeld "Standortlöschung bestätigen" wird angezeigt.
4. Klicken Sie auf Ja, um den Standort aus der Struktur "Standort" zu löschen, oder klicken Sie auf Nein, um das Löschen des Standorts abzubrechen.

Exportieren eines Standorts

Gehen Sie folgendermaßen vor, um einen Standort zu exportieren:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Standorte.
3. Klicken Sie mit der rechten Maustaste auf den Standort, den Sie exportieren möchten, und wählen Sie Standort exportieren aus. Das Fenster "Standort speichern unter" wird angezeigt.
4. Wählen Sie den Speicherort aus, in dem die Datei gespeichert werden soll.
5. Benennen Sie die exportierte Konfigurationsdatei. Standardmäßig ist dies der Name des Standorts mit der Erweiterung .ims. Wenn Sie die Konfiguration eines Standorts exportieren, wird die aktuelle Konfiguration in jedem Ordner im entsprechenden Ordner dieses Standorts gespeichert.
6. Klicken Sie auf Speichern. Der Standort wird in den angegebenen Speicherort exportiert.

Vorgehensweise zum Importieren eines Standorts

Gehen Sie folgendermaßen vor, um einen Standort zu importieren:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Standorte.
3. Klicken Sie mit der rechten Maustaste in der Struktur "Standorte" auf den Hauptordner eines Standorts und wählen Sie Standort importieren aus. Das Fenster "Konfigurationsdatei auswählen" wird angezeigt.
4. Suchen Sie die Standortdatei, die Sie importieren möchten, und klicken Sie auf Öffnen. Der Standort wird in die aktuelle Anzeige importiert, wodurch ein neuer Standortknoten hinzugefügt und der Bereich "Transaktionsdatenbankkonfiguration" für diesen Standort angezeigt wird.
