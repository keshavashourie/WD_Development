Öffnen und Speichern einer Konfigurationsdatei

Management Studio zeigt anfänglich eine leere Konfiguration an, die nicht gespeichert wurde. Sie können eine neue Konfiguration erstellen und die Änderungen speichern. Sie können auch die Management Studio-Konfigurationsdatei öffnen, die vorher gespeichert wurde.

Hinweis: Sie können Konfigurationsinformationen für einen bestimmten Standort und nur für diesen Standort anzeigen.

Gespeicherte Konfigurationen und exportierte Standorte werden in eine XML-Datei geschrieben, die die Erweiterung ims hat.

Beim Speichern einer Konfigurationsdatei

Management Studio ermöglicht es Ihnen, die aktuelle Konfigurationsdatei zu speichern oder die aktuelle Konfigurationsdatei unter einem neuen Namen oder in einem anderen Speicherort zu speichern.

Wenn Sie die Standardkonfiguration zum ersten Mal speichern, wird das Fenster "Konfiguration speichern unter" angezeigt. Es wird auch angezeigt, wenn Sie den Befehl "Konfiguration speichern unter" im Menü "Datei" auswählen.

Vorgehensweise zum Öffnen einer Konfigurationsdatei

Gehen Sie folgendermaßen vor, um eine Konfigurationsdatei zu öffnen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Die Standardkonfigurationsdatei

Erweitern Sie den Ordner "Konfiguration" und klicken Sie auf das Symbol "Konfiguration". Die Konfigurationsinformationen werden im rechten Bereich des Konfigurationsfensters angezeigt.

Eine andere Konfigurationsdatei
a. Wählen Sie Konfiguration öffnen im Menü Datei aus. Das Fenster "Konfigurationsdatei auswählen" wird angezeigt.
b. Klicken Sie auf die .ims-Datei, die Sie anzeigen möchten, und klicken Sie auf Öffnen. Die Konfigurationsinformationen werden im rechten Bereich des Konfigurationsfensters angezeigt.

Vorgehensweise zum Speichern einer Konfigurationsdatei

Gehen Sie folgendermaßen vor, um eine Konfigurationsdatei in Management Studio zu speichern:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Klicken Sie auf Konfiguration speichern im Menü Datei oder klicken Sie auf die Schaltfläche Speichern. Die aktuelle Konfigurationsdatei wird gespeichert und die Meldung "Konfiguration erfolgreich gespeichert" wird unten im Management Studio-Fensters angezeigt.

Vorgehensweise zum Speichern einer Konfigurationsdatei als eine andere Datei

Gehen Sie folgendermaßen vor, um eine Konfigurationsdatei als eine andere Datei in Management Studio zu speichern:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Wählen Sie Konfiguration speichern unter im Menü Datei aus. Das Fenster "Konfiguration speichern unter" wird angezeigt.
3. Klicken Sie auf den Namen der Konfigurationsdatei, die Sie unter einem anderen Namen speichern möchten.
4. Geben Sie den neuen Namen in das Feld Dateiname ein.
5. Klicken Sie auf Speichern. Die neue Konfigurationsdatei wird gespeichert.
