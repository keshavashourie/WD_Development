Konfigurieren von Inline-SPC

Mithilfe von Inline Statistical Process Control (SPC) können Produktion und Engineering SPC-Kontrollcharts konfigurieren und in eine Opcenter EX MDD- oder Opcenter EX CR-Implementierung aufnehmen. Die Kontrollcharts können bei der Erfassung von Qualitätsdaten aktualisiert und angezeigt werden, damit der Operator sofort Feedback erhält. Die Technik kann bei der Untersuchung bestimmter Vorfälle auch historische Charts überprüfen.

Beim Konfigurieren von Inline SPC

Inline SPC bietet die Möglichkeit, angezeigte Charts automatisch in einem Dateipfad auf Ihrem Server zu speichern. Bei der Installation von Inline SPC wird ein Standarddateipfad (C:\ProgramData\Camstar\InlineSPC\Chart Output) erstellt. Sie können den Pfad nach Bedarf ändern. Weitere Optionen zum Speichern von Charts werden auf der Modellierungsseite "SPC Chart" definiert. Weitere Informationen finden Sie im Opcenter Execution Medical Device and Diagnostics Inline SPC-Referenzhandbuch oder im Opcenter Execution Core Inline SPC-Referenzhandbuch.

Die Registerkarte "Inline SPC" wird nur angezeigt, wenn Inline SPC installiert ist. Weitere Informationen finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung und der Opcenter Execution Core-Installationsanleitung.

Inline SPC-Lizenzierung

Inline SPC-Lizenzierung wird auf der Konfigurationsregisterkarte "Lizenz" aktiviert. Rufen Sie die Registerkarte "Lizenz" auf und klicken Sie auf Speichern, um die Inline SPC-Lizenz zu aktivieren und den Flexlm-Lizenzserver mit dem Inline SPC-Wert in der Appsettings-Datei zu aktualisieren.

Vorgehensweise zum Konfigurieren des Inline SPC-Chartpfads

Gehen Sie folgendermaßen vor, um den Inline SPC-Chartpfad zu konfigurieren:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Or

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Konfiguration in der Struktur "Standorte" und wählen Sie das Symbol Konfiguration aus. Der Konfigurationsbereich wird angezeigt.
3. Klicken Sie auf die Registerkarte Inline SPC. Das Dialogfeld "Industry Solutions Configuration Tool" wird angezeigt.
4. Klicken Sie auf die Schaltfläche "Durchsuchen". Das Fenster "Ordner suchen" wird angezeigt.
5. Wählen Sie den Dateiordner aus, der für den Inline SPC-Chartpfad verwendet werden soll, und klicken Sie auf OK. Das Fenster "Ordner suchen" wird geschlossen. Das Feld für den Inline SPC-Chartpfad wird aktualisiert, sodass es den ausgewählten Dateiordner enthält.
6. Klicken Sie auf Speichern. Der neue Inline SPC-Chartpfad ist konfiguriert.
Hinweis: Rufen Sie die Registerkarte "Lizenz" auf und klicken Sie auf Speichern, um die Inline SPC-Lizenz zu aktivieren.
