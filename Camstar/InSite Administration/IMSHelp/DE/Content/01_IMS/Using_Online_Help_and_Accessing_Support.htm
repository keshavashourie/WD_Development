Zugreifen auf die Onlinehilfe

Sie können das Menü "Hilfe" verwenden, um Folgendes zu öffnen:

• Onlinehilfe-Projekt für Management Studio
• Popup "Info"

Die Management Studio-Hilfe stellt Onlinehilfe für jedes Thema dieses Abschnitts bereit.

Beim Zugreifen auf die Onlinehilfe

Die Onlinehilfe wird in der bevorzugten Sprache, die Sie in Ihrem Browser eingestellt haben, angezeigt, sofern übersetzte Hilfe verfügbar ist. Gewährleisten Sie, dass Sie die neuesten Sprachpakete für Ihre bevorzugte Sprache installiert haben. Standardmäßig wird die Hilfe in englischer Sprache angezeigt.

Vorgehensweise zum Zugreifen auf die Management Studio-Hilfe

Gehen Sie folgendermaßen vor, um auf die Management Studio-Hilfe zuzugreifen:

1. Wählen Sie Management Studio-Hilfe im Menü Hilfe aus. Die Datei mit der Onlinehilfe wird angezeigt.
2. Verwenden Sie die Navigation auf der linken Seite, um nach bestimmten Themen zu suchen.

Vorgehensweise zum Zugreifen auf das Popup "Info"

Gehen Sie folgendermaßen vor, um auf das Popup "Info" zuzugreifen:

1. Wählen Sie Info im Menü Hilfe aus. Das Popup "Info" wird angezeigt.
2. Klicken Sie auf Schließen, wenn Sie die Informationen über Management Studio nicht mehr anzeigen möchten. Das Popup "Info" wird geschlossen.
