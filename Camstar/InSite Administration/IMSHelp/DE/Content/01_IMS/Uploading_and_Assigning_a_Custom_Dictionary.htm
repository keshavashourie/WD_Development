Hochladen und Zuweisen eines benutzerdefinierten Wörterbuchs

Sie können benutzerdefinierte Wörterbücher erstellen, um Ihre benutzerdefinierten oder übersetzten System- und Benutzerbeschriftungen zu organisieren. Sie können Wörterbücher Mitarbeitern auf individueller Basis zuweisen.

Beim Hochladen und Zuweisen eines benutzerdefinierten Wörterbuchs

Sie können Wörterbuchbeschriftungen mithilfe von benutzerdefinierten .csv-Dateien in Management Studio hochladen. Die Anwendung zeigt die entsprechenden Beschriftungen an, die im Wörterbuch enthalten sind, wenn sich ein Mitarbeiter mit einem zugewiesenen Wörterbuch beim Portal anmeldet. Wenn einem Mitarbeiter kein Wörterbuch zugewiesen ist, werden die Standardbeschriftungen angezeigt.

Wörterbuchbeschriftungen werden in Anwendungsserver- und Portal-Anwendungscaches zwischengespeichert. Wörterbuchbeschriftungen werden in der Datenbank gespeichert und im IIS-Cache des Portals zwischengespeichert. Sie müssen den IIS-Anwendungspool neu starten, um den Cache zu aktualisieren. Der Wörterbuchbeschriftungscache wird aktualisiert, wenn eine Wörterbuchmodellierungsinstanz aktualisiert wird.

Beim Speichern einer Wörterbuchmodellierungsinstanz wird der Beschriftungscache standardmäßig automatisch aktualisiert, wenn der Speichervorgang Änderungen umfasst.

Weitere Informationen zum Definieren von Wörterbüchern finden Sie im Opcenter Execution Medical Device and Diagnostics Modeling-Benutzerhandbuch oder im Opcenter Execution Core Modeling-Benutzerhandbuch. Weitere Informationen zu Beschriftungen finden Sie im Opcenter Execution Medical Device and Diagnostics Designer-Benutzerhandbuch oder im Opcenter Execution Core Designer-Benutzerhandbuch.

Vorgehensweise zum Hochladen eines benutzerdefinierten Wörterbuchs

Gehen Sie folgendermaßen vor, um ein benutzerdefiniertes Wörterbuch hochzuladen:

1. Exportieren Sie die Beschriftungsdatei.
2. Gewährleisten Sie, dass das Tabellenblatt das richtige Format hat. Die folgenden Spalten sind erforderlich: "LabelID", "Name", "CategoryID", "LabelValue", "WorkspaceCode" und "NewValue".
Hinweis: Die letzte Spalte hat den Namen "Column1", wenn sie exportiert wird, sodass die Spalte in "NewValue" umbenannt werden muss.
3. Geben Sie die Übersetzungen der einzelnen Einträge in die Spalte "NewValue" ein.
4. Speichern Sie das Tabellenblatt als .csv-Datei, wobei Sie den Namen verwenden, den Sie als Ihr Wörterbuch-Modellierungsobjekt verwenden möchten.
5. Kopieren Sie die .csv-Datei in das Verzeichnis "C:\Programme (x86)\Camstar\InSite Administration\Dictionaries".
6. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

7. Erweitern Sie Datenbanken und klicken Sie dann mit der rechten Maustaste auf Transaktionsdatenbank.
8. Wählen Sie Datenbank aktualisieren aus. Das Dialogfeld "Datenbank aktualisieren" wird angezeigt.
9. Wählen Sie Camstar-Wörterbücher laden und Alles neu laden aus.
10. Klicken Sie auf OK. Das Wörterbuch-Modellierungsobjekt und die zugehörigen Übersetzungen werden erstellt.
11. Weisen Sie dem gewünschten Mitarbeiter das fremdsprachliche Wörterbuch zu. Informationen hierzu finden Sie unter "Vorgehensweise zum Zuweisen eines benutzerdefinierten Wörterbuchs".
12. Melden Sie sich von Opcenter EX MDD oder Opcenter EX CR ab.
13. Starten Sie die Anwendungspools und Dienste neu.
Hinweis: Weitere Informationen zur optimalen Reihenfolge zum Starten der Anwendungspools und Dienste finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung oder in der Opcenter Execution Core-Installationsanleitung.
14. Führen Sie bei Bedarf ein IISReset durch.
15. Leeren Sie den Browsercache.

Vorgehensweise zum Zuweisen eines benutzerdefinierten Wörterbuchs

Gehen Sie folgendermaßen vor, um ein benutzerdefiniertes Wörterbuch zuzuweisen:

1. Melden Sie sich im Portal an.
2. Wählen Sie Modellierung im Menü Modellierung aus. Die Seite "Modellierung" wird angezeigt.
3. Klicken Sie auf Mitarbeiter. Die Seite "Mitarbeiter" wird auf der Seite "Modellierung" angezeigt.
4. Wählen Sie eine Mitarbeiterinstanz aus.
5. Wählen Sie das entsprechende Wörterbuch in der Liste "Sprachwörterbuch" aus.
6. Klicken Sie auf Speichern. Die Anwendung zeigt eine Erfolgsmeldung an, die angibt, dass das Modellierungsobjekt aktualisiert wurde.
7. Melden Sie sich vom Portal ab.
8. Melden Sie sich beim Portal als der Mitarbeiter an, dem Sie das neue Wörterbuch zugewiesen haben. Die Beschriftungen werden nun in der Fremdsprache angezeigt.
Hinweis: Einige Elemente, z. B. Seitennamen und Menüpunkte, werden nicht über Beschriftungen gesteuert. Sie müssen diese Elemente in Portal Studio in die Fremdsprache ändern.
