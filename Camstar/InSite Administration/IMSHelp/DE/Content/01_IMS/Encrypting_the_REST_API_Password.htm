Verschlüsseln des REST API-Passworts

REST-APIs bieten eine einfach zu verwendende Web-API-Abstraktionsebene für die Ausführung von Transaktionen, die vom Anwendungsserver unterstützt werden. REST-APIs ermöglichen es, Transaktionen effizienter auszuführen als bei Verwendung von WCF-Services. Mit dem Verschlüsselungsdienstprogramm können Sie das Passwort verschlüsseln, das Sie mit der REST-API verwenden, wenn Sie Ihre Anmeldeinformationen manuell angeben möchten. Nachdem das Dienstprogramm das Passwort verschlüsselt hat, können Sie es für jeden API-Dienst manuell in die Datei appsettings.json kopieren.

Hinweis: Anstatt das Passwort mit diesem Dienstprogramm zu verschlüsseln und dann manuell das verschlüsselte Passwort in die Dateien appsettings.json zu kopieren, können Sie Ihre REST API-Anmeldeinformationen in Management Studio angeben und Management Studio automatisch das Passwort verschlüsseln und die Anmeldeinformationen für jeden API-Dienst in die Datei appsettings.json kopieren lassen. Weitere Informationen finden Sie unter "REST API-Einstellungen".

Weitere Informationen zum Installieren und Verwenden von REST APIs finden Sie in der Opcenter Execution Medical Device and Diagnostics Technical Reference: REST API oder der Opcenter Execution Core Technical Reference: REST API.

Verschlüsseln des REST API-Passworts

Gehen Sie folgendermaßen vor, um das REST API-Passwort zu verschlüsseln:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Wählen Sie Encrypt Utility aus dem Menü Tools aus. Das Fenster Encrypt Utility wird angezeigt.
3. Geben Sie das gewünschte REST API-Kennwort in das Eingabefeld ein.
4. Klicken Sie auf Verschlüsseln. Das verschlüsselte Kennwort wird im Feld "Ausgabe" angezeigt.
5. Wählen Sie das verschlüsselte Kennwort aus.
6. Drücken Sie die rechte Maustaste und wählen Sie Kopieren aus.
7. Fügen Sie das verschlüsselte Kennwort für jeden API-Dienst in die Datei appsettings.json ein. Informationen zu den Dateien appsettings.json und zum Einfügen des Passworts in diese Dateien finden Sie in der Opcenter Execution Medical Device and Diagnostics Technical Reference: REST API oder in der Opcenter Execution Core Technical Reference: REST API.
