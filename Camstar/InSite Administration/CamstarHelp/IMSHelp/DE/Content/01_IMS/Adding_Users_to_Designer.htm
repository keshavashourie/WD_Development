Hinzufügen von Benutzern zu Designer

Sie können Benutzer zu Designer hinzufügen und Benutzer aus Designer löschen.

Informationen für Designer-Benutzer

Die Designer-Benutzerinformationen werden im rechten Bereich des Management Studio-Fensters angezeigt, wenn Sie "Designer-Benutzerverwaltung" im Ordner "Administration" auswählen.

Siemens stellt drei Standardbenutzer bereit:

• CamstarAdmin
• Administrator
• InSiteAdmin

Der Zugriff auf Designer basiert auf der Windows-Sicherheit. Gewährleisten Sie, dass Designer-Benutzer ein gültiges Windows-Konto haben und als Designer-Benutzer in Management Studio hinzugefügt wurden. Weitere Informationen zur Verwendung von Designer finden Sie im Opcenter Execution Medical Device and Diagnostics Designer-Benutzerhandbuch oder im Opcenter Execution Core-Benutzerhandbuch.

Sie können Benutzer hinzufügen, indem Sie in die erste leere Zeile klicken und den Benutzernamen eingeben. Klicken Sie auf "Speichern", um den Benutzer hinzuzufügen. Sie können Benutzer löschen, indem Sie die Zeile eines Benutzers auswählen und die Entf-Taste drücken oder auf das rote Löschsymbol klicken, das dem Benutzernamen zugeordnet ist. das in der Spalte "Verknüpfung löschen" angezeigt wird. Nach Klicken auf das Löschsymbol werden Sie aufgefordert, den Löschvorgang zu bestätigen. Klicken Sie in der Sicherheitsabfrage "Zeile löschen" auf "Ja", um den Benutzer zu löschen und die Meldung zu schließen.

Vorgehensweise zum Hinzufügen von Designer-Benutzern

Gehen Sie folgendermaßen vor, um Designer-Benutzer hinzuzufügen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Administration in der Struktur "Standorte" und wählen Sie Designer-Benutzerverwaltung aus. Die Verwaltungsinformationen für Designer-Benutzer werden im rechten Bereich angezeigt.
3. Geben Sie in das erste leere Feld Benutzername den Namen des neuen Benutzers ein.
4. Wiederholen Sie Schritt 3, um ggf. weitere Benutzer hinzuzufügen.
5. Klicken Sie auf Speichern. Management Studio zeigt eine Erfolgsmeldung an.

Vorgehensweise zum Löschen von Designer-Benutzern

Gehen Sie folgendermaßen vor, um Designer-Benutzer zu löschen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

2. Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.
3. Erweitern Sie den Ordner Administration in der Struktur "Standorte" und wählen Sie Designer-Benutzerverwaltung aus. Die Verwaltungsinformationen für Designer-Benutzer werden im rechten Bereich angezeigt.
4. Wählen Sie die Zeile des Benutzers aus, den Sie löschen möchten.
5. Drücken Sie die Entf-Taste. Die Anwendung löscht den Benutzer.
6. Wiederholen Sie Schritte 3 bis 4, um ggf. weitere Benutzer zu löschen.
7. Klicken Sie auf Speichern. Management Studio zeigt eine Erfolgsmeldung an.
