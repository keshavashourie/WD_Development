Verwalten der Konfiguration der Metadaten-Datenbank

Sie müssen eine Metadaten-Datenbank erstellen, bevor Sie die anderen Datenbanken erstellen.

Konfigurationsinformationen für die Metadaten-Datenbank

Konfigurationsinformationen für die Metadaten-Datenbank werden im rechten Bereich des Management Studio-Fensters angezeigt, wenn Sie die Metadaten-Datenbank hinzufügen oder auswählen.

Im Management Studio-Fenster wird ein Menü "Datenbanken" angezeigt, wenn der Ordner "Datenbanken" oder ein Datenbankknoten ausgewählt wird. Weitere Informationen zum Menü für Datenbanken finden Sie unter "Menü "Datenbanken"".

Diese Felder zeigen die Verbindungsinformationen für die Metadaten-Datenbank (InSite.mdb) und die Standortinformationsdatenbank (SiteInfo.mdb) an. Die Namen der Datenbankdateien sind schreibgeschützt, aber Sie können nach den Dateien suchen.

Vorgehensweise zum Hinzufügen und Konfigurieren einer Metadaten-Datenbank

Gehen Sie folgendermaßen vor, um eine Metadaten-Datenbank hinzuzufügen und zu konfigurieren:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Klicken Sie mit der rechten Maustaste auf den Ordner Datenbanken und wählen Sie Metadaten-Datenbank hinzufügen Ein Metadaten-Datenbank-Symbol erscheint und die Metadaten-Datenbank Konfigurationsinformationen erscheinen in der rechten Leiste.
3. Klicken Sie auf Durchsuchen für das Feld Designer-Metadaten-Datenbank, damit das Fenster "Metadaten-Datenbank auswählen" geöffnet wird. "InSite.mdb" ist die Standardauswahl.
4. Klicken Sie auf Öffnen, um die Standarddatenbank auszuwählen oder wählen Sie, falls nötig, eine andere Datenbank aus. Die Datenbankauswahl wird im Feld "Designer-Metadaten-Datenbank" angezeigt.
5. Klicken Sie auf Durchsuchen für das Feld Dateiname für Standortinformationsdatenbank, damit das Fenster "Standortinformationsdatenbank auswählen" geöffnet wird. "SiteInfo.mdb" ist die Standardauswahl.
6. Klicken Sie auf Öffnen, um die Standarddatenbank auszuwählen oder wählen Sie, falls nötig, eine andere Datenbank aus. Die Datenbankauswahl wird im Feld "Dateiname für Standortinformationsdatenbank" angezeigt.
7. Klicken Sie auf Verbindung testen für jede Datenbank. Management Studio zeigt die Meldung "Verbindung hergestellt" an, wenn die Verbindung erfolgreich hergestellt wurde. Andernfalls zeigt die Anwendung eine Fehlermeldung an.
8. Klicken Sie auf OK, um die Meldung zu schließen.
9. Klicken Sie auf Speichern. Management Studio zeigt eine Erfolgsmeldung an.
