Aktivieren der Serverablaufverfolgungsprotokolle

Im Menü "<Servername> - Protokolle" können Sie verschiedene Protokollierungsebenen für die Serverablaufverfolgung aktivieren. Mithilfe der Serverablaufverfolgung können Sie Debugginginformationen für verschiedene Anforderungen und Antworten erfassen.

Beim Aktivieren der Serverablaufverfolgungsprotokolle

Sie aktivieren Serverablaufverfolgungsprotokolle, indem Sie im Ordner "Camstar Servers" einen Serverknoten und dann im Menü "<Servername> - Protokolle" ein Serverablaufverfolgungsprotokoll auswählen. Weitere Informationen zum Menü "<Servername> - Protokolle" finden Sie unter "Menü "<Servername> - Protokolle" (<Server Name> - Logs)".

Hinweis: Sie müssen die Server-Ablaufverfolgungsprotokolle nach Abschluss einer Datenbankaktualisierung (dbUpdate) erneut aktivieren. Dieses erneute Aktivieren der Protokolle ist erforderlich, da der Server neu gestartet wird und die Server-Ablaufverfolgungsprotokolle deaktiviert werden, wenn eine Aktualisierung mit dbUpdate durchgeführt wird.

Diese Tabelle definiert die Informationen, die auf den einzelnen Protokollierungsebenen für die Serverablaufverfolgung erfasst werden.

Ebene

Erfasste Informationen

Niedrig

Funktionsnamen und Parameter.

Mittel

Funktionsnamen, Parameter und aufgelöste Werte.

Hoch

Funktionsnamen, Parameter, aufgelöste Werte, XML-Anforderungen und XML-Antworten.

Es kann jeweils nur eine Protokollierungsebene für die Serverablaufverfolgung ("Niedrig", "Mittel" oder "Hoch" auf einem Server aktiviert werden. Wenn Sie z. B. "Niedrig" und dann "Mittel" auswählen, wird lediglich die mittlere Protokollierungsebene für die Serverablaufverfolgung aktiviert. Sie können auf den einzelnen Servern gleichzeitig separate Serverablaufverfolgungen auf verschiedenen Ebenen ausführen.

Sie können ein aktives Serverablaufverfolgungsprotokoll deaktivieren, indem Sie einen Serverknoten auswählen, auf dem derzeit eine Serverablaufverfolgung ausgeführt wird, und dann "Serverablaufverfolgungsprotokoll deaktivieren" im Menü "Protokolle" auswählen.

Die Protokolldateien werden standardmäßig in "Programme (x86)\Camstar\Logs\Transaction Logs" gespeichert.

Sie können auch eine Clientablaufverfolgungsprotokollierung aktivieren, indem Sie "Clientablaufverfolgungsprotokolle aktivieren" im Menü "<Servername> - Protokolle" auswählen. Im Clientablaufverfolgungsprotokoll werden die vom Client erstellten, gesendeten WCF-Dokumente und deren Antworten erfasst. Sie können die Clientablaufverfolgungsprotokollierung wieder deaktivieren, indem Sie "Clientablaufverfolgungsprotokolle deaktivieren" im Menü "<Servername> - Protokolle" auswählen.

Möglicherweise wird das Popupfenster "Datei öffnen - Sicherheitswarnung" angezeigt, wenn Sie ein Serverablaufverfolgungsprotokoll aktivieren. Klicken Sie auf "Ausführen", um das Serverablaufverfolgungsprotokoll zu aktivieren und das Popupfenster zu schließen. Klicken Sie auf "Abbrechen", um das Serverablaufverfolgungsprotokoll abzubrechen und das Popupfenster zu schließen. Wenn Sie das Serverablaufverfolgungsprotokoll über das Popupfenster "Datei öffnen - Sicherheitswarnung" abbrechen, werden möglicherweise Fehler-Popupfenster angezeigt. Klicken Sie auf OK, um alle Fehler-Popupfenster zu schließen, die möglicherweise angezeigt werden.

Sie können optional den Pfad zur ausführbaren Datei des Serverablaufverfolgungsprotokolls zu Ihren lokalen Intraneteinstellungen hinzufügen, um das Anzeigen des Popupfensters "Datei öffnen - Sicherheitswarnung" zu verhindern. Fügen Sie den folgenden Pfad zu den lokalen Intraneteinstellungen hinzu und ersetzen Sie dabei <Hostname> durch den Hostnamen oder die IP-Adresse des Anwendungsservers:

file://<Hostname>\c$\Program Files (x86)\Camstar\InSite Server

Vorgehensweise zum Aktivieren der Serverablaufverfolgungsprotokolle

Gehen Sie folgendermaßen vor, um Serverablaufverfolgungsprotokolle zu aktivieren:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie Camstar-Server und wählen Sie einen Serverknoten aus. Das Menü "<Servername> - Protokolle" wird angezeigt.
3. Wählen Sie im Menü Protokolle ein Serverablaufverfolgungsprotokoll aus. Die Anwendung beginnt daraufhin mit dem Erfassen von Informationen für die ausgewählte Ebene des Serverablaufverfolgungsprotokolls.
4. Führen Sie die erforderlichen Arbeitsschritte aus.
5. Wählen Sie denselben Serverknoten aus und dann Serverablaufverfolgungsprotokolle deaktivieren aus dem Menü Protokolle. Die Anwendung beendet das Erfassen von Informationen und erstellt eine Protokolldatei.
