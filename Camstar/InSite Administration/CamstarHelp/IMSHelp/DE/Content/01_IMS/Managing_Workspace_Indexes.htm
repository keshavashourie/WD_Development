Verwalten von Arbeitsbereichsindizes

Die in Designer definierten Indizes werden durch eine gespeicherte Prozedur erstellt, die die Definition einliest und die Datenbankindizes erstellt. Es gibt einige Fälle, in denen Änderungen eines vorhandenen Index erforderlich sind, die aber von Designer nicht unterstützt werden, z. B. geclusterte Indizes oder Fälle, in denen zusätzliche Spalten für einen bestimmten Arbeitsbereich erforderlich sind. Um diese Fälle zu unterstützen, können arbeitsbereichsspezifische gespeicherte Prozeduren erstellt werden, die bei der Indexerstellung aufgerufen werden. Dadurch wird eine Änderung vorhandener Indizes ermöglicht. Für jeden aktiven Arbeitsbereich ist eine eigene Prozedur möglich, die im Rahmen der Indexerstellung vom niedrigsten zum höchsten aktiven Arbeitsbereich aufgerufen wird.

Beim Verwalten von Arbeitsbereichsindizes

Eine gespeicherte Prozedur wird ausgeführt, wenn die Transaktionsdatenbank aktualisiert wird oder Datenbanktabellen erstellt werden und das Kontrollkästchen "Indizes erstellen" aktiviert ist. Die gespeicherte Prozedur "csiCreateIndexes" wird ausgeführt, um die Definitionen einzulesen und die Indizes den jeweiligen Definitionen entsprechend zu erstellen.

Nachdem die Indizes für die einzelnen aktiven Arbeitsbereiche in aufsteigender Reihenfolge (gemäß Arbeitsbereichssequenz) erstellt wurden, überprüft die Prozedur, ob eine gespeicherte Prozedur mit einem bestimmten Namen vorhanden ist, die dann aufgerufen wird (sofern vorhanden). Wenn z. B. die Arbeitsbereiche "180", "190" und "200" aktiv sind und für jeden Arbeitsbereich eine Datei für eine benutzerdefinierte gespeicherte Prozedur vorhanden ist, führt die Anwendung die Prozeduren in der Reihenfolge 180, 190 und dann 200 aus.

Hinweis: Alle Änderungen, die an Indizes vorgenommen werden, werden in der Protokolldatei des Dienstprogramms zum Ersetzen von Arbeitsbereichsdaten protokolliert. Weitere Informationen zum Dienstprogramm zum Ersetzen von Arbeitsbereichsdaten finden Sie in der Opcenter Execution Medical Device and Diagnostics-Installationsanleitung oder in der Opcenter Execution Core-Installationsanleitung.

Für jeden aktiven Arbeitsbereich darf nur eine gespeicherte Prozedur vorhanden sein. Sie müssen die Benennungskonvention "Workspace_WSCode_CreateIndexes" befolgen, wobei "WSCode" der Code des Arbeitsbereichs ist, z. B. "180" oder "190". Der Name der gespeicherten Prozedur für den Arbeitsbereich "200" muss z. B. "Workspace_200_CreateIndexes" lauten.

Als Ausgangspunkt zum Erstellen eigener benutzerdefinierter gespeicherter Indexprozeduren werden Beispieldateien mit gespeicherten Prozeduren für SQL Server- und Oracle-Datenbanken zur Verfügung gestellt. Die Beispieldateien stehen in folgenden Verzeichnissen zur Verfügung:

• "C:\Programme (x86)\Camstar\Insite Administration\Scripts\Oracle" für Oracle-Datenbanken
• "C:\Programme (x86)\Camstar\Insite Administration\Scripts\SqlServer" für SQL Server-Datenbanken.

Sie müssen die für die jeweilige Datenbank erstellten Skripts in Management Studio ausführen, um die gespeicherte Prozedur zu erstellen. Eine gespeicherte Prozedur wird ausgeführt, wenn die Transaktionsdatenbank aktualisiert wird oder Datenbanktabellen erstellt werden und das Kontrollkästchen "Indizes erstellen" aktiviert ist. Die Prozedur "csiCreateIndexes" sucht dann die benutzerdefinierte Prozedur und ruft sie bei der Indexerstellung auf.
