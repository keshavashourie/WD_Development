Aktualisieren der Transaktionsdatenbank

Die Aufgabe "Datenbank aktualisieren" in Management Studio aktualisiert Ihre DataStore-Transaktions- und Betriebsdatenbanken, vorausgesetzt, die Datenbankkonfigurationen sind eingerichtet. Führen Sie diese Aufgabe aus, nachdem Sie Konfigurationsänderungen in Designer vorgenommen haben, aber auch nur dann, wenn die Aufgabe "Neue Datenbank erstellen" ausgeführt wurde. Weitere Informationen finden Sie unter "Erstellen von neuen Datenbanktabellen".

Änderungen, die über Designer eingegeben wurden, werden in den InSite.mdb-Dateien festgehalten. Sie müssen diese Änderungen auf Ihre Transaktionsdatenbank und ggf. auf Ihre DataStore-Datenbank anwenden. Die Transaktionsdatenbank und die DataStore-Datenbank müssen verschiedene Datenbanken sein, wenn eine Datenbankaktualisierung durchgeführt wird. Die Anwendung aktualisiert Tabellen und Spalten in der Transaktionsdatenbank, wenn für die Designer-Klassen Unterklassen erstellt und Felder hinzugefügt wurden.

Wichtig: Führen Sie das Erstellen oder Aktualisieren nur einmal für jedes Mitglied des Clusters in einer Clusterumgebung aus.

Voraussetzung für Aufgaben zur Datenbankaktualisierung

Der Opcenter EX MDD- oder Opcenter EX CR-Datenbankbenutzer erfordert uneingeschränkten Zugriff auf die folgenden Standardbenutzeransichten für Aufgaben vom Typ "Datenbank aktualisieren":

• Für Oracle
USER_TABLES
USER_TAB_COLUMNS
USER_CONSTRAINTS
USER_CONS_COLUMNS
• Für SQL Server
INFORMATION_SCHEMA.TABLES
INFORMATION_SCHEMA.COLUMNS
INFORMATION_SCHEMA.KEY_COLUMN_USAGE

Wann müssen Anwendungspools und Dienste nach dem Aktualisieren der Datenbank neu gestartet werden?

In der Regel werden Anwendungspools und Dienste beim Aktualisieren der Datenbank in der Anwendung nicht angehalten. Dadurch kann die Anwendung Fertigungstransaktionen ohne Unterbrechung weiterverarbeiten. In folgenden Situationen müssen die Anwendungspools und Dienste beendet und nach dem Aktualisieren der Datenbank neu gestartet werden:

• Das Neuerstellen von WCF-Diensten erfordert eine Wiederverwendung der Anwendungspools für Portal- und Camstar-WCF-Dienste.
• Das Neugenerieren von REST API-Diensten erfordert ein Recyceln der Portal- und REST API-Anwendungspools.
• Änderungen an den Datenbankverbindungsinformationen erfordern einen Neustart der Anwendungspools für den Camstar-Sicherheitsdienst und den Camstar-Anwendungsserver.
• Manuelle Änderungen des Datenbankschemas erfordern einen Neustart des Anwendungspools für den Camstar-Anwendungsserver.
Hinweis: In Management Studio wird unter Umständen eine Meldung angezeigt, dass der Camstar-Anwendungsserver neu gestartet werden kann, falls Sie weitere Aktionen durchführen, die einen Neustart erfordern. Weitere Informationen zu Anwendungspools und Diensten finden Sie unter "Verwalten von Diensten".

Vorgehensweise zum Aktualisieren der Transaktionsdatenbank

Gehen Sie folgendermaßen vor, um die Transaktionsdatenbank zu aktualisieren, nachdem Sie Änderungen in Designer vorgenommen haben:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie Datenbanken und klicken Sie dann mit der rechten Maustaste auf Transaktionsdatenbank.
3. Wählen Sie Datenbank aktualisieren aus. Das Dialogfeld "Datenbank aktualisieren" wird angezeigt.
4. Aktivieren oder deaktivieren Sie die Aktualisierungsoptionen entsprechend den Anforderungen Ihres Unternehmens. Informationen über die Kontrollkästchen finden Sie in der Tabelle mit den Definitionen der Kontrollkästchen.
5. Klicken Sie auf OK. Die Statusanzeige zeigt an, dass der Prozess ausgeführt wird. In einem SQL-Skriptpopupfenster wird der Ausführungsfortschritt der Skripts angezeigt. Wenn ein Fehler auftritt, wird der Abschnitt "Fehlerinformationen" aktiviert und gefüllt. Wenn Sie eine andere Datei auswählen, wird der Abschnitt "Fehlerinformationen" mit dem Skriptnamen aktualisiert.
6. Führen Sie einen der folgenden Schritte aus, wenn ein Fehler auftritt:
• Klicken Sie auf die Schaltfläche Anzeigen…-, um die Skriptdatei in Editor (oder dem entsprechenden Programm) zu öffnen.
• Klicken Sie auf die Schaltfläche Skripts ausführen, um alle Skripts von Beginn an neu zu starten.
