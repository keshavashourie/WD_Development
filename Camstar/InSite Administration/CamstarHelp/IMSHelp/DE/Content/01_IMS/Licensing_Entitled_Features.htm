Anzeigen von berechtigten Funktionen

Sie können über den Bereich "Funktionsberechtigung" in Management Studio die Liste der berechtigten (lizenzierten) Funktionen anzeigen, die in Ihrem höchsten aktiven Arbeitsbereich vorhanden sind.

Beim Anzeigen von berechtigten Funktionen

Die Informationen zur Funktionsberechtigung werden im rechten Bereich des Management Studio-Fensters angezeigt, wenn Sie "Funktionsberechtigung" im Ordner "Arbeitsbereichsverwaltung" auswählen. Im Bereich "Funktionsberechtigung" werden alle berechtigten Funktionen für Ihre aktiven Arbeitsbereiche angezeigt.

Vorgehensweise zum Anzeigen von berechtigten Funktionen

Gehen Sie folgendermaßen vor, um berechtigte Funktionen anzuzeigen:

1. Klicken Sie auf Start > Opcenter Execution MDD > Management Studio. Das Fenster "Management Studio" wird angezeigt.

Oder

Klicken Sie auf Start > Opcenter Execution Core > Management Studio. Das Fenster "Management Studio" wird angezeigt.

2. Erweitern Sie den Ordner Arbeitsbereichsverwaltung und wählen Sie den Knoten Funktionsberechtigung aus. Die Informationen zur Funktionsberechtigung werden im rechten Bereich angezeigt.
