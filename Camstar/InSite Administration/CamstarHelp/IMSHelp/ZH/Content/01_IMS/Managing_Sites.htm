管理站点

站点特定信息对于指定唯一标识符和数据库更新至关重要。这些信息通常不会频繁更改。

站点名称是指派给 Opcenter EX MDD 或 Opcenter EX CR 安装的唯一且有意义的名称。例如，可以指派站点名称以匹配地理位置。

管理站点

Opcenter EX MDD 或 Opcenter EX CR 配置从创建新站点开始。从“站点”菜单或快捷方式菜单中选择“添加站点”后，将显示一个新的站点树。

选择站点文件夹或站点树后，“站点”菜单将显示在 Management Studio 窗口中。有关“站点”菜单的信息，请参考“站点菜单”。

可以重命名和删除站点。此外，还可以将站点的配置文件导出到其他位置以进行测试和备份。还可以从以前导出的配置文件（其中包括站点的所有配置信息）将站点导入到 Management Studio。

如何添加站点

按照以下步骤来添加站点：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 右键单击站点文件夹，然后选择添加站点。此时将显示一个新的站点树，并且默认站点名称处于编辑模式。
3. 在突出显示的 NewSite 节点中输入站点的名称。
重要提示: 站点名称相当于旧版软件中的站点 ID；因此，如果要从先前版本升级，则必须输入站点 ID。
4. 按 Enter。出现确认信息。
5. 单击是将新站点名称保存到此站点的配置文件中，或单击否取消添加站点。

如何重命名站点

按照以下步骤重命名站点：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 根据需要，展开站点文件夹。
3. 右键单击“站点树”中的站点，然后选择重命名站点。站点名称变为编辑模式。
4. 输入新的站点名称，然后按 Enter。出现确认信息。
5. 单击是将新站点名称保存到此站点的配置文件中。

或

单击否取消新站点名称。

如何删除站点

按照以下步骤删除站点：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 根据需要，展开站点文件夹。
3. 右键单击要在站点树中删除的站点，然后选择删除站点。此时将显示“确认删除站点”对话框。
4. 单击是从站点树中移除该站点，或单击否取消删除站点。

如何导出站点

按照以下步骤导出站点：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 根据需要，展开站点文件夹。
3. 右键单击要导出的站点，然后选择导出站点。此时将显示“站点另存为”窗口。
4. 如果需要，选择文件保存位置。
5. 命名导出的配置文件。默认情况下，它将是扩展名为 .ims 的站点名称。导出站点的配置时，它会保存该特定站点文件夹下各文件夹中的当前配置。
6. 单击保存。该站点会导出到指定的位置。

如何导入站点

按照以下步骤导入站点：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 根据需要，展开站点文件夹。
3. 右键单击站点树中的主站点文件夹，然后选择导入站点。此时将显示“选择配置文件”窗口。
4. 找到要导入的站点文件，然后单击打开。该站点会导入到当前显示中，进而添加新的站点节点并显示该站点的“事务数据库配置”窗口。
