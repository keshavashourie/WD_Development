加密 REST API 密码

REST API 提供易于使用的 Web API 抽象层，用于执行应用程序服务器支持的事务。REST API 可比使用 WCF 服务更高效地执行事务。如果要手动指定凭证，加密实用程序可用于加密用于 REST API 的密码。 该实用程序加密密码后，可以手动将其复制到每个 API 服务的 appsettings.json 文件中。

注释: 除了使用此实用程序加密密码然后手动将加密密码复制到 appsettings.json 文件中外，还可以在 Management Studio 中指定 REST API 凭证，并让 Management Studio 自动加密密码以及将凭证复制到每个 API 服务的 appsettings.json 文件中。 请参考“REST API 设置”以了解有关信息。

访问 Opcenter Execution Medical Device and Diagnostics Technical Reference: REST API 或 Opcenter Execution Core Technical Reference: REST API 可了解有关安装和使用 REST API 的信息。

如何加密 REST API 密码

按照以下步骤加密 REST API 密码：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 从工具菜单中选择加密实用程序。此时将显示“加密实用程序”窗口。
3. 在输入字段中输入要使用的 REST API 密码。
4. 单击加密。 “输出”字段将显示加密密码。
5. 选择加密密码。
6. 右键单击并选择复制。
7. 将加密密码粘贴到每个 API 服务的 appsettings.json 文件中。 有关 appsettings.json 文件以及将密码插入这些文件的信息，请参见 Opcenter Execution Medical Device and Diagnostics 技术参考：REST API 或 Opcenter Execution Core 技术参考：REST API。
