创建新的数据库表

在 Management Studio 中添加数据库之后，下一步是使用产品相关的表填充数据库管理系统 (DBMS)。可为事务数据库和 DataStore 数据库创建表。

注释: 本主题介绍为事务数据库创建数据库表。有关为 DataStore 数据库创建表的信息，请参考《Opcenter Execution Medical Device and Diagnostics DataStore 参考指南》或《Opcenter Execution Core DataStore 参考指南》。

创建新的数据库表

通过执行“创建新的数据库表”任务，可以创建生产数据库中的元数据字段、表、关系、实例数据、索引、存储过程和主键。第一次安装 Opcenter EX MDD 或 Opcenter EX CR 之后，需执行此任务。

“创建新的数据库表”任务设计用于自动执行以下过程：

• 在 DBMS 中创建产品相关表、数据库索引和存储程序
• 将初始默认数据（包括默认安全管理角色和权限）加载到 DBMS 中

可以选择加载默认门户种子数据（如果适用）。

默认情况下，SSL 安全已启用，表示 Opcenter EX MDD 和 Opcenter EX CR 产品与模块在安全环境中运行。如果禁用了 SSL 安全，可以在生成 WCF 服务时清除“加密 Web 流量”复选框中的复选标记。有关 SSL 安全的信息，请参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。

选择“数据库”文件夹或数据库节点时，Management Studio 窗口中将显示“数据库”菜单。有关“数据库”菜单的信息，请参考“数据库菜单”。

在集群环境中

只能从集群环境的集群中的任何成员执行一次创建或更新过程。

创建存储过程

运行 InstallProcedures.bat 文件。Opcenter EX MDD 或 Opcenter EX CR 的存储程序是指在数据库中定义和存储并由程序调用的一系列 SQL 语句和逻辑控制。默认存储过程包括特定于平台的规则，可提高性能并减少网络流量。由于数据对象使用的是同一规则集，因此其逻辑应统一。

如果要更改或添加任意这些存储过程或者创建初始数据库，可选择此选项。

此脚本还能加载初始默认角色和关联的权限。

重要事项：Siemens 不建议在生产环境中使用该选项。如果使用该选项，所有原始更改管理实例将重置为初始安装后的状态，它们的 ID 将更改。此外，任何现有更改管理包都将孤立。

如何为事务数据库创建新的数据库表

按照以下步骤为事务数据库创建新的数据库表：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开数据库，然后右键单击事务数据库。
3. 单击创建新的数据库表。此时将显示“创建表”对话框。
4. 保留默认选择。

 

5. 单击确定。Management Studio 窗口底部将显示消息“创建新的事务数据库已成功完成”。
