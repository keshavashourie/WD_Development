管理元数据数据库配置

在创建其他数据库之前，必须创建元数据数据库。

元数据数据库配置信息

当您添加或选择元数据数据库时，元数据数据库的配置信息将显示在 Management Studio 窗口的右窗格中。

选择“数据库”文件夹或数据库节点时，Management Studio 窗口中将显示“数据库”菜单。 有关“数据库”菜单的信息，请参考“数据库菜单”。

这些字段显示元数据数据库 (InSite.mdb) 和站点信息数据库 (SiteInfo.mdb) 连接信息。数据库文件名仅显示，但您可以浏览文件。

如何添加和配置元数据数据库

按照以下步骤添加和配置元数据数据库：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 右键单击数据库文件夹，然后选择添加元数据数据库。将出现一个元数据数据库图标，并且元数据数据库配置信息将显示在右窗格中。
3. 针对 Designer 元数据数据库字段单击浏览以打开“选择元数据数据库”窗口。InSite.mdb 是默认选择。
4. 单击打开以选择默认数据库，或在必要时选择其他数据库。数据库选择将显示在“Designer 元数据数据库”字段中。
5. 针对站点信息数据库文件名字段单击浏览以打开“选择站点信息数据库”窗口。SiteInfo.mdb 是默认选择。
6. 单击打开以选择默认数据库，或在必要时选择其他数据库。 数据库选择将显示在“站点信息数据库文件名”字段中。
7. 单击每个数据库的测试连接。如果已成功建立连接，Management Studio 将显示“已建立连接”消息。 否则，应用程序将显示错误消息。
8. 单击确定以关闭消息。
9. 单击保存。 Management Studio 将显示成功消息。
