管理服务器

可以向站点添加一个或多个服务器。

应用程序服务器是运行业务逻辑的核心事务服务器。所有事务都通过应用程序服务器进行处理，该服务器可提供以下服务：

• 包含封装了业务规则和逻辑的 Opcenter EX MDD 或 Opcenter EX CR 产品和工厂信息模型。
• 使用户能够通过可配置数据对象 (CDO) 以及可配置逻辑流 (CLF) 来定义他们的业务规则。
• 与使用 XML 文档的客户端应用程序进行通信。它会侦听从 HTTP/S 客户端请求传入的 XML 文档，对文档进行解析，并将其作为 Opcenter EX MDD 或 Opcenter EX CR 事务进行处理。它以 XML 文档的形式返回结果。
• 存储和检索信息。
• 提供对象模型与行业标准关系数据库之间的转换，以存储和检索数据。
注释: 服务器必须在 Management Studio 中使用相同的事务数据库。例如，localhost 和其他远程服务器都必须使用相同的事务数据库。
重要提示: 应用程序服务器、事务 (OLTP) 数据库以及 DataStore (ODS) 数据库服务器必须位于地理位置相同的数据中心。这些服务器必须配置有相同的时区，且位于同一 VLAN（一个跃点）中。理想情况下，所有这些服务器都会连接同一网络交换机。应用程序服务器到 OLTP 数据库服务器的网络延迟最好少于 1 毫秒，但不能超过 5 毫秒，才能确保 Opcenter EX MDD 和 Opcenter EX CR 产品的最佳性能。

添加服务器的主机信息

选择现有服务器或添加新服务器时，将在 Management Studio 窗口的右窗格中显示服务器的主机信息。

选择 Camstar 服务器文件夹或服务器节点后，Management Studio 窗口中将显示 Camstar 服务器菜单。有关 Camstar 服务器菜单的信息，请参考“Camstar 服务器菜单”。

在“主机名”或“IP 地址”字段中输入文本之前，“保存”和“放弃”按钮处于禁用状态。单击“保存”可保存更改。单击“放弃”可撤消更改并还原之前的字段值。

如果在未放弃或未保存更改的情况下尝试关闭“主机信息”窗格，则会显示一条消息提示您进行保存或取消。按照说明保存或放弃更改。

如何添加服务器

按照以下步骤来添加服务器：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 右键单击 Camstar 服务器文件夹，然后选择添加 Camstar 服务器。新的服务器图标显示在“Camstar 服务器”文件夹下，“主机信息”字段显示在右窗格中，并且服务器名称处于编辑模式。
3. 在突出显示的 NewServer 节点中输入新服务器的名称。
4. 输入服务器的主机名或 IP 地址。
5. 确认端口字段中的条目是否为 443。
6. 单击保存。 Management Studio 将显示成功消息。

如何重命名服务器

按照以下步骤来重命名服务器：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 右键单击要在“Camstar 服务器”文件夹中重命名的服务器，然后选择重命名。服务器名称变为编辑模式。
3. 输入新的服务器名称。
4. 单击保存。 Management Studio 将显示成功消息。

如何删除服务器

按照以下步骤删除服务器：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 右键单击要在“站点”树中删除的服务器，然后选择删除。将显示“确认删除服务器”消息。
3. 单击是。服务器即从“站点”树中删除。
