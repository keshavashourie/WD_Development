管理工作区应用程序代码文件

Siemens 提供了一个 MergeAppCode 可执行文件，可合并各活动工作区之间的应用程序代码文件。

管理工作区应用程序代码文件

MergeAppCode 可执行文件 (MergeAppCode.exe) 通过每个工作区子文件夹进行工作，并更改每个应用程序代码文件的继承，以便从其上面的工作区继承。例如，如果 csi、180 和 190 工作区都处于活动状态，则 MoveStd_190 继承将从“:MoveStd”更改为“:MoveStd_180”。可从文件路径 C:\Program Files (x86)\Camstar\Insite Conversion Tool\MergeAppCode 找到该可执行文件。

可从文件路径 C:\Program Files (x86)\Camstar\Insite Conversion Tool\MergeAppCode 找到修改该可执行文件的配置文件 (MergeAppCode.exe.config)。可以使用 WebPortlet 文件夹的相对或绝对路径修改 WebPortletPath 键。

重要提示: 不要更改 MergeAppCode.config 文件中的 mdbConnectionString 键。

必须在文件路径 C:\Program Files (x86)\Camstar\Camstar Portal\App_Code\WebPortlets\Workspaces 中添加工作区子文件夹，以存储用于合并的应用程序代码文件。工作区子文件夹必须命名为关联工作区的代码。例如，与工作区 200 关联的子文件夹必须命名为“200”。

必须将所有自定义控件、函数和属性名称附加到关联工作区代码中。例如，工作区 200 中名为“ControlName”的控件必须命名为“ControlName_200”，以使可执行文件能确定关联工作区和继承。所有文件都必须存储在其关联工作区子文件夹中。

如果没有可用的活动工作区（不包括基础 csi 工作区），或者找不到 WebPortletPath，则会显示错误消息。错误会记录在事件查看器中。

如何合并应用程序代码文件

按照以下步骤合并应用程序代码文件：

1. 导航至文件路径 C:\Program Files (x86)\Camstar\Insite Conversion Tool\MergeAppCode。
2. 双击 MergeAppCode.exe。当可执行文件合并应用程序代码文件并在完成后显示成功消息时，将显示一个命令提示符弹出窗口。
