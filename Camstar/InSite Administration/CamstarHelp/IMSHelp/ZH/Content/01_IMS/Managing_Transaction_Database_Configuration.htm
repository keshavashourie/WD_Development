事务数据库配置字段定义

此表定义了事务数据库配置窗格中的字段。

字段

定义

类型

事务数据库连接信息

事务数据库类型

SQL Server 或 Oracle。

必需

事务数据库主机

数据库服务器的主机名。在集群环境中，必须为集群中的每个服务器输入完全相同的数据库主机名。

注意：请勿指定 "localhost"。即使托管数据库的服务器为本地服务器，也请使用实际服务器名称。

如果在“事务数据库类型”字段中选择了 SQL Server，请参考“SQL Server 环境中的事务数据库连接”。

端口

该数据库连接的端口号。仅当数据库管理员指示需要其他端口时，才可更改默认端口。

如果在“事务数据库类型”字段中选择了 SQL Server，请参考“SQL Server 环境中的事务数据库连接”。

必需

数据库名称

这是在 DBMS 中创建的数据库名称（SQL 服务器）或服务名称 (Oracle)。

必需

架构

表的架构名称。即使不使用架构，也需要输入。在这种情况下，输入数据库的用户名。输入必须与在 DBMS 中输入的值匹配。

必需

用户

用于登录到事务数据库的登录名。输入区分大小写。输入必须与在 DBMS 中输入的值匹配。

必需

密码

事务数据库用户的密码。此值区分大小写。

出于安全考虑，将对输入的值进行加密。输入必须与在 DBMS 中输入的值相匹配。

必需

加密数据库流量

加密数据库与 Opcenter 应用程序服务器、安全服务、通知服务和 Opcenter Management Studio 之间的流量。

注意：如果选中该复选框，确保将事务数据库端口的端口更改为为加密流量配置的加密端口。Oracle 的默认加密标准端口为 2484，SQL Server 为 1433。

可选

验证服务器证书

此复选框指示是否验证服务器证书。 选中“验证服务器证书”复选框以在 TLS 信号交换期间验证数据库服务器。 选中“验证服务器证书”时，可以选择指定“验证证书中的主机名”和“证书中的主机名”。 未选中“验证服务器”证书时，将禁用所有加密设置（证书存储文件、验证证书中的主机名和证书中的主机名）。选中“验证服务器证书”复选框被视为典范做法。

可选

加密设置

证书存储文件

对于 SQL Server，不再需要证书存储文件。 由于 Opcenter EX MDD 或 CR 客户端上的 Microsoft 证书存储用于查找证书授权链信任的证书，因此将忽略证书存储文件值。 请参考《Opcenter Execution Medical Device and Diagnostics 安全指南》或《Opcenter Execution Core 安全指南》的“针对 SQL Server 的 Opcenter Execution MDD 或 CR 客户端配置”中的过程。

对于 Oracle，仅当已选择在 Opcenter EX MDD 或 CR 客户端上使用包含证书授权链信任的一个或多个证书的 Oracle 客户端钱包时，才需要证书存储文件。 在此情况下，证书存储文件的值是路径和 cwallet.sso 文件。 否则，Opcenter EX MDD 或 CR 客户端上的 Microsoft 证书存储将用于查找证书授权链信任的证书。 请参考《Opcenter Execution Medical Device and Diagnostics 安全指南》或《Opcenter Execution Core 安全指南》的“针对 Oracle 的 Opcenter Execution MDD 或 CR 客户端配置”中的过程。

可选

验证证书中的主机名

如果选中此复选框，还必须为“证书中的主机名”字段指定值。 在 TLS 信号交换期间，将根据“证书中的主机名”字段中指定的值检查数据库证书中可分辨名称的公用名 (CN) 属性，以确定它们是否匹配。 对于 Oracle，还会根据“证书中的主机名”的值中指定的证书属性，检查数据库证书可分辨名称中的其他证书属性。

可选

证书中的主机名

在证书中的主机名字段中指定要与数据库电子证书中的属性和属性值匹配的属性和属性值，以验证证书中的主机名。

• Oracle。 对于 Oracle，证书中的主机名必须与数据库服务器证书可分辨名称的公用名 (CN) 属性匹配。 如果数据库证书可分辨名称是使用其他证书属性（如组织、组织单位、城市/地区、省/市/自治区/直辖市）生成的，则“证书中的主机名”值中可能需要其他证书属性。 如果在数据库证书可分辨名称中定义了其他属性，则除了公用名属性外，还必须在“证书中的主机名”值中包含这些证书属性。 每个属性必须具有指定的属性缩写，后跟等号和“证书中的主机名”值中的属性值。 每个属性必须用逗号分隔。

Opcenter EX MDD 或 CR Management Studio 中的“证书中主机名”值的示例：
在数据库证书中仅定义 CN 属性：
CN=oramachine12.opac.local


除 CN 属性外，数据库证书中还定义了其他属性：
CN=oramachine12.opac.local, C=US
CN=oramachine12.opac.local, O=APAC, OU=IT,
L=Charlotte, S=North Carolina, C=US


• SQL Server。 对于 SQL Server，证书中的主机名必须仅与证书可分辨名称中的公用名 (CN) 部分匹配。 生成数据库服务器证书可分辨名称时，可能输入了组织、组织单位、城市/区域、省/市/自治区/直辖市等其他证书属性。 在 Opcenter Management Studio 中指定“证书中的主机名”值时，不需要这些附加证书属性，但可以根据需要指定其中任意或全部属性。

Opcenter Management Studio 中验证服务器证书值的示例：

CN=sqlmachine12.opac.local, C=US

CN=sqlmachine12.opac.local

CN=sqlmachine12.opac.local, O=APAC, OU=IT, L=Charlotte, S=North Carolina, C=US

注意：如果已标记“证书中的主机名”复选框，则此字段为必填字段。

必需

站点标识符

站点总数

企业将包含的站点的数目。此数目决定 Siemens 将为企业内的站点预留的标识符范围。

默认值 10 适用于大多数 Siemens 客户。对站点数量估值应留出富余，以便于未来能够扩展。

例如，如果预期为 10 站点个以上，则输入数值就为站点数目加 3。

重要：此数目不得超过 15。如果需要大于 15 的值，请与产品支持联系以讨论该值。

必需

站点标识符

一个编号，表示站点的唯一标识符。

请勿指派 0（零），因为此编号预留供 Siemens 使用。将某个 DBID 指派给站点后，即使在移除该站点之后也不能重用该 DBID。

此编号不得超过 15。

必需

警告阈值

系统通知系统管理员标识符即将用尽时的可用标识符数目（总数可能超过二十亿）。

保留默认值 500000。

必需

如何添加和配置事务数据库

按照以下步骤添加和配置事务数据库：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 右键单击数据库文件夹，然后选择添加事务数据库。此时将显示事务数据库图标，并且事务数据库配置信息会显示在右窗格中。
3. 有关需要在事务数据库连接信息字段中输入的内容的信息，请参考字段定义表。
4. 单击测试连接。如果已成功建立连接，Management Studio 将显示“已建立连接”消息。 否则，应用程序将显示错误消息。
5. 单击确定以关闭消息。
6. 有关需要在站点标识符字段中输入的内容的信息，请参考字段定义表。
7. 单击保存。 Management Studio 将显示成功消息。
