管理性能计数器

可以管理站点的性能计数器，从而在 Management Studio 中捕获性能信息。

性能计数器信息

从“管理”文件夹中选择性能计数器节点时，性能计数器信息会显示在 Management Studio 窗口的右窗格中。Management Studio 中的性能计数器基于选定的计数器一次收集一个计数器的原始数据。该应用程序将性能计数器日志另存为 CSV 文件。默认文件名为 PerformanceCounter.csv。已保存日志的默认位置为 C:\Program Files (x86)\Camstar\Logs。

每次启动性能计数器时，应用程序都会覆盖 PerformanceCounter.csv 文件。

性能日志包含列标题信息。第一列为 DateTimestamp。DateTimestamp 包含收集样本的日期和时间。根据选定的性能计数器设置，可以还包括三个其他列标题：

• 类别
• 计数器
• 实例

每个性能计数器设置标题在名称中由 "[]" 和 "." 分隔。

示例：

DateTimestamp,[类别].[计数器].[实例]

DateTimestamp,[ASP.NET 应用程序].[托管处理器时基百分比（估计值）].[__总数__]

性能计数器会使用 Microsoft 性能监视器和性能计数器。有关 Microsoft 性能监视器和性能计数器的信息，请参考 Microsoft 支持站点。

发生错误时，应用程序会显示一条错误消息。错误会记录在事件查看器中。

如何启动和停止性能计数器

按照以下步骤启动和停止性能计数器：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开管理文件夹并选择性能计数器节点。性能计数器信息会显示在右窗格中。
3. 从服务器字段中选择一个服务器。
4. 从类别字段中选择一个类别。“计数器”字段将启用，并根据所选类别填充计数器列表。
5. 从计数器字段中选择一个计数器。“实例”字段将启用，并根据选定的计数器填充实例列表。
6. 从实例字段中选择一个实例。“开始”按钮将启用。
7. 从要收集的样本字段设置要捕获的样本数。
8. 在采样频率 (秒) 字段中设置捕获样本的频率。
9. 单击启动。Management Studio 会显示“正在收集样本”消息并开始捕获性能信息。然后，Management Studio 显示“停止收集样本”消息，并在收集了指定数量的样本后，将性能信息保存到日志文件中。
10. 单击输出文件 (单击打开) 字段以显示日志文件。
