管理工作区

Siemens 为元数据提供工作区，以降低合作伙伴产品和客户自定义的开发、部署和升级的难度并提高可管理性。元数据记录将指派给客户、合作伙伴、行业解决方案或基础 (csi) 工作区。

注释: 在升级到 Opcenter EX MDD 或 Opcenter EX CR 之后必须转换元数据数据库，以启用适当的工作区功能。

了解工作区

客户、合作伙伴和 Siemens 可以通过工作区更改或自定义 Opcenter EX MDD 或 Opcenter EX CR，且不会覆盖其他用户所作的更改。在一个工作区中进行的更改与对任何其他工作区进行的更新分离。例如，在最高级别工作区中进行的更改不会影响基础工作区。同样，当客户接受对基础工作区进行的更新时，不会覆盖其工作区中的自定义。

Siemens 提供以下四种类型的工作区：

• 基础 (csi)
• 行业解决方案
• 合作伙伴
• 客户 -（公司工作区、部门工作区和站点工作区）

具有最高序号的活动工作区优先，所有工作和用户内容保存在其中。站点工作区是具有最高优先级的工作区。在 Designer 中开始在某个工作区中工作后，无法停用该工作区。

管理工作区

默认情况下，基础工作区和站点工作区处于活动状态。可以通过 Management Studio 激活其他工作区。

还可以停用基础工作区以外的任何其他工作区。无法停用基础工作区。请勿停用站点工作区。

客户始终都应在站点工作区 (200) 中工作。如果客户停用站点工作区并且仅在基础 (csi) 工作区中工作，则当客户安装软件更新时，将覆盖对基础工作区进行的任何更改。

激活或停用工作区后，必须更新事务数据库，包括生成 WCF 服务。

如果 InSite.mdb 文件设为只读，则无法激活或停用工作区。如果在 InSite.mdb 文件为只读的情况下尝试管理工作区，Management Studio 将显示警告消息。

注释: 激活工作区 220 时，将显示警告消息。激活工作区 220 并保存更改会导致未来无法在工作区 200 中进行更改。

如何激活工作区

按照以下步骤激活工作区：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开工作区管理文件夹，然后选择工作区管理节点。工作区管理信息将显示在右窗格中。
3. 选中要激活的工作区的活动复选框。
4. 根据您的业务需求输入可选信息。有关可选字段的信息，请参考字段定义表。
5. 单击保存。 Management Studio 将显示成功消息。
6. 执行“如何针对工作区更改更新事务数据库”过程。

如何针对工作区更改更新事务数据库

按照以下步骤针对工作区更改更新事务数据库：

1. 在“站点”树中展开“数据库”文件夹，然后右键单击事务数据库。
2. 选择更新数据库...。将显示“更新数据库”对话框。
3. 选中生成 WCF 服务复选框。
4. 根据业务要求选择或清除其他更新选项。有关这些复选框的信息，请参考“更新事务数据库”。有关重新生成 WCF 服务（包括管理文件）的信息，请参考《Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。
5. 单击确定。更新过程将开始，该过程完成后，Management Studio 将显示成功消息。
