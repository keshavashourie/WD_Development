配置许可证到期通知

Opcenter EX MDD 和 Opcenter EX CR 提供了许可证到期时自动通知指定收件人的功能。也可以使用 Management Studio 来配置设置，以在许可证到期之前按间隔发送电子邮件通知。可以设置以下两个间隔：

• 警告期
• 紧急期

应用程序将在每个时期发送一次电子邮件通知：一次表示警告，一次表示紧急。例如，如果将警告期设置为 30 天并将紧急期设置为 15 天，您将在许可证到期前的 30 天之前收到警告通知，接着在许可证到期前的 15 天之前收到紧急通知。您还会在许可证到期时收到电子邮件。

配置许可证到期通知

可以将警告期设置为零以禁用警告期电子邮件通知。

可以将紧急期设置为零以禁用紧急期电子邮件通知。

Note: 可在“警告期”字段和“紧急期”字段中输入的最大天数为 365。

可以用分号分隔多个电子邮件收件人地址。至少需要一个地址。

颁发新许可证时，将重置许可证到期日期。

每封电子邮件通知的主题和文本由系统定义。

必须为 Exchange 服务器定义 SMTP 传输，并定义使用该 SMTP 传输的新站点。站点名称必须与 Management Studio 中使用的站点名称匹配。SMTP 传输和站点可以在“建模”页面中进行定义。

在紧急情况下，可以通过产品支持获取临时许可证。例如，如果您订购其他许可证，Siemens 可以在处理您的新许可证订单之前提供临时许可证。

Note: 保存配置信息后，应用程序会将 Siemens PLM License Server 端口号 (28000) 作为前缀添加到许可证服务器字段中。

许可错误

某些登录和注销过程会影响可用许可证的数量。从 Web 浏览器登录到门户时，遵循此基本过程以防止发生错误：

1. 启动 Web 浏览器的新会话。
2. 登录到门户。

有关登录的信息，请参考《Opcenter Execution Medical Device and Diagnostics 入门用户指南》或《Opcenter Execution Core 入门用户指南》。

使用以下任意方法启动浏览器将导致发生许可证错误。不要使用以下过程之一启动浏览器：

• 使用 .exe 文件启动新的浏览器会话（例如从“开始”菜单选择该文件）
• 从现有浏览器会话中打开新窗口
• 从现有浏览器会话中启动新选项卡

Siemens 不支持同一浏览器中应用程序的多个实例。

安装新的许可证而不重新启动产品相关应用程序工具和服务会导致许可证未显示在 Management Studio 中。有关安装新许可证文件的信息，请参考《 Opcenter Execution Medical Device and Diagnostics 安装指南》或《Opcenter Execution Core 安装指南》。

如何配置许可证到期通知

按照以下步骤配置许可证到期通知：

1. 单击开始 > Opcenter Execution MDD > Management Studio。此时将显示 Management Studio 窗口。

或

单击开始 > Opcenter Execution Core > Management Studio。此时将显示 Management Studio 窗口。

2. 展开要为其配置许可证到期通知的站点。
3. 在“站点”树中展开配置文件夹，然后选择配置节点。站点配置信息将显示在右窗格中。
4. 单击许可证选项卡。此时将显示“许可证”选项卡。
5. 选择启用通知电子邮件。
6. 在警告期字段中选择天数，以定义何时发送警告通知。
7. 在紧急期字段中选择天数，以定义何时发送紧急通知。
8. 输入记录为通知电子邮件的电子邮件发件人的电子邮件地址。
9. 输入电子邮件通知将发送到的电子邮件地址（用分号分隔）的列表。
10. 单击保存。 Management Studio 将显示成功消息。
