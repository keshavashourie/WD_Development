Creating New Database Tables

The next step after adding the databases in Management Studio is to populate your database management system (DBMS) with product-related tables. You can create tables for the Transaction database and the DataStore database.

Note: This topic describes creating database tables for the Transaction database. Refer to the Opcenter Execution Medical Device and Diagnostics DataStore Reference Guide or the Opcenter Execution Core DataStore Reference Guidefor information on creating tables for the DataStore database.

When Creating New Database Tables

The metadata fields, tables, relationships, instance data, indexes, stored procedures, and primary keys in the production database are created by performing the Create New Database Tables task. You perform this task after installing Opcenter EX MDD or Opcenter EX CR for the first time.

The Create New Database Table task is designed to automate these processes:

• Creating product-related tables, database indexes, and stored procedures in your DBMS
• Loading the initial default data in your DBMS, including the default security administration roles and permissions

You can select to load the default Portal seed data if applicable.

SSL security is enabled by default, indicating that the Opcenter EX MDD and Opcenter EX CR products and modules run in a secure environment. If you have disabled SSL security, you can clear the checkmark from the Encrypt Web Traffic check box when generating WCF services. Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information on SSL security.

A Databases menu appears on the Management Studio window when the Databases folder or database nodes are selected. Refer to "Databases Menu" for information on the Databases menu.

In Clustered Environments

Perform the Create or Update process only once from any member in the cluster in a clustered environment.

Create Tables Dialog Box Check Box Definitions

This table defines the check boxes on the Create Tables dialog box.

Option

Definition

Type

Update Metadata and Schema

Disabled when creating database tables. Enabled when performing a database update.

Optional

Force Database Schema Update

Disabled when creating database tables. Enabled when performing a database update.

Optional

Force ODS Database Schema Update

Disabled when creating database tables. Enabled when performing a database update.

Note: If an ODS is not present or if the ODS is turned off, then the Force ODS Database Schema Update check box option will be disabled. If the ODS is present, then the Force ODS Database Schema Update check box option will be automatically checked when the Force Database Schema Update check box option is selected.

Optional

Create Stored Procedures

Runs the InstallProcedures.bat file. The stored procedures for Opcenter EX MDD or Opcenter EX CR are a collection of SQL statements and logic controls that are defined and stored in the database and called by programs. Default stored procedures contain platform-specific rules, improve performance, and reduce network traffic. Because data objects use a common set of rules, logic is centralized.

Select this option when you change or add any of these stored procedures, or when you are creating the initial database.

Optional

Create Indices

Triggers the creation of new or altered indexes. This option should always be checked.

Note: Any changes made to indexes are logged in the Replace Workspace Data utility's log file. Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Medical Device and Diagnostics Installation Guide for information on the Replace Workspace Data utility.

Optional

Load Configuration

Updates the database with any configuration changes made on the Configuration pane.

Note: This option is always selected and disabled.

Optional

Load Initial Data

Runs the csiPopulateReleaseData.bat script to create instances such as the default logins (CamstarAdmin, Administrator and InSiteAdmin), primary keys, etc., in the database tables. This provides you with the initial modeling definitions as a starting point for first-time installations.

This script also loads the initial default roles and associated permissions.

Optional

Reload Menus

Restores the default Portal menus. Any changes made to the default menus are overwritten. Custom menus are not overwritten or deleted. Custom menus remain available in Portal Studio.

Note: This check box is not available for selection when creating tables.

Optional

Reload Change Management Seed Data

Reloads the initial data to use with the Change Management application. Any changes made to the default change management spec and change management workflow modeling objects are overwritten. Custom change management modeling objects are not overwritten or deleted.

Important: Siemens does not recommend using this option in your production environment. If this option is used, all the original change management instances will be reset to the state after the initial installation and their IDs will be changed. Also, any existing change management packages will be orphaned.

Note: This check box is not available for selection when creating tables.

Optional

Populate SPC Tester Data

Downloads data that can be used with the SPC Test page.

Optional

Cleanup Orphaned Permissions

Disabled when creating database tables. Is enabled when performing a database update.

Optional

Load Camstar Portal Objects

Populates the Portal with objects created in Modeling. Refer to the Opcenter Execution Medical Device and Diagnostics Modeling User Guide or the Opcenter Execution Core Modeling User Guide for information on how to create and modify Portal Modeling Definitions.

Optional

Reload All

Reloads all objects when checked.

Optional

Load Camstar Dictionaries

Populates the Portal with dictionary labels from CSV files located in the Insite Administration\Dictionaries folder. Placing custom CSV files containing translations for labels enables foreign language labels or customized labels to appear in the Portal. Refer to the Opcenter Execution Medical Device and Diagnostics Modeling User Guide or the Opcenter Execution Core Modeling User Guide for information on how to create and modify dictionary definitions.

Optional

Reload All

Reloads all dictionaries when checked.

Note: This check box is not available for selection when creating tables.

Optional

Generate WCF Services

Generates the DLL that contains the exposed service and data contracts by extracting their definitions from the MDB. You should select this option when enabling or disabling workspaces. Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information on generating WCF services.

Optional

Encrypt Web Traffic

Enables you to generate WCF services using SSL security. Encrypt Web Traffic is selected by default.

Optional

Generate REST API Services

Generates all of the REST API model and starts the REST API services if selected. This option is valid only if you are using static DLLs as set by default in the appsettings.json file. Refer to information on error responses in the Opcenter Execution Medical Device and Diagnostics Technical Reference: REST API or the Opcenter Execution Core Technical Reference: REST API if an error occurs.

Optional

How to Create New Database Tables for the Transaction Database

Follow these steps to create new database tables for the Transaction database:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand Databases, and then right-click Transaction Database.
3. Click Create New Database Tables. The Create Tables dialog box appears.
4. Leave the default selections.

 

5. Click OK. The message "Creating a new transaction database completed successfully" appears at the bottom of the Management Studio window.
