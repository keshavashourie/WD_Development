Managing Databases

The next step in the configuration process is to create the databases. There are three types of databases you can add.

Type

Definition

Metadata

The databases, InSite.mdb and SiteInfo.mdb, are used by Designer. These databases contain Opcenter EX MDD or Opcenter EX CR configuration information.

Transaction

The transaction database is the main production database used by Opcenter EX MDD or Opcenter EX CR. It stores all your Opcenter EX MDD or Opcenter EX CR information such as tables and instances. Also called OLTP.

DataStore

DataStore is an operational database that is separate from the transaction (production) database. It is only required if you will be running DataStore.

Metadata fields, tables, relationships, instance data, indexes, stored procedures, and primary keys in the production database are:

• Created through the Create New Database Tables menu option, and
• Updated by the Update Database menu option.

Refer to the current Release Matrix for OC EX MDD on the Support Center for information on supported database versions.

Refer to the current Release Matrix for OC EX CR on the Support Center for information on supported database versions.

When Creating Databases

You must create a:

• Metadata database before you can create a Transaction database.
• Transaction database before you can create a DataStore database.

These two databases are required. The DataStore database is only required if you have DataStore installed.

The metadata database uses the Designer data sources, InSite.mdb and SiteInfo.mdb, which are created by the install. The Designer and InSite SiteInfo are automatically defined with the Administration and Configuration component during installation.

Note: In a clustered environment, verify that each member of the cluster has the same settings for the ODBC info and site info tabs.

When Updating Databases

The Update Databases selection is capable of sending updates to your different database types, such as transaction or operational databases, as long as the database configurations are in place.

Special Note on Oracle Databases

Oracle Enterprise Edition does not lock database tables while the indices are rebuilt. Therefore, all Opcenter EX MDD or Opcenter EX CR transactions will run successfully during this update process.

However, if you are using Oracle Standard Edition, database tables may be temporarily locked while the indices are rebuilt. Some Opcenter EX MDD or Opcenter EX CR transactions may fail if the transaction is trying to access a temporarily locked table. Therefore, it is recommended that you do not run Opcenter EX MDD or Opcenter EX CR transactions during a database update with Oracle Standard Edition.

When Deleting Databases

Databases must be deleted in reverse order of how they were created. For example, you must delete the DataStore database before you can delete the Transaction database. You must also delete the Transaction database before you can delete the Metadata database.

Deleting a database in Management Studio does not affect the data in the database. It only removes the entry in the .mdb.
