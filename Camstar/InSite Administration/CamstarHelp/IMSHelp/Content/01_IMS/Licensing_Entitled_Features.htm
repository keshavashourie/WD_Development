Viewing Entitled Features

You can view a list of entitled (licensed) features that exist across your active workspaces from the Feature Entitlement pane in Management Studio.

When Viewing Entitled Features

Feature entitlement information appears in the right pane of the Management Studio window when Feature Entitlement is selected from the Workspace Administration folder. The Feature Entitlement pane displays all the features entitled to your active workspaces.

Feature Entitlement Pane Field Definitions

This table defines the fields on the Feature Entitlement pane.

Field

Definition

Type

Feature Entitlement grid

Name

Unique name of the feature.

Display Only

Feature Display Name

Unique name that appears in Designer on the Feature Entitlement tab. Refer to the Opcenter Execution Medical Device and Diagnostics Designer User Guide or the Opcenter Execution Core User Guide for information on feature membership.

Display Only

Workspace Code

Workspace code of the associated workspace for the feature.

Display Only

Feature Id

Unique ID of the feature.

Display Only

How to View Entitled Features

Follow these steps to view entitled features:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Workspace Administration folder and select the Feature Entitlement node. Feature entitlement information appears in the right pane.
