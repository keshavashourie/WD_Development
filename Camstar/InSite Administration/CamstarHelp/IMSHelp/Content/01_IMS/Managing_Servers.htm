Managing Servers

You can add one or more servers to a site.

The Application Server is the core transaction server that runs the business logic. All transactions are processed through the Application Server, which provides these services:

• Contains the Opcenter EX MDD or Opcenter EX CR product and factory information model that encapsulate the business rules and logic.
• Enables users to define their business rules through configurable data objects (CDOs) and configurable logic flows (CLFs).
• Communicates with client applications using XML documents. It listens for incoming XML documents from HTTP/S client requests, parses the documents, and processes them as Opcenter EX MDD or Opcenter EX CR transactions. It returns an XML document of the results.
• Stores and retrieves information.
• Provides translation between the Object Model and industry-standard relational databases to store and retrieve data.
Note: Servers must use the same transaction database in Management Studio. For example, your localhost and an additional remote server must both use the same transaction database.
Important: The Application Server, transaction (OLTP) database, and DataStore (ODS) database servers must be co-located in the same geographic datacenter. These servers must be configured for the same time zone, and be physically on the same VLAN (one hop). Ideally, all of these servers are connected to the same network switch. The network latency from the Application Server to the OLTP database server should optimally be less than 1 millisecond, but no more than 5 milliseconds to ensure the best performance of Opcenter EX MDD and Opcenter EX CR products.

When Adding Host Information for a Server

Host information for a server appears in the right pane of the Management Studio window when you select an existing server or add a new server.

A Camstar Servers menu appears on the Management Studio window when the Camstar Servers folder or server nodes are selected. Refer to "Camstar Servers Menu" for information on the Camstar Servers menu.

The Save and Discard buttons are disabled until you enter text in the Hostname or IP Address field. Click Save to save your changes. Click Discard to undo your changes and restore the previous field values.

A message prompts you to save or cancel if you try to close the Host Information pane without discarding or saving your changes. Follow the directions to save or discard your changes.

How to Add a Server

Follow these steps to add a server:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Right-click the Camstar Servers folder, and select Add Camstar Server. A new server icon appears under the Camstar Servers folder, Host Information fields appear in the right pane, and the server name is in edit mode.
3. Enter the name for your new server in the highlighted NewServer node.
4. Enter the Hostname or IP Address for the server.
5. Verify that the entry in the Port field is 443.
6. Click Save. Management Studio displays a success message.

How to Rename a Server

Follow these steps to rename a server:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Right-click the server you want to rename in the Camstar Servers folder, and select Rename. The server name is changed to edit mode.
3. Enter the new server name.
4. Click Save. Management Studio displays a success message.

How to Delete a Server

Follow these steps to delete a server:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Right-click the server you want to delete in the Sites tree and select Delete. The Confirm Server Deletion message appears.
3. Click Yes. The server is deleted from the Sites tree.
