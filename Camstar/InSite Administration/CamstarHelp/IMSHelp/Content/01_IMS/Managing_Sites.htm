Managing Sites

Site-specific information is critical for the designation of unique identifiers and database updates. It is not expected to change often.

The site name is a unique but meaningful name assigned to the Opcenter EX MDD or Opcenter EX CR installation. For example, you could assign a site name to match a geographical location.

When Managing Sites

Opcenter EX MDD or Opcenter EX CR configuration begins with the creation of a new site. A new site tree appears when you select Add Site from the Sites menu or shortcut menu.

A Sites menu appears on the Management Studio window when the Sites folder or a site tree are selected. Refer to "Sites Menu" for information on the Sites menu.

You can rename and delete sites. Additionally, you can export a site’s configuration file to another location for testing and backup purposes. You can also import a site into Management Studio from a previously exported configuration file that contains all the configuration information for the site.

How to Add a Site

Follow these steps to add a site:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Right-click the Sites folder and select Add Site. A new site tree appears and the default site name is in edit mode.
3. Enter a name for your site in the highlighted NewSite node.
Important: The Site Name is equal to the Site ID in previous versions of the software ; therefore, if you are upgrading from a previous version, you must enter the Site ID.
4. Press Enter. A confirmation message appears.
5. Click Yes to save the new site name to the configuration file for this site, or click No to cancel the site addition.

How to Rename a Site

Follow these steps to rename a site:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Sites folder if necessary.
3. Right-click the site in the Sites tree and select Rename Site. The site name changes to edit mode.
4. Enter the new site name and press Enter. A confirmation message appears.
5. Click Yes to save the new site name to the configuration file for this site.

Or

Click No to cancel the new site name.

How to Delete a Site

Follow these steps to delete a site:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Sites folder if necessary.
3. Right-click the site you want to delete in the Sites tree and select Delete Site. The Confirm Site Deletion dialog box appears.
4. Click Yes to remove the site from the Sites tree, or click No to cancel the site deletion.

How to Export a Site

Follow these steps to export a site:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Sites folder if necessary.
3. Right-click the site you want to export, and then select Export Site. The Save Site As window appears.
4. Select a location for the saved file if necessary.
5. Name the exported configuration file. By default, it will be the name of the site with an extension of .ims. When you export a site's configuration, it saves the current configuration in each folder under that specific site’s folder.
6. Click Save. The site is exported to the indicated location.

How to Import a Site

Follow these steps to import a site:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Sites folder if necessary.
3. Right-click the main Sites folder in the Sites tree and select Import Site. The Select Configuration File window appears.
4. Locate the site file you want to import and click Open. The site is imported into the current display, adding a new site node and displaying the Transaction Database Configuration window for that site.
