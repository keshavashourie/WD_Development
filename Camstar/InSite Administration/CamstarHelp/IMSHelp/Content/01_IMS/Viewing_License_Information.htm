Viewing License Information

Management Studio allows you to view the number of licenses available to your enterprise, view the number of licensed users currently using Opcenter EX MDD or Opcenter EX CR, and the expiration date of your licenses.

When Viewing License Information

License information appears in the right pane of the Management Studio window when you select License Information from the Administration folder.

If you notice that the number of licenses in use is always close, or equal, to the number of licenses available, you may need more licenses. Please contact Product Support for information on purchasing additional licenses.

The number of licenses in use is captured at the time the License Information page is displayed. To see the most current number of licenses in use, simply navigate away from the License Information page and then redisplay the License Information page.

You can also view the Event Log to see if the number of users attempting to log into the application exceeds the number of available licenses.

Temporary licenses are available on an emergency basis through Product Support. For example, if you order additional licenses, Siemens can provide temporary licenses until your new license order is processed. Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information on installing new licenses.

How to View the Number of Licenses in Use

Follow these steps to view the number of licenses in use:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Administration folder in the Sites tree and select License Information. The License information appears in the right pane.
3. View the information in the Licenses in Use field.

How to Check the Log for Exceeded Number of Concurrent Users

Follow these steps to check the event log for exceeded number of concurrent users:

1. Click Start > Windows Administrative Tools > Event Viewer. The Event Viewer window appears.
2. Expand the Applications and Services Logs.
3. Click Camstar.
4. Look for errors with Camstar Security as the Source.
5. Select the error to see the details. For example, it may indicate that "Maximum number of concurrent users is reached, please try again later."

How to Check the Log to See if Your License Has Expired

Follow these steps to check the event log to see if your license has expired:

1. Click Start > Windows Administrative Tools > Event Viewer. The Event Viewer window appears.
2. Expand the Applications and Services Logs.
3. Click Camstar.
4. Look for errors with Camstar Security as the Source.
5. Select the error to see the details. For example, it may indicate that "Service Initialization failed due to the following error: License for CamstarServerApplication is expired, contact your licensing administrator."
