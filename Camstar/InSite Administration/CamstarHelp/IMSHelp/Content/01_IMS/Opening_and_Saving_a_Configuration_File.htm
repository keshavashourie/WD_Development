Opening and Saving a Configuration File

Management Studio initially displays an empty configuration that has not been saved. You can create a new configuration and save your changes. You can also open any Management Studio configuration file that was previously saved.

Note: You can view configuration information for a specific site and only that site.

Saved configurations and exported sites are written to an XML file that has the extension ims.

When Saving a Configuration File

Management Studio allows you to save the current configuration file or to save the current configuration file with a new name or to a new location.

The Save Configuration As window appears the first time you save the default configuration file. It also appears when you select the Save Configuration As option from the File menu.

How to Open a Configuration File

Follow these steps to open a configuration file:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

How to Save a Configuration File

Follow these steps to save a configuration file in Management Studio:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Select Save Configuration from the File menu or click the Save button. The current configuration file is saved and the message, "Configuration Saved Successfully," appears at the bottom of the Management Studio window.

How to Save a Configuration File as Another File

Follow these steps to save a configuration file as another file in Management Studio:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Select Save Configuration As from the File menu. The Save Configuration As window appears.
3. Click the configuration file name that you want to save as another name.
4. Enter the new name in the File name field.
5. Click Save. The new configuration file is saved.
