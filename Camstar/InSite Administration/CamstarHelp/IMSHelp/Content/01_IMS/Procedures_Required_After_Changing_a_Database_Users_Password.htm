Procedures Required After Changing a Database User’s Password

If you have changed the user/schema password at the database level, then related procedures are required to change the user’s password for the Transaction database (OLTP) and, if relevant, the DataStore database.

Transaction Database Procedures

Perform these Management Studio procedures in the order listed to change the password for the Transaction database user:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Databases folder and select the Transaction database. The Transaction Database Configuration information appears in the right pane.
3. Update the entry in the Password field to match the password entered for the DBMS.
4. Click Test Connect button to verify that a connection from the database to the data source was actually established. Management Studio displays a Connection Established message.
5. Click Save.
6. Perform the "How to Update the Transaction Database" procedure.

DataStore Database Procedures

Perform these Management Studio procedures in the order listed to change the password for the DataStore database user:

1. Click Start > Opcenter Execution MDD > Management Studio. The Management Studio window appears.

Or

Click Start > Opcenter Execution Core > Management Studio. The Management Studio window appears.

2. Expand the Databases folder and select the DataStore database. The DataStore Database Configuration information appears in the right pane.
3. Update the entry in the Password field to match the password entered for the DBMS.
4. Click Test Connect button to verify that a connection from the database to the data source was actually established. Management Studio displays a Connection Established message.
5. Click Save.
6. Perform the "How to Update the Transaction Database" procedure.
Note: If the DataStore database password is changed, transactions will continue to process and DataStore will propagate normally.
