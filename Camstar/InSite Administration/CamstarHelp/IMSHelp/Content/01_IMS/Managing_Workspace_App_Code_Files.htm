Managing Workspace App Code Files

Siemens provides a MergeAppCode executable to merge app code files across your active workspaces.

When Managing Workspace App Code Files

The MergeAppCode executable (MergeAppCode.exe) works through each workspace subfolder and changes the inheritance on each app code file to inherit from the workspace above it. For example, if the csi, 180, and 190 workspaces are all active, then the MoveStd_190 inheritance would change from ":MoveStd" to ":MoveStd_180." The executable is available at the file path C:\Program Files (x86)\Camstar\Insite Conversion Tool\MergeAppCode.

A configuration file (MergeAppCode.exe.config) for modifying the executable is available at the file path C:\Program Files (x86)\Camstar\Insite Conversion Tool\MergeAppCode. You can modify the WebPortletPath key with the relative or absolute path to the WebPortlet folder.

Important: Do not alter the mdbConnectionString key in the MergeAppCode.config file.

You must add workspace subfolders at the file path C:\Program Files (x86)\Camstar\Camstar Portal\App_Code\WebPortlets\Workspaces to store your app code files for merging. Workspace subfolders must be named the code of the associated workspace. For example, the subfolder associated with workspace 200 must be named "200."

You must append all custom controls, functions, and property names with the associated workspace code. For example, a control named "ControlName" in workspace 200 must be named "ControlName_200" to allow the executable to determine the associated workspace and inheritance. All files must be stored in their associated workspace subfolder.

An error message appears if no active workspaces are available, excluding the base csi workspace, or if the WebPortletPath cannot be found. Errors are logged in the Event Viewer.

How to Merge App Code Files

Follow these steps to merge app code files:

1. Navigate to the file path C:\Program Files (x86)\Camstar\Insite Conversion Tool\MergeAppCode.
2. Double-click MergeAppCode.exe. A Command Prompt pop-up appears as the executable merges the app code files and displays a success message when finished.
