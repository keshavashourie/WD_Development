Managing Workspace JavaScript and CSS Files

You can store custom JavaScript and CSS files for each active workspace which allows custom code to be extended to sequential higher workspaces. The application works through each active workspace, excluding the base csi workspace, and searches files for duplicate functions in your code files before bundling the higher active workspace functionality.

When Managing Workspace JavaScript and CSS Files

You must add a workspace subfolder at the expected file paths when storing custom workspace JavaScript and CSS files. Workspace subfolders must be named the code of the associated workspace. For example, the subfolder associated with workspace 200 must be named "200."

The expected file paths for workspace subfolders are:

• Camstar\Camstar Portal\Scripts\User for JavaScript files.
• Camstar\Camstar Portal\Themes\User for CSS files.

Only one user code file can exist in each workspace subfolder. You must follow the naming convention "WorkspaceCode.js" and "WorkspaceCode.css," where "WorkspaceCode" is the workspace's code, such as "180" or "190". For example, "200.css" is an accepted file name for a CSS file, and must be placed in the "200" subfolder in the Camstar\Camstar Portal\Themes\User folder.

Bundling of custom code files occurs when the server starts. Siemens recommends stopping and restarting your servers when adding or updating workspace code files.

Managing Workspace JavaScript and CSS Files Example

In this example, workspaces 190 and 200 are currently active. You have JavaScript files for both workspaces and a CSS file for the 200 workspace. These steps outline the correct way to store these files:

1. Navigate to the file path Camstar\Camstar Portal\Scripts\User.
2. Create a new folder named 190.
3. Create another new folder named 200.
4. Rename your JavaScript file for workspace 190 as 190.js and copy it to the newly created 190 folder.
5. Rename your JavaScript file for workspace 200 as 200.js and copy it to the newly created 200 folder.
6. Navigate to the file path Camstar\Camstar Portal\Themes\User.
7. Create a new folder named 200.
8. Rename your CSS file for workspace 200 as 200.css and copy it to the newly created 200 folder.

The application bundles the stored files when the server starts. In this example, the application bundles the 200.css file and looks for duplicate functionality in the 190.js and 200.js folders, and then bundles duplicate functionality found in the 200.js file over the 190.js file, because the 200.js file is associated with the highest active workspace.
