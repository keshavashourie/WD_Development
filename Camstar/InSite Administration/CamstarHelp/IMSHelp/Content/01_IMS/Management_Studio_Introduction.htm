Management Studio

Management Studio enables you to configure Opcenter EX MDD or Opcenter EX CR products after installation. These include Manufacturing and Opcenter EX CR Intelligence. Management Studio consolidates basic configuration and administration tasks into a single application that is installed with the Administration Tools.

You use Management Studio to maintain a list of sites and configuration information for each site. A site is one or more Application Servers that share a transaction database. A site can be a cluster of Application Servers or a single Application Server.

Configuration Procedures Overview

This list identifies the procedures required to configure Opcenter EX MDD or Opcenter EX CR. These procedures are performed in the order listed.

1. Open Management Studio.
2. Define the database configuration for the transaction database, and optionally for the DataStore database.
3. Create the new site.
4. Configure the servers.
5. Configure the databases.
6. Create the database tables.
7. Configure Opcenter EX MDD or Opcenter EX CR, including security and notification settings.
