Configuring Industry Solutions

The Industry Solutions Configuration Tool enables you to configure the workspaces necessary to run the industry solution features. Files needed for the industry solution features are provided as part of Opcenter Execution MDD or Opcenter Execution CR , but you must configure them using the tool. You must run the tool if you want to use any of the following features:

• CIO
• Opcenter EX CR Scheduling
• Overall Equipment Effectiveness (OEE)
• Medical Device
• Batch Processing
• Shop Floor Resource Configuration (SRC)

The Industry Solutions Configuration Tool provides a mechanism to deliver CIO functionality that enables you to send messages outbound from Opcenter Execution MDD or Opcenter Execution CR to external applications.

The industry solutions workspaces provide a mechanism to easily deliver features specific to the medical device industry. Features are developed in the industry solutions workspaces and are therefore isolated. This enables the medical device-specific functionality to remain separate while still allowing the inheritance of subsequent Opcenter Execution MDD or Opcenter Execution CR changes.

You must be licensed for Opcenter Execution Core Batch Processing to use the Batch Processing features. You must be licensed for Opcenter EX CR Scheduling to use the Opcenter EX CR Scheduling features.

Refer to the Opcenter Execution Medical Device and Diagnostics Installation Guide or the Opcenter Execution Core Installation Guide for information on installing Opcenter Execution MDD or Opcenter Execution CR, and its components.

Refer to the following guides for information specific to installing, configuring, and using these features:

• Opcenter Execution Medical Device and Diagnostics Scheduling User Guide or the Opcenter Execution Core Scheduling User Guide
• Opcenter Execution Medical Device and Diagnostics Industry Solutions User Guide or the Opcenter Execution Core Industry Solutions User Guide
• Opcenter Execution Medical Device and Diagnostics Medical Device User Guide or the Opcenter Execution Core Medical Device User Guide

When Configuring Industry Solutions

The Industry Solutions Configuration Tool enables you to merge the databases and run scripts associated with the workspaces. The tool also verifies dependencies. For example, CIO must be installed before the Industry Solutions or Batch Processing workspaces can be installed.

You select the workspaces you want to install. Available workspaces include:

• CIO
• Industry
• OEE
• Medical Device
• Batch Processing
• SRC

The Industry Solutions Configuration Tool performs the following after you make your selections and click Finish:

1. Displays the Confirm Installation dialog box which indicates information such as the install type and selected feature workspaces. You can click OK to proceed with the installation or cancel.
2. Verifies that the correct version of Opcenter Execution MDD or Opcenter Execution CR is installed
Note: The tool returns an error if the correct version is not installed.
3. Indicates that CIO is required if you selected Industry or Batch Processing
Note: You must select CIO to continue with the installation. The tool does not indicate that CIO is required if you select Medical Device only.
4. Prompts you to enter DataStore database details if you select OEE
Note: The tool returns an error if you do not enter all details. The Industry workspace is required for the OEE option. The tool returns an error if you do not select the Industry workspace. The tool verifies that the connection to the DataStore database is successful. The tool returns an error if you do not provide the correct connection information.
5. Runs the Replace Workspace Data utility for each workspace you selected
6. Copies the .js, .css, and .cs files for each selected workspace to the appropriate locations in the \Camstar\Industry Solutions\<feature>\Camstar Portal folder
7. Updates the settings.xml file with the CDOForms settings for each selected workspace
8. Generates the WCF services
9. Moves the virtual pages .xml files for each selected workspace to the InsiteAdministration\PortalData folder
10. Performs a database update (dbupdate)
11. Imports Portal forms for each selected workspace
12. Executes menu definition and roles scripts for each selected workspace
13. Restarts the CamstarAppServer and CamstarSecurityServices application pools
14. Executes the Industry Solutions IPL integration configuration scripts if Industry is selected and the required data is entered
15. Executes Industry Solutions OEE scripts if you select OEE

A progress bar appears on the Industry Solutions Configuration Tool dialog box to indicate the status of the configuration. The tool displays a dialog box when the process finishes.

You can use the industry solution features after the configuration completes. Opcenter EX CR Scheduling requires you to install and configure Preactor. Refer to the Opcenter Execution Medical Device and Diagnostics Scheduling User Guide or the Opcenter Execution Core Scheduling User Guide for information.

Configuring Shop Floor Resource Configuration (SRC) in Industry Solutions

The Shop Floor Resource Configuration (SRC) functionality for managing the IPL Smart Settings is installed using the Industry Solutions Configuration Tool. For the SRC to be fully functional, the Valor MSS Shop Floor Application Server must also be installed and configured.

Note: If you are upgrading from the current release or installing an update release to the current version, fewer dialog boxes appear when you run the installer. The interface guides you through the upgrade process.

Before Configuring SRC Installation

SRC requires ASP.NET Core 8.x Windows Hosting Bundle and .NET Desktop Runtime 8.x to be installed. If they are not yet installed, a dialog box will be displayed to prompt if you want to download and install ASP.NET Core 8.x Windows Hosting Bundle and .NET Desktop Runtime 8.x support. You will be directed to the Microsoft site to download the installer for .NET Desktop Runtime 8.x after clicking the OK button. The SRC installation will not proceed if you select No on the dialog box. Once .NET Desktop Runtime 8.x has been installed, you will need to re-open the Industry Solutions Configuration Tool and re-select SRC to complete the installation. It is possible to proceed with SRC Installation without installing the ASP.NET Core 8.x Windows Hosting Bundle, but SRC cannot function without it, so it is absolutely necessary to install the ASP.NET Core 8.x Windows Hosting Bundle.

Refer to the Release Matrix on Siemens Support Center for information on the supported version for the Hosting Bundle.

How to Configure Shop Floor Resource Configuration

Follow these steps to configure Shop Floor Resource Configuration:

1. Ensure you have performed the first six steps of "How to Configure Industry Solutions."
2. Once the SRC installer starts, an initial installer dialog box is displayed. Click Next. The installer dialog box displays Installation Folder fields on IPL folder information.
3. On the Components Folder and Home Folder fields, make changes according to your business requirements. Click Next.The installer dialog box displays the License Server fields indicating the location of the Mentor Graphics License Server
4. Enter the License Server Name, License Server Port and TimeOut. Click Next. A test is performed automatically to check if the connection to the server is valid. Once finished, the installer dialog box prompts for Opcenter Connect MOM Web API Adapter information used by IPL applications to send messages to Opcenter Execution Core.
5. Enter the WebAPI adapter IP address/hostname, Web API adapter port, and Web API adapter protocol. Click Next. The installer dialog box prompts for Opcenter EX CR Rest API credentials.
Note: SRC does not require Opcenter Connect MOM to be installed in order for SRC to be installed or function. It is requesting this information to provide it to other applications that communicate with SRC.
Note: Previously, SRC required that Opcenter Execution Electronics also be installed and that the appropriate Opcenter Connect MOM configuration script (ES_MIO_ConfigurationLoad.cfg) be run to create the required CN MOM objects. However, the hardcoded use of the es_valorinbound Web API Adapter has been removed. This will support non-Electronics environments where only Industry is installed that provides the is_valorinbound Web API Adapter. If you have installed Opcenter Execution Electronics, the es_valorinbound Web API Adapter will be used.
6. Enter the Username and Password. Click Next. SRC Server Configuration fields is display.
Important: The Opcenter Execution REST API user name and password must be configured to avoid failing the connection test to the server.
7. Select the network protocol options according to your business requirements.
8. Enter SRC server HostName or IP, selected Http Port or Https port, and the SSL Certificate. Click Next. A Preinstallation Summary dialog box appears.
9. Click Install. A progress bar appears on the SRC Installer dialog box. After it is finished installing, the screen displays a complete installation message.
10. Click Close. The SRC Installation dialog box closes.

Additional Modeling for Full Functionality

It is necessary to create or update a Shop Floor Instance where the SRC API must be configured in order to make SRC fully functional. This Shop Floor Integration Settings instance must then be assigned to the Factory that is associated with the Employees. So, in the Shop Floor Integration Settings object, the SRC API must be configured with the appropriate value. Typically this would be the following:

https://servername:5443/

Where ‘servername’ is the appropriate value for the server where SRC is installed.

For more information, refer to the Opcenter Execution Core Modeling User Guide.

How to Uninstall SRC

Follow these steps to uninstall SRC.

1. Go to Control Panel. The Control Panel window appears.
2. Click Uninstall a Program. The Programs and Features window appears.
3. Select Opcenter Execution Core SRC [version number] and click Uninstall.
